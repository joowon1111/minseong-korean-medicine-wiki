# 고전→현대 연구 연결 지도

고전 병증명과 현대 질환명을 일대일 대응시키지 않습니다.

`고전 원문 → 병증·맥증 → 치법 → 본초·방제·경혈 → 현대 연구의 대상군·중재·결과지표`

## 황제내경
장부·경락·병기·침구의 이론적 토대를 현대 경락·경혈 지식망과 연결합니다.

## 상한론·금궤요략
처방명보다 맥증·병위·한열·허실·수기를 먼저 읽고 현대 임상시험의 대상자 기준과 비교합니다.

## 동의보감
허로·잡병·탕액·침구를 현대 보익·소화·통증·여성·호흡기 연구와 연결합니다.

## 동의수세보원
체질명만 보지 않고 소증·체질병증·표리·순역이 연구에서 어떻게 진단되었는지 확인합니다.
