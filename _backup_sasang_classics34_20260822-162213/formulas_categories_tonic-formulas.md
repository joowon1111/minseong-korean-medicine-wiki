# 보익 처방 임상 지식망

보익 처방은 단순히 피로에 쓰는 처방군이 아니라 **어떤 허증을 무엇으로 보하는가**를 중심으로 비교합니다.

## 변증별 대표 처방

| 변증 | 대표 처방 |
|---|---|
| 기허 | 사군자탕 · 보중익기탕 |
| 비위기허·담음 | 육군자탕 · 향사육군자탕 |
| 혈허 | 사물탕 |
| 기혈양허 | 팔물탕 · 십전대보탕 |
| 심비양허 | 귀비탕 |
| 신허 | 육미지황환 · 팔미지황환 |
| 보익·정혈 | 공진단 · 경옥고 |

→ [임상 핵심 변증](../../diagnostics/patterns/index.md)

## 본초 구조
