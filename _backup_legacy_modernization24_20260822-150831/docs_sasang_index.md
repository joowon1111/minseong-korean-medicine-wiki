# 사상의학 지식망

사상의학은 이제마가 체계화한 한의학의 의학 체계로, 태양인·소양인·태음인·소음인의 네 체질과 각 체질의 생리·병리·병증·치료 원칙을 함께 살핀다.

```text
사상체질
  ↓
평소의 소증
  ↓
현재 병증
  ↓
표리·한열·경중
  ↓
치법·체질 처방
```
