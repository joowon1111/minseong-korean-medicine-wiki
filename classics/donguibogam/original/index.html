    동의보감 원문 열람·검색¶

    한문 원문은 아래 원문 검색에서 찾습니다. 검색어를 모르면 권별 원문 목록을 열고, 이미지로 읽으려면 편별 영인본 목차에서 원하는 권을 선택합니다. 일반 아카이브 검색은 기존 질환·본초·방제·경혈 문서를 중심으로 유지합니다.

    수록 범위와 읽는 방법¶

    자료 이 화면에서 할 수 있는 일 현재 범위
    원문 전사 한글 약재명·한자명·원문 구절로 검색하고 본문 읽기 탕액편 3권의 전사와 내경편 권1 신형·정의 확보된 부분
    전권 영인본 책과 페이지를 선택하여 원전 이미지 열람 국립중앙도서관 자료 CNTS-00047980284의 목판본 23권 25책
    임상 해설 원문에서 기존 본초·방제 문서로 이동 연결이 확인된 본초·방제부터 안내

    전사 전체의 교감과 전권의 검색 가능한 텍스트화는 완료되지 않았습니다. 위키문헌 전사에는 오자·누락이 있을 수 있어 정확한 글자·용량·포제는 출처의 영인 페이지와 대조합니다. 탕액편 전사에 대응하는 영인본과 전권 열람용 목판본은 별도 자료이며, 같은 판본으로 합쳐 표시하지 않습니다. 출처가 명시한 간행연도가 없는 전권 영인본에 1613년 초간본이라는 이름을 붙이지 않습니다.

    원문은 역사적 의학 기록입니다. 고전의 無毒이나 용량·주치가 오늘의 안전성·효과·복용법을 보증하지는 않습니다. 실제 활용의 기원종·제형·금기·병용약은 본초 문서와 한약 안전성을 함께 읽습니다.

    원문 검색과 열람¶

    원문 열람기를 준비합니다.

    범위를 고른 뒤 목록을 열면 수록된 원문을 50항목씩 모두 둘러볼 수 있습니다. 한글명은 검색을 돕는 이름이며, 고전 약재와 현대 약재의 기원·부위·규격이 같다는 뜻은 아닙니다.

    전권 영인본

    본문 23권과 목록 2권을 편·권 이름으로 찾습니다. 아래 목차에서 권을 누르면 본문 위치로 이동하며, 제1책은 앞부분의 총목·서문을 지나 신형 항목을 엽니다. 표시한 항목은 원전의 편목으로, 해당 권의 모든 글자가 검색되는 것은 아닙니다.

    이미지는 Wikimedia Commons에서 선택한 한 페이지씩 불러옵니다. 이미지 페이지 번호는 PDF의 순서이며 원전의 장차와 다릅니다. 전사에 대응하는 영인 페이지는 원문 항목의 출처 링크에서 확인합니다.

    출처·전사·이용조건¶

    한의학고전DB의 본문·번역·교감 자료를 가져오지 않았습니다. 해당 DB는 이용조건에 따라 외부 참고 링크로만 안내합니다.

    • 전사 출처: 한국어 위키문헌 동의보감 탕액편, 중국어 위키문헌 내경편 권1. 저자 허준, 전사·편집 기여자 위키문헌 사용자들. 각 검색 결과에서 사용한 수정판의 고정 링크와 기여 이력을 제공합니다.
    • 전사 이용조건: CC BY-SA 4.0. 이 화면의 가져온 전사와 이를 정리한 전사 데이터는 동일한 이용조건을 따릅니다. 텍스트 항목에는 위키 전사와 검색용 한글명·관련 문서 연결이 포함되며, 현대 번역은 포함되지 않습니다. 정본·완역본이라는 의미가 아닙니다.
    • 전권 영인본: Wikimedia Commons 공개 파일과 서지. 국립중앙도서관 디지털 자료를 바탕으로 제공된 목판본 25책이며, 파일 설명의 PD-scan / PD-South Korea 표시를 확인했습니다. 이미지와 PDF는 제공처에서 불러옵니다.
    • 영인본 목차: 각 책의 권두제 이미지를 대조해 편·권을 식별했습니다. 파일 제24책은 목록 권2, 제25책은 목록 권1입니다. 원전의 목차 순서와 파일 번호를 구분하며, 간행연도·정본 여부는 별도로 확인합니다.
