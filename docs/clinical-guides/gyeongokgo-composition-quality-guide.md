# 경옥고 구성·원료·제조 품질 가이드 {#_1}

## 핵심 답변 {#_2}
경옥고는 **인삼·생지황·복령·봉밀**의 네 재료가 각기 다른 역할을 맡는 전통 고제입니다. 품질을 평가할 때는 특정 원료 하나의 양만 보기보다 **원료의 질, 배합 구조, 생지황의 처리, 봉밀의 품질, 농축·고제 제조 과정과 보관**을 함께 봐야 합니다.

## 네 가지 구성축 {#_3}

| 구성 | 전통적으로 보는 역할 | 품질에서 볼 점 |
|---|---|---|
| [인삼](../herbs/ginseng.md) | 보기·원기 | 뿌리 품질·가공·규격 |
| [생지황](../herbs/rehmannia-root-fresh.md) | 양음·생진 | 신선도·수분·변질 관리 |
| [복령](../herbs/poria.md) | 건비·수습 | 절편·건조·이물·규격 |
| [봉밀](../herbs/honey.md) | 윤조·완급·조화·제형 | 수분·진위·보관·열관리 |

## 왜 생지황인가? {#_4}
전통 경옥고 구성의 핵심은 **생지황의 즙**이며, 인삼·복령 가루와 봉밀을 함께 중탕해 고제로 만듭니다. 생지황의 신선도·착즙, 인삼·복령의 입도, 봉밀의 정련과 전체 고제의 가열·수분 관리를 각각 확인하면 원료와 제법의 의미를 정확하게 살릴 수 있습니다.

## 기본형·인삼 증량형·익수영진고를 대조하기 {#variant-quality-check}

| 확인 자료 | 함께 기록할 내용 |
|---|---|
| 기본 네 약재의 배합 | 생지황·인삼·복령·봉밀의 실제 중량과 수록본 |
| 인삼 증량형 | 인삼의 절대량과 나머지 재료에 대한 상대 비중 |
| 익수영진고·기타 가감형 | 천문동·맥문동·구기자·지골피·호박·침향 등의 추가 여부와 출전 |
| 인삼·사삼 가감 | 보기·양음의 목적과 기원종·부위·함량 |
| 제조·복용 기록 | 중탕 조건·농축 종점·수분·당류·보관과 1회량 |

[출전별 배합과 본초 해설](../formulas/gyeongok-go.md#gyeongok-variant-comparison)을 기준으로 실제 조제품을 비교합니다. 원료 생지황·건지황·숙지황은 각각의 가공 규격으로, 경옥고는 여러 재료를 함께 제조한 완제품으로 기록해 성분·품질 자료를 연결합니다.

## 고제의 품질 {#_5}
경옥고는 단순한 탕약이 아니라 농축된 고제이므로 다음 요소가 중요합니다.

1. 원료 선별
2. 생지황 처리
3. 분말·즙·봉밀의 균질한 배합
4. 적절한 가열·농축 과정
5. 수분과 점도 관리
6. 위생적인 용기·충전
7. 보관 안정성

## 경옥고와 경옥고환을 비교할 때 {#paste-pill-quality}

전통 경옥고의 고제와 환으로 조제한 경옥고환은 **구성·수분·결합재·환당량과 실제 복용량**을 함께 봅니다. 같은 처방명이 있어도 고제 한 숟가락과 환 한 개를 같은 원료량으로 환산할 수는 없습니다.

| 확인할 정보 | 비교하는 이유 |
|---|---|
| 기본 네 약재와 추가 약재 | 단삼 등 가미 약재와 그 배합 목적을 구분 |
| 생지황의 형태 | 생지황즙·추출물 등 실제 사용 원료와 처리 방식 확인 |
| 꿀·조청·그 밖의 결합재 | 배합·점도·환 성형과 복용량에 영향을 주는 구성 |
| 고제·환의 1회량과 하루 횟수 | 한 번 먹는 양과 하루 총량을 연결 |
| 제조 배치·포장·보관 안내 | 같은 제형 안에서도 실제 완제품의 관리 조건 확인 |

봉밀이나 조청은 제형을 만드는 역할과 함께 당류 섭취에 영향을 줍니다. 혈당을 관리 중이라면 표시된 성분과 1회량·하루량을 함께 확인합니다. 꿀의 당류를 설명하는 일반 기준은 [FDA 당류 표시 안내](https://www.fda.gov/food/nutrition-facts-label/added-sugars-nutrition-facts-label)에서 볼 수 있으며, 실제 조제품의 함량은 조제기관에 확인합니다.

### 원료 자료와 완제품 자료를 연결합니다 {#finished-product-records}

원료의 기원·규격·보관 기록은 어떤 재료를 사용했는지 알려 줍니다. 완제품에서는 전체 배합, 조제 과정, 1회량과 포장·복용기한을 따로 확인합니다. 지표성분 시험을 했다면 **무엇을 어떤 방법으로 측정했는지와 어느 배치의 자료인지**를 함께 봅니다.

실제 품질 설명은 ‘오래 달였다’는 시간 하나보다 원료 준비·균질한 배합·가열과 수분·충전·보관이 연결된 기록으로 구체화합니다. 복용 뒤에는 식사·대변·건조감·피로와 일상활동을 비교합니다. [경옥고 구성과 방의](../tonic-masterpieces/gyeongokgo/composition.md#preparation-followup) · [복용 상담](../conditions/gyeongokgo-guide.md)

## 공진단과 함께 비교하면 {#_7}
공진단은 녹용·당귀·산수유·사향을 중심으로 한 환제 계통이고, 경옥고는 인삼·생지황·복령·봉밀을 중심으로 한 고제 계통입니다. 두 처방은 모두 보익 영역에서 널리 알려져 있지만 **구성 약재와 제형, 처방 구조가 분명히 다릅니다.**
