# 출처·근거 카드

이 영역은 긴 논문목록이 아니라 **질환의 임상 맥락 → 한의학적 탐색 → 치료 구성 → 사람 대상 연구 → PMID·DOI → 재평가**를 한 문서에 정리하는 근거카드 도서관입니다.

## 근거카드의 표준 구조

1. 환자가 찾는 증상과 현대 질환의 임상 맥락
2. 위험신호와 필요한 감별
3. 한의학적 병증·변증·치법
4. 본초·처방 구성 또는 경혈·자극방법
5. 사람 대상 임상시험과 종합연구
6. 대상자·용량·치료기간·비교군
7. 긍정적으로 관찰된 증상·기능 변화
8. 안전성과 치료 후 재평가
9. PMID·DOI 및 기존 지식망

## 각 영역의 역할

- **근거카드:** 질환·치료별 핵심 임상근거 요약
- **연구 데이터베이스:** RCT·메타분석·참고문헌 상세 목록
- **근거 읽는 법:** 연구설계와 논문 해석의 표준
- **임상 적용 심화:** 연구 대상과 현재 환자를 비교해 치료계획으로 연결
