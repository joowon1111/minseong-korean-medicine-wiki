# 통증질환 — 한약 현대근거 확장 지도

- 경구 한약 vs placebo: **18 RCT·3,015명**, 편두통 빈도·일수·통증강도·반응률 개선, PMID `35873759`
- 예방치료: **35 RCT·2,840명**, flunarizine 비교에서 발작빈도 감소, PMID `33424985`
- 천궁 함유 처방: **19 RCT·1,832명**, 빈도·지속시간·통증강도 개선, PMID `30013473`

## 무릎 골관절염

- *Phytomedicine* meta-analysis: **31 RCT·3,115명**, 통증·기능 개선, PMID `35316726`
