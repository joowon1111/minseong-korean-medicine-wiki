# 보양환오탕 — 뇌졸중 후 회복·우울 현대 임상근거 카드
## 대표 임상영역
뇌졸중 후 기허혈어와 연결되는 기능회복·우울·일상생활 기능을 중심으로 현대 임상근거를 연결합니다.
## 현대 임상연구
- 뇌졸중 후 우울 systematic review/meta-analysis: **15 RCT**. 보양환오탕 단독 또는 기존 항우울치료 병용에서 HAMD 등 우울지표와 신경학적·일상기능 outcome의 긍정적인 개선이 보고되었습니다. PMID `36408491`, DOI `10.3389/fneur.2022.981476`.
- 뇌졸중 후 한약 전체 network meta-analysis에서도 다양한 중성약의 회복효과를 비교했습니다. PMID `29245245`.
## 한의학 지식망
`뇌졸중 후 기능저하 → 기허혈어 → 보양환오탕 → 황기·당귀미·적작약·천궁·도인·홍화·지룡 → 신경·ADL·정서 outcome`
## 연결
뇌졸중 후 우울·운동재활·인지장애 카드와 황기·당귀·천궁·도인·홍화 등 익기활혈 본초 지식망을 연결합니다.
