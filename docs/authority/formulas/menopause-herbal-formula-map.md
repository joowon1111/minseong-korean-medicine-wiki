# 갱년기 — 한약 처방 현대근거 지도

## 현대 임상근거
2026 systematic review는 비대두(non-soy) 경구 herbal supplement RCT **30편**을 포함했고, 그중 28편에서 갱년기 증상 개선이 보고되었습니다. 주요 outcome은 혈관운동증상·수면·신경계 증상·삶의 질이었습니다. PMID `42451042`.

## 한의학 처방 연결
- 정곤단(Ding Kun Dan) → Kupperman Index·PSQI·SF-36·정서·호르몬 지표를 평가한 systematic review/meta-analysis, PMID `41143285`
- 가미소요산 → 갱년기 정서·간울화열 지식망
- 당귀작약산 → 여성 월경·혈허·수습 지식망
- 온경탕 → 월경통·한응어혈 지식망

## 한의학 지식망
