# 한약 처방 임상근거 — 확장 허브

한약 처방의 현대 임상근거를 단순 처방목록이 아니라 **질환 → 변증 → 처방 → 구성 본초 → 임상 outcome → PMID·DOI**로 연결합니다.

## 소화기
- 반하사심탕 → 기능성소화불량: 57 RCT·5,525명 meta-analysis, PMID `37274096`
- 육군자탕 → 기능성소화불량·비위기능
- 보중익기탕 → 기허·피로·기능회복

## 수면·정서
- 산조인탕 → 만성불면: 12 RCT·1,311명, PMID `36459033`
- 귀비탕 → 불면·심비양허: 2025 network meta-analysis 186 RCT에서 PSQI 상위 치료군, PMID `40826721`
- 천왕보심단 → 수면·심계 관련 처방망

## 여성질환
- 온경탕 → 원발성 월경통: 18개 연구·1,736명, PMID `28791471`
- 침+온경탕 → 11 RCT·1,024명, PMID `40988743`
- 당귀작약산·가미소요산 등 여성 생애주기 처방은 후속 임상근거 카드로 확장

## 비염·호흡기
- 소청룡탕 → 알레르기비염: 24 RCT meta-analysis, PMID `35257842`

## 근골격
- 독활기생탕 → 무릎·요추·관절 근골격 임상근거
- 오적산·청상견통탕 등 통증 처방은 후속 근거카드로 확장

## 보익·회복
- 공진단
- 경옥고
- 십전대보탕
- 생맥산

## 읽는 방법
`환자 증상 → 질환 → 한의학적 변증 → 처방 선택 → 구성 본초 → 현대 임상근거 → 치료반응 재평가`
