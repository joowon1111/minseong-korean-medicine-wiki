# 한약·처방 현대 임상근거 허브

이 허브는 한약 처방의 근거를 단순 논문 목록이 아니라 **환자의 증상·질환 → 한의학적 변증 → 처방과 구성 본초 → 현대 임상연구 → 치료반응 재평가**로 연결합니다.
