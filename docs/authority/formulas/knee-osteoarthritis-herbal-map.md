# 무릎 골관절염 — 한약 처방 현대근거 지도

## 한약 전체 근거
- 2022 updated systematic review/meta-analysis: **56 RCT·5,350명**. 한약 단독 또는 병용치료는 VAS·WOMAC·Lequesne index를 유의하게 감소시키고 Lysholm knee function score와 전체 임상반응률을 향상시켰습니다. PMID `35035664`.
- *Phytomedicine* systematic review/meta-analysis: **31 RCT·3,115명**. 한약은 placebo 및 서양의학 치료보다 WOMAC을 개선했고 VAS·Lequesne·Lysholm 등 여러 통증·기능지표에서 긍정적인 결과를 보였습니다. PMID `35316726`, DOI `10.1016/j.phymed.2022.154029`.

## 대표 처방
- 독활기생탕 → 무릎 골관절염 12개 연구·982명, PMID `26729379`
- 한약+침도 병용 → 최신 meta-analysis에서 무릎 골관절염 통증·기능 개선을 평가, PMID `39822562`

## 한의학 지식망
`무릎 골관절염 → 풍한습비·간신부족·어혈 → 처방·본초 → VAS·WOMAC·Lysholm → 침·전침·운동재활`

## 연결
무릎 골관절염 질환카드와 독활기생탕, 두충·우슬·상기생·독활 등 본초 및 침구 근거를 통합합니다.
