# 기사회복방 계열(Qishe) — 경항통 현대 임상근거 카드

## 대표 임상영역
퇴행성 경추질환과 만성 목통증의 통증·기능을 중심으로 봅니다.

## 현대 임상근거
- 만성 경항통 임상시험에서 Compound Qishe Tablet은 placebo보다 단기 통증을 유의하게 감소시켰습니다. 관련 연구는 목·요통 TCM systematic review/meta-analysis에 포함되어 있습니다. PMID `25710765`, DOI `10.1371/journal.pone.0117146`.
- 경추 퇴행성 디스크질환 Cochrane review에서도 Qishe 계열 경구 한약의 placebo 비교 임상효과가 평가되었습니다. PMID `20091597`.

## 한의학 지식망
`퇴행성 경추질환 → 목통증·방사통 → 활혈·통락·강근골 치료전략 → 복합 한약 → 통증·기능`

## 연결
경추 신경근병증·만성 목통증 카드와 경근·침구·한약 근거를 통합합니다.
