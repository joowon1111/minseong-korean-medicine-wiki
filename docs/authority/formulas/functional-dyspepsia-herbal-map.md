# 기능성소화불량 — 한약 처방 현대근거 지도

## 대표 처방
### 육군자탕
- **52 RCT·5,475명** meta-analysis에서 전체 임상반응률·소화불량 증상·위배출 기능 개선 및 6개월 재발률 감소. PMID `32767596`.

### 반하사심탕
- **57 RCT·5,525명** meta-analysis에서 전체 임상반응과 병용치료의 긍정적인 결과. PMID `37274096`.
