# 천궁 함유 처방 — 편두통 현대 임상근거 카드

## 현대 임상연구
- 2018 high-quality randomized-trial systematic review/meta-analysis: **19 RCT·1,832명**. 천궁 함유 한약처방은 placebo·일반 약물치료 비교에서 편두통의 발작빈도·지속시간·편두통 일수·통증강도를 유의하게 개선했고 전체 임상반응률도 향상시켰습니다. PMID `30013473`, DOI `10.3389/fphar.2018.00589`.

## 임상 연결
천궁을 단일 본초로만 보는 것이 아니라 실제 복합처방 속에서 두통·편두통 outcome과 연결해 탐색합니다.

## 한의학 지식망
`두통·편두통 → 기체·혈어·풍 → 천궁 중심 처방 → 통증·발작빈도·지속시간`

## 연결
천궁 본초 카드, 편두통·긴장형두통 현대근거 카드와 청상견통탕 등 두통 처방 근거망으로 확장합니다.
