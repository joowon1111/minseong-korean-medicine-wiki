# 갈근금련탕 — 제2형 당뇨병 현대근거 카드
원방·가감방의 구성과 시험별 결과는 [갈근금련탕 상세 문서](../../formulas/gegen-qinlian-tang.md)에서 확인합니다.

## 대표 임상영역
습열·장위불화와 연관된 제2형 당뇨병의 혈당·대사 지표를 중심으로 봅니다.
## 현대 임상근거
- 2015년 *ISME Journal*: 제2형 당뇨병 187명·12주 무작위시험에서 용량군별 혈당·HbA1c와 장내미생물을 평가했습니다. [PMID 25279787](https://pubmed.ncbi.nlm.nih.gov/25279787/)
- 2024년 *Precision Clinical Medicine*: 120명 무작위배정·104명 완료·110명 전체분석. 원방에 오미자·지모·건강을 더한 가감방에서 위약보다 HbA1c 감소가 컸습니다. [PMID 38495337](https://pubmed.ncbi.nlm.nih.gov/38495337/)
- 2025 대사질환 systematic review/meta-analysis **122 RCT·11,252명**은 거습법 한약의 임상효과를 종합했고, 제2형 당뇨병 영역에서 **갈근금련탕을 유망한 처방**으로 제시했습니다. PMID `41552833`, DOI `10.3389/fphar.2025.1644950`.
- 위 122개 RCT는 여러 거습법 한약을 합한 수치이며, 모두 갈근금련탕 시험이 아닙니다. 병용치료의 종합 결과와 갈근금련탕의 직접 시험 결과를 구분합니다.
## 한의학 지식망
`제2형 당뇨 → 습열·장위불화 → 갈근금련탕 → 갈근·황금·황련·감초 → FPG·2hPG`
## 연결
당뇨·대사·장-뇌축 카드와 갈근·황금·황련 본초 지식망을 연결합니다.
