# 마행감석탕 — 현대 임상근거 카드
## 대표 임상영역
폐열·천급·해수와 연결되는 급성 호흡기 증상군과 COPD 급성악화의 현대 임상근거를 봅니다.
## 현대 임상근거
- AECOPD network meta-analysis **55개 연구·4,560명**에서 마행감석탕+기존치료는 폐기능과 동맥혈가스 개선에서 상위권 치료로 평가되었습니다. PMID `31438920`.
- 2026 최신 Bayesian network meta-analysis **132 RCT·13,177명**에서도 마행감석탕은 PaO2·PaCO2 등 동맥혈가스 교정에서 높은 순위를 보였습니다. PMID `41625332`.
## 한의학 지식망
`천급·기침·폐열 → 마행감석탕 → 마황·행인·석고·감초 → 호흡·혈액가스 outcome`
## 연결
COPD·천식·호흡곤란 카드와 마황·행인·석고·감초 본초 지식망을 연결합니다.
