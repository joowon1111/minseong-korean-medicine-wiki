# 통사요방 — 현대 임상근거 카드

## 대표 임상영역
설사형 과민성장증후군(IBS-D)의 복통·배변빈도·변 상태와 삶의 질, 불안 증상을 중심으로 봅니다.

## 현대 임상근거
- 2022 systematic review/meta-analysis: **11 RCT·985명**. 표준 통사요방은 placebo 및 서양의학 치료보다 IBS-D 전체 증상개선에서 좋은 결과를 보였습니다. 변 상태·배변빈도·복통이 개선됐고, 서양의학 치료보다 삶의 질과 불안 증상에서도 유의한 개선이 보고되었습니다. PMID `36091782`, DOI `10.3389/fphar.2022.904657`.
- 기존 systematic review: **12개 연구·1,125명**에서 가감 통사요방의 단기·중기·장기 임상효과가 대조치료보다 높게 나타났습니다. PMID `16722791`.

## 한의학 지식망
`IBS-D·복통·설사 → 간비불화 → 통사요방 → 백출·백작약·진피·방풍 → 배변·복통·삶의 질`

## 연결
IBS·장-뇌축 현대근거 카드와 백출·작약·진피·방풍 본초 지식망을 연결합니다.
