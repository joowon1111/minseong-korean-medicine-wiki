# 천마구등음 — 현대 임상근거 카드

## 대표 임상영역
간양상항과 연관된 고혈압의 혈압·두통·어지럼·전통의학 증상과 혈관기능을 중심으로 봅니다.

## 현대 임상근거
- 2021 systematic review + trial sequential analysis: **15 RCT·1,508명**. 천마구등 과립+기존 항고혈압 치료는 기존치료 단독보다 수축기혈압을 평균 10.24 mmHg, 이완기혈압을 5.33 mmHg 더 낮췄고 전체 임상효과와 변증증상도 유의하게 개선했습니다. PMID `33787150`.
- 2020 systematic review/meta-analysis: **14개 연구·1,537명**. 천마구등탕+nifedipine 병용은 nifedipine 단독보다 전체 임상반응과 혈압·전통의학 증상 개선에서 좋은 결과를 보였습니다. PMID `32089726`.
- 연구에서는 nitric oxide 증가와 endothelin-1·TNF·IL-6 감소 등 혈관·염증 관련 지표의 긍정적 변화도 보고했습니다.

## 한의학 지식망
`고혈압·두통·어지럼 → 간양상항·간신음허 → 천마구등음 → 천마·구등·석결명·우슬·두충 → SBP·DBP·증상`

## 연결
고혈압·어지럼·두통 현대근거 카드와 천마·구등·두충·우슬 등 본초 지식망을 연결합니다.
