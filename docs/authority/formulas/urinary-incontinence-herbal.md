# 요실금 — 한약 현대 임상근거 카드

## 대표 임상영역
요실금에서는 누출 빈도와 일상기능·삶의 질을 중심으로 비수술적 치료 근거를 연결합니다.

## 현대 임상연구
- 2023 systematic review/network meta-analysis는 고령 여성 요실금의 여러 비수술적 치료를 비교했고, **행동치료+한약 병용이 가장 높은 치료 선택 순위**로 평가되었습니다. PMID `37832271`.

## 한의학 지식망
`요실금 → 방광기능·기화 → 신기·비기·하초 상태 → 한약 + 행동치료 → 배뇨기능·삶의 질`

## 연결
과민성방광·뇌졸중 후 요실금·수술 후 요폐 카드와 중극 CV3·관원 CV4·삼음교 SP6 및 보신·고삽 본초 지식망을 연결합니다.
