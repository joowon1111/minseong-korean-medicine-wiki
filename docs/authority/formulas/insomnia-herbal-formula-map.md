# 불면 — 한약 처방 현대근거 지도
## 대규모 한약 근거
2025 network meta-analysis는 **186 RCT, 13개 한약 중재**를 비교했습니다. PSQI 순위에서는 귀비탕이 가장 높았고 산조인 계열, 시호가용골모려탕 등 여러 처방이 상위권에 포함됐습니다. PMID `40826721`.

- 천왕보심단 → 원발성 불면 임상연구에서 PSQI·ISI 개선, PMID `33919176`
