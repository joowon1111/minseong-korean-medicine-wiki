# 불면 — 한약 처방 현대근거 지도

불면 처방의 연구는 **어떤 환자에게, 어떤 제형을, 무엇과 비교하여, 어느 기간에 평가했는지**부터 읽습니다. 같은 수면 점수라도 무작위 비교시험의 군 간 차이와 한 집단의 복용 전후 변화는 답하는 질문이 다릅니다.

## 대규모 한약 근거

2025년 네트워크 메타분석은 **186개 RCT·13개 한약 중재**의 직접·간접 비교를 종합했습니다. PSQI 순위에서는 귀비탕이 가장 높았으나, 임상 유효율에서는 용담사간탕이 가장 높아 평가 지표에 따라 순위가 달랐습니다. 186개는 전체 네트워크의 시험 수이며 귀비탕만의 시험 수가 아닙니다. [PMID 40826721](https://pubmed.ncbi.nlm.nih.gov/40826721/) · [DOI](https://doi.org/10.1097/MD.0000000000043789)

순위는 그 분석에 포함된 치료들 사이의 상대적 위치입니다. SUCRA 같은 순위 지표를 개인의 치료 성공률로 읽거나, 1위와 2위 사이에 반드시 임상적으로 큰 효과 차이가 있다고 해석하지 않습니다. 실제 선택에는 비교별 효과 크기와 불확실성, 환자군·제제·기간의 유사성을 함께 확인해야 합니다. 연구별 ‘임상 유효율’의 기준도 수면의 질 점수와 구별합니다.

### 수면 결과를 비교하는 순서 {#reading-sleep-studies}

| 확인 항목 | 읽는 기준 |
|---|---|
| 대상 | 원발성·만성 불면인지, 암 등 다른 질환에 동반된 불면인지 확인 |
| 중재 | 원방·가감방·추출 제제, 단독·병용과 복용기간을 구별 |
| 비교군 | 위약·통상 약물·인지행동치료 또는 대조군 없는 전후 비교인지 확인 |
| 결과 | PSQI는 수면의 질, ISI는 불면 중증도를 평가하며 입면시간·총수면시간·낮 기능과 함께 읽음 |
| 변화의 의미 | 군 내 호전과 군 간 효과 차이를 구별하고, 통계적 차이와 환자가 체감하는 변화도 나누어 판단 |
| 지속성과 안전성 | 치료 종료 뒤 추적 여부, 중도탈락·이상반응 수집 방식과 병용약을 확인 |

자세한 평가 기록은 [불면의 수면 결과와 재평가](../../conditions/insomnia.md#sleep-results-reading)로 연결합니다. 서로 겹칠 수 있는 메타분석의 시험 수와 참여자 수를 더하여 독립적인 전체 근거 규모처럼 제시하지 않습니다.

## 한의학 지식망

`불면 → 동반 증상·변증 → 처방 구성 → 실제 연구 제제·비교군 → 수면과 낮 기능의 변화`

[귀비탕](../../formulas/guibi-tang.md)은 피로·식욕 저하·심계·건망을, [산조인탕](../../formulas/suanzaoren-tang.md)은 허로허번의 문맥을, [천왕보심단](../../formulas/tianwang-buxin-dan.md)은 구건·허열·심계 등과 처방 구성을 대조해 읽습니다. 이는 전통적인 처방 선택의 설명이며, 네트워크 순위가 해당 변증의 효과를 별도로 검증했다는 뜻은 아닙니다.

고전의 [백합병 3.1~3.9](../../classics/jinkui-yaolue/chapters/lily-fox-yinyang.md#lily-treatment-branches)는 수면뿐 아니라 식욕·활동·치료 뒤 변화를 함께 다룹니다. 현대 불면 진단과 일대일로 대응시키거나 이 페이지의 연구를 백합 처방의 임상시험으로 인용하지 않습니다.
