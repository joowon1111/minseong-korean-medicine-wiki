# 골다공증 — 한약 현대 임상근거 지도 {#_1}

## 한약 전체 {#_2}
- 2025 systematic review/meta-analysis: **18 RCT·1,816명**. 한약치료에서 요추·대퇴경부·Ward's triangle 골밀도의 유의한 개선이 보고되었습니다. PMID `40786085`.

## 폐경 후 골다공증 {#_3}
- 보신 한약 network meta-analysis: **15 RCT·1,360명**. 통증·요추 BMD·대퇴경부 BMD·골대사 outcome에서 여러 병용처방의 긍정적인 결과. PMID `40121932`.
- 이선탕 updated meta-analysis: **13 RCT·1,269명**. 요추·대퇴경부 골밀도와 VAS 통증 개선. PMID `42155162`.

## 좌귀환: 처방별 병용 연구 {#zuogui-evidence}

2021년 *Phytotherapy Research*에 수록된 SR(온라인 발표 2020년)은 **12개 연구**를 포함했습니다. 좌귀환과 기존 골다공증 치료제 병용에서 요추·Ward 부위·전체 고관절 골밀도 및 일부 골대사 지표의 개선을 보고했습니다. 병용군에서 위장 불편·어지럼·피로도 보고되었으며, 저자들은 결론을 확인할 더 큰 규모의 엄격한 시험이 필요하다고 평가했습니다. [Li et al., PMID 33089589](https://pubmed.ncbi.nlm.nih.gov/33089589/) · [DOI 10.1002/ptr.6908](https://doi.org/10.1002/ptr.6908)

| 확인할 항목 | 이 연구를 읽는 범위 |
|---|---|
| 처방·비교 조건 | 좌귀환의 기존 치료 병용 결과를 중심으로 확인 |
| 평가 결과 | 부위별 골밀도와 골대사 지표를 통증·삶의 질·골절 발생과 구분 |
| 적용 범위 | 좌귀환의 결과를 우귀환·대보원전이나 모든 보신 처방으로 확대하지 않음 |
| 안전성 | 이상사건 보고와 추적 기간을 함께 확인하며 장기 안전성을 단정하지 않음 |

골밀도 변화는 실제 골절 감소를 입증하는 결과와 구별합니다. 처방의 전통적 구성은 [좌귀환](../../formulas/zuogui-wan.md#jingyue-source), 원문 배합의 의미는 [《경악전서》](../../classics/jingyue-quanshu.md#modern-evidence), 현재 진료의 목표는 [골다공증·골절 예방](../../conditions/osteoporosis.md#bone-treatment)에서 이어 봅니다.
