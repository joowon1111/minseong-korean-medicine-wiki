# 골다공증 — 한약 현대 임상근거 지도

## 한약 전체
- 2025 systematic review/meta-analysis: **18 RCT·1,816명**. 한약치료에서 요추·대퇴경부·Ward's triangle 골밀도의 유의한 개선이 보고되었습니다. PMID `40786085`.

## 폐경 후 골다공증
- 보신 한약 network meta-analysis: **15 RCT·1,360명**. 통증·요추 BMD·대퇴경부 BMD·골대사 outcome에서 여러 병용처방의 긍정적인 결과. PMID `40121932`.
- 이선탕 updated meta-analysis: **13 RCT·1,269명**. 요추·대퇴경부 골밀도와 VAS 통증 개선. PMID `42155162`.

## 기존 아카이브 연결
- 독활기생탕 → 폐경 후 골다공증 임상근거
- 육미지황 계열 → 보신·골대사 근거망
- 두충·우슬·상기생 → 강근골 본초망

## 한의학 지식망
`폐경·노화 → 신허·간신부족 → 보신·강근골 → 처방·본초 → BMD·통증·골대사`
