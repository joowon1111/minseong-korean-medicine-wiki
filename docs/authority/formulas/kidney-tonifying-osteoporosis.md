# 보신 한약 — 폐경 후 골다공증 현대근거 카드

## 현대 임상연구
- 2025 network meta-analysis: **15 RCT·1,360명**. 여러 보신 한약과 bisphosphonate 병용치료를 비교했습니다. 일부 보신 처방 병용군은 통증 완화와 요추·대퇴경부 골밀도 개선에서 높은 순위를 보였고, 육미지황 계열 병용은 골대사 개선에서 좋은 결과를 보였습니다. PMID `40121932`, DOI `10.1016/j.jocd.2025.101581`.
- 2025 한약 골다공증 meta-analysis: **18 RCT·1,816명**. 한약치료는 요추와 대퇴경부, Ward's triangle의 골밀도를 유의하게 향상시켰습니다. PMID `40786085`.
