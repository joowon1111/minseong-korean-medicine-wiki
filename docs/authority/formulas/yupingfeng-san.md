# 옥병풍산 — 현대 임상근거 카드
## 대표 임상영역
폐위기허·표허와 연결되는 반복적 호흡기·알레르기 증상군을 중심으로 봅니다.
## 현대 임상근거
- 최신 성인 기관지천식 systematic review/meta-analysis에서는 옥병풍산과 기존 치료의 병용효과를 종합해 천식 조절과 폐기능 관련 임상지표를 평가했습니다. PMID `42147341`.
## 한의학 지식망
`반복적 호흡기 증상 → 폐위기허·표허 → 옥병풍산 → 황기·백출·방풍 → 천식·비염·면역 지식망`
## 연결
천식·알레르기비염 현대근거 카드와 황기·백출·방풍 본초카드를 연결합니다.
