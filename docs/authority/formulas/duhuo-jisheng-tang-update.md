# 독활기생탕 — 현대 임상근거 확장 카드
## 주요 임상영역
독활기생탕은 풍한습비·간신부족·기혈부족과 연결되는 대표적인 근골격 방제로, 무릎 골관절염과 골다공증 임상근거를 중심으로 연결합니다.
## 무릎 골관절염
- systematic review: **12개 연구·982명**. 독활기생탕 병용치료는 WOMAC 총점과 통증에서 긍정적인 개선을 보였습니다. PMID `26729379`, DOI `10.1136/bmjopen-2015-008973`.
## 폐경 후 골다공증
- systematic review/meta-analysis에서는 독활기생탕 단독 또는 병용치료의 골밀도·골대사·통증 관련 임상지표를 종합했습니다. PMID `33014108`, DOI `10.1155/2020/6957825`.
## 한의학 지식망
`무릎·허리·관절통 → 풍한습비 + 간신부족·기혈허 → 독활기생탕 → 독활·상기생·두충·우슬·당귀 등 → WOMAC·통증·골기능`
