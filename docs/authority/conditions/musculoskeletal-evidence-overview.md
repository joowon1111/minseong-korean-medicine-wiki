# 근골격 통증 — 현대 임상근거 지도

## 왜 질환별로 나누는가
근골격 통증은 같은 '통증'이라도 요통·경항통·무릎 골관절염·어깨질환·좌골신경통·턱관절장애 등 병태와 임상 outcome이 다릅니다. 따라서 침 연구도 질환별로 분리해 읽습니다.

## 현재 아카이브의 주요 근거 카드
- 만성 요통
- 만성 목통증
- 무릎 골관절염
- 어깨통증
- 유착성관절낭염
- 좌골신경통
- 족저근막염
- 외측상과염
- 턱관절장애
- 손목터널증후군
- 섬유근육통
- 대상포진 후 신경통

## 근거를 읽는 순서
`질환 진단·위험신호 → landmark RCT → systematic review/meta-analysis → 근거확실성 → 통증 + 기능 outcome → 한의학 지식망`

## 임상 연결
침의 효과를 '근골격 통증 전체'로 일반화하지 않고 각 질환의 대상군, 비교군, 치료량, 추적기간과 실제 기능 outcome을 확인합니다.
