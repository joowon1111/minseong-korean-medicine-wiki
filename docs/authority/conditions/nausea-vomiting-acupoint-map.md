# 오심·구토 — 경혈 기반 현대근거 지도

## 공통 경혈 패턴
서로 다른 임상상황의 오심·구토 연구에서 **내관 PC6·족삼리 ST36·중완 CV12**이 반복적으로 핵심 경혈로 나타납니다.

### 임신 중 오심·구토
24 RCT·2,390명 meta-analysis에서 PC6 19개 연구, ST36 16개, CV12 13개 연구에서 사용되었습니다. PMID `39214380`.

### 항암치료 유발 오심·구토
49 RCT·4,133명 meta-analysis에서 ST36 42회, PC6 38회, CV12 23회로 가장 자주 사용되었습니다. PMID `42490841`.

## 한의학 지식망
`오심·구토 → 원인별 분류 → 위기상역·담음·비위상태 → PC6 + ST36 + CV12 → 침·전침·지압 → 증상 재평가`

## 아카이브 연결
내관 PC6·족삼리 ST36·중완 CV12의 개별 경혈 페이지에서 임신오조·CINV·기능성소화불량 등 현대 임상근거 카드로 상호 연결할 수 있습니다.
