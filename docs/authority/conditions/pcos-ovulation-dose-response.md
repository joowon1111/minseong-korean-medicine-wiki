# PCOS 배란장애 — 침 치료량 현대근거 카드

## 임상 맥락
PCOS에서 침 치료는 단순 시행 여부뿐 아니라 경혈 수, 치료빈도, 1회 치료시간과 총 치료기간이 배란효과와 연결되는 중요한 요소입니다.

## 현대 임상연구
- 2025 meta-analysis + network meta-analysis + dose-response modeling: **43 RCT·4,827명**. 침 단독은 sham 침보다 배란율을 유의하게 높였고, 약물치료와의 비교에서도 긍정적인 결과를 보였습니다.
- 침+한약은 약물치료보다 높은 배란율을 보였고 network analysis에서 **SUCRA 97.8%**로 가장 높은 순위를 기록했습니다. PMID `40951420`.
- dose-response 분석에서는 경혈 수·주당 치료빈도·유침시간·총 치료기간과 배란율의 관계를 구체적으로 모델링했습니다.

## 한의학 지식망
`배란장애 → 월경주기·난포·배란 → 변증·배혈 → 치료빈도·유침시간·총 치료기간 → 배란율 재평가`

## 치료 연결
관원 CV4·삼음교 SP6·족삼리 ST36 등 핵심 경혈과 난임·ART·PCOS·한약 지식망을 연결합니다.
