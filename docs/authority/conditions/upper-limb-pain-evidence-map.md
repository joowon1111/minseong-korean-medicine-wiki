# 경항·어깨·상지 통증 — 침구 긍정적 현대근거 지도
## 주요 임상영역
상지 통증은 목에서 시작되는 신경근병증, 어깨 회전근개질환, 근막통증, 손목터널증후군 등을 구분해 기능별로 봅니다.
### 경추 신경근병증
- 28 RCT·2,593명 network meta-analysis에서 다양한 침 관련 치료의 통증 개선효과 비교. PMID `38912448`.
- 27개 연구·3,124명 meta-analysis에서 침이 견인보다 임상반응과 통증지표에서 좋은 결과. PMID `37957858`.
### 회전근개질환
- 13 RCT·1,371명 meta-analysis에서 단기·중기 통증·어깨기능 및 외전·외회전·전방굴곡 개선. PMID `38463603`.
### 목·어깨 근막통증
- 29 RCT·2,424명 network meta-analysis에서 전침·침+운동 등 여러 치료의 긍정적 임상효과를 비교. PMID `40893120`.
## 한의학 지식망
`경항부 → 어깨 → 팔 → 손`
`경근·경락 → 국소혈·원위혈 → 침·전침 → 통증·ROM·근력·기능`
## 아카이브 연결
경추 신경근병증·회전근개질환·어깨통증·손목터널증후군 카드와 표준경혈 아틀라스·전침·경근 페이지를 연결합니다.
