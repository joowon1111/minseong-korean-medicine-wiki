# 신경계 재활 — 침·전침 긍정적 현대근거 지도

## 핵심 임상영역
신경계 재활에서 침구치료는 하나의 질환명보다 **회복해야 할 기능**을 중심으로 현대근거를 연결하면 임상적으로 활용하기 쉽습니다.

### 안면신경 기능
2025 급성기 말초성 안면마비 meta-analysis **15 RCT·771명**에서 안면기능과 회복기간의 긍정적인 개선이 보고되었습니다. PMID `41376771`.

### 연하기능
뇌졸중 후 연하장애 meta-analysis+TSA **20 RCT·1,718명**에서 SSA·VFSS·WST·SWAL-QOL이 유의하게 개선되었습니다. PMID `39965554`.

### 전침과 연하재활
전침 meta-analysis **30 RCT·2,290명**에서 VFSS·WST 등 연하기능 개선과 자극 파라미터가 함께 분석되었습니다. PMID `41602993`.

## 한의학 지식망
`신경계 질환 → 안면·연하·운동·인지·배뇨 기능별 분류 → 표준경혈·두침·전침 → 재활치료 → 기능 outcome 재평가`

## 아카이브 활용
질환별 현대근거 카드와 표준경혈 아틀라스, 전침, 경근·경락, 뇌졸중 재활 페이지를 서로 연결해 치료법과 임상근거를 함께 탐색합니다.
