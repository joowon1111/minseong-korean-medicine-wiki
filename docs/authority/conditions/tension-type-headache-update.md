# 긴장형 두통 — 최신 현대 임상근거 확장 카드
## 임상 맥락
긴장형 두통은 압박감·조이는 느낌과 두통 빈도, 통증강도, 경항부 긴장, 일상기능을 함께 평가합니다.
## 현대 임상연구
- 2025 systematic review/meta-analysis: **6 RCT·927명**. 침 치료는 6주 시점 두통 빈도를 유의하게 감소시켰고 sham 침보다 두통완화 가능성이 높았습니다. **1개월 이상 또는 10회 이상 치료** subgroup에서 통증수준이 유의하게 감소했습니다. PMID `41436106`, DOI `10.22514/jofph.2025.067`.
- 2024 network meta-analysis에서는 여러 침 관련 치료를 비교해 두통 빈도·지속시간·통증강도·반응률을 평가했습니다. PMID `39703352`.
- 별도 Bayesian network meta-analysis에서도 다양한 침 치료법의 긴장형 두통 효과를 비교했습니다. PMID `37426434`.
## 한의학 지식망
`긴장형 두통 → 빈도·강도·경항부 긴장 → 두경부 경근·경락 → 침·전침 → 두통일수·통증·진통제 사용 재평가`
## 치료 연결
풍지 GB20·태양 EX-HN5·백회 GV20·합곡 LI4·태충 LR3 등과 두통·경항통 경혈망을 연결합니다.
