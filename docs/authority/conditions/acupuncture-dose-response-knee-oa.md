# 무릎 골관절염 — 침 치료량·전침 임상근거 카드

## 임상 맥락
침 치료 연구에서는 단순히 '침을 했는가'뿐 아니라 치료 횟수·빈도·총 치료량과 전침 사용 여부가 실제 임상효과와 연결되는 중요한 요소입니다.

## 현대 임상연구
- 2024 pairwise/exploratory network meta-analysis **80 RCT·9,933명**에서 침은 여러 비교군보다 통증과 기능을 개선했습니다. 특히 NSAIDs와 비교한 subgroup에서 더 높은 침 치료량이 더 큰 통증완화와 연결됐고, network analysis에서는 전침이 수기침보다 통증완화에 더 좋은 효과를 보였습니다. PMID `39486882`.

## 한의학 지식망
`무릎 골관절염 → 통증·기능 → 배혈 → 치료빈도·총치료량 → 전침 여부 → WOMAC·VAS·보행기능 재평가`

## 치료 연결
독비 ST35·내슬안 EX-LE4·양릉천 GB34·족삼리 ST36 등 주요 경혈에 치료량과 전침 프로토콜 개념을 연결해 현대 임상근거를 탐색합니다.
