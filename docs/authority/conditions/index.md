## 읽는 방법

각 카드는 다음 항목을 중심으로 읽습니다.

| 확인 항목 | 임상적으로 중요한 이유 |
|---|---|
| 연구대상 | 실제 환자의 진단·기간·중증도와 비슷한지 확인 |
| 치료방법 | 침·전침·약침·한약의 구성과 치료량 확인 |
| 비교군 | 무치료·가짜치료·통상치료·병용치료의 질문이 서로 다름 |
| 결과지표 | 증상점수뿐 아니라 기능·수면·삶의 질·약물 사용 확인 |
| 치료기간·추적 | 언제 효과를 평가했고 얼마나 유지됐는지 확인 |
| 안전성 | 이상반응, 중도탈락과 병용약물 확인 |

체계적 문헌고찰과 메타분석은 여러 임상시험을 종합하지만 포함 연구의 치료방법과 비교군이 다를 수 있습니다. PMID·DOI를 통해 원문을 확인하고, 연구의 평균 결과를 개인의 진단·변증·치료목표와 연결해 해석합니다.

## 근거 카드에서 진료로 연결하기

```text
질환과 위험신호 확인
 → 연구 대상과 비교
 → 치료방법·치료량 확인
 → 개인의 변증·체질과 병용치료 조정
 → 증상·기능·삶의 질 재평가
```
