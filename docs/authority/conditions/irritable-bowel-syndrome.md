# 과민성장증후군 — 침·한약 현대 임상근거

## 임상 질문

반복되는 복통과 설사·변비·복부팽만이 있는 IBS 환자에게 침·전침과 변증 한약을 적용했을 때 전체 증상, 복통, 배변과 삶의 질이 개선되는가?

## 환자에게 중요한 outcome

- IBS 전체 반응률과 IBS-SSS 증상중증도
- 복통 일수와 통증강도
- 배변 횟수, 변 형태, 급박변·잔변감
- IBS-QOL과 외출·업무·여행 가능성
- 불안·우울과 수면
- 지사제·변비약·진경제 사용량

## 침치료 근거

### 2026년 sham 비경혈 침 비교 메타분석

12개 무작위시험·1,105명을 포함한 2026년 *Gastroenterology* systematic review/meta-analysis에서는 침치료가 sham 비경혈 침보다 IBS 반응률과 치료 종료 시 전체 증상중증도에서 유리했고, 삶의 질에서도 개선이 보고됐습니다.

- PMID: [42413705](https://pubmed.ncbi.nlm.nih.gov/42413705/)
- 반응률 RR 1.61, 95% CI 1.25–2.07

### 2025년 삶의 질 메타분석

14개 논문·2,038명을 포함한 메타분석에서는 침치료 후 IBS 삶의 질과 증상중증도에서 긍정적인 결과가 보고됐습니다.

- PMID: [39946356](https://pubmed.ncbi.nlm.nih.gov/39946356/)

2022년 component network meta-analysis는 25개 RCT·3,041명에서 일반치료에 침을 추가했을 때의 효과를 비교했고, 2023년 umbrella review는 기존 침·뜸 systematic review의 근거수준을 종합평가했습니다.

- PMID: [35437029](https://pubmed.ncbi.nlm.nih.gov/35437029/)
- PMID: [38199885](https://pubmed.ncbi.nlm.nih.gov/38199885/)

## 한약치료 근거

2021년 meta-analysis와 trial sequential analysis는 10개 시험·2,501명을 포함하여 한약이 위약보다 IBS 전체 증상과 복통 완화에서 유리한 결과를 보고했습니다.

- PMID: [34385918](https://pubmed.ncbi.nlm.nih.gov/34385918/)

통사요방은 간비불화로 해석되는 스트레스성 복통·설사와 연결되는 대표 처방입니다. 2025년 무작위 이중맹검 위약대조 2상시험은 설사형 IBS에서 통사요방 과립의 치료효과와 안전성을 평가했습니다.

- PMID: [39870499](https://pubmed.ncbi.nlm.nih.gov/39870499/)
- DOI: [10.1136/bmjopen-2024-088410](https://doi.org/10.1136/bmjopen-2024-088410)

설사형 IBS의 여러 한약을 비교한 2023년 network meta-analysis도 위약대조 이중맹검 시험들을 종합했습니다.

- PMID: [37328079](https://pubmed.ncbi.nlm.nih.gov/37328079/)
- DOI: [10.1016/j.jep.2023.116672](https://doi.org/10.1016/j.jep.2023.116672)

### 복합 한약을 평가한 JAMA 무작위시험 {#jama-herbal-trial}

1998년 *JAMA*에 발표된 호주 연구에는 웨스턴시드니대와 시드니대·Nepean Hospital 내과, Concord 병원 소화기 연구진 등이 참여했습니다. Rome 진단기준을 충족한 **116명**을 개별 복합 한약 38명, 표준 복합 한약 43명, 위약 35명으로 무작위 배정해 **16주**간 평가한 이중눈가림 시험입니다.

한약 치료군은 위약군보다 환자와 소화기 전문의가 평가한 **장 증상·전반적 개선**에서 유리했고, 증상이 일상생활을 방해하는 정도도 줄었습니다. 치료 기간 중 개별 처방이 표준 처방보다 더 우수하지는 않았으며, 종료 14주 후에는 개별 처방군에서 개선 유지가 보고됐습니다.

연구에서 사용한 복합 한약 캡슐의 결과를 통사요방이나 다른 특정 처방에 그대로 적용하지 않습니다. 이 논문은 대표적인 초기 임상시험으로, 위의 후속 연구와 함께 IBS 아형·처방 구성·평가 시점을 비교하는 자료입니다.

*Treatment of Irritable Bowel Syndrome With Chinese Herbal Medicine: A Randomized Controlled Trial.* [PMID 9820260](https://pubmed.ncbi.nlm.nih.gov/9820260/) · [JAMA 원문·DOI 10.1001/jama.280.18.1585](https://jamanetwork.com/journals/jama/fullarticle/188145)

## 장–뇌축과 정서·삶의 질

2025년 메타분석은 침치료가 IBS 환자의 불안·우울과 삶의 질에 미치는 영향을 종합했습니다.

- PMID: [39870963](https://pubmed.ncbi.nlm.nih.gov/39870963/)
- DOI: [10.1007/s12529-025-10348-z](https://doi.org/10.1007/s12529-025-10348-z)

## 임상 적용

**위험신호 배제 → IBS-D·IBS-C·IBS-M 구분 → 간비불화·비위기허·비신양허·습열·한열착잡 변증 → 한약·침·전침 → 복통·배변·삶의 질 재평가**

- 설사형·변비형·혼합형을 같은 처방으로 고정하지 않습니다.
- 침치료는 천추 ST25·상거허 ST37·족삼리 ST36·내관 PC6·태충 LR3 등을 증상과 변증에 맞춰 조합합니다.
- IBS-SSS뿐 아니라 급박변, 외출과 식사 범위, 필요약 사용량을 봅니다.
- 혈변·체중감소·빈혈·야간증상이 새로 생기면 재평가합니다.
