# 여성 내분비·생식 — 침구 긍정적 현대근거 지도

## 주요 임상영역
여성 내분비·생식 영역은 월경·배란·난임·산후·갱년기까지 생애주기별로 연결해 볼 수 있습니다.

### PCOS
- 53 RCT·4,406명 network meta-analysis에서 대사·생식내분비·난소형태 관련 여러 지표의 개선. PMID `41837127`.
- 43 RCT·4,827명 dose-response 분석에서 배란율 개선과 치료량 관계 확인. PMID `40951420`.
- 46개 논문·51개 연구 meta-analysis에서 침 및 병용치료의 호르몬·대사·체중 지표 개선. PMID `40091529`.

### 난임·ART
배아이식·임상임신율·치료과정의 불안과 통증 등을 중심으로 침 치료 현대근거를 연결합니다.

### 월경통·자궁내막증
통증과 월경 관련 삶의 질을 중심으로 침·전침·온침·한약 지식망을 연결합니다.

### 산후
수유저하·산후우울·수면·피로와 기혈회복을 하나의 산후 회복 네트워크로 봅니다.

## 지식망
`월경 → 배란 → 난임/ART → 임신·산후 → 갱년기`
`경혈 → 침·전침 → 한약 → 현대 임상 outcome`

여성질환 페이지들을 단절된 개별 질환이 아니라 생식·내분비의 연속적인 지식망으로 연결합니다.
