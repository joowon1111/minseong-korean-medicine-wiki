# 약침 — 출전·임상근거 카드

**약침은 국내 다기관 비교시험에서 만성요통·목통증과 척추관협착증의 통증·기능을 평가받고 있습니다.** 질환과 사용 제제, 주입 위치·용량, 비교치료를 함께 확인하면 연구 결과를 더 구체적으로 이해할 수 있습니다.

## 대표 연구에서 먼저 확인할 것 {#pharmaco-study-map}

| 연구·설계 | 비교와 치료기간 | 이 페이지에서 읽는 결과 |
|---|---|---|
| 만성요통 · 100명 다기관 실용적 RCT | 약침 대 물리치료, 5주 10회 | [6주 통증·기능과 25주 추적](#pharmaco-back-trial) |
| 요추 척추관협착증 · 96명 다기관 실용적 RCT | 약침 대 통상치료, 12주 주 2회 | [13주 통증·기능과 53주 추적](#lumbar-spinal-stenosis-trial) |
| 만성 목통증 · 101명 다기관 RCT | 약침 대 물리치료, 2주 이내 8회 | [통증·목 기능과 12주 추적](#pharmaco-neck-trial) |
| 오십견 · 50명 예비 RCT | 약침 대 물리치료, 6주 주 2회 | [통증·어깨 기능·가동범위](#pharmaco-shoulder-trial) |

본시험과 예비시험은 역할이 다릅니다. 실용적 시험은 실제 진료에 가까운 비교효과를 평가하므로, 눈가림 여부·환자보고 지표와 실제 시행된 치료 내용을 함께 살펴봅니다.

## 치료 개념
약침은 경혈 또는 치료부위에 약침액을 소량 주입해 **경혈 자극과 약물 자극을 결합**하는 한의치료법이다.

→ [약침](../treatments/pharmacopuncture.md)

## 만성요통 RCT
2023년 4개 한방병원에서 수행된 다기관 pragmatic RCT는 만성요통 환자 100명을 약침과 물리치료군으로 무작위 배정했다. 6주 시점에서 약침군은 요통 NRS, ODI와 삶의 질 지표에서 물리치료군보다 유리한 결과를 보였고 추적기간은 25주였다.

**연구유형:** Multicenter pragmatic randomized controlled trial  
**PMID:** `37554434`  
**PMCID:** `PMC10406108`  
**DOI:** `10.2147/JPR.S413512`

## 의미
한국 한의 임상에서 사용되는 약침이 실제 사람 대상 비교 임상시험으로 평가되고 있다는 점에서 중요한 연구다.

→ [요통](../conditions/low-back-pain.md)

## 요통 시험의 치료기간과 효과크기 {#pharmaco-back-trial}

5주 동안 10회 치료를 시행한 연구에서 6주 요통 NRS의 군 간 차이는 **1.54점(95% CI 0.94~2.13)**이었습니다. ODI 기능과 삶의 질도 함께 평가하고 25주까지 추적했습니다. 물리치료와 비교한 실용적 임상시험이며, 모든 약침 제제가 동일한 효과를 낸다거나 일반침보다 우월하다는 비교는 아닙니다. [PMID 37554434](https://pubmed.ncbi.nlm.nih.gov/37554434/)

## 요추 척추관협착증 — 다기관 RCT {#lumbar-spinal-stenosis-trial}

2026년 국내 다기관 실용적 무작위시험은 요추 척추관협착증 환자 **96명**을 약침과 통상치료에 1:1 배정했습니다. 두 군 모두 12주 동안 주 2회 치료받았고 13·25·53주에 추적했습니다. 13주 주된 통증 NRS의 기저치 대비 변화는 약침군이 통상치료군보다 **2.7점 더 컸으며**, 기능과 삶의 질을 포함한 이차 결과도 약침군에 유리했습니다. 심각한 이상반응은 관찰되지 않았습니다. [PMID 42099446](https://pubmed.ncbi.nlm.nih.gov/42099446/) · [PMCID PMC13145381](https://pmc.ncbi.nlm.nih.gov/articles/PMC13145381/) · [DOI 원문](https://doi.org/10.1016/j.imr.2026.101323)

실제 진료에 가까운 설계와 53주 추적은 장점입니다. 다만 사용 제제·주입 위치·병행치료를 확인해야 하며, 결과를 모든 약침이나 진행성 근력저하가 있는 환자에게 일괄 적용하지 않습니다. → [척추관협착증 진료 안내](../conditions/lumbar-spinal-stenosis.md#pharmacopuncture-rct)

## 만성 목통증 — 통증과 업무 기능 {#pharmaco-neck-trial}

2021년 온라인 발표된 다기관 RCT는 **101명**을 약침과 물리치료로 배정하고 2주 이내 8회 치료했습니다. 5주 평가에서 목 통증과 NDI 등 기능 지표의 유리한 결과가 보고됐고 12주까지 추적했습니다. [Park 등, PMID 35011752](https://pubmed.ncbi.nlm.nih.gov/35011752/) · [DOI 원문](https://doi.org/10.3390/jcm11010012)

연구가 다룬 만성 경항통을 진행하는 신경마비나 모든 목디스크와 같은 상태로 보지 않습니다. → [목통증 감별](../conditions/neck-pain.md) · [목·어깨 경혈](../acupuncture-integrated/points-for-neck-shoulder.md)

## 오십견 — 50명 예비시험 {#pharmaco-shoulder-trial}

2024년 유착성관절낭염 연구는 **50명**에서 6주간 주 2회 약침과 물리치료를 비교했습니다. 7주 통증·SPADI와 어깨 굴곡·외전 등의 개선이 보고됐습니다. 후속 본시험의 실행 가능성을 살핀 **예비시험**이라는 점을 함께 표시합니다. [Kim 등, PMID 39224580](https://pubmed.ncbi.nlm.nih.gov/39224580/)

야간통·옷 입기·머리 감기와 능동·수동 가동범위를 함께 평가합니다. → [오십견 안내](../conditions/frozen-shoulder.md) · [오십견 전체 근거](conditions/frozen-shoulder.md)

## 초음파 유도 연구의 의미 {#ultrasound-pharmacopuncture-evidence}

2025년 체계적 문헌고찰은 **16개 임상연구 중 9개 무작위시험·685명**을 정량합성했습니다. 초음파 유도 약침은 비유도 약침 또는 통상치료와 비교해 통증 개선을 보인 비율이 높게 보고됐습니다. [PMID 40101074](https://pubmed.ncbi.nlm.nih.gov/40101074/)

영상 유도는 목표 조직과 주변 구조를 확인하는 방식입니다. 연구마다 제제·부위·질환이 다르므로 영상 사용 자체가 모든 질환의 효과나 안전을 보장한다고 설명하지 않습니다.

## 제제·시술·기능을 함께 읽기 {#pharmaco-clinical-reading}

약침 연구에서 말하는 치료는 **약침액과 주입 방식이 결합된 중재**입니다. 아래 정보를 확인해야 서로 다른 약침 시험이나 실제 치료와 비교할 수 있습니다.

| 확인 항목 | 연구 결과를 읽을 때의 의미 |
|---|---|
| 원료·성분·농도·제조 규격 | 같은 이름의 약침이나 다른 제제를 동일한 중재로 취급하지 않음 |
| 1회·부위별 용량과 주입 위치 | 경혈·근육 등 목표 부위와 실제 자극량을 확인 |
| 병용치료·비교군 | 약침을 추가한 효과인지, 다른 치료와 직접 비교한 효과인지 확인 |
| 치료기간과 추적 | 치료 종료 직후 평가와 수개월 뒤 경과를 구분 |
| 통증·기능 지표 | NRS는 통증, ODI는 허리 관련 장애, NDI는 목 관련 장애, SPADI는 어깨 통증·장애를 평가 |

요통에서는 보행·앉기·수면·업무 수행, 목통증에서는 고개 돌리기와 업무, 오십견에서는 옷 입기·머리 감기와 능동·수동 가동범위를 함께 봅니다. 통증의 평균 차이와 실제 기능 변화가 어떤 관계인지 확인하는 과정입니다.

시술 전 원료별 알레르기 이력·복용약과 치료부위 상태를 확인하고, 제조·보관·무균관리와 시술 뒤 국소 통증·부종·발진 등을 살펴봅니다. 초음파 유도 여부도 실제 시술 조건으로 기록합니다. 구체적인 제제와 치료 과정은 [약침 안내](../treatments/pharmacopuncture.md)에서 이어집니다.

## 침·전침과 근거를 비교하려면 {#pharmaco-related-evidence}

[일반 침치료 연구](acupuncture.md)는 자침·경혈 자극, [전침 연구](electroacupuncture.md)는 전기 자극을 포함한 시술, 이 페이지는 약침액 주입을 평가합니다. 물리치료 비교에서 나온 결과를 일반침·전침과의 직접 우열로 바꾸지 않고 **질환·비교군·기능 목표가 가까운 연구끼리** 읽습니다. [침과 약침의 실제 치료 차이](../compare/acupuncture-vs-pharmacopuncture.md) · [출처·근거 전체 안내](index.md)
