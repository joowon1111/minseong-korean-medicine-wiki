# 사상체질·병증 처방 탐색기

**사상의학 탐색기는 소양인·소음인·태음인·태양인의 병증과 대표 처방을 원문·해석·감별점으로 비교하는 학습 도구**입니다. 체질 → 병증 → 원문·감별 → 대표 처방 순서로 살펴보고, 체질별 소증·음식·양생·운동을 함께 읽습니다. 단일 증상이나 체형으로 체질을 확정하지 않습니다.

## 탐색기를 읽는 순서

**학습·문서 탐색용 도구입니다.** 이 탐색기는 사상체질이나 질병을 진단하거나 개인별 처방을 추천하지 않습니다.

1. 학습할 **체질**을 선택한 뒤 주요 **병증군**을 살펴봅니다.
2. **신축본 핵심 원문과 우리말 풀이**를 읽고, 펼쳐보기에서 관련 조문·소증·처방 연결을 확인합니다. 인용 확인 링크는 해당 원문이 수록된 CPG PDF의 쪽으로 연결됩니다.
3. **유사 병증 비교**로 감별 지점을 살피고 **대표 처방**의 구성·출전을 대조합니다. 병증명·한자·조문 번호·처방명으로 검색할 수 있습니다.
4. 체질별 상세 탭에서 평소와 현재를 비교하는 **소증 8영역**, 병증 구조, 처방 비교, 음식·체질식이, 양생·운동을 확인합니다.
5. 체질을 임의로 확정하지 않고 **한의원 진찰과 필요한 검사, 치료가 필요한 경우 처방받은 체질한약의 경과까지 종합해 판단**합니다. 한약 반응 하나만으로 확정하거나 체질 확인 목적으로 자가 복용하지 않습니다.
