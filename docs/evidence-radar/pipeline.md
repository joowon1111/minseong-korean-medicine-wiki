# Evidence Pipeline 운영 흐름

## 1. 수집
외부 API 또는 PubMed 검색으로 최신 후보 논문을 가져옵니다.

## 2. 필터
`한의학 관련 → 인체연구 → 기간 → 연구유형 → 질환/치료법`

## 3. 구조화
PICO, PMID, DOI, 연구유형, 환자 수와 주요 outcome을 Evidence Record로 변환합니다.

## 4. 매핑
`논문 → KCD 후보 → conditions → treatment → formula/herb/acupoint`

## 5. 검토
자동분류 오류, 과도한 결론, 질환명 불일치와 중복논문을 사람이 확인합니다.

## 6. 게시
검토 완료 연구만 기존 질환별 현대근거 카드와 참고문헌 DB에 반영합니다.

## 7. 업데이트
최근 30일은 탐색용, 최근 90일은 정기 검토용, 최근 3년은 질환별 심화 보고서용으로 활용합니다.
