# 소음인 처방 배합망

소음인 처방은 ‘몸이 차다’거나 ‘소화가 약하다’는 인상으로 한 묶음이 되지 않습니다. **신수열표열병의 울광·망양**과 **위수한리한병의 태음병·소음병**을 먼저 가르고, 발한 뒤 기력, 음식선화, 복통·설사·구토, 사지냉과 전신 쇠약의 깊이에 따라 배합이 달라집니다.

`평소 음식선화·땀·대변 → 표병/리병 → 울광/망양 또는 태음병/소음병 → 승양·온중·온리·회양 → 처방 → 안전·경과 재평가`

## 네 개의 배합 중심축

### 1. 계지·백작약의 표병·영위축

천궁계지탕에서 시작한 계지·백작약축은 망양이 깊어지면서 보기·승양·온양 약물이 더해집니다.

| 배합의 이동 | 대표 처방 | 병증 변화 |
|---|---|---|
| 계지·백작약 + 천궁·진피 | 천궁계지탕 | 울광 초기의 오한·발열·두통·신체통 |
| 계지·백작약 + 인삼·황기·관계·당귀 | 승양익기탕 | 발한 뒤 기력저하와 망양초증 |
| 계지·백작약 + 부자 | 계지부자탕 | 자한·냉감·사지 구급 |
| 인삼·계지·황기·백작약 + 부자 | 인삼계지부자탕 | 발한 뒤 쇠약과 양기 손상 심화 |

### 2. 향부자·소엽·진피의 기체축

향소산·궁귀향소산은 표병과 기체·소화 변화가 함께 있는지 봅니다. 향부자팔물탕도 향부자·진피를 공유하지만 급성 표병이 아니라 비위 허약과 기혈·사려상비가 겹친 맥락입니다.

| 처방 | 더해지는 중심 | 갈림점 |
|---|---|---|
| 향소산 | 소엽·창출·생강·총백 | 표증과 흉복 답답함·식욕 변화 |
| 궁귀향소산 | 천궁 | 두통·신체통의 비중 |
| 향부자팔물탕 | 당귀·백작약·천궁·백하수오·백출 | 만성 허약·기혈 회복과 긴장·수면 |

### 3. 건강·관계·백출의 온중·리한축

리병에서는 건강·관계·백출이 반복되지만 한습·담습, 단순 태음병 자리증, 깊은 허한·장궐을 구분합니다.

| 분기 | 대표 처방 | 임상에서 더 보는 부분 |
|---|---|---|
| 곽향·소엽·반하·청피·창출 | 곽향정기산 | 한습·담습, 오심·구토·심하비만 |
| 백하수오·백작약·계지 | 백하오이중탕 | 복통·설사·식욕저하의 태음병 자리증 |
| 인삼·관계·부자 | 관계부자이중탕 | 지속 설사·사지궐냉·전신 쇠약 |
| 오수유·부자·소회향·보골지 | 오수유부자이중탕 | 구토·장궐·격양과 더 깊은 리한 |

### 4. 부자 분기: 병증 깊이와 안전을 함께 읽기

부자는 표병 망양과 리병의 깊은 허한 모두에 나타날 수 있으므로 **부자가 있다는 사실만으로 병증 위치를 정할 수 없습니다**.

| 표병·망양 쪽 | 리병·소음병 쪽 |
|---|---|
| 계지부자탕, 승양익기부자탕, 인삼계지부자탕, 인삼관계부자탕 | 궁귀총소이중탕, 관계부자이중탕, 오수유부자이중탕 |
| 발한 뒤 탈진·냉감·자한과 활동 저하 | 복통·설사·구토·사지궐냉과 섭취·소변 저하 |

부자 포함 처방은 기원·포제·실제량·전탕시간, 심혈관·간·신장 상태와 병용약을 기록합니다. 입술·혀·사지 저림, 오심·구토, 심계·부정맥, 어지럼은 즉시 복용을 중단하고 평가할 신호입니다.

## 가장 자주 헷갈리는 처방 쌍

| 비교 | 공통점 | 실제 갈림점 |
|---|---|---|
| 천궁계지탕 ↔ 향소산 | 초기 표병, 두통·오한·발열 | 신체통·계지축인지, 향부자·소엽의 기체·소화축인지 |
| 향소산 ↔ 향부자팔물탕 | 향부자·진피, 흉복 답답함 | 급성 표병인지, 만성 비위허약·기혈저하·사려상비인지 |
| 승양팔물탕 ↔ 인삼계지부자탕 | 망양, 인삼·황기·기혈 회복 | 망양초증인지, 부자가 필요한 깊은 냉감·쇠약인지 |
| 인삼계지부자탕 ↔ 관계부자이중탕 | 인삼·부자·냉감·쇠약 | 발한 뒤 망양 표병인지, 설사·복통 중심의 깊은 리한인지 |
| 곽향정기산 ↔ 백하오이중탕 | 태음병, 복통·설사·냉감 | 한습·담습과 구토인지, 자리증의 복통·설사·식욕저하인지 |
| 백하오이중탕 ↔ 관계부자이중탕 | 온중·리한, 복통·설사 | 비교적 덜 깊은 태음병인지, 사지궐냉·쇠약의 소음병 방향인지 |
| 관계부자이중탕 ↔ 오수유부자이중탕 | 깊은 리한, 부자이중축 | 지속 설사·허한인지, 구토·장궐·격양과 오수유축인지 |
| 관중탕 ↔ 십이미관중탕 | 흉복·복만과 기체·리한 | 배뇨불리·사지권태인지, 황색 변화·부종과 넓은 복만인지 |

## 처방군 선택 흐름

```text
오한·발열·두통·신체통이 앞선다
├─ 통증·계지축 → 천궁계지탕
├─ 흉복 기체·식욕 변화 → 향소산/궁귀향소산
└─ 땀 뒤 탈진·냉감 → 승양계·망양 처방군

복통·설사·구토가 앞선다
├─ 한습·담습·심하비만 → 곽향정기산
├─ 복통·설사·식욕저하 → 백하오이중탕
├─ 구토·흉복 정체 → 계지반하생강탕
└─ 사지궐냉·전신 쇠약 → 부자이중계와 응급 원인 평가
```

## 복용 뒤 무엇을 다시 볼까

| 관찰축 | 호전 방향 | 처방군을 다시 볼 신호 |
|---|---|---|
| 음식선화 | 식욕·식사량과 식후 편안함 회복 | 물도 못 마시는 구토, 체중감소 |
| 대변·복통 | 형태·횟수와 복통이 함께 안정 | 혈변·검은변, 반발통, 지속 설사 |
| 발한·체온 | 땀 뒤 기력과 수족 온도가 회복 | 실신·저혈압, 고열·의식 변화 |
| 소변·수분 | 음수·소변과 어지럼이 안정 | 소변 감소·탈수·빠른 부종 |
| 활동 | 기립·보행·일상기능 회복 | 진행성 쇠약·흉통·호흡곤란 |

## 근거를 읽는 범위

- 『동의수세보원』의 표리·순역 병증 구조와 『동의사상신편』의 후대 처방·구성 기록을 구분합니다.
- 동명 처방은 일반 방제학 처방과 소음인방의 구성이 다를 수 있으므로 처방명만으로 합치지 않습니다.
- 부자 포함 처방의 전통 수록은 안전성과 현대 중증질환 치료효과를 자동으로 보장하지 않습니다.
