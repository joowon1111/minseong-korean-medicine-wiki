# 사상처방 공통본초 빈도

이 표는 구성 항목을 약재 단위로 정규화할 수 있었던 **핵심 비교군 21처방(소양인 9·태음인 9·소음인 3)**을 대상으로 합니다. 현재 아카이브의 모든 사상처방 수를 뜻하지 않습니다. 백복령·적복령은 복령, 자감초는 감초처럼 같은 본초의 표기 차이를 묶어 계산했습니다.

후대 처방 중 개별 용량이 일부 누락된 처방, 판본에 따라 구성 범위가 달라지는 처방, 곡물성 보조재가 별도 계량으로 적힌 태양인 처방은 임의 환산하지 않았습니다. 전체 처방의 병증 위치와 실제 구성은 [사상체질별 한약처방](../sasang-formula-cards/index.md)과 체질별 배합망에서 확인합니다.

## 체질별로 읽으면 의미가 달라집니다

| 반복 본초·본초군 | 소양인에서 주로 읽는 축 | 태음인에서 주로 읽는 축 | 소음인에서 주로 읽는 축 |
|---|---|---|---|
| 복령·택사 | 표병·망음과 지황계의 수분대사 | 중심 반복축은 아님 | 처방별 포함 여부를 별도 확인 |
| 형개·방풍·강활·독활 | 표병과 망음의 형방계 | 같은 방식으로 적용하지 않음 | 같은 방식으로 적용하지 않음 |
| 숙지황·산수유 | 망음 또는 음허오열의 진액·소모 | 중심 반복축은 아님 | 중심 반복축은 아님 |
| 나복자·길경 | 일부 강열·정체 보조 / 태음인과 역할 다름 | 조위·승청과 갈근계 리열을 잇는 반복축 | 중심 반복축은 아님 |
| 건율·의이인·마황·맥문동 | 중심 반복축은 아님 | 위완수한표한·조위·폐원축 | 중심 반복축은 아님 |
| 건강·백출·진피·감초 | 중심 반복축은 아님 | 중심 반복축은 아님 | 온중·리한과 비위 회복축 |

빈도는 반복 사용 정도를 보여주는 지표일 뿐, 개별 처방 안에서의 역할은 배합·용량·병증 위치에 따라 달라집니다. 특히 같은 약재가 다른 체질 처방에 들어간다고 효능과 적용 병증이 같아지는 것은 아닙니다.
