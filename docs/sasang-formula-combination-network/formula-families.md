# 사상처방군·골격 비교

## 태음인 위완수한표한 계열
태음조위탕과 조위승청탕은 건율·의이인·나복자·길경·마황·맥문동·석창포·오미자·천문동 등의 골격을 공유하고, 조위승청탕에는 산조인·용안육·원지 등이 더해집니다.

## 태음인 간수열리열 계열
열다한소탕과 청폐사간탕은 갈근·고본·황금·길경·나복자·백지·승마를 공유하며, 청폐사간탕에는 대황이 추가됩니다.

## 소양인 지황계
형방지황탕·독활지황탕·숙지황고삼탕·화석지황탕은 숙지황·산수유·복령·택사 등의 반복 골격에 강활·독활·형개·방풍 또는 고삼·지모·황백, 목단피·구기자 등이 달라집니다.

## 소음인 온중·리한 계열
백하오이중탕·관계부자이중탕·소음인방 곽향정기산은 건강·백출·감초·진피 등의 반복이 보이지만 병증 깊이와 배합구조는 다릅니다.
