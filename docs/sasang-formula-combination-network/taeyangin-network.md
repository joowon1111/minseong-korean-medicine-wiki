# 태양인 처방 배합망

태양인은 현존 문헌에서 확인할 수 있는 병증·처방 자료가 다른 체질보다 제한적입니다. 이 페이지는 처방 수를 억지로 늘리지 않고 **외감요척병·해역의 오가피장척탕**과 **내촉소장병·열격의 미후등식장탕**을 공통 골격과 기능 목표로 비교합니다.

`태양인 판단 근거 → 평소 소변·섭취·보행 → 해역/열격 → 현대 질환 감별 → 배합 구조 → 기능 경과평가`

## 두 처방을 한눈에 보기

| 병증축 | 처방 | 중심 배합 | 처방을 가르는 기능 |
|---|---|---|---|
| 외감요척병·해역 | [오가피장척탕](../sasang-formula-cards/ogapi-jangcheok-tang.md) | 오가피 고용량 + 모과·송절 + 포도근·노근·앵도육 | 요척·하지 힘, 기립·보행·계단·낙상 |
| 내촉소장병·열격 | [미후등식장탕](../sasang-formula-cards/mihudeung-sikjang-tang.md) | 미후도/미후등 고용량 + 모과·포도근 + 노근·앵도·오가피·송화 | 연하·섭취·구토, 체중·수분·소변 |

## 공유 골격과 분기

두 처방은 모과·포도근·노근·앵도류를 공유합니다. 그러나 같은 약재가 반복된다는 사실보다 **어느 약물이 중심에 있고 어떤 기능장애를 목표로 하는지**가 중요합니다.

| 구조 | 오가피장척탕 | 미후등식장탕 |
|---|---|---|
| 중심 약물 | 오가피 16 g | 미후도/미후등 16 g |
| 공통축 | 모과·포도근·노근·앵도류 | 모과·포도근·노근·앵도류 |
| 분기축 | 송절, 교맥 | 오가피·송화, 저두강 |
| 병증 위치 | 외감요척병·해역 | 내촉소장병·열격 |
| 우선 지표 | 하지 근력·보행 | 연하·섭취·구토·영양 |

### 명칭과 원료를 반드시 구분하기

미후등식장탕은 처방명에 **미후등(獼猴藤)**이 들어가지만 『동의사상신편』 수록 구성의 첫 약재는 **미후도(獼猴桃)**로 적혀 있습니다. 처방명만 보고 덩굴 부위를 임의로 선택하지 않고, 사용 판본과 실제 원료의 학명·약용 부위를 조제기록에 남깁니다.

오가피도 오가피·가시오가피·추출물을 같은 원료로 취급하지 않습니다. 상세 기원과 감별은 [오가피](../herbs/acanthopanax-bark.md), 미후도·미후등의 표기는 [미후등·미후도](../herbs/mihudeung.md)에서 확인합니다.

## 해역과 열격의 감별

| 확인축 | 해역 쪽 | 열격 쪽 |
|---|---|---|
| 주된 기능 | 서기·걷기·계단·하지 지탱 | 삼킴·식사·수분 유지 |
| 동반 변화 | 허리·하지 통증, 감각·균형, 낙상 | 사레·기침, 가슴 걸림, 구역·구토 |
| 소증과 전신상태 | 소변·섭취가 유지되는지, 근력저하 진행성 | 체중·소변량·탈수·영양 저하 |
| 먼저 배제할 문제 | 뇌·척수·말초신경·근육·관절 질환 | 식도 폐색·종양, 신경성 연하장애, 위장관 폐색 |
| 대표 처방 | 오가피장척탕 | 미후등식장탕 |

하지무력과 연하장애가 함께 있으면 운동신경원·신경근육·뇌간 질환처럼 두 기능을 동시에 설명할 원인을 먼저 평가합니다. 두 처방을 함께 쓸 근거로 단순 연결하지 않습니다.

## 처방 판단 흐름

```text
기능 저하의 중심은 무엇인가?
├─ 요척·하지 힘, 기립·보행
│  ├─ 급성 편측 마비·대소변 장애 → 응급 신경·척추 평가
│  └─ 태양인 외감요척병·해역 구조 → 오가피장척탕 검토
└─ 연하·섭취·구토
   ├─ 침도 못 삼킴·호흡곤란·빠른 체중감소 → 응급·소화기·연하 평가
   └─ 태양인 내촉소장병·열격 구조 → 미후등식장탕 검토
```

## 치료 전후 기능지표

| 영역 | 시작할 때 | 재진에서 볼 변화 |
|---|---|---|
| 기립 | 5회 의자일어나기 시간, 손 지지 | 시간·보조 감소와 안전성 |
| 보행 | 거리·속도·보조기·낙상 | 거리 증가와 피로 회복 |
| 연하 | 물·죽·고형식 단계, 사레·기침 | 안전하게 가능한 음식 단계 |
| 섭취·구토 | 한 끼 섭취량, 구토 횟수·양 | 섭취 유지와 구토 감소 |
| 영양·수분 | 체중·음수·소변·기립성 어지럼 | 체중 안정과 탈수 회복 |
| 전신 소증 | 수면·피로·소변·활동 | 주증과 소증이 같은 방향으로 회복 |

침·전침·약침·재활은 통증·근긴장·보행훈련과 오심·긴장 같은 동반 문제를 보조할 수 있지만, 태양인 병증 감별이나 진행성 신경·연하 질환 평가를 대신하지 않습니다.

## 근거와 안전의 경계

- 오가피장척탕과 미후등식장탕의 기본 위치는 전통 병증·처방 기록에 근거합니다.
- 현대 자료는 단일 증례와 복합치료 보고가 중심이므로 특정 신경병증·구토·연하장애에 대한 일반적 효과를 확정하지 않습니다.
- 처방 수가 적다는 이유로 다른 체질 처방이나 출전이 불명확한 후대방을 태양인 처방으로 편입하지 않습니다.
- 갑작스러운 마비·언어장애, 빠른 근력저하, 대소변 장애, 침도 삼키기 어려움, 반복 흡인, 토혈·검은변, 심한 탈수는 즉시 의료기관 평가가 우선입니다.
