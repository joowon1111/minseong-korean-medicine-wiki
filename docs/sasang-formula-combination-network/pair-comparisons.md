# 비슷한 사상처방 쌍 비교 {#_1}

공통 약재가 많아도 병증 위치가 다를 수 있고, 구성이 달라도 같은 임상 질문에서 비교해야 할 수 있습니다. 아래 26개 비교는 **공통점 → 구성 차이 → 병증 갈림점** 순서로 읽습니다. 조성 차이는 각 링크의 특정 수록형을 기준으로 하며 처방 간 효과 우열을 뜻하지 않습니다.

## 비교 뒤 반드시 확인할 것 {#_6}

- 공통 약재 수보다 표리·순역·중증도와 평소 소증의 붕괴 방향이 더 중요합니다.
- 처방을 바꾼 뒤 주증만이 아니라 식욕·대변·소변·땀·수면·갈증·활동이 함께 회복되는지 봅니다.
- 마황·대황·부자 포함 처방은 용량·포제·병용약과 혈압·맥박·수분상태 등 안전항목을 별도로 확인합니다.
