# 비슷한 사상처방 쌍 비교

## [태음조위탕(太陰調胃湯)](../sasang-formula-cards/taeeumjowi-tang.md) ↔ [조위승청탕(調胃升淸湯)](../sasang-formula-cards/jowiseungcheong-tang.md)
- **공통:** 건율, 길경, 나복자, 마황, 맥문동, 석창포, 오미자, 의이인, 천문동
- **태음조위탕에만:** 없음
- **조위승청탕에만:** 산조인, 용안육, 원지

## [열다한소탕(熱多寒少湯)](../sasang-formula-cards/yeoldahanso-tang.md) ↔ [청폐사간탕(淸肺瀉肝湯)](../sasang-formula-cards/cheongpyesagan-tang.md)
- **공통:** 갈근, 고본, 길경, 나복자, 백지, 승마, 황금
- **열다한소탕에만:** 없음
- **청폐사간탕에만:** 대황

## [형방지황탕(荊防地黃湯)](../sasang-formula-cards/hyeongbangjihwang-tang.md) ↔ [독활지황탕(獨活地黃湯)](../sasang-formula-cards/dokhwaljihwang-tang.md)
- **공통:** 독활, 방풍, 복령, 산수유, 숙지황, 택사
- **형방지황탕에만:** 강활, 차전자, 형개
- **독활지황탕에만:** 목단피

## [백하오이중탕(白何烏理中湯)](../sasang-formula-cards/baekhao-ijung-tang.md) ↔ [곽향정기산(藿香正氣散) — 소음인방](../sasang-formula-cards/gwakhyangjeonggi-san.md)
- **공통:** 감초, 건강, 백출, 진피
- **백하오이중탕에만:** 계지, 백작약, 백하수오
- **곽향정기산에만:** 계피, 곽향, 대복피, 반하, 소엽, 익지인, 창출, 청피
