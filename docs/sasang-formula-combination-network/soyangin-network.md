# 소양인 처방 배합망

소양인 처방의 반복 약물은 처방 선택의 답이 아니라 **병증이 어느 방향으로 움직이는지 보여 주는 구조 단서**입니다. 형개·방풍·강활·독활이 반복되어도 표병의 깊이와 흉격·대소변·진액 상태가 다르면 처방은 달라집니다. 숙지황·산수유·복령·택사가 겹쳐도 망음의 설사인지, 음허오열의 만성 소모인지 먼저 가릅니다.

`평소 소증 → 표병/리병 → 순증/역증 → 배설·진액·열의 변화 → 배합 골격 → 가까운 처방 감별 → 재평가`

## 병증 단계와 배합을 한눈에 보기

| 병증축 | 처방 | 중심 배합 | 처방을 가르는 단서 |
|---|---|---|---|
| 소양상풍·얕은 표병 | [형방패독산](../sasang-formula-library/hyeongbangpaedok-san.md) | 형개·방풍·강활·독활 + 생지황·복령·차전자 | 두통·한열왕래·신체통이 앞서고 심한 설사·소모는 아직 뚜렷하지 않음 |
| 표병·결흉 | [형방도적산](../sasang-formula-cards/hyeongbangdojeok-san.md) | 형개·방풍·강활·독활 + 생지황·현삼·목통 + 과루인·전호 | 흉격 답답함·담·기역과 대소변 변화를 함께 봄 |
| 표병·열과 배설 변화 | [형방도백산](../sasang-formula-library/soyangin-extended-formulas.md#soyang-hyeongbangdobaek) | 생지황·복령·택사 + 석고·지모 + 형방계 | 두통·번조·구갈과 소변·대변 변화가 결합 |
| 신열두통망음 | [형방사백산](../sasang-formula-cards/hyeongbangsabaek-san.md) | 형방도백산 골격 + 독활 | 신열·두통·번조·구갈과 표병의 역증 방향 |
| 망음·설사와 소모 | [형방지황탕](../sasang-formula-cards/hyeongbangjihwang-tang.md) | 숙지황·산수유 + 복령·택사·차전자 + 형방계 | 복통·설사, 진액·기력 저하와 수분상태 |
| 망음·복통 | [활석고삼탕](../sasang-formula-library/soyangin-extended-formulas.md#soyang-hwalseokgosam) | 고삼·황백·황련 + 복령·택사·활석 | 복통은 있으나 설사가 전면인지, 열·습과 배설 변화가 중심인지 구분 |
| 흉격열 | [양격산화탕](../sasang-formula-cards/yanggyeoksanhwa-tang.md) | 생지황·인동등·연교 + 치자·박하·석고·지모 | 상열·흉격열·번조·구갈과 대변·수면 변화 |
| 이열변폐·백호계 | [지황백호탕](../sasang-formula-library/soyangin-extended-formulas.md#soyang-jihwangbaekho) | 석고·지모 + 생지황 + 방풍·독활 | 심한 구갈·변폐와 전신 열증의 깊이 |
| 강한 열·진액손상 | [현삼백호탕](../sasang-formula-library/hyeonsambaekho-tang.md) | 숙지황·생지황·현삼 + 석고·지모 | 변폐와 심한 탈수, 의식·신경학적 변화까지 확인 |
| 장관 열·설사 | [황련청장탕](../sasang-formula-library/hwangryeoncheongjang-tang.md) | 생지황·황련 + 복령·저령·차전자·택사 | 혈액·점액·급박감, 발열, 소변량과 감염성 원인 |
| 음허오열·하지 기능 | [독활지황탕](../sasang-formula-cards/dokhwaljihwang-tang.md) | 숙지황·산수유 + 복령·택사 + 목단피·독활·방풍 | 만성 열감·배뇨 변화와 허리·하지 무력 |
| 음허오열·습열 단서 | [숙지황고삼탕](../sasang-formula-library/soyangin-extended-formulas.md#soyang-sukjihwanggosam) | 지황계 + 고삼·지모·황백 | 지속 열감·갈증·배뇨와 피부·습열 단서 |
| 음허오열·허로 | [화석지황탕](../sasang-formula-library/soyangin-extended-formulas.md#soyang-hwaseokjihwang) | 숙지황·구기자·산수유 + 목단피·복령·택사 | 체중·기력 저하와 야간 열감·수면·배뇨 변화 |

## 네 개의 배합 중심축

### 1. 형방계 표병축

형개·방풍·강활·독활은 두통·신체통과 표부 울체를 다루는 반복축입니다. 그러나 네 약물이 보인다는 이유만으로 같은 처방군으로 뭉뚱그리지 않습니다.

| 더해지는 축 | 배합의 이동 | 임상에서 확인할 변화 |
|---|---|---|
| 시호·전호 | 한열왕래·흉협·담의 비중 | 형방패독산 |
| 현삼·목통·과루인·전호 | 흉격과 진액·배설 쪽으로 이동 | 형방도적산 |
| 복령·택사·석고·지모 | 번열과 수분대사 쪽으로 이동 | 형방도백산·형방사백산 |
| 숙지황·산수유·차전자 | 설사와 진액 소모를 받치는 쪽으로 이동 | 형방지황탕 |

형방도백산과 형방사백산은 매우 가까운 골격이지만, 후자는 독활이 더해진 구성을 포함해 신열·두통망음의 병증 맥락을 함께 확인합니다. 명칭 유사성과 약재 한두 개 차이만으로 경중을 기계적으로 정하지 않습니다.

### 2. 생지황·복령·택사의 열·수분대사축

생지황은 열과 진액 변화를, 복령·택사는 수분 이동과 배설을 읽는 축입니다. 이 조합은 형방사백산·형방도백산뿐 아니라 황련청장탕에도 나타나지만, **표병의 두통·번조**, **장관의 열성 설사**, **소변량과 탈수**라는 임상 맥락이 다릅니다.

- 두통·신열·번조가 중심이면 형방계 표병군을 우선 비교합니다.
- 설사·급박감·혈액·점액이 중심이면 황련청장탕을 검토하되 감염·염증성 장질환을 먼저 가립니다.
- 소변 감소·어지럼·체중 감소가 동반되면 이수 배합보다 탈수·전해질 평가가 우선입니다.

### 3. 석고·지모의 리열축

석고·지모는 형방사백산, 양격산화탕, 지황백호탕, 현삼백호탕에 반복되지만 병증 위치와 약물 비중이 다릅니다.

| 처방군 | 함께 놓인 약물 | 구분의 중심 |
|---|---|---|
| 형방사백산·형방도백산 | 형개·방풍·강활·독활, 복령·택사 | 표병의 두통·신열과 배설 변화 |
| 양격산화탕 | 인동등·연교·치자·박하 | 흉격열·상열·번조 |
| 지황백호탕 | 생지황, 방풍·독활 | 이열변폐·심한 구갈 |
| 현삼백호탕 | 숙지황·생지황·현삼의 큰 진액축 | 강한 열·변폐·진액손상과 중증 전신상태 |

### 4. 숙지황·산수유·복령·택사의 지황계축

지황계의 공통 골격은 소모된 진액·음분을 받치면서 배뇨·수분대사를 함께 보는 구조입니다. 여기에 무엇이 붙는지가 병증 위치를 가릅니다.

| 처방 | 분기 약물 | 병증의 갈림점 |
|---|---|---|
| 형방지황탕 | 강활·독활·형개·방풍·차전자 | 표병 망음의 복통·설사 |
| 독활지황탕 | 목단피·독활·방풍 | 리병의 만성 소모와 하지 기능 |
| 숙지황고삼탕 | 고삼·지모·황백 | 음허오열에 습열·피부 단서가 겹침 |
| 화석지황탕 | 구기자·목단피 | 허로·탈음으로 기록된 만성 소모 |

## 가장 자주 헷갈리는 처방 쌍

| 비교 | 공통점 | 실제 갈림점 |
|---|---|---|
| 형방도적산 ↔ 형방사백산 | 형방계 표병, 두통·열·배설 변화 | 흉격·담·기역인지, 신열·번조와 석고·지모축인지 |
| 형방사백산 ↔ 형방지황탕 | 표병·망음, 형방계 | 신열·두통이 전면인지, 복통·설사와 소모가 전면인지 |
| 형방지황탕 ↔ 독활지황탕 | 숙지황·산수유·복령·택사 | 표병 망음의 설사인지, 리병의 만성 소모·하지무력인지 |
| 양격산화탕 ↔ 지황백호탕 | 흉격열·구갈·번조 | 상부 산화가 중심인지, 변폐와 강한 전신 열증인지 |
| 지황백호탕 ↔ 현삼백호탕 | 석고·지모·지황의 강한 청열·진액축 | 현삼백호탕은 중증 전신상태·의식·신경 소견을 더 엄격히 확인 |
| 독활지황탕 ↔ 숙지황고삼탕 | 음허오열·하소, 지황계 | 하지·근골 기능인지, 고삼·황백축의 습열·피부 단서인지 |

## 처방군 선택 흐름

```text
두통·한열·신체통이 앞선다
├─ 흉격·담·기역 → 형방도적산
├─ 신열·번조·구갈 → 형방사백산/형방도백산
└─ 복통·설사·소모 → 형방지황탕

흉격열·강한 구갈이 앞선다
├─ 상열·번조 중심 → 양격산화탕
├─ 변폐·강한 전신 열증 → 지황백호탕
└─ 의식·신경 소견·심한 탈수 → 즉시 원인 평가 후 현삼백호탕 맥락 검토

만성 열감·갈증·배뇨 변화가 앞선다
├─ 허리·하지무력 → 독활지황탕
├─ 피부·습열 단서 → 숙지황고삼탕
└─ 체중·기력 저하·허로 → 화석지황탕
```

## 복용 뒤 무엇을 다시 볼까

| 관찰축 | 호전 방향 | 처방군을 다시 볼 신호 |
|---|---|---|
| 대변·복통 | 형태·횟수와 복통이 함께 안정 | 새 설사·변폐, 혈변, 지속 복통 |
| 갈증·소변 | 음수와 소변이 평소 기준으로 회복 | 소변 감소, 심한 다뇨·구갈, 어지럼 |
| 열·수면 | 번조·야간 열감과 수면이 함께 안정 | 고열, 의식 변화, 심한 불면·탈진 |
| 섭취·체중 | 식사량·활동과 체중이 안정 | 설명되지 않는 체중감소·섭취 저하 |
| 하지 기능 | 보행·계단·피로 회복 | 빠른 근력저하·감각 이상 |

고열과 의식 변화, 갑작스러운 신경학적 이상, 심한 탈수, 혈변·검은변, 반발통은 체질 처방 감별보다 신속한 의학적 평가가 우선입니다.

## 근거를 읽는 범위

- 『동의수세보원』의 병증·처방 구조, 『동의사상신편』과 한국전통지식포탈의 후대 수록 구성은 구분해 읽습니다.
- 2022 사상체질병증 한의표준임상진료지침은 병증 진단·치료·관리의 틀을 제공하지만, 위 모든 처방 사이의 직접 비교시험을 뜻하지 않습니다.
- 증례·관찰연구는 실제 적용 맥락을 보여 주지만 처방 단독 효과나 다른 현대 질환으로의 일반화를 입증하지 않습니다.
