# 사상처방 배합 원리·공통본초 네트워크 {#_1}

사상처방은 공통 약재의 개수만으로 서로 바꾸어 쓸 수 없습니다. 이 네트워크는 처방 구성을 **체질병증의 위치와 변화** 속에서 읽도록 정리합니다.

`체질 → 평소 소증 → 표리·한열·순역·경중 → 처방군 → 공통 골격 → 분기 본초 → 유사처방 감별 → 경과 재평가`

## 병증에서 배합으로 연결하기 {#pattern-to-composition}

| 병증 질문·상세 경로 | 처방 비교 | 구성에서 볼 차이 |
|---|---|---|
| 소양인 신열두통망음인가?<br>[망음의 분기](soyangin-network.md#soyang-new-branches) | 저령차전자탕 ↔ 형방사백산 | 생지황 유무, 저령·차전자와 형방계 |
| 소양인 상소·중소·음허오열인가?<br>[리열·음허오열의 분기](soyangin-network.md#soyang-new-branches) | 양격산화탕 ↔ 인동등지골피탕 / 독활지황탕 ↔ 십이미지황탕 | 청열·지황계의 실제 약미와 병증 위치 |
| 태음인 발표·효천·한궐 중 어디인가?<br>[표한 처방의 분기](taeeumin-network.md#taeeum-new-branches) | 마황발표탕 ↔ 마황정천탕 ↔ 한다열소탕 | 공유 5미와 상백피·백과 또는 의이인·건율의 차이 |
| 태음인 표한과 리열이 헷갈리는가?<br>[태음인 배합망](taeeumin-network.md) | 한다열소탕 ↔ 열다한소탕 | 마황·건율·의이인축과 갈근·고본·승마축 |
| 소음인 울광과 망양의 단계는?<br>[표병의 분기](soeumin-network.md#soeum-new-branches) | 팔물군자탕·독삼팔물군자탕 / 황기계지탕·보중익기탕 | 인삼·황기 공유 여부보다 발한 소증과 병증 단계 |
| 소음인 구토·복만·설사가 앞서는가?<br>[온위강음의 분기](soeumin-network.md#soeum-new-branches) | 향사양위탕 ↔ 곽향정기산 / 강출관중탕 ↔ 관중탕 | 방향성 약미·온중 약미와 출전별 구성 |
| 태양인 보행과 연하 중 어느 기능인가?<br>[태양인 배합망](taeyangin-network.md) | 오가피장척탕 ↔ 미후등식장탕 | 오가피·송절과 미후도·송화, 원료 부위 |

병증의 세부 단계가 궁금하면 [처방 병증 색인](../sasang-formula-library/index.md), 약미의 차이가 궁금하면 [유사처방 감별](pair-comparisons.md)을 봅니다. 증상만으로 처방을 확정하지 않으며, 한의사의 문진·진찰과 필요한 검사 후 치료 목표를 정합니다. 치료가 필요해 처방한 경우에는 주증과 소증의 경과를 함께 재평가합니다.

## 하나의 연결선이 뜻하는 것 {#network-meaning}

배합망의 연결에는 세 가지가 있습니다. **구성 관계**는 실제 수록형에서 약미가 겹치거나 다름을, **병증 관계**는 같은 진료 질문에서 비교할 처방임을, **출전 관계**는 원전·후대 기록·연구 제제를 대조할 필요가 있음을 뜻합니다. 어느 연결도 두 처방을 함께 복용하라는 지시가 아닙니다.

| 관계 | 구체적인 예 | 추가로 알아야 할 것 |
|---|---|---|
| 구성 관계 | 마황발표탕과 마황정천탕의 공유 5미 | 각각의 약미 용량·법제·탕전과 실제 제제 |
| 병증 관계 | 한다열소탕과 열다한소탕의 표한·리열 감별 | 소증, 발한 뒤 상태, 갈증·대변·호흡 |
| 출전 관계 | 일반 보중익기탕과 소음인 보중익기탕 | 시호·승마 또는 곽향·소엽, 논문 중재의 실제 조성 |

[처방군·골격 비교](formula-families.md)는 계열의 구조를, [공통본초 빈도](ingredient-frequency.md)는 제한된 비교군의 출현 횟수를 다룹니다. 약미가 확인되어도 용량이 빠져 있으면 구성 관계는 설명할 수 있지만 [구성비·용량 지문](../sasang-formula-dose-fingerprint/index.md)을 계산할 수는 없습니다.

## 배합망을 읽는 다섯 원칙 {#_4}

1. **병증 위치가 먼저입니다.** 공통 약재가 많아도 표병과 리병이면 같은 계열로 대체하지 않습니다.
2. **골격과 분기를 나눕니다.** 반복되는 약물군은 기본 치료축을, 추가·제외된 약물은 증후와 중증도의 이동을 보여 줍니다.
3. **용량과 제형을 함께 봅니다.** 같은 약재라도 비중이 다르면 처방의 중심이 달라지고, 산제·탕제·후대 제제는 구분합니다.
4. **원전과 후대 수록을 구분합니다.** 『동의수세보원』의 병증·처방과 『동의사상신편』·공공 DB의 후대 처방을 같은 근거 층으로 표시하지 않습니다.
5. **반응으로 다시 판정합니다.** 주증뿐 아니라 소화·배설·땀·수면·갈증·활동이 건강 기준선으로 함께 회복되는지 확인합니다.

## 구성 유사성과 임상 감별의 관계 {#_5}

| 구성에서 보이는 것 | 구성만으로 알 수 없는 것 |
|---|---|
| 반복되는 본초군과 처방의 계통 | 실제 환자의 체질과 현재 병증 |
| 한 약물이 추가·제외되는 구조 | 처방 간 임상효과의 우열 |
| 용량 비중과 배합 중심 | 현대 질환명과의 일대일 대응 |
| 가까운 처방을 비교할 출발점 | 안전성·상호작용·응급 원인의 배제 |

따라서 이 네트워크는 처방 자동선택표가 아니라 **비슷해 보이는 처방을 어디서 다시 감별해야 하는지 보여 주는 지도**입니다.

## 근거와 안전 {#_6}

- 기본 구성과 전통 사용 맥락은 『동의수세보원』, 『동의사상신편』과 한국전통지식포탈 수록 자료를 대조합니다.
- 병증 진단·치료·관리 구조는 [2022 사상체질병증 한의표준임상진료지침](https://nikom.or.kr/nckm/module/practiceGuide/view.do?guide_idx=232&menu_idx=14)과 연결합니다. 체질진단 자체는 이 지침의 범위에서 제외됩니다.
- 현대 연구는 대상 체질·병증, 원방/가감방, 제형, 병행치료와 결과지표가 실제 처방과 같은지 별도로 확인합니다.
- 부자·마황·대황 등 안전성 확인이 중요한 약재는 구성 유사성보다 포제·용량·병용약과 환자 상태가 우선입니다.
