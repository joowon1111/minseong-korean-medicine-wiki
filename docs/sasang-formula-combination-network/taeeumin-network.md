# 태음인 처방 배합망

태음인 처방은 크게 **건율·의이인·나복자·길경·마황을 중심으로 한 위완수한표한·승청 계열**과 **갈근·황금·길경·나복자·승마를 중심으로 한 간수열리열 계열**로 갈립니다. 땀의 많고 적음 하나가 아니라 땀 뒤 느낌, 식후 복만, 호흡·담, 갈증·대변, 피부·수면이 어느 묶음으로 변했는지를 먼저 봅니다.

`평소 땀·소화·호흡 → 표한/리열 → 조위·승청·폐원/해기·청열·승기 → 처방 → 소증과 기능 재평가`

## 병증 단계와 배합을 한눈에 보기

| 병증축 | 처방 | 중심 배합 | 처방을 가르는 단서 |
|---|---|---|---|
| 표한·흉복통 | [마황정통탕](../sasang-formula-library/mahwangjeongtong-tang.md) | 마황·길경·행인 + 건율·의이인·나복자 | 오한·무한과 흉복통·신체통·호흡 변화 |
| 표한·비위 담습 | [태음조위탕](../sasang-formula-cards/taeeumjowi-tang.md) | 건율·의이인·나복자 + 길경·마황 + 맥문동·천문동·오미자 | 식후 팽만·몸의 무거움·담과 발한불리 |
| 표한·조위 | [승지조위탕](../sasang-formula-library/taeeumin-extended-formulas.md#taeeum-seungjijowi) | 태음조위탕 골격 + 백지·승마 | 무한·산증·식후 복만과 조위·상달 저하 |
| 표한·승청 저하 | [조위승청탕](../sasang-formula-cards/jowiseungcheong-tang.md) | 태음조위탕 골격 + 산조인·용안육·원지 | 중소·하지무력·회복 지연과 수면·심신 변화 |
| 승청·폐원 | [행인승청탕](../sasang-formula-library/haenginseungcheong-tang.md) | 조위승청 골격 + 행인 | 기침·담·호흡과 식후 불편·회복 지연 |
| 병후체허·폐원 | [조리폐원탕](../sasang-formula-library/joripyewon-tang.md) | 길경·마황·맥문동 + 의이인·나복자·황금 | 급성기 뒤 기침·호흡·식욕·활동 회복 지연 |
| 후대 승청·폐조 | [경험승청탕](../sasang-formula-library/taeeumin-extended-formulas.md#taeeum-gyeongheomseungcheong) | 건율·해송자 + 길경·마황·양음·안신축 | 호흡·건조·수면·심계가 함께 얽힌 회복 지연 |
| 간열·폐조 | [열다한소탕](../sasang-formula-cards/yeoldahanso-tang.md) | 갈근 고용량 + 고본·황금·길경·나복자·백지·승마 | 열·갈증·다한, 피부·대변 건조와 호흡 변화 |
| 리열·양독 | [갈근해기탕](../sasang-formula-library/galgeunhaegi-tang.md) | 갈근·승마·황금 + 길경·행인 + 대황 | 두면·인후·피부의 열성 변화와 복만·변폐 |
| 리열·조열·심신 | [청심연자탕](../sasang-formula-cards/cheongsimyeonja-tang.md) | 연육·산약 + 맥문동·천문동 + 원지·석창포·산조인·용안육 | 피로·현훈·심번·심계·수면과 조열 |
| 강한 리열·정체 | [청폐사간탕](../sasang-formula-cards/cheongpyesagan-tang.md) | 열다한소탕 골격 + 대황 | 번갈·변비·복만과 강한 리열 |
| 리열·승기 | [갈근승기탕](../sasang-formula-library/taeeumin-extended-formulas.md#taeeum-galgeunseunggi) | 갈근·대황·황금 + 길경·백지·승마 | 구갈·두면부 열증과 복만·변폐 |
| 리열·식체·정체 | [나복자승기탕](../sasang-formula-library/taeeumin-extended-formulas.md#taeeum-nabokjaseunggi) | 갈근승기 골격 + 나복자 | 열·변폐뿐 아니라 식후 복만·식체가 전면 |

## 네 개의 배합 중심축

### 1. 조위 골격: 건율·의이인·나복자

건율·의이인·나복자는 표한 계열에서 비위·담습과 식후 불편을 받치는 반복축입니다. 길경·마황이 폐의 호산과 표부를 연결하고, 맥문동·천문동·오미자가 폐원·진액축을 보완합니다.

| 골격의 변화 | 처방 | 임상에서 더 보는 부분 |
|---|---|---|
| 기본 조위·담습·폐원 | 태음조위탕 | 식후 팽만·무거움·무한·담 |
| 백지·승마 추가 | 승지조위탕 | 산증·상달 저하·발한불리 |
| 산조인·용안육·원지 추가 | 조위승청탕 | 중소·하지무력·수면·회복 |
| 행인과 안신·폐원축 확장 | 행인승청탕 | 기침·담·호흡의 비중 |
| 통증·행인·백자인·사군자 배합 | 마황정통탕 | 흉복통·신체통과 표한의 결합 |

이 계열에서 ‘건율이 들어간다’거나 ‘마황이 들어간다’는 사실만으로 처방을 정하지 않습니다. 같은 골격 안에서도 소화, 하지 기능, 호흡, 통증, 수면의 우선순위가 다릅니다.

### 2. 승청·폐원·심신 분기

조위승청탕과 행인승청탕은 태음조위탕 골격을 넓히지만 방향이 같습니다. 조위승청탕은 중소·하지무력·심신 회복, 행인승청탕은 기침·담·호흡 비중을 더 살핍니다. 조리폐원탕은 구성이 더 간결하고 **병후체허·회복기 폐원**에 초점을 둡니다.

청심연자탕에도 맥문동·천문동·원지·석창포·산조인·용안육이 겹치지만, 이는 표한 승청 저하가 아니라 간수열리열의 조열·심번·현훈·수면 맥락에서 읽습니다. 약재 유사성보다 표리병증이 우선입니다.

### 3. 갈근·황금의 간열폐조축

열다한소탕은 갈근을 중심으로 고본·황금·길경·나복자·백지·승마가 결합한 기본 리열 골격입니다.

| 변형 | 배합 차이 | 병증의 이동 |
|---|---|---|
| 열다한소탕 → 청폐사간탕 | 대황 추가 | 변비·복만·번갈과 강한 정체 쪽으로 이동 |
| 열다한소탕 → 갈근해기탕 | 행인·대황·산조인 배합, 나복자·고본 제외 | 두면·인후·피부의 양독과 통부 쪽으로 이동 |
| 갈근승기탕 | 갈근·대황·황금의 승기 골격 | 열·구갈과 변폐·복만이 중심 |
| 나복자승기탕 | 갈근승기탕에 나복자 | 식체·식후 복만의 비중이 커짐 |

### 4. 대황이 들어가는 승기·통부축

대황 포함 여부는 강한 리열과 정체를 읽는 중요한 구조 차이지만, ‘변비가 있으면 대황 처방’이라는 뜻은 아닙니다. 평소 배변과 현재 변폐의 시작, 복부팽만·구토, 수분상태와 전신의 허실을 함께 확인합니다.

- 열다한소탕 ↔ 청폐사간탕: 거의 같은 골격에서 대황 추가가 핵심입니다.
- 갈근승기탕 ↔ 나복자승기탕: 나복자 추가로 식체·복만의 비중을 더 봅니다.
- 갈근해기탕: 승기뿐 아니라 두면·인후·피부의 양독 맥락이 중심입니다.

## 가장 자주 헷갈리는 처방 쌍

| 비교 | 공통점 | 실제 갈림점 |
|---|---|---|
| 태음조위탕 ↔ 조위승청탕 | 건율·의이인·나복자·길경·마황·맥문동·천문동·석창포·오미자 | 기본 조위·담습인지, 중소·하지무력·심신 회복까지 필요한지 |
| 조위승청탕 ↔ 행인승청탕 | 승청·폐원·안신 골격 | 하지·전신 승청인지, 기침·담·호흡의 행인축인지 |
| 행인승청탕 ↔ 조리폐원탕 | 기침·호흡·회복 지연 | 승청·비위 골격이 큰지, 병후체허의 간결한 폐원 회복인지 |
| 조위승청탕 ↔ 청심연자탕 | 양음·안신 본초 다수 공유 | 표한·식후비만·하지무력인지, 리열·조열·심번인지 |
| 열다한소탕 ↔ 청폐사간탕 | 갈근·고본·황금·길경·나복자·백지·승마 | 대황이 필요한 변비·복만·강한 정체인지 |
| 갈근승기탕 ↔ 나복자승기탕 | 갈근·대황·황금·길경·백지·승마 | 열·구갈이 중심인지, 식체·식후 복만이 더 큰지 |

## 처방군 선택 흐름

```text
오한·무한·식후 복만·몸의 무거움이 앞선다
├─ 기본 조위·담습 → 태음조위탕
├─ 중소·하지무력·회복 지연 → 조위승청탕
├─ 기침·담·호흡 비중 증가 → 행인승청탕
└─ 흉복통·신체통 전면 → 마황정통탕

열·갈증·피부·대변 건조가 앞선다
├─ 간열폐조 기본축 → 열다한소탕
├─ 두면·인후·피부의 양독 → 갈근해기탕
├─ 심번·현훈·심계·수면 → 청심연자탕
└─ 변비·복만·강한 정체 → 청폐사간탕/승기계
```

## 복용 뒤 무엇을 다시 볼까

| 관찰축 | 호전 방향 | 처방군을 다시 볼 신호 |
|---|---|---|
| 땀 | 양보다 땀 뒤 개운함과 체온감 회복 | 심계·불면·탈진, 과도한 발한 |
| 소화·대변 | 식후 팽만과 배변이 함께 안정 | 새 설사·심한 복통·구토·변폐 지속 |
| 호흡·담 | 호흡과 활동, 수면이 함께 개선 | 호흡곤란·흉통·저산소증 |
| 갈증·수분 | 갈증·음수·소변이 기준선 회복 | 소변 감소·어지럼·심한 탈수 |
| 하지·활동 | 일어나기·걷기·피로 회복 | 진행성 근력저하·부종·실신 |

마황 포함 처방은 혈압·맥박·심계·불면과 다른 교감신경 자극 약물을, 대황 포함 처방은 설사·복통·탈수·임신·수유와 장폐색 신호를 별도로 확인합니다.

## 근거를 읽는 범위

- 원전 처방, 『동의사상신편』의 후대 수록 처방, 경험방은 같은 근거 층으로 표시하지 않습니다.
- 공통 약재와 구조적 유사성은 감별을 돕지만 치료효과의 동등성이나 대체 가능성을 뜻하지 않습니다.
- 현대 연구는 실제 사용 제제·가감·대상 체질·병증·병행치료가 원방과 같은지 확인합니다.
