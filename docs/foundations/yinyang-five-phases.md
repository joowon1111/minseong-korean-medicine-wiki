# 음양·오행

음양과 오행은 인체의 생리·병리와 자연의 변화를 **관계와 균형의 관점에서 설명하는 한의학의 기본 이론**이다.

## 음양
음양은 서로 대립하면서도 의존하고, 끊임없이 소장·전환하는 두 측면을 설명한다.

### 기본 관계
- **대립:** 한과 열, 안과 밖처럼 서로 대비되는 성질
- **상호의존:** 음과 양은 어느 한쪽만 독립적으로 존재하지 않음
- **소장:** 한쪽이 성하면 다른 쪽이 상대적으로 약해지는 변화
- **전환:** 일정한 조건에서 음적 상태가 양적으로, 양적 상태가 음적으로 변할 수 있음

임상에서는 한열·허실과 장부 기능의 균형을 이해하는 중요한 틀이 된다.

## 오행
오행은 목(木)·화(火)·토(土)·금(金)·수(水)의 다섯 범주로 변화와 상호관계를 설명한다.

| 오행 | 대표 장부 | 계절 | 방향 |
|---|---|---|---|
| 목 | 간·담 | 봄 | 동 |
| 화 | 심·소장 | 여름 | 남 |
| 토 | 비·위 | 장하 | 중앙 |
| 금 | 폐·대장 | 가을 | 서 |
| 수 | 신·방광 | 겨울 | 북 |

### 상생
`목 → 화 → 토 → 금 → 수 → 목`

서로 자생하고 돕는 관계다.

### 상극
`목 → 토 → 수 → 화 → 금 → 목`

지나친 편향을 제어해 전체의 균형을 유지하는 관계다.

## 임상적 의미
음양·오행은 처방을 기계적으로 결정하는 공식이라기보다 **장부와 증후 사이의 관계를 조직적으로 이해하는 언어**로 사용된다.
