# 폐(肺)

## 핵심 기능
**주기(主氣), 선발숙강(宣發肅降), 통조수도(通調水道)**

## 개요
폐는 호흡과 전신의 기운행, 체표의 선발, 수액대사의 일부를 주관한다고 설명된다.

## 현대적 해석의 원칙
한의학의 폐은 현대 해부학의 동일 이름 장기만을 뜻하지 않는다. 장기의 해부학적 기능에 더해 전신의 기혈진액·정신·체질적 기능을 포괄하는 전통적 기능체계로 이해한다.
