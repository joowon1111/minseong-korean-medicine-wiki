# 심(心)

## 핵심 기능
**주혈맥(主血脈), 장신(藏神)**

## 개요
심은 혈맥을 주관하고 정신활동의 중심인 신(神)을 간직한다고 설명된다. 심계·불면·건망 등의 전통적 변증과 밀접하다.

## 현대적 해석의 원칙
한의학의 심은 현대 해부학의 동일 이름 장기만을 뜻하지 않는다. 장기의 해부학적 기능에 더해 전신의 기혈진액·정신·체질적 기능을 포괄하는 전통적 기능체계로 이해한다.
