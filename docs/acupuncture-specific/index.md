# 특정혈·배혈 임상 지식망

경혈을 위치와 주치로만 보지 않고 **경맥 안에서의 역할과 다른 혈과의 연결**까지 함께 보는 지도입니다.

**361경혈 → 특정혈 속성 → 경맥·장부 관계 → 배혈 원리 → 임상 적용**

## 읽는 순서
**오수혈 → 원·락·극 → 배수·모 → 팔회·팔맥교회 → 배혈법 → 사암침법**

> 특정혈 분류와 오행 배속은 전통 침구 이론을 설명하는 체계입니다. 실제 치료에서는 환자 상태, 해부학적 안전성, 진단과 치료 목적을 함께 고려합니다.
