# 사암침법 기초 지식망

사암침법은 한국 전통 침법의 대표적인 체계 가운데 하나로, **오수혈의 오행 속성과 상생·상극 관계를 이용하여 자경과 타경의 혈을 조합**합니다.

## 이해 순서
**12경맥 → 오수혈 → 오행 배속 → 상생·상극 → 허실 → 자경·타경 → 보사 조합**

→ [오수혈·오행 통합표](five-shu.md)

## 정격과 승격
- **정격(正格)**: 해당 경맥의 허증을 보완하는 방향의 대표 형식
- **승격(勝格)**: 해당 경맥의 실증을 조절하는 방향의 대표 형식

처방을 외우기보다 **어떤 오행 관계 때문에 해당 혈이 선택되는지**를 이해하는 것이 핵심입니다.

### 예: 폐정격
폐경의 허를 예로 들면 토(土)의 관계를 이용하여 **LU9 태연·SP3 태백을 보하고**, 화(火)의 제어관계를 이용하여 **LU10 어제·HT8 소부를 사하는 구조**가 대표적으로 설명됩니다.

## 아카이브 연결
**경혈 상세 → 오수혈·오행 속성 → 경맥 → 사암침법 조합 원리**로 연결합니다. 따라서 SP3 태백 같은 혈도 위치·주치뿐 아니라 비경의 수혈·토혈이라는 속성과 배혈 구조까지 확장해 볼 수 있습니다.

## 근거를 읽는 법
오수혈·오행·보사 원리는 전통 이론 구조이고, 특정 질환에서의 효과는 별도의 현대 임상연구 근거와 구분해 읽습니다.
