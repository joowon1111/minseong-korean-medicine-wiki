# 말초신경 초음파

말초신경 초음파는 신경의 **주행, 단면적, 형태, 주변 근육·혈관과의 관계, 포착부위**를 동적으로 확인하는 데 활용됩니다.

## 상지
- 정중신경 → 손목터널·전완
- 척골신경 → 주관·Guyon canal
- 요골신경 → radial tunnel
- 견갑상신경 → suprascapular notch

## 하지
- 좌골신경 → 심부둔부
- 외측대퇴피신경 → 서혜인대 주변
- 총비골신경 → 비골두
- 경골신경 → 족근관
