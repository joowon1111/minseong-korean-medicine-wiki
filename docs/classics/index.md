# 한의학 고전

이 아카이브의 고전 영역은 단순한 책 소개가 아니라 **원전 → 개념 → 본초 → 방제 → 변증 → 현대 연구**를 연결하는 축으로 운영합니다.

## 핵심 고전

| 고전 | 주요 역할 |
|---|---|
| [황제내경](huangdi-neijing.md) | 음양·장부·기혈·경락·침구의 이론적 기반 |
| [상한론](shanghanlun.md) | 외감병의 변증과 처방 운용 체계 |
| [금궤요략](jinkui-yaolue.md) | 내과·잡병의 증후와 처방 체계 |
| [비급천금요방](beiji-qianjin-yaofang.md) | 당대 임상의학의 대규모 집성 |
| [비위론](piwei-lun.md) | 비위기허·중기하함과 이동원의 비위학설 |
| [동의보감](donguibogam.md) | 조선 의학의 종합적 지식 체계 |
| [동의수세보원](donguisusebowon.md) | 이제마의 사상의학·체질의학 체계 |

## 편집 원칙
1. 원문은 실제 판본이나 공신력 있는 디지털 원문을 확인한 뒤 수록합니다.
2. 원문·번역·현대적 해설을 명확히 구분합니다.
3. 후대의 해석을 원저자의 문장처럼 표현하지 않습니다.
4. 고전의 질병명과 현대 질환명을 단순 대응시키지 않습니다.
5. 관련 본초·방제·변증 문서와 양방향 내부링크를 구축합니다.
