# 한의학 고전 임상 지식망 {#_1}

민성 한의학 아카이브는 **오랜 시간 축적된 한의학 문헌 가운데 오늘날에도 임상적·학술적으로 살펴볼 가치가 높은 지식을 선별하고, 현대 한의학의 임상 체계와 최신 연구 근거에 연결하여 활용 가능한 지식으로 정리합니다.** **궁금한 질문에 맞는 책을 고르고, 원문이 관찰한 증후와 치료 판단을 따라 읽는 것**이 이 자료실의 출발점입니다. 책별 개요에서는 구성과 읽는 방법을, 상세 지식망에서는 병증·본초·방제·경혈의 연결을 살펴볼 수 있습니다.

## 민성의담 — 고전 속 한의학 {#_5}

[민성의담 旻城醫談](../classical-stories/index.md)은 ‘고전의 기록, 오늘의 한의학’을 주제로 옛 의서의 한 장면에서 병기와 처방 판단을 따라 읽는 칼럼입니다. 첫 이야기 [기침은 같아도 약첩은 달랐다](../classical-stories/cough-formulas.md)에서는 소청룡탕과 맥문동탕을 비교하고, 마른기침을 다루는 처방에 반하가 들어가는 이유를 살펴봅니다.

## 고전과 현대를 연결하는 방향 {#clinical-selection}

**원문 → 현대어 해석 → 병증·병기 → 치법 → 본초·방제·침구 → 현대 임상·근거**를 한 흐름으로 읽습니다. 원문은 편명·조문에서 확인하고, 약재 구성과 연구 결과는 기존 기준문서로 이어가면 같은 내용을 여러 곳에서 반복하지 않고 깊이 있게 탐색할 수 있습니다.

WHO의 [Global Traditional Medicine Strategy 2025–2034](https://www.who.int/publications/i/item/9789240113176)가 제시하는 과학적 근거 강화, 안전성과 효과성, 연구 및 적절한 보건의료체계 통합의 방향을 참고합니다. 실제 임상연구와 국제 표준화의 맥락은 [연구·근거 안내](../portal/evidence.md#who-tm-context)에서 이어 봅니다.

태루·태동불안·활태·최생은 임신 경과·출혈·분만의 맥락이 서로 다릅니다. 현재 임신의 치료·출혈 평가와 분만 계획은 [임신 중 진료](../conditions/pregnancy-herbal-care.md)에서 확인하고, 산후 발열·붕루·유즙·욕로 등은 [산후회복](../conditions/postpartum-recovery.md)에서 원인과 치료 단계를 구분합니다. 반진·혈풍창·렴창·이창·옹저는 병변의 위치·형태·진물·감염 여부를 원문과 현재 진찰에서 대조합니다.

## 읽는 순서 {#_3}

책 전체를 처음부터 읽기 어렵다면 질문 하나를 정합니다. 예를 들어 ‘비슷한 표증에서 계지탕과 마황탕은 왜 구분되는가’, ‘비위론에서 피로와 식사는 어떻게 연결되는가’처럼 비교할 대상이 분명한 질문이 좋습니다.

**원문·출전 → 증후와 맥증 → 병기·치법 → 구성·제법 → 후대 해석 → 현대 연구** 순서로 읽으며, 원문과 주석·현대 해설이 각각 무엇인지 구별합니다. 옛 용량을 현재 복용량으로 바로 바꾸거나, 병증명을 현대 진단명과 일대일로 맞추지는 않습니다.

목적별로 책을 고르려면 [고전 읽는 순서](../classics-network/reading-path.md)를, 두 책의 관점 차이를 보려면 [주요 고전 9종 비교](../classics-network/comparison.md)를 이용하세요. 같은 병증을 여러 책에서 찾을 때에는 각 책의 편제·용어·시대가 다르다는 점도 비교 항목으로 남깁니다.

## 원문에서 현대 자료로 연결하기 {#classics-to-clinic}

| 확인 단계 | 기록하면 좋은 내용 |
|---|---|
| 출전 | 책·판본·권 또는 편·조문 첫 구절 |
| 문맥 | 주증과 동반증상, 앞뒤 조문, 이전 치료와 경과 |
| 해석 | 원문의 표현과 후대 주석에서 덧붙인 설명 |
| 치료 구조 | 치법, 약재 배합, 제형·제법, 침구와의 관계 |
| 현대 자료 | 실제 연구 대상, 중재, 비교군, 평가 결과와 한계 |

고전은 병기와 치법의 출전을 확인하는 자료이고 현대 연구는 특정 대상·중재의 결과를 확인하는 자료입니다. 둘을 연결할 때 필요한 비교 항목은 [고전→현대 연구](../network/classic-to-evidence-map.md)에서 이어 봅니다.
