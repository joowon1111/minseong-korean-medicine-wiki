# 고전 처방을 읽는 방법

처방명과 구성 약재만으로 고방을 충분히 이해하기 어렵습니다. 특히 같은 처방명이라도 시대와 판본, 후대 가감에 따라 구성과 용량이 달라질 수 있습니다.

## 기본 확인 순서

1. **출전** — 어느 고전에 처음 또는 대표적으로 수록되었는가
2. **원문 병증** — 어떤 증후·맥증에서 제시되었는가
3. **구성** — 어떤 본초가 들어가는가
4. **원방 용량** — 고전 단위와 현대 환산을 구분
5. **제법·복용법** — 탕·환·산·고 등 제형과 조제법
6. **군신좌사·약대** — 처방 구조
7. **가감과 후대 처방계열**
8. **현대 연구** — 실제 사용한 구성·용량·대상군 확인

## 현대 용량을 표시할 때

고전 단위를 단순히 하나의 g값으로 고정하지 않고 **판본·환산법의 차이와 임상에서 사용되는 범위**를 구분해 적는 것이 좋습니다.
