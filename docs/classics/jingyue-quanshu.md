# 경악전서(景岳全書) {#_1}

《경악전서》는 명대 의가 **[장개빈(張介賓, 호 경악)](../physicians/zhang-jingyue.md)**의 이론과 임상 경험을 집대성한 종합 의서입니다. 음양과 장부의 생리·병리를 바탕으로 맥진, 상한, 잡증, 부인·소아·두진·외과, 본초와 방제를 폭넓게 연결합니다.

## 전체 구성의 핵심 {#_2}

| 영역 | 주요 내용 |
|---|---|
| 전충록·맥신장 | 의학의 기본 관점과 맥진 |
| 상한전 | 상한 병증과 진단·치료 |
| 잡증모 | 내과 잡증의 병기와 치법 |
| 부인규·소아칙 | 부인과·소아과의 임상 체계 |
| 두진전·외과검 | 두진과 외과 병증 |
| 본초정 | 본초의 성미·효능과 운용 |
| 신방팔진·고방팔진 | 새로 구성한 처방과 기존 처방의 분류 |

## 임상 사상의 특징 {#_3}

### 음양과 장부를 중심으로 보기 {#_4}

증상 하나보다 음양의 성쇠, 장부 기능, 정기와 사기의 관계를 함께 보며 병기의 중심을 찾습니다.

### 허손과 보법 {#_5}

허손을 세밀하게 구분하고 음·양·정·기의 부족을 치료 원칙과 연결한 점이 중요합니다. 다만 보법은 무조건 보하는 의미가 아니라 실제 허증 여부와 담습·어혈·울체·열증의 동반 여부를 함께 판단하는 구조입니다.

허손을 공부할 때에는 먼저 무엇이 부족하다고 설명하는지 적고, 다음으로 소화·수분대사·열·정체 가운데 병행해서 다룰 요소를 찾습니다. 같은 피로라는 표현이 있어도 음·양·정·기의 구분과 동반 병기가 다르면 치료 방향이 달라집니다. [보익 처방 비교](../network/tonic-formula-compare.md)는 이 차이를 처방 구성으로 이어 읽는 자료입니다.

### 신방팔진과 고방팔진 {#_6}

처방을 보·화·공·산·한·열·고·인이라는 치료 방향으로 분류합니다. 신방과 고방은 각각의 처방군을 살피는 구분이고, 팔진은 어떤 방향으로 병기를 다루는지 읽는 분류입니다. ‘보약을 많이 쓴 책’이라는 요약만으로는 화·공·산·한 등 다른 치료 방향을 놓칠 수 있습니다.

| 팔진 | 분류를 읽는 기본 방향 |
|---|---|
| 보(補) | 부족한 것을 보충 |
| 화(和) | 치우친 관계를 조화·조정 |
| 공(攻) | 적체 등 제거할 병리 요인을 다룸 |
| 산(散) | 밖으로 풀거나 흩어 주는 방향 |
| 한(寒) | 열을 식히는 방향 |
| 열(熱) | 한을 따뜻하게 다스리는 방향 |
| 고(固) | 새거나 빠져나가는 것을 수렴·고섭 |
| 인(因) | 개별 병증과 상황에 따른 운용을 살핌 |

이는 목차를 이해하는 안내입니다. 실제 처방은 여러 작용을 함께 가지므로 한 글자만으로 효능이나 적응증을 확정하지 않습니다. [방제 구조](../formula-architecture/index.md)에서 약물 배합과 전체 치법을 함께 확인할 수 있습니다.

## 병증에서 처방까지 찾아가는 순서 {#reading-route}

1. 잡증모 등에서 관심 병증을 찾고, 저자가 구분한 원인과 허실의 조건을 기록합니다.
2. 필요한 이론·맥진 설명을 전충록·맥신장에서 대조합니다.
3. 제시된 치료 방향이 어느 팔진에 해당하는지 살피고 실제 처방을 확인합니다.
4. 본초정에서 약물 설명을 보되, 단미 효능과 처방 전체의 목적을 구별합니다.

예를 들어 허손이 관심사라면 허손 논의와 보진을 중심으로 시작하고, 같은 증후를 설명하는 [금궤요략](jinkui-yaolue.md)의 허로 문목과 비교합니다. 체질에 따른 설명이 궁금할 때에는 [동의수세보원](donguisusebowon.md)의 장부·소증 체계가 다른 분류라는 점을 먼저 확인합니다. 현재의 회복·보약에 관한 실용적인 질문은 [보익·회복 안내](../pillar/tonic-recovery.md)로 이어집니다.
