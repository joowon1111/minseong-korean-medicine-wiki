# 갈근탕 조문

!!! info "조문 ID"
    **MS-SHL-TY-GGT-001** — 민성 한의학 아카이브 내부 관리용 ID입니다.

## 대표 원문
> 太陽病，項背強几几，無汗惡風，葛根湯主之。

## 번역
태양병에서 목덜미와 등이 뻣뻣하고 당기며, 땀이 나지 않고 바람을 싫어하는 경우에는 갈근탕이 주치한다고 기술한다.

## 관련 합병 조문
상한론에는 태양·양명 합병에서 자하리(自下利)가 나타나는 경우 갈근탕을 사용하는 조문도 전한다.

## 계지가갈근탕과 비교
- 계지가갈근탕: 항배강 + **한출** + 오풍
- 갈근탕: 항배강 + **무한** + 오풍

이는 증상 하나만으로 처방을 선택하기보다 증후의 조합을 비교하는 상한론의 특징을 보여준다.
