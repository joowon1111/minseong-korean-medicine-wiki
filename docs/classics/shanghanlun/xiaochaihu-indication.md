# 소시호탕 주치 조문

!!! info "조문 ID"
    **MS-SHL-SY-XCHT-001** — 아카이브 내부 관리용 ID입니다.

## 원문
> 傷寒五六日，中風，往來寒熱，胸脅苦滿，默默不欲飲食，心煩喜嘔……小柴胡湯主之。

## 번역
상한이 된 지 5~6일 무렵에 왕래한열이 있고, 가슴과 옆구리가 그득하고 불편하며, 묵묵히 음식 먹기를 싫어하고, 가슴이 답답하고 구역하려는 등의 증후가 나타날 때 소시호탕이 주치한다고 기술한다.

## 핵심 증후
- 왕래한열(往來寒熱)
- 흉협고만(胸脅苦滿)
- 묵묵불욕음식(默默不欲飲食)
- 심번희구(心煩喜嘔)

## 해설
상한론에서 소시호탕은 소양 계열 병증을 이해하는 핵심 처방이다. 다만 원문에는 이어지는 여러 '혹(或)' 증후와 가감법이 있으므로 전체 조문은 원전 페이지에서 확장할 예정이다.
