# 침구대성 — 명대 침구학의 종합과 배혈

《침구대성》(鍼灸大成)은 명대 양계주(楊繼洲)가 1601년에 간행한 침구 종합서입니다. 선행 의서의 경락·경혈·자침·구법·가결과 양씨 가전의 임상 내용을 모아 후대 침구 교육과 임상에 큰 영향을 주었습니다. 여러 시대의 자료가 함께 실려 있으므로 각 문장이 같은 시기·같은 저자의 견해라고 가정하지 않는 것이 중요합니다.

## 무엇을 찾을 때 유용한가

| 질문 | 책에서 확인할 내용 | 현재 자료와의 연결 |
|---|---|---|
| 경혈 위치와 주치 | 경맥별 혈위·주치 기록 | [표준 경혈 아틀라스](../acupoint-network/standard-atlas.md) |
| 증상에 따른 배혈 | 부위별·병증별 가결과 처방 | [배혈 원칙](../acupuncture-specific/pairing-principles.md) |
| 자침 조작과 보사 | 수기법·보사·득기 관련 기록 | 현대 술기교육·안전 기준과 분리해 검토 |
| 뜸의 적용과 금기 | 구법, 장수, 금구 기록 | [침 치료 안전성과 임상해부학](../acupuncture-integrated/safety.md) |

## 사총혈가를 어떻게 읽을까

책에 수록된 사총혈가의 “肚腹三里留，腰背委中求，頭項尋列缺，面口合谷收”는 복부–족삼리, 허리·등–위중, 머리·목–열결, 얼굴·입–합곡을 연결한 기억법입니다.

| 부위 색인 | 대표 혈 | 현재 확인할 사항 |
|---|---|---|
| 배·복부 | [족삼리 ST36](../acupuncture/points/st36-zusanli.md) | 복통 위험신호와 원인, 국소·원위 배혈 목적 |
| 허리·등 | [위중 BL40](../acupuncture/points/bl40-weizhong.md) | 신경학적 결손·외상·혈관 위험과 움직임 평가 |
| 머리·목 | [열결 LU7](../acupuncture/points/lu7-lieque.md) | 급성 신경학적 증상과 경추성·일차성 두통 감별 |
| 얼굴·입 | [합곡 LI4](../acupuncture/points/li4-hegu.md) | 치과·이비인후과 원인, 임신 등 주의사항 |

이는 네 혈을 각 부위 증상에 자동 적용하는 고정 처방표가 아닙니다. 주증, 경맥, 국소 소견, 동반증상과 안전성을 바탕으로 배혈 가설을 세우는 전통적 색인으로 읽습니다.

## 선행 문헌과 연결해 읽기

《침구대성》은 앞선 문헌을 폭넓게 인용합니다. 경혈의 이른 체계는 [침구갑을경](zhenjiu-jiayi-jing.md), 경맥·경근의 이론적 배경은 [황제내경](huangdi-neijing.md), 오수혈·기경팔맥의 논점은 [난경](nanjing.md)과 대조하면 출전 층위를 확인하기 쉽습니다.

## 현대 임상에 옮길 때

1. 원문에서 증상 묶음과 치료 목적을 확인합니다.
2. 표준 혈명·코드와 현대 취혈 위치를 다시 확인합니다.
3. 개인별 해부학과 위험구조, 출혈·감염 위험을 평가합니다.
4. 질환별 임상연구의 대상·자침법·치료량과 결과를 검토합니다.
5. 통증뿐 아니라 기능과 이상반응을 같은 방식으로 추적합니다.

고전의 깊이·방향·장수는 현대의 보편적 안전 수치가 아닙니다. 원문이 역사적 술기 근거라면, 현재의 해부학·감염관리·응급대응은 실제 시술의 필수 기준입니다.
