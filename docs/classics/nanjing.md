# 난경(難經)

《난경》은 《황제내경》의 중요한 이론과 임상 쟁점을 **81개의 문답**으로 풀어낸 고전입니다. 맥진·경락·기경팔맥·장부·병증·수혈·침법을 간결하게 논해, 기초 이론과 실제 진단·침구 임상을 연결하는 역할을 합니다.

## 어떤 책인가요?

서명은 ‘어려운 의문을 풀이한 경전’이라는 뜻입니다. 전통적으로 진월인(秦越人), 곧 편작과 연결해 전해지지만 실제 성립 시기와 저자 문제는 여러 견해가 있으므로 단정하지 않습니다.

| 범위 | 중심 내용 |
|---|---|
| 1–22난 | 촌구맥과 맥진의 원리 |
| 23–29난 | 경맥·낙맥과 기경팔맥 |
| 30–47난 | 영위·삼초·장부의 생리와 구조 |
| 48–61난 | 질병의 허실·병인·진단 |
| 62–68난 | 오수혈·원혈 등 수혈 이론 |
| 69–81난 | 보사·영수·침법과 치료 원칙 |

판본과 주석서에 따라 세부 구분이나 해석은 달라질 수 있습니다.

## 임상에서 중요한 연결

### 맥진

촌구맥을 통해 장부와 병증을 판단하는 논리를 살피되, 맥 하나만으로 질환을 단정하지 않고 문진·설진·복진과 함께 해석합니다.

### 경락과 기경팔맥

십이경맥뿐 아니라 독맥·임맥·충맥·대맥·양교맥·음교맥·양유맥·음유맥의 기능과 병증을 이해하는 중요한 출전입니다.

### 수혈과 침법

오수혈·원혈·보사법을 병기의 허실과 연결합니다. 현대 임상에서는 해부학적 위치, 안전 깊이와 환자 상태를 함께 확인합니다.
