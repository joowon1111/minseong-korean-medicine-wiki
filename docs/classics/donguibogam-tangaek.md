# 동의보감 탕액편 임상 지도 {#_1}

《동의보감》 탕액편은 약재를 단순 목록으로 보는 것이 아니라 **기원·성미·주치와 실제 처방 속 역할**을 이해하는 고전적 기반입니다.

## 본초를 읽는 순서 {#_2}

1. 약재명과 기원
2. 사용 부위와 법제
3. 성미·귀경
4. 전통 효능과 주치
5. 함께 쓰는 약대
6. 대표 방제에서의 역할
7. 현대 성분·약리·임상연구
8. 안전성·품질

## 현재 본초 지식망과 연결 {#_3}

탕액편의 약재 기록을 현재의 효능별 본초 분류로 연결합니다. 아래 표는 **아카이브에서 연결한 임상 색인**이며, 원전의 편목을 현대 효능 분류와 동일하게 바꾼 목록은 아닙니다.

## 고전과 현대 연구 {#_4}

고전의 효능 용어와 현대 약리작용을 그대로 같은 개념으로 치환하지 않고, 실제 연구의 성분·추출법·용량·대상군을 확인합니다.

| 연구로 연결할 때 | 확인할 자료 |
|---|---|
| 약재 자체·추출물의 연구 | [본초 근거](../authority/herbs/index.md)에서 기원·부위·추출 조건 확인 |
| 복합 처방의 사람 대상 연구 | [보중익기탕](../research/formulas/buzhong-yiqi-tang.md)·[반하사심탕](../authority/formulas/banxia-xiexin-tang.md) 등 실제 구성 확인 |
| 회복·보익의 적용 범위 | [보익 연구 해석](../clinical-guides/tonic-research-deep-guide.md)에서 대상·결과·병용 여부 확인 |
| 안전한 사용 조건 | [한약 안전성](../herbal-integrated/safety.md#safety-evidence-guide)에서 간·신장·병용약·품질 확인 |

예를 들어 인삼을 찾아보았다면 [인삼 본초 문서](../herbs/ginseng.md)에서 기원과 활용을 읽고, [사군자탕](../formulas/sijunzi-tang.md)에서 보기건비의 배합을 확인할 수 있습니다. 이 연결은 학습 경로이며, 동의보감의 모든 처방에 인삼이 들어간다는 의미가 아닙니다.
