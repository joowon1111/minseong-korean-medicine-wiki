# 상한론(傷寒論)

《상한론》은 장중경 계통의 의학을 대표하는 고전으로, **맥증과 증후의 조합을 바탕으로 병의 단계와 처방을 연결하는 임상 체계**를 보여준다.

## 육경
- 태양병
- 양명병
- 소양병
- 태음병
- 소음병
- 궐음병

육경은 단순한 해부학적 부위가 아니라 병의 진행과 인체 반응을 해석하는 임상적 틀로 활용된다.

## 태양병과 대표 처방
```text
태양병
├─ 중풍 → 계지탕
├─ 상한 → 마황탕
├─ 번조·표실 → 대청룡탕
├─ 수음 → 소청룡탕
└─ 수기불리 → 오령산
```

## 의학사적 의미
《상한론》의 특징은 질환명 하나에 처방 하나를 고정하기보다 **현재 나타나는 맥과 증후를 종합해 처방을 선택한다는 점**이다. 이 구조는 이후 동아시아 방제학과 변증치료에 큰 영향을 주었다.
