# 침·전침·약침 치료방식 비교

치료방식은 어느 하나가 항상 우월한 것이 아니라 **증상·조직 상태·치료목표·자극 민감도·안전성**에 따라 선택합니다.

| 방식 | 핵심 | 임상에서 보는 점 |
|---|---|---|
| 침 | 경혈·국소조직에 수기 자극 | 배혈·깊이·방향·득기 |
| 전침 | 침에 전기자극을 연결 | 주파수·강도·통증/근육 목표 |
| 약침 | 경혈·조직에 약침액 적용 | 제제·용량·알레르기·무균 |

## 선택의 흐름
위험신호·구조적 감별 → 경맥·변증 → 국소/원위혈 → 자극 방식 → 치료반응 재평가

처음 치료를 비교할 때는 [침·전침 차이](../compare/acupuncture-vs-electroacupuncture.md)·[침·약침 차이](../compare/acupuncture-vs-pharmacopuncture.md)를 읽습니다. 진료에서는 목표 증상과 기능, 자극 민감도, 제제·부위를 확인하고 [치료량](dose-followup.md)과 [다음 평가](response-reassessment.md)를 정합니다.
