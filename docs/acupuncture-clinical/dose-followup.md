# 치료 강도·빈도·경과
침구치료의 '용량'은 약물처럼 한 숫자로만 표현되지 않습니다.

## 구성요소
- 치료 횟수
- 치료 간격
- 사용 혈수
- 자침 깊이·조작
- 유침시간
- 전침 자극 강도·빈도
- 뜸·부항 병행 여부
- 운동·자가관리 병행

## 경과관찰
```text
초진 기능 기준점
 ↓
1~수회 치료
 ↓
통증 + 기능 + 활동량 평가
 ↓
반응 있음 → 단계적 기능 회복
반응 부족 → 진단·치료전략 재평가
```

만성통증에서는 단기 통증점수뿐 아니라 **걷기·수면·업무·운동 등 실제 기능**을 함께 추적하는 것이 중요합니다.
