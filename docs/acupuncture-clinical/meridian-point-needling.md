# 경락 → 경혈 → 자침
전통 침구학에서는 장부·경락·경혈을 연결하고, 현대 임상에서는 여기에 국소 해부학·근육·신경·압통점 정보를 함께 활용할 수 있습니다.

```text
증상·병증
 ↓
관련 경락
 ↓
원위 경혈
 +
국소 경혈·압통점
 ↓
자침 방법·자극량
 ↓
반응 평가
```

## 경혈 선택의 네 층
1. 국소 부위
2. 해당 경락의 원위혈
3. 병증에 따른 배혈
4. 기능·근막·압통점 기반 접근

경혈의 이름만 외우기보다 **왜 그 혈을 선택했는가**가 위키에서 드러나도록 구성합니다.
