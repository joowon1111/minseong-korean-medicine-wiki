# 근골격 통증 감별
## 통증에서 먼저 묻는 것
- 어디가 아픈가?
- 언제 시작됐나?
- 어떤 동작에서 심해지는가?
- 휴식/야간에도 지속되는가?
- 저림·감각저하·근력저하가 있는가?
- 발열·외상·체중감소 등 전신 신호가 있는가?

## 임상 패턴
| 패턴 | 확인할 것 |
|---|---|
| 근육·근막 | 압통점, 반복동작, 자세 |
| 관절 | 특정 가동범위, 부하 시 통증 |
| 신경 | 방사통, 저림, 감각·근력 |
| 염증성 | 휴식통, 강직, 열감·부종 |
| 내장 연관 | 움직임과 무관한 통증, 전신증상 |

WHO의 만성 일차성 요통 지침은 단일 치료보다 사람 중심의 통합적 접근을 강조하며, 교육·운동·일부 물리치료·심리치료·약물 등 여러 중재를 상황에 맞게 조합할 수 있다고 설명합니다.
