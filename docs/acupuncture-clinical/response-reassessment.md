## 치료 직후와 다음 날을 나누어 보기 {#after-acupuncture-response}

침을 맞고 바로 편해진 느낌, 시술부위의 국소 뻐근함, 원래 통증의 변화는 나누어 설명합니다. 시술 후 불편이 모두 치료가 잘 듣는 신호인 것은 아닙니다. 정도·기간·확산 여부와 일상 기능을 함께 확인합니다.

| 관찰한 변화 | 다음에 확인할 내용 |
|---|---|
| 직후 편하지만 금방 다시 아픔 | 효과가 유지된 시간과 다시 악화시킨 자세·작업 |
| 통증은 비슷해도 더 오래 걸음 | 활동량과 기능 개선을 별도로 기록 |
| 통증은 줄었는데 힘이 계속 약해짐 | 신경 기능을 재평가하고 필요한 검사 연결 |
| 부위가 뻐근하거나 멍이 생김 | 크기·강도·지속시간과 점점 심해지는지 확인 |
| 약침 뒤 가려움·부기가 생김 | 정확한 제제와 국소·전신 반응을 구분 |

## 연락·평가가 필요한 변화 {#after-treatment-assessment}

숨참·흉통, 전신 두드러기와 목 부종·실신, 진행하는 근력저하는 신속히 평가합니다. 발열과 함께 붉어짐·열감·부종이 커지거나 통증이 계속 악화되는 경우도 시술기관에 알립니다. → [안전·위험신호](../acupuncture-integrated/safety.md)

## 좋아졌다면 무엇을 줄이거나 늘리나요? {#response-based-plan}

치료 없는 날에도 기능이 유지되는지 확인하며 내원 간격을 조정하고 활동·운동을 단계적으로 확대합니다. 변화가 없으면 자극을 더하기 전에 진단, 목표 부위, 생활 부하와 동반 질환을 다시 살핍니다.

진료 때 **가장 불편한 활동 1~2개, 편했던 시간, 다음 날 반응, 새 증상**을 알려 주면 치료 계획을 구체적으로 조정하기 쉽습니다. 침·전침·약침·한약을 병행했다면 각 치료 시점과 변화도 함께 기록합니다.
