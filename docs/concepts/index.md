# 한의학 핵심 병리·변증 개념

한의학 병리개념은 현대 질환명과 일대일로 대응하지 않고 **환자에게 나타나는 증상 조합과 치료 방향을 설명하는 변증 언어**로 사용합니다.

## 개념을 읽는 기본 구조

```text
환자가 느끼는 증상
 + 평소 소증과 경과
 + 망진·문진·절진
        ↓
병위: 표·리 / 장부·경락
병성: 한·열 / 허·실
병리: 기·혈·진액 / 담음·어혈·식적
        ↓
주병기 + 겸증
        ↓
치법과 치료 후 재평가
```

같은 피로도 기허·혈허·양허·담습에서 나타날 수 있고, 같은 환자에게 기허와 담습처럼 부족과 정체가 함께 존재할 수 있습니다.

## 허증 — 무엇이 부족한가

| 개념 | 핵심 방향 | 함께 보는 증상 | 대표 치법 |
|---|---|---|---|
| [기허](../diagnostics/patterns/qi-deficiency.md) | 기능과 추진력 부족 | 피로·무기력·숨참·자한·식후 피곤 | 보기·익기 |
| [혈허](../diagnostics/patterns/blood-deficiency.md) | 영양·윤택의 부족 | 어지럼·창백·건조·저림·수면 불편 | 보혈·양혈 |
| 음허 | 진액·음분의 부족 | 구건·건조·도한·오심번열·야간 증상 | 자음·생진·청허열 |
| 양허 | 온후·기화 기능의 부족 | 냉감·사지냉·부종·묽은 변·기력저하 | 온양·보양 |
| [신허](../diagnostics/patterns/kidney-deficiency.md) | 신계 기능의 허약 | 요슬산연·이명·배뇨·생식·만성 회복 저하 | 보신익정·자음·온양 |
| [심비양허](heart-spleen-deficiency.md) | 기혈 생성과 심신 안정의 동반 저하 | 식욕저하·피로·불면·두근거림·건망 | 건비익기·보혈양심 |
| [중기하함](spleen-qi-sinking.md) | 비기허에 승거 저하가 결합 | 처짐·탈항·장기 하수감·만성 설사 | 보중익기·승양거함 |
| [간신부족·허손](liver-kidney-deficiency.md) | 간신의 정혈·음분 허약 | 현훈·이명·눈·근육·허리·무릎 증상 | 자보간신·익정 |

### 기허·혈허·기혈양허 구분

- **기허:** 활동할 힘과 기능 유지가 부족한 양상
- **혈허:** 영양·윤택·수면과 감각의 부족이 두드러지는 양상
- **기혈양허:** 두 방향이 함께 나타나 피로·창백·어지럼·수면·회복 저하가 겹치는 구조

## 한열 개념

| 방향 | 환자가 말하는 예 | 진찰에서 함께 보는 것 |
|---|---|---|
| 한증 | “손발과 배가 차요”, “따뜻하면 편해요” | 분비물·대변·소변, 안색, 설맥, 기능 저하 |
| 실열 | “열이 나고 갈증이 심해요”, “붉고 붓고 아파요” | 발열·염증, 황색 분비물, 설홍태황 |
| 허열 | “밤에 열이 오르고 식은땀이 나요” | 건조·도한·오심번열, 설홍소태 |
| 한열착잡 | 위아래·겉과 속에 한열이 섞임 | 시간대·부위·배설·소화의 상반된 변화 |

체온계의 발열과 한의학의 열증은 같은 말이 아닙니다. 감염·염증·내분비질환 등 현대의학적 원인을 먼저 확인하면서 전체 증후를 해석합니다.

| 증상군 | 우선 살필 장부·병증 예 |
|---|---|
| 스트레스성 흉협·소화·월경 변화 | 간기울결, 간비불화 |
| 두근거림·불면·건망 | 심혈허, 심음허, 심비양허, 담화요심 |
| 식욕저하·복창·묽은 변·피로 | 비기허, 비양허, 담습 |

| 요슬산연·이명·배뇨 변화 | 신양허, 신음허, 신기불고 |

## 증상에서 개념 찾기

### 피로

- 활동하면 심해지고 숨이 차며 땀이 많음 → 기허 방향
- 어지럽고 창백하며 건조·저림이 동반 → 혈허 방향
- 몸이 무겁고 속이 더부룩하며 붓는 느낌 → 담습 방향
- 냉감·야간뇨·허리·무릎 약화 → 양허·신허 방향

### 통증

- 찬 날 심하고 따뜻하면 편함 → 한습
- 외상 뒤 한곳이 찌르듯 지속 → 어혈
- 스트레스에 따라 위치·강도가 변함 → 기체
- 오래되고 피로·무력과 함께 회복이 느림 → 기혈허·간신부족

### 불면

- 피로·식욕저하·두근거림·건망 → 심비양허
- 구건·오열·야간각성 → 음허·허열
- 흉민·오심·꿈이 많음 → 담울·담열
- 스트레스·근긴장과 함께 악화 → 간울기체

## 비슷한 개념을 감별하는 질문

1. 부족이 중심인가, 정체와 과잉이 중심인가?
2. 차고 기능이 떨어지는가, 열과 번조가 두드러지는가?
3. 증상이 움직이고 변동하는가, 한곳에 고정되는가?
4. 식사·수면·대소변·땀·월경 가운데 무엇이 함께 변하는가?
5. 급성기인가, 오래되어 허증이 중심으로 바뀌었는가?
6. 치료 뒤 어떤 기능이 회복돼야 가설이 맞다고 볼 수 있는가?

## 개념 사용 시 주의

- 변증 개념으로 빈혈·갑상선·감염·심폐질환 같은 진단을 대신하지 않습니다.
- 혀·맥 한 가지 소견으로 병증을 확정하지 않습니다.
- 여러 개념을 많이 붙이기보다 주병기와 겸증을 구분합니다.
- 치료 반응이 예상과 다르면 병기 가설과 검사 필요성을 다시 평가합니다.
