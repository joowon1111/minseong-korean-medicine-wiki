# 기초이론 → 본초·방제·침구 연결
## 본초·방제
`병증 → 치법 → 본초의 효능 → 배합 → 방제`

## 침구
`병증 + 경락 + 국소 기능문제 → 경혈·국소점 → 자침·전침·뜸·부항`

## 생활관리
`병인·악화요인 → 식사·수면·활동·정서 관리`

```text
기초이론
 ↓
임상추론
 ↓
치료목표
 ├─ 본초·방제
 ├─ 침구
 └─ 생활관리
 ↓
경과관찰
```
