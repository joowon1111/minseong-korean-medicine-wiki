# 열다한소탕(熱多寒少湯) 임상 카드

열다한소탕은 태음인 **간수열리열병·간열폐조**의 대표 처방입니다. 이름만 보고 ‘열이 한보다 많은 상태’에 넓게 쓰는 처방이 아니라, 간열이 안에 울체되고 폐의 호산 기능과 진액대사가 영향을 받아 **열·갈증·발한·피부·대변·호흡**의 변화가 하나의 병증 방향을 이루는지를 봅니다.

## 한눈에 보기

| 항목 | 핵심 |
|---|---|
| 체질 | 태음인 |
| 병증 위치 | 간수열리열병, 간열폐조·조열 방향 |
| 병리 축 | 간국의 흡취가 성해 내부 열이 울체되고 폐국의 호산이 약해지며 건조·소모가 나타나는 흐름 |
| 큰 치법 | 청열해기·선폐·조기, 폐조와 진액의 균형 회복 |
| 핵심 단서 | 열감·갈증·다한, 두면부 불편, 피부·대변의 건조, 호흡·수면 변화 |
| 구성 특징 | 갈근 고용량 + 고본·황금 + 길경·나복자·백지·승마 |
| 가까운 비교 | 청폐사간탕·갈근해기탕·청심연자탕·태음조위탕 |

## 병증 위치: 간열에서 폐조로

태음인의 큰 병증 축은 **위완수한표한병**과 **간수열리열병**입니다. 열다한소탕은 오한·무한·몸의 무거움이 중심인 표한 방향보다, 더위를 견디기 어렵고 갈증과 열감이 두드러지며 땀·대변·피부가 열과 건조의 방향으로 변하는 리열병에 놓입니다.

간열폐조를 볼 때에는 다음 연결을 확인합니다.

1. 열감·상열·두면부 불편이 반복됩니다.
2. 갈증과 음수량이 늘고 피부·입안·대변의 건조가 나타납니다.
3. 땀이 많아지거나 땀의 질이 달라지고, 땀 뒤의 개운함과 피로가 변합니다.
4. 폐의 호산이 영향을 받으면서 호흡·기침·가래 또는 전신 소모가 함께 나타납니다.

‘다한’은 양만 세는 것이 아니라 **평소 발한, 현재 발한, 땀 뒤 상쾌함, 야간발한, 활동과의 관계**를 나누어 기록합니다.

## 구성과 용량

| 본초 | 용량 | 처방 안에서 읽는 역할 |
|---|---:|---|
| [갈근](../herbs/pueraria.md) | 15 g | 가장 큰 비중으로 기육·두항의 울체와 리열을 풀어 주는 중심축 |
| 고본 | 7.5 g | 두면·상부와 표리 사이의 울체를 조절 |
| [황금](../herbs/scutellaria.md) | 7.5 g | 간열·폐열과 상부의 열성 증상을 조절 |
| [길경](../herbs/platycodon.md) | 3.75 g | 폐기를 선통하고 인후·가래·호흡을 연결 |
| [나복자](../herbs/raphanus-seed.md) | 3.75 g | 담·식체·복만과 폐기의 하강을 조절 |
| 백지 | 3.75 g | 두면부 울체와 비인후 불편을 풀어 줌 |
| 승마 | 3.75 g | 갈근과 함께 기육·두면의 열을 해기 |

**총량 45 g.** 『동의사상신편』(1929)·한국전통지식포탈 P0018568 수록본 기준입니다. 갈근이 전체의 3분의 1을 차지하고 고본·황금이 각각 6분의 1로 뒤를 받칩니다. 이 비율은 **갈근의 해기축과 황금의 청열축, 길경·나복자의 폐기·담식축**을 함께 보는 근거가 됩니다.

## 진료에서 묶어 보는 단서

| 영역 | 문진과 관찰 |
|---|---|
| 한열 | 상열감, 전신 열감, 더위 민감, 오한 동반 여부, 하루 중 심한 시간 |
| 갈증·음수 | 입마름, 하루 음수량, 찬물 선호, 야간 갈증 |
| 땀 | 평소·현재 발한량, 두면·흉배·전신 분포, 땀 뒤 상쾌함·탈진 |
| 피부 | 건조·가려움·홍반·반창, 손끝·발끝의 변화, 사진과 범위 |
| 대변·복부 | 굳기·횟수·색, 배변 곤란, 복만, 식후 불편 |
| 호흡·인후 | 숨참, 기침·가래, 목마름·인후 불편, 흉민 |
| 수면·심신 | 열감·가려움으로 깨는지, 번조, 꿈, 낮 피로 |
| 소변 | 횟수·양·색, 빈뇨·야간뇨, 갈증과의 동반 변화 |

## 소증을 이용한 감별

2017년 전향적 임상자료를 이용한 의사결정나무 연구는 열다한소탕과 태음조위탕·조위승청탕 처방 결정에서 여러 기관에 공통으로 **평소 대변 형태, 평소·현재 소변 횟수, 평소 불안**이 중요하게 사용되었고, 성별·BMI·혈압도 판단에 관여했다고 보고했습니다. 이는 주증만이 아니라 평소 소증과 객관정보를 함께 기록해야 한다는 점을 보여줍니다. [김상혁·박만영·이시우, 2017](https://www.kci.go.kr/kciportal/landing/article.kci?arti_id=ART002268369)

따라서 열다한소탕을 검토할 때에는 다음을 함께 묻습니다.

- 평소 대변은 굳은가, 무른가, 매일 보는가?
- 소변 횟수와 야간뇨가 발병 전후 어떻게 달라졌는가?
- 땀이 난 뒤 개운한가, 지치는가?
- 최근의 열감과 갈증이 피부·대변 건조와 동시에 심해졌는가?
- 수면·불안·피로가 열증과 함께 변했는가?

## 치료 경과에서 기록할 항목

| 경과지표 | 기록 방법 |
|---|---|
| 열감·갈증 | 0~10점, 심한 시간, 하루 음수량 |
| 발한 | 분포·횟수·의복 교체 여부, 땀 뒤 느낌 |
| 피부 | 건조·홍반·가려움 범위와 사진 |
| 대변 | 횟수, Bristol 형태, 복만·배변곤란 |
| 호흡 | 숨참·기침·가래, 계단 또는 보행 시 변화 |
| 수면·피로 | 총 수면시간, 야간 각성, 아침 피로, 활동량 |
| 질환별 지표 | 이명 NRS·THI, 청력검사, 배뇨일지, 혈당 등 주증에 맞춘 객관지표 |

침·전침·약침을 병행하면 치료 횟수와 부위, 증상척도 측정일, 한약 원방·가감방의 복용기간을 나누어 기록합니다.

## 현대 임상자료

- 2017년 처방 결정요인 연구는 대변·소변·불안 등 소증을 포함한 실제 임상 의사결정 구조를 제시했습니다. [DOI 10.7730/JSCM.2017.29.3.248](https://doi.org/10.7730/JSCM.2017.29.3.248)
- 2021년 삼차신경초종 수술 뒤 돌발성 난청·이명 환자 증례에서는 열다한소탕가미방을 사용하고 청력과 이명 경과를 보고했습니다. [강유정 등, 2021](https://doi.org/10.7730/JSCM.2021.33.4.23)
- 2022년 태음인 당뇨 환자 증례와 2024년 만성신부전·뇌출혈 후 배뇨곤란 증례에서도 열다한소탕가미방의 사용 과정과 혈당·배뇨지표가 보고되었습니다. [문원경 등, 2024](https://doi.org/10.7730/JSCM.2024.36.2.65)
- 열다한소탕과 청심연자탕의 CYP450 활성에 관한 전임상 연구는 병용약을 검토할 때 참고할 약물대사 자료를 제시했습니다. [진성은 등, 2012](https://doi.org/10.7730/JSCM.2012.24.4.84)

서로 다른 질환의 증례는 열다한소탕을 질환명 하나에 고정하기보다, **태음인 간열폐조 진단 근거와 전신 소증, 가감·병행치료, 객관지표**를 함께 살피는 자료로 활용합니다.

## 안전과 함께 확인할 검사

지속되는 고열·의식 변화, 새로 생긴 흉통·호흡곤란, 심한 탈수는 신속히 평가합니다. 갑작스러운 난청·이명은 청력검사와 이비인후과 평가가 중요하며, 다뇨·심한 갈증·체중감소는 혈당과 신장기능을 함께 확인합니다.

복용 중에는 대변·식욕·수면·심계와 혈압 변화를 살피고, 간·신장질환과 다약제 복용 시에는 현재 약물 목록과 검사치를 바탕으로 처방과 가감을 조정합니다.
