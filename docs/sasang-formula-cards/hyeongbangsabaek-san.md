# 형방사백산(荊防瀉白散) 임상 카드

형방사백산은 **소양인 비수한표한병의 신열두통망음증**을 중심으로 살피는 대표 처방입니다. 몸의 열감과 두통이 두드러지더라도 한 증상에 고정하지 않고, 표음이 내려가지 못하는 병리와 함께 번조·갈증·대소변·흉격·소화·수면의 변화가 어떤 순서로 나타났는지를 종합합니다.

## 한눈에 보기

| 항목 | 핵심 |
|---|---|
| 체질 | 소양인 |
| 병증 위치 | 비수한표한병, 신열두통망음증 |
| 병리 축 | 표음의 하강이 원활하지 않고 표부의 울체와 내열·수분대사 변화가 함께 나타나는 흐름 |
| 큰 치법 | 표음의 순환을 돕고 울체된 열을 풀며 대소변의 통로를 조정 |
| 핵심 단서 | 신열·두통·번조, 구갈, 소변·대변 변화, 흉격 불편, 소화·수면의 동반 변화 |
| 구성 특징 | 생지황·복령·택사 + 석고·지모 + 강활·독활·형개·방풍 |
| 가까운 비교 | 형방도적산·형방지황탕·저령차전자탕·활석고삼탕·양격산화탕 |

## 병증 위치: 표병인데 왜 열감이 나타나는가

소양인 비수한표한병은 병명에 ‘한’이 들어가지만 모든 환자가 차갑게만 느끼는 것은 아닙니다. 표음이 원활히 내려가지 못하면 표부에 울체가 생기고, 병이 진행하면서 **몸의 열감·두통·번조와 대소변 변화**가 함께 나타날 수 있습니다. 형방사백산은 이 가운데 신열두통이 뚜렷하고 망음의 방향이 시작되는 병증을 살핍니다.

임상에서는 다음 순서를 구분합니다.

| 단계 | 살피는 변화 | 가까운 처방군 |
|---|---|---|
| 표병의 한열·두면·흉격 불편 | 두통, 한열왕래, 흉격 답답함, 배설 변화 | 형방도적산 |
| 신열두통과 번조·갈증, 배설 변화 | 몸의 열감, 두통, 구갈, 소변·대변 변화 | **형방사백산** |
| 복통·설사와 진액 손상·기력 저하 | 신한, 복통, 설사, 갈증, 쇠약 | 형방지황탕·활석고삼탕 등 |

이 표는 시간에 따라 반드시 한 방향으로만 진행한다는 뜻이 아니라, 현재 병증의 위치와 중증도를 읽기 위한 비교틀입니다.

## 구성과 용량

| 본초 | 용량 | 배합에서의 역할 |
|---|---:|---|
| 생지황 | 11.25 g | 진액을 보완하며 혈분의 열과 번열을 조절하는 중심축 |
| [복령](../herbs/poria.md) | 7.5 g | 비위와 수분대사를 조화하고 소변 변화를 받침 |
| [택사](../herbs/alisma.md) | 7.5 g | 하초의 수분대사와 배설 통로를 조정 |
| 석고 | 3.75 g | 신열·번열·구갈의 열성 축을 조절 |
| 지모 | 3.75 g | 석고와 함께 열·진액의 균형을 보완 |
| 강활 | 3.75 g | 두항·상부와 표부의 울체를 풀어 줌 |
| [독활](../herbs/angelica-pubescens.md) | 3.75 g | 신체통·근골과 표부의 순환을 연결 |
| 형개 | 3.75 g | 표부의 울체와 두면부 증상을 조절 |
| [방풍](../herbs/saposhnikovia.md) | 3.75 g | 표부 순환과 형개·강활·독활 축을 보완 |

**총량 48.75 g.** 생지황이 가장 크고 복령·택사가 그다음 비중을 차지하여 **진액·열·수분대사**가 중심축을 이룹니다. 여기에 석고·지모의 청열축과 강활·독활·형개·방풍의 해표축이 결합됩니다. 고전 용량은 처방의 비율과 구조를 이해하기 위한 자료이며, 실제 탕약·제제의 규격과 가감은 진료기록에서 따로 확인합니다.

## 진료에서 확인하는 증상 묶음

| 영역 | 핵심 문진 |
|---|---|
| 두통·신체 | 머리의 부위와 강도, 몸의 열감, 오한, 목·어깨·관절통 |
| 흉격·호흡 | 가슴 답답함, 숨의 불편, 목의 건조·이물감 |
| 갈증·땀 | 물을 찾는 정도, 선호 온도, 땀의 양과 땀 뒤 느낌 |
| 대변 | 평소 형태와 현재 변화, 횟수, 복통·설사의 동반 여부 |
| 소변 | 횟수·양·색, 배뇨 뒤 개운함, 야간뇨 |
| 소화 | 식욕, 식후 더부룩함, 구역, 복부 불편 |
| 수면·번조 | 잠들기, 중간 각성, 열감 때문에 깨는지, 초조·불편감 |

‘신열두통’은 체온과 두통만을 뜻하기보다 **전신 열감·두면부 불편·배설·갈증·번조가 연결된 병증 표지**로 봅니다. 평소의 대변·소변·소화가 어떻게 달라졌는지를 확인해야 망음의 깊이와 가까운 처방을 구분할 수 있습니다.

## 가까운 처방과 감별

| 처방 | 공통점 | 갈림점 |
|---|---|---|
| [형방도적산](hyeongbangdojeok-san.md) | 강활·독활·형개·방풍을 공유하는 표병 처방 | 흉격·한열·두면부와 배설 변화가 중심인지, 생지황·복령·택사·석고·지모가 필요한 신열두통망음 방향인지 비교 |
| [형방지황탕](hyeongbangjihwang-tang.md) | 표병·망음과 형방계 약물을 공유 | 복통·설사·진액 손상·기력 저하가 전면에 있는지 확인. 생지황·석고·지모 대신 숙지황·산수유·차전자 축 |
| 저령차전자탕 | 망음과 수분대사·배설 변화를 함께 봄 | 설사·소변 변화와 습열의 비중, 두통·신열의 강도를 비교 |
| [활석고삼탕](../sasang-formula-library/soyangin-extended-formulas.md#soyang-hwalseokgosam) | 망음에서 열·수분대사를 다룸 | 복통·설사와 습열 양상이 더 뚜렷한지 확인 |
| [양격산화탕](yanggyeoksanhwa-tang.md) | 열감·번조·구갈을 함께 볼 수 있음 | 비수한표한병이 아니라 위수열리열병의 흉격열이 중심인지 구분 |

## 진료 흐름과 경과지표

`응급성 두통·탈수 확인 → 소양인 소증 확인 → 표병·리병 구분 → 신열두통과 대소변·갈증의 조합 확인 → 망음의 깊이 감별 → 치료 → 같은 지표로 재평가`

| 경과 영역 | 시작할 때 | 재진에서 확인 |
|---|---|---|
| 두통·열감 | 0~10점, 지속시간, 진통제 사용, 체온 | 강도·빈도·지속시간과 일상 복귀 |
| 대변 | 횟수, Bristol 형태, 복통·급박감 | 평소 배변 리듬으로 회복되는지 |
| 소변 | 횟수·양·색·야간뇨 | 갈증·부종과 함께 안정되는지 |
| 갈증·수분 | 하루 음수량, 입마름, 선호 온도 | 음수량과 구강건조 변화 |
| 수면·번조 | 잠들기·각성·총 수면시간 | 야간 열감과 각성 감소 |
| 전신 상태 | 식사량, 체중, 피로, 활동량 | 소화·기력·활동의 동반 회복 |

침·전침·약침·뜸을 함께 시행한 경우에는 치료 부위와 횟수, 한약의 원방·가감, 각 시점의 증상척도를 나누어 적으면 어떤 치료 구간에서 변화가 나타났는지 파악하기 좋습니다.

## 현대 임상자료

- 망음 처방 비교 연구는 형방사백산·저령차전자탕·형방지황탕·활석고삼탕의 구성과 병증 위치를 비교하여, 형방사백산을 신열두통과 내열·수분대사 변화가 함께 나타나는 단계로 설명했습니다. [Lee 등, 2011](https://journal.kci.go.kr/JSCIM/archive/articleView?artiId=ART001538465)
- 하지불안증, 국소다한증, 청각과민 등에 대한 증례에서는 주증뿐 아니라 수면·땀·대변·소변 같은 소증 변화를 함께 기록했습니다.
- 2025년 전신성 접촉피부염 2례에서는 피부 범위와 소양감, 체질병증 판단, 한약과 병행치료의 경과가 보고되었습니다. [Park 등, 2025](https://journal.kci.go.kr/JSCIM/archive/articleView?artiId=ART003228443)

임상자료는 **질환명–처방의 단순 대응표**보다, 체질진단·병증진단·소증·현증·치료구성·평가척도를 연결해 읽을 때 활용도가 높습니다.

## 안전과 진료 우선 상황

갑작스러운 극심한 두통, 의식 변화, 편측 마비, 고열과 목 경직은 신경계·감염성 원인을 신속히 평가합니다. 심한 설사와 소변 감소, 기립성 어지럼, 지속 구토는 수분·전해질 상태를 함께 확인합니다. 빠르게 번지는 수포성 발진, 입술·혀의 부종, 호흡곤란은 즉시 응급평가가 필요한 증상입니다.
