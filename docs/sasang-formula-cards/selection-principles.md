# 사상처방 선택 원칙
## 8단계 임상 흐름

| 단계 | 확인할 질문 |
|---|---|
| 1. 체질 진단 | 체형·용모만이 아니라 성정, 소증, 병력과 치료 반응이 일관되는가? |
| 2. 평소 소증 | 식욕·소화, 대변·소변, 땀, 수면, 한열, 갈증, 피로의 평소 기준은 무엇인가? |
| 3. 현재 주증 | 언제 시작했고 무엇이 악화·완화하며 어떤 동반증상이 있는가? |
| 4. 표병·리병 | 병증의 중심이 표와 리 가운데 어디에 놓이는가? |
| 5. 순증·역증 | 체질의 보명지주가 유지되는지, 소증이 무너지는 방향인지 살핍니다. |
| 6. 중증도 | 섭취·배설·수면·활동 저하와 위험신호가 어느 정도인가? |
| 7. 치법 | 보명지주를 돕고 현재 병리 방향을 바로잡는 치료 원칙은 무엇인가? |
| 8. 처방·재평가 | 처방 후 주증뿐 아니라 소증과 전신 회복 방향이 함께 좋아지는가? |

잘못된 단순화: `태음인+비만=태음조위탕`, `소양인+열=양격산화탕`, `소음인+설사=곽향정기산`.

올바른 구조는 **체질 + 소증 + 현재 체질병증 → 중증도·치법 → 처방**입니다.

## 처방 전 감별 체크

- 체질 진단이 불확실하면 처방명부터 정하지 않습니다.
- 같은 설사라도 한열, 갈증, 복통, 소변, 발한, 전신 기력의 조합을 구분합니다.
- 같은 열감이라도 표리의 위치, 진액 손상, 대변과 흉격 증상을 함께 봅니다.
- 기존 복용약, 임신·수유, 간·신장질환, 고혈압·부정맥과 약재 안전성을 확인합니다.
- 급격한 의식 변화, 심한 탈수, 호흡곤란, 흉통, 지속되는 출혈 등은 우선 의학적 평가가 필요합니다.

## 경과관찰의 네 가지 판단

| 판단 | 관찰 방향 |
|---|---|
| 유지 | 주증과 소증이 함께 안정적으로 호전 |
| 가감·조정 | 일부만 호전하거나 새로운 불편이 생김 |
| 재변증 | 표리·한열·순역 또는 병증 단계가 달라짐 |
| 중단·의뢰 | 이상반응, 위험신호 또는 예상과 다른 급격한 악화 |
