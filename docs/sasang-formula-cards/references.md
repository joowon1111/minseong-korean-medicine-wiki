# 사상처방 임상 카드 근거·참고문헌

대표 카드 18종은 다음 순서로 근거를 읽습니다.

1. **원전·공공 DB:** 체질, 병증, 원방 구성과 출전 확인
2. **임상진료지침:** 표리·순역·중증도 및 권고 맥락 확인
3. **현대 연구:** 대상 체질·병증, 가감 여부, 병행치료, 평가도구와 연구설계 확인
4. **증례:** 새로운 적용 가능성을 탐색하되 확정적 효과로 일반화하지 않음

## 공통 기준 자료

1. 『동의수세보원』 및 『동의사상신편』의 체질병증·처방 기록.
2. 국가한의임상정보포털(NCKM). *사상체질병증 한의표준임상진료지침*. 2022.
3. 한국전통지식포탈 처방 DB: 출전별 구성·용량·조제법 확인.
4. 한국민족문화대백과사전 사상처방 항목: 처방 연혁과 구성 교차확인.
5. *A Report on the Collecting Status of the Prospective Clinical Data Included the Constitutional Prescription.* Journal of Sasang Constitution and Immune Medicine.

## 해석할 때 주의할 점

- 사상처방 연구는 증례·후향자료 비중이 높아 무작위시험과 같은 수준으로 표현하지 않습니다.
- 가감방, 침치료, 생활관리 등이 병행된 경우 처방 단독 효과로 귀속하지 않습니다.
- 현대 질환명과 전통 체질병증은 일대일 대응하지 않습니다.
- 원방의 구성·용량과 연구에서 사용한 제형이 다르면 별도로 기록합니다.
