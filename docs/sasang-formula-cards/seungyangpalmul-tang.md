# 승양팔물탕(升陽八物湯) 임상 카드

승양팔물탕은 소음인 표병이 이어지며 땀 뒤 기력이 떨어지고 양난지기의 회복이 필요한 **망양초증·승양** 방향에서 살피는 대표 처방입니다. 발열이나 발한 하나만 보지 않고 오한, 기력, 식욕·소화, 손발 냉감과 평소 소증을 함께 봅니다.

| 항목 | 핵심 |
|---|---|
| 체질 | 소음인 |
| 병증 위치 | 신수열표열병·망양초증, 승양 회복 방향 |
| 핵심 단서 | 땀 뒤 탈진, 오한·신체통, 회복 지연, 식욕·기력 저하 |
| 가까운 비교 | 승양익기탕·인삼계지부자탕·황기계지탕 |

## 구성·용량

| 본초 | 용량 |
|---|---:|
| 인삼·황기 | 각 7.5 g |
| 관계·당귀·백작약·백출·자감초 | 각 3.75 g |
| 대조 | 2매 |
| 생강 | 3조각 |

『동의사상신편』(1929), 한국전통지식포탈 P0018143 수록본 기준입니다. 인삼·황기로 기운을 보하고 관계로 온양하며, 당귀·백작약으로 영혈을 돕고 백출·감초·생강·대조로 비위와 조화를 받치는 배합으로 읽습니다.

## 가까운 처방과 감별

- [인삼계지부자탕](insamgyejibujatang.md): 발한·냉감·쇠약이 더 깊고 부자가 필요한 망양 심화 방향인지 비교합니다.
- [백하오이중탕](baekhao-ijung-tang.md): 표병의 발한보다 복통·설사·식욕저하의 리한이 중심인지 봅니다.
- [곽향정기산](gwakhyangjeonggi-san.md): 오심·구토·심하비만과 한습·담습의 비중을 비교합니다.

## 경과관찰과 안전

땀의 양보다 땀 뒤 기력, 오한·신체통, 체온, 식욕·소화, 손발 온도, 수면과 일상활동이 회복되는지 기록합니다. 고열 지속, 의식 변화, 호흡곤란, 저혈압·실신, 심한 탈수는 즉시 의학적 평가가 우선입니다.

## 병증을 단계로 읽기

승양팔물탕은 ‘기운이 없다’는 일반적인 허약 처방이 아니라 **소음인 신수열표열병의 망양초증**이라는 위치에서 읽습니다.

1. 오한·두통·신체통 같은 표병이 있었는지 확인합니다.
2. 땀이 난 뒤 증상이 풀리기보다 기력이 더 떨어졌는지 봅니다.
3. 식욕·소화·손발 냉감과 활동 회복이 함께 나빠졌는지 확인합니다.
4. 지속 자한·심한 냉감·저혈압처럼 더 깊은 망양이면 부자 배합 처방군과 구분합니다.

## 배합을 기능축으로 보기

| 배합축 | 구성 | 읽는 포인트 |
|---|---|---|
| 보기·승양 | 인삼·황기 | 발한 뒤 기력과 활동 회복 |
| 온양 | 관계 | 냉감·오한과 회복 저하 |
| 영혈 | 당귀·백작약 | 발한 뒤 소모·근육 긴장·회복 |
| 비위 조화 | 백출·감초·생강·대조 | 식욕·소화와 전신 회복 |

인삼·황기가 상대적으로 크게 배치된 것은 망양초증에서 **승양과 기력 회복**을 중심으로 읽게 하는 구조적 단서입니다. 관계가 들어가지만 부자가 포함된 더 깊은 망양 처방과는 중증도가 다릅니다.

## 승양익기탕·부자계와 비교

| 비교 처방 | 승양팔물탕과 가르는 단서 |
|---|---|
| 승양익기탕 | 망양초증의 승양·보기라는 큰 방향은 같지만 실제 구성과 출전의 차이를 확인 |
| 인삼계지부자탕 | 냉감·쇠약과 양기 손상이 더 깊고 부자 안전성 판단이 필요 |
| 계지부자탕 | 지속 자한·사지 구급과 발한 뒤 허탈이 더 전면 |
| 관계부자이중탕 | 표병 발한보다 복통·설사·리한이 중심 |

## 재진에서 확인할 항목

- 땀 뒤 기력이 회복되는지
- 오한·신체통과 손발 냉감이 줄어드는지
- 한 끼 섭취량과 식후 편안함이 회복되는지
- 기립 어지럼·보행·업무 가능 범위가 좋아지는지
- 수면 뒤 회복감이 좋아지는지

표증만 줄고 식욕·냉감·기력이 계속 나빠지거나, 새 설사·구토가 생기면 망양의 깊이와 리병 전환 여부를 다시 평가합니다.

## 학습 포인트

승양팔물탕은 **울광에서 망양으로 넘어가는 소음인 표병의 중증도**를 이해하는 데 좋은 기준점입니다. ‘보약’이라는 범주보다 발한 전후의 변화와 양난지기 회복이라는 병증 맥락을 먼저 기억합니다.
