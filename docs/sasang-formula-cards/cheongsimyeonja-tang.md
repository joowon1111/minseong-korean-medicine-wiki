# 청심연자탕
## 언제 고려하는가?
태음인의 **간수열리열병 → 간열폐조병 → 조열병우증**과 연결되는 대표 처방입니다.

`태음인 → 리병 → 간열폐조병 → 조열병우증 → 청심연자탕`

## 특히 보는 변화
열·번조·건조·피로·현훈과 소화·대변·수면·발한 변화를 종합합니다. 전향적 체질처방 자료에서는 **피로와 현훈**이 주요 주증으로 보고됐습니다.

## 비슷한 처방
- 열다한소탕·청폐사간탕: 조열병증 단계.
- 청심연자탕: 조열병우증.
- 공진흑원단: 음혈모갈열다증의 위증 방향.
- 태음조위탕: 표한 계열.

## 회복 신호
열감·번조·건조와 피로·현훈이 안정되고 수면·소화·발한이 회복되는지 봅니다.

## 현대 임상 보고
2021년 태음인 위식도역류질환 환자에서 청심연자탕과 침 치료 후 증상 개선을 보고한 증례가 있습니다. 단일 증례이므로 일반적 질환 효과와는 구분합니다.
