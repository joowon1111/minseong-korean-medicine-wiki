# 인삼계지부자탕(人蔘桂枝附子湯) 임상 카드

인삼계지부자탕은 소음인 **망양증**에서 발한과 함께 기력이 크게 떨어지고 오한·사지 냉감·전신 쇠약이 두드러지는 방향을 살피는 처방입니다. 망양은 단순한 피로나 식은땀과 같은 말이 아니라 소음인 표병의 역증 구조를 뜻합니다.

## 한눈에 보기

| 항목 | 핵심 |
|---|---|
| 체질 | 소음인 |
| 병증 위치 | 신수열표열병의 망양증 |
| 핵심 단서 | 발한 뒤 탈진, 오한·냉감, 전신 쇠약, 회복력 저하 |
| 가까운 비교 | 승양팔물탕·인삼관계부자탕·관계부자이중탕 |

## 구성·용량

| 본초 | 용량 |
|---|---:|
| 인삼 | 15 g |
| 계지 | 11.25 g |
| 백작약·황기 | 각 7.5 g |
| 당귀·자감초 | 각 3.75 g |
| 포부자 | 3.75–7.5 g |
| 대조 | 2매 |
| 생강 | 3조각 |

『동의사상신편』(1929) 계통의 구성입니다. 한국전통지식포탈 P0018129 화면은 8개 약재만 표시해 포부자가 누락되어 있지만, [한국민족문화대백과사전의 인삼계지부자탕](https://encykorea.aks.ac.kr/Article/E0046919)과 『동의수세보원』 계통 자료에는 포부자 3.75–7.5 g이 수록됩니다. 출전별 데이터 차이를 표시해 두고 실제 제형은 처방전과 조제기록으로 확인합니다.

### 인삼·계지의 비중과 계지탕 골격 {#ginseng-guizhi-source-structure}

위 구성은 인삼을 가장 크게 놓고 계지가 뒤를 받치며, 작약·감초·생강·대조의 계지탕 계열 골격에 황기·당귀·포부자를 배치합니다. 계지탕에 부자만 더한 처방이나 모든 허한을 포괄하는 이중탕 가미방으로 요약하기 어렵습니다. 발한과 기력의 소모를 함께 다루는 **소음인 표병의 망양 문맥**을 유지합니다.

| 비교축 | 확인할 구성·기록 |
|---|---|
| 계지탕과의 관계 | 계지·작약·감초·강·조의 공통 약미와 달라진 상대량 |
| 기력·영혈 | 인삼·황기·당귀의 추가와 비중 |
| 부자 | 포제품·조제량·출전별 포함 여부 |
| 표병·리병 | 발한 뒤 쇠약인지, 복통·설사와 깊은 리한인지 |

공개 DB에서 포부자가 빠져 있는 문제는 처방명·원전 계통 자료와 목록을 대조해 확인합니다. 이 문서의 포부자 범위는 역사적 수록량의 설명이며, DB 누락을 근거로 부자 없는 원방을 만들거나 다른 처방의 부자량을 가져오지 않습니다. 생강 3조각·대조 2매는 개수 기록이므로 g 표시 약미와 단순 합산하지 않습니다.

망양의 중증도는 체질병증의 경과와 현대의 순환·수분 상태를 함께 살피는 문제입니다. 저혈압·실신을 처방 선택의 자동 기준으로 쓰지 않고 원인을 신속히 평가합니다. 회복은 발한량 감소뿐 아니라 식사·기립·보행·체온·의식과 땀 뒤 기력이 함께 안정되는지 확인합니다.

## 감별의 중심

- [승양팔물탕](seungyangpalmul-tang.md#source-layers): 후대 태양양명 수록형의 구성과 구별하며, 망양의 경중을 두 처방의 단순 순서로 배열하지 않습니다.
- [관계부자이중탕](gwangye-buja-ijung-tang.md): 표병의 발한보다 지속 설사·복통·식욕저하의 깊은 리한이 중심인지 봅니다.
- 인삼관계부자탕: 망양의 중증도, 냉감과 전신 기능 저하, 출전별 구성을 비교합니다.

## 경과관찰과 안전

발한량, 땀 뒤 기력, 오한, 체온, 맥박·혈압, 손발 온도, 식욕·소화, 보행·일상활동을 함께 봅니다. 의식 변화·실신·흉통·호흡곤란·지속 고열은 즉시 진료가 우선입니다. 부자 함유 제제는 자가 조제하거나 임의 증량하지 않습니다.

## 망양의 깊이를 판단하는 기준

인삼계지부자탕은 **냉감·전신 쇠약과 양기 손상이 깊어진 망양**을 비교할 때 읽습니다. 승양팔물탕과는 주치·출전이 다르므로 같은 단계표의 전후 처방으로 고정하지 않습니다. 발한량 자체보다 발한 뒤 순환·기립·식사·활동이 얼마나 무너졌는지가 중요합니다.

| 관찰축 | 기록할 변화 | 판단에서의 의미 |
|---|---|---|
| 발한 뒤 상태 | 발한량·빈도와 땀 뒤 피로·오한 | 양만 줄었는지 전신 상태도 회복되는지 |
| 냉감·활동 | 손발 온도, 기립·보행의 제한 | 체감 냉감과 실제 기능 저하를 함께 확인 |
| 식사 | 섭취량·구역·설사·수분 섭취 | 소모와 표병·리병 감별에 필요한 정보 |
| 순환·의식 | 혈압·맥박·실신·의식 변화 | 원인 평가와 치료 우선순위를 결정할 정보 |

이 표는 관찰 항목이며 망양을 확진하거나 특정 처방을 자동 선택하는 점수표가 아닙니다.

## 배합 구조

인삼·황기가 기력 회복을 받치고, 계지·백작약·감초가 표병의 영위와 발한 뒤 균형을 조절하며, 포부자가 깊어진 냉감·양기 손상의 회복축을 형성합니다. 당귀는 소모된 영혈을 받치는 방향으로 읽습니다.

## 부자계 처방을 서로 구분하기

- **인삼계지부자탕:** 망양 표병, 발한 뒤 탈진·냉감·쇠약이 중심.
- **계지부자탕:** 지속 자한과 사지 구급·굴신 불편이 더 전면.
- **관계부자이중탕:** 복통·설사·식욕저하의 깊은 리한이 중심.
- **오수유부자이중탕:** 장궐·격양, 구토·설사·사지궐냉이 더 깊은 리병.

부자가 공통으로 들어간다고 같은 병증이 아닙니다. **표병의 발한이 중심인지, 리병의 복통·설사가 중심인지**가 첫 갈림점입니다.

## 안전 확인 체크리스트

- 포제된 부자인지, 원방과 실제 조제량이 일치하는지
- 심혈관질환·부정맥·신장질환·간질환 여부
- 이뇨제·항부정맥제·교감신경계 약물 등 병용약
- 복용 뒤 입술·혀·사지 저림, 심계, 어지럼, 오심·구토
- 혈압·심박수와 기립 증상의 변화

## 경과평가

발한이 줄었다는 한 항목보다 **땀 뒤 기력, 냉감, 식사량, 기립·보행, 수면과 일상활동**이 함께 회복되는지 봅니다. 저혈압·실신·의식 변화·흉통·호흡곤란이 있으면 처방 반응을 기다리지 않습니다.

역사적 경과는 [소음인 열한 살 아이의 발한과 회복](../classical-stories/sasang/soeumin-sweating-case.md)에서 읽습니다. 『동의수세보원』 6-32는 땀과 대소변, 죽을 먹는 양과 스스로 앉고 걷는 변화를 함께 기록했습니다. 그 의안의 가감·투여와 위 표의 『동의사상신편』 계통 구성을 같은 조제 기록으로 합치지 않습니다.
