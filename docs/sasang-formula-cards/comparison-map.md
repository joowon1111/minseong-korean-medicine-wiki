# 사상체질 대표처방 18종 비교 지도

## 공통 재평가 원칙

- 주증뿐 아니라 식욕·소화, 대변·소변, 땀, 수면, 한열, 갈증, 피로가 같은 방향으로 회복되는지 봅니다.
- 호전 방향이 서로 어긋나거나 새로운 증상이 생기면 단순 가감보다 체질병증과 중증도를 다시 평가합니다.
- 급성 신경학적 증상, 호흡곤란·흉통, 의식 변화, 심한 탈수·출혈, 진행성 연하곤란은 체질 감별보다 필요한 의학적 평가가 우선입니다.
