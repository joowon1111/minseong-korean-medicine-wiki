# 사상체질 대표처방 임상카드 27종

흩어져 있던 대표 처방 문서를 이곳으로 통합했습니다. 기존 대표 카드 18종에 병증 감별이 필요한 확장 처방 9종을 더해, 현재 **태음인 9종·소양인 8종·소음인 8종·태양인 2종, 총 27종**을 임상적으로 비교할 수 있습니다.

> 체질명이나 질환명만으로 처방을 고르지 않습니다. **체질 → 평소 소증 → 현재 체질병증 → 표리·순역·중증도 → 처방 → 치료 반응**의 순서로 읽습니다.
