# 사상처방 상세 임상 카드
처방을 **언제 고려하는가 → 핵심 병증 → 증상 변화 → 비슷한 처방과 차이 → 회복 신호 → 현대 연구** 순서로 정리한 대표 임상 허브입니다.

> 사상처방은 체질명이나 증상 하나만으로 선택하지 않고, 체질 → 소증 → 현재 체질병증 → 표리·순역·중증도 → 치법의 흐름 안에서 이해합니다.

## 카드 활용 순서

1. [처방 선택 원칙](selection-principles.md)에서 체질·소증·현재 병증을 먼저 정리합니다.
2. [대표 6종 비교](comparison-map.md)와 [주요 15종 연결 지도](../sasang-formula-cards-2/full-map.md)에서 가까운 처방군을 좁힙니다.
3. 개별 카드에서 원문 병증, 구성, 감별점과 경과관찰 항목을 확인합니다.
4. 더 많은 처방은 [사상처방 전체 색인](../sasang-formula-library/index.md)에서 체질과 병증군별로 찾습니다.

## 처방 전후에 함께 볼 항목

사상처방의 적합성은 한 가지 증상의 호전만으로 판단하지 않습니다. 평소와 비교한 **식욕·소화, 대변·소변, 땀, 수면, 한열, 갈증, 피로·회복, 정서**의 방향과 현재 주증의 변화를 함께 기록하면 재평가가 쉬워집니다.

> 이 자료는 처방을 임의로 선택하기 위한 자가진단표가 아닙니다. 사상체질 진단과 병증 판단, 약재의 용량·가감은 한의사의 진료를 전제로 합니다.
