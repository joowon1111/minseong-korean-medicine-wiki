# 사상처방 상세 임상 카드
처방을 **언제 고려하는가 → 핵심 병증 → 증상 변화 → 비슷한 처방과 차이 → 회복 신호 → 현대 연구** 순서로 정리합니다.

> 사상처방은 체질명이나 증상 하나만으로 선택하지 않고, 체질 → 소증 → 현재 체질병증 → 표리·순역·중증도 → 치법의 흐름 안에서 이해합니다.
