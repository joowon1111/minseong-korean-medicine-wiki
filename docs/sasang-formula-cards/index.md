# 사상체질별 한약처방

사상처방은 체질 이름이나 현대 질환명 하나로 정하지 않습니다. 먼저 평소 건강할 때의 소화·대변·소변·땀·수면·한열과 활동 상태를 확인하고, 현재의 체질병증과 표리·순역·경중을 가른 뒤 처방을 비교합니다.

`체질 → 평소 소증 → 병리 변화 → 현재 병증 → 표리·한열·순역·경중 → 치법 → 처방 → 치료 반응과 재평가`

아래 처방명은 적용 병증, 구성·법제, 가까운 처방과의 감별, 복용 뒤 관찰 항목, 안전과 근거 한계를 확인하는 상세 문서로 연결됩니다.

## 처방표를 읽는 순서

| 확인 단계 | 핵심 질문 |
|---|---|
| 소증 기준선 | 평소 소화·배변·배뇨·땀·수면과 체력은 어떠했는가? |
| 현재 병증 | 평소와 달라진 증상이 어느 체질병증의 표리·한열 방향에 놓이는가? |
| 순역·경중 | 회복 가능한 순증인가, 소모·탈진·배설 장애가 깊어진 역증인가? |
| 처방 감별 | 주증이 비슷한 처방 가운데 구성과 병증 단계가 가장 맞는 것은 무엇인가? |
| 경과관찰 | 주증뿐 아니라 소증과 섭취·수면·활동이 같은 방향으로 회복되는가? |

## 태양인 한약처방 {#taeyangin-formulas}

태양인은 현존 문헌의 병증·처방 자료가 다른 체질보다 제한적입니다. 숫자를 맞추려고 다른 체질 처방이나 확인되지 않은 효능을 덧붙이지 않고, 외감요척병의 해역과 내촉소장병의 열격을 중심으로 읽습니다.

| 병증 단계 | 처방 | 핵심 증후 | 감별·경과관찰 |
|---|---|---|---|

| 내촉소장병·열격 | [미후등식장탕](mihudeung-sikjang-tang.md) | 연하불편·구역·구토·섭취 저하 | 위·식도 원인과 탈수·체중감소를 우선 평가 |

## 처방 뒤 재평가

| 판단 | 관찰되는 변화 | 다음 검토 |
|---|---|---|
| 같은 방향으로 회복 | 주증과 소화·배설·수면·활동이 함께 개선 | 목표를 유지하며 용량·기간과 이상반응 기록 |
| 일부 증상만 호전 | 통증·열감만 줄고 소증과 기능은 그대로 | 병증 위치·치법·동반치료의 역할 재검토 |
| 반대 방향의 변화 | 새 설사·변비, 냉감·열감, 불면·탈진 발생 | 처방 구성·용량·포제·병용약과 표리·순역 재평가 |
| 전신상태 악화 | 섭취·소변 감소, 의식·호흡·보행 저하, 출혈·심한 탈수 | 복용 지속 여부를 즉시 판단하고 필요한 검사·처치 우선 |

원전과 후대 처방집의 수록은 전통적 사용 맥락과 조성의 근거입니다. 현대 임상진료지침, 임상연구와 같은 수준의 치료효과 근거를 뜻하지 않으며 현대 질환명과 체질병증을 일대일로 대응하지 않습니다.
