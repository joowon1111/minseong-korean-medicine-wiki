# 미후등식장탕(獼猴藤植腸湯)

미후등식장탕은 태양인 **내촉소장병의 열격증**에서 음식물을 받아들이고 내려 보내는 기능이 막혀 연하·섭취·구토 문제가 나타나는 방향을 살피는 처방입니다. 연하곤란과 반복 구토에는 응급·기질적 원인이 있을 수 있으므로 체질병증 감별과 현대의학적 평가를 함께 진행합니다.

## 한눈에 보기

| 항목 | 핵심 |
|---|---|
| 체질 | 태양인 |
| 병증 위치 | 내촉소장병·열격증 |
| 핵심 단서 | 삼킴 불편, 음식이 내려가지 않는 느낌, 구역·구토, 섭취량 감소 |
| 순역·경중 | 물과 음식의 통과, 구토 빈도, 체중·수분·소변·기력 저하로 판단 |
| 회복 지표 | 물·고형식 섭취량, 구토, 체중, 소변량, 기립·활동 |
| 가까운 비교 | 오가피장척탕의 외감요척병·해역증 |

## 원방 구성과 명칭 확인

『동의사상신편』 수록본의 처방명은 **미후등(獼猴藤)식장탕**이지만 구성의 첫 약재는 **미후도(獼猴桃)**로 적혀 있습니다. 처방명만 보고 덩굴 부위를 사용한다고 추정하지 않습니다.

| 본초 | 용량·표기 | 배합에서 읽는 역할 |
|---|---:|---|
| [미후도·미후등](../herbs/mihudeung.md) | 16 g | 처방의 중심축. 사용 판본과 실제 원료의 기원·부위를 반드시 기록 |
| 모과·포도근 | 각 8 g | 근육·기역과 수분 이동을 조화 |
| 노근·앵도·[오가피](../herbs/acanthopanax-bark.md)·송화 | 각 4 g | 진액·상역·근골·회복을 보조 |
| 저두강 | 반 숟가락 | 원방의 곡물성 보조재 표기를 보존 |

중량으로 적힌 일곱 약재의 합은 48 g이며, 저두강은 별도의 개별 계량입니다. 판본·원료 동정이 명확하지 않으면 처방명만으로 조제하지 않습니다.

## 소증에서 병증까지 확인하는 흐름

`태양인 진단 → 평소 섭취·소변 소증 → 내촉소장병 → 열격의 경중 → 미후등식장탕 → 섭취·체중·기력 재평가`

| 확인축 | 초진 질문·평가 |
|---|---|
| 연하 | 고형식과 물 중 어느 쪽부터 어려운지, 걸리는 위치, 사레·기침 |
| 구토 | 식후까지 걸리는 시간, 횟수·양, 담즙·혈액, 복통·복만 |
| 영양·수분 | 하루 섭취량, 체중 감소 속도, 소변량, 어지럼·탈수 |
| 평소 소증 | 평소 소변이 시원한지, 섭취와 소화, 하체 힘·보행 |
| 검사 | 필요 시 내시경·영상·연하검사, 전해질·신장기능·영양 지표 |

## 가까운 병증·처방과 감별

| 비교 | 미후등식장탕 쪽 단서 | 다른 쪽 단서 |
|---|---|---|
| [오가피장척탕](ogapi-jangcheok-tang.md) | 연하·섭취·구토와 체중·기력 저하가 중심 | 요척·하지무력과 보행 기능 저하가 중심인 해역 |
| 구조적 연하장애 | 검사와 응급평가를 병행하면서 병증을 판단 | 점차 심해지는 고형식 연하곤란, 체중감소, 흉통·출혈은 구조적 원인 배제 우선 |
| 신경성 연하장애 | 사레·기침과 전신 소증을 함께 기록 | 뇌졸중·신경근육질환 징후가 있으면 연하 안전과 재활 평가 우선 |

전통의 열격은 식도암, 역류성 식도염, 기능성 소화불량, 신경성 구토 중 어느 하나와 같은 개념이 아닙니다.

## 경과관찰

| 목표 | 시작할 때 기록 | 재진에서 판단 |
|---|---|---|
| 연하 | 물·죽·고형식 단계, 사레·기침 | 안전하게 가능한 음식 단계와 흡인 징후 |
| 섭취 | 한 끼와 하루 섭취량 | 섭취량 증가와 불편 없는 유지 |
| 구토 | 하루 횟수·양·식후 시간 | 횟수와 강도, 수분 유지 |
| 영양·수분 | 체중, 소변량, 기립성 어지럼 | 체중 안정, 탈수·전해질 회복 |
| 전신 기능 | 기립·보행, 피로, 수면 | 활동량과 회복 속도 |

침·전침은 오심·긴장·동반 근골격 불편을 보조할 수 있지만, 연하 안전 평가와 영양·수액 치료, 구조적 원인 검사를 대체하지 않습니다.

## 현대 임상자료

- 2023년 원인불명 오심·구토 환자에게 미후등식장탕을 사용한 단일 증례가 보고됐습니다. 증상과 변비 경과를 함께 관찰했으나 대조군이 없는 한 사례이므로 일반적 항구토 효과를 확정하지 않습니다. [DOI 10.7730/JSCM.2023.35.4.116](https://doi.org/10.7730/JSCM.2023.35.4.116)
- 체질을 다르게 판단한 상태에서 미후등식장탕 투여 뒤 복통·발한·오심이 발생한 증례도 보고됐습니다. 태양인 자가판정과 처방명 중심 투여를 피해야 한다는 안전 신호로 읽습니다. [관련 증례 보고](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART001616485)
- 가미미후등식장탕 동물연구는 변형 처방·동물모델 자료입니다. 원방의 열격 임상효과로 확대하지 않습니다.

## 안전과 의료기관 평가가 우선인 경우

- 침도 삼키기 어렵거나 침을 흘림
- 음식이 걸린 뒤 흉통·호흡곤란, 반복 흡인·사레
- 토혈·검은변·담즙성 또는 분출성 구토
- 빠른 체중감소, 소변 감소, 의식저하·심한 어지럼
- 새로 생긴 마비·발음장애·보행장애

이 경우 처방 반응을 기다리지 않고 응급·소화기·신경학적 평가를 우선합니다. 키위·다래류 알레르기 가능성과 실제 조제 원료의 학명·부위도 확인합니다.
