# 미후등식장탕(獼猴藤植腸湯) 임상 카드

미후등식장탕은 태양인 **내촉소장병의 열격증**에서 음식물을 받아들이고 내려 보내는 기능이 막혀 연하·섭취·구토 문제가 나타나는 방향을 살피는 대표 처방입니다.

## 병증 위치와 평가

| 항목 | 핵심 |
|---|---|
| 체질 | 태양인 |
| 병증 위치 | 내촉소장병·열격증 |
| 핵심 단서 | 삼킴 불편, 음식이 내려가지 않는 느낌, 구역·구토, 섭취량 감소 |
| 회복 지표 | 물·고형식 섭취, 구토 빈도, 체중·수분상태, 기력 |
| 가까운 비교 | 오가피장척탕의 해역증 |

## 진료에서 먼저 확인할 위험신호

연하곤란이 새로 생겼거나 빠르게 악화되고, 물도 삼키기 어렵거나 반복 흡인·기침, 토혈·검은변, 지속 구토, 급격한 체중감소가 있으면 식도·위장관·신경계 평가가 우선입니다. 전통의 열격과 현대의 식도암·연하장애를 같은 개념으로 단정하지 않습니다.

## 처방을 읽는 방식

`태양인 확진 → 평소 섭취·소변 소증 → 내촉소장병 → 열격의 경중 → 미후등식장탕 → 섭취·체중·기력 재평가`

태양인 처방 자료는 제한적이므로 처방명보다 병증 위치와 객관적 경과를 중심으로 기록합니다. 보행·하지무력이 핵심인 해역증은 [오가피장척탕](ogapi-jangcheok-tang.md)과 비교합니다.

## 자료의 한계

현대 임상근거는 증례와 전통 문헌이 중심입니다. 자가진단을 위한 카드가 아니라 태양인 열격의 개념, 필수 감별과 경과관찰을 연결하는 안내로 활용합니다.
