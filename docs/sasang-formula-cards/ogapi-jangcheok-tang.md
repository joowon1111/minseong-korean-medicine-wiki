# 오가피장척탕(五加皮壯脊湯) 임상 카드

오가피장척탕은 태양인 **외감요척병의 해역증**에서 요척·하지의 힘과 보행·활동 기능 저하를 중심으로 살피는 대표 처방입니다. 태양인은 문헌과 임상 자료가 상대적으로 적으므로 증상만으로 체질과 처방을 연결하지 않습니다.

## 병증 위치와 평가

| 항목 | 핵심 |
|---|---|
| 체질 | 태양인 |
| 병증 위치 | 외감요척병·해역증 |
| 핵심 단서 | 요척·하지 무력, 오래 서기·걷기 어려움, 전신 기능 저하 |
| 회복 지표 | 기립·보행, 계단, 보행거리, 일상활동, 소변과 섭취 상태 |
| 가까운 비교 | 미후등식장탕의 열격증 |

## 임상적으로 먼저 구분할 것

하지 힘 저하는 척수·말초신경·뇌혈관·근육·관절 문제 등 다양한 원인으로 생길 수 있습니다. 갑자기 발생한 편측 마비, 감각 소실, 대소변 장애, 회음부 감각저하, 보행이 빠르게 악화되는 경우에는 체질 치료보다 신경학적·영상의학적 평가가 우선입니다.

## 처방을 읽는 방식

`태양인 확진 → 평소 소증 → 외감요척병 → 해역의 경중 → 오가피장척탕 → 보행·기능 재평가`

전통 병증명은 현대의 특정 신경계 질환과 일대일로 같지 않습니다. 치료 전후에는 통증보다 실제 기능인 기립 시간, 보행거리, 낙상, 일상생활 수행을 기록하는 편이 유용합니다.

## 자료의 한계

태양인 처방은 대규모 임상시험보다 고전 기록과 증례 중심입니다. 따라서 대표 처방의 구조를 이해하는 카드로 활용하되, 특정 질환에 대한 효과를 확정적으로 표현하지 않습니다.
