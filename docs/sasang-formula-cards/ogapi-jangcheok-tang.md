# 오가피장척탕(五加皮壯脊湯)

오가피장척탕은 태양인 **외감요척병의 해역증**에서 요척·하지의 힘과 보행·활동 기능 저하를 중심으로 살피는 처방입니다. 태양인은 문헌과 임상 자료가 상대적으로 적으므로 하지무력만 보고 체질과 처방을 정하지 않고, 평소 소증·현재 병증·신경학적 위험신호를 먼저 확인합니다.

## 한눈에 보기

| 항목 | 핵심 |
|---|---|
| 체질 | 태양인 |
| 병증 위치 | 외감요척병·해역증 |
| 핵심 단서 | 요척·하지 무력, 오래 서기·걷기 어려움, 전신 기능 저하 |
| 순역·경중 | 소변·섭취와 전신 기능이 유지되는지, 근력저하·보행장애가 진행하는지 확인 |
| 회복 지표 | 기립, 보행거리, 계단, 낙상, 일상활동, 소변·섭취 |
| 가까운 비교 | 미후등식장탕의 내촉소장병·열격증 |

## 원방 구성

| 본초 | 용량·표기 | 배합에서 읽는 역할 |
|---|---:|---|
| [오가피](../herbs/acanthopanax-bark.md) | 16 g | 요척·근골과 하지 기능을 받치는 중심축 |
| 모과·송절 | 각 8 g | 근육·경락의 긴장과 풍습·구련을 조절 |
| 포도근·노근·앵도육 | 각 4 g | 수분·진액·상역을 조화 |
| 교맥 | 반 숟가락 | 원방의 곡물성 보조재 표기를 보존 |

중량으로 적힌 여섯 약재의 합은 44 g이며, 교맥은 별도의 개별 계량입니다. ‘반 숟가락’을 임의의 g 수치로 바꾸기보다 사용 판본과 실제 계량법을 조제기록에 남깁니다.

오가피가 가장 많다고 해서 단미 처방처럼 읽지 않습니다. 오가피·모과·송절의 요척·근골축과 포도근·노근·앵도육의 수분·진액 조화, 교맥의 보조축이 결합된 전체 구조입니다.

## 소증에서 병증까지 확인하는 흐름

`태양인 진단 → 평소 소변·섭취·보행 → 외감요척병 → 해역의 경중 → 오가피장척탕 → 근력·보행 재평가`

| 확인축 | 초진 질문·평가 |
|---|---|
| 평소 소증 | 소변이 시원한지, 평소 섭취량·구토 경향, 하체 힘과 보행거리 |
| 발병 양상 | 갑작스러운지 서서히 진행했는지, 감염·외상·약물 변화가 있었는지 |
| 운동 기능 | 의자에서 일어나기, 계단, 발처짐, 보행 보조기 사용, 좌우 차이 |
| 감각·통증 | 저림·감각저하, 허리에서 다리로 뻗는 통증, 야간통 |
| 자율·배설 | 대소변 장애, 기립성 어지럼, 발한 변화 |

## 가까운 병증·처방과 감별

| 비교 | 오가피장척탕 쪽 단서 | 다른 쪽 단서 |
|---|---|---|
| [미후등식장탕](mihudeung-sikjang-tang.md) | 요척·하지무력과 보행 기능 저하가 중심 | 연하·섭취·구토·체중감소가 중심인 열격 |
| 일반 요통 | 전신 소증과 해역의 기능 저하가 함께 있음 | 국소 근골격 통증, 자세·부하와의 관계가 중심일 수 있음 |
| 신경계 질환 | 전통 병증 감별 후에도 객관적 근력·반사·감각을 추적 | 진단명에 맞는 신경학적 검사·응급치료·재활이 우선 |

전통의 해역은 급성 운동축삭신경병증, 척추관협착증, 근병증 등 어느 하나의 현대 질환명과 동일하지 않습니다.

## 경과관찰

| 목표 | 시작할 때 기록 | 재진에서 판단 |
|---|---|---|
| 근력 | 주요 근육 MRC 등급, 좌우 차이 | 한 등급 변화와 실제 동작의 일치 |
| 기립 | 5회 의자일어나기 시간·보조 필요 | 시간 단축, 손 지지 감소 |
| 보행 | 보행거리·속도·보조기·낙상 | 거리와 안전성, 피로 회복 |
| 통증·감각 | NRS, 저림 분포, 야간통 | 통증 외 감각·기능의 동반 변화 |
| 전신 소증 | 소변, 섭취, 체중, 수면 | 태양인 소증과 기능의 함께 회복 여부 |

침·전침·약침·뜸·부항은 근골격 통증·근긴장·재활을 보조할 수 있지만, 처방 병증 감별이나 진행성 신경질환 평가를 대신하지 않습니다.

## 현대 임상자료

2021년 급성 운동축삭신경병증으로 진단된 태양인 환자에게 오가피장척탕을 포함한 사상의학 치료를 시행하고 근력·통증·장애척도의 경과를 보고한 단일 증례가 있습니다. 한 사람의 복합치료 사례이므로 특정 신경병증에 대한 인과효과나 일반적 치료효과를 확정할 수 없습니다. [DOI 10.7730/JSCM.2021.33.3.171](https://doi.org/10.7730/JSCM.2021.33.3.171)

## 안전과 의료기관 평가가 우선인 경우

- 갑자기 생긴 편측 마비·언어장애·안면 비대칭
- 빠르게 진행하는 양측 하지 또는 상하지 근력저하
- 호흡곤란·연하곤란, 목소리 변화
- 대소변 장애, 회음부 감각저하, 심한 허리통증
- 발열·의식 변화, 반복 낙상

이 경우 체질 치료를 기다리지 않고 응급·신경학적 평가를 우선합니다. 오가피류 원료는 종·부위가 다양하므로 [오가피 본초 문서](../herbs/acanthopanax-bark.md)에서 가시오가피·추출물과의 차이도 확인합니다.
