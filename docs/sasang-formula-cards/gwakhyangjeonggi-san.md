# 곽향정기산
## 언제 고려하는가?
사상의학에서 소음인의 **태음병 비만증(痞滿證)**과 연결되는 대표 처방입니다.

`소음인 → 리병 → 태음병 → 복통·설사 + 심하비만/구토·소화불편 → 곽향정기산`

## 비슷한 처방
- 백하오이중탕: 태음병 자리증.
- 계지반하생강탕: 같은 비만증에서 병증에 따라 고려.
- 십이미관중탕·강출관중탕: 황달증 방향.
- 관계부자이중탕: 더 깊은 소음병 자리증.

## 회복 신호
설사·복통·구토·심하 답답함과 냉감이 줄고 식욕·소화가 회복되어 **음식선화**에 가까워지는지 봅니다.

국가 사상체질병증 안내자료에서도 곽향정기산은 소음인 체질한약치료 처방군에 포함됩니다.
