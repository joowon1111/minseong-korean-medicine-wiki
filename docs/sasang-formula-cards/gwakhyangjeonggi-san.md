# 곽향정기산(藿香正氣散) — 소음인방

## 구성·용량·출전

> 일반 방제학의 고방 곽향정기산과 **소음인 체질방의 구성은 구별**한다.

| 본초 | 용량 |
|---|---:|
| 곽향 | 5.625 g |
| 소엽 | 3.75 g |
| 건강 | 1.875 g |
| 계피 | 1.875 g |
| 대복피 | 1.875 g |
| 반하 | 1.875 g |
| 백출 | 1.875 g |
| 익지인 | 1.875 g |
| 자감초 | 1.875 g |
| 진피 | 1.875 g |
| 창출 | 1.875 g |
| 청피 | 1.875 g |

**총량 26.25 g**

**출전:** 한국전통지식포탈 『동의사상신편』(1929), 소음인, P0018218. 포탈 조제법은 약재를 가루내어 사용.

『태평혜민화제국방』 계통의 곽향정기산은 곽향·자소·백지·대복피·복령·백출·진피·후박·고경·반하국·감초 등으로 구성되어 위 소음인방과 동일하지 않다.
