# 근거 수준 읽기

근거 수준은 논문을 기계적으로 줄 세우는 표가 아닙니다. 연구마다 답할 수 있는 질문이 다르며, 설계가 좋아도 대상·치료·결과가 현재 환자와 다르면 직접 적용하기 어렵습니다.

## 연구설계별로 알 수 있는 것

| 연구 | 주로 답하는 질문 | 읽을 때 확인 |
|---|---|---|
| 기초·전임상 | 성분·기전·생물학적 가능성이 있는가 | 사람의 임상효과로 바로 확대하지 않았는가 |
| 증례·증례군 | 실제 진료에서 어떤 경과가 관찰됐나 | 자연회복·병용치료와 구분 가능한가 |
| 단면연구 | 특정 시점에 어떤 특성이 함께 나타나나 | 원인과 결과의 순서를 알 수 있는가 |
| 코호트·관찰연구 | 노출·치료와 장기 결과가 연관되나 | 교란요인과 선택편향을 조정했는가 |
| 무작위대조시험 | 비교군 대비 치료효과가 있는가 | 무작위배정·눈가림·탈락·프로토콜 |
| 체계적 문헌고찰 | 관련 연구 전체가 어떤 방향인가 | 검색범위·선정기준·비뚤림 평가 |
| 메타분석 | 여러 연구를 합친 효과크기는 얼마인가 | 이질성·출판편향·연구 간 차이 |
| 임상진료지침 | 근거와 가치·안전·현실성을 종합한 권고는 무엇인가 | 최신성·개발방법·권고 강도 |

## 높은 단계의 연구면 항상 좋은가요?

그렇지는 않습니다. 작은 규모의 부실한 RCT보다 잘 수행된 대규모 관찰연구가 안전성이나 장기 경과를 더 잘 보여줄 수 있습니다. 메타분석도 질이 낮고 서로 다른 연구를 단순히 합치면 결론의 확실성이 높아지지 않습니다.

```text
연구유형
 +
연구 자체의 품질
 +
현재 질문과의 적합성
 +
환자에게 직접 적용 가능성
 =
임상적으로 쓸 수 있는 근거
```

## 무작위대조시험에서 확인할 것

- 무작위배정 방법과 배정 은폐
- 환자·시술자·평가자의 눈가림 가능성
- 대조군이 무치료·통상치료·위약·가짜침 중 무엇인지
- 사전에 정한 1차 결과가 무엇인지
- 탈락률과 결측치 처리
- 의도한 대로 배정군을 분석했는지
- 연구계획서와 등록된 결과가 일치하는지
- 이상반응을 양 군에서 같은 방식으로 수집했는지

## 체계적 문헌고찰·메타분석에서 확인할 것

- 질문과 포함 기준이 미리 정해졌는가
- 여러 데이터베이스를 충분히 검색했는가
- 연구 선택과 자료 추출을 두 명 이상이 수행했는가
- 포함 연구의 비뚤림 위험을 평가했는가
- 한약 구성·침 프로토콜·대상 질환의 차이가 큰가
- 통계적 이질성이 높은데도 하나의 숫자로만 결론냈는가
- 소규모 긍정 연구만 출판되는 편향을 살폈는가
- 최신 연구가 포함됐는가

## 통계적으로 유의하면 임상적으로 중요한가요?

p값이 기준보다 작다는 사실만으로 환자가 체감할 만큼 좋아졌다고 판단할 수 없습니다.

| 확인할 값 | 의미 |
|---|---|
| 효과크기 | 치료군과 비교군의 차이가 얼마나 큰가 |
| 신뢰구간 | 실제 효과가 있을 법한 범위가 얼마나 넓은가 |
| 절대위험차 | 실제 환자 몇 명에게 차이가 생기는가 |
| 최소임상중요차이 | 환자가 의미 있게 느끼는 변화 수준인가 |
| 반응자 분석 | 일정 수준 이상 좋아진 환자 비율이 늘었는가 |
| 추적관찰 | 치료가 끝난 뒤에도 변화가 유지되는가 |

## 결과지표는 무엇을 봐야 하나요?

- 통증점수뿐 아니라 기능과 활동
- 증상 총점뿐 아니라 환자가 가장 불편한 증상
- 수면·피로·소화·대변 등 동반증상
- 삶의 질과 업무·운동 복귀
- 약물 사용량
- 객관적 검사와 환자보고 결과
- 치료부담과 이상반응

대리지표가 좋아졌어도 환자의 증상과 기능이 달라지지 않았다면 임상적 의미를 별도로 판단해야 합니다.

## 한약·침구 연구의 특별한 변수

### 한약

처방명뿐 아니라 구성, 용량, 추출법, 제형, 품질관리, 가감과 병용약을 확인합니다.

### 침구

경혈, 자침 깊이와 방향, 득기, 수기·전침, 전기자극의 빈도·강도, 치료 횟수와 비교군을 확인합니다.

### 사상의학

체질진단 방법, 평소 소증, 현재 체질병증, 처방 구성과 치료반응을 구분합니다.

## 근거의 확실성을 낮추는 요인

- 무작위배정·눈가림·결측치 처리의 문제
- 연구 결과가 서로 크게 다름
- 연구 대상과 현재 질문이 간접적임
- 표본이 작아 신뢰구간이 넓음
- 부정적 연구가 출판되지 않았을 가능성
- 치료 프로토콜이 불충분하게 보고됨

## 자주 묻는 질문

### 메타분석이 있으면 효과가 확정된 건가요?

포함된 연구의 품질과 치료의 유사성, 이질성과 출판편향을 함께 봐야 합니다. 메타분석이라는 형식만으로 결론이 확정되지는 않습니다.

### 동물실험은 의미가 없나요?

성분과 기전, 다음 단계 연구의 가능성을 탐색하는 데 중요합니다. 다만 사람의 증상·기능 개선과 안전성을 직접 증명하는 자료는 아닙니다.

### 전통적으로 오래 쓴 치료는 연구가 없어도 되나요?

전통 사용은 중요한 임상 맥락을 제공합니다. 현대 연구는 효과의 크기, 적용 대상, 안전성과 다른 치료와의 비교를 더 명확하게 하는 역할을 합니다.
