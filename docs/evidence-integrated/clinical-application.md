# 근거를 임상에 적용하기

좋은 연구가 있다고 모든 환자에게 같은 치료를 적용하는 것은 아닙니다.

```text
연구 대상자
 + 환자의 실제 상태
 + 병증·체질
 + 안전성
 + 선호·치료목표
 ↓
치료 선택
 ↓
경과관찰
 ↓
재평가
```

## 임상에서 확인
- 연구 대상과 현재 환자가 얼마나 비슷한가
- 연구에서 사용한 처방·용량·시술법이 같은가
- 효과의 크기가 임상적으로 의미 있는가
- 이상반응은 어떠했는가
- 환자가 중요하게 생각하는 기능이 좋아지는가
