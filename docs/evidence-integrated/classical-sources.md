# 고전·전통자료 판별과 인용

고전·전통자료를 근거로 사용할 때는 책 이름만 적는 것으로 충분하지 않습니다. **어느 판본의 어떤 편·권·조문인지, 원문인지 후대 주석인지, 번역과 현대 해석을 누가 덧붙였는지**를 구분해야 합니다.

## 전통자료의 층위

| 자료 | 의미 | 기록할 것 |
|---|---|---|
| 원전 | 해당 의서의 본문 | 서명·편명·권차·조문 |
| 이본·개정본 | 시대·판본에 따라 달라진 본문 | 판본·간행정보·문구 차이 |
| 후대 주석 | 원문에 대한 의가의 해석 | 주석자·주석서·해석 범위 |
| 후대 처방서 | 원전 이후 처방과 임상경험 | 출전·구성·원전과의 차이 |
| 현대 번역 | 원문을 현대어로 옮긴 자료 | 번역자·출판정보 |
| 현대 해설 | 병증·처방의 현대적 설명 | 해설자·해석임을 표시 |
| 데이터베이스 | 원문·서지·본초·처방 검색 | 제공기관·접속정보·원자료 |

## 출전을 확인하는 순서

1. 현재 문서가 주장하는 병증·치법·구성·용량을 구분합니다.
2. 가장 이른 직접 출전을 찾습니다.
3. 편명·권차·조문과 앞뒤 문맥을 확인합니다.
4. 판본과 이본의 차이를 확인합니다.
5. 후대 주석과 후대 처방 확장을 원문과 분리합니다.
6. 번역문은 원문과 대조하고 번역자를 기록합니다.
7. 현대 질환명과 연결한 부분은 현대 해석임을 표시합니다.
8. 가능한 경우 현대 임상연구의 PMID·DOI를 별도로 연결합니다.

## 병증과 현대 질환명을 구분합니다

고전의 병증명은 당시의 관찰과 이론체계 안에서 형성됐으므로 현대 질환명과 그대로 같다고 단정하지 않습니다.

| 고전 자료 | 현대 연결에서 확인할 것 |
|---|---|
| 병증·증후 | 실제 증상군과 중증도 |
| 치법 | 치료 목표와 방향 |
| 본초·방제 | 구성·용량·제형 |
| 경맥·경혈 | 위치·자침법·주치 맥락 |
| 예후·순역 | 기능 변화와 경과 |
| 현대 질환명 | 진단기준과 연구 대상군 |

## 동명 처방을 확인하는 법

같은 처방명이 여러 문헌에 등장해도 구성과 용량, 주치가 다를 수 있습니다.

- 최초 출전과 후대 수록본
- 약미의 추가·삭제
- 약재별 용량과 상대 구성비
- 탕·산·환·고 등 제형
- 원문 병증과 후대 확장 적응
- 현대 연구에 사용된 실제 제제

따라서 출전이 다른 동명 처방을 하나의 고정 처방처럼 섞지 않습니다.

## 본초·경혈 자료를 확인하는 법

### 본초

기원식물·약용부위·수치·성미귀경·주치가 어느 본초서와 판본에 근거하는지 확인합니다. 현대 성분·약리 연구는 전통 본초 기록과 별도의 층위로 표시합니다.

### 경혈

경맥 소속·위치·취혈·주치·자침법이 어느 원전 또는 현대 표준에 근거하는지 구분합니다. 고전 위치와 현대 표준경혈 위치가 다를 수 있으면 차이를 설명합니다.

## 인용 표준

| 항목 | 권장 기록 |
|---|---|
| 고전 | 서명·편명·권차·조문 |
| 판본 | 판본명·간행연도·소장 또는 영인 정보 |
| 주석 | 주석자·주석서·해당 대목 |
| 번역 | 번역자·서명·출판사·연도 |
| 데이터베이스 | 기관명·자료명·접속일 |
| 논문 | 저자·학술지·연도·PMID·DOI |

직접 인용은 원문과 번역을 구분하고, 의역·요약·현대 해설은 인용문처럼 제시하지 않습니다.

## 아카이브의 기록 원칙

1. 원전과 후대 주석·현대 해석을 구분합니다.
2. 판본이 다르면 차이를 표시합니다.
3. 용량이 없는 원문에 임의 숫자를 넣지 않습니다.
4. 출전별 동명 처방의 구성을 섞지 않습니다.
5. 전통 병증과 현대 질환명을 자동 대응시키지 않습니다.
6. 현대 임상근거는 PMID·DOI와 연구유형을 별도로 표시합니다.
7. 독자가 원자료와 현대 해설을 다시 구분할 수 있게 링크합니다.
