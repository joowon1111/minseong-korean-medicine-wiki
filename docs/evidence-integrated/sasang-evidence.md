# 사상의학 연구 읽기

사상의학 연구는 체질 이름만 확인해서는 부족합니다. **체질을 어떻게 진단했는지, 평소 소증과 현재 병증을 구분했는지, 어떤 표리·순역 병증에 어떤 처방을 사용했으며 치료 뒤 무엇이 변했는지**를 함께 봅니다.

## 사상의학 연구의 주요 질문

| 연구 영역 | 핵심 질문 |
|---|---|
| 체질진단 | 누가 어떤 도구와 기준으로 진단했나 |
| 진단 재현성 | 반복평가·평가자 간 결과가 일치했나 |
| 소증 연구 | 평소 소화·대변·수면·땀·한열 특성을 어떻게 측정했나 |
| 체질병증 | 체질뿐 아니라 표리·순역·경중을 구분했나 |
| 처방 연구 | 원전·후대 처방, 구성·용량·가감을 기록했나 |
| 건강지표 | 체질과 지표의 연관성을 원인처럼 해석하지 않았나 |
| 치료반응 | 주증상과 소증·기능·삶의 질을 함께 평가했나 |

## 체질진단 연구에서 확인할 것

- 설문·면담·체형·안면·음성 중 무엇을 사용했는가
- 한 명의 진단인지 여러 전문가 합의인지
- 《동의수세보원》의 소증과 병증 정보를 반영했는가
- 처방 반응을 진단 기준에 포함했는가
- 같은 사람을 다시 평가했을 때 결과가 유지되는가
- 연령·성별·질환이 다른 집단에서도 재현되는가

체질진단은 단일 설문이나 체형 수치보다 **평소 소증·현재 병증·전문가 종합평가와 시간에 따른 일관성**을 함께 봅니다.

→ [체질진단 연구](../sasang-research/diagnosis-research.md)

## 소증과 현재 병증을 구분합니다

| 구분 | 예시 |
|---|---|
| 평소 소증 | 평소 식욕·소화·대변·수면·땀·추위와 더위 |
| 현재 현증 | 지금 가장 불편한 통증·발열·기침·소화·수면 문제 |
| 체질병증 | 체질별 표리·순역 병증과 병의 진행 방향 |
| 현대 진단 | 검사와 진단기준으로 확인된 질환 |
| 치료 목표 | 증상뿐 아니라 기능과 소증 회복 |

현대 질환명 하나로 사상처방을 자동 선택하거나, 전통 병증명을 현대 질환 하나와 일대일로 동일시하지 않습니다.

## 체질처방 연구에서 확인할 것

1. 체질과 체질병증 진단 기준
2. 처방의 원전과 후대 수록 여부
3. 약미·구성비·1일 용량·제형
4. 가감과 처방 변경 원칙
5. 양약·침·생활관리 병행
6. 치료기간과 추적관찰
7. 주증상·소증·기능·삶의 질
8. 이상반응과 중도탈락

## 원전과 현대 연구의 층위

- **《동의수세보원》:** 체질 생리·병리, 표리병증, 치법과 처방의 핵심 원전
- **후대 문헌:** 원전 이후 처방 확장과 임상경험
- **표준·진료지침:** 용어와 진단·치료 흐름의 공통 틀
- **진단 연구:** 도구의 재현성과 타당성
- **관찰연구:** 체질과 증상·건강지표의 연관성
- **임상시험:** 정해진 환자와 처방에서 치료효과와 안전성 평가

→ [사상의학 근거·출전](../sasang-integrated/evidence.md)

## 치료반응을 평가하는 방식

주증상 점수만 보지 않고 사상의학에서 중요하게 보는 회복 방향을 함께 기록합니다.

- 식욕과 소화
- 대변과 소변
- 수면과 꿈
- 땀과 체온감각
- 기력과 활동 후 회복
- 통증·기침·두통 등 주증상
- 일상기능과 삶의 질
- 처방 복용 후 새롭게 나타난 불편

## 환자에게 설명할 때

“이 체질에는 무조건 이 처방”보다는 연구 대상의 체질·병증, 사용 처방과 기간, 개선된 증상·기능, 현재 환자와의 유사성, 재평가 시점을 함께 설명합니다.
