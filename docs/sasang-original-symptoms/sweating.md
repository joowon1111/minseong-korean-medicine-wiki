# 땀
**문진:** 평소 양, 운동/더위 때 양, 주된 부위, 땀 후 개운함/피로, 발병 후 증가·감소.

- 태음인: **한액통창**이 핵심 건강신호.
- 소양인: 더운 환경의 발한량·부위가 표리병 연구에서 차이를 보임.
- 소음인: 운동 시 발한량 등이 표리병 연구에서 차이를 보임.

핵심은 '땀이 많으면 어느 체질'이 아니라 **평소 발한 패턴과 현재 변화**입니다.
