# 소증과 체질병증

<span id="9"></span>


소증(素證)은 아프기 전부터 평소 반복되던 생리적·증상적 특징을 말합니다. 현재 불편한 증상과 비교하는 기준이 되지만, 평소에 늘 있었다고 모두 정상이라는 뜻은 아닙니다. 오래된 불편도 생활을 방해하거나 변화하면 별도로 평가합니다.

## 평소와 지금을 나누어 기록하기 {#baseline-current}

| 항목 | 평소 상태 | 현재 달라진 점 |
|---|---|---|
| 식욕·소화 | 평소 식사량, 식후 편안함, 더부룩함 | 식사량 감소, 새로 생긴 통증·구역, 체중 변화 |
| 대변 | 횟수·굳기·배변 후 느낌 | 변비·설사의 시작과 지속, 혈변 여부 |
| 소변 | 횟수·야간 배뇨·배뇨감 | 통증, 눈에 띄는 양의 변화, 혈뇨 |
| 땀 | 활동·더위에 따른 발한과 땀 후 느낌 | 야간 발한, 식은땀, 발한 뒤 심한 탈진 |
| 수면 | 잠드는 시간, 중간 각성, 기상 후 상태 | 불면의 시작 시점, 낮 졸림과 일상 영향 |
| 한열 | 평소 추위·더위에 대한 반응 | 발열·오한, 특정 시기의 화끈거림 |
| 갈증·음수 | 평소 갈증과 마시는 습관 | 갑자기 심해진 갈증, 섭취·배뇨 변화 |
| 피로·회복 | 활동량과 휴식 후 회복 정도 | 활동 능력 저하, 회복 시간 증가 |
| 성정·정서 | 평소 긴장·스트레스에 대한 반응 | 수면·식사·대인 활동에 미치는 변화 |

발병 전의 평소 모습을 기준으로 쓰고, 증상이 시작된 뒤의 변화에는 시점·지속 기간·악화 조건을 덧붙입니다. 복용약·건강기능식품, 최근 수술·감염, 식사나 근무 형태의 변화도 함께 기록하면 체질적 특징과 다른 원인을 구별하는 데 도움이 됩니다.

## 체질 판단과 현재 진료를 연결하기 {#clinical-use}

같은 체질이라도 평소 소화 상태와 현재의 한열·대소변·체력 변화가 다르면 병증 판단과 치료 목표가 달라집니다. 반대로 한 가지 특징이 비슷하다고 같은 체질·처방으로 이어지지는 않습니다. 설문은 정보를 빠뜨리지 않기 위한 보조자료이며 진찰과 현재 질환 평가를 대신하지 않습니다.

기록한 뒤에는 가장 불편한 증상과 줄어든 일상 기능을 먼저 정리합니다. 치료 후에도 같은 항목을 비교하되, 피로가 좋아졌다는 느낌만으로 체질 판별이나 처방의 적합성이 확정되었다고 보지 않습니다. 새로 생긴 마비·호흡곤란·의식 변화나 출혈 등은 체질 설명보다 [위험신호 평가](../symptom-clinical/red-flags.md)가 우선입니다.
