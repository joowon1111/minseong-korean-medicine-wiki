# 성정·정서
사상의학에서 성정은 단순 성격테스트가 아니라 체질의 생리·병리와 생활관리로 이어지는 축입니다.

**문진:** 스트레스 때 먼저 변하는 신체기능, 걱정 후 소화, 흥분 후 수면·심계, 피로 시 정서반응.

소증 리뷰는 신체 증상뿐 아니라 심리적 특성도 체질진단과 병증 이해에 활용된다고 정리합니다.
