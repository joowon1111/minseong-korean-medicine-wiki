# 사상체질별 증상 변화와 치료 상세

기존의 사상체질 설명에서 한 단계 더 들어가, **몸이 나빠질 때 무엇이 어떻게 변하고, 어떤 병증으로 보며, 어떤 치료 원칙과 처방을 연결하는지**를 체질별로 정리합니다.


!!! note "읽는 방법"
    아래 내용은 **체질명만으로 처방을 정하는 표가 아니라**, 사상체질 → 평소 소증(素證) → 현재 체질병증 → 중증도 → 치법·처방의 흐름을 이해하기 위한 임상 지식망입니다. 실제 진료에서는 체질 진단과 병증 진단을 함께 해야 합니다.


## 전체 임상 흐름

```text
사상체질
   ↓
평소 소증
(소화·대변·땀·소변·수면·한열·정서)
   ↓
현재 증상의 변화
   ↓
표병 / 리병
   ↓
순증 / 역증
   ↓
경증 / 중등증 / 중증 / 위중증
   ↓
체질별 치법
   ↓
체질한약 + 침·뜸 + 식사·운동·성정관리
```

## 이 상세 허브에서 문서를 읽는 순서

1. [네 체질 비교](four-constitution-comparison.md)에서 큰 병증축을 봅니다.
2. [임상 알고리즘](clinical-algorithm.md)으로 평소 소증과 현재 현증을 분리합니다.
3. 체질별 상세 문서에서 세부 병증군과 처방군을 비교합니다.
4. [중증도·위험신호](../sasang-severity/index.md)에서 경중과 현대 위험신호를 확인합니다.
5. [처방 탐색기](../sasang-explorer/index.md)에서 관련 처방·원문 문서로 이동합니다.

## 체질별 상세 문서가 다루는 범위

| 체질 | 세부 병증 |
|---|---|
| 소양인 | 소양상풍·결흉·신열두통망음·망음·흉격열·장관열·강한 리열·음허오열 |
| 태음인 | 표한·한궐·비위담습·승청저하·호흡/폐원·간열폐조·조열·리열정체 |
| 소음인 | 울광·기체표병·망양초증·망양심화·태음병·한습/구토·소음병·장궐 |
| 태양인 | 외감요척병·해역 / 내촉소장병·열격·반위 |

각 문서는 진단이나 개인별 처방을 자동 결정하는 표가 아니라 **병증 구조를 공부하고 가까운 문서를 비교하기 위한 지식망**입니다.


## 원전·CPG를 함께 읽기

체질별 상세 문서의 각 주요 병증 카드에는 이제 **[원전] 《동의수세보원·신축본》 편명·핵심 표지어 → [CPG 2014/2015] 병증별 분류·표준증후 → [NCKM 2022] 현재 진단·치료·관리 틀**이 바로 연결됩니다.

→ [사상체질 병증 원전·CPG 직결 지도](pattern-source-map.md)

이 지도에서는 원전에 직접 있는 병증, CPG가 표준화한 병증, 《동의사상신편》 등 후대 처방 분기를 서로 다른 근거층으로 표시합니다. 특히 장관 열·승청 저하·병후 폐원 회복·급성 토사 같은 아카이브의 임상 연결축을 원전의 독립 대병증처럼 보이지 않도록 구분했습니다.
