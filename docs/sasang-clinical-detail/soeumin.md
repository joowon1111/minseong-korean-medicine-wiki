# 소음인: 몸이 나빠질 때 어떻게 변하나?


!!! note "읽는 방법"
    아래 내용은 **체질명만으로 처방을 정하는 표가 아니라**, 사상체질 → 평소 소증(素證) → 현재 체질병증 → 중증도 → 치법·처방의 흐름을 이해하기 위한 임상 지식망입니다. 실제 진료에서는 체질 진단과 병증 진단을 함께 해야 합니다.


## 1. 평소에 먼저 보는 소증

소음인은 체질진단에서 **소화·식욕, 대변, 냉감, 땀, 수면, 피로와 회복**을 중요하게 봅니다. 특히 평소 식욕과 소화가 약하고 복부 불편이나 가스가 반복되는 양상은 소음인 진단에서 참고되는 소증의 한 예입니다.

```text
평소 소화·식욕
     +
대변·냉감·피로
     ↓
소음인 소증 파악
```

## 2. 몸이 나빠질 때 중요한 변화

소음인의 리병에서는 **복만·설사·몸이 찬 느낌**이 중요한 축입니다. 진료지침에서 소음인 태음병은 복통·설사 계열을 중심으로 보고, **갈증이 뚜렷하지 않은 경우**가 중요한 감별점으로 제시됩니다.

### 태음병 경증
- 복만, 설사
- 몸이 차고 찬 것을 싫어함
- 갈증이 뚜렷하지 않음
- 복통, 구토, 식욕저하가 동반될 수 있음
- 심하부가 막힌 듯 답답한 비만감이 나타날 수 있음

### 태음병이 더 진행할 때
- 황색이 돌거나 황달 양상
- 부종
- 사지냉·심한 신체통
- 얼굴빛이 창백·청백해짐
- 심한 경우 기력이 크게 떨어지고 누워 있으려는 양상

### 소음병으로 더 깊어질 때
진료지침에서는 **복통·심한 설사에 갈증, 심번, 수족냉, 몸살·관절통** 등이 동반되는 것을 중요한 악화 양상으로 봅니다.

```text
복통·설사
 ↓
갈증 없음 → 태음병 쪽
갈증 + 심번·수족냉·통증 증가 → 소음병 쪽
```

## 3. 대표적인 치료 원칙과 처방

| 병증 맥락 | 치료 방향 | 대표 처방 예 |
|---|---|---|
| 태음병 자리증 | 온위강음 | 백하오이중탕 |
| 태음병 비만증 | 온위강음 | 곽향정기산, 계지반하생강탕 |
| 태음병 황달증 | 온위강음 | 십이미관중탕, 강출관중탕 |
| 태음병 음독증 | 온위강음 | 인삼계피탕, 인삼진피탕 |
| 소음병 자리증 | 건비이강음 | 관계부자이중탕 등 |

!!! caution "처방명만 보고 복용하지 않습니다"
    같은 소음인이라도 태음병인지 소음병인지, 갈증·복통·설사·수족냉의 양상과 중증도에 따라 처방이 달라집니다.

## 4. 한약 외 치료

사상체질병증 진료지침에서는 병증에 따라 **침·뜸·부항·기공 등의 처치와 정신적 안정·성정 조절**을 병행할 수 있다고 제시합니다. 현대 NCKM 지침은 체질한약뿐 아니라 체질침, 뜸, 식사요법, 운동요법, 성정요법을 함께 다룹니다.

## 5. 회복할 때 보는 변화

- 설사와 복통의 감소
- 식욕과 소화의 회복
- 냉감·사지냉의 완화
- 수면·기력의 안정
- 평소 소증 수준으로 돌아오는지 확인

→ [소증→현재병증→처방 알고리즘](clinical-algorithm.md)


## 6. 표병까지 포함한 전체 병증 지도

소음인을 소화기 리병만으로 이해하면 울광·망양이라는 중요한 표병축이 빠집니다.

| 병증군 | 중심 증후 | 깊어질 때 보는 변화 | 대표 처방 연결 |
|---|---|---|---|
| 태양증·울광 초기 | 오한·발열·두통·신체통 | 발한 뒤 기력저하 | 천궁계지탕 |
| 표병·기체/소화 | 두통·흉복 답답함·식욕 변화 | 망양으로 전환하는지 | 향소산·궁귀향소산 |
| 망양초증 | 땀 뒤 탈진·냉감·회복 지연 | 활동·식욕 저하 | [승양팔물탕](../sasang-formula-cards/seungyangpalmul-tang.md) |
| 망양 심화 | 지속 자한·냉감·전신 쇠약 | 순환·의식·기립 기능 | [인삼계지부자탕](../sasang-formula-cards/insamgyejibujatang.md)·계지부자탕 |
| 태음병·리한 | 복통·설사·식욕저하 | 구토·비만·냉감 | [백하오이중탕](../sasang-formula-cards/baekhao-ijung-tang.md) |
| 태음병·한습/구토 | 오심·구토·심하비만 | 수분·전해질 소모 | [곽향정기산](../sasang-formula-cards/gwakhyangjeonggi-san.md) |
| 소음병·깊은 리한 | 심한 설사·복통·수족냉 | 갈증·심번·전신통·쇠약 | [관계부자이중탕](../sasang-formula-cards/gwangye-buja-ijung-tang.md) |
| 장궐·격양 | 구토·설사·사지궐냉 | 섭취·순환·의식 저하 | [오수유부자이중탕](../sasang-formula-library/osuyubujairijung-tang.md) |

## 7. 표병과 리병을 시간순서로 구분하기

둘 다 냉감·피로가 있을 수 있어 현재 증상만 보면 헷갈릴 수 있습니다. **오한·두통·신체통과 발한이 먼저였는지**, 아니면 **식욕저하·복통·설사·구토가 먼저였는지**를 묻습니다. 발한 뒤 급격한 탈진이 핵심이면 망양축, 소화·배설의 리한이 핵심이면 태음병·소음병축을 더 적극적으로 봅니다.

## 8. 태음병의 세부 분기

- **자리·리한:** 백하오이중탕처럼 복통·설사·식욕저하와 복부 냉감을 중심으로 봅니다.
- **한습·비만:** 곽향정기산·계지반하생강탕처럼 오심·구토·심하비만과 담습의 비중을 봅니다.
- **급성 토사:** 궁귀총소이중탕 계열은 구토·설사·복통·냉감과 수분상태를 함께 확인합니다.
- **황달·음독:** 관중탕·십이미관중탕 계열의 전통적 위치를 보되 새 황달·진한 소변은 간담도 평가가 우선입니다.
- **기체·사려상비:** [향부자팔물탕](../sasang-formula-cards/hyangbujapalmul-tang.md)은 흉복 답답함·긴장·소화저하가 만성적으로 얽힌 방향에서 비교합니다.

## 9. 부자 처방군을 읽는 원칙

부자 포함 처방은 ‘몸이 차다’는 이유로 묶지 않습니다. 망양의 표병인지, 소음병의 깊은 리한인지 먼저 구분하고, 포제·용량·전탕·심혈관 상태·간신장 기능·병용약을 별도로 확인합니다. 입술·혀·사지 저림, 심계·부정맥, 심한 어지럼·오심이 생기면 이상반응 평가가 필요합니다.

## 10. 초진·재진 기록 항목

- 발병 전 식욕·식사량과 식후 편안함
- 대변 형태·횟수, 복통 위치와 구토
- 땀의 상황과 땀 뒤 기력
- 손발 냉감·체온감과 기립 어지럼
- 갈증·음수량·소변량
- 수면·걷기·업무 가능 범위
- 체중과 치료 뒤 회복 순서

## 11. 회복을 음식선화로 다시 보기

설사나 구토가 멎는 것만으로 끝내지 않고 **먹을 수 있고, 먹은 뒤 편안하며, 대변·냉감·기력·수면이 발병 전 수준으로 돌아오는지**를 봅니다. 이것이 소음인의 평소 건강 기준선과 치료 후 재평가를 연결하는 핵심입니다.
