# 사상체질 처방 전체 비교 지도

사상의학의 처방은 체질별로 서로 다른 병증 구조를 바탕으로 한다.

| 체질 | 대표적으로 연결되는 처방 예 |
|---|---|
| 소양인 | 형방도적산·형방사백산·양격산화탕 |
| 소음인 | 향사양위탕·곽향정기산·팔물군자탕 |
| 태음인 | 태음조위탕·조위승청탕·청심연자탕·열다한소탕 |
| 태양인 | 오가피장척탕·미후등식장탕 |

```text
사상체질
   ↓
태양인 · 소양인 · 태음인 · 소음인
   ↓
평소 소증 + 현재 병증
   ↓
표리·한열·경중
   ↓
체질별 치법
   ↓
체질 처방
```

이 표의 목적은 체질별 대표 처방을 한눈에 보여주는 것이며, 실제 사상의학적 처방 판단에서는 **같은 체질 안에서도 현재 병증이 다르면 처방이 달라질 수 있다.**
