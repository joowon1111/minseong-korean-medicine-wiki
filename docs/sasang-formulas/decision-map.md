# 체질 → 병증 → 처방 탐색

사상체질 처방을 탐색할 때는 다음과 같은 단계적 구조가 유용하다.

```text
1. 체질
   ↓
2. 평소의 소증
   ↓
3. 현재의 주증상·동반증상
   ↓
4. 표리병증
   ↓
5. 한열·경중·병의 전개
   ↓
6. 치료 원칙
   ↓
7. 체질 처방
```

## 소양인 예시
```text
소양인
 ↓
병증 분석
 ├─ 형방도적산 계열
 ├─ 형방사백산 계열
 └─ 양격산화탕 계열
```

핵심은 `소양인 → 특정 처방`처럼 바로 연결하는 것이 아니라 **중간의 병증 판단을 지식망에 명시적으로 남기는 것**이다.
