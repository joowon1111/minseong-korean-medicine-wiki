# 건강검진 위염·위내시경 소견

검진 결과의 **병변 위치·조직검사·헬리코박터 결과·다음 검사 계획**을 함께 읽는 안내입니다. 증상과 치료의 상세 설명은 [위염·속쓰림·명치통증](gastritis-symptoms.md)으로 이어집니다.

## 환자가 이렇게 검색할 수 있습니다

- 건강검진 위염 · 위내시경 위염 · 만성위염
- 위축성위염 · 장상피화생 · 위점막만성염증
- 위염 한약 · 위내시경 정상인데 소화불량 · 속쓰림

## 검사결과를 볼 때

| 결과지 항목 | 확인할 내용 |
|---|---|
| 내시경 소견 | 발적·미란·위축·궤양 등의 위치와 범위 |
| 조직검사 | 만성 염증, 위축, 장상피화생, 이형성 여부; 조직검사를 했는지부터 확인 |
| 헬리코박터 | 검사 방법·결과, 제균치료 여부와 치료 후 확인검사 |
| 이전 결과 | 같은 부위를 비교했는지, 새로 생긴 소견이 있는지 |
| 추적 계획 | 담당 의료진이 권고한 검사 시기와 추가 진료 |

만성위염은 만성 염증, 위축성위염은 위샘 감소, 장상피화생은 장형 상피로의 변화라는 서로 다른 정보를 담습니다. 위축이나 장상피화생은 곧 암이라는 의미가 아닙니다. 이형성 여부와 병변 범위를 구분해 읽습니다. [용어별 상세 해설](gastritis-symptoms.md#chronic-atrophy-metaplasia)

위축성위염에서는 헬리코박터 감염을 확인하고 양성이면 제균과 성공 여부 확인을 논의합니다. 추적 간격은 병변 범위·정도와 개인 위험을 고려해 정합니다. 필요하면 철·비타민 B12 부족도 평가합니다. [AGA 진료 자문](https://pubmed.ncbi.nlm.nih.gov/34454714/)

### 상담 전에 준비할 자료

내시경 사진·결과지, 조직검사 결과지, 헬리코박터 검사·제균 기록, 복용 중인 위장약·진통제 목록을 준비합니다. 명치 쓰림인지 가슴 뒤쪽 쓰림인지, 공복·식후·야간 중 언제 심한지와 체중 변화를 함께 적으면 도움이 됩니다.

## 한의학적 관리와 연결

검사 소견과 함께 식후팽만·조기포만·속쓰림·식욕저하·오심·배변을 평가합니다. 비위기허, 비위허한, 담습, 간위불화, 한열착잡, 위음부족 등 현재의 증후를 구분하여 처방과 식사관리를 구성합니다. **내시경의 위축을 곧바로 위음허로 판정하지 않습니다.**

| 동반 증상 조합 | 처방을 비교하는 방향 |
|---|---|
| 식욕저하·조기포만·피로 | 육군자탕·향사육군자탕의 비위기허·담습 배합 |
| 명치 답답함·오심·장명·묽은변 | 반하사심탕의 한열착잡·심하비 |
| 신물·열감과 흉협 불편 | 좌금환의 간위울열·강역 |
| 냉감·허약·묽은변 | 이중탕의 온중·건비 |

[소화 한약의 구성·원전·감별](../herbal-integrated/formula-for-digestion.md#digestive-pattern-comparison)에서 각 처방을 비교할 수 있습니다. 증상·식사량·일상 기능의 개선과 조직 소견의 변화는 각각 평가하며, 처방받은 약과 검사 추적 계획을 함께 확인합니다.

## 먼저 확인해야 할 경우

토혈·검은변, 지속 구토, 음식 삼킴 곤란, 설명되지 않는 체중감소·빈혈, 새롭거나 심해지는 통증은 진료를 앞당길 이유입니다. 결과지에 이형성·종양 의심·추가 조직검사 권고가 적혀 있다면 해당 계획을 먼저 확인합니다.
