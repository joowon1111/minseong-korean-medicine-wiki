# 다이어트 정체기·체중이 안 빠져요

## 환자가 이렇게 검색할 수 있습니다

- 다이어트 정체기
- 살이 안 빠져요
- 운동해도 체중이 그대로
- 다이어트하다 체중이 멈췄어요
- 체중감량 정체
- 다이어트 한약 정체기

## 함께 구분할 상태

며칠의 체중 변화만으로 정체기를 확정하지 않습니다. 같은 조건에서 측정한 추세와 허리둘레·생활 기록을 함께 봅니다.

| 확인할 요소 | 점검할 내용 |
|---|---|
| 체수분·배변 | 짠 음식·운동 후 회복·생리주기·변비·부종 |
| 실제 섭취 | 음료·술·간식·주말 식사와 끼니 간격 |
| 활동 변화 | 운동 외 일상활동이 줄었는지, 피로 때문에 덜 움직이는지 |
| 감량 후 변화 | 체중이 줄면서 필요한 에너지와 생활 리듬이 달라졌는지 |
| 수면·약물 | 수면 부족·야식, 새로 시작한 약과 증상 |

## 먼저 확인해야 할 신호

- 극단적 절식
- 심한 두근거림·흉통
- 실신
- 급격한 쇠약

## 한의치료·체중관리 연결

약을 더 강하게 쓰기 전에 식욕·소화·배변·부종·기력·잠의 변화를 확인합니다. 체수분이나 변비의 영향이 큰 경우와 실제 감량 추세가 멈춘 경우를 나누고, 섭취·활동·처방을 조정합니다.

피로·냉감·식사량 부족이 커졌다면 회복과 근육 유지가 중요합니다. 혈압·두근거림·불면·설사가 생겼는지도 함께 봅니다. [다이어트 한약](weight-management-herbal.md) · [부종과 체중](edema-weight.md)

## 체중 숫자만 보지 않기

체중관리는 **허리둘레·식욕·식사패턴·근육량·활동량·수면·스트레스·소화·부종**을 함께 보는 것이 중요합니다. 한약도 하나의 획일적인 방식보다 현재 목표와 병증에 맞춰 구성합니다.
