# 날개뼈·견갑골 안쪽 통증 — 목·어깨·흉추 감별

날개뼈 안쪽 통증은 능형근·승모근·견갑거근의 과부하로 흔히 생기지만, 목의 관절·신경근에서 퍼지는 통증, 어깨 움직임의 보상, 갈비뼈·흉추 문제도 비슷하게 느껴질 수 있습니다. 오래 앉은 자세만 탓하기보다 **목·팔 움직임, 호흡, 저림과 전신증상**을 함께 확인합니다.

!!! tip "핵심 답변"
    누르거나 견갑골을 움직일 때 재현되는 국소 뻐근함은 근육성 가능성을 높이지만 그것만으로 확정하지 않습니다. 팔저림·근력저하, 흉통·호흡곤란, 발열·외상은 다른 원인을 우선 평가하는 단서입니다.

## 견갑골 안쪽 통증 구분하기

| 주된 양상 | 우선 살피는 상태 | 구분할 점 |
|---|---|---|
| 오래 앉거나 팔을 뻗은 뒤 안쪽모서리 뻐근함 | 능형근·승모근 MPS | 압통, 견갑 뒤당김·팔 뻗기 |
| 목을 돌리거나 젖힐 때 견갑·팔로 뻗음 | [목디스크](cervical-disc-herniation.md)·경추성 연관통 | 감각·반사·분절 근력 |
| 팔 올리기·뒤로 보내기에서 어깨와 견갑 통증 | [어깨통증](shoulder-pain.md) | 회전근개, 능동·수동 ROM |
| 벽 밀기에서 견갑골 안쪽모서리가 들림 | 견갑운동 이상·장흉신경 문제 | 전거근·승모근 기능, 익상견갑 |
| 깊은숨·기침·몸통 회전에서 통증 | 늑골·흉추·흉막성 원인 | 압통·외상·호흡기 증상 |
| 띠 모양 화끈거림 뒤 피부발진 | 대상포진·신경통 | 감각 분포와 피부 변화 |

## 바로 평가해야 할 위험신호

- 흉통·호흡곤란·식은땀·실신감과 등·팔 통증이 함께 생김
- 갑작스러운 숨참, 피 섞인 가래 또는 한쪽 다리 붓기가 동반됨
- 외상 뒤 갈비뼈·척추 통증이 심하거나 숨쉬기 어려움
- 팔·손 근력이 빠르게 떨어지거나 감각저하가 진행함
- 발열·오한, 원인 모를 체중감소와 지속되는 휴식·야간통
- 띠 모양 통증 뒤 물집이 생기거나 면역저하 상태에서 심한 통증

## 진료에서는 무엇을 확인하나요?

1. 통증이 견갑골 안쪽·위각·아래각 중 어디인지 표시합니다.
2. 목 회전·폄과 팔 올리기·바깥돌림에서 증상이 변하는지 봅니다.
3. 견갑골의 상방회전·전인·뒤당김과 벽 밀기 동작을 확인합니다.
4. 능형근·승모근·견갑거근·극하근 압박이 익숙한 통증을 재현하는지 봅니다.
5. 팔 감각·반사·근력, 흉곽 움직임과 호흡·심폐 증상을 함께 확인합니다.

근육성 양상이 분명하면 영상검사가 항상 필요하지 않습니다. 외상·신경학적 이상, 흉부 장기 원인, 골절·종양·감염이 의심되거나 경과가 예상과 다르면 X선·MRI·흉부검사 등을 원인에 맞춰 선택합니다.

## 자세와 운동은 어떻게 조절하나요?

- 화면·키보드 위치를 조정하고 팔을 오래 앞으로 뻗은 작업을 짧게 나눕니다.
- 자세를 한 모양으로 고정하기보다 자주 바꾸고 짧게 걷거나 팔을 움직입니다.
- 통증 범위에서 흉추 폄·회전과 견갑골 전인·뒤당김을 연습합니다.
- 전거근과 중·하부 승모근의 조절을 단계적으로 회복합니다.
- 운동 뒤와 다음 날 팔 사용·호흡 통증을 기록해 부하를 조정합니다.

## 침·전침·약침과 한약

침치료는 아픈 점 하나뿐 아니라 능형근·승모근·견갑거근·극하근, 목과 어깨 관절을 함께 평가합니다. 견외수(SI14)·견중수(SI15)·천종(SI11)·고황(BL43)과 견갑대의 아시혈 등을 분포에 맞춰 구성할 수 있습니다. [어깨·견갑대 MPS 아틀라스](../clinical-anatomy/mps-shoulder.md)에서 기능·신경지배를 확인합니다.

견갑골 주변에는 갈비뼈와 흉막이 있으므로 침·약침은 목표 근육과 깊이·방향을 해부학적으로 정합니다. 전침은 근육 기능과 반응에 맞추고, 약침은 제제·알레르기·항응고제·감염 위험을 확인합니다.

| 전통적 변증 단서 | 치료 방향 | 검토할 수 있는 처방 계열 |
|---|---|---|
| 갑작스러운 목결림과 견배부 긴장 | 서근·통락 | [회수산](../formulas/huishou-san.md) 계열 |
| 외상·과사용 뒤 고정통과 압통 | 활혈거어·통락 | [당귀수산](../formulas/danggui-susan.md) 계열 |
| 오래된 뻣뻣함과 풍습·어혈 | 거풍습·활혈통락 | [소경활혈탕](../formulas/shujing-huoxue-tang.md) 계열 |
| 냉감·무거움과 한습에 악화 | 산한제습·통락 | [오적산](../formulas/wuji-san.md) 계열 |

## 치료 반응은 무엇으로 판단하나요?

| 평가 영역 | 기록 예시 |
|---|---|
| 작업 | 컴퓨터·운전·진료 자세를 유지할 수 있는 시간 |
| 목·팔 기능 | 목 회전, 팔 올리기·뒤로 보내기 |
| 견갑 기능 | 벽 밀기, 견갑골 들림과 좌우 움직임 |
| 신경 증상 | 팔·손 저림 범위, 악력과 물건 놓침 |
| 수면·호흡 | 돌아눕기, 깊은숨·기침 통증 |

국소 압통이 줄어도 팔저림·근력저하가 진행하거나 흉부 증상이 생기면 근막통증만으로 보지 않습니다.
