# 삼차신경통·얼굴 전기통증

## 환자가 이렇게 검색할 수 있습니다

- 삼차신경통
- 얼굴이 전기 오듯 아파요
- 세수할 때 얼굴이 찌릿해요
- 양치할 때 얼굴이 아파요
- 한쪽 얼굴 번개통증
- 삼차신경통 한의원

## 함께 구분할 상태

- 치과질환
- 턱관절
- 대상포진 후 신경통
- 안면통증증후군
- 중추신경계 원인

## 턱관절통증과 어떻게 다른가요?

| 구분 | 전형적인 통증 모습 | 다음 단계 |
|---|---|---|
| 삼차신경통 | 한쪽 얼굴에 수초에서 2분가량 전기·칼로 베는 듯한 통증이 반복되고 세수·양치·말하기·가벼운 접촉으로 유발 | 신경과·신경외과 감별과 영상검사 필요성 평가 |
| 턱관절·저작근 통증 | 씹거나 크게 벌릴 때 심해지는 둔통·압통, 관절음·개구제한, 교근·측두근 촉진으로 익숙한 통증 재현 | [턱관절장애 통합 안내](temporomandibular-disorder.md)와 치과·근육·관절 평가 |

두 양상이 겹치거나 통증 때문에 턱을 지속적으로 긴장하는 경우도 있어 **통증의 지속시간·촉발점·씹기와의 관계·신경학적 증상**을 구분합니다.

## 먼저 확인해야 할 신호

- 새로운 감각소실·근력저하
- 양측성 증상
- 시력·청력 변화
- 다른 신경학적 이상

## 한의치료 연결

전형적인 짧은 전격통과 촉발요인을 확인하고 신경학적 감별을 우선합니다. 한의치료는 기존 의학적 치료와 병행 가능성을 검토하며 안면부 자침 안전을 특히 중시합니다.

**통증·저림의 분포와 시간패턴 → 신경학적 위험신호 → 경추·근육·신경·MPS 감별 → 한약·침·전침·약침 → 재평가** 순으로 봅니다.
