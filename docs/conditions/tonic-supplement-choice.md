# 보약·영양제 무엇을 선택할까

## 환자가 이렇게 검색할 수 있습니다

- 보약 영양제 차이
- 보약이랑 영양제 뭐가 다른가요
- 기력회복 보약 영양제
- 만성피로 영양제 보약
- 부모님 보약 영양제
- 녹용보약 영양제
- 한약과 건기식 차이

## 먼저 이해하기

보약과 영양제는 어느 하나가 항상 우월한 선택이 아닙니다. 결핍이 명확한 영양소는 보충이 중요하고, 한약은 증상·체질·병증·소화·수면·회복상태를 종합해 처방하는 방식이라는 차이를 설명합니다.

## 같이 확인할 항목

- 현재 복용 중인 처방약·일반의약품
- 영양제·건강기능식품·천연제품의 제품명과 실제 성분
- 하루 섭취량과 복용 횟수
- 같은 성분이 여러 제품에 중복되는지
- 간·신장질환, 출혈경향, 알레르기
- 임신·수유 여부와 수술·시술 예정 여부

## 한약·보약과 함께 복용할 때

제품을 단순히 **한약 / 영양제 / 천연제품**으로만 나누지 않고 실제 성분과 용량을 기준으로 봅니다. 필요하면 복용시간을 조정할 수 있지만, 중요한 것은 시간 간격만이 아니라 **중복성분·총 섭취량·약물상호작용 가능성**입니다.

## 먼저 확인이 필요한 경우

황달·진한 소변, 비정상적인 출혈, 심한 두근거림·흉통, 호흡곤란, 심한 알레르기 반응처럼 새로운 이상증상이 생기면 복용제품을 점검하고 필요한 의학적 평가를 우선합니다.
