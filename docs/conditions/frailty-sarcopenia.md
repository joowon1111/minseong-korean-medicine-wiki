# 노쇠·근감소·근력저하

## 환자가 이렇게 검색할 수 있습니다

- 노쇠
- 근감소증
- 근력이 떨어졌어요
- 다리에 힘이 없어요
- 노인 근력저하
- 어르신 체력저하
- 근감소 보약
- 노인 기력회복

## 함께 구분할 상태

- 노화와 활동량 감소
- 단백질·영양상태
- 만성질환
- 비타민·빈혈·내분비 문제
- 낙상위험
- 기허·기혈양허·신허 등 병증

## 먼저 확인해야 할 신호

- 갑작스러운 한쪽 근력저하
- 보행이 급격히 나빠짐
- 원인 모를 체중감소
- 반복 낙상
- 호흡곤란·흉통

## 한의치료 연결

근력저하는 한약만으로 해결하는 문제가 아니므로 단백질·저항운동·낙상예방을 기본으로 봅니다. 한약은 식욕·피로·수면·회복저하 등 동반 병증을 보조적으로 관리하는 방향으로 연결합니다.

## 치료를 한눈에 보기

**원인 감별 → 현재 회복단계 → 한의학적 병증 → 한약·침구치료 → 영양·수면·활동관리 → 재평가** 순으로 봅니다.
