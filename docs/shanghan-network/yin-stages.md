# 태음·소음·궐음

태음·소음·궐음은 육경병증의 음경 단계로, 허한·한열착잡·정기 쇠약 등 다양한 병리구조를 포함한다.

## 태음
비위의 허한과 소화기 증후가 중요한 축이다.

## 소음
심신 양허 또는 음허의 구조가 주요하게 논의된다.

## 궐음
한열착잡과 상열하한 등 복합적인 병증 구조가 나타날 수 있다.

```text
태음 → 비위 허한
소음 → 양허/음허
궐음 → 한열착잡
```
