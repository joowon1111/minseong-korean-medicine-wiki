# 고전 예방·기능 회복 연구 지도

**한의학의 예방·만성 관리·회복 분야는 실제로 무엇이 개선됐는지를 기준으로 읽을 때 강점이 선명해집니다.** 발병 위험, 반복 발작, 식사와 수면, 움직임과 생활기능은 서로 다른 목표입니다. [양생·치미병 원문과 현대 해석](../yangsaeng/index.md)이 고전의 질문을 다룬다면, 이 지도는 그 질문과 연결되는 사람 대상 연구를 찾는 출발점입니다.

## 어떤 의미의 예방과 회복인가 {#outcomes}

| 목표 | 연구에서 확인할 결과 | 다른 결과와 구분할 점 |
|---|---|---|
| 발병 위험 관리 | 실제 질병 발병, 추적기간 | 검사 수치 개선과 발병 감소는 다름 |
| 반복 증상 관리 | 발작일수, 증상 강도, 구조약 사용 | 첫 발병 예방과 재발·발작 예방 구분 |
| 기능 회복 | 보행·일어서기·일상 동작·낙상 | 기력이 좋아진 느낌과 기능 측정 구분 |
| 식사·장기능 회복 | 조기포만, 섭취량, 첫 배변 | 장운동 지표를 전신 회복으로 확대하지 않음 |
| 생활 적응 | 수면효율·낮 기능·삶의 질 | 개별 증상과 종합 척도를 구분 |

‘상대적 우위’는 **어떤 대상에서 무엇과 비교했는지**를 붙여 말합니다. 위약보다 나은 결과, 통상관리에 더했을 때의 개선, 다른 적극적 치료보다 나은 결과는 각각 의미가 다릅니다.

## 생활관리·침·전통 운동의 대표 임상시험 {#clinical-trials}

| 질문·연구 | 대상과 비교 | 확인한 결과와 적용 범위 |
|---|---|---|
| 당뇨병 발병을 줄일 수 있는가 — DPP, *NEJM* 2002 | 고위험군 3,234명, 생활중재·메트포르민·위약, 평균 2.8년 | 생활중재군 발병 상대위험 58% 감소. 한의치료 시험이 아니라 생활관리의 목표를 보여주는 비교 자료. [상세 조건](../conditions/prediabetes.md#diabetes-prevention-trial) · [원 논문](https://doi.org/10.1056/NEJMoa012512) |
| 편두통 발작을 줄이는가 — Xu 등, *BMJ* 2020 | 환자 150명, 실제 침·가짜 침·통상관리 | 17–20주 평가의 4주당 편두통일수에서 실제 침과 가짜 침의 보정 차이 −2.1일. 대상과 시행 횟수 확인. [예방 관리](../conditions/migraine.md#prevention-classical-context) · [논문](https://doi.org/10.1136/bmj.m697) |
| 고령자 요통의 생활기능이 회복되는가 — DeBar 등, *JAMA Network Open* 2025 | 65세 이상 800명, 통상관리와 침을 추가한 두 방식 | 6개월 RMDQ 기능장애 차이 −1.0·−1.5점. 유지치료를 늘린 방식의 추가 우위는 뚜렷하지 않음. 가짜 침 대조시험과 구분. [상세](../conditions/low-back-pain.md#older-adult-functional-trial) · [논문](https://doi.org/10.1001/jamanetworkopen.2025.31348) |
| 낙상을 줄이는가 — Li 등, *JAMA Internal Medicine* 2018 | 낙상 위험이 있는 70세 이상 670명, 낙상예방용 태극권·복합운동·스트레칭, 24주 | 태극권 프로그램의 낙상 발생률이 스트레칭보다 58%, 복합운동보다 31% 낮음. 특정 균형훈련 프로그램의 결과. [상세](../conditions/elderly-tonic.md#falls-prevention-trial) · [논문](https://doi.org/10.1001/jamainternmed.2018.3915) |
| 수면이 개선되는가 — Siu 등, *JAMA Network Open* 2021 | 60세 이상 만성불면 320명, 태극권·일반운동·비중재, 12주 | 수면효율은 비중재 대비 각각 3.4·3.5%p 개선. 두 활동군의 객관적 결과 차이는 뚜렷하지 않음. [상세](../conditions/insomnia.md#movement-sleep-trial) · [논문](https://doi.org/10.1001/jamanetworkopen.2020.37199) |
| 혈압 관리에서 운동 방식이 다른가 — *JAMA Network Open* 2024 | 혈압 경계 범위 성인 342명, 태극권과 유산소운동, 12개월 | 진료실 수축기혈압 변화의 군 간 차이 −2.4 mmHg. 심혈관 사건 감소를 직접 입증한 시험은 아님. [상세](../conditions/high-blood-pressure-checkup.md#tai-chi-blood-pressure) · [논문](https://doi.org/10.1001/jamanetworkopen.2023.54937) |
| 섬유근육통의 종합 생활기능을 개선하는가 — Wang 등, *NEJM* 2010 | 66명, 태극권과 교육·스트레칭, 12주 | FIQ 종합척도 차이 −18.4점. 소규모 시험이며 통증 하나만의 점수가 아님. [상세](../authority/conditions/fibromyalgia.md#tai-chi-functional-trial) · [논문](https://doi.org/10.1056/NEJMoa0912611) |

전통 운동 연구는 양생과 연결되는 중재의 사례이며 한의진료 전체의 효과 수치가 아닙니다. 통상관리 추가시험은 실제 진료에서의 추가 가치를, 적극적 비교시험은 다른 선택지와의 차이를 설명합니다. 숫자만 나열한 순위보다 대상·시행 방식·추적기간을 먼저 맞춥니다.

## 일본 의사·연구진의 캄포 연구 {#japan-kampo}

일본에서는 전통 처방을 **Kampo(캄포·일본 한방)** 의료용 제제로 사용하면서 소화기 증상, 만성질환에 동반된 허약, 수술 후 회복을 임상시험으로 평가해 왔습니다. 연구자 이름과 처방의 영문명을 함께 찾으면 원 논문에 접근하기 쉽습니다. 아래 소속은 해당 논문의 표기 기준입니다.

### Tominaga 연구진: 육군자탕과 식후 불편 {#rikkunshito}

**K. Tominaga — 오사카의과대학 내과 등, DREAM 연구(2018).** 일본 56개 병원에서 모집한 기능성소화불량 환자 중 2주 위약 준비기간에도 증상이 남은 **128명을 무작위배정**해 8주간 육군자탕(Rikkunshito)과 위약을 비교했습니다. 전체 치료효과 평가가 개선됐고(P=0.019), 조기포만·식후포만·팽만에서도 차이가 확인됐습니다. 헬리코박터 음성 등의 모집 조건이 있습니다. [원 논문](https://doi.org/10.1111/nmo.13319) · [PMID 29498457](https://pubmed.ncbi.nlm.nih.gov/29498457/)

이는 ‘먹는 양을 늘리라’는 조언만으로 해결되지 않는 식후 불편을 구체적 치료 목표로 평가한 사례입니다. 앞선 Suzuki 연구와 일본소화기학회의 권고까지 함께 읽으려면 [육군자탕의 일본 RCT·지침](formulas/rikkunshito.md#japanese-fd-trials)으로 이어집니다. 그렐린 기전 연구와 실제 증상 개선은 별도 자료입니다.

### Hirai·Ohbayashi 연구진: 인삼양영탕과 COPD의 허약 {#ninjinyoeito}

| 연구자·연구 | 설계와 대상 | 무엇을 확인했는가 |
|---|---|---|
| Hirai 등, 2020 | 65세 이상 노쇠·전노쇠 COPD 환자 68명 배정·62명 분석, 24주 공개 무작위시험 | 식욕·COPD 건강상태·불안·우울 지표 개선. 노쇠 체크리스트의 군 간 차이는 유의하지 않음. [논문](https://pubmed.ncbi.nlm.nih.gov/32551796/) |
| Hiroyuki Ohbayashi — 기후현 Tohno Chuo Clinic 등, 2024 | 안정적 COPD와 피로, 53명 완료·분석. 즉시 복용과 12주 지연 복용 비교 | 처음 12주에 피로와 무릎 폄 근력 개선 차이. 보행속도 차이는 유의하지 않음. [논문](https://doi.org/10.2147/COPD.S441767) · [PMID 38737191](https://pubmed.ncbi.nlm.nih.gov/38737191/) |

**인삼양영탕(Ninjin'yoeito)** 연구는 ‘기력을 보한다’는 설명을 식욕·피로·근력·보행으로 나누어 측정합니다. COPD 표준치료에 동반된 허약을 다룬 공개시험이며, 건강한 고령자의 일반적 노화 예방이나 모든 근감소증에 대한 결과로 옮기지 않습니다. 2024년 시험의 후반에는 두 군 모두 복용하므로 계속 미복용군과 비교한 효과가 아닙니다. [제제·안전성·연구 상세](../formulas/renshen-yangrong-tang.md#frailty-trials) · [근감소증·노쇠](../conditions/frailty-sarcopenia.md)

### Shimada 연구진: 대건중탕과 간절제 뒤 장기능 {#daikenchuto}

**Mitsuo Shimada 등, 일본 26개 기관의 3상 시험**은 간절제 환자 231명 등록, **209명 분석**으로 대건중탕(Daikenchuto, TU-100)과 위약을 비교했습니다. 발관 후 첫 배변 중앙값은 **88.2시간 대 93.1시간**이었습니다. 다른 주평가인 염증·암모니아 지표에는 차이가 없었습니다. 2014년 온라인 공개, 2015년 권호 논문입니다. [원 논문](https://doi.org/10.1007/s10147-014-0678-2) · [PMID 24595550](https://pubmed.ncbi.nlm.nih.gov/24595550/)

고전 처방을 현대 외과의 회복 과정에 병행하여 비교한 사례입니다. 첫 배변이 빨라지는 결과를 입원기간 단축·암 치료·생존 개선으로 확대하지 않습니다. [대건중탕 간절제 시험](../formulas/dajianzhong-tang.md#japanese-hepatectomy-trial)에서 제제와 투여 조건을, [간이식 시험](../formulas/dajianzhong-tang.md#japanese-transplant-trial)에서 다른 수술의 영양 결과를 따로 확인합니다.

### 일본 연구를 국내 진료에 연결할 때 {#translation-to-care}

| 확인 항목 | 이유 |
|---|---|
| 제품·구성·추출 방식 | 이름이 같아도 국내 수록본·탕약·가감방과 연구 제품이 다를 수 있음 |
| 원약재와 엑스제 중량 | 시험제제의 g을 탕약 원약재 g으로 직접 환산할 수 없음 |
| 기존 치료와 병용 조건 | COPD·수술 후 시험은 담당팀의 표준치료 안에서 시행 |
| 주평가와 부평가 | 일부 증상 개선을 시험 전체의 성공으로 확대하지 않기 위함 |
| 눈가림·준비기간·연구 지원 | 기대 효과, 모집된 대상, 이해관계가 해석에 영향을 줌 |

감초 함유 처방을 겹쳐 오래 복용한다면 부종·혈압·칼륨과 병용약을 확인합니다. 수술 후에는 복통·구토·가스와 대변 정지 등 원인 평가가 필요한 상태를 먼저 살핍니다. 자세한 사용 조건은 각 처방의 안전성 절에 연결했습니다.
