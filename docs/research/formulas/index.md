# 한약 처방 임상근거 허브

한약 처방은 여러 본초가 하나의 배합 원리 안에서 작용하는 복합치료다. 현대 연구에서는 전통적인 처방을 **무작위 임상시험(RCT), systematic review, meta-analysis**를 통해 평가하는 연구가 꾸준히 늘고 있다.

| 처방 | 대표 현대 연구 영역 | 현재 연구 축적 |
|---|---|---|
| [공진단](gongjin-dan.md) | 만성피로·급성피로 | 사람 대상 RCT 축적 |
| [경옥고](gyeongok-go.md) | 피로·운동능력·삶의 질 | RCT·체계적 고찰 |
| [십전대보탕](sipjeondaebo-tang.md) | 암 관련 피로·식욕·삶의 질 | systematic review/meta-analysis |
| [생맥산](shengmai-san.md) | 심혈관·바이러스성 심근염 | 다수 RCT 메타분석 |
| [육군자탕](rikkunshito.md) | 기능성 소화불량·상부위장관 | RCT·메타분석 |
| [귀비탕](guibi-tang.md) | 불면·정서증상 | RCT systematic review |
| [보중익기탕](buzhong-yiqi-tang.md) | COPD·기능성 변비 등 | 다수 RCT 메타분석 |
| [독활기생탕](duhuo-jisheng-tang.md) | 골관절·요추·류마티스 영역 | 다수 RCT 메타분석 |

## 연구를 읽는 방법
한약 연구에서는 동일 처방명이라도 **가감 여부, 제형, 용량, 병용치료**가 다를 수 있다. 이 아카이브에서는 긍정적인 임상결과를 충분히 소개하되, 어떤 처방과 어떤 비교군을 사용했는지 구분해서 기록한다.

→ [한약·처방 임상근거 허브](../../authority/formulas/herbal-formula-evidence-hub.md)

## 처방별 현대 연구 빠르게 보기

전통 처방의 현대 연구는 **오랜 임상 활용을 현대적인 평가변수로 다시 살펴보고, 임상적 가능성과 작용 기전을 구체화해 가는 과정**입니다. 연구 규모와 설계에는 차이가 있지만 여러 처방에서 긍정적인 가능성을 탐색하는 연구가 꾸준히 축적되고 있습니다.

> 연구의 제한점은 기존 연구를 부정하는 결론이라기보다 **현재 확인된 가능성을 어디까지 해석할 수 있는지 보여주는 경계**로 읽습니다.
