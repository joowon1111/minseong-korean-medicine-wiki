# 사이트 검색 안내 {#_1}

상단 검색창에서는 **일상적인 증상 표현과 한의학 전문용어를 함께 검색**할 수 있습니다. 정확한 병명이나 처방명을 몰라도 지금 불편한 증상을 그대로 입력해 보세요.

## 검색창 이용하기 {#_2}

검색창에 한 단어 또는 짧은 표현을 입력하면 문서 제목·주요 검색어·본문을 바탕으로 관련 문서를 우선 표시합니다.

| 찾고 싶은 내용 | 검색어 예시 |
|---|---|
| 증상을 일상 표현으로 찾기 | `잠이 안 와요`, `허리가 아파요`, `체했어요`, `코가 막혀요` |
| 증상·질환명으로 찾기 | `불면`, `요통`, `소화불량`, `비염` |
| 본초·방제 찾기 | `녹용`, `인삼`, `공진단`, `보중익기탕` |
| 경혈 찾기 | `신문`, `HT7`, `신문 HT7` |
| 고전·사상의학 찾기 | `상한론`, `동의보감`, `소음인` |
| 현대 연구 찾기 | `무작위 임상시험`, `메타분석`, `PMID`, `DOI` |

제목과 잘 맞는 문서를 우선 찾고, 관련 증상 표현·태그·본문도 함께 검색합니다. 검색 순서는 내용을 찾기 위한 안내이며, 치료의 효과나 개인에게 맞는 처방의 순위를 뜻하지 않습니다.

## 검색 결과에서 문서 찾기 {#_3}

검색 결과에는 관련성이 높은 문서가 우선 표시됩니다. 제목 아래의 요약을 함께 읽으면 원하는 증상·질환·치료 문서인지 빠르게 구분할 수 있습니다.

결과가 너무 많을 때는 검색어를 조금 더 구체적으로 입력해 보세요.

- `통증` → `발목통증`, `손목통증`, `턱관절통증`
- `잠` → `잠이 안 와요`, `자주 깨요`
- `소화` → `식후 더부룩함`, `명치가 답답해요`
- `저림` → `손이 저려요`, `다리가 저려요`

## 검색 결과 강조와 공유 {#_4}

검색 결과에서 원하는 문서를 연 뒤 **목차의 제목을 누르면 해당 부분으로 이동**할 수 있습니다. 본문에서 단어를 바로 찾고 싶다면 컴퓨터의 `Ctrl+F` 또는 `⌘+F`, 모바일 브라우저의 ‘페이지에서 찾기’를 이용하세요. 검색어 강조와 검색 결과 공유 기능의 표시 여부는 검색 화면에 따라 다를 수 있습니다.

다른 사람에게 자료를 전달할 때는 **문서를 연 뒤 주소창의 URL을 복사**하면 됩니다. 특정 문단을 공유하려면 제목 옆 `¶` 링크의 주소를 복사하세요. 검색어를 다시 입력하지 않아도 같은 설명으로 바로 이동할 수 있습니다.

## 원하는 결과가 없을 때 {#_5}

표현을 짧게 바꾸거나 비슷한 말로 다시 검색해 보세요. 정확한 진단명을 모르는 경우에는 증상 중심 탐색이 더 편리합니다.

- [증상으로 찾기](symptom-integrated/index.md)
- [질환별 보기](conditions/index.md)
- [태그 지식 색인](tags.md)
- [전체 지식지도](portal/maps.md)

검색 결과만으로 증상의 원인이나 치료를 단정하지 말고, 각 문서의 위험신호·감별·치료 안내를 함께 확인하세요.
