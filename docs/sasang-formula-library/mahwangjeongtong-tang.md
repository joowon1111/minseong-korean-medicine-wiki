# 마황정통탕(麻黃定痛湯) 임상 카드

마황정통탕은 『동의사상신편』에 태음인의 **흉복통** 맥락으로 수록된 처방입니다. 이름의 ‘정통’을 모든 통증에 쓰는 뜻으로 넓히지 않고, 태음인 위완수한표한병의 오한·발한불리·비위 담습과 흉복부 불편이 함께 나타나는지 살핍니다.

## 한눈에 보기

| 항목 | 핵심 |
|---|---|
| 체질·병증 | 태음인 위완수한표한병 방향 |
| 핵심 단서 | 흉복부 통증·답답함, 오한·무한, 몸의 무거움, 담·호흡 변화 |
| 배합 특징 | 마황·길경·행인의 선폐축 + 건율·의이인·나복자의 비위·담습축 |
| 가까운 비교 | 태음조위탕·조위승청탕·행인승청탕 |
| 출전 | 『동의사상신편』(1929), 한국전통지식포탈 P0018567 |

## 먼저 배제할 흉복통

흉통은 운동과의 관계, 호흡곤란·식은땀·방사통을 확인하고, 복통은 위치·지속시간·압통·구토·출혈·발열을 평가합니다. 급성관상동맥증후군, 폐색전증, 대동맥질환, 급성복증과 담낭·췌장 질환이 의심되면 체질처방보다 응급평가가 우선입니다.

## 구성·용량과 배합

| 구성축 | 본초·용량 | 읽는 관점 |
|---|---|---|
| 비위·담습 | 건율 7개, 의이인 11.25 g, 나복자 7.5 g | 복만·무거움·담습의 동반 양상 |
| 선폐·통표 | 마황 7.5 g, 길경·행인 각 3.75 g | 표한·호흡과 흉부 불편 |
| 보폐·회복 | 맥문동·오미자 각 3.75 g | 호흡·진액·회복 |
| 심신·수면 | 백자인·산조인·용안육·석창포 각 3.75 g | 흉민과 수면·긴장·회복의 동반 변화 |

건율은 수록 자료에 g이 아니라 **7개**로 표시되어 그대로 보존합니다. 이 수치를 임의로 중량 환산하지 않으며, 원전 수록본·제형·가감을 구별합니다.

## 가까운 처방과 감별

| 처방 | 갈림점 |
|---|---|
| **마황정통탕** | 흉복통과 표한·호흡·담습축이 함께 나타남 |
| [태음조위탕](../sasang-formula-cards/taeeumjowi-tang.md) | 식후비만·몸의 무거움·오한·무한이 중심 |
| [조위승청탕](../sasang-formula-cards/jowiseungcheong-tang.md) | 중소·하지무력과 오래된 승청 저하가 중심 |
| [행인승청탕](haenginseungcheong-tang.md) | 기침·담과 폐원 기능, 수면·회복 단서가 더 두드러짐 |

## 경과관찰과 안전

흉복통의 위치·강도·지속시간과 식사·호흡·운동의 관계, 땀, 식욕·복만, 대변, 기침·가래와 수면을 기록합니다. 마황 함유 처방은 두근거림·불면·혈압과 심혈관질환, 갑상선질환, 교감신경 자극 약물 복용을 확인합니다. 통증 감소만으로 중대한 흉복부 질환이 배제됐다고 판단하지 않습니다.

## 근거의 범위와 이어서 보기

전통 문헌의 흉복통 수록은 현대의 특정 흉통·복통 질환에 대한 효과 근거와 동일하지 않습니다. 연구를 연결할 때에는 실제 구성, 진단, 비교군과 통증·기능 결과를 확인합니다.
