# 형방도백산(荊防導白散)

## 구성 본초·용량
| 본초 | 용량 |
|---|---:|
| 강활 | 3.75 g |
| 방풍 | 3.75 g |
| 복령 | 7.5 g |
| 생지황 | 11.25 g |
| 석고 | 3.75 g |
| 지모 | 3.75 g |
| 택사 | 7.5 g |
| 형개 | 3.75 g |

## 출전
소양인. 『동의사상신편』(1929). 한국전통지식포탈 P0018328.

## 조제·주치
두통·번조·소양인망음·소양증·방광통 등에 쓰는 것으로 수록. 포탈 조제법은 약재를 가루내어 사용.

## 기록 원칙
한국전통지식포탈에 표시된 단위와 수치를 그대로 기록한다. 출전별 동명 처방의 구성이 다를 경우 별도 처방으로 구분하며, 표시되지 않은 용량은 임의로 보충하지 않는다.
