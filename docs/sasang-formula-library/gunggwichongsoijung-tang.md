# 궁귀총소이중탕(芎歸葱蘇理中湯)

## 체질·주치
**소음인** 처방으로 건곽란에 쓰는 것으로 수록된다.

## 구성·용량
| 본초 | 용량 |
|---|---:|
| 인삼 | 11.25 g |
| 건강(구움) | 7.5 g |
| 관계 | 7.5 g |
| 백출 | 7.5 g |
| 백작약 | 3.75 g |
| 자감초 | 3.75 g |
| 진피 | 3.75 g |
| 포부자 | 3.75–7.5 g |

## 출전
『동의사상신편』(1929), 소음인. 한국전통지식포탈 **P0018165**.

## 조제
약재를 썰어 물에 달여 복용.
