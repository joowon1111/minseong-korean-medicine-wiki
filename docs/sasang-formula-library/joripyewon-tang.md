# 조리폐원탕(調理肺元湯) 임상 카드

조리폐원탕은 『동의사상신편』에 태음인 병에 응용하는 처방으로 수록되며, 주치에 **병후체허**가 제시됩니다. 질환명보다 급성기가 지난 뒤 남은 기침·호흡불편, 식욕·체력과 땀·진액 회복이 태음인의 병증 구조 안에서 함께 나타나는지 봅니다.

## 한눈에 보기

| 항목 | 핵심 |
|---|---|
| 체질·병증 | 태음인, 병후체허와 폐원 회복을 살피는 맥락 |
| 핵심 단서 | 회복기 기침·호흡불편, 피로, 식욕·활동 저하, 진액과 땀의 변화 |
| 구성 특징 | 길경·마황의 선폐, 맥문동의 진액, 의이인·나복자의 비위·담습, 황금의 열 조절 |
| 가까운 비교 | 행인승청탕·태음조위탕·열다한소탕 |
| 출전 | 『동의사상신편』(1929), 한국전통지식포탈 P0018577 |

## 적용 전 평가

- 원질환의 진단과 치료가 끝났는지, 발열·저산소증·진행성 호흡곤란이 남아 있지 않은지 확인합니다.
- 발병 전 땀·호흡·소화·대변과 현재 체중·식사량·운동능력을 비교합니다.
- 빈혈, 심폐질환, 감염 후 증후군, 약물 부작용과 영양 부족을 감별합니다.
- 체허라는 말만으로 보약처럼 선택하지 않고 현재 표한·리열과 담습·건조의 방향을 확인합니다.

## 구성·용량

| 본초 | 용량 | 배합에서 읽는 역할 |
|---|---:|---|
| 길경·맥문동·의이인 | 각 7.5 g | 폐기 선통, 진액, 비위·담습의 회복축 |
| 나복자·마황·황금 | 각 3.75 g | 담·기역, 표부·호흡, 남은 열성 양상을 조절 |

**총량 33.75 g.** 약재를 썰어 물에 달이는 것으로 수록되어 있습니다. 병후 상태에서는 원방·가감방, 제형, 식사·수분·재활계획을 함께 기록합니다.

## 가까운 처방과 감별

| 처방 | 갈림점 |
|---|---|
| **조리폐원탕** | 급성기 뒤 폐원·진액·체력 회복을 간결한 배합으로 살핌 |
| [행인승청탕](haenginseungcheong-tang.md) | 승청 저하와 기침·담, 수면·회복 단서가 함께 큼 |
| [태음조위탕](../sasang-formula-cards/taeeumjowi-tang.md) | 식후비만·몸의 무거움·표한·담습이 전면에 있음 |
| [열다한소탕](../sasang-formula-cards/yeoldahanso-tang.md) | 갈증·다한·건조와 간수열리열의 전신 열증이 중심 |

## 경과관찰과 안전

체온, 산소포화도와 호흡곤란, 기침·가래, 한 끼 섭취량, 체중, 땀 뒤 느낌, 수면, 걷는 거리와 다음날 피로를 기록합니다. 마황이 포함되므로 혈압·심박수와 두근거림·불면을 확인합니다. 새 발열, 객혈, 흉통, 산소포화도 저하, 빠른 체중감소는 원질환 재평가가 우선입니다.

## 근거의 범위와 이어서 보기

‘병후체허’라는 전통 수록 문구는 특정 감염 후 상태나 만성폐질환의 임상효과를 확정하지 않습니다. 현대 연구는 질환, 회복 시점, 실제 제제와 기능 결과를 구분해 읽습니다.
