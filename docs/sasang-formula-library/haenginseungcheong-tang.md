# 행인승청탕(杏仁升淸湯) 임상 카드

행인승청탕은 태음인 **위완수한표한병의 승청 저하와 폐원 기능**을 함께 살피는 처방입니다. 『동의사상신편』에는 조위승청탕의 증상과 임산부 기침에 쓰는 것으로 수록되어 있지만, 임신 중 기침이라는 조건만으로 자동 선택하지 않고 체질병증·호흡상태·산과적 안전성을 함께 평가합니다.

## 한눈에 보기

| 항목 | 핵심 |
|---|---|
| 체질·병증 | 태음인 위완수한표한병, 승청 저하·폐원 기능 |
| 핵심 단서 | 식후 그득함·몸의 무거움, 기침·담·호흡, 피로와 회복 지연 |
| 배합 특징 | 태음조위탕계 비위·담습축에 행인과 안신·보폐 약재를 더한 구조 |
| 가까운 비교 | 조위승청탕·태음조위탕·조리폐원탕 |
| 출전 | 『동의사상신편』(1929), 한국전통지식포탈 P0018564 |

## 적용 소증과 병증 단계

- 발병 전부터 식후 더부룩함, 몸의 무거움, 담·기침과 피로가 반복됐는지 봅니다.
- 현재 오한·발한불리 같은 표한과 기침·호흡불편, 식욕·부종이 한 병증축으로 모이는지 확인합니다.
- 고열·누런 가래·흉통, 천식 악화, 폐렴·심부전 같은 현대 질환을 우선 감별합니다.
- 임신 중에는 감염·천식·위식도역류와 임신 주수, 다른 약물·한약 복용을 함께 확인합니다.

## 구성·용량과 배합

| 구성축 | 본초·용량 | 읽는 관점 |
|---|---|---|
| 비위·담습 | 건율·의이인 각 11.25 g, 나복자 5.625 g | 식후 그득함·담습과 중초 기능 |
| 선폐·강기 | 길경·마황·행인 각 3.75 g | 기침·담·호흡과 폐기의 승강 |
| 보폐·진액 | 맥문동·천문동·오미자 각 3.75 g | 건조·진액과 호흡 회복 |
| 수면·회복 | 산조인·용안육·원지·석창포 각 3.75 g | 수면·심번·회복의 동반 양상 |

약재를 썰어 물에 달이는 것으로 수록됩니다. 마황이 포함되므로 원방·가감방, 제형과 실제 투여량을 구분해 기록합니다.

## 경과관찰과 안전

기침 빈도·야간각성, 가래, 호흡곤란, 식사량·복만, 땀 뒤 느낌, 부종, 수면과 활동 회복을 기록합니다. 마황 함유 처방은 혈압·심박수, 두근거림·불면과 교감신경 자극 약물 병용을 확인합니다. 임신 중 사용은 산모·태아 상태와 임신 주수를 확인한 한의사의 개별 판단이 필요하며, 문헌 수록만으로 임신 중 안전성이 확립된 것은 아닙니다.
