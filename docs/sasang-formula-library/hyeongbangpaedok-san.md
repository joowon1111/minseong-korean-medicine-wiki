# 형방패독산(荊防敗毒散) 임상 카드

형방패독산은 소양인 **비수한표한병의 소양상풍·표병군**에서 두통과 한열왕래, 몸살이 비교적 앞서는 때 살피는 처방입니다. 처방명에 패독산이 들어가지만 일반 감염병이나 감기라는 현대 질환명만으로 선택하지 않고, 발병 전 소증과 현재 표병의 증후 묶음을 확인합니다.

## 한눈에 보기

| 항목 | 핵심 |
|---|---|
| 체질·병증 | 소양인 비수한표한병, 소양상풍·표병 방향 |
| 핵심 단서 | 두통, 한열왕래, 신체통, 흉협 불편과 배설 변화 |
| 치법을 읽는 축 | 형개·방풍·강활·독활의 표병축 + 생지황·복령·차전자의 진액·배설축 |
| 가까운 비교 | 형방도적산·형방사백산·형방지황탕 |
| 출전 | 『동의사상신편』(1929), 한국전통지식포탈 P0018325 |

## 적용 맥락과 병증 단계

- 소양인 판단 근거가 있고 발병 뒤 두통·몸살·한열 변화가 전면에 나타납니다.
- 흉협·흉격 불편, 입마름, 소변·대변 변화가 동반되는지 확인합니다.
- 지속 설사·탈수·심한 복통과 기력저하가 중심인 망음 방향이나, 상열·번조·변비가 중심인 리열 방향과 구분합니다.
- 고열의 원인, 호흡기 감염, 수막자극증상과 다른 급성 질환을 먼저 배제합니다.

## 구성·용량과 배합

| 본초 | 용량 | 처방 안에서 읽는 역할 |
|---|---:|---|
| 강활·독활·방풍·형개 | 각 3.75 g | 두통·신체통과 표병의 울체를 푸는 축 |
| 생지황 | 3.75 g | 열과 진액 변화를 함께 살핌 |
| 시호·전호 | 각 3.75 g | 한열왕래·흉협 및 담·기역의 동반 양상 |
| 적복령·차전자 | 각 3.75 g | 소변과 수분대사의 변화를 받침 |

**총량 33.75 g.** 수록본은 약재를 가루 내어 사용하는 조제법을 제시합니다. 실제 사용에서는 원전 수록본·제형·복용량·가감 여부를 구분해 기록하며, 이 환산량을 자가조제 기준으로 사용하지 않습니다.

## 가까운 처방과 감별

| 처방 | 갈림점 |
|---|---|
| **형방패독산** | 두통·한열왕래·신체통 등 비교적 얕은 소양상풍의 표병축 |
| [형방도적산](../sasang-formula-cards/hyeongbangdojeok-san.md) | 흉격 답답함·구갈과 대소변 변화가 더 뚜렷한 표병 |
| [형방사백산](../sasang-formula-cards/hyeongbangsabaek-san.md) | 신열·두통·번조와 열·수분대사 변화가 심화된 방향 |
| [형방지황탕](../sasang-formula-cards/hyeongbangjihwang-tang.md) | 복통·설사와 진액 소모가 중심인 망음 방향 |

## 복용 뒤 경과관찰

체온과 두통만 보지 않고 한열왕래의 빈도, 신체통, 흉격·흉협 불편, 식욕, 갈증, 대변·소변, 수면과 활동 회복을 같은 간격으로 기록합니다. 표증은 줄지만 설사·구갈·쇠약이 커지면 망음 또는 다른 병증으로의 전환을 다시 평가합니다.

## 안전과 근거의 범위

호흡곤란, 의식 변화, 목 경직, 지속 고열, 반복 구토·설사와 소변량 감소는 신속한 의학적 평가가 우선입니다. 형방패독산의 문헌 수록과 병증 분류는 특정 현대 감염질환에 대한 임상효과를 곧바로 입증하지 않습니다. 현대 자료를 읽을 때에는 실제 처방 구성, 체질·병증 기준, 병행치료와 결과지표를 확인합니다.
