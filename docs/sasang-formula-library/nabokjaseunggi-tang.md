# 나복자승기탕(蘿菔子承氣湯)

## 구성 본초·용량
| 본초 | 용량 |
|---|---:|
| 갈근 | 15 g |
| 길경 | 3.75 g |
| 나복자 | 7.5 g |
| 대황 | 7.5 g |
| 백지 | 3.75 g |
| 승마 | 3.75 g |
| 황금 | 7.5 g |

## 출전
태음인. 『동의사상신편』(1929). 한국전통지식포탈 P0018576.

## 조제·주치
소화장애·식체에 쓰는 것으로 수록. 관련 병증으로 담성·발광·비기 등이 제시됨. 물에 달여 복용.

## 기록 원칙
한국전통지식포탈에 표시된 단위와 수치를 그대로 기록한다. 출전별 동명 처방의 구성이 다를 경우 별도 처방으로 구분하며, 표시되지 않은 용량은 임의로 보충하지 않는다.
