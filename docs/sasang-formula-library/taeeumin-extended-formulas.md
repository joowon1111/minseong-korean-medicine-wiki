# 태음인 처방 상세 — 표한·승청·리열

태음인 처방은 **위완수한표한·승청 저하 ↔ 간수열리열·대변 정체**의 축에서 비교합니다. 후대 경험방은 원전 처방과 근거 층을 구분하고, 체중·부종·변비 같은 한 증상만으로 선택하지 않습니다. 전체 처방의 병증 위치는 [태음인 한약처방](../sasang-formula-cards/index.md#taeeumin-formulas)에서 함께 볼 수 있습니다.

| 병증축 | 비교 처방 | 먼저 가르는 단서 |
|---|---|---|
| 표한·조위 | [승지조위탕](#taeeum-seungjijowi) | 무한·발한불리, 산증, 식후 복만과 몸의 무거움 |
| 승청·폐조 | [경험승청탕](#taeeum-gyeongheomseungcheong) | 호흡·건조·병후 회복, 수면·심신 증후 |
| 리열·승기 | [갈근승기탕](#taeeum-galgeunseunggi) · [나복자승기탕](#taeeum-nabokjaseunggi) | 열·구갈 중심인지 식체·복만 중심인지, 급성 복증 여부 |

## 승지조위탕(升芷調胃湯) {#taeeum-seungjijowi}

| 항목 | 임상적으로 읽는 범위 |
|---|---|
| 적용 소증·병증 단계 | 태음인 위완수한표한병에서 평소 발한·소화·호흡을 기준으로, 후대 자료가 ‘무한·산증’으로 기록한 표한·조위 방향을 봅니다. |
| 핵심 증후 | 무한·발한불리, 오한·몸의 무거움, 식후 복만과 산증 맥락. |
| 감별 처방 | 담습·식후 불편의 기본 축은 [태음조위탕](../sasang-formula-cards/taeeumjowi-tang.md), 중소·하지무력 등 승청 저하는 [조위승청탕](../sasang-formula-cards/jowiseungcheong-tang.md), 통증이 전면에 서면 [마황정통탕](mahwangjeongtong-tang.md)을 비교합니다. |
| 구성·법제 | 건율·의이인 각 11.25 g, 나복자 7.5 g, 길경·마황·맥문동·석창포·오미자 각 3.75 g, 백지·승마는 원자료 개별 g 미표시. 절단 후 탕전 기록입니다. |
| 복용·관찰 | 발한 여부와 땀 뒤 느낌, 식후 복만, 통증, 호흡, 대변·소변과 수면을 기록합니다. |
| 주의사항 | 마황 함유 처방은 혈압·맥박, 심계·불면, 갑상선질환, 임신·수유와 교감신경 자극 약물 병용을 확인합니다. 급성 고환·서혜부 통증은 산증으로만 보지 않습니다. |
| 근거와 한계 | 『동의사상신편』(1929), 한국전통지식포탈 P0018555의 기록이며 백지·승마 용량을 임의 보충하지 않습니다. 현대 질환별 임상효과 근거는 제한적입니다. |

## 경험승청탕(經驗升淸湯) {#taeeum-gyeongheomseungcheong}

| 항목 | 임상적으로 읽는 범위 |
|---|---|
| 적용 소증·병증 단계 | 태음인 조위승청탕 계열의 후대 경험방으로, 위완수한표한병에서 승청 저하와 폐조·병후 회복 지연을 비교합니다. |
| 핵심 증후 | 식후 불편·기력저하와 함께 호흡·건조, 수면·심계·회복 지연이 어떤 조합으로 나타나는지 봅니다. |
| 감별 처방 | 식후비만·중소·하지무력이 중심이면 [조위승청탕](../sasang-formula-cards/jowiseungcheong-tang.md), 기침·호흡과 폐원 회복이 중심이면 [조리폐원탕](joripyewon-tang.md), 행인 배합의 승청 방향은 [행인승청탕](haenginseungcheong-tang.md)을 비교합니다. |
| 구성·법제 | 건율 11.25 g, 해송자 7.5 g, 길경·마황·맥문동·산조인·석창포·오미자·용안육·원지·천문동 각 3.75 g. 실제 제형과 용량은 별도 확인합니다. |
| 복용·관찰 | 식사량·식후 불편, 호흡·기침, 발한 뒤 반응, 수면·심계, 활동과 회복 시간을 기록합니다. |
| 주의사항 | 호흡곤란·흉통·실신, 저산소증, 빠른 체중감소는 폐·심혈관 평가가 우선입니다. 마황과 원지·산조인 등 병용 시 복용약과 수면 변화를 함께 봅니다. |
| 근거와 한계 | 『동의사상신편』(1929), 한국전통지식포탈 P0018563의 **후대 경험방**입니다. 조위승청탕과 동일 처방으로 취급하거나 독립 임상효과를 단정하지 않습니다. |

## 갈근승기탕(葛根承氣湯) {#taeeum-galgeunseunggi}

| 항목 | 임상적으로 읽는 범위 |
|---|---|
| 적용 소증·병증 단계 | 태음인 간수열리열병에서 후대 자료가 간열·온병·대변불통으로 기록한 승기 방향을 봅니다. 평소 대변과 급성 변폐를 구분합니다. |
| 핵심 증후 | 열감·구갈·두면부 열증과 복만·변폐의 동반. |
| 감별 처방 | 간열·폐조의 전반은 [열다한소탕](../sasang-formula-cards/yeoldahanso-tang.md), 강한 리열·조열은 [청폐사간탕](../sasang-formula-cards/cheongpyesagan-tang.md), 식체·복만의 비중이 크면 [나복자승기탕](#taeeum-nabokjaseunggi), 양독·인후·피부 증후는 [갈근해기탕](galgeunhaegi-tang.md)을 비교합니다. |
| 구성·법제 | 갈근 15 g, 대황·황금 각 7.5 g, 길경·백지·승마 각 3.75 g. 절단 후 탕전 기록입니다. |
| 복용·관찰 | 대변 횟수·형태, 복만·복통, 열·갈증, 수분 섭취·소변, 기력과 어지럼을 짧은 간격으로 봅니다. |
| 주의사항 | 대황 함유 처방은 설사·복통·탈수, 항응고제 등 병용약, 임신·수유를 확인합니다. 가스·대변이 모두 끊기고 구토·복부팽만이 심하면 장폐색 평가가 우선입니다. |
| 근거와 한계 | 『동의사상신편』(1929), 한국전통지식포탈 P0018574의 구성·주치 기록입니다. ‘온병’을 현대 감염병 진단이나 해열 효능과 일대일로 해석하지 않습니다. |

## 나복자승기탕(蘿菔子承氣湯) {#taeeum-nabokjaseunggi}

| 항목 | 임상적으로 읽는 범위 |
|---|---|
| 적용 소증·병증 단계 | 태음인 리열 축에서 후대 자료가 소화장애·식체와 대변 정체로 기록한 경우를 살핍니다. |
| 핵심 증후 | 식후 복만·식체, 대변불통과 번조·열증의 조합. ‘담성·발광·비기’ 표기는 현대 정신질환명과 동일하지 않습니다. |
| 감별 처방 | 열·구갈·변폐가 앞서면 [갈근승기탕](#taeeum-galgeunseunggi)·청폐사간탕, 표한·담습과 식후 무거움이면 [태음조위탕](../sasang-formula-cards/taeeumjowi-tang.md), 단순 기능성 소화불량은 별도 원인·변증 평가를 합니다. |
| 구성·법제 | 갈근 15 g, 나복자·대황·황금 각 7.5 g, 길경·백지·승마 각 3.75 g. 절단 후 탕전 기록입니다. |
| 복용·관찰 | 식사량·식후 팽만, 배변과 복통, 구역·구토, 갈증·소변, 의식·행동 변화를 기록합니다. |
| 주의사항 | 심한 복통·반발통, 반복 구토, 혈변·검은변, 의식·행동의 급격한 변화는 급성 복증·대사·신경정신과 평가가 우선입니다. 대황 관련 주의는 갈근승기탕과 같습니다. |
| 근거와 한계 | 『동의사상신편』(1929), 한국전통지식포탈 P0018576의 기록입니다. 고전 병명과 현대 질환명을 직접 대응하거나 정신증상 치료효과를 주장하지 않습니다. |

## 공통 재평가와 근거 읽기

발한의 양보다 **땀 뒤 개운함**, 소화·대변, 호흡, 수면, 활동 회복을 함께 기록합니다. 한 증상만 좋아지고 심계·불면·설사·탈진이 새로 생기면 처방군과 용량·병용약을 다시 평가합니다.

- 이 문서의 네 처방은 후대 자료에 기록된 처방이며, 원전 처방과 출전·병증 맥락을 구분해 읽습니다.
