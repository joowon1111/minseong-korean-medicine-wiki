# 갈근해기탕(葛根解肌湯)

갈근해기탕은 태음인의 **간수열리열병에서 양독 양상**을 살피는 처방입니다. 얼굴과 피부에 열성 변화가 나타나고 인후가 붓거나 아프며, 열감·갈증·두면부 증상이 함께 이어지는지를 봅니다. ‘갈근이 든 감기 처방’으로 단순화하지 않고 태음인의 평소 땀·호흡·소화·대변과 현재의 리열 변화를 함께 판단합니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 체질·병증 | 태음인 간수열리열병, 양독증 계열 |
| 핵심 치법 | 해기청열·청리인후·선폐 |
| 대표 단서 | 얼굴·피부의 열성 변화, 인후종통, 번열·갈증, 두면부 열감 |
| 수록 구성 | 갈근·승마·행인·황금·길경·대황·백지·산조인(초) |
| 가까운 비교 | 열다한소탕·청폐사간탕·갈근승기탕 |
| 대표 출전 | 《동의사상신편》(1929), 한국전통지식포탈 P0018561 |

## 구성과 배합 구조

| 구성축 | 본초 | 처방 안에서 읽는 역할 |
|---|---|---|
| 해기·승산 | [갈근](../herbs/pueraria.md)·승마·백지 | 두면·기육에 뭉친 열과 표리 사이의 울체를 풀어 줌 |
| 청열 | 황금·대황 | 안팎의 열과 장부의 울체를 조절 |
| 선폐·이인 | [행인](../herbs/apricot-kernel.md)·[길경](../herbs/platycodon.md) | 폐기의 승강과 인후·호흡 증상을 함께 살핌 |
| 완급·안정 | 산조인(볶음) | 열성 불편에 동반되는 번조와 수면 변화를 받침 |

한국전통지식포탈 수록량은 갈근 11.25g, 승마 7.5g, 행인·황금 각 5.625g, 길경·대황·백지·산조인(초) 각 3.75g으로 총 45g입니다. 고전 용량은 수록본의 처방 비율을 이해하는 자료이며 실제 탕약·과립제는 제형과 가감에 따라 달라집니다.

## 임상에서 먼저 보는 단서

| 관찰 영역 | 확인할 내용 |
|---|---|
| 얼굴·피부 | 붉은 반점, 열감, 건조감 또는 양독으로 기록된 피부 변화 |
| 인후·호흡 | 목의 붓기·통증, 가래나 기침, 숨의 불편, 행인·길경 축이 필요한지 |
| 열·진액 | 번열, 갈증, 입마름, 땀의 양과 땀을 낸 뒤의 개운함 |
| 대변·복부 | 대변 정체와 복만이 리열의 강도와 함께 나타나는지 |
| 체질 소증 | 평소 땀·소화·호흡·수면과 현재 증상의 차이 |

`급성 인후·피부 위험신호 확인 → 태음인 소증과 현재 표리 판단 → 양독·리열·폐기 증상 조합 → 갈근해기탕 → 열감·인후·피부·대변·수면 재평가`

## 가까운 태음인 처방과 감별

| 처방 | 중심 병증 | 갈림점 |
|---|---|---|
| **갈근해기탕** | 양독·두면과 인후의 열성 변화 | 승마·행인·대황·산조인이 함께 구성된 해기청열 구조 |
| [열다한소탕](../sasang-formula-cards/yeoldahanso-tang.md) | 간열폐조·열다한소 | 갈증·다한·피부와 대변 건조 등 전신 리열 양상이 중심 |
| [청폐사간탕](../sasang-formula-cards/cheongpyesagan-tang.md) | 리열과 변비·복만 | 열다한소탕 골격에 대황이 더해져 장부 열과 대변 정체를 중점 비교 |
| [갈근승기탕](galgeunseunggi-tang.md) | 갈근계 리열에 승기 필요 | 복만·변비와 공하 필요성이 더 뚜렷한지 확인 |

## 치료 경과에서 확인할 항목

- 얼굴·피부의 열감과 붉은 변화의 범위
- 인후통·연하 불편, 기침·가래와 호흡의 편안함
- 체온·갈증·구강건조·발한 양상의 변화
- 대변 횟수와 형태, 복부 팽만·통증
- 번조·수면과 일상 활동 회복

호흡곤란, 침도 삼키기 어려운 연하장애, 빠르게 번지는 발진, 의식 변화, 지속되는 고열은 신속한 의학적 평가와 함께 관리합니다. 대황이 포함되므로 설사·복통과 수분상태를 살피고, 임신·수유 및 다른 하제 복용 여부를 진료 시 확인합니다.
