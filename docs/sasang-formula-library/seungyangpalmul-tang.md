# 승양팔물탕(升陽八物湯)

## 체질·주치
**소음인**의 태양양명증을 치료하는 처방으로 수록된다.

## 구성·용량
| 본초 | 용량 |
|---|---:|
| 인삼 | 7.5 g |
| 황기 | 7.5 g |
| 관계 | 3.75 g |
| 당귀 | 3.75 g |
| 백작약 | 3.75 g |
| 백출 | 3.75 g |
| 자감초 | 3.75 g |
| 대조 | 2매 |
| 생강 | 3조각 |

## 출전
『동의사상신편』(1929), 소음인. 한국전통지식포탈 **P0018143**.

## 조제
약재를 썰어 물에 달여 복용.
