# 소음인 처방 상세 — 울광·망양·태음병

소음인 처방은 ‘몸이 차다’거나 ‘소화가 약하다’는 인상만으로 고르지 않습니다. **울광·망양의 표병 ↔ 태음병·소음병의 리한**을 나누고, 식욕·대변·땀 뒤 기력이라는 소증 기준선을 함께 봅니다. 전체 처방의 병증 위치는 [소음인 한약처방](../sasang-formula-cards/index.md#soeumin-formulas)에서 함께 볼 수 있습니다.

| 병증축 | 비교 처방 | 먼저 가르는 단서 |
|---|---|---|
| 태양증·울광 | [천궁계지탕](#soeum-cheongung-gyeji) · [향소산](#soeum-hyangso) · [궁귀향소산](#soeum-gunggwihyangso) | 오한·발열, 두통·신체통, 기체·소화와 땀 |
| 망양 | [승양익기탕](#soeum-seungyangikgi) · [승양익기부자탕](#soeum-seungyangikgi-buja) · [인삼관계부자탕](#soeum-insam-gwangye-buja) | 발한 뒤 탈진·냉감, 중증도와 부자 필요성 |
| 태음병·리한 | [계지반하생강탕](#soeum-gyeji-banha) · [궁귀총소이중탕](#soeum-gunggwichongso) | 구토·수결흉인지 급성 토사곽란·탈수인지 |
| 황달·음독·복통 | [십이미관중탕](#soeum-sibimi-gwanjung) · [관중탕](#soeum-gwanjung) | 황색 변화·부종과 간담도 평가, 배뇨·사지권태 |

## 천궁계지탕(川芎桂枝湯) {#soeum-cheongung-gyeji}

### 깊이 읽기

천궁계지탕은 소음인 **울광 초기의 표병 기준점**으로 읽습니다. 오한·발열·두통·신체통과 땀 변화를 확인하고, 발한 뒤 기력이 급격히 떨어지면 망양 처방군으로 병증이 이동하는지 봅니다. 감염성 질환의 중증도와 호흡기 위험신호는 별도로 평가합니다.

| 항목 | 임상적으로 읽는 범위 |
|---|---|
| 적용 소증·병증 단계 | 소음인 신수열표열병의 태양증·울광 초기에서 발병 전 땀·기력과 현재 오한·발열·두통·신체통을 비교합니다. |
| 핵심 증후 | 오한·발열, 두통·신체통과 땀의 변화. |
| 감별 처방 | 기체·소화불편과 외감이 겹치면 향소산·궁귀향소산, 발한 뒤 탈진이 진행하면 [승양익기탕](#soeum-seungyangikgi), 망양이 뚜렷하면 [승양팔물탕](../sasang-formula-cards/seungyangpalmul-tang.md)을 비교합니다. |
| 구성·법제 | 계지 7.5 g, 백작약·진피·천궁·감초 각 3.75 g. 실제 제형·전탕법은 확인한 판본에 따라 기록합니다. |
| 복용·관찰 | 체온·오한, 통증, 발한량과 땀 뒤 기력, 식욕·대변·수면을 봅니다. |
| 주의사항 | 고열 지속, 호흡곤란, 의식 변화·경부강직은 감염성·신경계 평가가 우선입니다. 감초 함유 처방은 부종·혈압·저칼륨 위험과 병용약을 확인합니다. |
| 근거와 한계 | 『동의사상신편』(1929), 한국전통지식포탈 P0018136의 수록 기록입니다. 일반 계지탕류나 현대 감기약과 동일하게 취급하지 않습니다. |

### 관찰 포인트

발열·오한의 시간대, 두통·신체통, 땀의 유무와 땀 뒤 기력, 식욕·대변을 함께 기록합니다. 표증이 줄어도 발한 뒤 탈진·냉감이 커지면 망양으로 진행하는지 다시 봅니다.

## 향소산(香蘇散) {#soeum-hyangso}

### 깊이 읽기

향소산은 표병에서 **기체·흉복 답답함과 식욕 변화**가 두통·오한과 함께 나타나는 방향을 비교합니다. 궁귀향소산과는 두통·신체통의 비중, 향부자팔물탕과는 급성 표병인지 만성 비위·기체인지 시간축을 가릅니다.

| 항목 | 임상적으로 읽는 범위 |
|---|---|
| 적용 소증·병증 단계 | 후대 자료가 소음인의 사시온역으로 기록한 표병 맥락에서 외감 양상과 기체·소화 변화를 함께 봅니다. |
| 핵심 증후 | 오한·발열·두통 등의 표증에 흉복부 답답함, 식욕·소화 변화가 겹치는지 확인합니다. |
| 감별 처방 | 통증과 표증이 중심이면 천궁계지탕, 천궁 배합과 두통·기혈 단서가 필요하면 [궁귀향소산](#soeum-gunggwihyangso), 만성 사려상비·허약은 [향부자팔물탕](../sasang-formula-cards/hyangbujapalmul-tang.md)을 비교합니다. |
| 구성·법제 | 향부자 11.25 g, 소엽 9.375 g, 감초·진피·창출 각 3.75 g, 대조 2매, 생강 3조각, 총백 2뿌리. 원자료는 산제로 기록합니다. |
| 복용·관찰 | 체온·오한, 두통, 식욕·복만·오심, 대변, 발한 뒤 기력과 수면을 기록합니다. |
| 주의사항 | ‘온역’을 특정 감염병으로 단정하지 않습니다. 고열·호흡곤란·탈수는 검사와 급성기 치료가 우선입니다. |
| 근거와 한계 | 『동의사상신편』(1929), 한국전통지식포탈 P0018182의 기록입니다. 문서명 끝의 임시 표기 ‘W’는 제거했으며, 동명 고방과 구성·체질 맥락을 구분합니다. |

### 관찰 포인트

흉복 답답함이 식사·긴장·호흡과 어떻게 연결되는지, 두통·오한과 같은 시기에 시작됐는지 봅니다. 급성 표병이 사라진 뒤에도 기체·소화불편이 지속되면 향부자팔물탕 계열과 구분합니다.

## 궁귀향소산(후대 수록명) {#soeum-gunggwihyangso}

### 깊이 읽기

궁귀향소산은 후대 수록명이라는 근거 층을 분명히 하면서 **울광 표병의 두통·신체통과 기체·소화 변화**를 함께 봅니다. 발한 뒤 탈진·냉감이 커지면 승양익기탕·승양팔물탕 등 망양초증으로의 전환을 다시 평가합니다.

| 항목 | 임상적으로 읽는 범위 |
|---|---|
| 적용 소증·병증 단계 | 소음인 태양증·울광의 후대 사시온역 기록 가운데 두통·기체·소화 변화가 함께 있는지 봅니다. |
| 핵심 증후 | 오한·발열, 두통·신체통, 흉복 답답함과 식욕 변화. |
| 감별 처방 | 표증·통증 중심은 천궁계지탕, 향부자·소엽 중심의 기체는 [향소산](#soeum-hyangso), 발한 뒤 기력저하가 두드러지면 승양계 처방으로 병증 단계를 다시 봅니다. |
| 구성·법제 | 향부자 7.5 g, 자소엽·진피·창출·천궁·자감초 각 3.75 g, 대조 2매, 생강 3조각, 총백 5뿌리. 원자료는 산제로 기록합니다. |
| 복용·관찰 | 두통·체온, 발한과 회복, 식욕·복만, 배변, 수면·기력을 기록합니다. |
| 주의사항 | 감초 병용과 부종·혈압·전해질 위험을 확인합니다. 심한 두통·신경학적 이상은 표병으로만 보지 않습니다. |
| 근거와 한계 | 『동의사상신편』(1929), 한국전통지식포탈 P0018137의 기록입니다. 기존 DB 전사에서 한글 처방명과 한자 표기가 엇갈릴 수 있어 이 문서는 한자명을 단정하지 않으며, 인용 시 원문 판본을 다시 확인합니다. |

### 관찰 포인트

두통·신체통의 강도와 함께 식욕·흉복 답답함, 발한 뒤 회복을 기록합니다. 후대 경험방은 원전 처방과 근거 층을 구분하고, 현대 두통 질환의 표준치료로 일반화하지 않습니다.

## 승양익기탕(升陽益氣湯) {#soeum-seungyangikgi}

### 깊이 읽기

승양익기탕은 망양초증에서 **발한 뒤 기력저하·오한·식욕저하와 승양 회복**을 보는 처방입니다. 승양팔물탕과 같은 초기 망양군으로 비교하되 실제 구성·출전과 환자의 소화·냉감·활동 회복을 함께 봅니다.

| 항목 | 임상적으로 읽는 범위 |
|---|---|
| 적용 소증·병증 단계 | 소음인 태양증에서 망양초증으로 기울며 발한 뒤 기력저하와 회복 지연이 나타나는 방향을 봅니다. |
| 핵심 증후 | 표증이 이어지고 땀 뒤 탈진·냉감, 식욕·활동 저하가 동반되는지 확인합니다. |
| 감별 처방 | 망양이 비교적 얕으면 [승양팔물탕](../sasang-formula-cards/seungyangpalmul-tang.md)과 비교하고, 냉감·쇠약이 더 깊어 부자 배합을 검토하는 단계는 [승양익기부자탕](#soeum-seungyangikgi-buja)·인삼계지부자탕으로 구분합니다. |
| 구성·법제 | 계지·백작약·인삼·황기 각 7.5 g, 관계·당귀·자감초·백하수오 각 3.75 g. |
| 복용·관찰 | 발한량, 땀 뒤 어지럼·기력, 체온감, 식사량·대변, 혈압·맥박과 활동을 봅니다. |
| 주의사항 | 실신·저혈압, 소변 감소·탈수, 고열·의식 변화는 즉시 평가합니다. 감초와 계지·관계의 병용약·심혈관 상태를 확인합니다. |
| 근거와 한계 | 『동의사상신편』(1929), 한국전통지식포탈 P0018132의 수록 정보입니다. 이름이 유사한 보중익기탕과 다른 처방입니다. |

### 관찰 포인트

땀의 양보다 땀 뒤 기력·냉감·기립 어지럼·식욕과 활동 회복을 봅니다. 지속 자한·저혈압·심한 냉감이 나타나면 부자 배합이 필요한 더 깊은 망양인지, 다른 의학적 원인이 있는지 재평가합니다.

## 승양익기부자탕(升陽益氣附子湯) {#soeum-seungyangikgi-buja}

### 깊이 읽기

승양익기부자탕은 승양익기탕 방향에 부자 배합이 필요할 정도로 **냉감·쇠약·활동 저하가 깊어진 망양**을 비교합니다. 부자 유무는 중증도 단서이면서 동시에 포제·용량·심혈관 상태·병용약 안전성을 별도로 확인해야 한다는 뜻입니다.

| 항목 | 임상적으로 읽는 범위 |
|---|---|
| 적용 소증·병증 단계 | 망양 방향에서 발한·탈진·냉감과 일상기능 저하가 더 뚜렷해 부자 배합을 비교하는 단계입니다. |
| 핵심 증후 | 지속 발한, 냉감·쇠약, 섭취·활동 저하와 회복 지연. |
| 감별 처방 | 부자 없이 망양초증을 다루는 [승양익기탕](#soeum-seungyangikgi), 계지·인삼·부자 축은 [인삼계지부자탕](../sasang-formula-cards/insamgyejibujatang.md), 관계 고용량 방향은 [인삼관계부자탕](#soeum-insam-gwangye-buja)을 비교합니다. |
| 구성·법제 | 계지·백작약·인삼·황기 각 11.25 g, 관계·당귀·**포제한 부자**·감초·백하수오 각 3.75 g. 부자의 기원·포제·실제량을 기록합니다. |
| 복용·관찰 | 혈압·맥박, 발한, 냉감·기력, 오심·저림·두근거림, 식사·소변·활동을 면밀히 봅니다. |
| 주의사항 | 부자는 자가 조제·복용하지 않습니다. 입주위·사지 저림, 오심, 심계·부정맥, 어지럼이 생기면 복용을 중단하고 즉시 평가합니다. |
| 근거와 한계 | 『동의사상신편』(1929), 한국전통지식포탈 P0018130의 기록입니다. 부자 포함 처방은 수록 사실보다 안전한 포제·용량·감시가 우선입니다. |

### 관찰 포인트

혈압·심박수·수분상태와 발한 뒤 활동 저하를 기록하고, 부자 관련 이상감각·심계·어지럼을 확인합니다. 단순 피로가 아니라 망양의 깊이와 안전성 판단이 동시에 필요한 처방군입니다.

## 인삼관계부자탕(人蔘官桂附子湯) {#soeum-insam-gwangye-buja}

### 깊이 읽기

인삼관계부자탕은 망양의 깊은 단계에서 인삼·관계·부자의 **보기·온양·회복축**을 읽습니다. 인삼계지부자탕·계지부자탕과 발한·자한·사지 증상의 비중을 비교하고, 관계부자이중탕처럼 복통·설사 중심의 리병과 구분합니다.

| 항목 | 임상적으로 읽는 범위 |
|---|---|
| 적용 소증·병증 단계 | 소음인 망양증의 심화 방향에서 발한·냉감·쇠약과 전신상태를 평가합니다. |
| 핵심 증후 | 땀 뒤 심한 탈진, 냉감·사지 기능 저하, 섭취 감소와 회복력 저하. |
| 감별 처방 | 승양·익기 축이 중심이면 승양익기부자탕, 계지 배합의 표병·망양은 인삼계지부자탕, 리한·설사·복통이 중심이면 [관계부자이중탕](../sasang-formula-cards/gwangye-buja-ijung-tang.md)과 구분합니다. |
| 구성·법제 | 관계 18.75 g 또는 37.5 g, 황기 11.25 g, 백작약 7.5 g, 포부자 3.75–7.5 g, 당귀·감초 각 3.75 g. 용량 범위·포제·판본을 반드시 기록합니다. |
| 복용·관찰 | 혈압·맥박, 체온감·발한, 식사·배변·소변, 심계·저림·오심과 활동 기능을 짧은 간격으로 봅니다. |
| 주의사항 | 관계·부자 고용량 가능성이 있어 심혈관질환·간신기능·임신·수유·병용약을 확인합니다. 쇼크·감염·출혈 등 현대 응급 원인 배제가 우선입니다. |
| 근거와 한계 | 『동의사상신편』(1929), 한국전통지식포탈 P0018131의 기록입니다. 용량 예시는 자가복용 지시가 아니며 현대 중증질환의 대체치료 근거가 아닙니다. |

### 관찰 포인트

지속 발한, 냉감, 한 끼 섭취량, 기립·보행과 수면을 함께 봅니다. 의식 변화·실신·흉통·호흡곤란은 망양의 중증도 기록과 별개로 즉시 현대 의학적 평가가 우선입니다.

## 계지반하생강탕(桂枝半夏生薑湯) {#soeum-gyeji-banha}

### 깊이 읽기

계지반하생강탕은 태음병에서 **오심·구토·심하·흉부 답답함과 냉감**이 전면인 분기를 봅니다. 곽향정기산의 한습·담습, 백하오이중탕의 복통·설사 리한과 비교하며 물도 유지하지 못하는 구토·폐색 신호는 즉시 평가합니다.

| 항목 | 임상적으로 읽는 범위 |
|---|---|
| 적용 소증·병증 단계 | 소음인 태음병·리한에서 후대 자료가 허한성 구토·수결흉으로 기록한 흉복부 정체 방향을 봅니다. |
| 핵심 증후 | 오심·구토, 심하·흉부 답답함, 복부 냉감과 식욕저하. |
| 감별 처방 | 한습·설사가 중심이면 [곽향정기산](../sasang-formula-cards/gwakhyangjeonggi-san.md), 기체·허약은 [향부자팔물탕](../sasang-formula-cards/hyangbujapalmul-tang.md), 급격한 토사·복통과 전신 쇠약은 [궁귀총소이중탕](#soeum-gunggwichongso)을 비교합니다. |
| 구성·법제 | 생강 11.25 g, 계지·반하 각 7.5 g, 백작약·백출·자감초·진피 각 3.75 g. 반하의 법제와 제형을 확인합니다. |
| 복용·관찰 | 구토 횟수·섭취 유지, 심하 불편, 복통·대변, 소변량·체중과 어지럼을 기록합니다. |
| 주의사항 | 물도 유지하지 못하는 구토, 토혈·검은변, 심한 흉통·복통, 소변 감소는 탈수·폐색·심혈관·위장관 평가가 우선입니다. |
| 근거와 한계 | 『동의사상신편』(1929), 한국전통지식포탈 P0018146의 수록 정보입니다. ‘수결흉’을 현대 흉수·심장질환과 동일시하지 않습니다. |

### 관찰 포인트

구토 횟수, 물 유지 가능 여부, 심하비만·복통, 대변·소변과 체중을 기록합니다. 지속 구토·복부팽만·가스와 대변 정지는 장폐색 등 급성 원인을 먼저 확인합니다.

## 궁귀총소이중탕(芎歸葱蘇理中湯) {#soeum-gunggwichongso}

### 깊이 읽기

궁귀총소이중탕은 **급성 토사·복통·냉감·쇠약**이 함께 나타나는 태음병 분기를 공부하는 처방입니다. 구토·설사 횟수뿐 아니라 수분·소변·체중·기립 상태를 기록하고 감염성 장염·식중독·급성 복증을 먼저 감별합니다.

| 항목 | 임상적으로 읽는 범위 |
|---|---|
| 적용 소증·병증 단계 | 후대 자료가 소음인 건곽란으로 기록한 급성 토사·복통과 리한 방향을 살핍니다. |
| 핵심 증후 | 갑작스러운 구토·설사 또는 헛구역·복통, 냉감·쇠약과 섭취 저하. |
| 감별 처방 | 한습·비위 불편은 곽향정기산, 구토·수결흉은 계지반하생강탕, 심한 리한·설사·사지냉은 관계부자이중탕·오수유부자이중탕을 비교합니다. |
| 구성·법제 | 인삼 11.25 g, 구운 건강·관계·백출 각 7.5 g, 백작약·자감초·진피 각 3.75 g, 포부자 3.75–7.5 g. 건강의 포제와 부자 안전을 확인합니다. |
| 복용·관찰 | 구토·설사 횟수, 섭취·소변량, 혈압·맥박, 복통·체온감, 의식과 활동을 짧게 추적합니다. |
| 주의사항 | 급성 토사곽란은 탈수·감염·전해질 이상이 빠르게 진행할 수 있습니다. 혈변, 고열, 의식 변화, 소변 감소가 있으면 수액·검사 등 필요한 진료가 우선입니다. |
| 근거와 한계 | 『동의사상신편』(1929), 한국전통지식포탈 P0018165의 수록 기록입니다. 현대 급성 위장염의 일률적 처방이나 응급치료 대체로 해석하지 않습니다. |

### 관찰 포인트

급성 토사에서는 체질 문진과 동시에 탈수·전해질·감염 여부를 확인합니다. 구토·설사 감소 뒤에도 식욕·냉감·소변·기력이 회복되는지를 봐야 태음병의 회복을 판단하기 쉽습니다.

## 십이미관중탕(十二味寬中湯) {#soeum-sibimi-gwanjung}

### 깊이 읽기

십이미관중탕은 태음병의 **복만·황색 변화·부종·권태** 같은 후대 수록 맥락을 봅니다. 황달이라는 표현을 체질병증만으로 설명하지 않고 새 황달·진한 소변·회색변·발열·우상복부 통증은 간담도·혈액 질환 평가가 우선입니다.

| 항목 | 임상적으로 읽는 범위 |
|---|---|
| 적용 소증·병증 단계 | 소음인 위수한리한병에서 후대 자료가 위장병·황달·음독 방향과 연결한 처방을 검토합니다. |
| 핵심 증후 | 복만·소화저하, 황색 변화·부종, 냉감·사지권태가 어떤 조합인지 확인합니다. |
| 감별 처방 | 흉복통·배뇨불리 중심은 [관중탕](#soeum-gwanjung), 일반 태음병의 복통·설사는 [백하오이중탕](../sasang-formula-cards/baekhao-ijung-tang.md), 심한 리한은 부자이중계와 구분합니다. |
| 구성·법제 | 대복피·목향·지실·후박 각 18.75 g, 건강·양강·익지인·적하수오·진피·청피·향부자·백하수오 각 3.75 g, 대조 2매. 대용량 표기와 제형·판본을 재확인합니다. |
| 복용·관찰 | 복부팽만·통증, 식사량, 대변·소변, 피부·공막 색, 부종·체중과 피로를 기록합니다. |
| 주의사항 | 새 황달·진한 소변·회색변, 발열·우상복부통, 빠른 부종은 간담도·췌장·심신장 평가가 우선입니다. 하수오 기원·포제와 간기능을 확인합니다. |
| 근거와 한계 | 『동의사상신편』(1929), 한국전통지식포탈 P0018150의 기록입니다. 고전 ‘황달·음독’을 현대 간염·담도폐쇄 치료효과로 확대하지 않습니다. |

### 관찰 포인트

피부·공막의 황색 변화, 소변색·대변색, 부종·체중, 복통·발열을 기록합니다. 황달은 체질병증 용어만으로 설명하지 않고 간담도 폐쇄·간염·용혈 등 현대 원인을 우선 감별합니다.

## 관중탕(寬中湯) {#soeum-gwanjung}

### 깊이 읽기

관중탕은 리한에서 **흉복통·배뇨 변화·사지권태·냉감**의 조합을 비교합니다. 흉통은 심혈관·호흡기, 배뇨 변화는 비뇨기·신장 원인을 함께 확인하고, 십이미관중탕과는 황색 변화·부종의 비중을 비교합니다.

| 항목 | 임상적으로 읽는 범위 |
|---|---|
| 적용 소증·병증 단계 | 후대 자료의 흉복통·배뇨불리·사지권태 맥락을 소음인 리한·기체·배설 변화 안에서 평가합니다. |
| 핵심 증후 | 흉복부 통증·답답함, 소변 불편과 사지권태·냉감. |
| 감별 처방 | 복만·황색 변화·부종이 넓게 겹치면 [십이미관중탕](#soeum-sibimi-gwanjung), 기체·소화허약은 향부자팔물탕, 소변 불리와 부종은 심장·신장·비뇨기 원인을 먼저 감별합니다. |
| 구성·법제 | 건강·양강·오령지·익지인·청피 각 3.75 g. 약재 기원·품질과 실제 제형을 확인합니다. |
| 복용·관찰 | 통증 위치·강도, 식사·배변, 배뇨 횟수·양, 부종·체중, 냉감과 활동 기능을 기록합니다. |
| 주의사항 | 흉통·호흡곤란, 요폐, 혈뇨, 발열·옆구리통증, 소변 감소와 부종은 심혈관·비뇨기·신장 평가가 우선입니다. |
| 근거와 한계 | 『동의사상신편』(1929), 한국전통지식포탈 P0018171의 기록입니다. 증상명만으로 처방하거나 현대 배뇨질환 효능을 단정하지 않습니다. |

### 관찰 포인트

흉복통의 위치와 식사·호흡 관계, 배뇨량·빈도·통증, 부종·냉감·기력을 함께 봅니다. 새 흉통·호흡곤란, 혈뇨·요폐, 심한 국소 복통은 체질처방보다 원인 평가가 우선입니다.

## 공통 재평가와 안전

소음인 처방의 회복은 따뜻해졌다는 느낌 하나가 아니라 **음식선화**, 복통·설사, 발한 뒤 기력, 수면과 활동이 발병 전 기준선으로 돌아오는지로 봅니다. 특히 부자·관계·건강이 포함된 처방은 정확한 기원·포제·용량과 심혈관·간신기능, 병용약을 확인합니다.

- 위 열 처방의 주된 근거는 『동의사상신편』 수록과 병증·배합 비교입니다. 현대 질환별 독립 임상시험은 제한적입니다.
