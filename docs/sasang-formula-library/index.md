# 사상처방 구성·용량 라이브러리

사상처방을 **체질 → 병증축 → 개별 처방 → 구성본초·용량·출전** 순서로 탐색합니다.

| 체질 | 주요 병증축 | 바로가기 |
|---|---|---|
| 소양인 | 망음·표병 / 흉격열·리열 / 음허오열·하소 | [소양인 처방](soyangin-exterior.md) |
| 태음인 | 위완수한표한 / 간수열리열 | [태음인 처방](taeeumin-exterior-cold.md) |
| 소음인 | 태음병·리한 / 망양·표병 / 비위·기체 | [소음인 처방](soeumin-taeeum.md) |

**언제 추가된 처방인지가 아니라 어떤 체질병증에서 어떤 역할을 하는지**를 기준으로 정리합니다.
