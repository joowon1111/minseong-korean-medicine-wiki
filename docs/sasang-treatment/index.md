# 사상체질 치료·관리 지식망

사상의학의 임상 활용은 한약 처방에만 한정되지 않는다. 국가한의임상정보포털의 사상체질병증 진료지침은 **체질한약치료·체질침치료·뜸치료·체질식사요법·체질운동요법·체질성정요법**을 치료·예방·관리의 구성요소로 제시한다.

```text
사상체질
   ↓
체질병증
   ↓
┌────────┬────────┬────────┐
한약     침·뜸     생활관리
                  ├─ 식사
                  ├─ 운동
                  └─ 성정
```
