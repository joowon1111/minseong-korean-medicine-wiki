# 사상체질 치료·예방 통합 지도

```text
                    사상체질
                       ↓
                  체질병증 진단
                       ↓
        ┌──────────────┼──────────────┐
      한약            침·뜸          생활관리
        │               │          ┌──┼──┐
      처방            경혈        식사 운동 성정
        └──────────────┼──────────────┘
                       ↓
                치료·예방·건강관리
```
