# 근현대 한국 한의학 임상서

이 영역은 고대·조선의 고전과 구분하여, **근현대 한국 한의사가 실제 임상에서 남긴 진료기록·의론·처방 운용과 교육의 흐름**을 살펴봅니다.

## 왜 별도 영역으로 보나요?

《황제내경》·《상한론》·《동의보감》은 전통 이론과 임상체계의 주요 출전입니다. 근현대 임상서는 이러한 지식이 새로운 질병명, 의료제도와 사회환경 속에서 어떻게 해석되고 사용됐는지를 보여줍니다.

`전통 고전 → 의가의 임상 해석 → 진료기록과 처방 → 근현대 한국 한의학`

## 핵심 문헌

### [소문대요](../classics/somun-daeyo.md)

석곡 이규준이 《황제내경·소문》을 선별·교정하고 부양론·기혈론·맥진·병기 해석을 더한 한국 근대 의서입니다.

- 황제내경 원문과 한국 의가의 재해석
- 부양론·기혈론·신유양장변
- 장부·경락·운기·맥진
- 원전 교정과 근현대 이론 형성

### [청강의감](../classics/cheonggang-uigam.md)

청강 김영훈의 장기간 진료 경험과 의학사상을 제자 이종형이 정리한 임상서입니다.

- 의학의 기본 원리
- 병증별 이론과 치료
- 처방과 가감법
- 치험례
- 유고와 생애
- 20세기 동서의학의 접점

## 자료를 읽는 기준

근현대 임상기록은 실제 진료의 흐름을 보여주는 중요한 사료이지만, 현대 임상시험과 같은 연구 설계는 아닙니다.

1. 당시 병명과 현재 진단명이 같은지 확인합니다.
2. 처방 구성·용량·제형과 가감 내용을 구분합니다.
3. 치험례는 개별 임상 경험으로 읽습니다.
4. 현재의 안전성·상호작용·검사와 진료지침을 별도로 확인합니다.
5. 현대 연구가 있다면 대상·중재·평가지표가 실제로 일치하는지 봅니다.
