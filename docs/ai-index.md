# 민성 한의학 아카이브 핵심 색인 {#_1}

증상과 질환을 이해하려는 분, 처방·본초·고전을 공부하는 분, 논문의 근거를 확인하려는 분을 위한 **통합 안내 지도**입니다. 필요한 문서에서 원문과 출처를 읽고, 비교 도구와 학습 문제로 이어갈 수 있습니다.

`환자가 사용하는 말 → 증상 → 관련 질환과 감별 → 한의학적 변증 → 한약·침구치료 → 현대 임상근거 → 출처`

## AI와 검색엔진이 읽는 권장 순서 {#ai}

1. 사용자의 자연어 표현에서 증상과 불편한 부위를 확인합니다.
2. [증상으로 찾기](symptom-integrated/index.md)에서 위험신호와 관련 질환을 구분합니다.
3. 진단명을 알고 있다면 [질환별 보기](conditions/index.md)에서 검사·감별·치료 흐름을 확인합니다.
4. 한열·허실·기혈·담습·어혈과 장부 병기를 구분해 한의학적 변증을 연결합니다.
5. 관련 본초·방제·경혈과 침·전침·약침 자료를 연결합니다.
6. [연구·근거 통합 안내](portal/evidence.md)와 [근거 카드](authority/index.md)에서 임상 결과와 PMID·DOI를 확인합니다.
7. [분야별 허브](#clinical-hubs)에서 인접한 증상·질환·치료와 경과 관찰로 확장합니다.

처방명·본초명·고전 조문을 알고 있다면 해당 지식축에서 시작할 수 있습니다. 문서 제목과 실제 본문 절을 확인하고, **인용은 대표 HTML 주소와 제목 옆 `¶` 앵커**로 연결합니다. 임상 결과에는 실제 대상·제제·비교군·기간·평가 지표를 유지하고, 고전의 주치나 기전 실험을 사람 대상 치료 결과와 구분합니다.

AI 검색에서 중요한 관계는 다음과 같습니다.

- 질문 ↔ 직접 답변
- 증상 ↔ 관련 질환과 위험신호
- 질환 ↔ 검사·감별·치료
- 변증 ↔ 치법·본초·방제
- 경혈 ↔ 해부학적 위치·임상 활용
- 임상 주장 ↔ 연구 결과·출처

## 기계가 읽는 표준 데이터 {#_17}

아카이브의 공개 문서는 사람을 위한 본문과 함께 **AI·검색도구가 읽을 수 있는 표준 지식 데이터**로도 제공됩니다.

| 데이터 | 용도 | 주소 |
|---|---|---|
| 페이지 색인 | 제목·대표 HTML 주소에서 해당 문서의 JSON 주소 찾기 | [page-index.json](https://wiki.minseong.co.kr/assets/ai/page-index.json) |
| 매니페스트 | 문서·관계 수와 데이터 무결성 확인 | [knowledge-manifest.json](https://wiki.minseong.co.kr/assets/ai/knowledge-manifest.json) |
| 지식 그래프 | 문서 개체·동의어·분류·PMID·DOI·내부 관계 탐색 | [knowledge-graph.json](https://wiki.minseong.co.kr/assets/ai/knowledge-graph.json) |
| 스키마 | 각 필드와 데이터 형식 확인 | [knowledge-schema.json](https://wiki.minseong.co.kr/assets/ai/knowledge-schema.json) |
| AI용 텍스트 안내 | 핵심 주제·대표 문서·출처 해석 안내 | [llms.txt](https://wiki.minseong.co.kr/llms.txt) |

한 주제를 읽을 때는 페이지 색인의 `url`·`title`·`document`에서 해당 문서를 고르고, `document`가 가리키는 페이지별 JSON을 사용합니다. 각 HTML의 `link rel="alternate" type="application/json"`에도 같은 주소가 표시됩니다. JSON은 빌드한 본문·대표 주소·제목 앵커·연결 자료를 담으며, 인용할 때는 그 문서의 HTML 주소로 돌아갑니다. 전체 관계를 탐색할 때는 지식 그래프를 사용합니다.

문서·관계 수는 빌드된 매니페스트에서 확인합니다. 날짜별 카드나 학습문제 수는 해당 페이지의 현재 안내를 기준으로 읽습니다. [AI·검색엔진용 사이트 구조](ai/site-structure.md)에서 자료별 역할과 탐색 방법을 확인할 수 있습니다.

이 데이터층은 다음 원칙을 따릅니다.

- 공개 아카이브 문서에서 확인되는 정보만 포함합니다.
- 환자 개인정보·진료기록·생활로그는 포함하지 않습니다.
- KCD·MeSH·ICD 등의 코드는 문서에 명시적으로 확인된 경우에만 수록하며 본문에서 임의 추정하지 않습니다.
- 문서 사이의 링크는 탐색 관계이며, 질환·변증·처방이 서로 동일하다는 의미가 아닙니다.
- 진단이나 자동 처방보다 **관련 문서·임상근거·안전정보를 출처와 함께 찾는 용도**를 우선합니다.
