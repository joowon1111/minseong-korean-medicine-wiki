# 소음인 태음병 vs 소음병
두 병증 모두 복통·설사가 나타날 수 있으므로 **갈증·흉부불편·전신통·수족냉과 중증도**가 중요한 감별축입니다.

| 감별 | 태음병 | 소음병 |
|---|---|---|
| 큰 위치 | 위수한리한병의 태음병 | 더 중한 소음병 |
| 공통 | 복통·설사 | 복통·설사 |
| 갈증 | 뚜렷하지 않은 방향이 중요 | 갈증 가능 |
| 추가 증후 | 비만·구토·황달·부종 등 단계별 | 구중불화·흉부불편·전신통·관절통·수족냉 |
| 중증도 | 경증·중등증 | 중증·위중증 |

진료지침은 태음병을 경증·중등증으로, 소음병을 **중증·위중증**으로 분류합니다.

```text
복통·설사
 ↓
갈증·수족냉·전신통·흉부불편 증가?
 ├─ 아니오 → 태음병 축 탐색
 └─ 예 → 소음병 축을 더 적극적으로 탐색
```

### 처방 연결 예
태음병 자리증 → 백하오이중탕  
태음병 비만증 → 곽향정기산·계지반하생강탕  
소음병 자리증 → 관계부자이중탕 등

## 태음병과 소음병을 가르는 핵심은 '깊이'입니다

두 병증 모두 복통·설사가 나타날 수 있어 대변만으로 구분하기 어렵습니다. 발병 전 소화·식욕을 기준선으로 두고 **갈증·심번·수족냉·전신통·섭취와 순환 상태**가 새로 더해지는지를 봅니다.

| 관찰축 | 태음병 쪽 | 소음병 쪽 |
|---|---|---|
| 소화·식욕 | 저하되지만 경증·중등증 범위 | 섭취와 전신 기능이 더 크게 무너질 수 있음 |
| 설사 | 복통·리한과 함께 | 더 심하고 쇠약·냉감과 연결 |
| 갈증 | 뚜렷하지 않은 방향이 중요 | 갈증·심번이 새롭게 동반될 수 있음 |
| 냉감 | 복부·전신 냉감 | 수족냉·사지궐냉이 더 두드러질 수 있음 |
| 통증 | 복통·비만 중심 | 전신통·관절통까지 확대 가능 |
| 기능 | 식사·일상기능 일부 유지 | 기립·보행·활동이 크게 저하될 수 있음 |

## 태음병 안의 분기

- **자리·리한:** 복통·설사·식욕저하·복부 냉감이 중심이면 [백하오이중탕](../sasang-formula-cards/baekhao-ijung-tang.md)을 비교합니다.
- **한습·비만:** 오심·구토·심하비만·담습이 두드러지면 [곽향정기산](../sasang-formula-cards/gwakhyangjeonggi-san.md)이나 계지반하생강탕을 비교합니다.
- **황달·음독 방향:** 황색 변화·부종·사지냉이 나타나면 간담도·혈액·심장·신장 질환을 먼저 평가하면서 관중탕·십이미관중탕의 전통적 위치를 공부합니다.

## 소음병 안의 분기

- **깊은 리한:** 지속 설사·복통·사지냉·전신 쇠약이 중심이면 [관계부자이중탕](../sasang-formula-cards/gwangye-buja-ijung-tang.md)을 비교합니다.
- **장궐·격양:** 구토·설사·사지궐냉과 섭취·순환 저하가 깊어지면 [오수유부자이중탕](../sasang-formula-library/osuyubujairijung-tang.md) 문서의 중증 감별을 함께 봅니다.

## 망양과도 혼동하지 않기

망양도 냉감·쇠약이 심하지만 출발점은 **발한 뒤 탈진과 표병**입니다. 반면 태음병·소음병은 **복통·설사·구토와 리한**이 중심입니다. 시간순서를 묻는 것이 중요한 이유입니다.

## 경과관찰

- 설사 횟수와 형태, 복통 위치·강도
- 한 끼 섭취량, 구토, 체중
- 음수량·소변량, 갈증·심번
- 손발 온도, 혈압·맥박, 기립 어지럼
- 수면·보행·업무 등 일상기능

물도 유지하지 못하는 구토, 혈변·검은변, 의식저하, 지속 저혈압·실신, 소변량 급감은 즉시 평가가 우선입니다. 부자 함유 처방은 포제·용량·병용약과 심혈관 상태를 별도로 확인합니다.
