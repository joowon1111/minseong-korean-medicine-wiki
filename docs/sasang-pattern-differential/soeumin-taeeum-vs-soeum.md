# 소음인 태음병 vs 소음병
두 병증 모두 복통·설사가 나타날 수 있으므로 **갈증·흉부불편·전신통·수족냉과 중증도**가 중요한 감별축입니다.

| 감별 | 태음병 | 소음병 |
|---|---|---|
| 큰 위치 | 위수한리한병의 태음병 | 더 중한 소음병 |
| 공통 | 복통·설사 | 복통·설사 |
| 갈증 | 뚜렷하지 않은 방향이 중요 | 갈증 가능 |
| 추가 증후 | 비만·구토·황달·부종 등 단계별 | 구중불화·흉부불편·전신통·관절통·수족냉 |
| 중증도 | 경증·중등증 | 중증·위중증 |

진료지침은 태음병을 경증·중등증으로, 소음병을 **중증·위중증**으로 분류합니다.

```text
복통·설사
 ↓
갈증·수족냉·전신통·흉부불편 증가?
 ├─ 아니오 → 태음병 축 탐색
 └─ 예 → 소음병 축을 더 적극적으로 탐색
```

### 처방 연결 예
태음병 자리증 → 백하오이중탕  
태음병 비만증 → 곽향정기산·계지반하생강탕  
소음병 자리증 → 관계부자이중탕 등
