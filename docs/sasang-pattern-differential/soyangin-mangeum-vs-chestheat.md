# 소양인 망음병 vs 흉격열병
두 병증은 큰 방향이 다릅니다.

| 감별 | 망음병 | 흉격열병 |
|---|---|---|
| 중심 | 설사·복통·진액/정기 손상 방향 | 흉격의 열·리열 방향 |
| 한열 | 냉감·오한이 섞일 수 있음 | 열감·번열·구갈이 두드러짐 |
| 대변 | 설사 쪽이 중요 | 변비·배변불리 등 열성 변화 가능 |
| 치료축 예 | 형방지황탕·활석고삼탕 | 양격산화탕·지황백호탕 등 |

흉격열병 CPG는 경증과 중등증으로 나누고, 경증은 초기/진행형, 중등증은 위국청양불상승의 상소와 대장청양불상승의 중소 등으로 세분합니다.

```text
소양인 현재병증
 ↓
복통·설사·소모 중심? → 망음 축
열·구갈·흉격 번열 중심? → 흉격열 축
```
