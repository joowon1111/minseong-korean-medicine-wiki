# 사상체질 병증 감별 문진 순서
1. **평소 소증:** 소화·대변·소변·땀·수면·한열·갈증·피로·성정
2. **발병 후 가장 크게 달라진 소증은?**
3. **표/리:** 체표·한증·발한 변화인가, 내부 열·소화·배설 변화인가?
4. **순/역:** 체질의 보명지주 기능과 평소 소증이 얼마나 무너졌는가?
5. **중증도:** 일상기능·섭취·배설·전신통·냉감/열·정신상태 변화
6. **표준 체질병증**
7. **치법·처방**
8. **치료 후 소증과 완실무병 조건 회복 확인**

```text
체질 → 소증 → 현재 변화 → 표리 → 순역 → 중증도 → 처방
```


## 단계별 문진을 실제 질문으로 바꾸기

| 단계 | 핵심 질문 | 기록할 항목 |
|---|---|---|
| 평소 소증 | 아프기 전 2–4주에 소화·대변·소변·땀·수면은 어땠나? | 빈도·양·편안함·회복감 |
| 발병 변화 | 가장 먼저 달라진 것은 무엇인가? | 시간순서, 유발요인 |
| 표리 | 오한·신체통·발한 변화가 앞서는가, 소화·배설·내열이 앞서는가? | 한열, 흉복부, 대소변 |
| 순역 | 평소 건강 지표가 유지되는가 크게 무너졌는가? | 음식선화·대변선통·한액통창·소변 |
| 중증도 | 일상기능과 섭취·배설이 얼마나 떨어졌나? | 식사량, 체중, 보행, 업무 |
| 현대 감별 | 체질병증으로 설명하기 전에 배제할 질환이 있는가? | 활력징후, 검사, 위험신호 |
| 처방 비교 | 같은 병증군에서 가까운 처방을 가르는 단서는? | 구성 차이, 핵심 동반증 |
| 재평가 | 치료 뒤 무엇이 먼저 회복됐나? | 주증 + 소증 + 기능 |

## 네 체질에서 우선 묻는 질문

### 소양인
대변이 평소보다 굳었는지 또는 설사로 바뀌었는지, 갈증·상열·두통·수면이 함께 변했는지 묻습니다. 복통·설사와 소모가 중심이면 망음, 흉격 번열·구갈·변폐가 중심이면 리열, 하지무력·배뇨·야간열이 깊어지면 음허오열 방향을 비교합니다.

### 태음인
땀이 안 나서 답답한지, 땀 뒤 몸이 가벼워지는지, 식후 몸이 무겁고 호흡·담이 불편한지 묻습니다. 열·갈증·변비·건조가 전면이면 간수열리열, 오한·발한불리·무거움이 전면이면 위완수한표한 방향을 봅니다.

### 소음인
식욕과 식후 편안함, 복통·설사·구토, 냉감과 땀 뒤 기력을 묻습니다. 발한 뒤 탈진이 중심이면 망양, 복통·설사·식욕저하가 중심이면 태음병, 갈증·심번·수족냉·전신통이 더해지면 소음병의 깊이를 확인합니다.

### 태양인
보행·기립과 연하·섭취 중 어느 기능이 먼저 흔들렸는지 묻습니다. 태양인은 자료가 제한적이므로 체질 추정보다 신경계·근골격·연하·식도 질환 감별과 기능평가를 더 엄격하게 합니다.

## 문진 기록의 최소 단위

- 증상 강도만 0–10으로 적지 말고 **빈도·지속시간·기능 영향**을 같이 기록합니다.
- 대변은 횟수·형태, 소변은 양·빈도·야간뇨, 땀은 상황과 땀 뒤 느낌까지 적습니다.
- 식사는 한 끼 섭취량, 식후 불편이 시작되는 시간, 체중 변화를 함께 봅니다.
- 수면은 총시간보다 입면·중간각성·기상 후 회복감을 구분합니다.
- 치료 반응은 통증·열감 하나가 아니라 소증과 활동이 같은 방향으로 좋아지는지 확인합니다.

## 중단하고 다른 평가를 먼저 해야 하는 경우

의식 변화, 편측마비·언어장애, 흉통·호흡곤란·실신, 지속 고열, 혈변·토혈·흑변, 심한 탈수·소변 감소, 진행성 연하곤란·빠른 체중감소는 체질 문진보다 즉시 필요한 의학적 평가가 우선입니다.
