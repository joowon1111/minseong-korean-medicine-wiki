# 태양인 해역증 vs 열격증
태양인은 드문 체질이므로 병증 감별을 특히 신중히 합니다.

| 감별 | 해역증 | 열격증 |
|---|---|---|
| 중심 기능 | 요척·하지·보행 | 연하·섭취·구토 |
| 주요 변화 | 다리 힘 저하, 기립·보행 불편 | 음식이 잘 내려가지 않음, 구토·섭취 감소 |
| 대표 처방 | 오가피장척탕 | 미후등식장탕 |

태양인 CPG는 소장 기능의 유리/불리 소증과 열격 등의 병증을 표준화하여 진단하도록 제시합니다.

```text
태양인
├─ 요척·하지 기능 저하 → 해역
└─ 연하·섭취·구토 문제 → 열격
```


## 두 병증은 '어떤 기능이 무너지는가'로 구분합니다

태양인 병증 자료는 다른 체질보다 제한적이므로 증상 수를 억지로 늘리기보다 **요척·하지 기능**과 **연하·섭취 기능**이라는 두 축을 깊게 관찰하는 편이 중요합니다.

| 확인 항목 | 해역 방향 | 열격·반위 방향 |
|---|---|---|
| 시작 기능 | 오래 서기·걷기·계단 | 삼킴·섭취·음식 유지 |
| 진행 지표 | 보행거리 감소, 기립 불안정 | 한 끼 섭취량 감소, 구토·역류 |
| 기능 결과 | 낙상·일상활동 저하 | 체중·수분·영양 저하 |
| 대표 처방 | [오가피장척탕](../sasang-formula-cards/ogapi-jangcheok-tang.md) | [미후등식장탕](../sasang-formula-cards/mihudeung-sikjang-tang.md) |

## 해역에서 먼저 확인할 것

- 좌우 근력 차이, 감각저하, 반사 변화, 보행 양상과 낙상 여부를 확인합니다.
- 요통이나 하지통이 있으면 척추관협착증·추간판질환·고관절/무릎 질환과 구분합니다.
- 갑작스러운 편측 위약, 언어장애, 배뇨·배변 장애가 동반되면 뇌·척수 응급질환 평가가 우선입니다.
- 경과는 통증 점수보다 **걷는 거리·계단·의자에서 일어나기·보조기 사용** 같은 기능으로 기록합니다.

## 열격·반위에서 먼저 확인할 것

- 입안·목·가슴 중 어디에서 걸리는지, 고형식과 물 중 무엇이 더 어려운지 묻습니다.
- 식사 중 기침·사레, 젖은 목소리, 반복 폐렴은 흡인 위험을 시사할 수 있습니다.
- 진행성 연하곤란, 체중감소, 토혈·흑변, 반복 구토는 위·식도 질환을 포함한 신속한 평가가 필요합니다.
- 경과는 **섭취량·식사시간·구토 빈도·체중·수분상태**로 기록합니다.

## 회복을 판단하는 기준

해역은 하지 힘이 조금 좋아졌다는 느낌보다 보행거리와 기립 안정성이 실제로 늘었는지 확인합니다. 열격은 구토 감소뿐 아니라 음식·수분 섭취량, 체중과 식사 시간이 회복되는지를 봅니다. 태양인의 평소 소변 상태도 함께 기록해 전신 기능 회복을 확인합니다.

## 처방 문서를 읽을 때

오가피장척탕과 미후등식장탕은 태양인 병증 구조를 공부하기 위한 대표 처방입니다. 처방 수가 적다는 이유로 다른 체질 처방을 끌어오거나 현대 질환명을 일대일로 대응하지 않습니다. 먼저 [태양인 통합 허브](../sasang-integrated/taeyangin.md)에서 병증 구조를 확인한 뒤 각 처방의 구성·감별·안전을 읽습니다.
