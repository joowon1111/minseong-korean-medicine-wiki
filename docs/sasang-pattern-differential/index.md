# 사상체질 병증 감별 심화

사상체질 진료에서 체질명은 출발점이고, 처방에 더 직접적으로 연결되는 것은 **현재 체질병증**입니다. 같은 체질에서도 표병과 리병, 순증과 역증, 중증도와 표준증후가 다르면 치료 원칙과 대표 처방군이 달라집니다.

```text
위험신호·현대 질환 확인
        ↓
체질 판단 근거 + 발병 전 소증
        ↓
현재 현증의 핵심 묶음
        ↓
표병/리병 → 순증/역증 → 중증도 → 세부 표준증후
        ↓
치법·처방 + 침·전침·약침·뜸·생활관리
        ↓
주증·소증·기능 변화로 재평가
```

## 감별 전에 먼저 분리할 세 가지 {#three-layers}

| 층 | 뜻 | 대표 질문 |
|---|---|---|
| 체질 | 비교적 지속되는 생리·병리 반응의 기본 방향 | 평소 어떤 상황에서 소화·대소변·땀·수면이 흔들리는가? |
| 소증 | 발병 전부터 반복되던 개인의 건강 기준선과 병리적 경향 | 아프기 전 식욕·대변·소변·땀·한열·회복은 어땠는가? |
| 현증 | 이번 발병 뒤 새로 생기거나 뚜렷해진 증상 | 언제 시작했고 무엇이 얼마나 달라졌는가? |

평소 냉감이 있던 사람이 발열할 수 있고, 평소 변비가 있던 사람이 이번에는 설사할 수 있습니다. 소증과 현증을 섞으면 체질과 현재 병증을 모두 잘못 해석하기 쉬우므로 시간축을 나눠 기록합니다.

## 1단계: 위험신호와 현대 질환을 함께 확인하기 {#step-1}

체질병증 감별은 현대 의학적 진단을 대신하는 과정이 아니라 함께 통합하는 과정입니다.

- 갑작스러운 마비·언어장애·의식 변화, 진행하는 근력저하
- 흉통·실신·호흡곤란, 입술의 청색 변화
- 물도 삼키기 어렵거나 반복 사레·흡인 의심
- 지속 고열, 혈변·검은변·토혈, 심한 복통
- 반복 구토·설사와 소변량 감소·탈수
- 원인 모를 빠른 체중감소·황달·전신 부종

위 신호가 있으면 필요한 검사와 급성기 처치를 먼저 연결합니다. 검사 결과와 현대 질환명은 이후 체질병증 치료의 목표·안전성·경과지표를 정하는 데도 활용합니다.

## 2단계: 발병 전 소증 기준선 만들기 {#step-2}

| 영역 | 구체적으로 기록할 것 |
|---|---|
| 소화·식욕 | 배고픔, 한 끼 섭취량, 식후 더부룩함·오심 |
| 대변 | 횟수·형태·잔변감, 변비·설사와 배변 뒤 느낌 |
| 소변 | 횟수·양·야간뇨, 배뇨불편과 음수량 |
| 땀 | 상황·부위·양, 땀 뒤 개운함·탈진·냉감 |
| 수면 | 입면·각성·꿈·코골이, 아침 회복감 |
| 한열·갈증 | 전신·상하·손발의 냉열, 입마름과 선호 음료 |
| 피로·회복 | 식사·업무·운동 뒤 회복 시간 |
| 성정·정서 | 긴장·분노·걱정이 신체 증상으로 이어지는 방식 |

## 3단계: 네 체질의 큰 병증축 찾기 {#step-3}

| 체질 | 표·리의 큰 축 | 핵심 감별 질문 | 대표 병증 |
|---|---|---|---|
| 소양인 | 비수한표한 ↔ 위수열리열 | 복통·설사와 소모가 중심인가, 상열·구갈·변비가 중심인가? | 소양상풍·망음 / 흉격열·음허오열 |
| 태음인 | 위완수한표한 ↔ 간수열리열 | 오한·발한불리·무거움인가, 열·갈증·번조·건조인가? | 위완한·위완한폐조 / 간열·간열폐조 |
| 소음인 | 신수열표열 ↔ 위수한리한 | 발한·표증과 탈진인가, 식욕저하·복통·설사·냉감인가? | 울광·망양 / 태음병·소음병 |
| 태양인 | 외감요척 ↔ 내촉소장 | 하지·보행 기능 저하인가, 연하·섭취·구토 문제인가? | 해역 / 열격·반위 |

표병과 리병은 환자가 겉이 춥다고 말하는지, 속이 덥다고 말하는지만으로 나누지 않습니다. 각 체질의 핵심증상·발현지표·소증지표가 어떤 묶음으로 나타나는지 봅니다.

## 4단계: 순증과 역증을 구분하기 {#step-4}

순역은 단순한 초기·말기나 가벼움·심함만을 뜻하지 않습니다. 각 체질에서 생명 유지의 핵심으로 보는 보명지주의 보존 또는 손상과 병리 방향을 반영합니다.

| 체질 | 감별에서 특히 보는 역증 방향 |
|---|---|
| 소양인 | 망음의 복통·설사·소모, 음허오열의 하지·배뇨·진액 변화 |
| 태음인 | 폐조와 음혈 소모가 더해지는 표한·리열의 심화 |
| 소음인 | 망양의 발한·탈진, 소음병의 심한 냉감·설사·전신 쇠약 |
| 태양인 | 해역의 보행 기능 저하, 열격·반위의 섭취·영양 유지 저하 |

순증과 역증을 처방명으로 역산하지 않고, 먼저 소증과 현증·기능 저하의 구조를 확인합니다.

→ [건강→악화→중증→회복](../sasang-progression/index.md) · [순역과 병증 비교](../sasang-integrated/patterns.md)

## 5단계: 중증도와 표준증후를 기록하기 {#step-5}

같은 병증명 안에서도 경증·중등증·중증·위중증의 치료 목표와 관찰 간격이 달라질 수 있습니다.

| 판단축 | 확인 내용 |
|---|---|
| 주증 강도 | 0–10점, 빈도·지속시간, 야간·휴식 시 증상 |
| 섭취·배설 | 식사·수분 유지, 설사·구토, 소변량 |
| 활력·전신상태 | 체온·맥박·혈압, 의식·탈수·체중 변화 |
| 일상기능 | 보행·계단·업무·가사·수면의 제한 |
| 소증 손상 | 평소 건강 기준에서 얼마나 멀어졌는가 |
| 회복 여력 | 치료·휴식 뒤 회복 속도와 변동폭 |

2022 지침은 소증과 현증의 중증도 및 개선 정도를 평가하고 mCGI-G/I for SCS를 참고하도록 제시합니다. 이 도구는 증상 한 개보다 체질병증 전체의 중증도와 변화를 구조적으로 기록하는 데 의미가 있습니다.

## 체질별 핵심 감별표 {#constitution-differential}

### 소양인: 망음과 흉격열·음허오열

| 감별 | 망음 | 흉격열 | 음허오열 |
|---|---|---|---|
| 중심 | 복통·설사와 음청지기 소모 | 흉격 번열·상열·구갈·배변불리 | 지속 소모·허열, 하지위약·배뇨 변화 |
| 대변 | 설사·급박변 방향 | 변비·배변불리 방향 | 대변과 함께 배뇨·전신소모 확인 |
| 함께 볼 것 | 오한·신체통, 탈수·소변량 | 두통·수면·체온·수분 | 체중·근력, 당뇨·신장·신경질환 |
| 처방군 예 | 형방지황탕·활석고삼탕 | 양격산화탕·지황백호탕 | 독활지황탕·숙지황고삼탕 |

### 태음인: 위완수한표한과 간수열리열

| 감별 | 표한 | 리열 |
|---|---|---|
| 중심 | 오한·발한불리·무거움·호흡 불편 | 열감·구갈·번조·건조·변비 |
| 땀 | 잘 나지 않거나 막힌 느낌, 땀 뒤 반응 중요 | 열·조열과 함께 양·부위·소모를 평가 |
| 함께 볼 것 | 감염·호흡·부종·수면무호흡 | 혈압·대사·수면·피부·대변 |
| 처방군 예 | 태음조위탕·조위승청탕 | 열다한소탕·갈근해기탕·청폐사간탕 |

### 소음인: 태음병과 소음병·망양

| 감별 | 태음병 | 소음병 | 망양 |
|---|---|---|---|
| 중심 | 복만·복통·설사·식욕저하 | 심한 설사·복통과 냉감·쇠약 | 발한과 함께 기력·회복력 저하 |
| 갈증 | 뚜렷하지 않은 방향이 중요 | 갈증·심번이 함께 가능 | 수분·전신상태와 함께 평가 |
| 함께 볼 것 | 구토·심하비만, 감염·약물 | 수족냉·전신통, 탈수·전해질 | 혈압·어지럼·실신·체온 |
| 처방군 예 | 백하오이중탕·곽향정기산 | 관계부자이중탕 | 승양익기탕·승양팔물탕 |

### 태양인: 해역과 열격

| 감별 | 해역 | 열격·반위 |
|---|---|---|
| 중심 | 요척·하지 힘 저하, 기립·보행 불편 | 연하불편, 구역·구토, 섭취 유지 저하 |
| 기능평가 | 근력·감각·반사·균형·낙상 | 고형식/물, 사레·기침, 체중·수분 |
| 함께 볼 것 | 뇌·척수·신경·관절·근육 | 연하·위·식도·신경계 질환 |
| 처방군 예 | 오가피장척탕 | 미후등식장탕 |

## 비슷한 환자 표현을 다시 묻는 법 {#symptom-questions}

| 환자 표현 | 감별을 위해 더 물을 내용 |
|---|---|
| “열이 많아요” | 전신/상체/야간, 체온, 갈증·대변·땀·수면과 발병 전 상태 |
| “손발이 차요” | 전신 냉감, 발열·오한, 빈혈·갑상선·혈관·약물, 소화·대변 |
| “소화가 안 돼요” | 식욕, 걸림·사레, 식후 복만·오심, 복통·대변·체중 |
| “땀이 많아요” | 운동/휴식/수면, 부위, 땀 뒤 개운함·탈진·어지럼 |
| “기운이 없어요” | 섭취·수면·감염·빈혈·대사, 근력과 활동 뒤 회복 |
| “다리가 약해요” | 통증인지 근력저하인지, 좌우차·감각·보행·대소변 변화 |

## 감별에서 자주 생기는 오류 {#pitfalls}

- 체형·얼굴·성격 한 항목으로 체질을 확정하는 것
- 오늘의 열감·냉감·설사를 발병 전 소증으로 간주하는 것
- 현대 질환명 하나에 사상처방 하나를 고정하는 것
- 소음인의 태음병과 태음인 병증, 소양인의 망음과 소음인의 망양을 혼동하는 것
- 태음인의 한액통창을 의도적인 과도한 발한으로 해석하는 것
- 처방 반응만으로 체질을 확정하고 소증·현증·기능 변화를 기록하지 않는 것
- 원전 처방과 후대 경험방, 동명 처방의 구성을 구분하지 않는 것

## 감별 뒤 치료와 재평가 {#treatment-follow-up}

| 치료·관리 | 감별 결과를 반영하는 방법 |
|---|---|
| 체질한약 | 체질병증·중증도에 맞는 처방군과 구성·용량·복용 반응을 기록 |
| 침·체질침 | 체질과 현재 병증, 경맥·배혈·보사와 치료 뒤 기능 변화를 연결 |
| 전침 | 통증·근긴장·근력·보행 등 측정 가능한 기능 목표를 설정 |
| 약침 | 국소 병소, 제제 특성, 알레르기 병력과 국소·전신 반응을 기록 |
| 뜸·온열 | 현재 한열·피부감각·체력과 치료 뒤 편안함·피로를 확인 |
| 생활관리 | 음식·운동·수면·스트레스 뒤 실제 반응과 소증 회복을 추적 |

재진에서는 주증 감소만 보지 않고 소화·대변·소변·땀·수면·한열·갈증·회복력과 일상기능이 같은 방향으로 좋아지는지 확인합니다. 병증축이 달라지거나 중증도가 변하면 치법·처방과 침구 자극을 다시 조정합니다.
