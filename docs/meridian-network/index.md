# 경락·경맥 임상 지식망

경락은 **장부 → 경맥 유주 → 전체 경혈 → 특정혈 → 배혈 → 증상·변증**으로 이어지는 하나의 구조입니다.

### 경맥 순환
폐 → 대장 → 위 → 비 → 심 → 소장 → 방광 → 신 → 심포 → 삼초 → 담 → 간 → 다시 폐
