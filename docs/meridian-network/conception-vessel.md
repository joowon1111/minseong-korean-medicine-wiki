# 임맥(任脈) CV

## 핵심 의미
음맥의 바다로 설명되며 전면 정중선을 따라 하복부·복부·흉부·인후·턱을 연결합니다.

## 기시·종지와 유주

**체표 첫 혈:** [회음 CV1](../acupuncture/points/cv1.md) · **체표 마지막 혈:** [승장 CV24](../acupuncture/points/cv24.md)

**몸에서 따라 읽기:** 회음 → 하복부 → 배꼽·명치 → 가슴 정중선 → 목 앞 → 턱.

## 특정혈·기경 연결
**모혈 CV3·4·5·12·14·17 / 팔회혈 CV12·17 / 락혈 CV15 / LU7 열결이 임맥과 연결**

## 임상 축

하복부는 배뇨·월경과의 관계, 상복부는 식사와의 관계, 흉부는 활동 시 호흡·통증 양상을 구분해 읽습니다. 중완·관원·전중이 같은 정중선에 있어도 치료 목표와 깊은 해부 구조는 다릅니다. [증상별 경혈 지도](../acupoint-network/by-condition.md)에서 목표를 정하고 [침구 임상근거](../acupuncture-integrated/evidence.md)에서 질환·배혈·자극법을 확인합니다.

하복부·여성·비뇨 / 소화 / 흉민·호흡·인후 / 기허·회복

## 대표 배혈
관원 CV4 + 기해 CV6 / 중완 CV12 + 족삼리 ST36 + 내관 PC6 / 전중 CV17 + 내관 PC6 / 열결 LU7 + 조해 KI6

## 안전
경항·흉복부 등 부위별 해부학적 위험을 고려하며, 특히 심부 장기·척수 방향의 부적절한 자침을 피합니다.
