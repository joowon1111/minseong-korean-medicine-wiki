# 수태양소장경 SI {#si}

팔 뒤쪽·견갑·목과 얼굴의 연결을 경혈 코드와 함께 읽는 자료입니다. 먼저 유주를 살핀 뒤 전체 혈위와 특정혈, 임상에서의 해석을 차례로 확인하세요.

## 한눈에 보기 {#_1}
- **기시:** 새끼손가락
- **종지:** 귀 앞
- **표리:** 소장↔심
- **경혈 수:** 19혈

## 전체 유주 {#_2}
새끼손가락→상지 후외측→견갑→목. 내부는 심·위·소장, 얼굴에서는 광대·눈·귀 주변으로 분지.

## 임상 해석 {#_5}

소장경은 새끼손가락에서 팔 후외측·견갑·목으로 이어지고 얼굴의 눈·귀 주변으로 분지합니다. 내부 장부의 연결과 체표 경로를 함께 살펴야 소장이라는 이름과 어깨·견갑 증상이 한 문서에 놓이는 이유를 이해할 수 있습니다.

**대표 경혈을 읽는 방법**

후계 SI3는 오수혈의 수혈이며 독맥과 연결되는 팔맥교회혈로 읽습니다. 신맥 BL62와의 짝은 [팔맥교회혈](special-points/eight-confluent.md)에서 확인하고, 견갑 부위의 천종 SI11 같은 국소혈과 원위혈을 선택한 목적은 별도로 봅니다.

**증상과 연결할 때의 질문**

견갑 안쪽이나 어깨 뒤가 아플 때는 경맥 경로와 함께 목·어깨 움직임, 근력·감각, 압통을 비교합니다. 근육·관절·경추 신경의 원인을 소장경의 설명 하나로 대체하지 않습니다. 귀 주변의 경혈을 언급한 문헌도 현재의 청력·어지럼 진단과는 구분해 읽습니다.

[심경](heart-meridian.md)과 표리 관계를, [삼초경](triple-energizer-meridian.md)과 팔 뒤·바깥쪽의 주행을, [임상해부학](../clinical-anatomy/index.md)과 견갑대의 실제 구조를 연결해 보세요.

위치의 표준과 실제 시술의 적합성은 다른 질문입니다. 정확한 혈위는 [표준 경혈 아틀라스](../acupoint-network/standard-atlas.md)에서 확인하고, 경맥별 전체 표는 특정 증상에 대한 일괄 시술 목록으로 사용하지 않습니다.
