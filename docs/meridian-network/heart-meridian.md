# 수소음심경 HT {#ht}

상지 안쪽·새끼손가락과 심의 기능 설명을 경혈 코드와 함께 읽는 자료입니다. 먼저 유주를 살핀 뒤 전체 혈위와 특정혈, 임상에서의 해석을 차례로 확인하세요.

## 한눈에 보기 {#_1}
- **기시:** 심중
- **종지:** 새끼손가락
- **표리:** 심↔소장
- **경혈 수:** 9혈

## 전체 유주 {#_2}
심중→소장 분지·인후와 눈 분지. 체표는 폐→액와→상지 후내측→새끼손가락.

정9 형8 수7 경4 합3 / 원7 / 락5 / 극6

## 임상 해석 {#_5}

심경은 심·소장 등의 내부 관계와 겨드랑이에서 팔 안쪽·새끼손가락으로 이어지는 체표 주행을 구분해 읽습니다. 심이라는 장부의 전통적 기능, 심경 유주, 현대 심장 질환은 서로 다른 설명 수준입니다.

**대표 경혈을 읽는 방법**

[신문 HT7](../acupuncture/points/ht7-shenmen.md)은 원혈이면서 오수혈의 수혈이고, 통리 HT5는 락혈, 음극 HT6는 극혈입니다. 신문을 불면·심계와 연결하는 설명에서는 현재 수면 양상과 동반 증상, 함께 선택한 경혈의 목적을 확인합니다.

**증상과 연결할 때의 질문**

새끼손가락 쪽 저림이 심경의 유주와 가까워 보여도 심장 질환으로 곧바로 연결하지 않습니다. 손·팔의 감각과 근력, 압박·자세에 따른 변화를 확인하고 [척골신경 포착](../nerve-entrapment/ulnar-entrapment.md) 같은 별도의 감별을 살핍니다. 두근거림은 발병 방식·활동과의 관계를 따로 평가합니다.

[심포경](pericardium-meridian.md)과는 상지 전면에서의 위치와 대표 특정혈을, [소장경](small-intestine-meridian.md)과는 표리 관계를 비교하세요. 연구를 읽을 때는 신문 한 혈인지 복합 배혈인지도 구분합니다.

위치의 표준과 실제 시술의 적합성은 다른 질문입니다. 정확한 혈위는 [표준 경혈 아틀라스](../acupoint-network/standard-atlas.md)에서 확인하고, 경맥별 전체 표는 특정 증상에 대한 일괄 시술 목록으로 사용하지 않습니다.
