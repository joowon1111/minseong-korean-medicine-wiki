# 원혈(原穴) 완전 정리

| 경맥 | 원혈 |
|---|---|
| 폐 LU | LU9 태연 |
| 대장 LI | LI4 합곡 |
| 위 ST | ST42 충양 |
| 비 SP | SP3 태백 |
| 심 HT | HT7 신문 |
| 소장 SI | SI4 완골 |
| 방광 BL | BL64 경골 |
| 신 KI | KI3 태계 |
| 심포 PC | PC7 대릉 |
| 삼초 TE | TE4 양지 |
| 담 GB | GB40 구허 |
| 간 LR | LR3 태충 |

## 원혈의 임상적 의미

원혈은 해당 경맥과 장부의 상태를 살펴보고 치료할 때 중요하게 다뤄지는 특정혈입니다. 음경의 원혈은 오수혈의 수혈과 일치하고, 양경에는 별도의 원혈이 있습니다.
