# 락혈(絡穴) 완전 정리

## 십이경맥의 락혈

| 경맥 | 락혈 |
|---|---|
| 폐 LU | LU7 열결 |
| 대장 LI | LI6 편력 |
| 위 ST | ST40 풍륭 |
| 비 SP | SP4 공손 |
| 심 HT | HT5 통리 |
| 소장 SI | SI7 지정 |
| 방광 BL | BL58 비양 |
| 신 KI | KI4 대종 |
| 심포 PC | PC6 내관 |
| 삼초 TE | TE5 외관 |
| 담 GB | GB37 광명 |
| 간 LR | LR5 여구 |

## 추가 락혈
- 임맥: CV15 구미
- 독맥: GV1 장강
- 비의 대락: SP21 대포

락혈은 표리경과의 연결, 국소·원위 증상, 원락배혈을 이해하는 중요한 축입니다. 공손 SP4·내관 PC6, 열결 LU7 등은 기경팔맥과도 연결됩니다.
