# 동의보감과 방약합편 비교

| 구분 | 동의보감 | 방약합편 |
|---|---|---|
| 성격 | 종합 의학서 | 임상 활용 중심 편람 |
| 대표 구조 | 내경·외형·잡병·탕액·침구 | 손익본초 + 상·중·하통 |
| 강점 | 이론·병증·본초·침구의 종합 | 본초·처방의 빠른 탐색 |
| 활용 | 분야별 폭넓은 조회 | 치법 방향에서 처방 조회 |
