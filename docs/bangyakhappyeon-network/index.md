# 방약합편 임상 지식망

《방약합편》은 조선 후기 한의학의 방제와 본초 지식을 **진료 현장에서 빠르게 찾고 활용할 수 있도록 압축·정리한 임상 처방서**입니다.

《황제내경》처럼 기초 이론의 출발점이거나 《상한론》처럼 특정 병증 체계를 세운 고전이라기보다, 앞선 의학 지식을 실제 처방 선택과 본초 배합으로 연결한 한국 한의학의 실용서라는 데 특징이 있습니다. 따라서 이 아카이브에서는 방약합편을 고대 핵심 고전과 나란히 두기보다 **한국 한의학 임상서·처방서** 영역에서 살펴봅니다.

## 상통·중통·하통으로 읽기

방약합편의 상·중·하통은 단순한 목차가 아니라 처방의 치료 방향을 빠르게 파악하게 하는 탐색 장치입니다.

- **상통**: 허약한 기능과 기혈을 보충하고 회복을 돕는 방향
- **중통**: 한열·기혈·장부 사이의 치우침을 조절하고 화해하는 방향
- **하통**: 정체된 병리 산물이나 실증을 공격·배출하는 방향

같은 증상이라도 허실·한열·병기와 환자의 상태에 따라 서로 다른 통의 처방이 검토될 수 있습니다.

## 방약합편을 임상적으로 탐색하는 순서

1. 환자가 표현하는 증상과 발생 시기·악화 요인을 확인합니다.
2. 한열·허실·표리와 장부·기혈·담음·어혈 등의 병기를 구분합니다.
3. 보·화·공 가운데 필요한 치료 방향을 정합니다.
4. 상통·중통·하통에서 관련 처방군을 찾습니다.
5. 손익본초·약성가에서 구성 본초의 역할과 배합을 확인합니다.
6. 현재의 진단, 복용 약물, 안전성 정보와 현대 임상근거를 함께 검토합니다.
