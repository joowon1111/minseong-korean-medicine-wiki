# 칠방·십제

칠방과 십제는 처방의 구성과 약물의 작용 방향을 이해하는 전통적인 분류 틀이다.

```text
칠방 → 처방의 규모·구성 방식
십제 → 약물·처방의 기능적 작용 방향
```

개별 처방의 이름을 외우는 데서 그치지 않고, 처방이 어떤 원리로 구성되고 어떤 방향으로 작용하는지 이해하는 보조 지식망으로 활용할 수 있다.
