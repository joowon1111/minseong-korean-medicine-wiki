# 방약합편 처방 탐색법

방약합편은 본초와 처방을 빠르게 왕복하며 탐색하는 데 강점이 있다.

```text
병증 파악
 ↓
치료 방향 판단
 ↓
보·화·공
 ↓
상통·중통·하통
 ↓
후보 처방
 ↓
구성 본초·약성 확인
 ↓
주치·가감 검토
```

핵심은 **본초 ↔ 치법 ↔ 처방**을 연결해서 보는 것이다.
