# 상통·중통·하통

의방활투에서는 처방을 큰 치료 방향에 따라 상통·중통·하통으로 나눈다.

| 구분 | 중심 방향 | 탐색 관점 |
|---|---|---|
| 상통 | 보(補) | 허약을 보하는 처방 |
| 중통 | 화(和) | 불균형을 조화시키는 처방 |
| 하통 | 공(攻) | 실한 병사·적체 등을 다루는 처방 |

이 구조는 수많은 처방을 단순 목록이 아니라 **치법의 큰 방향**으로 빠르게 찾아가도록 돕는다.
