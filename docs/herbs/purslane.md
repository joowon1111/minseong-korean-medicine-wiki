# 마치현(馬齒莧)

마치현은 쇠비름 *Portulaca oleracea*의 전초를 약용합니다. 전통적으로 **청열해독·량혈지혈·지리**의 방향에서 설명하며, 습열성 설사·이질이나 피부 종창·습진의 처방 또는 외용 문맥에서 다룹니다. 식용 재료와 생약은 재배·채취·세척·건조·검사 기준이 다를 수 있습니다.

| 항목 | 내용 |
|---|---|
| 약용 부위 | 전초 |
| 성미·귀경 | 산·한; 간·대장경으로 설명 |
| 전통 효능 | 청열해독 · 량혈지혈 · 지리 |
| 비교 본초 | 어성초·포공영·백화사설초 |

## 장관·피부 증후 문맥

전통적인 지리·청열해독은 습열이 동반된 설사나 이질을 처방 전체에서 다루는 방향입니다. 혈변·고열·심한 복통, 탈수·소변량 감소·의식 변화가 있으면 원인 확인과 적절한 치료가 우선입니다. 외용할 때도 병변 범위, 진물·감염 여부와 피부 적용 부위를 살핍니다.

| 본초 | 차이를 살피는 지점 |
|---|---|
| [어성초](houttuynia.md) | 청열해독·배농의 전통적 활용 |
| [포공영](dandelion.md) | 청열해독·소종, 이뇨의 배합 |
| [백화사설초](oldenlandia.md) | 청열해독·이습통림 |
| [대청엽](isatis-leaf.md) | 잎 약재, 량혈소반을 함께 다룸 |

## 기원과 품질

전초의 기원·이물, 농약·중금속 등 검사, 건조·보관 상태를 확인합니다. 같은 이름의 식용 재료가 약재 규격을 충족한다고 단정하지 않습니다. 약재 선택은 증상명만이 아니라 변증과 다른 치료를 함께 고려합니다.
