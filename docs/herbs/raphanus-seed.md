# 나복자(萊菔子·蘿蔔子)

나복자는 **음식 적체를 풀면서 기를 아래로 내리고 담을 삭이는 소식약**입니다. 과식 뒤 더부룩함만 보는 것이 아니라 창만·트림·기침·가래처럼 식적과 기체·담이 이어지는 양상을 함께 봅니다.

## 기본 정보

| 항목 | 내용 |
|---|---|
| 생약명 | Raphani Semen |
| 약용 부위 | 무의 성숙한 씨 |
| 성미·귀경 | 신·감, 평 / 폐·비·위 |
| 전통 효능 | 소식제창·강기화담 |

## 효능을 병증으로 읽기

- **소식제창:** 식적에 따른 완복창만·트림·산취·대변 이상을 소식약 배합 안에서 봅니다.
- **강기화담:** 폐·위의 기가 위로 거슬러 기침·가래·오심이 겹친 경우 화담·강기약과 연결합니다.
- **가공:** 생품과 볶은 나복자의 전통적 활용 비중이 다르므로 포제와 처방 목적을 확인합니다.

## 대표 처방과 본초 비교

[보화환](../formulas/baohe-wan.md)에서는 산사·신곡과 소식하고 반하·진피·복령과 담습·기체를 함께 다룹니다. [산사](hawthorn.md)는 육류·유지류 적체와 행기산어, [맥아](barley-malt.md)는 곡식 적체와 건비개위를 더 비중 있게 봅니다.

→ [산사·맥아·나복자 비교](../herbal-integrated/herb-comparisons.md#digestant-herbs)

## 실제 활용과 안전성

식욕저하·복부팽만이 비기허에서 비롯된 경우 소식·강기만 지속하면 맞지 않을 수 있습니다. 기허가 뚜렷한 사람, 임신·수유 중인 사람, 지속되는 복통·구토·체중감소·출혈이 있는 경우에는 먼저 원인과 처방 전체를 평가합니다.

현대 연구에서는 소화기 증상·위장운동·기침·객담 등을 나눠 볼 수 있지만, 씨 추출물의 실험 결과를 소식화담 전체나 복합처방의 임상효과로 동일시하지 않습니다.
