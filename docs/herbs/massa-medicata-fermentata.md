# 신곡·신국(神麴)

신곡은 곡물과 여러 식물성 재료를 섞어 발효시킨 **발효 한약재**입니다. 문헌에는 신곡(神麴)·신국(神麴)·육신곡(六神麴) 등의 이름으로 나타나며, 소식화중·건비개위의 방향으로 음식 적체와 비위의 운화를 돕습니다.

## 원료보다 제조공정을 함께 본다

신곡은 단일 식물의 특정 부위를 말린 본초와 달리 **원료 배합 → 수분 조절 → 발효 → 건조 → 절단·볶음**을 거쳐 만들어집니다. 밀가루·밀기울을 바탕으로 적소두·행인과 청호·청대·창이초 계열 재료를 사용하는 기록이 있으나, 시대·지역·제조규격에 따라 원료와 발효법이 달라집니다.

| 품질 확인점 | 살피는 이유 |
|---|---|
| 원료와 제조규격 | 같은 ‘신곡’이라도 배합과 미생물 환경이 달라질 수 있음 |
| 발효 상태 | 고른 발효색·향과 내부 조직을 확인 |
| 수분·보관 | 흡습·곰팡이·이취를 예방하고 발효 후 품질을 유지 |
| 초법 | 생신곡·초신곡·초초신곡의 소식·지사 방향과 처방 목적을 구분 |

## 효능을 임상 병증으로 읽기

| 효능 | 함께 보는 증상 조합 |
|---|---|
| 소식화중 | 과식 뒤 명치·복부가 그득하고 트림·가스·식욕저하가 나타남 |
| 건비개위 | 소화력이 떨어진 바탕에 음식 적체가 반복됨 |
| 화약·조화 | 여러 약미가 들어간 처방에서 중초의 소화와 흡수를 받쳐 줌 |

식적이 강한지, 비위기허가 바탕인지, 담습·기체·울열이 겹치는지를 구분해 다른 본초와 배합합니다.

## 대표 처방에서의 역할

| 처방 | 신곡의 역할 |
|---|---|
| [보화환](../formulas/baohe-wan.md) | 산사·나복자와 소식하고 반하·진피·복령의 담습·기체 조절을 받침 |
| [월국환](../formulas/yueju-wan.md) | 향부자·천궁·창출·치자와 기·혈·습·화·식의 울체 가운데 식울을 담당 |
| [삼출건비탕](../formulas/samchul-geonbi-tang.md) | 산사·맥아와 소식하고 인삼·백출·복령의 건비축을 보완 |
| [정전가미이진탕](../formulas/jeongjeon-gami-ijin-tang.md) | 산사·맥아의 소식축과 이진탕 계열의 화담축을 연결 |
| [청서익기탕](../formulas/qingshu-yiqi-tang.md) | 더위·습으로 식욕이 떨어진 상태에서 진피·청피와 중초 운화를 도움 |

## 산사·맥아·나복자와 구분

| 본초 | 중심 역할 |
|---|---|
| **신곡** | 다양한 음식 적체를 소화하며 발효제 특성으로 화중·건비를 함께 봄 |
| [산사](hawthorn.md) | 육류·유지류 적체와 행기산어의 비중이 큼 |
| [맥아](barley-malt.md) | 곡식·전분성 적체와 건비개위, 회유 관련 활용 |
| [나복자](raphanus-seed.md) | 소식제창과 강기화담, 가스·트림·담이 겹친 양상 |

## 현대 연구와 활용 기록

2024년 연구는 신곡의 발효 단계에 따른 화학성분과 소화효소 활성, 장내미생물 관련 변화를 분석했습니다. 이는 발효공정과 품질표준의 중요성을 보여 주는 전임상·품질 연구이며, 완성 처방에서는 실제 신곡 규격과 배합을 함께 확인합니다.

- [PubMed: Massa Medicata Fermentata의 발효·소화기 연구](https://pubmed.ncbi.nlm.nih.gov/38495103/)
- [Frontiers in Pharmacology 원문](https://www.frontiersin.org/journals/pharmacology/articles/10.3389/fphar.2024.1359954/full)

치료 전후에는 식후팽만·트림·가스·식욕·대변 형태를 같은 기준으로 기록합니다. 밀·곡물과 발효 원료에 대한 알레르기, 보관 중 변질 여부, 혈당 관리가 필요한 경우의 제형과 부원료를 함께 확인합니다.
