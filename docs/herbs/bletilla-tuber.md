# 백급(白及)

백급(白及)은 난초과 *Bletilla striata*의 덩이줄기를 약용하는 본초입니다. ‘흰 뿌리’라는 일반 묘사가 아니라 약재명이며, 난초의 뿌리 전체가 아닌 덩이줄기가 약용 부위입니다. 전분이 풍부한 단단한 덩이줄기의 형태와 단면, 기원식물 및 규격을 함께 확인합니다.

| 항목 | 내용 |
|---|---|
| 약용 부위 | 백급의 덩이줄기 |
| 성미·귀경 | 고·감·삽·미한; 폐·간·위경으로 설명 |
| 전통 효능 | 수렴지혈 · 소종생기 |
| 비교 본초 | 대계·소계·백모근·삼칠·자초 |

## 수렴지혈과 생기의 전통적 의미

**수렴지혈**은 출혈을 수렴하는 처방 방향이고, **소종생기**는 창양·궤양의 종창과 회복을 다루는 전통 효능 표현입니다. 고전 주치에는 객혈·토혈·외상 출혈과 창양 등이 포함되지만, 이 표현만으로 원인을 진단하거나 응급·외과 처치를 대신할 수 있다는 뜻은 아닙니다.

출혈은 부위·양·반복 여부와 혈열·어혈·기허·허한 등 동반 병기를 함께 살핍니다. 상처는 깊이·오염·감염 징후를 평가합니다. 처방에서는 백급의 수렴 방향이 다른 지혈·양혈·활혈 본초와 어떻게 균형을 이루는지 봅니다.

## 유사한 지혈 본초와 감별

| 본초 | 전통 중심 방향 | 감별 단서 |
|---|---|---|
| 백급 | 수렴지혈·소종생기 | 난초과 덩이줄기, 전분성 약재 |
| [대계](cirsium-japonicum.md)·[소계](cirsium-setosum.md) | 량혈지혈·산어소종 | 엉겅퀴류, 기원과 약용 부위 확인 |
| [백모근](imperata-rhizome.md) | 청열량혈·이수 | 뿌리줄기, 열·소변 양상과 배합 |
| [측백엽](biota-leaf.md) | 량혈지혈·화담지해 | 측백의 어린 가지와 잎 |
| [삼칠](notoginseng.md) | 화어지혈·소종정통 | 인삼속 뿌리, 어혈·통증 배합 |
| [자초](purple-gromwell.md) | 량혈활혈·해독투진 | 지치과 뿌리, 발진·피부 배합 |

이 표는 전통 분류 비교이며, 같은 출혈 증상에 서로 대체해 쓸 수 있다는 뜻은 아닙니다.

## 처방 배합·품질·안전

백급은 수렴·생기의 역할로 지혈 또는 창양 처방 안에 배치됩니다. 대계·소계처럼 열을 식히는 약재, 백모근처럼 열과 수분대사를 함께 보는 약재, 삼칠처럼 어혈·통증을 다루는 약재의 배합은 처방 목적에 따라 달라집니다. 단일 본초의 효능명만으로 복용을 결정하지 않습니다.

HKBU 약용식물 이미지 데이터베이스는 백급을 **白及 / Bletillae Rhizoma / Common Bletilla Tuber**로 기록합니다. 꽃과 약재 이미지를 확인하고, 국내 실제 유통품은 국내 공정서 기준과 검사 자료도 대조합니다. 분말은 다른 전분성 원료 혼입 여부를 외관만으로 가리기 어려울 수 있습니다.

출혈이 지속되거나 토혈·혈변·검은 변, 호흡곤란·실신이 있으면 신속한 평가가 필요합니다. 깊거나 오염된 상처, 열·붓기·고름이 번지는 경우도 진료가 필요합니다.
