# 황정(黃精)

황정은 보비·윤폐·보신의 전통적 방향을 함께 가진 본초입니다. 한 가지 효능으로만 분류하기보다 허약·건조·비위 상태가 어떻게 동반되는지, 어떤 포제품을 어떤 처방에 넣는지를 살핍니다.

## 기원·전통 효능

황정은 황정속 식물의 근경을 사용합니다. 유통명만으로 기원종을 확정하지 않고 현행 약전·규격집의 품목 각조와 실제 원료 표시를 대조합니다. 전통적으로 보비익기·윤폐·보신의 방향으로 설명되며, 보익과 자윤을 함께 고려하는 배합에 위치합니다.

## 옥죽·산약·숙지황과 비교

| 본초 | 구별해서 볼 중심 |
|---|---|
| 황정 | 비·폐·신을 함께 보익·자윤하는 전통적 배합 |
| [옥죽](polygonatum-odoratum.md) | 양음윤조·생진의 방향을 중심으로 비교 |
| [산약](dioscorea.md) | 보비·익폐·보신과 고삽의 배합 |
| [숙지황](prepared-rehmannia.md) | 가공 지황의 보혈자음·익정 작용과 소화 수용성 |

생품과 주증·증숙 등 포제품은 원료 규격 및 전통적 사용 목적을 확인해 구분합니다. 같은 황정이라도 포제·전탕·보관이 다르면 품질과 사용 맥락이 달라집니다.

## 처방 안에서 읽기

황정은 고전과 후대 문헌에서 처방 구성이 다양하므로, 특정 보약의 고정 구성으로 일반화하지 않습니다. 복용약·기저질환과 소화 상태를 포함해 실제 처방 전체의 목적을 확인합니다.
