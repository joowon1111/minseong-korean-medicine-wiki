# 백강잠(白殭蠶)

백강잠은 누에 유충을 기원으로 하는 동물성 생약으로, **풍담이 경락과 두면부를 막는 병증을 풀고 경련·통증·결취를 다루는 식풍지경·거풍지통·화담산결약**입니다. 현대의 신경학적 진단명과 일대일로 대응하기보다 처방의 풍·담·경락 구조에서 역할을 읽습니다.

## 기원·약용 부위

| 항목 | 내용 |
|---|---|
| 생약명 | Bombyx Batryticatus |
| 기원 | 누에 *Bombyx mori* 유충이 백강균 *Beauveria bassiana*에 감염되어 경직·건조된 약용 규격품 |
| 성미·귀경 | 함·신, 평; 간·폐·위경을 중심으로 설명 |
| 핵심 효능 | 식풍지경·거풍지통·화담산결 |

단백질성 동물생약이므로 원료의 정체성, 미생물·이물 관리, 건조·보관 상태와 알레르기 병력을 함께 확인합니다.

## 대표 처방에서의 역할

| 처방 | 배합과 역할 |
|---|---|
| [오약순기산](../formulas/wuyao-shunqi-san.md) | 오약·진피·지각의 순기축과 마황·백지·천궁의 소풍지통축 사이에서 풍담·경락의 막힘을 풀어 줌 |
| 견정산 계열 | 전갈·백부자 등과 두면부 풍담·경련성 병증을 살피는 전통적 배합 |

## 전갈·천마·반하와 구분

| 본초 | 중심 방향 |
|---|---|
| **백강잠** | 풍담·경락과 두면부 증상, 경련·결취를 함께 봄 |
| [천마](gastrodia.md) | 평간식풍·지경, 어지럼·두통과 내풍의 방향 |
| [반하](pinellia.md) | 조습화담·강역지구로 비위와 담음의 근원을 조절 |
| 전갈 | 식풍지경·통락지통의 전통적 활용, 독성·용량 관리가 중요 |

## 임상·품질 확인

갑작스러운 얼굴마비, 편측 근력저하, 언어장애, 의식 변화나 새로 발생한 경련은 신속한 신경학적 평가를 연결합니다. 만성 안면경련·통증은 분포, 유발요인, 감각·근력, 현재 치료와 경과를 함께 기록합니다.

누에·곤충·진균 관련 알레르기, 임신·수유, 간·신장 기능과 항응고제 등 복용약을 확인합니다. 동물성 원료의 공급처, 시험성적서와 보관 온·습도를 조제기록에 남깁니다.
