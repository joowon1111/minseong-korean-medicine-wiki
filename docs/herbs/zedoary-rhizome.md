# 봉출(蓬朮)

봉출은 강황속 식물의 뿌리줄기를 쓰며, **기체와 어혈·적체가 함께 굳어진 병증을 움직이는 파혈행기·소적지통약**입니다. 통증이나 덩어리라는 한 증상보다 통증의 고정성, 복부팽만, 식사·월경과의 관계 및 허실을 함께 살핍니다.

## 기원·약용 부위

| 항목 | 내용 |
|---|---|
| 생약명 | Curcumae Rhizoma |
| 약용 부위 | 강황속 *Curcuma* 식물의 뿌리줄기 |
| 대표 기원 | *C. phaeocaulis*, *C. kwangsiensis*, *C. wenyujin* 계열 등; 공정서별 허용 기원 확인 |
| 성미·귀경 | 신·고, 온; 간·비경을 중심으로 설명 |
| 핵심 효능 | 파혈행기·소적지통 |

봉출·울금·강황은 같은 강황속이라도 약용 부위와 가공·효능 분류가 다르므로 생약명과 절편을 함께 확인합니다.

## 대표 처방에서의 역할

| 처방 | 배합과 역할 |
|---|---|
| [분심기음](../formulas/fenxin-qiyin.md) | 향부자·청피·진피·목향의 이기축에 적체가 오래된 방향을 더함 |
| 삼릉환·아위환 계열 | 삼릉과 함께 기혈의 적취·완고한 식적을 소산하는 전통적 배합 |

## 비슷한 본초와 구분

| 본초 | 중심 방향 |
|---|---|
| **봉출** | 기체·어혈·식적이 얽힌 적취와 통증을 파혈행기로 조절 |
| 삼릉 | 파혈행기·소적의 약대로 봉출과 자주 배합 |
| [향부자](cyperus.md) | 소간해울·이기조경이 중심 |
| 울금 | 행기해울·량혈과 담즙 흐름의 전통적 활용을 함께 봄 |
| [현호색](corydalis.md) | 활혈행기지통으로 통증 조절의 비중이 큼 |

## 품질·경과·안전 확인

절편의 색·향·수분과 기원을 확인하고 울금·강황과 혼동하지 않습니다. 월경량이 많거나 출혈 경향이 있는 경우, 임신 가능성·수술 전후, 항응고제·항혈소판제 복용을 처방 전에 확인합니다.

경과는 통증 강도뿐 아니라 통증 위치와 고정성, 복부팽만, 식사·배변·월경과의 관계를 기록합니다. 새로 만져지는 종괴, 지속 체중감소, 출혈 또는 점점 심해지는 국소 통증은 필요한 검사를 함께 진행합니다.
