# 측백엽(側柏葉)

측백엽은 측백나무 *Platycladus orientalis*의 어린 가지와 잎을 약용하는 본초입니다. **량혈지혈·화담지해·생발**의 전통 효능으로 설명하며, 출혈과 기침 등 서로 다른 문맥에서 처방 내 역할을 구분합니다. 조경수 가지를 임의로 채취해 쓰는 대신 기원과 규격이 확인된 원료를 사용합니다.

| 항목 | 내용 |
|---|---|
| 약용 부위 | 어린 가지와 잎 |
| 성미·귀경 | 고·삽·한; 폐·간·대장경으로 설명 |
| 전통 효능 | 량혈지혈 · 화담지해 · 생발 |

## 병증에서 보는 역할

량혈지혈은 혈열을 전통 병리로 판단하는 출혈의 처방 방향입니다. 화담지해는 담열이 기침에 관여한다고 보는 상황에서 다른 폐열·거담 본초와 함께 살핍니다. 탈모 관련 전통 주치도 두피 상태와 허실을 함께 보는 처방 문맥이며, 단일 약재가 탈모를 치료한다고 단정하는 뜻은 아닙니다.

## 지혈 본초 감별

- [대계](cirsium-japonicum.md)·[소계](cirsium-setosum.md): 엉겅퀴류로 량혈지혈·산어소종.
- [지유](sanguisorba-root.md): 뿌리 약재, 하부 출혈·습열 문맥에서 구분.
- [애엽](mugwort-leaf.md): 온경지혈 방향으로 한열 축이 다름.
- [백급](bletilla-tuber.md): 수렴지혈·소종생기.

포제에 따라 생품·초탄 등이 구분될 수 있으므로 처방 목적과 규격을 확인합니다. 기침·객혈이나 반복되는 코피·혈변은 원인 평가가 필요하고, 호흡곤란·실신이 있으면 즉시 진료합니다. 복용약과 출혈 병력을 처방 전에 알립니다.
