# 백선피(白鮮皮)

백선피는 백선나무 뿌리껍질을 사용하는 본초입니다. 피부 질환에 쓰였다는 전통 설명을 모든 발진이나 가려움의 단일 치료법으로 읽지 않고, 병변 양상·습열·열독 등 병기와 처방 전체를 확인합니다.

| 항목 | 내용 |
|---|---|
| 약용 부위 | 백선나무의 뿌리껍질 |
| 전통 효능 | 청열조습 · 거풍해독 |

## 전통적 효능과 감별

전통적으로 청열조습·거풍해독의 방향에서 설명합니다. [금은화](honeysuckle.md)·[연교](forsythia.md)와 청열해독·피부 증후를 살피되, 기원·약용 부위와 처방 역할은 서로 다릅니다. 증상 하나만으로 세 약재를 바꾸지 않습니다.

## 실제 활용에서 확인할 점

발진의 시작 시점, 분포, 물집·통증·열감, 복용약과 알레르기 등을 확인합니다. 얼굴·입안·눈의 부종, 호흡곤란, 빠르게 번지는 발진은 즉시 의료평가가 필요합니다. 약재의 기원과 약전 규격, 잔류·오염 검사를 확인합니다.
