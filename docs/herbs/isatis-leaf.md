# 대청엽(大靑葉)

대청엽은 청열해독약 가운데 **기분의 열독과 혈분의 열성 발진을 이어 보는 잎 약재**입니다. 인후의 붓기·열감, 고열 뒤 피부 반점·출혈성 변화처럼 열이 깊어지는 양상을 살피며, 금은화·연교·현삼·생지황 등과 배합합니다.

## 기원과 약용 부위

| 항목 | 내용 |
|---|---|
| 국제 생약명 | Isatidis Folium |
| 대표 기원 | 숭람 *Isatis indigotica*의 잎 |
| 성미·귀경 | 고, 한; 심·위경 |
| 핵심 효능 | 청열해독·량혈소반·이인 |

‘대청엽’은 지역 공정서와 본초 전승에 따라 서로 다른 식물의 잎을 가리킨 기록이 있습니다. 원료를 사용할 때는 단순 상명보다 **기원식물·약용 부위·공정서 기준·지표성분**을 함께 확인합니다. 같은 식물의 뿌리인 판람근, 색소 가공물인 청대와도 부위·제법이 다릅니다.

## 효능을 병증으로 읽기

| 효능 | 임상에서 함께 보는 단서 |
|---|---|
| 청열해독 | 인후종통, 구강·상기도의 열감, 열독성 종창 |
| 량혈소반 | 고열과 함께 나타나는 피부 반점·홍반·출혈성 열상 |
| 이인 | 목의 붓기·통증과 연하 불편을 청열해독약과 함께 조절 |

## 비슷한 청열해독약과 구분

| 본초 | 중심 역할 |
|---|---|
| **대청엽** | 청열해독과 량혈소반을 잎 약재 하나에서 연결 |
| [금은화](honeysuckle.md) | 열독을 맑히면서 표의 풍열을 소산 |
| [연교](forsythia.md) | 소종산결·청심제번과 상초 열의 배출 |
| 판람근 | 같은 식물의 뿌리로 인후·열독에 활용하되 약용 부위가 다름 |
| 청대 | 잎을 발효·가공해 만든 색소성 약재로 량혈·청간 방향이 선명 |

## 처방·연구·품질

대청엽은 보제소독음계 가감, 온병의 청열해독·량혈 처방에서 금은화·연교·현삼·황금 등과 배합됩니다. *Isatis indigotica*의 잎·뿌리·분리성분은 항염·항바이러스 경로를 중심으로 전임상 연구가 축적돼 있으므로, 연구한 부위가 대청엽인지 판람근인지 먼저 확인합니다.

→ [Isatis indigotica 성분·항바이러스 전임상 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC3405817/)

차가운 청열약이므로 대변·복부냉감과 식사량을 함께 보고, 복용 뒤 인후·체온·피부 변화와 소화상태를 기록합니다. 빠르게 번지는 자반, 호흡곤란, 심한 연하장애, 의식 변화는 신속한 평가와 함께 관리합니다.
