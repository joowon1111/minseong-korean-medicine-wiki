# 녹용 鹿茸

## 개요
녹용은 사슴과 동물의 골질화되지 않은 어린 뿔을 약용한 한약재입니다.

## 전통적 이해
전통적으로 보신양(補腎陽), 익정혈(益精血), 강근골(強筋骨) 등의 범주에서 설명됩니다.

## 문서화 기준
- 한자명 / 라틴 생약명
- 성미·귀경
- 전통적 효능과 주치
- 고전 출전
- 주요 성분 및 약리 연구
- 임상 연구
- 안전성
- 관련 처방·변증·질환
