# 사삼(沙參·남사삼)

사삼은 잔대류의 뿌리를 쓰는 양음약으로 **폐·위의 음을 기르고 열을 맑히며 진액을 생기게 하는 역할**을 합니다. 마른기침·끈적하고 적은 가래, 인후와 구강의 건조, 열병 뒤 식욕저하와 갈증이 함께 있을 때 배합 구조가 선명합니다.

## 기원과 이름 구분

| 이름 | 대표 기원·구분 |
|---|---|
| 사삼·남사삼 | 잔대속 *Adenophora* spp.의 뿌리; 국내 공정서의 기원종을 확인 |
| 북사삼 | 갯방풍 *Glehnia littoralis*의 뿌리; 별도 생약 |

남사삼과 북사삼은 모두 양음청폐·익위생진에 쓰이지만 기원식물이 다릅니다. 전통적으로 남사삼은 청폐거담의 방향, 북사삼은 양위생진의 부드러운 방향을 비교하므로 처방 기록에 기원을 구체적으로 남깁니다.

## 효능과 임상 단서

| 효능 | 함께 보는 증상 조합 |
|---|---|
| 양음청폐 | 오래된 마른기침, 적고 끈적한 가래, 인후건조 |
| 익위생진 | 입마름·갈증, 열병 뒤 식욕저하와 진액 손상 |
| 청열거담 | 열감과 건조가 있으면서 가래가 시원하게 나오지 않음 |

## 대표 배합

| 처방·배합 | 역할 |
|---|---|
| 사삼맥동탕 | 사삼·옥죽·맥문동·상엽·천화분 등과 온조가 폐위 음분을 상한 마른기침·갈증을 다룸 |
| 사삼 + [맥문동](ophiopogon.md) | 폐위의 음과 진액을 함께 보완 |
| 사삼 + [길경](platycodon.md) | 양음청폐와 선폐이인을 연결 |
| 사삼 + [오미자](schisandra.md) | 양음생진과 렴폐수렴을 함께 살핌 |

## 맥문동·백합과 감별

| 본초 | 중심 차이 |
|---|---|
| **사삼** | 양음청폐·익위생진에 거담 방향을 겸함 |
| [맥문동](ophiopogon.md) | 폐위 음을 기르고 생진하며 심번과 장조까지 폭넓게 연결 |
| [백합](lily.md) | 양음윤폐와 청심안신을 함께 살핌 |

건조감과 기침뿐 아니라 발열·호흡곤란·혈담, 체중감소, 야간발한을 확인해 필요한 검사를 함께 진행합니다. 윤조하는 약재이므로 평소 묽은변·담습·복부팽만과의 균형을 보고, 치료 뒤 기침 빈도·야간각성·가래·구강건조·식사량을 기록합니다.
