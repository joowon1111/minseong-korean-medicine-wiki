# 노근(蘆根)

노근은 갈대 *Phragmites australis*의 뿌리줄기(근경)를 약용합니다. 전통적으로 **청열생진·제번·지구·이뇨**의 방향으로 이해하며, 식물의 잎이나 줄기와 약용 부위를 구분합니다.

| 항목 | 내용 |
|---|---|
| 약용 부위 | 뿌리줄기 |
| 성미·귀경 | 감·한; 폐·위경으로 설명 |
| 전통 효능 | 청열생진 · 제번 · 지구 · 이뇨 |
| 비교 본초 | 죽엽·죽여·천화분·맥문동 |

## 병증에서 보는 역할

열로 진액이 손상되어 갈증이 나거나 위열로 구역·구토가 생기는 전통 병증에서 청열과 생진을 함께 고려합니다. 구토가 지속되어 물을 마시지 못하거나 소변량 감소·어지럼·의식 변화가 나타나면 탈수와 원인 질환 평가가 필요합니다.

| 전통 방향 | 함께 확인하는 단서 |
|---|---|
| 청열생진 | 열감·구갈, 수분 섭취와 소변 상태 |
| 청위지구 | 구역·구토, 식사·수분을 유지할 수 있는지 |
| 청열이뇨 | 소변의 양·색·통증, 부종 여부 |

## 죽엽·죽여·천화분과 구분

- [죽엽](bamboo-leaf.md): 대나무 잎으로 청열제번·생진을 살핍니다.
- [죽여](bamboo-shavings.md): 대나무 줄기 중간층으로 청열화담·지구가 중심입니다.
- [천화분](trichosanthes-root.md): 뿌리 약재, 청열생진과 소종의 배합을 살핍니다.
- [맥문동](ophiopogon.md): 진액·음을 보하는 방향을 함께 살핍니다.

## 처방과 품질

노근은 처방의 청열·생진·화위 구조 안에서 역할을 읽습니다. 생품·건조품과 절편의 형태가 다를 수 있으므로 기원식물, 약용 부위, 이물과 저장 상태를 확인합니다. 심한 탈수·고열·지속 구토는 한약재 정보만으로 판단하지 않습니다.
