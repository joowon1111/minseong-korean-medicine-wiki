# 만형자(蔓荊子)

만형자는 **두면부의 풍열과 머리·눈 주위 불편을 살피는 본초**입니다. 두통의 위치만으로 선택하지 않고 열감·눈의 불편·외감 여부와 전체 기혈 상태를 확인합니다.

## 기본 정보

| 항목 | 내용 |
|---|---|
| 약용 부위 | 순비기나무류의 성숙한 열매 |
| 생약명 | Viticis Fructus |
| 성미 | 신·고, 미한 |
| 전통 효능 | 소산풍열·청리두목 |

## 대표 처방에서 맡는 역할

| 처방 | 배합에서 읽는 역할 |
|---|---|
| [청상견통탕](../formulas/qingshang-juantong-tang.md) | 맥문동·감국 등과 청리두목하고 강활·방풍·천궁 등의 배합을 연결 |

## 비슷한 본초와 구분

[백지](angelica-dahurica.md)의 거풍·통규, [방풍](saposhnikovia.md)의 거풍승습, [천궁](chuanxiong.md)의 활혈행기와 비교합니다. 서양의 체이스트베리(Vitex agnus-castus) 제품과 기원이 다르므로 관련 호르몬·월경 연구를 만형자에 그대로 적용하지 않습니다.

## 실제 활용에서 확인할 점

눈의 피로를 모두 같은 병증으로 보지 않습니다. 갑작스러운 시력저하·복시, 신경학적 증상이나 심한 새 두통은 별도 평가가 필요하며 실제 배합은 기존 진료·복용약과 함께 확인합니다.
