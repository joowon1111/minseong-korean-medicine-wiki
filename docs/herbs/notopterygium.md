# 강활(羌活)

강활은 **외감 풍한습을 풀면서 항배·상반신 통증을 다루는 거풍습 본초**입니다. 단순한 목·어깨 통증약이 아니라 표증과 풍한습비가 겹친 처방에서 역할을 봅니다.

## 기본 정보와 효능

| 항목 | 내용 |
|---|---|
| 생약명 | Notopterygii Rhizoma et Radix |
| 약용 부위 | 강활류의 뿌리줄기와 뿌리 |
| 성미·귀경 | 신·고, 온 / 방광·신 |
| 전통 효능 | 산한해표·거풍승습·지통 |

## 효능을 병증으로 읽기

- **산한해표:** 오한·발열·무한·신통처럼 풍한습이 표에 머문 증후를 봅니다.
- **거풍승습·지통:** 목덜미·등·어깨·상지의 무거움과 통증이 풍한습과 연결되는지를 봅니다.

상반신이라는 위치만으로 선택하지 않습니다. 급성 외감의 표증인지, 만성 근골격 통증인지, 음혈부족·기혈허·어혈이 중심인지 구분합니다.

## 대표 처방에서 맡는 역할

[구미강활탕](../formulas/jiuwei-qianghuo-tang.md)에서는 방풍·창출·세신과 풍한습을 풀고, 황금·생지황과 표리의 한열·진액을 함께 조절하는 구조를 이룹니다. [독활기생탕](../formulas/duhuo-jisheng-tang.md)의 독활은 만성 요슬부 풍한습과 간신·기혈 허손을 함께 보는 점에서 다릅니다.

→ [강활·독활·방풍 비교](../herbal-integrated/herb-comparisons.md#wind-damp-herbs)

## 현대 연구와 안전성을 읽는 법

강활 원약재·추출물·분리 성분과 강활이 포함된 복합처방은 구분합니다. 통증·관절가동범위·기능·염증지표 연구가 있더라도 거풍습 전체나 특정 근골격 진단의 치료효과로 확대하지 않습니다. 신온조산한 성격을 고려해 음혈·진액 부족, 임신·수유, 출혈 위험과 병용약을 전체 처방 기준으로 확인합니다.
