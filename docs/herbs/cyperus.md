# 향부자(香附子)

향부자는 정서적 긴장, 흉협·복부의 기체와 월경 전후의 통증이 서로 영향을 주는 병증에서 **소간해울·이기관중·조경지통을 연결하는 대표 이기약**입니다. ‘스트레스 약재’로 단순화하지 않고 증상의 위치·시간, 소화·수면·월경과의 관계를 함께 봅니다.

## 기원·약용 부위

| 항목 | 내용 |
|---|---|
| 생약명 | Cyperi Rhizoma |
| 기원·약용 부위 | 향부자 *Cyperus rotundus*의 뿌리줄기 |
| 성미·귀경 | 신·미고·미감, 평; 간·비·삼초경 |
| 핵심 효능 | 소간해울·이기관중·조경지통 |

## 효능을 증상 조합으로 읽기

| 방향 | 함께 보는 단서 |
|---|---|
| 소간해울 | 긴장과 함께 변하는 흉협·명치 답답함, 한숨, 목의 막힌 느낌 |
| 이기관중 | 식후팽만·트림·복통이 감정 변화와 함께 악화하거나 이동함 |
| 조경지통 | 월경 전후의 하복부·유방 불편, 주기와 통증·출혈의 관계 |

기체는 증상이 고정되지 않고 팽팽하거나 이동하는 양상으로 설명되지만, 실제 진료에서는 담음·식적·어혈·기혈허와 겹치는지 구분합니다.

## 대표 처방에서의 배합 역할

향부자는 소간해울·이기·조경지통을 함께 살피는 본초입니다. 스트레스와 함께 변하는 흉복부 답답함·통증·월경 불편을 다른 배합으로 연결합니다.

| 대표 처방 | 본초의 역할 |
|---|---|
| [시호소간산](../formulas/chaihu-shugan-san.md) | 시호·진피·천궁 등과 기체·통증을 다룸 |
| [월국환](../formulas/yueju-wan.md) | 창출·천궁 등과 여러 울체의 배합 |
| [향사육군자탕](../formulas/xiangsha-liujunzi-tang.md) | 국내 방약합편 구성에서 향부자와 건비·이기 약재의 역할 확인 |
| [분심기음](../formulas/fenxin-qiyin.md) | 청피·진피·목향·대복피 등과 흉복부 기체와 수습을 다층적으로 소통 |
| [개울종옥탕](../formulas/kaiyu-zhongyu-tang.md) | 간울과 월경·임신준비 병증에서 보혈·조경약과 배합 |

## 시호·청피·진피와 구분

| 본초 | 중심 역할 |
|---|---|
| **향부자** | 소간해울·이기조경으로 흉복·월경의 기체를 세밀하게 조절 |
| [시호](bupleurum.md) | 소간해울과 화해·승거의 방향으로 병증의 틀을 엶 |
| [청피](green-citrus-peel.md) | 소간파기·소적화체의 힘이 비교적 선명 |
| [진피](citrus-peel.md) | 비위의 이기건비·조습화담이 중심 |

## 포제·경과·안전 확인

식초로 법제한 향부자는 소간지통·조경의 방향을 강조하는 전통이 있으므로 생품·초제품을 구분해 기록합니다. 뿌리줄기의 향·색·절편과 이물·수분을 확인합니다.

월경 불편은 통증 시점·출혈량·주기·냉열·임신 가능성을, 흉복 불편은 식사·배변·수면과의 관계를 함께 봅니다. 임신·수유, 수술 전후, 출혈 경향과 복용약을 확인하고 갑작스러운 흉통·호흡곤란이나 심한 골반통·과다출혈은 원인 평가를 연결합니다.
