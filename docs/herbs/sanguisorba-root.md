# 지유(地楡)

지유는 장미과 오이풀 *Sanguisorba officinalis*의 뿌리를 약용하는 본초입니다. **량혈지혈·해독렴창**의 전통 효능으로 설명하며, 하부 출혈·습열·창양과 관련된 처방 구조에서 살펴봅니다.

| 항목 | 내용 |
|---|---|
| 약용 부위 | 뿌리 |
| 성미·귀경 | 고·산·미한; 간·대장경으로 설명 |
| 전통 효능 | 량혈지혈 · 해독렴창 |
| 주요 비교 | 대계·소계·백급·포황 |

## 병증과 함께 보기

전통적으로 혈열 및 하초 습열과 관련된 출혈·창양 배합에 활용합니다. 혈변·치출혈·이질에 대한 고전 주치는 장관 출혈 원인이나 감염을 판정하는 현대 진단명이 아닙니다. 발열·복통·설사·점액변과 출혈량, 활력 상태를 함께 확인합니다. ‘렴창’은 창양의 수렴·회복을 돕는 전통 표현으로, 깊거나 오염된 상처의 진료를 대체한다는 뜻이 아닙니다.

## 지혈 본초 감별

- [대계](cirsium-japonicum.md)·[소계](cirsium-setosum.md): 엉겅퀴류 지상부·뿌리, 량혈지혈·산어소종.
- [백급](bletilla-tuber.md): 덩이줄기, 수렴지혈·소종생기.
- [포황](cattail-pollen.md): 꽃가루, 생용·초탄 및 혈행 관련 배합을 함께 봄.
- [애엽](mugwort-leaf.md): 온경지혈로 한열 방향이 다름.

지유는 다른 청열·지혈 본초와 배합하여 처방 단위로 살핍니다. 절편의 형태, 뿌리 단면, 기원·이물·가공 규격을 확인하고 출혈이 반복되거나 어지럼·창백·실신이 동반되면 적절한 진료를 받습니다.
