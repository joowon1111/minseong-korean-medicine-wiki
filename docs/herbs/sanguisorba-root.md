# 지유(地楡) {#_1}

지유는 장미과 오이풀 *Sanguisorba officinalis*의 뿌리를 약용하는 본초입니다. **량혈지혈·해독렴창**의 전통 효능으로 설명하며, 하부 출혈·습열·창양과 관련된 처방 구조에서 살펴봅니다.

| 항목 | 내용 |
|---|---|
| 약용 부위 | 뿌리 |
| 성미·귀경 | 고·산·미한; 간·대장경으로 설명 |
| 전통 효능 | 량혈지혈 · 해독렴창 |
| 주요 비교 | 대계·소계·백급·포황 |

## 병증과 함께 보기 {#_2}

전통적으로 혈열 및 하초 습열과 관련된 출혈·창양 배합에 활용합니다. 혈변·치출혈·이질에 대한 고전 주치는 장관 출혈 원인이나 감염을 판정하는 현대 진단명이 아닙니다. 발열·복통·설사·점액변과 출혈량, 활력 상태를 함께 확인합니다. ‘렴창’은 창양의 수렴·회복을 돕는 전통 표현으로, 깊거나 오염된 상처의 진료를 대체한다는 뜻이 아닙니다.

## 지혈 본초 감별 {#_3}

| 본초 | 주로 비교하는 전통 방향 | 구분할 점 |
|---|---|---|
| 지유 | 량혈지혈·해독렴창 | 뿌리, 하부 출혈·습열·창양의 배합 |
| [대계](cirsium-japonicum.md)·[소계](cirsium-setosum.md) | 량혈지혈·산어소종 | 기원종·약용부위와 배합 |
| [백급](bletilla-tuber.md) | 수렴지혈·소종생기 | 덩이줄기, 수렴·회복의 비중 |
| [포황](cattail-pollen.md) | 지혈과 혈행 관련 배합 | 꽃가루, 생용·초탄 구분 |
| [애엽](mugwort-leaf.md) | 온경지혈 | 량혈 계열과 한열 방향이 다름 |

효능명 ‘지혈’만으로 서로 대체하지 않습니다. 출혈 부위·병기·포제와 함께 배합하는 약을 확인하며, 괴화산 원방의 괴화·백엽을 지유로 바꾸었다면 다른 구성으로 기록합니다. [괴화산 4미와 비교](../formulas/huaihua-san.md#formula-structure)

## 지유의 본초학: 량혈지혈과 해독렴창 {#_4}

혈변·치출혈·이질의 전통 주치를 현재의 원인 진단과 나누어 읽습니다. [혈변](../conditions/rectal-bleeding.md)은 출혈량·반복·빈혈과 감염·장관 병변 등을 평가하고, [치핵](../conditions/hemorrhoids.md)은 출혈·통증·탈출을 각각 확인합니다. 약재의 색·맛이나 수렴 성질이 출혈 원인을 확정해 주지는 않습니다.

‘렴창’은 창양의 수렴·회복을 설명하는 전통 용어입니다. 실제 상처는 깊이·오염·감염과 조직 상태를 평가하며, 약재를 임의로 상처나 항문에 바르는 방법으로 연결하지 않습니다.

### 기원·포제와 처방 경과 {#processing-followup}

기원·뿌리 절편·이물·보관·가공 규격을 확인하고 생품과 초탄품의 기록을 구분합니다. 처방에서는 열·습의 비중, 변비·묽은변·소화, 다른 지혈약과 병용약을 함께 봅니다. 경과는 출혈이 덜 보이는 변화와 배변·통증·빈혈 및 원인질환의 결과를 따로 비교합니다.
