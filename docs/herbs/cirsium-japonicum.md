# 대계(大薊)

대계는 엉겅퀴류 *Cirsium japonicum*의 지상부 또는 뿌리를 약용하는 지혈 본초입니다. 전통적으로 **량혈지혈·산어소종**의 방향으로 설명합니다. 대계와 소계는 효능명이 비슷하지만 기원식물과 약재 규격이 달라 별도 본초로 구분합니다.

| 항목 | 내용 |
|---|---|
| 약용 부위 | 지상부·뿌리(규격 확인) |
| 전통 효능 | 량혈지혈 · 산어소종 |
| 함께 살피는 병증 | 혈열로 해석하는 출혈, 종창·창양의 배합 |
| 감별 핵심 | 소계와 기원·형태·규격 구분 |

출혈은 코·잇몸·소변·대변·피부 등 부위와 원인, 양과 지속시간이 다릅니다. 발열·갈증·복통·어지럼·전신 쇠약 등도 함께 평가해야 합니다. 전통의 혈열은 현대 검사 결과나 특정 질환명과 일대일로 대응하지 않습니다.

## 소계·백모근·백급과 비교

| 본초 | 중심 방향 | 구분 |
|---|---|---|
| 대계 | 량혈지혈·산어소종 | 엉겅퀴류, 약용 부위와 기원 확인 |
| [소계](cirsium-setosum.md) | 량혈지혈·산어소종 | 유사 효능이지만 다른 기원종 |
| [백모근](imperata-rhizome.md) | 청열량혈·이수 | 뿌리줄기, 열·소변 양상과 배합 |
| [백급](bletilla-tuber.md) | 수렴지혈·소종생기 | 난초과 덩이줄기, 수렴·생기 방향 |

## 처방·품질

생지황·현삼·측백엽·소계 등과 병증에 따라 배합할 수 있습니다. 단일 약재 주치보다 처방 전체의 한열·허실과 지혈 목적을 확인합니다. 기원식물·사용 부위·이물·가공·검사 자료를 살피며, 반복 출혈이나 토혈·혈변·검은 변·호흡곤란·실신은 신속한 진료가 필요합니다.
