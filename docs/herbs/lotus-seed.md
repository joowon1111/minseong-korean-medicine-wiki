# 연자육·연자(蓮子肉)

연자육은 **비위를 보하면서 오래된 묽은변을 살피고, 심신과 신의 수렴 기능까지 연결하는 본초**입니다. 기력을 보하는 방향과 지나친 소모를 줄이는 방향이 함께 있어 건비·보익 처방의 구성을 이해할 때 유용합니다.

## 기본 정보

| 항목 | 내용 |
|---|---|
| 약용 부위 | 연꽃의 성숙한 씨에서 연자심을 제거한 부분 |
| 생약명 | Nelumbinis Semen |
| 성미 | 감·삽, 평 |
| 전통 효능 | 보비지사·익신삽정·양심안신 |

## 대표 처방에서 맡는 역할

| 처방 | 배합에서 읽는 역할 |
|---|---|
| [삼령백출산](../formulas/shenling-baizhu-san.md) | 산약·백편두와 비위를 보하고 의이인·복령의 삼습을 함께 살핌 |
| [태음인 청심연자탕](../sasang-formula-cards/cheongsimyeonja-tang.md) | 사상체질 병증에 따른 별도 처방 구조에서 연자의 배합을 확인 |

## 비슷한 본초와 구분

[산약](dioscorea.md)은 보비·보폐·보신, [백편두](lablab-seed.md)는 보비화습을 중심으로 비교합니다. 씨 안의 녹색 배아인 **연자심**은 별도 약용 부위이며, 연자육의 건비·수렴 역할과 동일하게 취급하지 않습니다.

## 실제 활용에서 확인할 점

묽은변이 오래간다는 이유만으로 수렴약을 선택하지 않고 배변 양상·식욕·복통과 원인을 함께 확인합니다. 사상처방은 체질·소증·병증 체계 안에서 읽습니다.
