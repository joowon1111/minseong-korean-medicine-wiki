# 천문동(天門冬)

## 핵심 정보
- **생약명:** Asparagi Radix
- **성미:** 감·고, 한
- **귀경:** 폐·신
- **핵심 효능:** 양음윤조, 청폐생진

## 임상에서 읽는 법
