# 화담·이기 본초 임상 지식망

담음과 기체는 임상에서 자주 겹칩니다. **더부룩함·오심·목이물감·가래·흉민·트림·스트레스성 소화불량**의 조합을 봅니다.

이기는 기의 울체·상역을 조절하고, 화담은 담의 성상과 담이 생기는 병기를 다룹니다. 화담을 거담, 이기를 장운동 촉진 한 가지로 축약하지 않습니다. → [효능·주치 표준](../../herbal-integrated/efficacy-indication-standard.md#damp-phlegm)

## 담의 성상과 기체를 나누어 보기 {#phlegm-qi-herbs}

| 중심 방향 | 대표 본초 | 주요 구분 |
|---|---|---|
| 조습화담·강역 | [반하](../pinellia.md) | 한담·습담, 오심·심하비·매핵기 등 배합에 따라 역할이 달라짐 |
| 이기조습·화담 | [진피](../citrus-peel.md) | 비위기체와 담습을 연결하며 반하·복령과 자주 배합 |
| 행기제만 | [후박](../magnolia-bark.md) | 완복창만과 기체가 뚜렷한지 봄 |
| 행기온중·화습 | [사인](../amomum.md) | 비위허한·기체와 습이 겹친 병기에서 봄 |
| 건비삼습 | [복령](../poria.md) | 담이 생기는 비허·수습의 바탕을 다룸 |
| 청열화담 | [천패모](../fritillaria.md)·[죽여](../bamboo-shavings.md) | 열담·조담, 번조·구역의 겸증을 구분 |
| 선폐거담 | [길경](../platycodon.md)·[전호](../peucedanum-root.md) | 폐기의 선강과 기침·가래 양상을 봄 |
| 풍담 | 천남성·[천마](../gastrodia.md) | 풍담과 현훈·경련성 증후의 전통 배합을 보며 안전성을 우선 |

## 핵심 약대

- 반하 + 진피 → 화담 + 이기
- 반하 + 복령 → 담음·비위
- 후박 + 진피 → 복만·기체
- 사인 + 백출·인삼 계열 → 비위허와 기체

### 반하·진피·후박의 역할을 한 처방 안에서 구분하기

| 본초 | 공통으로 만나는 증상 | 처방 안의 중심 역할 |
|---|---|---|
| [반하](../pinellia.md) | 오심·흉민·가래 | 습담을 말리고 위기상역을 내림 |
| [진피](../citrus-peel.md) | 더부룩함·트림·가래 | 비위의 기를 소통하며 조습화담 |
| [후박](../magnolia-bark.md) | 흉복부 답답함·팽만 | 기를 아래로 내려 창만을 풀고 습을 다룸 |

[이진탕](../../formulas/erchen-tang.md)에서는 반하·진피가 담습과 기체를 연결하고, [평위산](../../formulas/pingwei-san.md)에서는 후박·진피가 창만과 습체를 나누어 맡습니다. [반하후박탕](../../formulas/banxia-houpo-tang.md)에서는 반하의 화담·강역과 후박의 행기·제만이 만나 담기울결의 구조를 이룹니다.

반대로 마른기침·인후건조·적은 가래처럼 진액 손상이 중심이면 조습화담약을 기계적으로 늘리지 않고 [맥문동 중심의 양음윤폐](../ophiopogon.md)와 비교합니다.

### 길경의 선폐거담을 처방별로 읽기

길경은 담을 직접 말리는 조습화담약과 달리 **폐기를 펴고 인후·흉격을 열어 담의 배출을 돕는 방향**으로 배합됩니다.

| 처방 | 함께 쓰이는 약물 | 길경을 읽는 초점 |
|---|---|---|
| [은교산](../../formulas/yinqiao-san.md) | 금은화·연교·우방자·박하 | 풍열 초기의 인후 불편과 폐기의 소통 |
| [상국음](../../formulas/sangju-yin.md) | 상엽·국화·행인 | 비교적 가벼운 풍온성 기침에서 선폐거담 |
| [삼소음](../../formulas/renshen-suyin.md) | 인삼·자소엽·전호·반하 | 기허를 겸한 외감·담체에서 폐기를 폄 |
| [삼령백출산](../../formulas/shenling-baizhu-san.md) | 인삼·백출·복령·의이인 | 비허습을 다루면서 상부의 폐기를 소통 |

[길경 상세](../platycodon.md)에서 인후·거담·배농 주치와 혈부축어탕 등 다른 처방에서의 역할을 함께 볼 수 있습니다.

## 현대 연구에서 구분할 것

가래·기침과 오심·복부팽만·위배출·현훈은 서로 다른 결과지표입니다. 반하 원약재·법제품·추출물과 이진탕·온담탕 같은 복합처방도 구분하며, 담음 전체를 객담량 하나로 측정하지 않습니다. 기도 점액이나 염증성 cytokine을 측정한 길경 전임상 연구도 선폐거담이라는 전통 개념 전체 또는 사람의 기침 개선과 동일시하지 않습니다.
