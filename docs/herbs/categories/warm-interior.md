# 온리·온보 본초 임상 지식망

온리·온보 본초는 **차고 아프며 따뜻하게 하면 편해지는 양상, 사지냉감, 비위허한, 신양허**를 중심으로 봅니다.

온리는 이한·한응을 흩는 치법이고 보양은 양허를 보하는 치법입니다. 겹칠 수 있지만 같은 효능은 아닙니다. → [효능·주치 표준](../../herbal-integrated/efficacy-indication-standard.md#regulation)

## 대표 본초

[육계](../cinnamon-bark.md) · 건강 · 부자 계열 · 녹용

## 변증 감별

- 한습: 무겁고 뻣뻣하며 날씨와 연동
- 신양허: 냉감·야간뇨·허리무릎 무력
- 비위허한: 복부 냉감·묽은변·식욕저하

→ [한습](../../diagnostics/patterns/cold-damp.md)  
→ [신음허 vs 신양허](../../diagnostics/differentials/kidney-yin-vs-yang.md)

## 대표 처방

오적산 · 팔미지황환 · 십전대보탕 등에서 온리·온보 약물의 역할을 비교할 수 있습니다.

## 경혈 연결

관원 CV4 · 기해 CV6 · 명문 GV4 · 태계 KI3

## 현대 연구에서 구분할 것

통증·설사·냉감·말초체온·혈압·심박과 안전성 가운데 실제 결과지표를 확인합니다. 특히 부자 계열은 기원·법제·전탕·용량과 부정맥·신경독성 위험을 효능 설명보다 먼저 확인합니다.
