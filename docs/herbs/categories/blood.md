# 보혈·활혈 본초 임상 지식망

한의학의 혈은 **영양·자윤과 순환**을 함께 봅니다. 따라서 혈허와 어혈은 서로 다른 축이지만 한 환자에게 동시에 나타날 수 있습니다.

보혈은 혈허의 영양·자윤 부족을 보하고, 활혈거어는 어혈의 고정통·종괴·월경 이상 등을 다루는 서로 다른 효능입니다. [공통 정의와 연구 해석](../../herbal-integrated/efficacy-indication-standard.md#qi-blood-digestion)을 기준으로 약재별 겸효능을 비교합니다.

## 혈허와 어혈 구분

- **혈허**: 창백·어지럼·피부·모발 건조·수면저하·생리양 감소
- **어혈**: 고정통·찌르는 통증·야간통·타박 후 지속통·혈괴

→ [혈허](../../diagnostics/patterns/blood-deficiency.md)  
→ [어혈](../../diagnostics/patterns/blood-stasis.md)

## 대표 본초 비교

| 구분 | 대표 본초 | 같은 효능 안에서의 차이 |
|---|---|---|
| 보혈·활혈 | [당귀](../angelica.md) | 혈허를 보하면서 혈행을 돕는 축. 혈허와 어혈이 함께 있을 때 배합의 연결점이 됨 |
| 보혈·자음 | [숙지황](../prepared-rehmannia.md) | 혈과 음·정을 기르는 비중이 큼. 점윤한 성질과 소화 상태를 함께 고려 |
| 양혈·렴음 | [백작약](../white-peony.md) | 혈을 기르면서 음을 거두고 완급하는 방향 |
| 양심비·안신 | [용안육](../longan.md) | 심비양허의 건망·심계·수면저하와 함께 보는 보혈약 |
| 활혈행기·지통 | [천궁](../chuanxiong.md) | 기체와 어혈이 겹친 두통·월경통·통증 배합에 자주 연결 |
| 활혈·량혈 | [단삼](../salvia.md)·[적작약](../red-peony.md) | 열과 어혈이 함께 보이는 병기에서 비교. 단삼은 청심제번, 적작약은 량혈산어의 겸효능을 봄 |
| 파혈거어 | [도인](../peach-kernel.md)·[홍화](../safflower.md) | 비교적 강하게 어혈을 깨는 축. 출혈 위험과 임신 가능성을 먼저 확인 |
| 활혈지통 | [현호색](../corydalis.md) | 기체·어혈성 통증을 중심으로 배합 |
| 활혈조경·이수 | [익모초](../leonurus.md) | 월경·산후의 어혈과 수분대사 병기를 함께 보는 약재 |
| 활혈·하행·근골 | [우슬](../achyranthes.md) | 혈행을 아래로 이끌고 요슬부·근골 배합을 연결 |

→ [도인·홍화·단삼·천궁의 처방 역할 비교](../../herbal-integrated/herb-comparisons.md#blood-moving-herbs)

## 대표 배합

- 당귀 + 백작약 → 보혈·양혈의 조화
- 도인 + 홍화 → 활혈거어
- 당귀 + 천궁 → 보혈과 행혈을 함께 고려

→ [본초 배합 지도](../../network/herb-pair-combinations.md)

### 백작약은 보혈방 밖에서도 역할이 달라집니다

| 처방 구조 | 백작약을 읽는 중심 |
|---|---|
| [사물탕](../../formulas/siwu-tang.md) | 숙지황·당귀·천궁과 양혈렴음·완급을 맡아 보혈과 행혈의 균형을 이룸 |
| [계지탕](../../formulas/guizhi-tang.md)·[소건중탕](../../formulas/xiaojianzhong-tang.md) | 계지의 발산·온통과 작약의 수렴·완급을 짝지음. 소건중탕은 작약 비중과 교이로 중초허한 복통에 초점 |
| [작약감초탕](../../formulas/shaoyao-gancao-tang.md) | 감초와 경련성 당김·급박을 완화하는 배합 |
| [당귀작약산](../../formulas/danggui-shaoyao-san.md) | 당귀·천궁의 혈분과 복령·백출·택사의 수습 조절을 연결 |
| [대시호탕](../../formulas/dachaihu-tang.md) | 소양·양명 병증에서 복부 긴장을 완화하며 지실·대황의 공하·행기 구조를 조정 |

따라서 백작약을 ‘보혈약’ 한 칸에만 두지 않고, 실제 처방에서 **양혈·렴음·완급·조화영위** 가운데 어느 역할이 강조되는지 확인합니다.

## 지혈 본초는 따로 구분합니다 {#hemostasis-herbs}

| 출혈 병기 | 대표 본초군 | 읽는 기준 |
|---|---|---|
| 혈열 | 지유·측백엽·대계·소계 | 열과 출혈 부위를 함께 봄 |
| 어혈을 동반한 출혈 | 삼칠·포황 | 지혈과 화어를 함께 고려 |
| 허한 | 애엽 | 충임허한 등 한증성 출혈의 배합에서 봄 |
| 수렴 | 백급·선학초 | 출혈 부위와 원인, 허실을 먼저 감별 |

지혈약은 출혈의 원인을 대신 진단하는 약재군이 아닙니다. 원인불명·대량·지속 출혈, 흑변·토혈, 임신 중 출혈은 즉시 의학적 평가가 우선입니다.

여성 생리증상, 병후 회복, 어지럼, 수면저하, 타박·근골격 통증에서 혈허와 어혈의 비중을 구분합니다.

## 현대 연구에서 구분할 것

보혈 연구의 혈색소·철지표, 활혈 연구의 통증·월경·혈류·혈소판·응고 지표는 서로 다른 연구 질문입니다. 혈허를 빈혈과, 활혈거어를 ‘혈액순환 개선’과 그대로 동일시하지 않으며, 출혈 위험과 항응고제·항혈소판제 병용을 전체 처방 기준으로 확인합니다.
