# 안신 본초 임상 지식망

안신 본초는 불면을 하나의 병명으로 보지 않고 **입면장애·중간각성·심계·건망·긴장·담음·음혈부족**의 조합에 따라 이해합니다.

양심안신과 중진안신의 대상과 배합은 다릅니다. 안신을 ‘진정’ 한 가지 약리작용으로 축약하지 않고 [효능·주치 표준](../../herbal-integrated/efficacy-indication-standard.md#regulation)의 공통 정의를 따릅니다.

## 대표 본초 비교 {#calm-spirit-herbs}

| 방향 | 대표 본초 | 구분해서 볼 점 |
|---|---|---|
| 양혈·양심안신 | [산조인](../ziziphus-seed.md) | 간혈부족·허번·다몽과 땀의 양상을 함께 봄 |
| 양심안신·윤장 | [백자인](../thuja-seed.md) | 심혈·심음 부족과 건조성 변비가 겹치는지를 봄 |
| 교통심신·화담 | [원지](../polygala.md) | 건망·심계뿐 아니라 담이 청규를 막는 병기와 배합을 봄 |
| 건비·안신 | 복신 | 비허·담음과 심신불안이 겹친 처방에서 역할을 확인 |
| 양혈안신 | 야교등 | 혈허·허번과 피부 소양 등 겸증을 문헌과 처방 안에서 구분 |
| 해울안신 | 합환피 | 정서적 울체와 불면·번조가 함께 있는 전통 병기에서 봄 |
| 중진안신·잠양 | 용골·모려 | 중량성 광물·패각 약재로 양심안신약과 용법·안전성이 다름 |

맥문동·오미자는 각각 양음생진과 수렴의 축으로 안신 처방을 보조할 수 있지만, 그 자체를 모든 불면의 대표 안신약으로 묶지는 않습니다.

## 자주 보는 배합

- 산조인 + 원지 → 수면·심계·건망
- 맥문동 + 오미자 → 음액·생진과 수렴
- 당귀·용안육 계열 → 심비양허·기혈부족과 연결
