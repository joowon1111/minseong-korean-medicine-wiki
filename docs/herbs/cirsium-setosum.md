# 소계(小薊)

소계는 엉겅퀴류 *Cirsium setosum*의 지상부를 약용하는 본초입니다. **량혈지혈·산어소종**의 전통 효능이 대계와 겹치지만, 기원식물과 원료 규격은 따로 확인합니다. 이름이나 효능 설명이 비슷하다는 이유로 서로 같은 약재로 취급하지 않습니다.

| 항목 | 내용 |
|---|---|
| 약용 부위 | 지상부 |
| 전통 효능 | 량혈지혈 · 산어소종 |
| 감별 본초 | 대계·백모근·측백엽·포황 |

## 출혈 양상과 처방 배합

전통적인 량혈지혈 배합에서는 출혈의 색·양·빈도, 열감·갈증, 배뇨통·빈뇨, 복부 불편과 피로를 함께 살핍니다. 혈뇨·혈변은 요로·장관의 구조적 원인 평가가 필요할 수 있으므로 주치 표현만으로 판단하지 않습니다. 처방에서는 생지황·치자·측백엽·백모근 등과 병기와 증후에 맞춰 배합합니다.

| 비교 본초 | 구분 포인트 |
|---|---|
| [대계](cirsium-japonicum.md) | 가까운 효능군이나 기원종·약용 부위는 별도 |
| [백모근](imperata-rhizome.md) | 뿌리줄기 약재, 청열량혈과 이수 배합 |
| [측백엽](biota-leaf.md) | 어린 가지·잎 약재, 화담지해 전통도 함께 설명 |
| [포황](cattail-pollen.md) | 꽃가루 약재, 생용·초탄 구분을 살핌 |

## 원료와 안전

이물 혼입, 약용 부위, 기원식물, 건조와 규격을 확인합니다. 지속 출혈, 창백함, 식은땀, 실신, 검은 변은 빠른 진료가 필요합니다. 복용약과 기저질환을 처방 전에 공유해 적절한 처방을 구성합니다.
