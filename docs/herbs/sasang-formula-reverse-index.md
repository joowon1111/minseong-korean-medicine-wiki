# 사상체질별 본초 → 처방 역색인

이 색인은 **본초에서 사상처방으로 거슬러 올라가는 탐색 지도**입니다. 본초 하나를 특정 체질의 전용 약재로 분류하거나, 약재명만으로 처방을 고르는 표가 아닙니다. 같은 본초도 체질병증·배합·용량·포제에 따라 역할이 달라집니다.

`본초 → 처방 안의 역할 → 체질병증 → 가까운 처방과 감별 → 복용 뒤 재평가`

| 체질 | 처방에서 반복해 살필 본초축 | 먼저 연결할 병증축 |
|---|---|---|
| [소양인](#soyangin-herbs) | 지황·산수유·복령·택사 / 형개·방풍·강활·독활 / 석고·지모·황련·황백 | 표병·망음, 흉격열·리열, 음허오열·하소 |
| [태음인](#taeeumin-herbs) | 갈근·황금·길경·나복자 / 건율·의이인·마황·맥문동 / 산조인·석창포·원지 | 위완수한표한·승청 저하, 간수열리열·대변 정체 |
| [소음인](#soeumin-herbs) | 계지·관계·건강·부자 / 인삼·황기·백출·백작약 / 진피·향부자·소엽·반하 | 울광·망양의 표병, 태음병·소음병의 리한 |
| [태양인](#taeyangin-herbs) | 오가피 / 미후등 | 외감요척병·해역, 내촉소장병·열격 |

각 표의 ‘처방 안에서 읽는 축’은 개별 본초의 효능을 독립적으로 보장하는 설명이 아닙니다. 실제 비교는 연결된 처방 문서에서 **전체 구성·원방 용량·법제·적용 병증·경과관찰**을 함께 확인합니다.

## 태양인 처방의 주요 본초 {#taeyangin-herbs}

태양인은 현존 병증·처방 자료가 다른 체질보다 적습니다. 확인되지 않은 본초를 숫자에 맞춰 덧붙이거나 다른 체질 처방을 끌어오지 않고, 처방명과 원전 병증이 확인되는 범위만 제시합니다.

| 본초 | 처방 안에서 읽는 축 | 연결되는 태양인 처방 |
|---|---|---|
| 오가피 | 외감요척병·해역에서 요척·하지 기능을 살피는 축 | [오가피장척탕](../sasang-formula-cards/ogapi-jangcheok-tang.md) |
| 미후등 | 내촉소장병·열격에서 연하·구토·섭취를 살피는 축 | [미후등식장탕](../sasang-formula-cards/mihudeung-sikjang-tang.md) |

오가피·미후등이라는 처방명만으로 전체 구성·용량을 추정하지 않습니다. 진행성 하지 근력저하·보행장애는 신경계·척추 평가를, 연하곤란·반복 구토·체중감소는 위·식도와 영양·탈수 평가를 우선합니다.

## 같은 본초를 비교할 때

| 확인 항목 | 왜 필요한가 |
|---|---|
| 생지황 ↔ 숙지황 | 같은 지황 기원이라도 가공과 처방 속 역할이 다릅니다. |
| 계지 ↔ 관계·계피 | 사용 부위·규격·기재명과 온열축의 강도를 구분해야 합니다. |
| 생강 ↔ 건강 | 생품과 건조·포제 상태를 처방명만 보고 바꾸지 않습니다. |
| 부자·반하·하수오 | 기원·포제·전탕·용량이 안전성과 직결됩니다. |
| 마황·대황·감초 | 혈압·맥박, 설사·탈수, 부종·전해질과 병용약을 확인합니다. |
| 같은 본초의 여러 체질 처방 | 본초가 같아도 체질병증과 배합이 다르므로 서로 대체할 수 없습니다. |

## 근거와 이용 범위

- 이 색인은 위키의 [사상체질별 한약처방](../sasang-formula-cards/index.md)과 각 처방 문서에서 구성·출전을 확인한 본초를 중심으로 정리했습니다.
- 원전·후대 처방집의 수록은 **전통적 병증 맥락과 조성의 근거**입니다. 특정 현대 질환에 대한 치료효과를 자동으로 입증하지 않습니다.
- [사상체질병증 한의표준임상진료지침](https://nikom.or.kr/nckm/module/practiceGuide/view.do?guide_idx=232&menu_idx=14)은 진단·치료·예방·관리를 구조화한 자료입니다. 각 본초를 단독으로 복용하거나 모든 연결 처방의 효과를 동일하게 보장하는 자료가 아닙니다.
- 체질 자가판정이나 자가조제용 표가 아닙니다. 처방 선택은 평소 소증, 현재 표리·한열·순역·경중, 검사 결과와 병용약을 함께 확인하는 진료를 전제로 합니다.
