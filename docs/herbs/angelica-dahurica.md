# 백지(白芷)

백지는 **두면부의 풍사와 통증, 코의 막힘을 함께 살피는 해표 본초**입니다. 이마·얼굴의 묵직함과 코 증상을 한열·습의 양상에 따라 나누며, 다른 거풍·통규 본초와의 배합을 봅니다.

## 기본 정보

| 항목 | 내용 |
|---|---|
| 약용 부위 | 구릿대류의 뿌리; 사용하는 기원과 규격 확인 |
| 생약명 | Angelicae Dahuricae Radix |
| 성미 | 신, 온 |
| 전통 효능 | 거풍·지통·통규 |

## 대표 처방에서 맡는 역할

| 처방 | 배합에서 읽는 역할 |
|---|---|
| [창이자산](../formulas/cangerzi-san.md) | 신이·창이자·박하와 코막힘·비연의 통규 구조를 형성 |
| [청상견통탕](../formulas/qingshang-juantong-tang.md) | 강활·방풍·천궁 등과 두면부 통증의 배합을 살핌 |
| [곽향정기산](../formulas/huoxiang-zhengqi-san.md) | 곽향·자소엽 등과 외감과 습체가 겹친 구성을 이해 |

## 비슷한 본초와 구분

[강활](notopterygium.md)·[방풍](saposhnikovia.md)의 거풍·승습과 비교하고, [신이](magnolia-bud.md)는 코막힘을 다루는 꽃봉오리 본초로 구분합니다. [당귀](angelica.md)·[독활](angelica-pubescens.md)과도 별개 약재입니다.

## 실제 활용에서 확인할 점

두통이나 얼굴 통증을 모두 비염으로 설명하지 않습니다. 새롭게 심한 두통, 시야 변화, 고열 등은 별도 평가가 필요하며 실제 배합은 코·목·전신 상태를 함께 확인합니다.
