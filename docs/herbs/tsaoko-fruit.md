# 초과(草果)

초과는 향이 강한 열매 약재로, **중초의 한습을 말리고 속을 따뜻하게 하는 조습온중**의 역할이 선명합니다. 비위허약을 바탕으로 오한·몸의 무거움·식욕저하·오심·묽은변이 함께 나타나는지를 살펴 방향화습약 사이의 위치를 정합니다.

## 기원·약용 부위

| 항목 | 내용 |
|---|---|
| 생약명 | Tsaoko Fructus |
| 대표 기원 | 초과 *Amomum tsao-ko* 계열의 성숙한 열매 |
| 성미·귀경 | 신, 온; 비·위경을 중심으로 설명 |
| 핵심 효능 | 조습온중·제학 |

열매껍질과 씨앗의 상태, 향·색·수분과 곰팡이 여부를 확인합니다. 정유 성분을 고려해 보관과 전탕 순서를 기록합니다.

## 대표 처방에서의 역할

| 처방 | 배합과 역할 |
|---|---|
| [인삼양위탕](../formulas/renshen-yangwei-tang.md) | 인삼·복령이 허약한 비위를 받치고 창출·후박·진피·반하·곽향이 습담을 조절할 때 산한조습을 강화 |
| 달원음 계열 | 후박·빈랑·지모·황금 등과 막원에 머문 습탁 병증을 다루는 전통적 배합 |

## 사인·백두구·곽향과 구분

| 본초 | 중심 방향 |
|---|---|
| **초과** | 한습이 비교적 깊고 탁하며 오한·중초 냉습이 뚜렷한 방향 |
| [사인](amomum.md) | 행기온중·화습과 안태를 함께 봄 |
| [백두구](white-cardamom.md) | 상·중초의 습탁과 오심을 방향성 있게 풀어 줌 |
| [곽향](agastache.md) | 화중지구와 외감·습체의 동반을 함께 살핌 |

## 임상·품질 확인

식사량, 오심·구토, 복부 냉감과 팽만, 대변 형태, 오한·발열의 경과를 함께 기록합니다. 고열이 지속되거나 반복 구토·탈수·의식 변화가 나타나는 급성 질환은 필요한 진단과 치료를 신속히 연결합니다.

열성·건조 경향, 임신·수유, 간·신장 기능, 항응고제 등 복용약과 다른 온열성 방향약의 중복을 확인합니다.
