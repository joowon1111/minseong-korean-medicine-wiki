# 단삼(丹蔘)

단삼은 **활혈거어(活血祛瘀)·통경지통(通經止痛)**에 **량혈소옹·청심제번**의 방향을 겸하는 본초입니다. 흉비·월경·통증과 심번의 전통 병기를 연결하지만, 현대 심혈관 질환명과 곧바로 같은 개념으로 보지는 않습니다.

## 핵심 정보

- **생약명:** Salviae Miltiorrhizae Radix
- **성미·귀경:** 고·미한, 심·심포·간으로 설명
- **핵심 효능:** 활혈거어, 통경지통, 량혈소옹, 청심제번
- **효능 기준:** [활혈거어의 공통 정의](../herbal-integrated/efficacy-indication-standard.md#qi-blood-digestion)

## 기원·약용 부위·성분층

| 확인 항목 | 내용 |
|---|---|
| 기원·약용 부위 | *Salvia miltiorrhiza*의 뿌리와 뿌리줄기 |
| 지용성 성분군 | tanshinone류 |
| 수용성 성분군 | salvianolic acid류 |
| 제형 구분 | 절편 탕제, 표준화 추출물, 복합 중성약·주사제와 분리 성분을 각각 구분 |

단삼은 추출법에 따라 노출되는 성분군이 달라질 수 있습니다. 따라서 분리 성분의 전임상 결과, 단삼 추출물, 단삼이 들어간 복합제제의 사람 대상 결과를 같은 근거처럼 합치지 않습니다.

## 주치와 본초 감별

| 비교 본초 | 중심 차이 |
|---|---|
| [천궁](chuanxiong.md) | 활혈행기와 거풍지통의 비중이 커 두통·기체 병기와 연결 |
| [적작약](red-peony.md) | 량혈산어의 비중이 뚜렷하며 혈열 병기에서 비교 |
| [도인](peach-kernel.md)·[홍화](safflower.md) | 파혈거어와 조경의 강도를 처방 전체에서 비교 |
| [현호색](corydalis.md) | 활혈행기지통의 통증 조절 역할이 중심 |

단삼의 ‘청심제번’은 불안·불면 전체를 단삼 하나로 다룬다는 뜻이 아니라, 혈열·어혈과 심번이 연결된 처방 문맥에서 읽습니다.

## 처방과 제제에서의 역할

- [천왕보심단](../formulas/tianwang-buxin-dan.md)에서는 생지황·맥문동·산조인 등과 음혈부족·심번의 맥락에서 단삼의 양혈·청심과 혈분 조절을 살핍니다.
- [심적환·복방단삼적환](../formulas/simjeok-hwan.md)은 단삼·삼칠·용뇌 계열 복합제제의 임상연구를 연결합니다.
- [기력강심](../formulas/qiliqiangxin.md)은 단삼을 포함한 다약재 복합제제의 심부전 연구를 다룹니다.

두 자료의 결과는 **단삼 단독 효과가 아니라 각 완성 제제의 결과**입니다. 고전 탕제, 현대 중성약, 단삼 추출물과 분리 성분을 서로 바꾸어 해석하지 않습니다.

## 현대 연구를 읽는 기준

단삼 연구에서는 혈압·협심증 증상·운동능력·심기능·혈소판·응고·내피기능 같은 서로 다른 지표가 다뤄집니다. 어떤 대상에서 어떤 제제와 병용치료를 시험했는지, 임상 결과와 대리지표가 구분됐는지 확인합니다. 전임상 혈관·항염 연구를 ‘활혈거어가 증명되었다’는 문장으로 단순화하지 않습니다.

2018년 종설은 단삼의 심혈관 분야 연구를 성분·약리와 임상 적용으로 나누어 정리했습니다. 이는 통증 전반의 임상효과를 뜻하지 않으며, 통증에서는 흉비·월경·어혈 등 전통 주치와 실제 연구 대상·평가지표가 맞는지 별도로 확인합니다.

- [단삼 심혈관 연구 종설, PMID 29698387](https://pubmed.ncbi.nlm.nih.gov/29698387/)

## 안전과 감별

항응고제·항혈소판제, 출혈성 질환, 수술 전후, 임신 가능성에서는 상호작용과 출혈 위험을 처방 전체 기준으로 확인합니다. 흉통·호흡곤란·실신·신경학적 증상은 즉시 현대 의학적 평가가 우선입니다.
