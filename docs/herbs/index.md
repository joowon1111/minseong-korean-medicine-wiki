# 본초학

본초학은 한약재의 이름과 효능을 외우는 데 그치지 않고, **어떤 상태에서 어떤 역할을 하며 다른 본초와 만나 처방을 어떻게 구성하는지** 살피는 분야입니다.

민성 한의학 아카이브의 본초 문서는 기원·약용 부위, 성미·귀경, 전통적 효능, 실제 처방에서의 역할, 현대 연구와 안전성을 서로 연결해 정리합니다.

## 무엇을 찾고 있나요?

| 찾는 방법 | 추천 출발점 |

| 피로·불면·소화불량처럼 증상부터 찾고 싶어요 | [증상·치법으로 본초·방제 찾기](../herbal-integrated/by-symptom-treatment.md) |
| 비슷한 약재의 차이가 궁금해요 | [주요 본초 비교·감별](../herbal-integrated/herb-comparisons.md) |

| 논문·고전 출전을 확인하고 싶어요 | [본초·방제 근거·출전](../herbal-integrated/evidence.md) |
| 복용약·임신·수술·간신장 기능이 걱정돼요 | [본초·방제 안전·복용 주의](../herbal-integrated/safety.md) |

!!! tip "전문용어를 몰라도 찾을 수 있습니다"
    “자도 피곤해요”, “속이 더부룩해요”, “잠들기 어려워요”, “몸이 붓고 무거워요”처럼 평소 표현으로 시작해도 됩니다. 증상 문서에서 관련 변증·본초·방제로 이어집니다.

## 임상 목적별 본초군

본초는 하나의 효능만 갖는 것이 아니지만, 먼저 치료 방향별 본초군을 잡으면 전체 구조를 이해하기 쉽습니다.

| 본초군 | 이런 상태와 연결해 봅니다 | 대표 본초 |
|---|---|---|
| [보익약](categories/tonics.md) | 쉽게 지침, 식욕·체력 저하, 회복 지연, 근골 허약 | 인삼·황기·백출·당귀·숙지황·녹용 |
| [안신·양심](categories/calm-spirit.md) | 잠들기 어려움, 자주 깸, 두근거림, 생각이 많음 | 산조인·원지·복신·백자인 |
| [화담·이기](categories/phlegm-qi.md) | 더부룩함, 목 이물감, 담음, 메스꺼움, 흉민 | 반하·진피·후박·사인 |
| [이수·거습](categories/drain-damp.md) | 붓기, 몸이 무거움, 소변 불편, 수분대사 저하 | 복령·저령·택사·의이인 |
| [자음·생진](categories/nourish-yin.md) | 입과 목의 건조, 마른기침, 소모 뒤 진액 부족 | 맥문동·생지황·천문동·오미자 |
| [보혈·활혈](categories/blood.md) | 어지럼·건조·혈허, 통증·어혈, 여성의 월경 문제 | 당귀·숙지황·천궁·단삼·도인 |
| [온리·온보](categories/warm-interior.md) | 속과 손발이 차고 복부가 냉하며 기력이 떨어짐 | 건강·육계·부자 |
| [개규](categories/open-orifices.md) | 의식·감각과 관련된 위급하거나 막힌 병증의 전통적 활용 | 사향·석창포 |
| [화해·조화](categories/harmonize.md) | 한열이 엇갈리거나 간비·영위의 조화가 필요한 상태 | 시호·백작약·감초 |

같은 증상도 원인이 다를 수 있습니다. 예를 들어 불면은 혈허·음허·담열·간울 등으로 나뉠 수 있고, 피로도 기허·기혈양허·기음양허·정혈부족으로 구분될 수 있으므로 본초군 하나만으로 처방을 정하지 않습니다.

## 본초는 처방 안에서 어떻게 달라지나요?

같은 본초도 배합에 따라 역할의 중심이 달라집니다.

- **인삼 + 백출 + 복령 + 감초:** 기허와 비위 기능을 돕는 기본 보기 구조
- **당귀 + 숙지황 + 백작약 + 천궁:** 보혈과 혈행을 함께 살피는 기본 구조
- **반하 + 진피 + 복령:** 담음과 비위의 수분대사를 조절하는 구조
- **산조인 + 원지 + 복신:** 심신의 안정과 수면을 돕는 구조
- **두충 + 우슬:** 간신과 근골을 보하면서 허리·무릎 상태를 살피는 구조

더 깊이 보려면 [임상 핵심 본초 배합 지도—약대](../network/herb-pair-combinations.md)와 [본초 찾기](../herbal-integrated/herbs.md)를 이용하세요.

## 개별 본초 문서는 이렇게 읽으세요

1. **기원과 약용 부위:** 같은 이름으로 유통되는 원료가 무엇인지 확인합니다.
2. **성미·귀경:** 한열·윤조·승강과 어느 장부·경락에 작용하는지 살핍니다.
3. **전통적 효능:** 효능명을 현대 질환명과 단순히 일대일로 대응하지 않습니다.
4. **처방 속 역할:** 군·신·좌·사와 배합에 따라 실제 방향이 달라집니다.
5. **현대 연구:** 성분·전임상 연구와 사람 대상 임상시험을 구분합니다.
6. **안전과 품질:** 용량·법제·원산지·검사·복용약과 개인 상태를 함께 확인합니다.

## 안전하게 활용하려면

한약재는 자연물이라는 이유만으로 모든 사람에게 같은 방식으로 안전한 것은 아닙니다. 반대로 약재 이름 하나만으로 위험성을 단정할 수도 없습니다. **정확한 기원, 법제와 전탕법, 용량, 배합, 복용 기간, 환자의 질환과 복용약**을 함께 판단해야 합니다.

특히 임신·수유, 수술 전후, 항암·면역치료 중, 간·신장 기능 저하, 항응고제·항혈소판제 복용, 소아·고령자와 알레르기 병력이 있는 경우에는 처방 전에 관련 정보를 알려야 합니다.
