# 천패모(川貝母)

천패모는 **청열윤폐(淸熱潤肺)·화담지해(化痰止咳)·산결(散結)**의 방향으로 사용하는 패모류 본초입니다. 가래가 있다는 이유만으로 쓰기보다 열·조·폐허와 담의 성상을 함께 봅니다.

## 핵심 정보

- **생약명:** Fritillariae Cirrhosae Bulbus
- **성미·귀경:** 고·감, 미한; 폐·심으로 설명
- **핵심 주치 범위:** 열담·조담의 기침, 폐허구해, 담화가 뭉친 전통 병기
- **효능 기준:** [화담의 공통 정의](../herbal-integrated/efficacy-indication-standard.md#damp-phlegm)

## 비슷한 본초와의 차이

| 비교 본초 | 중심 차이 |
|---|---|
| [반하](pinellia.md) | 온조한 성격의 조습화담·강역지구가 중심으로 습담·한담과 오심에서 비교 |
| [죽여](bamboo-shavings.md) | 청열화담과 제번지구의 비중이 커 담열·번조·구역을 함께 봄 |
| [길경](platycodon.md) | 선폐이인·거담과 상행의 역할을 처방에서 확인 |
| [행인](apricot-kernel.md) | 강기지해평천과 윤장의 비중이 있어 폐기상역을 중심으로 비교 |

천패모와 절패모는 기원과 전통적 활용의 강조점이 다를 수 있으므로 ‘패모’라는 이름만으로 서로 대체하지 않고 실제 규격 약재를 확인합니다.

## 배합과 처방에서 읽기

- **패모 + 과루 계열:** 조열·열담과 흉격의 담결을 함께 보는 전통 배합
- **천패모 + 지모·맥문동 계열:** 폐조·음액손상과 기침의 비중을 함께 봄
- [감로소독단](../formulas/ganlu-xiaodu-dan.md): 습온·습열 병기에서 화습·청열약과 함께 담·인후 불편을 연결
- [육울탕](../formulas/yukwul-tang.md): 담울·기울 등 복합 울체 속 패모의 역할을 확인

## 현대 연구와 안전

패모류 연구에서는 alkaloid 성분, 기침·객담·기도염증 관련 전임상 지표가 주로 탐색됩니다. 천패모 원약재와 다른 패모종, 분리 성분, 복합처방을 구분하고 사람 대상 임상근거의 범위를 별도로 확인합니다. 임신·수유, 만성 호흡기질환, 여러 약물 복용 중에는 전문가가 처방 전체를 검토해야 합니다.

호흡곤란, 객혈, 흉통, 고열 지속, 산소포화도 저하는 화담 변증보다 즉시 의학적 평가가 우선입니다.
