# 목통(木通)

목통은 줄기의 통도성을 이미지로 삼아 **수도와 심·소장의 열을 소통시키는 이수통림약**으로 활용해 온 본초입니다. 소변의 양만 보는 약재가 아니라 배뇨 불편, 열감, 갈증, 부종과 흉복부의 기체가 어떤 조합으로 나타나는지 살펴 처방 안에서 역할을 정합니다.

## 기원·약용 부위 확인

| 항목 | 내용 |
|---|---|
| 생약명 | Akebiae Caulis |
| 약용 부위 | 으름덩굴속 *Akebia* 식물의 목질성 줄기 |
| 대표 기원 | *Akebia quinata*, *A. trifoliata* 계열 등; 적용 공정서의 허용 기원을 확인 |
| 성미·귀경 | 고, 한; 심·소장·방광경을 중심으로 설명 |
| 핵심 효능 | 청심이수·통림·통유 |

목통은 이름이 비슷한 원료가 역사적으로 혼용된 적이 있으므로 **한글명만으로 입고하지 않고 생약명·학명·공정서 규격을 함께 확인**합니다. 특히 *Aristolochia* 계열의 관목통을 목통 대신 사용하지 않습니다.

## 효능을 병증으로 읽기

| 전통 효능 | 함께 보는 단서 |
|---|---|
| 이수통림 | 소변이 시원하지 않음, 배뇨 시 열감, 소변색 변화와 하복부 불편 |
| 청심설화 | 번열·구갈과 심화가 소장으로 이어진 병증 구조 |
| 통리혈맥 | 수습 정체와 열이 함께 있는 부종·비체의 배합 |
| 통유 | 산후 유즙 문제를 기혈·유방 상태와 함께 살피는 전통적 활용 |

배뇨통·빈뇨는 요로감염, 결석, 전립선·방광 질환 등과 감별하고 산후 유방의 발적·고열·심한 통증은 유선염 평가를 함께 진행합니다.

## 대표 처방에서의 역할

| 처방 | 배합에서 읽는 역할 |
|---|---|
| [팔정산](../formulas/bazheng-san.md) | 차전자·편축·구맥·활석·치자·대황 등과 하초 습열의 이수통림을 구성 |
| [분심기음](../formulas/fenxin-qiyin.md) | 향부자·청피·진피·대복피 등의 이기축과 연결되어 흉복 비체와 수습을 함께 소통 |

## 택사·복령·차전자와 구분

| 본초 | 중심 방향 |
|---|---|
| **목통** | 심·소장·방광의 열과 배뇨 불편을 통리하는 축 |
| [택사](alisma.md) | 하초 수습을 배출하고 지황계 처방의 보익축을 조절 |
| [복령](poria.md) | 건비이수와 안신을 함께 담당 |
| [차전자](plantago-seed.md) | 이수통림에 청간명목·청폐화담의 방향을 더함 |

## 품질·안전·경과 기록

공정서 적합 원료의 시험성적서와 공급처 추적성을 확인하고, 절편의 횡단면·색·냄새·이물 여부를 기록합니다. 신장 기능 저하, 탈수, 임신·수유, 이뇨제 복용과 다른 이수약의 중복을 진료에서 확인합니다.

경과는 배뇨 횟수만이 아니라 배뇨통·잔뇨감·소변색, 부종, 체중, 갈증과 수분 섭취를 같은 기준으로 봅니다.
