# 황련(黃連)

## 핵심 정보
- **생약명:** Coptidis Rhizoma
- **성미:** 고, 한
- **귀경:** 심·비·위·간·담·대장
- **핵심 효능:** 청열조습, 사화해독

## 임상에서 읽는 법
심위화·습열·열독의 전통적 병증과 연결한다.

## 효능·주치에서의 위치

황련은 [청열조습](../herbal-integrated/heat-clearing-herbs.md#clear-heat-dry-dampness)을 중심으로 사화해독을 겸합니다. 황금·황백과 공통 정의를 공유하지만 심·위·중초의 화열과 습열을 중심으로 비교하며, [황련해독탕](../formulas/huanglian-jiedu-tang.md)과 [반하사심탕](../formulas/banxia-xiexin-tang.md)에서는 처방 전체의 병기와 역할이 다릅니다.

## 기원·포제와 처방 기록 {#processing}

황련은 뿌리줄기를 사용하며 기원종과 절편 규격을 확인합니다. 생황련 외에도 주황련·강황련·오수유제황련처럼 보조재와 가열법이 다른 포제 전승이 있으므로, 단순히 `황련`으로 합쳐 기록하지 않습니다.

| 확인 영역 | 구분할 내용 |
|---|---|
| 원약재 | 기원종·약용부위·절편·지표성분 |
| 포제품 | 술·생강즙·오수유 등 보조재와 실제 공정 |
| 분리성분 | berberine 단일 성분의 용량·제형 |
| 복합처방 | [황련해독탕](../formulas/huanglian-jiedu-tang.md), [반하사심탕](../formulas/banxia-xiexin-tang.md), [갈근금련탕](../formulas/gegen-qinlian-tang.md)의 상대비와 병기 |

포제별 전통적 사용 방향과 현대 성분 연구는 별도 근거층으로 읽습니다. 특정 포제품의 실험 결과를 황련 전체 또는 황련 함유 처방의 임상효과로 확대하지 않습니다.

## 베르베린과 현대 대사 연구

황련의 주요 알칼로이드인 베르베린은 분리 성분으로도 연구됩니다. **본초 전체·추출물·분리 성분·복합 처방**은 구성과 노출량이 달라 각각의 결과를 구분해 읽습니다.

2004년 *Nature Medicine*의 사람 대상 지질 연구와 별도 기전실험은 [베르베린·콜레스테롤 연구](../conditions/dyslipidemia.md#berberine-lipid-study)에서 확인할 수 있습니다. [황련해독탕](../formulas/huanglian-jiedu-tang.md) 등의 처방에서는 배합과 환자의 병증을 별도로 평가합니다.
