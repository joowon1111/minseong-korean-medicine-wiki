# 적작약(赤芍藥)

적작약은 **혈분의 열과 어혈을 함께 살피는 본초**입니다. 활혈 처방에서는 통증 부위의 고정성, 멍·종창, 열감 등과 전체 병증을 연결해 배합을 이해합니다.

## 기본 정보

| 항목 | 내용 |
|---|---|
| 약용 부위 | 작약류의 뿌리; 기원과 가공 규격을 확인 |
| 생약명 | Paeoniae Radix Rubra |
| 성미 | 고, 미한 |
| 전통 효능 | 청열량혈·산어지통 |

## 대표 처방에서 맡는 역할

| 처방 | 배합에서 읽는 역할 |
|---|---|
| [당귀수산](../formulas/danggui-susan.md) | 당귀미·소목·홍화·도인 등과 외상 뒤 어혈을 살피는 구성 |
| [혈부축어탕](../formulas/xuefu-zhuyu-tang.md) | 도인·홍화·천궁 등의 활혈과 시호·지각의 이기를 연결 |

## 비슷한 본초와 구분

[백작약](white-peony.md)은 양혈렴음·유간완급, 적작약은 청열량혈·산어의 방향을 중심으로 비교합니다. 색깔만으로 구분하거나 백작약을 그대로 대체하지 않고 원료·가공·처방의 출전을 확인합니다.

## 실제 활용에서 확인할 점

월경통과 타박통도 원인이 다릅니다. 임신 가능성, 출혈 상태, 항응고제·항혈소판제 복용 여부를 전체 활혈 배합과 함께 확인합니다.
