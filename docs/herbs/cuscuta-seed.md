# 토사자(菟絲子)

토사자는 **간신과 정을 보하면서 수렴의 역할을 함께 살피는 보익 본초**입니다. 정혈을 채우는 처방에서 숙지황·구기자·산수유 등과 어떤 역할을 나누는지 보면 특징이 분명해집니다.

## 기본 정보

| 항목 | 내용 |
|---|---|
| 약용 부위 | 새삼류의 성숙한 씨; 사용 원료의 기원 확인 |
| 생약명 | Cuscutae Semen |
| 성미 | 감, 온 |
| 전통 효능 | 보신익정·양간명목·고삽 |

## 대표 처방에서 맡는 역할

| 처방 | 배합에서 읽는 역할 |
|---|---|
| [좌귀환](../formulas/zuogui-wan.md) | 숙지황·구기자·산약 등과 진음·정혈을 보하는 구조 |
| [우귀환](../formulas/yougui-wan.md) | 정혈을 받치는 배합에 부자·육계의 온양을 함께 살핌 |
| [수태환](../formulas/shoutai-wan.md) | 상기생·속단·아교와 보신·고충을 읽는 전통 처방 |

## 비슷한 본초와 구분

[구기자](cornus-extra.md)는 자보간신, [산수유](cornus-fructus.md)는 보익과 수렴, [산약](dioscorea.md)은 비·폐·신의 보익을 중심으로 비교합니다. 토사자가 포함된 처방도 음허·양허와 출전별 구성이 다릅니다.

## 실제 활용에서 확인할 점

수태환에 쓰인다는 사실을 토사자 단독의 착상·유산 예방 효과로 해석하지 않습니다. 임신 중 출혈·복통이 있으면 원인 평가와 산과 진료를 먼저 연결하고, 실제 사용은 임신 단계·배합·복용약을 확인합니다.
