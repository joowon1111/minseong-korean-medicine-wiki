# 오수유(吳茱萸)

오수유는 **속의 한증과 위로 치미는 기역을 함께 살피는 온리 본초**입니다. 냉감과 복부 통증·구역이 연결되는지, 온경 배합이 필요한지를 전체 병증으로 확인합니다.

## 기본 정보

| 항목 | 내용 |
|---|---|
| 약용 부위 | 오수유류의 덜 익은 열매 |
| 생약명 | Euodiae Fructus |
| 성미 | 신·고, 열 |
| 전통 효능 | 산한지통·강역지구 |

## 대표 처방에서 맡는 역할

| 처방 | 배합에서 읽는 역할 |
|---|---|
| [온경탕](../formulas/wenjing-tang.md) | 온경산한과 당귀·작약·맥문동 등의 양혈·양음이 함께 작동하는 구조 |
| [조경종옥탕](../formulas/tiaojing-zhongyu-tang.md) | 건강 등의 온경과 이기·양혈 배합을 임신 준비 단계에서 구분 |

## 비슷한 본초와 구분

[건강](dried-ginger.md)의 온중, [육계](cinnamon-bark.md)의 온양과 비교합니다. **산수유**는 보익간신·수렴의 다른 본초이므로 ‘수유’라는 이름만으로 혼동하지 않습니다.

## 실제 활용에서 확인할 점

성질이 뜨겁고 자극성·독성에 유의하는 약재이므로 가공·용량·기간을 확인합니다. 속쓰림이나 상열감만 보고 온리약을 선택하지 않으며 임신 가능성·복용약을 함께 살피고 임신 확인 뒤에는 처방을 재평가합니다.
