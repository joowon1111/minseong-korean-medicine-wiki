# 상백피(桑白皮)

상백피는 **폐열에 의한 기침·숨참과 수분 정체를 살피는 본초**입니다. 기침과 부종이라는 증상명만으로 고르지 않고 한열·허실과 전체 배합을 나누어 봅니다.

## 기본 정보

| 항목 | 내용 |
|---|---|
| 약용 부위 | 뽕나무의 뿌리껍질 |
| 생약명 | Mori Cortex |
| 성미 | 감, 한 |
| 전통 효능 | 사폐평천·이수소종 |

## 대표 처방에서 맡는 역할

| 처방 | 배합에서 읽는 역할 |
|---|---|
| [정천탕](../formulas/dingchuan-tang.md) | 마황·행인·황금·반하 등과 선폐·청열·화담의 역할을 나누어 살핌 |

## 비슷한 본초와 구분

[상엽](mulberry-leaf.md)은 잎을 쓰며 소산풍열·청폐윤조에 초점을 둡니다. [행인](apricot-kernel.md)은 강기지해, [복령](poria.md)은 건비이수 방향과 비교합니다. 상백피를 단순한 이뇨제나 모든 숨참에 쓰는 약재로 보지 않습니다.

## 실제 활용에서 확인할 점

갑작스러운 호흡곤란이나 흉통·심한 부종은 심장·폐·신장 등의 원인을 먼저 평가합니다. 실제 배합은 현재 치료와 복용약, 신장 기능 및 전탕·가공 상태를 확인합니다.
