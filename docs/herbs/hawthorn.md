# 산사(山楂)

산사는 **음식이 정체된 식적을 풀어 소화를 돕는 본초**입니다. 식후 더부룩함과 트림, 과식 뒤 답답함을 소식약의 배합 안에서 살핍니다. 특히 전통적으로 육류·기름진 음식의 적체를 설명할 때 자주 등장합니다.

## 기본 정보

| 항목 | 내용 |
|---|---|
| 약용 부위 | 산사나무류의 잘 익은 열매 |
| 생약명 | Crataegi Fructus |
| 성미 | 산·감, 미온 |
| 전통 효능 | 소식화적·행기산어 |

## 대표 처방에서 맡는 역할

| 처방 | 배합에서 읽는 역할 |
|---|---|
| [보화환](../formulas/baohe-wan.md) | 신곡·나복자와 소식하고, 반하·진피·복령과 담습을 함께 살핌 |
| [정전가미이진탕](../formulas/jeongjeon-gami-ijin-tang.md) | 맥아·신곡의 소식과 이진탕 계열 화담 구조를 연결 |

## 비슷한 본초와 구분

[맥아](barley-malt.md)는 곡식 적체와 건비개위, [나복자](raphanus-seed.md)는 소식과 강기화담을 함께 비교합니다. 식욕이 낮다고 모두 식적인 것은 아니므로 [백출](atractylodes.md)의 보기건비 방향과 구분합니다.

## 실제 활용에서 확인할 점

생품·초품 등 가공과 배합 목적을 확인합니다. 산사 열매와 서양 산사 잎·꽃 추출물은 원료가 달라 연구 결과를 그대로 옮기지 않습니다.
