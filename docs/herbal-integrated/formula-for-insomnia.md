# 불면·두근거림 한약 처방 찾기

불면은 같은 진단명이어도 **잠들기 어려운지, 자주 깨는지, 너무 일찍 깨는지**, 그리고 피로·심계·열감·소화·담음 증상이 어떻게 동반되는지에 따라 처방 방향이 달라집니다.

## 먼저 수면 양상을 구분합니다

| 확인 항목 | 기록할 내용 |
|---|---|
| 수면 형태 | 입면곤란·야간각성·새벽각성·얕은 잠·다몽 |
| 시간 | 잠드는 데 걸리는 시간, 총수면시간, 기상시간, 주말 차이 |
| 낮 기능 | 졸림·피로·집중력·두통·운전과 업무 영향 |
| 동반 증상 | 심계·구건·열감·식은땀·식욕저하·오심·어지럼·월경주기 |
| 악화 요인 | 카페인·음주·야식·교대근무·통증·폐경기·복용약 |
| 위험신호 | 코골이·무호흡, 심한 주간졸림, 흉통·실신, 갑작스러운 행동변화 |

## 치료반응을 확인하는 방법

처방 전후에는 ‘잘 잤다’는 느낌만 아니라 **PSQI·ISI, 입면시간, 야간각성 횟수, 총수면시간, 다음 날 기능**을 함께 봅니다. 1~2주 수면일지를 작성하면 생활리듬과 치료반응을 구분하는 데 도움이 됩니다.

한약은 수면위생, 일정한 기상시간, 빛·운동 조절과 함께 계획합니다. 만성불면에서는 불면 인지행동치료를 포함한 비약물치료도 중요한 축입니다.
