# 통증·관절통·근육통의 주요 본초와 한약 처방

## 환자가 이렇게 검색할 수 있습니다

- 통증 한약재
- 관절에 쓰는 한약재
- 허리통증 약재
- 독활 두충 우슬
- 근육통 한약재
- 어혈 약재

## 관련 본초

**근육이 당기는 통증, 차고 무거운 통증, 고정된 통증, 오래된 요슬부 허약**을 구분하면 주요 본초의 배합 목적을 이해하기 쉽습니다.

| 본초 | 전통적 배합 목적 | 연결해서 볼 방제·상태 |
|---|---|---|
| [백작약](../herbs/white-peony.md) | 양혈·유간지통, 긴장과 경련성 당김 | [작약감초탕](../formulas/shaoyao-gancao-tang.md), [쌍화탕](../formulas/ssanghwa-tang.md) |
| [당귀](../herbs/angelica.md)·[천궁](../herbs/chuanxiong.md) | 양혈·활혈과 통증 조절의 배합 | [소경활혈탕](../formulas/shujing-huoxue-tang.md), [당귀수산](../formulas/danggui-susan.md) |
| [독활](../herbs/angelica-pubescens.md) | 거풍습·지통, 풍한습과 요슬부 통증 | [독활기생탕](../formulas/duhuo-jisheng-tang.md) |
| [강활](../herbs/notopterygium.md) | 거풍습·해표와 몸의 뻣뻣함을 보는 배합 | [회수산](../formulas/huishou-san.md) |
| [두충](../herbs/eucommia.md) | 보간신·강근골, 오래된 허리·무릎의 시큰함·허약 | 독활기생탕, [우귀환](../formulas/yougui-wan.md) |
| [우슬](../herbs/achyranthes.md) | 활혈과 요슬부를 함께 보는 배합 | 소경활혈탕, 독활기생탕 |
| [속단](../herbs/dipsacus.md) | 보간신·강근골·속절상의 전통적 배합 | 손상과 허약의 맥락에서 두충·우슬과 비교; 독활기생탕 원방의 구성약은 아님 |

두충·우슬·속단을 모두 같은 ‘관절약’으로 보지 않습니다. 이 표는 배합을 읽는 안내이며 연골 재생이나 골절 유합을 보장하는 의미는 아닙니다.

## 본초를 이해하는 관점

| 통증에 동반되는 양상 | 전통적 변증·치법 | 비교할 처방 |
|---|---|---|
| 과로 후 몸이 쑤시고 회복이 더딤 | 기혈부족·보익 | [쌍화탕](../formulas/ssanghwa-tang.md), [피로 본초·처방](herbs-for-fatigue.md) |
| 다리가 갑자기 당기고 쥐가 남 | 근육의 경련성 통증·완급지통 | [작약감초탕](../formulas/shaoyao-gancao-tang.md) |
| 팔다리 통증에 혈허·어혈·풍습이 겹침 | 양혈·활혈·거풍습 | [소경활혈탕](../formulas/shujing-huoxue-tang.md) |
| 냉감·몸의 무거움에 소화·담습 문제가 겹침 | 한습·기혈·담의 복합 배합 | [오적산](../formulas/wujisan.md) |
| 목·어깨·전신의 뻣뻣함과 풍한습 양상 | 거풍습·통증 배합 | [회수산](../formulas/huishou-san.md) |
| 외상 후 멍·고정된 통증이 중심 | 어혈·활혈거어 | [당귀수산](../formulas/danggui-susan.md) |
| 오래된 허리·무릎 통증과 허약이 동반 | 풍한습비와 간신·기혈의 부족 | [독활기생탕](../formulas/duhuo-jisheng-tang.md) |

처방명보다 먼저 **통증 위치, 붓기·열감, 저림·근력, 유발동작, 수면·피로**를 확인합니다. 열나고 붓는 관절은 한습으로 단정하지 않고 염증·감염 등 원인을 평가합니다.

## 한약과 침·전침·약침을 연결하는 기준 {#pain-herb-treatment}

한약은 통증과 함께 나타나는 냉열·소화·수면·회복 상태를 변증해 구성합니다. [침](../treatments/acupuncture.md)·[전침](../treatments/electroacupuncture.md)은 통증 부위와 근육 긴장·기능을 평가해 적용하고, [약침](../treatments/pharmacopuncture.md)은 성분·주입 부위·적응증별 근거와 안전성을 따로 봅니다. 탕제 연구의 결과가 같은 이름의 약침에 그대로 적용되는 것은 아닙니다.

[근골격 한약 임상근거](../authority/formulas/musculoskeletal-herbal-evidence.md)에서 질환별 결과를 확인하고, 치료 전후 **통증 강도·관절 움직임·보행 또는 작업 지속시간·수면**을 비교합니다. 작약감초탕의 경련 연구도 모든 운동 후 근육통에 대한 효과로 확대하지 않습니다.
