# 근거·출전

## 전통자료
- 고전 원전의 처방 구성과 주치
- 한국전통지식포탈의 본초·처방 데이터
- 출전별 동명 처방의 구성 차이

## 현대근거
- 기초·전임상 연구
- 증례·관찰연구
- 무작위대조시험
- 체계적 문헌고찰·메타분석
- 임상진료지침

## 읽는 원칙
1. 개별 성분 연구와 완성 처방 임상효과를 구분
2. 전임상 결과와 사람 임상시험을 구분
3. 전통 적응 병증과 현대 질환명을 그대로 동일시하지 않음
4. 출전별 처방구성이 다르면 혼합하지 않음
