# 여성·난임 본초 역인덱스

## 읽는 방법

본초는 ‘난임에 좋은 약재’ 순위가 아니라 **전통 효능 → 귀경 → 병기 → 배합 → 방제 → 활용 → 현대 연구**로 읽습니다. 귀경은 전통적 작용 분류이며 해당 장기의 현대 해부학·호르몬 표적과 같지 않습니다. [난임 변증](../womens-health/fertility-patterns.md), [처방 네트워크](formula-for-women.md)와 함께 확인합니다.

| 본초 | 전통 효능·귀경 | 배합·포함 방제와 활용 | 반드시 구분할 점 |

| [익모초](../herbs/leonurus.md) | 활혈조경·이수; 간·심포·방광 | 어혈·수습의 월경/산후 맥락 | 임신 중 자가복용 금지; 산후도 출혈·잔류조직 평가 |
| [단삼](../herbs/salvia.md) | 활혈거어·양혈안신; 심·간 | 어혈·혈행·심번 증후의 배합 | 항응고·항혈소판 병용 주의 |
| [도인](../herbs/peach-kernel.md) | 활혈거어·윤장; 심·간·대장 | 계지·목단피·작약·복령, [계지복령환](../formulas/guizhi-fuling-wan.md) | 고전 임신 주의와 실제 용량·제제 안전성 별도 |
| [홍화](../herbs/safflower.md) | 활혈통경·거어; 심·간 | 도인·당귀 등 | 월경통 활용을 착상 촉진으로 바꾸지 않음 |
| [목단피](../herbs/moutan.md) | 청열량혈·활혈; 심·간·신 | 계지복령환·육미지황환 | 처방 전체와 임신 시기를 검토 |

혈어 증후와 자궁강 병변·난관 폐쇄는 다른 정보입니다. 활혈약이 폐쇄를 뚫거나 이식 후 착상을 높인다는 일반 효과를 주장하지 않습니다.

## 현대 연구에서는 무엇을 조사했나요?

성분·세포·동물 연구에서 항염·산화스트레스·호르몬 경로를 조사한 결과는 **사람의 자연임신·생아출산 효과가 아닙니다**. 복합 처방 RCT의 결과도 포함 본초 하나의 효과로 분해할 수 없습니다. [오자연종환 연구](../formulas/wuzi-yanzong-wan.md)와 [여성 난임 한약 메타분석](../authority/conditions/female-infertility-art.md)을 통해 연구 대상·제제·대조군·출산과 안전성 보고를 확인합니다.

## 안전성과 연결망

귀경·전통 효능·고전 안태 기록만으로 임신 안전성을 보장하지 않습니다. 독성 약재·법제·용량·배합·오염·제품 품질, 항응고제·호르몬제·간신장질환을 확인합니다. [임신 가능 시기부터 초기 임신까지 안전성](safety.md#fertility-pregnancy-safety)이 우선입니다.
