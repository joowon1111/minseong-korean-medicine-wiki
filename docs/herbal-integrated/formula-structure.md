# 처방 구조·비교

처방을 개별 이름으로 외우기보다 **기본 골격이 어떻게 변형되는지**를 봅니다.

## 1. 보기·기혈 보익 계열

```text
사군자탕
 ├─ + 진피·반하 → 육군자탕
 ├─ + 목향·사인 등 → 향사육군자탕
 └─ + 승마·시호·황기 강화 → 보중익기탕

사물탕
 └─ + 사군자탕 → 팔물탕
      └─ + 황기·육계 → 십전대보탕
```

**갈림점:** 비기허 / 담습 / 기체 / 중기하함 / 혈허 / 기혈양허.

## 2. 담음 계열

```text
이진탕
 ├─ 담울·심번 → 온담탕·가미온담탕
 ├─ 비허담습·현훈 → 반하백출천마탕
 └─ 완고한 담습 → 도담탕
```

**갈림점:** 담습 자체 / 담울·담열 / 비허 / 현훈 / 불면.

## 3. 비위·습체 계열

```text
평위산
 ├─ + 보기·화담·이기 → 향사육군자탕
 ├─ 허한·기체 강화 → 향사양위탕
 ├─ + 이수 → 위령탕
 └─ 외감+습체 → 불환금정기산·곽향정기산
```

**갈림점:** 습체 / 비허 / 허한 / 외감 / 수습.

## 4. 간울·기체 계열

```text
소요산
 └─ + 청열 → 가미소요산

시호소간산 → 기체·흉협통 중심
반하후박탕 → 담기울결·매핵기
분심기음 → 칠정기울 + 수습·담
```

## 5. 수습·이수 계열

```text
오령산 → 수습·기화불리
저령탕 → 수열호결 + 음손
진무탕 → 양허 + 수기내정
영계출감탕 → 중양부족 + 담음
실비음 → 비양허 수종 + 행기
팔정산 → 습열하주·열림
```

## 6. 폐·해수·천식 계열

```text
삼소음 → 기허 + 외감풍한 + 담
마행감석탕 → 폐열
정천탕 → 담열옹폐
소자강기탕 → 상실하허 + 기역·담연
행소산 → 량조
보폐탕 → 폐기허
생맥산 → 기음양허
```

## 7. 청열 계열

```text
황련해독탕 → 실열·화독
용담사간탕 → 간담실화·습열
백호탕 → 양명기분대열
죽엽석고탕 → 열병 후 여열 + 기음손상
청서익기탕 → 서열 + 기진양상
```

## 8. 어혈·통락 계열

```text
혈부축어탕 → 흉중어혈 + 기체
보양환오탕 → 기허혈어 + 통락장애
도핵승기탕 → 하초축혈 + 공하
```

## 9. 두통·현훈 계열

```text
천궁다조산 → 외풍 두통
청상견통탕 → 풍한·풍열·습담·혈분 복합
반하백출천마탕 → 비허담습·풍담
천마구등음 → 간양상항·간풍
창이자산 → 비연·비색·두통
```

## 임상에서 읽는 순서

`주증상 → 병증축 → 기본 처방군 → 가감되는 병리 요소 → 후보 2~4개 → 상세 구성·용량·출전`
