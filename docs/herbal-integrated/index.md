# 본초·방제 한눈에 보기

본초와 방제를 **증상이나 약 이름에서 바로 시작해도 핵심 구조를 빠르게 파악할 수 있도록** 정리합니다.

| 찾고 싶은 것 | 바로가기 |
|---|---|
| 개별 약재의 성미·귀경·효능 | [본초 찾기](herbs.md) |
| 대표 처방의 구성·방의 | [방제 찾기](formulas.md) |
| 녹용·공진단·경옥고 | [보익·회복 핵심](tonic-recovery.md) |
| 피로·불면·소화·통증에서 처방 찾기 | [증상·치법으로 찾기](by-symptom-treatment.md) |
| 비슷한 처방의 공통 골격과 차이 | [처방 구조·비교](formula-structure.md) |
| 금기·상호작용·주의 | [안전·복용 주의](safety.md) |
| 원전·논문·임상근거 | [근거·출전](evidence.md) |

```text
증상·병증 → 치법 → 본초 → 배합 → 방제 → 치료반응 → 재평가
```

## 핵심 원칙
**같은 증상 = 같은 처방**이 아닙니다.  
먼저 병증과 치료방향을 정하고, 그 다음 본초와 방제를 봅니다.
