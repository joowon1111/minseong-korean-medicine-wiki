본초와 방제를 **약 이름 / 증상 / 병증 / 치법 어느 쪽에서 시작해도 같은 지식망으로 연결**되도록 정리합니다.

| 처방명을 찾고 싶다 | [방제 찾기](formulas.md) |


## 핵심 원칙

**같은 증상 = 같은 처방이 아닙니다.**

본초와 방제는 따로 떨어진 사전이 아니라  
`병증 → 치법 → 본초 → 배합 → 방제`라는 하나의 연결망으로 봅니다.
