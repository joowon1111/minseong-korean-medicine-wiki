# 일반 방제 임상 지도

일반 방제를 **병증과 치법 중심으로 한눈에 비교**하고, 필요한 처방 상세로 바로 내려갑니다.

`증상 → 병증 → 치법 → 처방군 → 갈림점 → 개별 처방 → 구성·용량 → 출전·근거`

## 임상 핵심 처방 100선 {#core-formulas-100}

**현재 한의 임상에서의 활용도, 방제학적 기본 구조, 고전·질환·본초·현대 근거와의 연결 가치**를 함께 고려해 정밀하게 관리할 처방입니다.

각 상세 문서에서는 처방명만 보지 않고 `대표 출전 → 원방의 약미·상대비 → 수치(修治)·법제 → 제형·전탕 → 임상 감별 → 현대 연구`를 확인합니다. 같은 처방명도 출전·제형·구성비가 다르면 별도 기록으로 구분합니다.

## 한약치료의 비중을 높여 볼 임상상황

한약은 특히 **전신 병증과 여러 증상군이 하나의 패턴으로 묶일 때** 처방구조를 통해 탐색합니다.

| 임상상황 | 먼저 비교할 처방군 |
|---|---|
| 소화불량 + 피로 | 평위산·향사육군자탕·보중익기탕 등 병증별 비교 |
| 불면 + 심계 + 피로 | 귀비탕·천왕보심단·가미온담탕 |
| 현훈 + 오심·담 | 반하백출천마탕·이진탕 |
| 만성통증 + 허약 | 독활기생탕·기혈보익 처방군 |
| 기침 + 피로·허증 | 보폐탕·생맥산 |
| 스트레스 + 소화 + 불면 | 소요산·시호소간산·가미온담탕 |
