# 일반 방제 임상 지도

일반 방제를 **병증과 치법 중심으로 한눈에 비교**하고, 필요한 처방 상세로 바로 내려갑니다.

`증상 → 병증 → 치법 → 처방군 → 갈림점 → 개별 처방 → 구성·용량 → 출전·근거`

## 이 페이지를 읽는 법

1. **증상명보다 병증축을 먼저 찾습니다.**
2. 같은 처방군 안에서 **한열·허실·담습·어혈·기체·수습**의 차이를 봅니다.
3. 후보 처방을 2~4개로 좁힌 뒤 상세 페이지에서 **구성·용량·출전·유사처방 차이**를 확인합니다.
4. 동명 처방은 출전별 구성을 섞지 않습니다.
