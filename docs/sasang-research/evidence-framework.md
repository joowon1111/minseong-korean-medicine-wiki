# 사상의학 연구는 어떻게 읽어야 하나?

사상의학 연구를 읽을 때는 **체질진단 연구와 치료효과 연구를 구분**하면 이해가 쉬워진다.

```text
체질진단 연구
→ 체질을 얼마나 일관되게 분류할 수 있는가?

임상연구
→ 특정 체질·병증에서 치료 후 어떤 변화가 나타나는가?

생활관리 연구
→ 체질별 식사·운동·생활 특성이 어떤 건강지표와 연결되는가?
```

또한 사상체질 연구에서는 체질 판별 기준과 병증 분류가 연구마다 다를 수 있으므로 **어떤 진단기준을 사용했는지**를 함께 보는 것이 중요하다.

이 페이지는 연구의 한계를 강조하기보다, 사상의학 연구를 더 정확하게 이해하기 위한 구조를 제공한다.
