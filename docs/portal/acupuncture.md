# 침구·치료

침구·치료를 **경혈 이름의 목록**으로만 보지 않고, 환자가 느끼는 통증·저림·기능저하에서 출발해 해부학과 신경생리, 경혈·경락, 치료방법과 현대 임상근거까지 연결합니다.

`증상·통증 위치 → 감별 → 근육·말초신경 → 신경포착 → 경혈·경락 → 침·전침·약침·뜸·부항 → 치료반응 → 현대 임상근거`

## 어디서부터 찾을까요?

### 통증·증상에서 시작

목·어깨·허리·무릎·팔꿈치·발목·두통·저림처럼 **불편한 부위와 증상**에서 관련 치료와 근거를 찾습니다.

→ [통증·증상으로 찾기](../acupuncture-integrated/by-symptom.md)  
→ [근골격 통증 핵심](../acupuncture-integrated/musculoskeletal.md)

### 손발 저림·신경통에서 시작

저림의 위치와 감각분포를 따라 정중신경·척골신경·요골신경·좌골신경·총비골신경·경골신경 등의 주행과 주요 포착부위를 탐색합니다.

→ [신경포착증후군](../nerve-entrapment/index.md)

### 근육과 말초신경에서 시작

Dermatome·Myotome, spinal root, peripheral nerve, muscle을 연결해 **신경근병증과 말초신경 포착, 근육성 통증을 구분하는 임상해부학**을 탐색합니다.

→ [근육·말초신경 임상해부학](../clinical-anatomy/index.md)

### 경혈·경락에서 시작

WHO 표준 361경혈과 경맥을 한글명·국제표준코드로 탐색합니다.

→ [WHO 표준 361경혈 임상 아틀라스](../acupoint-network/standard-atlas.md)  
→ [경혈·경락 찾기](../acupuncture-integrated/points-meridians.md)

### 치료법에서 시작

침·전침·약침·뜸·부항의 특징과 임상 적용을 비교합니다.

→ [침·전침·뜸·부항](../acupuncture-integrated/modalities.md)

## 신경포착증후군

말초신경은 해부학적으로 좁은 공간이나 반복적인 압박·마찰을 받기 쉬운 위치에서 자극될 수 있습니다.

대표적으로 다음 영역을 연결합니다.

- 손목터널증후군 — 정중신경
- 척골신경 포착·주관증후군
- 요골신경 포착
- 원회내근증후군
- 흉곽출구증후군
- 심부둔부·좌골신경
- 외측대퇴피신경 포착
- 총비골신경 포착
- 족근관증후군

임상 탐색은 다음 순서를 기본으로 합니다.

`저림·통증 위치 → 감각분포 → 근력·반사 → 신경근 → 말초신경 → 포착부위 → 관련 근육 → 침구`

→ [신경포착증후군 전체 보기](../nerve-entrapment/index.md)

## 근육·말초신경 임상해부학

침구 임상에서 해부학은 단순히 근육의 기시·정지를 외우는 것보다 **증상이 어느 신경·근육·분절과 연결되는지**를 이해하는 데 중요합니다.

핵심 관계는 다음과 같습니다.

`Dermatome → Myotome → Spinal root → Peripheral nerve → Muscle → Entrapment site → Acupoint`

현재 아카이브에서는 상지·하지 말초신경, 경부·견갑대, 둔부·고관절, 주요 신경포착부위를 연결해 탐색할 수 있습니다.

→ [Dermatome·Myotome 임상지도](../clinical-anatomy/dermatome-myotome.md)  
→ [말초신경 포착부위 지도](../clinical-anatomy/peripheral-nerve-map.md)

## 침의 과학적 접근

침 자극을 현대 생의학적으로 이해할 때는 하나의 단일 기전보다 **말초조직에서 시작해 척수·뇌·자율신경계로 이어지는 다층적인 신경생리 과정**으로 보는 것이 유용합니다.

### 말초 단계
`침 자극 → 피부·근육·결합조직 → 감각신경 → DRG → 척수`

감각신경 섬유, ATP·adenosine, purinergic signaling, TRPV 계열 수용체 등 다양한 말초 기전이 연구되어 왔습니다.

### 통증조절
척수 후각과 PAG–RVM 등의 하행성 통증조절계, endogenous opioid·serotonin·noradrenaline 등 여러 신경전달계가 연구되고 있습니다.

### 뇌·중추신경계
ACC·insula·thalamus·somatosensory cortex·default mode network 등 통증·감각·정서·주의와 관련된 뇌 네트워크의 변화가 neuroimaging 연구에서 탐색되고 있습니다.

### 자율신경계
체성감각 입력이 척수·뇌간·시상하부 등을 거쳐 교감·부교감 출력으로 연결되는 **somato-autonomic reflex**가 중요한 연구축입니다.

### 전침
전침은 frequency·intensity·pulse width·stimulation time을 비교적 명확하게 조절할 수 있어 자극의 `dose`를 연구하기 좋은 치료방식입니다.

→ [침의 과학적 접근 전체 보기](../acupuncture-science/index.md)

## WHO 표준 361경혈

경혈은 **족삼리 ST36, 내관 PC6, 신문 HT7, 삼음교 SP6, 합곡 LI4**처럼 한글명과 국제 표준 코드를 함께 사용합니다.

아카이브에서는 경혈을 단순 위치 정보에서 끝내지 않고 가능한 범위에서 다음 관계로 확장합니다.

`경혈 → 해부층 → 근육 → 말초신경 → spinal segment → 관련 증상·질환 → 임상근거`

→ [WHO 표준 361경혈 임상 아틀라스](../acupoint-network/standard-atlas.md)

## 침구치료 현대 임상근거

현대 침구 연구는 질환별로 통증점수뿐 아니라 기능·삶의 질·수면·신경학적 기능 등 실제 임상 outcome을 함께 평가합니다.

대표적으로 아카이브에서는 다음 영역의 RCT·systematic review·meta-analysis를 연결합니다.

- 만성 요통·목통증
- 무릎 골관절염
- 편두통
- 손목터널증후군
- 알레르기비염
- 기능성소화불량
- 불면
- 뇌졸중 후 재활
- PCOS·여성질환
- CP/CPPS·비뇨생식

## 치료 경과와 안전

치료는 한 번의 통증점수만 보는 것이 아니라 **기능·활동범위·수면·일상생활·증상의 지속시간과 재발양상**을 함께 평가합니다.

침구치료에서는 자침부위의 해부학, 깊이와 방향, 신경·혈관·장기 구조, 환자의 출혈위험과 전신상태를 함께 확인하는 것이 중요합니다.

→ [치료 경과·재평가](../acupuncture-integrated/followup.md)  
→ [안전·위험신호](../acupuncture-integrated/safety.md)  
→ [침 치료 안전성과 임상해부학](../acupuncture-science/safety.md)

## 검색으로 바로 찾기

상단 검색창에 **증상, 질환, 근육, 말초신경, 경혈, 처방 또는 PMID**를 입력하면 관련 문서와 근거를 찾을 수 있습니다.

예:
- 손가락 저림
- 정중신경
- 이상근
- 좌골신경
- 족삼리 ST36
- 손목터널증후군
- 전침
- PMID
