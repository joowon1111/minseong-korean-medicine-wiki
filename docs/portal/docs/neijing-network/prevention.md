# 치미병과 예방

황제내경에서는 질병이 뚜렷해진 뒤 치료하는 것뿐 아니라 **질병이 생기기 전 또는 악화되기 전에 관리하는 관점**을 강조한다.

이른바 치미병(治未病)은 오늘날의 예방·건강관리 개념과 직접 동일시할 수는 없지만, 평소 생활과 체질·계절·환경을 고려해 건강을 지키는 전통적 관점을 보여준다.

```text
평소 건강관리
 ↓
계절·생활·정서 조절
 ↓
질병 발생·악화 예방
```
