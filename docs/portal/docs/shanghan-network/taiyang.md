# 태양병

태양병은 상한론 육경병증의 첫 축으로, 외감 초기에 나타나는 표증의 구조를 중심으로 이해한다.

대표적인 처방 흐름에서는 **계지탕·마황탕** 등이 태양병의 서로 다른 증후 맥락과 연결된다.

```text
태양병
  ↓
표증의 양상 구분
  ↓
영위·발한·맥·오한발열 등 종합
  ↓
치법
  ↓
계지탕 / 마황탕 등
```

같은 태양병이라도 병증의 세부 구조에 따라 처방이 달라질 수 있다.
