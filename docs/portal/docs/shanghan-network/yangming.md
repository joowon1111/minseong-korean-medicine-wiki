# 양명병

양명병은 상한론에서 리열이 두드러지는 병증 구조와 연결해 이해한다.

```text
양명병
  ↓
열의 성격·병위
  ↓
기분열 / 부실 등 구분
  ↓
치법
  ↓
대표 처방
```

대표적으로 **백호탕·승기탕류**가 서로 다른 양명병 병증 맥락에서 연결된다.
