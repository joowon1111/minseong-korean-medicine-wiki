# 상한론 핵심 지식망

《상한론》은 외감병의 진행과 변화, 병증의 구분, 치법과 처방의 관계를 체계적으로 보여주는 대표 고전이다. 핵심은 **증상 하나에 처방 하나를 대응시키는 것이 아니라 병의 단계와 전체 병증 구조를 판단하는 것**이다.

```text
외감병
  ↓
육경병증
  ↓
태양 · 양명 · 소양 · 태음 · 소음 · 궐음
  ↓
병증 판단
  ↓
치법
  ↓
처방
```
