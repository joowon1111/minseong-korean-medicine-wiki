# 동의보감의 양생과 예방

동의보감은 질병 치료뿐 아니라 **양생·생활관리·계절에 따른 건강관리**를 중요하게 다룬다.

```text
생활습관
 +
계절·환경
 +
정서·음식·수면
      ↓
양생
      ↓
건강 유지·질병 예방
```

이러한 양생관은 황제내경의 치미병 사상과 이어지며, 오늘날 한의학의 예방·건강관리 영역과도 연결해서 이해할 수 있다.
