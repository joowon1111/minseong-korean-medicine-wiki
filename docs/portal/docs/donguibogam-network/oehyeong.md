# 동의보감 외형편

외형편은 머리·얼굴·눈·귀·코·입·목·등·허리·사지·피부 등 **신체 부위별 증상과 질환**을 체계적으로 정리한다.

```text
외형편
├─ 두면부
├─ 오관
├─ 경항·흉복·요배
├─ 사지
└─ 피부·근골
```

오늘날의 증상·질환형 탐색과 연결하기 좋은 구조로, 부위별 증상에서 본초·방제·침구로 이어지는 지식망의 기반이 된다.
