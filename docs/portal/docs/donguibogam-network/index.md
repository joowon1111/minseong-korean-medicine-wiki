# 동의보감 핵심 지식망

《동의보감》은 조선 한의학의 대표적인 의학서로, 인체의 생리와 병리, 외형과 부위별 질환, 각종 잡병, 본초와 처방, 침구를 하나의 체계로 정리한 대규모 의학 지식서다.

```text
동의보감
├─ 내경편
├─ 외형편
├─ 잡병편
├─ 탕액편
└─ 침구편
```
