# 사상인의 기본 구조

동의수세보원은 사람을 **태양인·소양인·태음인·소음인**의 네 체질로 구분하고, 각 체질의 생리적 강약과 병리적 경향을 서로 다르게 본다.

```text
사상인
├─ 태양인
├─ 소양인
├─ 태음인
└─ 소음인
```

체질은 단순한 성격 분류가 아니라 장부 기능의 상대적 특성과 병증의 전개, 치료 원칙까지 연결되는 의학적 구조다.
