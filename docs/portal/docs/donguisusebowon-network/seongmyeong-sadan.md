# 성명론·사단론의 의미

동의수세보원 전반부의 성명론·사단론은 사상의학의 인간관과 체질론의 철학적 기반을 보여준다. 사람의 성정과 행동, 장부의 기능적 차이를 체질적 생리·병리와 연결하는 관점이 여기서 출발한다.

```text
성정
 ↓
체질적 기능 차이
 ↓
생리·병리
 ↓
병증·치료
```

이 구조는 오늘날 사상의학에서 체질의 성정 특성을 생활관리와 연결하는 근거가 된다.
