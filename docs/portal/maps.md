## 환자를 위한 두 개의 대표 입구 {#_2}

### 증상으로 찾기 {#_3}

병명을 모르더라도 환자가 실제로 표현하는 말에서 시작합니다.

- 허리가 아파요
- 손발이 저려요
- 다리에 쥐가 나요
- 몸이 붓고 무거워요
- 입 벌릴 때 턱이 아파요
- 밤에 다리가 불편해요
- 잠이 안 오고 자주 깨요
- 소화가 안 되고 더부룩해요

→ [생활 표현으로 증상 찾기](../symptom-integrated/index.md)

### 질환별 보기 {#_4}

진단명이나 의심 질환을 알고 있다면 질환 페이지에서 감별, 검사, 한의학적 해석, 한약·침구치료와 현대 근거를 함께 확인합니다.

→ [질환별 보기](../conditions/index.md)  
→ [질환별 현대 근거 카드](../authority/conditions/index.md)

증상에서 출발해 **위험신호·감별 → 관련 질환·검사 → 변증·체질 → 치료·생활관리 → 연구 근거 → 경과와 재평가**로 이어 읽습니다.

## 고전 원문·해석과 현대 임상 연결 {#_10}

**네 책의 원문을 찾는 공통 입구는 [고전 원문·해석](../classics-reader/index.md)입니다.** 책별 시작 위치와 수록 범위를 먼저 확인하고, 관심 편·조문·병증으로 이동하세요.

| 책 | 원문을 찾는 곳 | 해석·임상으로 이어 읽기 |
|---|---|---|
| 상한론 | [통행 398조 목차](../shanghan-network/index.md#complete-clauses) | [태양병 첫 조문·한국어 독해](../classics/shanghanlun/clauses/taiyang-upper.md#clause-001) · [처방 계열](../formula-architecture/shanghan-family.md) |
| 금궤요략 | [제1–22편 임상 원문·독해](../jingui-network/index.md#complete-chapters) | [소화·복만](../classics/jinkui-yaolue/chapters/abdominal-cold-food.md) · [기침·상기](../classics/jinkui-yaolue/chapters/lung-cough.md) · [백합병](../classics/jinkui-yaolue/chapters/lily-fox-yinyang.md) · [부인 잡병](../classics/jinkui-yaolue/chapters/gynecology.md) |
| 동의수세보원 | [체질별 병론을 포함한 40개 원문·한국어 풀이](../classics/donguisusebowon/original.md) | [평소 증상별 원문](../sasang-original-symptoms/index.md) · [체질·병증·처방](../donguisusebowon-network/index.md) |
| 동의보감 | [다섯 편 36개 원문·풀이와 전사 검색](../classics/donguibogam/original.md) | [선별 원문 해석](../classics/donguibogam.md#selected-clinical-passages) · [5편 임상 색인](../donguibogam-network/index.md) |

## 목적별 추천 경로 {#_11}

| 독자 | 추천 탐색 순서 |
|---|---|
| 증상이 궁금한 환자 | 증상 → 위험신호 → 질환 → 치료 → 경과 |
| 진단받은 환자 | 질환 → 검사·감별 → 한약·침구 → 근거 |
| 한의학 입문자 | 기초이론 → 변증 → 본초·방제 → 침구 |
| 한의학 학습자 | [고전 원문·해석](../classics-reader/index.md) → 병증 → 처방·경혈 → [학습실 복습](../learning/index.md) → 현대 연구 |
| 임상가 | 위험신호 → 임상추론 → 변증·체질 → 치료 → 재평가 |
| 논문을 찾는 독자 | 질환별 근거 → 연구설계 → PMID·DOI → 원문 |

## 검색으로 바로 찾기 {#_12}

상단 검색창에는 다음처럼 입력할 수 있습니다.

- 생활 표현: `입 벌릴 때 아파요`, `밤에 다리가 불편해요`
- 증상: `저림`, `부종`, `불면`, `더부룩함`
- 질환: `비염`, `과민성장증후군`, `손목터널증후군`
- 한약: `녹용`, `귀비탕`, `독활기생탕`
- 경혈·신경: `족삼리 ST36`, `정중신경`
- 고전·연구: `동의수세보원`, `PMID`, `DOI`

동의보감의 한문 전사는 [전용 원문 검색](../classics/donguibogam/original.md#reader)에서, 책별 원문 위치는 [고전 원문·해석](../classics-reader/index.md)에서 찾습니다.

## 사이트를 읽는 핵심 원칙 {#_13}

1. 환자 표현과 전문 질환명을 연결합니다.
2. 위험신호와 필요한 검사를 먼저 확인합니다.
3. 한의학적 병증과 현대 질환명을 단순히 동일시하지 않습니다.
4. 한약·침구·사상의학은 환자의 현재 상태에 맞춰 탐색합니다.
5. 전통 출전과 현대 임상연구의 역할을 구분합니다.
6. 치료효과는 증상뿐 아니라 기능·수면·소화·삶의 질로 재평가합니다.
7. 세부 자료는 대표 허브에서 연결되는 다음 단계로 활용합니다.
