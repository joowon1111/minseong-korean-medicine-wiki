## 지식지도·안내

아카이브의 핵심은 문서 개수가 아니라 **문서 사이의 연결관계**입니다.

환자 생활언어, 증상, 질환, 병증, 방제, 본초, 경혈·침구, 고전, 현대 연구를 여러 통합지도를 통해 오갈 수 있습니다.

대표 진입점은 **생활 표현으로 찾는 증상 허브**와 **진단명으로 찾는 질환 허브**로 나뉩니다.

| 찾고 싶은 것 | 시작점 |
|---|---|
| 아파요·저려요·부어요 같은 생활 표현 | [증상으로 찾기](../symptom-integrated/index.md) |
| 진단명·검사·감별·질환별 치료 | [질환별 보기](../conditions/index.md) |
| R-code 증상군·변증·한약 | [증상 기반 한약 탐색](../symptom-herbal-guide/index.md) |
| 전체 분류와 운영 기준 | [분류 체계](../guide/taxonomy.md) |
