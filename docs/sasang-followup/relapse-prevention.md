# 재발예방·생활관리
증상이 안정된 뒤에는 체질별 생활관리를 현재 상태에 맞게 연결합니다.

- 식사요법
- 운동요법
- 성정·스트레스 관리
- 수면·회복 관리
- 소증의 정기적 확인

## 재발 조기신호
“예전 병이 다시 심해졌나?”만 묻지 않고 **평소 소증 중 먼저 흔들리는 항목**을 개인별 조기신호로 기록합니다.

예:
`수면 악화 → 소화 저하 → 대변 변화 → 주증 재발`

이렇게 개인별 순서를 기록하면 다음 진료에서 더 빠르게 변화를 포착할 수 있습니다.
