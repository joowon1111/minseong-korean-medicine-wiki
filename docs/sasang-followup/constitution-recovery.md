# 체질별 회복 추적 {#_1}

‘체질개선’을 상담할 때는 **무엇이 반복해서 불편하고, 어떤 일상이 편해지기를 원하는지**부터 정합니다. 사상체질의 분류와 현재의 건강 상태는 구분하며, 치료 경과는 소화·수면·땀·대소변·활동과 현재 병증의 변화를 함께 비교합니다.

## 어떤 변화를 체질개선의 목표로 삼나요? {#care-goals}

| 막연한 표현 | 관찰할 구체적인 변화 |
|---|---|
| 속이 약해요 | 식사량, 식후 불편, 복통·설사와 회복 |
| 잠을 못 자고 쉽게 지쳐요 | 입면·중간 각성, 낮 피로와 활동 |
| 열이 많거나 몸이 차요 | 언제 어느 부위가 불편한지, 땀·갈증·수면의 동반 변화 |
| 대소변이 불편해요 | 변 형태·힘주기·잔변감, 배뇨량·횟수·절박감 |

단일 증상이나 음식 선호로 체질을 확정하지 않고 [평소 소증과 현재 병증](../sasang-integrated/index.md)을 종합합니다. 아래의 전통적인 건강 지표는 현대 검사나 개별 질환의 평가와 구분해 읽습니다.

## 소음인 {#_2}
복통·설사·냉감 등 현증 안정 → 식욕·소화 회복 → **음식선화** 확인.

## 소양인 {#_3}
열/갈증 또는 설사·복통 안정 → 수면·진액상태 회복 → **대변선통** 확인.

## 태음인 {#_4}
한열·호흡·조열 안정 → 소화·활동 회복 → 자연스러운 **한액통창** 확인.

## 태양인 {#_5}
연하·섭취 또는 요척·하지 기능 회복 → 일상기능·배뇨 안정 → **소변왕다** 확인.

완실무병 조건 하나만으로 치료종결을 결정하지 않고, 현증·소증·기능상태 전체를 함께 봅니다.


## 회복과 처방 조정은 어떻게 연결하나요? {#followup-plan}

건강할 때의 평소 상태, 치료 직전의 불편, 현재 상태를 나누어 기록합니다. 통증이나 설사가 줄었더라도 식사·수면·활동이 충분히 회복됐는지 확인하고, 새 증상이 생기면 이전 체질 판단만으로 설명하지 않습니다.
