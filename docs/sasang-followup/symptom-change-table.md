# 소증·현증 변화표 {#_1}

**평소 상태 → 치료 직전 → 현재**를 구분해 같은 항목으로 비교합니다. 평소부터 있던 특징과 이번에 새로 생긴 불편을 한 칸에 섞지 않는 것이 핵심입니다. 소증이 건강한 특징과 병적인 상태를 모두 포함한다는 개념은 [소증 문헌 고찰](https://pubmed.ncbi.nlm.nih.gov/28462103/)에서 확인할 수 있습니다.

아래 표는 관찰할 항목을 고르는 안내입니다. 모든 항목을 점수로 합산하는 검사나 체질 판정표는 아닙니다.

| 영역 | 관찰할 내용 | 비교할 때 함께 적을 조건 |
|---|---|---|
| 주증상 | 발생 횟수·지속시간·불편 정도 | 같은 활동이나 시간대인지 |
| 소화·식욕 | 식사량, 식후 불편, 조기포만 | 식사 시각·양과 달라진 음식 |
| 대변 | 횟수·형태·힘주기·잔변감 | 평소와 달라진 식사·약 복용 |
| 소변 | 횟수·대략적인 양·절박감·야간 배뇨 | 음수·카페인·관련 약 변경 |
| 땀 | 나타나는 부위·시점과 동반 불편 | 기온·운동·수면 중 발생 여부 |
| 수면 | 잠드는 데 걸린 시간·중간 각성·기상 | 취침 시간, 낮잠과 다음 날 졸림 |
| 한열 | 불편한 부위·지속시간·상황 | 실내외 온도·활동과의 관계 |
| 갈증·음수 | 갈증의 시점과 실제 마신 양 | 입마름, 운동·식사와의 관계 |
| 피로·활동 | 수행한 활동과 쉬어야 했던 정도 | 업무·돌봄·운동량의 변화 |
| 정서·긴장 | 긴장한 상황과 일상에 준 영향 | 그날의 수면·식사·업무 조건 |

### 세 시점을 나누는 방법 {#three-timepoints}

| 기록 시점 | 적는 방법 |
|---|---|
| 평소 | 이번 문제가 생기기 전의 보통 상태. 기억에 따른 기록이면 그렇게 표시 |
| 치료 직전 | 날짜와 관찰한 기간을 적고, 가장 불편한 항목을 선택 |
| 현재·재진 | 같은 항목을 같은 방식으로 기록. 빠진 날은 0이 아닌 미기록으로 표시 |

하루 횟수와 일주일 횟수를 섞지 않고 단위를 붙입니다. 불편 정도를 숫자로 적는다면 같은 질문과 범위를 유지하고, 진료에서 정한 척도가 있으면 그 도구를 따릅니다. 개인 일지의 숫자를 mCGI나 다른 공식 평가 점수로 바꾸어 해석하지 않습니다.

### 기록을 다음 진료로 연결하기 {#review-record}

좋아진 항목 옆에 **아직 어려운 활동과 새 불편**을 함께 적습니다. 예를 들어 배변 횟수가 달라졌다는 사실과 배변이 편해졌다는 느낌은 별도로 기록할 수 있습니다. 빈뇨는 횟수뿐 아니라 양과 절박감도 함께 설명합니다.

- [배변 후 잔변감과 변 양상](../answer-guides/incomplete-bowel-movement-guide.md)
- [빈뇨와 배뇨일지](../conditions/frequent-urination.md#bladder-diary-use)
- [충분히 자도 개운하지 않을 때](../answer-guides/unclear-head-after-sleep-guide.md)
- [소화 증상과 스트레스 상황](../answer-guides/stress-digestion-guide.md)

개별 기록에서 확인한 변화와 그 변화의 원인은 구분합니다. 치료·다른 약·생활 조건이 동시에 바뀌었다면 변경일을 표시하여 진료 때 함께 살펴봅니다.
