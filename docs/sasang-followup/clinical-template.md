# 사상체질 진료 경과기록 템플릿 {#_1}

진료 전에 증상과 생활 변화를 정리하고, 진료 뒤에는 설명받은 평가와 계획을 남기는 양식입니다. **환자는 관찰한 내용을 기록하고, 체질병증·중증도·치료 조정은 한의사가 평가합니다.** 모르는 항목은 비워 두어도 됩니다.

필요한 항목을 개인 메모에 복사해 사용하세요. 이 페이지는 입력·제출 기능이 없는 안내 양식입니다. 아래 양식은 공식 진단 도구나 mCGI 채점표를 재현한 것이 아닙니다.

## 초진 {#_2}

| 환자가 준비할 내용 | 기록란 |
|---|---|
| 작성 날짜·관찰 기간 |  |
| 가장 불편한 증상·발병일 |  |
| 빈도·지속시간·악화 또는 완화 상황 |  |
| 함께 생긴 증상 |  |
| 회복하고 싶은 일상 활동 |  |
| 기존 진단·검사 날짜와 결과 |  |
| 처방약·일반약·한약·보충제의 실제 복용 |  |
| 알레르기·과거 치료 반응·기저질환 |  |
| 해당하는 경우 임신·수유 여부 |  |

**진료에서 평가할 내용:** 체질 및 판단 근거 / 주증 / 표리 / 순역 / 중증도 / 세부 체질병증 / 동반질환 / 처방·치료 목표. 체질 판단이 유보된 경우에도 그 상태를 기록합니다.

### 재평가 {#_5}

한의사가 진찰과 기록을 종합해 설명한 내용을 적습니다.

- 체질병증 판단 유지·변화와 그 이유:
- 주증상·소증·중증도의 변화:
- 필요시 사용한 평가도구와 결과:
- 추가 검사·타 진료 확인 사항:
- 치료 유지·조정·종료 계획:
- 다음 관찰 항목과 진료 시점:
- 예정일보다 먼저 연락하거나 진료받을 상황:

mCGI를 사용했다면 [중증도와 개선도 평가](mcgi-assessment.md)를 구분해 기록합니다. 개인 메모로 채점하거나 점수에 따라 스스로 처방을 바꾸는 양식은 아닙니다.

## 회복기 {#_6}

- 남은 현재 증상과 평소 불편:
- 회복한 활동과 아직 제한되는 활동:
- 체질별 건강신호에 대한 진료 설명:
- 이번에 실천할 생활 목표:
- 변화 확인 방법과 점검 시점:
- 반복해서 관찰된 악화 신호:
- 증상 재발·새 불편이 생겼을 때의 연락·진료 계획:

생활 목표를 구체화하는 방법은 [재발예방·생활관리](relapse-prevention.md), 기록을 검토하는 순서는 [1차 치료 후 재평가](first-followup.md)로 이어집니다. 사상체질병증 진료의 평가·추적 체계는 [공식 진료 알고리즘](https://nikom.or.kr/board/boardFile/download/38/21705/34839.do)을 참고합니다.
