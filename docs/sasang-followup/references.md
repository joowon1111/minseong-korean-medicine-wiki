# 사상의학 추적관찰 근거·참고문헌 {#_1}

경과관찰 자료는 **진료의 전체 흐름, 평가도구의 기준, 소증·현증의 개념**을 나누어 읽으면 활용하기 쉽습니다. 아래 문헌은 각 설명의 출처이며 아카이브의 기록 양식 자체를 검증한 연구는 아닙니다.

## 참고문헌 {#bibliography}

1. 국가한의임상정보포털(NCKM). **사상체질병증 한의표준임상진료지침. 2022.** [공식 등록 페이지·전체 지침](https://nikom.or.kr/nckm/module/practiceGuide/view.do?guide_idx=232&menu_idx=14) · [진료 알고리즘 1쪽](https://nikom.or.kr/board/boardFile/download/38/21705/34839.do). 전체 지침의 권고와 요약 알고리즘을 구분해 읽습니다.
2. Shin S, Kim YH, Hwang MW. **Diagnosis and treatment principle in Sasang medicine: original symptom.** Integr Med Res. 2016;5(2):99–104. [PubMed PMID 28462103](https://pubmed.ncbi.nlm.nih.gov/28462103/) · [DOI](https://doi.org/10.1016/j.imr.2016.03.005). 소증의 진단·치료상 역할을 설명하는 고찰로, 특정 처방의 효과를 비교한 임상시험과는 연구 목적이 다릅니다.
3. Lee JH, Lee EJ. **Clinical Practice Guideline for Soyangin Disease: Diagnosis and Algorithm.** JSCIM. 2014;26(3):224–240. [DOI](https://doi.org/10.7730/JSCM.2014.26.3.224).
4. Lee JH, Lee EJ. **Clinical Practice Guideline for Taeeumin and Taeyangin Disease: Diagnosis and Algorithm.** JSCIM. 2015;27(1):13–41. [DOI](https://doi.org/10.7730/JSCM.2015.27.1.013).
5. 이의주 외. **소음인체질병증 임상진료지침: 총론.** JSCIM. 2014;26(1):1–10. [평가도구를 수록한 원문 PDF](https://journal.kci.go.kr/JSCIM/archive/articlePdf?artiId=ART001865399) · [DOI](https://doi.org/10.7730/JSCM.2014.26.1.001).

2014년 평가도구의 정의와 2022년 지침의 임상 흐름은 각각의 문맥과 판본을 확인합니다. 치료효과를 판단할 때는 평가 방법의 출처와 해당 치료의 임상연구를 구분하고, [진료 경과기록 양식](clinical-template.md)의 관찰 메모를 공식 척도 점수로 대체하지 않습니다.
