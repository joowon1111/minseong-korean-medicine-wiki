# 사상체질 치료 경과관찰·재평가
2022 사상체질병증 한의표준임상진료지침은 치료효과와 예후 판단을 위해 **소증과 현증의 중증도 및 호전 정도를 평가**하도록 권고하며, mCGI-G for SCS와 mCGI-I for SCS를 참고하도록 제시합니다.

체질개선이 궁금하다면 먼저 [어떤 변화를 회복 목표로 삼는지](constitution-recovery.md#care-goals)를 읽어보세요. 평소의 소화·수면·배변·피로와 병이 생긴 뒤의 변화를 나누어 기록하는 방법으로 이어집니다.

| 지금 필요한 내용 | 확인할 항목 | 이어 읽기 |
|---|---|---|
| 첫 진료를 준비할 때 | 체질 판단의 근거, 발병 전 소증, 현재 증상과 비교 기준 | [초진 기록](initial-assessment.md) |
| 치료 뒤 변화를 정리할 때 | 주증상의 강도·빈도·지속시간과 일상기능 | [1차 치료 후 재평가](first-followup.md) |
| 여러 증상을 함께 비교할 때 | 소화·식욕·대소변·땀·수면·피로의 초진과 재진 기록 | [소증·현증 변화표](symptom-change-table.md) |
| 전체 경과를 평가할 때 | 체질병증의 중증도와 치료 전후 개선도 | [mCGI 평가의 의미](mcgi-assessment.md) |
| 치료 방향을 다시 살필 때 | 남은 증상, 새로 생긴 변화와 처방 조정의 판단 과정 | [처방 유지·변경 판단](formula-decision.md) |
| 회복 목표를 정할 때 | 체질별로 살피는 회복 항목과 생활 기능 | [체질별 회복 추적](constitution-recovery.md) |
| 증상이 안정된 뒤 | 생활관리와 개인별 재발 조기신호 기록 | [재발예방·생활관리](relapse-prevention.md) |

설사·발한·열감은 줄었는데 식사나 활동이 더 나빠졌다면 [증상 감소와 회복이 엇갈리는 경우](../sasang-symptoms/index.md#discordant-recovery)를 함께 확인합니다.

초진부터 회복기까지 한 흐름으로 기록하려면 [진료 경과기록 템플릿](clinical-template.md)을 참고하세요. 평가 방법의 출처는 [사상의학 추적관찰 근거·참고문헌](references.md)에서 확인할 수 있습니다.
