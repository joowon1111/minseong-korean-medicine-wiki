# 증상·질환 치료경과·재평가
## 초진 기준점
- 증상 강도
- 빈도·지속시간
- 기능제한
- 수면
- 약물 사용
- 동반증상

## 재진
```text
증상 변화
 +
기능 변화
 +
새로운 증상
 +
치료 부작용
 ↓
유지 / 조정 / 추가평가
```

통증은 통증점수와 기능, 불면은 수면과 낮 기능, 비염은 코증상과 수면·약물 사용처럼 **증상별 핵심 결과지표**를 다르게 잡습니다.
