# 증상·질환 임상 평가·경과

<span id="_4"></span>


이 자료실은 **진료에서 무엇을 확인하고, 어떤 목표로 치료하며, 다음 방문에서 무엇을 비교할지**를 정리합니다. 환자용 질환 설명을 다시 짧게 반복하기보다 문진·진찰·감별·기능 평가를 연결하는 임상가용 자료입니다. 병명 없이 증상부터 찾으려면 [증상별 안내](../symptom-integrated/index.md), 진단명을 알고 있다면 [질환별 보기](../conditions/index.md)에서 시작할 수 있습니다.

## 증상에서 임상 판단으로

| 진료 단계 | 핵심 질문 | 연결 자료 |
|---|---|---|
| 첫 평가 | 지금 기다려도 되는가, 평소와 다른 변화가 있는가? | [위험신호·감별](red-flags.md) |
| 원인과 기능 확인 | 언제·어떤 조건에서 생기며 무엇을 못 하게 되었는가? | 아래 증상별 임상 평가 |
| 한의학적 해석 | 한열·허실·기혈·담음·어혈의 어떤 조합이 설명에 도움이 되는가? | [진단·변증](../diagnostics/index.md) |
| 치료 목표 설정 | 줄일 증상과 회복할 활동, 각 치료의 역할은 무엇인가? | [처방·치료 비교](../compare/index.md) |
| 경과와 계획 조정 | 증상·기능·새 이상 반응이 어떻게 변했는가? | [치료경과·재평가](followup.md) |

한 증상에서 특정 처방·경혈로 바로 넘어가지 않습니다. 예를 들어 “밤에 아프다”는 표현은 통증 위치·외상·전신 증상·활동·수면을 함께 묻는 출발점입니다. 검사 소견과 환자의 기능 제한도 서로 연결해 해석합니다.

## 통증의 분포·움직임·신경 기능 {#pain-assessment}

| 임상 문서 | 먼저 비교할 항목 | 경과에서 볼 기능 |
|---|---|---|
| [요통](low-back-pain.md) | 허리와 다리의 통증 분포, 감각·근력·위험신호 | 걷기·앉기·들기·수면 |
| [어깨통증](shoulder-pain.md) | 능동·수동 가동범위, 근력, 목과 팔 증상 | 옷 입기·팔 올리기·작업 |
| [두통](headache.md) | 발작의 시간 양상, 동반 증상, 약물 사용 | 두통일·업무 제한·약물 사용일 |

[오래된 허리통증에서 침과 한약](../questions/choice/chronic-back-pain-treatment.md)은 치료를 함께 고려할 때의 질문을 풀어 설명합니다. 이곳의 임상 문서는 그 질문을 실제 진료의 기준점과 재평가로 연결합니다.

## 수면·소화·비염·피로의 시간 양상 {#systemic-assessment}

| 임상 문서 | 구분할 문제 | 경과에서 볼 기능 |
|---|---|---|
| [불면](insomnia.md) | 수면 기회, 입면·각성, 다른 수면질환·약물 | 밤 수면과 낮의 졸림·집중 |
| [소화불량](dyspepsia.md) | 식욕·조기 포만·식후 팽만·경고 증상 | 섭취량·식사 회피·체중 |
| [비염](rhinitis.md) | 알레르겐·비알레르기 자극·약물·코막힘 | 수면·노출 조건·약물 사용 |
| [피로](fatigue.md) | 수면·섭취·활동 후 악화·전신 상태 | 활동 범위와 회복 시간 |

여러 증상이 함께 있어도 처음부터 모두 하나의 원인으로 묶지 않습니다. [복합 증상 질문](../questions/choice/index.md)에서 먼저 시작된 증상과 생활 조건을 정리하고, [자율신경·스트레스 지식망](../autonomic/index.md)에서 긴장·수면·소화·회복의 관계를 더 깊게 볼 수 있습니다.

## 초진과 재진을 연결하는 기록 {#clinical-record}

초진에는 대표 증상과 중요한 활동을 각 1~2개 선택합니다. 재진에서는 같은 기준에 치료 변경, 활동량·수면, 새로운 불편을 더해 비교합니다. 한 번의 통증점수보다 반복되는 방향과 생활 기능을 함께 보아야 치료 유지·조정·추가 평가를 결정하기 쉽습니다.

치료 반응이 예상과 다르면 진단 가설, 목표, 강도와 구성, 검사나 협진 필요성을 다시 검토합니다. [치료경과·재평가](followup.md)의 증상별 표를 기록 틀로 사용할 수 있습니다.

## 관련 핵심 문서

[연구·근거 자료실](../portal/evidence.md)에서는 치료 연구의 대상·비교군·평가 항목을 읽는 법을, [진료 안전·감별](../clinical-safety/index.md)에서는 증상별 우선 평가 기준을 확인합니다. 변증 설명과 현대 임상근거는 서로의 역할을 구분해 사용합니다.
