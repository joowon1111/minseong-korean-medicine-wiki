# 증상·질환 임상 심화 자료실
이 페이지는 환자용 대표 허브가 아니라 **임상가용 심화 자료실**입니다. 생활 표현으로 탐색하려면 [증상으로 찾기](../symptom-integrated/index.md), 진단명으로 탐색하려면 [질환별 보기](../conditions/index.md)에서 시작합니다.

증상 하나를 곧바로 특정 처방이나 경혈에 연결하지 않고 **위험신호 → 현대의학적 감별 → 한의학 변증 → 치료전략 → 경과관찰** 순서로 탐색합니다.

```text
증상
 ↓
위험신호 확인
 ↓
원인·질환 감별
 ↓
한의학적 병증
 ↓
한약 + 침구 + 생활관리
 ↓
증상·기능 변화
 ↓
재평가
```
