# 증상·질환 위험신호·감별
한의학적 변증보다 먼저 **즉각적인 일반 의학적 평가가 필요한 상태**를 확인합니다.

예:
- 의식 변화
- 진행하는 마비·근력저하
- 대소변 조절의 급격한 이상
- 심한 흉통·호흡곤란
- 지속적 고열과 전신쇠약
- 심한 탈수·섭취불가
- 중대한 외상
- 갑작스럽고 이전과 다른 극심한 두통
- 원인 불명의 지속적인 체중감소·출혈

위험신호가 없더라도 증상이 지속·악화하거나 진단이 불분명하면 필요한 검사와 협진을 고려합니다.
