# 어깨통증 임상 심화

어깨통증은 **어디가 아픈지뿐 아니라 능동·수동 움직임과 근력, 목·팔 신경 증상을 함께 비교**해야 치료 목표가 분명해집니다. 질환별 설명은 [어깨통증 안내](../conditions/shoulder-pain.md)에서 읽고, 이 문서는 문진·진찰·경과를 연결하는 데 사용합니다.

## 감별

| 확인할 질문 | 진찰·문진에서 연결할 내용 |
|---|---|
| 외상 뒤 시작했나요? | 변형·부종, 팔을 올릴 수 있는지, 외상 전 기능 |
| 스스로 움직일 때와 다른 사람이 도와줄 때 차이가 있나요? | 능동·수동 가동범위와 통증에 의한 제한 |
| 특정 방향에서 힘이 빠지나요? | 통증 억제와 실제 근력 저하를 구분 |
| 밤에 아프거나 누우면 심해지나요? | 수면 자세·지속시간·낮 활동과의 관계 |
| 목을 움직일 때 팔까지 달라지나요? | 목통증·저림·감각·근력과 신경학적 평가 |
| 일상에서 어떤 동작이 어렵나요? | 옷 입기·머리 감기·선반에 손 뻗기 등 기준 동작 |

야간통 하나로 특정 질환을 확정하지 않습니다. 외상 뒤 갑자기 팔을 못 쓰거나 변형·심한 부종·지속 감각 저하가 있으면 신속히 평가합니다. [NHS 어깨통증 안내](https://www.nhs.uk/symptoms/shoulder-pain/)도 이런 변화를 빠른 진료가 필요한 신호로 제시합니다.

## 임상 구조

회전근개 관련 통증, 관절의 강직, 경추에서 비롯된 통증은 비슷하게 느껴져도 움직임과 기능의 양상이 다릅니다. 통증을 재현하는 동작과 가동범위·근력을 함께 보고, 영상검사가 치료 방침에 어떤 정보를 더할지 판단합니다.

| 평가에서 드러난 중심 문제 | 치료 목표의 예 |
|---|---|
| 통증 때문에 움직임을 피함 | 편안하게 가능한 범위부터 움직임 회복 |
| 전반적인 관절 가동범위 제한 | 일상 동작과 단계별 가동범위 관찰 |
| 반복 사용 뒤 악화 | 작업·운동 부하와 회복 시간 조정 |
| 목 움직임·팔 저림이 동반 | [목통증](../conditions/neck-pain.md)과 신경 증상 평가 |

한의학에서는 견비통의 경락·기혈·한습·어혈 등을 현재 진찰 소견과 함께 해석합니다. 침·전침·약침과 한약을 병행할 때도 각 치료가 줄이려는 통증, 움직임, 전신 증상을 구체적으로 나눕니다. 처방은 [통증 한약 안내](../herbal-integrated/formula-for-pain.md), 시술의 차이는 [침과 약침 비교](../compare/acupuncture-vs-pharmacopuncture.md)에서 연결합니다.

## 재평가

팔 올리기, 옷 입기, 뒤로 손 뻗기 중 환자에게 중요한 동작을 선택합니다. 같은 방향·조건에서 가능한 범위와 불편 정도를 비교하고, 수면과 업무 수행의 변화도 기록합니다. 통증이 줄었다는 이유로 활동량을 갑자기 늘리기보다 현재 회복 범위에 맞춰 조정합니다.

치료 후 국소 불편이 얼마나 지속됐는지, 새로운 저림이나 근력 저하가 있는지도 확인합니다. 호전이 더디면 진단 가설, 활동 부하, 치료 강도와 검사 필요성을 다시 검토합니다. [치료경과·재평가](followup.md)에 공통 기록 틀이 있습니다.
