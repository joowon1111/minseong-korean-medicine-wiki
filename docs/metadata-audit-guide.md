# 문서 메타데이터 가이드

문서의 메타데이터는 각 페이지의 주제와 범위를 명확하게 나타내고 관련 정보를 쉽게 탐색할 수 있도록 돕습니다.

## 기본 항목

```yaml
---
title: 문서 제목
description: 문서의 핵심 내용을 설명하는 한 문장
tags: [핵심태그1, 핵심태그2, 핵심태그3]
---
```

## title

문서가 무엇에 관한 것인지 가장 직접적으로 표현합니다.

증상·질환은 일반적으로 사용하는 명칭을 우선하고, 질문형 콘텐츠는 실제 질문 형태의 제목을 사용할 수 있습니다.

## description

문서에서 다루는 범위를 간결하게 설명합니다.

- **증상·질환** — 주요 증상, 감별, 한의학적 해석과 치료
- **방제** — 출전, 구성, 방의, 전통적 활용과 관련 연구
- **본초** — 기원, 성미·귀경, 효능, 처방에서의 역할과 관련 연구
- **질문형 문서** — 질문의 핵심 내용과 함께 살펴볼 사항

## tags

태그는 문서의 주요 주제와 분류를 나타냅니다. 유사한 표현을 과도하게 나열하기보다 실제 탐색에 도움이 되는 핵심어를 사용합니다.

## 본문 제목

H1은 페이지의 중심 주제를 명확하게 나타내며 메타데이터의 `title`과 의미상 일치하도록 작성합니다.

## 문서 첫 부분

증상이나 질문을 다루는 문서는 문서 앞부분에서 핵심 내용을 쉽게 확인할 수 있도록 구성합니다.

이후 증상의 특징, 감별, 한의학적 해석, 치료와 관련 자료를 단계적으로 살펴볼 수 있도록 합니다.

## 내부링크

관련 증상·본초·방제·치료·고전·연구 문서로 자연스럽게 연결합니다.

세부문서는 핵심색인과 분야별 허브를 통해 탐색할 수 있습니다.

## 참고자료

고전이나 현대 연구를 인용하는 경우 문서의 내용과 직접 관련된 자료를 우선하며, 확인 가능한 서지정보가 있는 경우 함께 기록합니다.
