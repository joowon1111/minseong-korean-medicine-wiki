# 세부 증상 자료실

이 페이지는 초기 증상 문서를 보존한 **세부 자료실**입니다. 환자가 일상 표현에서 전체 증상을 탐색하는 대표 입구는 [증상으로 찾기](../symptom-integrated/index.md), 진단명과 질환별 치료를 깊이 보는 대표 입구는 [질환별 보기](../conditions/index.md)입니다.

## 핵심 세부 문서

- [피로·기력저하](/authority/conditions/fatigue/)
- [잠이 안 올 때](sleep-problem.md)
- [허리·목·무릎 통증](musculoskeletal-pain.md)
- [소화가 안 될 때](digestion.md)
- [코막힘·비염](rhinitis.md)

## 이 자료실의 역할

세부 증상 하나를 특정 처방 하나에 고정하지 않고 **위험신호·감별 → 가능한 한의학적 변증 → 관련 본초·방제·침구 → 질환 심화 문서** 순서로 연결합니다.

- 생활 표현 전체에서 찾기 → [증상으로 찾기](../symptom-integrated/index.md)
- 진단명에서 찾기 → [질환별 보기](../conditions/index.md)
- 핵심 주제 관계 보기 → [통합 한의학 지식 그래프](../network/integrated-knowledge-graph.md)
