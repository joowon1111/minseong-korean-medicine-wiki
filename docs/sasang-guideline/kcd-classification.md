# 사상체질병증의 표준 분류

국가한의임상정보포털의 사상체질병증 임상자료에서는 한국표준질병·사인분류(KCD)에서 사상체질병증을 별도의 코드 체계로 다룬다.

| 체질 | KCD-8 범위 |
|---|---|
| 소음인병증 | U95.0–U95.4 |
| 소양인병증 | U96.0–U96.4 |
| 태음인병증 | U97.0–U97.4 |
| 태양인병증 | U98.0–U98.2 |

이 분류는 사상체질의 임상 진단을 단순 성격분류가 아니라 **병증 단위의 의료적 분류체계**로 다루고 있다는 점에서 의미가 있다.

```text
체질
 ↓
체질병증
 ↓
표준 진단분류
 ↓
임상 기록·연구·진료지침
```
