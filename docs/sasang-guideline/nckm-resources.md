# 국가 임상자료·사상체질 진단가이드

국가한의임상정보포털(NCKM)은 사상체질병증의 임상 활용을 위한 다양한 자료를 제공한다.

## 제공 자료의 예
- 사상체질병증 인포그래픽
- 사상체질병증 카드뉴스·리플렛
- 소음인병증 진단가이드라인
- 소양인병증 진단가이드라인
- 태음인병증 진단가이드라인
- 태양인·소양인·태음인·소음인 체질진단 결과지
- 체질별 식사요법 안내문
- 체질별 운동요법 안내문
- 체질별 성정요법 안내문

이러한 자료는 **사상체질 진단 → 병증 구분 → 생활관리**를 실제 임상에서 활용할 수 있는 형태로 구조화한다.
