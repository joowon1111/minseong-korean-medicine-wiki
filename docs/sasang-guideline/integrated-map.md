# 사상의학 표준 임상 통합 지도

```text
                     사상의학
                        ↓
                    체질 진단
                        ↓
          ┌─────────────┼─────────────┐
        소음인         소양인        태음인       태양인
          └─────────────┼─────────────┘
                        ↓
                평소 소증 + 현재 병증
                        ↓
                  체질병증 진단
                        ↓
                KCD 사상체질병증
                        ↓
        ┌───────────────┼───────────────┐
       처방            침구           생활관리
                                      ↓
                         식사·운동·성정요법
```

이 구조를 통해 위키의 사상의학 영역은 **고전 → 체질 → 병증 → 처방 → 현대 임상표준**으로 연결된다.
