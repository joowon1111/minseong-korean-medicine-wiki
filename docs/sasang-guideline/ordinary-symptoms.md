# 소증(素證)과 현재 병증

사상의학에서 **소증(素證)**은 평소 반복적으로 나타나는 생리적·증상적 특징을 뜻하며, 현재 발생한 증상만큼 중요하게 활용된다.

예를 들어 다음과 같은 항목을 함께 살필 수 있다.

- 소화와 식욕
- 땀의 양상
- 대변·소변
- 수면
- 추위·더위에 대한 반응
- 피로와 활동 후 회복
- 평소 정서·행동 특성

```text
        ↓
사상체질적 임상 판단
```
