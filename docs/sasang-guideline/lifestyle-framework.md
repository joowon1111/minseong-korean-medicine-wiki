# 사상체질별 생활관리 구조

사상의학의 임상 활용은 한약 처방에만 한정되지 않고 **식사·운동·정서·생활관리**와 연결될 수 있다.

국가한의임상정보포털의 사상체질병증 임상 활용자료에는 체질별로 다음과 같은 안내 자료가 제공된다.

```text
체질 진단
 ↓
├─ 식사요법
├─ 운동요법
├─ 성정요법
└─ 생활관리
```

이 구조는 사상의학이 질병 치료뿐 아니라 평소의 생활과 건강관리를 함께 다루는 체계임을 보여준다.

체질별 생활관리는 개인의 현재 질환과 신체 상태를 함께 고려해 적용하는 것이 중요하다.
