# 지역 사투리·생활구어로 찾는 증상 검색 지도

## 핵심 답변
환자는 의학용어 대신 `허리가 우리하다`, `목이 땡긴다`, `몸이 골골한다`, `속이 얹힌 것 같다`, `기운이 하나도 없다`처럼 생활말로 검색할 수 있습니다.

이 문서는 이런 표현을 진단명으로 단정하지 않고 **표준 증상 개념과 기존 전문문서로 연결하는 검색 보조 레이어**입니다.

> 같은 표현도 지역·세대·개인에 따라 뜻이 달라질 수 있습니다.

## 통증·근골격
- 허리가 우리하다 / 우릿하다 → 욱신·은근한 근육통 → [요통](../conditions/low-back-pain.md)
- 목이 땡긴다 → 당김·근육 긴장 → [경항통](../conditions/neck-pain.md)
- 어깨가 꽉 뭉쳤다 → 견갑대 긴장 → [어깨통증](../conditions/shoulder-pain.md)
- 삭신이 쑤신다 / 뼈마디가 쑤신다 → 전신 근육통·관절통
- 다리가 땡긴다 → 근육 당김·방사통 감별 → [하지저림](../conditions/leg-numbness.md)

## 소화·장
- 체한 것 같다 / 얹힌 것 같다 → 체기·[소화불량](../conditions/dyspepsia.md)
- 명치가 꽉 막힌다 → 상복부 불편
- 속이 더부룩하다 → 복부팽만·소화불량
- 속이 울렁거린다 → 오심
- 먹은 게 안 내려가는 것 같다 → 소화불량·삼킴 문제 감별

## 호흡기·면역
- 감기를 달고 산다 → 반복 감기·회복 저하
- 맨날 골골한다 → 잔병치레·피로
- 코가 맹맹하다 → [비염](../conditions/rhinitis.md)·코막힘
- 목에 뭐가 걸린 것 같다 → [목이물감](../conditions/globus-sensation.md)
- 기침이 안 떨어진다 → [기침](../conditions/cough.md)

## 피로·자율신경
- 기운이 하나도 없다 / 몸이 축 처진다 / 맥을 못 춘다 → 기력저하
- 자도 자도 피곤하다 → [만성피로](../conditions/chronic-fatigue.md)
- 몸이 천근만근이다 → 전신 무거움
- 가슴이 벌렁거린다 → 두근거림
- 머리가 띵하다 / 멍하다 → 두통·브레인포그
- 잠을 설친다 → 불면·수면유지 문제

## 냉증·부종·배뇨
- 손발이 얼음장 같다 / 시리다 → 수족냉감
- 다리가 퉁퉁 붓는다 → [부종](../conditions/edema.md)
- 피가 안 도는 것 같다 → 냉감·저림 감별
- 밤에 오줌 때문에 자꾸 깬다 → 야간뇨
- 오줌을 눠도 시원찮다 → 잔뇨감
