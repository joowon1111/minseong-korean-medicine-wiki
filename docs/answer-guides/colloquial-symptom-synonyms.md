# 환자 생활구어·증상 동의어 사전

## 통증
- 우리하다·우릿하다 → 아리고 욱신한 느낌, 근육통성 불편
- 땡긴다 → 당김, 근육 긴장, 방사통 가능
- 결린다 → 뻐근함, 근육 긴장
- 쑤신다 → 욱신거리는 통증
- 찌릿하다 → 신경성 통증·저림
- 묵직하다 → 압박감·둔통
- 화끈거린다 → 작열감
- 시리다 → 냉감 또는 시린 통증

## 소화
- 얹혔다 → 체기·소화불량
- 체기가 있다 → 상복부 불편
- 속이 꽉 막혔다 → 명치 답답함
- 신물이 올라온다 → 역류 증상
- 속이 울렁거린다 → 오심
- 배가 빵빵하다 → 복부팽만·가스

## 호흡기·면역
- 코가 맹맹하다 → 코막힘·비음
- 목이 칼칼하다 → 인후 자극·건조
- 목이 간질간질하다 → 기침 유발
- 기침이 안 떨어진다 → 지속성 기침
- 감기를 달고 산다 → 반복 상기도 증상
- 골골한다 → 잔병치레·회복 저하

## 피로·자율신경
- 맥을 못 춘다 → 기력저하
- 축 처진다 → 무기력
- 몸이 천근만근이다 → 전신 무거움
- 머리가 띵하다 → 두통·두중감
- 머리가 멍하다 → 브레인포그
- 가슴이 벌렁거린다 → 두근거림
- 숨이 턱 막힌다 → 호흡불편·흉민
- 잠을 설친다 → 수면유지 문제

## 순환·배뇨
- 손발이 얼음장 같다 → 심한 냉감
- 피가 안 도는 것 같다 → 냉감·저림 감별
- 퉁퉁 붓는다 → 부종
- 오줌을 자주 눈다 → 빈뇨
- 오줌을 눠도 시원찮다 → 잔뇨감
- 아랫도리가 묵직하다 → 골반·회음부 불편
