# 감기를 자주 하는 아이에게 소아보약이 필요한가요?

## 핵심 답변
감기 횟수만으로 소아보약 필요 여부를 정하지는 않습니다. **한 번 아프면 회복하는 데 얼마나 걸리는지, 증상 사이에 충분히 회복하는지, 비염·코막힘, 식욕과 수면, 체중과 성장 흐름**을 함께 봅니다.

## 횟수보다 회복속도를 봅니다
집단생활을 시작하면서 호흡기 감염을 반복할 수 있지만 매번 오래 앓거나 회복 직후 다시 아프고 평소에도 쉽게 지친다면 전체적인 회복상태를 살펴봅니다.

## 비염·수면과도 연결합니다
감기처럼 보이지만 알레르기 비염이나 지속적인 코막힘이 섞여 있을 수 있습니다. 코막힘으로 잠을 설치거나 입으로 숨 쉬는 경우 수면의 질도 확인합니다.

## 한의학에서는
폐기허·비기허·기혈부족 등과 연결해 볼 수 있으나 증상 하나만으로 정하지 않습니다. **땀·식욕·대변·수면·회복속도와 성장상태**를 함께 보고 한약·보약의 필요성과 방향을 판단합니다.

## 진료를 서둘러야 할 신호
호흡곤란, 청색증, 심한 탈수, 의식저하가 있거나 감염이 지나치게 심하고 반복되며 체중·성장에도 문제가 생기면 원인 평가가 우선합니다.
