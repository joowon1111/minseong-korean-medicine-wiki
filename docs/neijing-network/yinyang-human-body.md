# 음양과 인체

황제내경의 음양론은 인체의 생리와 병리, 계절과 환경, 장부와 기혈의 관계를 이해하는 기본 언어다.

```text
음양
 ↓
상대성·균형·변화
 ↓
생리
 ↓
병리
 ↓
치료 원칙
```

음양은 고정된 두 물질이라기보다 서로 대립하면서도 의존하고 변화하는 관계를 설명하는 틀로 이해할 수 있다.
