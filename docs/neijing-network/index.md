# 황제내경 임상 지식망 {#_1}

《황제내경》은 한의학의 생리·병리·진단·치료·경락 이론을 폭넓게 형성한 핵심 고전입니다. 이 네트워크는 원문 내용을 중복 복제하기보다 **현재 임상 지식망으로 연결하는 해석층**으로 사용합니다.

음양·장부·기혈진액을 따로 외우기보다 생리의 설명이 병기·진단·치료·양생으로 이어지는 순서로 읽습니다. 아래 목차에서 필요한 개념으로 바로 이동할 수 있으며, 전통적 기능 체계와 현대 해부·생리학의 설명 수준을 구분합니다.

## 황제내경의 음양과 인체 {#yinyang-human-body}

음양은 신체 현상을 둘로 고정 분류하는 표가 아니라 **상대적이고 변화하는 관계를 읽는 기본 틀**입니다.

### 임상에서 보는 축
- 상·하
- 표·리
- 한·열
- 동·정
- 기능·물질
- 흥분·회복

### 팔강과 연결
팔강의 표리·한열·허실 판단을 음양의 큰 틀에서 종합할 수 있지만, 실제 환자에서는 여러 축이 동시에 나타납니다.

### 임상적 주의
현대의 자율신경·호르몬·면역기능과 음양을 그대로 동일시하지 않습니다. 전통적 설명 수준과 현대 생리학의 설명 수준을 구분합니다.

→ [팔강변증](../eight-principles-network/index.md)  
→ [음양 종합](../eight-principles-network/yin-yang.md)


## 황제내경 장부체계 {#zangfu-system}

황제내경의 장부는 현대 해부학적 장기와 겹치는 부분이 있지만 **기능적·관계적 체계**로 읽어야 합니다.

### 오장
간·심·비·폐·신은 기혈진액·정신·소화·호흡·생식·회복 등 여러 기능축과 연결됩니다.

### 육부
담·위·소장·대장·방광·삼초는 수곡의 수납·소화·배설·수분대사와 연결됩니다.

### 임상으로 내려가기
장부명 하나에서 처방으로 바로 가기보다 **증상 → 팔강 → 기혈진액 → 장부변증 → 치법** 순으로 구체화합니다.

→ [장부 기초](../foundations-integrated/zangfu-qi-blood-fluids.md)<br>
→ [핵심 변증](../diagnostics/patterns/index.md)


## 황제내경 기·혈·진액 {#qi-blood-fluids}

기·혈·진액은 서로 독립된 물질 목록이 아니라 **생성·운행·영양·윤택·회복을 설명하는 연결축**입니다.

### 기
기허·기체·기역·기함 등을 기능과 방향의 변화로 봅니다.

### 혈
혈허·어혈·출혈 등을 영양과 운행의 문제로 봅니다.

### 진액
담음·습·조燥·진액부족을 수분대사와 윤택의 문제로 봅니다.

### 복합병증
비위기허+담음 / 기혈허+어혈 / 음허+허열처럼 여러 병리가 함께 나타날 수 있습니다.

→ [기허](../diagnostics/patterns/qi-deficiency.md)  
→ [어혈](../diagnostics/patterns/blood-stasis.md)  
→ [담음](../diagnostics/patterns/phlegm-fluid.md)


## 황제내경 병기 {#pathogenesis}

병기는 '병 이름'보다 **왜 이런 증상 조합이 생겼는지 설명하는 구조**입니다.

### 핵심 관찰축
정기와 사기의 관계 / 한열 / 허실 / 기의 승강출입 / 장부 기능 / 기혈진액 / 경락의 소통

### 임상 적용
같은 두통이라도 풍·담음·어혈·간양·기혈허 등 병기가 다를 수 있고, 같은 병기라도 환자에 따라 증상 표현이 달라질 수 있습니다.

### 치료와 연결
병기 → 치법 → 본초·방제·경혈의 순서로 연결합니다.

→ [팔강변증](../eight-principles-network/index.md)  
→ [질환→치료 지도](../network/condition-to-treatment-map.md)


## 황제내경 진단과 임상 관찰 {#diagnosis}

전통 진단은 환자의 **색·형·목소리·호흡·증상·생활·촉진·맥** 등 여러 정보를 종합하는 과정입니다.

### 현대 임상에서의 순서
1. 환자의 실제 주소
2. 위험신호와 일반의학적 감별
3. 망문문절의 전통적 정보
4. 팔강·장부·기혈진액 변증
5. 치료 후 재평가

### 중요한 점
설·맥 하나만으로 진단을 확정하지 않고 전체 증상과 경과를 함께 봅니다.

→ [통합 임상추론](../clinical-reasoning/index.md)  
→ [임상 안전성](../clinical-safety/index.md)


## 황제내경 경락 개념 {#meridian-concepts}

경락은 장부·체표·사지·두면부를 연결해 증상 위치와 치료점을 이해하는 핵심 틀입니다.

### 현재 위키와 연결
- 12경맥 전체 유주
- 임맥·독맥
- 기경팔맥
- WHO 표준 361경혈
- 원혈·락혈·극혈·오수혈·팔회혈·하합혈·모혈·배수혈·팔맥교회혈

### 임상 적용
질환명 하나에 혈 하나를 대응시키지 않고 **증상 위치 → 경맥 → 특정혈 → 국소/원위 배혈 → 변증**으로 연결합니다.

→ [경락·경맥 지식망](../meridian-network/index.md)  
→ [WHO 표준 361경혈 아틀라스](../acupoint-network/standard-atlas.md)


## 황제내경 예방·양생 {#prevention}

예방·양생은 병이 생긴 뒤 치료하는 것만이 아니라 **수면·식사·활동·정서·계절 적응을 통해 균형을 유지하는 관점**입니다.

### 임상에서 보는 항목
수면 / 식사 / 과로 / 활동량 / 정서적 긴장 / 계절과 기후 / 회복 속도

### 현대적으로 읽기
고전의 생활규범을 그대로 적용하기보다 현재의 수면위생·운동·영양·스트레스 관리와 조화시킵니다.

→ [자율신경·스트레스 지식망](../autonomic/index.md)  
→ [피로·회복](../conditions/fatigue.md)
