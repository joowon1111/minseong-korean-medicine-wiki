# 한의 진단 통합 지도

한의 진단은 맥이나 혀 하나로 처방을 정하는 과정이 아닙니다. 환자의 표현, 증상의 경과, 사진(四診), 신체검사와 현대의학적 감별을 종합해 **현재 상태를 가장 잘 설명하는 변증과 치료 우선순위**를 세우는 과정입니다.

## 진단의 전체 흐름

```text
주소·치료 목표
  ↓
위험신호와 현대 감별
  ↓
망진 · 문진(聞診) · 문진(問診) · 절진
  ↓
표리·한열·허실 + 장부·기혈진액
  ↓
핵심 병기·겸증·중증도
  ↓
치법·치료계획·재평가 지표
```

## 1. 환자의 주소와 목표

먼저 환자가 실제로 불편해하는 표현을 그대로 확인합니다. ‘기허’, ‘담음’ 같은 전문용어보다 “식후에 배가 꽉 찬다”, “새벽에 자꾸 깬다”, “찬 날 허리가 더 아프다” 같은 표현이 진단 정보의 출발점입니다.

- 언제 시작했고 갑작스러운지 서서히 진행했는지
- 위치·강도·빈도와 하루 중 심한 시간
- 식사·수면·활동·날씨·정서에 따른 악화와 완화
- 가장 회복하고 싶은 기능: 수면, 식사, 보행, 업무, 배변 등

## 2. 위험신호와 현대 감별

변증보다 먼저 응급·중증 가능성을 확인합니다.

| 증상군 | 우선 확인할 예 |
|---|---|
| 통증 | 외상, 진행성 근력저하, 대소변 장애, 흉통, 갑작스러운 극심한 통증 |
| 두통·어지럼 | 신경학적 결손, 의식 변화, 벼락두통, 심한 보행장애 |
| 소화기 | 토혈·흑변, 지속 구토, 체중 감소, 황달, 심한 복막자극 증상 |
| 호흡기 | 호흡곤란, 청색증, 고열 지속, 흉통, 산소포화도 저하 |
| 피로·불면 | 심한 우울·자살사고, 빈혈·갑상선·감염·수면무호흡 가능성 |

필요하면 활력징후, 신경학적·근골격계 검사, 혈액검사, 영상검사 또는 해당 진료과 의뢰를 연결합니다.

## 3. 망진 — 보고 관찰하기

- 전반적 활력, 자세, 움직임과 보행
- 안색·피부색·부종·체형과 영양 상태
- 호흡의 깊이와 속도, 기침과 객담
- 혀의 색·형태·윤조·태와 변화
- 통증 부위의 발적·부종·변형과 좌우 차이

설진은 음식·착색, 구강건조, 흡연, 약물과 촬영 환경의 영향을 받을 수 있으므로 다른 정보와 함께 해석합니다.

## 4. 문진(聞診) — 듣고 냄새 맡기

- 목소리의 힘·속도·쉰소리
- 호흡음, 기침 소리, 가래 끓는 소리
- 트림·딸꾹질·복부 장음
- 구취와 분비물의 특성

문진(聞診)은 호흡기·소화기 상태와 기의 강약을 파악하는 단서이지만, 청진이나 폐기능검사를 대신하지 않습니다.

## 5. 문진(問診) — 체계적으로 질문하기

| 영역 | 핵심 질문 |
|---|---|
| 한열·땀 | 추위·더위 민감도, 오한·열감, 자한·도한 |
| 수면 | 입면, 중간각성, 조기각성, 꿈, 코골이·무호흡 |
| 식욕·소화 | 식사량, 더부룩함, 트림·역류, 구역, 복통 |
| 대변·소변 | 횟수, 형태, 색, 잔변감·야간뇨·배뇨통 |
| 갈증·음수 | 갈증 정도, 찬물·따뜻한 물 선호, 구강건조 |
| 통증 | 부위, 성질, 방사, 움직임·온도와의 관계 |
| 정서·피로 | 스트레스, 불안·우울, 활동 후 회복 시간 |
| 여성건강 | 월경 주기·양·통증, 임신 가능성, 산후·갱년기 |
| 병력·약물 | 진단질환, 수술, 알레르기, 복용약·건강기능식품 |

## 6. 절진 — 만지고 확인하기

- **맥진:** 속도·힘·깊이·리듬 등을 전체 증후와 함께 해석합니다.
- **복진:** 압통, 긴장, 팽만, 온도와 박동을 살핍니다.
- **경락·경혈:** 압통·감각 변화와 치료 반응점을 확인합니다.
- **근골격 검사:** 관절가동범위, 근력, 감각, 반사와 특수검사를 시행합니다.

맥진은 부정맥·빈맥 같은 이상을 발견하는 단서가 될 수 있지만 심전도와 현대적 심혈관 평가를 대체하지 않습니다.

## 7. 정보를 변증으로 묶기

| 단계 | 결과물 |
|---|---|
| 큰 방향 | 표리·한열·허실 |
| 기능 위치 | 장부·경락·상중하초 |
| 물질·병리 | 기·혈·진액, 담음·어혈·식적 |
| 주병기 | 현재 증상을 가장 많이 설명하는 중심 구조 |
| 겸증 | 치료에 영향을 주지만 중심은 아닌 동반 구조 |
| 중증도 | 기능 손실, 소증 붕괴와 위험신호의 정도 |

## 8. 기록과 재평가

초진 기록에는 주증의 기준값과 치료 목표를 남깁니다.

- 통증 강도와 관절가동범위
- 잠드는 시간·각성 횟수·총수면시간
- 식사량·복부팽만·배변 횟수와 형태
- 피로·활동량·업무 수행
- 월경·배뇨·호흡 증상의 객관적 변화
- 이상반응과 복용 순응도

치료 후 예상한 방향의 변화가 없다면 처방만 반복하지 않고 진단 가설, 치료 강도, 검사와 의뢰 필요성을 다시 평가합니다.
