# 장부·기혈진액

## 장부
한의학의 장부는 현대 해부학적 장기와 완전히 동일한 개념이라기보다 **생리기능과 증후의 연결체계**로 이해합니다.

## 기·혈·진액
- **기:** 추진·온후·방어·고섭·기화
- **혈:** 영양·윤택과 정신활동의 물질적 기반
- **진액:** 체액의 생성·분포·배설과 윤택
