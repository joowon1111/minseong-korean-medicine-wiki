# 고전 → 현대 연결

한의학 고전은 개념·병증·치법·처방이 형성되고 변화한 맥락을 보여주고, 현대 연구는 특정 대상과 중재에서 무엇을 관찰했는지 보여줍니다. 둘은 서로를 대신하지 않으며 **출전과 해석, 임상 적용과 연구 결과를 구분한 뒤 연결**해야 합니다.

```text
고전 원문·전통 개념
 ↓
전통 병증·치법
 ↓
현대 임상에서 관찰되는 증상·기능
 ↓
현대 연구·임상시험
```

## 네 개의 정보층

| 정보층 | 핵심 질문 | 기록할 내용 |
|---|---|---|
| 고전 원문 | 실제로 무엇이라고 쓰였는가? | 원문, 편명·조문, 판본과 문맥 |
| 후대 해석 | 시대별로 어떻게 이해했는가? | 주석가·학파·의가의 해석 차이 |
| 현대 임상 | 오늘날 어떤 환자와 상황에 적용하는가? | 진단·변증, 제형·용량, 병용치료 |
| 현대 연구 | 어떤 설계에서 무엇이 관찰됐는가? | 대상, 비교군, 결과지표, PMID·DOI |

네 층을 한 문장에 섞으면 고전의 권위를 현대 임상효과의 증명처럼 사용하거나, 현대 질환명을 고전 병증과 동일시하는 오류가 생길 수 있습니다.

## 고전 원문을 읽는 순서

1. 책과 편명, 조문 위치를 확인합니다.
2. 핵심 용어가 해당 시대에 어떤 뜻으로 쓰였는지 봅니다.
3. 앞뒤 조문에서 병의 단계와 치법을 확인합니다.
4. 후대 판본·주석과 처방 구성 차이를 구분합니다.
5. 현대 임상에 적용할 때 달라진 진단환경·제형·용량을 명시합니다.

## 주요 고전은 어떤 질문에 답하나요? {#classical-reading-routes}

고전은 모두 같은 책을 반복하는 자료가 아닙니다. 인체의 생리와 병기를 설명하는 책, 증후와 처방의 결합을 보여 주는 책, 후대의 의학을 종합하거나 새로운 변증 체계를 세운 책을 나누어 읽으면 차이가 선명해집니다.

### 짧은 원문에서 시작해 보기 {#original-passages}

**통증이 있는 곳을 살피다 — 《영추》 「경근」**

> 以痛為輸

아픈 곳을 치료점으로 삼는다는 뜻입니다. 현재 진료에서는 환자가 가리키는 위치와 압통, 통증을 재현하는 움직임을 살펴 국소 치료점과 원위 경혈을 함께 고려하는 질문으로 이어 볼 수 있습니다. 해당 구절은 경근의 맥락에서 읽고 시술 부위의 해부학과 안전성도 확인합니다. [경근 원문과 해설](../classics/huangdi-neijing.md#_7)

**보하면서 방향을 살피다 — 《비위론》 「음식노권소상시위열중론」**

> 補其中而升其陽

중초를 보하면서 양기를 올린다는 뜻으로, 음식·노권에 의한 내상과 처방의 방향을 설명하는 대목입니다. 보기와 승양을 함께 두는 이유를 [보중익기탕의 구성](../classics/piwei-lun.md#buzhong-source)에서 살필 수 있습니다. [대조 원문: 명 만력본 등을 저본으로 한 전사](https://jicheng.tw/tcm/book/脾胃論/index.html)

**발열에 동반된 양상을 나누다 — 《온병조변》 상초 4조**

> 但熱不惡寒而渴者，辛涼平劑銀翹散主之。

열이 나면서 오한은 두드러지지 않고 갈증이 있는 양상에 은교산을 제시한 대목입니다. 발열 하나보다 오한·갈증을 함께 읽으며, [조문 앞뒤와 은교산 배합](../classics/wenbing-tiaobian.md#upper-004)을 확인합니다. 오늘날의 감염 진단이나 치료 효과는 별도 평가합니다. [대조 원문: 혜제창 중간본 전사](https://jicheng.tw/tcm/book/溫病條辨/index.html)

## 전통 병증과 현대 질환을 연결하는 법

전통 병증과 현대 질환은 관계가 있을 수 있지만 1:1 대응표가 아닙니다.

```text
현대 질환·검사 결과
      ↕
환자의 실제 증상·기능
      ↕
전통 병증·병기·치법
```

예를 들어 ‘두통’이라는 고전 증상 범주 안에는 오늘날의 편두통, 긴장형두통, 경추성두통과 위험한 이차성 두통이 함께 포함될 수 있습니다. 먼저 현대 감별을 거친 뒤 한열·허실·담음·어혈·기혈 상태를 이용해 치료 방향을 세웁니다.

## 처방을 연결할 때 확인할 점

| 항목 | 확인 이유 |
|---|---|
| 원출전과 조문 | 처방이 놓인 본래 병증과 치법 파악 |
| 구성·용량 | 동명 처방과 후대 가감방의 혼합 방지 |
| 제형·전탕법 | 탕·산·환·고제의 차이와 실제 노출량 파악 |
| 대상 환자 | 현대 질환명보다 선정된 증후와 중증도 확인 |
| 병용치료 | 침구·약물·생활관리의 영향을 구분 |
| 안전성 | 독성 약재, 임신·수유, 간·신장질환과 상호작용 확인 |

## 현대 연구를 읽는 계단

| 연구 단계 | 알 수 있는 것 | 단독으로 말하기 어려운 것 |
|---|---|---|
| 성분·기전 | 어떤 생물학적 경로가 연구됐는가 | 사람에서 실제 임상효과가 있는가 |
| 세포·동물 | 가능성과 작용 방향 | 환자에게 같은 결과가 나타나는가 |
| 관찰연구 | 실제 진료의 연관성과 사용 양상 | 인과관계와 비교치료 우월성 |
| 임상시험 | 정해진 대상·중재에서의 효과와 안전성 | 모든 환자와 모든 제형으로의 일반화 |
| 체계적 고찰 | 여러 연구의 전체 경향과 일관성 | 포함 연구의 한계를 넘어선 결론 |

현대 연구는 ‘논문이 있다’보다 **누구에게, 무엇을, 얼마나, 무엇과 비교해, 어떤 결과지표로 평가했는가**를 기록해야 임상적으로 의미가 있습니다.

## 연결의 좋은 예와 피해야 할 예

| 피해야 할 연결 | 더 나은 연결 |
|---|---|
| “고전에 있으므로 현대 질환에 효과가 입증됐다” | 고전의 활용 맥락과 현대 연구 결과를 별도 제시 |
| “비허는 췌장 기능저하다” | 비의 전통 기능과 현대 소화기 평가의 관계·차이를 설명 |
| “동물실험에서 항염이므로 환자 통증을 치료한다” | 전임상 가능성과 사람 대상 근거를 구분 |
| “같은 처방명이므로 구성도 같다” | 출전별 구성·용량·제형을 각각 기록 |
| “유의하지 않았다=효과가 없다” | 표본수·효과크기·신뢰구간·연구목적을 함께 해석 |

## 실제로 연결해 보기: 계지탕의 원문과 현대 연구 {#guizhi-reading-example}

[상한론 12조](../classics/shanghanlun/clauses/taiyang-upper.md#clause-012)에서는 태양병의 증상과 계지탕을 연결해 기록합니다. 먼저 해당 조문의 표현과 앞뒤 문맥, [계지탕 원문·구성](../formulas/guizhi-tang.md)을 확인하고, 후대의 해석과 현대 제형을 구분합니다. 고전에서 묘사한 증후를 오늘날의 특정 감염병 진단명으로 곧바로 바꾸지 않습니다.

현대 연구를 찾을 때는 논문이 평가한 **대상·제형·비교군·측정 결과·안전성**을 따로 기록합니다. 계지탕이란 이름이 같아도 출전과 가감, 용량 및 복용 방식에 차이가 있을 수 있으므로, 한 연구의 결과를 모든 제형이나 다른 질환에 옮겨 적용하지 않습니다. [상한론 지식망](../shanghan-network/index.md) · [연구 설계 읽기](../portal/evidence.md#study-design-reading)

## 아카이브 기록 원칙

- 고전의 직접 인용과 현대어 해설을 구분합니다.
- 전통 장부와 현대 해부학적 장기를 단순 동일시하지 않습니다.
- 전통 병증과 현대 질환명을 1:1로 치환하지 않습니다.
- 원방, 후대 가감방과 현대 제품을 구분합니다.
- 현대 연구는 설계·대상·중재·비교군·결과지표와 식별자를 함께 기록합니다.
- 연구의 긍정적 임상 의미를 설명하되 적용 범위와 안전성도 명확히 합니다.

## 실제 문서를 만드는 흐름

```text
고전 원문 확인
 ↓
후대 해석과 처방 변천 정리
 ↓
현대 질환·증상과의 공통점과 차이 설명
 ↓
사람 대상 연구 우선 검토
 ↓
임상 적용·안전성·재평가 기준 제시
```
