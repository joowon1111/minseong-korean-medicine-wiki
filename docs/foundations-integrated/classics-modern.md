# 고전 → 현대 연결

한의학 위키에서는 고전과 현대 의학·연구를 서로 대체하지 않고 **서로 다른 정보층으로 연결**합니다.

```text
고전 원문·전통 개념
 ↓
전통 병증·치법
 ↓
현대 임상에서 관찰되는 증상·기능
 ↓
현대 연구·임상시험
```

## 기록 원칙
- 전통 장부와 현대 해부학적 장기를 단순 동일시하지 않음
- 전통 병증과 현대 질환명을 1:1로 치환하지 않음
- 고전 출전과 후대 해석을 구분
- 현대 연구는 연구설계와 대상군을 함께 기록
