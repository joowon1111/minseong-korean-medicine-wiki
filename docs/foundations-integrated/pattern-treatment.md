# 변증·치법

## 변증
흩어진 증상과 진찰정보를 하나의 병리 구조로 묶는 과정입니다.

## 치법
변증 뒤에는 치료방향을 정합니다.

| 병리 | 치법 예 |
|---|---|
| 기허 | 익기 |
| 혈허 | 보혈 |
| 한 | 온리·산한 |
| 열 | 청열 |
| 담습 | 화담·조습 |
| 어혈 | 활혈화어 |
| 식적 | 소식도체 |

```text
증상 목록 ≠ 처방
증상 + 소증 + 진찰 → 변증 → 치법 → 본초·방제·침구
```
