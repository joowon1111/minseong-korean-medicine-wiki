# 한의학 기초 한눈에 보기

한의학의 기본개념을 암기 목록이 아니라 **환자의 상태를 어떻게 관찰하고 해석해 치료방향으로 연결하는가**라는 하나의 흐름으로 봅니다.

| 단계 | 핵심 | 바로가기 |
|---|---|---|
| 1 | 음양·오행 — 변화와 관계의 틀 | [음양·오행](yinyang-fivephases.md) |
| 2 | 장부·기혈진액 — 인체 기능체계 | [장부·기혈진액](zangfu-qi-blood-fluids.md) |
| 3 | 병인·병기 — 왜 문제가 생겼는가 | [병인·병기](etiology-pathogenesis.md) |
| 4 | 사진 — 무엇을 보고 들을 것인가 | [사진·진단](diagnosis.md) |
| 5 | 변증 — 정보를 어떤 병증으로 묶을 것인가 | [변증·치법](pattern-treatment.md) |
| 6 | 치법 — 어떤 방향으로 치료할 것인가 | [변증·치법](pattern-treatment.md) |
| 7 | 임상 추론 — 실제 환자에서 종합 | [임상 추론](clinical-reasoning.md) |

```text
생리 → 병인 → 병기 → 증상·소증 → 사진 → 변증 → 치법 → 처방·침구 → 재평가
```

이 구조를 이해하면 본초·방제·침구·사상의학을 각각 따로 외우는 것이 아니라 하나의 임상 언어로 연결할 수 있습니다.
