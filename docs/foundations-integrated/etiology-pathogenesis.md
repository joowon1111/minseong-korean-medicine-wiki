# 병인·병기 통합 안내

병인은 질병과 증상을 일으키거나 악화시키는 요인이고, 병기는 그 요인이 인체의 기능과 물질에 어떤 변화를 만들고 증상으로 이어지는지를 설명하는 과정입니다.

```text
병인·유발요인
   ↓
개인의 체질·연령·기저상태
   ↓
장부·기혈진액의 반응
   ↓
한열·허실·표리와 병리산물
   ↓
증상군·기능 저하·경과
```

같은 감염, 스트레스, 과로를 겪어도 평소 소화력·수면·체력과 질환 단계가 다르면 병기가 달라질 수 있습니다. 반대로 서로 다른 원인이 비슷한 병기와 증상군으로 모일 수도 있습니다.

## 주요 병인 범주

| 범주 | 전통적 관점 | 실제 진료에서 확인할 내용 |
|---|---|---|
| 외감 | 풍·한·서·습·조·화 등 외부 환경 | 감염 노출, 계절, 온도·습도, 알레르기 |
| 정지 | 기쁨·분노·걱정·생각·슬픔·두려움 등의 지속 | 스트레스 사건, 불안·우울, 수면과 자율신경 반응 |
| 음식 | 과식·편식·찬 음식·기름진 음식·음주 | 섭취량, 식사 시간, 체중, 역류·장 증상 |
| 노권 | 과로와 과도한 안일 | 업무·운동량, 회복 시간, 수면 부족 |
| 외상 | 타박·염좌·골절·수술 | 손상기전, 신경·혈관 증상, 영상검사 |
| 담음·어혈·식적 | 병의 결과이면서 다시 증상을 지속시키는 요인 | 부종·가래·고정통·팽만·배변 변화 |
| 기타 | 벌레·독성·약물·선천적 요인 등 | 복용약, 독성 노출, 유전·발달·기저질환 |

## 병기를 정리하는 핵심 축

### 병위: 어디에 있는가

- **표·리:** 급성 외부 반응인지 장부와 내부 기능 변화인지 큰 위치를 봅니다.
- **장부:** 간·심·비·폐·신과 육부 가운데 어떤 기능 관계가 중심인지 살핍니다.
- **경락·근골격:** 통증과 감각 변화가 경락·근육·관절·신경 경로와 어떻게 연결되는지 확인합니다.
- **상·중·하초:** 호흡·소화·배설과 생식 기능의 전신적 위치를 나눠 볼 수 있습니다.

### 병성: 어떤 성질인가

| 축 | 한쪽 방향 | 반대 방향 |
|---|---|---|
| 한열 | 냉감·수축·기능 저하 | 열감·갈증·번조·염증성 양상 |
| 허실 | 기능·기혈진액의 부족 | 병리산물·정체·과도한 반응 |
| 조습 | 건조와 진액 부족 | 무거움·끈적함·수분 정체 |
| 승강출입 | 처짐·하함 또는 배출 이상 | 기침·구토·상충 등 역상 |

### 병리산물: 무엇이 남고 막히는가

- **기체:** 팽만·답답함·이동하거나 변동하는 통증
- **어혈:** 고정되고 찌르는 통증, 외상 후 지속통
- **담음·습:** 가래·오심·어지럼·무거움·부종감
- **식적:** 과식 뒤 더부룩함·트림·복통·대변 변화
- **울화·열:** 긴장과 억울함이 오래되며 열감·번조로 진행하는 양상

## 병의 진행을 보는 관점

| 진행 변화 | 의미 | 예시 |
|---|---|---|
| 표에서 리로 | 병위가 깊어지거나 내부 기능 변화가 중심이 됨 | 급성 증상 후 소화·수면 저하 지속 |
| 실에서 허로 | 장기간 소모 뒤 회복력이 약해짐 | 반복 통증 뒤 피로·기력저하 |
| 한열의 변화 | 병의 단계나 치료 반응에 따라 성질이 바뀜 | 초기 오한 뒤 발열·갈증 증가 |
| 기에서 혈로 | 기능적 정체가 오래되어 고정된 변화로 진행 | 스트레스성 긴장 뒤 만성 고정통 |
| 허실협잡 | 부족과 정체가 동시에 존재 | 기허와 담습, 혈허와 어혈이 함께 나타남 |

## 증상에서 병기로 가는 예

### 오래된 피로

`수면 부족·과로·질환 → 기의 소모 → 소화·활동 저하 → 기혈 생성 감소 → 회복 지연`

그러나 빈혈, 갑상선질환, 감염, 수면무호흡, 우울증과 약물 영향 등도 먼저 감별해야 합니다.

### 반복되는 복부팽만

`식사·긴장 → 비위 운화 저하 또는 기체 → 음식·수분 정체 → 팽만·트림·대변 변화`

체중 감소, 출혈, 지속 구토, 심한 야간통 등은 별도의 의학적 평가가 우선입니다.

### 외상 후 고정통

`조직 손상 → 국소 순환·근긴장 변화 → 어혈·경락 불통 → 고정통·움직임 제한`

골절, 인대 손상, 신경압박과 혈관 손상 여부를 함께 확인합니다.

## 병기 가설을 세우는 법

1. 증상의 시작과 선행 사건을 확인합니다.
2. 시간대·계절·식사·활동·정서에 따른 변화를 봅니다.
3. 표리·한열·허실과 장부·기혈진액을 이용해 핵심 구조를 정리합니다.
4. 모든 정보를 억지로 하나로 묶지 말고 주병기와 겸병기를 구분합니다.
5. 치료 뒤 예상한 변화가 나타나는지 확인해 병기 가설을 수정합니다.
