# 요통의 한의학적 임상 추론

## 1. 먼저 보는 것
통증 위치·발병 시점·움직임과의 관계·하지 증상·기능 제한 등을 살핀다.

예를 들어 30대에 시작한 허리·둔부 통증이 수개월째 이어지고, 밤 후반에 깨며 일어나 움직이면 덜하고 건선 병력도 있다면 [축성 척추관절염 의뢰 기준](../symptom-clinical/low-back-pain.md#axial-spa-referral)을 먼저 확인한다. 반대로 들어 올리거나 비튼 뒤 국소 통증과 압통이 시작됐다면 손상 기전과 [골절·신경학적 위험신호](../conditions/low-back-pain.md#_2)를 확인한 뒤 활동 제한과 치료 방향을 정한다.

## 2. 변증
```text
요통
├─ 타박·염좌 뒤 고정통과 국소 압통 → 어혈 고려
├─ 냉기에 악화되고 온기에 덜하며 허리가 무거움 → 한습 양상 확인
└─ 오래된 통증에 요슬 무력·활동 후 회복 지연 → 간신부족·기혈허 비교
```

통증의 기간·위치에 발병 계기와 냉온 반응, 평소 체력과 회복 상태를 더해 [요통 변증과 치법](../conditions/low-back-pain.md#_5)을 비교한다. 원인 평가와 변증은 각각 기록하고 치료 뒤에는 통증과 걷기·앉기·수면의 변화를 함께 확인한다.
