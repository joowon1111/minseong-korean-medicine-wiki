# 3D 경혈 지도

**돌려보는 경혈 동인.** 동인(銅人)은 혈자리와 경락을 익히는 인체 모형입니다. 이 지도에서는 몸을 회전·확대하며 **14경맥 361경혈**의 위치 관계를 살펴보고, 선택한 혈의 상세 문서로 이어갈 수 있습니다.

## 이렇게 살펴보세요

- **경혈 찾기:** 한글명·한자·코드로 검색하거나 몸의 점을 선택합니다. `족삼리`, `合谷`, `ST36`처럼 입력해 보세요.
- **경락 살펴보기:** 경락 버튼으로 표시 범위를 좁히고 정면·후면·측면 또는 부위별 보기로 이동합니다.
- **조직 겹쳐 보기:** 골격·근육·장기 표시와 투시를 켜 모형 안에서의 위치 관계를 살펴봅니다.
- **자료 이어 읽기:** 선택한 경혈의 위치·주치·배혈 상세 문서, 경락 경로, 하루 경혈 카드로 이동합니다. 주치·활용의 자료 출처도 따로 확인할 수 있습니다.
- **같은 경혈 다시 열기:** ‘경혈 링크 복사’로 선택한 혈의 주소를 공유하고, ‘오늘의 경혈’로 날짜별 학습 카드와 같은 혈을 찾습니다.

컴퓨터에서는 드래그로 회전, 휠로 확대, 오른쪽 버튼이나 Shift를 누른 드래그로 이동합니다. 휴대전화에서는 한 손가락으로 회전하고 두 손가락으로 확대·이동합니다.

## 모형과 실제 위치를 구분합니다

경혈 점과 경락선은 **성인 남성 참고 모형에 맞춘 근사 표시**입니다. 경락선은 경혈의 위치 관계를 연결한 교육용 선이며 실제 혈관·신경을 나타내지 않습니다. 실제 위치는 체형·자세와 해부학적 표지, 신체 비례에 따라 달라집니다. 피부 아래 조직을 켜더라도 특정 경혈의 자침 경로·방향·깊이를 확인한 영상이 되지는 않습니다.

위치 설명과 주치·활용은 기존 아카이브 자료에 연결했습니다. 모형의 점과 표준 위치 설명이 다르게 느껴지면 상세 문서의 설명·도해·출처를 함께 확인하세요. 근사 좌표 전체를 개별 혈의 실제 취혈 위치로 검증한 자료는 아닙니다.
