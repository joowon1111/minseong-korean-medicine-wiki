# 대표 방제 비교

같은 피로·소화불편·불면이라도 처방의 출발점과 배합은 다릅니다. **공통 약재 → 달라지는 약재와 비율 → 원문의 주치 → 현재 함께 살필 증상 → 연구한 제제**를 나란히 읽으면 처방 이름을 외우는 데서 더 나아갈 수 있습니다. 이 비교는 방제학 학습용이며 개인의 처방을 정하는 표가 아닙니다.

[임상 핵심 처방 100선](../herbal-integrated/general-formulary.md#core-formulas-100)에서 전체 목록을, [처방 구조 비교 도구](../herbal-integrated/formula-structure.md#interactive-comparison)에서 선택한 처방의 구성 차이를 확인합니다.
## 비슷한 증상, 다른 방제
| 주증 | 가능한 병증 예 | 방제 방향 예 |
|---|---|---|
| 피로 | 기허 / 혈허 / 양허 | 익기 / 보혈 / 온양 |
| 복통 | 한 / 열 / 기체 / 어혈 / 식적 | 온중 / 청열 / 이기 / 활혈 / 소도 |
| 불면 | 심혈허 / 심음허 / 담화 / 심비양허 | 보혈·양심 / 자음 / 청담화 / 보익심비 |
| 기침 | 풍한 / 풍열 / 담습 / 음허 | 산한 / 소풍청열 / 조습화담 / 자음윤폐 |

**같은 증상 = 같은 처방**이 아니라 `증상 → 병증 → 치법 → 방제`가 기본입니다.

## 사군자탕·육군자탕·향사육군자탕 {#digestive-family}

《시방가괄》 권상 「보가부약」은 육군자탕에 「加木香砂仁各八分。以行氣消脹」이라 기록합니다. **목향·사인을 각 8푼 더하여 기를 움직이고 팽만을 해소한다**는 뜻입니다. 약미가 많아질수록 무조건 더 좋은 처방이 된다는 순서가 아니라, 비위기허에 담습·기체가 얼마나 겹치는가를 설명합니다. [대조 수록본·앞선 사군자와 육군자의 약량](../formulas/xiangsha-liujunzi-tang.md#source-dose-original)

| 처방·대조 출전 | 공통 골격과 달라지는 배합 | 원문을 현재 증상과 함께 읽기 |
|---|---|---|
| [사군자탕·국방](../formulas/sijunzi-tang.md#source-dose-original) | 인삼·백출·복령·자감초의 보기건비 | 식욕·식사량·피로·대변 등 비위허약의 바탕 |
| [육군자탕·의학심오](../formulas/liujunzi-tang.md#source-dose-original) | 사군자의 골격에 반하·진피; 해당 수록본은 생강·대조도 사용 | 허약과 함께 오심·그득함·담습·상역이 있는가 |
| [향사육군자탕·시방가괄](../formulas/xiangsha-liujunzi-tang.md#source-dose-original) | 육군자의 골격에 목향·사인; 두 약은 각 8푼 | 식후 팽만·트림·기체를 함께 다룰 필요가 있는가 |

**주된 차이:** 반하는 화담·강역, 진피는 이기·조습, 목향·사인은 행기와 중초의 습체 조절을 더합니다. 같은 반하·진피를 쓰는 [이진탕](../formulas/erchen-tang.md)은 담습을 다루는 출발점이고, 육군자탕은 인삼·백출을 포함한 보기건비가 바탕입니다. [사군자와 육군자의 상세 비교](../compare/sijunzi-vs-liujunzi.md#pinellia-citrus)로 이어집니다.

여기서는 출전이 다른 세 처방의 **골격**을 비교했습니다. 각 약량을 하나의 원방처럼 합치지 않습니다. 향사육군자탕의 《시방가괄》형과 《방약합편》형도 구성·비율이 다릅니다. [국내 수록형](../formulas/xiangsha-liujunzi-tang.md#_3)을 대조하고, 연구는 [일본 육군자탕 위약대조시험](../research/formulas/rikkunshito.md#japanese-fd-trials)과 [향사육군자탕의 기능성소화불량 시험](../formulas/xiangsha-liujunzi-tang.md#_5)으로 나누어 읽습니다. 서로 다른 시험 결과로 세 처방의 효과 순위를 정하지 않습니다.

## 사물탕·팔물탕·십전대보탕·인삼양영탕 {#qi-blood-family}

네 처방은 혈분의 보완과 기혈 회복이라는 공통 관심을 갖지만, **보혈의 기본방·기혈쌍보·온보·양영**의 배합이 다릅니다.

| 처방·대조 출전 | 기본 배합과 상대비 | 구분하는 임상 문맥 |
|---|---|---|
| [사물탕·국방](../formulas/siwu-tang.md#source-dose-original) | 숙지황·백작약·당귀·천궁 각 등분 | 혈허의 바탕에 혈행 조절을 함께 둠 |
| [팔물탕·만병회춘의 팔진탕](../formulas/bazhen-tang.md#source-dose-original) | 사군자·사물의 여덟 약; 7미 각 1돈·자감초 5푼인 수록형 | 혈허와 함께 식사·기력 저하 등 기허가 겹침 |
| [십전대보탕·국방](../formulas/shi-quan-da-bu-tang.md#source-dose-original) | 팔물 계열에 황기·육계, 해당 원문은 10미 등분 | 기혈양허에 허한·소모의 문맥을 함께 살핌 |
| [인삼양영탕·국방](../formulas/renshen-yangrong-tang.md#source-dose-original) | 십전과 비교하면 천궁이 없고 진피·오미자·원지가 있음; 백작약 3냥, 인삼·황기·당귀 등 각 1냥 | 오래된 허손에 식욕저하·심계·건조·숨참 등이 함께 기록됨 |

인삼양영탕 원문은 「心虛驚悸，咽乾唇燥，飲食無味」, 곧 **심계와 놀람, 목·입술의 건조, 음식 맛이 없는 상태**를 허손의 문맥에 놓습니다. 진피의 이기, 오미자의 수렴, 원지의 안신과 백작약의 높은 비중을 함께 보면 십전대보탕에 약재 세 개를 단순히 더한 처방으로 설명하기 어려운 이유가 드러납니다. [주치·약량·제법 상세](../formulas/renshen-yangrong-tang.md#fatigue-original-ratio)

‘혈허’는 혈액검사상의 빈혈과 동일한 진단명이 아닙니다. 현재의 피로는 식사량·체중·수면·출혈·복용약과 필요한 검사를 함께 확인합니다. 처방 뒤에도 식욕·활동·근력·생활 회복을 나누어 보며, [인삼양영탕의 COPD 허약 연구](../formulas/renshen-yangrong-tang.md#frailty-trials)는 해당 제제와 환자군에서 읽습니다. 이 결과를 사물탕·팔물탕·십전대보탕의 효과로 합치지 않습니다.

## 귀비탕·산조인탕·온담탕 {#sleep-family}

세 처방을 ‘안신약’으로만 묶으면 **식사와 기혈의 회복, 허로허번, 담과 기의 조절**이라는 차이가 가려집니다.

| 원문·처방 | 자체 풀이 | 배합과 비교할 동반 양상 |
|---|---|---|
| [귀비탕·엄씨제생방](../formulas/guibi-tang.md#source-dose-original): 「思慮過度，勞傷心脾，健忘怔忡」 | 생각이 지나치고 과로하여 심비를 손상하고 건망·심계가 생김 | 보기건비에 용안육·산조인·복신의 안신; 피로·식욕저하·건망·심계 |
| [산조인탕·금궤요략 6.17](../classics/jinkui-yaolue/chapters/blood-bi-deficiency.md#clause-06-017): 「虛勞虛煩不得眠」 | 허로와 허번으로 잠들지 못함 | 산조인·지모·천궁·복령·감초; 번조·휴식 곤란과 허로의 문맥 |
| [온담탕·동의보감 몽문](../formulas/wendan-tang.md#donguibogam-version): 「心膽虛怯，觸事易驚」 | 마음이 겁약해 일에 부딪히면 쉽게 놀람 | 반하·진피·복령에 죽여·지실 등의 화담·이기; 오심·흉민·어지럼·놀람 |

귀비탕의 초기 《제생방》 8미에는 당귀·원지가 없으며 [《동의보감》형](../formulas/guibi-tang.md#donguibogam-version)과 구분합니다. 산조인탕도 [금궤요략형](../formulas/suanzaoren-tang.md#source-dose-original)과 [동의보감 동명방](../formulas/suanzaoren-tang.md#donguibogam-version)이 다릅니다. 온담탕은 [삼인방의 구성·약량](../formulas/wendan-tang.md#source-dose-original)과 동의보감형을 각각 확인합니다.

현재 불면의 감별·수면일지·인지행동치료와의 병행은 [불면 기본 문서](../conditions/insomnia.md#classical-clinical-reading)에서, 산조인탕 자체의 연구는 [처방별 수면 결과](../authority/formulas/suanzaoren-tang.md#szrd-results)에서 읽습니다. 산조인을 공통으로 포함한다고 귀비탕에 산조인탕 시험 결과를 적용하지 않습니다. [불면 지식망](../network/insomnia-map.md)은 동반 양상에서 본초·처방·출전으로 돌아가는 길을 안내합니다.
