# 한약·방제 현대 임상근거 연결

현대 연구를 볼 때 처방명만 같다고 같은 중재로 보지 않습니다.

## 확인할 항목
1. 대상군과 진단기준
2. 변증 기준의 유무
3. 실제 처방 구성과 가감
4. 약재 기원·품질
5. 용량·제형·복용기간
6. 비교군
7. 증상·기능·삶의 질 등 결과지표
8. 이상반응과 추적기간

## 연구 결과를 소개하는 방식
임상적으로 의미 있는 긍정적 결과가 보고된 경우 **어떤 대상과 조건에서 어떤 지표가 개선되었는지** 구체적으로 소개합니다. 동시에 연구의 제형·구성·대상군을 함께 적어 결과를 지나치게 넓게 일반화하지 않습니다.

## 전임상과 임상
성분·기전·동물연구는 작용 가능성을 이해하는 데 유용하고, 실제 환자에서의 효과는 사람 대상 임상연구를 중심으로 봅니다.
