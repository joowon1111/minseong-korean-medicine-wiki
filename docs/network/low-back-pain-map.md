# 요통 임상 지식망

한의학에서는 요통을 한 가지 병리로 보지 않고 **풍한습, 어혈, 간신부족, 기혈허 등 다양한 변증**으로 해석한다.

## 1. 오래된 비증 + 간신부족
허리와 무릎의 통증·무력감, 냉감, 오래 지속되는 통증 등이 함께 나타나는 경우.

연결:
- [독활기생탕](../formulas/duhuo-jisheng-tang.md)
- [두충](../herbs/eucommia.md)
- [우슬](../herbs/achyranthes.md)
- [당귀](../herbs/angelica.md)
- [인삼](../herbs/ginseng.md)

독활기생탕은 거풍습과 함께 간신·기혈을 보하는 구조를 지녀 만성적인 근골격계 허증을 이해하는 대표 처방이다.

## 2. 어혈
고정된 부위의 통증, 자통, 오래된 외상 후 통증 등은 전통적으로 어혈과 연결해 해석할 수 있다.

연결:
- [어혈](../diagnostics/blood-stasis.md)
- [당귀](../herbs/angelica.md)
- [천궁](../herbs/chuanxiong.md)

## 3. 근골 관련 본초
### [두충](../herbs/eucommia.md)
보간신·강근골의 대표 본초.

### [우슬](../herbs/achyranthes.md)
보간신·강근골과 활혈통경의 방향을 함께 지닌 본초.

## 지식망 요약
```text
요통
├─ 풍한습비 + 간신부족
│  ├─ 독활기생탕
│  ├─ 두충
│  └─ 우슬
└─ 어혈
   ├─ 당귀
   └─ 천궁
```
