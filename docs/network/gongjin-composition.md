# 공진단 구성 본초

공진단의 네 본초는 전통적으로 **보익·보혈·수렴·통달**을 나누어 맡습니다. 실제 제제는 약재의 기원·포제와 배합 비율까지 함께 확인합니다.

| 본초 | 배합의 중심 | 심화해서 읽을 내용 |
|---|---|---|
| [녹용](../herbs/cervi-parvum-cornu.md) | 정혈·신양·근골 보익 | 원전의 酥炙·去毛皮와 분말·물 추출·효소처리의 차이 |
| [당귀](../herbs/angelica.md#species-chemistry) | 보혈·행혈 | 川當歸 기록과 참당귀·중국당귀·일당귀의 기원·성분 차이 |
| [산수유](../herbs/cornus-fructus.md#constituent-quality) | 간신 보익·수렴 | 씨를 제거한 과육, 주제품과 loganin·morroniside 연구 |
| [사향](../herbs/moschus.md#material-identity) | 방향·개규·통달 | 천연 사향·무스콘·대체 원료와 완제품 임상시험의 구분 |

## [녹용](../herbs/cervi-parvum-cornu.md)
공진단의 보익적 중심축. 정혈·신양·근골을 돕는다.

## [당귀](../herbs/angelica.md)
혈을 보하면서 혈행을 돕는 방향을 더한다.

## [산수유](../herbs/cornus-fructus.md)
간신을 보하고 정기의 지나친 소모를 수렴하는 방향을 더한다.

## [사향](../herbs/moschus.md)
밀도 높은 보익 배합에 개규·행기·통락의 방향을 부여하는 특징적인 약재다.

## 전체 구조
공진단은 **보익 + 보혈 + 수렴 + 통달**이 결합된 처방으로 이해할 수 있다.

## 네 본초로 읽는 공진단

원전은 녹용·산수유·당귀 **각 4량**, 사향 **반량·別研**을 기록합니다. 같은 약미라도 원료종·부위·포제·혼합 균일성과 실제 1환 함량을 확인해야 합니다. 전통 단위를 제품의 mg으로 자동 환산하거나, 사향의 ‘引藥透達’을 모든 성분의 흡수율 증가로 설명하지 않습니다.

[공진단 원문·출전별 용량](../formulas/gongjin-dan.md#source-dose-original)에서 배합을 먼저 확인한 뒤, 각 본초의 성분·제형과 완제품 사람 연구를 연결합니다. 단일 성분의 동물실험은 공진단 전체의 임상효과와 별도로 읽습니다.
