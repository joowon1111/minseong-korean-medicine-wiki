# 의가·고전·처방 계보

한의학의 처방과 치료이론은 각각 따로 존재하기보다 **의가의 임상관점 → 고전의 이론 → 병증 해석 → 처방과 치료체계**로 이어져 발전해 왔다.

```text
장중경
├─ 상한론
│  ├─ 계지탕
│  ├─ 마황탕
│  ├─ 갈근탕
│  ├─ 소청룡탕
│  ├─ 소시호탕
│  └─ 오령산
└─ 금궤요략
   └─ 허로·담음·흉비·수기·잡병

이동원
└─ 비위론
   └─ 비위기허·중기하함
      └─ 보중익기탕

손사막
└─ 비급천금요방
   └─ 풍한습비 + 간신·기혈허
      └─ 독활기생탕

이천
└─ 의학입문
   └─ 기초·진단·본초·상한·내상·잡병·침구

허준
└─ 동의보감
   ├─ 공진단
   └─ 경옥고

이제마
└─ 동의수세보원
   └─ 사상의학
      ├─ 태양인
      ├─ 태음인
      ├─ 소양인
      └─ 소음인
```

## 이 지식망의 의미

이 구조를 통해 사용자는 처방명만 찾는 데서 끝나지 않고 **“이 처방은 어떤 의가의 어떤 임상관점에서 나왔는가?”**, **“어떤 고전의 어떤 병리체계와 연결되는가?”**를 역으로 탐색할 수 있다.
