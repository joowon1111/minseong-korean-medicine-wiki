# 방제·경혈 임상 조합 지도

**육군자탕·향사육군자탕 ↔ [족삼리 ST36](../acupuncture/points/st36-zusanli.md)·[중완 CV12](../acupuncture/points/cv12-zhongwan.md)·[내관 PC6](../acupuncture/points/pc6-neiguan.md)**
→ [소화불량 임상 경로](../conditions/dyspepsia.md)

## 수면·심계
**귀비탕·산조인탕 ↔ [신문 HT7](../acupuncture/points/ht7-shenmen.md)·[내관 PC6](../acupuncture/points/pc6-neiguan.md)·[인당 EX-HN3](../acupuncture/points/ex-hn3-yintang.md)**
→ [불면 임상 경로](../conditions/insomnia.md)

## 한습·어혈성 근골격 통증
**오적산·소경활혈탕 ↔ [대장수 BL25](../acupuncture/points/bl25-dachangshu.md)·[위중 BL40](../acupuncture/points/bl40-weizhong.md)·[곤륜 BL60](../acupuncture/points/bl60-kunlun.md)**
→ [요통 임상 경로](../conditions/low-back-pain.md)

## 여성 냉증·어혈
**온경탕·계지복령환 ↔ [삼음교 SP6](../acupuncture/points/sp6-sanyinjiao.md)·[관원 CV4](../acupuncture/points/cv4-guanyuan.md)·[태충 LR3](../acupuncture/points/lr3-taichong.md)**
→ [여성 임상 경로](../conditions/dysmenorrhea.md)

## 기허·회복저하
**보중익기탕·십전대보탕 ↔ [족삼리 ST36](../acupuncture/points/st36-zusanli.md)·[기해 CV6](../acupuncture/points/cv6-qihai.md)·[관원 CV4](../acupuncture/points/cv4-guanyuan.md)**
→ [피로·회복 임상 경로](../conditions/chronic-fatigue.md)

## 해석 원칙
한약과 침구를 같은 효능으로 단순 대응시키지 않고 **병증·치법이라는 공통 언어**를 중심으로 연결합니다.
