# 처방 구성 네트워크

한의학 처방은 약재의 단순한 목록이 아니라 **여러 본초의 역할·용량·배합 관계가 하나의 치료 방향을 만드는 구조**다. 같은 약재도 처방 안의 비중과 짝이 되는 약재에 따라 의미가 달라진다.

## 대표 처방

| 처방 | 핵심 구성 | 배합을 읽는 축 | 연결할 임상 맥락 |
|---|---|---|---|
| [공진단](gongjin-composition.md) | 녹용·당귀·산수유·사향 | 보익·정혈과 통달의 결합 | 피로·회복을 볼 때 원방과 현대 제형을 구분 |
| [경옥고](gyeongok-composition.md) | 인삼·생지황·복령·봉밀 | 기·음·진액과 비위의 조화 | 보익·윤조의 방향과 복용 조건 |
| [생맥산](shengmai-composition.md) | 인삼·맥문동·오미자 | 익기·양음·생진·수렴 | 기진양상과 진액 손상의 동시 고려 |
| [오령산](wuling-composition.md) | 택사·저령·복령·백출·계지 | 이수·건비·기화 | 수분대사 양상과 표리 맥락 |
| [십전대보탕](shipjeondaebo-composition.md) | 팔물탕 + 황기·육계 | 기혈쌍보에 온보를 더함 | 허약·회복기의 한열과 소화상태 |

## 처방을 읽는 다섯 축

1. **기본 골격**: 처방의 중심 병리와 치료 방향을 만드는 약물군은 무엇인가?
2. **역할 분담**: 주된 방향, 보조, 조화, 전달을 담당하는 구성은 무엇인가?
3. **용량 관계**: 포함 여부뿐 아니라 어느 약재의 비중이 높은가?
4. **가감 규칙**: 어떤 증후가 있을 때 무엇을 더하거나 줄이는가?
5. **제법·제형**: 탕·환·고·산, 포제와 추출법이 처방의 실제 투여를 어떻게 바꾸는가?

군신좌사 표기는 배합을 설명하는 유용한 틀이지만 모든 처방을 하나의 고정 역할표에 억지로 맞추지는 않는다. 원전의 구성과 후대의 해석, 현대 제품의 실제 조성을 구분한다.

## 탐색 방법

처방 문서에서 구성 본초로 이동한 뒤 그 본초가 들어가는 다른 처방을 찾고, 두 처방에서의 역할·용량·짝약재를 비교한다. 이후 처방군 지도에서 기본방과 파생방의 차이를 확인하면 `처방 → 본초 → 다른 처방 → 처방군`의 지식망이 형성된다.

구성 유사성이 곧 임상적 대체 가능성을 뜻하지는 않는다. 실제 선택은 환자의 증상·변증·체질, 병용약, 제형과 안전성을 함께 평가한다.
