# 십전대보탕 구성 본초

십전대보탕은 열 개 약재를 각각 외우기보다 **사군자탕 + 사물탕 + 황기 + 육계**로 보면 구조가 명확하다.

```text
십전대보탕
├─ 사군자탕 → 보기
│  ├─ 인삼
│  ├─ 백출
│  ├─ 복령
│  └─ 감초
├─ 사물탕 → 보혈·활혈
│  ├─ 숙지황
│  ├─ 당귀
│  ├─ 백작약
│  └─ 천궁
├─ 황기 → 보기 강화
└─ 육계 → 온보·온통
```
