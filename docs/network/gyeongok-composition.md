# 경옥고 구성 본초

경옥고는 **생지황즙·인삼 가루·백복령 가루·정련한 봉밀**을 함께 중탕하는 고제입니다. 무엇을 넣는지뿐 아니라 즙·분말·꿀이라는 재료 상태를 함께 읽습니다.

| 본초 | 배합의 중심 | 심화해서 읽을 내용 |
|---|---|---|
| [인삼](../herbs/ginseng.md#tonic-preparation-context) | 보기·보원 | 분말·탕약·홍삼 추출물과 진세노사이드·다당류의 차이 |
| [생지황](../herbs/fresh-rehmannia.md) | 자음·생진 | 생즙의 수분·당질·카탈폴과 증숙 지황의 구분 |
| [복령](../herbs/poria.md#gyeongok-powder) | 건비·삼습 | 細末 제형, 다당류·트리테르펜의 분획과 기원 |
| [봉밀](../herbs/honey.md#honey-processing) | 보중·윤조·제형 | 정련·수분·점도·당질과 제조·보관 안정성 |

## [인삼](../herbs/ginseng.md)
원기와 비·폐의 기를 돕는 보기의 중심축.

## [생지황](../herbs/fresh-rehmannia.md)
음혈과 진액을 돕는 자음·생진의 중심축.

## [복령](../herbs/poria.md)
비위를 돕고 습을 조절하는 전통적 배합축이다. 다른 약재의 흡수율 증가가 입증됐다는 뜻은 아니다.

## 봉밀
약성을 조화시키고 고(膏)의 제형을 형성하며 전통적으로 보중·윤조의 방향을 지닌다.

## 전체 구조
경옥고는 **보기 + 자음 + 건비 + 윤조**를 간결하게 결합한 양생 보익 처방이다.

## 네 본초로 읽는 경옥고

인삼·복령을 달여 거른 추출액과 고제 속 분말은 같은 재료 상태가 아닙니다. 생지황즙을 숙지황 탕액으로 바꾸거나 봉밀을 다른 당질로 바꾸면 추출·농축·점도·보관 조건과 원방의 구성이 함께 달라집니다.

[경옥고 출전별 배합](../formulas/gyeongok-go.md#donguibogam-variants)은 복령 48량·49량 수록형을 나누며, [제법·성분 변화](../formulas/gyeongok-go.md#preparation-chemistry)는 중탕·농축의 변수를 설명합니다. 고제의 품질과 임상효과는 완제품 자료로 확인하고 각 본초의 성분 실험과 연결합니다.
