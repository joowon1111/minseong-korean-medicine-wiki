# 침구 임상 지식망 {#_1}

침구는 혈자리 목록에서 시작하기보다 **안전성 감별 → 문제 정의 → 치료목표 → 경맥·경혈과 배혈 → 자극량 → 반응평가**로 연결한다. 같은 증상이라도 원인·병기·부위·환자 상태에 따라 혈위와 자극법은 달라질 수 있다.

## 임상 연결 순서 {#_2}

| 단계 | 확인할 내용 | 기록할 예 |
|---|---|---|
| 1. 안전성 감별 | 응급·중증 가능성, 출혈 위험, 감염, 임신, 시술 금기 | 즉시 의뢰가 필요한가? |
| 2. 문제 정의 | 통증 부위·성격, 기능 제한, 유발·완화 요인, 전신 증상 | 목 회전 시 통증과 가동범위 제한 |
| 3. 치료목표 | 통증, 기능, 수면, 일상활동 중 우선 목표 | 통증점수보다 야간수면 회복 우선 |
| 4. 배혈 설계 | 국소·원위혈, 경맥, 특정혈, 변증 근거 | 국소 2혈 + 원위 2혈 |
| 5. 자극량 | 깊이·방향·수기·득기·유침·전침·빈도 | 회당 조건과 주당 횟수 |
| 6. 재평가 | 같은 지표를 같은 시점에 반복 | 즉시 반응, 다음 방문, 치료군 종료 |

### 같은 요통에서도 목표가 달라지는 이유 {#assessment-example}

허리를 숙일 때만 국소적으로 아픈 사람과, 오래 서면 종아리까지 저리는 사람은 같은 ‘요통’이라고 말해도 평가가 다릅니다. 전자는 요추·고관절 움직임과 국소 압통을 살피고 앉았다 일어나기·물건 들기를 목표로 정할 수 있습니다. 후자는 근력·감각·반사와 보행·혈관 상태를 확인한 뒤 다리 증상과 연속 보행을 목표로 삼습니다.

두 경우 모두 신수·위중이 포함될 수 있지만 **그 혈을 쓴 이유, 다른 혈과 조합한 이유, 좋아졌다고 판단할 기준**은 달라집니다. [요통 경혈 지식망](low-back-pain-acupoints.md#point-combinations)에서 국소통·방사통·보행통을 나누어 읽습니다.

## 특정혈과 배혈 {#_5}

원혈·락혈·극혈·합혈·하합혈·배수혈·모혈·팔회혈·팔맥교회혈의 성격을 배혈 이유와 연결한다. 혈의 분류만 나열하지 않고 “이 환자의 어떤 목표 때문에 이 혈을 선택했는가”를 기록한다.

배혈은 다음 축으로 비교할 수 있다.

- **국소 + 원위**: 증상 부위의 조직·경근과 관련 경맥의 원위혈을 결합
- **전면 + 후면**: 복모혈과 배수혈처럼 기능적 연결을 활용
- **원혈 + 락혈**: 표리경 관계를 임상 목표에 맞게 활용
- **팔맥교회혈 짝**: 증상 영역과 기경팔맥의 연결을 근거로 선택
- **기본혈 + 변증혈**: 공통 치료 골격에 개인별 소견을 반영

예를 들어 중완은 위의 모혈, 족삼리는 위의 하합혈이라는 전통적 분류로 복부와 하지의 연결을 설명할 수 있습니다. 신수는 배수혈의 의미와 요부 국소 기능을 함께 살피고, 내관·공손은 팔맥교회혈 관계와 실제 흉격·상복부 증상을 비교합니다. 분류는 선택을 설명하는 도구이며 혈위 하나의 임상효과를 보증하는 등급이 아닙니다.

경맥의 선은 현대 신경근·말초신경의 분포와 다른 체계입니다. 다리 뒤쪽 방사통을 방광경과 비교하더라도 감각·근력·반사로 신경 문제를 별도로 확인합니다. **경혈, 압통에 따라 정하는 아시혈, 근육의 통증유발점**도 서로 겹칠 수 있지만 같은 개념으로 통합하지 않습니다. [통증유발점·연관통 평가](../clinical-anatomy/mps-atlas.md#assessment)

## 자극법과 ‘용량’도 치료의 일부다 {#_6}

같은 혈을 사용해도 침 규격, 깊이·방향, 수기 자극, 득기, 유침시간, 전침 주파수, 회당 혈수, 치료 간격에 따라 중재가 달라진다. 반응과 이상반응을 기록하고 다음 회차의 자극량을 조정한다. 연구를 읽을 때도 혈위명만 비교하지 말고 이 세부조건을 확인한다.

### 반응에 따라 치료를 조정하기 {#response-decisions}

| 관찰한 반응 | 다음 판단 |
|---|---|
| 통증이 줄고 같은 동작·활동도 편해짐 | 효과 지속시간과 다음 날 반응을 보고 운동·일상 부하를 조절 |
| 시술 직후만 편하고 기능 변화가 없음 | 진단, 치료 목표, 업무·수면·운동 부하와 치료 구성을 재검토 |
| 멍·국소 통증·피로가 오래가 일상에 방해 | 혈수·자극 강도·간격과 출혈 위험·체위 조정 |
| 새 근력저하·감각 변화, 흉통·호흡곤란·고열 | 치료 반응으로 넘기지 않고 필요한 신속 평가 |
| 활동 뒤 지연성 악화가 반복됨 | 피로의 원인과 PEM을 재평가하고 이동·치료 부담까지 감량 |

좋은 반응은 통증점수 하나만이 아닙니다. 요통은 앉기·걷기, 불면은 수면과 낮 집중력, 소화불량은 섭취와 식후 활동, 피로는 활동 지속·회복시간을 같은 기준으로 비교합니다. 목표가 달라지면 평가 도구도 달라집니다.

## 연구의 질문을 구분하기 {#evidence-reading}

경혈 네트워크에서 많이 쓰인 혈은 실제 연구의 배혈 경향을 보여줍니다. 그러나 많이 함께 쓰였다는 이유만으로 그 혈의 독립 효과나 조합의 우월성이 입증된 것은 아닙니다. 특히 ‘경혈 연결망 분석’과 치료법을 직접·간접 비교하는 ‘네트워크 메타분석’은 이름이 비슷해도 같은 분석이 아닙니다.

| 연구·자료 | 답하는 질문 | 함께 확인할 조건 |
|---|---|---|
| 경혈 사용 빈도·연관규칙 | 어떤 혈이 자주 함께 쓰였는가? | 수록 문헌·질환군·선택 관행; 효과의 인과관계와 구분 |
| 무작위 비교시험 | 해당 환자에게 해당 치료를 더하면 얼마나 달라지는가? | 통상관리·가짜침 등 비교군, 혈위·자극·기간·척도 |
| 체계적 문헌고찰·메타분석 | 여러 시험의 결과를 함께 보면 어떤가? | 편향·이질성·근거확실성, 같은 시험의 중복 포함 |
| 기전·생리 연구 | 어떤 신경·생리 변화와 관련되는가? | 동물·건강인·환자 구분; 생리 변화와 임상적 이득 구분 |
| 진료지침 | 어떤 상황에서 치료를 고려하도록 권고하는가? | 발표 시점·대상·권고 강도·근거확실성과 적용 환경 |

미국 고령자 요통 시험은 기존 진료에 침을 병행한 결과를, PDS 시험은 특정 식후불편 환자에서 침과 가짜침의 차이를 보여줍니다. 일반침·전침·피부 전기자극·약침도 중재가 다르므로 혈명이 같다는 이유만으로 결과를 옮기지 않습니다.
