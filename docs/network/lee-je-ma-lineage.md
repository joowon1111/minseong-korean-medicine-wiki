# 이제마 계보

[이제마](../physicians/lee-je-ma.md)의 [《동의수세보원》](../classics/donguisusebowon.md)은 사상의학을 체계화하여 **체질 → 장부 구조 → 현재의 병증 → 체질별 치료**로 이어지는 독자적인 임상체계를 형성했다.

```text
이제마
 ↓
동의수세보원
 ↓
사상의학
├─ 태양인 → 폐대간소
├─ 태음인 → 간대폐소
├─ 소양인 → 비대신소
└─ 소음인 → 신대비소
      ↓
현재의 표리병증
      ↓
체질별 치료
```
