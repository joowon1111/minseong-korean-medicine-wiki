# 불면 경혈 지식망

불면 침구치료에서는 심신을 안정시키고, 기혈과 장부의 불균형을 조절하는 경혈이 자주 활용된다.

## 대표 경혈
- [신문 HT7](../acupuncture/points/ht7-shenmen.md) — 양심안신
- [삼음교 SP6](../acupuncture/points/sp6-sanyinjiao.md) — 비·간·신 조절, 양혈안신
- [내관 PC6](../acupuncture/points/pc6-neiguan.md) — 관흉이기·안신
- [백회 GV20](../acupuncture/points/gv20-baihui.md) — 성뇌·안신

2024년 노년성 불면 systematic review에서는 HT7, SP6, GV20, ST36, PC6가 주요 경혈로 확인되었고, HT7·SP6·ST36가 핵심적인 조합으로 제시됐다.

```text
불면
├─ 심신불안 → 신문·내관
├─ 음혈·간신 조절 → 삼음교
└─ 두면·신지 조절 → 백회
```
