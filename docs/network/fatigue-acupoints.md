# 피로·회복 경혈 지식망

허약과 피로의 침구치료에서는 비위의 기를 돕고 원기와 전신 조절을 보조하는 경혈이 자주 활용된다.

## 대표 경혈
- [족삼리 ST36](../acupuncture/points/st36-zusanli.md) — 건비·보기·전신 조절
- [관원 CV4](../acupuncture/points/cv4-guanyuan.md) — 원기·하초·허손
- [백회 GV20](../acupuncture/points/gv20-baihui.md) — 승양·성뇌

## 본초·방제와 연결
- 기허 → [인삼](../herbs/ginseng.md)·[황기](../herbs/astragalus.md) → [보중익기탕](../formulas/buzhong-yiqi-tang.md)
- 정혈 허손 → [녹용](../herbs/cervi-parvum-cornu.md) → [공진단](../formulas/gongjin-dan.md)
- 양생·기음 → [경옥고](../formulas/gyeongok-go.md)

피로·회복
