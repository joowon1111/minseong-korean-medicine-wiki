# 고전→현대 연구 연결 지도 {#_1}

고전에서 읽은 병증과 처방을 **현재의 증상 안내, 구성 본초, 임상시험과 진료지침까지 이어서 확인하는 지도**입니다. 고전의 주치 문구는 처방을 이해하는 출발점이고, 현대 연구는 어떤 환자에게 어떤 제제로 무엇을 평가했는지 알려 줍니다.

`원문·현대어 독해 → 병증·병기 → 치법 → 본초·방제·침구 → 현대 임상 질문 → 연구·안전성`

같은 처방이 등장하는 두 고전을 연결하고, 연구에서는 원방·가감방·제형·병용치료를 확인합니다. 고전 병증과 현대 진단은 각각의 기준을 유지하면서 비교합니다.

## 황제내경 {#_2}

[황제내경 임상 지식망](../neijing-network/index.md)에서 장상·경락·통증·침구의 개념을 읽고, [경락](../meridian-network/index.md)과 [표준 경혈](../acupoint-network/standard-atlas.md)에서 위치와 관계를 확인합니다. 현대 적용은 [통증·근골격](../pillar/pain-musculoskeletal.md)의 질환별 평가와 [침구 근거](../evidence-integrated/acupuncture-evidence.md)로 이어집니다. 고전의 혈위 설명과 현대 연구의 자침·전침 조건은 각각 출처를 확인합니다.

## 상한론·금궤요략 {#_3}

[상한론](../shanghan-network/index.md)은 육경과 치료 전후의 변화를, [금궤요략](../jingui-network/index.md)은 잡병의 증후 조합을 중심으로 읽습니다. 두 책에서 같은 처방을 찾아보면 병명보다 **땀·갈증·구토·배변·어지럼·복부 소견이 어떻게 묶이는지**가 드러납니다.

| 연결할 처방 | 상한론의 출발점 | 금궤요략의 출발점 | 이어서 볼 구조 |

| 소건중탕 | [102조 심계·번증](../classics/shanghanlun/clauses/taiyang-middle.md#clause-102) | [6.13 허로·복통·심계](../classics/jinkui-yaolue/chapters/blood-bi-deficiency.md#clause-06-013) | [건중과 완급](../formulas/xiaojianzhong-tang.md) |

### 원전에서 기존 근거 카드까지 {#clinical-examples}

아래 연구 연결은 원전 병증을 현대 질환명으로 바꾼 표가 아닙니다. **원전에서 얻은 질문을 실제 연구 대상과 대조하는 경로**입니다.

| 원전에서 읽는 질문 | 현재 임상·처방 자료 | 확인한 현대 연구 | 적용 범위를 판단할 항목 |
|---|---|---|---|
| 반하사심탕의 심하비에 구토·장명이 어떻게 동반되는가 | [기능성소화불량](../conditions/functional-dyspepsia.md) → [반하사심탕 근거 카드](../authority/formulas/banxia-xiexin-tang.md) | [2023 SR·메타분석, 57 RCT·5,525명](https://www.frontiersin.org/journals/pharmacology/articles/10.3389/fphar.2023.1130257/full) | 기능성소화불량 진단, 가감방, 단독·병용, 증상척도와 임상반응의 정의 |
| [6.17 허로허번불면](../classics/jinkui-yaolue/chapters/blood-bi-deficiency.md#clause-06-017)에서 산조인탕을 어떻게 읽는가 | [불면](../conditions/insomnia.md) → [산조인탕 근거 카드](../authority/formulas/suanzaoren-tang.md) | [2022 SR·메타분석, 12 RCT·1,311명](https://pubmed.ncbi.nlm.nih.gov/36459033/) | 만성불면 대상, 원방·가감방, PSQI, 비교치료, 추적기간 |
| [10.14 대건중탕](../classics/jinkui-yaolue/chapters/abdominal-cold-food.md#clause-10-014)의 냉통·구토·음식불능을 어떻게 읽는가 | [대건중탕의 현대 제제·연구](../formulas/dajianzhong-tang.md) → [수술 후 회복](../conditions/postoperative-recovery.md) | [2025 수술 후 장기능 관련 메타분석](https://pubmed.ncbi.nlm.nih.gov/40820043/) | 수술 종류, 사용 제제, 장기능 결과지표; 전체 수술 회복 효과와 구분 |

논문 숫자에 더해 무작위배정·눈가림, 연구 간 차이, 이상반응 보고를 함께 확인합니다. 임신·수유, 간·신장 기능, 병용약물과 포제는 [한약 안전성 근거](../herbal-integrated/safety.md#safety-evidence-guide)에서 이어서 살핍니다.

## 동의보감 {#_4}

[동의보감 5편 임상 색인](../donguibogam-network/index.md#clinical-index)은 내경의 담음·기혈진액, 외형의 부위별 증상, 잡병의 내상·허로·부인·소아를 탕액과 침구로 연결합니다.

- **담음**: [담음 변증](../diagnostics/patterns/phlegm-fluid.md) → [반하](../herbs/pinellia.md)·[진피](../herbs/citrus-peel.md)·[복령](../herbs/poria.md) → [이진탕](../formulas/erchen-tang.md)·[온담탕](../formulas/wendan-tang.md)·[영계출감탕](../formulas/linggui-zhugan-tang.md) → 증상별 연구 질문.
- **허로·내상**: [기허](../diagnostics/patterns/qi-deficiency.md) → [보익 처방 계열](../formula-architecture/tonic-family.md) → [보중익기탕 연구](../research/formulas/buzhong-yiqi-tang.md)와 [피로 한약 근거](../authority/formulas/chronic-fatigue-herbal-map.md).

고전에 함께 등장하거나 후대 해석으로 연결되는 처방은 출전을 구분하고, 원방·연구 제제의 구성 차이는 각 방제 문서에서 확인합니다.

## 동의수세보원 {#_5}

[사상의학 통합 허브](../sasang-integrated/index.md)에서 소증·체질병증·표리·순역을 먼저 읽고 [사상의학 연구](../sasang-research/index.md)로 이동합니다. 연구의 체질 진단 방법, 병증 기준, 처방 구성과 결과지표를 확인하여 사상의학의 체계를 보존합니다.

## 연구 유형에 맞춰 읽기 {#evidence-reading}

[Evidence Hub](../portal/evidence.md#classical-evidence-paths)에서 진료지침·SR·메타분석·RCT·안전성 자료를 목적에 맞게 고를 수 있습니다. 진료지침은 권고 대상과 조건, SR은 전체 연구의 일관성, RCT는 구체적 중재와 비교군, 안전성 연구는 이상반응과 사용 조건을 살피는 자료입니다.
