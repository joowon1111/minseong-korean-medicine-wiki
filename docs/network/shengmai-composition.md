# 생맥산 구성 본초

```text
생맥산
├─ 인삼 → 익기
├─ 맥문동 → 양음·생진
└─ 오미자 → 수렴·생진
```

## [인삼](../herbs/ginseng.md)
기운을 돕는 중심축.

## [맥문동](../herbs/ophiopogon.md)
음과 진액을 보하여 인삼의 보기와 균형을 이룬다.

## [오미자](../herbs/schisandra.md)
기와 진액이 지나치게 흩어지는 것을 수렴하는 방향을 더한다.

## 전체 구조
세 약재만으로 **익기 + 양음 + 생진 + 수렴**을 완성하는 대표적인 소방이다.

→ [생맥산](../formulas/shengmai-san.md)
