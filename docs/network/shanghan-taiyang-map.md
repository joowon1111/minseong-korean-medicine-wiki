# 상한론 전체 조문 지도 {#_1}

《상한론》은 태양병의 몇 가지 해표 처방에서 끝나지 않습니다. **표리·한열·허실의 변화, 수기와 진액·혈분, 잘못된 치료 뒤의 구제, 큰 병 이후의 회복**까지 이어집니다. 이 지도에서 통행 398조의 각 편으로 들어가 원문과 조문별 한국어 독해를 읽을 수 있습니다.

## 전체 조문으로 들어가기 {#complete-map}

| 편과 조문 | 중심 내용 | 원문·독해 |
|---|---|---|
| 태양 상 · 1–30조 | 제강·계지탕류·오치 뒤 회복 | [태양병 상편](../classics/shanghanlun/clauses/taiyang-upper.md) |
| 태양 중 · 31–127조 | 해표·수음·허번·시호탕류·축혈 | [태양병 중편](../classics/shanghanlun/clauses/taiyang-middle.md) |
| 태양 하 · 128–178조 | 결흉·비·사심탕류·풍습·심계 | [태양병 하편](../classics/shanghanlun/clauses/taiyang-lower.md) |
| 양명 · 179–262조 | 위가실·진액·백호·승기·황달 | [양명병편](../classics/shanghanlun/clauses/yangming.md) |
| 소양 · 263–272조 | 구고·인건·목현·화해와 금기 | [소양병편](../classics/shanghanlun/clauses/shaoyang.md) |
| 태음 · 273–280조 | 복만·토리·중초 허한·복통 | [태음병편](../classics/shanghanlun/clauses/taiyin.md) |
| 소음 · 281–325조 | 한화·열화·수기·인후병 | [소음병편](../classics/shanghanlun/clauses/shaoyin.md) |
| 궐음 · 326–381조 | 궐열·한열착잡·하리·구토 | [궐음병편](../classics/shanghanlun/clauses/jueyin.md) |
| 곽란 · 382–391조 | 토리·한열·체액 손상 | [곽란병편](../classics/shanghanlun/clauses/huoluan.md) |
| 음양역·차후노복 · 392–398조 | 노복·재발열·수기·기진 회복·식복 | [회복기편](../classics/shanghanlun/clauses/recovery.md) |

398조에 포함되지 않는 [서문·맥법·상한례·치습갈](../classics/shanghanlun/clauses/prefaces-pulse.md)과 [한·토·하의 가부 및 치료 후](../classics/shanghanlun/clauses/treatment-methods.md)도 송본의 원문·편별 해설로 이어집니다. [판본·수록 범위와 용어 안내](../shanghan-network/index.md#complete-clauses)에서 조문 번호와 해석의 기준을 확인할 수 있습니다.

## 계지탕 {#_2}
영위불화와 자한을 중심으로 이해하는 태양중풍의 대표 처방이다.

→ [계지탕](../formulas/guizhi-tang.md) · [12–13조 원문·독해](../classics/shanghanlun/clauses/taiyang-upper.md#clause-012)

## 마황탕 {#_3}
무한·신통 등 표실의 양상을 중심으로 하는 태양상한의 대표 처방이다.

→ [마황탕](../formulas/mahuang-tang.md) · [35조 원문·독해](../classics/shanghanlun/clauses/taiyang-middle.md#clause-035)

## 갈근탕 {#_4}
태양병에서 항배강 등 경항부의 긴장이 두드러지는 맥락과 연결된다.

→ [갈근탕](../formulas/gegen-tang.md) · [31–34조 원문·독해](../classics/shanghanlun/clauses/taiyang-middle.md#clause-031)

## 대청룡탕 {#_5}
강한 표실에 번조·내열의 양상이 함께 나타나는 구조를 이해하는 데 중요하다.

→ [대청룡탕](../formulas/daqinglong-tang.md) · [38–39조 원문·독해](../classics/shanghanlun/clauses/taiyang-middle.md#clause-038)

## 소청룡탕 {#_6}
표증과 함께 담음·수음이 겹쳐 기침·천명·묽은 담 등의 양상이 나타나는 구조와 연결된다.

→ [소청룡탕](../formulas/xiaoqinglong-tang.md) · [40–41조 원문·독해](../classics/shanghanlun/clauses/taiyang-middle.md#clause-040)

## 오령산 {#_7}
태양병 과정에서 수액대사의 불균형과 소변불리·구갈 등의 수기 문제를 다루는 대표 처방이다.

→ [오령산](../formulas/wuling-san.md) · [71–74조 원문·독해](../classics/shanghanlun/clauses/taiyang-middle.md#clause-071)
