# 통합 한의학 지식 그래프

민성 한의학 아카이브의 핵심 구조를 **한 방향으로만 읽는 문서 모음이 아니라 서로 역탐색 가능한 지식망**으로 정리한다.

```text
의가
 ↓
고전
 ↓
이론·변증
 ↓
본초 ↔ 방제
 ↓
질환·증상
 ↓
침·약침·전침·부항·뜸
 ↓
현대 임상연구
```

## 본초에서 시작하기
예:
`인삼 → 사군자탕·육군자탕·보중익기탕·귀비탕·경옥고`

→ [본초→방제 역탐색](herb-to-formula-map.md)

## 방제에서 시작하기
예:
`보중익기탕 → 비위기허·중기하함 → 피로·허약`

→ [방제→질환·변증 지도](formula-to-condition-map.md)

## 증상에서 시작하기
예:
`요통 → 신수·위중 → 침·약침·전침·부항 → 독활기생탕`

→ [질환→치료 통합 지도](condition-to-treatment-map.md)

## 고전에서 시작하기
예:
`상한론 → 계지탕·마황탕·소청룡탕 → 현대 연구 문서`

→ [고전→현대 연구 연결](classic-to-evidence-map.md)
