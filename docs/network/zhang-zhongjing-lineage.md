# 장중경 계보

[장중경](../physicians/zhang-zhongjing.md) 계통의 핵심은 **맥과 증후를 바탕으로 병의 구조를 파악하고 그에 맞는 처방을 선택하는 임상체계**에 있다.

```text
장중경
├─ 상한론
│  ├─ 태양병 → 계지탕·마황탕
│  ├─ 항배강 → 갈근탕
│  ├─ 표증 + 수음 → 소청룡탕
│  ├─ 소양병 → 소시호탕
│  └─ 수기불리 → 오령산
└─ 금궤요략
   ├─ 허로
   ├─ 담음
   ├─ 흉비
   ├─ 수기
   └─ 부인병·잡병
```

## 상한론
[《상한론》](../classics/shanghanlun.md)은 육경과 맥증의 변화에 따라 처방을 연결하는 고방 임상체계의 대표 고전이다.

## 금궤요략
[《금궤요략》](../classics/jinkui-yaolue.md)은 잡병을 중심으로 허로·담음·흉비·수기 등 다양한 임상 상황의 맥증과 처방 구조를 보여준다.

## 지식망 확장
장중경 계보는 **고전 → 증후 → 방제**가 가장 선명하게 연결되는 축 가운데 하나다.
