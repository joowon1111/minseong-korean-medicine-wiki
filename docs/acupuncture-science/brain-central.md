# 침과 뇌·중추신경계

fMRI·PET 등 neuroimaging은 살아있는 사람에서 침 자극과 치료 전후의 뇌 기능 변화를 탐색할 수 있게 했습니다.

## 반복적으로 연구되는 뇌 영역

- anterior cingulate cortex (ACC)
- insula
- primary/secondary somatosensory cortex
- thalamus
- prefrontal cortex
- periaqueductal gray
- default mode network (DMN)
- sensorimotor network

## 최신 만성통증 근거

2026 systematic review/meta-analysis는 **17 RCT·750명**의 만성통증 환자를 분석했습니다. ACC·insula, S1·thalamus, DMN 관련 neuroimaging 지표 변화와 임상 통증 개선을 함께 평가했습니다. PMID `42147848`.

2022 fMRI coordinate-based meta-analysis는 **14개 연구·524명**에서 만성통증 침 치료와 default mode network 및 frontoparietal network의 변화를 정리했습니다. PMID `36590302`.

## 해석

뇌영상 변화는 ‘특정 뇌 부위 하나가 침의 효과를 만든다’는 식보다 **감각·통증·정서·주의·자율신경을 포함하는 네트워크 수준의 조절**로 보는 것이 적절합니다.
