# 태음인 중증도·위험신호
태음인은 **위완수한표한병**과 **간수열리열병**이라는 큰 축에서 중증도가 진행합니다.

## 표한 악화
```text
발한 불리·오한·몸의 무거움
 ↓
호흡불편·사지냉
 ↓
폐조·전신쇠약 증가
```

## 리열 악화
```text
열·구갈·번조
 ↓
조열·건조
 ↓
진액·음혈 소모
 ↓
전신쇠약
```

## 위험신호
- 평소와 달리 발한이 크게 막히거나 비정상적
- 호흡불편의 증가
- 심한 냉감·사지냉 또는 지속되는 조열
- 진액소모·건조와 기력저하
- 태음인의 건강신호인 한액통창이 현저히 무너짐

→ [표한 vs 리열](../sasang-pattern-differential/taeeumin-exterior-vs-interior.md)


## 표한과 리열의 중증도 지표

| 축 | 비교적 초기 | 깊어질 때 | 우선 평가 신호 |
|---|---|---|---|
| 표한 | 오한·발한불리·무거움 | 호흡불편·사지냉·활동저하 | 흉통·호흡곤란·저산소 |
| 승청·폐원 | 식후비만·기침·담 | 보행·식사·수면 회복 지연 | 새 발열·객혈·빠른 악화 |
| 리열 | 열·갈증·건조 | 조열·변폐·진액소모 | 심한 복통·구토·의식변화 |
| 심신·조열 | 현훈·심계·불면 | 낮 기능·활동 회복 저하 | 실신·지속 빈맥·신경학적 이상 |

## 한액통창의 붕괴를 구체화하기

땀이 안 난다는 한 문장 대신 운동·더위·발열 중 어느 상황에서 발한이 달라졌는지, 땀 뒤 몸이 편한지 탈진하는지, 갈증·부종·호흡이 함께 변하는지 적습니다. 표한의 발한불리와 리열의 과도한 발한·진액소모를 구분합니다.

## 중증도와 처방군

표한에서는 태음조위탕·조위승청탕·행인승청탕·조리폐원탕의 기능 차이를, 리열에서는 열다한소탕·청심연자탕·청폐사간탕·승기계의 열·건조·정체 차이를 비교합니다. 이는 교육용 병증 지도이며 응급도 판단을 대신하지 않습니다.
