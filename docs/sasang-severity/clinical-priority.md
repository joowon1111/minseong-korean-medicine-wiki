# 사상체질 진료 우선순위 체크
## 1. 먼저 일반적인 의학적 위험신호 확인
사상체질 감별보다 먼저 의식저하, 호흡곤란, 심한 탈수, 지속적인 출혈, 급격한 신경학적 이상, 지속적인 섭취불가 등 즉각적인 평가가 필요한 상태가 있는지 확인합니다.

## 2. 체질병증 평가
1. 체질 확정도
2. 평소 소증
3. 현재 현증
4. 표/리
5. 순/역
6. 중증도
7. 세부 병증
8. 치법·처방

## 3. 치료 후 재평가
주증상만 좋아졌는지, **소증과 일상기능까지 회복되는지**를 봅니다.

2021년 사상체질병증 진단도구 연구는 CPG와 『동의수세보원』에서 진단·평가지표를 추출해 소음인 58문항, 소양인 68문항, 태음인 81문항, 태양인 42문항의 중분류 진단도구를 개발했습니다.


## 우선순위를 0–4단계로 정리하기

| 단계 | 질문 | 행동 |
|---|---|---|
| 0 | 즉각적 위험신호가 있는가? | 응급/신속 평가 우선 |
| 1 | 현대 진단·검사가 필요한가? | 감염·심폐·신경·복부·연하 등 감별 |
| 2 | 체질과 평소 소증이 충분히 확인됐는가? | 불확실하면 체질 단정 보류 |
| 3 | 표리·순역·중증도·세부 병증은 무엇인가? | 가까운 병증/처방 비교 |
| 4 | 치료 뒤 소증·기능이 회복되는가? | 같은 지표로 재평가 |

## 체질별 우선 위험신호 예

- **소양인:** 혈변·심한 탈수, 지속 고열·의식 변화, 빠른 체중감소.
- **태음인:** 흉통·호흡곤란·저산소, 심한 부종, 장폐색 의심 복통.
- **소음인:** 지속 저혈압·실신, 반복 구토·소변 감소, 심한 설사·수족냉과 쇠약.
- **태양인:** 갑작스러운 보행/신경학적 저하, 진행성 연하곤란·흡인·체중감소.

## 치료 우선순위와 병증 우선순위는 다릅니다

전통 병증에서 위중하다고 설명되는 단계와 현대 응급도는 같은 개념이 아닙니다. 활력징후·의식·출혈·호흡·수분상태 같은 현대적 위험평가를 먼저 하고, 안정된 뒤 체질병증의 위치와 처방을 정리합니다.
