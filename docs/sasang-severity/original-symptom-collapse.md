# 소증 붕괴와 위험신호
사상의학에서 중증도를 볼 때 현재 주증상뿐 아니라 **평소 소증이 얼마나 무너졌는가**가 중요합니다. 사상체질병증 검사는 현증과 소증 검사로 구분되며, 병력청취·신체검사·진단적 검사를 함께 사용하도록 지침이 구성돼 있습니다.

## 체질별 기준점
- 소음인: 음식선화
- 소양인: 대변선통
- 태음인: 한액통창
- 태양인: 소변왕다

```text
평소 건강신호
 ↓
소증 변화
 ↓
여러 소증이 동시에 붕괴
 ↓
역증·중증도 상승 가능성 평가
```

특히 소화·배설·발한·수면·한열·갈증·활동성이 동시에 나빠질수록 현재 병증을 다시 평가해야 합니다.


## 소증 붕괴를 수치 대신 패턴으로 보기

한 항목이 심해진 것보다 **여러 평소 기능이 동시에 나빠지는지**가 중요합니다.

| 체질 | 평소 기준 | 붕괴 예 |
|---|---|---|
| 소양인 | 편안한 배변 | 설사/변폐 + 갈증 + 수면·기력 저하 |
| 태음인 | 자연스러운 발한 뒤 편안함 | 발한불리/과도한 발한 + 호흡·부종·피로 |
| 소음인 | 편안한 식사·소화 | 섭취감소 + 설사/구토 + 냉감·탈진 |
| 태양인 | 안정된 배뇨와 전신 기능 | 섭취·보행 저하와 수분·체중 변화 |

## 붕괴를 기록하는 최소 세트

발병 전 기준선과 현재를 나란히 적습니다: 한 끼 섭취량, 대변 형태·횟수, 소변량·야간뇨, 발한 상황과 땀 뒤 느낌, 수면, 체중, 보행/업무 가능 범위.

## 소증 붕괴와 현대 위험신호

소증이 여러 개 무너진다고 반드시 사상병증만 심해진 것은 아닙니다. 감염·출혈·탈수·내분비·심폐·신경계 질환도 여러 기능을 동시에 악화시킬 수 있으므로 원인 평가를 병행합니다.
