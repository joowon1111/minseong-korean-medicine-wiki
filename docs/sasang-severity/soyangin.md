# 소양인 중증도·위험신호
소양인 CPG도 **표리 → 순역 → 경·중·중증·위중 → 진행단계**의 구조를 사용하며, 역증에서는 성정편급, 설사, 주간 발열 등 평소 소증의 변화가 중요합니다.

## 서로 다른 악화축
```text
망음 방향
복통·설사·진액소모
        ↘
         중증도 상승
        ↗
흉격열 방향
열·구갈·번열·배변변화

또 다른 깊은 축
음허오열 → 배뇨·하지위약·관절통·소모
```

## 위험신호
- 설사·복통과 함께 전신 쇠약이 증가
- 지속적인 고열감·번열·갈증
- 배뇨 상태의 뚜렷한 변화
- 하지 위약·관절통·소모가 진행
- 평소 대변선통이 크게 무너짐
