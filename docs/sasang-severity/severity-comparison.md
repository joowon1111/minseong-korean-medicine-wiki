# 네 체질 경증→위중증 비교
| 체질 | 비교적 초기 변화 | 더 깊어질 때 | 특히 위험한 변화 |
|---|---|---|---|
| 소음인 | 소화저하·복통·설사·냉감 | 갈증·심번·수족냉·전신통 | 설사/섭취저하 + 심한 쇠약 |
| 소양인 | 열·갈증 또는 설사·복통 | 진액소모·배뇨변화·하지위약 | 지속 열/설사 + 전신소모 |
| 태음인 | 발한불리·오한 또는 리열 | 폐조·조열·진액/음혈소모 | 호흡·발한 붕괴 + 쇠약 |
| 태양인 | 하지기능 또는 연하 변화 | 보행/섭취 기능 저하 | 반복구토·섭취곤란·기능저하 |

이 표는 응급도 판정표가 아니라 **사상체질병증의 진행을 이해하는 교육용 지도**입니다.


## 체질 간 '누가 더 중한가'를 비교하지 않습니다

경증·중증은 체질의 우열이 아니라 **각 체질의 병증 안에서 평소 기능이 얼마나 무너졌는지**를 뜻합니다. 같은 설사라도 소양인의 망음과 소음인의 태음병·소음병은 병리적 위치가 다릅니다.

## 공통 기능 척도

| 기능 | 경증 쪽 | 중증도 상승 |
|---|---|---|
| 섭취 | 평소의 대부분 유지 | 절반 이하, 물 유지 어려움 |
| 배설 | 변화 있으나 수분 유지 | 소변 감소·심한 설사/변폐 |
| 활동 | 일상 가능 | 기립·보행·업무 현저히 감소 |
| 수면 | 불편하지만 회복 가능 | 반복 각성·낮 기능 저하 |
| 전신 | 활력징후 안정 | 의식·호흡·순환 변화 |

이 표의 수치는 임상 점수표가 아니라 관찰 방향을 설명하기 위한 예시입니다. 실제 응급도는 활력징후·검사와 현대 의학적 진단으로 판단합니다.
