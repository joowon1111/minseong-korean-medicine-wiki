# 사상체질 중증도·위험신호 지도
사상체질병증 CPG는 병증을 단순 체질명이 아니라 **표리 → 순역 → 경증·중등증·중증·위중증 → 세부 진행단계**로 구조화합니다.

```text
체질
 ↓
소증 + 현증
 ↓
표병 / 리병
 ↓
순증 / 역증
 ↓
경증 → 중등증 → 중증 → 위중증
 ↓
치법·처방·예후평가
```

특히 역증에서는 평소 소증이 얼마나 무너졌는지가 중요합니다.

## 중증도를 판단하는 네 층

1. **현재 주증의 강도:** 통증·열·설사·구토·호흡 등.
2. **소증 붕괴:** 평소 소화·대변·소변·땀·수면·한열이 얼마나 동시에 무너졌는가.
3. **기본 기능:** 섭취·배설·순환·호흡·보행·의식이 유지되는가.
4. **현대 위험신호:** 응급검사·처치가 필요한 상황이 있는가.
