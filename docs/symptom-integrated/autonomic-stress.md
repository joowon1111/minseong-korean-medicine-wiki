# 자율신경·스트레스

## 어지럼증·머리가 띵해요
급성 신경학적 이상·실신·보행불가·갑작스러운 심한 두통은 우선 평가합니다.

- 비허담습·풍담 → [반하백출천마탕](../formulas/banxia-baizhu-tianma-tang.md)
- 간양상항·간풍 → [천마구등음](../formulas/tianma-gouteng-yin.md)
- 침구는 경항부·평형·자율신경 증상을 함께 평가.

## 스트레스 받으면 소화가 안 돼요
간울기체·칠정기울 → 소요산·시호소간산·분심기음. 소화 페이지의 비위 병증과 교차해서 봅니다.

## 목에 뭔가 걸린 느낌·매핵기
구조적 인후질환·연하곤란·체중감소를 먼저 확인. 담기울결 → [반하후박탕](../formulas/banxia-houpo-tang.md).

## 손발냉증·냉증
양허·한습·말초순환·기혈 상태를 구분. 양허수습은 진무탕, 충임허한·어혈은 온경탕과 연결합니다.

## 부종·몸이 잘 붓는다
| 병증 | 처방 |
|---|---|
| 수습·기화불리 | [오령산](../formulas/wuling-san.md) |
| 수열호결 | [저령탕](../formulas/zhuling-tang.md) |
| 양허수기 | [진무탕](../formulas/zhenwu-tang.md) |

심장·신장·간질환 가능성이나 갑작스러운 부종은 우선 평가합니다.

## 화병처럼 답답하고 열이 올라요
간울화·울열·담울을 구분해 가미소요산·시호소간산·가미온담탕을 비교합니다. 흉통·호흡곤란은 별도 평가가 우선입니다.
