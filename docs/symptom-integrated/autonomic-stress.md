# 자율신경·스트레스 {#_1}

두근거림·기립성 어지럼·소화불량·불면·발한·피로가 함께 반복된다면 [자율신경 기능 이상 핵심 안내](../autonomic/index.md)에서 위험신호, HRV, 한약·침치료와 회복지표를 한 번에 확인할 수 있습니다.

만성피로·소화불량·두근거림·두통·수면은 [다섯 핵심 증상 안내](../autonomic/index.md#five-core-symptoms)에서 각각 깊게 다룹니다. 이 페이지는 여기에 **어지럼·목 이물감·냉증·부종·상열감이 겹칠 때 무엇을 더 구분할지** 설명합니다. 스트레스와 시간상 연결된다는 사실만으로 모든 증상의 원인을 자율신경 문제로 확정하지 않습니다.

## 어지럼증·머리가 띵해요 {#어지럼증머리가-띵해요}
급성 신경학적 이상·실신·보행불가·갑작스러운 심한 두통은 우선 평가합니다. 빙 도는 느낌인지, 일어설 때 아찔한지, 걸을 때 균형이 흔들리는지부터 구분합니다. 자세·식사·복용약·수분 섭취와의 관계, 청력 변화·두통을 함께 기록합니다. [어지럼 상세](../conditions/dizziness.md)와 [증상별 어지럼 감별](../symptom-herbal-guide/neuro-mental/r42-dizziness.md)에서 전정계·기립성·약물 등 원인을 확인한 뒤 아래 전통적 병증을 비교합니다.

- 비허담습·풍담 → [반하백출천마탕](../formulas/banxia-baizhu-tianma-tang.md)
- 간양상항·간풍 → [천마구등음](../formulas/tianma-gouteng-yin.md)
- 침구는 경항부·평형·자율신경 증상을 함께 평가.

## 스트레스 받으면 소화가 안 돼요 {#스트레스-받으면-소화가-안-돼요}
긴장한 날 식후 포만이 오래가는지, 식사량이 줄어 피로와 두근거림이 생기는지, 잠을 못 잔 다음 날 악화하는지 시간 관계를 살핍니다. [기능성소화불량의 복합 증상](../conditions/functional-dyspepsia.md#combined-symptoms)과 [불면·소화불편 질문](../questions/choice/insomnia-dyspepsia.md)을 함께 읽습니다.

간울기체·칠정기울에서는 소요산·시호소간산·분심기음을 비교할 수 있지만, 식사량·무력감·메스꺼움에 따라 비위기허·담습도 구분해야 합니다. [소화불량 처방 구성](../conditions/functional-dyspepsia.md#formula-composition)은 같은 더부룩함에서 배합이 달라지는 이유를 설명합니다.

## 목에 뭔가 걸린 느낌·매핵기 {#목에-뭔가-걸린-느낌매핵기}
음식은 넘어가는데 목에 걸린 듯한 느낌인지, 실제 음식·물이 걸리고 삼키기 어려운지를 나눕니다. 통증·진행성 연하곤란·체중감소가 있으면 구조적 인후·식도 문제를 확인합니다. 후비루·역류·목 사용과의 관계도 묻습니다. 전통적으로 목 이물감과 흉민·담이 함께 나타나는 담기울결에서는 [반하후박탕](../formulas/banxia-houpo-tang.md)을 비교합니다. 긴장과 연동된다는 이유만으로 실제 삼킴 장애를 매핵기로 묶지 않습니다.

## 손발냉증·냉증 {#손발냉증냉증}
손발만 찬지 전신이 추운지, 좌우가 같은지, 피부색 변화·통증·저림과 연결되는지 살핍니다. 피로·식사량·월경·복용약도 확인합니다. 냉감만으로 체질이나 양허를 결정하지 않으며, [사상의학 한열 원전](../sasang-original-symptoms/cold-heat.md)에서 평소 소증과 현재 병중 변화를 구분합니다.

전통적 처방에서는 냉감에 수습·부종 등이 겹치는 양허수습의 진무탕과 충임허한·어혈을 살피는 온경탕의 맥락이 다릅니다. 두 처방을 단순한 손발냉증 약으로 서로 바꿔 읽지 않습니다.

## 부종·몸이 잘 붓는다 {#부종몸이-잘-붓는다}
| 병증 | 처방 |
|---|---|
| 수습·기화불리 | [오령산](../formulas/wuling-san.md) |
| 수열호결 | [저령탕](../formulas/zhuling-tang.md) |
| 양허수기 | [진무탕](../formulas/zhenwu-tang.md) |
| 비양허 수종 | [실비음](../formulas/shipi-yin.md) |

심장·신장·간질환 가능성이나 갑작스러운 부종은 우선 평가합니다. 한쪽만 붓는지, 아침 얼굴과 저녁 다리 중 어디가 주로 붓는지, 체중·배뇨·숨참·약물 변경과 함께 변하는지 확인합니다. 위 표는 원인 평가 뒤 수습·열·양허의 동반 양상을 비교하는 자료이며, 붓는다는 이유만으로 이수 처방을 고르거나 수분을 일률적으로 제한하지 않습니다.

## 화병처럼 답답하고 열이 올라요 {#화병처럼-답답하고-열이-올라요}
간울기체·간화상염·심신불교·기혈양허·담울담요를 구분해 한약·침과 상담·명상치료를 함께 비교합니다. 흉통·호흡곤란은 별도 평가가 우선입니다.

## 진료실 문진·변증 체크 {#_4}

### 공통 문진 {#_5}
- 증상이 스트레스와 얼마나 연동되는가
- 두근거림·흉민·한숨·숨막힘
- 소화불량·복부팽만
- 불면·꿈·야간각성
- 열감·상열감·냉증
- 어지럼·두통·목긴장
- 땀·대변·소변 변화

### 병증 갈림점 {#_6}
| 소견 | 병증축 |
|---|---|
| 스트레스 + 흉협만·한숨 | 간울기체 |
| 목 이물감 + 흉민 + 담 | 담기울결 |
| 불면 + 심계 + 식욕저하 | 심비양허 |
| 상열감·초조·불면 | 울열·간화 |
| 어지럼 + 오심·담 | 비허담습 |
| 냉증 + 부종 | 양허·수습 |

### 재평가 {#_7}
증상 하나보다 **수면·소화·흉부불편·근긴장·활동기능**이 함께 변하는지 봅니다.

## 생활관리·회복 체크 {#생활관리회복-체크}

### 스트레스성 증상 {#_8}
- 증상이 발생한 시간·상황·감정·수면·식사를 함께 기록합니다.
- 긴장할수록 호흡이 얕아지고 목·어깨·복부가 함께 굳는지 확인합니다.
- 과도한 카페인·수면부족·과로가 두근거림과 어지럼을 악화시키는지 봅니다.

### 냉증·부종 {#_9}
- 아침/저녁 중 언제 심한지 기록합니다.
- 한쪽만 붓는지, 양쪽이 비슷한지 확인합니다.
- 체중·배뇨·호흡곤란과 함께 변하는지 봅니다.

### 회복지표 {#_10}
| 증상 | 회복을 볼 때 |
|---|---|
| 어지럼 | 빈도, 지속시간, 보행·일상활동 |
| 스트레스성 소화불량 | 식후 불편 + 스트레스 연동 정도 |
| 매핵기 | 이물감 빈도, 연하 기능 |
| 냉증 | 냉감 지속시간, 일상 불편 |
| 부종 | 붓기 정도, 신발·양말 자국, 체중 |
| 울열·답답함 | 발생빈도, 수면·두근거림 동반 |

> 갑작스러운 편측 부종, 흉통·호흡곤란, 실신, 새 신경학적 증상은 자가관리보다 평가가 우선입니다.

## 증상의 단계와 패턴 변화 {#_11}

| 단계 | 특징 | 치료에서 볼 것 |
|---|---|---|
| 일시적 | 특정 스트레스와 짧게 연동 | 호흡·근긴장·수면·소화 변화 |
| 반복적 | 두근거림·소화불량·불면 등이 같이 반복 | 간울·담울·심비양허 등 병증 비교 |
| 만성화 | 피로·냉증·부종·수면저하가 누적 | 전신 허실·기혈·수습·기능 회복 |

시간이 지났다는 사실만으로 간울이 양허로 진행했다고 판단하지 않습니다. 현재의 식사·수면·발한·배뇨·활동 변화에 맞춰 병증과 원인 가설을 다시 검토합니다. [치료경과 기록](../symptom-clinical/followup.md)에서는 증상이 줄어도 활동이 회복되지 않는 경우를 구분하고, [두근거림의 경과 지표](../conditions/palpitation.md#outcomes)에서는 빈도·지속시간·유발 상황을 확인합니다.
