# 치료·경과·근거

환자의 상태에 따라 한약·침구·운동·수면·식사·생활관리를 조합합니다.

## 치료선택의 연결 구조

```text
증상
 ↓
위험신호·감별
 ↓
한의학 병증
 ↓
치법
 ↓
한약/방제 + 침구 + 생활관리
 ↓
증상 변화 + 기능 변화
 ↓
재평가
```

## 경과 추적

| 증상 | 경과 추적 |
|---|---|
| 통증 | 강도 + 가동범위 + 실제 기능 |
| 불면 | 입면시간 + 각성 + 총수면 + 낮 기능 |
| 피로 | 활동량 + 회복 + 수면 + 식욕 |
| 비염 | 재채기·콧물·코막힘 + 수면 + 약물사용 |
| 소화 | 식사량 + 포만감 + 통증 + 체중 |
