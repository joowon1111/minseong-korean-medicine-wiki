# 치료·경과·근거

환자가 실제로 궁금해하는 질문을 기존 **증상 → 병증 → 치법 → 한약·본초·방제 + 침구 → 경과평가** 구조 안에서 설명합니다.

## 한약은 어떤 기준으로 고르나요?
같은 `허리통증`, `불면`, `소화불량`이라도 같은 처방을 쓰는 것은 아닙니다.

```text
환자 증상
 ↓
위험신호·감별
 ↓
한열·허실·기혈진액·담습·어혈
 ↓
치법
 ↓
후보 처방군 비교
 ↓
구성 본초·용량·출전 확인
```

→ [증상·치법으로 방제 찾기](../herbal-integrated/by-symptom-treatment.md)

## 침과 한약을 같이 치료하는 이유는?
침구와 한약은 같은 증상을 서로 다른 층위에서 볼 수 있습니다.

- **침구:** 통증 부위·근육긴장·움직임·신경경로·전신 상태를 평가해 치료점을 구성
- **한약:** 한열·허실·기혈·담습·어혈·장부 병기를 기준으로 처방군을 구성
- **공통 목표:** 증상 감소뿐 아니라 수면·소화·활동·기능 회복

→ [침구·치료 증상으로 찾기](../acupuncture-integrated/by-symptom.md)

## 한약은 증상마다 하나씩 정해져 있나요?
아닙니다. 예를 들어 불면에서도:

| 병증 | 처방 탐색 |
|---|---|
| 심비양허 | 귀비탕 |
| 심신음혈부족 | 천왕보심단 |
| 허번 | 산조인탕 |
| 담울 | 가미온담탕 |

따라서 위키에서도 **증상명 → 처방명**이 아니라 중간에 병증과 치법을 둡니다.

## 얼마나 먹어야 하나요?
기간을 처방명만으로 정하지 않습니다. 급·만성, 증상의 깊이, 동반질환, 연령, 소화상태, 치료반응에 따라 재평가합니다.

## 좋아지고 있는지는 어떻게 보나요?
| 영역 | 함께 보는 변화 |
|---|---|
| 통증 | 통증점수 + 걷기·앉기·가동범위·수면 |
| 불면 | 입면 + 각성 + 재입면 + 아침 회복감 |
| 피로 | 활동량 + 회복시간 + 식욕 + 낮 기능 |
| 소화 | 식사량 + 포만감 + 통증 + 배변 |
| 비염 | 재채기·콧물·코막힘 + 수면 |
| 어지럼 | 빈도·강도 + 보행·일상활동 |

## 처음 좋아지는 신호는 무엇인가요?
질환과 병증에 따라 다르지만 통증점수 자체보다 **잠을 덜 깨거나, 움직임이 편해지거나, 식욕이 회복되거나, 증상 발생 빈도가 줄어드는 변화**가 먼저 나타나는지 함께 봅니다.

## 처방이 맞지 않으면 어떻게 하나요?
치료 후 반응을 보고 병증 가설을 다시 평가합니다.

`처방 → 반응 관찰 → 호전/불변/악화 → 병증·용량·치법 재평가`

## 한약 구성은 어디에서 확인하나요?
→ [방제 찾기](../herbal-integrated/formulas.md)  
→ [일반 방제 임상 지도](../herbal-integrated/general-formulary.md)

각 상세 처방에서 구성 본초·용량·출전을 확인하고, 동명 처방은 출전별 구성을 섞지 않습니다.

## 본초 하나하나의 차이도 볼 수 있나요?
→ [본초 찾기](../herbal-integrated/herbs.md)  
→ [주요 본초 비교·감별](../herbal-integrated/herb-comparisons.md)

예를 들어 황련·황금·황백, 시호·향부자, 후박·지실·목향·사인처럼 비슷해 보이는 본초의 차이를 실제 처방 배합과 함께 봅니다.

## 통증은 침만 맞아도 되나요?
증상의 성격과 환자 상태에 따라 달라집니다. 국소 근골격 기능을 중심으로 침구치료를 구성할 수도 있고, 만성화·수면·소화·피로·한열·허실 같은 전신 병증이 함께 있으면 한약치료를 함께 검토할 수 있습니다.

## 허리통증에는 어떤 처방을 쓰나요?
허리통증 하나로 처방을 정하지 않습니다.

- 한습·기혈담식 복합 → 오적산
- 오래된 풍한습비 + 간신기혈허 → 독활기생탕
- 어혈·기체가 두드러지면 활혈거어 처방군을 비교

→ [통증](pain.md)

## 소화가 약하면 보약을 못 먹나요?
소화상태는 보익 처방을 구성할 때 중요한 요소입니다. 비위기허·담습·식적·습체 여부를 먼저 보고 보익과 소화·이기·화습의 균형을 판단합니다.

→ [소화](digestive.md)  
→ [보익·회복 핵심](../herbal-integrated/tonic-recovery.md)

## 피곤하면 무조건 보약인가요?
피로는 수면장애·빈혈·갑상선·감염 후 상태·약물 등 다양한 원인이 있을 수 있습니다. 한의학적으로도 기허·기혈허·기음허·담습 등으로 나누어 접근합니다.

→ [수면·피로](sleep-fatigue.md)

## 비염도 체질에 따라 치료가 달라지나요?
증상의 한열·허실·분비물 양상·소화·수면·계절성 등을 함께 보고 병증을 판단합니다. 사상체질을 적용하는 경우에는 기존 사상의학 자료와 교차해 볼 수 있습니다.

→ [호흡·비염](respiratory-rhinitis.md)  
→ [사상의학](../sasang-integrated/index.md)

## 스트레스성 증상도 한약과 침으로 보나요?
스트레스 상황에서 소화불량·흉민·불면·근육긴장·두근거림 등이 함께 나타나는 경우 **간울·기체·담울·심비양허 등 병증축**과 신체 긴장을 함께 평가합니다.

→ [자율신경·스트레스](autonomic-stress.md)

## 안전성은 어떻게 확인하나요?
복용 중인 의약품·기저질환·임신 가능성·알레르기·간신장 기능·이상반응 등을 확인해야 합니다. 부자·마황·대황 등 주의가 필요한 본초나 공하·온리 처방은 특히 전문적 판단이 필요합니다.

→ [한약 안전·복용 주의](../herbal-integrated/safety.md)

## 근거는 어디까지 있나요?
전통 문헌의 주치와 현대 임상연구는 같은 종류의 근거가 아닙니다. 위키에서는 가능하면 **원전·공식 처방DB / 임상진료지침 / 임상연구 / 전임상연구**를 구분해 표시합니다.

→ [연구·근거 임상 해석](../evidence-integrated/index.md)
