# 수면·피로

## 불면증·잠이 안 와요 {#불면증잠이-안-와요}
**환자가 자주 묻는 것:** “생각이 많아서 못 자요”, “한약 먹으면 잠이 깊어질까요?”

| 패턴 | 처방 |
|---|---|
| 심비양허·기혈허 | [귀비탕](../formulas/guipi-classic.md) |
| 심신음혈부족 | [천왕보심단](../formulas/tianwang-buxin-dan.md) |
| 허번불면 | [산조인탕](../formulas/suanzaoren-tang.md) |
| 담울·심번·경계 | [가미온담탕](../formulas/jiawei-wendan-tang.md) |

**본초:** 산조인·원지·백자인·용안육 → [비교](../herbal-integrated/herb-comparisons.md).  
**침구:** 긴장·두근거림·경항부·호흡·소화 상태를 함께 봄.  
**회복:** 입면시간↓ → 야간각성↓ → 재입면↑ → 아침 회복감↑ → 낮 기능↑.

## 자꾸 깨요·얕은 잠 {#자꾸-깨요얕은-잠}
총수면시간만 보지 않고 각성 횟수·재입면 시간·꿈·야간뇨·코골이·낮 졸림을 함께 확인합니다.

피로는 빈혈·갑상선·수면장애·감염 후 상태·약물 등 원인 평가가 필요할 수 있습니다.

## 자고 나도 피곤해요 {#자고-나도-피곤해요}
수면시간보다 **비회복성 수면** 여부를 봅니다. 코골이·무호흡 가능성과 낮 졸림도 확인합니다.

## 두근거림·가슴답답 {#두근거림가슴답답}
흉통·실신·호흡곤란은 먼저 평가. 심비양허·담울·기울에서는 귀비탕·가미온담탕·반하후박탕 계열을 비교합니다.

## 진료실 문진·변증 체크

### 수면 문진
- 잠드는 데 얼마나 걸리는가
- 밤에 몇 번 깨는가
- 깨면 다시 잠들기 쉬운가
- 꿈이 많거나 심계·불안이 동반되는가
- 아침에 개운한가
- 낮 졸림·집중저하가 있는가

### 피로 문진
- 아침부터 피곤한가 / 오후에 심해지는가
- 활동 후 회복시간
- 식욕·소화·체중 변화
- 추위를 많이 타는가 / 열감이 많은가
- 땀·갈증·대변·소변 변화

### 병증 갈림점
| 패턴 | 병증축 |
|---|---|
| 불면 + 심계 + 건망 + 식욕저하 | 심비양허 |
| 허번·초조 + 음허 소견 | 음혈부족·허열 |
| 불면 + 담·메스꺼움·흉민 | 담울 |
| 피로 + 식욕저하 + 무력감 | 비기허 |
| 피로 + 자한·구갈 | 기음양허 |

### 재평가
수면시간보다 **입면·각성·아침 회복감·낮 기능**을 같은 기준으로 추적합니다.

## 생활관리·회복 체크 {#생활관리회복-체크}

### 불면
- 기상시간을 가능한 일정하게 유지합니다.
- 잠이 오지 않는 상태에서 침대에 오래 머무르는 습관을 줄입니다.
- 늦은 시간 과도한 카페인·음주·강한 운동·밝은 화면 노출을 줄입니다.
- 낮잠이 밤 수면을 방해한다면 시간과 길이를 조절합니다.

### 피로
- 하루 활동량을 한 번에 몰아 쓰지 않고 **활동과 회복을 분배**합니다.
- 무리해서 활동한 다음 며칠간 크게 떨어지는 패턴이 있는지 기록합니다.
- 식사량·수면·운동량을 함께 봅니다.

### 회복지표
| 증상 | 회복을 볼 때 |
|---|---|
| 불면 | 입면시간, 야간각성, 재입면, 아침 회복감 |
| 피로 | 활동 후 회복시간, 낮 기능, 식욕 |
| 두근거림 | 발생빈도, 지속시간, 유발상황 |
| 긴장 | 목·어깨 긴장, 호흡 깊이, 수면 영향 |

> 심한 낮 졸림, 수면 중 무호흡 의심, 흉통·실신이 동반되는 두근거림은 별도 평가가 필요합니다.
