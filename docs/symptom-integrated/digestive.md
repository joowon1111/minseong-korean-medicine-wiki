# 소화

## 소화불량·체한 느낌
**환자가 자주 묻는 것:** “위가 약한가요?”, “조금만 먹어도 체해요.”

| 갈림점 | 처방 |
|---|---|
| 습체·창만 | [평위산](../formulas/pingwei-san.md) |
| 비기허 + 담습 + 기체 | [향사육군자탕](../formulas/xiangsha-liujunzi-tang.md) |
| 음식적체 | [보화환](../formulas/baohe-wan.md) |
| 한열착잡·심하비 | [반하사심탕](../formulas/banxia-xiexin-tang.md) |

**본초:** 후박·지실·목향·사인 → [비교](../herbal-integrated/herb-comparisons.md).  
**침구:** 복부 긴장·압통, 스트레스와 식후 변화, 전신 자율신경 상태를 함께 봅니다.

## 식후 더부룩함·복부팽만
평위산 ↔ 향사육군자탕 ↔ 향사양위탕을 **습체 / 비허 / 허한·기체**로 감별합니다.

## 식욕저하
향사육군자탕·인삼양위탕을 비교하고 지속적 체중감소·연하곤란·빈혈 등은 원인평가를 우선합니다.

## 메스꺼움·울렁거림
담습·위기상역은 [이진탕](../formulas/erchen-tang.md), 한열착잡은 반하사심탕, 현훈이 함께하면 반하백출천마탕과 비교합니다.

## 잦은 설사
비위습체·수습·허한을 구분하고 [위령탕](../formulas/weiling-tang.md)·[곽향정기산](../formulas/huoxiang-zhengqi-san.md) 등을 탐색합니다.

## 변비
열결·부실에서는 소승기탕 ↔ 대승기탕, 축혈이 겹치면 도핵승기탕을 비교합니다. 공하방은 전문적 안전성 판단이 특히 중요합니다.
