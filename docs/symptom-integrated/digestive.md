# 소화

환자가 실제로 검색하거나 진료실에서 표현하는 말을 출발점으로 **위험신호 확인 → 병증 → 한약·본초·방제 → 침구치료 → 경과평가**로 연결합니다.

## 소화불량·체한 느낌

- **한의학적 병증축:** 습체·비허·식적·한열착잡
- **한약·방제 탐색:** 평위산 · 향사육군자탕 · 보화환 · 반하사심탕
- **침구·치료 연결:** 복부·자율신경 긴장를 함께 평가하고 기존 침구 자료에서 혈위·치료원칙을 확인합니다.
- **경과:** 증상 강도뿐 아니라 수면·식사·걷기·업무·운동 등 실제 기능 변화를 함께 봅니다.

## 식후 더부룩함·복부팽만

- **한의학적 병증축:** 습체·기체·비허
- **한약·방제 탐색:** 평위산 · 향사육군자탕 · 향사양위탕
- **침구·치료 연결:** 복부팽만·식후 변화를 함께 평가하고 기존 침구 자료에서 혈위·치료원칙을 확인합니다.

- **침구·치료 연결:** 식사량·체중·소화를 함께 평가하고 기존 침구 자료에서 혈위·치료원칙을 확인합니다.
