# 증상·질환 한눈에 보기

환자는 의학용어보다 **“허리가 아파요”, “자꾸 깨요”, “밥만 먹으면 더부룩해요”**처럼 검색합니다.  
이 페이지는 그런 표현을 기존 증상·한약·방제·침구 자료로 바로 연결합니다.

## 통증·저림

| 이렇게 검색해도 됩니다 | 연결 |
|---|---|
| 허리가 아파요 · 허리 삐끗 · 허리에서 다리까지 당겨요 · 오래 앉으면 허리가 아파요 | [허리통증·요통](pain.md#허리통증요통) |
| 목이 뻐근해요 · 뒷목이 당겨요 · 목 때문에 머리가 아파요 | [목통증](pain.md#목통증뒷목-뻐근함) |
| 팔을 올리기 힘들어요 · 어깨가 밤에 아파요 · 오십견 같아요 | [어깨통증](pain.md#어깨통증오십견) |
| 계단에서 무릎이 아파요 · 무릎이 시큰해요 | [무릎통증](pain.md#무릎통증) |
| 머리가 지끈거려요 · 뒷머리가 아파요 · 두통이 자주 와요 | [두통](pain.md#두통) |
| 손이 저려요 · 발이 저려요 · 찌릿찌릿해요 | [손발저림·신경통](pain.md#손발저림신경통) |

## 수면·피로·긴장

| 환자 표현 | 연결 |
|---|---|
| 잠이 안 와요 · 누워도 생각이 많아요 | [불면](sleep-fatigue.md#불면증잠이-안-와요) |
| 자꾸 깨요 · 잠이 얕아요 | [얕은 잠](sleep-fatigue.md#자꾸-깨요얕은-잠) |
| 늘 피곤해요 · 기운이 없어요 | [만성피로](sleep-fatigue.md#만성피로기운이-없어요) |
| 오래 자도 피곤해요 · 자고 나도 개운하지 않아요 | [비회복성 수면](sleep-fatigue.md#자고-나도-피곤해요) |
| 심장이 두근거려요 · 가슴이 답답해요 | [두근거림](sleep-fatigue.md#두근거림가슴답답) |
| 긴장하면 목·어깨가 굳어요 | [긴장](sleep-fatigue.md#긴장하면-몸이-굳어요) |

## 소화·배변

| 환자 표현 | 연결 |
|---|---|
| 자주 체해요 · 소화가 느려요 | [소화불량](digestive.md#소화불량체한-느낌) |
| 조금만 먹어도 더부룩해요 · 배에 가스가 차요 | [복부팽만](digestive.md#식후-더부룩함복부팽만) |
| 입맛이 없어요 · 밥 생각이 안 나요 | [식욕저하](digestive.md#식욕저하) |
| 속이 울렁거려요 · 메스꺼워요 | [메스꺼움](digestive.md#메스꺼움울렁거림) |
| 설사를 자주 해요 · 배가 자주 아파요 | [설사](digestive.md#잦은-설사) |
| 변비가 심해요 · 배가 꽉 막힌 느낌이에요 | [변비](digestive.md#변비) |

## 코·목·기침

|---|---|

| 코가 막혀요 · 축농증처럼 답답해요 | [코막힘](respiratory-rhinitis.md#코막힘축농증-느낌) |

| 기침이 몇 주째 안 나아요 | [오래가는 기침](respiratory-rhinitis.md#기침이-오래가요) |
| 가래가 많아요 · 목에 가래가 붙어요 | [가래](respiratory-rhinitis.md#가래가-많아요) |
| 숨이 차요 · 쌕쌕거려요 | [숨참·천명](respiratory-rhinitis.md#숨참쌕쌕거림) |

## 어지럼·스트레스·냉증·부종

| 환자 표현 | 연결 |
|---|---|
| 머리가 띵해요 · 빙빙 도는 느낌이에요 | [어지럼](autonomic-stress.md#어지럼증머리가-띵해요) |
| 스트레스 받으면 체해요 · 배가 아파요 | [스트레스성 소화불량](autonomic-stress.md#스트레스-받으면-소화가-안-돼요) |
| 목에 뭔가 걸린 것 같아요 · 삼켜도 안 없어져요 | [매핵기·목 이물감](autonomic-stress.md#목에-뭔가-걸린-느낌매핵기) |
| 손발이 차요 · 몸이 냉해요 | [냉증](autonomic-stress.md#손발냉증냉증) |
| 아침마다 얼굴이 부어요 · 다리가 잘 부어요 | [부종](autonomic-stress.md#부종몸이-잘-붓는다) |
| 화가 나면 가슴이 답답하고 열이 올라요 | [울열·답답함](autonomic-stress.md#화병처럼-답답하고-열이-올라요) |

## 증상에서 치료자료까지

```text
 ↓
증상 페이지
 ↓
위험신호·감별
 ↓
한의학 병증
 ↓
본초·방제 + 침구
 ↓
치료 경과·회복신호
```
