# 증상으로 찾기

병명을 정확히 몰라도 괜찮습니다. **“입 벌릴 때 턱이 아파요”, “밤에 다리가 불편해요”, “손발이 저려요”, “몸이 자주 부어요”**처럼 지금 느끼는 불편에서 시작할 수 있습니다.

이 페이지는 환자의 생활 표현을 먼저 모아 둔 **증상 입구**입니다. 특정 질환을 알고 있거나 한 질환의 검사·감별·한의치료를 자세히 보고 싶다면 [질환별 보기](../conditions/index.md)로 이동합니다.

| 내가 알고 있는 것 | 시작할 곳 |
|---|---|
| 불편한 증상만 알고 있어요 | 이 페이지의 환자 표현에서 찾기 |
| 진단명이나 의심 질환을 알고 있어요 | [질환별 보기](../conditions/index.md) |
| R-code 증상군에서 한약·변증을 찾고 싶어요 | [증상 기반 한약 탐색](../symptom-herbal-guide/index.md) |
| 논문과 현대 임상근거를 보고 싶어요 | [질환별 현대 근거 카드](../authority/conditions/index.md) |

## 저림·경련·냉감·부종

| 이렇게 느껴요 | 관련 질환 심화 | 먼저 구분할 것 |
|---|---|---|
| 손발이 저려요 · 팔다리가 찌릿해요 | [손발저림](../conditions/limb-numbness.md) | 신경 압박, 말초신경, 혈류 문제 |
| 다리에 쥐가 나요 · 종아리가 뭉쳐요 | [근육경련](../conditions/muscle-cramps.md) | 실제 근육수축, 탈수·전해질, 신경 |
| 밤에 다리가 불편하고 움직이고 싶어요 | [하지불안증후군](../conditions/restless-legs-syndrome.md) | 쉬면 악화, 움직이면 완화, 철결핍 |
| 손발이 차요 · 몸이 냉해요 | [수족냉증](../conditions/cold-hands-feet.md) | 냉감, 색 변화, 갑상선·빈혈·혈관 |
| 얼굴·손·발이 부어요 · 양말 자국이 남아요 | [붓기·부종](../conditions/edema-swelling.md) | 한쪽/양쪽, 호흡곤란, 심장·신장·간 |

저림, 쥐, 하지불안과 부종은 서로 비슷하게 표현되지만 핵심 패턴이 다릅니다. 특히 **밤에 쉬면 불편하고 움직이는 동안 편해지는 충동**은 하지불안증후군을, **근육이 실제로 단단하게 수축하며 아픈 증상**은 근육경련을 먼저 살핍니다.

## 증상을 찾지 못했다면

오른쪽 위 검색창에 일상 표현을 그대로 입력해 보세요. 예를 들어 **“입 벌릴 때 아파요”**, **“밤에 다리가 불편해요”**, **“다리에 쥐가 나요”**, **“얼굴이 부어요”**처럼 검색할 수 있습니다. 같은 표현도 원인이 다를 수 있으므로 상세 문서의 위험신호와 감별 항목을 먼저 확인합니다.
