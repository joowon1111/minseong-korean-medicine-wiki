# 호흡·비염

## 비염·재채기·맑은 콧물
계절성/통년성·눈 가려움·코막힘·수면 영향을 함께 봅니다. 침구는 비강·두면부와 전신 상태를 연결합니다.

## 코막힘·축농증 느낌
- 비규폐색 → [창이자산](../formulas/cangerzi-san.md)
- 풍열·울열성 이비인후 → [형개연교탕](../formulas/jingjie-lianqiao-tang.md)
- 고열·심한 안면통·안와 증상은 우선 의학적 평가.

## 목이 자주 붓고 아파요
은교산 ↔ 형개연교탕 ↔ 연교패독산을 풍열표증 / 울열 / 열독·종통으로 구분합니다.

## 기침이 오래가요
| 병증 | 처방 |
|---|---|
| 풍열 + 기침 | [상국음](../formulas/sangju-yin.md) |
| 폐열·천해 | [마행감석탕](../formulas/maxing-ganshi-tang.md) |
| 담열옹폐 | [정천탕](../formulas/dingchuan-tang.md) |
| 폐기허 | [보폐탕](../formulas/bufei-tang.md) |
| 기음양허 | [생맥산](../formulas/shengmai-san.md) |

객혈·호흡곤란·고열·체중감소·흉통은 우선 평가합니다.

## 가래가 많아요
담습 → 이진탕·도담탕, 담열 → 정천탕. 반하·천패모·행인의 차이는 [본초 비교](../herbal-integrated/herb-comparisons.md)에서 확인합니다.

## 숨참·쌕쌕거림
급성 호흡곤란은 응급평가 우선. 폐열 마행감석탕 / 담열 정천탕 / 상실하허 소자강기탕으로 병증을 나눕니다.
