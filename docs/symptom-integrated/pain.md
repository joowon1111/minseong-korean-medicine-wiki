# 통증

## 먼저 확인
급성/만성 · 국소/방사통 · 움직임과의 관계 · 저림/감각/근력 · 외상/발열 등 전신신호를 먼저 봅니다.

## 기능으로 보기
통증점수뿐 아니라 **걷기·앉기·들기·수면·업무·운동 같은 실제 기능**을 함께 봅니다.
