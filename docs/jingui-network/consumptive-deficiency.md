# 허로

허로는 장기간의 허약·피로·소모 상태를 다루는 금궤요략의 중요한 병증 영역이다.

```text
장기간의 허약
  ↓
기혈·음양의 소모
  ↓
피로·식욕저하·수면·통증 등
  ↓
보익·조화
  ↓
처방
```

대표 처방으로 **소건중탕·황기건중탕·서여환** 등이 서로 다른 허로 병증의 맥락에서 논의된다.
