# 잡병과 병증 구조

금궤요략의 임상적 특징은 다양한 잡병을 **병명 하나가 아니라 증후의 조합과 병기**로 이해하고, 그에 맞는 치법과 처방을 연결하는 데 있다.

```text
주증상
 +
동반증상
 +
한열·허실·담음·어혈·수기
      ↓
병증 구조
      ↓
치법
      ↓
처방
```

이러한 방식은 오늘날 한의학의 변증논치와 임상 추론을 이해하는 데도 중요한 기반이 된다.
