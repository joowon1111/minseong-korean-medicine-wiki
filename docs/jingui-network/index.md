# 금궤요략 임상 지식망 {#_1}

《금궤요략》은 장중경 의학의 **잡병 영역과 처방 운용**을 보여주는 핵심 고전입니다.

잡병의 기본 틀에서 흉비·담음·허로·복만·부인병을 차례로 비교합니다. 각 주제는 고전 병증의 설명이며 현대 진단을 대체하지 않습니다. 병증을 이해한 다음 치법과 원방, 실제 연구의 대상·제형·평가 결과를 나누어 확인합니다.

## 금궤요략 잡병 임상 틀 {#misc-disease-framework}

금궤요략의 잡병은 현대 질환명을 나열한 체계라기보다 **증상·맥증·병기·처방을 연결하는 임상 구조**로 읽는 것이 중요합니다.

### 주요 병리축
허로 / 담음 / 수기 / 어혈 / 한 / 열 / 기체 / 복만 / 흉비

### 임상 적용
현대 진단명을 먼저 확인한 뒤, 고전의 병증 구조가 실제 환자의 증상 조합과 어떻게 맞는지 봅니다.

→ [팔강변증](../eight-principles-network/index.md)  
→ [통합 임상추론](../clinical-reasoning/index.md)


## 금궤요략 흉비·심통 {#chest-bi-heart-pain}

흉비·심통은 흉부의 막힘·통증·답답함을 설명하는 고전 병증입니다.

### 가장 먼저
흉통·호흡곤란·식은땀·실신·운동 시 악화 등 심혈관 위험신호는 즉시 일반의학적 평가가 우선됩니다.

### 고전적 병기
양기불통 / 담음·수기 / 한응 / 기체 등 여러 축이 겹칠 수 있습니다.

### 임상 연결
전중 CV17 · 내관 PC6 등 흉부·심포경 경혈과 담음·기체 변증을 함께 봅니다.

→ [두근거림·심계](../conditions/palpitation.md)  
→ [임상 안전성](../clinical-safety/index.md)


## 금궤요략 담음·수기 {#phlegm-fluid}

금궤요략은 담음을 하나의 가래 증상으로 보지 않고 **체내 수액대사의 병리적 정체**로 폭넓게 설명합니다.

### 임상 연결
복만·오심·흉민·기침·어지럼·몸의 무거움·부종 등 다양한 증상군을 수분대사와 함께 봅니다.

### 현대 위키와 연결
담음 → 반하·진피·복령 → 이진탕·육군자탕·온담탕 등으로 내려가되, 병증과 처방을 일대일로 고정하지 않습니다.

→ [담음](../diagnostics/patterns/phlegm-fluid.md)  
→ [담음 vs 식적](../diagnostics/differentials/phlegm-vs-food-stagnation.md)

### 변증·처방·치료를 이어서 보기 {#pattern-care-network}

고전의 담음·수기를 현대의 습담·비허담습·수음 변증 및 처방 선택과 연결합니다.

[담음 전체 안내](../diagnostics/phlegm-fluid.md) · [담음 변증 지도](../diagnostics/patterns/phlegm-fluid.md) · [담음 치료와 경과 확인](../pattern-treatment/phlegm-fluid.md)


## 금궤요략 허로 {#consumptive-deficiency}

허로는 장기간의 허손과 쇠약을 설명하는 고전적 병증입니다.

### 임상에서 먼저 볼 것
빈혈·갑상선·수면장애·감염·대사질환·약물·과로 등 현대 의학적 원인을 필요한 범위에서 확인합니다.

### 한의학적 구분
기허 / 혈허 / 음허 / 양허 / 기혈양허 / 신허

### 본초·방제
인삼·황기·당귀·숙지황·녹용 등의 보익축과 팔물탕·십전대보탕·보중익기탕 등 처방 구조를 비교합니다.

→ [피로·회복](../conditions/fatigue.md)  
→ [보익 처방 계열](../formula-architecture/tonic-family.md)


## 금궤요략 복만·한·식적 임상 지도 {#abdominal-cold-food-retention}

복만·복통·냉감·소화정체는 서로 비슷해 보여도 병기가 다릅니다.

### 감별축
- 한: 냉감·온열 선호
- 비위허: 식욕저하·묽은변·피로
- 담음: 오심·흉민·어지럼·가래
- 식적: 과식·특정 음식 후 복만·트림·대변 변화

### 임상 연결
중완 CV12 · 족삼리 ST36 · 내관 PC6 · 공손 SP4

→ [소화불량](../conditions/dyspepsia.md)  
→ [담음 vs 식적](../diagnostics/differentials/phlegm-vs-food-stagnation.md)


## 금궤요략 부인병 임상 지도 {#gynecology}

금궤요략의 부인병 조문은 여성의 복통·월경·임신·산후 등 다양한 병증과 고방을 보여줍니다.

### 대표 처방 연결
- 계지복령환 — 어혈·징가·하복부
- 당귀작약산 — 혈허+수습
- 당귀생강양육탕 등 허한성 병증의 고전적 구조

### 현대 임상에서
월경통·출혈·골반통 등에서는 임신 가능성, 구조적 질환, 과다출혈 등 위험상황을 먼저 확인합니다.

## 금궤요략 처방 지도 {#formula-map}

금궤요략 처방을 처방명 목록으로 외우기보다 **병증 → 치법 → 구성 → 약대 → 유사처방 감별**로 읽습니다.

### 대표 연결축
- 어혈·부인 → 계지복령환
- 혈허+수습 → 당귀작약산
- 허로 → 보익계 고방
- 담음·수기 → 온화담음·이수계 고방
- 흉비 → 통양·화담·이기 구조

### 원방 확인
같은 처방명이라도 현대 엑스제·탕제와 원전 구성·제법·용량이 다를 수 있습니다.

→ [방제학](../formulas/index.md)

## 금궤요략 임상추론 {#clinical-reasoning}

### 1. 현대 위험신호와 진단
흉통·출혈·급성복통·신경학적 증상 등은 우선 감별합니다.

### 2. 고전 병증 구조
맥증·복증·한열·허실·담음·어혈·수기 등을 봅니다.

### 3. 치법
온·청·보·사·활혈·화담·이수 등 치료 방향을 정합니다.

### 4. 원방
구성·원방 용량·제법·복용법을 확인합니다.

### 5. 현대 임상근거
실제 연구에서 사용한 처방이 원방과 같은지, 대상군·결과지표·안전성을 확인합니다.

→ [통합 임상추론](../clinical-reasoning/index.md)
