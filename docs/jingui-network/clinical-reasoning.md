# 금궤요략식 임상 추론

금궤요략은 다양한 잡병에서 **증상의 조합과 병기를 통해 치료 방향을 정하는 임상 사고**를 잘 보여준다.

```text
주증상
 +
동반증상
 +
병위·한열·허실
 +
담음·어혈·수기 등
      ↓
병증 구조
      ↓
치법
      ↓
처방
```

상한론의 육경병증과 함께 보면 외감병과 잡병을 아우르는 고전적 임상 추론 구조가 더 선명해진다.
