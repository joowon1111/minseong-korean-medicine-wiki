# 한열(寒熱)

한열은 병증의 성질을 구분하는 핵심 축이다.

| 한증에서 살피는 경향 | 열증에서 살피는 경향 |
|---|---|
| 추위를 탐 | 열감을 느낌 |
| 따뜻한 것을 선호 | 찬 것을 선호 |
| 맑고 묽은 분비물 | 진하고 농축된 분비물 |
| 설담·백태 등 | 설홍·황태 등 |

한두 증상만으로 한열을 단정하기보다 **전신 증후를 종합**한다.
