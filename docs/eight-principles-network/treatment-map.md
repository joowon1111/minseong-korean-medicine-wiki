# 팔강에서 치법으로

팔강변증의 목적은 분류 자체보다 치료 방향을 정하는 데 있다.

```text
표 → 해표의 방향
리 → 내부 병증에 따른 치법

한 → 온법의 방향
열 → 청법의 방향

허 → 보법의 방향
실 → 사법의 방향
```

실제 치법은 장부·기혈·담음·어혈 등 보다 구체적인 변증과 함께 결정한다.
