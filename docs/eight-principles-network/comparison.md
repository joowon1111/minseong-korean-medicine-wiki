# 팔강과 다른 변증체계 비교

| 변증 체계 | 주된 질문 |
|---|---|
| 팔강변증 | 병위·한열·허실의 전체 방향은 무엇인가? |
| 장부변증 | 어느 장부 기능의 병리가 중심인가? |
| 기혈진액변증 | 기·혈·진액의 어떤 변화가 중심인가? |
| 육경변증 | 상한병의 육경 병증 구조는 어떠한가? |
| 위기영혈변증 | 온병의 병위와 열사의 깊이는 어떠한가? |
| 사상체질병증 | 체질과 현재 병증의 관계는 어떠한가? |

이 체계들은 서로 완전히 대체하는 분류가 아니라 **서로 다른 임상 질문을 던지는 렌즈**로 이해할 수 있다.
