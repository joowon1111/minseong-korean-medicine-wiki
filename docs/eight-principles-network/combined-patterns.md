# 팔강의 조합

실제 병증은 한 가지 팔강만으로 표현되기보다 여러 축이 조합된다.

```text
표 + 한 + 실
리 + 열 + 실
리 + 한 + 허
표 + 열 + 허
...
```

또한 병의 진행 과정에서 **한열전환·허실전환·표리전변**이 나타날 수 있다.

팔강을 조합해서 보면 단순 증상 목록이 **병증의 구조**로 바뀐다.
