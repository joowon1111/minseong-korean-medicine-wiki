# 팔강변증 임상 추론

팔강변증은 환자의 여러 증상을 큰 방향으로 정리하는 첫 단계로 활용할 수 있다.

```text
증상·맥·설·병력
       ↓
표 / 리
한 / 열
허 / 실
       ↓
음 / 양의 전체 방향
       ↓
구체적 변증
       ↓
치법·처방
```

예를 들어 같은 복통이라도 **리한허증, 리열실증, 기체·어혈** 등 구조가 다르면 치료 방향도 달라질 수 있다.
