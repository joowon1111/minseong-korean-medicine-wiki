# 팔강변증(八綱辨證) 임상 지식망

팔강은 **표·리, 한·열, 허·실, 음·양**의 네 쌍을 통해 복잡한 증후를 큰 방향에서 정리하는 기본 변증 틀입니다.

## 네 축
- [표 vs 리](exterior-interior.md) — 병위가 겉에 가까운지 안에 깊은지
- [한 vs 열](cold-heat.md) — 냉·열 양상의 방향
- [허 vs 실](deficiency-excess.md) — 정기의 부족과 사기의 성함
- [음 vs 양](yin-yang.md) — 앞의 여러 판단을 종합하는 상위 축

## 임상 순서
**환자 주소 → 위험신호 → 병위(표리) → 성질(한열) → 정사 관계(허실) → 음양 종합 → 장부·기혈진액 변증 → 치법 → 본초·방제·경혈**

팔강 하나만으로 처방을 결정하지 않고 장부변증·기혈진액·육경·사상체질 등 다른 체계와 함께 봅니다.

## 변증과 실제 경혈 선택 자료 {#acupoint-pattern-research}

허실·한열을 실제 처방과 연결해 읽으려면 [한의원 423명 관찰연구](../acupuncture-integrated/evidence.md#pattern-profiles-2026)를 참고하세요. 연구의 세 축은 허실·한열·조습이며 팔강 전체를 측정한 점수가 아닙니다. 환자군의 평균 분포를 요약한 자료를 경혈의 고정 속성이나 개인별 진단 기준으로 바꾸지 않습니다. [배혈을 판단하는 과정](../acupuncture-integrated/how-acupoints-combine.md#pattern-selection)에서 질환·해부학적 평가와 함께 읽을 수 있습니다.
