# 허실(虛實)

허실은 정기와 병사의 관계, 인체 기능의 부족과 병리적 실체의 성함을 구분하는 축이다.

```text
허
→ 기·혈·음·양 등 기능과 물질의 부족

실
→ 병사·담음·어혈·식적·기체 등의 성함
```

허실은 서로 섞여 **허실협잡**으로 나타날 수 있으므로 현재 증상과 경과를 함께 살핀다.
