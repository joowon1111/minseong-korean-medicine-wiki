# 사상처방 용량 지문 표

이 표는 각 자료에 수록된 약재량을 비교한 것입니다. 출처가 확인된 행은 아래에 밝히고, 나머지 행의 정확한 판본과 환산 근거는 각 상세 문서를 확인합니다. 원전의 전(錢) 표기, 후대 문헌의 g 수록량, 한의표준임상진료지침의 현대 환산량은 구분해서 읽습니다.

같은 전 수와 약재 비율에 1전 3.75 g과 4 g을 적용하면 g 수치는 달라집니다. 이는 해당 자료를 비교하기 위한 환산 기준이며 모든 시대의 실제 전 무게가 동일했다는 뜻은 아닙니다. 약재나 배합 비율이 다르면 단위 환산만으로 서로 바꿀 수 없습니다.
