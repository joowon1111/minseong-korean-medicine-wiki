# 같은 체질이면 같은 처방을 쓰나?

**같은 체질이라고 해서 항상 같은 처방을 쓰는 것은 아니다.**

사상의학에서는 체질을 확인한 뒤에도 현재의 표리병증·한열·경중·소증을 다시 살핀다.

```text
같은 체질
   ↓
현재 병증이 다름
   ↓
치법이 달라짐
   ↓
처방도 달라질 수 있음
```

예를 들어 소양인에서도 형방도적산·형방사백산·양격산화탕은 서로 다른 병증 맥락에서 탐색된다.
