# 사상체질은 어떻게 진단하나?

사상체질은 외모나 성격 하나만으로 정하는 것이 아니라 **평소의 소증, 현재 병증, 체형·용모·성정, 소화·발한·대소변·수면 등 여러 정보를 종합**해 판단한다.

```text
체형·용모
+ 성정
+ 소화·수면·발한
+ 대소변
+ 평소 소증
+ 현재 병증
      ↓
   체질 판단
```
