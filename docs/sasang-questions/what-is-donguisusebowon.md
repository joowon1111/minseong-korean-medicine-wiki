# 동의수세보원은 어떤 책인가?

**《동의수세보원》은 이제마가 사상의학의 체질·생리·병리·병증·치료 원칙을 체계화한 핵심 고전**이다.

```text
동의수세보원
 ↓
태양인·소양인·태음인·소음인
 ↓
체질별 생리·병리
 ↓
표리병증
 ↓
치료 원칙·처방
```
