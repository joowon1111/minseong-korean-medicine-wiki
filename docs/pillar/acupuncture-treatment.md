# 침구·한의치료 허브 {#_1}

침구 자료를 찾을 때는 **어떤 증상으로 치료를 알아보는지, 치료방법을 비교하려는지, 경혈과 침법을 공부하려는지**부터 나누면 읽을 순서가 분명해집니다. 이 페이지에서는 목적에 맞는 자료를 고르고, 상세 설명은 각 전문 문서에서 이어갑니다.

## 경락과 경혈 {#_2}

경혈 이름을 알고 있다면 **혈명·국제표준 코드 → 위치와 주변 구조 → 주치의 출처 → 배혈에서의 역할** 순서로 읽습니다. 경맥을 공부한다면 유주와 해당 경혈을 먼저 확인한 뒤 증상별 연결로 돌아옵니다.

- [WHO 표준 361경혈 아틀라스](../acupoint-network/standard-atlas.md): 이름·코드에서 개별 경혈 찾기
- [경락·경맥 임상 지식망](../meridian-network/index.md): 경맥의 흐름과 관련 자료
- [경혈 임상 지식망](../acupoint-network/index.md): 위치·주치·배혈의 연결
- [경맥→증상 임상 지도](../acupoint-network/by-condition.md): 증상에서 경맥·경혈로 이동

3D 모형은 위치 관계를 살펴보는 학습 자료입니다. 실제 시술의 깊이·방향을 모형만 보고 정하지 않으며, 해부학과 진찰은 아래 [안전·구조 안내](#_7)에서 함께 확인합니다.

## 특정혈 체계 {#_3}

오수혈·원혈·락혈·극혈·배수혈·모혈·팔회혈·하합혈·팔맥교회혈은 서로 다른 분류 체계입니다. 이름을 외우는 것에서 나아가 **어떤 체계에 속하는지, 해당 자료에서 어떤 배혈 맥락을 설명하는지**를 함께 읽습니다.

[특정혈 전체 보기](../meridian-network/special-points/index.md)에서 분류별 설명과 경혈을 찾고, 실제 조합은 [배혈](#_4)로 이어갑니다. 특정혈 분류와 현대 연구의 평가 결과는 각각 확인합니다.

## 배혈 {#_4}

배혈을 읽을 때는 아픈 부위의 국소혈, 떨어진 부위의 원위혈, 전신 증후에 따라 선택한 혈의 역할을 나눠 봅니다. 같은 혈이 포함되어 있어도 전체 구성과 치료 목표가 같다는 뜻은 아닙니다.

| 공부할 내용 | 읽을 자료 | 비교할 질문 |
|---|---|---|
| 기본 배혈 | [임상 핵심 배혈 조합](../network/acupoint-combinations.md) | 어떤 증상·부위를 중심으로 구성했는가 |
| 한약과 침구의 연결 | [방제·경혈 임상 조합](../network/formula-acupoint-combinations.md) | 각 치료가 맡는 목표는 무엇인가 |
| 사암침법 | [정격·승격 구성](../acupuncture-specific/saam-12-meridians.md) | 보사·자경·타경의 구성을 어떻게 설명하는가 |
| 동씨침법 | [동씨기혈 아틀라스](../tung-acupuncture/index.md) | 혈군의 위치·출처와 활용 맥락은 무엇인가 |
| 태극침법 | [체질별 구성](../taegeuk-acupuncture/constitutions.md) | 체질 판단·배혈·반응 관찰을 어떻게 구분하는가 |

각 침법의 전체 자료는 [침구·치료 포털](../portal/acupuncture.md)에서 찾을 수 있습니다. 서로 다른 침법의 구성을 한 표에 섞어 하나의 처방처럼 읽지 않고, 원래 체계의 설명과 출처를 따라갑니다.

## 주요 치료 {#_5}

치료방법을 비교할 때는 이름과 함께 시술 목적, 자극 방식, 치료 뒤 확인할 변화를 살펴봅니다. 아래는 상세 안내로 들어가는 길이며 모든 치료를 함께 받아야 한다는 뜻은 아닙니다.

| 치료 | 상세 자료에서 확인할 내용 | 다음 안내 |
|---|---|---|
| 침 | 치료 부위·배혈과 시행 과정 | [침치료](../treatments/acupuncture.md) |
| 전침 | 전기 자극을 더하는 방식과 장치 관련 확인 | [전침](../treatments/electroacupuncture.md) |
| 약침 | 사용 성분·적용 부위·알레르기 등 사전 확인 | [약침](../treatments/pharmacopuncture.md) · [약침 임상 지도](../acupuncture-integrated/pharmacopuncture.md) |
| 부항 | 시술 방식·피부 상태와 시술 후 관찰 | [부항](../treatments/cupping.md) |
| 뜸 | 온열 방식·피부와 감각 상태의 확인 | [뜸](../treatments/moxibustion.md) |

진료에서는 가장 불편한 증상과 회복하고 싶은 활동을 먼저 정하고 치료 계획을 설명받습니다. 계획한 횟수만 채우는 것보다 무엇이 달라졌고 어떤 불편이 남았는지 비교합니다. [치료 후 경과관찰](../acupuncture-integrated/followup.md)

## 해부학과 안전 {#_7}

경혈 위치와 고전적 주치만으로 자침을 결정하지 않습니다. 신경·혈관·흉곽·복강·척추·관절 등 주변 해부학을 확인하고 부위와 환자 상태에 맞게 시술을 계획합니다.

- 구조를 공부할 때: [근육·말초신경 임상해부학](../clinical-anatomy/index.md) · [MPS 해부 아틀라스](../clinical-anatomy/mps-atlas.md)
- 진료를 준비할 때: [침구치료 안전 확인](../acupuncture-integrated/safety.md)
- 치료 뒤 변화를 살필 때: [치료 전후 기록과 재평가](../conditions/treatment-response-evaluation.md#followup-summary)

시술 전에는 복용약·알레르기·기저질환·임신 여부와 과거 시술 반응을 전달하고, 새 불편은 시작 시점과 함께 알립니다. 구체적인 사전 확인 사항과 대응은 안전 안내에서 이어집니다.

## 현대 연구 {#_8}

연구를 읽을 때는 **누구에게, 어떤 치료를, 무엇과 비교하여, 어떤 결과를 확인했는지**를 먼저 정리합니다. 배혈명만 같다고 동일한 치료로 보지 않고 횟수·기간·자극 방식·병행치료도 확인합니다.

| 읽을 부분 | 확인할 질문 |
|---|---|
| 대상 | 같은 진단·중증도·급성 또는 만성 경과인가 |
| 치료 구성 | 배혈·자극 방식·시행 간격과 병행치료가 무엇인가 |
| 비교군 | 가짜침·일상치료·다른 치료 중 무엇과 비교했는가 |
| 결과 | 통증·증상 점수와 실제 활동 기능이 어떻게 달라졌는가 |
| 추적·안전 | 치료 종료 뒤에도 관찰했는가, 이상반응은 어떻게 수집했는가 |

침 임상시험의 중재 보고 기준인 [STRICTA](https://www.equator-network.org/reporting-guidelines/consort-stricta/)는 시행한 치료를 충분히 설명하기 위한 자료입니다. 보고 기준을 따랐다는 사실과 치료 효과의 크기·확실성은 구분해서 읽습니다.
