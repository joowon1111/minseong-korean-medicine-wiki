# 한의학 핵심 주제 허브

이 페이지는 아카이브의 방대한 자료를 **환자가 궁금해하는 증상과 질환 → 한의학적 변증 → 한약·침구치료 → 본초·방제·경혈 → 현대 임상근거** 순서로 찾아가도록 연결합니다.

정확한 병명을 모르면 [증상으로 찾기](../symptom-integrated/index.md)에서, 진단명이나 관심 질환을 알고 있다면 [질환별 보기](../conditions/index.md)에서 시작하세요.

## 어떤 문제로 찾고 있나요?

| 관심 분야 | 대표 증상·질환 | 주제 허브 |
|---|---|---|
| 기력이 없고 회복이 더딤 | 만성피로·허약·수술 후·퇴원 후·암 치료 후·골절 후 회복 | [보익·피로·회복](tonic-recovery.md) |
| 몸의 특정 부위가 아픔 | 허리·등·옆구리·목·어깨·턱·손목·무릎·발목통증 | [통증·근골격](pain-musculoskeletal.md) |
| 잠·긴장·신경 증상이 불편함 | 불면·두통·어지럼·저림·하지불안·이명·브레인포그 | [수면·정서·신경](sleep-neuro.md) |
| 속과 장이 불편함 | 소화불량·복통·팽만·식욕저하·변비·설사·과민성장증후군 | [소화·비위](digestion-spleen-stomach.md) |
| 코·목·기침·알레르기가 반복됨 | 비염·알레르기비염·기침·만성기침·감기·인후불편 | [호흡·비염·면역](respiratory-rhinitis-immune.md) |
| 피부·두피·모발이 불편함 | 여드름·습진·두드러기·건선·두피염·탈모 | [피부·두피·모발](skin-hair.md) |
| 아이의 성장과 반복 증상이 걱정됨 | 성장·식욕·수면·복통·변비·비염·야뇨 | [소아·성장·면역](pediatrics.md) |
| 여성 생애주기와 임신을 준비함 | 난임·임신준비·생리통·생리불순·다낭성난소증후군·갱년기·산후회복 | [여성건강](womens-health.md) |
| 소변·골반·남성건강이 불편함 | 방광염·과민성방광·야간뇨·전립선·골반통·발기기능 | [비뇨·배뇨·남성건강](urology-mens-health.md) |
| 건강검진 수치와 대사가 걱정됨 | 혈압·혈당·지질·지방간·체중·콩팥·요산 | [대사·건강검진](metabolic-checkup.md) |
| 침·전침·약침 등 치료법이 궁금함 | 경락·경혈·배혈·침·전침·약침·뜸·부항 | [침구·한의치료](acupuncture-treatment.md) |
| 고전과 한국 임상서가 궁금함 | 황제내경·상한론·동의보감·방약합편·소문대요·청강의감 | [고전·역사](classics-history.md) |
| 연구와 논문을 확인하고 싶음 | 질환별 근거·RCT·체계적 문헌고찰·메타분석·PMID·DOI | [현대 임상근거](clinical-evidence.md) |
