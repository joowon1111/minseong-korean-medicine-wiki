# 한의학 핵심 주제 허브

이 페이지는 아카이브의 방대한 자료를 **환자가 궁금해하는 증상과 질환 → 한의학적 변증 → 한약·침구치료 → 본초·방제·경혈 → 현대 임상근거** 순서로 찾아가도록 연결합니다.

정확한 병명을 모르면 [증상으로 찾기](../symptom-integrated/index.md)에서, 진단명이나 관심 질환을 알고 있다면 [질환별 보기](../conditions/index.md)에서 시작하세요. 처방명·약재명·경혈명을 알고 있다면 아래의 분야별 안내로 바로 이동할 수 있습니다.

## 목적에 맞는 시작점 {#reading-entry}

| 지금 알고 싶은 것 | 먼저 읽을 자료 | 이어서 살펴볼 내용 |
|---|---|---|

| 한약의 구성과 배합 이유 | [본초·방제 안내](../portal/herbs-formulas.md) | 약재의 역할 → 처방 구조 → 출전·약량·가감 |
| 혈자리와 침·전침·약침 | [침구·치료 안내](../acupuncture-integrated/index.md) | 경혈 위치·해부 → 배혈·침법 → 치료 목표·연구 |

## 증상에서 처방의 배합까지 이어 읽기 {#clinical-formula-routes}

질환별 문서에서는 **동반 증상과 변증 → 치법 → 처방의 본초 배합 → 침·전침·약침의 역할 → 경과 확인**을 함께 읽을 수 있습니다. 아래 연결은 처방의 차이를 비교하는 본문으로 이어집니다.

| 관심 주제 | 본문에서 비교하는 내용 | 바로 읽을 곳 |
|---|---|---|
| 식후 더부룩함·식욕저하 | 습체·담음·비위허약에 따른 다섯 처방의 소도·화습·보기 배합 | [기능성소화불량의 처방 비교](../conditions/functional-dyspepsia.md#damp-phlegm-deficiency-formulas) |
| 허리·다리 통증 | 담음·한습·어혈과 근골 허약에 따른 배합, 통증과 보행의 경과 | [요통의 다섯 처방](../conditions/low-back-pain.md#five-low-back-formulas) |
| 어깨·팔 통증 | 풍습·기혈응체와 허약의 차이, 관절 움직임과 회복 목표 | [견비통의 다섯 처방](../conditions/shoulder-pain.md#five-shoulder-formulas) |
| 재채기·콧물·코막힘 | 비염의 증상 조합과 다섯 처방의 해표·온폐·보기 배합 | [비염의 본초 배합 비교](../conditions/rhinitis.md#five-herbal-formulas) |
| 배뇨 불편·야간뇨 | 저장·배출 증상과 변증, 처방 선택과 배뇨일지 | [전립선비대증의 변증·처방](../conditions/benign-prostatic-hyperplasia.md#pattern-formulas) |
| 체중·대사 관리 | 식욕·배변·부종·냉열에 따른 다섯 처방의 구성 차이 | [체중관리 처방 비교](../conditions/weight-management-herbal.md#five-obesity-formulas) |
| 안면마비·중풍 후유증 | 경련·담음·기혈 부족과 기능 회복에 따른 치법·배합 | [안면마비의 다섯 처방](../conditions/facial-palsy.md#five-facial-formulas) · [중풍 후유증의 다섯 처방](../authority/conditions/stroke-rehabilitation.md#five-poststroke-formulas) |
| 월경통 | 활혈·소통과 음혈·기혈 보강, 월경 시점과 동반 증상 | [월경통의 다섯 처방](../conditions/dysmenorrhea.md#five-menstrual-formulas) |
| 허약·피로와 보익 처방 | 공진단의 온보·음혈 배합, 경옥고의 보비익기·청열생진·윤조, 출전별 구성 | [공진단](../formulas/gongjin-dan.md#warm-yin-yang-tonification) · [경옥고](../formulas/gyeongok-go.md#spleen-qi-deficiency-heat) · [보익 처방 비교](../network/tonic-formula-compare.md) |

원방·가감방의 차이는 **출전·약재·포제·상대량·제형**을 함께 보면 분명해집니다. [임상 핵심 처방 100선](../herbal-integrated/general-formulary.md)에서 원문과 구성을 확인하고, [처방 구조 비교](../herbal-integrated/formula-structure.md#interactive-comparison)와 [본초 비교·감별](../herbal-integrated/herb-comparisons.md#interactive-comparison)에서 유사한 배합을 나란히 살펴보세요.

## 고전과 일상의 이야기로 읽기 {#classics-and-daily-reading}

고전의 구절을 확인할 때는 [고전 원문·해석](../classics-reader/index.md)에서 시작해 [상한론](../shanghan-network/index.md)·[금궤요략](../jingui-network/index.md)·[동의보감](../donguibogam-network/index.md)·[온병학](../wenbing-network/index.md)·[동의수세보원](../donguisusebowon-network/index.md)의 병증·치법·처방을 이어 읽습니다. 동의보감의 특정 약재나 구절은 [원문 열람·검색](../classics/donguibogam/original.md)에서 찾아볼 수 있습니다.

사람과 사건을 중심으로 읽고 싶다면 [민성의담](../classical-stories/index.md)의 왕실 진료·본초·처방 이야기와 사상의학 연재를, 짧게 읽고 생활에 적용하고 싶다면 [하루 한의학](../daily-korean-medicine/index.md)의 날짜별 카드와 절기 이야기를 이용하세요. [학습실](../learning/index.md)은 본초·경혈·고전·사상의학의 개념을 복습하는 길을 제공합니다.

## 치료 설명에서 임상근거로 이어가기 {#clinical-evidence-reading}

[연구·근거 안내](../portal/evidence.md)는 주요 국제저널의 침·전침·한약 연구, 국내 약침·추나 연구, 일본 Kampo와 소화기·간·신장 연구를 연결합니다. 관심 치료의 성과를 살펴본 뒤 해당 질환 문서에서 평가·변증·치료·경과를 함께 읽을 수 있습니다.

- **주요 국제저널의 임상연구**: [저널·연구별 핵심 성과](../portal/evidence.md#high-impact-journal-studies)에서 대상과 평가 지표, 원 논문으로 이어집니다.
- **일본 의사들의 한약 연구**: [일본 Kampo 연구](../portal/evidence.md#japan-kampo-studies)와 [간·신장질환 연구](../portal/evidence.md#liver-kidney-research)에서 실제 제제와 치료 조건을 확인합니다.
- **증상별 치료 결과**: [자율신경·소화·수면·두통·통증의 근거](../portal/evidence.md#symptom-focused-evidence)에서 관련 질환의 상세 연구 절로 이동합니다.

논문에서는 **대상·치료와 제제·비교군·기간·결과**를 함께 확인합니다. [현대 임상근거 허브](clinical-evidence.md)와 [근거 가이드](../evidence-guide/index.md)는 연구 설계와 결과를 읽는 방법을, [참고문헌 데이터베이스](../research/references/index.md)는 PMID·DOI와 원문을 찾는 경로를 안내합니다.

원하는 문서를 더 빠르게 찾는 방법은 [사이트 검색 안내](../search-guide.md)에서 확인할 수 있습니다.
