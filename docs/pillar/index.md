# 한의학 핵심 주제 허브

이 페이지는 민성 한의학 아카이브의 큰 주제를 **환자 질문 → 증상·질환 → 변증 → 한약·침구치료 → 본초·방제·경혈 → 현대 임상근거**의 흐름으로 연결합니다.

정확한 병명을 모르면 [증상으로 찾기](../symptom-integrated/index.md)에서 시작하고, 진단명이나 관심 질환을 알고 있다면 [질환별 보기](../conditions/index.md)를 이용하세요.
