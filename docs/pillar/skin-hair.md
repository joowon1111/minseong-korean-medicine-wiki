# 피부·두피·모발 한의치료 허브

피부질환은 비슷한 붉음·가려움·각질로 보여도 원인과 치료가 다릅니다. 이 허브에서는 **병변 모양과 분포 → 급성 위험신호 → 질환 감별 → 한의학적 변증 → 한약·침구·외용·생활관리 → 사진과 증상으로 재평가** 순서로 찾아갑니다.

## 증상에서 시작하기

| 주된 불편 | 먼저 볼 문서 | 함께 구분할 것 |
|---|---|---|
| 얼굴·등의 면포와 염증 | [여드름](../conditions/acne.md) | 약물·화장품, 월경, 흉터 위험 |
| 접히는 부위의 만성 가려움 | [아토피피부염](../conditions/atopic-dermatitis.md) | 접촉피부염, 감염, 수면장애 |
| 손의 균열·물집·진물 | [손습진](../conditions/eczema-hands.md) · [한포진](../conditions/dyshidrotic-eczema.md) | 직업 노출, 곰팡이, 감염 |
| 두피 유분·각질·가려움 | [지루성피부염](../conditions/seborrheic-dermatitis.md) | 두피건선, 접촉반응 |
| 두꺼운 붉은 판과 각질 | [건선](../conditions/psoriasis.md) | 관절·손발톱 침범 |
| 팽진이 생겼다 사라짐 | [두드러기](../conditions/urticaria.md) | 혈관부종·호흡곤란 |
| 머리카락이 가늘거나 많이 빠짐 | [탈모](../conditions/hair-loss.md) | 흉터성·원형·휴지기·유전형 |
| 발진 없이 가려움 | [가려움증](../conditions/pruritus.md) | 간·신장·혈액·약물 원인 |

## 먼저 확인할 위험신호

- 입술·혀가 붓고 숨이 차거나 어지러운 알레르기 반응
- 고열과 함께 피부가 넓게 벗겨지거나 물집·점막 통증이 생김
- 붉은 부위가 빠르게 번지고 심한 통증·열감·고름이 동반됨
- 눈 주위 발진과 시야 변화, 얼굴 한쪽 수포와 심한 통증
- 전신 홍반·농포성 건선, 빠르게 진행하는 흉터성 탈모
- 새 약을 시작한 뒤 전신 발진과 발열·얼굴부종이 생김

## 한의학적 감별 축

피부의 **붉음·열감, 진물·부종, 건조·각질, 색소와 두꺼움, 가려움의 시간대**를 전신 상태와 연결합니다.

| 중심 양상 | 변증 축 | 치료 방향 |
|---|---|---|
| 붉고 뜨거우며 빠르게 번짐 | 풍열·혈열 | 열감과 염증 반응 조절 |
| 진물·유분·무거움 | 습열·담습 | 습열과 비위·대사 조절 |
| 오래되고 건조·균열 | 혈허·혈조 | 양혈윤조와 피부장벽 회복 |
| 어둡고 두꺼운 만성 병변 | 어혈 | 순환과 조직 회복 지원 |
| 피로·식욕저하와 반복 악화 | 기혈허·비허 | 회복력과 소화·수면 보강 |

한약은 피부 병명만으로 고정하지 않고 병변 단계, 계절, 월경, 소화·대변, 수면, 감염과 현재 치료를 반영합니다. 침·전침·이침은 가려움·통증·스트레스·수면 조절에 활용하고, 병변 주변 시술은 감염과 피부 손상을 먼저 확인합니다.

## 병변 단계에 따른 치료 설계

| 단계 | 우선 관찰 | 한의치료 구성 | 경과 지표 |
|---|---|---|---|
| 급성 홍반·열감 | 번지는 속도, 열감·통증, 전신 증상 | 풍열·혈열·습열을 구분해 한약과 편안한 침치료 구성 | 새 병변 수, 붉음·열감, 수면 |
| 진물·부종 | 감염, 삼출량, 접촉 자극 | 습열·담습과 피부장벽을 함께 조절 | 진물·부종, 드레싱·외용제 사용 |
| 건조·각질 | 균열, 출혈, 세정·환경 | 양혈윤조와 보습·생활환경 조정 | 각질·균열, 가려움, 긁는 횟수 |
| 만성 비후·색소 | 반복 마찰, 수면, 스트레스 | 어혈·기혈허와 순환·회복을 함께 조절 | 두께·면적, 야간 가려움, 재발 간격 |
| 두피·모발 | 염증·흉터, 모발 굵기, 탈락 형태 | 두피 상태와 전신 변증에 맞춘 한약·침구치료 | 월별 사진, 가르마 폭, 염증·탈락 추세 |

## 초진과 경과관찰

초진에는 시작 시점, 처음 생긴 부위, 사용 중인 연고·약·화장품, 직업 노출, 월경·식사·수면, 가족력을 정리합니다. 치료 뒤에는 같은 조명 사진, 병변 면적, 붉음·진물·각질, 가려움 0~10, 긁어 깨는 횟수, 외용제 사용량을 봅니다. 모발은 월 단위, 습진·두드러기는 주 단위로 기록 주기를 달리합니다.

사진은 같은 거리·조명·자세로 촬영하고, 새 치료를 시작한 날짜를 함께 남깁니다. 피부가 좋아진 날뿐 아니라 악화 전 24~48시간의 수면·땀·음주·새 제품·감염·월경 변화를 기록하면 반복 유발요인과 처방 조정 근거를 찾기 쉽습니다.
