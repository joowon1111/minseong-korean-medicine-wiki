# 여성건강 한의학 허브

여성건강은 한 시점의 증상만이 아니라 **월경주기, 배란과 임신준비, 임신·출산, 산후회복, 주폐경기 변화**가 이어지는 과정으로 살펴보는 것이 중요합니다.

## 생애주기와 증상으로 찾기

| 시기·상황 | 대표 문서 | 함께 확인할 내용 |
|---|---|---|
| 임신을 준비하거나 난임 진료 중 | [난임·임신준비](../conditions/infertility-preconception.md) | 월경·배란·난소예비력·정액검사·보조생식 일정 |
| 생리 때 통증이 심함 | [생리통·월경통](../conditions/dysmenorrhea.md) | 통증 시기·출혈량·혈괴·자궁내막증 가능성 |
| 주기가 불규칙함 | [월경불순](../conditions/irregular-menstruation.md) | 주기·체중·갑상선·프로락틴·배란 |
| 다낭성난소증후군이 있음 | [다낭성난소증후군](../conditions/polycystic-ovary-syndrome.md) | 배란·인슐린저항성·체중·여드름·다모 |
| 출산 뒤 회복이 더딤 | [산후회복](../conditions/postpartum-recovery.md) | 오로·수유·수면·빈혈·골반·정서 |
| 열감·불면·발한 등 갱년기 변화 | [갱년기](../conditions/menopause.md) | 월경 변화·수면·기분·골건강·심혈관 위험 |

## 한의학적 해석

- **기혈허·혈허**: 월경·출산·질환 뒤 피로와 어지럼, 회복저하가 두드러지는 경우
- **간울기체**: 주기와 스트레스에 따라 유방창통·복부팽만·정서 변화가 나타나는 경우
- **어혈**: 고정된 생리통·혈괴·골반통이 두드러지는 경우
- **한응·양허**: 냉감과 하복부 불편, 허리·무릎의 약화가 함께 나타나는 경우
- **음허·허열**: 갱년기 열감·발한·건조·불면이 동반되는 경우

## 대표 치료 연결

- 방제: 온경탕 · 조경종옥탕 · 당귀작약산 · 귀비탕 · 가미소요산
- 본초: 당귀 · 백작약 · 숙지황 · 천궁 · 황기 · 산수유
- 경혈: 관원 CV4 · 기해 CV6 · 삼음교 SP6 · 혈해 SP10 · 태충 LR3 · 신수 BL23
