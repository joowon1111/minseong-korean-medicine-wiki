# 보익·피로·회복 한의학 허브

회복이 더딘 상태는 단순히 “기운이 없다”는 한마디로 같지 않습니다. **식욕·소화, 수면, 체중과 근력, 수술·질환 경과, 통증, 활동 후 회복 속도**를 함께 확인하고 기허·기혈양허·비위기허·기음양허·정혈부족 등의 비중을 살핍니다.

나이에 따른 면역 변화와 저등급 염증을 포함한 장기 관리의 공통 축은 [면역·만성염증·질병·노화와 회복 지식망](../immune-allergy/inflammation-pain.md)에서 함께 볼 수 있습니다.

## 어떤 회복 상황인가요?

| 상황 | 먼저 볼 문서 | 함께 확인할 것 |
|---|---|---|
| 오래 피곤하고 자도 개운하지 않음 | [만성피로](../conditions/chronic-fatigue.md) | 수면·식욕·빈혈·갑상선·감염·활동 후 악화 |
| 일반 수술 뒤 기력과 식욕이 떨어짐 | [수술 후 회복관리](../conditions/postoperative-recovery.md) | 수술 종류·상처·감염·통증·영양상태 |
| 퇴원하거나 오래 입원한 뒤 쇠약함 | [퇴원 후 회복](../conditions/post-hospitalization-recovery.md) | 근감소·보행·식사량·수면 |
| 암 수술·항암치료 뒤 회복이 필요함 | [암 치료·수술 후 회복](../conditions/cancer-treatment-recovery.md) | 치료 단계·혈액검사·오심·말초신경증상 |
| 골절 뒤 뼈와 근력이 함께 약해짐 | [골절 후 회복](../conditions/fracture-recovery.md) | 유합 상태·부종·가동범위·재활 |
| 출산 뒤 피로·식욕·수면이 저하됨 | [산후회복](../conditions/postpartum-recovery.md) | 오로·수유·빈혈·골반통·정서상태 |

## 한의학적 회복 방향

- **기허·비위기허**: 쉽게 지치고 식욕과 소화가 떨어지며 활동 뒤 회복이 늦은 경우
- **기혈양허**: 피로와 함께 안색·어지럼·두근거림·수면저하가 동반되는 경우
- **기음양허**: 소모성 질환이나 치료 뒤 피로·구갈·열감이 함께 나타나는 경우
- **정혈부족·간신부족**: 장기 회복 과정에서 근골과 체력이 함께 약해진 경우
- **어혈·담음·기체**: 통증·부종·답답함이 회복을 방해하는 경우

## 대표 본초

보익 본초는 “기운을 올리는 약재” 하나로 묶기보다 **무엇이 부족하고 어떤 회복이 더딘지**에 따라 봅니다.

| 회복축 | 대표 본초 | 임상에서 연결하는 모습 |
|---|---|---|
| 보기·비위 | [인삼](../herbs/ginseng.md) · [황기](../herbs/astragalus.md) · [백출](../herbs/atractylodes.md) · [복령](../herbs/poria.md) | 쉽게 지침, 식욕저하, 식후 처짐, 말하거나 움직인 뒤 탈진 |
| 보혈·기혈회복 | [당귀](../herbs/angelica.md) · [숙지황](../herbs/prepared-rehmannia.md) · [백작약](../herbs/white-peony.md) | 안색저하, 어지럼, 두근거림, 건조, 출혈·산후·병후 쇠약 |
| 기음·진액 | [맥문동](../herbs/ophiopogon.md) · [오미자](../herbs/schisandra.md) · [생지황](../herbs/rehmannia-root-fresh.md) | 구갈·건조·도한, 더위나 장기 질환 뒤 소모, 쉽게 마르는 피로 |
| 간신·정혈 | [녹용](../herbs/cervi-parvum-cornu.md) · [산수유](../herbs/cornus-fruit.md) · [산약](../herbs/dioscorea.md) | 허리·무릎 무력, 성장·노년기·장기 회복, 정혈부족 양상 |
| 근골 회복 | [두충](../herbs/eucommia.md) · [우슬](../herbs/achyranthes.md) | 골절·수술·장기 안정 뒤 근력과 보행 회복, 요슬산연 |

한 약재의 효능만으로 처방을 결정하지 않습니다. 예를 들어 피로가 있어도 식욕저하가 중심이면 비위 회복을, 어지럼·심계가 두드러지면 기혈을, 냉감·하체무력이 뚜렷하면 양기와 간신을 함께 살핍니다.

## 회복 상황별 선택 지도

| 현재 가장 불편한 점 | 우선 살필 변증축 | 연결할 본초·처방군 |
|---|---|---|
| 먹는 양이 줄고 식후 더 처짐 | 비위기허·담음 | 인삼·백출·복령 / 사군자탕·육군자탕 계열 |
| 피로와 어지럼·안색저하·심계 | 혈허·기혈양허 | 당귀·숙지황·백작약 / 팔물탕·십전대보탕 계열 |
| 수면이 얕고 걱정·건망이 동반 | 심비양허·심혈부족 | 인삼·황기·당귀 / 귀비탕 계열 |
| 입이 마르고 도한·열감이 동반 | 기음양허·진액부족 | 맥문동·오미자·생지황 / 생맥산·경옥고 방향 |
| 냉감과 허리·무릎 무력, 회복 지연 | 양허·간신부족·정혈부족 | 녹용·산수유·두충·우슬 중심의 보익 방향 |
| 통증·부종·뻣뻣함이 회복을 방해 | 어혈·담음·기체가 허증에 겸함 | 보익만 하지 않고 순환·통증·부종 치료를 함께 설계 |

## 회복 단계에 따라 달라지는 우선순위

1. **초기 안정 단계**: 발열·출혈·감염·상처·급성 통증과 담당 진료 계획을 먼저 확인합니다.
2. **섭취 회복 단계**: 식욕·오심·복부팽만·배변을 조절해 영양과 수분 섭취 기반을 만듭니다.
3. **기혈 회복 단계**: 일중 피로, 어지럼, 숨참, 수면과 활동 후 회복속도를 함께 개선합니다.
4. **기능 회복 단계**: 보행·계단·근력·관절 가동범위와 일상생활 복귀를 목표로 합니다.
5. **유지 단계**: 무리한 활동 뒤 재악화를 줄이고 식사·수면·운동 리듬을 안정시킵니다.

수술·항암·골절·산후회복에서는 같은 처방을 고정하기보다 회복 단계와 검사 결과, 복용약, 식사량 변화에 맞춰 구성과 용량을 조정합니다.

## 치료 반응은 이렇게 확인합니다

| 관찰축 | 실제로 기록할 항목 |
|---|---|
| 에너지 | 아침 기상 난이도, 오전·오후 피로도, 활동 뒤 회복시간 |
| 섭취·소화 | 식사량, 식욕, 더부룩함·오심, 체중 변화 |
| 수면 | 입면시간, 야간각성, 수면 뒤 개운함 |
| 신체 기능 | 걷는 시간, 계단, 외출·가사·업무 복귀 정도 |
| 동반 증상 | 어지럼·심계·숨참, 냉감·열감, 통증·부종 |
| 객관 지표 | 필요한 경우 혈액검사, 상처·골유합, 재활평가와 담당과 추적 결과 |

복용 뒤 식욕과 수면이 먼저 안정되고 활동시간이 늘어나는지, 반대로 불편이 새로 생기거나 기존 증상이 악화되는지를 함께 기록하면 처방 유지·조정 판단이 쉬워집니다.
