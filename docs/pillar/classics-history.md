# 한의학 고전·역사 허브 {#_1}

## 한 대목을 깊게 읽는 순서 {#close-reading}

책의 어느 편인지 확인한 뒤, 원문이 말하는 증후와 해설자의 설명을 나누어 읽습니다. 아래 순서는 학습 메모를 정리하는 방법입니다.

| 단계 | 남길 질문 | 연결 자료 |
|---|---|---|
| 출전 확인 | 책·편명·조문과 판본은 무엇인가 | [고전 임상 지식망](../classics/index.md) |
| 문장 이해 | 원문에 적힌 증후와 후대 해설을 구분했는가 | 해당 고전의 조문·해석 문서 |
| 처방 분석 | 구성·제법·용량·가감은 어느 수록형을 기준으로 하는가 | [방제 구조](../formula-architecture/index.md) |
| 약재·경혈 연결 | 처방이나 배혈에서 각 요소가 맡는 역할은 무엇인가 | [본초](../herbs/index.md) · [경혈](../acupoint-network/index.md) |
| 현대 질문 | 지금의 진단·검사·치료 연구와 비교할 때 확인할 점은 무엇인가 | [고전과 현대 연구 연결](../network/classic-to-evidence-map.md) |

같은 처방명이라도 원방·후대 가감방·현대 시험 제제를 따로 확인합니다. 옛 약량과 현대 용량은 판본과 환산 근거를 함께 보고, 단위만 기계적으로 바꾸어 복용량으로 삼지 않습니다. [고전 처방의 용량·제법 읽기](../classics/classical-formula-reading.md)

## 주제에 따라 읽기 경로를 좁히기 {#topic-reading}

**소화·식욕·피로**가 궁금하다면 비위론의 관련 설명에서 처방의 배합을 읽고, [소화·비위 안내](digestion-spleen-stomach.md)에서 현재의 증상 감별과 치료 목표를 확인합니다. **통증·근골격**은 동의보감의 해당 분류와 처방을 읽은 뒤 [통증·근골격 안내](pain-musculoskeletal.md)에서 해부학·기능 평가로 연결합니다.

**여성·산후**는 금궤요략과 동의보감의 해당 편을 살펴보고 [여성건강 안내](womens-health.md)에서 월경·임신·산후의 서로 다른 상황을 구분합니다. **사상의학**은 다른 고전의 병증을 그대로 대입하기보다 [체질별 소증·병증 체계](../sasang-integrated/index.md)를 따라 읽고 [경과관찰](../sasang-followup/index.md)로 이어갑니다.

고전의 병명·주치는 당시 문헌의 맥락에서 읽고, 현대 질환명·검사 결과와 일대일로 맞추지 않습니다. 고전 원문, 후대 해석, 현대 임상연구는 서로 다른 자료이며 각각의 출처와 설명 범위를 확인합니다.
