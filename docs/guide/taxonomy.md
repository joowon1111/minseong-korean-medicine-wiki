# 아카이브 분류 체계

민성 한의학 아카이브의 분류는 모든 문서를 좌측 메뉴에 나열하기 위한 목록이 아닙니다. **사용자가 어디에서 시작하든 증상·질환·한의학적 해석·치료·근거로 이동할 수 있게 하는 지식 구조**입니다.

## 세 단계 탐색 구조

| 계층 | 역할 | 대표 예시 |
|---|---|---|
| 분야별 포털 | 처음 방문한 사용자가 큰 분야를 선택 | 한의학 기초·본초방제·침구·사상·연구근거 |
| 핵심 주제 허브 | 환자 진료 분야와 주요 질문을 통합 | 통증·소화·수면·호흡면역·여성건강·보익회복 |
| 상세 기준문서 | 하나의 증상·질환·본초·처방·경혈·연구를 깊게 설명 | 불면·비염·녹용·귀비탕·신문 HT7·질환별 근거카드 |

```text
포털
 ├─ 핵심 주제 허브
 │   ├─ 증상·질환 기준문서
 │   ├─ 치료·본초·방제·경혈
 │   └─ 현대 임상근거
 └─ 전문 자료실
     ├─ 고전·사상·변증
     └─ 세부 색인·비교·네트워크
```

## 주요 문서 영역

| 영역 | 중심 질문 | 연결해야 할 영역 |
|---|---|---|
| 한의학 기초 | 장부·기혈진액·병인병기·사진·변증이 무엇인가 | 임상 추론·고전·증상·방제 |
| 증상 | 지금 느끼는 불편이 무엇과 관련되는가 | 위험신호·질환·변증·치료 |
| 질환 | 어떤 진단·검사·치료와 회복관리가 필요한가 | 증상·치료·근거·안전 |
| 변증·치법 | 증상과 소견을 어떤 병리 구조로 해석하는가 | 장부·본초·방제·임상추론 |
| 본초 | 어떤 약재이며 처방에서 어떤 역할을 하는가 | 효능·배합·방제·성분·근거 |
| 방제 | 어떤 병기와 치법에 쓰이며 유사 처방과 무엇이 다른가 | 구성본초·변증·질환·근거 |
| 침구·경혈 | 어디에 위치하고 어떤 치료 목표로 활용하는가 | 해부학·경락·증상·임상연구 |
| 사상의학 | 체질의 소증과 현재 병증, 처방·생활관리를 어떻게 연결하는가 | 동의수세보원·병증·처방·음식 |
| 고전 | 원전의 병증·치법·처방이 무엇이며 현대에 어떻게 읽는가 | 변증·본초·방제·현대근거 |
| 현대 근거 | 사람 대상 연구에서 무엇이 평가됐는가 | 질환·치료·연구설계·출처 |
| 임상 안전 | 어떤 경우 검사·의뢰·응급평가가 우선인가 | 증상·질환·치료법·특수환자군 |
| 안내·색인 | 자료를 어떻게 찾고 인용하고 운영하는가 | 모든 대표 허브 |

## 증상과 질환을 구분합니다

| 구분 | 증상 문서 | 질환 문서 |
|---|---|---|
| 출발점 | 환자가 느끼는 표현 | 진단명 또는 의심 질환 |
| 첫 질문 | “왜 이런 증상이 생길 수 있나요?” | “어떻게 진단하고 치료하나요?” |
| 핵심 내용 | 위치·양상·위험신호·관련 질환 | 정의·진단·검사·치료·예후 |
| 한의학 연결 | 변증·치법·치료 선택 | 질환 안의 병증 차이와 통합치료 |
| 상호 링크 | 관련 질환으로 이동 | 주요 증상으로 돌아감 |

예를 들어 `어지럼`은 증상 문서이고, `양성돌발성체위성현훈`은 질환 문서입니다. 같은 본문을 복사하지 않고 증상 문서에서는 감별 지도를, 질환 문서에서는 진단과 치료를 중심으로 합니다.

## 본초와 방제를 구분합니다

### 본초 문서

- 기원·학명·약용부위
- 성미·귀경·효능·주치
- 품질·포제·용량·안전
- 처방 안에서의 역할과 배합
- 성분·기전·사람 대상 연구의 구분

### 방제 문서

- 출전과 원방 구성
- 군신좌사 또는 기능적 배합 구조
- 병기·치법·핵심 증상
- 비슷한 처방과 가감 방향
- 복용 뒤 관찰할 변화
- 완성 처방의 현대 임상연구

개별 구성약재의 전임상 결과를 처방 전체의 임상효과로 합산하지 않습니다.

## 침구 영역의 세부 분류

| 하위 유형 | 중심 내용 |
|---|---|
| 경락 | 유주·장부 연결·경근·표리 관계 |
| 경혈 | 표준 위치·취혈·해부학·주치·안전 |
| 침 치료 | 질환별 경혈 조합·자침·치료빈도·근거 |
| 전침 | 주파수·강도·파형·전극 배치·연구 프로토콜 |
| 약침 | 성분·농도·용량·주입부위·안전·임상근거 |
| 해부·초음파 | 구조물·신경혈관·시술 안전과 영상 활용 |

본초·방제 메뉴에 침구·초음파·포착증후군 문서가 섞이지 않도록 분야별 포털과 전문 자료실을 분리합니다.

## 사상의학 영역의 세부 분류

```text
체질의 기본 구조
 → 평소 소증
 → 현재 표리병증·순역·중증도
 → 체질 처방
 → 음식·생활관리
 → 치료 뒤 소증 회복
 → 원전·현대 연구
```

체질 소개, 병증 비교, 처방 전체 색인, 개별 처방 임상카드, 음식 가이드와 현대 연구는 역할이 다릅니다. `소음인`이라는 이유만으로 소음인 처방과 음식을 한 페이지에 모두 복사하지 않고 각 기준문서를 연결합니다.

## 현대 근거 문서의 분류

| 문서 유형 | 역할 |
|---|---|
| 근거 안내 | RCT·관찰연구·메타분석을 읽는 방법 |
| 질환별 근거카드 | 특정 질환에 대한 한약·침·전침·약침 연구 |
| 본초·방제 근거 | 특정 약재 또는 완성 처방의 연구 |
| 치료법 근거 | 침·전침·약침 등 중재별 연구 |
| 참고문헌 DB | PMID·DOI와 서지정보를 추적하는 색인 |
| 고전→현대 연결 | 원전 병증과 현대 임상 질문의 접점 |

프로토콜·전임상·사람 대상 결과를 같은 층위의 근거카드로 혼합하지 않습니다.

→ [연구·근거 한눈에 보기](../evidence-integrated/index.md)

## 기준문서와 연결문서

### 기준문서(canonical)

해당 검색 의도와 주제를 가장 충실하게 설명하는 대표 문서입니다. 허브·검색·관련 문서에서 이 URL을 우선 연결합니다.

### 연결문서(canonical bridge)

과거 URL이나 다른 분류 경로를 보존하면서 기준문서로 안내합니다. 의도적으로 짧을 수 있으며 기준문서의 본문을 반복하지 않습니다.

### 비교·네트워크 문서

두 처방의 차이, 한 본초가 포함된 처방군, 증상에서 치료로 가는 관계처럼 여러 기준문서 사이의 관계를 설명합니다. 개별 문서의 내용을 모두 복사하지 않고 비교축과 이동 경로에 집중합니다.

## 핵심 주제 허브의 분류

환자 진료 분야를 중심으로 다음 핵심 허브를 운영합니다.

- 통증·근골격
- 소화·비위
- 수면·정서·신경
- 호흡·비염·면역
- 여성건강
- 보익·피로·회복
- 침구·한의치료
- 고전·역사
- 현대 임상근거

한 문서가 여러 허브와 관련될 수 있지만 원본은 한 곳에 두고 필요한 허브에서 같은 기준 URL로 연결합니다.

## 좌측 메뉴에 넣는 문서와 넣지 않는 문서

### 좌측 메뉴에 우선 배치

- 각 분야의 포털과 기준 허브
- 사용자가 반복적으로 찾는 대표 증상·질환·본초·처방
- 체계적인 순서로 읽어야 하는 고전·경락·병증 시리즈
- 전체 색인으로 들어가는 중요한 입구

### 검색·색인으로 제공

- 매우 세부적인 개별 연구카드
- 롱테일 질문형 문서
- 개별 경혈·세부 처방·참고문헌
- 과거 URL을 보존하는 연결문서

좌측 메뉴는 전체 데이터베이스가 아니라 탐색의 뼈대입니다. 세부 문서를 과도하게 나열해 다른 분야가 섞이거나 스크롤이 지나치게 길어지지 않도록 합니다.

## 제목·URL·슬러그 기준

| 항목 | 원칙 |
|---|---|
| 제목 | 환자가 찾는 일반 명칭과 필요한 전문용어를 명확히 표시 |
| H1 | 한 페이지에 하나, 메타데이터 title과 의미상 일치 |
| URL | 영문 소문자·숫자·하이픈 사용 |
| 공개 URL | 특별한 이유가 없으면 변경하지 않음 |
| 파일명 | 경로 구조와 공개 URL을 예측할 수 있게 작성 |
| 앵커 | 자동 번호형 앵커보다 의미 있는 제목을 유지 |

한글·한자·영문·약어는 본문과 태그에서 연결할 수 있지만 동일한 주제의 URL을 표현별로 여러 개 만들지 않습니다.

## 태그 사용 기준

태그는 좌측 메뉴를 대신하는 또 하나의 거대한 분류표가 아니라 분야를 가로질러 관련 문서를 찾는 보조 색인입니다.

- 주제의 중심어 3~8개를 우선
- 상위 분야·질환·치료·핵심 처방명을 선택
- 띄어쓰기만 다른 유사 태그를 반복하지 않음
- 검색 유입만을 위한 관련 없는 키워드를 넣지 않음
- 환자 표현과 전문용어가 모두 중요할 때 함께 사용

## 문서를 추가·이동할 때의 판단 순서

1. 같은 검색 의도의 기준문서가 있는가
2. 새 내용은 기존 문서의 한 절로 충분한가
3. 독립 문서가 필요하다면 어느 영역의 어떤 유형인가
4. 어떤 포털·핵심 허브에서 진입해야 하는가
5. 증상·질환·변증·치료·근거 중 어떤 문서와 상호 연결되는가
6. 좌측 메뉴에 필요한가, 검색·색인으로 충분한가
7. 기존 공개 URL과 충돌하거나 중복되지 않는가
8. 이동 뒤 과거 링크가 끊기지 않는가

## 안정화 점검표

- [ ] 한 주제의 기준문서가 둘 이상 경쟁하지 않는가
- [ ] 과거 URL이 404가 되지 않고 새 대표 문서로 이어지는가
- [ ] 좌측 메뉴에 다른 분야 문서가 혼입되지 않았는가
- [ ] 세부 문서가 대표 허브에서 발견 가능한가
- [ ] 증상과 질환, 본초와 방제의 역할이 구분되는가
- [ ] 내부 링크 문구가 이동할 내용을 분명히 말하는가
- [ ] URL·제목·앵커 충돌이 없는가
- [ ] 태그가 과도하거나 중복되지 않는가
- [ ] 검색 색인과 사이트맵에 공개 문서가 반영되는가
