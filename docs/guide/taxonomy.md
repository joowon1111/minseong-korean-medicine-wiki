# 아카이브 분류 체계 {#_1}

민성 한의학 아카이브의 분류는 **증상·질환·변증·치료·본초·처방·경혈·고전·임상근거를 연결하는 지식 구조**입니다. 같은 주제를 대표 문서에서 깊이 설명하고, 포털·주제 허브·검색·탐색 도구가 그 문서로 안내합니다.

읽을 자료를 고를 때는 [핵심 주제 허브](../pillar/index.md), 문서를 찾는 방법은 [사이트 검색 안내](../search-guide.md), 검색엔진·AI용 자료 구조는 [사이트 구조 안내](../ai/site-structure.md)에서 확인할 수 있습니다.

## 세 단계 탐색 구조 {#_2}

| 계층 | 역할 | 대표 입구 |
|---|---|---|
| 분야별 포털 | 관심 분야의 개념과 읽는 순서를 안내 | [한의학 기초](../foundations-integrated/index.md) · [고전 원문·해석](../classics-reader/index.md) · [본초·방제](../herbal-integrated/index.md) |
| 핵심 주제 허브 | 진료 분야와 주요 질문에 맞춰 대표 문서를 연결 | [핵심 주제 허브](../pillar/index.md)의 보익·통증·소화·수면 등 분야별 안내 |
| 상세 기준문서 | 하나의 증상·질환·본초·처방·경혈·연구 질문을 충실히 설명 | [기능성소화불량](../conditions/functional-dyspepsia.md) · [공진단](../formulas/gongjin-dan.md) · [신문 HT7](../acupuncture/points/ht7-shenmen.md) |

**포털 → 주제 허브 → 상세 문서**가 기본 흐름이며, 알고 있는 처방명·경혈명·고전 구절에서 상세 문서로 바로 시작할 수도 있습니다. 비교·네트워크와 탐색기는 여러 대표 문서의 관계를 보여주고, 학습·연재 자료는 내용을 익히는 별도의 읽기 경로를 제공합니다.

상단의 주요 분야는 한의학 기초, 고전 원문·해석, 본초·방제, 침구·치료, 증상·질환, 사상의학, 연구·근거, 민성의담으로 나뉩니다. [전체 둘러보기](../portal/maps.md)는 이 분야들과 전문 자료실·학습 도구를 한곳에서 연결합니다.

| 영역 | 중심 질문 | 연결해야 할 영역 |
|---|---|---|
| 한의학 기초 | 장부·기혈진액·병인병기·사진·변증이 무엇인가 | 임상 추론·고전·증상·방제 |
| 증상 | 지금 느끼는 불편이 무엇과 관련되는가 | 위험신호·질환·변증·치료 |
| 질환 | 어떤 진단·검사·치료와 회복관리가 필요한가 | 증상·치료·근거·안전 |
| 변증·치법 | 증상과 소견을 어떤 병리 구조로 해석하는가 | 장부·본초·방제·임상추론 |
| 본초 | 어떤 약재이며 처방에서 어떤 역할을 하는가 | 효능·배합·방제·성분·근거 |
| 방제 | 어떤 병기와 치법에 쓰이며 유사 처방과 무엇이 다른가 | 구성본초·변증·질환·근거 |
| 침구·경혈 | 어디에 위치하고 어떤 치료 목표로 활용하는가 | 해부학·경락·증상·임상연구 |
| 사상의학 | 체질의 소증과 현재 병증, 처방·생활관리를 어떻게 연결하는가 | 동의수세보원·병증·처방·음식 |
| 고전 | 원전의 병증·치법·처방이 무엇이며 현대에 어떻게 읽는가 | 편목·조문·판본·해석·임상 문서 |
| 이야기·의학사 | 누가 어떤 상황에서 진료하고 약재·처방을 활용했는가 | 실제 기록·출전·의가·고전·본초·처방 |
| 학습·생활 카드 | 읽은 개념을 어떻게 복습하고 일상에 적용하는가 | 대표 문서·원문 풀이·해설 문제·양생 |
| 현대 근거 | 사람 대상 연구에서 무엇이 평가됐는가 | 질환·치료·연구설계·출처 |
| 임상 안전 | 어떤 경우 검사·의뢰·응급평가가 우선인가 | 증상·질환·치료법·특수환자군 |
| 안내·색인 | 자료를 어떻게 찾고 인용하고 운영하는가 | 모든 대표 허브 |

## 증상과 질환을 구분합니다 {#_4}

| 구분 | 증상 문서 | 질환 문서 |
|---|---|---|
| 출발점 | 환자가 느끼는 표현 | 진단명 또는 의심 질환 |
| 첫 질문 | “왜 이런 증상이 생길 수 있나요?” | “어떻게 진단하고 치료하나요?” |
| 핵심 내용 | 위치·양상·위험신호·관련 질환 | 정의·진단·검사·치료·예후 |
| 한의학 연결 | 변증·치법·치료 선택 | 질환 안의 병증 차이와 통합치료 |
| 상호 링크 | 관련 질환으로 이동 | 주요 증상으로 돌아감 |

예를 들어 `어지럼`은 증상 문서이고, `양성돌발성체위성현훈`은 질환 문서입니다. 증상 문서는 감별 지도를, 질환 문서는 진단과 치료를 중심으로 서로 연결합니다.

질환의 변증·한약·침구치료·경과와 해당 임상근거는 **대표 질환 본문에서 함께 읽는 구조**를 우선합니다. [요통](../conditions/low-back-pain.md#back-research)·[불면](../conditions/insomnia.md#sleep-research)·[기능성소화불량](../conditions/functional-dyspepsia.md#pds-acupuncture-results)의 연구 절이 그 예입니다. 같은 질문을 다루던 짧은 확장·근거 안내의 주소는 해당 본문이나 절로 이어집니다.

## 본초와 방제를 구분합니다 {#_5}

### 본초 문서 {#_6}

- 기원·학명·약용부위
- 성미·귀경·효능·주치
- 품질·포제·용량·안전
- 처방 안에서의 역할과 배합
- 성분·기전·사람 대상 연구의 구분

### 방제 문서 {#_7}

- 출전과 원방 구성
- 군신좌사 또는 기능적 배합 구조
- 병기·치법·핵심 증상
- 비슷한 처방과 가감 방향
- 복용 뒤 관찰할 변화
- 완성 처방의 현대 임상연구

본초의 성분·기전 연구와 완성 처방의 사람 대상 연구는 각각의 대상·제제·평가 지표에 맞춰 설명합니다.

### 출전별 이본과 배합 해설 {#source-formula-variants}

이름이 같은 처방도 출전·구성·포제·상대량·용량·제형이 다르면 **출전별 수록형이나 가감방**으로 구분합니다. [공진단](../formulas/gongjin-dan.md#musk-agarwood-variants)의 사향 원방과 침향·목향 가감방, [경옥고](../formulas/gyeongok-go.md#gyeongok-variant-comparison)의 인삼 증량형·익수영진고 비교처럼 같은 상세 문서 안에서 차이를 설명하고 관련 본초로 연결합니다. 독립된 출전과 임상 맥락을 가진 동명 처방은 고유 문서를 유지하며 서로 비교합니다.

[임상 핵심 처방 100선](../herbal-integrated/general-formulary.md)은 출전·원문·구성·용량을 찾는 색인이고, [처방 구조 비교](../herbal-integrated/formula-structure.md#interactive-comparison)는 유사방의 차이를 나란히 보는 도구입니다. 질환별 다섯 처방 해설은 각 질환의 치료 절에 배치하고, [핵심 주제 허브의 처방 연결](../pillar/index.md#clinical-formula-routes)에서 찾아가도록 합니다.

## 본초·방제 탐색과 중복 분류 {#herb-formula-navigation}

본초는 보익·안신양심·화담이기·이수삼습·양음생진·활혈보혈·온리온보·개규·조화 등의 전통적 역할로, 방제는 보익·해표·화담이기·이수·거풍습 등 주된 치법으로 찾아볼 수 있습니다. 하나의 본초·처방이 여러 방향을 가질 수 있어 여러 허브에 같은 기준문서가 연결될 수 있습니다. 복령·오미자·우슬 등이 여러 분류에 나타나는 것은 각각의 배합 역할을 찾아가기 위한 것입니다.

| 알고 있는 정보 | 먼저 찾는 곳 | 이어서 읽는 이유 |
|---|---|---|
| 본초 이름 | [본초→방제 역탐색](../network/herb-to-formula-map.md) | 같은 본초가 처방에 따라 맡는 역할 비교 |
| 처방 이름·약재 목록 | [처방 구성 네트워크](../network/formula-composition-hub.md) | 비율·포제·제형과 원문 대조 |
| 치료 방향·처방군 | [처방군 지도](../network/formula-family-map.md) | 주된 치법과 겹치는 배합의 차이 |
| 증상·변증 | [질환→치료 지도](../network/condition-to-treatment-map.md) | 원인 감별을 거쳐 처방·침구·경과로 연결 |

여러 분류에서는 같은 대표 문서를 연결하고, 각 허브는 그 분야에서 읽을 이유를 짧게 설명합니다. 목록이 겹치는 페이지는 대표 지도나 관련 절로 정리하며, 과거 주소는 이어 읽을 설명으로 연결합니다. [본초 비교·감별](../herbal-integrated/herb-comparisons.md#interactive-comparison)은 기원·부위·효능·배합의 차이를 비교하는 경로입니다.

## 침구 영역의 세부 분류 {#_8}

| 하위 유형 | 중심 내용 |
|---|---|
| 경락 | 유주·장부 연결·경근·표리 관계 |
| 경혈 | 표준 위치·취혈·해부학·주치·안전 |
| 침 치료 | 질환별 경혈 조합·자침·치료빈도·근거 |
| 전침 | 주파수·강도·파형·전극 배치·연구 프로토콜 |
| 약침 | 성분·농도·용량·주입부위·안전·임상근거 |
| 해부·초음파 | 구조물·신경혈관·시술 안전과 영상 활용 |

[침구·치료 통합 안내](../acupuncture-integrated/index.md)를 중심으로 경혈·침법·해부·초음파 자료를 연결합니다. [361경혈 아틀라스](../acupoint-network/standard-atlas.md#clinical-explorer)는 표준경혈·사암침·동씨기혈을 찾는 탐색 입구이고, [3D 경혈 지도](../acupoint-network/3d-map.md)는 위치·공간 관계를 살펴보는 도구입니다. 경혈의 고전 주치·현대 해부·임상연구는 해당 상세 문서에서 각각 확인합니다.

신경포착·근육·초음파 자료는 해부·질환 문서와 연결하고, 약재·처방의 분류는 본초·방제 포털에서 담당합니다.

## 사상의학 영역의 세부 분류 {#_9}

[사상의학 통합 안내](../sasang-integrated/index.md)는 **체질별 생리 → 평소 소증 → 현재 표리병증·순역·중증도 → 처방·생활관리 → 치료 뒤 변화 → 원전·현대 연구**를 연결합니다.

체질 소개, 병증 비교, 개별 처방, 음식·양생, 경과 평가와 연구는 각각의 역할에 맞는 대표 문서를 둡니다. [사상의학 탐색기](../sasang-explorer/index.md)는 이 자료를 체질·병증·원문·감별·처방의 순서로 비교하는 학습 경로입니다. [동의수세보원 원문](../classics/donguisusebowon/original.md)과 [소증별 원문](../sasang-original-symptoms/index.md), [치료 뒤 경과](../sasang-followup/index.md)를 함께 연결합니다.

## 현대 근거 문서의 분류 {#_10}

| 문서 유형 | 역할과 대표 경로 |
|---|---|
| 연구·근거 포털 | [연구·근거 안내](../portal/evidence.md)에서 주요 저널·치료법·일본 Kampo 등의 연구 성과와 상세 문서를 연결 |
| 질환 본문의 연구 절 | 질환의 평가·변증·치료와 연구 대상·중재·비교군·결과를 함께 설명 |
| 고유한 연구 질문의 근거 자료 | 여러 질환을 잇는 방법론이나 별도의 임상 질문을 다루고 관련 질환·치료 본문으로 연결 |
| 본초·방제 근거 | 특정 약재·완성 처방·시험 제제의 구성과 사람 대상 연구를 연결 |
| 치료법 근거 | 침·전침·약침·추나 등 중재의 조건과 질환별 연구를 비교 |
| 참고문헌 DB | [PMID·DOI와 서지정보](../research/references/index.md)를 추적하는 색인 |
| 고전→현대 연결 | 원전 병증·치법·배합을 현대 임상 질문과 연결하고 각각의 출처를 표시 |

진료지침·체계적 문헌고찰·무작위시험·관찰연구·안전성·기전 연구는 **각각 답하는 질문과 평가 범위**에 따라 분류합니다. 연구 프로토콜은 계획, 결과 논문은 관찰된 성과를 설명하며 대상·제제·기간·평가 지표를 함께 제시합니다.

자료가 합쳐진 뒤에도 예전 근거 카드 주소는 대표 본문으로 이어지는 경로로 활용합니다. [질환별 근거 안내](../authority/conditions/index.md)와 [근거 읽기 가이드](../evidence-guide/index.md)에서 관심 질환과 연구 유형을 찾을 수 있습니다.

## 기준문서와 연결문서 {#_11}

### 기준문서(canonical) {#canonical}

해당 검색 의도와 주제를 가장 충실하게 설명하는 대표 문서입니다. 허브·검색·관련 문서에서 이 URL을 우선 연결합니다.

### 연결문서(canonical bridge) {#canonical-bridge}

과거 URL이나 다른 분류 경로를 보존하면서 기준문서의 제목과 관련 절로 안내합니다. 리다이렉트 또는 짧은 안내문 등 저장소가 지원하는 방식으로 연결하며, 본문·출처·근거는 도착한 대표 문서에서 함께 읽습니다.

### 비교·네트워크 문서 {#_12}

두 처방의 차이, 한 본초가 포함된 처방군, 증상에서 치료로 가는 관계처럼 여러 기준문서 사이의 관계를 설명합니다. 개별 문서의 내용을 모두 복사하지 않고 비교축과 이동 경로에 집중합니다.

## 탐색·비교·검색 도구의 역할 {#tools-and-search}

[본초·처방 비교](../search-guide.md#specialized-explorers), 경혈 아틀라스·3D 지도, 사상의학 탐색기는 **기존 자료를 선택·비교·탐색하는 도구**로 분류합니다. 도구에서 고른 항목은 구성·출전·위치·병증 등을 설명하는 해당 대표 문서로 연결합니다.

상단 검색은 제목·동의어·본문으로 문서를 찾는 입구이고, [질문으로 근거 자료 찾기](../search-guide.md#question-search)는 질문에 관련된 본문 발췌와 출처를 함께 찾는 경로입니다. 페이지별 JSON 등 AI용 색인은 [사이트 구조 안내](../ai/site-structure.md)에서, 인용·공유와 원문 출처 확인은 [콘텐츠 이용 안내](content-use.md#provenance)에서 설명합니다.

## 좌측 메뉴에 넣는 문서와 넣지 않는 문서 {#_14}

### 좌측 메뉴에 우선 배치 {#_15}

- 각 분야의 포털과 기준 허브
- 사용자가 반복적으로 찾는 대표 증상·질환·본초·처방
- 체계적인 순서로 읽어야 하는 고전·경락·병증 시리즈
- 전체 색인으로 들어가는 중요한 입구

### 검색·색인으로 제공 {#_16}

- 질환 본문의 세부 연구 절과 고유한 연구 질문의 자료
- 롱테일 질문형 문서
- 개별 경혈·세부 처방·참고문헌
- 과거 URL을 보존하는 연결문서

좌측 메뉴는 대표 입구와 연속해서 읽을 순서를 제공하고, 세부 자료는 허브·본문 링크·검색·탐색기로 찾습니다. 메뉴의 분야와 대표 문서의 분류를 맞추어 탐색 흐름을 유지합니다.

## 제목·URL·슬러그 기준 {#url}

| 항목 | 원칙 |
|---|---|
| 제목 | 환자가 찾는 일반 명칭과 필요한 전문용어를 명확히 표시 |
| H1 | 한 페이지에 하나, 메타데이터 title과 의미상 일치 |
| URL | 영문 소문자·숫자·하이픈 사용 |
| 공개 URL | 특별한 이유가 없으면 변경하지 않음 |
| 파일명 | 경로 구조와 공개 URL을 예측할 수 있게 작성 |
| 앵커 | 기존 앵커는 보존하고 새 절에는 의미 있는 고정 ID를 부여 |

한글·한자·영문·약어·환자 표현은 제목·검색 메타데이터·본문·태그에서 연결하고, 같은 주제는 대표 URL로 모읍니다. 처방의 출전별 이본과 서로 다른 임상 질문은 고유 내용을 기준으로 구분합니다.

## 태그 사용 기준 {#_17}

태그는 분야를 가로질러 관련 문서를 찾는 보조 색인입니다. 대표 분류와 문서의 주제를 함께 드러내는 표현을 고릅니다.

- 주제의 중심어 3~8개를 우선
- 상위 분야·질환·치료·핵심 처방명을 선택
- 띄어쓰기만 다른 유사 태그를 반복하지 않음
- 검색 유입만을 위한 관련 없는 키워드를 넣지 않음
- 환자 표현과 전문용어가 모두 중요할 때 함께 사용

## 문서를 추가·이동할 때의 판단 순서 {#_18}

1. 같은 검색 의도의 기준문서가 있는가
2. 새 내용은 기존 문서의 한 절로 충분한가
3. 독립 문서가 필요하다면 어느 영역의 어떤 유형인가
4. 어떤 포털·핵심 허브에서 진입해야 하는가
5. 증상·질환·변증·치료·근거 중 어떤 문서와 상호 연결되는가
6. 좌측 메뉴에 필요한가, 검색·색인으로 충분한가
7. 기존 공개 URL과 충돌하거나 중복되지 않는가
8. 이동 뒤 과거 주소·앵커가 대표 본문과 관련 절로 이어지는가
9. 검색·질문 발췌·비교 도구와 AI용 색인에 대표 주소와 출처가 일치하는가

## 안정화 점검표 {#_19}

- [ ] 한 주제의 기준문서가 둘 이상 경쟁하지 않는가
- [ ] 과거 URL이 404가 되지 않고 새 대표 문서로 이어지는가
- [ ] 좌측 메뉴에 다른 분야 문서가 혼입되지 않았는가
- [ ] 세부 문서가 대표 허브에서 발견 가능한가
- [ ] 증상과 질환, 본초와 방제의 역할이 구분되는가
- [ ] 내부 링크 문구가 이동할 내용을 분명히 말하는가
- [ ] URL·제목·앵커 충돌이 없는가
- [ ] 태그가 과도하거나 중복되지 않는가
- [ ] 검색 색인과 사이트맵에 공개 문서가 반영되는가
- [ ] 통합된 근거·확장 문서의 과거 주소가 대표 질환 본문으로 이어지는가
- [ ] 처방 이본의 출전·구성·포제·용량·제형이 구분되는가
- [ ] 탐색 도구·학습 카드·이야기의 출처가 해당 대표 문서와 연결되는가
- [ ] 페이지 제목·대표 주소·본문 앵커가 검색·AI용 자료와 일치하는가
