## 모든 상세 문서의 품질 기준

1. **임상 질문:** 증상 정의, 원인 감별, 치료 선택과 경과를 독자의 질문 순서로 작성한다.
2. **한의학적 치료:** 침·전침·약침·한약을 단순 열거하지 않고 적용 목적, 변증, 치료 단계, 경과 평가를 구분한다.
3. **처방·경혈 연결:** 실제 존재하는 방제·본초·경혈 아틀라스·3D 지도 문서로 직접 연결한다. 없는 경로는 만들지 않는다.
4. **긍정적 근거 소개:** 효과가 관찰된 연구의 질환, 표본 수, 중재, 대조군, 결과척도, 추적기간을 정확하게 기술한다. 통계적 유의성과 임상적 중요성은 구분한다.
5. **근거의 한계:** 무작위시험·체계적 문헌고찰·관찰연구·증례를 구분하고, 이질성·눈가림·편향 위험을 명시한다. 확인하지 못한 PMID/DOI는 기재하지 않는다.
6. **환자 안전:** 응급 위험신호, 표준 초기치료 시기, 검사·협진 필요성을 보존한다.
7. **검색 메타데이터:** 고유한 제목·설명·검색 동의어·명확한 H1/H2와 관련 내부 링크를 점검한다. 제목/설명은 검색 클릭을 위한 과장 문구로 채우지 않는다.
8. **AI 검색 가독성:** 문단 첫머리에 질문에 대한 직접 답을 배치하고, 원전 설명과 현대 임상연구를 분리하며, 참고문헌의 서지정보를 명확히 한다.
9. **색인:** XML 사이트맵의 정규 URL, canonical, noindex, HTTP 상태, 내부 링크, 중복·얇은 문서 여부를 검토한다. 색인 요청 자체는 검색엔진의 수집·노출을 보장하지 않는다.
10. **검증:** 수정 뒤 MkDocs 빌드·내부 링크·앵커·브라우저 검사를 통과한 후 배포한다.

## 연구 보강 시 유의할 점

긍정적인 한의학 연구를 적극 소개하되 치료 효과를 질환 전체에 일반화하지 않는다. 예를 들어 안면마비의 전침 연구에서 단기 기능 지표가 개선되었다면, 이를 모든 환자의 완전 회복률 상승으로 바꾸어 표현하지 않는다. 두통 예방침 연구와 급성 두통 완화 연구는 구별한다. 이명에서는 소리 자체의 크기와 이명으로 인한 고통·수면 개선을 구분한다.

## 검색엔진 후속 점검

- Google Search Console: 페이지 색인 보고서, 사이트맵, URL 검사, 검색 실적의 쿼리/페이지 확인
- Naver Search Advisor: 사이트맵·수집 현황·웹페이지 검색 반영 여부 확인
- 색인 우선순위: 기존 검색 유입이 있는 대표 질환 문서 → 증상 통합 허브 → 경혈·처방 지식망
- 색인 제외 시: 크롤링/색인 상태를 분리하여 원인 확인 후 수정. 반복 색인 요청보다 문서 고유성·내부 연결을 우선 개선
