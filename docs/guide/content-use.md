# 콘텐츠 이용 안내

민성 한의학 아카이브는 한의학 지식을 더 쉽게 찾고 이해할 수 있도록 공개한 지식 아카이브입니다. **개인적인 학습과 열람, 페이지 링크 공유, 출처를 밝힌 통상적인 범위의 인용을 환영합니다.**

## 편하게 이용할 수 있는 범위

- 개인적인 학습과 진료 참고를 위한 열람
- 해당 페이지로 연결되는 링크 공유
- 문맥을 왜곡하지 않는 짧은 인용
- 출처와 원문 URL을 함께 표시한 소개

인용할 때에는 가능하면 다음과 같이 출처를 표시해 주세요.

> 출처: 민성 한의학 아카이브, 「문서 제목」, 원문 URL

## 별도 협의가 필요한 이용

다음과 같이 아카이브의 콘텐츠를 독립적인 자료나 서비스의 주요 구성으로 활용하려는 경우에는 사전에 운영자와 협의해 주세요.

- 문서 전체 또는 상당 부분을 다른 웹사이트·블로그·카페에 옮겨 게시하는 경우
- 책·전자책·강의안·교육상품·홍보물 등에 수록하는 경우
- 유료 서비스나 상업적인 콘텐츠에 활용하는 경우
- 여러 문서를 모아 별도의 데이터베이스나 자료집으로 재구성하는 경우
- 자동화된 방식으로 콘텐츠를 대량 수집·복제·재배포하는 경우

이 안내는 일반적인 검색엔진 노출, 페이지 링크 공유 또는 필요한 범위의 인용을 제한하려는 것이 아닙니다. 아카이브가 오랫동안 안정적으로 운영되고 원문의 출처와 맥락이 유지될 수 있도록 협의를 부탁드리는 취지입니다.

## 아카이브에서 보호되는 부분

개별적인 의학 사실이나 고전 문헌 자체와 별도로, 아카이브에서 작성한 설명·요약·표·비교 방식과 문서의 선택·배열·연결 구조에는 운영자의 편집과 제작 과정이 반영되어 있습니다.

논문·고전 원문·외부 자료·이미지처럼 별도의 출처가 표시된 자료는 해당 원저작자와 제공처의 이용조건을 따릅니다.

## 의료정보 이용 안내

아카이브의 내용은 한의학과 관련 연구를 이해하기 위한 교육·정보 자료입니다. 개인의 진단이나 치료를 대신하지 않으며, 실제 진료에서는 증상과 병력, 검사 결과, 복용약과 치료 경과를 함께 확인해야 합니다.

## 이용 문의

콘텐츠를 교육·출판·연구·서비스에 활용하고 싶다면 [민성한의원 공식 홈페이지](https://www.minseong.co.kr/)를 통해 문의할 수 있습니다. 이용 목적과 범위, 표시할 출처를 알려주시면 확인하기 쉽습니다.
