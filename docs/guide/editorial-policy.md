# 운영 원칙

## 1. 한 문서, 한 개념
한 문서는 가능한 한 하나의 본초·처방·변증·질환·고전·연구 주제를 중심으로 작성합니다.

## 2. 전통 설명과 현대 근거의 분리
고전 및 전통 한의학의 서술은 **전통적 사용과 이론**으로, 현대 연구는 **연구 결과와 근거 수준**으로 명확히 분리합니다.

## 3. 단정적 효능 표현 지양
현대 연구가 제한적이거나 관찰연구·전임상 수준인 경우 이를 임상적 효능으로 단정하지 않습니다.

## 4. 내부링크 우선
본초 ↔ 방제 ↔ 변증 ↔ 질환 ↔ 고전 ↔ 연구가 서로 연결되도록 관련 문서를 적극 링크합니다.

## 5. 출처 추적 가능성
고전은 서명·권차·편명 등 가능한 범위의 출전을, 현대 연구는 저자·연도·저널·PMID·DOI 등을 기록합니다.

## 6. 개정 기록
중요 문서는 `최종 검토일`을 관리하고, GitHub 이력을 통해 변경 내용을 추적합니다.
