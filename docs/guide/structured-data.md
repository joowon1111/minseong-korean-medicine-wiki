# 구조화 데이터 운영 원칙

민성 한의학 아카이브의 핵심 질환 페이지는 사람이 읽는 본문과 함께 검색엔진·AI가 문서의 성격을 이해하기 쉬운 JSON-LD를 제공합니다.

## 기본 관계

`WebSite → MedicalWebPage → MedicalCondition`

각 질환 페이지에는 다음 정보를 명시합니다.

- 문서명
- 설명
- canonical 성격의 공개 URL
- 언어 `ko-KR`
- 상위 사이트 `민성 한의학 아카이브`
- 핵심 질환·증상 주제
- 환자 검색어와 한의학 지식어를 함께 포함한 keywords
- 최근 수정일

## 원칙

구조화 데이터는 본문에 없는 치료효과를 새로 주장하지 않습니다.  
본문과 실제 지식망을 검색엔진과 AI가 더 명확히 해석하도록 보조하는 역할만 합니다.

향후에는 핵심 질환부터 적용한 뒤 본초·방제·경혈 허브로 확장합니다.
