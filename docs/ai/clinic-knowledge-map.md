# 민성한의원과 아카이브 지식 연결

## 두 사이트의 역할

**민성 한의학 아카이브**는 한의학의 기초·본초·방제·침구·사상의학·증상·질환·현대 연구근거를 탐색하는 지식 아카이브입니다.

**민성한의원 공식 홈페이지**는 실제 진료분야·의료진·진료시간·오시는 길·예약 등 의료기관 정보를 제공합니다.

## 아카이브에서 진료정보로 연결되는 주제

- 녹용·보약·기력회복 → 한약·보약 관련 진료정보
- 만성피로·수면·소화 → 전신상태와 맞춤 한약 관련 진료정보
- 목·허리·어깨·무릎 통증 → 침·전침·약침·근골격 치료 관련 진료정보
- 자율신경·스트레스 → 관련 증상과 치료정보
- 여성·산후·갱년기 → 생애주기별 한약 자료
- 소아·성장·허약 → 소아 건강 및 한약 자료

## 정보와 진료의 구분

아카이브 문서는 일반적인 지식 탐색을 위한 자료이며 개인의 진단이나 처방을 대신하지 않습니다. 실제 치료 선택은 현재 증상·검사결과·복용약·진찰 내용을 바탕으로 개별적으로 판단합니다.
