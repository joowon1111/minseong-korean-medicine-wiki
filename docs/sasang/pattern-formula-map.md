# 사상체질 → 병증·처방 지도

사상의학에서는 **체질을 정한 뒤 현재 병증을 다시 구분**한다.

```text
체질
 ↓
소증·현재 증상
 ↓
표리병증
 ↓
한열·경중
 ↓
치법
 ↓
체질 처방
```

## 소양인 처방 연결 예
- 형방도적산
- 형방사백산
- 양격산화탕

핵심은 `체질 = 처방 하나`가 아니라 **체질 + 현재 병증 → 치료 원칙과 처방**이라는 구조다.
