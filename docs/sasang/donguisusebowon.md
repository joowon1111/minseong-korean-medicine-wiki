# 동의수세보원과 사상의학

**동의수세보원(東醫壽世保元)**은 이제마의 사상의학 체계를 이해하는 핵심 고전이다. 태양인·소양인·태음인·소음인의 생리와 병리를 구분하고 체질별 병증과 치료를 체계적으로 설명한다.

```text
동의수세보원
 ↓
사상인
 ↓
체질별 생리·병리
 ↓
표리병증
 ↓
치료 원칙·처방
```
