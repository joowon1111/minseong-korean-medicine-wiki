# 태양인

태양인(太陽人)은 **폐대간소(肺大肝小)**의 장부 기능 편차로 설명되는 사상인입니다.

사상의학에서 상대적으로 드물게 다뤄지는 체질이며, 성격이 적극적이거나 상체가 발달했다는 특징만으로 판단하지 않습니다.

## 한눈에 이해하기

`폐대간소 → 상하·승강의 기능 균형 → 소증 → 원전 병증 → 음식 섭취·하체 기능 변화 → 회복신호`

## 원전 병증을 이해하는 방향

《동의수세보원》에서는 태양인의 독특한 병증 구조를 설명하며 **열격·반위** 등의 전통적 개념이 중요하게 다뤄집니다.

이러한 원전 병증을 현대의 특정 질환명과 바로 동일시하지 않고, 당시 기술된 증상과 병리 구조를 먼저 이해합니다.

## 살펴볼 증상 흐름

- 음식이 잘 내려가지 않는 느낌
- 구역·구토와 섭취 불편
- 체중 변화
- 상체의 긴장과 하체의 안정감
- 보행과 하지 기능의 변화

연하곤란, 지속적 구토, 원인 모를 체중감소, 진행하는 하지 근력저하 등은 체질적 설명보다 현대의학적 평가가 우선됩니다.

## 대표 처방과 원전

태양인 처방은 다른 체질보다 자료가 상대적으로 적으므로 처방 이름을 단순 나열하기보다 **원전 병증과 처방의 연결**을 중심으로 읽습니다.

## 회복·악화 신호

**회복 방향:** 음식 섭취가 편안해짐 · 상체 긴장 감소 · 하체 안정감과 전신 균형 향상  
**악화 방향:** 음식 걸림·구역 증가 · 체중감소 · 하체 기능 저하

## 감별

태양인은 드물다는 통념만으로 배제하거나 외형만으로 쉽게 진단하지 않습니다. 평소 소증, 현재 병증과 원전의 병증 구조를 함께 살펴야 합니다.
