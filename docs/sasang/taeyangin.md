# 태양인(太陽人)

## 기본 장부 구조
**폐대간소(肺大肝小)**

사상의학에서는 태양인을 폐의 기능은 상대적으로 강하고 간의 기능은 상대적으로 약한 체질로 설명한다.

## 전통적 이해
태양인은 호산지기(呼散之氣)가 강하고 흡취지기(吸聚之氣)가 상대적으로 약한 체질적 특징을 지닌다고 설명한다.

이러한 구조는 태양인의 생리·병리와 음식·약물 선택을 이해하는 출발점이 된다.

## 병증을 보는 방향
태양인의 병증은 체질적 장부 균형이 깨지면서 나타나는 여러 증후를 표리병의 구조 안에서 해석한다.

《동의수세보원》에는 태양인의 반위·열격 등과 관련된 독특한 병증과 처방 체계가 제시되어 있다.

## 임상적 의미
태양인은 문헌상 다른 체질보다 드물게 언급되는 체질이다. 따라서 외형이나 성격 한두 가지로 태양인이라고 단정하기보다 **병증과 생리 특성을 포함한 종합적인 체질진단**이 중요하다.
