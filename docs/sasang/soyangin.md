# 소양인

소양인은 사상의학의 네 체질 가운데 하나다. 실제 치료에서는 체질 판별 후에도 현재의 표리병증과 한열·대소변·소화·수면 등의 상태를 함께 살핀다.

대표적인 사상의학 처방 체계에서는 **형방도적산·형방사백산·양격산화탕** 등이 소양인 병증과 연결된다.
