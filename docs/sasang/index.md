# 사상의학

사상의학은 이제마가 《동의수세보원》을 통해 체계화한 한국 고유의 체질의학이다. 사람을 **태양인·태음인·소양인·소음인**의 네 체질로 나누고, 체질마다 장부 기능의 강약과 병리의 경향, 치료 원칙과 처방을 다르게 본다.

- [태음인](taeumin.md)
- [소양인](soyangin.md)
- [소음인](soeumin.md)

## 핵심 특징
사상의학은 단순한 성격 분류가 아니라 **장부 기능, 병증, 생활습관, 약물과 처방을 체질별로 통합하는 맞춤형 의학 체계**다.

같은 증상이라도 체질과 병증에 따라 치료 방향이 달라질 수 있다는 점이 핵심이다.
