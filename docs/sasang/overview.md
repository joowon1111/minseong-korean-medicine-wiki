# 사상체질 개요

《동의수세보원》의 사상의학은 사람을 네 체질로 나누고 **장부 기능의 상대적인 강약**을 중심으로 생리와 병리를 설명한다.

| 체질 | 전통적 장부 특징 |
|---|---|
| [태양인](taeyangin.md) | 폐대간소(肺大肝小) |
| [태음인](taeumin.md) | 간대폐소(肝大肺小) |
| [소양인](soyangin.md) | 비대신소(脾大腎小) |
| [소음인](soeumin.md) | 신대비소(腎大脾小) |

여기서 '대·소'는 단순한 해부학적 크기를 뜻하기보다 **기능적 강약과 체질적 경향을 설명하는 사상의학의 언어**로 이해하는 것이 중요하다.

## 체질은 어떻게 판단하는가
사상체질 진단은 한 가지 특징만으로 결정하지 않는다.

- 체형과 외형
- 용모와 음성
- 성정과 행동 경향
- 소화·땀·대변·수면 등 생리 특성
- 현재의 병증과 치료 반응

을 종합해 판단한다.

현대에는 설문지와 얼굴·체형·음성 데이터를 결합한 진단도구 연구도 진행되어 왔다.

## 체질과 병증
체질은 평생의 기본 틀을 설명하지만 실제 치료에서는 **현재 어떤 표리병증이 나타나는지**가 함께 중요하다.

따라서 '나는 소음인이니 항상 이 처방'처럼 체질명만으로 처방을 기계적으로 선택하는 것은 사상의학의 임상체계와 다르다.
