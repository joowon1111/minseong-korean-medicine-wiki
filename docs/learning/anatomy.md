# 기초 해부학

[기초 한의학 퀴즈 & 학습실](index.md) / **기초 해부학**

**302개 카드 · 1,852문제.** 근육·신경·뼈·혈관·조직의 이름을 외우는 데서 출발해, **어디에 있고 무엇과 연결되며 어떤 기능을 하는지** 설명해 보세요. 의학·치의학·한의학의 기초 해부학을 공부할 때 강의와 실습 범위에 맞춰 사용할 수 있는 자체 학습 자료입니다.

## 무엇을 공부하나요?

| 단원 | 학습 범위 | 직접 확인할 질문 |
|---|---|---|
| 근육 | 주요 근육·근육군 90항목; 목·턱·설골·견갑대·팔·손·복벽·호흡·둔부·하지 | 기시·정지·작용·신경지배와 유사 근육의 차이를 연결할 수 있나요? |
| 신경 | 말초신경·신경얼기·분지 50항목과 뇌신경 12쌍 | 기원·분지·운동·감각과 뇌신경의 머리뼈 통과 경로를 구분할 수 있나요? |
| 뼈와 표지 | 뼈·뼈군·돌기·오목·관절 표지 70항목; 머리뼈·척추·가슴우리·사지 | 서로 비슷한 이름의 구조와 부착 표지를 구분할 수 있나요? |
| 혈관 | 주요 동맥·정맥과 혈관 계통 45항목; 대동맥·사지·복부 장기·문맥·폐순환 | 기원·분지·공급 영역·정맥 합류와 동행 구조를 말할 수 있나요? |
| 조직과 층 | 상피·결합·근육·신경 조직, 피부·근막·근육 내부층 25개 | 형태와 위치를 근거로 조직을 구분할 수 있나요? |

‘구조 식별’은 설명이나 이름을 가린 도해에서 구조 이름을 찾는 연습입니다. 근육 도해는 기존 아카이브의 8개 부위 자료를 사용하고, 조직층 도해에서는 피부·피하조직·깊은근막·근외막·근주막·근내막·골격근을 구분합니다. 뼈·신경·혈관과 세포 형태는 현재 **설명과 학습카드**로 복습합니다.

## 카드와 구조 식별 퀴즈 {#practice}

과목은 ‘기초 해부학’, 단원은 원하는 부위로 선택하세요. 학습 방식에서 **학습카드**, **퀴즈**, **구조 이름 직접 입력**을 고를 수 있습니다. 직접 입력은 한글의 다른 표기와 영문명을 인정하며, 틀리거나 ‘모르겠어요’를 누른 문제는 오답 목록에 남습니다.

<div class="learning-room" data-learning-room data-subject="anatomy"><p>아래 전체 학습 요약에서 구조별 핵심 내용과 참고 자료를 읽을 수 있습니다.</p></div>

## 학습 순서

1. **방향 용어부터 확인:** 안쪽·가쪽, 몸쪽·먼쪽, 앞·뒤, 시상면·관상면·가로면을 기준으로 위치를 말합니다.
2. **근육을 묶어서 회상:** 한 부위의 카드 5~10개를 보고 부착 → 작용 → 신경지배 순서로 말합니다. 회전근개나 허벅지 앞뒤처럼 함께 비교합니다.
3. **설명에서 이름 찾기:** 퀴즈의 ‘설명으로 구조 식별’을 고릅니다. 근육의 작용이나 신경의 분포만 보고 이름을 떠올려 봅니다.
4. **도해에서 구조 찾기:** ‘도해로 구조 식별’에서 주황색 강조 부위를 확인합니다. ‘구조 이름 직접 입력’으로 바꾸면 보기 없이 답할 수 있습니다.
5. **틀린 구조를 다시 연결:** 오답 해설과 구조별 학습 요약을 읽고, 강의 도해·실습 표본에서 같은 구조를 다시 찾아봅니다.

도해는 구조 관계를 단순화한 **자체 제작 교육용 개념도**이며 실제 해부표본·현미경 사진은 포함하지 않습니다. 부위와 층을 나눈 패널이 있으므로 같은 화면의 구조가 모두 한 층에서 동시에 보인다고 해석하지 않습니다. 개별 근육과 근육군을 구분하고, 신경지배의 예외나 여러 갈래로 이루어진 근육은 카드의 설명까지 읽으세요.

## 헷갈리는 구조 함께 비교하기 {#compare-structures}

먼저 부위와 층을 확인하고 **부착 → 작용 → 신경·혈관 연결** 순서로 설명하세요. 아래 링크를 누르면 해당 구조의 상세 요약을 펼쳐 확인할 수 있습니다. 일반적인 해부 관계를 정리한 자료로, 신경 영역은 인접 영역과 겹칠 수 있고 혈관·힘줄·근육 구성에는 변이가 있습니다.
