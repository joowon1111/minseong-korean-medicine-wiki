# 본초학 공부 — 이름에서 배합까지

[기초 한의학 학습실](index.md) / **본초학**

**184개 카드 · 853문제.** 개별 본초 120카드에 비교·감별 64카드를 더해 효능과 기원·부위, 처방 안의 역할을 묶었습니다. 문서에 확인된 항목을 카드에 표시하며 모든 본초에 성미·귀경·생약명 항목이 똑같이 채워진 것은 아닙니다.

## 한 본초를 읽는 다섯 질문

1. **무엇을 쓰는가:** 식물·동물·광물의 기원과 실제 약용 부위를 확인합니다.
2. **어떤 방향인가:** 성미·귀경과 전통 효능을 설명합니다.
3. **어떤 병기를 보는가:** 효능에서 주치로 연결되는 한열·허실·기혈진액을 읽습니다.
4. **처방에서 무엇을 맡는가:** 같은 본초가 다른 배합에서 어떻게 역할이 달라지는지 봅니다.
5. **무엇과 비교해야 하는가:** 비슷한 본초의 공통점과 차이를 원문에서 확인합니다.

퀴즈는 생약명·전통 효능뿐 아니라 원문에 확인된 약용 부위·성미·귀경과 비교군의 상대적 차이를 묻습니다. ‘이름 → 개념·특징’과 ‘설명 → 이름 찾기’를 번갈아 선택해 보세요. 효능은 현대의 특정 약리작용·질환명과 같은 뜻으로 외우지 않고 [효능·주치 표준](../herbal-integrated/efficacy-indication-standard.md)을 함께 읽습니다.

## 비교하며 외울 묶음

| 묶음 | 비교할 질문 | 확인 자료 |
|---|---|---|
| 인삼·황기·백출·산약 | 보기의 공통점 안에서 생진·고표·조습·고삽이 어떻게 다른가 | [보기·보익 본초 비교](../herbal-integrated/herb-comparisons.md) |
| 황련·황금·황백 | 청열조습·사화와 귀경·배합의 강조점은 무엇인가 | [청열약 5분류](../herbal-integrated/heat-clearing-herbs.md) |
| 복령·택사·저령 | 이수삼습 외에 건비·안신·설열이 어떻게 연결되는가 | [택사의 비교표](../herbs/alisma.md) |
| 반하·죽여·천패모·길경 | 조습·청열·윤폐·선폐와 구역·가래의 방향을 구분하는가 | [천패모 비교](../herbs/fritillaria.md) |
| 생지황·숙지황 | 같은 지황 계열의 가공과 전통 효능이 어떻게 다른가 | [생지황](../herbs/rehmannia-root-fresh.md) · [숙지황](../herbs/prepared-rehmannia.md) |
| 계지·육계 / 당귀의 기원종 | 이름이 비슷하거나 번역명이 같을 때 실제 원료를 확인하는가 | [본초 비교·감별](../herbal-integrated/herb-comparisons.md) |

학습 단원은 효능을 중심으로 묶은 **복습용 분류**입니다. 복합 효능을 가진 본초는 다른 단원과도 연결됩니다. 미후등·미후도처럼 문헌의 이름과 식물 기원을 구분해야 하는 항목은 그 불확실성을 카드에 보존했습니다.

## 성미·귀경·효능을 병기와 연결하기 {#efficacy-reasoning}

한 본초를 ‘어떤 질환에 좋은가’로 시작하기보다 **성질과 방향 → 병기 → 처방 속 역할**의 순서로 읽습니다. 성미는 전통적으로 작용을 설명하는 언어이며 실제 맛이나 성분 하나로 효능을 결정하는 규칙이 아닙니다. 귀경은 작용을 설명하는 장부·경맥의 범주이고, 약물이 특정 장기에만 도달한다는 약동학 설명과 구분합니다.

| 연결할 개념 | 구분 질문 | 본초·방제에서 확인 |
|---|---|---|
| 청열조습 / 청열생진 | 습열·탁함을 말리는 방향인가, 열과 진액 손상을 함께 보는가? | 황련·황금·황백의 고한 조습 / 석고·지모의 청열과 진액 고려 |
| 조습화담 / 청열화담 / 윤폐 | 한습·오심인가, 담열인가, 건조·음손인가? | 법제 반하 / 죽여·천패모 / 맥문동·백합을 비교 |
| 건비익기 / 조습건비 | 허약한 운화를 받치는가, 습체를 조절하는 비중이 큰가? | 백출의 사군자탕 / 창출의 평위산 역할 |
| 이수삼습 / 수삽 | 머무는 수습을 배출하는가, 허약으로 새는 것을 거두는가? | 복령·택사 / 오미자·산수유·연자육을 비교 |
| 보혈 / 활혈 / 량혈 | 부족을 보하는가, 어혈을 푸는가, 혈분의 열을 식히는가? | 숙지황·당귀 / 천궁·도인 / 생지황 등. 한 본초에 여러 방향이 겹칠 수 있음 |
| 온리 / 보양 | 중초의 한과 구역·설사인가, 신양·정혈의 허약인가? | 건강의 이중탕 역할 / 육계·녹용 등의 보양·익정 배합 |

열감·냉감, 허약·창만, 건조·습체는 서로 함께 나타날 수 있습니다. 본초를 단일 증상에 대응시키기보다 [효능·주치 표준](../herbal-integrated/efficacy-indication-standard.md)과 [본초 비교·감별](../herbal-integrated/herb-comparisons.md)을 함께 읽어 배합 이유를 설명합니다.

## 약용 부위·가공이 바뀌면 무엇을 다시 확인하나요? {#identity-and-processing}

기원식물의 학명과 약용 부위는 원료를 확인하는 출발점입니다. **기원이 비슷한 약재, 같은 식물의 다른 부위, 가공 전후 약재**를 각각 구분하세요. 가공은 추출·성분·전통적 사용 방향에 영향을 줄 수 있으므로 이름만 같다고 같은 연구 시료로 합치지 않습니다.

| 비교 | 확인할 원료·공정 | 전통적 학습의 초점 |
|---|---|---|
| [계지](../herbs/cinnamon-twig.md) / [육계](../herbs/cinnamon-bark.md) | 가지 / 수피 | 해기·온경통맥과 보화조양·산한의 상대적 비중. 서로 바꾸어 기록하지 않음 |
| [생강](../herbs/fresh-ginger.md) / [건강](../herbs/dried-ginger.md) | 신선한 뿌리줄기 / 건조·가공 원료 | 해표·화위지구와 온중산한의 강조점. 건조했다고 모든 가공품이 같은 건강 규격은 아님 |
| [생지황](../herbs/rehmannia-root-fresh.md) / [숙지황](../herbs/prepared-rehmannia.md) | 생지황 명칭 아래 실제 생품·건조품 구분 / 찌는 등 포제 공정 | 량혈·생진과 보혈·자음익정의 구분. 원료의 수분·가공 상태까지 확인 |
| [감초](../herbs/licorice.md#processing) / 자감초 | 생품 / 보조재·가열법을 기록한 포제품 | 청열·윤폐·조화와 보기·완급의 비중을 처방 문맥에서 읽음 |
| [백출](../herbs/atractylodes.md) / [창출](../herbs/atractylodes-lancea.md) | 각각 적용 공정서의 기원·뿌리줄기 규격 | 포제 전후 비교가 아니라 다른 약재의 비교. 건비익기와 조습건비의 비중 구분 |
| [반하](../herbs/pinellia.md) / 법제 반하 | 원료 동정, 보조재·공정과 제품 규격 | 처방과 연구에 사용한 법제품을 정확히 밝힘. ‘법제했으니 모든 조건에서 안전’으로 해석하지 않음 |

원료 동정·약용 부위·규격은 [식품의약품안전평가원 생약종합정보](https://www.nifds.go.kr/herb/m_442/list.do)에서 확인합니다. 출전의 포제 명칭, 조제기록, 연구 시험물을 나란히 적으면 같은 약재명 아래 섞인 차이를 발견할 수 있습니다.

## 단미 효능에서 짝약·처방의 역할로 {#combination-reasoning}

두 본초가 함께 쓰인다는 사실만으로 현대 약리학의 상승효과가 입증되는 것은 아닙니다. 먼저 배합이 **같은 치료축을 받치는지, 서로 다른 병기를 담당하는지, 한쪽의 방향을 조절하는지** 설명하고, 현대 연구는 사용 시료·비교 설계에 맞춰 별도로 읽습니다.

| 배합 예 | 두 역할을 연결하는 설명 | 처방에서 더 읽기 |
|---|---|---|
| 인삼 + 백출 | 기를 보하는 축과 비위·습을 조절하는 축 | [사군자탕](../formulas/sijunzi-tang.md) |
| 법제 반하 + 진피 | 조습화담·강역과 이기조습을 결합 | [이진탕](../formulas/erchen-tang.md) · [육군자탕](../formulas/liujunzi-tang.md) |
| 계지 + 백작약 | 해기·온통과 영음 조절·완급을 함께 읽음 | [계지탕](../formulas/guizhi-tang.md) |
| 백작약 + 감초 | 유간·완급의 방향을 함께 읽음 | [작약감초탕](../formulas/shaoyao-gancao-tang.md) |
| 황기 + 당귀 | 보기와 보혈을 기혈의 관계로 연결 | [당귀보혈탕](../formulas/danggui-buxue-tang.md); 원방 상대비를 실제 수록본에서 확인 |
| 맥문동 + 오미자 | 음·진액을 기르는 방향과 수렴하여 지키는 방향 | [생맥산](../formulas/shengmai-san.md)에서 인삼의 보기까지 연결 |
| 황련·황금 + 건강 | 한열착잡에서 고한 청열과 신온 온중의 역할을 분담 | [반하사심탕](../formulas/banxia-xiexin-tang.md); 한약을 ‘차다/덥다’ 하나로 평균내지 않음 |

안전성도 배합 전체에서 봅니다. 감초는 여러 처방에 중복될 수 있으므로 **총 노출과 기간, 혈압·부종·칼륨 관련 상태, 병용약**을 함께 확인합니다. 관련 설명은 [감초](../herbs/licorice.md), [NCCIH 감초 안전 정보](https://www.nccih.nih.gov/health/licorice-root), [본초·방제 안전성](../herbal-integrated/safety.md)에 연결됩니다.

## 가까운 본초를 배제하는 질문 {#differential-questions}

공통 효능이 있으면 정답 근거보다 **다른 본초를 덜 적합하게 만드는 조건**을 먼저 찾아 보세요. 기원·부위와 병기·배합의 두 축을 함께 확인합니다.

| 비교 | 공통점 | 갈림점과 다음 질문 |
|---|---|---|
| 인삼·황기 | 보기 | 진액·기력 회복인가, 자한·표허와 고표가 함께인가? 단일 증상으로 확정하지 않음 |
| 백출·창출 | 비·습과 연결 | 보기건비의 바탕인가, 습체 조절의 비중이 큰가? 실제 처방 골격 확인 |
| 복령·저령·택사 | 이수삼습 | 건비·안신, 이수 중심, 설열 방향 등 상대적 역할을 비교 |
| 반하·죽여·천패모 | 담·호흡/위기와 연결 | 한습·조습강역 / 담열·지구 / 청열화담·윤폐의 배합 조건 |
| 생지황·숙지황 | 지황 계열 | 량혈생진 / 보혈자음의 방향과 실제 원료·포제 |
| 오미자·산수유·연자육 | 수렴·고삽의 역할 | 폐·신·비와 진액·정·대변 등 각 처방의 목표를 확인 |

시험물 정보도 감별 조건입니다. **원약재→포제품→추출물→분리 성분→복합처방**은 서로 다른 시험물입니다. 사람 연구 여부, 투여경로·제형·비교군을 붙여 읽고, 전통 효능 이름과 측정한 현대 결과를 따로 기록하세요. [본초 비교표](../herbal-integrated/herb-comparisons.md)와 [연구 연결 표준](../herbal-integrated/efficacy-indication-standard.md#research-translation)에서 근거를 이어 확인합니다.

## 본초 선택 이유 서술형 복습 {#reasoning-practice}

<details markdown="1">
<summary>1. 백출과 창출은 같은 ‘출’이므로 서로 바꿔도 되나요?</summary>

다른 본초로 기원과 규격을 각각 확인합니다. 백출은 건비익기와 조습을 함께, 창출은 조습건비·거풍산한의 비중을 읽습니다. 사군자탕과 평위산에서 각각 어떤 축을 맡는지 설명하면 차이가 더 분명합니다.

</details>

<details markdown="1">
<summary>2. 갈증이 있는 사례를 모두 청열조습약으로 연결하면 무엇이 빠지나요?</summary>

갈증의 맥락이 실열·습열인지, 진액 손상·음허인지, 다른 원인인지 확인해야 합니다. 고한 조습과 청열생진·양음은 역할이 다르므로 열상·건조·습체·대변·전신 상태를 함께 봅니다. 갈증 한 증상이 본초를 결정하지 않습니다.

</details>

<details markdown="1">
<summary>3. 반하가 육군자탕과 반하사심탕에 모두 있어도 두 처방은 같은 방향인가요?</summary>

육군자탕에서는 보기건비 바탕에 화담·강역을 더합니다. 반하사심탕에서는 한열착잡·심하비의 구조 안에서 화위·강역을 읽습니다. 반하 하나의 효능보다 함께 있는 인삼·백출, 황련·황금·건강 등의 배합축이 처방을 구분합니다.

</details>

<details markdown="1">
<summary>4. 생강과 건강의 차이를 수분량만으로 설명하면 충분한가요?</summary>

신선한 원료인지 건조·가공 원료인지 확인한 뒤 전통적 작용의 비중, 공정·규격, 처방 문맥을 함께 봅니다. 생강의 화위지구·해표와 건강의 온중산한을 구분하고 실제 사용한 가공품을 기록합니다.

</details>

<details markdown="1">
<summary>5. 베르베린 세포실험을 황련탕약의 사람 치료효과로 읽어도 되나요?</summary>

분리 성분과 원약재·탕약은 시험물이 다르고, 세포실험과 사람 임상시험은 연구 대상도 다릅니다. 성분·농도·투여경로·제형·비교군·결과를 구분한 뒤 관련성을 설명합니다. [연구 연결 표준](../herbal-integrated/efficacy-indication-standard.md#research-translation)을 다시 읽으세요.

</details>

<details markdown="1">
<summary>6. 감초가 조화제약이면 안전성 확인은 생략할 수 있나요?</summary>

조화제약은 전통적 배합 역할입니다. 감초 노출량·기간과 다른 감초 함유 제품, 혈압·부종·칼륨 및 병용약은 별도 안전성 항목입니다. ‘조화’라는 효능 이름으로 모든 조건의 안전성을 대신하지 않습니다.

</details>

현대 연구에서는 원약재·포제품·추출물·분리 성분과 복합처방을 구분합니다. 기원·규격은 [식품의약품안전평가원 생약종합정보](https://www.nifds.go.kr/herb/m_442/list.do), 실제 적용과 연구 범위는 각 본초 원문의 참고문헌에서 확인하세요.

## 중·상 문제와 보기별 해설 {#advanced-questions}

각 난이도 17문제씩입니다. **중**은 여러 단서와 가까운 개념을 함께 구별하고, **상**은 예외·조건 변화·복수 분류 또는 출전의 차이를 판단합니다. 난이도는 출제 의도에 따른 구분이며 실제 정답률로 보정한 등급은 아닙니다. 퀴즈의 **문제 난이도**에서 선택하거나 아래 문항을 읽어 보세요. 증례·수치는 교육용 가정이고, 제시된 체질·병론 안에서 문헌을 읽는 문제는 체질 판정 검사가 아닙니다.

3. 기원종·부위를 확인해 전통 효능의 일치로 효과량 통합
4. 기원종·부위를 확인해 같은 주요 성분만으로 제제 동등 판정

<details markdown="1">
<summary>정답·보기별 해설 펼치기</summary>

**결정적 감별 단서:** 동명·같은 부위·일부 성분 공통점과 시험물 동일성은 각각 다른 수준이다.

**가장 가까운 오답:** 4번 — 성분 일부의 공통점만으로 전체 조성·규격·노출과 임상적 동등성을 정할 수 없다.

**상 2. 성분·제형·연구 대상을 모두 분리한 결론은?**

황련 유래 분리 성분을 세포배양에 일정 농도로 노출해 지표가 변했다. 전탕 황련 복합방의 사람 임상자료는 제시되지 않았다.

3. 분리 성분의 세포 반응 자료 / 복합방 성분 수로 효과량 보정
4. 분리 성분의 세포 반응 자료 / 전탕 추출률로 사람 용량 환산

<details markdown="1">
<summary>정답·보기별 해설 펼치기</summary>

**결정적 감별 단서:** 성분·농도·모델과 원료·제형·사람 대상의 차이를 동시에 유지한다.

**가장 가까운 오답:** 1번 — 전임상 반응은 기전 가설에 참고할 수 있지만 해당 자료만으로 전탕의 사람 반응을 예측한 결과로 기록할 수 없다.

3. 제품별 총 노출·기간 / 혈압·칼륨·병용약 확인
4. 제품별 총 노출·기간 / 시작 전 혈압·칼륨 확인

<details markdown="1">
<summary>정답·보기별 해설 펼치기</summary>

**상 6. 원방 구성과 효능상 유사성을 구별한 것은?**

두충·속단·우슬·골쇄보를 비교한 뒤 “속단도 근골약이므로 독활기생탕 원방 성분이다”라는 기록을 검토한다.

1. 두충·속단의 보근골 유사성을 원방 구성 판정에 적용
2. 속단의 보근골·속절상 역할과 원방 수록 여부를 분리
3. 우슬·속단의 활혈 유사성을 원방 구성 판정에 적용
4. 골쇄보·속단의 속절상 유사성을 원방 구성 판정에 적용

<details markdown="1">
<summary>정답·보기별 해설 펼치기</summary>

**정답: 2번** — 속단(續斷) — 전통 효능의 유사성·가감 가능성과 원방에 실제 포함된 약재라는 사실을 나누었다.

**결정적 감별 단서:** 효능이 가까운 약재를 고르는 문제와 원방의 약미를 확인하는 문제는 다르다.

**가장 가까운 오답:** 1번 — 효능상 가까워도 속단이 특정 원방에 들어 있는지는 약미 목록으로 따로 확인해야 한다.

3. 택사 공통이므로 저령탕·오령산의 배합축을 동일하게 기록

## 증례·배혈·본초 추론 5지선다 {#clinical-questions}

### 1. 중 · 이 배합에서 우선한 본초는?

2. 백출
3. 창출
4. 복령
5. 의이인

<details markdown="1">
<summary>정답·감별 해설 펼치기</summary>

**결정적 감별 단서:** 창출과 공통인 조습보다 건비익기·지한이라는 추가 역할이 중요하다.

**가장 가까운 오답:** 3번 — 조습건비라는 공통점은 있으나 습체를 말리는 방향이 더 두드러지며 백출의 보기·지한 축과 구별한다.

- **1번:** 이수삼습을 중심으로 읽으며 건비익기·지한과 해당 기원이라는 조건이 다르다.
- **2번:** 건비익기·조습이수·지한을 함께 연결하므로 허약한 비기라는 제시된 배합 문맥에 맞는다.
- **3번:** 조습건비라는 공통점은 있으나 습체를 말리는 방향이 더 두드러지며 백출의 보기·지한 축과 구별한다.

심하의 비만과 음식 정체를 파기·소적의 방향으로 읽는 문헌 배합이다. 시료는 성숙 과피가 아니라 어린 미성숙 열매이며, 대황·후박과 함께 승기계의 행기제만 축을 구성한다. 감귤류 이기약을 구별한다.

1. 사인
2. 향부자
3. 지실
4. 진피
5. 청피

<details markdown="1">
<summary>정답·감별 해설 펼치기</summary>

**정답: 3번** — 지실은 어린 미성숙 열매를 쓰고 파기소적·화담산비를 승기계의 행기제만과 연결한다. 원료 성숙도와 실제 배합이 모두 맞는다.

**결정적 감별 단서:** 미성숙이라는 단어 하나보다 열매 전체의 규격과 승기계 배합 약미를 확인한다.

**가장 가까운 오답:** 5번 — 미성숙 감귤 원료라는 조건은 가까우나 소간파기·소적화체와 과피 규격을 읽으며 제시한 승기계의 지실 배합과 다르다.

- **1번:** 비위의 행기·화습 약재이나 감귤류 어린 열매가 아닌 생강과 식물의 열매이다.
- **2번:** 기체를 다루지만 감귤류 미성숙 열매가 아닌 사초과 뿌리줄기 계통이다.
- **3번:** 지실은 어린 미성숙 열매를 쓰고 파기소적·화담산비를 승기계의 행기제만과 연결한다. 원료 성숙도와 실제 배합이 모두 맞는다.
- **4번:** 감귤류 이기약이나 성숙 과피이며 이기건비·조습화담의 방향을 중심으로 읽는다.
- **5번:** 미성숙 감귤 원료라는 조건은 가까우나 소간파기·소적화체와 과피 규격을 읽으며 제시한 승기계의 지실 배합과 다르다.

### 20. 상 · 백하수오 원료 규격을 이름과 부위로 검토하면?

소음인방의 원료 명세서에서 백하수오를 확인한다. 이름에 수오가 겹친다는 이유로 하수오나 이엽우피소와 동등 원료로 취급하지 않는다. 식약처 생약 규격에 근거한 백수오의 기원·약용부위 조합을 고른다.

1. Cynanchum auriculatum의 덩이뿌리
2. Cynanchum wilfordii의 잎
3. Rehmannia glutinosa의 증숙한 뿌리
4. Cynanchum wilfordii의 덩이뿌리
5. Polygonum multiflorum의 덩이뿌리

<details markdown="1">
<summary>정답·감별 해설 펼치기</summary>

**정답: 4번** — 백수오·백하수오는 Cynanchum wilfordii의 덩이뿌리로 확인한다. 이름이 유사한 별도 기원과 약용부위를 대조한다.

**결정적 감별 단서:** 한글 이름뿐 아니라 기원종과 덩이뿌리라는 두 규격을 모두 대조한다.

**가장 가까운 오답:** 1번 — 같은 속이고 덩이뿌리라는 점은 가까우나 이엽우피소의 기원으로 백수오 규격과 다르다.

- **1번:** 같은 속이고 덩이뿌리라는 점은 가까우나 이엽우피소의 기원으로 백수오 규격과 다르다.
- **2번:** 기원종은 맞지만 약용부위를 잎으로 바꾸어 덩이뿌리 규격을 충족하지 않는다.
- **3번:** 보익 배합의 뿌리 약재라는 점은 비슷하지만 증숙한 지황 뿌리는 숙지황이며 백수오 기원이 아니다.
- **4번:** 백수오·백하수오는 Cynanchum wilfordii의 덩이뿌리로 확인한다. 이름이 유사한 별도 기원과 약용부위를 대조한다.
- **5번:** 덩이뿌리와 수오라는 이름은 가까우나 Polygonum multiflorum은 하수오의 기원으로 백하수오와 다르다.

- **1번:** 시호가 다른 처방에서 맡을 수 있는 승양 역할과 배합약의 양혈 역할을 이 두 문맥에 섞었다.
- **2번:** 시호의 역할을 A의 소양 화해와 B의 간울 해소에 각각 연결한다. 황금과 당귀·작약이라는 배합 문맥이 다르다.

### 22. 중 · 약용 부위와 반하사심탕 안의 청열 배합 역할이 함께 맞는 본초는?

반하사심탕의 한열 병용 구조를 공부한다. 황금과 함께 고한한 청열축을 이루되 약용 부위가 뿌리줄기인 본초를 찾는다. 같은 청열군 본초의 뿌리·껍질·열매와 구별한다.

1. 황련 · 뿌리줄기
2. 황금 · 뿌리
3. 황백 · 줄기껍질
4. 치자 · 열매
5. 용담 · 뿌리와 뿌리줄기

<details markdown="1">
<summary>정답·감별 해설 펼치기</summary>

**정답: 1번** — 황련 · 뿌리줄기 — 황련은 뿌리줄기를 쓰는 고한한 본초로 반하사심탕에서 황금과 청열축을 이룬다.

**결정적 감별 단서:** 청열이라는 공통 효능을 넘어 약용 부위와 처방 안의 짝을 함께 확인한다.

**가장 가까운 오답:** 2번 — 청열축의 배합약은 맞지만 약용 부위는 뿌리이다. 황금과 함께 배합되는 뿌리줄기 본초라는 조건과 다르다.

- **1번:** 황련은 뿌리줄기를 쓰는 고한한 본초로 반하사심탕에서 황금과 청열축을 이룬다.
- **2번:** 청열축의 배합약은 맞지만 약용 부위는 뿌리이다. 황금과 함께 배합되는 뿌리줄기 본초라는 조건과 다르다.

### 23. 중 · 백호탕의 석고·지모 배합을 기원과 역할로 읽은 것은?

백호탕의 두 청열약을 비교한다. A는 광물성 본초이며 강한 기분열을 청하는 중심축, B는 식물의 뿌리줄기이며 청열과 자음의 역할을 함께 읽는다. 전통 방제학의 배합 과제이다.

1. A 지모 · B 석고
2. A 석고 · B 맥문동
3. A 활석 · B 지모
4. A 석고 · B 황련
5. A 석고 · B 지모

<details markdown="1">
<summary>정답·감별 해설 펼치기</summary>

**정답: 5번** — A 석고 · B 지모 — 석고는 광물성 청열약, 지모는 뿌리줄기를 쓰며 청열·자음으로 배합된다. 기원과 역할을 함께 맞춘다.

**결정적 감별 단서:** 광물성이라는 기원만으로 활석과 석고를 같게 보지 않고 백호탕의 실제 기본 구성을 확인한다.

**가장 가까운 오답:** 1번 — 백호탕의 두 약명은 맞지만 광물성과 식물 뿌리줄기 기원을 뒤집었다.

- **1번:** 백호탕의 두 약명은 맞지만 광물성과 식물 뿌리줄기 기원을 뒤집었다.
- **2번:** A는 맞지만 백호탕 기본 구성의 B는 지모이다. 맥문동의 양음생진을 다른 처방 문맥과 섞었다.
- **3번:** B는 맞고 A도 광물성이지만 활석은 이수통림 등의 배합축으로 구별된다. 백호탕의 중심 청열약은 석고이다.
- **4번:** A는 맞지만 황련은 고한 청열조습을 중심으로 하며 백호탕의 지모 자음 배합과 다르다.
- **5번:** 석고는 광물성 청열약, 지모는 뿌리줄기를 쓰며 청열·자음으로 배합된다. 기원과 역할을 함께 맞춘다.

### 24. 중 · 생맥산과 소청룡탕의 오미자를 같은 효능으로 연결하되 전체 처방을 구별한 것은?

생맥산은 인삼·맥문동·오미자, 소청룡탕은 마황·계지·건강·세신 등에 오미자를 배합한다. 같은 열매 본초가 두 처방에 들어갈 때 오미자의 수렴 역할과 각 처방의 다른 배합축을 함께 설명한다.

1. 오미자는 두 처방에서 각각 발산과 청열을 담당한다
2. 생맥산의 오미자는 뿌리, 소청룡탕의 오미자는 열매라서 작용이 다르다
3. 오미자는 소청룡탕의 온화축이므로 생맥산에서도 온폐화음을 중심으로 읽는다
4. 오미자는 수렴축을 공유하지만 생맥산의 익기양음과 소청룡탕의 해표온폐화음은 다르다
5. 오미자는 수렴축을 공유하므로 두 처방 모두 익기양음을 중심으로 읽는다

<details markdown="1">
<summary>정답·감별 해설 펼치기</summary>

**정답: 4번** — 오미자는 수렴축을 공유하지만 생맥산의 익기양음과 소청룡탕의 해표온폐화음은 다르다 — 같은 수렴약이 들어가도 인삼·맥문동과 마황·계지·건강 등의 배합이 달라 전체 처방의 병기·치법은 같지 않다.

**결정적 감별 단서:** 공통 약재의 역할과 전체 처방의 역할은 설명의 범위가 다르다.

**가장 가까운 오답:** 5번 — 생맥산의 구조를 소청룡탕에 그대로 적용했다. 소청룡탕의 외한·내음과 해표·온화의 배합을 놓친다.

- **1번:** 각 처방의 다른 약재가 맡는 배합축을 오미자 자체의 역할로 바꾸었다. 오미자의 수렴 역할과 구별한다.
- **2번:** 두 처방에서 같은 오미자의 약용 부위를 처방에 따라 다르게 바꾸는 설명이다.
- **3번:** 전체 처방의 온화 구조를 오미자 하나의 고유 역할로 옮긴 뒤 생맥산에 재적용했다.
- **4번:** 같은 수렴약이 들어가도 인삼·맥문동과 마황·계지·건강 등의 배합이 달라 전체 처방의 병기·치법은 같지 않다.
- **5번:** 생맥산의 구조를 소청룡탕에 그대로 적용했다. 소청룡탕의 외한·내음과 해표·온화의 배합을 놓친다.

### 25. 상 · 기체와 혈행을 나누어 배합할 때 지정된 이기조경 역할에 더 직접 맞는 본초는?

전통 본초학의 역할 분담 과제이다. 복부 팽만·트림과 월경 전의 긴장으로 표현한 기체축을 먼저 적고, 천궁의 활혈행기축을 별도로 배치한다. 천궁과 마찬가지로 땅속줄기를 쓰지만 소간이기·조경을 중심으로 기록할 약재를 고른다.

1. 목향
2. 백작약
3. 향부자
4. 천궁
5. 당귀

<details markdown="1">
<summary>정답·감별 해설 펼치기</summary>

**정답: 3번** — 향부자 — 뿌리줄기를 쓰며 소간이기·조경을 중심으로 비교한다. 천궁의 활혈행기와 역할이 겹치는 부분을 인정하면서 지정된 기체축에 더 직접 연결한다.

**결정적 감별 단서:** 조경이라는 공통 효능만으로 고르지 않고 약용 부위와 지정된 기체·혈행의 역할 분담을 확인한다.

**가장 가까운 오답:** 4번 — 활혈행기를 겸하고 뿌리줄기를 쓰지만 문항은 천궁과 별도로 소간이기·조경축을 담당할 약재를 묻는다.

- **1번:** 행기지통이라는 공통점이 있으나 뿌리를 쓰며 비위 기체의 배합에서 중심적으로 읽는다.
- **2번:** 양혈유간·완급의 역할과 뿌리 부위로 구별한다. 소간이기하는 뿌리줄기 약재와 다르다.
- **3번:** 뿌리줄기를 쓰며 소간이기·조경을 중심으로 비교한다. 천궁의 활혈행기와 역할이 겹치는 부분을 인정하면서 지정된 기체축에 더 직접 연결한다.
- **4번:** 활혈행기를 겸하고 뿌리줄기를 쓰지만 문항은 천궁과 별도로 소간이기·조경축을 담당할 약재를 묻는다.
- **5번:** 양혈활혈·조경을 중심으로 하며 뿌리를 쓴다. 지정된 뿌리줄기·소간이기 조건과 다르다.

### 26. 상 · 해표와 생진·승양지사의 연결을 약용 부위까지 바르게 설명한 것은?

표증에서 항배부의 뻣뻣함을 푸는 역할과, 다른 배합에서 생진·승양지사를 연결해 공부하고 있다. 이 효능 연결을 뿌리 약재의 설명으로 기록하려 한다. 처방 전체의 작용을 단미 효능으로 확대하지 않는다.

1. 계지 · 어린 가지 · 해기·온경통맥
2. 갈근 · 뿌리 · 해기·생진·승양지사
3. 승마 · 뿌리줄기 · 해표·승양거함
4. 시호 · 뿌리 · 화해소양·소간해울
5. 마황 · 지상 줄기 · 발한해표·선폐

<details markdown="1">
<summary>정답·감별 해설 펼치기</summary>

**정답: 2번** — 갈근 · 뿌리 · 해기·생진·승양지사 — 갈근은 뿌리를 쓰며 항배부 긴장과 해기, 생진·승양지사의 전통 효능을 연결해 읽는다.

**결정적 감별 단서:** 해표군 안에서도 항배·생진·승양지사의 효능 연결과 뿌리라는 부위를 함께 확인한다.

**가장 가까운 오답:** 3번 — 해표·승양이라는 일부 역할은 비슷하지만 부위가 뿌리줄기이고 갈근의 항배·생진·지사 연결과 구별된다.

- **1번:** 해기라는 표현은 공유하지만 어린 가지를 쓰며 갈근의 뿌리·생진·승양지사 연결과 다르다.
- **2번:** 갈근은 뿌리를 쓰며 항배부 긴장과 해기, 생진·승양지사의 전통 효능을 연결해 읽는다.
- **3번:** 해표·승양이라는 일부 역할은 비슷하지만 부위가 뿌리줄기이고 갈근의 항배·생진·지사 연결과 구별된다.
- **4번:** 뿌리 약재와 승양 관련 역할을 공유할 수 있으나 이 문항의 항배·생진·승양지사 조합은 갈근이다.
- **5번:** 해표 역할은 공유하지만 약용 부위와 생진·승양지사 조건이 다르다.

### 27. 상 · 비슷한 종자류 본초를 처방 안의 역할로 구별한 기록은?

A는 도핵승기탕·혈부축어탕에서 어혈을 다루는 배합과 윤장 역할을 연결한다. B는 마황탕에서 기침·천을 다루는 선폐 배합을 읽는다. 두 본초 모두 종자류라는 공통점보다 처방의 배합 목적을 우선한다.

1. A 도인 · B 행인
2. A 행인 · B 도인
3. A 도인 · B 오미자
4. A 홍화 · B 행인
5. A 마자인 · B 행인

<details markdown="1">
<summary>정답·감별 해설 펼치기</summary>

**정답: 1번** — A 도인 · B 행인 — 도인은 활혈거어·윤장, 행인은 기침·천의 폐기 조절과 윤장으로 비교한다. 같은 종자류·윤장 역할이 있어도 처방의 중심 배합은 다르다.

**결정적 감별 단서:** 윤장과 종자라는 공통점 안에서 활혈거어·폐기 조절 및 실제 처방 구성으로 나눈다.

**가장 가까운 오답:** 2번 — 종자류·윤장 공통점에만 맞추어 활혈거어와 선폐 배합의 대응을 뒤집었다.

- **1번:** 도인은 활혈거어·윤장, 행인은 기침·천의 폐기 조절과 윤장으로 비교한다. 같은 종자류·윤장 역할이 있어도 처방의 중심 배합은 다르다.
- **2번:** 종자류·윤장 공통점에만 맞추어 활혈거어와 선폐 배합의 대응을 뒤집었다.
- **3번:** A는 맞지만 오미자는 열매를 쓰는 수렴약이다. 마황탕의 선폐 배합약으로 지정된 B는 행인이다.
- **4번:** B는 맞고 홍화도 활혈약이지만 꽃을 쓴다. 제시한 종자류 A와 도핵승기탕의 기본 구성에 맞지 않는다.
- **5번:** B는 맞고 마자인도 윤장 종자류지만 활혈거어를 중심으로 도핵승기탕·혈부축어탕에 배합되는 A는 도인이다.

### 28. 상 · 향사육군자탕의 두 방향성 본초를 부위와 역할로 구별한 것은?

향사육군자탕의 보기·화담 골격에 더해지는 두 약재를 비교한다. A는 Amomi Fructus로 표기되는 사인류의 열매·종자 덩어리 원료이고, B는 목향의 뿌리이다. 두 본초의 중심 역할을 서로 바꾸지 않고 기록한다.

1. A 행기지통 · B 화습개위·온비지사
2. A 보기건비 · B 행기지통
3. A 화습개위·온비지사 · B 양혈활혈
4. A 청열조습 · B 하기제만·조습
5. A 화습개위·온비지사 · B 행기지통

<details markdown="1">
<summary>정답·감별 해설 펼치기</summary>

**정답: 5번** — A 화습개위·온비지사 · B 행기지통 — 사인은 화습개위·온비지사를, 목향은 행기지통을 중심으로 비교한다. 실제 원료의 기원·규격은 별도로 확인한다.

**결정적 감별 단서:** 방향성·소화 배합이라는 공통점보다 사인 열매류의 화습·온비와 목향 뿌리의 행기 역할을 나눈다.

**가장 가까운 오답:** 1번 — 공통된 기체 조절만 보고 두 본초의 중심 역할을 뒤집었다. 사인의 화습·온비축과 목향의 행기지통을 구별한다.

- **1번:** 공통된 기체 조절만 보고 두 본초의 중심 역할을 뒤집었다. 사인의 화습·온비축과 목향의 행기지통을 구별한다.
- **2번:** B는 맞지만 A의 중심 역할을 백출 등의 보기건비축으로 바꾸었다. 사인은 보익약과 함께 배합되는 화습·온비약이다.
- **3번:** A는 맞지만 목향의 행기지통을 당귀 등의 양혈활혈 역할로 바꾸었다.
- **4번:** 한습·비위 배합의 사인을 고한 청열약으로 읽고 목향을 후박의 중심 설명과 섞었다.
- **5번:** 사인은 화습개위·온비지사를, 목향은 행기지통을 중심으로 비교한다. 실제 원료의 기원·규격은 별도로 확인한다.

</details>
