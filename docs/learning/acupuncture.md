[기초 한의학 학습실](index.md) / **침구학**

## 같은 혈에 겹치는 분류와 배혈의 목적 {#classification-and-pairing}

특정혈은 서로 배타적인 이름표가 아닙니다. **오수혈은 정·형·수·경·합의 단계**, 원·낙은 원기·표리 연결, 팔회는 조직·기능 범주, 하합은 육부 연결이라는 다른 분류축입니다. 한 혈의 여러 속성을 읽은 뒤 어떤 속성을 근거로 조합했는지 설명합니다.

| 혈 | 겹치는 분류 | 비교하면서 확인할 점 |
|---|---|---|
| LU9 태연 | 폐경 수혈(兪)·원혈·맥회 | ‘수혈’과 ‘원혈’이 겹치지만 팔회혈이라는 질문에는 맥회로 답함 |
| LR3 태충 | 간경 수혈(兪)·원혈 | 음경의 수혈·원혈 일치 관계를 확인 |
| LI3 삼간 / LI4 합곡 | 대장경 수혈(兪) / 원혈 | 양경에서는 수혈·원혈이 별도 혈이라는 대비 |
| GB34 양릉천 | 담경 합혈·담 하합혈·근회 | 합혈과 하합혈이 이 혈에서는 겹침 |
| LI11 곡지 / ST37 상거허 | 대장경 합혈 / 대장 하합혈 | 하합혈의 소속 경맥과 연결되는 육부는 다를 수 있음 |
| SP4 공손 | 비경 낙혈·충맥 팔맥교회혈 | PC6 내관과의 짝을 설명할 때는 팔맥 연결을 사용 |

[특정혈 통합표](../acupuncture-specific/special-points-atlas.md)에서 같은 혈을 세로로 따라 읽고, [오수혈 표](../acupuncture-specific/five-shu.md)에서는 같은 경맥을 가로로 비교하세요.

### 배혈을 구성에서 설명하는 연습

| 학습용 조합 | 설명할 원리 | 헷갈리기 쉬운 조합 |
|---|---|---|
| LU9 태연 + LI6 편력 | 폐경 원혈 + 표리인 대장경 낙혈의 원락배혈 | LU9 + LU7은 같은 폐경의 원·낙혈이며 이 예와 표리 구조가 다름 |
| LI4 합곡 + LU7 열결 | 대장경 원혈 + 표리인 폐경 낙혈 | 원락배혈은 어느 경맥을 중심으로 보는지에 따라 원혈·낙혈의 방향이 달라짐 |
| BL21 위수 + CV12 중완 | 같은 위(胃)에 연결되는 배수·모혈의 수모배혈 | 앞·뒤에 있는 두 혈을 임의로 고르는 것이 아님 |
| SP4 공손 + PC6 내관 | 충맥 + 음유맥의 팔맥교회혈 짝 | 비경과 심포경은 12정경의 표리 짝이 아님 |
| 국소 아시혈 + 관련 원위혈 | 통증 부위의 조직과 원위 경혈을 연결하는 원근배혈 | ‘국소’와 ‘원위’는 증상 부위에 대한 관계이며 고정 혈 분류가 아님 |

위 조합은 분류 원리를 설명하는 학습 예입니다. 실제 치료에서는 통증·기능·병증과 해부학적 조건에 맞춰 혈을 정하고 반응을 재평가합니다. [배혈 원리](../acupuncture-specific/pairing-principles.md)에서 팔맥 짝과 다른 배혈법을 이어서 비교합니다.

## 치료 목표에서 자극·평가로 이어가기 {#treatment-reasoning}

배혈 이름을 말한 다음에는 **무엇을 변화시키려는지 → 어떤 조직·혈을 선택했는지 → 어떤 자극을 사용했는지 → 무엇으로 변화를 확인하는지**를 연결합니다. 치료수단의 차이는 목표 조직과 자극·제제·온열·음압의 차이로 읽습니다.

| 판단 단계 | 통증·운동 제한 학습 사례에서 묻는 질문 | 기록할 내용 |
|---|---|---|
| 평가 | 아픈 위치 외에 어떤 움직임이 제한되는가? | 휴식·활동 시 통증, 가동범위, 일상 기능, 감각·근력 |
| 부위 선택 | 경혈·아시혈·근육 중 어떤 구조를 근거로 삼았는가? | 좌우·부위·해부학적 층과 국소·원위의 역할 |
| 수단 선택 | 수기침·전침·약침·뜸·부항이 목표에 어떻게 연결되는가? | 수기 / 전류 경로·파형 / 제제·주입층 / 온열 / 음압 |
| 치료량 | 반복 횟수·치료기간과 자극량을 설명할 수 있는가? | 유침시간·회차·간격, 병용 운동·교육 |
| 재평가 | 통증 점수 외에 기능 변화가 있는가? | 같은 동작의 범위·활동·수면, 치료 뒤 및 다음날 반응 |

전침의 주파수만으로 치료효과를 확정하지 않고 강도·파형·전극·시간과 대상 상태를 함께 읽습니다. 약침은 제제의 성분·품질·투여 부위·알레르기 이력을 기록합니다. 뜸·부항은 감각과 피부 상태에 맞춰 온열·음압의 강도를 살핍니다. 자세한 연결은 [치료수단 지도](../acupuncture-integrated/modalities.md), [임상해부학](../clinical-anatomy/index.md), [안전과 재평가](../acupuncture-integrated/safety.md)에서 확인합니다.

## 연구의 차이를 읽는 구체적 질문 {#research-reasoning}

침 연구를 읽을 때 ‘유의하다’는 결론보다 **어떤 두 조건을 비교했는지, 차이가 얼마나 큰지, 기능에도 변화가 있는지**를 먼저 묻습니다. 가짜침의 부위·접촉·관통 여부가 달라지면 비교가 분리하려는 자침 요소도 달라집니다. 시술자 눈가림, 기대와 병용치료의 영향도 설계에 맞춰 살핍니다.

예를 들어 통증 0–10점 척도에서 평균 군간 차이가 −1.0점, 95% 신뢰구간이 −1.8~−0.2점이었다고 가정해 보세요. 이 **교육용 가상 수치**는 차이의 방향과 불확실성 범위를 보여줍니다. 그것만으로 모든 환자에게 1점 개선을 보장하거나 개인의 치료 전후 변화와 같은 값으로 해석하지 않습니다. 임상적 의미는 척도·질환·기준점·기능 변화와 함께 판단합니다.

[STRICTA 원문](https://journals.plos.org/plosmedicine/article?id=10.1371/journal.pmed.1000261)은 침 치료의 근거, 자침 세부사항, 치료 일정, 병용 요소, 시술자 배경, 비교중재를 보고하도록 안내합니다. **보고 항목이 충실하다는 것과 치료효과가 입증되었다는 것은 별개의 평가**입니다. [침구 연구 읽기](../acupuncture-integrated/evidence.md)의 비교군·근거 종류와 연결해 읽으세요.

## 분류·배혈·연구 서술형 복습 {#reasoning-practice}

<details markdown="1">
<summary>1. 음경의 수혈과 원혈 관계를 양경에도 그대로 적용하나요?</summary>

음경의 오수혈 수혈(兪)은 원혈과 겹치지만 양경의 원혈은 별도로 있습니다. 예를 들어 LR3 태충은 간경 수혈·원혈이고, 대장경은 LI3 삼간이 수혈, LI4 합곡이 원혈입니다.

</details>

<details markdown="1">
<summary>2. 대장경 합혈과 대장 하합혈은 어디인가요?</summary>

LI11 곡지와 ST37 상거허입니다. 대장 하합혈이 위경에 속한다는 점을 함께 답합니다. ‘소속 경맥’과 ‘하합혈로 연결되는 육부’를 분리해서 읽어야 합니다.

</details>

<details markdown="1">
<summary>3. 폐경 중심의 원락배혈을 원혈·낙혈까지 설명해 보세요.</summary>

LU9 태연은 폐경 원혈, LI6 편력은 표리인 대장경 낙혈입니다. 같은 폐경 낙혈인 LU7 열결을 연결한 경우와 구성을 구분합니다. 조합의 실제 적용은 병증과 치료 목표를 확인하는 다음 단계입니다.

</details>

<details markdown="1">
<summary>4. 공손·내관을 표리경 배혈이라고 설명하면 무엇이 빠지나요?</summary>

SP4·PC6은 각각 충맥·음유맥의 팔맥교회혈 짝입니다. 비경과 심포경은 12정경 표리 관계가 아니므로 팔맥 연결을 설명해야 합니다. SP4의 낙혈 속성과 PC6의 낙혈 속성도 이 조합의 기경 설명과 구분합니다.

</details>

<details markdown="1">
<summary>5. 통증은 줄었는데 움직임은 그대로라면 무엇을 더 기록하나요?</summary>

같은 동작의 가동범위와 기능, 활동량·수면, 감각·근력, 치료 후 지속시간을 함께 기록합니다. 통증과 기능은 서로 다른 결과지표이며 한 값만으로 치료 목표 전체의 달성을 판단하지 않습니다.

</details>

<details markdown="1">
<summary>6. 침+운동군과 운동 단독군 연구에서 무엇을 비교하나요?</summary>

해당 운동 프로그램에 침을 추가한 효과를 비교합니다. 침 단독의 효과, 다른 운동과의 병용, 모든 질환에서의 효과로 바로 넓히지 않습니다. 두 군의 운동·치료량·병용약과 추적기간을 확인합니다.

</details>

## 상·극상 문제와 보기별 해설 {#advanced-questions}

각 난이도 10문제씩입니다. **상**은 여러 단서와 가까운 개념을 함께 구별하고, **극상**은 예외·조건 변화·복수 분류 또는 출전의 차이를 판단합니다. 난이도는 출제 의도에 따른 구분이며 실제 정답률로 보정한 등급은 아닙니다. 퀴즈의 **문제 난이도**에서 선택하거나 아래 문항을 읽어 보세요. 증례·수치는 교육용 가정이고, 제시된 체질·병론 안에서 문헌을 읽는 문제는 체질 판정 검사가 아닙니다.

### 상 · 통합·감별 10문제

<span id="advanced-acupuncture-high-01"></span>

**상 1. 폐경을 중심으로 한 원락배혈과 폐경 내부 원·낙 암기를 나눈 것은?**

표리경의 낙혈을 결합한다는 원락배혈 정의를 적용한다.

1. 원락: LU9+LI6 / 같은 경맥: LU9+LU7
2. 원락: LU9+LU7 / 같은 경맥: LU9+LI6
3. 원락: LI4+LI6 / 같은 경맥: LU9+LU6
4. 원락: LU7+LI4 / 같은 경맥: LU9+LI6

<details markdown="1">
<summary>정답·보기별 해설 펼치기</summary>

**정답: 1번** — 폐 LU 원·낙·극 — 폐 원혈에 대장 낙혈을 붙인 경우와 폐 원·낙만 묶은 경우를 구별했다.

- **1번 (정답):** 폐 원혈에 대장 낙혈을 붙인 경우와 폐 원·낙만 묶은 경우를 구별했다.
- **2번 (오답):** 표리 원락과 같은 경맥 조합을 반대로 붙였다.
- **3번 (오답):** 앞 조합은 대장 원·낙, 뒤는 폐 원·극이다.
- **4번 (오답):** 대장 중심 원락을 폐 중심으로 읽었으며 뒤 조합도 같은 경맥이 아니다.

[연결 학습 원문](/acupuncture-specific/special-points-atlas/)

**상 10. 군간 차이와 개별 환자 변화량을 구별한 설명은?**

**극상 4. 요소를 분리한 해석에 가장 적합한 것은?**

A는 경혈 관통 자침, B는 같은 부위 비관통 피부접촉이며 일정·설명은 유사하다. B도 감각 입력과 기대를 유발할 수 있다.

1. A–B는 경혈 위치만의 차이를 분리함
2. A–B는 전기 자극의 차이를 분리함
3. A–B는 침 치료 전체와 치료를 전혀 안 받는 조건의 차이
4. A–B는 그 비교 조건에서 추가되는 관통 등 요소의 차이이며 B의 무활성을 전제하지 않음

<details markdown="1">
<summary>정답·보기별 해설 펼치기</summary>

**정답: 4번** — 침 vs 가짜침 — 접촉 대조도 반응을 만들 수 있고 중재·눈가림의 실제 차이를 읽어야 한다.

- **1번 (오답):** 두 군은 같은 부위여서 경혈 위치 자체를 대조한 설계가 아니다.
- **2번 (오답):** 전침이 제시되지 않아 전류 효과를 분리하지 않는다.
- **3번 (오답):** B는 접촉·설명·방문을 받으므로 무치료 비교와 다른 질문이다.
- **4번 (정답):** 접촉 대조도 반응을 만들 수 있고 중재·눈가림의 실제 차이를 읽어야 한다.

[연결 학습 원문](/acupuncture-integrated/evidence/)

</details>

<span id="advanced-acupuncture-expert-05"></span>

**극상 5. 교차 비교를 피하면서 두 효과를 해석한 것은?**

가상 시험: 침+통상치료군은 통증 6→3, 통상치료군은 6→4다. 여기서는 단순 평균 변화 차이만 계산하며 통계적 유의성 자료는 없다.

1. 군내 개선 3점 / 개선량의 군간 차이 1점 / 유의성은 미판정
2. 군내 개선 3점 / 군간 차이 3점 / 유의함
3. 군내 개선 1점 / 군간 차이 3점 / 유의성 미판정
4. 군내 개선 3점 / 군간 차이 1점 / 모든 환자 1점 개선

<details markdown="1">
<summary>정답·보기별 해설 펼치기</summary>

**정답: 1번** — 무작위 임상시험 — 자연경과·기반 치료가 포함된 군내 변화와 추가 중재의 평균 차이를 구분했다.

- **1번 (정답):** 자연경과·기반 치료가 포함된 군내 변화와 추가 중재의 평균 차이를 구분했다.
- **2번 (오답):** 대조군의 2점 개선을 빼지 않았고 유의성도 자료 없이 확정했다.
- **3번 (오답):** 군내 변화와 군간 개선량 차이를 뒤바꿨다.
- **4번 (오답):** 계산은 맞지만 집단 평균 차이를 모든 개인에게 적용했다.

[연결 학습 원문](/acupuncture-integrated/evidence/)

<span id="advanced-acupuncture-expert-06"></span>

**극상 6. 주효과와 기능 결과·지속성을 분리한 결론은?**

가상 연구에서 통증 차이 −0.4(95% CI −0.7~−0.1), 사전 임상적 중요 기준 1.0점이다. 기능 CI는 0을 포함하며 장기 추적은 없다.

1. 기능 CI가 0을 포함하므로 두 치료의 동등성이 증명됨
2. 통증 차이는 통계적이지만 1점 기준에 못 미침; 기능·장기 효과는 확정 못함
3. 통증이 유의하므로 기능·장기 효과도 임상적으로 중요함
4. 통증이 기준 미만이므로 통계적으로도 차이가 없음

<details markdown="1">
<summary>정답·보기별 해설 펼치기</summary>

**정답: 2번** — 결과 — 유의성·효과 크기·다른 지표·추적 범위의 네 판단을 구분했다.

- **1번 (오답):** 차이 미검출은 사전 동등성 한계와 검정 없이 동등성 증명이 되지 않는다.
- **2번 (정답):** 유의성·효과 크기·다른 지표·추적 범위의 네 판단을 구분했다.
- **3번 (오답):** 통계적 차이를 임상적 크기와 다른 결과까지 확장했다.
- **4번 (오답):** 임상적 중요 기준과 0을 포함하는지의 통계 기준은 다르다.

[연결 학습 원문](/acupuncture-integrated/evidence/)

<span id="advanced-acupuncture-expert-07"></span>

**극상 7. 해당 설계에서 가장 정확한 효과 귀속은?**

가상 시험에서 A는 침+운동+교육, B는 통상치료만 받는다. A의 기능 결과가 더 좋다. 운동·교육을 양 군에 똑같이 제공하지 않았다.

1. 침 단독의 효과가 프로그램 전체 차이와 같음
2. 무작위배정이 있으므로 병용 요소 차이는 자동 제거됨
3. 그 복합 프로그램의 비교 효과로 해석하고 침 단독 효과 분리는 보류
4. 운동이 들어갔으므로 침의 효과는 반드시 0

<details markdown="1">
<summary>정답·보기별 해설 펼치기</summary>

**정답: 3번** — 병용치료 — 세 중재 요소가 함께 달라져 침만의 기여를 직접 떼어낼 수 없다.

- **1번 (오답):** 운동·교육의 차이와 상호작용 가능성을 무시했다.
- **2번 (오답):** 무작위배정은 설계된 복합중재의 차이를 침 하나의 효과로 분해하지 않는다.
- **3번 (정답):** 세 중재 요소가 함께 달라져 침만의 기여를 직접 떼어낼 수 없다.
- **4번 (오답):** 복합 설계는 각 요소 효과가 없음을 증명하지 않는다.

[연결 학습 원문](/acupuncture-integrated/evidence/)

<span id="advanced-acupuncture-expert-08"></span>

**극상 8. 서로 다른 자극 조건과 지표를 비교할 때 우선 기록할 것은?**

두 전침군에서 통증은 비슷하게 줄었으나 A만 기능이 호전됐다. A는 강도·전극 배치·운동 병용도 B와 다르다.

1. 통증이 같으므로 기능 차이는 존재하지 않음
2. A의 주파수만이 기능 개선을 만들었다고 확정
3. 기능 차이가 있으므로 통증 결과는 보고에서 제외
4. 기능·통증·반응 시점과 변경된 세 조건을 함께 기록; 주파수 단독 귀속은 보류

<details markdown="1">
<summary>정답·보기별 해설 펼치기</summary>

**정답: 4번** — 전침 재평가 — 여러 조건 차이를 남기고 결과지표를 분리해야 차이의 원인을 검토할 수 있다.

- **1번 (오답):** 서로 다른 결과지표가 다른 양상으로 변할 수 있다.
- **2번 (오답):** 강도·배치·병용 운동이 달라 단일 조건으로 귀속할 수 없다.
- **3번 (오답):** 계획된 결과를 함께 보고해야 선택적 결과 제시를 피할 수 있다.
- **4번 (정답):** 여러 조건 차이를 남기고 결과지표를 분리해야 차이의 원인을 검토할 수 있다.

<span id="advanced-acupuncture-expert-09"></span>

**극상 9. 안전성 보고에서 분모·단위·누락을 함께 처리한 것은?**

가상 기록: 100명에게 600회 치료, 멍 12건. 멍이 생긴 고유 환자 수는 기록하지 않았다. 추적에서 10명은 빠졌다.

1. 보고된 치료 600회당 멍 12건; 환자 비율·누락자 반응은 별도 미상
2. 환자의 정확히 12%가 멍을 경험함
3. 추적 누락자 10명은 무사건이므로 안전성 평가에 영향 없음
4. 600회 분모로 모든 장기 이상반응 위험이 확정됨

<details markdown="1">
<summary>정답·보기별 해설 펼치기</summary>

**정답: 1번** — 안전성 — 사건·환자·회차 분모가 다르며 빠진 추적자료를 무사건으로 처리하지 않는다.

- **1번 (정답):** 사건·환자·회차 분모가 다르며 빠진 추적자료를 무사건으로 처리하지 않는다.
- **2번 (오답):** 같은 사람의 반복 사건일 수 있어 12건을 12명으로 바꿀 수 없다.
- **3번 (오답):** 누락자는 관측되지 않은 반응이 있어 자동 무사건 처리할 수 없다.
- **4번 (오답):** 보고된 단기 사건률이 미관측 장기 위험을 확정하지 않는다.

<span id="advanced-acupuncture-expert-10"></span>

**극상 10. 사전 주결과와 탐색 결과를 정확히 분리한 것은?**

가상 RCT: 사전 주결과는 12주 기능, 차이가 불확실하다. 부차 결과 20개 중 1주 통증만 p<0.05이며 다중비교 보정은 없다.

1. 주결과가 불확실하므로 모든 부차 효과가 정확히 0
2. 12주 주결과의 불확실성을 먼저 보고하고 1주 통증은 탐색 신호로 읽음
3. 1주 통증을 새 주결과로 바꿔 시험 성공으로 확정
4. 유의 결과가 하나라도 있으므로 12주 기능도 개선됨

<details markdown="1">
<summary>정답·보기별 해설 펼치기</summary>

**정답: 2번** — 결과 — 시점·위계·다중비교를 구분해 하나의 유의 결과를 전체 성공으로 바꾸지 않는다.

- **1번 (오답):** 불확실한 주결과는 다른 결과의 무효를 증명하지 않는다.
- **2번 (정답):** 시점·위계·다중비교를 구분해 하나의 유의 결과를 전체 성공으로 바꾸지 않는다.
- **3번 (오답):** 결과를 본 뒤 주결과를 바꾸면 사전 질문과 보고가 어긋난다.
- **4번 (오답):** 다른 시점·지표의 결과를 주결과로 대체했다.
