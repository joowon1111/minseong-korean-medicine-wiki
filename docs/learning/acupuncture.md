# 침구학 공부 — 특정혈에서 연구 읽기까지

## 헷갈리기 쉬운 관계

| 비교 | 구분 기준 |
|---|---|
| 수혈(兪) / 배수혈(背兪) | 오수혈의 한 단계와 장부의 등쪽 배수혈을 구분 |
| 원락배혈 / 같은 경맥 원·낙 암기 | 원락배혈은 한 경맥의 원혈과 **표리경**의 낙혈을 연결 |
| 팔회혈 / 팔맥교회혈 | 조직·기능 범주의 회혈과 기경팔맥에 연결된 혈을 구분 |
| 수모배혈 / 원근배혈 | 같은 장부의 배수·모혈과 근위·원위 조합을 구분 |
| 침 vs 무치료 / 침 vs 가짜침 | 치료를 받는 전체 효과와 특정 자침 요소의 비교 질문을 구분 |

[배혈 원리](../acupuncture-specific/pairing-principles.md)와 [연구의 비교군](../acupuncture-integrated/evidence.md)에서 각각의 정의를 확인하세요. 실제 자침에는 [임상해부학](../clinical-anatomy/index.md), [안전·위험신호](../acupuncture-integrated/safety.md), 치료 목표·기능 평가가 연결됩니다.

<summary>특정혈 개념 · 9개 카드</summary>

**원혈**

- **전통적 정의:** 각 경맥의 원기와 관련된 특정혈
- **연결:** 해당 장부·경맥

[원문에서 확인](/acupuncture-specific/pairing-principles/)

**낙혈**

- **전통적 정의:** 표리 경맥을 연결하는 낙맥의 대표혈
- **연결:** 원락배혈

[원문에서 확인](/acupuncture-specific/pairing-principles/)

**극혈**

- **전통적 정의:** 기혈이 깊이 모이는 곳으로 설명되는 혈
- **연결:** 급성·통증성 병증

[원문에서 확인](/acupuncture-specific/pairing-principles/)

**배수혈**

- **전통적 정의:** 방광경상의 장부 배수혈
- **연결:** 장부 병증의 등쪽 접근

[원문에서 확인](/acupuncture-specific/pairing-principles/)

**모혈**
