# 기초 한의학 퀴즈 & 학습실

한의학을 처음 접하는 사람부터 한의대 과목을 복습하는 학생까지, **구조·위치·분류·효능·배합을 설명할 수 있는지** 확인해 보세요. 민성 한의학 아카이브의 문서와 도해를 연결한 **학습카드 1,281개 · 해설형 문제 5,924개**로 다섯 과목을 공부할 수 있습니다. 회원가입 없이 바로 시작할 수 있습니다.

## 바로 복습하기 {#practice}

과목과 단원을 고른 뒤 카드를 뒤집거나 퀴즈를 풀어 보세요. 틀린 문제는 **오답 다시 풀기**, 헷갈린 카드는 **다시 볼 카드**, 남겨 둘 자료는 **북마크 카드**에서 모아 볼 수 있습니다.

<div class="learning-room" data-learning-room>
<p>학습 도구를 준비하고 있습니다. 실행되지 않으면 아래 과목별 학습 자료에서 전체 요약과 원문을 읽을 수 있습니다.</p>
</div>

## 어떻게 공부하면 좋을까요?

1. **단원 하나를 선택:** 처음부터 전체를 무작위로 풀기보다 경맥·특정혈·처방군처럼 범위를 좁힙니다.
2. **카드 앞면에서 회상:** 답을 보기 전에 말하거나 적어 봅니다. 모호했다면 ‘다시 볼게요’를 누릅니다.
3. **10~20문제 확인:** 정답 해설과 보기별 원문을 읽고, 왜 다른 보기는 다른 개념인지 구분합니다.
4. **오답과 원문 복습:** 맞힌 오답은 목록에서 빠집니다. 이해한 카드 수와 문제 정답 기록은 별도로 관리합니다.
5. **다음날 다시 확인:** ‘오늘의 10문제’는 같은 날짜·과목·선택 범위에서는 같은 문제를 제공합니다. 다른 범위로 좁혀 복습할 수도 있습니다.

학교 강의계획서에 맞춰 순서를 조정하세요. 자료는 아카이브를 바탕으로 만든 **자체 학습문제**이며 특정 대학의 공식 교육과정이나 국가시험 기출문제가 아닙니다.

해부학을 먼저 배우고 있다면 [기초 해부학](anatomy.md)에서 부위별 근육 카드 → 설명으로 구조 식별 → 도해 식별 → 구조 이름 직접 입력 순서로 시작하세요.

## 처음 시작하는 7일 복습 {#first-week}

하루에 카드 5~10개를 설명하고 퀴즈 10개를 풀어 보세요. 아래 순서는 기초 개념을 연결하는 출발점이며, 한 과목을 일주일 만에 끝내는 과정은 아닙니다.

| 날 | 시작할 자료 | 스스로 확인할 질문 |
|---|---|---|
| 1일 | [경혈학](acupoints.md)에서 폐경 선택 | LU 코드와 혈명을 연결하고, 손목·힘줄 같은 위치 표지를 말할 수 있나요? |
| 2일 | [침구학](acupuncture.md)에서 오수혈 개별 60혈 선택 | 정·형·수·경·합 분류를 말하고 같은 경맥의 다섯 혈을 찾을 수 있나요? |
| 3일 | [침구학](acupuncture.md)에서 원혈·낙혈·극혈 선택 | 원·낙·극을 구분하고 원락배혈의 표리경 관계를 설명할 수 있나요? |
| 4일 | [본초학](herbs.md)에서 보익·수삽 선택 | 이름뿐 아니라 약용 부위와 전통 효능을 설명할 수 있나요? |
| 5일 | [본초학](herbs.md)에서 본초 비교·감별 선택 | 황련·황금·황백이나 계지·육계의 차이를 원문 문맥에서 구분할 수 있나요? |
| 6일 | [방제학](formulas.md)에서 보기·기혈·회복 선택 | 사군자탕·사물탕·팔물탕·십전대보탕의 배합축을 설명할 수 있나요? |
| 7일 | 과목별 오답 다시 풀기와 북마크 카드 | 설명만 보고 이름을 찾고, 틀린 보기와 정답의 차이를 말할 수 있나요? |

낯선 용어가 많다면 [한의학 기초 안내](../portal/basics.md)에서 장부·기혈진액·병인병기·변증의 뜻을 먼저 읽으세요. 퀴즈의 ‘설명 → 이름 찾기’를 선택하면 암기 방향을 바꿔 점검할 수 있습니다.

## 이름을 외운 다음, 이유를 설명하는 심화 복습 {#deeper-study}

카드로 기본 지식을 확인했다면 아래 심화 설명에서 **구조 관계 → 감별 기준 → 선택 이유**를 말해 보세요. 다섯 과목에 각각 6개씩, **서술형 복습 30문항**과 펼쳐 보는 해설이 있습니다. 이 문항은 카드 퀴즈 통계에 포함되지 않는 읽기·설명 연습입니다.

| 과목 | 심화 학습 | 스스로 설명할 예 |
|---|---|---|
| [기초 해부학](anatomy.md#regional-relations) | 사지 구획, 주와·수근관·대퇴삼각·내전근관·슬와, 신경 기능·조직 감별 | 같은 관을 지난 혈관·신경이 이후에도 같은 길로 가는가? |
| [경혈학](acupoints.md#location-reasoning) | 골도분촌·기준 구간, 인접 혈의 뼈·힘줄 표지, 경맥 방향·표리관계 | PC6·PC7의 높이와 힘줄 표지를 함께 말할 수 있는가? |
| [침구학](acupuncture.md#classification-and-pairing) | 다중 특정혈 분류, 원락·수모·팔맥 배혈 예시, 치료 목표·연구 해석 | 대장 합혈과 대장 하합혈이 다른 이유를 설명하는가? |
| [본초학](herbs.md#efficacy-reasoning) | 효능에서 병기로, 기원·약용 부위·포제, 짝약과 처방 역할 | 백출·창출, 생강·건강을 실제 처방에서 구분하는가? |
| [방제학](formulas.md#composition-reasoning) | 군신좌사·치료축, 소화·수습·열병 감별, 기본방과 이본 | 같은 소화불편에서도 허약·습체·식적·허한이 왜 갈리는가? |

서술형 문항은 각 과목의 **‘서술형 복습’** 절에 있습니다. 답을 확인한 뒤 연결 원문에서 배합이나 구조의 근거를 다시 읽으세요. 강의의 판본·용어·실습 범위와 다른 부분은 해당 수업의 기준과 나란히 비교합니다.

## 원문과 근거를 함께 읽기

본초·방제의 효능과 특정혈·배혈은 **전통적 교육 개념**으로 읽고, 현대 치료효과는 해당 문서의 연구 대상·중재·비교군·결과에서 확인합니다. 경혈 위치는 시술의 깊이·방향이나 해부학적 안전을 대신하지 않습니다. 실제 임상 적용은 지도하의 실습과 환자 평가로 연결합니다.
