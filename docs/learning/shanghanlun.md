# 상한론 원문·조문·치법 문제은행

[기초 한의학 학습실](index.md) / **상한론**

**70개 카드 · 268문제.** 태양·양명·소양·태음·소음·궐음의 제강과 주요 처방 분기를 골라, **원문 → 우리말 풀이 → 증후 판독 → 치법·처방 → 가까운 조문과 감별**을 연습합니다. 전편의 모든 조문을 출제한 은행이 아니라 핵심 조문을 중심으로 한 확장 학습 묶음입니다.

## 판본과 해석 기준 {#edition}

원문은 아카이브의 [상한론 전체 조문](../shanghan-network/index.md#complete-clauses)과 같은 **송본 계열·중의급성 전사문, 통행 398조 구분**을 따릅니다. 문장 분절과 번호는 판본·교재마다 다를 수 있으므로 번호와 함께 첫 구절을 확인하세요. [대조 원문과 저본 안내](https://jicheng.tw/tcm/book/%E5%82%B7%E5%AF%92%E8%AB%96%EF%BC%88%E5%AE%8B%E6%9C%AC%EF%BC%89/index.html)에서 해당 조문으로 연결합니다.

우리말 풀이와 해설은 이 학습실을 위해 작성한 **독해 요지**입니다. 제강은 병증을 읽는 출발점이며, 증상 하나만으로 처방을 정하는 규칙으로 읽지 않습니다. 치법 용어는 조문과 방의에 대한 전통적 교육 해석이고 현대 임상효과는 연결 문서의 연구에서 따로 확인합니다. 고전 용량의 환산이나 자가 복용 문제는 출제하지 않습니다.

## 문제은행 시작하기 {#practice}

<div class="learning-room" data-learning-room data-subject="shanghanlun"><p>아래 전체 학습 요약에서 원문과 우리말 풀이·판독·치법을 읽을 수 있습니다.</p></div>

퀴즈에서 **원문·표지어 → 우리말 풀이**, **조문·병증 해석**, **치법·처방 연결** 중 원하는 유형을 고르세요. 70개 조문에는 기본 세 유형을, 새로 보강한 36개에는 **증례·배합 → 조문·병증 찾기**를 더해 총 246문제를 연결했습니다. 증례형은 짧은 상황에서 해당 조문을 고르고, 해설에서 원문의 조건과 비교 보기의 차이를 확인하는 문제입니다. 정답을 확인한 뒤 ‘보기별 설명과 원문’을 펼치면 비교 조문의 판독 단서와 처방 방향을 함께 볼 수 있습니다. 틀린 문제는 오답 다시 풀기에 남습니다.

## 치법을 조문 조건에 붙이기 {#methods}

| 방향 | 연결 조문·처방 | 확인할 조건 |
|---|---|---|
| 해표·해기 | 계지탕·마황탕·갈근탕 | 땀·맥·오풍오한·체통·항배강 |
| 화해소양 | 소시호탕 | 왕래한열·흉협고만·구역·식욕과 시호증의 존속 |
| 공리·윤장 | 승기탕류·마자인환 | 표해 여부, 조열·변경·복만, 건조와 배뇨 |
| 온중·온양 | 이중환·사역탕류 | 한열·갈증·하리·맥·전신 상태 |
| 청열 | 백호탕·백두옹탕 | 리열·활맥 또는 열리하중 등 해당 조문의 표지 |
| 수음·수기 조절 | 영계출감탕·오령산·진무탕 | 기상충·현훈, 배뇨·갈증, 사지침중·복통·하리의 차이 |

하나의 치법에 여러 처방이 연결되어도 같은 처방은 아닙니다. 원문의 병위·허실·한열·진액 상태와 배합을 함께 읽습니다.

## 오치 뒤에는 현재 맥증부터 다시 읽기 {#after-treatment}

16조의 **觀其脈證…隨證治之**는 이전 병명이나 처방을 반복하기 전에 치료 뒤 바뀐 맥증을 다시 관찰하라는 원칙입니다. 발한·토·하·온침이라는 이력과 지금의 땀·복부 소견·배설·맥을 나누어 읽습니다. 새 문제에는 이러한 **치료 전후의 변화**를 넣었습니다.

| 치료 뒤 단서 | 조문·처방 | 독해의 초점 |
|---|---|---|
| 누한·오풍·소변난·사지미급 | 20조 계지가부자탕 | 발한 뒤 지속 한출과 굴신곤란 |
| 과한 발한·심하계·욕득안 | 64조 계지감초탕 | 두근거림의 위치와 눌러 주길 바라는 양상 |
| 제하계·욕작분돈 | 65조 복령계지감초대조탕 | 심하계와 배꼽 아래의 기상충 전조 구분 |
| 발한 뒤 현훈·신순동·진전 | 82조 진무탕 | 316조 소음병 수기와 같은 처방, 다른 발병 문맥 |
| 하후·흉만·번경·소변불리 | 107조 시호가용골모려탕 | 놀람 하나보다 전신·배설 변화의 조합 |
| 재하 뒤 심하비와 하리 악화 | 158조 감초사심탕 | ‘비결열·위중허’라는 원문의 이유와 재하 금기 |

**문장 분해 예:** 158조는 `오하 → 심한 하리·곡불화·뇌명·비 → 실사로 오인해 재하 → 비익심 → 위중허·상역 → 감초사심탕`으로 읽습니다. 마지막 처방명만 외우면 재하로 악화한 이유를 놓치기 쉽습니다.

## 결흉·비증과 사심탕류의 차이 {#chest-and-pi}

심하의 불편은 공통이지만 **통증·촉진·수기·하리·치료 이력**의 조합은 다릅니다. ‘심하경’이라는 말도 주변 문장을 읽어야 합니다.

| 조문·처방 | 원문 표지 | 배합·치법을 읽는 질문 |
|---|---|---|
| 134 대함흉탕 | 膈內拒痛·心下因鞕 | 오하 뒤 결흉의 통증·경결에 축수·사열이 연결되는가? |
| 138 소함흉탕 | 正在心下·按之則痛·脈浮滑 | 국소 압통과 황련·반하·과루실의 청열화담 구조인가? |
| 149 반하사심탕 | 但滿而不痛 | 만이불통의 비증에 한열 병용·위기 조화가 연결되는가? |
| 154 대황황련사심탕 | 按之濡·關上浮 | 누르면 부드러운 열비인가? 조시·실결의 승기탕증과 어떻게 다른가? |
| 157 생강사심탕 | 乾噫食臭·脇下有水氣·雷鳴下利 | 식취 나는 애기와 수기가 하리와 함께 있는가? |
| 158 감초사심탕 | 穀不化·此非結熱·胃中虛 | 반복 오하와 위중허를 설명했는가? |
| 161 선복대자탕 | 噫氣不除 | 남은 애기를 강역·위기 회복의 배합과 연결했는가? |

사심탕류를 ‘같은 처방에 약 하나만 추가’로 단순화하지 않습니다. 판본의 약재·제법을 확인하면서 **해석의 무게중심이 어디로 이동하는지** 비교합니다.

| 비교축 | 조위승기탕 | 소승기탕 | 대승기탕 |

## 조문을 설명하는 답안의 틀 {#answer-reasoning}

정답 확인 뒤에는 **① 출발 조건 ② 지지 단서 두 개 ③ 가까운 보기와의 차이 ④ 치법·배합 ⑤ 관찰 또는 제한 조건**의 순서로 한 문단을 작성해 보세요.

예를 들어 229조는 “양명편의 조열이지만 대변당·흉협만이 남아 시호증을 읽는다. 대변경·조시를 보는 승기탕류와 구별하며 소시호탕의 화해 방향에 연결한다”라고 설명할 수 있습니다. 퀴즈의 보기별 해설에서 비교 조문의 원문으로 이동하면 자신의 배제 근거도 확인할 수 있습니다.

## 상·극상 문제와 보기별 해설 {#advanced-questions}

각 난이도 11문제씩입니다. **상**은 여러 단서와 가까운 개념을 함께 구별하고, **극상**은 예외·조건 변화·복수 분류 또는 출전의 차이를 판단합니다. 난이도는 출제 의도에 따른 구분이며 실제 정답률로 보정한 등급은 아닙니다. 퀴즈의 **문제 난이도**에서 선택하거나 아래 문항을 읽어 보세요. 증례·수치는 교육용 가정이고, 제시된 체질·병론 안에서 문헌을 읽는 문제는 체질 판정 검사가 아닙니다.

### 상 · 통합·감별 11문제

<span id="advanced-shanghanlun-high-01"></span>

**상 1. 갈증의 두 문장을 조건에 맞게 나눈 것은?**

71조: 발한 뒤 위중건·번조·불면·음수 욕구와, 이어지는 맥부·소변불리·미열·소갈을 비교한다.

- **판본·범위:** 송본 계열 · 중의급성 전사문 · 통행 398조 구분
- **우리말 풀이:** 조열·대변경 등의 리실 조건에서는 승기탕을 논하지만, 오한·미열로 표가 안 풀린 경우에는 성급히 쓰지 않는다.
- **판독 핵심:** 승기탕 분기: 표해 여부와 조열·변경·복만을 함께 본다.

**209조 · 조시의 확인과 중지**

- **원문 구분:** 조문 원문
- **원문:** 陽明病，潮熱，大便微鞕者，可與大承氣湯，不鞕者，不可與之。若不大便六七日，恐有燥屎，欲知之法，少與小承氣湯。湯入腹中，轉矢氣者，此有燥屎也，乃可攻之；若不轉矢氣者，此但初頭鞕，後必溏，不可攻之，攻之必脹滿不能食也。欲飲水者，與水則噦。其後發熱者，必大便復鞕而少也，以小承氣湯和之。不轉矢氣者，慎不可攻也。
- **판본·범위:** 송본 계열 · 중의급성 전사문 · 통행 398조 구분
- **우리말 풀이:** 양명병에 조열·대변경이 있으면 공하를 검토하되 단단하지 않으면 쓰지 않는다. 오래 배변하지 않았어도 조시 여부를 확인하며, 소승기탕 뒤 방귀가 나오지 않으면 함부로 공격하지 말라고 한다.

**338조 · 장궐·회궐과 오매환**

- **원문 구분:** 조문 원문
- **원문:** 傷寒，脈微而厥，至七八日，膚冷，其人躁無暫安時者，此為藏厥，非蚘厥也。蚘厥者，其人當吐蚘，令病者靜而復時煩者，此為藏寒。蚘上入其膈故煩，須臾復止，得食而嘔，又煩者，蚘聞食臭出，其人常自吐蚘。蚘厥者，烏梅丸主之。又主久利。
- **판본·범위:** 송본 계열 · 중의급성 전사문 · 통행 398조 구분
- **우리말 풀이:** 지속적으로 불안하고 차가운 장궐과, 잠잠하다 간헐적으로 번하며 식후 구토·회충 구토가 있는 회궐을 나눈다. 회궐에는 오매환을 쓰고 오래된 하리에도 주치한다고 한다.
- **판독 핵심:** 장궐의 지속 조동과 회궐의 정이복시번·토회를 구별한다.
- **치법·처방:** 오매환의 한열 병용·산수렴 구조를 회궐·구리의 문맥에서 읽는다.
- **감별·해석:** 원문상 주치는 회궐·구리다. 한열착잡이라는 후대 방의와 원문 병명을 구분하며 오늘날 모든 복통·설사에 확장하지 않는다.
- **증례 독해:** 차가운 상태에서 잠잠하다 간헐적으로 번하고 먹으면 토하며 회충을 토하는 기록이 있다. 계속 조동하는 장궐과 구별하는 조문이다.
