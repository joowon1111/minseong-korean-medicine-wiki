# 경혈학 공부 — 361경혈

[기초 한의학 학습실](index.md) / **경혈학**

**361개 카드 · 1,075문제.** 먼저 코드와 혈명·경맥을 연결하고, 표준 위치의 해부학적 표지를 짚은 뒤 그림에서 찾아보세요. 같은 이름의 혈도 코드·경맥까지 구분합니다.

## 학습 순서

| 단계 | 회상할 내용 | 확인 자료 |
|---|---|---|
| 경맥 단위 | 경맥 코드, 혈명·한자, 배열 | [경락·경맥 지식망](../meridian-network/index.md) |
| 위치 문장 | 부위, 뼈·근육·힘줄·주름 같은 표지, 상대 위치 | [361경혈 아틀라스](../acupoint-network/standard-atlas.md) |
| 도해 확인 | 붉은 점을 보고 혈명·코드 말하기 | 아래 ‘퀴즈’의 도해 문제 |
| 다중 분류 | 경맥 외에 오수·원·낙·극·회혈 등이 겹치는지 | [특정혈 학습](acupuncture.md) |

위치를 숫자만 외우기보다 문장의 해부학적 표지를 먼저 말해 보세요. ‘혈명·경맥’ 문제는 이름 회상, ‘표준 위치’ 문제는 문장 이해, ‘도해’ 문제는 부위 식별을 연습합니다. 경맥을 선택하면 해당 범위로 좁힐 수 있습니다.

## 카드와 위치 퀴즈 {#practice}

## 특정혈까지 연결하기

태연 LU9은 수혈(兪)·원혈·맥회, 양릉천 GB34는 합혈·담 하합혈·근회처럼 분류가 겹칩니다. [오수혈 60혈](../acupuncture-specific/five-shu.md)과 [특정혈 통합 아틀라스](../acupuncture-specific/special-points-atlas.md)를 나란히 읽고, 왜 한 혈에 여러 분류가 붙는지 확인하세요.

## 위치 자료·도해의 출처

혈명·코드·경맥은 아카이브의 표준 경혈 목록을 사용했습니다. 위치 문장은 [KM-Agent acupoints.csv](https://github.com/wonyung-lee/km-agent/blob/main/data/acupoints.csv)의 361 정경혈 자료를 바탕으로 합니다. Won-Yung Lee, Ji-Hwan Kim, Jungtae Leem, Byung-Wook Lee, Seungho Lee, Young Woo Kim; [CC BY 4.0 라이선스](https://github.com/wonyung-lee/km-agent/blob/main/LICENSE). 원자료 중 혈명·한자 정규화와 학습 형식 변환을 적용했습니다.

아카이브의 부위별 SVG 도해를 학습용으로 사용하며 퀴즈 그림에서는 혈명·코드 표시와 경혈 링크를 가렸습니다. 개략 도해의 붉은 점만으로 정확한 취혈이나 자침 경로를 결정하지 않고, 표준 위치 문장과 지도하의 해부·실습을 함께 확인합니다. [WHO 표준 경혈 위치](https://iris.who.int/items/f188654a-d8a7-4519-9979-8e2de713c060)와 [경혈 문서 작성 원칙](../acupuncture/acupoint-writing-guide.md)에서 위치 자료의 범위를 읽을 수 있습니다.
