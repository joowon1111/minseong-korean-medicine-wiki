# 표리병증과 처방

동의수세보원에서는 각 체질의 병증을 표병·리병 등으로 구분하고, 다시 한열과 경중, 증상의 전개를 살펴 처방을 연결한다.

```text
체질
 ↓
표병 / 리병
 ↓
한열·경중
 ↓
치법
 ↓
체질 처방
```

예를 들어 소양인에서는 형방도적산·형방사백산·양격산화탕 등이 서로 다른 병증 맥락에서 탐색된다. 태음인·소음인·태양인 역시 체질별 병증 구조에 따라 처방이 구분된다.
