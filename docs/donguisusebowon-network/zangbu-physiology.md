# 장부론과 체질 생리

동의수세보원에서는 체질마다 장부 기능의 상대적 강약이 다르다고 보고, 이 차이를 생리와 병리의 기본 틀로 삼는다.

```text
체질
 ↓
장부 기능의 상대적 강약
 ↓
평소의 소증
 ↓
병증의 경향
 ↓
치료 원칙
```

이 장부론은 기존 한의학의 장부 개념을 그대로 반복하기보다 **사상체질이라는 새로운 축으로 재구성**한다는 점이 특징이다.
