# 동의수세보원·사상의학 임상 네트워크 {#_1}

《동의수세보원》 네트워크는 체질명을 고정적인 성격 유형처럼 보는 것이 아니라 **소증·현재 병증·표리·순역·경중·치료반응**을 연결하는 임상층으로 구성합니다.

사상인의 큰 구조와 성명·사단·장부의 논의를 먼저 읽고, 평소 소증과 현재 표리병증이 치료 판단에 어떻게 연결되는지 살펴봅니다. 체질명은 처방이나 식품을 일괄 지정하는 표지가 아니며, 같은 체질 안에서도 현재 병증에 따라 판단이 달라집니다.

## 태양인·소양인·태음인·소음인 {#four-constitutions}

사상체질은 체형·성격 한 가지로 결정하지 않습니다. 평소 소화·대소변·땀·수면·냉열·피로와 현재 병증을 함께 봅니다.

### 네 체질
#### 태양인
고전적 상역·구토·하지 기능 등의 병증을 신중히 봅니다.

#### 소양인
대변·구갈·열감·흉협·수면·소화의 패턴을 중요하게 봅니다.

#### 태음인
발한·호흡·흉부·대변·피부·체액대사를 함께 봅니다.

#### 소음인
소화력·복부 냉감·대변·발한·사지냉감·피로를 자세히 봅니다.

→ [사상의학 소증](../sasang/minor-symptoms.md)


## 성명론·사단론 임상 이해 {#seongmyeong-sadan}

성명론·사단론은 사상의학의 인간관과 체질론을 이해하는 철학적 토대입니다.

### 임상에서의 주의
성격 몇 가지로 체질을 확정하거나 사람을 고정된 유형으로 단정하는 방식은 피합니다. 정서적 경향은 **소증·생활습관·현재 병증과 함께 참고하는 한 요소**로 봅니다.

### 생활·정서와 연결
지속적인 긴장, 분노, 불안, 과로 등은 수면·소화·심계·피로와 연동될 수 있으므로 실제 증상 변화와 함께 관찰합니다.

→ [생활·정서](index.md#lifestyle-emotion)  
→ [자율신경·스트레스 지식망](../autonomic/index.md)


## 사상의학 장부생리 {#zangbu-physiology}

사상의학의 장부론은 현대 해부학적 장기 크기를 그대로 뜻하는 개념이 아닙니다. 체질별 생리적 기능의 강약과 병리 방향을 설명하는 전통적 이론체계로 읽습니다.

### 임상에서의 활용
장부 대소 개념을 단독 진단기준으로 사용하지 않고 **소증·체질병증·대소변·발한·소화·호흡·냉열**과 함께 봅니다.

### 현대적으로 읽을 때
전통 이론과 현대 생리학을 억지로 일대일 대응시키지 않고, 각각의 설명 수준을 구분합니다.

→ [사상의학 임상 지식망](../sasang/index.md)


## 사상의학 소증·평소 증상 {#ordinary-symptoms-patterns}

이 페이지는 초창기 소증 문서를 중복 확장하지 않고 최신 기준문서와 연결합니다.

소증은 체질을 정하는 단순 체크리스트가 아니라 **평소 반복되는 생리 패턴과 현재 병증의 변화를 비교하는 기준선**입니다.

## 사상의학 표리병증 {#exterior-interior-patterns}

사상의학의 표리병증은 일반 팔강의 표리와 단순 동일하지 않습니다. 각 체질의 생리·병리 구조 안에서 **현재 병증이 어느 방향으로 진행되는지**를 봅니다.

### 임상 흐름
체질 후보 → 평소 소증 → 현재 증상 → 체질별 표리병증 → 한열·대소변·발한 → 순역·경중 → 치법·처방

→ [사상체질 병증](../sasang/disease-patterns.md)  
→ [체질→병증·처방 지도](../sasang/pattern-formula-map.md)


## 사상의학 치료원칙 {#treatment-principles}

사상치료의 핵심은 **체질 → 처방명**의 단순 대응이 아닙니다.

### 치료 설계
1. 평소 소증 확인
2. 체질 후보와 현재 병증 확인
3. 표리·한열·순역·경중 판단
4. 치법과 체질처방 선택
5. 주증과 소증의 변화 재평가

### 처방
소양인의 형방도적산·형방사백산·양격산화탕처럼 같은 체질 안에서도 병증에 따라 처방이 달라집니다.

→ [체질→병증·처방 지도](../sasang/pattern-formula-map.md)  
→ [사상 처방 라이브러리](../sasang-formula-library/index.md)


## 사상의학 생활·정서 관리 {#lifestyle-emotion}

사상의학의 생활관리는 체질별 금지목록을 만드는 방식보다 **평소 소증이 안정되는 생활 리듬을 찾는 것**이 중요합니다.

### 공통 평가
수면 / 식사량과 소화 / 대변 / 발한 / 활동 후 회복 / 정서적 과긴장

### 경과평가
치료 후 주증만 좋아졌는지보다 평소 소증과 생활 기능이 함께 안정되는지 확인합니다.

→ [사상의학 소증](../sasang/minor-symptoms.md)  
→ [피로·회복](../conditions/fatigue.md)


## 동의수세보원 통합 임상 지도 {#integrated-map}

`평소 소증 → 체질 후보 → 현재 체질병증 → 표리·한열 → 순역·경중 → 치법 → 체질처방 → 생활관리 → 경과평가`

### 핵심 원칙
- 체형이나 성격 한 가지로 체질을 정하지 않음
- 같은 체질에서도 현재 병증에 따라 처방이 달라짐
- 치료 후 주증과 소증을 함께 평가
- 현대 질환명과 체질병증을 일대일 대응시키지 않음
