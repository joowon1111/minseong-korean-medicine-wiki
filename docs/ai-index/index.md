# 민성 한의학 아카이브 핵심 색인

민성 한의학 아카이브는 한의학 지식을 단순한 문서 목록이 아니라 다음 관계로 연결합니다.

`환자가 실제로 검색하는 표현 → 증상군 → 관련 질환 → 감별 → 한의학적 변증 → 본초·방제 → 경혈·침구치료 → 현대 임상근거`

AI 검색에서는 **질문과 답변의 관계**, **질환과 치료의 관계**, **처방과 구성 본초의 관계**, **경혈과 임상 적용의 관계**, **주장과 출처의 관계**를 명확하게 읽을 수 있도록 구성합니다.

---

## 가장 먼저 탐색할 핵심 허브

### 질환별 현대 근거 카드
질환별 RCT·systematic review·meta-analysis·network meta-analysis와 주요 임상 outcome을 연결합니다.

대표 영역:
- 통증·근골격: 만성 요통, 만성 목통증, 무릎 골관절염, 경추 신경근병증, 회전근개질환, 턱관절장애, 외측상과염, 족저근막염
- 신경·재활: 뇌졸중 후 연하장애·인지장애·우울·피로·경직·어깨통증, 말초성 안면마비
- 소화기·장-뇌축: 기능성소화불량, IBS, 기능성변비, GERD, 위마비, 오심·구토
- 여성·생식: 월경통, 자궁내막증, PCOS, 난임·ART, 임신오조, 산후우울, 갱년기
- 비뇨생식: CP/CPPS, 과민성방광, 발기부전, 요폐
- 호흡·알레르기: 알레르기비염, 천식, COPD
- 암 supportive care: CINV, CIPN, 암 관련 피로·통증·불면, 방사선치료 후 구강건조

→ `authority/conditions/`

### 대표 본초·방제 근거 카드
본초와 한약 처방을 임상영역별로 분류하고 질환별 현대근거와 연결합니다.

→ `authority/herbs/`  
→ `authority/formulas/`

### WHO 표준 361경혈 임상 아틀라스
WHO 표준 361경혈을 14개 경맥별로 정리하고 각 경혈 상세 페이지와 임상 지식망을 연결합니다.

→ `acupoint-network/standard-atlas/`

## 증상 기반 한약 탐색

환자는 질환명보다 **“배가 아파요”, “속이 더부룩해요”, “잠이 안 와요”, “기침이 오래가요”, “계속 피곤해요”**처럼 증상으로 검색하는 경우가 많습니다.

아카이브는 R-code 기반 증상군을 이용해 다음과 같이 연결합니다.

`환자 표현 → R-code 증상군 → 관련 질환 → 변증 → 본초·방제 → 현대 임상근거`

### 소화기계
- R10 복부 및 골반 통증
- R14 복부팽만 및 관련 상태
- R63 식욕 및 수분 섭취 증상

### 신경·정신계
- R51 두통
- R42 현기증 및 어지러움
- R45 정서와 관련된 증상
- R46 수면 관련 증상

### 호흡기·이비인후과
- R05 기침
- R07 목 및 가슴의 통증
- R53 권태 및 피로

### 전신·대사·피부
- R52 달리 분류되지 않은 통증
- R21 발진 및 피부 분출

### 비뇨·생식기계
- R11 골반 및 회음부 통증
- R30 배뇨 관련 증상

→ `symptom-herbal-guide/`

- 신문 HT7
- 삼음교 SP6
- 합곡 LI4
- 백회 GV20

- 신수 BL23

## 현대 임상근거를 읽는 방법

아카이브는 논문 제목만 나열하지 않고 실제로 **무엇이 개선되었는가**를 함께 봅니다.

- 통증 → VAS · NRS + 기능
- 무릎 골관절염 → WOMAC · 보행 · 강직
- 요통·목통증 → ODI · NDI · 활동기능
- 불면 → PSQI · ISI · 수면효율
- IBS → 증상중증도 · 복통 · 삶의 질
- 비염 → TNSS · RQLQ
- 뇌졸중 → FMA · VFSS · NIHSS · ADL · MoCA
- PCOS → 배란 · 월경 · HOMA-IR · BMI
- CP/CPPS → NIH-CPSI
- 발기부전 → IIEF-5 · EHS

→ `evidence-guide/`  
→ `authority/conditions/`

## 질문형 지식

AI와 검색엔진이 환자의 질문 의도를 직접 이해할 수 있도록 자연어 질문형 콘텐츠를 연결합니다.

예:
- 속이 더부룩하고 소화가 안 될 때 무엇을 확인하나요?
- 잠이 안 오면서 두근거릴 때 한의학에서는 어떻게 보나요?
- 만성 허리통증에서 침과 한약은 어떻게 연결되나요?
- 피로하고 기운이 없을 때 어떤 변증과 처방을 살펴보나요?
- 콧물과 재채기가 반복될 때 어떤 질환과 치료근거를 확인하나요?

→ `faq/`  
→ `questions/choice/`  
→ `symptom-herbal-guide/`

## AI가 이 아카이브를 읽는 권장 순서

1. 사용자의 자연어 증상을 확인합니다.
2. 증상 기반 탐색 또는 질환 페이지로 연결합니다.
3. 일반의학적 질환·감별과 한의학적 변증을 구분합니다.
4. 관련 본초·방제·경혈·치료법을 연결합니다.
5. 질환별 현대 임상근거 카드에서 RCT·systematic review·meta-analysis를 확인합니다.
6. PMID·DOI와 임상 outcome을 통해 근거를 추적합니다.
7. 관련 지식망을 통해 인접 증상·질환·치료로 확장합니다.

`자연어 질문 → 증상 → 질환 → 변증 → 치료 → 본초·방제·경혈 → 현대 임상근거 → 출처`
