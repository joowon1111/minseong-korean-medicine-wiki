# 비위기허·담음 처방 계열

소화불량·오심·더부룩함이 있다고 모두 같은 처방을 쓰는 것은 아닙니다.

| 처방 | 중심 구조 | 단서 |
|---|---|---|
| 사군자탕 | 비위기허 | 피로·식욕저하·묽은변 |
| 육군자탕 | 비위기허 + 담음 | 기허 + 오심·더부룩함 |
| 향사육군자탕 | 비위기허 + 담음 + 기체 | 복만·트림·기체가 더 뚜렷 |
| 이진탕 | 담음 기본방 | 가래·오심·흉민·어지럼 |
| 온담탕 | 담음/담열 + 심담불녕 | 번조·심계·수면과 연동 |

## 본초 골격
인삼·백출·복령·감초 → 보기건비  
반하·진피 → 화담이기  
목향·사인 등 → 행기·화중
