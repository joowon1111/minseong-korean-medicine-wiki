# 사군자탕 계열 임상 구조 {#_1}

사군자탕 계열은 **비위기허라는 기본축에 담음·기체·중기하함이 어떻게 더해지는가**를 보면 관계가 선명합니다.

| 처방 | 중심 병리 | 구조 |
|---|---|---|
| [사군자탕](../formulas/sijunzi-tang.md) | 비위기허 | 인삼·백출·복령·감초의 보기건비 |
| [육군자탕](../formulas/liujunzi-tang.md) | 비위기허 + 담음 | 사군자탕 + 반하·진피 |
| [향사육군자탕](../formulas/xiangsha-liujunzi-tang.md) | 비위기허 + 담음·기체 | 육군자탕 + 이기·행기 |
| [보중익기탕](../formulas/buzhong-yiqi-tang.md) | 중기허·하함 | 황기 중심의 보기승양 |

## 임상에서 갈라지는 지점 {#_2}
식욕저하·피로·묽은변이 중심이면 기허축을, 오심·더부룩함·가래·어지럼이 더해지면 담음축을, 복만·트림·스트레스 연동이 강하면 기체축을 더 봅니다. [사군자탕 vs 육군자탕](../compare/sijunzi-vs-liujunzi.md#appetite-fullness)에서는 식욕저하·조기포만의 실제 표현을 나누어 배합의 차이와 연결합니다.
