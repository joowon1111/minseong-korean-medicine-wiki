# 방제 구조·처방 계열 지식망 {#_1}

방제를 처방명과 효능 목록으로만 외우지 않고 **기본 골격과 확장 관계**로 이해합니다.

## 구성표에서 먼저 읽을 것 {#composition-questions}

처방명 다음에 나오는 구성표에서는 약재의 개수보다 역할과 비중을 봅니다. 같은 본초가 여러 처방에 들어 있어도 함께 배합한 약재, 용량비, 법제와 제형에 따라 읽어야 할 맥락이 달라집니다.

| 확인 순서 | 질문 |
|---|---|
| 출전·수록본 | 동명 처방 중 어느 문헌의 구성인가? |
| 중심 골격 | 보기·보혈·화담·활혈 등 어느 방향이 중심인가? |
| 보완하는 배합 | 주된 방향을 돕거나 다른 증상을 함께 다루는 약재는 무엇인가? |
| 기본방과 차이 | 어떤 약재·용량·제법이 달라졌고 그 의미는 무엇인가? |
| 유사 처방 | 비슷한 증상에서 전제가 어떻게 달라지는가? |

군신좌사는 역할을 설명하는 도구이며 모든 수록본에서 해설이 완전히 같다는 뜻은 아닙니다. 구성 약재를 외우는 것과 실제 환자에게 적합한 처방을 판단하는 것은 별개의 단계입니다.

## 기본방을 비교하는 예 {#family-examples}

| 비교 | 구조에서 읽는 차이 | 이어 볼 자료 |
|---|---|---|
| 사군자탕·육군자탕 | 보기·건비 골격에 화담·이기가 더해지는 관계 | [두 처방 비교](../compare/sijunzi-vs-liujunzi.md) |
| 사물탕·팔물탕 | 혈의 자양과 기혈을 함께 보하는 구조 | [사물탕·기혈 계열](siwu-qi-blood-family.md) |
| 팔물탕·십전대보탕 | 기혈 보익에 황기·육계의 방향이 더해지는 관계 | [보익 계열](tonic-family.md) |
| 귀비탕·온담탕 | 기혈의 허약과 담음·담울을 읽는 전제 | [두 처방 비교](../compare/guibi-vs-wendan.md) |

기본방에서 확장되는 관계는 학습용 비교이지 원방 용량을 그대로 합산하거나 약재를 임의로 추가하는 복용법이 아닙니다. 같은 처방 이름이라도 수록본·가감·제형이 다른 경우에는 각각의 구성표를 확인합니다.

## 처방을 읽는 순서 {#_3}
**출전 → 원문 병증 → 구성 → 원방 용량·제법 → 군신좌사·약대 → 기본방과 가감 → 유사처방 감별 → 현대 임상근거**

## 임상 연결 {#_4}
증상에서 출발했다면 [본초·방제 임상 연결](../herbal-formula-clinical/index.md)에서 감별과 치법을 먼저 정리합니다. 이름만 알고 있다면 각 처방의 출전과 구성을 확인한 뒤 계열 안에서 비교합니다.

현대 연구를 찾을 때도 처방명이 같다는 이유만으로 동일한 중재로 보지 않습니다. 대상 질환·진단 기준, 실제 구성·제형·용량·기간, 비교군과 결과지표를 확인해야 고전의 구조 설명과 연구 결과가 어느 범위에서 연결되는지 알 수 있습니다.
