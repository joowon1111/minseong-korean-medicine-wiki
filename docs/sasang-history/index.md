# 사상의학 역사·인물 지식망

사상의학은 이제마가 19세기 말 조선에서 체계화한 독자적인 의학 체계다. 기존 한의학의 장부·기혈·병증 이론을 바탕으로 하면서 사람의 체질적 차이를 치료체계의 중심에 놓았다는 점에서 중요한 전환을 이루었다.

```text
조선 후기 한의학
   ↓
이제마
   ↓
동의수세보원
   ↓
사상체질 이론
   ↓
현대 사상의학
```
