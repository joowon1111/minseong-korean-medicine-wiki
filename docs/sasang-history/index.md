# 사상의학 역사·인물 지식망

사상의학은 이제마가 조선 후기의 의학과 인간 이해를 바탕으로 체질적 생리, 평소 소증, 현재 병증과 치료를 연결해 체계화한 의학입니다. 역사를 읽을 때에는 **이제마가 직접 남긴 내용**, 사후 간행과 판본, 후대 임상 확장, 현대 표준화·연구를 구분해야 합니다.

## 핵심 연표

| 시기 | 사건 | 읽을 때의 의미 |
|---|---|---|
| 1837 | 이제마 출생 | 조선 후기의 사회·의학적 배경에서 생애를 이해 |
| 1894 | 《동의수세보원》 저술 | 갑오구본과 이후 수정 과정을 구분 |
| 1900 | 이제마 사망 때까지 원고 수정 | 생전 저술과 사후 편집·간행을 나누어 봄 |
| 1901 | 문인들이 신축본을 목활자로 초간 | 현재 널리 읽히는 신축본 계열의 출발 |
| 1911·1913·1914·1921·1936·1941 | 후속 간행본 | 판본별 조문·처방 차이를 확인해야 하는 이유 |
| 현대 | 대학 교육, 전문진료, 병증 표준화와 진단·임상 연구 | 원전 체계와 현대 제도·연구의 역할을 구분 |

연도와 간행 정보는 [한국민족문화대백과사전 《동의수세보원》 항목](https://encykorea.aks.ac.kr/Article/E0016732)을 기준으로 정리했습니다.

## 이제마와 사상의학의 문제의식 {#lee-je-ma}

[이제마(李濟馬, 1837–1900)](../physicians/lee-je-ma.md)는 사람을 태양인·태음인·소양인·소음인으로 나누는 분류 자체보다, 체질별 기능적 강약과 성정, 평소 소증, 병증의 진행과 치료 반응을 하나의 임상체계로 연결했습니다.

| 단순화하기 쉬운 설명 | 역사·임상적으로 더 정확한 이해 |
|---|---|
| 성격 네 유형 | 성정·장부 기능·소증·현재 병증의 종합 |
| 체질마다 고정 음식 | 병증과 상태, 섭취 뒤 반응을 포함한 생활관리 |
| 체질마다 한 처방 | 표리·순역·경중과 치료 반응에 따른 처방 선택 |
| 장기의 실제 크기 차이 | 폐대간소 등은 사상의학의 기능적 관계 설명 |

→ [한국민족문화대백과사전 이제마 항목](https://encykorea.aks.ac.kr/Article/E0045869)

## 《동의수세보원》의 형성과 판본 {#donguisusebowon-context}

《동의수세보원》은 1894년 저술 뒤 계속 수정됐고, 이제마 사후 1901년에 문인들이 신축본을 간행했습니다. 갑오구본과 신축본은 단순한 오탈자 차이가 아니라 이론·병증·처방의 구성 차이를 포함할 수 있으므로, 인용할 때 판본을 밝혀야 합니다.

## 앞선 의학과 무엇이 다른가 {#historical-position}

사상의학은 기존 장부·기혈·한열·허실과 처방 전통을 단절시킨 체계가 아닙니다. 앞선 지식을 활용하면서도 동일한 병명·증상이라도 체질의 생리와 평소 상태, 병증의 진행 방향에 따라 다르게 판단하는 축을 전면에 두었습니다.

[동의보감](../classics/donguibogam.md)이 신형·내경·외형·잡병·탕액·침구로 방대한 지식을 집대성했다면, 《동의수세보원》은 체질별 장부 기능과 소증·병증·처방의 연결을 중심으로 임상 판단을 재구성합니다. 어느 체계가 다른 체계를 단순히 대체했다고 보지 않습니다.

## 후대 전승과 현대 확장 {#modern-expansion}

사후 판본 간행과 임상 전승을 거쳐 사상의학은 현대 한의과대학 교육, 사상체질과 전문진료, 체질병증 표준화, 진단도구·관찰·임상시험 연구로 확장됐습니다. 이 과정에서 생긴 용어·진단도구·진료지침은 이제마의 원문과 같은 층위가 아닙니다.

| 층위 | 역할 |
|---|---|
| 원전 | 체질 생리·병리, 소증, 표리병증과 처방의 출발점 |
| 후대 임상·판본 | 원전 해석과 처방 운용의 전승·확장 |
| 표준·진료지침 | 현대 진료에서 용어와 판단 흐름을 공통화 |
| 현대 연구 | 진단 재현성, 건강지표 연관성, 치료효과와 안전성 평가 |
