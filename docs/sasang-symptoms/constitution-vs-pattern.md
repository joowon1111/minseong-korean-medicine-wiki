# 체질과 현재 병증

사상체질은 치료의 기본 틀이지만 **실제 처방에는 현재 병증이 함께 중요하다.**

```text
체질 + 현재 병증
       ↓
치료 원칙
       ↓
체질 처방
```

같은 소양인에서도 형방도적산·형방사백산·양격산화탕 등이, 같은 태음인에서도 태음조위탕·청심연자탕 등이 서로 다른 병증 맥락에서 연결된다.

→ [사상체질 처방 전체 비교](../sasang-formula-cards/comparison-map.md)


## 같은 체질 안에서도 병증은 여러 갈래입니다

| 체질 | 같은 체질 안의 대표적인 다른 병증 |
|---|---|
| 소양인 | 소양상풍·망음·흉격열·음허오열 |
| 태음인 | 위완수한표한·승청저하·간열폐조·조열/정체 |
| 소음인 | 울광·망양·태음병·소음병 |
| 태양인 | 외감요척병·해역 / 내촉소장병·열격 |

예를 들어 소양인이라는 체질 정보만으로 형방도적산·양격산화탕·독활지황탕 중 하나를 고를 수 없습니다. 두통·한열·설사·변폐·갈증·하지무력 등 **현재 병증의 조합과 진행 방향**이 필요합니다.

## 체질과 병증을 분리해 묻는 네 질문

1. 평소 건강할 때 소화·대변·소변·땀·수면은 어땠나?
2. 이번에 무엇이 가장 먼저 달라졌나?
3. 지금 가장 무너진 기능은 식사·배설·호흡·보행 중 무엇인가?
4. 치료 뒤 주증뿐 아니라 평소 소증도 회복되는가?

## 자가진단에 쓰지 않는 이유

체질은 한 가지 증상으로 확정하지 않고 병증도 현대 질환 진단을 대신하지 않습니다. 특히 흉통·호흡곤란·의식 변화·출혈·심한 탈수·진행성 연하곤란·급성 신경학적 이상은 체질 해석보다 의학적 평가가 우선입니다.
