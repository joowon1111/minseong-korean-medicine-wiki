# 체질과 현재 병증

사상체질은 치료의 기본 틀이지만 **실제 처방에는 현재 병증이 함께 중요하다.**

```text
체질 + 현재 병증
       ↓
치료 원칙
       ↓
체질 처방
```

같은 소양인에서도 형방도적산·형방사백산·양격산화탕 등이, 같은 태음인에서도 태음조위탕·청심연자탕 등이 서로 다른 병증 맥락에서 연결된다.
