# 동의보감 탕액편

탕액편은 약재의 성질과 효능, 채취·수치·배합과 처방 활용을 폭넓게 정리한 본초·방제 지식의 핵심 영역이다.

```text
약재
 ↓
성미·귀경·효능
 ↓
배합
 ↓
처방
 ↓
병증 적용
```

오늘날의 본초학과 방제학을 동의보감의 고전적 지식 체계와 연결하는 중요한 부분이다.
