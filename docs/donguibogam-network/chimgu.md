# 동의보감 침구편

침구편은 경혈과 침·뜸 치료를 질환·증상과 연결하여 설명하는 동의보감의 핵심 치료 영역이다.

```text
증상·질환
 ↓
경락·경혈
 ↓
침·뜸
 ↓
치료
```

이 부분은 황제내경의 경락 이론과 후대의 임상 침구를 연결하는 실용적 지식망으로 볼 수 있다.
