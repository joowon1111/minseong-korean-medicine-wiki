# 동의보감 임상 탐색 네트워크 {#_1}

《동의보감》은 인체와 질병, 본초·방제·침구를 한 체계 안에서 다루는 대표적인 한국 한의학 고전입니다. 이 네트워크는 원문을 반복 복제하기보다 **현재의 임상 지식망으로 들어가는 탐색층**으로 사용합니다.

내경편은 기능과 생명의 요소, 외형편은 몸의 부위, 잡병편은 병증을 기준으로 탐색합니다. 같은 불편을 어느 편에서 읽느냐에 따라 질문이 달라집니다. 본초·방제와 침구의 자세한 구성은 해당 기준문서로 이어집니다.

## 동의보감 내경편 임상 탐색 {#naegyeong}

내경편은 몸의 안쪽 기능과 생명의 기본 요소를 다루는 축으로 읽을 수 있습니다.

### 핵심 연결
- 정·기·신 → 회복·노화·수면·정신신경
- 장부 → 비위·심·간·신 등 장부변증
- 기혈 → 기허·혈허·기혈양허·어혈
- 진액 → 담음·조燥·수분대사

### 임상 적용
내경편의 개념을 현대 장기 하나와 그대로 동일시하지 않고, 환자의 증상 패턴과 변증을 구조화하는 전통적 생리·병리 언어로 읽습니다.

## 동의보감 외형편 임상 탐색 {#oehyeong}

외형편은 머리·얼굴·눈·귀·코·입·목·등·허리·사지 등 **신체 부위별 증상 탐색**에 유용한 구조입니다.

### 현재 위키와의 연결
부위만으로 치료하지 않고 **위험신호 → 국소 해부학·질환 감별 → 해당 경맥 → 변증 → 경혈·방제** 순으로 연결합니다.

예:
- 목·어깨 → 담경·방광경·소장경
- 요부 → 방광경·독맥·신경
- 무릎 → 위경·비경·담경·방광경
- 두면부 → 양명·소양·태양경

→ [경락·경맥 지식망](../meridian-network/index.md)  
→ [WHO 표준 361경혈 아틀라스](../acupoint-network/standard-atlas.md)  
→ [통증·근골격 허브](../pillar/pain-musculoskeletal.md)


## 동의보감 잡병편 임상 탐색 {#japbyeong}

잡병편은 외감·내상·허로·담음·적취·부인·소아 등 다양한 병증을 폭넓게 다루는 임상 영역입니다.

### 읽는 방법
현대 질환명을 고전 병명에 바로 대입하지 않고 **환자 증상 → 고전 병증의 핵심 양상 → 변증 → 치법 → 처방**으로 연결합니다.

### 현재 지식망과 연결
- 피로·허로 → 기허·혈허·신허·보익
- 소화 → 비위기허·담음·식적·간울
- 통증 → 한습·어혈·허증
- 수면·심계 → 기혈부족·담음·간울·음혈부족

→ [질환→치료 지도](../network/condition-to-treatment-map.md)  
→ [팔강변증](../eight-principles-network/index.md)


## 동의보감 양생·예방 임상 지도 {#yangsaeng-prevention}

양생은 질병이 생긴 뒤 치료하는 것만이 아니라 **수면·식사·활동·정서·계절 적응을 통해 몸의 균형과 회복을 유지하는 관점**입니다.

### 현재 임상에서 연결할 항목
- 일정한 수면과 회복
- 과식·과음·과로 조절
- 계절과 기후에 따른 생활 조절
- 적절한 활동과 휴식
- 정서적 긴장과 신체 증상의 연동
- 연령·체력에 맞춘 보익과 생활관리

### 현대적으로 읽기
고전의 양생법을 그대로 의무화하기보다 현재의 수면위생·운동·식사·스트레스 관리와 조화시켜 실천 가능한 방향으로 해석합니다.

→ [자율신경·스트레스 지식망](../autonomic/index.md)  
→ [피로·회복](../conditions/fatigue.md)


## 동의보감 임상 탐색법 {#clinical-navigation}

### 탐색 순서
**환자의 말 → 위험신호 → 부위/장부/병증 분류 → 변증 → 치법 → 본초·방제·경혈 → 현대근거**

### 예시
- '목이 뻐근해요' → 외형편의 부위 탐색 → 경항부 위험신호 → 담경·방광경 → 경혈·통증 처방
- '속이 더부룩해요' → 내경·잡병 → 비위·담음·식적·간울 감별 → 소화 처방·경혈
- '기운이 없어요' → 내경·잡병의 허손 → 기허·혈허·신허 → 보익 본초·방제

→ [통합 임상추론](../clinical-reasoning/index.md)
