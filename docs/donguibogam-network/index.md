# 동의보감 임상 탐색 네트워크 {#_1}

《동의보감》은 인체와 질병, 본초·방제·침구를 한 체계 안에서 다루는 대표적인 한국 한의학 고전입니다. 이 네트워크는 원문을 반복 복제하기보다 **현재의 임상 지식망으로 들어가는 탐색층**으로 사용합니다.

내경편은 기능과 생명의 요소, 외형편은 몸의 부위, 잡병편은 병증을 기준으로 탐색합니다. 같은 불편을 어느 편에서 읽느냐에 따라 질문이 달라집니다. 본초·방제와 침구의 자세한 구성은 해당 기준문서로 이어집니다.

## 동의보감 내경편 임상 탐색 {#naegyeong}

내경편은 몸의 안쪽 기능과 생명의 기본 요소를 다루는 축으로 읽을 수 있습니다.

### 핵심 연결 {#_2}

| 내경의 항목 | 읽을 증상·병기 | 기존 문서로 이어가기 |
|---|---|---|
| 氣 · 기 | 활동 후 피로, 말과 호흡, 식욕을 함께 살피는 기허 | [기허](../diagnostics/patterns/qi-deficiency.md) · [원기회복](../conditions/energy-recovery.md) |
| 神 · 신 | 수면·두근거림·긴장과 낮 기능 | [불면](../conditions/insomnia.md) · [두근거림](../conditions/palpitation.md) · [수면·정서 한약 근거](../authority/formulas/sleep-emotion-herbal-evidence.md) |
| 血 · 혈 | 혈허·어혈을 나누어 읽는 혈의 병증 | [당귀](../herbs/angelica.md) · [사물탕·기혈쌍보](../formula-architecture/siwu-qi-blood-family.md) |
| 津液 · 진액 | 땀·구갈·건조와 체액 손실·정체의 구별 | [부종](../conditions/edema-swelling.md) · [한약 안전성](../herbal-integrated/safety.md) |
| 痰飮 · 담음 | 물소리·오심·흉민·머리 무거움과 현훈의 조합 | [담음 변증](../diagnostics/patterns/phlegm-fluid.md) · [어지럼](../conditions/dizziness.md) · [소화불량](../conditions/dyspepsia.md) |
| 精 · 정, 장부 | 성장·노화·허약을 전신 상태와 함께 읽기 | [신허](../diagnostics/patterns/kidney-deficiency.md) · [노인보약](../conditions/elderly-tonic.md) |

### 담음에서 본초·방제·증상으로 {#phlegm-pathway}

담음은 **내경편의 항목**에서 출발합니다. 오늘의 어지럼·이명·두통이 모두 담음이라는 뜻은 아니며, 소화 상태·흉민·오심·수분대사 증후가 함께 있는지를 살피는 연결 경로입니다.

- [반하](../herbs/pinellia.md)·[진피](../herbs/citrus-peel.md)·[복령](../herbs/poria.md)의 관계는 [이진탕](../formulas/erchen-tang.md)에서 확인합니다. 오심·가래·비위불화와 화담·이기의 구조를 읽습니다.
- 여기에 불면·놀람·흉민 같은 단서가 함께 있으면 [온담탕](../formulas/wendan-tang.md)의 구성과 [수면·정서 연구](../authority/formulas/sleep-emotion-herbal-evidence.md)를 살펴봅니다.
- 흉협 지만·목현과 온양화음의 구조는 [영계출감탕](../formulas/linggui-zhugan-tang.md) 및 [금궤요략 12.16](../classics/jinkui-yaolue/chapters/fluid-cough.md#clause-12-016)으로 거슬러 올라갑니다.

증상별로는 [어지럼](../conditions/dizziness.md)·[이명](../conditions/tinnitus.md)·[두통](../conditions/headache.md)의 감별과 평가를 먼저 확인합니다. 연구는 [소화기 한약 근거](../authority/formulas/digestive-herbal-evidence.md)와 [이명 근거](../authority/conditions/tinnitus.md)처럼 실제 연구 대상에 따라 나누어 읽습니다.

내경편의 개념을 현대 장기 하나와 그대로 동일시하지 않고, 환자의 증상 패턴과 변증을 구조화하는 전통적 생리·병리 언어로 읽습니다.

## 동의보감 외형편 임상 탐색 {#oehyeong}

외형편은 머리·얼굴·눈·귀·코·입·목·등·허리·사지 등 **신체 부위별 증상 탐색**에 유용한 구조입니다.

### 현재 위키와의 연결 {#_5}
부위만으로 치료하지 않고 **위험신호 → 국소 해부학·질환 감별 → 해당 경맥 → 변증 → 경혈·방제** 순으로 연결합니다.

| 외형의 부위 | 현재 임상에서 먼저 구별할 내용 | 연결 |
|---|---|---|
| 頭 · 머리 | 두통의 발생 양상·동반 증상·위험신호 | [두통](../conditions/headache.md) · [두통·어지럼 안전성](../clinical-safety/headache-dizziness.md) |
| 耳 · 귀 | 청력 변화·이명·현훈의 동반 여부 | [이명](../conditions/tinnitus.md) · [어지럼](../conditions/dizziness.md) |
| 眼 · 눈 | 시력 변화와 반복 사용에 따른 피로 | [눈 피로](../conditions/eye-fatigue.md) |
| 背·腰·手足 · 등·허리·사지 | 통증 위치, 운동·감각, 국소 조직과 경맥 | [통증·근골격](../pillar/pain-musculoskeletal.md) · [경락 지식망](../meridian-network/index.md) |

부위 색인에서 찾은 경혈은 표준 위치·자침 안전성을 확인한 뒤, 해당 질환을 대상으로 한 현대 침 연구와 연결합니다.

→ [경락·경맥 지식망](../meridian-network/index.md)  
→ [WHO 표준 361경혈 아틀라스](../acupoint-network/standard-atlas.md)  
→ [통증·근골격 허브](../pillar/pain-musculoskeletal.md)


## 동의보감 잡병편 임상 탐색 {#japbyeong}

잡병편은 외감·내상·허로·적취·부인·소아 등 다양한 병증을 폭넓게 다루는 임상 영역입니다.

### 읽는 방법 {#_6}
현대 질환명을 고전 병명에 바로 대입하지 않고 **환자 증상 → 고전 병증의 핵심 양상 → 변증 → 치법 → 처방**으로 연결합니다.

### 현재 지식망과 연결 {#_7}

| 잡병의 항목 | 읽을 임상 질문 | 기존 연결 |
|---|---|---|
| 內傷 · 내상 | 식사·과로 이후 식욕과 소화·활동량이 어떻게 달라졌나 | [성인 식욕저하](../conditions/poor-appetite-adult.md) · [기능성소화불량](../conditions/functional-dyspepsia.md) · [비위론](../classics/piwei-lun.md) |
| 虛勞 · 허로 | 허약에 식욕저하·불면·건조·냉감이 어떻게 겹치나 | [피로](../conditions/fatigue.md) · [보익 처방 계열](../formula-architecture/tonic-family.md) |
| 咳嗽 · 해수 | 기침에 담·건조·허약이 어떤 양상으로 동반되나 | [질환→치료 지도](../network/condition-to-treatment-map.md) · [담음](../diagnostics/patterns/phlegm-fluid.md) |
| 消渴 · 소갈 | 갈증·음수·배뇨·체중 변화의 조합은 무엇인가 | [제2형 당뇨병](../conditions/type-2-diabetes.md) · [심혈관·대사 한약 근거](../authority/formulas/cardiometabolic-herbal-evidence.md) |
| 浮腫 · 부종 | 붓는 부위·시간과 호흡·소변의 변화는 무엇인가 | [부종](../conditions/edema-swelling.md) · [금궤요략 수기병](../classics/jinkui-yaolue/chapters/water-qi.md) |
| 婦人 · 부인 | 월경·임신·산후 중 어느 시기의 문제인가 | [여성·임신·산후 허브](../womens-health/fertility-pregnancy-postpartum.md) · [산후 회복](../conditions/postpartum-recovery.md) |
| 小兒 · 소아 | 성장 경과·식사·수면·반복 질환은 어떠한가 | [소아보약 안내](../conditions/child-parent-tonic-guide.md) · [소아 식욕저하](../conditions/child-poor-appetite.md) |

### 허로에서 회복의 임상 질문으로 {#deficiency-pathway}

허로를 읽을 때는 **보기·보혈·보음·보양 중 무엇을 살필지**와 함께 식사량·체중·수면·활동 능력을 기록합니다. [인삼](../herbs/ginseng.md)·[황기](../herbs/astragalus.md), [당귀](../herbs/angelica.md)·[숙지황](../herbs/prepared-rehmannia.md), [녹용](../herbs/cervi-parvum-cornu.md)은 각각의 성미·구성 역할과 사용 조건을 본초 문서에서 확인합니다.

| 읽을 방향 | 처방 구조 | 현재의 회복 상황·연구 |
|---|---|---|
| 비위의 기허와 식욕·활동 저하 | [보중익기탕](../formulas/buzhong-yiqi-tang.md) | [원기회복](../conditions/energy-recovery.md) · [보중익기탕 연구](../research/formulas/buzhong-yiqi-tang.md) |
| 기와 혈을 함께 보하는 구조 | [팔물탕](../formulas/bazhen-tang.md) | [산후보약](../conditions/postpartum-herbal.md) · [보익 처방 근거 해석](../clinical-guides/tonic-research-deep-guide.md) |
| 기혈 부족에 피로·식욕·수면이 함께 문제되는 상황 | [인삼양영탕](../formulas/renshen-yangrong-tang.md) | [노인보약](../conditions/elderly-tonic.md) · [피로 한약 근거](../authority/formulas/chronic-fatigue-herbal-map.md) |
| 보익 본초의 가미와 전체 처방의 관계 | [녹용 본초](../herbs/cervi-parvum-cornu.md) · [보익 처방 계열](../formula-architecture/tonic-family.md) | [녹용보약](../conditions/deer-antler-tonic-guide.md) · [수술 후 회복](../conditions/postoperative-recovery.md) |

수술 후 회복·노쇠·산후 피로는 각각 평가할 원인과 목표가 다릅니다. 위 표는 상담과 문헌 탐색을 위한 연결이며 특정 보익 처방을 모든 회복기에 동일하게 적용하는 목록은 아닙니다.

## 동의보감 탕액편 임상 탐색 {#tangaek}

탕액편에서는 **약재의 이름·사용 부위·성질·수치와 복용 조건**을 읽습니다. 현재의 약재 기준명과 포제는 [본초 찾기](../herbal-integrated/herbs.md), 처방에서 각 약재가 맡는 역할은 [방제학](../formulas/index.md)으로 이어집니다.

예를 들어 담음에서 반하·진피·복령을 찾았다면 세 약재를 모두 화담이라는 말 하나로 묶기보다 조습·이기·수습 조절의 조합을 확인합니다. 허로에서 인삼·황기·당귀·숙지황을 찾았다면 보기와 보혈의 구성비·가감이 어느 처방에서 달라지는지를 살핍니다.

[탕액편 기준문서](../classics/donguibogam-tangaek.md) → [본초 근거](../authority/herbs/index.md) → [한약 안전성](../herbal-integrated/safety.md#safety-evidence-guide)로 연결합니다. 단일 성분의 실험 결과와 복합 처방을 환자에게 사용한 결과는 연구 단위를 구별해서 읽습니다.

## 동의보감 침구편 임상 탐색 {#acupuncture}

침구편은 **병증에서 경혈·자침·뜸으로 이어지는 사고 과정**을 살펴보는 출발점입니다. 혈명은 [WHO 표준 361경혈](../acupoint-network/standard-atlas.md), 경맥 관계는 [경락 지식망](../meridian-network/index.md)에서 확인합니다.

현대 침·전침 연구와 연결할 때는 경혈 이름뿐 아니라 수기침·전침의 구분, 전침 자극 조건, 치료 횟수·기간, 대조군과 평가 시점을 함께 확인합니다. 고전의 자침 설명만으로 현대 전침의 효과를 설명하지 않습니다.

[침구편 기준문서](../classics/donguibogam-acupuncture.md) · [침구 현대 근거](../evidence-integrated/acupuncture-evidence.md) · [침구 안전성](../acupuncture-integrated/safety.md)

## 동의보감 양생·예방 임상 지도 {#yangsaeng-prevention}

양생은 질병이 생긴 뒤 치료하는 것만이 아니라 **수면·식사·활동·정서·계절 적응을 통해 몸의 균형과 회복을 유지하는 관점**입니다.

### 현재 임상에서 연결할 항목 {#_8}
- 일정한 수면과 회복
- 과식·과음·과로 조절
- 계절과 기후에 따른 생활 조절
- 적절한 활동과 휴식
- 정서적 긴장과 신체 증상의 연동
- 연령·체력에 맞춘 보익과 생활관리

### 현대적으로 읽기 {#_9}
고전의 양생법을 그대로 의무화하기보다 현재의 수면위생·운동·식사·스트레스 관리와 조화시켜 실천 가능한 방향으로 해석합니다.

→ [자율신경·스트레스 지식망](../autonomic/index.md)  
→ [피로·회복](../conditions/fatigue.md)


## 동의보감 임상 탐색법 {#clinical-navigation}

### 탐색 순서 {#_10}
**환자의 말 → 위험신호 → 부위/장부/병증 분류 → 변증 → 치법 → 본초·방제·경혈 → 현대근거**

### 예시 {#_11}
- '목이 뻐근해요' → 외형편의 부위 탐색 → 경항부 위험신호 → 담경·방광경 → 경혈·통증 처방
- '속이 더부룩해요' → 내경·잡병 → 비위·담음·식적·간울 감별 → 소화 처방·경혈
- '기운이 없어요' → 내경·잡병의 허손 → 기허·혈허·신허 → 보익 본초·방제
