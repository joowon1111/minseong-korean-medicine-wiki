# 동의보감은 임상에서 어떻게 찾아보나?

동의보감은 방대한 내용을 담고 있기 때문에 **증상·부위·병증·약재·치료법**을 기준으로 탐색하면 이해하기 쉽다.

```text
어디가 불편한가?
   ↓
외형편

어떤 병증인가?
   ↓
잡병편

어떤 약재·처방인가?
   ↓
탕액편

어떤 침구치료인가?
   ↓
침구편

장부·기혈의 구조는?
   ↓
내경편
```

이런 구조는 오늘날 디지털 한의학 아카이브에서 메뉴·태그·검색을 설계하는 데도 매우 잘 맞는다.
