# 사상처방 상세 임상 카드 2차
1차의 태음조위탕·청심연자탕·형방지황탕·형방도적산·양격산화탕·곽향정기산에 이어 9개 처방을 확장합니다.

| 체질 | 확장 카드 | 비교의 중심 |
|---|---|---|
| 태음인 | [열다한소탕](yeoldahanso-tang.md) · [조위승청탕](jowiseungcheong-tang.md) · [청폐사간탕](cheongpyesagan-tang.md) | 표한·리열의 위치, 발한·대변·갈증·호흡과 전신 소증 |
| 소양인 | [독활지황탕](dokhwaljihwang-tang.md) · [형방사백산](hyeongbangsabaek-san.md) | 망음·음허오열과 표병의 경중·진액 변화 |
| 소음인 | [백하오이중탕](baekhao-ijung-tang.md) · [관계부자이중탕](gwangye-buja-ijung-tang.md) | 태음병 리한의 깊이, 설사·복통·구토·전신 냉감 |
| 태양인 | [오가피장척탕](ogapi-jangcheok-tang.md) · [미후등식장탕](mihudeung-sikjang-tang.md) | 해역과 열격의 핵심 병증 구분 |

> 체질명 또는 증상 하나로 처방하지 않고 체질·소증·현재 체질병증·중증도·치법을 먼저 봅니다.

## 두 묶음을 함께 사용하는 법

- [1차 대표 임상 카드](../sasang-formula-cards/index.md)는 자주 비교하는 처방의 기본 축을 제공합니다.
- 이 2차 카드는 같은 체질 안에서 병증 단계와 치법을 더 세밀하게 나눕니다.
- [15종 연결 지도](full-map.md)에서 전체 위치를 확인한 뒤 개별 카드로 이동하면 처방명만 나열해서 보는 오류를 줄일 수 있습니다.
- 더 세부적인 출전·구성·용량 자료는 [사상처방 전체 색인](../sasang-formula-library/index.md)에서 확인합니다.
