## 태양인

- [오가피장척탕](ogapi-jangcheok-tang.md): 해역증의 병증 구조에서 살핍니다.
- [미후등식장탕](mihudeung-sikjang-tang.md): 열격증의 섭취·구토와 전신 상태를 함께 봅니다.

```text
체질 → 소증 → 표/리 → 순/역 → 중증도 → 치법 → 처방
```

## 경과평가로 다시 연결하기

처방 후에는 현재 주증뿐 아니라 식욕·소화, 대변·소변, 땀, 수면, 한열, 갈증, 피로의 **평소 기준선 회복 여부**를 함께 봅니다. 호전이 한 방향으로 모이지 않거나 새로운 증상이 생기면 같은 처방군 안의 단순 가감보다 체질병증과 중증도를 다시 평가합니다.
