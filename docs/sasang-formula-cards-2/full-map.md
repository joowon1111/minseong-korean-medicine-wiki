# 주요 사상처방 15종 연결 지도

## 태음인
**표한:** 태음조위탕 → 조위승청탕 → (위중 단계 처방군)  
**리열:** 열다한소탕·청폐사간탕 → 청심연자탕 → (위증 처방군)

## 소양인
형방도적산 · 형방사백산 · 형방지황탕 · 양격산화탕 · 독활지황탕  
→ 표리·망음·흉격열·음허오열의 병증 구조에 따라 구분

## 소음인
백하오이중탕 · 곽향정기산 · 관계부자이중탕  
→ 태음병 자리/비만과 더 깊은 소음병 자리증을 구분

## 태양인
오가피장척탕 → 해역증  
미후등식장탕 → 열격증

```text
체질 → 소증 → 표/리 → 순/역 → 중증도 → 치법 → 처방
```
