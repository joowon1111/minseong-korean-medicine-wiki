# 오가피장척탕
**체질:** 태양인  
**큰 방향:** 해역증.

## 특히 보는 변화
요척·하지의 힘 저하, 기립·보행 불편, 전신 기능 저하를 체질·소증과 함께 봅니다.

`태양인 → 해역증 → 요척·하지 기능 저하 → 오가피장척탕`

태양인은 상대적으로 드문 체질이므로 증상 하나로 처방을 연결하지 않고 체질 확진과 병증 진단을 특히 신중히 합니다.

## 회복
하지 힘, 기립·보행, 일상활동이 회복되는지와 태양인의 건강신호인 **소변왕다**가 안정적인지 봅니다.
