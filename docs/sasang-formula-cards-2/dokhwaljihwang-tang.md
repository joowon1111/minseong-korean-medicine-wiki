# 독활지황탕(獨活地黃湯)

## 구성·용량·출전

| 본초 | 용량 |
|---|---:|
| 숙지황 | 15 g |
| 산수유 | 7.5 g |
| 복령 | 5.625 g |
| 택사 | 5.625 g |
| 독활 | 3.75 g |
| 목단피 | 3.75 g |
| 방풍 | 3.75 g |

**총량 45 g**

**출전:** 한국전통지식포탈 『동의사상신편』(1929), 소양인, P0018332. 포탈은 비만식체·음허오열 등을 주치병증으로 수록하며 물에 달여 복용하도록 기록한다.

**임상 위치:** 소양인 음허오열병 계열.
