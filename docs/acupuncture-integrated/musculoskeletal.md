# 근골격 통증 핵심 {#_1}

근골격 통증은 아픈 부위만 자극하기보다 **통증 발생 조직, 신경학적 상태, 움직임과 기능 제한, 회복 단계**를 함께 평가해 치료계획을 세웁니다.

## 먼저 구분 {#_2}

| 통증 유형 | 특징 | 평가 방향 |
|---|---|---|
| 근육·근막 | 압통·긴장, 특정 동작과 자세에서 악화 | 근력·길이·협응, 아시혈과 유발점 |
| 관절 | 가동범위 제한, 부종·잠김·불안정 | 관절선 압통, 특수검사, 영상 필요성 |
| 신경·방사통 | 저림·감각 변화·근력저하, 신경 경로 방사 | 근력·감각·반사, 신경긴장검사 |
| 염증성 | 휴식·야간통, 열감·부종·아침 강직 | 감염·염증성질환과 혈액검사 |
| 외상성 | 명확한 손상기전, 멍·부종·체중부하 곤란 | 골절·인대·힘줄 손상과 영상검사 |
| 내장 연관 | 움직임과 무관하거나 전신·장기 증상 동반 | 심폐·복부·비뇨기·부인과 감별 |

근육·근막 통증은 **어떤 근육·조직층에서 평소 증상이 재현되는지** 확인하고 기능·신경학적 소견과 함께 해석합니다. [MPS·근육·근막 아틀라스](../clinical-anatomy/mps-atlas.md)에서 주요 근육 20개 항목의 그림·기능·평가를 보고, [조직층 도해](../clinical-anatomy/mps-atlas.md#layers)와 [통증유발점·연관통](../clinical-anatomy/mps-atlas.md#assessment)을 함께 읽습니다.

## 기능으로 보기 {#_3}
통증점수뿐 아니라 **걷기·앉기·들기·팔 올리기·수면·업무·운동**이 얼마나 제한되는지 함께 봅니다.

| 현재 불편한 일 | 치료 목표로 구체화할 내용 |
|---|---|
| 고개를 돌리거나 옷을 입기 어려움 | 회전·팔 올리기의 통증과 가동범위 |
| 오래 앉거나 걷기 어려움 | 견딜 수 있는 시간·거리와 활동 뒤 회복 |
| 손으로 들거나 쥐기 어려움 | 반복 동작·악력과 저림의 변화 |
| 통증 때문에 자주 깸 | 야간 각성·자세와 다음 날 기능 |

국소 치료와 원위 경혈을 실제 진찰에 맞춰 계획하고, 운동·생활 조정도 같은 목표에 연결합니다. 근골격 통증의 한의학적 동반 양상은 [변증·처방·치료 비교](../pillar/pain-musculoskeletal.md#pattern-care-network), 처방 배합은 [통증 한약 안내](../herbal-integrated/formula-for-pain.md)에서 이어서 봅니다.

## 부위별 핵심 평가 {#_4}

| 부위 | 자주 확인하는 기능 | 놓치지 말아야 할 방향 |
|---|---|---|
| 목·어깨 | 회전·팔 올리기·견갑 움직임 | 진행성 근력저하, 외상, 흉통·호흡증상 |
| 허리 | 굴곡·신전·보행·앉기 | 대소변 장애, 안장부 감각, 발열·암 병력 |
| 턱관절 | 개구량·편위·관절음·저작 | 외상, 잠김, 감염·치과질환 |
| 손목·팔꿈치 | 쥐기·들기·회전·감각 | 골절, 힘줄파열, 신경포착 |
| 무릎 | 계단·쪼그리기·보행·부종 | 잠김·불안정, 급성 종창·발열 |
| 발목·발 | 체중부하·균형·보행 | 골절 기준, 심한 부종·혈관 문제 |

## 침구치료 구성 {#_5}

- **국소 치료:** 압통점·아시혈, 긴장 근육과 관절 주변
- **원위 경혈:** 경락 관계와 전신적 통증조절을 고려
- **전침:** 통증·근활성·신경재활 목표에 따라 설정
- **약침:** 제제와 목표 조직, 주입층·안전성을 고려
- **뜸·부항:** 냉감·긴장·피부 상태와 출혈 위험을 고려
- **운동·생활관리:** 가동범위, 점진적 부하, 자세와 업무 동작 조정

## 급성기와 만성기의 차이 {#_6}

| 단계 | 치료의 중심 |
|---|---|
| 급성 손상 | 골절·파열 배제, 부종·통증 조절과 보호 |
| 아급성 회복 | 가동범위 회복, 점진적 근활성·부하 |
| 만성 통증 | 기능회복, 수면·스트레스·회피행동과 재발요인 관리 |
| 수술·골절 후 | 수술 지침과 유합 상태를 확인하며 단계적 재활 |

근육·힘줄·관절의 회복 상태와 수술·골절 지침에 따라 허용되는 움직임이 달라집니다. 치료 직후 통증이 줄었다고 곧바로 높은 부하로 복귀하기보다 활동 직후와 다음 날의 반응을 확인합니다.

### 병행 치료와 근거를 연결하는 기준 {#care-evidence}

침·전침은 통증과 기능 회복을 목표로 구성하고, 약침은 사용 제제·목표 조직·주입층을 기록합니다. 한약·재활을 병행하면 각각 무엇을 목표로 했는지와 활동량·복용약의 변화도 함께 확인합니다. 모든 치료를 한 번에 같은 강도로 적용하는 고정 계획 대신 현재 문제와 반응에 따라 조정합니다.

[질환별 통증 근거 지도](../pillar/pain-musculoskeletal.md#pain-evidence-routes)에서는 요통·목·무릎·상지·하지 연구를 연결합니다. 연구의 치료 횟수·자극 방법·비교군·추적기간과 실제 진료의 차이를 확인하고, 다른 제형이나 치료의 결과로 바꾸어 읽지 않습니다.

## 경과관찰 {#_7}

통증점수만 낮아지고 기능이 그대로라면 치료 목표와 진단을 다시 검토합니다. 반대로 통증이 조금 남아도 가동범위·보행·수면·업무 기능이 안정적으로 회복되면 치료 간격과 운동량을 조정할 수 있습니다.

| 평가 지표 | 예 |
|---|---|
| 증상 | 통증 강도·빈도, 저림 범위 |
| 기능 | 보행거리, 앉는 시간, 팔 올리기, 쥐는 힘 |
| 신체검사 | 가동범위, 근력, 감각·반사 |
| 생활 | 수면, 업무·운동 복귀, 진통제 사용 |

치료 유지·간격 조정·원인 재평가의 판단은 [통증·기능 경과 확인](../pillar/pain-musculoskeletal.md#pain-function-followup)과 연결합니다.
