# 근골격 통증 핵심

## 먼저 구분
- 근육·근막
- 관절
- 신경·방사통
- 염증성 가능성
- 외상
- 내장 연관 가능성

## 기능으로 보기
통증점수뿐 아니라 **걷기·앉기·들기·팔 올리기·수면·업무·운동**이 얼마나 제한되는지 함께 봅니다.

```text
통증 위치
 + 유발/완화 동작
 + 가동범위
 + 압통
 + 감각·근력
 ↓
치료목표
 ↓
국소치료 + 원위 경혈 + 운동·생활관리
```
