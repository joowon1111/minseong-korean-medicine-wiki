# 안전·위험신호

## 시술 전 확인
- 출혈성 질환·항응고/항혈소판제
- 임신
- 피부감염·상처
- 면역저하
- 전침 사용 시 심박조율기 등 전기장치
- 실신 과거력

## 일반 의학적 평가가 우선인 신호
- 진행하는 근력저하
- 대소변 기능의 급격한 이상
- 의식 변화
- 심한 호흡곤란·흉통
- 고열과 전신쇠약
- 중대한 외상
- 지속적인 섭취불가·탈수

→ [안전·금기·위험신호 상세](../acupuncture-clinical/safety-redflags.md)

침구치료가 필요한 검사나 다른 치료를 지연시키는 이유가 되어서는 안 됩니다.
