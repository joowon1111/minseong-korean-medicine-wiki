# 안전·위험신호

침구치료의 안전성은 시술 기술뿐 아니라 **적응증 판단, 위험신호 확인, 해부학, 감염관리와 시술 후 관찰**을 포함합니다.

## 시술 전 확인

| 확인 항목 | 치료계획에 반영할 내용 |
|---|---|
| 출혈성 질환·항응고/항혈소판제 | 출혈·멍 위험, 자침 깊이와 부항·습식부항 여부 |
| 임신·임신 가능성 | 시술 자세, 복부·요천부와 강한 자극의 적절성 |
| 피부감염·상처 | 해당 부위 회피와 감염 치료 우선 여부 |
| 면역저하·당뇨 | 감염·상처 회복과 피부 상태 |
| 심박조율기 등 전기장치 | 전침 사용 여부와 전류 경로 |
| 감각저하·신경병증 | 뜸·온열·전침 강도와 화상 위험 |
| 실신·침 공포 과거력 | 식사 여부, 눕는 자세, 자극량과 관찰 시간 |
| 알레르기 | 약침 제제, 소독제·금속·접착제 반응 |

## 부위별 해부학적 주의

- 흉곽·견갑부: 폐와 흉막의 깊이와 자침 방향
- 목 앞·옆과 쇄골 주변: 큰 혈관·신경·기도 구조
- 후두하·척추 주변: 신경·혈관과 척추관 방향
- 복부·골반: 장기 위치, 수술력, 임신 여부
- 손목·팔꿈치·무릎·발목: 표재 신경과 혈관

해부학적 표지와 환자의 체형을 확인하며, 깊은 자침이 치료효과를 의미하는 것은 아닙니다.

## 일반 의학적 평가가 우선인 신호
- 진행하는 근력저하
- 대소변 기능의 급격한 이상
- 의식 변화
- 심한 호흡곤란·흉통
- 고열과 전신쇠약
- 중대한 외상
- 지속적인 섭취불가·탈수

## 시술 중·직후 확인

| 반응 | 우선 대응 방향 |
|---|---|
| 창백·식은땀·메스꺼움·어지럼 | 시술 중단, 눕히고 활력징후와 회복 확인 |
| 심한 전격통·지속 감각이상 | 즉시 자극 중단, 신경학적 상태 평가 |
| 호흡곤란·흉통·마른기침 | 기흉 등 중대한 합병증 가능성 평가 |
| 빠르게 커지는 부종·출혈 | 압박 지혈과 혈관 손상 평가 |
| 전신 두드러기·호흡 불편 | 알레르기·아나필락시스 응급대응 |

## 시술 후 안내

- 가벼운 국소 뻐근함이나 작은 멍은 일시적으로 생길 수 있습니다.
- 심해지는 통증, 열감·발적·고름, 지속되는 출혈이나 감각·근력 변화는 확인이 필요합니다.
- 흉곽 주변 시술 뒤 호흡곤란·흉통이 나타나면 지체하지 말고 응급평가를 받습니다.
- 뜸·온열 뒤 물집이나 화상이 생기면 임의로 터뜨리지 않고 상처 상태를 확인합니다.

## 치료별 핵심 안전 포인트

| 치료 | 핵심 확인 |
|---|---|
| 침 | 무균술, 해부학적 깊이·방향, 출혈과 실신 |
| 전침 | 전기장치, 감각저하, 강도와 전류 경로 |
| 약침 | 제제 추적성·알레르기·주입층·감염관리 |
| 뜸 | 화상·연기 노출·감각저하 |
| 부항 | 피부손상·수포·출혈 위험과 위생관리 |
