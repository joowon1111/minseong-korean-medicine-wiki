# 침구치료 경과·재평가

증상에 맞는 침구치료 후 **통증점수 하나가 아니라 증상 + 기능 + 생활 변화**를 함께 추적합니다.

## 초진 기준점

- 증상 강도·빈도·지속시간
- 가동범위·근력·감각
- 걷기·앉기·들기·계단·운전 등 실제 기능
- 수면·피로·식욕·배변
- 진통제·기타 약물 사용
- 업무·운동 수행
- 증상을 악화시키는 자세·활동·스트레스

## 증상군별 회복신호

| 증상군 | 초기 회복신호 | 다음 단계 |
|---|---|---|
| 허리·목·어깨·무릎 | 움직임이 조금 편해짐·야간통 감소 | ROM·보행·근력 회복 |
| 저림 | 범위 감소·발생빈도 감소 | 감각·근력·기능 회복 |
| 두통 | 빈도·지속시간 감소 | 진통제 사용·업무 기능 회복 |
| 불면 | 입면시간·각성 감소 | 아침 회복감·낮 기능 |
| 피로 | 회복시간 단축 | 활동량·운동·업무 회복 |
| 소화 | 식후 불편 감소 | 식사량·체중·배변 안정 |
| 비염 | 재채기·콧물·코막힘 감소 | 수면·약물사용 변화 |
| 기침 | 빈도·야간기침 감소 | 활동 시 호흡·수면 개선 |
| 어지럼 | 발생빈도·강도 감소 | 보행·일상활동 회복 |
| 부종 | 붓기·무거움 감소 | 배뇨·보행·신발 착용감 |

## 같은 동작·같은 기간으로 비교하기 {#same-task-comparison}

통증 점수가 줄었어도 활동을 줄여서 덜 아픈 경우와, **같은 활동을 더 편하게 수행하게 된 경우**는 경과가 다릅니다. 초진 때 환자가 실제로 불편해하는 동작 하나를 정하고, 다음 평가에서도 자세·부하·시간 조건을 가능한 한 맞춥니다.

아래는 경과 기록을 돕는 항목 예시입니다. 질환별 진단검사나 검증된 척도의 채점표를 대신하는 것은 아니며, 필요한 척도는 해당 문서와 원자료의 기준을 따릅니다.

| 주증상 | 반복해서 비교할 기능·일상 항목 | 함께 기록할 조건 |
|---|---|---|
| [요통](../conditions/low-back-pain.md) | 앉아 있기·일어나기·걷기 중 가장 불편한 동작 | 앉은 시간·보행량, 다리 저림·근력 변화, 약물 |
| [어깨통증](../conditions/shoulder-pain.md) | 팔 올리기·옷 입기·물건 꺼내기 | 능동·수동 가동범위, 부하, 야간통 |
| [턱관절통증](../conditions/temporomandibular-disorder.md) | 벌리기·씹기·하품 | 개구 범위·잠김, 음식의 단단함, 악습관 |
| [무릎통증](../conditions/knee-pain.md) | 보행·계단·의자에서 일어나기 | 거리·계단 수·보조기구, 부종과 활동량 |
| [두통](../conditions/headache.md) | 일정 기간의 두통 일수와 업무 방해 | 두통 지속·약물 사용일, 수면·월경·유발요인 |
| [불면](../conditions/insomnia.md) | 입면·밤중 각성·낮 기능 | 기상 시각·낮잠·수면약·카페인 변화 |
| [식후 불편](../conditions/functional-dyspepsia.md) | 비슷한 식사의 섭취량·식후포만·조기포만 | 음식 종류·양·시간, 배변·체중·병행약 |

**줄어든 증상, 늘어난 활동, 치료 후 불편을 따로 기록**하면 부분 호전의 의미가 분명해집니다. 근력이 떨어지거나 감각 범위가 넓어지는 변화는 통증 점수가 줄었더라도 별도로 평가합니다.

## 직후·다음 방문·치료 종료에서 보는 것 {#assessment-timing}

| 시점 | 확인할 질문 | 기록의 목적 |
|---|---|---|
| 치료 직후 | 같은 동작이 편해졌는가? 어지럼·출혈·예상 밖 통증은 없는가? | 즉시 반응과 시술 관련 불편 확인 |
| 다음 방문 | 편안함이 얼마나 지속됐는가? 다음 날 활동과 수면은 어땠는가? | 지속 반응·지연 불편과 생활 기능 확인 |
| 계획한 치료 과정의 종료 | 처음 정한 기능 목표가 달라졌는가? 약물·운동·업무는 어떻게 변했는가? | 계속 치료할 목표와 조정 이유 정리 |
| 치료 간격 조정·경과 관찰 | 치료 없는 날에도 기능을 유지하는가? 재발 시 어떤 조건이 겹치는가? | 회복 유지와 악화요인 파악 |

직후의 호전은 다음 치료를 설계하는 단서입니다. 지속되는 변화는 이후 방문과 생활 기록에서 확인합니다. 질환·중증도·치료 목표에 따라 평가 시점을 정하며 모든 증상에 같은 횟수를 적용하지 않습니다.

## 한약과 같이 치료할 때

```text
침구 반응
 +
한약 복용 후 증상·수면·소화·기력 변화
 ↓
병증 가설이 맞는가?
 ↓
유지 / 가감 / 치료전략 재평가
```

한약과 침구를 같이 사용했다고 해서 모든 변화를 한 치료법의 효과로 단정하지 않고, **시간 순서와 기능 변화를 함께 기록**합니다.

## 반응이 부족할 때

치료반응이 부족하다고 **자극을 무조건 강하게 하거나 같은 치료를 반복하지 않습니다.**

- 진단·감별이 맞는가
- 위험신호가 새로 생겼는가
- 치료목표가 현실적인가
- 운동·수면·업무·자세가 회복을 방해하는가
- 침구 전략 또는 한약 병증을 재평가할 필요가 있는가

## 치료 단계별 재평가 체크포인트

### 1차 체크
- 통증·증상 강도
- 급성 위험신호가 새로 생겼는가
- 치료 후 과도한 피로·통증 악화가 있는가

### 2차 체크
- ROM·보행·수면·식사·업무기능이 변했는가
- 증상 빈도·지속시간이 줄었는가
- 한약과 침구 중 어떤 변화가 먼저 나타났는가

### 만성기 체크
- 치료 없는 날에도 기능이 유지되는가
- 운동·업무·수면이 회복되고 있는가
- 치료 의존도가 줄고 있는가

### 반응에 따른 다음 선택

| 반응 | 다음 평가·조정 |
|---|---|
| 증상과 기능이 함께 호전 | 현재 목표의 달성 정도를 확인하고 활동 확대·치료 간격을 조정 |
| 통증은 감소했으나 기능이 그대로 | 부하·관절 움직임·근력과 두려움·생활 제약을 다시 확인 |
| 직후만 호전하고 곧 반복 | 효과 지속시간과 업무·운동·수면, 치료 구성·간격을 함께 검토 |
| 변화가 불분명 | 같은 조건으로 평가했는지, 진단·표적·병증과 목표가 적절한지 재확인 |
| 새 근력저하·감각 변화·진행하는 통증 | 원인과 위험신호를 먼저 평가하고 필요한 검사·진료로 연결 |

경혈·수기침·전침·유침시간과 병행치료를 함께 남기는 방법은 [배혈과 자극 조건의 기록](how-acupoints-combine.md#pairing-record)에서 볼 수 있습니다. 임상시험 보고 기준인 [STRICTA](https://pmc.ncbi.nlm.nih.gov/articles/PMC2882429/)의 항목을 참고하되, 위 표는 진료 경과를 정리하기 위한 아카이브의 실무 구성안입니다.

## 치료 방법·연구·경과로 이어가기 {#modality-care-routes}

치료를 몇 번·얼마 간격으로 받을지는 [치료 횟수·강도 안내](../acupuncture-clinical/dose-followup.md), 뻐근함·효과 지속·악화의 구분은 [치료 후 반응](../acupuncture-clinical/response-reassessment.md)으로 이어집니다. 약침을 받았다면 [제제와 국소 반응](../treatments/pharmacopuncture.md#pharmacopuncture-visit)도 함께 기록합니다.
