# 치료 경과·재평가

## 초진 기준점
- 통증 강도·빈도·지속시간
- 가동범위
- 걷기·앉기·들기 등 실제 기능
- 저림·방사통
- 수면
- 진통제 사용
- 업무·운동 수행

## 치료 후
```text
통증 변화 + 기능 변화 + 새 증상
 ↓
반응 양호 → 단계적 기능 회복
반응 부족 → 감별·목표·치료수단 재평가
```

치료반응이 부족하다고 **자극을 무조건 강하게 하는 방식**으로 접근하지 않습니다.
