# 침구치료 경과·재평가

30개 환자 증상 키워드를 치료한 뒤 **통증점수 하나가 아니라 증상 + 기능 + 생활 변화**를 함께 추적합니다.

## 초진 기준점

- 증상 강도·빈도·지속시간
- 가동범위·근력·감각
- 걷기·앉기·들기·계단·운전 등 실제 기능
- 수면·피로·식욕·배변
- 진통제·기타 약물 사용
- 업무·운동 수행
- 증상을 악화시키는 자세·활동·스트레스

## 증상군별 회복신호

| 증상군 | 초기 회복신호 | 다음 단계 |
|---|---|---|
| 허리·목·어깨·무릎 | 움직임이 조금 편해짐·야간통 감소 | ROM·보행·근력 회복 |
| 저림 | 범위 감소·발생빈도 감소 | 감각·근력·기능 회복 |
| 두통 | 빈도·지속시간 감소 | 진통제 사용·업무 기능 회복 |
| 불면 | 입면시간·각성 감소 | 아침 회복감·낮 기능 |
| 피로 | 회복시간 단축 | 활동량·운동·업무 회복 |
| 소화 | 식후 불편 감소 | 식사량·체중·배변 안정 |
| 비염 | 재채기·콧물·코막힘 감소 | 수면·약물사용 변화 |
| 기침 | 빈도·야간기침 감소 | 활동 시 호흡·수면 개선 |
| 어지럼 | 발생빈도·강도 감소 | 보행·일상활동 회복 |
| 부종 | 붓기·무거움 감소 | 배뇨·보행·신발 착용감 |

## 한약과 같이 치료할 때

```text
침구 반응
 +
한약 복용 후 증상·수면·소화·기력 변화
 ↓
병증 가설이 맞는가?
 ↓
유지 / 가감 / 치료전략 재평가
```

한약과 침구를 같이 사용했다고 해서 모든 변화를 한 치료법의 효과로 단정하지 않고, **시간 순서와 기능 변화를 함께 기록**합니다.

## 반응이 부족할 때

치료반응이 부족하다고 **자극을 무조건 강하게 하거나 같은 치료를 반복하지 않습니다.**

- 진단·감별이 맞는가
- 위험신호가 새로 생겼는가
- 치료목표가 현실적인가
- 운동·수면·업무·자세가 회복을 방해하는가
- 침구 전략 또는 한약 병증을 재평가할 필요가 있는가

## 치료 단계별 재평가 체크포인트

### 1차 체크
- 통증·증상 강도
- 급성 위험신호가 새로 생겼는가
- 치료 후 과도한 피로·통증 악화가 있는가

### 2차 체크
- ROM·보행·수면·식사·업무기능이 변했는가
- 증상 빈도·지속시간이 줄었는가
- 한약과 침구 중 어떤 변화가 먼저 나타났는가

### 만성기 체크
- 치료 없는 날에도 기능이 유지되는가
- 운동·업무·수면이 회복되고 있는가
- 치료 의존도가 줄고 있는가

### 반응에 따른 다음 선택
| 반응 | 다음 단계 |
|---|---|
| 분명한 호전 | 치료 간격·강도 조절, 기능회복 확대 |
| 부분 호전 | 병증·혈위·치료수단·생활요인 재검토 |
| 변화 없음 | 진단·감별·목표 재설정 |
| 악화 | 위험신호 확인 후 치료전략 재평가 |
