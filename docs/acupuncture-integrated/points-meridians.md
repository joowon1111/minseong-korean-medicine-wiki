# 경혈·경락 찾기

## 경혈을 찾는 네 가지 층
1. **국소 경혈** — 증상 부위 주변
2. **원위 경혈** — 관련 경락을 따라 선택
3. **병증 배혈** — 한열·허실·장부·기혈 병증
4. **기능·압통점** — 근육·근막·움직임과 연결

```text
증상·병증
 ↓
관련 경락
 ↓
원위혈 + 국소혈/압통점
 ↓
자침 방법·자극량
```
