# 근거·연구

침 연구는 **비교군을 어떻게 설정했는가**가 특히 중요합니다.

```text
침 vs 무치료
침 vs 통상치료
침 vs 가짜침(sham)
침 + 통상치료 vs 통상치료
```

## 논문을 볼 때
- 대상 질환·환자군
- 경혈과 자침방법
- 수기침/전침
- 치료 횟수·기간
- 비교군
- 통증뿐 아니라 기능 결과
- 이상반응
- 효과크기와 근거확실성
