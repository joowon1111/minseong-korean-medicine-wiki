# 사상의학 한눈에 보기

사상의학을 **체질 → 평소 소증 → 몸이 나빠질 때의 변화 → 체질병증 → 대표처방 → 회복** 순서로 빠르게 탐색합니다.

| 체질 | 먼저 볼 것 | 대표 병증 축 | 바로가기 |
|---|---|---|---|
| 소양인 | 대변·한열·갈증·수면 | 망음 · 흉격열 · 음허오열 | [소양인](soyangin.md) |
| 태음인 | 땀·호흡·소화·한열 | 위완수한표한 · 간수열리열 | [태음인](taeeumin.md) |
| 소음인 | 소화·설사·냉감·발한 | 태음병 · 소음병 · 망양 | [소음인](soeumin.md) |
| 태양인 | 소변·섭취·하지기능 | 열격 · 해역 | [태양인](taeyangin.md) |

## 가장 빠른 탐색
**처방을 찾는다면** → [대표처방 찾기](formulas.md)  
**비슷한 병증을 구분한다면** → [병증 비교](patterns.md)  
**원전·논문을 확인한다면** → [근거·출전](evidence.md)

```text
체질 → 소증 → 병증 → 처방 → 구성본초·용량 → 출전 → 치료 후 재평가
```
