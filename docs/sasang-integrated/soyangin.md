# 소양인

## 한눈에
**건강 기준:** 대변선통을 중요한 소증 기준으로 봅니다.  
**핵심 감별:** 망음 ↔ 흉격열 ↔ 음허오열.

## 몸이 나빠질 때
- 복통·설사와 소모가 중심 → **망음 축**
- 열·구갈·흉격 번열이 중심 → **흉격열 축**
- 배뇨·하지위약·관절통·전신소모가 깊어짐 → **음허오열 축**
