# 태양인

태양인은 다른 체질보다 자료와 처방 수가 제한적이므로 **숫자를 억지로 맞추지 않고 핵심 병증과 처방을 중심으로** 봅니다.

## 핵심 감별
- 요척·하지 힘 저하, 기립·보행 문제 → **해역**
- 연하·섭취곤란, 구토·역류 → **열격**

## 핵심처방
- 오가피장척탕 — 해역
- 미후등식장탕 — 열격
