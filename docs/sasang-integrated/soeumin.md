# 소음인

## 한눈에
**건강 기준:** 음식선화, 즉 음식의 소화·수납 상태를 중요한 기준으로 봅니다.  
**핵심 감별:** 태음병 ↔ 소음병, 그리고 표병의 망양.

## 몸이 나빠질 때
- 복통·설사·냉감이 있으나 비교적 얕은 단계 → **태음병 축**
- 갈증·심번·수족냉·전신통·쇠약이 더해짐 → **소음병 축**
- 발한과 전신상태가 무너지는 표병 역증 → **망양 축**

- **[곽향정기산 — 소음인방](../sasang-formula-cards/gwakhyangjeonggi-san.md)** — 소음인 비위·한습 계열
- **[관계부자이중탕](../sasang-formula-cards/gwangye-buja-ijung-tang.md)** — 더 깊은 리한·허한 방향
- **[계지반하생강탕](#soeum-gyeji-banha)** — 허한성 구토·수결흉

- **[관중탕](#soeum-gwanjung)** — 흉복통·배뇨불리·사지권태

## 천궁계지탕 빠른 카드
**병증:** 소음인 태양증.  
**구성:** 계지 7.5 g, 백작약·진피·천궁·감초 각 3.75 g.  
**출전:** 『동의사상신편』(1929), P0018136.

<a id="soeum-gyeji-banha"></a>
## 계지반하생강탕 빠른 카드
**병증:** 허한성 구토·수결흉.  
**구성:** 생강 11.25 g, 계지·반하 각 7.5 g, 백작약·백출·자감초·진피 각 3.75 g.  
**출전:** 『동의사상신편』(1929), P0018146.

<a id="soeum-seungyangikgi"></a>
## 승양익기탕 빠른 카드
**병증:** 소음인 태양증·망양초증.  
**구성:** 계지·백작약·인삼·황기 각 7.5 g, 관계·당귀·자감초·백하수오 각 3.75 g.  
**출전:** 『동의사상신편』(1929), P0018132.

<a id="soeum-seungyangikgi-buja"></a>
## 승양익기부자탕 빠른 카드
**병증:** 소음인의 위중한 망양증.  
**구성:** 계지·백작약·인삼·황기 각 11.25 g, 관계·당귀·부자·감초·백하수오 각 3.75 g.  
**출전:** 『동의사상신편』(1929), P0018130.

<a id="soeum-insam-gwangye-buja"></a>
## 인삼관계부자탕 빠른 카드
**병증:** 소음인 망양증.  
**구성:** 관계 18.75 g 또는 37.5 g, 황기 11.25 g, 백작약 7.5 g, 포부자 3.75–7.5 g, 당귀·감초 각 3.75 g.  
**출전:** 『동의사상신편』(1929), P0018131.

<a id="soeum-sibimi-gwanjung"></a>
## 십이미관중탕 빠른 카드
**병증:** 소음인 위장병.  
**구성 핵심:** 대복피·목향·지실·후박 각 18.75 g, 건강·양강·익지인·적하수오·진피·청피·향부자·백하수오 각 3.75 g, 대조 2매.  
**출전:** 『동의사상신편』(1929), P0018150.

<a id="soeum-gwanjung"></a>
## 관중탕 빠른 카드
**병증:** 흉복통·배뇨불리·사지권태 등의 맥락.  
**구성:** 건강·양강·오령지·익지인·청피 각 3.75 g.  
**출전:** 『동의사상신편』(1929), P0018171.
