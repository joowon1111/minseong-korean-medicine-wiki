# 경악전서 탐색

《경악전서》는 장경악의 이론과 임상 경험을 집대성한 명대 종합 의서로, 음양·장부와 정기의 관점에서 허손·잡증·본초·방제를 폭넓게 연결합니다.

## 이 고전에서 먼저 볼 질문

- 허손은 기·혈·음·양의 부족과 동반 병리를 어떻게 구분하는가?
- 보법은 언제 필요하며 담습·어혈·울체·열과 어떻게 감별하는가?
- 본초와 처방을 치료 방향에 따라 어떻게 분류하는가?

## 핵심 탐색축

| 탐색축 | 임상적으로 읽는 관점 |
|---|---|
| 전충록·맥신장 | 기본 의론과 맥진 |
| 잡증모 | 내과 잡증의 병기·치법 |
| 본초정 | 본초의 성미와 임상 운용 |
| 고방팔진·신방팔진 | 기존 처방과 신방을 치료 방향으로 분류 |

## 다른 고전과 함께 읽기

- [금궤요략](jingui-yaolue.md)의 허로와 경악전서의 허손·보법을 비교합니다.
- [동의보감](donguibogam.md)의 허로·정혈·보익 구조와 함께 봅니다.
- [동의수세보원](donguisusebowon.md)의 체질별 정기·병증 관점과 구분해 읽습니다.

고전의 병증을 현대 질환명과 곧바로 동일시하지 않고, **원문 맥락 → 변증과 치법 → 본초·방제·경혈 → 현대 진단과 근거**의 순서로 연결합니다.
