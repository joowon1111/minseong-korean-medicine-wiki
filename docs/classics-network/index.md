## 고전을 임상적으로 읽는 공통 순서

1. 원문에서 관찰한 증상·맥증·설명 범위를 확인합니다.
2. 한열·허실·표리, 장부·기혈·진액과 병의 전변을 구분합니다.
3. 제시된 치법이 어떤 병기 판단에서 나왔는지 봅니다.
4. 본초·방제·경혈·침구가 치법과 어떻게 연결되는지 살핍니다.
5. 판본·용량·제법의 차이와 현대의 진단·안전성 정보를 확인합니다.
6. 사람 대상 현대 연구가 있다면 대상군·중재·평가지표를 함께 봅니다.

## 서로 연결해서 읽기

- **황제내경 ↔ 난경**: 기초 이론에서 맥진·경락·수혈·침법으로
- **상한론 ↔ 금궤요략**: 외감병과 잡병에서 병증·치법·고방으로
- **의학입문 ↔ 동의보감**: 종합 의학 학습과 조선 임상 체계로
- **경악전서 ↔ 보익·방제**: 허손·음양·잡증에서 치료 원칙과 처방으로
- **상한론 ↔ 온병조변**: 한사와 온열성 병증의 서로 다른 전변 체계로
- **동의보감 ↔ 동의수세보원**: 종합 임상에서 체질별 병증·처방으로
