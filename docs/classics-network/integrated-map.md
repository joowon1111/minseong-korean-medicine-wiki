# 고전 통합 임상 지도

| 고전 | 핵심 탐색축 |
|---|---|
| 황제내경 | 음양·장부·경락·병기·침구 |
| 난경 | 맥진·경락·기경팔맥·수혈·침법 |
| 상한론 | 육경병·맥증·고방 |
| 금궤요략 | 잡병·부인병·고방 |
| 의학입문 | 기초이론·진단·본초·상한·내상·잡병·침구 |
| 동의보감 | 내경·외형·잡병·탕액·침구 |
| 경악전서 | 음양·장부·허손·보법·잡증·본초·방제 |
| 온병조변 | 삼초변증·위기영혈·온병 치법과 처방 |
| 동의수세보원 | 사상체질·소증·체질병증 |

고전을 현대 질환명과 직접 일대일 대응시키지 않고 **원문 병증 → 진단과 변증 → 치법 → 본초·방제·경혈 → 현대 연구**로 연결합니다.

→ [고전→현대 연구](../network/classic-to-evidence-map.md)

## 임상 질문에서 고전으로 이동하기

| 임상 질문 | 먼저 볼 고전 |
|---|---|
| 장부·기혈·경락의 기본 관계가 궁금하다 | 황제내경 |
| 맥진·기경팔맥·오수혈을 찾고 싶다 | 난경 |
| 외감병의 전변과 고방을 보고 싶다 | 상한론 |
| 만성 잡병·허로·담음·부인병 처방을 찾고 싶다 | 금궤요략 |
| 기초부터 본초·각과·침구까지 연결하고 싶다 | 의학입문 |
| 증상 부위에서 탕액·침구까지 찾고 싶다 | 동의보감 |
| 허손·보법·잡증과 방제를 보고 싶다 | 경악전서 |
| 온열성 병증의 단계와 진액 손상을 보고 싶다 | 온병조변 |
| 체질·소증·표리병증·체질처방을 보고 싶다 | 동의수세보원 |

## 아카이브 연결 원칙

고전의 문장 하나를 현대 치료 효과의 직접 근거로 사용하지 않습니다. 고전은 병기와 치법의 출전으로, 현대 연구는 실제 대상·중재·평가지표의 근거로 구분한 뒤 서로 연결합니다.
