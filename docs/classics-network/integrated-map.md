# 고전 통합 임상 지도

| 고전 | 핵심 탐색축 |
|---|---|
| 황제내경 | 음양·장부·경락·병기·침구 |
| 난경 | 맥진·경락·기경팔맥·수혈·침법 |
| 상한론 | 육경병·맥증·고방 |
| 금궤요략 | 잡병·부인병·고방 |
| 의학입문 | 기초이론·진단·본초·상한·내상·잡병·침구 |
| 동의보감 | 내경·외형·잡병·탕액·침구 |
| 경악전서 | 음양·장부·허손·보법·잡증·본초·방제 |
| 온병조변 | 삼초변증·위기영혈·온병 치법과 처방 |
| 동의수세보원 | 사상체질·소증·체질병증 |

고전을 현대 질환명과 직접 일대일 대응시키지 않고 **원문 병증 → 진단과 변증 → 치법 → 본초·방제·경혈 → 현대 연구**로 연결합니다.
