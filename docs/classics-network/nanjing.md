# 난경 탐색

《난경》은 《황제내경》의 어려운 쟁점을 81개 문답으로 압축한 고전입니다. 특히 촌구맥, 기경팔맥, 오수혈과 침법을 함께 탐색할 때 가치가 큽니다.

## 이 고전에서 먼저 볼 질문

- 촌구맥을 통해 장부와 병증을 판단하는 논리는 무엇인가?
- 기경팔맥은 십이경맥과 어떤 관계를 이루는가?
- 오수혈·원혈과 보사법은 허실 판단에 어떻게 연결되는가?

## 핵심 탐색축

| 탐색축 | 임상적으로 읽는 관점 |
|---|---|
| 1–22난 | 촌구맥과 맥진 |
| 23–29난 | 경락과 기경팔맥 |
| 30–61난 | 영위·삼초·장부·허실·병인·진단 |
| 62–81난 | 오수혈·원혈·보사·침법 |

## 다른 고전과 함께 읽기

- [황제내경](huangdi-neijing.md)의 넓은 이론을 난경의 문답식 쟁점과 비교합니다.
- [의학입문](uihak-ipmun.md)에서 맥진·장부·경락·침구가 종합 학습체계로 이어지는 모습을 봅니다.
- 현대 경혈 문서에서는 고전 주치와 해부학적 위치·안전성을 구분해 확인합니다.

고전의 병증을 현대 질환명과 곧바로 동일시하지 않고, **원문 맥락 → 변증과 치법 → 본초·방제·경혈 → 현대 진단과 근거**의 순서로 연결합니다.
