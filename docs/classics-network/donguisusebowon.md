# 동의수세보원 탐색

《동의수세보원》은 이제마가 사람의 체질적 생리와 병리, 소증, 표리병증과 치료를 태양인·태음인·소양인·소음인의 체계로 정리한 사상의학의 핵심 고전입니다.

## 이 고전에서 먼저 볼 질문

- 체질의 장부 대소는 해부학적 크기가 아니라 어떤 기능 관계를 뜻하는가?
- 평소 소화·땀·대변·수면 같은 소증이 현재 병증 판단에 왜 중요한가?
- 같은 체질에서도 표리·순역·경중에 따라 처방이 왜 달라지는가?

## 핵심 탐색축

| 탐색축 | 임상적으로 읽는 관점 |
|---|---|
| 사상인과 장부 | 체질별 기능의 상대적 강약 |
| 성정과 생리 | 성정의 편차와 장부 기능의 관계 |
| 소증·표리병증 | 평소 상태와 현재 병의 위치·경과 |
| 치료 원칙과 처방 | 체질명보다 현재 병증과 치료 반응을 함께 판단 |

## 다른 고전과 함께 읽기

- [동의보감](donguibogam.md)의 종합 병증 체계와 사상의학의 체질별 병증 체계를 비교합니다.
- [경악전서](jingyue-quanshu.md)의 음양·허손 관점과 체질의 장부·소증 관점을 구분합니다.
- 체형이나 성격 하나만으로 체질을 자가판정하지 않고 진단 근거와 경과를 종합합니다.

고전의 병증을 현대 질환명과 곧바로 동일시하지 않고, **원문 맥락 → 변증과 치법 → 본초·방제·경혈 → 현대 진단과 근거**의 순서로 연결합니다.
