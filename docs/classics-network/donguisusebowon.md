# 동의수세보원

《동의수세보원》은 이제마가 사상의학의 체질·생리·병리·병증·치료 원칙을 체계화한 핵심 고전이다.

```text
동의수세보원
 ↓
태양인 · 소양인 · 태음인 · 소음인
 ↓
체질별 생리·병리
 ↓
체질병증
 ↓
치법·처방
```

한의학 고전의 긴 흐름 속에서 **개인의 체질적 차이**를 임상 판단의 중심 축으로 체계화했다는 점이 중요하다.
