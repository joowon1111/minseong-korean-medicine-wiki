# 의학입문 탐색

《의학입문》은 의학을 처음 배우는 사람이 이론에서 진단과 치료까지 단계적으로 익히도록 구성한 명대 종합 의서입니다.

## 이 고전에서 먼저 볼 질문

- 기초 이론과 실제 진단·치료를 어떤 순서로 공부하도록 구성했는가?
- 본초·방제·침구가 각과 병증과 어떻게 연결되는가?
- 명대 의학의 종합이 조선의 의학 학습에 어떤 영향을 주었는가?

## 핵심 탐색축

| 탐색축 | 임상적으로 읽는 관점 |
|---|---|
| 내집 | 의학사·운기·경락·장부·진단·본초 |
| 외집 | 상한·내상·잡병·부인·소아·외과·침구 |
| 운문과 주석 | 핵심을 기억하고 세부 설명을 확장하는 학습 방식 |
| 조선의 수용 | 의학 교육·시험·필사와 후대 임상서에 미친 영향 |

## 다른 고전과 함께 읽기

- [황제내경](huangdi-neijing.md)·[난경](nanjing.md)의 이론이 종합 학습서에 편입되는 방식을 봅니다.
- [동의보감](donguibogam.md)과 종합 의서의 편제·임상 탐색 방식을 비교합니다.
- [방약합편](../bangyakhappyeon-network/index.md)에 이어진 진단·잡병·처방의 압축 방식을 살핍니다.

고전의 병증을 현대 질환명과 곧바로 동일시하지 않고, **원문 맥락 → 변증과 치법 → 본초·방제·경혈 → 현대 진단과 근거**의 순서로 연결합니다.
