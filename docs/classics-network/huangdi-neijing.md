# 황제내경 탐색

《황제내경》은 한의학의 생리·병리·진단·치료·예방을 이해하는 가장 넓은 이론적 기반입니다. 《소문》의 이론과 《영추》의 경락·침구 논의를 함께 보아야 전체 구조가 드러납니다.

## 이 고전에서 먼저 볼 질문

- 같은 증상이 한열·허실에 따라 어떻게 다르게 해석되는가?
- 장부·기혈·진액·경락은 하나의 병기 안에서 어떻게 연결되는가?
- 치미병·계절·생활관리와 치료 원칙은 어떤 관계인가?

## 핵심 탐색축

| 탐색축 | 임상적으로 읽는 관점 |
|---|---|
| 음양·오행 | 대립과 균형, 변화의 방향을 해석하는 기본 언어 |
| 장부·기혈진액 | 기능체계와 인체 물질·활동의 관계 |
| 병인·병기·진단 | 원인보다 현재 형성된 병리 과정과 증후를 함께 판단 |
| 경락·침구·양생 | 경맥과 자법, 예방과 계절 생활을 치료체계에 연결 |

## 다른 고전과 함께 읽기

- [난경](nanjing.md)과 함께 맥진·기경팔맥·수혈 이론을 심화합니다.
- [상한론](shanghan-lun.md)에서 이론이 구체적인 병증·처방 운용으로 이어지는 방식을 봅니다.
- [동의보감](donguibogam.md)에서 조선 의학이 내경의 개념을 어떻게 재구성했는지 살핍니다.

고전의 병증을 현대 질환명과 곧바로 동일시하지 않고, **원문 맥락 → 변증과 치법 → 본초·방제·경혈 → 현대 진단과 근거**의 순서로 연결합니다.
