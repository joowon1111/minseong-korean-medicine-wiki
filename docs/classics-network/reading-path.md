# 한의학 고전은 어떤 순서로 읽으면 좋은가? {#_1}

## 세 가지 추천 경로 {#_4}

### 진단·경락·침구 중심 {#_5}

황제내경 → 난경 → 동의보감 침구편 → 현대 경락·경혈 지식망

### 병증·방제 중심 {#_6}

상한론 → 금궤요략 → 의학입문 → 동의보감 → 경악전서

### 온병 또는 체질의학에 관심이 있다면

온열성 병증이 목적이면 황제내경의 열병·병기에서 [온병조변](../classics/wenbing-tiaobian.md)과 온병학 지식망으로 이어갑니다. 체질의학이 목적이면 [동의수세보원](../classics/donguisusebowon.md)에서 장부·소증·표리병증을 차례로 읽습니다. 온병학을 마쳐야 사상의학으로 넘어가는 필수 학습 순서나, 한 이론이 다른 이론으로 발전했다는 계보를 뜻하지 않습니다.

원문 전체를 한 번에 읽기보다 대표 병증 하나를 정해 여러 고전에서 **증상 표현·병기·치법·처방**이 어떻게 달라지는지 비교하면 실제 연결관계를 이해하기 쉽습니다.

| 기록 | 예시 질문 |
