# 한의학 고전은 어떤 순서로 읽으면 좋은가?

처음부터 원문 전체를 차례로 읽기보다 **기초이론 → 병증·처방 → 종합 학습서 → 조선 의학 → 체질의학**의 흐름으로 접근하면 이해하기 쉽습니다.

1. [황제내경](huangdi-neijing.md) — 음양·장부·기혈·경락의 핵심 개념
2. [상한론](shanghan-lun.md) — 육경병증과 대표 처방
3. [금궤요략](jingui-yaolue.md) — 주요 잡병과 처방 연결
4. [의학입문](uihak-ipmun.md) — 기초·진단·본초·각과 임상을 종합하는 학습 구조
5. [동의보감](donguibogam.md) — 내경·외형·잡병·탕액·침구의 조선 의학 체계
6. [동의수세보원](donguisusebowon.md) — 체질·소증·병증·처방 구조

## 목적에 따라 다르게 읽기

| 관심 분야 | 먼저 볼 고전 |
|---|---|
| 기초이론·장부·경락 | 황제내경 |
| 고방·외감병·육경 | 상한론 |
| 잡병과 처방 | 금궤요략 |
| 의학 입문과 종합 임상 학습 | 의학입문 |
| 한국 한의학·양생·탕액·침구 | 동의보감 |
| 사상체질과 체질병증 | 동의수세보원 |

고전을 하나씩 분리하기보다 공통 개념과 서로 다른 임상 초점을 비교하고, 원문 병증을 현대 질환명과 곧바로 동일시하지 않는 것이 중요합니다.
