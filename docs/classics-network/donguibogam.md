# 동의보감 탐색

《동의보감》은 인체 내부, 신체 부위, 각종 병증, 약물과 침구를 다섯 편으로 조직한 조선 한의학의 대표 종합 의서입니다.

## 이 고전에서 먼저 볼 질문

- 증상은 내경·외형·잡병 가운데 어디에서 찾아야 하는가?
- 병증 설명에서 본초·방제·침구로 어떻게 이동하는가?
- 양생·예방과 질병 치료가 한 체계 안에서 어떻게 연결되는가?

## 핵심 탐색축

| 탐색축 | 임상적으로 읽는 관점 |
|---|---|
| 내경편 | 정·기·신·장부·기혈진액과 인체 내부 |
| 외형편 | 머리·얼굴·목·가슴·배·허리·사지 등 부위별 탐색 |
| 잡병편 | 병인·외감·내상·허로·부인·소아 등 병증 |
| 탕액편·침구편 | 본초·약성·처방과 경락·경혈·자법 |

## 다른 고전과 함께 읽기

- [의학입문](uihak-ipmun.md)과 종합 의학서의 학습·임상 편제를 비교합니다.
- [황제내경](huangdi-neijing.md)의 이론이 동의보감에서 어떻게 인용·재구성되는지 봅니다.
- [동의수세보원](donguisusebowon.md)과 종합 임상·체질 임상의 관점 차이를 살핍니다.

고전의 병증을 현대 질환명과 곧바로 동일시하지 않고, **원문 맥락 → 변증과 치법 → 본초·방제·경혈 → 현대 진단과 근거**의 순서로 연결합니다.
