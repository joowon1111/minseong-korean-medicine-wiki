# 동의보감

《동의보감》은 조선 한의학의 대표적인 의학서로, 인체·질병·본초·처방·침구 등 방대한 의학 지식을 체계적으로 정리했다.

```text
동의보감
├─ 내경
├─ 외형
├─ 잡병
├─ 탕액
└─ 침구
```

이 구조는 인체 내부의 생리와 병리, 외형적 부위, 다양한 질환, 약물, 침구를 한 체계 안에서 살펴볼 수 있게 한다.
