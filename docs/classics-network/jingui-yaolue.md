# 금궤요략 임상 탐색

《금궤요략》은 장중경 의학의 잡병 영역을 보여주는 핵심 고전입니다. 내과·부인과의 다양한 병증을 병기와 치법, 처방의 구조로 연결합니다.

## 이 고전에서 먼저 볼 질문

- 허로·담음·수기·흉비는 어떤 증후 조합으로 구분되는가?
- 만성·복합 증상에서 정기와 사기의 관계를 어떻게 보는가?
- 부인병과 복부 병증의 처방은 어떤 병기 판단에서 출발하는가?

## 핵심 탐색축

| 탐색축 | 임상적으로 읽는 관점 |
|---|---|
| 허로 | 기혈음양의 부족과 동반 병리 |
| 담음·수기 | 체액 정체의 위치와 증상 조합 |
| 흉비·심통·복만 | 흉복부 증상과 한열·허실 |
| 부인병·고방 | 월경·임신·산후 병증과 처방 구조 |

## 다른 고전과 함께 읽기

- [상한론](shanghan-lun.md)의 육경 전변과 금궤요략의 잡병 병증을 함께 봅니다.
- [경악전서](jingyue-quanshu.md)의 허손·보법과 금궤의 허로를 비교합니다.
- 고방은 처방명보다 원문 병증·용량·제법을 먼저 확인합니다.

고전의 병증을 현대 질환명과 곧바로 동일시하지 않고, **원문 맥락 → 변증과 치법 → 본초·방제·경혈 → 현대 진단과 근거**의 순서로 연결합니다.
