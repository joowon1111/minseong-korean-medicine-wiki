# 청영탕(清營湯)

청영탕은 《온병조변》에서 **영분의 열을 맑히면서 손상된 음액을 돌보는 배합**을 읽는 대표 처방입니다. 청영해독과 투열양음을 함께 설명하며, 단순한 발열 처방이나 일상적 수면 처방으로 묶지 않습니다.

## 원문과 병증 {#source-pattern}

상초편 15·30조는 설강·수면·갈증·의식과 진액의 관계에서 청영법을 설명합니다. 습과 건조에 따라 황련의 사용 조건이 달라지므로 영분증이라는 이름과 실제 증후를 함께 봅니다.

[원문 발췌·한국어 독해](../classics/wenbing-tiaobian.md#upper-030) → [위기영혈의 영분](../wenbing-network/index.md#ying-xue-stages) 순으로 보면 열의 깊이뿐 아니라 진액과 습의 상태가 왜 중요한지 이해할 수 있습니다.

## 구성과 방의 {#composition}

원전 구성은 **서각·생지·현삼(元參)·죽엽심·맥문동·단삼·황련·금은화·연교**입니다. 원전의 서각 표기는 문헌 확인용이며, 현재 사용하는 제제는 대체 원료를 포함한 실제 허가 구성과 기원을 별도로 확인합니다.

| 배합 | 읽을 역할 |
|---|---|
| [생지황](../herbs/fresh-rehmannia.md)·[현삼](../herbs/scrophularia.md)·[맥문동](../herbs/ophiopogon.md) | 열과 함께 손상된 음액을 돌보는 축 |
| [금은화](../herbs/honeysuckle.md)·[연교](../herbs/forsythia.md) | 청열해독과 열을 투달시키는 축 |
| [황련](../herbs/coptis.md)·죽엽심 | 번열을 다루는 배합; 원문에서 황련 가감 조건도 확인 |
| [단삼](../herbs/salvia.md) | 혈분의 소통을 함께 고려하는 구성 |

생지황·현삼·맥문동의 비중과 투열약의 결합은 청열과 진액 회복을 함께 살피는 구조입니다.

## 원전 구성과 현대 제제를 구분하기 {#processing}

| 확인점 | 기록 원칙 |
|---|---|
| 서각 표기 | 역사적 원문으로 보존하되 실제 제제의 합법적 대체 원료와 허가 구성을 별도 확인 |
| 생지황·현삼·맥문동 | 생지황과 숙지황을 바꾸지 않고 약용부위·가공 확인 |
| 금은화·연교·죽엽심 | 원료 규격과 향기성분을 고려한 실제 전탕법 기록 |
| 황련 | 생품·포제품과 출전상 가감 조건 구분 |
| 현대 연구 | 원방·가감방·대체 원료·추출제의 구성을 그대로 제시 |

현대 임상자료는 실제 제제의 성분표·원료·제형을 기준으로 비교합니다.

## 청영·양음·투열이 한 방에 있는 이유 {#original-pattern-course}

《온병조변》 상초 30조는 열과 불안정한 수면·번갈·설적·간헐적 섬어를 함께 읽고 청영탕을 제시하면서 백활태의 경우를 구별합니다. 상초 15조에는 설강·건조와 갈증의 관계에 따라 황련을 빼는 조건도 나옵니다. 같은 영분의 열이라는 설명 안에서도 습과 진액의 상태에 따라 구성이 달라집니다. [상초 15·30조 독해](../classics/wenbing-tiaobian.md#upper-030)

| 원방의 축 | 약재 | 해설의 중심 |
|---|---|---|
| 청영·양혈 | 원문 서각·생지황 | 영혈의 열과 진액을 함께 살핌 |
| 양음·청열 | 현삼·맥문동 | 열로 소모된 음액의 바탕 |
| 투열·해독 | 금은화·연교·죽엽심 | 안의 열을 맑히면서 밖으로 풀 방향도 둠 |
| 청심·혈분 | 황련·단삼 | 번·심신 불편과 혈분의 배합 |

양음약만 모으거나 고한청열약만 모은 방과 다릅니다. 영분을 다루면서 금은화·연교를 포함하는 것은 원전의 투열 관점을 이해하는 지점입니다. 단삼도 현대의 혈전 치료약과 같은 역할로 단정하지 않고 전체 혈분 배합 안에서 봅니다.

### 원방 약재와 현대 규격

서각은 원전의 역사적 약재명으로 표시합니다. 현대에는 멸종위기 동물 원료를 재현하는 조제를 안내하지 않으며, 수우각 등 대체 원료를 쓰는 제제는 이름·기원·량·공정서와 임상자료를 별도로 확인합니다. 대체 원료가 원래 약재와 질량상 일대일 대응한다고 가정하지 않습니다.

### 백호·황련해독·삼인과의 갈림점

백호탕은 석고·지모·감초·갱미의 기분 청열과 진액, 황련해독탕은 황련·황금·황백·치자의 실열·화독, 삼인탕은 습온의 불갈·백태·흉민·신중을 다룹니다. 청영탕의 설강·진액 소모·수면과 의식 변화는 이들과 비교하는 단서이며, 발열의 높이만으로 방을 배열하지 않습니다. [백호탕](baihu-tang.md) · [황련해독탕](huanglian-jiedu-tang.md) · [삼인탕](sanren-tang.md)

섬어·의식 변화·출혈·급격한 악화는 현재의 중증도와 원인 평가로 바로 이어집니다. 고전의 영분·혈분은 패혈증이나 특정 감염의 현대 단계명과 같지 않습니다. 원전 배합은 온병학을 공부하는 자료로, 현대 연구는 실제 환자·제제·병용치료와 결과를 확인하는 자료로 각각 읽습니다.

## 비슷한 치료 방향과 구별 {#clinical-context}

[백호탕](baihu-tang.md)은 기분의 성열을, [삼인탕](sanren-tang.md)은 습이 막힌 기기의 소통을 중심으로 봅니다. 청영탕은 영분의 열과 음액을 함께 살피므로 열이 있다는 공통점만으로 서로 바꾸지 않습니다.

피부의 [청열자음](../conditions/atopic-dermatitis.md#skin-clear-heat-nourish-yin)과는 생지황·현삼·맥문동의 배합을 이해하는 지식 경로로 연결합니다. 아토피·습진을 영분증으로 단정하거나 청영탕을 피부질환의 기본 처방으로 제시하는 것은 아닙니다.

## 현재 임상과 근거 {#evidence}

청영탕의 현대 연구는 원방·가감방·대체 원료와 병용치료를 구별하여 읽습니다. [임상근거 허브](../portal/evidence.md)에서 대상 질환·제제·비교군·효과지표가 해당 임상 질문과 맞는지 확인합니다.
