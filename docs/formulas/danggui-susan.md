# 당귀수산(當歸鬚散)

당귀수산은 **타박·염좌 뒤 생긴 어혈을 풀고 막힌 기를 움직여 멍·부종·고정통을 다루는 대표 외상 처방**입니다. 당귀미·적작약·소목·홍화·도인의 활혈축과 오약·향부자의 이기축이 함께 작동하는 구조입니다.

> **핵심 해석:** 통증 부위만 보지 않고 **분명한 외상 뒤 멍과 부종이 남고, 누르거나 움직일 때 특정 부위가 아프며, 골절·탈구·인대 완전파열 같은 구조적 손상은 배제되었는지** 확인합니다.

## 처방 구조

| 구성축 | 주요 본초 | 처방 안에서 보는 역할 |
|---|---|---|
| 활혈거어 | 당귀미·[적작약](../herbs/red-peony.md)·소목·[홍화](../herbs/safflower.md)·[도인](../herbs/peach-kernel.md) | 외상 뒤 정체된 혈과 멍·종창·고정통을 풀어줌 |
| 이기지통 | [오약](../herbs/aucklandia.md)·[향부자](../herbs/cyperus.md) | 기의 울체를 풀어 움직일 때의 통증과 당김을 조절 |
| 온통조화 | [계피](../herbs/cinnamon-bark.md)·[감초](../herbs/licorice.md) | 혈행을 돕고 처방을 조화 |

전통적으로 당귀미 1.5전, 적작약·오약·향부자·소목 각 1전, 홍화 8분, 도인 7분, 계피 6분, 감초 5분의 비례가 전해집니다. 현대 제제는 원료 규격·추출률·1일 용량이 다를 수 있어 제품과 처방기록을 기준으로 비교합니다.

## 임상에서 먼저 보는 단서

| 관찰 영역 | 당귀수산을 생각하게 하는 표현 |
|---|---|
| 계기 | 발목을 삐거나 부딪힌 뒤 통증이 시작됨 |
| 피부·부종 | 멍·국소 부종·압통이 분명함 |
| 통증 | 위치가 비교적 고정되고 누르거나 체중을 실을 때 아픔 |
| 기능 | 걷기·계단·관절가동 범위가 통증 때문에 제한됨 |
| 경과 | 급성 염증기가 지나도 어혈성 통증과 멍이 남음 |

`보행 불가·뼈 압통·변형·감각저하 → 골절·탈구 평가 → 염좌 등급과 손상부위 확인 → 기체혈어 → 처방·침·재활 → 통증·부종·기능 재평가`

## 현대 임상근거

2021년 국내 두 한방병원 무작위·이중맹검·위약대조시험은 발생 72시간 이내의 1·2도 급성 외측 발목 염좌 환자 **48명**을 당귀수산군과 위약군으로 나눴습니다. 두 군 모두 5일간 침 치료를 받았고, 당귀수산 또는 위약 캡슐을 7일간 복용했습니다.

46명이 연구를 완료했으며 1주에서 5주 사이의 통증 VAS와 FAOS 일부 증상·통증 항목 변화에서 군 간 차이가 관찰됐고 보고된 이상반응은 없었습니다. **침을 공통으로 시행한 부가치료 연구**이므로 당귀수산 단독효과로 해석하지 않고, 급성 염좌의 통증·기능 회복을 평가한 국내 사람 대상 근거로 읽습니다.

→ [급성 외측 발목 염좌 RCT, PMID 33663582](https://pubmed.ncbi.nlm.nih.gov/33663582/) · [DOI 10.1186/s13063-021-05135-6](https://doi.org/10.1186/s13063-021-05135-6)

## 회복과 재활 연결

초기에는 보호·적절한 압박과 거상, 통증 허용 범위의 체중부하를 조절하고, 이후 관절가동·근력·균형훈련으로 이어갑니다. 한약·침 치료는 구조적 손상 평가와 단계별 재활을 대신하지 않고 **통증 감소와 기능 회복을 돕는 축**으로 배치합니다.

## 복용과 안전

도인·홍화·소목 등 활혈약이 포함되므로 임신 가능성, 출혈성 질환, 수술 전후, 항응고·항혈소판제 복용을 확인합니다. 멍과 부종이 계속 커지거나, 발이 차고 창백해지거나, 감각·운동 저하가 나타나면 즉시 재평가합니다.
