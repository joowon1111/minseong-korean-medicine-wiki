# 청경사물탕(淸經四物湯)

청경사물탕은 사물탕 계열의 양혈조경 구조에 청열·지혈·이기 약재를 더해 **혈허에 열이 겹쳐 월경이 예정일보다 빨라지는 양상**을 다루는 처방입니다.

## 『동의보감』 수록 구성

| 약재 | 용량 |
|---|---:|
| 당귀 | 5.625g |
| 생건지황·조금·향부자 | 각 3.75g |
| 백작약·황련 | 각 3g |
| 지모·천궁·황백·아교주 | 각 1.875g |
| 감초·애엽 | 각 1.125g |

## 처방 구조

- **당귀·백작약·지황·천궁:** 양혈조경의 사물탕 축
- **황금·황련·황백·지모:** 혈분과 충임에 겹친 열을 조절
- **아교·애엽:** 혈을 보하면서 출혈을 고섭
- **향부자:** 기체를 풀어 월경주기의 흐름을 조절
- **감초:** 중초와 약력을 조화

## 임상에서 보는 단서

- 월경주기가 반복적으로 앞당겨짐
- 출혈량이 늘거나 선홍색·열감이 나타나면서 피로·어지럼 등 혈허가 동반됨
- 단순 실열성 과다월경보다 오래된 출혈 뒤 허약이 함께 있음
- 월경 전 번조·구건이 나타나지만 냉감·한응이 중심은 아님

## 안전과 확인

월경과다·부정출혈은 빈혈검사와 임신 가능성, 자궁근종·선근증·폴립·배란장애·갑상선질환·항응고제 복용을 함께 확인합니다. 한 시간마다 생리대를 갈 정도의 출혈, 실신·호흡곤란, 임신 중 출혈은 즉시 평가가 필요합니다.
