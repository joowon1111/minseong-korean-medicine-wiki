# 청경사물탕(淸經四物湯)

청경사물탕은 사물탕 계열의 양혈조경 구조에 청열·지혈·이기 약재를 더해 **혈허에 열이 겹쳐 월경이 예정일보다 빨라지는 양상**을 다루는 처방입니다.

## 출전·원문·약량 대조 {#source-dose-original}

**대조 출전:** [古今醫鑑](https://jicheng.tw/tcm/book/古今醫鑑/index.html)

**원문 발췌**

> 清經四物湯　治經水不及期而來者，及血虛有熱。
>
> 當歸（一錢五分）　川芎（五分）　白芍（八分）　生地黃（一錢）　阿膠（炒，五分）　艾葉（三分）　條芩（一錢）　宣黃連（姜炒，八分）　黃柏（五分）　知母（五分）　香附（一錢）　甘草（三分）
>
> 上銼一劑，水煎，空心服。

**해석:** 혈허에 열이 겹쳐 월경이 예정일보다 빨리 오는 주치이다. 당귀·천궁·백작약·생지황의 양혈축에 조금·황련·황백·지모의 청열, 아교·애엽과 향부자의 조절을 함께 둔다.

| 본초·제법 항목 | 이 수록본의 기재량 |
|---|---|
| [당귀](../herbs/angelica.md) | 1전 5분 |
| [천궁](../herbs/chuanxiong.md)·[초아교](../herbs/donkey-hide-gelatin.md)·[황백](../herbs/phellodendron.md)·[지모](../herbs/anemarrhena.md) | 각 5분 |
| [백작약](../herbs/white-peony.md)·[강초황련](../herbs/coptis.md) | 각 8분 |
| [생지황](../herbs/fresh-rehmannia.md)·[조금](../herbs/scutellaria.md)·[향부자](../herbs/cyperus.md) | 각 1전 |
| [애엽](../herbs/mugwort-leaf.md)·[감초](../herbs/licorice.md) | 각 3분 |

원문은 생지황·조금·강초황련·초아교를 적는다. 위 동의보감 수록표의 생건지황·아교주와 수치 표기를 구분해 비교한다. 조금은 황금의 해당 수록 명칭이다.

## 『동의보감』 수록 구성

| 약재 | 용량 |
|---|---:|
| 당귀 | 5.625g |
| 생건지황·조금·향부자 | 각 3.75g |
| 백작약·황련 | 각 3g |
| 지모·천궁·황백·아교주 | 각 1.875g |
| 감초·애엽 | 각 1.125g |

## 처방 구조

- **당귀·백작약·지황·천궁:** 양혈조경의 사물탕 축
- **황금·황련·황백·지모:** 혈분과 충임에 겹친 열을 조절
- **아교·애엽:** 혈을 보하면서 출혈을 고섭
- **향부자:** 기체를 풀어 월경주기의 흐름을 조절
- **감초:** 중초와 약력을 조화

## 임상에서 보는 단서

- 월경주기가 반복적으로 앞당겨짐
- 출혈량이 늘거나 선홍색·열감이 나타나면서 피로·어지럼 등 혈허가 동반됨
- 단순 실열성 과다월경보다 오래된 출혈 뒤 허약이 함께 있음
- 월경 전 번조·구건이 나타나지만 냉감·한응이 중심은 아님

| **청경사물탕** | 혈허유열과 월경선기·출혈량 증가가 함께 나타남 |

## 안전과 확인

월경과다·부정출혈은 빈혈검사와 임신 가능성, 자궁근종·선근증·폴립·배란장애·갑상선질환·항응고제 복용을 함께 확인합니다. 한 시간마다 생리대를 갈 정도의 출혈, 실신·호흡곤란, 임신 중 출혈은 즉시 평가가 필요합니다.
