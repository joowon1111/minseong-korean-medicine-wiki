# 독활기생탕(獨活寄生湯)

## 핵심 카드
| 항목 | 내용 |
|---|---|
| 치법 | **거풍습·익간신·보기혈** |
| 핵심 병증 | 오래된 풍한습비 + 간신기혈허 |
| 구성 골격 | 독활·상기생·두충·우슬·진교·방풍·세신 + 숙지황·당귀·작약·인삼·복령 등 |

## 처방을 읽는 법
오적산보다 허증·만성 비증과 간신근골의 비중이 크다.

## 임상 탐색
`증상 → 한열·허실 → 기혈진액·담습·어혈 → 치법 → 처방군 → 개별 처방`

## 구성·용량·출전
이 페이지는 기존 일반방제 지식망의 **핵심 임상 위치와 배합 골격을 통합 정리**한 페이지다. 이미 출전별 정확한 용량이 확인된 처방은 해당 수록본을 유지하고, 동명 처방은 서로 섞지 않는다.
