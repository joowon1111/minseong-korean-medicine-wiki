# 여신탕(如神湯)

여신탕은 허리를 삐끗하거나 무거운 것을 들다가 발생한 **좌섬요통**에서 기혈의 울체와 근골의 손상을 함께 살피는 간결한 처방입니다. 《동의보감》과 《방약합편》에 이어지는 기록에서는 현호색·당귀·계심·두충을 같은 비중으로 배합합니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 핵심 치법 | 활혈행기·산한통락·보간신강근골 |
| 중심 병증 | 삐끗한 뒤 생긴 요통, 국소 압통과 움직임 제한 |
| 구성 | 현호색·당귀·계심·두충(강초) 각 등분 |
| 제형 기록 | 산제로 1회 2돈을 온주에 조복; 탕용 기록도 있음 |
| 출전 계통 | 《부인대전양방》·《동의보감》·《방약합편》 |

## 네 약미의 역할

| 본초 | 처방 안에서 보는 역할 |
|---|---|
| [현호색](../herbs/corydalis.md) | 기혈을 소통해 삔 뒤의 고정 통증·압통을 조절 |
| [당귀](../herbs/angelica.md) | 혈분을 보하면서 활혈해 손상 회복을 받침 |
| 계심 | 온경산한·통맥으로 냉감과 긴장을 풀어 줌 |
| [두충](../herbs/eucommia.md) | 간신과 허리·무릎, 근골 회복축을 보완 |

## 임상에서 확인할 단서

- 무거운 물건을 들거나 몸을 비튼 직후 허리 통증이 시작됐습니다.
- 특정 부위가 찌르듯 아프고 눌렀을 때 통증이 분명합니다.
- 허리를 굽히거나 펴고 돌리는 동작이 제한됩니다.
- 냉감·근육긴장 또는 평소 허리와 무릎의 약화가 회복을 더디게 합니다.

급성 요통에서는 다리 근력·감각, 방사통, 보행, 대소변 변화를 먼저 확인합니다. 여신탕은 손상기전과 어혈·한응·근골 상태를 함께 보는 처방이며, 침·전침·약침 치료와 병행할 때도 통증점수와 가동범위, 앉기·걷기·수면 같은 기능지표로 경과를 기록합니다.

## 비슷한 처방과 감별

| 처방 | 더 중심이 되는 단서 |
|---|---|
| **여신탕** | 좌섬·염좌 뒤 국소 요통, 네 약미의 간결한 활혈·온통·강근골 구조 |
| [당귀수산](danggui-susan.md) | 타박·멍·부종을 포함한 외상성 어혈 |
| [오적산](wujisan.md) | 한습·기혈담식이 겹친 넓은 범위의 냉습성 통증과 소화불편 |
| [독활기생탕](duhuo-jisheng-tang.md) | 오래된 요슬통에 간신·기혈부족과 하지무력이 동반 |
