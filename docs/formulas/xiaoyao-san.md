# 소요산(逍遙散)

소요산은 간기의 울체를 풀면서 혈을 기르고 비위를 돕는 처방입니다. 긴장이나 감정이라는 한 요소로 단순화하지 않고, **옆구리·가슴의 답답함, 피로, 식욕·소화, 월경주기와 증상의 변동성**을 함께 살핍니다.

## 한눈에 보기

| 항목 | 임상에서 읽는 핵심 |
|---|---|
| 치법 | 소간해울·양혈건비·조화간비 |
| 핵심 병기 | 간울을 바탕으로 혈허와 비허가 함께 나타남 |
| 주요 단서 | 오르내리는 피로, 흉협창만, 식욕저하·복부팽만, 월경 전후 증상 변화, 근육 긴장 |
| 감별의 중심 | 울열·상열이 뚜렷한지, 심비양허인지, 담습·식적인지, 기질질환이 있는지 |
| 치료 후 평가 | 피로척도, 식사량·소화, 흉협 불편, 월경주기, 수면과 일상기능 |

## 처방 구조

| 처방축 | 대표 본초 | 역할 |
|---|---|---|
| 소간 | 시호·박하 | 울체된 간기를 풀고 기기의 소통을 도움 |
| 양혈유간 | [당귀](../herbs/angelica.md)·[백작약](../herbs/white-peony.md) | 혈을 기르고 간의 긴장과 통증을 부드럽게 조절 |
| 건비삼습 | [백출](../herbs/atractylodes.md)·[복령](../herbs/poria.md) | 비위 운화를 돕고 피로·식욕저하·수습을 조절 |
| 조화 | [감초](../herbs/licorice.md)·생강 | 비위를 조화하고 처방의 균형을 잡음 |

## 비슷한 처방과 구분

| 처방 | 더 중심이 되는 단서 |
|---|---|
| **소요산** | 간울 + 혈허·비허, 피로·소화·주기성 증상의 변동 |
| [가미소요산](jiawei-xiaoyao-san.md) | 울열·상열감·번조·야간 열감이 더 뚜렷함 |
| [시호소간산](chaihu-shugan-san.md) | 흉협통·복부팽만·트림 등 기체와 통증이 중심 |
| [귀비탕](guibi-tang.md) | 심비양허·기혈부족, 심계·건망·불면·식욕저하가 중심 |
| [향사육군자탕](xiangsha-liujunzi-tang.md) | 비위기허·담습·기체, 조기포만과 복부창만이 중심 |

## 사람 대상 임상근거

2025년 만성피로증후군 체계적 문헌고찰·메타분석은 소요산 기반 치료를 평가한 6개 연구·623명을 종합했습니다. 전체 임상반응과 FS-14 피로점수를 평가했으며 소요산 단독과 통상치료 병용 연구가 함께 포함돼 있습니다. 실제 적용에서는 연구 처방과 병용조건을 구분합니다. [PMID 39981187](https://pubmed.ncbi.nlm.nih.gov/39981187/) · [DOI 10.3389/fphar.2025.1496774](https://doi.org/10.3389/fphar.2025.1496774)

## 안전성과 진료 연결

- 피로가 새로 심해졌거나 체중감소·발열·호흡곤란·흉통, 신경학적 증상이 동반되면 원인 평가가 우선입니다.
- 빈혈·갑상선·수면무호흡·감염·대사질환과 복용약을 함께 확인합니다.
- 감초 함유 처방의 장기·중복 복용 시 부종·혈압·전해질 상태를 살핍니다.
- 임신·수유, 간·신장질환, 항응고제·항혈소판제 복용은 개별 평가가 필요합니다.
