# 좌귀환(左歸丸)

좌귀환은 『경악전서』의 대표적인 **진음·정혈 보충 처방**입니다. 육미지황환의 삼보 약재인 숙지황·산약·산수유를 중심으로 구기자·토사자·우슬과 녹각교·귀판교를 배합해 사하는 약재 없이 보하는 방향을 강화합니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 핵심 치법 | 자신보신·익정전수 |
| 중심 병증 | 신음·정혈·정수 부족 |
| 대표 증상축 | 요슬산연·어지럼·이명·건조·도한·허열·정력저하 |
| 출전 | 『경악전서』 |
| 기본 구성 | 숙지황·산약·산수유·[구기자](../herbs/cornus-extra.md)·[토사자](../herbs/cuscuta-seed.md)·우슬·녹각교·귀판교 |
| 임상 위치 | 육미지황환보다 순수한 보음·익정 방향이 강한 처방 |

[한국전통지식포탈의 좌귀환](https://koreantk.com/ktkp2014/prescription/prescription-view.view?preCd=P0016887&tempLang=ko)은 숙지황을 고로 만들어 환제로 조제하는 원방 특징을 보여줍니다.

## 감별

| 처방 | 갈림점 |
|---|---|
| [육미지황환](../authority/formulas/liuwei-dihuang-wan.md) | 보하면서 택사·복령·목단피로 조절하는 삼보삼사 구조 |
| [우귀환](yougui-wan.md) | 냉감·양위·설사 등 신양허가 중심 |
| [대보원전](dabo-wonjeon.md) | 신정뿐 아니라 인삼·당귀로 기혈허를 함께 크게 보함 |
| [팔미지황환](bawei-dihuang-wan.md) | 육미지황환에 부자·육계를 더해 온양과 수분대사를 함께 봄 |

## 안전과 관찰

허리·무릎의 힘, 구강건조, 수면·도한, 소변, 소화상태를 기록합니다. 자윤하고 동물성 교질 약재가 포함되어 소화가 약하거나 설사가 잦으면 적합성을 살핍니다. 녹각교·귀판교의 원료 품질과 알레르기, 임신·수유 및 항응고제 병용을 확인합니다.
