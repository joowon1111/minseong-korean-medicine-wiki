# 온담탕(溫膽湯)

온담탕은 **담이 위의 화강을 방해하고 심담을 어지럽혀 속이 불편하면서 잠과 정서까지 흔들리는 병증**을 다루는 대표 화담방입니다. 반하·진피·복령의 이진탕 골격에 지실·죽여를 더해 담과 기의 울체, 위기상역을 함께 풀고 생강·대조·감초로 중초를 조화합니다.

> **핵심 해석:** 불면 하나만 보지 않고 **명치 답답함·메스꺼움·가래나 이물감·어지럼·두근거림·꿈이 많고 잘 놀람**이 한 묶음으로 나타나는지 확인합니다.

## 출전 원문·약량·본초 해석 {#source-dose-original}

**대조 수록본:** 《삼인극일병증방론(三因極一病證方論)》 「卷九・虛煩・溫膽湯」. [해당 문헌 확인](https://jicheng.tw/tcm/book/三因極一病證方論/index.html)

**원문 발췌**

> 半夏（湯洗七次）　竹茹　枳實（麩炒，去瓤，各二兩）　陳皮（三兩）　甘草（一兩，炙）　茯苓（一兩半）

**해석·주치와 배합:** 담과 기의 불화에 허번·불면이 겹친 문맥입니다. 이진 계열에 죽여·지실을 두어 화담과 기역·담열 조절을 함께 설명합니다.

**약량 읽기:** 표는 위 수록본의 약미·약량을 풀어 쓴 것입니다. 등분은 같은 비중, 량·전·분은 중량, 승·합은 부피, 매·립은 개수 기록입니다. 역사적 제조 배합을 현대 1일 g 처방으로 일괄 환산하지 않습니다.

| 구성 본초·원문 약명 | 수록량 | 원문 포제의 뜻 | 배합에서의 본초 역할 |
|---|---|---|---|
| [반하](../herbs/pinellia.md) · 半夏 | 2량 | 뜨거운 물로 7회 씻음 | 화담·강역으로 담습과 오심을 함께 다룸 |
| [죽여](../herbs/bamboo-shavings.md) · 竹茹 | 2량 | 별도 포제 표기 없음 | 담열·위기상역과 번조를 조절 |
| [지실](../herbs/citrus-immature.md) · 枳實 | 2량 | 밀기울로 볶음·속살 제거 | 기체·비만·담적을 내려 풀어 주는 축 |
| [진피](../herbs/citrus-peel.md) · 陳皮 | 3량 | 별도 포제 표기 없음 | 이기·조습으로 팽만과 담습을 조절 |
| [감초](../herbs/licorice.md) · 甘草 | 1량 | 자(굽거나 볶음) | 중초를 돕고 완급·배합 조화를 맡음 |
| [복령](../herbs/poria.md) · 茯苓 | 1량반 | 별도 포제 표기 없음 | 건비·삼습으로 수습의 정체를 조절 |

## 《동의보감》 수록 원문과 구성 {#donguibogam-version}

> 治心膽虛怯，觸事易驚，夢寐不祥，虛煩不得睡。

**해석:** 심담이 허약해 쉽게 놀라고, 꿈자리와 잠이 불편하며 허번으로 잠들지 못하는 양상입니다. 심담허겁은 전통적 병증 설명입니다. 현재에는 불면과 함께 흉민·오심·어지럼·예민함이 어떤 순서로 나타나는지 확인하는 단서로 활용합니다.

| 《동의보감》 수록 약재 | 원문 용량 |
|---|---|
| 반하·진피·백복령·지실 | 각 2전 |
| 청죽여 | 1전 |
| 감초 | 5분 |
| 생강·대추 | 5편·2매, 달일 때 더함 |

이진탕 계열의 화담·이기에 죽여·지실을 더해 흉민·담의 울체를 함께 다스리는 구조입니다. **허겁이라는 표현만으로 보익 처방으로 분류하지 않고 실제 약물 구조를 함께 읽습니다.** 식욕저하·피로·건망이 중심인 [귀비탕](guibi-tang.md)과, 흉민·오심·놀람이 중심인 온담탕을 비교합니다. 《삼인방》 계열 원방, 《동의보감》 수록 용량, 현대 가미온담탕의 구성·연구는 각각 확인합니다.

출전: 《동의보감》 내경편 권2 몽, 허번불수(虛煩不睡) — 《고금의감》 인용. [원문 대조](https://ko.wikisource.org/wiki/동의보감/내경편) · [발췌·해석·원문 단위의 이용 기준](../classics/donguibogam.md#selected-clinical-passages). 위 표의 전·분은 해당 수록본의 역사적 용량 기록이며 현대 제제의 1일 복용량과 구분합니다.

## 처방 구조

| 구성축 | 주요 본초 | 처방 안에서 보는 역할 |
|---|---|---|
| 화담·강역 | [반하](../herbs/pinellia.md) | 담을 삭이고 오심·구역과 위기상역을 내림 |
| 이기·조습 | [진피](../herbs/citrus-peel.md) | 막힌 기를 풀고 담이 다시 생기는 중초 환경을 조절 |
| 건비·삼습 | [복령](../herbs/poria.md) | 비위를 돕고 수습을 배출해 담의 바탕을 정리 |
| 파기·개울 | [지실](../herbs/citrus-immature.md) | 흉격과 명치의 그득함, 기체를 풀어줌 |
| 청담·제번 | [죽여](../herbs/bamboo-shavings.md) | 담과 번조, 메스꺼움을 함께 다룸 |
| 조화·호위 | [감초](../herbs/licorice.md)·[생강](../herbs/fresh-ginger.md)·대조 | 위를 보호하고 여러 약재의 방향을 조화 |

이진탕의 담습 골격에 지실·죽여가 더해지면서 **그득함과 기체, 메스꺼움과 번조를 함께 다루는 배합**이 됩니다. 지실은 막히고 그득한 기의 흐름, 죽여는 담과 번조·오심을 살피는 역할로 읽습니다. 따라서 반하·진피가 들어 있다는 공통점만으로 육군자탕과 같은 방향이라고 보기는 어렵습니다.

이름의 ‘온(溫)’은 단순히 뜨겁게 덥힌다는 뜻으로만 읽기보다 담위불화를 조화하는 구성으로 이해합니다. 기본 온담탕과 황련을 더한 가감방의 차이도 구분합니다. 불면과 소화불편이 함께 있을 때 보기·보혈의 방향과 어떻게 비교하는지는 [귀비탕 vs 온담탕](../compare/guibi-vs-wendan.md#digestion-context)에서 이어서 볼 수 있습니다.

### 온담탕의 온(溫)과 죽여·지실 {#wendan-name-and-components}

처방명의 온을 ‘담을 뜨겁게 덥힌다’는 문자 풀이에만 맞추면 죽여·지실의 역할을 설명하기 어렵습니다. 이진탕축에 죽여·지실이 배치되면서 화담강역에 제번·개울을 함께 읽는 구조가 됩니다. 이름보다 **수록 약미·비율·현재 한열**이 판단의 기준입니다.

| 수록 용량의 관계 | 해석할 배합 |
|---|---|
| 반하·진피·복령·지실 각 2전 | 담습·기체·명치 그득함을 함께 다루는 중심축 |
| 청죽여 1전 | 오심과 번조·담울의 조정 |
| 감초 5분, 강·조 별기 | 중초를 조화하는 전탕 구성 |
| 황련·안신약의 유무 | 황련온담탕·가미온담탕과 원방을 구분 |

동의보감의 심담허겁은 쉽게 놀람·허번·불수라는 주치 문맥입니다. 이를 심장·담낭의 해부학적 기능 저하나 불안장애 진단으로 직접 바꾸지 않습니다. 심계·불면과 함께 흉민·오심·식후 불편이 어느 정도인지, 기혈허의 피로·건망·창백이 중심인지 비교합니다.

같은 불면이라도 귀비탕은 보기양혈·안신, 산조인탕은 허로허번의 양혈안신·제번, 온담탕은 담위불화의 화담강역·개울에 무게가 있습니다. [귀비탕과 온담탕](../compare/guibi-vs-wendan.md)을 비교하면 수면 증상 뒤의 소화·기혈·담 축이 어떻게 달라지는지 확인할 수 있습니다.

## 임상에서 먼저 보는 단서

| 관찰 영역 | 온담탕을 생각하게 하는 표현 |
|---|---|
| 소화 | 속이 메슥거리거나 명치가 막히고 더부룩함 |
| 흉격 | 가슴이 답답하고 목에 무언가 걸린 듯함 |
| 수면 | 꿈이 많고 자주 깨며, 누우면 생각과 두근거림이 늘어남 |
| 신경·평형 | 머리가 맑지 않고 어지럽거나 쉽게 놀람 |
| 설·맥 단서 | 담습·담울을 시사하는 태와 활한 맥을 전체 증상과 함께 판단 |

`흉통·실신·호흡곤란 위험신호 → 소화·담음 단서 → 수면·심계 동반 → 한열·허실 → 온담탕 계열 선택 → 소화와 수면을 함께 재평가`

## 온담탕 계열 현대 임상연구를 읽는 법

온담탕은 불면과 두통 등을 대상으로 연구되어 왔지만 논문마다 **표준 온담탕, 가미온담탕, 황련온담탕과 개별 가감방**이 섞여 있습니다. 2017년 원발성 불면 체계적 문헌고찰 논문은 결과 보고가 아니라 연구계획서이며, 표준 온담탕의 효과를 확정한 자료로 사용하지 않습니다.

불면 처방을 비교한 최근 네트워크 메타분석에는 황련온담탕 등 온담탕 계열 처방이 포함됐습니다. 이 자료는 담열과 불면의 연결을 탐색하는 데 의미가 있지만, 황련을 더한 처방의 결과를 기본 온담탕에 그대로 옮기지 않습니다.

## 복용과 경과 관찰

치료 전후에는 **입면시간·야간각성·꿈·두근거림·명치 답답함·오심·어지럼·낮 피로**를 함께 기록합니다. 수면만 좋아지고 소화가 악화되거나, 반대로 소화는 편해져도 심계·흉통이 지속되면 병증과 원인을 다시 평가합니다.

반하는 적절히 법제된 규격 원료를 사용해야 합니다. 다른 감초 함유 처방과 장기간 병용할 때는 총량을 확인하고, 지속되는 흉통·실신·호흡곤란·새로운 신경학적 증상·심한 구토가 있으면 처방 조정보다 의학적 평가가 우선입니다.
