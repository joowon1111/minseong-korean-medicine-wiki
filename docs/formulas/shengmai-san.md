# 생맥산(生脈散)

## 한눈에
**인삼·맥문동·오미자 세 약재로 기를 보하고 진액을 만들며 흩어지는 기음을 수렴하는 간결한 대표방**이다.

- **치법:** 익기생진·렴음지한
- **핵심 병증:** 기음양허·구갈·자한·단기·피로

## 구성 골격
| 본초 | 역할 |
|---|---|
| 인삼 | 익기 |
| 맥문동 | 양음생진 |
| 오미자 | 렴폐·생진·수렴 |

## 방의
세 약재가 **익기 + 양음 + 수렴**이라는 명확한 구조를 이루어, 더위·소모·병후 등에서 기와 진액이 함께 손상된 전통적 병증을 이해하기 좋다.

## 비교
- **보중익기탕:** 비위기허·중기하함
- **쌍화탕:** 기혈구상
- **생맥산:** 기음양허·진액손상
