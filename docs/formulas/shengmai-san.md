# 생맥산(生脈散)

생맥산은 **인삼·맥문동·오미자** 세 약재로 기를 보하고 진액을 만들며 흩어지는 음을 수렴하는 대표적인 기음쌍보 처방입니다. 더위·과로·오랜 질환 뒤 땀과 갈증, 숨참, 마른 피로가 함께 남은 상태를 이해하는 기본방입니다.

## 한눈에 보기

| 항목 | 핵심 |
|---|---|
| 구성 | 인삼·맥문동·오미자 |
| 중심 치법 | 익기생진·렴음지한 |
| 병증축 | 기음양허·진액소모 |
| 살필 단서 | 피로·숨참 + 땀·입마름·갈증·마른기침 |
| 이름의 뜻 | 기와 진액을 회복해 약해진 맥을 되살린다는 의미 |

## 세 약재의 역할

- **인삼**: 기를 보하고 진액 생성의 동력을 돕습니다.
- **맥문동**: 폐·위의 음과 진액을 길러 건조와 갈증을 완화하는 축입니다.
- **오미자**: 기와 진액이 땀·기침으로 계속 소모되지 않도록 수렴합니다.

즉 **보하기 → 진액 만들기 → 새지 않게 거두기**가 한 처방 안에서 이어집니다.

## 어떤 때 이 계열을 살피나요?

- 더위나 과로 뒤 기운이 없고 땀이 쉽게 남
- 오래 앓은 뒤 입이 마르고 숨이 짧으며 맥이 약함
- 마른기침·목마름과 피로가 함께 나타남
- 운동·질환 뒤 회복기에 수분을 보충해도 마른 느낌과 무력감이 지속됨

갈증·다뇨·체중감소가 있으면 혈당을, 숨참·흉통·부종이 있으면 심폐질환을 먼저 확인합니다. 열사병이나 심한 탈수는 생맥산 감별보다 즉각적인 수분·전해질 치료가 우선입니다.

## 활용을 기록하는 법

복용 전후의 갈증·발한량·입마름, 계단이나 보행 때 숨참, 오후 피로, 야간 기침, 수면 뒤 회복감을 함께 기록하면 기음 회복 여부를 구체적으로 볼 수 있습니다.

## 안전하게 보기

오미자·인삼을 포함한 제제는 복용약과 상호작용 가능성을 확인합니다. 임신·수유, 심혈관질환, 당뇨, 항응고제 복용 중에는 전문가와 제형·용량을 조정합니다.
