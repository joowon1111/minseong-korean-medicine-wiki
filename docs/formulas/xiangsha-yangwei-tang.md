# 향사양위탕(香砂養胃湯)

## 한눈에
**비위의 허약·한습·기체가 겹쳐 식욕저하·비민·창만이 나타나는 병증에서 보는 대표 향사계 처방**이다.

- **치법:** 온중화습·이기화위
- **핵심:** 비위허약 + 습체 + 기체

## 주요 구성 골격
향부자 · 사인 · 창출 · 후박 · 진피 · 백출 · 복령 등을 중심으로 하는 후세방 계열.

## 임상 감별
- **평위산:** 습체·창만 자체가 중심
- **향사육군자탕:** 비기허·담습 + 기체
- **향사양위탕:** 비위허한·습체·기체의 색채가 더 뚜렷

한국전통지식포탈의 **비민(痞悶)** 병증 자료에서도 『방약합편』 향사양위탕B가 관련 처방으로 연결된다.
