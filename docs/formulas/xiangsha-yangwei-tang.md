# 향사양위탕(香砂養胃湯)

향사양위탕은 『동의수세보원』에 제시된 **소음인 비위허약·내상 소화기 처방**입니다. 비위의 온기와 운화가 약해 음식이 잘 내려가지 않고, 식욕저하·식후 더부룩함·탄산·트림·오심·묽은변에 기체와 담체가 겹치는지를 봅니다. 이중탕의 온중건비 골격에 향부자·사인·백작약·반하·진피·산사육·백두구를 더해 **허약을 받치면서 기·담·식체를 함께 조절**하는 구조입니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 체질·병증 | 소음인, 비위허약과 내상으로 음식의 소화·운화가 떨어진 방향 |
| 중심 치법 | 온중건비·익기화위·이기화담·소식 |
| 핵심 단서 | 식욕저하, 식후비만·조기포만, 트림·탄산, 오심, 복통, 무른변·설사, 냉감·피로 |
| 구성 골격 | 인삼·백출·구감초·건강 + 백작약 + 반하·진피 + 향부자·사인·백두구 + 산사육 |
| 가까운 비교 | 이중탕·향사육군자탕·평위산·반하사심탕·보화환 |
| 대표 출전 | 『동의수세보원』 소음인 처방 체계 |

## 소음인 원전 처방으로 읽기

이 문서는 **『동의수세보원』의 소음인 향사양위탕**을 기준으로 합니다. 향사육군자탕·향사평위산처럼 이름이 가까운 방제와 섞지 않고, 인삼·백출·백작약·구감초·반하·향부자·진피·건강·산사육·사인·백두구의 원전 구성을 중심으로 병증과 배합을 해석합니다.

## 원전 구성과 용량

| 본초 | 용량 | 처방 안에서 읽는 역할 |
|---|---:|---|
| [인삼](../herbs/ginseng.md) | 3.75 g | 비위의 기와 식욕·회복을 받치는 중심축 |
| 백출 | 3.75 g | 건비하고 습을 조절하여 인삼을 보완 |
| 백작약 | 3.75 g | 복부 긴장·통증과 영혈을 조화 |
| [감초](../herbs/licorice.md), 구 | 3.75 g | 중초를 조화하고 여러 약재를 연결 |
| 반하 | 3.75 g | 담·오심·구역과 위기의 상역을 조절 |
| 향부자 | 3.75 g | 기체·울체와 식후 창만을 풀어 줌 |
| [진피](../herbs/citrus-peel.md) | 3.75 g | 이기화담하여 트림·더부룩함을 조절 |
| 건강 | 3.75 g | 중초를 덥히고 냉감·복통·묽은변을 받침 |
| 산사육 | 3.75 g | 육류·기름진 음식 후 식체와 복만을 소화 |
| [사인](../herbs/amomum.md) | 3.75 g | 방향화습·행기·온중하여 식욕과 오심을 조절 |
| [백두구](../herbs/white-cardamom.md) | 3.75 g | 중초의 습체·오심·비만을 풀어 줌 |
| 생강 | 3쪽 | 반하와 함께 위기를 조화하고 구역을 조절 |
| 대조 | 2개 | 비위와 영위를 조화 |

정량된 11개 본초는 **총 41.25 g**이며 생강 3쪽·대추 2개가 더해집니다. 한국민족문화대백과사전의 『동의수세보원』 수록 설명을 기준으로 정리했습니다. 실제 탕전에서는 약재 규격·포제·제형과 환자별 가감을 처방전에 명시합니다.

## 처방 구조를 네 축으로 읽기

| 배합축 | 본초 | 임상 연결 |
|---|---|---|
| 온중건비·익기 | 인삼·백출·구감초·건강 | 오래된 식욕저하, 냉감, 피로, 묽은변 |
| 완급·복통 조절 | 백작약·감초 | 복부 긴장, 은은한 복통, 식후 불편 |
| 이기화담·화위 | 반하·진피·향부자 | 트림·오심·목과 명치의 막힘, 기체·담체 |
| 방향화습·소식 | 사인·백두구·산사육 | 식후비만, 음식 정체, 육류·기름진 음식 후 악화 |

이중탕 골격이 **비위의 허한을 받치고**, 반하·진피·향부자가 위기의 상역과 기체를 풀며, 사인·백두구·산사육이 습체와 식상을 정리합니다. 그래서 단순 과식 직후의 실증뿐 아니라 소화기가 약한 사람이 반복적으로 체하고 기운이 떨어지는 패턴을 함께 살핍니다.

## 원전 증후를 현대 문진으로 풀기

| 전통 증후 | 환자에게 물어볼 내용 |
|---|---|
| 식상·식창 | 과식·육류·기름진 음식·과일 뒤 악화, 식후 팽만 지속시간 |
| 담체·식담 | 가래·오심·구역, 명치 막힘, 머리 무거움, 음식 생각만 해도 울렁거림 |
| 탄산·조잡 | 신물, 속쓰림, 공복의 허기 같은 불편, 위산 역류의 시간대 |
| 애기 | 트림의 횟수·냄새·음식 역류, 트림 후 편안해지는지 |
| 설사·이질 | 변 횟수·형태·점액·복통, 찬 음식 후 악화, 배변 후 기력 |
| 부종 | 얼굴·손·발의 붓기, 아침·저녁 차이, 체중과 소변 변화 |
| 육울 | 식사·감정·수면·활동과 흉복부 답답함의 관계 |

## 이런 조합에서 우선 비교

- 평소 소화력이 약하고 식사량이 적거나 조금만 먹어도 배가 찹니다.
- 찬 음식·과로·수면 부족 뒤 명치 더부룩함과 묽은변이 함께 심해집니다.
- 트림·오심·탄산처럼 위기가 위로 치미는 증상과 복부 냉감이 겹칩니다.
- 식욕저하가 오래되면서 피로·손발냉·회복 지연이 동반됩니다.
- 육류·기름진 음식 후 식체가 반복되며 산사육의 소식 축을 함께 고려할 상황입니다.

속쓰림·작열감·야간통이 중심이면 한열과 역류 양상을 다시 구분하고, 명치비만·장명·설사·구역이 교차하면 반하사심탕 계열을, 과식 직후의 음식 정체가 중심이면 보화환 계열을 함께 비교합니다.

## 한의원 진료 흐름

`위험신호·기질질환 확인 → 소음인 소증과 현재 소화상태 확인 → 허한·기체·담체·식상의 비중 판단 → 유사 처방 감별 → 한약·침·전침·약침 치료계획 → 식사·대변·체중·증상척도로 재평가`

한약과 함께 침·전침·약침을 시행할 때에는 중완·상완 주변의 압통과 긴장, 복벽·횡격막의 움직임, 자율신경·수면, 경항부 긴장 등을 치료 목표에 포함할 수 있습니다. 치료별 시행일과 증상 변화를 나누어 기록하면 복합치료의 경과를 더 분명히 파악할 수 있습니다.

## 경과관찰표

| 영역 | 시작할 때 기록 | 재진에서 확인 |
|---|---|---|
| 식사 | 한 끼 섭취량, 식욕 0~10점, 식사 횟수 | 식욕과 섭취량의 안정 |
| 식후비만 | 시작 시각·지속시간·강도, 조기포만 | 불편 지속시간과 강도 감소 |
| 트림·오심 | 하루 횟수, 음식·자세와의 관계 | 빈도와 식사 가능 범위 변화 |
| 복통·냉감 | 위치, 압통, 온찜질 반응, 0~10점 | 냉감·통증·복벽 긴장 변화 |
| 대변 | 횟수, Bristol 형태, 급박감·잔변감 | 평소 배변 리듬과 배변 후 기력 |
| 체중·피로 | 주 1회 체중, 활동량, 아침 피로 | 체중 안정과 활동 후 회복 |
| 표준척도 | 필요 시 NDI-K·FD-QoL 등 | 같은 도구로 시점별 비교 |

## 임상기록의 핵심

향사양위탕의 치료기록은 **소음인 체질진단 → 평소 소화·대변·냉열 소증 → 현재 허한·기체·담체·식상의 비중 → 원방·가감과 복용기간 → 침·전침·약침의 병행 내용 → 식욕·식후비만·대변·체중의 변화** 순서로 남깁니다. 같은 기준으로 재진 기록을 이어가면 주증과 전신 소증이 함께 회복되는 과정을 확인할 수 있습니다.

## 안전과 진료 우선 신호

연하곤란, 반복 구토, 토혈·흑변, 지속되는 체중감소·빈혈, 야간에 깨는 심한 통증, 만져지는 복부 종괴는 내시경·영상·혈액검사 등 원인 평가와 함께 관리합니다. 헬리코박터 파일로리 감염과 위축성위염은 검사 결과와 치료계획을 진료기록에 포함합니다.

감초 함유 처방이므로 장기간·고용량 사용 시 혈압·부종·혈중 칼륨과 이뇨제·스테로이드·디곡신 등 병용약을 확인합니다. 반하는 법제된 규격품을 사용하고, 임신·수유·간신장질환·다약제 복용 여부를 처방 전에 확인합니다.
