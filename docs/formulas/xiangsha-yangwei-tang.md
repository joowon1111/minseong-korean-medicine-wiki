# 향사양위탕(香砂養胃湯)

향사양위탕은 비위가 허하고 차가우면서 습과 기체가 겹쳐 생기는 **식욕저하·더부룩함·메스꺼움**을 다루는 빈용 소화기 처방입니다. 단순 식적보다 오래된 소화기 허약과 냉감이 배경에 있는지 살핍니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 중심 치법 | 온중화습·이기화위·익기건비 |
| 핵심 병기 | 비위허한에 습체와 기체가 겹침 |
| 대표 단서 | 입맛 저하, 식후 더부룩함, 잦은 트림·오심, 찬 음식 후 악화, 무른 변 |
| 구성 골격 | 창출·후박·진피·향부자 + 사인·목향·백두구 + 인삼·백출·복령·감초 |

## 구성과 배합 구조

| 배합축 | 대표 본초 | 역할 |
|---|---|---|
| 습을 말리고 창만을 풂 | 창출·[후박](../herbs/magnolia-bark.md)·[진피](../herbs/citrus-peel.md) | 무겁고 그득한 중초의 습체를 조절 |
| 기를 움직이고 위를 편안히 함 | 향부자·[사인](../herbs/amomum.md)·목향·백두구 | 식후 팽만·트림·오심과 기체를 다룸 |
| 비위를 지지 | [인삼](../herbs/ginseng.md)·백출·[복령](../herbs/poria.md)·[감초](../herbs/licorice.md) | 오래된 식욕저하와 비위기허를 보완 |
| 중초를 조화 | 생강·대조 | 온중하고 위기를 조화 |

의서·보험제제·제품별로 구성과 함량이 다를 수 있어 실제 처방의 원전과 성분표를 확인합니다.

## 임상에서 살피는 단서

- 식사량이 적고 조금만 먹어도 배가 부름
- 찬 음식이나 과로 뒤 더부룩함·묽은 변이 심해짐
- 명치가 차거나 손발이 차고 기운이 떨어짐
- 트림·오심·가스처럼 기체와 습의 증상이 함께 있음

속쓰림과 작열감이 뚜렷하거나 입이 마르고 변비가 심한 열증에서는 다른 처방군을 우선 비교합니다.

## 자주 비교하는 처방

| 처방 | 중심 병기 | 구분 단서 |
|---|---|---|
| [평위산](pingwei-san.md) | 습체 | 허약보다 복부창만·몸의 무거움이 중심 |
| [향사육군자탕](xiangsha-liujunzi-tang.md) | 비위기허·담습·기체 | 기허와 식욕저하의 비중이 더 큼 |
| [보화환](baohe-wan.md) | 식적 | 과식 직후 악화와 음식 냄새 트림이 중심 |
| 이중탕 | 중초허한 | 습체·기체보다 복통·설사·냉감이 중심 |
| [반하사심탕](banxia-xiexin-tang.md) | 한열착잡 | 명치 막힘과 장명·설사·구역이 교차함 |

## 사람 대상 연구

2020년 체계적 문헌고찰은 만성위염 환자 1,720명이 포함된 18개 RCT에서 향사양위환과 기존 치료의 병용을 검토했습니다. 증상 개선 가능성이 보고되었지만 연구의 방법론적 질이 낮았고, 헬리코박터 파일로리 제균률은 차이가 분명하지 않았습니다. 따라서 **원방 단독효과가 아니라 만성위염 병용연구**로 구분합니다. [PMID 32627502](https://pubmed.ncbi.nlm.nih.gov/32627502/)

## 안전과 진료 우선 신호

연하곤란, 반복 구토, 토혈·흑변, 지속되는 체중감소·빈혈, 심한 복통이 있으면 위내시경 등 원인 평가가 우선입니다. 위축성위염·헬리코박터 감염은 필요한 검사와 표준치료를 병행하며, 감초 함유 제제는 고혈압·부종·저칼륨혈증 위험과 병용약을 확인합니다.
