# 도담탕(導痰湯)

## 핵심 카드
| 항목 | 내용 |
|---|---|
| 치법 | **조습거담·행기** |
| 핵심 병증 | 담습이 완고하고 흉민·현훈·담궐 등이 두드러지는 병증 |
| 구성 골격 | 반하·남성·진피·복령·지실·감초 등을 중심으로 한 강한 거담이기 구조 |

## 처방을 읽는 법
이진탕보다 거담·파기의 성격이 강하고, 온담탕은 담울·담열과 심번·불면 쪽이다.

## 임상 탐색
`증상 → 한열·허실 → 기혈진액·담습·어혈 → 치법 → 처방군 → 개별 처방`

## 구성·용량·출전
이 페이지는 기존 일반방제 지식망의 **핵심 임상 위치와 배합 골격을 통합 정리**한 페이지다. 이미 출전별 정확한 용량이 확인된 처방은 해당 수록본을 유지하고, 동명 처방은 서로 섞지 않는다.
