# 연교패독산(連翹敗毒散)

연교패독산은 **연교·금은화의 청열해독축에 형개·방풍·강활·독활의 소풍축을 결합해, 열감·붓기·통증이 함께 나타나는 풍열독을 풀어주는 처방**입니다. 감기·인후 증상부터 붉고 붓는 초기 피부 병변까지 쓰임이 이어지지만, 감염의 중증도와 배농·항균치료 필요성을 먼저 구분합니다.

> **핵심 해석:** ‘염증’이라는 말만으로 고르기보다 **발병이 비교적 급하고, 붉음·열감·압통·인후 불편이 있으면서 오한·두통·몸살 같은 표증이 함께 남아 있는지** 봅니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 핵심 치법 | 청열해독·소풍산결·소종지통 |
| 중심 병증 | 풍열독이 표와 피부·인후에 맺힌 상태 |
| 대표 증상축 | 인후통·발열감·두통·몸살·붉은 종창·압통 |
| 구성 특징 | 연교·금은화 + 형개·방풍·강활·독활 + 시호·전호·천궁·지각·길경·복령·감초 |
| 출전 | 『고금의감』, 『동의보감』 |
| 국제 연구명 | Yeon-gyo-pae-dok-san, Lianqiao Baidu San |
| 현대 연구축 | 감기의 증상점수와 병증별 반응 |

## 처방 구조

| 구성축 | 주요 본초 | 처방 안에서 보는 역할 |
|---|---|---|
| 청열해독 | [연교](../herbs/forsythia.md)·[금은화](../herbs/honeysuckle.md) | 붉음·열감·종창·인후 불편의 열독축을 정리 |
| 소풍해표 | [형개](../herbs/schizonepeta.md)·[방풍](../herbs/saposhnikovia.md)·[강활](../herbs/notopterygium.md)·[독활](../herbs/angelica-pubescens.md) | 표에 남은 풍사와 오한·두통·몸살을 풀어줌 |
| 소산·이기 | [시호](../herbs/bupleurum.md)·전호·[천궁](../herbs/chuanxiong.md)·[지각](../herbs/citrus-immature.md)·[길경](../herbs/platycodon.md) | 상부의 울체를 풀고 인후·흉격의 기운을 소통 |
| 건비조화 | [복령](../herbs/poria.md)·[감초](../herbs/licorice.md)·생강·박하 | 중초와 약성을 조화하고 표증 해소를 보조 |

『동의보감』 수록형은 연교·금은화·형개·방풍·강활·독활·시호·전호·천궁·지각·길경·복령·감초를 같은 비중으로 두고 생강과 박하를 더합니다. 의료기관·보험제제의 구성과 1일 투여량은 제품 허가사항을 확인합니다.

## 임상에서 먼저 보는 단서

| 관찰 영역 | 연교패독산을 생각하게 하는 표현 |
|---|---|
| 발병 | 비교적 급하게 시작되고 표증과 열독 증상이 겹침 |
| 인후·상기도 | 목이 붓고 아프며 열감·두통·몸살이 동반 |
| 피부 | 붉고 뜨겁고 누르면 아픈 초기 종창이나 염증성 병변 |
| 전신 | 오한과 발열감, 머리·팔다리의 무거운 통증이 함께 있음 |
| 경과 | 고름집이 깊게 형성되기 전이거나 배농 뒤 잔여 염증을 살핌 |

`호흡곤란·연하곤란·의식저하·빠르게 번지는 홍반 → 즉시 감염 평가 → 감기·인후·피부 증상 구분 → 풍열독+표증 확인 → 처방 → 열·통증·부종·기능 재평가`

## 현대 임상근거

2011년 국내 무작위·이중맹검·위약대조시험은 감기 증상이 시작된 지 48시간 이내인 **480명**에게 연교패독산 또는 소청룡탕 엑스와 위약을 비교했습니다. 연교패독산군은 일부 치료일의 WURSS-21-K 감기 증상점수가 위약군보다 감소했고, 연구진은 설문으로 풍한·풍열 병증도 함께 분류했습니다.

이 연구는 처방명만으로 결과를 일반화하기보다 **발병 시점, 엑스제 구성, 투여기간과 병증 분류가 실제 환자와 가까운지** 확인할 수 있는 국내 사람 대상 자료라는 데 의미가 있습니다.

→ [감기 무작위·이중맹검·위약대조시험, PMID 21040773](https://pubmed.ncbi.nlm.nih.gov/21040773/) · [DOI 10.1016/j.jep.2010.10.056](https://doi.org/10.1016/j.jep.2010.10.056)

## 복용과 경과 관찰

감기에서는 **발열·인후통·기침·콧물·몸살·수면·일상기능**을, 피부 병변에서는 **크기·붉음·열감·압통·삼출**을 기록합니다. 급성 증상은 짧은 간격으로 경과를 확인하고 악화되면 진단과 치료계획을 다시 봅니다.

임신·수유, 알레르기, 간·신장질환과 복용약을 확인합니다. 피부 홍반이 빠르게 퍼지거나 고열·오한이 심하고, 안면·눈 주위가 붓거나 깊은 농양이 의심되면 항생제·절개배농 등 표준치료 평가가 우선입니다.
