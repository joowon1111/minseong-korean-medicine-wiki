# 연교패독산(連翹敗毒散)

## 핵심 카드
| 항목 | 내용 |
|---|---|
| 치법 | **청열해독·소풍산결** |
| 핵심 병증 | 풍열독·창양·종통 등 |
| 구성 골격 | 연교·금은화·형개·방풍 등을 중심으로 청열해독·소풍약을 배합 |

## 처방을 읽는 법
형개연교탕은 이비인후·두면 풍열, 연교패독산은 종독·창양의 해독 방향이 더 뚜렷하다.

## 임상 탐색
`증상 → 한열·허실 → 기혈진액·담습·어혈 → 치법 → 처방군 → 개별 처방`

## 구성·용량·출전
이 페이지는 기존 일반방제 지식망의 **핵심 임상 위치와 배합 골격을 통합 정리**한 페이지다. 이미 출전별 정확한 용량이 확인된 처방은 해당 수록본을 유지하고, 동명 처방은 서로 섞지 않는다.
