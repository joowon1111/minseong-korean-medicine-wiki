# 오약순기산(烏藥順氣散) {#_1}

## 한눈에 {#_2}
**기체와 풍사를 함께 풀어 순기·소풍하는 대표 후세방**이다.

- **치법:** 순기소풍·산한
- **주치:** 풍질
- **출전:** 『태평혜민화제국방』, 『방약합편』(1884) 중통

## 『방약합편』 수록 구성·용량 {#_3}
| 본초 | 용량 |
|---|---:|
| 마황 | 5.625 g |
| 오약 | 5.625 g |
| 진피 | 5.625 g |
| 길경 | 3.75 g |
| 백강잠 | 3.75 g |
| 백지 | 3.75 g |
| 지각 | 3.75 g |
| 천궁 | 3.75 g |
| 건강 | 1.875 g |
| 감초 | 1.125 g |

**가미:** 생강 3편, 대조 2매.


## 방의 {#_4}

오약·진피·지각의 기를 소통시키는 축에 마황·백지·강잠 등 풍사를 다루는 약재가 결합되고 천궁이 혈분과 통증의 관계를 더합니다. 이름의 순기만 보고 소화불량 전반에 적용하는 구조는 아닙니다.

## 비교 {#_5}
- 분심기음: 칠정기울·흉복비체
- 오약순기산: 풍사 + 기체 + 지체통·마목의 방향
- 오적산: 한습·기혈담식이 더 복합적

<!-- MINSEONG_ONE_SHOT_FIX_V2 -->

분심기음은 칠정기울·흉복비체, 오약순기산은 풍사·기체와 지체 증상을 비교합니다. 오적산은 한습·기혈담식의 복합 구조를 살피므로 통증이라는 공통점만으로 대체하지 않습니다. [오적산(五積散)](../formulas/wujisan.md)에서 구성과 병증을 비교할 수 있습니다.

## 임상 탐색 {#clinical-assessment}

| 진료에서 확인할 항목 |
|---|
| 통증·저림이 시작된 계기와 분포 |
| 냉온·움직임에 따른 변화 |
| 근력 저하와 신경학적 평가 여부 |

통증과 감각·근력·보행을 따로 추적합니다. 갑자기 생긴 마비·언어 변화는 고전의 풍질이라는 말로 처리하지 않습니다. 마황이 포함된 실제 제제와 심계·수면·혈압 및 병용약을 진료에서 확인합니다.
