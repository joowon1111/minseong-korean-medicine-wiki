# 계지복령환(桂枝茯苓丸)

계지복령환은 《금궤요략》에 전하는 다섯 약미의 대표적인 활혈화어 처방입니다. 여성 하복부 증상을 폭넓게 가리키는 이름이 아니라, **어혈로 인한 고정성 통증·압통·혈괴와 순환 정체의 단서**를 확인해 선택합니다.

## 한눈에 보기

| 항목 | 임상에서 읽는 핵심 |
|---|---|
| 치법 | 활혈화어·완소징괴·조화기혈 |
| 핵심 병기 | 어혈이 하초와 충임에 머물러 통증·종괴감·월경 이상을 일으킴 |
| 주요 단서 | 고정성 하복부통, 누르면 아픈 부위, 월경혈괴·암자색 혈, 주기성 골반 불편 |
| 먼저 감별 | 임신, 자궁외임신, 급성 골반염, 난소염전, 심한 출혈·빈혈, 자궁근종·내막증 등 |
| 치료 후 평가 | 통증강도·지속시간, 혈괴·출혈량, 진통제 사용, 압통·일상기능 |

## 다섯 약미의 구조

| 본초 | 처방 안의 역할 |
|---|---|
| [계지](../herbs/cinnamon-bark.md) | 양기를 통하게 하고 기혈 운행을 도움 |
| [복령](../herbs/poria.md) | 수습을 조절하며 계지의 온통 작용을 받침 |
| [목단피](../herbs/moutan.md) | 혈분의 울체와 열을 풀어 활혈 구조를 보완 |
| [도인](../herbs/peach-kernel.md) | 파혈행어하여 고정성 통증·혈괴의 축을 조절 |
| [백작약](../herbs/white-peony.md) | 양혈완급하여 통증과 활혈의 균형을 잡음 |

다섯 약미가 같은 비중으로 움직이는 간결한 처방이지만, 현대 엑스제·환제·캡슐은 추출법과 용량이 다를 수 있습니다. 제품명만으로 고전 원방과 같다고 보지 않습니다.

## 임상에서 떠올리는 단서

- 통증 위치가 비교적 일정하고 찌르듯 아프거나 누르면 민감합니다.
- 월경혈이 어둡고 혈괴가 많으며 혈괴 배출 전후 통증이 달라집니다.
- 월경주기마다 하복부 팽만·골반통이 반복됩니다.
- 한응·혈허·기체·수습 가운데 어혈이 얼마나 중심인지 판단합니다.

## 비슷한 처방과 구분

| 처방 | 더 중심이 되는 단서 |
|---|---|
| **계지복령환** | 고정성 통증·압통·혈괴 등 비교적 뚜렷한 어혈 |
| [당귀작약산](danggui-shaoyao-san.md) | 혈허와 수습, 어지럼·피로·붓기·묽은변이 함께 있음 |
| [온경탕](wenjing-tang.md) | 하초 허한과 어혈, 냉감·주기 이상·건조가 함께 있음 |
| [당귀수산](danggui-susan.md) | 타박·염좌 등 외상 직후의 종창·어혈통 |
| [가미소요산](jiawei-xiaoyao-san.md) | 간울혈허·울열과 주기성 열감·긴장·유방창통 |

## 사람 대상 임상근거

2023년 발표된 원발성 월경통 무작위 대조시험은 열작혈어형 환자를 대상으로 계지복령환의 통증강도와 관련 증상을 평가했습니다. 처방과 병증을 함께 정한 직접 연구라는 점이 중요하며, 다른 유형의 월경통이나 기질질환성 통증에 결과를 그대로 넓히지 않습니다. [PMID 36746293](https://pubmed.ncbi.nlm.nih.gov/36746293/) · [DOI 10.1016/j.jep.2023.116247](https://doi.org/10.1016/j.jep.2023.116247)

## 안전성과 진료 연결

- 활혈약이 포함되므로 임신 가능성·임신, 과다출혈, 항응고제·항혈소판제, 출혈성 질환과 수술 일정을 확인합니다.
- 비정상 자궁출혈이나 골반 종괴가 의심되면 처방 선택과 별도로 산부인과적 평가를 병행합니다.
- 임신 가능성이 있는 급성 편측 골반통, 실신·어깨통증, 발열을 동반한 통증은 신속한 평가가 필요합니다.
- 치료반응은 통증점수뿐 아니라 월경량·혈괴, 진통제 사용, 결석·조퇴와 일상기능으로 확인합니다.
