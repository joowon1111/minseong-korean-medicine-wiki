# 팔물탕(八物湯)

팔물탕은 **사군자탕의 보기축과 사물탕의 보혈축을 하나로 합친 기혈쌍보의 대표방**입니다. 기력만 떨어진 상태나 혈허만 뚜렷한 상태를 넘어, 식욕·활동력·안색·어지럼·회복속도가 함께 저하된 허손을 이해하는 기본 처방입니다.

## 한눈에 보기

| 항목 | 핵심 |
|---|---|
| 다른 이름 | 팔진탕(八珍湯) 계열로도 널리 알려짐 |
| 중심 치법 | 익기보혈·기혈쌍보 |
| 구성 원리 | 사군자탕 + 사물탕 |
| 살필 단서 | 피로·식욕저하 + 안색저하·어지럼·심계가 함께 나타남 |
| 계보 | 사군자탕·사물탕 → 팔물탕 → 십전대보탕 |

## 처방 구조

| 축 | 구성 | 역할 |
|---|---|---|
| 보기축 | 인삼·백출·복령·감초 | 비위를 돕고 기혈 회복의 기반을 마련 |
| 보혈축 | 숙지황·당귀·백작약·천궁 | 혈을 기르고 조화하며 순환을 보조 |

두 기본방을 합쳤기 때문에 “기와 혈을 모두 보한다”는 설명에 그치지 않고, **소화·흡수의 기반과 혈허 증상을 동시에 살핀다**는 점이 핵심입니다.

## 임상에서 살피는 모습

- 병후·수술 후·산후에 기력과 안색이 함께 떨어짐
- 식욕저하·쉽게 지침과 어지럼·두근거림이 동반
- 월경이나 출혈 뒤 회복이 늦고 손발이 차거나 힘이 없음
- 만성질환이나 장기 치료 뒤 체중·근력·수면 회복이 더딤

회복기라도 발열·감염·지속 출혈·영양결핍의 원인을 먼저 확인하며, 소화력이 매우 약하고 더부룩함이 심하면 숙지황 등 자윤한 약재의 비중을 조절할 수 있습니다.

| 처방 | 더 두드러지는 축 |

| [사물탕](siwu-tang.md) | 혈허·조혈 |

| [인삼양영탕](renshen-yangrong-tang.md) | 오래된 허손에 심계·불면·식욕저하까지 폭넓게 동반 |

## 계보로 기억하기

**사군자탕 + 사물탕 = 팔물탕**  
**팔물탕 + 황기 + 육계 = 십전대보탕**

이 계보는 보익방을 개별 암기하기보다, 어떤 기능을 더하기 위해 약재군이 확장되었는지 이해하게 해 줍니다.

## 안전하게 보기

원인 불명의 체중감소·발열·야간발한, 지속 출혈, 흉통·호흡곤란, 심한 부종은 먼저 평가가 필요합니다. 임신·수유, 항응고제 복용, 수술·항암치료 중에는 진료계획과 병용약을 함께 확인합니다.
