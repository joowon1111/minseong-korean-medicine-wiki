# 청상견통탕(淸上蠲痛湯)

## 핵심 카드
| 항목 | 내용 |
|---|---|
| 치법 | **소풍산한·청열·지통** |
| 핵심 병증 | 풍한풍열·담어가 얽힌 두통 |
| 주요 구성 골격 | 강활·독활·방풍·천궁·백지·세신·황금·창출·맥문동·당귀·감국 등 |

## 임상에서 읽는 순서
`주증상 → 위험신호 → 한열·허실 → 기혈진액·담습·어혈 → 치법 → 처방`

## 구성·용량·출전
출전별 차이가 있을 수 있으므로 현재는 **임상 위치와 구성 골격**을 우선 정리합니다. 정확한 출전별 구성량은 원전·공식 처방 DB 확인 후 심화합니다.
