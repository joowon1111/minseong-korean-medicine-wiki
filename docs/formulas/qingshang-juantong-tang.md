# 청상견통탕(淸上蠲痛湯)

## 핵심 카드
| 항목 | 내용 |
|---|---|
| 치법 | **소풍산한·청열지통** |
| 핵심 병증 | 풍한·풍열·습담·혈분 요소가 섞인 두통 |
| 구성 골격 | 강활·독활·방풍·천궁·백지·세신·황금·창출·맥문동·당귀·감국 등 |

## 처방을 읽는 법
두통 부위·한열·담습·혈분을 함께 읽는 다층 처방이다.

## 임상 탐색
`증상 → 한열·허실 → 기혈진액·담습·어혈 → 치법 → 처방군 → 개별 처방`

## 구성·용량·출전
이 페이지는 기존 일반방제 지식망의 **핵심 임상 위치와 배합 골격을 통합 정리**한 페이지다. 이미 출전별 정확한 용량이 확인된 처방은 해당 수록본을 유지하고, 동명 처방은 서로 섞지 않는다.
