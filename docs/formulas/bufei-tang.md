# 보폐탕(補肺湯)

## 핵심 카드
| 항목 | 내용 |
|---|---|
| 치법 | **보기보폐·지해** |
| 핵심 병증 | 폐기허·기침·단기·기력저하 |
| 구성 골격 | 인삼·황기·숙지황·오미자·자완·상백피 등을 중심으로 보기·렴폐·지해 |

## 처방을 읽는 법
생맥산은 기음양허·진액손상, 보폐탕은 폐기허와 기침 쪽이 중심이다.

## 임상 탐색
`증상 → 한열·허실 → 기혈진액·담습·어혈 → 치법 → 처방군 → 개별 처방`

## 구성·용량·출전
이 페이지는 기존 일반방제 지식망의 **핵심 임상 위치와 배합 골격을 통합 정리**한 페이지다. 이미 출전별 정확한 용량이 확인된 처방은 해당 수록본을 유지하고, 동명 처방은 서로 섞지 않는다.
