# 인삼황기탕(人蔘黃芪湯)

인삼황기탕은 『동의보감』 내경편의 기문에서 **사군자탕의 보기·건비 구조에 황기와 당귀를 더해 기허와 회복저하를 보완하는 처방**으로 설명됩니다. 기력이 약하고 식욕이 떨어지며 쉽게 땀이 나는 양상을 함께 살핍니다.

> **동명 처방 주의:** 인삼황기탕은 고전의 수록 위치와 주치에 따라 구성이 다른 동명방이 여러 개입니다. 이 문서는 『동의보감』 기문에서 설명되는 사군자탕 가미 계통을 중심으로 합니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 핵심 치법 | 보기건비·익기고표·양혈 |
| 중심 병증 | 비위기허와 기혈회복 저하 |
| 대표 증상축 | 피로·소기·식욕저하·자한·안색저하 |
| 출전 | 『동의보감』 내경편 「기」 |
| 기본 구조 | 사군자탕 + 황기·당귀 |
| 임상 위치 | 사군자탕과 팔물탕 사이의 간결한 익기양혈 처방 |

[한국민족문화대백과사전](https://encykorea.aks.ac.kr/Article/E0046929)은 인삼·백출·복령·감초의 사군자탕 구조에 황기와 당귀를 더하는 처방을 설명하며, 종기·맥·혈행 관련 동명방과 구분합니다.

## 임상 단서와 감별

| 처방 | 갈림점 |
|---|---|
| [사군자탕](sijunzi-tang.md) | 순수한 비위기허와 식욕·소화 저하가 중심 |
| [팔물탕](bazhen-tang.md) | 사물탕 전체를 합해 혈허·어지럼·안색저하가 더 뚜렷 |
| [보중익기탕](buzhong-yiqi-tang.md) | 중기하함·처짐·오래 서 있을 때 악화되는 무력이 중심 |
| [황기건중탕](huangqi-jianzhong-tang.md) | 허로성 복통과 복부 긴장·자한이 중심 |
| [인삼양영탕](renshen-yangrong-tang.md) | 기혈허에 심계·건망·수면저하와 누적 허손이 겹침 |

## 경과와 안전

식사량, 활동 후 회복시간, 땀, 어지럼·심계, 체중을 기록합니다. 감초 중복과 부종·혈압·저칼륨 위험을 확인하고, 당뇨약·항응고제·항혈소판제 복용 중이면 인삼·황기·당귀와의 병용을 의료진과 조율합니다. 빈혈·체중감소·발열·호흡곤란이 지속되면 원인 검사가 우선입니다.
