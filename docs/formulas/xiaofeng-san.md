# 소풍산(消風散)

소풍산은 풍을 흩으면서 습열을 제거하고 혈분·진액을 함께 돌보는 피부 처방입니다. 가려움이라는 증상 하나보다 **붉음·열감·진물·발진의 이동성과 오래 긁어 생긴 건조**가 어떤 비중으로 겹치는지 봅니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 치법 | 소풍양혈·청열제습 |
| 핵심 병증 | 풍습열이 피부에 울체되고 혈분·진액이 손상된 소양 |
| 대표 단서 | 가려움, 홍반·구진, 진물 또는 긁은 뒤 건조·각질, 열감 |
| 출전 맥락 | 현행 방제학에서 주로 『외과정종』 계통으로 정리되는 소풍산 |
| 구성 골격 | 형개·방풍·우방자·선퇴 + 창출·고삼·목통 + 석고·지모 + 당귀·생지황·호마인·감초 |
| 감별의 중심 | 급성 알레르기·감염, 접촉원인, 건조·혈허 또는 습열 중 어느 층이 중심인지 |

## 피부 양상과 배합을 연결하기 {#skin-formula-context}

소풍산은 풍을 흩는 약, 습열을 다루는 약, 혈분과 건조를 돌보는 약을 함께 배합합니다. 풍·습·열과 혈분의 여러 요소가 겹친 가려움을 비교하는 출발점이며, 두드러기·아토피라는 병명만으로 처방을 고정하지 않습니다.

| 배합에서 보는 역할 | 본초 연결 | 임상에서 살필 내용 |
|---|---|---|
| 풍을 흩고 가려움의 맥락을 살핌 | 형개·[방풍](../herbs/saposhnikovia.md)·우방자·선퇴 | 발진·소양의 양상과 유발요인 |
| 습열·열성 양상을 조절 | 창출·고삼·석고·지모 | 진물·홍반·열감과 건조의 비중 |
| 혈분·진액을 함께 돌봄 | [당귀](../herbs/angelica.md)·생지황·호마인 | 오래된 건조·각질·긁은 피부 |

### 가까운 처방과 갈림점

| 처방 | 더 중심이 되는 단서 |
|---|---|
| **소풍산** | 풍습열성 가려움에 진물·홍반과 긁은 뒤 건조가 함께 나타남 |
| [황련해독탕](huanglian-jiedu-tang.md) | 화열·번조·홍반이 강하고 습·혈분을 함께 돌보는 구조는 적음 |
| [용담사간탕](longdan-xiegan-tang.md) | 간담습열과 하초·옆구리·이비인후 증상축이 중심 |
| 당귀음자 | 오래된 건조·혈허성 소양이 중심이고 진물·습열은 덜함 |

## 출전 원문·약량·본초 해석 {#source-dose-original}

**대조 수록본:** 《외과정종(外科正宗)》 「疥瘡論第七十三」. [해당 문헌 확인](https://jicheng.tw/tcm/book/外科正宗/index.html)

**원문 발췌**

> 當歸　生地　防風　蟬脫　知母　苦參　胡麻　荊芥　蒼朮　牛蒡子　石膏（各一錢）　甘草　木通（各五分）

**해석·주치와 배합:** 풍·습·열이 피부의 가려움·발진에 겹친 문맥입니다. 형개·방풍·우방자·선퇴의 소풍, 고삼·창출의 조습과 당귀·생지황·호마의 혈분·윤조를 함께 둡니다.

**약량 읽기:** 표는 위 수록본의 약미·약량을 풀어 쓴 것입니다. 등분은 같은 비중, 량·전·분은 중량, 승·합은 부피, 매·립은 개수 기록입니다. 역사적 제조 배합을 현대 1일 g 처방으로 일괄 환산하지 않습니다.

| 구성 본초·원문 약명 | 수록량 | 원문 포제의 뜻 | 배합에서의 본초 역할 |
|---|---|---|---|
| [당귀](../herbs/angelica.md) · 當歸 | 1전 | 별도 포제 표기 없음 | 혈을 기르면서 혈행을 조절 |
| [생지황](../herbs/fresh-rehmannia.md) · 生地 | 1전 | 별도 포제 표기 없음 | 음액을 보존하고 혈분의 열을 조절 |
| [방풍](../herbs/saposhnikovia.md) · 防風 | 1전 | 별도 포제 표기 없음 | 풍을 흩고 표·경락의 불편을 조절 |
| [선퇴](../herbs/cicada-slough.md) · 蟬脫 | 1전 | 별도 포제 표기 없음 | 산풍열·투진·지양으로 피부와 표의 풍을 조절 |
| [지모](../herbs/anemarrhena.md) · 知母 | 1전 | 별도 포제 표기 없음 | 열을 조절하면서 음액 소모를 함께 살핌 |
| [고삼](../herbs/sophora-root.md) · 苦參 | 1전 | 별도 포제 표기 없음 | 청열·조습·지양으로 습열성 피부축을 다룸 |
| [흑지마](../herbs/sesame-seed.md) · 胡麻 | 1전 | 별도 포제 표기 없음 | 음혈·윤조로 소풍·조습약의 건조를 보완 |
| [형개](../herbs/schizonepeta.md) · 荊芥 | 1전 | 별도 포제 표기 없음 | 표의 풍을 흩고 울체를 조절 |
| [창출](../herbs/atractylodes-lancea.md) · 蒼朮 | 1전 | 별도 포제 표기 없음 | 조습·건비로 습체와 중초의 정체를 다룸 |
| [우방자](../herbs/arctium.md) · 牛蒡子 | 1전 | 별도 포제 표기 없음 | 풍열·인후와 폐기의 울체를 풀어 줌 |
| [석고](../herbs/gypsum.md) · 石膏 | 1전 | 별도 포제 표기 없음 | 기분의 열과 번갈을 청해 |
| [감초](../herbs/licorice.md) · 甘草 | 5분 | 별도 포제 표기 없음 | 중초를 돕고 완급·배합 조화를 맡음 |
| [목통](../herbs/akebia-stem.md) · 木通 | 5분 | 별도 포제 표기 없음 | 청열·이뇨·통리의 축; 기원 확인이 필요 |


### 가려움·진물·혈조가 겹치는 원전의 층 {#wind-damp-heat-blood-original}

> 治風濕浸淫血脈，致生瘡疥，搔癢不絕，及大人小兒風熱癮疹，遍身云片斑點，乍有乍無並效。

**해석:** 풍습이 혈맥에 스며들어 생긴 창개와 끊이지 않는 가려움, 성인·소아의 풍열 은진과 넓게 나타났다 사라지는 발진을 기록합니다. 소산과 제습뿐 아니라 혈분을 함께 돌보는 이유를 이 문맥에서 읽습니다. [외과정종 창개편](https://jicheng.tw/tcm/book/外科正宗/index.html)

| 함께 둔 약군 | 배합에서 달라지는 방향 |
|---|---|
| 형개·방풍·우방자·선퇴 | 표부의 풍과 변동하는 발진·소양을 살핌 |
| 창출·고삼·목통 | 습열과 진물의 비중을 조절 |
| 석고·지모 | 홍반·열감에 청열과 음액 고려를 더함 |
| 당귀·생지황·호마 | 소풍·조습만으로 치우치지 않고 혈분·건조를 받침 |

11미는 각 1전이고 감초·목통은 각 5분입니다. 방후는 물 2종(鍾)을 달여 8분을 취해 식사와 시간 간격을 두고 복용하는 탕법이므로, 처방명 ‘산’만 보고 가루를 그대로 먹는 제법으로 바꾸지 않습니다.

같은 창개편의 당귀음자는 ‘혈조피부작양(血燥皮膚作癢)’을 주치로 기록하고 황기·백작약·천궁·하수오 등을 둡니다. 소풍산의 석고·지모·고삼·창출과 비교하면 열·습의 비중과 보혈·건조의 비중이 갈립니다. 원문의 창개가 오늘의 옴으로 확진된 경우에는 감염 원인 치료와 접촉자 관리를 별도로 진행합니다.

## 약재 규격·제형과 안전

목통은 이름만으로 원료를 정하지 않고 공정서에 맞는 기원과 품질을 확인합니다. 창출·방풍·고삼·선퇴도 기원종과 약용부위를 구분하고, 생지황과 숙지황을 임의로 바꾸지 않습니다. 원방 탕제, 가감방, 과립제와 연구 제품은 구성비·추출법·1일량을 별도로 기록합니다.

얼굴·입술·혀의 부종, 숨참·쌕쌕거림, 어지럼·실신감은 급성 알레르기 평가가 우선입니다. 발열·통증·고름·빠르게 번지는 홍반은 피부감염을 확인하고, 임신·수유·간신장질환·다약제 복용에서는 처방 전체의 적합성을 검토합니다.

## 소풍산 제제의 현대 임상연구 {#clinical-evidence}

2011년 위약대조 무작위시험에서는 난치성 아토피 환자에게 경구 소풍산 제제를 투여해 병변·가려움·수면 지표를 평가했습니다. 대상과 결과·한계는 [아토피 근거 카드의 소풍산 시험](../authority/conditions/atopic-dermatitis.md#xiaofeng-san-trial)에서 확인합니다. [원 논문, PMID 21196758](https://pubmed.ncbi.nlm.nih.gov/21196758/)

전통적인 풍습열 해석과 연구 대상의 선정기준은 구분합니다. 해당 시험은 비삼출성 아토피의 맥락을 제시했으며, 연구 제품과 가감 탕약·외용제는 같은 제형으로 취급하지 않습니다.

## 증상·기본 치료와 이어서 보기 {#skin-care}

[두드러기](../conditions/urticaria.md)에서는 팽진의 시간 경과와 알레르기 위험신호를, [아토피피부염](../conditions/atopic-dermatitis.md)에서는 피부장벽·수면·감염을, [습진](../conditions/eczema.md)에서는 접촉 자극과 진물·건조를 구분합니다. 소풍산을 ‘피부 독소 제거’라는 하나의 설명으로 적용하지 않습니다.

치료 후 가려움·병변 범위·수면·기존 외용약 사용을 함께 기록합니다. 여러 처방이나 외용·건강제품을 병용하면 성분과 피부 반응을 확인하고, 급성 알레르기나 피부 감염의 치료를 미루지 않습니다.

발진이 뚜렷하지 않으면 [소양증의 원인 평가](../conditions/pruritus.md#assessment)를, 항문 주변에 집중되면 [항문소양증의 배변·세정·피부 평가](../conditions/pruritus-ani.md#causes)를 먼저 확인합니다. 이 연결은 소풍산을 모든 가려움의 공통 처방으로 지정하는 의미가 아닙니다.
