# 소풍산(消風散)

## 핵심 카드
| 항목 | 내용 |
|---|---|
| 치법 | **소풍양혈·청열제습** |
| 핵심 병증 | 풍습열이 피부에 울체되어 소양이 나타나는 병증 |
| 구성 골격 | 형개·방풍·우방자·선퇴·창출·고삼·목통·석고·지모·당귀·생지황·호마인·감초 |

## 처방을 읽는 법
풍을 흩으면서 습열을 제거하고 혈분을 돌보는 삼층 구조다.

## 임상 탐색
`증상 → 한열·허실 → 기혈진액·담습·어혈 → 치법 → 처방군 → 개별 처방`

## 구성·용량·출전
이 페이지는 기존 일반방제 지식망의 **핵심 임상 위치와 배합 골격을 통합 정리**한 페이지다. 이미 출전별 정확한 용량이 확인된 처방은 해당 수록본을 유지하고, 동명 처방은 서로 섞지 않는다.
