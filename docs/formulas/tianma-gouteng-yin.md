# 천마구등음(天麻鉤藤飮) {#_1}

## 한눈에 {#_2}
| 항목 | 내용 |
|---|---|
| 치법 | **평간식풍·청열활혈·보익간신** |
| 핵심 병증 | 간양상항·간풍내동 |
| 주요 구성 골격 | 천마·구등·석결명·치자·황금·우슬·두충·[익모초](../herbs/leonurus.md)·상기생·야교등·복신 |

## 평간식풍과 보익의 배합 {#formula-structure-reading}

천마·구등·석결명의 평간식풍을 중심으로 청열·활혈·보익간신의 여러 축이 함께 놓입니다. 간양·간풍은 전통적 병증 설명이며 혈압 수치나 뇌 영상 소견과 같은 뜻이 아닙니다.

| 배합 축 | 주요 본초 | 처방 안에서 읽는 역할 |
|---|---|---|
| 평간식풍·지현 | [천마](../herbs/gastrodia.md)·[구등](../herbs/uncaria.md)·석결명 | 간양의 상승과 풍동으로 해석되는 어지럼·두통·이명·흔들림을 다룸 |
| 청열 | [치자](../herbs/gardenia.md)·[황금](../herbs/scutellaria.md) | 상열감·번조·얼굴 화끈거림 같은 열성 단서를 조절 |
| 활혈·인혈하행 | [우슬](../herbs/achyranthes.md)·[익모초](../herbs/leonurus.md) | 상부에 몰린 긴장을 아래로 이끌고 혈행의 회복을 도움 |
| 보익간신 | [두충](../herbs/eucommia.md)·상기생 | 허약한 바탕과 허리·무릎 약화를 함께 보완 |
| 안신 | 야교등·[복령·복신](../herbs/poria.md) | 불면·심계·과민이 어지럼·이명과 서로 증폭되는 고리를 조절 |

이처럼 천마·구등만으로 이루어진 단일 치법이 아니라, **평간식풍을 중심에 두고 열·혈행·간신의 허약·수면과 긴장을 동시에 조율하는 복합 구조**입니다. 실제 진료에서는 상열과 두통이 뚜렷한지, 담습·오심이 더 중심인지, 기혈 또는 신정의 허약이 겹치는지를 확인해 가감합니다.

## 감별 포인트 {#_3}

| 비교 항목 | 천마구등음 쪽 단서 | 반하백출천마탕 쪽 단서 |
|---|---|---|
| 중심 병증 | 간양상항·간풍내동 | 비허담습·풍담상요 |
| 머리 증상 | 팽팽하거나 치솟는 두통, 상열감, 스트레스와 연동 | 머리가 무겁고 맑지 않으며 눕고 싶은 느낌 |
| 동반 증상 | 이명·불면·과민·목 긴장 | 오심·가래·더부룩함·식욕저하·피로 |
| 핵심 본초 | 천마·구등·석결명 | 반하·백출·복령·진피·천마 |

같은 천마가 들어가도 처방의 중심은 다릅니다. 상열·두통·긴장과 이명이 선명하면 천마구등음의 평간식풍 구조를, 두중·오심·소화저하가 선명하면 [반하백출천마탕](../formulas/banxia-baizhu-tianma-tang.md)의 화담건비 구조를 우선 비교합니다.

## 출전·구성 원칙 {#_4}
원방의 구성·용량·제법은 출전과 수록본을 지정해 확인합니다. 현대 연구는 실제 사용한 제제·대상 질환·비교군·평가 기간을 구분해 읽고, 전통적 치법과 환자의 현재 변증이 얼마나 잘 맞는지 함께 판단합니다.

## 임상 탐색 {#_5}

| 진료에서 확인할 항목 | 치료 후 함께 볼 변화 |
|---|---|
| 어지럼이 갑자기 생겼는지, 얼마나 자주·오래 반복되는지 | 발작 횟수·지속시간·DHI와 보행 안정 |
| 두통·목 긴장·상열감·이명·수면의 연동 | 두통일수·목 가동범위·THI·수면시간 |
| 혈압 변동, 현재 복용약, 식사·소화와 대소변 | 혈압 기록·피로·식사량과 복약 후 변화 |
| 혀·맥과 담습·기혈휴허·신정부족 겸증 | 가감 뒤 중심 증상과 전신 회복의 균형 |

천마구등음은 간양상항·간풍의 단서가 뚜렷한 어지럼·두통·이명에서 한약 치료축으로 활용하고, 침·전침은 풍지·태충·양릉천·백회와 경항부 긴장을 중심으로 연결할 수 있습니다. 새 마비·언어 변화·복시·급격한 극심한 두통·새 보행실조는 즉시 평가하며, 복용 중인 혈압약과 함께 혈압·어지럼 변화를 기록합니다.

## 이명·현훈 치료망에서의 위치

`간양상항·간풍 단서 → 천마·구등 중심 평간식풍 → 청열·활혈·보익간신·안신 배합 → 한약 + 침·전침 → 어지럼 빈도·두통일수·THI·수면·보행 재평가`

- [이명](../conditions/tinnitus.md): 어지럼·두통·상열감·목 긴장이 이명 변동과 함께 나타나는지 확인합니다.
- [어지럼·현훈](../conditions/dizziness.md): 담습중조·기혈휴허·신정부족과 비교해 간양상항이 중심인지 구분합니다.
- [메니에르병](../conditions/menieres-disease.md): 발작기와 안정기를 나누고 청력·발작일지와 함께 변증 변화를 추적합니다.
