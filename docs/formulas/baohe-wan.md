# 보화환(保和丸)

## 한눈에
**음식적체를 소화시키고 위를 조화하는 대표 소식화적방**이다.

- **치법:** 소식화적·화위
- **핵심 병증:** 식적·완복창만·애부·산부·식후불편

## 구성 골격
산사 · 신곡 · 반하 · 복령 · 진피 · 연교 · 나복자

## 구조
산사·신곡·나복자가 음식적체를 소화시키고, 반하·진피·복령이 담습과 위기불화를 조절하며, 연교가 식적에서 생긴 울열을 식히는 구조다.

## 비교
- **평위산:** 습체가 중심
- **보화환:** 식적이 중심
- **향사육군자탕:** 비기허를 바탕으로 담습·기체가 중심
