# 삼출건비탕(參朮健脾湯)

삼출건비탕은 인삼·백출의 보기건비를 중심으로 산사·신곡·맥아의 소식축과 진피·후박·사인의 이기화습축을 함께 배치한 처방입니다. **소화력이 약한 바탕에 음식 적체와 복부팽만이 반복되는 상태**를 한 번에 이해하기 좋습니다.

## 구성과 처방 구조

후대 해설서B의 11미 구성은 인삼·백출·백복령·감초, 백작약, 진피·후박·사인, 산사육·신곡·맥아입니다.

### 동의보감 수록형과 후대 기록의 차이 {#donguibogam-version}

《동의보감》 잡병편 권3 내상에 대응하는 **삼출건비탕A(P0001494)**는 다음 12미를 기록합니다. 기존에 연결된 **삼출건비탕B(P0016230)**는 《동의방제와 처방해설》(2002) 자료로, 지실이 없는 11미입니다.

| 약미군 | 동의보감A의 DB 용량 | 2002년 해설서B와의 비교 |
|---|---|---|
| 인삼·백출·백복령·진피·후박·산사육 | 각 3.75 g | 공통 |
| 백작약 | 3 g | 공통 |
| 지실 | 3 g | A에 있고 B에는 없음 |
| 신곡·맥아·축사·감초 | 각 1.875 g | 공통 |
| 생강·대조 | 3편·2매 | 제법에 함께 기록 |

약미별 g은 공개 DB 표기입니다. ‘삼출건비탕’이라는 이름만으로 두 구성을 합치지 않고 **지실의 유무와 출전**을 확인합니다. 지실은 다른 소식·이기약과 함께 복부 정체를 비교하는 약미이며, 명칭만 보고 임의로 추가하지 않습니다. [동의보감A 기록](https://koreantk.com/ktkp2014/prescription/prescription-view.view?preCd=P0001494&tempLang=ko) · [2002년 B 기록](https://koreantk.com/ktkp2014/prescription/prescription-view.view?preCd=P0016230&tempLang=ko)

| 구성축 | 본초 | 역할 |
|---|---|---|
| 보기건비 | [인삼](../herbs/ginseng.md)·[백출](../herbs/atractylodes.md)·[복령](../herbs/poria.md)·[감초](../herbs/licorice.md) | 비위의 운화와 식후 기력 회복을 받침 |
| 양혈완급 | [백작약](../herbs/white-peony.md) | 복부 긴장과 통증을 부드럽게 조절 |
| 소식화체 | [산사](../herbs/hawthorn.md)·신곡·[맥아](../herbs/barley-malt.md) | 음식 정체와 식후 더부룩함을 풀어 줌 |
| 이기화습 | [진피](../herbs/citrus-peel.md)·[후박](../herbs/magnolia-bark.md)·[사인](../herbs/amomum.md) | 트림·가스·복부창만과 습체를 조절 |
| 파기제만 | 동의보감A의 [지실](../herbs/citrus-immature.md) | 비위허약에 겹친 정체의 비중을 확인 |

### 보하는 약과 소식약을 함께 배치한 이유 {#tonification-and-food-stagnation}

이 처방은 음식 정체를 풀기만 하거나 기력을 보하기만 하는 두 방향 사이에서, **약해진 비위가 음식을 받아들이는 힘과 이미 머문 음식의 정체를 함께 조절**합니다. 인삼·백출·복령이 처방의 바탕을 받치고, 산사·신곡·맥아가 식후 정체를 다루며, 진피·후박·축사가 음식과 기의 이동을 돕습니다. 백작약은 복부의 당김·긴장을 완급하는 축으로 읽습니다.

| 약미의 관계 | 학습할 배합 의도 |
|---|---|
| 인삼·백출과 산사·신곡·맥아 | 보익이 정체를 더하지 않도록 하고 소식이 허약한 바탕을 놓치지 않도록 함 |
| 진피·후박·축사 | 소식약과 별도로 창만·트림·기체와 습체를 조절 |
| 백작약과 감초 | 복부의 긴장과 통증을 부드럽게 조절하는 방향 |
| 동의보감A의 지실 | 식적뿐 아니라 막히고 그득한 기의 비중을 확인하는 약미 |

동의보감A에서는 인삼과 산사육이 같은 DB 중량으로 기재됩니다. 이는 인삼만 크게 쓰는 순수 보익방과 다른 배합이라는 단서입니다. 산사·신곡·맥아도 모두 같은 작용으로 묶기보다 실제 약미·포제와 식사 양상을 대조합니다. 식사량은 늘었지만 식후 팽만이 더 오래가거나, 소화는 편해졌는데 섭취량·기력이 회복되지 않는다면 두 치료축의 균형을 다시 봅니다.

이 배합 설명은 [동의보감A의 구성·제법](https://koreantk.com/ktkp2014/prescription/prescription-view.view?preCd=P0001494&tempLang=ko)을 바탕으로 한 방의 해석이며, 각 약미가 현대 위장관 기능에 미치는 효과를 개별적으로 입증한 시험 결과는 아닙니다.

## 임상 선택 단서

- 평소 식사량이 적고 조금만 과식해도 오래 더부룩합니다.
- 체한 뒤 식욕이 회복되지 않고 피로·무력감이 함께 남습니다.
- 명치 답답함, 트림·가스, 복부팽만과 묽은변이 번갈아 나타납니다.
- 소식약만 쓰면 기력이 쉽게 떨어지고, 보익약만 쓰면 답답함이 생기는 양상입니다.

## 가까운 처방과 감별

| 처방 | 중심 단서 |
|---|---|
| **삼출건비탕** | 비위기허 + 식적 + 기체, 보기와 소식이 함께 필요 |
| [전씨이공산](jeonssi-igong-san.md) | 비위기허와 기체가 중심이며 소식약군이 간결함 |

| [평위산](pingwei-san.md) | 허약보다 습체·복부창만·몸의 무거움이 중심 |
| [보화환](baohe-wan.md) | 과식 뒤 급성 식적과 산사·신곡·나복자의 소식축이 중심 |

## 경과관찰과 진료 연결

한 끼 식사량, 식후 포만 지속시간, 트림·가스, 명치 불편, 배변형태, 체중·피로를 기록합니다. 만성 소화불량에서는 상복부 통증형과 식후불편형을 나누고, 수면·스트레스·식사 간격 및 복용약도 함께 살피면 처방 반응을 더 정확히 평가할 수 있습니다.

연하곤란, 반복 구토, 토혈·흑변, 빈혈이나 의도하지 않은 체중감소는 내시경 등 필요한 검사를 함께 진행합니다. 맥아는 수유 상태, 감초는 다른 처방과의 중복, 산사·백작약은 항응고·항혈소판제 복용 여부를 확인합니다.
