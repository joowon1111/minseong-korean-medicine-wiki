# 삼출건비탕(參朮健脾湯)

삼출건비탕은 인삼·백출의 보기건비를 중심으로 산사·신곡·맥아의 소식축과 진피·후박·사인의 이기화습축을 함께 배치한 처방입니다. **소화력이 약한 바탕에 음식 적체와 복부팽만이 반복되는 상태**를 한 번에 이해하기 좋습니다.

## 구성과 처방 구조

대표 수록 구성은 인삼·백출·백복령·감초, 백작약, 진피·후박·사인, 산사육·신곡·맥아입니다.

| 구성축 | 본초 | 역할 |
|---|---|---|
| 보기건비 | [인삼](../herbs/ginseng.md)·[백출](../herbs/atractylodes.md)·[복령](../herbs/poria.md)·[감초](../herbs/licorice.md) | 비위의 운화와 식후 기력 회복을 받침 |
| 양혈완급 | [백작약](../herbs/white-peony.md) | 복부 긴장과 통증을 부드럽게 조절 |
| 소식화체 | [산사](../herbs/hawthorn.md)·신곡·[맥아](../herbs/barley-malt.md) | 음식 정체와 식후 더부룩함을 풀어 줌 |
| 이기화습 | [진피](../herbs/citrus-peel.md)·[후박](../herbs/magnolia-bark.md)·[사인](../herbs/amomum.md) | 트림·가스·복부창만과 습체를 조절 |

## 임상 선택 단서

- 평소 식사량이 적고 조금만 과식해도 오래 더부룩합니다.
- 체한 뒤 식욕이 회복되지 않고 피로·무력감이 함께 남습니다.
- 명치 답답함, 트림·가스, 복부팽만과 묽은변이 번갈아 나타납니다.
- 소식약만 쓰면 기력이 쉽게 떨어지고, 보익약만 쓰면 답답함이 생기는 양상입니다.

## 가까운 처방과 감별

| 처방 | 중심 단서 |
|---|---|
| **삼출건비탕** | 비위기허 + 식적 + 기체, 보기와 소식이 함께 필요 |
| [전씨이공산](jeonssi-igong-san.md) | 비위기허와 기체가 중심이며 소식약군이 간결함 |
| [육군자탕](liujunzi-tang.md) | 담음·오심·조기포만과 반하·진피축이 중심 |
| [평위산](pingwei-san.md) | 허약보다 습체·복부창만·몸의 무거움이 중심 |
| [보화환](baohe-wan.md) | 과식 뒤 급성 식적과 산사·신곡·나복자의 소식축이 중심 |

## 경과관찰과 진료 연결

한 끼 식사량, 식후 포만 지속시간, 트림·가스, 명치 불편, 배변형태, 체중·피로를 기록합니다. 만성 소화불량에서는 상복부 통증형과 식후불편형을 나누고, 수면·스트레스·식사 간격 및 복용약도 함께 살피면 처방 반응을 더 정확히 평가할 수 있습니다.

연하곤란, 반복 구토, 토혈·흑변, 빈혈이나 의도하지 않은 체중감소는 내시경 등 필요한 검사를 함께 진행합니다. 맥아는 수유 상태, 감초는 다른 처방과의 중복, 산사·백작약은 항응고·항혈소판제 복용 여부를 확인합니다.
