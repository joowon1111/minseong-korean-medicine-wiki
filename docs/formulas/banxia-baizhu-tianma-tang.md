# 반하백출천마탕(半夏白朮天麻湯)

## 한눈에
**비위허약을 바탕으로 담습·풍담이 위로 올라 현훈·두통·오심을 만드는 병증의 대표방**이다.

- **치법:** 건비조습·화담식풍
- **출전:** 『비위론』, 『방약합편』(1884) 중통

## 핵심 감별
- **이진탕:** 담습 자체의 기본방
- **반하백출천마탕:** 비허담습 + 현훈·두통·풍담
- **온담탕:** 담울·담열과 심번·불면 쪽
