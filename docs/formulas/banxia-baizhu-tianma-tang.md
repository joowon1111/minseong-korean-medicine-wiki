# 반하백출천마탕(半夏白朮天麻湯)

반하백출천마탕은 **비위가 약해 수습이 정체되고, 그 담습이 풍과 함께 위로 올라 어지럼·머리 무거움·두통·오심을 만드는 병증**의 대표방입니다. 반하·진피·복령·백출이 담습의 바탕을 정리하고, 천마가 풍담성 현훈과 두통을 다루며, 인삼·황기가 중기의 허약을 받쳐줍니다.

> **핵심 해석:** 어지럼이라는 병명만 보지 않고 **머리가 무겁고 흐림·메스꺼움·식욕저하·피로·가래나 담감**이 함께 있는지 확인합니다.

## 출전 원문·약량·본초 해석 {#source-dose-original}

**대조 수록본:** 《비위론(脾胃論)》 「半夏白朮天麻湯」. [해당 문헌 확인](https://jicheng.tw/tcm/book/脾胃論/index.html)

**원문 발췌**

> 黃柏（二分）　乾薑（三分）　天麻　蒼朮　白茯苓　黃耆　澤瀉　人參（以上各五分）　白朮　炒曲（以上各一錢）　半夏（湯洗七次）　大麥糵面　橘皮（以上各一錢五分）

**해석·주치와 배합:** 비위의 기가 부족하면서 음식 적체와 습열이 겹친 문맥입니다. 보하는 약과 신곡·맥아 등의 소도약, 창출·택사 등 습의 조절을 한 배합에 둡니다.

**약량 읽기:** 표는 위 수록본의 약미·약량을 풀어 쓴 것입니다. 등분은 같은 비중, 량·전·분은 중량, 승·합은 부피, 매·립은 개수 기록입니다. 역사적 제조 배합을 현대 1일 g 처방으로 일괄 환산하지 않습니다.

## 『방약합편』 수록 구성

| 구성축 | 주요 본초 | 처방 안에서 보는 역할 |
|---|---|---|
| 화담강역 | [반하](../herbs/pinellia.md)·[진피](../herbs/citrus-peel.md) | 담을 삭이고 오심과 위기상역을 내림 |
| 건비조습 | [백출](../herbs/atractylodes.md)·[복령](../herbs/poria.md)·창출 | 비위를 돕고 담습이 생기는 바탕을 정리 |
| 식풍지현 | [천마](../herbs/gastrodia.md) | 풍담이 위로 흔드는 현훈·두통축을 다룸 |
| 보기승청 | [인삼](../herbs/ginseng.md)·[황기](../herbs/astragalus.md) | 비위허약과 피로를 보완해 맑은 기운이 오르도록 도움 |
| 소도이습 | 맥아·신국·[택사](../herbs/alisma.md) | 음식 정체와 수습 배출을 보조 |
| 온중조화 | 건강·황백·생강 | 한열과 중초 상태를 조정하며 전체 배합을 조화 |

『방약합편』 중통 115는 《동의보감》을 인용하며, 아래 수록 구성과 같은 약미별 상대량을 기록합니다. 반하·진피·맥아는 각 1전 5분, 백출·신국은 각 1전, 백복령을 포함한 여섯 약재는 각 5분, 건강은 3분입니다. [한의학고전DB 공개 원문 PDF, 443쪽](https://info.mediclassics.kr/bookshelf/books/eBook/20191213_bangyak_1/book.pdf#page=443)

### 《동의보감》의 담궐두통과 수록 비율 {#donguibogam-version}

> 脾胃虛弱，痰厥頭痛。 — 외형편 권1 두, 반하백출천마탕

**해석:** 비위가 약하고 담과 관련된 두통이 나타나는 상태입니다. 해당 항목은 **「嘔吐眩暈」**도 함께 기술하므로, 어지럼만이 아니라 오심·식욕저하·피로·두중감의 조합을 읽습니다. 《동의보감》은 이 처방에서 동원(東垣)을 인용합니다. [외형편 원문](https://ko.wikisource.org/wiki/동의보감/외형편)

| 동의보감 수록 구성 | 기록된 상대량 |
|---|---|
| 법제 반하·진피·볶은 맥아 | 각 1전 5분 |
| 백출·볶은 신국 | 각 1전 |
| 창출·인삼·황기·천마·백복령·택사 | 각 5분 |
| 건강 / 주세 황백 | 3분 / 2분 |
| 전탕 때 추가 | 생강 5쪽 |

위 《방약합편》 원문과 《동의보감》의 상대량을 함께 대조했습니다. 현대 제품·연구에서는 **포제·약미별 상대비·추출량**을 확인하고, 역사적 전·분을 환자의 현대 복용량으로 바로 환산하지 않습니다. [동의보감 처방 기록 대조](https://koreantk.com/ktkp2014/prescription/prescription-view.view?preCd=P0001007&tempLang=ko) · [어지럼의 감별과 원문 해석](../conditions/dizziness.md#classical-clinical-reading)

## 임상에서 먼저 보는 단서

| 관찰 영역 | 반하백출천마탕을 생각하게 하는 표현 |
|---|---|
| 어지럼 | 빙빙 돌거나 흔들리며 머리가 무겁고 맑지 않음 |
| 위장 | 메스꺼움·식욕저하·더부룩함이 어지럼과 함께 변함 |
| 체력 | 쉽게 피로하고 식후 나른하며 회복이 더딤 |
| 담습 | 몸이 무겁고 가래·부종감·끈끈한 설태 등 담습 단서가 동반 |
| 두통 | 머리가 무겁게 조이거나 어지럼과 함께 심해짐 |

## 현대 임상근거

2017년 체계적 문헌고찰·메타분석은 추골기저동맥 순환부전 관련 현훈을 다룬 **27개 무작위시험, 2,796명**을 종합했습니다. 반하백출천마탕을 어지럼 치료약에 더한 연구군에서 보고된 임상반응과 일부 도플러 혈류 지표가 대조군보다 개선됐습니다. 단독 비교는 350명으로 규모가 작았고, 포함 연구의 방법과 안전성 보고가 충분히 표준화되지 않았습니다.

이 근거의 연구 대상은 **추골기저동맥 순환부전 관련 현훈으로 분류된 환자군**입니다. 고전의 비허담습·풍담 변증 전체나 이석증·메니에르병에 같은 효과를 입증한 자료로 확대하지 않습니다. 임상 적용에서는 원인별 진료와 연구 제제·병용치료를 대조하고, 어지럼·보행과 오심·소화기능의 변화를 따로 추적합니다.

→ [PMID 28434468](https://pubmed.ncbi.nlm.nih.gov/28434468/) · [DOI 10.1016/j.ctim.2017.01.004](https://doi.org/10.1016/j.ctim.2017.01.004)

## 복용과 경과 관찰

치료 전후에는 **어지럼 강도와 빈도·보행 안정·오심·식사량·두중감·두통일수·일상활동**을 함께 기록합니다. 이석증이면 이석정복술, 전정신경염·메니에르병·편두통성 어지럼 등 원인별 진료를 병행합니다.

갑작스러운 말 어눌함·한쪽 마비·복시·새로운 보행실조·의식변화·벼락두통은 즉시 평가해야 합니다. 감초를 포함한 다른 처방의 중복, 이뇨제·혈압약과 함께 복용할 때의 어지럼·혈압 변화, 식욕과 대변 변화를 관찰합니다.
