# 반하사심탕(半夏瀉心湯)

## 한눈에
**한열착잡으로 심하가 막히고 구역·장명·설사가 함께 나타나는 비증의 대표방**이다.

- **치법:** 한열평조·소비산결
- **출전:** 『상한론』, 『방약합편』 증보방

## 『방약합편』 수록 구성·용량
| 본초 | 용량 |
|---|---:|
| 반하 | 11.25 g |
| 황금 | 5.625 g |
| 건강 | 5.625 g |
| 인삼 | 5.625 g |
| 감초 | 5.625 g |
| 황련 | 1.875 g |
| 대조 | 2매 |

## 방의
반하·건강의 온화강역과 황금·황련의 청열이 함께 작동하고, 인삼·감초·대조가 중기를 보완한다.

## 핵심 감별
**심하비만 + 구역/장명/설사 + 한열착잡**이라는 구조가 중요하다.
