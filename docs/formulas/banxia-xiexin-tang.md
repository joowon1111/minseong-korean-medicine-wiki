# 반하사심탕(半夏瀉心湯)

반하사심탕은 **명치가 막힌 듯 답답하면서 위로는 메스껍고 아래로는 장명·묽은 변이 나타나는 한열착잡의 비위불화**를 조절하는 대표 처방입니다. 반하·건강의 맵고 따뜻한 축과 황금·황련의 쓰고 찬 축을 함께 두어, 한쪽으로 데우거나 식히기보다 **신개고강(辛開苦降)으로 뒤엉킨 승강을 다시 맞추는 구조**가 핵심입니다.

> **핵심 해석:** 단순한 소화불량보다 **심하비만·식후 답답함·오심·트림과 장명·묽은 변이 함께 이어지는지**를 확인합니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 핵심 치법 | 한열평조·신개고강·소비산결 |
| 중심 병증 | 한열착잡, 비위불화, 심하비 |
| 대표 증상축 | 식후 더부룩함·명치답답함·오심·트림·복명·묽은 변 |
| 기본 구성 | 반하·황금·건강·인삼·감초·황련·대조 |
| 출전 | 『상한론』 |
| 국제 연구명 | Banxia Xiexin Tang/Decoction, Banha-sasim-tang, Hange-shashin-to |
| 현대 연구축 | 기능성소화불량, 위장관 운동·그렐린, 상부와 하부 위장관 증상 |

심하비의 감별과 배합을 이야기로 읽으려면 [한 약첩에 담긴 차가움과 따뜻함](../classical-stories/digestive-cold-warm-pairing.md)를 참고하세요. 원문이 구별한 그득함·통증과 후대의 한열 배합 해석을 연결합니다.

## 일곱 약재가 만드는 처방 구조

| 구성 본초 | 처방 안에서 보는 역할 |
|---|---|
| [반하](../herbs/pinellia.md) | 담을 삭이고 위기를 내려 오심과 명치의 막힘을 조절 |
| [건강](../herbs/dried-ginger.md) | 중초를 덥히며 반하와 함께 신개·강역의 축을 형성 |
| [황금](../herbs/scutellaria.md)·[황련](../herbs/coptis.md) | 위장관에 얽힌 열을 맑히고 쓴맛으로 하강을 도움 |
| [인삼](../herbs/ginseng.md) | 비위의 기를 보완해 한열 조절이 지나치게 공격적이지 않게 받침 |
| [감초](../herbs/licorice.md)·대조 | 중초를 조화하고 여러 약재의 작용을 연결 |

처방은 온약과 한약을 단순히 반씩 섞은 것이 아니라, **반하·건강의 개통과 황금·황련의 하강, 인삼·감초·대조의 회복축**을 동시에 배치합니다. 따라서 속이 냉한지 열한지 하나만 고르는 경우보다 상하·한열 증상이 교차하는 병증에서 구조가 선명합니다.

### 《동의보감》 수록본과 한열 조화의 의미 {#donguibogam-version}

잡병편 권3 한에 수록된 반하사심탕은 중경을 인용합니다. 한국전통지식포탈의 해당 기록은 **반하·황금·황련·건강·인삼·감초에 생강·대조를 더하는 탕제**로 정리돼 있습니다. 위 《상한론》의 일곱 약재 설명과 대조할 때 생강의 추가와 비율을 따로 확인합니다. [수록본 구성·제법](https://koreantk.com/ktkp2014/prescription/prescription-view.view?preCd=P0001009&tempLang=ko)

| 기록의 구성군 | 한국전통지식포탈의 환산 표기 |
|---|---|
| 법제 반하 | 7.5g |
| 황금·인삼·감초 | 각 5.625g |
| 건강 / 황련 | 3.75g / 1.875g |
| 전탕 때 추가 | 생강 3쪽·대조 2개 |

이 수치는 **문헌 DB의 해당 수록본 표기**이며 개인의 1일 복용량이나 임상시험 제제의 용량을 뜻하지 않습니다. 건강·반하는 신온강역, 황금·황련은 고한청열, 인삼·감초·대조는 중초를 돕는 축으로 읽습니다. 뜨겁거나 차다는 느낌 하나보다 **심하비·오심·장명·묽은변이 겹친 조합**에 이 배합이 맞는지 확인합니다.

## 임상에서 먼저 보는 단서

| 관찰 영역 | 반하사심탕을 생각하게 하는 표현 |
|---|---|
| 명치·상복부 | 눌러도 심한 통증보다는 막히고 그득한 심하비, 식후 답답함 |
| 위장 상부 | 오심·헛구역·트림·신물·입맛 저하 |

| 전신 상태 | 오래된 소화불편으로 식사량과 활동량이 줄고 쉽게 지침 |

## 현대 임상근거

### 기능성소화불량의 종합 근거

2023년 체계적 문헌고찰·메타분석은 **57개 RCT·5,525명**을 종합해 반하사심탕 단독 또는 통상치료 병용이 기능성소화불량의 전체 증상, 소화불편 점수와 일부 위장관 관련 지표에 미치는 영향을 평가했습니다. 연구마다 원방·가감방과 비교치료가 달라 실제 적용에서는 연구 처방과 환자의 병증을 함께 대조합니다.

→ [PMID 37274096](https://pubmed.ncbi.nlm.nih.gov/37274096/) · [DOI 10.3389/fphar.2023.1130257](https://doi.org/10.3389/fphar.2023.1130257)

### 국내 무작위 임상시험

2021년 국내 위약대조 연구에서는 기능성소화불량의 실증 환자에게 반하사심탕 시럽을 4주간 투여하고 Nepean Dyspepsia Index, 식후 포만감과 삶의 질을 평가했습니다. 같은 해 스트레스 관련 증상이 두드러진 기능성소화불량 환자 31명을 대상으로 한 무작위시험은 소화불편과 그렐린 변화를 함께 살펴, **위장관 증상과 스트레스 반응을 한 축으로 평가하는 임상질문**을 제시했습니다.

→ [PMID 34512334](https://pubmed.ncbi.nlm.nih.gov/34512334/) · [PMID 33959008](https://pubmed.ncbi.nlm.nih.gov/33959008/)

## 비슷한 처방과 감별

### 상한론 사심탕류의 원문 감별 {#shanghan-xiexin-family}

현대의 소화불량 처방과 비교하기 전에, 《상한론》 안에서 같은 ‘사심탕’ 이름을 가진 처방이 무엇을 달리 보는지 확인합니다. 149조는 **시호증이 남는 경우, 명치가 그득하고 단단하며 아픈 결흉, 그득하되 아프지 않은 비**를 먼저 나눕니다. 원문에서 치료 뒤 변화와 촉진 소견을 함께 읽는 이유입니다.

| 처방·조문 | 중심 증후 | 구성·제법의 차이 |
|---|---|---|
| [반하사심탕 · 149조](../classics/shanghanlun/clauses/taiyang-lower.md#clause-149) | 만이불통의 비 | 반하·황금·건강·인삼·감초·황련·대조. 건강 3냥, 황련 1냥 |
| [생강사심탕 · 157조](../classics/shanghanlun/clauses/taiyang-lower.md#clause-157) | 비경·건애식취·협하수기·장명·하리 | 생강 4냥, 건강 1냥. 생강과 건강을 같은 약재·용량으로 합치지 않음 |
| [감초사심탕 · 158조](../classics/shanghanlun/clauses/taiyang-lower.md#clause-158) | 반복 하법 뒤 위허·객기상역과 미소화 하리·건구·심번 | 감초 4냥. 아카이브 기준 송본의 약재 목록은 인삼 없는 6미이며 다른 판본·교감의 7미 구성과 구분 |
| [대황황련사심탕 · 154조](../classics/shanghanlun/clauses/taiyang-lower.md#clause-154) | 비·안지유·관상부 | 대황 2냥·황련 1냥의 끓는 물 침출. 반하사심탕 7미나 승기탕류의 전탕과 다름 |
| [부자사심탕 · 155조](../classics/shanghanlun/clauses/taiyang-lower.md#clause-155) | 비에 오한·한출이 겹침 | 대황·황련·황금의 침출액에 별도로 달인 부자액을 합침 |

이 수치는 **송본 내 배합을 비교하는 고전 단위**이며 현대 복용량이 아닙니다. 특히 158조는 심하의 그득함을 남은 결열로 오인해 다시 하법을 쓴 뒤 악화되는 경과를 적고, 위허와 상역을 설명합니다. 명치가 막혔다는 표현 하나보다 **치료 이력·대변의 소화 상태·장명·구역·촉진**이 함께 판단을 바꿉니다. [사심탕·치자시탕 계열의 위치](../formula-architecture/shanghan-family.md#vexation-and-pi) · [원문에서 치료 후 다시 판단하기](../shanghan-network/index.md#reassessment)

## 치료반응과 안전 확인

치료 전후에는 **식후포만·명치답답함·오심·트림·복명·대변 상태·식사량·체중과 일상기능**을 함께 봅니다. 명치의 막힘은 줄지만 식욕이 떨어지거나 설사·복통이 새로 생기는지도 확인해 유지·가감·전환 시점을 정합니다.

흑변·토혈, 반복되는 구토, 진행하는 체중 감소, 빈혈, 연하곤란, 심한 야간통처럼 기질적 질환을 시사하는 경우에는 내시경과 의학적 평가가 우선입니다. 반하의 법제, 황금·황련의 고한성, 감초의 총복용량은 제형·기간·복용약과 함께 확인합니다.
