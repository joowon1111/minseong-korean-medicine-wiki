# 혈부축어탕(血府逐瘀湯) {#_1}

## 한눈에 {#_2}
**흉중 어혈에 기체를 겸한 고정성 통증·두통·심계·불면 등의 전통적 병증을 다루는 대표 활혈거어방**이다.

- **치법:** 활혈거어·행기지통
- **출전:** 『의림개착』

## 출전 원문·약량·본초 해석 {#source-dose-original}

**대조 수록본:** 《의림개착(醫林改錯)》 「血府逐瘀湯」. [해당 문헌 확인](https://jicheng.tw/tcm/book/醫林改錯/index.html)

**원문 발췌**

> 當歸（三錢）　生地（三錢）　桃仁（四錢）　紅花（三錢）　枳殼（二錢）　赤芍（二錢）　柴胡（一錢）　甘草（一錢）　桔梗（一錢半）　川芎（一錢半）　牛膝（三錢）

**해석·주치와 배합:** 흉중의 혈어와 기체가 겹친 문맥입니다. 도홍사물 계열에 시호·지각·길경·우슬을 결합하여 기혈의 정체와 승강을 함께 조절합니다.

이 표는 원전의 전(錢) 기록입니다. 아래 현대 g 표는 별도 환산·임상 수록량이며 원전 단위 자체가 g인 것은 아닙니다.

**약량 읽기:** 표는 위 수록본의 약미·약량을 풀어 쓴 것입니다. 등분은 같은 비중, 량·전·분은 중량, 승·합은 부피, 매·립은 개수 기록입니다. 역사적 제조 배합을 현대 1일 g 처방으로 일괄 환산하지 않습니다.

| 구성 본초·원문 약명 | 수록량 | 원문 포제의 뜻 | 배합에서의 본초 역할 |
|---|---|---|---|
| [당귀](../herbs/angelica.md) · 當歸 | 3전 | 별도 포제 표기 없음 | 혈을 기르면서 혈행을 조절 |
| [생지황](../herbs/fresh-rehmannia.md) · 生地 | 3전 | 별도 포제 표기 없음 | 음액을 보존하고 혈분의 열을 조절 |
| [도인](../herbs/peach-kernel.md) · 桃仁 | 4전 | 별도 포제 표기 없음 | 어혈을 풀고 장의 건조를 윤택하게 함 |
| [홍화](../herbs/safflower.md) · 紅花 | 3전 | 별도 포제 표기 없음 | 활혈·통경으로 혈분의 정체를 조절 |
| [지각](../herbs/citrus-aurantium-immature.md) · 枳殼 | 2전 | 별도 포제 표기 없음 | 기체·팽만을 조절하는 행기축 |
| [적작약](../herbs/red-peony.md) · 赤芍 | 2전 | 별도 포제 표기 없음 | 혈분의 열과 정체를 조절 |
| [시호](../herbs/bupleurum.md) · 柴胡 | 1전 | 별도 포제 표기 없음 | 소양·간울의 기기 조절을 맡음 |
| [감초](../herbs/licorice.md) · 甘草 | 1전 | 별도 포제 표기 없음 | 중초를 돕고 완급·배합 조화를 맡음 |
| [길경](../herbs/platycodon.md) · 桔梗 | 1전반 | 별도 포제 표기 없음 | 폐기를 펼치고 인후·담을 조절 |
| [천궁](../herbs/chuanxiong.md) · 川芎 | 1전반 | 별도 포제 표기 없음 | 혈분의 정체와 기체를 함께 풀어 줌 |
| [우슬](../herbs/achyranthes.md) · 牛膝 | 3전 | 별도 포제 표기 없음 | 혈행과 요슬을 돕고 아래로 향하는 배합축 |

## 구성·용량 {#_3}

아래 g 표는 후대의 환산·임상 표기이며, 위 원전의 역사적 단위량과 구별합니다.

| 본초 | 용량 |
|---|---:|
| 도인 | 12 g |
| 당귀 | 9 g |
| 생지황 | 9 g |
| 우슬 | 9 g |
| 홍화 | 9 g |
| 적작약 | 6 g |
| 지각 | 6 g |
| 길경 | 5 g |
| 천궁 | 5 g |
| 감초 | 3 g |
| 시호 | 3 g |

## 수치·법제와 처방 방향 {#processing}

| 확인점 | 기록할 내용 |
|---|---|
| 도인 | 종자 기원·거피 여부와 분쇄·볶음 여부 |
| 홍화 | 약용부위·품질과 도인과의 실제 상대비 |
| 당귀·천궁·적작약 | 약용부위·포제와 사물탕계 양혈활혈축의 비율 |
| 생지황 | 숙지황으로 바꾸지 않고 원방의 청윤·양혈 역할 유지 |
| 지각·시호·길경·우슬 | 이기와 상하 방향성을 단순 보조약으로 생략하지 않음 |
| 제형 | 원방 탕제·가감방·엑스제의 1일 원생약량 구분 |

도인·홍화 등 활혈약이 많으므로 출혈 위험과 항혈소판·항응고제 병용을 확인합니다. 원방의 g 표기는 특정 수록본의 환산값이며 다른 판본의 절대 표준량으로 보지 않습니다.


## 주치·방의 {#_4}

한국전통지식포탈 수록본은 흉중 어혈로 인한 흉통, 오래 낫지 않는 두통, 찌르는 듯한 고정통, 심계·불면·급조 등의 증후를 기록한다.

도인·홍화·당귀·천궁·적작약의 활혈 구조에 시호·지각의 이기가 결합됩니다. 길경과 우슬의 배합은 상하 기혈의 방향을 함께 읽는 단서이며, 개별 본초의 효능을 단순 합산한 설명과 구분합니다.

## 비교 {#_5}
- **통규활혈탕:** 두면·규공의 어혈과 통규에 더 초점
- **독활기생탕:** 풍한습비 + 간신기혈허
- **오적산:** 한습·기혈담식이 복합된 통증

고정성 통증이라는 표현은 전통적 감별의 한 단서입니다. 혈부축어탕의 흉중 기체혈어, 보양환오탕의 기허혈어, 독활기생탕의 풍한습비와 허약을 각각 비교해야 합니다. [보양환오탕(補陽還五湯)](../formulas/buyang-huanwu-tang.md)에서 구성과 병증을 비교할 수 있습니다.

| 처방 | 핵심 차이 |
|---|---|
| **혈부축어탕** | 흉중 기체혈어, 고정통과 상하 기혈 조절 |
| [보양환오탕](buyang-huanwu-tang.md) | 대량 황기를 중심으로 기허혈어·통락불리를 다룸 |
| [소복축어탕](shaofu-zhuyu-tang.md) | 하초 한응어혈과 월경·하복부 고정통 |
| [계지복령환](guizhi-fuling-wan.md) | 하초 징가·어혈을 환제 구조로 다룸 |

## 출전 {#_6}
한국전통지식포탈 혈부축어탕B, P0020404. 원방·후대 가감방·현대 연구 제제의 구성은 별도로 확인합니다.

## 현대 근거를 읽는 범위 {#evidence}

[혈부축어탕 현대 임상근거 카드](../authority/formulas/xuefu-zhuyu-tang-hypertension.md)는 고혈압 병용 연구의 혈압·혈관 관련 지표를 정리합니다. 이 결과를 모든 흉통·두통이나 ‘혈액순환 개선’ 전반으로 확대하지 않습니다.

통증 연구에서는 통증 강도·기능, 심혈관 연구에서는 혈압·혈관지표·사건, 여성질환 연구에서는 월경·출혈을 구분합니다. 연구한 대상, 원방·가감방, 비교치료와 추적기간이 실제 적용 질문과 같은지 먼저 확인합니다.

## 임상 탐색 {#clinical-assessment}

| 진료에서 확인할 항목 |
|---|
| 통증의 위치·지속시간·활동과의 관계 |
| 외상·출혈·월경·수술 이력 |
| 항응고·항혈소판제 등 병용약 |

통증과 함께 수면·움직임·심계의 변화를 기록합니다. 흉통·호흡곤란·실신은 먼저 현대의학적으로 평가하며, 어혈이라는 설명만으로 심장이나 혈관의 문제를 배제하지 않습니다.
