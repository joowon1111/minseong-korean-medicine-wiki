| 항목 | 내용 |
|---|---|
| 치법 | **익기보혈·건비양심** |
| 핵심 병증 | 심비양허·기혈부족·불면·심계 |
| 주요 구성 골격 | 인삼·황기·백출·복령·당귀·용안육·산조인·원지·목향·감초 등 |

## 임상에서 읽는 순서
`주증상 → 위험신호 → 한열·허실 → 기혈진액·담습·어혈 → 치법 → 처방`
