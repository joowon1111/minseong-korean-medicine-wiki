# 귀비탕(歸脾湯)

## 한눈에
**심비를 함께 보하고 기혈을 보충하면서 안신하는 대표 심비양허방**이다.

- **치법:** 익기보혈·건비양심
- **핵심 병증:** 심계·건망·불면·피로·혈허·비허
- **출전:** 『교주부인양방』, 『방약합편』(1884) 상통

## 『방약합편』 수록 구성·용량
| 본초 | 용량 |
|---|---:|
| 목향 | 3.75 g |
| 백복신 | 3.75 g |

| 용안육 | 3.75 g |
| 원지 | 3.75 g |
| 인삼 | 3.75 g |
| 황기 | 3.75 g |
| 당귀 | 1.875 g |
| 감초 | 1.125 g |

**가미:** 생강 5편, 대조 2매.

## 방의
인삼·황기·백출로 비기를 보하고, 당귀·용안육으로 혈을 보하며, 산조인·원지·복신으로 심신을 안정시키고 목향으로 보익약의 체기를 막는다.
