# 팔미지황환(八味地黃丸)

팔미지황환은 《금궤요략》의 신기환 계열로, 육미지황환의 보신 구조에 계지·부자를 더해 **신양의 기화가 약해진 냉감·요슬산연·배뇨와 수분대사 증상**을 살피는 처방입니다. 나이가 많거나 소변 증상이 있다는 이유만으로 일률적으로 연결하지 않습니다.

## 한눈에 보기

| 항목 | 임상에서 읽는 핵심 |
|---|---|
| 치법 | 보신조양·온양화기 |
| 핵심 병기 | 신양부족으로 기화와 온후 기능이 약해짐 |
| 주요 단서 | 허리·무릎의 시림과 무력, 아랫배·발의 냉감, 야간뇨·빈뇨 또는 소변불리, 부종·피로 |
| 먼저 감별 | 요로감염, 요폐, 혈뇨, 전립선·신장질환, 당뇨병, 심부전, 약물성 부종 |
| 치료 후 평가 | 배뇨일지, 야간뇨·절박감, 소변줄기·잔뇨감, 냉감·요슬기능, 부종·체중 |

## 여덟 약미의 구조

| 처방축 | 대표 본초 | 역할 |
|---|---|---|
| 보신정 | [숙지황](../herbs/prepared-rehmannia.md)·[산약](../herbs/dioscorea.md)·[산수유](../herbs/cornus-fructus.md) | 간신의 정혈을 보하고 처방의 바탕을 형성 |
| 사습·조절 | [택사](../herbs/alisma.md)·[복령](../herbs/poria.md)·[목단피](../herbs/moutan.md) | 보약의 점체를 조절하고 수습·울체를 다스림 |
| 온양화기 | [계지](../herbs/cinnamon-bark.md)·[부자](../herbs/aconite.md) | 신양을 덥히고 기화를 도와 냉감·배뇨·수분대사 축을 조절 |

팔미지황환은 육미지황환에 온양약 두 가지를 단순히 더한 처방이 아니라, **보하는 여섯 약미와 소량의 온양약이 균형을 이루는 구조**로 이해합니다.

## 임상에서 떠올리는 단서

- 허리와 무릎이 시리고 약하며 오래 서거나 걸은 뒤 쉽게 지칩니다.
- 발과 아랫배가 차고 야간뇨·빈뇨·잔뇨감 또는 소변불리가 동반됩니다.
- 부종·무거움이 있으면서 맥이 약하고 전반적인 기능 저하가 보입니다.
- 갈증·열감·도한이 중심인지, 뚜렷한 수습정체인지, 기질적 비뇨기질환인지 먼저 구분합니다.

## 비슷한 처방과 구분

| 처방 | 더 중심이 되는 단서 |
|---|---|
| **팔미지황환** | 신양허의 냉감·요슬무력·배뇨 및 기화 저하 |
| [육미지황환](../authority/formulas/liuwei-dihuang-wan.md) | 신음허, 구건·허열·도한 등 음허 단서가 중심 |
| [진무탕](zhenwu-tang.md) | 비신양허와 수기내정, 어지럼·부종·소변불리·전신 무거움이 중심 |
| [오령산](wuling-san.md) | 허약보다 수습과 기화불리, 갈증·소변불리의 조합이 중심 |
| [청심연자음](qingxin-lianzi-yin.md) | 기음부족에 심화·상열과 배뇨불편이 함께 나타남 |

## 현대 임상연구를 읽는 방법

팔미지황환은 일본의 하치미지오간(Hachimijiogan) 연구를 포함해 배뇨증상·노년기 기능 영역에서 탐색돼 왔습니다. 전립선비대 관련 하부요로증상 연구는 탐스로신에 팔미지황환 또는 다른 처방을 더한 소규모 무작위 예비시험이므로, 팔미지황환 단독효과나 모든 배뇨증상으로 넓히지 않습니다. [PMID 35297106](https://pubmed.ncbi.nlm.nih.gov/35297106/) · [DOI 10.1111/iju.14821](https://doi.org/10.1111/iju.14821)

임상에서는 국제전립선증상점수(IPSS), 야간뇨 횟수, 배뇨일지, 잔뇨감·요속과 삶의 질을 함께 기록하고, 처방 반응과 비뇨기과적 평가를 병행합니다.

## 안전성과 진료 연결

- 부자는 반드시 적절히 법제되고 품질이 확인된 의약품용 약재를 전문가가 사용해야 합니다. 임의 증량·자가조제는 피합니다.
- 두근거림·입주위 또는 사지 저림, 오심·어지럼 등 새로운 증상이 나타나면 복용을 중단하고 평가합니다.
- 요폐, 육안적 혈뇨, 발열·옆구리통증, 급격한 부종·호흡곤란은 즉시 의학적 평가가 필요합니다.
- 이뇨제·심혈관계 약물, 신장질환, 임신·수유와 고령자의 다약제 복용을 확인합니다.
