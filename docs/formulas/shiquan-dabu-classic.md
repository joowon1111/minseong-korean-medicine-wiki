# 십전대보탕(十全大補湯)

## 한눈에
**팔물탕의 기혈쌍보 골격에 황기와 육계를 더해 기혈양허를 온보하는 대표 허손방**이다.

- **치법:** 온보기혈
- **핵심 병증:** 기혈양허·허손·피로·식욕저하·병후쇠약

## 구성 골격
| 처방층 | 구성 |
|---|---|
| 보기 | 인삼·백출·복령·감초 |
| 보혈 | 숙지황·당귀·백작약·천궁 |
| 온보 강화 | 황기·육계 |

## 방의
사군자탕 + 사물탕의 팔물탕 구조에 황기로 기를 더 보하고 육계로 양을 덥혀 **기혈과 양기의 회복**을 함께 겨냥한다.

## 비슷한 처방
- **팔물탕:** 기혈쌍보의 기본
- **쌍화탕:** 노권·기혈구상에 조화기혈
- **보중익기탕:** 비위기허와 중기하함
- **귀비탕:** 심비양허와 안신

## 현대 임상근거
암 관련 증상 한의표준임상진료지침은 암성 피로의 주요 증상 개선을 위해 십전대보탕과 일상관리 병행을 고려하도록 권고하며, 2개 무작위대조시험의 종합 근거를 중등도로 평가했다.
