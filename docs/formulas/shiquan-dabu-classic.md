# 십전대보탕 처방 구조·고전 연결

## 한눈에
- **치법:** 온보기혈
- **핵심 병증:** 기혈양허·허손·병후쇠약
- **주요 구성 골격:** 사군자탕 + 사물탕의 팔물탕 골격에 황기·육계

## 처방 구조·감별
팔물탕보다 온보·보기층을 강화한 구조다.

## 출전 읽기
십전대보탕은 **사군자탕의 보기와 사물탕의 보혈이 결합한 팔물탕에 황기·육계를 더한 구조**로 읽습니다. 구성·전통 활용·연구 출처는 [십전대보탕 상세 문서](shi-quan-da-bu-tang.md)에서 함께 확인할 수 있습니다. 출전별 용량과 제법을 기록할 때는 사용한 판본을 고정하고 서로 다른 수록본을 섞지 않습니다.

## 임상 탐색
`증상 → 위험신호 → 한열·허실 → 기혈진액·담습·어혈 → 치법 → 처방군 → 개별 처방`

→ [일반 방제 임상 지도](../herbal-integrated/general-formulary.md)

> 전통 병증과 현대 질환명을 1:1로 동일시하지 않으며, 실제 적용은 환자 상태와 안전성을 함께 평가한다.
