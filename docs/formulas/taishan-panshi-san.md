# 태산반석산(泰山磐石散)

태산반석산은 이름처럼 태산의 반석같이 태원을 안정시킨다는 뜻을 지닌 **보기양혈·건비안태** 처방입니다. 『경악전서』·『방약합편』 계열에서 기혈양허와 충임불고를 함께 보강하는 산전 대표방으로 전합니다.

## 출전·원문·약량 대조 {#source-dose-original}

**대조 출전:** [景岳全書](https://jicheng.tw/tcm/book/景岳全書/index.html)

**원문 발췌**

> 治婦人血氣兩虛，或肥而不實，或瘦而血熱，或脾肝素虛，倦怠少食，屢有墮胎之患。此方平和，兼養脾胃氣血。
>
> 人參　黃耆　當歸　川續斷　黃芩（各一錢）　川芎　白芍藥　熟地（各八分）　白朮（二錢）　炙甘草　砂仁（各五分）　糯米（一撮）
>
> 水一鍾半，煎七分，食遠服。

**해석:** 기혈양허와 평소 비위·간의 허약, 권태·섭취저하가 겹친 안태 맥락을 설명한다. 보기·양혈·속단의 하초 지지에 황금·사인으로 열과 위기를 조절하고 나미를 더한다.

| 본초·제법 항목 | 이 수록본의 기재량 |
|---|---|
| [인삼](../herbs/ginseng.md)·[황기](../herbs/astragalus.md)·[당귀](../herbs/angelica.md)·[속단](../herbs/dipsacus.md)·[황금](../herbs/scutellaria.md) | 각 1전 |
| [천궁](../herbs/chuanxiong.md)·[백작약](../herbs/white-peony.md)·[숙지황](../herbs/prepared-rehmannia.md) | 각 8분 |
| [백출](../herbs/atractylodes.md) | 2전 |
| [자감초](../herbs/licorice.md)·[사인](../herbs/amomum.md) | 각 5분 |
| 나미 | 1촬(한 줌) |

공개 원문 방명은 「泰山盤石散」이며 나미를 한 줌(一撮)으로 기록한다. 위 한국 수록자료의 나미 3.75 g을 원문 고정 중량으로 소급하지 않는다. 당시의 안태 운용은 현재 임신 주수·초음파·출혈 평가와 함께 읽는다.

## 기본 구성

| 처방축 | 약재 |
|---|---|
| 보기건비 | 인삼·황기·백출·감초 |
| 양혈조경 | 당귀·백작약·숙지황·천궁 |
| 보신안태 | 속단 |
| 이기화중 | 사인 |
| 청열안태 | 황금 |
| 위기 조화 | 나미 |

수록 구성은 백출 7.5g, 당귀·속단·인삼·황기·황금·나미 각 3.75g, 백작약·숙지황·천궁 각 3g, 사인·자감초 각 1.875g입니다.

## 임상에서 보는 단서

- 임신 중 피로·식욕저하·안색저하 등 기혈양허가 뚜렷함
- 허리의 시큰함과 하복부가 아래로 처지는 듯한 느낌
- 과거 유산력과 함께 비위허약·회복저하가 나타남
- 소량 출혈이나 태동불안의 고전적 증후에 전신 허약이 겹침
- 단일 보신방보다 비위와 기혈을 폭넓게 보강할 필요가 있음

## 단계와 안전

임신 중 출혈·복통은 먼저 초음파와 산부인과 평가로 원인을 확인합니다. 임신 주수와 혈압, 부종, 간·신장기능, 호르몬·항혈소판제·항응고제 복용을 확인하며, 한약은 상태 변화에 따라 재평가합니다.
