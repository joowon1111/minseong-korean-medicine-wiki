# 삼소음(蔘蘇飮)

삼소음은 **평소 기력이 약하고 소화가 부진한 사람이 외감 뒤 기침·가래·코 증상과 피로를 함께 보일 때** 쓰는 익기해표·이기화담 처방입니다. 자소엽·갈근·전호가 표와 폐기를 열고, 반하·진피·복령이 담을 정리하며, 인삼이 허약한 중기를 받칩니다.

> **핵심 해석:** 단순히 감기가 오래간다는 이유보다 **감기 증상 + 기침·가래 + 식욕과 기력 저하**가 함께 나타나는지를 봅니다.

## 처방 구조

| 구성축 | 주요 본초 | 처방 안에서 보는 역할 |
|---|---|---|
| 익기부정 | [인삼](../herbs/ginseng.md) | 외감을 푸는 동안 기허와 피로, 식욕저하를 받침 |
| 해표선폐 | [자소엽](../herbs/perilla-leaf.md)·[갈근](../herbs/pueraria.md)·전호 | 표를 풀고 폐기의 선강을 회복해 기침을 다룸 |
| 화담강역 | [반하](../herbs/pinellia.md)·[진피](../herbs/citrus-peel.md)·[복령](../herbs/poria.md) | 가래·오심·흉민과 중초의 담습을 정리 |
| 이기이인 | [길경](../herbs/platycodon.md)·[지각](../herbs/citrus-immature.md)·목향 | 위아래의 기기를 소통해 목·가슴과 복부 답답함을 풀어줌 |
| 조화 | [감초](../herbs/licorice.md)·[생강](../herbs/fresh-ginger.md)·대조 | 비위를 보호하고 해표·화담·보기의 방향을 조화 |

해표약만 강하게 쓰지 않고 인삼과 복령으로 정기를 받치면서, 기침과 담을 동시에 다루는 것이 핵심입니다. ‘허약자의 감기’라는 표현도 체질 고정이 아니라 **평소 체력·식사량·발병 뒤 회복력**을 현재 상태에서 평가한다는 뜻입니다.

## 임상에서 먼저 보는 단서

| 관찰 영역 | 삼소음을 생각하게 하는 표현 |
|---|---|
| 평소 상태 | 쉽게 피로하고 식사량이 적으며 감기 뒤 회복이 느림 |
| 호흡기 | 기침·가래·코막힘 또는 콧물이 함께 있음 |
| 전신 | 오한·두통·몸살은 있으나 강한 실열보다 기력저하가 두드러짐 |
| 소화 | 감기와 함께 입맛이 떨어지고 더부룩하거나 메스꺼움 |
| 경과 | 초기부터 허약감이 있거나 급성 증상 뒤 기침과 피로가 남음 |

`호흡곤란·저산소·지속 고열 → 감염 중증도 평가 → 발병 시점과 기침·가래 → 기허·식욕저하 → 삼소음 → 감기 점수와 일상기능 재평가`

## 국내 다기관 임상시험

2023년 국내 무작위·환자-평가자 눈가림·위약대조 다기관시험은 증상 시작 48시간 이내의 성인 감기 환자를 은교산·삼소음·위약군으로 배정했습니다. 총 **128명**이 등록됐고 삼소음군 42명, 위약군 42명이 포함됐습니다.

삼소음군은 6일째 한국어판 WURSS-21 감기 증상 총점에서 위약군보다 더 큰 개선을 보였고, 중대한 이상반응은 보고되지 않았습니다. 코로나19 유행으로 목표했던 375명보다 적게 모집됐으므로, 이 결과는 **삼소음이 감기 증상 부담을 줄일 가능성을 직접 확인한 국내 처방 단위 임상자료**로 읽고 더 큰 후속시험과 연결합니다.

→ [PMID 38033649](https://pubmed.ncbi.nlm.nih.gov/38033649/) · [PMCID PMC10682673](https://pmc.ncbi.nlm.nih.gov/articles/PMC10682673/) · [DOI 10.1016/j.imr.2023.101005](https://doi.org/10.1016/j.imr.2023.101005)

## 복용과 경과 관찰

치료 전후에는 **WURSS와 같은 감기 증상점수·체온·기침 빈도·가래·수면·식사량·활동량·회복일수**를 기록합니다. 급성 감기는 경과가 빠르게 변하므로 2~3일 안에 증상 방향을 다시 보고 처방을 유지·전환합니다.

숨이 차거나 흉통·의식저하·탈수·지속되는 고열·청색증이 있으면 즉시 진료가 우선입니다. 고령자와 만성 폐질환·심혈관질환·면역저하 환자는 초기에 감염 중증도를 평가하며, 감초 포함 처방의 중복과 복용약을 확인합니다.
