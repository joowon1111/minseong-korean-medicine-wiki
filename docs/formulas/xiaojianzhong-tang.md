# 소건중탕(小建中湯)

소건중탕은 계지탕에서 작약을 늘리고 교이를 더해 **중초를 따뜻하게 보하면서 긴장성 복통을 부드럽게 푸는 건중방의 기본 처방**입니다. 허약·피로와 함께 배가 당기듯 아프고 따뜻하게 하거나 누르면 편한 양상을 중심으로 봅니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 핵심 치법 | 온중보허·화리급·완급지통 |
| 중심 병증 | 중초허한·영위불화 |
| 대표 증상축 | 간헐적 복통·복부 긴장·피로·식욕저하·심계 |
| 출전 | 『상한론』·『금궤요략』 |
| 기본 구성 | 계지·작약·생강·대조·감초·교이 |
| 구조 | 계지탕에서 작약을 배량하고 교이를 추가 |

## 처방 구조

- **작약·감초**: 긴장되고 당기는 복부와 근육을 이완하는 축
- **계지·생강**: 중초를 따뜻하게 하고 영위를 조화
- **대조·감초·교이**: 비위를 보하고 급박한 통증을 완화

[한국전통지식포탈 수록본](https://koreantk.com/ktkp2014/prescription/prescription-view.view?preCd=P0014504&tempLang=ko)은 작약이 계지의 두 배이고 교이를 별도로 녹여 넣는 원방 구조를 보여줍니다.

## 임상에서 보는 단서

| 단서 | 해석 |
|---|---|
| 복통 | 간헐적으로 당기거나 쥐어짜지만 따뜻하게 하면 편함 |
| 허약 | 쉽게 지치고 식욕이 적으며 안색이 약함 |
| 촉진 | 강한 실증성 압통보다 부드럽게 누르면 편한 경향 |
| 동반 | 심계·허번·근육 긴장이 함께 나타날 수 있음 |

지속적인 우하복부 통증, 반발통, 고열, 혈변·흑변, 반복 구토는 자가 복용보다 즉시 평가가 우선입니다.

## 가까운 처방과 감별

| 처방 | 갈림점 |
|---|---|
| [계지탕](guizhi-tang.md) | 영위불화와 표허가 중심이며 교이가 없음 |
| [황기건중탕](huangqi-jianzhong-tang.md) | 소건중탕 증상에 기허·자한·회복저하가 더 뚜렷 |
| [쌍화탕](ssanghwa-tang.md) | 건중 계열에 보혈 구조가 더해져 과로 후 전신 근육 피로 비중이 큼 |
| [이중탕](lizhong-tang.md) | 비위허한의 설사·구토·냉감이 중심이고 복부 경련축은 덜함 |

## 안전과 관찰

복통 빈도·강도, 식사량, 배변, 피로와 냉감을 기록합니다. 교이가 포함되어 혈당 관리가 필요한 경우 제형과 용량을 확인합니다. 감초 함유 처방 중복, 부종·혈압·저칼륨 위험을 살핍니다.
