# 소건중탕(小建中湯)

소건중탕은 계지탕에서 작약을 늘리고 교이를 더해 **중초를 따뜻하게 보하면서 긴장성 복통을 부드럽게 푸는 건중방의 기본 처방**입니다. 허약·피로와 함께 배가 당기듯 아프고 따뜻하게 하거나 누르면 편한 양상을 중심으로 봅니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 핵심 치법 | 온중보허·화리급·완급지통 |
| 중심 병증 | 중초허한·영위불화 |
| 대표 증상축 | 간헐적 복통·복부 긴장·피로·식욕저하·심계 |
| 출전 | 『상한론』·『금궤요략』 |
| 기본 구성 | 계지·작약·생강·대조·감초·교이 |
| 구조 | 계지탕에서 작약을 배량하고 교이를 추가 |

허로와 복통, 교이의 배합을 이야기로 읽으려면 [탕약에 엿을 녹여 넣던 까닭](../classical-stories/abdominal-pain-malt-syrup.md)를 참고하세요. 『금궤요략』의 제법·주의와 『상한론』의 치료 뒤 재판단을 함께 읽습니다.

## 출전 원문·약량·본초 해석 {#source-dose-original}

**대조 수록본:** 《상한론(송본)》 「辨太陽病脈證並治中」 100조 처방문과 《금궤요략방론》 「血痹虛勞」 6.13. [상한론 전사문](https://jicheng.tw/tcm/book/傷寒論（宋本）/index.html) · [금궤요략 전사문](https://jicheng.tw/tcm/book/金匱要略方論/index.html)

**원문 발췌**

> 桂枝（三兩，去皮）　甘草（二兩，炙）　大棗（二十枚，擘）　芍藥（六兩）　生薑（三兩，切）　膠飴（一升）

**해석·주치와 배합:** 허로성 복통과 복부의 급박한 당김을 건중·완급으로 다룹니다. 계지탕 골격에서 작약의 비중을 늘리고 교이를 더한 배합입니다.

위 인용은 공개 송본의 기록입니다. 아래 표에서 금궤 전사본과 약량·포제를 대조하며, 황기건중탕은 **금궤의 소건중탕 수록형**을 기준으로 이어 읽습니다.

**약량 읽기:** 표는 위 수록본의 약미·약량을 풀어 쓴 것입니다. 등분은 같은 비중, 량·전·푼은 중량, 승·합은 부피, 매·립은 개수 기록입니다. 역사적 제조 배합을 현대 1일 g 처방으로 일괄 환산하지 않습니다.

| 본초·원문 약명 | 상한론 / 금궤 수록량 | 포제·제법과 배합 |
|---|---|---|
| [계지](../herbs/cinnamon-twig.md) · 桂枝 | 3량 / 3량 | 두 수록형 모두 거피 표기. 영위·온통의 축 |
| [감초](../herbs/licorice.md) · 甘草 | **2량 / 3량** | 두 수록형 모두 炙 표기. 작약과 완급·조화 |
| [대조](../herbs/jujube-fruit.md) · 大棗 | **20매 / 12매** | 상한론은 擘 표기. 중초·영위 조화 |
| [작약](../herbs/white-peony.md) · 芍藥 | 6량 / 6량 | 계지의 두 배인 중량 관계. 리급·긴장의 완급축 |
| [생강](../herbs/fresh-ginger.md) · 生薑 | 3량 / 3량 | 상한론은 切 표기. 위기·영위의 조화 |
| [교이](../herbs/maltose.md) · 膠飴 | 1승 / 1승 | 거재 뒤 녹임. 감온·건중·완급 |

## 처방 구조

- **작약·감초**: 긴장되고 당기는 복부와 근육을 이완하는 축
- **계지·생강**: 중초를 따뜻하게 하고 영위를 조화
- **대조·감초·교이**: 비위를 보하고 급박한 통증을 완화

[한국전통지식포탈 수록본](https://koreantk.com/ktkp2014/prescription/prescription-view.view?preCd=P0014504&tempLang=ko)은 작약이 계지의 두 배이고 교이를 별도로 녹여 넣는 원방 구조를 보여줍니다.

## 수치·법제와 전탕

| 확인점 | 기록할 내용 |
|---|---|
| 계지·작약 | 계지와 육계, 작약의 실제 규격을 구분하고 원방 상대비 확인 |
| 자감초 | 생감초가 아닌 포제품인지 확인하고 총 감초 노출량 기록 |
| 생강·대조 | 건생강·건강과 구분하고 개수 단위의 환산 기준 명시 |
| 교이 | 다른 약재를 달인 뒤 녹여 넣는 용화법, 당질과 실제 함량 확인 |

두 전사본은 다른 약을 달여 찌꺼기를 제거한 뒤 교이를 넣고 약한 불로 녹이는 순서를 기록합니다. 여섯 재료를 처음부터 함께 오래 달이는 방식과 구별하며, 탕제·엑스제의 교이 함량도 확인합니다. 방후문의 **구가불가용(嘔家不可用)**은 구토하는 사람에게 단맛의 배합을 경계한 기록입니다. 이를 소건중탕이 구토를 치료한다는 뜻으로 바꾸거나, 대건중탕을 포함한 모든 건중 처방의 동일한 금기로 확대하지 않습니다.

## 계지탕에서 건중법으로 달라지는 구조 {#original-pattern-course}

소건중탕은 계지탕의 축에서 작약의 비중을 높이고 교이를 결합합니다. 송본 **100조는 복중급통과 치료 순서**, **102조는 심중계·번**을 적습니다. 한 처방이 심계와 복통을 모두 다룬다는 사실보다 허약·긴장과 중초를 어떻게 묶어 설명하는지 살핍니다. [100조](../classics/shanghanlun/clauses/taiyang-middle.md#clause-100) · [102조](../classics/shanghanlun/clauses/taiyang-middle.md#clause-102)

작약의 비중과 교이는 위 구성표와 앞의 처방 구조 설명에서 함께 읽습니다. 교이는 엿 계통의 전통 재료이며, 설탕이나 임의의 단맛 재료를 넣었다고 같은 처방이 되지는 않습니다.

### 상한의 복급과 금궤의 허로

| 주치 문맥 | 원문을 풀어 읽기 | 처방을 고정하지 않게 하는 조건 |
|---|---|---|
| [상한론 100조](../classics/shanghanlun/clauses/taiyang-middle.md#clause-100) | 양맥삽·음맥현과 복중급통에 먼저 소건중탕, 낫지 않으면 소시호탕 | 초기 반응과 남은 맥증을 다시 보는 선후 치료 |
| [상한론 102조](../classics/shanghanlun/clauses/taiyang-middle.md#clause-102) | 발병 2–3일의 심중계·번 | 심계·번을 전부 같은 청열·안신 처방으로 묶지 않음 |
| [금궤 6.13](../classics/jinkui-yaolue/chapters/blood-bi-deficiency.md#clause-06-013) | 허로·리급·복통과 심계·코피·사지 산통·손발 번열·인후건조 등의 조합 | 냉감만을 필수조건으로 고정하거나 번열만으로 실열이라 단정하지 않음 |

상한의 외감 경과와 금궤의 허로가 같은 처방을 공유해도 주치 문장을 합쳐 모든 환자가 갖춰야 할 목록으로 만들지 않습니다. 감초·대조의 수록량도 위 표처럼 출전별로 남깁니다. [보익·회복 처방 계열](../formula-architecture/tonic-family.md)에서 일반 보기·기혈쌍보와 건중의 차이를 비교할 수 있습니다.

### 건중 계열 사이의 갈림점

[황기건중탕](huangqi-jianzhong-tang.md)은 같은 건중축에 황기를 포함하여 허로·부족과 기의 소모를 함께 살핍니다. [대건중탕](dajianzhong-tang.md)은 건강·촉초·인삼·교이의 별도 구성으로 심한 중초 한증을 다룹니다. 작약감초탕은 완급 배합을 공유하지만 계지·생강·대조·교이가 없습니다. 따라서 건중이라는 공통 이름, 또는 복통이라는 증상만으로 세 방을 같은 효능의 크기 순서로 배열하지 않습니다.

## 임상에서 보는 단서

| 단서 | 해석 |
|---|---|
| 복통 | 간헐적으로 당기거나 쥐어짜지만 따뜻하게 하면 편함 |
| 허약 | 쉽게 지치고 식욕이 적으며 안색이 약함 |
| 촉진 | 강한 실증성 압통보다 부드럽게 누르면 편한 경향 |
| 동반 | 심계·허번·근육 긴장이 함께 나타날 수 있음 |

지속적인 우하복부 통증, 반발통, 고열, 혈변·흑변, 반복 구토는 자가 복용보다 즉시 평가가 우선입니다.

## 가까운 처방과 감별

| 처방 | 갈림점 |
|---|---|
| [계지탕](guizhi-tang.md) | 영위불화와 표허가 중심이며 교이가 없음 |
| [황기건중탕](huangqi-jianzhong-tang.md) | 소건중탕 증상에 기허·자한·회복저하가 더 뚜렷 |
| [쌍화탕](ssanghwa-tang.md) | 건중 계열에 보혈 구조가 더해져 과로 후 전신 근육 피로 비중이 큼 |
| [이중탕](lizhong-tang.md) | 비위허한의 설사·구토·냉감이 중심이고 복부 경련축은 덜함 |

## 안전과 관찰

복통 빈도·강도, 식사량, 배변, 피로와 냉감을 기록합니다. 교이가 포함되어 혈당 관리가 필요한 경우 제형과 용량을 확인합니다. 감초 함유 처방 중복, 부종·혈압·저칼륨 위험을 살핍니다.
