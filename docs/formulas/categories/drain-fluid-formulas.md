# 이수제

이수제는 체내의 **수습 정체와 수액대사의 불균형**을 조절하는 처방군이다.

## 대표 처방

## 구성 이해
오령산은 택사·저령·복령·백출·계지의 배합으로 **이수 + 건비 + 기화**의 구조를 이룬다.
