# 화담·이기 처방 임상 지식망

화담·이기 처방은 **담음 자체, 비위허를 바탕으로 한 담음, 담열·심계, 위장관의 한열착잡, 기체**를 구분해서 봅니다.

## 대표 처방 비교

- 이진탕 — 담음·기체의 기본 구조
- 육군자탕 — 비위기허 + 담음
- 향사육군자탕 — 비위기허 + 기체·창만
- 온담탕 — 담과 심계·수면·긴장 연결
- 반하사심탕 — 심하비·위장관 불화와 한열착잡
- 평위산 — 습체·복만
