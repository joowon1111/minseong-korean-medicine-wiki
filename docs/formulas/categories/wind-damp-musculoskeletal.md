# 근골격 통증 처방 임상 지식망

근골격 처방은 통증 부위나 질환명 하나로 고르지 않고 **발병 시기·외상 여부·어혈·한습·풍한습·근경련·기혈허·간신부족**을 구분합니다.

## 대표 처방

| 임상에서 나눌 양상 | 처방·배합을 읽는 순서 |
|---|---|
| 목덜미·견배 강직 | [갈근탕](../gegen-tang.md)의 무한·표실 → [계지가갈근탕](../guizhi-jia-gegen-tang.md)의 한출·오풍 → [회수산](../huishou-san.md)의 풍한·기체와 회전 제한 |
| 외감과 몸살성 전신통 | [구미강활탕](../jiuwei-qianghuo-tang.md)의 풍한습·속열, [오적산](../wujisan.md)의 한습·기혈담식 비교 |
| 외상 뒤 멍·고정통 | [당귀수산](../danggui-susan.md)의 활혈거어와 손상 평가 |
| 오래된 다부위 통증 | [소경활혈탕](../shujing-huoxue-tang.md)의 혈분·풍습, [독활기생탕](../duhuo-jisheng-tang.md)의 거풍습·보익 비교 |
| 냉감이 두드러지는 관절통 | [계지가출부탕](../guizhi-jia-shu-fu-tang.md)의 계지탕·출·부자 구조 |
| 다관절통·부종·쇠약 | [계지작약지모탕](../guizhi-shaoyao-zhimu-tang.md)의 온통·청열·완급 배합 |
| 관절 부종·신중감 | [월비가출탕](../yuebi-jia-shu-tang.md)의 마황·석고·출과 [방기황기탕](../fangji-huangqi-tang.md)의 기허·수습 비교 |
| 갑자기 당기는 근경련 | [작약감초탕](../shaoyao-gancao-tang.md)의 완급지통과 전해질·약물·신경 원인 평가 |
| 저림·감각 둔함과 허약 | [황기계지오물탕](../huangqi-guizhi-wuwu-tang.md)의 혈비·영위기혈축 |

자세한 [배합 차이와 평가 질문](../../herbal-integrated/formula-for-pain.md#pain-composition-differences)은 처방 찾기에서, [계지작약지모탕 원전](../../classics/jinkui-yaolue/chapters/wind-joint.md#clause-05-008)과 [월비가출탕 원전](../../classics/jinkui-yaolue/chapters/water-qi.md#clause-14-025)은 고전 문서에서 확인합니다.

처방별 구성과 감별을 확인한 뒤 [통증·근골격 한약 임상근거](../../authority/formulas/musculoskeletal-herbal-evidence.md#clinical-studies)에서 질환·제제별 사람 대상 연구로 이어갈 수 있습니다.

## 핵심 본초

강활·독활은 풍습, 당귀·천궁·작약은 혈분·완급, 두충·우슬은 요슬·근골의 배합을 비교합니다. 출은 수습·중초, 석고·지모는 열·진액, 부자는 온통의 역할을 구별합니다. 이를 약재 하나로 통증 부위를 지정하는 규칙으로 사용하지 않습니다.

[통증 본초 배합표](../../herbal-integrated/formula-for-pain.md#_5)에서 각 본초 문서로 이어갈 수 있습니다.
