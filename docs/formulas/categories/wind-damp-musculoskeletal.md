# 근골격 통증 처방 임상 지식망

근골격 처방은 통증 부위나 질환명 하나로 고르지 않고 **발병 시기·외상 여부·어혈·한습·풍한습·근경련·기혈허·간신부족**을 구분합니다.

## 대표 처방

- [회수산](../huishou-san.md) — 풍한·기체와 급성 목결림·견배부 긴장
- [당귀수산](../danggui-susan.md) — 염좌·타박 뒤 멍·부종·어혈성 통증
- [구미강활탕](../jiuwei-qianghuo-tang.md) — 풍한습·외감과 몸살성 전신통
- [오적산](../wujisan.md) — 한습·기체·혈체가 복합된 통증
- [소경활혈탕](../shujing-huoxue-tang.md) — 혈행·경락과 오래된 통증
- [작약감초탕](../shaoyao-gancao-tang.md) — 근경련·긴장과 연결
- [독활기생탕](../duhuo-jisheng-tang.md) — 만성 풍한습비에 간신·기혈부족이 함께 나타나는 경우

처방별 구성과 감별을 확인한 뒤 [통증·근골격 한약 임상근거](../../authority/formulas/musculoskeletal-herbal-evidence.md#clinical-studies)에서 질환·제제별 사람 대상 연구로 이어갈 수 있습니다.
