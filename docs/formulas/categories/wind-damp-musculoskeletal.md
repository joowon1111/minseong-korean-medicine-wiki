# 거풍습·근골 처방 임상 지식망

근골격 처방은 통증 부위만으로 고르지 않고 **한습·어혈·기혈허·간신부족·외상 후 상태**를 구분합니다.

## 대표 처방

- 독활기생탕 — 풍한습비 + 간신·기혈부족
- 오적산 — 한습·기체·혈체가 복합된 통증
- 소경활혈탕 — 혈행·경락과 만성 통증
- 당귀수산 — 타박·어혈성 통증
- 작약감초탕 — 근경련·긴장과 연결

## 핵심 본초

독활 · 강활 · 두충 · 우슬 · 당귀 · 단삼 · 의이인
