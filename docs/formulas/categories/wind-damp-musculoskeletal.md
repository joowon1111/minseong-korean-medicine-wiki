# 근골격 통증 처방 임상 지식망

근골격 처방은 통증 부위나 질환명 하나로 고르지 않고 **발병 시기·외상 여부·어혈·한습·풍한습·근경련·기혈허·간신부족**을 구분합니다.

## 대표 처방

- 회수산·당귀수산 — 염좌·타박 뒤 어혈성 통증
- 구미강활탕 — 풍한습·외감과 몸살성 전신통
- 오적산 — 한습·기체·혈체가 복합된 통증
- 소경활혈탕 — 혈행·경락과 오래된 통증
- 작약감초탕 — 근경련·긴장과 연결
- 독활기생탕 — 만성 풍한습비에 간신·기혈부족이 함께 나타나는 경우

## 핵심 본초

독활 · 강활 · 두충 · 우슬 · 당귀 · 단삼 · 의이인
