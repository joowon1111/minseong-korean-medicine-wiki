# 월국환(越鞠丸)

월국환은 주단계의 육울 이론을 대표하는 **행기해울 기본방**입니다. 기·혈·습·화·식의 다섯 축을 다섯 약재로 움직여 담울까지 함께 풀어내는 간결한 구조입니다.

## 기본 구성

『의학입문』·『의학정전』 수록본은 향부자·천궁·창출·치자·신곡을 같은 비율로 사용합니다.

- **향부자:** 기울을 풀어 전체 처방의 흐름을 엶
- **천궁:** 혈중의 기를 움직여 혈울·통증을 조절
- **창출:** 조습건비하여 습울·담 생성 기반을 다룸
- **치자:** 울체되어 생긴 화열을 청설
- **신곡:** 식울을 소화하고 중초를 조화

담을 직접 삭이는 약재가 없어도 기·습·화·식의 정체를 풀면 담울이 함께 움직인다는 구조입니다.

## 수치·법제와 환제

| 구성 | 확인할 점 |
|---|---|
| 향부자 | 원료·식초제 등 실제 포제와 분쇄도 |
| 천궁 | 절편·정유성분 보존과 보관 상태 |
| 창출 | 백출과 혼용하지 않고 기원·볶음 여부 기록 |
| 치자 | 생치자·초치자 등 포제품 구분 |
| 신곡 | 발효 원료·제조 규격과 초제품 여부 확인 |
| 환제·탕제 | 원방 환제와 현대 탕제·과립제의 노출량·복용법 구분 |

다섯 약재를 같은 비율로 쓴다는 기록이 모든 수록본과 현대 제품에 그대로 적용되는 것은 아닙니다. 울체의 중심축과 소화력, 실제 제형을 함께 기록합니다.

## 임상 단서

- 스트레스 후 흉복부가 막히고 트림·식욕저하가 생김
- 소화불량·탄산·구역과 몸의 무거움이 번갈아 나타남
- 답답함이 오래되며 열감·번조·통증이 겹침
- 한 가지 허증보다 여러 종류의 울체가 상호 전환함

## 육울탕과 차이

| 처방 | 구조 | 더 어울리는 상황 |
|---|---|---|
| **월국환** | 향부자·천궁·창출·치자·신곡 5미 | 육울의 기본 골격, 비교적 간결한 행기해울 |
| [육울탕](yukwul-tang.md) | 월국환 축에 진피·복령·패모·지각·소엽·연교 등을 확장 | 담·흉민·복부팽만과 복합 울체가 더 구체적 |
| [정전가미이진탕](jeongjeon-gami-ijin-tang.md) | 이진탕+소식·건비·이기 | 음식 적체와 담습성 소화불량 비중이 큼 |

## 가감의 의미

육울 가운데 무엇이 주된지에 따라 소식, 화담, 활혈, 청열 약재가 달라집니다. 월국환을 모든 스트레스 증상에 동일하게 쓰기보다 혀·맥과 식사·대변·수면·월경, 흉복부 촉진을 함께 봅니다.

## 치료 목표와 현대 연구 독해

주증상을 하나 정해 흉복부 답답함, 식후포만, 트림·구역, 통증, 수면과 식욕을 같은 조건으로 기록합니다. ‘스트레스가 줄었다’는 인상만으로 기울·화울·식울이 모두 개선됐다고 판단하지 않습니다.

현대 연구에서는 월국환 원방과 가감월국환, 우울·기능성소화불량·대사질환 등 대상 진단을 분리합니다. 정서척도·소화기 증상·검사수치가 각각 무엇을 뜻하는지 확인하고, 육울 전체를 단일 신경전달물질이나 염증지표에 대응시키지 않습니다.

## 안전

흉통·호흡곤란, 지속적인 체중감소, 연하곤란, 흑변·혈변과 반복 구토는 원인 검사가 우선입니다. 임신 가능성, 출혈 위험과 항응고제, 간질환을 확인합니다.

치자·창출·신곡 등에서 나타날 수 있는 위장 반응과 천궁 관련 출혈 위험을 살피고, 같은 효능군의 처방을 중복하지 않습니다.
