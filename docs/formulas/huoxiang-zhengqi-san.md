# 곽향정기산(藿香正氣散)

곽향정기산은 **외부의 풍한과 내부의 습체가 겹쳐 오한·두통과 함께 메스꺼움·구토·설사·복부팽만이 나타나는 경우**를 다루는 대표 화습방입니다. 곽향·자소엽·백지가 표를 열고 습탁을 향기롭게 흩으며, 반하·진피·후박이 위기와 기체를 내리고, 복령·백출이 비위의 수습대사를 받칩니다.

> **핵심 해석:** 설사 하나만 보지 않고 **갑작스러운 위장 증상 + 몸이 무겁고 답답함 + 오한·두통 같은 표증 + 습체**가 함께 있는지 확인합니다.

!!! info "일반 방제와 사상처방을 구분합니다"
    이 문서는 『태평혜민화제국방』 계통의 일반 방제학 곽향정기산입니다. [소음인방 곽향정기산](../sasang-formula-cards/gwakhyangjeonggi-san.md)은 구성과 병리 체계가 다르므로 서로 바꾸어 읽지 않습니다.

## 처방 구조

| 구성축 | 주요 본초 | 처방 안에서 보는 역할 |
|---|---|---|
| 방향화습·해표 | 곽향·[자소엽](../herbs/perilla-leaf.md)·백지 | 표의 풍한과 중초의 습탁을 함께 흩음 |
| 이기제만 | [후박](../herbs/magnolia-bark.md)·대복피·[진피](../herbs/citrus-peel.md) | 흉복부의 답답함과 팽만, 기체를 풀어줌 |
| 화담강역 | [반하](../herbs/pinellia.md) | 메스꺼움·구토와 담습을 다룸 |
| 건비삼습 | [복령](../herbs/poria.md)·[백출](../herbs/atractylodes.md) | 비위를 돕고 수습을 배출 |
| 선폐조화 | [길경](../herbs/platycodon.md)·[감초](../herbs/licorice.md)·생강·대조 | 상중초의 기기를 연결하고 전체 배합을 조화 |

평위산의 조습운비·행기 구조에 **해표와 강역, 건비의 층**이 더해진 모습으로 볼 수 있습니다. 따라서 오래된 만성 설사보다 음식·환경 변화 뒤 갑자기 표리 증상이 함께 나타나는 상황에서 처방 구조가 더 잘 맞습니다.

## 임상에서 먼저 보는 단서

| 관찰 영역 | 곽향정기산을 생각하게 하는 표현 |
|---|---|
| 발병 | 음식·환경 변화 뒤 갑자기 메스껍고 배가 불편함 |
| 표증 | 오한·두통·몸살·무거움이 위장 증상과 동반 |
| 위장 | 복부팽만·식욕저하·구토·묽은 변 |
| 습체 | 입이 끈적하고 몸과 머리가 무거우며 답답함 |
| 감별 | 심한 갈증·고열·혈변·국소적 심한 복통 여부를 먼저 확인 |

`탈수·혈변·고열·지속되는 국소 복통 → 원인평가와 수분치료 → 표증·습체·기체 확인 → 곽향정기산 → 구토·대변·수분섭취 재평가`

## 현대 임상근거

2019년 체계적 문헌고찰·메타분석은 급성 위장염 환자 **4,153명이 포함된 44개 연구**에서 곽향정기환을 통상치료에 더한 결과를 종합했습니다. 병용군에서 보고된 전체 임상반응과 발열 호전시간이 대조군보다 개선됐고, 이상반응 발생은 통상치료 단독군과 뚜렷한 차이가 없었습니다.

이 결과는 대부분 **곽향정기환 병용치료**를 평가했으므로 탕제·액제의 효과와 동일시하지 않습니다. 연구 간 치료법과 평가방법이 다양해, 실제 활용에서는 원인 진단과 수분·전해질 보충을 기본으로 두고 적합한 병증의 구토·설사·복부불편 변화를 관찰하는 근거로 읽습니다.

→ [PMID 31602833](https://pubmed.ncbi.nlm.nih.gov/31602833/) · [DOI 10.19540/j.cnki.cjcmm.20190513.502](https://doi.org/10.19540/j.cnki.cjcmm.20190513.502)

## 복용과 경과 관찰

치료 전후에는 **구토 횟수·대변 횟수와 성상·복통 위치·체온·소변량·수분섭취·어지럼·체중 변화**를 기록합니다. 소아·고령자·임신부·면역저하자는 탈수가 빠르게 진행할 수 있어 진료 문턱을 낮춥니다.

물을 마시지 못하거나 소변량이 줄고, 혈변·검은변·지속되는 고열·우하복부나 우상복부의 심한 통증·의식저하가 있으면 즉시 평가합니다. 감초가 포함된 다른 처방과의 중복, 복용 중인 이뇨제·혈압약, 간·신장 상태도 함께 확인합니다.
