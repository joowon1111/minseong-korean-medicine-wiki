# 곽향정기산(藿香正氣散)

## 핵심 카드
| 항목 | 내용 |
|---|---|
| 치법 | **해표화습·이기화중** |
| 핵심 병증 | 외감풍한에 내상습체가 겹친 오심·설사·완복불화 |
| 구성 골격 | 곽향·자소엽·백지·반하·복령·백출·후박·진피·길경·감초 등 |

## 처방을 읽는 법
평위산보다 외감 해표의 층이 추가되고, 삼소음보다 습체·비위불화가 더 중심이다.

## 임상 탐색
`증상 → 한열·허실 → 기혈진액·담습·어혈 → 치법 → 처방군 → 개별 처방`

## 구성·용량·출전
이 페이지는 기존 일반방제 지식망의 **핵심 임상 위치와 배합 골격을 통합 정리**한 페이지다. 이미 출전별 정확한 용량이 확인된 처방은 해당 수록본을 유지하고, 동명 처방은 서로 섞지 않는다.
