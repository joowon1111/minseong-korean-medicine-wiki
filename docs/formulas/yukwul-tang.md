# 육울탕(六鬱湯)

육울탕은 **기울·혈울·습울·화울·담울·식울**이 서로 얽힌 복합 울체를 푸는 처방입니다. ‘우울한 기분’ 하나만 뜻하는 처방이 아니라 스트레스와 식사 뒤 흉복부 답답함, 소화불량, 담·열·통증이 복합된 상태를 육울 구조로 해석합니다.

## 출전·원문·약량 대조 {#source-dose-original}

**대조 출전:** [醫學入門](https://jicheng.tw/tcm/book/醫學入門/index.html)

**원문 발췌**

> 六郁湯　能解諸郁。陳皮、半夏、川芎、蒼朮各一錢，赤茯苓、山梔仁各七分，香附二錢，砂仁、甘草各五分，生薑三片，水煎服，隨證加減。

**해석:** 여러 울체를 푸는 처방으로 진피·반하·천궁·창출, 적복령·치자, 향부자·사인·감초를 생강과 달이는 9미 수록형이다. 기체·담습·열울·혈분과 중초의 움직임을 함께 읽는다.

|---|---|
| [진피](../herbs/citrus-peel.md)·[반하](../herbs/pinellia.md)·[천궁](../herbs/chuanxiong.md)·[창출](../herbs/atractylodes-lancea.md) | 각 1전 |
| [적복령](../herbs/poria.md)·[치자](../herbs/gardenia.md) | 각 7푼 |
| [향부자](../herbs/cyperus.md) | 2전 |
| [사인](../herbs/amomum.md)·[감초](../herbs/licorice.md) | 각 5푼 |
| [생강](../herbs/fresh-ginger.md) | 3편 |

이 9미는 위 방약합편·한국전통지식포탈의 연교·패모·지각·소엽·신곡을 포함한 12미 수록형과 다르다. 《단계심법》의 육울 이론과 월국환을 처방 계통으로 연결하되 서로 다른 구성표를 한 원방으로 합치지 않는다.

## 방약합편 수록 구성

한국전통지식포탈의 『단계심법』 계통·『방약합편』 수록기록은 향부자·창출·신곡·치자·연교·진피·천궁·적복령·패모·지각·소엽 각 3.75g, 감초 1.875g과 생강 3편으로 구성됩니다.

| 울체 | 중심 약재와 방향 |
|---|---|
| 기울 | 향부자·소엽·지각·진피로 흉복부 기체를 소통 |
| 혈울 | 천궁으로 기혈의 정체와 통증을 조절 |
| 습울 | 창출·적복령으로 중초의 무거움과 습을 다룸 |
| 화울 | 치자·연교로 울체되어 생긴 열을 식힘 |
| 담울 | 진피·패모·복령으로 담과 흉민을 조절 |
| 식울 | 신곡으로 음식 적체를 소화 |

## 임상에서 보는 단서

- 스트레스와 식사에 따라 명치·가슴·옆구리 답답함이 변함
- 트림·복부팽만·메스꺼움과 가래·목 막힘 느낌이 동반됨
- 오래 막힌 느낌 뒤 열감·번조가 생기지만 순수 실열만은 아님
- 통증·식체·담습이 한 축으로 설명되지 않고 함께 이동함
- 검사에서 큰 구조적 이상이 없더라도 실제 기능저하가 반복됨

## 육울별 가감 원리

『방약합편』은 기울에 목향·빈랑·소엽, 습울에 백출·강활·방기, 열울에 황련·연교, 담울에 남성·과루인·해분, 혈울에 목단피·홍화, 식울에 산사·신곡·맥아를 제시합니다. 현대 임상에서는 기계적으로 모두 더하지 않고, 환자의 주된 울체와 안전성을 정해 가감합니다.

## 불안·긴장·불면과 육울의 감별 {#autonomic-patterns}

긴장한 뒤 가슴과 명치가 막힌 듯하고 트림·팽만·메스꺼움이 생기며, 열감과 수면 불편이 겹칠 때 육울의 관점에서 진찰할 수 있습니다. 불안이 시작된 시점, 심계항진의 지속시간과 맥박, 식사·수면·배변의 변화를 함께 확인합니다.

| 두드러지는 양상 | 육울 중 확인할 부분 | 비교할 처방 |
|---|---|---|
| 한숨·흉협부 팽팽함·트림 | 기울 | [시호소간산](chaihu-shugan-san.md) |
| 답답함에 메스꺼움·가래·머리 무거움 | 담울·습울 | [온담탕](wendan-tang.md)·[분심기음](fenxin-qiyin.md) |
| 가슴이 달아오르고 초조하며 잠들기 어려움 | 화울과 동반 기울 | [가미소요산](jiawei-xiaoyao-san.md) |
| 과식 뒤 팽만·트림과 수면 불편 | 식울과 담습 | [정전가미이진탕](jeongjeon-gami-ijin-tang.md) |
| 통증이 일정한 부위에 지속 | 혈울과 실제 통증 원인 | 통증 위치·기존 검사·복용약을 확인해 처방 |

《방약합편》형은 신곡·연교·패모 등을, 앞의 《의학입문》형은 반하·사인 등을 포함합니다. 한의원 안내나 연구에서 구성 약재를 설명할 때는 어느 수록형인지 명시합니다. [자율신경·불안·긴장 진료의 처방 비교](../autonomic/index.md#anxiety-pattern-formulas)에서 다른 안신·이기 처방과 함께 확인할 수 있습니다.

치료 경과는 불안의 강도와 일상 영향, 잠드는 데 걸리는 시간, 두근거림·식후팽만·배변의 변화를 기록합니다. 기능성소화불량·과민성장증후군·불면증 등 기존 진단과 심장·갑상선·약물 관련 원인도 함께 평가합니다.

## 안전

체중감소, 연하곤란, 흑변·혈변, 지속 구토, 발열, 새롭게 생긴 흉통은 먼저 검사합니다. 연교·치자·패모·지각 등 구성과 병용약, 임신·수유, 간기능을 확인합니다.
