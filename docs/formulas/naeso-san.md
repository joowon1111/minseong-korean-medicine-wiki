# 내소산(內消散)

내소산은 생것이나 찬 음식 뒤 속이 그득하고 배가 부르며 아픈 식체를 다룬 《방약합편》 처방입니다. 산사·신곡으로 음식 정체를, 반하·복령으로 담습을 함께 살피는 배합입니다.

## 출전과 배합 {#formula-composition}

진피·지실·향부자는 기체와 팽만, 사인·건강은 온중과 방향화습, 삼릉·아출은 정체가 뚜렷한 경우의 소적·행기 배합으로 풀이합니다.

[《방약합편》 내소산](https://health.kr/researchInfo/herbalMedicine3_detail.asp?idx=78)

## 비슷한 처방과 차이 {#formula-comparison}

[보화환](baohe-wan.md)도 산사·신곡·반하·복령을 쓰며, 내소산은 건강과 삼릉·아출을 함께 둡니다. [대화중음](daehwa-jung-eum.md)은 산사·맥아와 택사를 두어 소식과 수습에 초점을 둡니다.

## 건강보험 기준과 제형 {#insurance-formula}

별표 2의 출전은 《방약합편》이며, 기준 약재는 **진피·반하·복령·지실·산사·신곡·사인·향부자·삼릉·아출·건강**입니다. 2026년 11월 9일 시행 고시의 별표 1에는 **산제·연조엑스**가 등재돼 있습니다. 진료일의 급여목록에서 제품명·제형·제품코드를 확인합니다. [보건복지부 고시 별표 1·2](https://www.law.go.kr/admRulLsInfoP.do?admRulSeq=2100000287748) · [건강보험 한약제제 목록](../herbal-integrated/insurance-herbal.md#insurance-formula-list)

## 진료에서 확인할 사항 {#clinical-context}

음식 섭취와 불편감의 시간차, 통증 위치, 구토·배변 양상을 기록하면 [복통의 원인 평가](../conditions/abdominal-pain.md)에 도움이 됩니다. 통증이 심하거나 한곳으로 모이면 급성 복통 평가가 우선입니다.
