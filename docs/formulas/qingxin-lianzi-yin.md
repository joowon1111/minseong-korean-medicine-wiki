# 청심연자음(淸心蓮子飮)

## 한눈에
**심화를 맑히면서 기음과 비신의 허를 함께 돌보는 처방군**이다.

- **출전:** 『태평혜민화제국방』, 『방약합편』(1884) 중통
- **주치 기록:** 구건번갈, 소변적삽, 심화상염 등

## 『방약합편』 수록 구성·용량
| 본초 | 용량 |
|---|---:|
| 연자 | 7.5 g |
| 인삼 | 3.75 g |
| 적복령 | 3.75 g |
| 황기 | 3.75 g |
| 감초 | 2.625 g |
| 맥문동 | 2.625 g |
| 지골피 | 2.625 g |
| 차전자 | 2.625 g |
| 황금 | 2.625 g |

## 구조
연자·인삼·황기로 기를 보하고, 맥문동으로 음을 보하며, 황금·지골피가 열을 식히고, 차전자·복령이 수습과 소변을 조절한다.
