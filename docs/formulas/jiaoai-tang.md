# 교애탕(膠艾湯)

교애탕은 궁귀교애탕으로도 불리며, 사물탕의 양혈화혈 구조에 **아교·애엽·감초**를 더해 충임이 허손된 출혈을 다루는 고전 처방입니다. 『금궤요략』의 부인과 처방으로 널리 알려져 있습니다.

## 『금궤요략』 계열 구성

- 당귀·천궁·작약·지황
- 아교·애엽·감초

수록본에 따라 지황의 포제와 용량, 황기 포함 여부가 달라질 수 있으므로 실제 기록에는 출전을 구분합니다.

## 처방 구조

- **당귀·작약·지황:** 혈을 보하고 충임을 자양
- **천궁:** 혈행을 조절해 보혈약의 정체를 막음
- **아교:** 양혈지혈
- **애엽:** 온경지혈하여 허한성 출혈을 조절
- **감초:** 완급하고 전체 구조를 조화

## 지황 포제·아교 용화와 전탕

| 확인점 | 기록할 내용 |
|---|---|
| 지황 | 수록본의 건지황·생지황·숙지황 표기를 임의로 통일하지 않음 |
| 아교 | 다른 약재를 달인 뒤 녹여 넣는 용화법과 실제 원료 확인 |
| 애엽 | 약용부위·가공과 탄화품 사용 여부 구분 |
| 감초 | 생감초·자감초 표기와 총 감초 노출량 확인 |
| 동명 이방 | 황기 포함 여부와 각 약미의 상대비·출전 명시 |

출혈을 다루는 처방이므로 포제품 차이를 ‘효능 강화’로 단순화하지 않고 출혈량·혈색소·임신 상태와 병용약을 함께 기록합니다. 탕제·엑스제 등 제형과 1일 원생약량도 구분합니다.

## 포조·누하를 읽는 혈분과 지혈의 구조 {#original-pattern-course}

금궤 「부인임신」의 교애탕 조문은 누하, 임신이 중도에 끝난 뒤 계속되는 출혈, 임신 중 출혈과 복통을 함께 적습니다. 포조라는 문헌 병증은 이 문맥에서 읽고, 현대의 유산·자궁외임신·태반 문제를 대신 분류하는 말로 사용하지 않습니다. [20.4조](../classics/jinkui-yaolue/chapters/pregnancy.md#clause-20-004)

### 사물 계열과 공유하는 약, 교애탕의 고유한 축

| 배합축 | 해당 약재 | 구별할 내용 |
|---|---|---|
| 혈분을 기르고 조절 | 당귀·작약·천궁·지황 | 사물탕 계열과 약미를 공유하지만 지황의 수치와 비율을 확인 |
| 양혈·지혈 | 아교 | 다른 약을 달인 뒤 녹여 넣는 제법을 포함 |
| 온경·지혈 | 애엽 | 허한과 출혈을 함께 읽는 축 |
| 완급·조화 | 감초 | 복통과 전체 배합을 받침 |

일곱 약이 모두 ‘피를 멈추는 약’은 아닙니다. 혈의 부족과 충임의 손상, 한증과 출혈을 함께 살피면서 기르고 따뜻하게 하고 조절하는 방향을 결합합니다. 사물탕에 아교·애엽·감초를 연결해 비교할 수 있지만, 원방의 건지황과 후대 숙지황, 각 약의 수록량을 그대로 같다고 가정하지 않습니다.

### 교애·귀비·생화의 갈림점

귀비탕은 인삼·황기·백출 등 보기건비와 안신을 결합해 기불섭혈·심비양허의 설명으로 이어집니다. 생화탕은 산후의 어혈·오로·복통과 온경활혈을 읽는 방입니다. 교애탕은 아교·애엽과 혈분 배합을 중심으로 충임허손·허한성 출혈을 비교합니다. 출혈이라는 같은 증상 안에서도 **어혈을 움직일지, 기를 보아 섭혈할지, 혈과 충임을 받칠지**가 달라집니다. [귀비탕](guibi-tang.md) · [생화탕](saenghwa-tang.md)

### 제법과 경과의 연결

아교는 용화의 절차와 원료를 확인하고, 지황·애엽은 전사본의 포제 표기를 남깁니다. 황기를 포함한 동명방을 만났다면 금궤의 일곱 약과 분리하여 출전과 구성을 밝힙니다. 약명 하나가 같아도 약미·가감·제법이 달라지면 같은 치료로 묶을 수 없습니다.

현대의 출혈 경과는 양·기간·혈괴·복통·어지럼과 혈색소, 임신 여부를 함께 평가합니다. 금궤의 임신 문목에 수록됐다는 사실은 현재 임산부의 자가 복용 근거가 아니며, 원문은 처방의 역사적 맥락과 배합을 이해하는 자료로 읽습니다.

## 임상에서 보는 단서

- 출혈이 오래되어 어지럼·피로·안색저하가 동반됨
- 하복부 은통과 냉감, 따뜻하게 하면 편안한 경향
- 출혈과 혈허가 함께 있어 지혈만으로는 회복이 부족함
- 붕루·월경과다 또는 임신 중 출혈의 고전적 충임허손 맥락

## 임신 중 출혈은 먼저 진단합니다

교애탕의 고전 주치에 태루·포조가 포함되지만, 임신 중 출혈을 곧바로 처방 적응증으로 단정하지 않습니다. 자궁외임신, 유산 진행, 태반 문제 등 원인을 산부인과에서 먼저 확인하고, 한약은 임신 주수·초음파·출혈량·복용약을 확인한 뒤 개별 판단합니다.

## 경과와 근거를 읽는 기준

비임신기 출혈에서는 패드 사용량·혈괴·출혈일수, 어지럼·피로와 혈색소·철 저장상태를 함께 추적합니다. 임신 중에는 출혈량 감소만으로 안전성을 판단하지 않고 초음파와 산과 경과를 우선합니다. 교애탕·궁귀교애탕 연구는 지황 포제, 황기 포함 여부, 가감방과 병용치료가 서로 다를 수 있으므로 **처방명보다 실제 구성과 대상군**을 먼저 대조합니다.
