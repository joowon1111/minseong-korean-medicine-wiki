# 회수산(回首散)

회수산은 **기체와 풍사를 푸는 오약순기산에 강활·독활·모과를 더해 목을 돌리기 어렵고 어깨·등까지 당기는 급성 경항통을 다루는 처방**입니다. 이름 그대로 고개를 돌리는 동작이 제한되는 ‘낙침’의 임상상을 선명하게 보여줍니다.

> **핵심 해석:** 목이 아프다는 병명보다 **잠을 잘못 자거나 찬바람을 맞은 뒤 갑자기 한쪽 목이 굳고, 움직일 때 통증이 심하며, 어깨·등의 근육 긴장과 몸살감이 함께 있는지** 봅니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 핵심 치법 | 순기소풍·산한서근·통락지통 |

| 대표 증상축 | 급성 목결림·회전 제한·견배통·근육 긴장·냉감 |
| 처방 골격 | 오약순기산 + 강활·독활·모과 |
| 출전 | 『동의보감』, 『방약합편』 |
| 임상 위치 | 급성 경항통·낙침의 대표적인 풍한·기체 처방 |

## 출전 원문·약량·본초 해석 {#source-dose-original}

**대조 수록본:** 《만병회춘(萬病回春)》 「頭痛」. [해당 문헌 확인](https://jicheng.tw/tcm/book/萬病回春/index.html) · [《국방》 오약순기산 기본방 원문](https://jicheng.tw/tcm/book/太平惠民和劑局方/index.html) · [오약순기산 수록본 비교](wuyao-shunqi-san.md)

**원문 발췌**

> 回首散　治頸攻強急、筋痛，或挫頸、轉項不得者。烏藥順氣散加羌活、獨活、木瓜。（方見中風。）

**해석·주치와 배합:** 목이 굳고 아파 돌리기 어려운 경항통에 오약순기산을 바탕으로 강활·독활·모과를 더합니다. 원문이 가미량을 적지 않았으므로 후대 수록량과 구별합니다.

《만병회춘》은 오약순기산에 세 약을 더한다고만 적습니다. 아래 기본방 10미 약량은 《국방》의 오약순기산에서 가져왔고, 강활·독활·모과는 회수산 원문에 가미량이 미기재입니다.

**약량 읽기:** 표는 위 수록본의 약미·약량을 풀어 쓴 것입니다. 등분은 같은 비중, 량·전·분은 중량, 승·합은 부피, 매·립은 개수 기록입니다. 역사적 제조 배합을 현대 1일 g 처방으로 일괄 환산하지 않습니다.

## 임상에서 먼저 보는 단서

| 관찰 영역 | 회수산을 생각하게 하는 표현 |
|---|---|
| 시작 | 자고 일어난 뒤 또는 찬바람·과로 뒤 갑자기 목이 굳음 |
| 움직임 | 고개를 한쪽으로 돌리거나 젖힐 때 통증과 제한이 큼 |
| 분포 | 목에서 승모근·견갑 사이·등 위쪽으로 당기거나 뻣뻣함 |
| 성질 | 냉감·몸살감이 있고 따뜻하게 하면 편해지는 경향 |
| 전신 | 심한 열감·붉은 부종보다 풍한과 근육 긴장이 중심 |

`사고·고에너지 외상·사지마비·보행장애 → 즉시 평가 → 급성 목결림 확인 → 풍한·기체·근육 긴장 → 회수산 → 통증·회전범위·수면 재평가`

## 현대 임상에서 기록할 것

회수산은 독립 처방 단위의 큰 사람 대상 임상시험보다 고전과 실제 임상 경험을 통해 이어져 온 처방입니다. 따라서 처방 전후 **통증점수만이 아니라 목의 좌우 회전범위, 운전·업무·수면의 불편, 진통제 사용량과 회복일수**를 함께 기록하면 임상적 의미를 더 정확히 볼 수 있습니다.

## 복용과 안전

마황 함유 처방이므로 심계·불면·혈압 변화, 갑상선기능항진, 심혈관질환과 교감신경 자극 약물 복용을 확인합니다. 감초 중복과 임신·수유도 개별 평가합니다.

넘어진 뒤 심한 정중선 압통, 팔·다리 힘 빠짐이나 감각저하, 보행장애, 배뇨·배변 변화, 고열과 경부강직이 있으면 단순 낙침으로 보지 않고 영상·신경학적 평가를 우선합니다.
