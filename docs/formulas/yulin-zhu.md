# 육린주(毓麟珠)

육린주는 『경악전서』의 임신준비 대표처방으로, **기혈을 보하면서 신정과 충임을 함께 돕는 구조**입니다. 월경주기만 조절하기보다 오랜 허손·요슬산연·피로와 기혈부족이 임신준비 과정에 겹친 경우를 이해하기 좋습니다.

## 출전·원문·약량 대조 {#source-dose-original}

**대조 출전:** [景岳全書](https://jicheng.tw/tcm/book/景岳全書/index.html)

**원문 발췌**

> 治婦人氣血俱虛，經脈不調，或斷續，或帶濁，或腹痛，或腰痠，或飲食不甘，瘦弱不孕。
>
> 人參　白朮（土炒）　茯苓　芍藥（酒炒，各二兩）　川芎　炙甘草（各一兩）　當歸　熟地（蒸搗，各四兩）　菟絲子（制，四兩）　杜仲（酒炒）　鹿角霜　川椒（各二兩）
>
> 上為末，煉蜜丸，彈子大。每空心嚼服一、二丸，用酒或白湯送下，或為小丸吞服亦可。

**해석:** 기혈이 모두 허하고 월경부조·대하·복통·요산·섭취저하가 겹친 임신준비 맥락이다. 12미를 가루 내 꿀로 환을 만들고 공복에 1~2환을 씹거나 작은 환으로 복용하는 역사적 제법이다.

| 본초·제법 항목 | 이 수록본의 기재량 |
|---|---|
| [인삼](../herbs/ginseng.md)·[토초백출](../herbs/atractylodes.md)·[복령](../herbs/poria.md)·[주초작약](../herbs/white-peony.md) | 각 2량 |
| [천궁](../herbs/chuanxiong.md)·[자감초](../herbs/licorice.md) | 각 1량 |
| [당귀](../herbs/angelica.md)·[숙지황](../herbs/prepared-rehmannia.md)·[법제토사자](../herbs/cuscuta-seed.md) | 각 4량 |
| [주초두충](../herbs/eucommia.md)·녹각상·천초 | 각 2량 |
| 밀환 매복량 | 탄자대 1~2환 |

량은 밀환을 만드는 일괄 배합량이며 1회 탕제량이 아니다. 원문의 임신을 단정하는 서술은 구성·제법 인용에서 생략했다. 토사자·숙지황·당귀의 각 4량과 다른 약미의 비율을 후대 탕제와 구별한다.

## 기본 구성

| 처방축 | 약재 | 의미 |
|---|---|---|
| 보신익정 | 숙지황·토사자·녹각상·두충 | 신정과 하초를 보강 |
| 보기건비 | 인삼·백출·복령·감초 | 기혈 생성의 기반을 도움 |
| 양혈조경 | 당귀·백작약·천궁 | 혈을 보하고 월경의 흐름을 조절 |
| 온하초 | 천초 | 허한 경향을 살피며 하초를 덥힘 |

『경악전서』·『방약합편』 계열은 숙지황·토사자·녹각상을 중심으로 인삼·백출·복령, 당귀·작약·천궁, 두충·천초·감초를 배합합니다.

## 임상에서 보는 단서

- 월경량이 적거나 주기가 불규칙하면서 피로·안색저하가 동반됨
- 허리·무릎이 시큰하고 하복부가 허냉함
- 오래된 질환·과로·체중저하 뒤 임신을 준비함
- 소화력이 약하고 회복이 더디며 맥이 허약한 경향
- 실열·담습·어혈 하나보다 기혈과 신정의 부족이 중심

## 임신 성립 뒤에는 다시 평가합니다

육린주는 임신 전 보익·조경 맥락의 처방입니다. 임신반응 양성 뒤에는 임신 주수와 증상, 초음파·호르몬 보조요법, 출혈 여부를 확인하고 원방을 그대로 지속할지 다시 판단합니다.
