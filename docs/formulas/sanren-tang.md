# 삼인탕(三仁湯)

삼인탕은 《온병조변》 상초편 43조에서 **몸의 무거움·흉민·식욕 저하·백태·불갈**이 함께 있는 습온을 읽는 처방입니다. 행인·백두구·의이인의 세 인(仁)을 중심으로 기기를 소통시키고 습을 다루는 구조를 가집니다.

## 원문에서 읽는 조건 {#source-pattern}

[43조 발췌·독해](../classics/wenbing-tiaobian.md#upper-043)는 두통·오한만 보지 않고 몸의 무거움, 혀의 태, 갈증, 흉부와 식욕을 함께 살피게 합니다. 습이 남은 상황과 음액이 부족한 상황을 구별하는 것이 중요합니다.

온병의 처방을 모두 차갑게 열을 내리는 약으로 이해하면 백두구·후박·반하가 함께 들어가는 이유를 놓칩니다. 삼인탕은 청열과 더불어 **선폐·행기·화습·담삼**을 조합합니다.

## 여덟 구성 본초 {#composition}

| 원전 구성 | 배합에서 읽는 역할 |
|---|---|
| [행인](../herbs/apricot-kernel.md) | 폐기의 소통과 하강 |
| [백두구](../herbs/white-cardamom.md) | 방향화습·행기의 중심 |
| [의이인](../herbs/coix.md) | 담삼리습의 중심 |
| [후박](../herbs/magnolia-bark.md)·[반하](../herbs/pinellia.md) | 중초의 창만·구역과 기기 소통 |
| 활석·백통초·죽엽 | 청리·삼습을 보완 |

원전은 행인·백두구·의이인만 쓰는 세 약재 처방이 아닙니다. 반하의 포제와 각 본초의 기원을 확인하고, 통초·목통 등 이름이 비슷한 약재를 임의로 대체하지 않습니다.

## 화습·조습·자음을 구별하기 {#treatment-choice}

| 함께 읽을 처방 | 구별할 질문 |
|---|---|
| [평위산](pingwei-san.md) | 중초 습체·창만의 조습운비와 무엇이 다른가 |
| [감로소독단](ganlu-xiaodu-dan.md) | 황금·인진·연교 등의 청열·해독·화탁 비중은 어떠한가 |
| [청영탕](qingying-tang.md) | 습의 정체가 중심인가, 영분의 열·음액 손상을 읽을 상황인가 |

비교표는 증상 하나로 처방을 고르는 규칙이 아닙니다. 열·태·섭취·대변·소변과 기존 치료 뒤 반응을 종합합니다.

## 기존 임상 자료로 연결 {#clinical-context}

[소화불량](../conditions/dyspepsia.md)·[식욕저하](../conditions/poor-appetite-adult.md)에서 현재의 증상을 살피고 [담음·식적 감별](../diagnostics/differentials/phlegm-vs-food-stagnation.md)로 이어갑니다. 소화가 안 된다는 사실만으로 습온이라 정하지 않습니다.

피부의 진물·습윤을 읽을 때는 [습진의 청열조습](../conditions/eczema.md#pattern-treatment)과 연결하되, 삼인탕의 선창기기·화습을 피부 치료의 조습과 완전히 같은 방법으로 보지는 않습니다. 현대 연구는 [소화기 한약 근거](../authority/formulas/digestive-herbal-evidence.md)에서 실제 시험한 처방과 대상군을 확인합니다.
