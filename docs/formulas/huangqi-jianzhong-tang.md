# 황기건중탕(黃耆建中湯)

황기건중탕은 **소건중탕에 황기를 더해 중초허한과 긴장성 복통뿐 아니라 기허·자한·회복저하를 강화해 다루는 처방**입니다. 허약한 사람이 배가 당기듯 아프고 쉽게 지치며 땀이 나고 회복이 더딘 양상을 함께 봅니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 핵심 치법 | 온중보허·익기고표·완급지통 |
| 중심 병증 | 중초허한에 기허·표허가 겹친 상태 |
| 대표 증상축 | 허로성 복통·피로·식욕저하·자한·도한·회복지연 |
| 출전 | 『금궤요략』 |
| 기본 구성 | 소건중탕 + 황기 |
| 임상 위치 | 건중탕 계열에서 보기·고표축을 강화 |

## 구조와 임상 단서

소건중탕의 계지·작약·감초·생강·대조·교이 구조에 황기를 더합니다. 황기는 비위를 받치고 쉽게 나는 땀과 기력저하를 함께 살피는 역할을 합니다.

- 복부가 당기거나 은은하게 아프고 따뜻하게 하면 편함
- 피로·식욕저하와 함께 자한 또는 병후 회복지연이 뚜렷함
- 활동량·체중·식사량이 잘 회복되지 않음

『금궤요략』 혈비허로편은 허로의 여러 증후를 제시한 뒤 황기건중탕을 “여러 허손이 부족할 때” 더하는 처방으로 놓습니다. 이를 단순한 피로 처방으로 넓히기보다 [원문 6.14와 앞뒤 허로 조문](../classics/jinkui-yaolue/chapters/blood-bi-deficiency.md#clause-06-014)을 함께 읽어, **건중이 필요한 복부 단서와 황기가 필요한 기허·표허 단서가 겹치는지** 확인합니다.

## 소건중탕에서 달라지는 수치·법제

황기건중탕은 소건중탕의 제형·전탕법을 유지하면서 황기를 더한 계통으로 읽습니다. 실제 기록에서는 `소건중탕 + 황기`라는 이름만 쓰지 말고 다음을 확인합니다.

- [황기](../herbs/astragalus.md)의 생품·밀자품과 실제 가감량
- 계지와 육계, 작약 규격, 자감초 여부
- 교이를 별도로 녹여 넣었는지와 완제품의 당질·함량
- 원방 탕제인지 현대 엑스제·과립제인지

황기만 더했다고 모든 허약성 복통에 더 강한 처방이 되는 것은 아닙니다. 자한·회복저하라는 보기고표의 필요가 실제로 겹치는지 감별합니다.

| 처방 | 갈림점 |

| [보중익기탕](buzhong-yiqi-tang.md) | 중기하함·처짐·오래 서 있을 때 악화되는 기허 |

## 경과를 판단하는 방법

처방 전후에는 막연한 “원기”보다 실제 변화를 같은 기준으로 비교합니다.

| 평가축 | 기록 예 |
|---|---|
| 복부 | 통증 빈도·지속시간, 식사·냉자극과의 관계, 온압 시 변화 |
| 회복 | 활동 후 원상태로 돌아오는 시간, 주간 활동량 |
| 소화·영양 | 식사량·체중·배변, 빈혈이나 영양결핍 검사 필요성 |
| 표허 단서 | 자한·야간 땀의 빈도와 옷을 갈아입을 정도인지 |

황기나 건중방을 사용한 연구가 있더라도 실제 처방 구성, 대상 질환, 비교치료와 결과지표가 다르면 황기건중탕 원방의 효과로 옮겨 설명하지 않습니다. 복통·피로·식사량 같은 환자중심 결과와 안전성 보고를 우선 확인합니다.

## 안전과 관찰

복통, 식욕, 배변, 땀, 활동 후 회복시간을 함께 기록합니다. 교이의 당질과 감초 중복을 확인하고, 당뇨·부종·고혈압·저칼륨혈증 위험이 있으면 의료진과 조율합니다. 급성 복증과 출혈·감염 신호는 우선 검사합니다.
