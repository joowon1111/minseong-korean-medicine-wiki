# 황기건중탕(黃耆建中湯)

황기건중탕은 **소건중탕에 황기를 더해 중초허한과 긴장성 복통뿐 아니라 기허·자한·회복저하를 강화해 다루는 처방**입니다. 허약한 사람이 배가 당기듯 아프고 쉽게 지치며 땀이 나고 회복이 더딘 양상을 함께 봅니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 핵심 치법 | 온중보허·익기고표·완급지통 |
| 중심 병증 | 중초허한에 기허·표허가 겹친 상태 |
| 대표 증상축 | 허로성 복통·피로·식욕저하·자한·도한·회복지연 |
| 출전 | 『금궤요략』 |
| 기본 구성 | 소건중탕 + 황기 |
| 임상 위치 | 건중탕 계열에서 보기·고표축을 강화 |

## 구조와 임상 단서

소건중탕의 계지·작약·감초·생강·대조·교이 구조에 황기를 더합니다. 황기는 비위를 받치고 쉽게 나는 땀과 기력저하를 함께 살피는 역할을 합니다.

- 복부가 당기거나 은은하게 아프고 따뜻하게 하면 편함
- 피로·식욕저하와 함께 자한 또는 병후 회복지연이 뚜렷함
- 활동량·체중·식사량이 잘 회복되지 않음

## 안전과 관찰

복통, 식욕, 배변, 땀, 활동 후 회복시간을 함께 기록합니다. 교이의 당질과 감초 중복을 확인하고, 당뇨·부종·고혈압·저칼륨혈증 위험이 있으면 의료진과 조율합니다. 급성 복증과 출혈·감염 신호는 우선 검사합니다.
