# 자음건비탕(滋陰健脾湯)

자음건비탕은 기혈과 음을 보하면서 비위를 돕고 담음을 조절해 **어지럼·두중·심계·불안정한 수면과 소화저하가 함께 나타나는 상태**를 살피는 처방입니다. 팔진탕의 기혈보익, 이진탕의 화담, 원지·복신의 안신, 맥문동의 양음이 한 구조 안에 연결됩니다.

## 《방약합편》 구성 구조

| 구성축 | 주요 본초 | 임상적 의미 |
|---|---|---|
| 건비익기 | 백출·진피·반하·복령·인삼·감초 | 비위기허와 담음, 식욕저하·오심을 조절 |
| 양혈자음 | 당귀·백작약·건지황·맥문동·천궁 | 혈허·음손상과 어지럼·건조·피로를 보완 |
| 안신정지 | 복신·원지 | 심계·건망·불안·수면 변화를 함께 살핌 |
| 조화중초 | 생강·대조 | 위기를 화하고 처방 전체를 조화 |

《방약합편》에는 백출 1돈 5푼, 진피·반하·백복령 각 1돈, 당귀·백작약·건지황 각 7푼, 인삼·복신·맥문동·원지 각 5푼, 천궁·감초 각 3푼과 생강 3편·대조 2매가 수록됩니다. 수록본과 제형에 따라 약미·포제 표기가 달라질 수 있습니다.

## 임상에서 먼저 보는 단서

| 영역 | 확인할 내용 |
|---|---|
| 어지럼 | 공중에 뜬 듯하거나 머리가 무겁고 피로·공복·수면부족 뒤 심해짐 |
| 담음 | 메스꺼움·가래·명치 답답함·식후 포만감이 동반 |
| 기혈허 | 창백함, 무력감, 집중력 저하, 활동 뒤 회복 지연 |
| 심신 | 두근거림·건망·걱정·잠들기 어려움 또는 자주 깸 |
| 진액 | 입마름·건조감과 함께 보익이 필요하지만 비위가 약함 |

## 가까운 처방과 감별

| 처방 | 중심 단서 |
|---|---|
| **자음건비탕** | 기혈·음 부족 + 비위허약·담음 + 심신 증상 |
| [반하백출천마탕](banxia-baizhu-tianma-tang.md) | 풍담·비허의 회전성 현훈, 두중·오심이 중심 |
| [육군자탕](liujunzi-tang.md) | 비위기허·담음과 조기포만이 중심이며 양혈·안신축은 간결 |
| [귀비탕](guibi-tang.md) | 심비양허의 심계·건망·불면과 혈허·출혈 경향이 중심 |
| [팔물탕](bazhen-tang.md) | 기혈양허의 전신 회복이 중심이며 화담·안신축은 적음 |

## 문헌·연구와 경과관찰

방제구성 연구에서는 자음건비탕을 팔진탕·이진탕·정지환·육군자탕·생맥산의 치료축이 어우러진 처방으로 해석합니다. 임상에서는 어지럼 강도와 빈도, DHI 같은 기능척도, 오심·식사량, 피로, 심계와 수면을 함께 기록하면 처방의 여러 축을 한 번에 평가할 수 있습니다.

갑작스러운 보행장애·한쪽 마비·말 어눌함·복시·새로운 심한 두통이 동반된 어지럼은 즉시 뇌신경계 평가와 함께 관리합니다. 반하는 법제 규격을 사용하고, 감초의 중복과 복용약·혈압·부종을 확인합니다.
