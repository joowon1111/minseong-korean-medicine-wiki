# 보중익기탕 처방 구조·고전 연결 {#_1}

## 한눈에 {#_2}
**비위의 기를 보하고 청양을 들어 올리는 대표 익기승양방**이다.

- **치법:** 보중익기·승양거함
- **핵심 병증:** 비위기허, 중기하함, 권태·무력·자한
- **출전:** 『비위론』, 『방약합편』(1884) 상통

## 《비위론》 원문 구성과 읽는 순서 {#piwei-composition}

「飲食勞倦所傷始為熱中論」 뒤의 「補中益氣湯」을 함께 읽습니다. 원문은 황기·감초·인삼·당귀신·귤피·승마·시호·백출의 **8미**를 제시하고, 식욕·복통·기체 등 동반 양상에 따라 가감을 설명합니다. [《비위론》 보중·승양 해설](../classics/piwei-lun.md#buzhong-source)

| 원문 표기 | 기재량 | 구성 해설 |
|---|---|---|
| 黃耆 | 五分, 병이 심하고 노역열이 있는 경우 一錢 | [황기](../herbs/astragalus.md), 보기의 중심 |
| 甘草 | 五分, 炙 | [감초](../herbs/licorice.md), 보중·배합 조화 |
| 人參 | 三分 | [인삼](../herbs/ginseng.md), 원기·비위 보조 |
| 當歸身 | 三分 | [당귀](../herbs/angelica.md), 혈맥을 조화 |
| 橘皮 | 二分 또는 三分 | [진피](../herbs/citrus-peel.md), 기기 조절 |
| 升麻 | 二分 또는 三分 | 승양 방향 |
| 柴胡 | 二分 또는 三分 | [시호](../herbs/bupleurum.md), 승양 방향 |
| 白朮 | 三分 | [백출](../herbs/atractylodes.md), 비위 보조 |

출처는 [《脾胃論》 「補中益氣湯」 공개 원문](https://jicheng.tw/tcm/book/脾胃論/index.html)입니다. 문헌 비교를 위해 원 단위를 보존했습니다. 아래 후대 《방약합편》 수록량과는 배합 비중이 다르며, 고전의 分·錢을 현대 복용량으로 곧바로 적용하지 않습니다. 현재 치료에서의 제제·용량은 별도로 확인합니다.

## 방의 {#_4}
황기·인삼·백출·감초로 중기를 보하고, 승마·시호로 청양을 승거하며, 당귀가 혈을 보조하고 진피가 기기를 조절한다.
