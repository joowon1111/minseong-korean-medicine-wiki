# 보중익기탕(補中益氣湯)

## 한눈에
**비위의 기를 보하고 청양을 들어 올리는 대표 익기승양방**이다.

- **치법:** 보중익기·승양거함
- **핵심 병증:** 비위기허, 중기하함, 권태·무력·자한
- **출전:** 『비위론』, 『방약합편』(1884) 상통

## 『방약합편』 수록 구성·용량

## 방의
황기·인삼·백출·감초로 중기를 보하고, 승마·시호로 청양을 승거하며, 당귀가 혈을 보조하고 진피가 기기를 조절한다.

## 비슷한 처방
- **사군자탕:** 비기허의 기본 골격
- **귀비탕:** 심비양허·혈허·안신의 비중이 더 큼
- **십전대보탕:** 기혈양허·허손을 폭넓게 온보
