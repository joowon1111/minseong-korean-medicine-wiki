# 옥병풍산(玉屏風散)

옥병풍산은 황기·백출·방풍 세 약미로 **폐위의 기를 돕고 표를 단단히 하는 익기고표**의 구조를 만듭니다. 감염을 직접 치료하는 처방으로 단순화하지 않고 반복되는 호흡기 증상, 자한, 체력과 회복기간을 함께 봅니다.

## 한눈에 보기

| 항목 | 임상에서 읽는 핵심 |
|---|---|
| 치법 | 익기고표·보기어풍 |
| 핵심 병기 | 폐비기허와 위외불고로 외부 자극에 대한 방어·회복이 약함 |
| 주요 단서 | 쉽게 감기에 걸림, 찬 공기·바람에 민감, 자한, 피로·식욕저하, 감기 뒤 회복 지연 |
| 먼저 확인 | 현재 감염·발열, 천식 조절상태, 비염·부비동염, 면역저하 원인과 흡입제·알레르기약 |
| 치료 후 평가 | 감기 빈도·지속일수, 야간기침·쌕쌕거림, 비염 증상, 활동량·회복기간 |

## 세 약미의 역할

| 본초 | 처방 안의 역할 |
|---|---|
| [황기](../herbs/astragalus.md) | 폐비의 기를 보하고 표를 굳혀 처방의 중심을 이룸 |
| [백출](../herbs/atractylodes.md) | 비위를 돕고 수습을 조절해 황기의 보기 작용을 받침 |
| [방풍](../herbs/saposhnikovia.md) | 외풍을 흩고, 보하는 약만으로 표가 막히지 않도록 움직임을 더함 |

세 약미가 적어 보이지만 ‘보기–건비–거풍’의 역할이 분명합니다. 황기와 백출로 바탕을 보하면서 방풍이 표의 소통을 돕는 구조입니다.

## 임상에서 떠올리는 단서

- 계절이 바뀌거나 찬바람을 맞으면 비염·기침·감기 증상이 쉽게 반복됩니다.
- 조금만 움직여도 땀이 나고 피로하며 회복이 늦습니다.
- 평소 식욕과 소화가 약하고 감기 뒤 기침·무기력이 오래 남습니다.
- 급성 고열·인후통·누런 가래가 중심인 시기와 평소 재발관리 시기를 구분합니다.

## 비슷한 처방과 구분

| 처방 | 더 중심이 되는 단서 |
|---|---|
| **옥병풍산** | 표허·자한·반복 호흡기 증상과 회복저하 |
| [보중익기탕](buzhong-yiqi-tang.md) | 중기하함·전신 피로·식욕저하와 처짐이 중심 |
| [소청룡탕](xiaoqinglong-tang.md) | 수양성 콧물·재채기·묽은 가래와 외한·수음이 중심 |
| [삼소음](renshen-suyin.md) | 기허한 사람이 현재 외감풍한·기침·담을 함께 보임 |
| [맥문동탕](maidong-tang.md) | 감염 후 마른기침·인후건조·기침 발작이 중심 |

## 사람 대상 임상근거

2026년 성인 기관지천식 체계적 문헌고찰·메타분석은 20개 무작위시험·1,896명을 종합했습니다. 옥병풍산을 기존 천식 치료에 더한 병용군에서 천식 조절, FEV1·FEV1/FVC·PEF 등 폐기능과 삶의 질을 평가했습니다. **흡입치료를 대체한 단독근거가 아니라 병용근거**로 읽습니다. [PMID 42147341](https://pubmed.ncbi.nlm.nih.gov/42147341/) · [DOI 10.3389/fphar.2026.1757474](https://doi.org/10.3389/fphar.2026.1757474)

## 안전성과 진료 연결

- 숨이 차서 문장을 잇기 어렵거나 청색증·흉통, 평소보다 잦은 속효성 흡입제 사용은 즉시 평가가 필요합니다.
- 처방을 시작해도 기존 천식 흡입제와 알레르기 치료를 임의로 중단하지 않습니다.
- 면역억제제·항응고제, 자가면역질환, 임신·수유와 간·신장질환을 확인합니다.
- 반복감염이 잦으면 빈혈·영양상태·당뇨병·수면·면역저하 원인을 함께 살핍니다.
