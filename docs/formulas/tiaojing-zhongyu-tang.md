# 조경종옥탕(調經種玉湯)

## 핵심 카드
| 항목 | 내용 |
|---|---|
| 치법 | **양혈조경·이기** |
| 핵심 병증 | 월경부조·충임실조의 전통적 조경 맥락 |
| 구성 골격 | 당귀·천궁·백작약·숙지황·향부자·진피·복령 등 계열 |

## 처방을 읽는 법
사물탕 계열의 양혈에 향부자 등 이기조경의 층을 더한 구조로 읽는다.

## 임상 탐색
`증상 → 한열·허실 → 기혈진액·담습·어혈 → 치법 → 처방군 → 개별 처방`

## 구성·용량·출전
이 페이지는 기존 일반방제 지식망의 **핵심 임상 위치와 배합 골격을 통합 정리**한 페이지다. 이미 출전별 정확한 용량이 확인된 처방은 해당 수록본을 유지하고, 동명 처방은 서로 섞지 않는다.
