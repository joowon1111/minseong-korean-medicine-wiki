# 가미소요산(加味逍遙散)

## 한눈에
**소요산 계열의 소간양혈건비 방향에 열을 식히는 요소가 더해진 처방군**으로 이해한다.

## 출전별 구성이 중요하다
한국전통지식포탈에는 여러 가미소요산이 별도로 수록되어 있다. 예를 들어 『동의보감』·『방약합편』 하통의 **가미소요산B**는 다음과 같다.

| 본초 | 용량 |
|---|---:|
| 목단피 | 5.625 g |
| 백출 | 5.625 g |
| 도인 | 3.75 g |
| 적작약 | 3.75 g |
| 패모 | 3.75 g |
| 산치자 | 3 g |
| 황금 | 3 g |
| 길경 | 2.625 g |
| 청피 | 1.875 g |
| 감초(구) | 1.125 g |

이 수록본은 담혈을 주치로 연결한다.

## 핵심
**'가미소요산'이라는 이름만으로 구성과 적응 병증을 단정하지 않고 반드시 출전을 확인**해야 한다.

## 비교
- 소요산: 간울·혈허·비허의 기본 축
- 가미소요산: 출전별 가미 구조에 따라 울열·혈분·담혈 등 초점이 달라짐
