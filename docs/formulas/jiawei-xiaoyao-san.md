# 가미소요산(加味逍遙散)

## 핵심 카드
| 항목 | 내용 |
|---|---|
| 치법 | **소간해울·양혈건비·청열** |
| 핵심 병증 | 간울혈허에 울열이 더해진 병증군 |
| 구성 골격 | 소요산 계열에 목단피·치자 등 청열약을 더하는 계통이 대표적이나 출전별 차이가 큼 |

## 처방을 읽는 법
처방명보다 출전과 실제 구성표를 먼저 확인한다.

## 임상 탐색
`증상 → 한열·허실 → 기혈진액·담습·어혈 → 치법 → 처방군 → 개별 처방`

## 구성·용량·출전
이 페이지는 기존 일반방제 지식망의 **핵심 임상 위치와 배합 골격을 통합 정리**한 페이지다. 이미 출전별 정확한 용량이 확인된 처방은 해당 수록본을 유지하고, 동명 처방은 서로 섞지 않는다.
