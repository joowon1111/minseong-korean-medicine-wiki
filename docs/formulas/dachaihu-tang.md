# 대시호탕(大柴胡湯)

## 한눈에
| 항목 | 내용 |
|---|---|
| 치법 | **화해소양·내사열결** |
| 핵심 병증 | 소양양명합병·흉협고만·변비 |
| 주요 구성 골격 | 시호·황금·백작약·반하·생강·지실·대황·대조 |

대시호탕은 소양의 흉협·구고·왕래한열 같은 축에 심하급·구토와 양명리실이 겹친 **소양·양명 동병의 화해겸하방**으로 읽습니다. 처방명보다 화해가 필요한 반표반리와 공하가 필요한 리실이 실제로 함께 있는지가 핵심입니다.

## 구성과 원문 이본

| 배합축 | 구성 | 구조에서의 의미 |
|---|---|---|
| 화해소양 | [시호](../herbs/bupleurum.md)·[황금](../herbs/scutellaria.md) | 반표반리의 열과 흉협 병증을 조절 |
| 화위지구 | 법제 반하·생강·대조 | 구역·구토와 위기불화를 다룸 |
| 완급조영 | 백작약 | 심하급·복부 긴장을 조절 |
| 파기공하 | 지실·대황 | 리실·열결을 풀되 허실을 가려 사용 |

《상한론》 103조의 처방문은 ‘칠미’로 적은 본문과 **대황 2량을 더한다는 이본 주석**이 함께 전합니다. 현대의 대시호탕은 대황을 포함하는 구성이 일반적이지만, 연구·제제마다 실제 구성과 함량을 반드시 확인합니다. [103조 원문과 제법](../classics/shanghanlun/clauses/taiyang-middle.md#clause-103)

## 감별 포인트
소시호탕보다 양명부실·열결이 더해져 공하의 층이 있습니다.

| 비교 처방 | 갈림점 |
|---|---|
| [소시호탕](xiaochaihu-tang.md) | 소양불화가 중심이고 대황·지실의 공하축이 없음 |
| **대시호탕** | 소양증에 심하급·구토·복만·리실이 겹침 |
| [대승기탕](dachengqi-tang.md) | 양명부실·비만조실이 중심이며 소양 화해축이 없음 |
| 사역산 | 간비기울·양울과 사지궐의 구조, 공하방이 아님 |

## 출전·구성 원칙
《상한론》의 103·136·165조와 《금궤요략》 복만편의 심하만통 문맥을 구분해 읽습니다. [금궤요략 원문과 처방](../classics/jinkui-yaolue/chapters/abdominal-cold-food.md)도 연결하되 서로 다른 조문을 하나의 현대 질환 적응증으로 합치지 않습니다.

대황의 생품·포제품과 후하 여부, 지실의 기원·약용부위, 반하의 법제, 시호·황금의 실제 함량을 기록합니다. 원방 탕제, 일본 한방 엑스제, 중국 중성약과 가감방은 조성·용량이 다를 수 있습니다.

## 임상 탐색
`주증상 → 위험신호 → 표리·한열·허실 → 기혈진액·담습·어혈 → 치법 → 처방`

→ [일반 방제 임상 지도](../herbal-integrated/general-formulary.md)

> 전통 병증과 현대 질환명을 단순히 동일시하지 않는다.

흉협·상복부 압통, 구역·구토, 대변과 복부팽만을 함께 보되 급성 복통·반발통·지속 구토·황달·고열은 담낭염·췌장염·장폐색 등 원인 평가가 우선입니다. 임신 가능성, 탈수, 고령·쇠약과 항응고제를 확인하고 대황 관련 설사·복통을 관찰합니다.

현대 연구에서는 담낭·대사·정신신경 등 연구 분야가 달라도 동일 처방으로 묶지 않습니다. 대상 진단, 변증, 대황 포함 여부, 병용치료와 증상·검사·이상반응 지표를 분리해 읽습니다.

## 체중관리에서의 비교와 경과 {#immune-weight-care}

흉협고만·상복부 답답함과 변비 등 소양양명의 병증을 확인한 뒤 체중관리의 전체 계획과 연결합니다. 스트레스로 과식한다는 이유 하나만으로 처방을 고정하지 않습니다.

[방풍통성산](fangfeng-tongsheng-san.md)은 표리구실·실열의 맥락, [방기황기탕](fangji-huangqi-tang.md)은 기허·수습의 맥락을 비교합니다. 대황이 포함되므로 대변·복통·설사·수분 상태를 살피고, 급성 복통이나 임신 가능성은 별도로 확인합니다.
