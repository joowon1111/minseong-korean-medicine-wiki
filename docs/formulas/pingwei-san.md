# 평위산(平胃散)

평위산은 비위의 습체를 말리고 기를 소통시켜 **더부룩함·몸의 무거움·식욕저하가 함께 나타나는 중초 습체**를 다루는 대표 화습화위방입니다. 소화불량이라는 병명 전체보다 창만과 습체가 얼마나 중심인지 확인합니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 치법 | 화습운비·행기화위 |
| 중심 병증 | 습곤비위·기체중초 |
| 대표 단서 | 완복창만, 식욕저하, 오심·애기, 몸의 무거움, 묽은변 |
| 출전 | 『태평혜민화제국방』 계통, 『방약합편』 하통 |
| 처방 골격 | 창출·후박·진피·감초 + 생강·대조 |

## 『방약합편』 수록 구성·용량
| 본초 | 용량 |
|---|---:|
| 창출 | 7.5 g |
| 진피 | 5.25 g |
| [후박](../herbs/magnolia-bark.md) | 3.75 g |
| 감초 | 2.25 g |
| 생강 | 3편 |
| 대조 | 2매 |

## 처방 구조와 수치·제형

| 배합축 | 구성 | 처방 안의 역할 |
|---|---|---|
| 조습운비 | [창출](../herbs/atractylodes-lancea.md) | 습체와 몸의 무거움·탁한 설태를 다루는 중심축 |
| 행기제만 | [후박](../herbs/magnolia-bark.md)·[진피](../herbs/citrus-peel.md) | 막힌 기를 소통시켜 복부창만·애기·오심을 조절 |
| 화중 | [감초](../herbs/licorice.md)·[생강](../herbs/fresh-ginger.md)·대조 | 위기를 조화하고 주약의 조습·행기를 받침 |

창출을 백출로, 후박을 다른 목피로 임의 치환하지 않습니다. 후박·감초의 포제 여부와 생강·대조의 실제 규격을 기록하고, 원방 산제·탕제·보험엑스제의 1일 원생약량과 추출법을 구분합니다. 같은 평위산 이름이라도 수록본과 허가제제의 구성비가 다르면 별도 처방 기록으로 남깁니다.

## 임상 단서와 가까운 처방 감별

| 처방 | 갈림점 |
|---|---|
| **평위산** | 몸이 무겁고 더부룩하며 습체·창만·식욕저하가 함께 나타남 |
| [이진탕](erchen-tang.md) | 담습·담음과 오심·다담이 더 중심 |
| [육군자탕](liujunzi-tang.md) | 비위기허·식욕저하와 피로가 중심이고 담습이 겹침 |
| [향사양위탕](xiangsha-yangwei-tang.md) | 비위허한에 냉감·기체·창만이 더 뚜렷 |
| [반하사심탕](banxia-xiexin-tang.md) | 심하비와 한열착잡, 장명·설사·구역이 교차 |

식후포만·조기포만·상복부통 중 무엇이 주증인지, 기름진 음식과의 관계, 대변·체중·복용약을 함께 봅니다. 심한 국소통증, 반복 구토, 흑변·혈변, 빈혈·체중감소, 연하곤란은 습체 감별보다 원인검사가 우선입니다.

## 현대 임상연구

2026년 한국 다기관 무작위시험은 기능성 소화불량 환자 140명을 평위산·육군자탕·통상관리군으로 나누어 6주간 비교했습니다. 평위산군은 통상관리보다 총 소화불량 증상점수가 더 감소했습니다(MD -1.55, 95% CI -2.98~-0.12). 육군자탕과의 전체 효과 차이는 뚜렷하지 않았고, 치료 관련 중대한 이상반응은 보고되지 않았습니다. 이 결과는 모든 소화불량에 평위산을 일률적으로 적용한다는 뜻이 아니라, 연구 제제·대상과 습체·창만 중심의 실제 병증이 가까운지 확인해 활용합니다. [PMID 42637062](https://pubmed.ncbi.nlm.nih.gov/42637062/) · [DOI 10.1016/j.jep.2026.122335](https://doi.org/10.1016/j.jep.2026.122335)

## 경과와 안전 확인

식후포만·복부팽만의 강도와 지속시간, 1회 식사량, 오심·애기, 대변과 일상기능을 같은 기준으로 추적합니다. 감초가 포함되므로 다른 처방과의 중복, 부종·혈압·저칼륨 위험을 확인하고, 창출·후박의 조습행기가 건조·변비·구갈을 악화시키는지도 살핍니다. 증상이 좋아져도 식사량·체중이 계속 줄면 처방을 반복하지 않습니다.
