# 형개연교탕(荊芥連翹湯)

## 한눈에
**풍열·울열을 소산하고 청열하는 후세방으로 이비인후·두면부 풍열 병증에서 자주 접한다.**

- **치법:** 소풍청열·해독
- **출전:** 『잡병원류서촉』, 『방약합편』 중통

## 주치
한국전통지식포탈의 해당 수록본은 **이종통(귀가 붓고 아픈 병증)**을 주치로 연결하며, 간담·삼초 풍열의 상충이라는 전통적 설명을 제시한다.

## 구조
형개·방풍·백지로 풍사를 소산하고, 연교·황금·치자로 열을 식히며, 당귀·작약·천궁으로 혈분을 조화한다.
