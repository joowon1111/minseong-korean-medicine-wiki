# 분심기음(分心氣飮) {#_1}

분심기음은 정서적 긴장과 생활 리듬의 변화 속에서 기가 울체되고, 그 결과 담·수습과 적체가 겹쳐 **가슴부터 명치·복부까지 답답하고 그득한 비체**가 나타나는 구조를 다층적으로 푸는 처방입니다. ‘마음을 나눈다’는 이름보다 상·중·하초의 기와 수습을 함께 소통시키는 배합을 중심으로 읽습니다.

## 한눈에 {#_2}
**칠정 등으로 기가 울체되어 흉복이 답답하고 비체가 생긴 병증에서 기를 소통시키고 수습을 통리하는 대표 이기방**이다.

- **치법:** 청이소쾌·통리대소변
- **주치:** 비체(痞滯)
- **출전:** 『인제직지방』, 『방약합편』(1884) 중통

## 구조 {#_4}

소엽·향부자·청피·진피·목향·지각 등은 기의 울체를 풀어 주는 축으로 읽고, 복령·목통은 수습, 반하·곽향은 담습과 중초의 관계를 함께 살피는 배합으로 봅니다. 여러 약재가 있다는 사실보다 어떤 불편을 함께 다루려는지가 중요합니다.

| 배합축 | 대표 구성 | 처방에서의 의미 |
|---|---|---|
| 소간·이기 | 소엽·[향부자](../herbs/cyperus.md)·[청피](../herbs/green-citrus-peel.md)·진피·목향·지각 | 흉협·명치·복부에 이어진 기체와 비만을 소통 |
| 행기·행수 | [대복피](../herbs/areca-pericarp.md)·[목통](../herbs/akebia-stem.md)·적복령·상백피 | 기체에 수습·부종·배뇨 변화가 겹친 구조를 조절 |
| 화담화중 | 반하·곽향·생강 | 오심·담음·중초의 습탁을 조화 |
| 소적행체 | [봉출](../herbs/zedoary-rhizome.md)·빈랑 | 기체가 오래되어 적체·결취가 더해진 방향을 살핌 |
| 윤조·조화 | 맥문동·감초·대조·등심 | 다수의 행기·조습약을 조화하고 진액과 심번을 함께 고려 |

약미 수가 많은 처방이므로 이름만 기록하지 않고 실제 구성과 용량, 가감·합방 여부를 처방전과 조제기록에 남깁니다.

## 비교 {#_5}
- 소요산: 간울 + 혈허·비허
- 분심기음: 칠정기울·기체 + 수습·담
- 오약순기산: 풍사·기체와 지체통·마목

소요산은 간울에 혈허·비허가 겹치는 구조와 비교하고, 분심기음은 흉복 비체에 수습·담이 어떻게 관여하는지 봅니다. 오약순기산은 지체의 통증·마목과 풍사의 맥락이 있어 같은 이기방으로 묶어 선택하지 않습니다. [소요산(逍遙散)](../formulas/xiaoyao-san.md)에서 구성과 병증을 비교할 수 있습니다.

| 처방 | 핵심 갈림점 |
|---|---|
| **분심기음** | 흉복 비체 + 다층 기체 + 담·수습·적체 |
| [소요산](xiaoyao-san.md) | 간울에 혈허·비허가 함께 있음 |
| [반하후박탕](banxia-houpo-tang.md) | 매핵기·인후 이물감과 기울담결이 중심 |
| [월국환](yueju-wan.md) | 기·혈·담·화·습·식의 여러 울체를 압축적으로 다룸 |
| [오약순기산](wuyao-shunqi-san.md) | 풍사·기체와 지체통·마목의 결합 |

## 임상 탐색 {#clinical-assessment}

| 진료에서 확인할 항목 |
|---|
| 흉부 답답함과 식후 복만의 위치 |
| 긴장·식사·배변·소변과의 관계 |
| 활동할 때 흉통이나 호흡곤란이 생기는지 |

흉복 불편의 지속시간, 식사와 배변, 일상활동을 비교합니다. 칠정이라는 전통적 설명이 스트레스만이 원인이라는 뜻은 아닙니다. 여러 복용약과 약재 중복도 확인합니다.

## 조제·경과·안전 확인 {#quality-followup}

목통은 공정서 적합 *Akebia* 기원만 사용하고, 봉출·빈랑 등 파적·행기약의 용량과 임신 가능성, 출혈 경향을 확인합니다. 감초·계피, 이수약과 다른 처방의 중복 및 간·신장 기능, 항응고제·이뇨제 등 복용약도 함께 살핍니다.

경과는 답답함의 위치와 지속시간, 식후팽만, 트림·가스, 대변·소변, 부종과 수면을 같은 기준으로 기록합니다. 활동과 연동되는 흉부 압박감·호흡곤란·식은땀, 지속되는 연하곤란·체중감소·출혈은 필요한 진단 평가를 연결합니다.
