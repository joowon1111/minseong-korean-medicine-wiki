# 가미온담탕(加味溫膽湯) {#_1}

## 한눈에 {#_2}
**온담탕 계열을 바탕으로 심담허겁·경계·불면·이경을 다루도록 확장한 후세방**이다.

- **치법:** 이기화담·청담·안신
- **출전:** 『잡병원류서촉』 계통, 『방약합편』(1884) 중통
- **주치 기록:** 심담허겁증, 촉사이경

## 온담탕의 확장과 동명 처방 구분 {#formula-structure-reading}

가미온담탕은 이름만으로 위 구성표와 일치한다고 단정할 수 없습니다. 『방약합편』 수록형의 향부자·시호·인삼·맥문동 등과 기본 화담 구조를 먼저 확인하고, 임상자료에서 같은 이름으로 소개한 가감방은 별도로 읽습니다.

| 구분 | 확인되는 구성의 특징 | 읽을 때의 기준 |
|---|---|---|
| 위 『방약합편』 수록형 | 향부자·귤홍·반하·죽여·지실에 길경·맥문동·백복령·시호·인삼·감초를 배합 | 출전이 명시된 구성표를 기준으로 비교 |
| 『제 나름의 得效方 정리』 8절 수록형 | 용안육·볶은 산조인·당귀·백복령·귤피·반하·지실·원지·죽여·감초·생강 | 용안육·산조인·당귀·원지를 포함하는 임상 가감방으로 구분 |

두 번째 자료는 피로·수면·심리적 긴장을 함께 살핀 경험을 소개합니다. **인삼이 포함된 위 수록형과도 다르고, 용안육·당귀·원지가 겹친다는 이유만으로 귀비탕과 같아지는 것도 아닙니다.** 약재가 일부 같아도 배합 전체와 용량이 다르면 동일한 처방으로 취급하지 않습니다. 개인 경험에 적힌 선호나 호전 사례는 비교시험에서 확인한 효과를 뜻하지 않습니다.

## 비교 {#_4}
- **온담탕:** 담울·담열의 기본 골격
- **가미온담탕:** 심담허겁·경계·불면·놀람에 더 초점

온담탕과의 차이는 단순한 수면 효과의 강도가 아닙니다. 담음·소화 불편에 놀람·경계·허약이 어떤 비중으로 겹치는지 살피고, [귀비탕](guibi-tang.md)의 기혈 보익 구조와도 구분합니다. [온담탕(溫膽湯)](../formulas/wendan-tang.md)에서 구성과 병증을 비교할 수 있습니다.

## 임상 탐색 {#clinical-assessment}

| 진료에서 확인할 항목 |
|---|
| 잠들기 어려움과 밤중 각성 중 무엇이 중심인지 |
| 두근거림·놀람과 오심·팽만의 시간 관계 |
| 피로·식사량·복용약 변화 |

밤의 수면뿐 아니라 낮의 집중·피로, 심계와 소화 불편을 따로 평가합니다. 두근거림과 흉통·실신·숨참이 겹치면 처방 비교에 앞서 원인 평가가 필요합니다.
