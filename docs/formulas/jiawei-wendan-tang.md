# 가미온담탕(加味溫膽湯)

## 한눈에
**온담탕 계열을 바탕으로 심담허겁·경계·불면·이경을 다루도록 확장한 후세방**이다.

- **치법:** 이기화담·청담·안신
- **출전:** 『잡병원류서촉』 계통, 『방약합편』(1884) 중통
- **주치 기록:** 심담허겁증, 촉사이경

## 『방약합편』 수록 구성·용량
| 본초 | 용량 |
|---|---:|
| 향부자 | 9 g |
| 귤홍 | 4.5 g |
| 반하 | 3 g |
| 죽여 | 3 g |
| 지실 | 3 g |
| 길경 | 2.25 g |
| 맥문동 | 2.25 g |
| 백복령 | 2.25 g |
| 시호 | 2.25 g |
| 인삼 | 2.25 g |
| 감초 | 1.5 g |

**가미:** 생강 3편, 대조 2매

## 비교
- **온담탕:** 담울·담열의 기본 골격
- **가미온담탕:** 심담허겁·경계·불면·놀람에 더 초점
