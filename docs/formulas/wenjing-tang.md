# 온경탕(溫經湯)

## 한눈에
**충임의 허한과 어혈을 따뜻하게 풀면서 혈을 보하고 조절하는 대표 부인과 처방**이다.

- **치법:** 온경산한·양혈거어
- **핵심 병증:** 충임허한·어혈, 월경부조·복부냉통 등의 전통적 맥락
- **출전:** 『금궤요략』 계통

## 출전별 차이
국내 조사자료에는 『동의보감』 수록 온경탕의 구성량도 별도로 제시되어 있어, **동명 처방이라도 출전별 용량을 섞지 않는 것**이 중요하다.

## 병증 연결
한국전통지식포탈의 월경부조 병증 자료에서도 온경탕 계열이 관련 처방으로 연결된다.
