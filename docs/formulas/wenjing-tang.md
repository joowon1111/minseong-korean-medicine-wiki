# 온경탕(溫經湯)

## 핵심 카드
| 항목 | 내용 |
|---|---|
| 치법 | **온경산한·양혈거어** |
| 핵심 병증 | 충임허한·어혈·월경부조·복부냉통 |
| 구성 골격 | 오수유·계지·당귀·천궁·작약·인삼·맥문동·반하·목단피·아교·생강·감초 |

## 처방을 읽는 법
온경·양혈·거어·보허가 한 처방 안에 함께 있다.

## 임상 탐색
`증상 → 한열·허실 → 기혈진액·담습·어혈 → 치법 → 처방군 → 개별 처방`

## 구성·용량·출전
이 페이지는 기존 일반방제 지식망의 **핵심 임상 위치와 배합 골격을 통합 정리**한 페이지다. 이미 출전별 정확한 용량이 확인된 처방은 해당 수록본을 유지하고, 동명 처방은 서로 섞지 않는다.
