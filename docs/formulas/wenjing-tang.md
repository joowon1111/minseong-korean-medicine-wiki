# 온경탕(溫經湯) {#_1}

온경탕은 《금궤요략》의 대표적인 여성 처방으로, **충임허한을 덥히면서 혈을 기르고 어혈을 풀며 진액을 보하는 복합 구조**입니다. 월경통이라는 이름만으로 선택하지 않고 냉감·출혈 양상·건조감·허약과 어혈의 비중을 함께 봅니다.

## 한눈에 보기 {#_2}

| 항목 | 임상에서 읽는 핵심 |
|---|---|
| 치법 | 온경산한·양혈거어·익기양음 |
| 핵심 병기 | 충임허한과 어혈, 기혈·진액의 부족이 함께 나타남 |
| 주요 단서 | 하복부 냉통, 따뜻하면 편안함, 월경주기·출혈량 변화, 혈괴, 손발냉증·건조감 |
| 먼저 감별 | 임신, 급성 골반통, 과다출혈·빈혈, 자궁내막증·근종·감염 등 |
| 치료 후 평가 | 통증강도·진통제 사용, 냉감, 월경량·혈괴·주기, 수면·소화·일상기능 |

## 처방 구조 {#_3}

| 처방축 | 대표 본초 | 역할 |
|---|---|---|
| 온경산한 | [오수유](../herbs/evodia-fruit.md)·[계지](../herbs/cinnamon-twig.md)·생강 | 충임과 하복부의 한응을 덥히고 기혈 운행을 도움 |
| 양혈활혈 | [당귀](../herbs/angelica.md)·[천궁](../herbs/chuanxiong.md)·[백작약](../herbs/white-peony.md)·[목단피](../herbs/moutan.md) | 혈을 기르면서 어혈과 통증을 조절 |
| 보기양음 | [인삼](../herbs/ginseng.md)·[맥문동](../herbs/ophiopogon.md)·아교 | 허약과 진액부족을 보완 |
| 조화강역 | 반하·[감초](../herbs/licorice.md) | 위기를 조화하고 복합 처방의 균형을 잡음 |

### 온경탕은 왜 따뜻하게 하는 약재만 쓰지 않나요? {#warming-and-moistening}

온경탕의 ‘온경’은 배합 전체를 이해하는 출발점입니다. 《금궤요략》 「부인잡병맥증병치」의 온경탕에는 오수유·계지·생강과 함께 당귀·천궁·작약·아교·맥문동·인삼·목단피·반하·감초가 들어 있습니다. [구성을 대조한 공개 원문](https://jicheng.tw/tcm/book/金匱要略方論/index.html)

전통적으로는 **냉감과 함께 혈의 부족·어혈·건조가 겹친 상태**를 읽으므로, 온경산한과 양혈·거어·양음의 역할을 함께 설명합니다. 맥문동·아교는 그중 진액·혈을 돕는 배합으로 읽습니다. 온경탕을 ‘따뜻한 약재를 더 많이 넣는 처방’으로만 이해하면 이 복합 구조가 빠집니다.

진료에서는 냉감·건조·통증·출혈을 따로 확인하며, 한 가지 단서만으로 온경탕을 정하지 않습니다. 원문 배합 설명은 현대의 호르몬 변화나 임신 결과를 입증하는 자료와 구분합니다. [통증은 줄었는데 월경 뒤 피로가 남으면 무엇을 확인하나요?](../herbal-integrated/formula-selection-guide.md#menstrual-pain-case)

### 《동의보감》 수록본의 육계·아교주를 구분하기 {#donguibogam-version}

잡병편 권10 부인에 수록된 온경탕은 《의학정전》을 인용합니다. 위 《금궤요략》의 계지·아교 설명과 대조할 때, 해당 기록의 **육계와 아교주**를 확인합니다. 한국전통지식포탈의 구성은 아래와 같고 전탕에 생강 3쪽을 더합니다. [동의보감 온경탕 A](https://koreantk.com/ktkp2014/prescription/prescription-view.view?preCd=P0002260&tempLang=ko)

| 약재군 | 문헌 DB 환산 표기 |
|---|---|
| 맥문동 / 당귀 | 7.5g / 5.625g |
| 인삼·법제 반하·백작약·천궁·목단피 | 각 3.75g |
| 아교주·자감초 | 각 2.813g |
| 오수유·육계 | 각 1.875g |

이 수치는 해당 수록본의 대조 자료이며 현재의 표준 1일 용량이나 연구 제제와 같다는 뜻은 아닙니다. **육계와 계지는 사용 부위가 다르고, 아교주와 용화하는 아교는 제법이 다릅니다.** 처방명만으로 약재·제조법을 같게 취급하지 않습니다.

구성 해석에서는 온경축과 맥문동·아교의 보완축을 함께 봅니다. 냉감·혈괴·건조·허약 가운데 어느 단서가 줄었는지 따로 확인하고, 월경통 연구의 원방·가감방도 실제 약재 구성을 대조합니다. [월경통의 원문·처방 연결](../conditions/dysmenorrhea.md#classical-clinical-reading)

## 비슷한 처방과 구분 {#_4}

| 처방 | 더 중심이 되는 단서 |
|---|---|
| **온경탕** | 하복부 냉감 + 허한·어혈 + 혈·진액 부족 |
| [당귀작약산](danggui-shaoyao-san.md) | 혈허와 수습, 어지럼·부종·묽은변이 함께 있음 |
| [계지복령환](guizhi-fuling-wan.md) | 냉감보다 고정성 통증·압통·혈괴 등 어혈이 더 뚜렷함 |
| [사물탕](siwu-tang.md) | 혈허가 중심이고 온경·거어·화담 구조는 적음 |
| [가미소요산](jiawei-xiaoyao-san.md) | 간울혈허·울열과 상열감·긴장·주기성 증상 |

## 사람 대상 임상근거 {#_5}

2017년 원발성 월경통 체계적 문헌고찰·메타분석은 18개 연구·1,736명을 종합해 온경탕 원방 또는 가감방의 통증강도와 임상반응을 평가했습니다. 한응·어혈 단서와 처방 구성, 비교치료를 함께 확인해 적용합니다. [PMID 28791471](https://pubmed.ncbi.nlm.nih.gov/28791471/) · [DOI 10.1007/s00404-017-4485-7](https://doi.org/10.1007/s00404-017-4485-7)

[자궁내막증](../conditions/endometriosis.md)·[선근증](../conditions/adenomyosis.md)에서는 통증 결과와 난임 결과를 구분합니다. [난임·ART 근거카드](../authority/conditions/female-infertility-art.md)의 임신·생아출산 자료와 [임신 시기 안전성](../herbal-integrated/safety.md#fertility-pregnancy-safety)을 함께 확인합니다.

침과 온경탕을 함께 사용한 연구는 복합치료 근거로 별도 구분합니다. 처방 자체의 효과와 동일하게 해석하지 않습니다.

## 안전성과 진료 연결 {#_6}

- 임신 가능성·임신·수유, 항응고제·항혈소판제, 출혈성 질환과 수술 일정을 확인합니다.
- 월경량이 갑자기 늘거나 실신·호흡곤란·심한 어지럼이 있으면 빈혈과 출혈 원인 평가가 우선입니다.
- 임신 가능성이 있는 급성 편측 골반통, 발열·악취 분비물을 동반한 통증은 신속한 진료가 필요합니다.
- 감초가 포함되므로 장기·중복 복용 시 부종·혈압·전해질 상태를 살핍니다.
