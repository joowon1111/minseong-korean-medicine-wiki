# 온경탕(溫經湯)

온경탕은 《금궤요략》의 대표적인 여성 처방으로, **충임허한을 덥히면서 혈을 기르고 어혈을 풀며 진액을 보하는 복합 구조**입니다. 월경통이라는 이름만으로 선택하지 않고 냉감·출혈 양상·건조감·허약과 어혈의 비중을 함께 봅니다.

## 한눈에 보기

| 항목 | 임상에서 읽는 핵심 |
|---|---|
| 치법 | 온경산한·양혈거어·익기양음 |
| 핵심 병기 | 충임허한과 어혈, 기혈·진액의 부족이 함께 나타남 |
| 주요 단서 | 하복부 냉통, 따뜻하면 편안함, 월경주기·출혈량 변화, 혈괴, 손발냉증·건조감 |
| 먼저 감별 | 임신, 급성 골반통, 과다출혈·빈혈, 자궁내막증·근종·감염 등 |
| 치료 후 평가 | 통증강도·진통제 사용, 냉감, 월경량·혈괴·주기, 수면·소화·일상기능 |

## 처방 구조

| 처방축 | 대표 본초 | 역할 |
|---|---|---|
| 온경산한 | 오수유·[계지](../herbs/cinnamon-bark.md)·생강 | 충임과 하복부의 한응을 덥히고 기혈 운행을 도움 |
| 양혈활혈 | [당귀](../herbs/angelica.md)·[천궁](../herbs/chuanxiong.md)·[백작약](../herbs/white-peony.md)·[목단피](../herbs/moutan.md) | 혈을 기르면서 어혈과 통증을 조절 |
| 보기양음 | [인삼](../herbs/ginseng.md)·[맥문동](../herbs/ophiopogon.md)·아교 | 허약과 진액부족을 보완 |
| 조화강역 | 반하·[감초](../herbs/licorice.md) | 위기를 조화하고 복합 처방의 균형을 잡음 |

## 비슷한 처방과 구분

| 처방 | 더 중심이 되는 단서 |
|---|---|
| **온경탕** | 하복부 냉감 + 허한·어혈 + 혈·진액 부족 |
| [당귀작약산](danggui-shaoyao-san.md) | 혈허와 수습, 어지럼·부종·묽은변이 함께 있음 |
| [계지복령환](guizhi-fuling-wan.md) | 냉감보다 고정성 통증·압통·혈괴 등 어혈이 더 뚜렷함 |
| [사물탕](siwu-tang.md) | 혈허가 중심이고 온경·거어·화담 구조는 적음 |
| [가미소요산](jiawei-xiaoyao-san.md) | 간울혈허·울열과 상열감·긴장·주기성 증상 |

## 사람 대상 임상근거

2017년 원발성 월경통 체계적 문헌고찰·메타분석은 18개 연구·1,736명을 종합해 온경탕 원방 또는 가감방의 통증강도와 임상반응을 평가했습니다. 한응·어혈 단서와 처방 구성, 비교치료를 함께 확인해 적용합니다. [PMID 28791471](https://pubmed.ncbi.nlm.nih.gov/28791471/) · [DOI 10.1007/s00404-017-4485-7](https://doi.org/10.1007/s00404-017-4485-7)

침과 온경탕을 함께 사용한 연구는 복합치료 근거로 별도 구분합니다. 처방 자체의 효과와 동일하게 해석하지 않습니다.

## 안전성과 진료 연결

- 임신 가능성·임신·수유, 항응고제·항혈소판제, 출혈성 질환과 수술 일정을 확인합니다.
- 월경량이 갑자기 늘거나 실신·호흡곤란·심한 어지럼이 있으면 빈혈과 출혈 원인 평가가 우선입니다.
- 임신 가능성이 있는 급성 편측 골반통, 발열·악취 분비물을 동반한 통증은 신속한 진료가 필요합니다.
- 감초가 포함되므로 장기·중복 복용 시 부종·혈압·전해질 상태를 살핍니다.
