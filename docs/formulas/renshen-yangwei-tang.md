# 인삼양위탕(人蔘養胃湯)

## 한눈에
**비위허약을 바탕으로 담습과 외감이 겹친 병증을 익기화습·화담화위하는 처방**이다.

- **출전:** 『태평혜민화제국방』, 『방약합편』(1884) 중통
- **주치:** 상한음증

## 『방약합편』 수록 구성·용량
| 본초 | 용량 |
|---|---:|
| 창출 | 5.625 g |
| 반하(법제) | 4.688 g |
| 진피 | 4.688 g |
| 후박 | 4.688 g |
| 곽향 | 3.75 g |
| 적복령 | 3.75 g |
| 감초(구) | 1.875 g |
| 인삼 | 1.875 g |
| 초과 | 1.875 g |

**가미:** 대조 2매, 생강 3편, 오매 1개.

## 구조
창출·후박·진피·반하·복령으로 습담과 중초를 다스리고, 인삼으로 정기를 보하며, 곽향·초과로 화습·산한의 방향을 강화한다.

## 비교
- 삼소음: 기허 + 외감풍한 + 담
- 인삼양위탕: 비위허약 + 습담 + 음증성 외감
- 불환금정기산: 외감과 내상습체의 정기 조절
