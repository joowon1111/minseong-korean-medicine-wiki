# 인삼양위탕(人蔘養胃湯) {#_1}

인삼양위탕은 평소 비위가 약하고 담습이 쉽게 머무는 사람에게 외감·한습이 겹쳐 **오한·몸의 무거움과 식욕저하·오심·묽은변이 함께 나타나는 구조**를 보는 처방입니다. 이름의 ‘인삼’보다 창출·후박·반하·진피·곽향·초과로 이어지는 화습산한축을 함께 읽어야 처방의 성격이 선명해집니다.

## 한눈에 {#_2}
**비위허약을 바탕으로 담습과 외감이 겹친 병증을 익기화습·화담화위하는 처방**이다.

- **출전:** 『태평혜민화제국방』, 『방약합편』(1884) 중통
- **주치:** 상한음증

## 『방약합편』 수록 구성·용량 {#_3}
| 본초 | 용량 |
|---|---:|
| 창출 | 5.625 g |
| 반하(법제) | 4.688 g |
| 진피 | 4.688 g |
| 후박 | 4.688 g |
| 곽향 | 3.75 g |
| 적복령 | 3.75 g |
| 감초(구) | 1.875 g |
| 인삼 | 1.875 g |
| 초과 | 1.875 g |

**가미:** 대조 2매, 생강 3편, 오매 1개.


## 구조 {#_4}

인삼이 들어가지만 인삼만으로 기력을 보하는 처방은 아닙니다. 창출·후박·진피·반하·복령의 습담 조절이 배합에서 큰 비중을 차지하고, 인삼은 그 과정에서 허약한 비위와 정기를 함께 고려하는 위치입니다. 곽향·초과는 화습·산한의 방향을 더합니다.

| 배합축 | 구성 | 처방에서의 의미 |
|---|---|---|
| 조습운비 | [창출](../herbs/atractylodes-lancea.md)·[후박](../herbs/magnolia-bark.md)·[진피](../herbs/citrus-peel.md) | 중초의 습체·창만과 운화 저하를 조절 |
| 화담강역 | 법제 [반하](../herbs/pinellia.md)·적복령 | 오심·구토·담음과 위기상역을 조절 |
| 방향화습·산한 | [곽향](../herbs/agastache.md)·[초과](../herbs/tsaoko-fruit.md) | 한습·탁기를 풀어 식욕과 중초의 움직임을 도움 |
| 익기고호 | [인삼](../herbs/ginseng.md)·감초 | 허약한 비위와 정기를 받쳐 화습약의 운행을 도움 |
| 산수렴·조화 | 오매·생강·대조 | 구토·설사 경향과 전체 배합을 조화 |

## 비교 {#_5}
- 삼소음: 기허 + 외감풍한 + 담
- 인삼양위탕: 비위허약 + 습담 + 음증성 외감
- 불환금정기산: 외감과 내상습체의 정기 조절

삼소음과는 기허·외감·담이라는 공통점이 있지만 비위와 습담의 비중을 비교합니다. 불환금정기산과는 평소 식사량·피로·배변이 약했는지까지 살펴 차이를 구체화합니다. [삼소음(蔘蘇飮)](../formulas/renshen-suyin.md)에서 구성과 병증을 비교할 수 있습니다.

| 처방 | 핵심 갈림점 |
|---|---|
| **인삼양위탕** | 평소 비위허약 + 한습·담습 + 새 외감 |
| [삼소음](renshen-suyin.md) | 기허 + 풍한표증 + 기침·가래의 호흡기축 |
| [불환금정기산](buhuanjin-zhengqi-san.md) | 외감과 중초 습체가 중심이며 보기축은 가벼움 |
| [향사양위탕](xiangsha-yangwei-tang.md) | 평소 비위허약·식욕저하와 한습을 조리하는 만성축 |
| [쌍금탕](ssanggeum-tang.md) | 과로 뒤 기혈소모와 습체성 소화불편의 결합 |

## 임상 탐색 {#clinical-assessment}

| 진료에서 확인할 항목 |
|---|
| 아프기 전부터 소화와 기력이 약했는지 |
| 외감 뒤 오심·식사량 감소가 더해졌는지 |
| 묽은 변·구토·어지럼으로 일상이 얼마나 제한되는지 |

식사를 유지하는 정도, 식후 불편, 활동 후 회복을 따로 봅니다. 표의 고전 용량은 특정 수록본의 기록이며 현재 환자의 1일 복용량을 지시하는 표가 아닙니다.

## 조제·경과·안전 확인 {#quality-followup}

반하의 법제, 곽향·초과의 기원과 향, 창출·후박의 절편, 인삼의 종·가공을 확인합니다. 감초와 다른 처방의 중복, 심계·혈압·부종, 임신·수유, 간·신장 기능과 현재 복용약을 함께 살핍니다.

경과는 체온·오한뿐 아니라 오심·구토 횟수, 식사량, 복부팽만, 대변 형태, 일상 활동 회복을 같은 기준으로 기록합니다. 고열·반복 구토·탈수·심한 국소 복통·혈변이 있으면 급성 원인 평가를 연결합니다.
