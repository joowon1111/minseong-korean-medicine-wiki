# 정천탕(定喘湯)

## 한눈에
| 항목 | 내용 |
|---|---|
| 치법 | **선폐강기·청열화담** |
| 핵심 병증 | 담열옹폐·해수천급 |
| 주요 구성 골격 | 백과·마황·소자·감초·관동화·행인·상백피·황금·반하 |

## 감별 포인트
마행감석탕보다 담열·담연과 강기화담의 층이 더 뚜렷하다.

## 출전·구성 원칙
이 처방은 고전 및 후대 의서에서 널리 사용되는 핵심 처방군이다. **동명 처방이나 후대 가감방이 존재할 수 있으므로 정확한 g 용량은 특정 원전·수록본을 지정한 뒤 기록**한다. 『방약합편』, 『동의보감』, 『상한론』, 『금궤요략』 및 온병학 계열 자료를 서로 섞지 않는다.

`주증상 → 위험신호 → 표리·한열·허실 → 기혈진액·담습·어혈 → 치법 → 처방`
