# 청서익기탕(淸暑益氣湯) {#_1}

## 한눈에 {#_2}
| 항목 | 내용 |
|---|---|
| 출전 계통 | 이동원(이고)의 《비위론》 계통; 《동의보감》 서문 수록 |
| 치법 | **청서익기·양음생진** |
| 핵심 병증 | 더위와 습에 노출된 뒤 땀·갈증·권태·식욕저하·묽은변이 겹친 기음손상 |
| 주요 구성 골격 | 창출·황기·승마·인삼·백출·신곡·진피·택사·감초·황백·당귀·청피·맥문동·갈근·오미자 |

## 청서와 익기가 함께 필요한 맥락 {#formula-structure-reading}

더위로 인한 소모를 설명할 때 열만 맑히거나 기운만 보하기보다 **땀과 갈증, 기력, 식욕과 배변, 몸의 무거움**을 한 묶음으로 읽는 처방입니다. 황기·인삼·백출이 기와 비위를 받치고, 맥문동·오미자가 진액을 보존하며, 창출·택사·진피·청피·신곡이 습체와 중초의 정체를 조절합니다. 황백은 습열을 맑히고 승마·갈근은 청양을 들어 올리며 표부의 열을 풀어 주는 방향을 더합니다.

## 15미 구성축 {#formula-role-map}

| 치료축 | 구성 | 함께 보는 임상 단서 |
|---|---|---|
| 익기건비·고표 | [황기](../herbs/astragalus-tonic-guide.md)·[인삼](../herbs/ginseng.md)·[백출](../herbs/atractylodes.md)·감초 | 조금만 움직여도 지치고 땀이 많으며 식욕이 저하됨 |
| 양음생진·렴한 | [맥문동](../herbs/ophiopogon.md)·[오미자](../herbs/schisandra.md) | 갈증·입마름·땀 뒤 탈력감 |
| 조습운비·이수 | [창출](../herbs/atractylodes-lancea.md)·택사 | 몸이 무겁고 머리가 맑지 않으며 묽은변·부종감이 겹침 |
| 이기소식 | 진피·청피·[신곡](../herbs/massa-medicata-fermentata.md) | 더위 뒤 입맛이 없고 식후 더부룩함이 지속됨 |
| 청열승청 | 황백·승마·갈근 | 번열·열감과 기허하함의 조절 |
| 양혈화영 | 당귀 | 땀과 소모 뒤 혈분의 회복을 보조 |

《동의보감》 수록 구성은 총 15미이며 황백은 술로 포제한 것으로 기록합니다. 보험제제나 일본 한방제제의 청서익기탕은 9미 등 다른 구성도 있으므로, 동일한 처방명 아래에서도 **출전과 실제 약미**를 먼저 확인합니다.

## 감별 포인트 {#_3}

| 처방 | 중심 구조 | 청서익기탕과의 갈림점 |
|---|---|---|
| **청서익기탕** | 익기생진 + 청서·건비·제습 | 더위·땀·갈증과 식욕저하·묽은변·몸의 무거움이 함께 나타남 |
| [생맥산](shengmai-san.md) | 인삼·맥문동·오미자의 익기생진·렴음 | 구성은 간결하며 기음소모와 맥약·자한이 중심 |
| [보중익기탕](buzhong-yiqi-tang.md) | 보기승양·중기하함 | 계절보다 만성 기허·권태·내장하수감·오래된 식욕저하가 중심 |
| [죽엽석고탕](zhuye-shigao-tang.md) | 청열생진·익기화위 | 열병 뒤 남은 여열·번갈과 위기불화가 중심 |
| [삼령백출산](shenling-baizhu-san.md) | 보기건비·삼습지사 | 만성 비위기허·묽은변과 수습이 중심 |

## 출전·원문·약량 대조 {#source-dose-original}

**대조 출전:** [內外傷辨惑論](https://jicheng.tw/tcm/book/內外傷辨惑論/index.html)

**원문 발췌**

> 清暑益氣湯
>
> 黃耆（汗少者減五分）　蒼朮（泔浸去皮，以上各一錢五分）　升麻（一錢）　人參（去蘆）　白朮　橘皮　神麯（炒）　澤瀉（以上各五分）　甘草（炙）　黃柏（酒浸）　當歸身　麥門冬（去心）　青皮（去白）　葛根（以上各三分）　五味子（九個）
>
> 《內經》云：「陽氣者，衛外而為固也」，「炅則氣泄。」今暑邪干衛，故身熱自汗。以黃耆、人參、甘草補中益氣為君；甘草、橘皮、當歸身甘辛微溫養胃氣，和血脈為臣。蒼朮、白朮、澤瀉滲利除濕。升麻、葛根苦甘平，善解肌熱，又以風勝濕也。濕勝則食不消而作痞滿，故炒曲甘辛，青皮辛溫，消食快氣。腎惡燥，急食辛以潤之，故以黃柏苦辛寒，借甘味瀉熱補水虛者，滋其化源。以五味子、麥門冬酸甘微寒，救天暑之傷庚金為佐也。
>
> 上㕮咀，作一服，水二盞，煎至一盞，去渣，稍熱服，食遠。
>
> 此病皆因飲食失節，勞倦所傷，日漸因循，損其脾胃，乘暑天而作病也。

**해석:** 더위에 땀과 열감이 생기고 비위가 손상된 맥락에서 황기·인삼·감초로 기를 받치고, 창출·백출·택사로 습을 조절하며, 맥문동·오미자로 진액을 보존하는 배합을 설명한다. 한 번의 전탕 분량을 물 2잔에서 1잔으로 달이는 기록이다.

| 본초·제법 항목 | 이 수록본의 기재량 |
|---|---|
| [황기](../herbs/astragalus.md)·[창출](../herbs/atractylodes-lancea.md) | 각 1전 5분 |
| [승마](../herbs/cimicifuga.md) | 1전 |
| [인삼](../herbs/ginseng.md)·[백출](../herbs/atractylodes.md)·[귤피](../herbs/citrus-peel.md)·[초신곡](../herbs/massa-medicata-fermentata.md)·[택사](../herbs/alisma.md) | 각 5분 |
| [자감초](../herbs/licorice.md)·주침황백·당귀신·[맥문동](../herbs/ophiopogon.md)·청피·[갈근](../herbs/pueraria.md) | 각 3분 |
| [오미자](../herbs/schisandra.md) | 9개 |

이 《내외상변혹론》 수록문은 황기·창출을 각 1전 5분으로 적는다. 위 동의보감 환산표는 창출 5.625 g, 황기 3.75 g이므로 같은 표로 합치지 않는다. 원문의 더위 노출 맥락을 모든 여름철 피로에 적용하는 규칙으로 바꾸지 않는다.

## 출전·구성 원칙 {#_4}
한국전통지식포탈의 《동의보감》 수록형은 창출 5.625g, 황기·승마 각 3.75g, 인삼·백출·신곡·진피·택사 각 1.875g, 감초·갈근·당귀·맥문동·황백·청피 각 1.125g, 오미자 9알을 기록합니다. 고전 단위를 현대 조제에 적용할 때에는 의료기관의 조제 기준과 환자 상태에 맞춰 판단합니다.

- [한국전통지식포탈 청서익기탕 A](https://koreantk.com/ktkp2014/prescription/prescription-view.view?preCd=P0003193&tempLang=ko)
- [약학정보원 청서익기탕 제제 정보](https://health.kr/searchDrug/result_take.asp?drug_cd=A11A1500A0436)

## 임상 탐색 {#_5}

| 시점 | 기록할 항목 |
|---|---|
| 치료 전 | 더위·습도·야외활동과 증상 발생의 관계, 평소 체력과 소화상태 |
| 치료 중 | 갈증·발한·어지럼, 식사량, 대변 형태, 몸의 무거움, 활동 후 회복시간 |
| 재평가 | 수면·체중·혈압·맥박, 수분 섭취와 소변량, 일상 활동의 회복 |

의식 변화·실신·고체온·심한 두통·혼동·경련은 온열질환 응급평가를 연결합니다. 고령자·소아, 이뇨제·혈압약 복용자, 심장·콩팥 질환자는 탈수와 전해질 상태를 함께 살피고, 황기·인삼·감초가 포함된 실제 처방과 복용약을 조율합니다.
