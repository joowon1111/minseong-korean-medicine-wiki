# 위령탕(胃苓湯)

## 한눈에
**평위산 계열의 화습화위와 오령산 계열의 이수삼습을 결합한 처방**으로 이해하면 빠르다.

- **치법:** 화습화위·이수
- **주치 기록:** 비위한습, 설사복통
- **출전:** 『고금의감』, 『방약합편』(1884) 하통

## 핵심 감별
평위산의 **중초 습체·창만**에 수습·소변·설사 축이 더해진 경우를 본다.
