# 행소산(杏蘇散) {#_1}

행소산은 가을철이라는 달력보다 **찬 기운을 띤 건조한 외사가 폐의 선발·숙강을 방해하고 묽거나 적은 담이 남은 량조해수**의 구조를 보는 처방입니다. 마른기침이라는 한 증상만 좇지 않고 오한·미열, 코와 목의 건조, 가래의 양과 색, 갈증과 흉민을 한 묶음으로 살핍니다.

## 한눈에 {#_2}
| 항목 | 내용 |
|---|---|
| 치법 | **경선양조·이폐화담** |
| 핵심 병증 | 외감량조·해수담희 |
| 주요 구성 골격 | 자소엽·행인·전호·반하·복령·진피·길경·지각·감초·생강·대조 등 |

## 처방 구조 {#formula-architecture}

| 배합축 | 대표 구성 | 역할 |
|---|---|---|
| 경선해표 | [자소엽](../herbs/perilla-leaf.md) | 풍한·량조를 가볍게 풀고 폐기의 울체를 소통 |
| 선폐강기 | [행인](../herbs/apricot-kernel.md)·[전호](../herbs/peucedanum-root.md)·[길경](../herbs/platycodon.md) | 기침의 상역을 내리고 폐의 선발과 숙강을 조절 |
| 조습화담 | [반하](../herbs/pinellia.md)·[복령](../herbs/poria.md)·[진피](../herbs/citrus-peel.md) | 묽고 적은 담, 흉민과 비위의 담습을 정리 |
| 이기관흉 | 지각 | 흉부의 답답함과 기체를 소통 |
| 조화 | 감초·[생강](../herbs/fresh-ginger.md)·[대조](../herbs/jujube-fruit.md) | 중초와 전체 배합을 조화 |

원전·후대 수록본에 따라 생강·대조 포함 여부와 용량이 다를 수 있으므로 실제 조제표에는 사용한 판본과 제형을 함께 기록합니다.

## 량조와 담을 함께 보는 기침 처방 {#formula-structure-reading}

자소엽·행인·전호의 폐기 조절에 반하·복령·진피의 담습 조절이 더해집니다. 건조라는 말이 있더라도 모든 마른기침을 같은 방식으로 보지 않고 한열과 담의 양상을 함께 읽습니다.

## 감별 포인트 {#_3}

은교산·상국음의 풍열과 달리 량조·폐기불선·희담의 맥락을 비교합니다. 기침이 오래된 경우에는 외감 초기라는 전제가 여전히 맞는지도 다시 확인합니다. [상국음(桑菊飮)](../formulas/sangju-yin.md)에서 구성과 병증을 비교할 수 있습니다.

| 처방 | 기침과 전신 단서의 중심 |
|---|---|
| **행소산** | 서늘한 건조감, 오한·미열, 마른기침 또는 묽고 적은 담 |
| [상국음](sangju-yin.md) | 풍온 초기에 기침이 중심이고 미열·구갈이 동반 |
| [은교산](yinqiao-san.md) | 발열·인후통·구갈 등 풍열표증의 비중이 큼 |
| [맥문동탕](maidong-tang.md) | 폐위음손과 기역성 기침, 인후건조가 오래 이어짐 |
| [삼소음](renshen-suyin.md) | 평소 기허에 새 외감풍한과 기침·담이 겹침 |

## 출전·구성 원칙 {#_4}
원방의 구성·용량·제법은 출전과 수록본을 지정해 확인합니다. 현대 연구를 읽을 때에는 실제 사용한 제제·대상 질환·비교군·평가 기간이 무엇인지 구분합니다. 전통적 치법 설명만으로 특정 질환에서 효과가 입증되었다고 볼 수 없습니다.

## 임상 탐색 {#_5}

| 진료에서 확인할 항목 |
|---|
| 찬 공기·계절과 기침의 관계 |
| 발열·목 통증·가래·갈증의 동반 |
| 야간 증상과 현재 호흡기 치료 |

- 기침이 시작된 시점과 감염·찬 공기·건조한 환경의 관계를 확인합니다.
- 가래가 없다고 단정하지 않고 양·색·점도와 목 뒤로 넘어가는 분비물을 구분합니다.
- 비염·천식·역류, 흡연·전자담배, ACE 억제제 등 만성기침에 영향을 주는 요인을 함께 기록합니다.

기침 횟수·수면·활동 시 호흡을 같은 기준으로 기록합니다. 가래나 기침이 줄었어도 숨참과 전신 쇠약이 늘면 치료 목표와 원인 평가를 다시 봅니다.

## 조제·경과·안전 확인 {#quality-followup}

행인의 기원·포제와 사용량, 반하의 법제, 자소엽·생강의 향과 보관 상태를 확인합니다. 임신·수유, 소아·고령자, 천식·만성폐질환, 간·신장 기능과 복용약을 처방 전에 살핍니다.

치료 전후에는 주간·야간 기침 횟수, 가래, 인후건조, 수면 중 각성, 보행·계단에서의 호흡을 같은 기준으로 비교합니다. 호흡곤란이 빠르게 심해지거나 흉통·객혈·청색증·산소포화도 저하가 동반되면 신속한 평가를 연결합니다.
