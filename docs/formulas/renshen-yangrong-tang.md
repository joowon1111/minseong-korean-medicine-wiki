# 인삼양영탕(人蔘養榮湯)

인삼양영탕은 **오래된 피로와 허손으로 기와 혈이 함께 부족하고, 식욕저하·마른 느낌·심계·불안정한 수면이 겹치는 양상**을 살피는 대표적인 기혈쌍보방입니다. 인삼·황기·백출·감초가 기를 돕고, 숙지황·당귀·백작약이 혈을 보하며, 원지·오미자가 심신과 진액의 소모를 함께 조절합니다.

> **핵심 해석:** 단순 피로회복제가 아니라 **기력·식욕·체중·안색과 함께 심계·건망·수면, 한열과 소화 적합성**을 종합해 선택하는 처방입니다.

## 『방약합편』 수록본의 구성

한국전통지식포탈의 『방약합편』 상통 수록본을 기준으로 정리했습니다. 생강 3편과 대추 2매를 더해 달입니다.

| 배합축 | 구성 | 처방 안에서 보는 역할 |
|---|---|---|
| 보기·건비 | 인삼·황기·백출·감초 | 기력·식욕과 비위의 운화를 받침 |
| 양혈·화영 | 백작약·당귀·숙지황 | 혈과 영분의 부족, 안색·근육의 영양을 보완 |
| 온통·이기 | 육계·진피 | 허한을 덥히고 보약의 체기를 줄임 |
| 양심·수렴 | 원지·오미자 | 심계·건망·불안정한 수면과 소모를 함께 살핌 |
| 조화 | 생강·대추 | 위장 적합성과 영위 조화를 도움 |

『태평혜민화제국방』 계통의 국제적 Ninjin'yoeito 제제는 복령을 포함하는 12개 구성으로 표준화된 경우가 많습니다. 국내 고전 수록본과 일본 의료용 제제의 구성이 완전히 같다고 가정하지 않고, 연구를 인용할 때는 실제 제품·용량을 확인합니다.

## 임상에서 먼저 보는 단서

| 영역 | 관찰할 내용 |
|---|---|
| 기력 | 휴식해도 회복이 더디고 말하거나 움직일 힘이 부족 |
| 영양·소화 | 식욕저하, 체중감소, 식후 피로가 동반 |
| 혈허 | 창백한 안색, 어지럼, 두근거림, 건조감 |
| 심신 | 건망·불안·얕은 잠이 피로와 함께 나타남 |
| 한열 | 냉감과 허약이 중심인지, 강한 실열·염증 소견은 없는지 |
| 경과 | 식사량·활동량·수면·심계가 같은 방향으로 회복되는지 |

빈혈·체중감소·지속 발열·야간발한·흑변 등이 있으면 처방 선택보다 혈액검사와 원인 평가가 먼저입니다.

## 현대 임상연구 읽기

일본의 표준화된 Ninjin'yoeito 제제를 이용한 임상연구가 축적되고 있습니다.

- 2005년 무작위시험에서는 만성 C형간염 치료 중 리바비린 관련 빈혈을 보조하는 맥락을 탐색했습니다. [PMID 15996025](https://pubmed.ncbi.nlm.nih.gov/15996025/)
- 2020년 52명 규모의 공개 무작위 2상 연구에서는 대장암 보조항암치료 중 옥살리플라틴 누적 말초신경병증 예방 가능성을 평가했습니다. [PMID 32232692](https://pubmed.ncbi.nlm.nih.gov/32232692/)
- 2022년 준무작위 연구는 산후 빈혈과 피로 회복 가능성을 살폈습니다. [PMID 35882511](https://pubmed.ncbi.nlm.nih.gov/35882511/)
- 2022년 철분과 병용한 수술 전 연구는 빈혈·피로·불안 및 회복 지표를 관찰했습니다. [PMID 35701778](https://pubmed.ncbi.nlm.nih.gov/35701778/)

각 연구는 질환·표준치료·제제가 다르므로 인삼양영탕의 모든 피로와 빈혈에 대한 일반적 효과로 확대하지 않습니다. 국내 사용 처방과 연구 제제의 구성 일치 여부도 함께 확인합니다.

## 안전과 경과 관찰

- 치료 전후 **피로 강도, 식사량, 체중, 활동량, 수면, 심계, 배변**을 기록합니다.
- 인삼·황기·육계가 포함되어 불면·상열·두근거림이 심한 경우 적합성을 재평가합니다.
- 감초 함유 처방의 중복·장기복용은 부종, 혈압, 근력저하, 혈중 칼륨과 병용약을 확인합니다.
- 항응고제·항혈소판제, 혈압약·이뇨제, 당뇨약 복용 중이거나 임신·수유 중이면 의료진과 상의합니다.
- 항암치료·간질환·수술 전후에는 표준치료를 대체하지 않고 담당 의료진과 병용을 조율합니다.
