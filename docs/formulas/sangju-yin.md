# 상국음(桑菊飮)

## 핵심 카드
| 항목 | 내용 |
|---|---|
| 치법 | **소풍청열·선폐지해** |
| 핵심 병증 | 풍온초기·기침이 중심인 풍열표증 |
| 주요 구성 골격 | 상엽·국화·행인·연교·박하·고길경·감초·노근 |
| 처방군 | 외감·호흡 |

## 언제 떠올리는가
처방명을 현대 질환명과 바로 연결하지 않고 **한열·허실·표리·기혈진액·담습·어혈과 장부 병기**를 먼저 확인한다.

## 구성·용량·출전
이 페이지는 우선 임상적으로 중요한 **처방 위치와 구성 골격**을 잡기 위한 허브다. 동명 처방과 출전별 구성 차이가 있으므로 정확한 g 용량은 『방약합편』·『동의보감』·『상한론』·『금궤요략』·온병학 원전 및 공식 처방 DB의 특정 수록본을 확인한 뒤 별도로 고정한다.
