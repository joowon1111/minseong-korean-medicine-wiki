# 향사육군자탕(香砂六君子湯)

향사육군자탕은 **비위기허와 담습을 다루는 육군자탕에 목향·사인·향부자·후박 등 이기약을 더해 식후팽만·조기포만·트림·식욕저하를 함께 푸는 처방**입니다. 허약함을 보하면서도 정체된 기를 움직이는 것이 특징입니다.

> **핵심 해석:** 단순히 위가 약한 경우보다 **조금만 먹어도 차고, 식후 답답함과 트림이 오래가며, 피로·식욕저하·담습이 기체와 함께 나타나는지** 봅니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 핵심 치법 | 익기건비·이기화담 |
| 중심 병증 | 비위기허 + 담습 + 기체 |
| 대표 증상축 | 조기포만·식후팽만·식욕저하·트림·오심·피로 |
| 구성 특징 | 육군자탕 골격 + 목향·사인·향부자·후박·백두구·익지인 |
| 출전 | 『증보만병회춘』, 『방약합편』 상통 |
| 국제 연구명 | Xiangsha Liujunzi Tang/Decoction/Granules |
| 현대 연구축 | 기능성소화불량의 증상·위배출·삶의 질 |

## 『방약합편』 구성 구조

| 구성축 | 주요 본초 | 처방 안에서 보는 역할 |
|---|---|---|
| 보기건비 | [인삼](../herbs/ginseng.md)·[백출](../herbs/atractylodes.md)·[복령](../herbs/poria.md)·[감초](../herbs/licorice.md) | 비위기허와 피로·식욕저하의 바탕을 보완 |
| 화담강역 | [반하](../herbs/pinellia.md)·[진피](../herbs/citrus-peel.md) | 담습·오심·명치 답답함을 정리 |
| 행기소창 | [목향](../herbs/aucklandia.md)·[사인](../herbs/amomum.md)·[향부자](../herbs/cyperus.md)·[후박](../herbs/magnolia-bark.md) | 식후팽만·트림과 기체를 적극적으로 풀어줌 |
| 온중화습 | [백두구](../herbs/white-cardamom.md)·[익지인](../herbs/alpinia-oxyphylla.md)·생강·대조 | 중초를 따뜻하게 조화하고 습체를 도움 |

『방약합편』에는 반하·백두구·백복령·백출·진피·향부자·후박 각 3.75g, 감초·목향·사인·익지인·인삼 각 1.875g에 생강 3편·대조 2매를 더하는 구성으로 수록됩니다.

## 임상에서 먼저 보는 단서

| 관찰 영역 | 향사육군자탕을 생각하게 하는 표현 |
|---|---|
| 식사 | 조금만 먹어도 배가 차고 식사가 오래 부담됨 |
| 상복부 | 식후 더부룩함·트림·명치 답답함이 주증 |
| 식욕·체력 | 입맛이 떨어지고 쉽게 피로하며 회복이 느림 |
| 담습 | 오심·가래감·몸의 무거움이 소화상태와 연동 |
| 기체 | 긴장하거나 스트레스가 심할 때 팽만과 트림이 증가 |

`체중감소·빈혈·흑변·반복구토·연하곤란 → 내시경 등 평가 → 기능성소화불량 확인 → 비허·담습·기체 → 처방 → 식후증상·식사량·체중 재평가`

## 현대 임상근거

2024년 체계적 문헌고찰·메타분석은 기능성소화불량 **23개 연구, 2,101명**을 종합했습니다. 향사육군자탕군에서 보고된 전체 임상반응, 위배출과 증상점수의 개선을 평가했고 안전성도 함께 비교했습니다. 연구별 처방 구성과 비교치료가 다양하므로 어떤 제형과 병증을 사용했는지 함께 읽습니다.

2017년 세 기관 무작위·이중맹검·위약대조시험은 식후불편증후군 환자 **216명**을 모집해 과립제를 4주간 평가했습니다. 식후포만·조기포만·상복부통증과 위배출, 삶의 질 등에서 향사육군자탕군의 개선을 확인했습니다. 다만 시험 제제 구성은 국내 『방약합편』 처방과 약미가 일부 달라 동일 제제로 간주하지 않습니다.

→ [2024년 메타분석·PMID 38933675](https://pubmed.ncbi.nlm.nih.gov/38933675/) · [2017년 다기관 RCT·PMID 28852318](https://pubmed.ncbi.nlm.nih.gov/28852318/) · [DOI 10.3748/wjg.v23.i30.5589](https://doi.org/10.3748/wjg.v23.i30.5589)

| [평위산](pingwei-san.md) | 습체·창만 | 허약보다 실한 습체와 후중감이 중심 |

## 복용과 경과 관찰

**식후포만·조기포만·식사량·상복부통증·트림·오심·대변·체중·활동량**을 기록합니다. 2~4주 단위로 가장 불편한 증상과 기능 목표가 얼마나 변했는지 확인하고 반응이 없거나 악화되면 원인과 병증을 다시 봅니다.

감초 함유 처방의 중복, 임신·수유, 간·신장질환과 복용약을 확인합니다. 진행하는 체중감소·흑변·토혈·연하곤란·지속구토·야간에 깨는 심한 통증은 한약 조정보다 의학적 평가가 우선입니다.
