# 계지탕(桂枝湯)

계지탕은 단순한 ‘감기 처방’이 아니라 **태양중풍의 한출·오풍과 영위불화**를 계지와 작약의 균형, 생강·대조·자감초의 조화, 복약 뒤 미한출 관찰로 설명하는 기본방입니다.

| 항목 | 내용 |
|---|---|
| 중심 치법 | 해기거풍·조화영위 |
| 대표 병증 | 태양중풍·영위불화 |
| 핵심 단서 | 두통·발열·한출·오풍 |
| 구성 골격 | 계지·작약·자감초·생강·대조 |
| 중요한 제법 | 따뜻하게 복용하고 죽을 보조하며 미한출을 관찰하는 원방 복법 |

## 출전
《상한론》 계통의 대표 처방이다. [12조](../classics/shanghanlun/clauses/taiyang-upper.md#clause-012)에서 태양중풍의 증후와 원방·복용 뒤 관찰을, [13조](../classics/shanghanlun/clauses/taiyang-upper.md#clause-013)에서 두통·발열·한출·오풍의 주치를 이어서 읽을 수 있다.

## 원전 구성
Chinese Text Project 전승문에는 다음과 같이 수록되어 있다.

- 桂枝 三兩
- 芍藥 三兩
- 甘草 二兩（炙）
- 生薑 三兩
- 大棗 十二枚

고대의 '兩'을 현대 g 단위로 단순 환산하지 않는다. 시대와 도량형 해석에 따라 환산법이 달라질 수 있다.

## 배합과 복법을 함께 읽기

| 구성 | 배합에서 보는 역할 | 확인점 |
|---|---|---|
| [계지](../herbs/cinnamon-twig.md) | 위양을 통하게 하고 해기 | 육계와 구분하고 가지 약재인지 확인 |
| [백작약](../herbs/white-peony.md) | 영음을 조절하고 계지의 산발을 균형화 | 적작약과 구분 |
| [자감초](../herbs/licorice.md) | 계지·작약을 조화하고 완급 | 포제품과 총 감초 노출량 확인 |
| [생강](../herbs/fresh-ginger.md)·[대조](../herbs/jujube-fruit.md) | 위기를 돕고 영위 조화를 보조 | 건강·건생강과 구분, 대조 개수·규격 기록 |

《상한론》 12조의 복법에는 따뜻하게 복용한 뒤 죽을 먹고 이불을 덮어 **온몸에 촉촉하게 땀이 날 정도**를 관찰하는 내용이 포함됩니다. 이는 다한을 유도하라는 뜻이 아니며, 현대의 탕제·엑스제에서는 제형과 환자 상태에 맞춰 해석해야 합니다.

## 대표 조문
> 太陽病，頭痛發熱，汗出惡風者，桂枝湯主之。

→ [조문 전체 해설](../classics/shanghanlun/guizhi-indication.md)

## 전통적 방의
[계지](../herbs/cinnamon-twig.md)와 [생강](../herbs/fresh-ginger.md)의 신온한 성질, [작약](../herbs/white-peony.md), [감초](../herbs/licorice.md)·[대조](../herbs/jujube-fruit.md)의 조합을 통해 영위(營衛)를 조화시키고 해기(解肌)하는 처방으로 설명되어 왔다.

## 마황탕과 비교
- 계지탕 대표 조문: **汗出 + 惡風**
- 마황탕 대표 조문: **無汗 + 喘 + 身疼痛**

이는 '땀이 나면 계지탕, 안 나면 마황탕'이라는 기계적 규칙만을 뜻하지 않으며 맥증과 전체 병태를 함께 본다.

| 비교 처방 | 구분하는 질문 |
|---|---|
| [마황탕](mahuang-tang.md) | 무한·전신통·천이 뚜렷한 풍한표실인가 |
| 계지가갈근탕 | 경항강·목덜미 긴장이 더 뚜렷한가 |
| 계지신가탕 | 발한 뒤 허손과 침지맥·신통이 남았는가 |
| 황기계지오물탕 | 외감보다 혈비·감각이상·기혈허가 중심인가 |

## 임상 확인과 안전

증상 시작 시점, 한출·오한, 수분 섭취, 맥박·혈압, 기존 감염·호흡기질환을 확인합니다. 발열이 지속되거나 호흡곤란·흉통·의식 변화가 있으면 외감 처방의 반응을 기다리지 않습니다.

계지와 육계를 혼용하지 않고 감초 함유 처방 중복, 항응고·항혈소판제, 부종·혈압·저칼륨 위험을 살핍니다. 치료 경과는 땀의 유무만이 아니라 오한·두통·활동·수면·섭취의 회복으로 평가합니다.

## 현대 연구를 읽는 기준

계지탕 원방, 계지탕 가감방, 계지탕류 처방을 구분합니다. 감기·발열·자율신경 등 연구 분야가 달라도 사용 제제, 대상 진단, 비교군과 결과지표가 일치하는지 먼저 확인하며, 전통적 영위조화를 하나의 현대 생리지표와 동일시하지 않습니다.
