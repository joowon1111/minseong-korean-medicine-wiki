# 한의치료 방법

한의치료는 한 가지 시술만을 반복하기보다 **환자의 변증과 통증 양상, 조직 상태, 전신 컨디션에 맞추어 여러 치료수단을 조합**하는 것이 특징이다.

## 치료를 조합하는 이유
같은 요통이라도 근육 긴장, 관절·인대의 문제, 오래된 허증, 냉감, 어혈성 통증 등 양상이 서로 다를 수 있다.

```text
진찰·변증
   ↓
침 → 경락·경혈·근육 자극
약침 → 국소·경혈 자극 강화
전침 → 일정한 반복 자극
부항 → 연부조직·음압 자극
뜸·온열 → 온통·이완 보조
   ↓
환자 상태에 맞춰 조합
```
