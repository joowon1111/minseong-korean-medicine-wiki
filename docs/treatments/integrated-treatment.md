# 복합 한의치료 전략

실제 한의 임상에서는 침·약침·전침·부항·뜸·온열을 각각 독립적으로만 사용하기보다 **치료 목적에 따라 서로 보완적으로 조합**한다.

## 예시: 근육성 요통
```text
침
→ 긴장된 근육·경혈 자극

+ 전침
→ 지속적인 반복 자극

+ 부항
→ 근막·연부조직 음압 자극

+ 온열
→ 이완과 냉감 개선 보조
```

## 예시: 오래된 허증성 요통
```text
침
+ 신수·관원 등 변증 배혈
+ 뜸·온열
+ 필요에 따라 약침
```

## 예시: 급성 국소 통증
국소 조직의 상태와 손상 정도를 먼저 평가한 뒤 침·약침·부항 등 치료수단을 선택한다.

## 치료계획의 핵심
- 통증의 위치와 조직
- 급성·만성 여부
- 냉·열과 허·실
- 신경학적 증상
- 환자의 체력과 치료 반응

을 종합하여 치료 강도와 조합을 조절한다.
