# 경옥고 구성·방의
전통 경옥고의 핵심 구성은 **인삼·생지황·복령·봉밀**입니다.

- 인삼: 보익의 중심축
- 생지황: 음혈·진액 방향
- 복령: 비위·수습의 조화
- 봉밀: 제형과 조화·윤택

`기·음·진액의 보익 + 비위의 조화 → 장기적인 회복·보익 방향`

개별 약재 연구와 완성 처방인 경옥고의 임상효과는 구분합니다.
