# 공진단 구성·방의
공진단은 여러 약재가 배합된 **복합 처방**입니다. 따라서 완성 처방의 임상연구 결과와 개별 구성약재의 연구를 구분합니다.

`환자의 허손·피로 양상 → 처방 전체의 보익·조화 방향 → 구성 약재의 역할 → 전체 방의`

출전·제형·구성·용량과 실제 조제품의 차이도 구분해서 기록하는 것이 중요합니다.
