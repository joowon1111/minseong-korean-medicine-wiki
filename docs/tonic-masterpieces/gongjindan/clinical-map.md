# 공진단 임상 활용 지도
`피로·기력저하 → 빈혈·갑상선·수면장애·감염후상태 등 원인평가 → 허손·기혈음양 평가 → 처방 방향 판단 → 복용 → 피로·활동·수면·사회기능 추적`

모든 피로를 공진단 하나로 연결하지 않고 피로의 원인과 병증을 먼저 평가합니다.
