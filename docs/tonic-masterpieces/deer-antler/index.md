# 녹용 심화 {#_1}
녹용은 아직 골화되지 않은 성장기 사슴뿔을 약용하는 동물성 한약재입니다. 전통적으로 보신양·익정혈·강근골 등의 방향으로 활용되어 왔습니다.

현대 리뷰에서는 단백질·펩타이드·성장 관련 인자·다당류·아미노산·지질·무기질 등 복합 성분과 면역·항산화·재생·신경·근골격 관련 작용이 연구되고 있습니다.

**핵심:** 기원·부위·품질 → 전통 본초학 → 성분·기전 → 사람 임상근거 → 처방 속 역할.
