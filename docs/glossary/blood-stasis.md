# 어혈(瘀血)

**어혈의 증상·주요 변증·처방·치료를 함께 보려면 [어혈 전체 안내](../diagnostics/blood-stasis.md)를 확인하세요.** 이 문서는 용어의 뜻을 간단히 정리합니다.

## 정의
어혈은 혈의 운행이 원활하지 않거나 정체된 병리 상태를 설명하는 한의학적 개념이다.

## 임상적 이해
고정된 자통, 오래된 통증, 자색의 변화, 혈괴 등의 특징이 전통적으로 논의된다.

    이 개념은 전통 한의학의 생리·병리 언어다. 현대 의학의 특정 질환이나 검사수치와 단순히 동일시하기보다 변증과 처방의 맥락 속에서 이해한다.
