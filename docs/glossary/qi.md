# 기(氣)

## 정의
기는 한의학에서 인체의 생명활동을 추동하고 온후·방어·고섭·기화하는 **기능적 동력**을 설명하는 핵심 개념이다.

## 임상적 이해
기허는 쉽게 피로하고 힘이 없으며 활동 후 더 지치는 등의 증후와 연결해 설명된다.
