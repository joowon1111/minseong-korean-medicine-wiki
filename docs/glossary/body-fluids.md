# 진액(津液)

## 정의
진액은 인체의 정상적인 수액을 설명하는 한의학 개념으로 피부·근육·장부를 자윤하고 정상적인 생리활동을 돕는다.

## 임상적 이해
진액이 부족하면 구갈·건조감 등으로 나타날 수 있고, 운화가 원활하지 않으면 담음·수습 같은 병리적 상태와 연결된다.
