# 신양(腎陽)

## 정의
신양은 신의 온후·추동·기화 작용을 설명하는 개념으로, 생명활동의 따뜻한 동력과 수액대사·생식·근골 기능 등과 연결된다.

## 임상적 이해
신양이 허하면 냉감, 허약, 요슬산연, 수액대사 저하 등의 증후와 연관해 설명한다.
