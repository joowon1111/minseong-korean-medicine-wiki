# 한의학 용어사전

한의학 용어는 현대 의학의 한 단어와 단순 대응하기보다 **이론·변증·처방·본초가 서로 연결되는 개념**으로 이해하는 것이 좋다.

| 용어 | 핵심 의미 | 연결 |
|---|---|---|
| [기(氣)](qi.md) | 생명활동의 기능적 동력 | 기허·보기약 |
| [혈(血)](blood.md) | 영양·자윤과 정신활동의 물질적 기반 | 혈허·보혈약 |
| [정(精)](essence.md) | 성장·발육·생식과 근본적 저장 | 녹용·공진단 |
| [진액(津液)](body-fluids.md) | 인체의 정상적인 체액과 자윤 | 생지황·맥문동 |
| [담음(痰飮)](phlegm-fluid.md) | 진액대사 이상에서 형성되는 병리적 산물 | 반하·온담탕 |
| [어혈(瘀血)](blood-stasis.md) | 혈행의 정체를 설명하는 병리 개념 | 당귀·천궁 |
| [신양(腎陽)](kidney-yang.md) | 신의 온후·추동 기능 | 녹용·육계 |
| [심비양허](heart-spleen-deficiency.md) | 심혈과 비기의 부족이 함께 나타나는 변증 | 귀비탕 |
| [중기하함](sinking-middle-qi.md) | 비위의 기가 허해 승거 기능이 떨어진 변증 | 보중익기탕 |

## 읽는 원칙
이 용어들은 전통 한의학의 생리·병리 언어이며 현대의 특정 검사수치나 질환명과 일대일로 대응하지 않는다. 이 아카이브에서는 용어를 실제 본초·방제·고전과 연결해 이해하도록 구성한다.
