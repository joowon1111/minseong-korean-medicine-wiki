# 한약·침구 치료 전 확인사항

치료 선택 전에는 증상과 변증뿐 아니라 **응급·중증 질환 가능성, 안전성과 병용치료에 영향을 줄 정보, 치료 후 관찰 계획**을 함께 확인한다. 아래 항목은 문진을 대신하는 자가 체크표가 아니라 진료 정보를 빠짐없이 공유하기 위한 틀이다.

## 1. 치료 전에 공통으로 확인할 것

| 영역 | 확인 내용 |
|---|---|
| 현재 문제 | 시작 시점, 악화·완화 요인, 중증도, 기능 제한, 동반 증상 |
| 의학적 평가 | 기존 진단, 최근 검사·영상 결과, 수술·입원력, 현재 치료계획 |
| 복용·사용 중인 것 | 처방약, 일반약, 한약, 건강기능식품, 외용제의 실제 이름·용량·횟수 |
| 과민반응 | 약물·식품·금속·라텍스·접착제·소독제·주사 후 반응 |
| 출혈·회복 | 항응고·항혈소판제, 출혈질환, 멍·출혈 경향, 당뇨와 상처 회복 |
| 임신·수유 | 임신 가능성·주수, 수유 여부, 관련 진료와 복용약 |
| 과거 경험 | 침·주사·채혈 실신, 약침 반응, 화상·피부손상, 한약 이상반응 |

기존 의약품은 임의로 중단하지 않는다. 치료를 추가하거나 변경할 때 기존 진료계획과의 관계, 추적검사와 연락 기준을 함께 정한다.

## 2. 먼저 의학적 평가가 필요한 신호

새로운 마비·근력저하, 배뇨·배변 장애, 의식 변화, 심한 흉통·호흡곤란, 지속되는 고열, 급격한 탈수·출혈, 갑작스럽고 매우 심한 두통이나 복통처럼 응급질환이 의심되는 증상은 한의치료 선택보다 신속한 평가가 우선이다.

증상군별 세부 기준은 [임상 안전·감별 허브](index.md), [통증 위험신호](pain-red-flags.md), [두통·어지럼 감별](headache-dizziness.md), [소화기 위험신호](digestive-red-flags.md)에서 확인한다.

## 3. 치료별 추가 확인

| 치료 | 추가로 확인할 내용 |
|---|---|
| 한약 | 간·신장 기능, 혈압·혈당 등 추적 항목, 구성·용량·제형, 병용약과 중복 성분, 복약 가능성 |
| 침 | 시술부위 피부 상태, 출혈 위험, 실신 병력, 자세 유지 가능성, 해부학적 고위험 부위 |
| 약침 | 제품·성분·투여경로·용량, 알레르기·과민반응, 응급대응 체계 |
| 부항 | 피부 취약성·감각저하, 출혈 위험, 감염·상처, 예상되는 자국과 관리법 |
| 뜸 | 화상 위험, 감각저하, 연기·냄새 민감성, 호흡기 상태, 시술부위 피부 상태 |
| 추나·수기 | 골절·탈구·중증 골다공증·신경학적 이상 가능성, 최근 수술·외상, 금기 동작 |
| 초음파 유도 시술 | 목표 구조와 접근 경로, 무균술, 시술 전 영상소견, 시술 후 신경·혈관 상태 |

## 4. 치료 직전과 직후

### 직전

- 환자·치료부위·치료내용·좌우를 다시 확인한다.
- 오늘의 상태 변화, 식사·수분, 새로 시작하거나 중단한 약을 확인한다.
- 기대할 수 있는 반응, 흔한 불편, 드물지만 중요한 이상반응과 대처를 설명한다.
- 동의 여부와 중단 요청 방법을 확인한다.

### 직후

- 어지럼, 식은땀, 호흡곤란, 과도한 출혈·통증, 피부반응을 확인한다.
- 치료 전 정한 통증·기능·증상 지표를 같은 방식으로 재평가한다.
- 귀가 후 관찰할 증상, 연락할 기준, 응급평가가 필요한 기준을 안내한다.
- 다음 평가 시점과 복용·생활관리 계획을 기록한다.

## 5. 기록에 남길 최소 항목

| 구분 | 기록 내용 |
|---|---|
| 판단 | 진단·변증, 위험신호 확인, 치료 목표와 대안 |
| 중재 | 처방 구성·용량 또는 혈위·깊이·자극법·시술부위 |
| 병용 | 의약품·건강기능식품·다른 치료와 조정 내용 |
| 반응 | 객관·주관 지표, 이상반응, 환자의 이해와 동의 |
| 계획 | 추적시점, 검사, 중단·변경 기준, 의뢰·협진 계획 |

환자에게는 [복용약 종류별 준비표](../conditions/herbal-consultation-prep.md#medicine-check)와 [검사결과 준비표](../conditions/herbal-consultation-prep.md#test-results)를 안내합니다. 실제 약·제품 이름과 용량을 확인하고, 기존 처방약의 임의 중단 없이 병용 여부와 추적 계획을 상담합니다.
