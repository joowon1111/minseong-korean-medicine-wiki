# 한의 임상 안전성 허브

안전성은 치료 뒤에 덧붙이는 주의문이 아니라 **임상추론의 앞단과 전 과정**에 포함됩니다.

```text
위험신호 확인
 → 치료 적합성·금기·주의 평가
 → 한약·침구·약침의 안전한 설계
 → 환자 설명과 동의
 → 효과·이상반응·새 증상 재평가
 → 유지 / 변경 / 중단 / 검사·의뢰
```

## 1. 먼저 확인할 전신 위험신호

| 신호 | 우선 고려할 방향 |
|---|---|
| 갑작스러운 흉통·호흡곤란·실신 | 심혈관·폐 응급질환 |
| 의식 변화·마비·언어장애·벼락두통 | 뇌혈관·중추신경 응급질환 |
| 고열·오한·전신쇠약·의식저하 | 중증 감염·패혈증 가능성 |
| 토혈·흑변·다량 출혈 | 위장관·혈관·혈액질환 |
| 지속 구토·섭취 불가·소변 감소 | 탈수·전해질 이상·폐색 가능성 |
| 설명되지 않는 체중감소·진행성 야간통 | 종양·만성 감염·전신질환 |
| 외상 뒤 변형·체중부하 불가 | 골절·탈구·중증 연부조직 손상 |
| 진행하는 근력저하·대소변 장애 | 척수·마미·중추신경 문제 |

위험신호가 있으면 한의학적 변증과 치료보다 활력징후, 검사·영상과 응급·전문과 의뢰를 우선합니다.

## 3. 치료 전 공통 확인

### 환자 상태

- 연령, 체중, 임신·수유와 임신 가능성
- 간·신장·심혈관·혈액질환, 당뇨와 면역저하
- 최근 수술·항암·방사선치료와 감염 상태
- 음식·약물·금속·소독제·약침 알레르기
- 어지럼·실신 과거력과 식사·수분 섭취 상태

### 복용약과 치료

| 약물·치료 | 확인 이유 |
|---|---|
| 항응고·항혈소판제 | 자침·부항의 출혈·혈종 위험 |
| 혈압·당뇨약 | 어지럼·저혈압·저혈당과 한약 병용 |
| 수면제·진정제 | 진정·낙상과 중복 작용 |
| 면역억제제·항암제 | 감염·골수억제·상처회복과 상호작용 |
| 스테로이드 | 감염·혈당·위장관·골 상태 |
| 건강기능식품 | 출혈·간독성·중복 성분 가능성 |

→ [한약·침구 치료 전 체크리스트](treatment-checklist.md)

## 4. 한약 안전성

| 확인 항목 | 구체적 내용 |
|---|---|
| 약재 | 정확한 기원·동정, 품질검사와 보관 |
| 법제 | 독성·자극성을 줄이기 위한 적절한 가공 |
| 처방 | 변증·체력·소화력에 맞는 구성과 용량 |
| 제형 | 탕·환·산·고·과립의 노출량과 복용법 |
| 장기기능 | 간·신장 기능과 체액·전해질 상태 |
| 병용약 | 약동·약력학적 상호작용과 중복 작용 |
| 특수상황 | 임신·수유·소아·노인·수술 전후 |

### 복용 중 확인할 변화

- 발진·가려움·입술·얼굴 부종과 호흡 불편
- 지속되는 구역·구토·복통·설사
- 심한 무기력, 황달, 짙은 소변, 전신 가려움
- 부종·소변량 변화·근육경련
- 두근거림·어지럼·혈압과 혈당의 변화

중대한 알레르기나 간·신장 이상이 의심되면 복용을 중단하고 평가합니다. 장기 복용이나 위험요인이 있으면 필요한 혈액검사를 계획합니다.

## 5. 침·전침 안전성

### 시술 전

- 피부 감염·상처와 시술 부위의 해부학적 구조
- 출혈질환·항응고제와 멍·혈종 위험
- 흉곽·목·복부·척추 주변의 자침 깊이와 방향
- 임신, 감각저하와 심박조율기 등 전기장치
- 침 공포·실신 과거력과 공복 상태

### 시술 중·후

| 반응 | 대응 방향 |
|---|---|
| 창백·식은땀·메스꺼움·어지럼 | 시술 중단, 눕히고 활력·회복 확인 |
| 지속되는 전격통·감각이상 | 자극 중단과 신경학적 평가 |
| 흉통·호흡곤란·기침 | 기흉 등 합병증 가능성 응급평가 |
| 빠르게 커지는 출혈·부종 | 압박 지혈과 혈관 손상 평가 |
| 발적·열감·고름·발열 | 감염 평가와 치료 |

→ [침구치료 안전·위험신호](../acupuncture-integrated/safety.md)

## 6. 약침 안전성

약침은 자침 안전성에 더해 제제와 주입에 관한 확인이 필요합니다.

- 제제의 성분·기원·조제 과정과 추적성
- 보관·유효기간과 무균 상태
- 알레르기·아나필락시스 과거력
- 주입 부위의 혈관·신경·관절·흉복강 구조
- 1회 용량, 농도·주입층과 양측 총량
- 시술 후 국소 통증·발적·부종과 전신 반응

전신 두드러기, 입술·혀 부종, 호흡곤란, 혈압 저하는 아나필락시스 가능성이 있으므로 즉시 응급대응합니다.

## 7. 뜸·부항·온열치료

| 치료 | 핵심 주의 |
|---|---|
| 뜸 | 화상·연기 노출, 감각저하·당뇨병성 신경병증 |
| 건식부항 | 피부손상·수포, 과도한 음압과 시간 |
| 습식부항 | 출혈·감염관리, 항응고제와 빈혈 |
| 온열치료 | 급성 염증·감각저하·혈관질환과 저온화상 |

강한 자반·열감·통증을 치료효과의 크기로 해석하지 않습니다.

## 8. 특수상황

### 임신·수유

임신 주수, 고위험 임신 여부, 복용약과 산부인과 치료를 확인합니다. 자궁수축 가능성이 우려되는 강한 자극, 복부·요천부 시술과 한약 안전성을 개별적으로 검토합니다.

### 소아

체중·연령에 맞는 용량과 자극량을 적용하고 보호자에게 복용·시술 후 관찰사항을 설명합니다. 지속 고열, 탈수, 호흡곤란과 의식 변화는 즉시 소아 진료가 우선입니다.

### 노인·허약 환자

다약제 복용, 낙상·저혈압, 신장기능, 영양과 인지 상태를 살핍니다. 작은 변화도 이상반응 또는 급성질환의 초기 신호일 수 있습니다.

### 수술·암 치료 전후

수술 일정, 상처·감염, 혈구수치, 항응고제와 항암치료 주기를 확인하고 담당 의료진의 계획과 조율합니다.

## 9. 설명·동의와 기록

치료 목적, 방법, 기대되는 경과, 흔한 일시적 반응과 중요한 이상반응, 대안과 중단 기준을 이해하기 쉽게 설명합니다.

기록에는 다음을 포함합니다.

- 치료 전 증상·기능과 활력·위험요인
- 사용한 처방·약재·제형·용량 또는 시술 부위·방법
- 약침 제제·용량·로트 등 추적 정보
- 즉시 반응, 이상반응과 대응
- 다음 평가 시점과 환자에게 안내한 주의사항

## 10. 효과와 안전성을 함께 재평가

| 경과 | 판단 |
|---|---|
| 효과가 있고 이상반응 없음 | 유지 후 치료 강도·간격 조절 |
| 효과는 있으나 불편한 반응 | 용량·제형·자극량 또는 치료수단 변경 |
| 효과가 없고 상태 안정 | 진단·변증·치료량과 순응도 재검토 |
| 새로운 증상·기능 악화 | 치료 중단·검사·의뢰 검토 |
| 위험신호·중대한 이상반응 | 즉시 응급대응과 보고·추적 |
