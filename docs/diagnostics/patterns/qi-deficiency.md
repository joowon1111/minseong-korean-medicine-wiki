# 기허(氣虛) 변증 지도

기허는 **쉽게 지치고 회복력이 떨어지는 양상**을 설명하는 허증입니다. 이 문서는 동반 증상에 따라 관련 변증·처방·경혈을 찾는 안내입니다. 기허의 뜻과 진찰 과정, 약재 배합은 [기허 본문](../qi-deficiency.md)에서 설명합니다.

## 임상 단서
쉽게 지침·활동 후 탈진·식욕저하·숨이 짧음·자한·회복저하 등을 전체적으로 봅니다.

## 감별

| 함께 나타나는 불편 | 비교할 변증·진료 자료 |
|---|---|
| 어지럼·창백·건조·얕은 잠 | [기허·혈허·기혈양허 비교](../differentials/qi-vs-blood-vs-qi-blood.md) |
| 두근거림·불면·건망과 식욕저하 | [심비양허](../../concepts/heart-spleen-deficiency.md) |
| 허리·무릎 무력과 배뇨·냉열 변화 | [신허](kidney-deficiency.md) |
| 일어설 때 아찔함과 무력감 | [기립성 어지럼의 혈압·맥박 평가](../../conditions/orthostatic-dizziness.md#standing-vitals) |
| 활동 다음 날까지 이어지는 심한 피로 | [활동 후 악화와 회복 관리](../../conditions/chronic-fatigue.md#post-exertional-malaise) |

## 본초·방제

[인삼](../../herbs/ginseng.md)·[황기](../../herbs/astragalus.md)·[백출](../../herbs/atractylodes.md)·[복령](../../herbs/poria.md)의 배합 역할과 사군자탕·육군자탕·보중익기탕·귀비탕·옥병풍산의 차이는 [기허 본문의 처방 비교](../qi-deficiency.md#관련-방제)에서 확인할 수 있습니다.

기허와 혈허가 함께 나타날 때의 팔물탕·십전대보탕 배합은 [기혈양허](qi-blood-deficiency.md)로 이어집니다.
