# 장부변증

장부변증은 사진으로 얻은 증후를 **간·심·비·폐·신과 육부의 기능 변화**를 중심으로 종합하는 한의학의 대표적인 변증 체계다.

## 간
간의 소설·장혈 기능과 관련해 간기울결, 간혈허, 간양상항 등의 변증을 논한다.

→ [간](../foundations/liver.md)

## 심
심의 주혈맥·장신 기능과 관련해 심기허, 심혈허, 심화 등의 변증을 논한다. 심혈과 비기가 함께 부족하면 [심비양허](../glossary/heart-spleen-deficiency.md)로 연결할 수 있다.

→ [심](../foundations/heart.md)

## 비
비의 운화·승청·통혈 기능을 중심으로 비기허, 비양허, 중기하함 등을 본다.

→ [비](../foundations/spleen.md)  
→ [보중익기탕](../formulas/buzhong-yiqi-tang.md)

## 폐
폐의 주기·선발숙강 기능을 중심으로 폐기허, 폐음허, 풍한범폐, 담습조폐 등을 구분한다.

→ [폐](../foundations/lung.md)

## 신
신의 장정·주수·납기 기능을 중심으로 신음허, [신양](../glossary/kidney-yang.md)허, 신정부족 등을 본다.

→ [신](../foundations/kidney.md)

## 변증은 서로 연결된다
장부변증은 장부 하나만 따로 보는 체계가 아니다.

```text
사진
 ↓
팔강으로 큰 성질 파악
 ↓
기혈진액의 상태 확인
 ↓
장부 기능과 연결
 ↓
치법·본초·방제·침구 선택
```

예를 들어 피로·식욕저하·불면·심계가 함께 나타나면 비기와 심혈의 관계를 살펴 심비양허의 가능성을 검토할 수 있다.

→ [팔강변증](eight-principles.md)  
→ [기혈진액변증](qi-blood-fluid-patterns.md)
