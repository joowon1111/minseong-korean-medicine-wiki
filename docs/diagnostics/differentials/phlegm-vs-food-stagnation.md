# 담음 vs 식적

| 항목 | 담음 | 식적 |
|---|---|---|
| 경과 | 반복·만성 경향 | 과식·특정 음식 후 뚜렷 |
| 증상 | 오심·가래·어지럼·흉민 | 트림·신물·복만·대변 변화 |
| 기반 | 비위허와 자주 결합 | 음식 정체가 중심 |
| 본초 | [반하](../../herbs/pinellia.md)·[진피](../../herbs/citrus-peel.md)·[복령](../../herbs/poria.md) | [산사](../../herbs/hawthorn.md)·신곡·[맥아](../../herbs/barley-malt.md) 계열 |
| 처방 | [이진탕](../../formulas/erchen-tang.md)·[육군자탕](../../formulas/liujunzi-tang.md) | [보화환](../../formulas/baohe-wan.md) 계열 |

반복·만성인지 과식 직후인지는 경향을 보는 단서입니다. 식적도 반복될 수 있고 담음도 급하게 드러날 수 있으므로, 시간 경과만으로 나누지 않습니다. 음식 정체에 비위허약·담습이 함께 나타나는지도 확인합니다.

## 경혈
담음: 풍륭 ST40 · 내관 PC6  
식적·복만: 중완 CV12 · 족삼리 ST36 · 천추 ST25
