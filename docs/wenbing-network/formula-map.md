# 온병학 대표 처방 구조

온병학 처방은 특정 병명보다 **위기영혈·삼초의 병증 구조와 치법**에 따라 이해하는 것이 핵심이다.

| 병증 단계·구조 | 대표 처방 예 |
|---|---|
| 위분 | 은교산·상국음 |
| 기분의 성열 | 백호탕 |
| 기분의 부실 | 승기탕류 |
| 영분 | 청영탕 |
| 열독이 성한 병증 | 청온패독음 등 |
| 습열·삼초 병증 | 병위와 습열 양상에 따른 처방군 |

```text
병증
 ↓
위기영혈 / 삼초
 ↓
치법
 ↓
대표 처방
```

이 표는 지식 탐색을 위한 기본 지도이며, 실제 처방 선택은 증후와 병위·병성의 종합 판단을 전제로 한다.
