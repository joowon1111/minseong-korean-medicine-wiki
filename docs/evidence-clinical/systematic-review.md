# 체계적 문헌고찰·메타분석 읽기
여러 연구를 합쳤다고 자동으로 높은 확실성의 결론이 되는 것은 아닙니다.

## 확인할 것
- 검색전략이 충분한가?
- 포함 연구의 질은?
- 서로 너무 다른 연구를 합치지 않았는가?
- 이질성(I² 등)은?
- 출판편향은?
- 효과크기와 신뢰구간은?
- GRADE 등 근거확실성 평가는?

```text
낮은 질의 연구 여러 개
          ↓
메타분석
          ≠
자동으로 높은 질의 근거
```
