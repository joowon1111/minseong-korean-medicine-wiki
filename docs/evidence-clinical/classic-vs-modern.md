# 고전근거와 현대근거
한의학에서는 전통 문헌과 현대 임상근거를 분리해서 읽는 것이 중요합니다.

## 고전 문헌이 주는 정보
- 전통적 병증
- 처방 구성과 활용 맥락
- 후대 임상 경험의 계보

## 현대 연구가 주는 정보
- 특정 대상군
- 비교군과 결과지표
- 효과크기
- 안전성
- 재현성·불확실성

```text
고전 적응 병증
        ≠
현대 특정 질환의 임상효과 확정
```

두 근거를 경쟁시키지 않고 **전통적 사용 맥락과 현대적 검증 수준을 병렬로 표시**합니다.
