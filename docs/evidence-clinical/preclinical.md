# 전임상·기전 연구 읽기
세포·동물·기전 연구는 **어떻게 작용할 수 있는지**를 탐색하는 데 유용합니다.

## 확인할 것
- 세포인지 동물인지
- 사용 용량이 사람에게 현실적인가
- 단일 성분인지 복합처방인지
- 실제 임상 결과와 연결되는가
- 반복 연구가 있는가

```text
항염 작용 관찰
 ↓
가능한 기전 제시
 ≠
사람에서 질환 치료효과 확정
```

전임상 결과를 임상효과처럼 표현하지 않는 것이 위키의 기본 원칙입니다.
