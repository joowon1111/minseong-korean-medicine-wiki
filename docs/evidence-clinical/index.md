# 근거의 임상 적용 심화

이 영역은 RCT와 메타분석의 정의를 반복하는 곳이 아니라, **좋은 연구 결과를 현재 환자에게 어떻게 적용하고 언제 유지·조정·중단할지** 판단하는 심화 자료입니다.

연구설계의 기본 개념은 [한의학 근거 읽는 법](../evidence-guide/index.md)에서 확인합니다.

## 연구에서 실제 진료로 옮기는 순서

1. 연구 질문과 결과를 확인합니다.
2. 연구 대상과 현재 환자의 진단·중증도·연령을 비교합니다.
3. 처방 구성·용량 또는 경혈·자극량을 비교합니다.
4. 환자의 병력·복용약·선호와 치료 목표를 반영합니다.
5. 증상·기능·안전성의 기준점을 기록합니다.
6. 재평가 시점을 정하고 유지·조정·전환·중단을 결정합니다.

## 연구 대상과 현재 환자 비교

| 연구에서 확인 | 실제 진료에서 확인 |
|---|---|
| 진단기준·중증도 | 현재 진단·검사·증상 기간 |
| 나이·성별·제외기준 | 고령·소아·임신·수술·만성질환 |
| 처방·경혈·시술 | 실제 구성·용량·제형·자극방법 |
| 병용치료 | 복용약·물리치료·운동·생활관리 |
| 치료기간 | 현실적으로 가능한 치료계획 |
| 결과지표 | 환자가 중요하게 생각하는 기능 목표 |
| 이상반응 | 알레르기·간신장 기능·출혈·감염 위험 |

## 효과크기를 환자 변화로 번역합니다

- 통증·두통일수·야간각성·배변불편이 얼마나 감소했는가
- 보행·가동범위·식사량·수면효율이 좋아졌는가
- 진통제와 증상완화제 사용이 줄었는가
- 업무·운동·가사와 일상생활 복귀에 도움이 되었는가
- 효과가 치료 종료 후에도 유지되었는가

## 한약과 침구 근거의 적용

### 한약

연구 처방과 실제 처방의 약미·구성비·가감·제형·1일 용량·복용기간, 현대 진단과 변증의 유사성, 병용약과 안전성을 함께 확인합니다.

→ [한약·처방 현대 임상근거](../authority/formulas/herbal-formula-evidence-hub.md)

### 침·전침·약침

치료 유형, 경혈·아시혈·국소 조직, 깊이·득기·전침 주파수와 강도, 치료횟수, 비교군, 기능결과와 이상반응을 함께 확인합니다.

→ [침·전침·약침 현대 임상근거](../evidence-integrated/acupuncture-evidence.md)

## 직접 근거가 적은 환자

고령자·소아·임신부·수술 후 환자·다약제 복용자·간신장 기능 저하 환자는 더 보수적인 용량과 자극량, 짧은 초기 재평가, 복용약·검사수치 확인, 이상반응 감시와 필요한 협진을 강화합니다.

## 재평가 계획

| 시점 | 확인 내용 |
|---|---|
| 치료 전 | 증상·기능·약물사용·환자의 우선 목표 |
| 초기 | 치료 반응·불편·이상반응·복용과 내원 부담 |
| 계획된 재평가 | 목표 달성·기능 회복·삶의 질 |
| 장기 | 유지 여부·재발 요인·생활관리 |
| 악화 시 | 진단 재검토·추가검사·의뢰·치료 중단 |
