# 한의학 연구의 해석 포인트

한의학 연구에서도 무작위배정, 비교군, 결측치, 효과 크기와 안전성 같은 일반 임상연구 원칙이 먼저 적용된다. 여기에 **진단 과정과 치료 내용이 재현 가능한지, 개인화된 임상 의사결정을 얼마나 충실히 담았는지**를 추가로 본다.

## 한약

| 확인 항목 | 구체적으로 볼 내용 |
|---|---|
| 처방 정체성 | 원방·후대방·연구용 조성 중 무엇이며 가감 범위가 있는가? |
| 구성 | 각 약재명, 기원식물·약용부위, 포제, 배합비가 제시됐는가? |
| 제조·품질 | 탕전·추출·농축법, 제형, 제조기관, 배치와 품질관리 정보가 있는가? |
| 투여 | 1회·1일 용량, 횟수, 기간, 복약순응도를 알 수 있는가? |
| 진단 | 병명과 변증을 어떻게 결합했고 처방 선택·가감 규칙이 명확한가? |
| 병용치료 | 의약품, 건강기능식품, 침·재활·생활관리를 군별로 확인했는가? |

같은 처방명이라도 구성·용량·제형이 다르면 동일한 중재로 보기 어렵다. 반대로 임상적 가감을 모두 배제해야 좋은 연구인 것은 아니다. 가감의 허용 범위와 결정 규칙을 사전에 정하고 실제 시행 내용을 보고하면 개인화 치료도 평가할 수 있다.

## 침 {#acupuncture}

- 경혈 선택의 이론적·임상적 근거와 필수혈·선택혈은 무엇인가?
- 자침 위치, 깊이·방향, 침 규격, 수기법, 득기, 유침시간을 알 수 있는가?
- 회당 자극량, 주당 빈도, 전체 횟수와 치료기간이 명확한가?
- 전침·온침·뜸 등 추가 자극과 병행치료가 기술됐는가?
- 시술자의 교육·경력과 치료 충실도를 확인했는가?
- 대조시술이 생리적으로 완전히 비활성이라고 가정하지 않았는가?

대기군과의 비교는 전체 치료 패키지의 효과를, 일반치료에 추가한 비교는 추가 이득을, 가짜침 비교는 특정 자침 요소의 차이를 주로 묻는다. 서로 다른 비교군의 결과는 같은 의미로 합치지 않는다. 침 임상시험의 중재 보고는 [STRICTA 체크리스트](https://www.equator-network.org/reporting-guidelines/consort-stricta/)를 참고할 수 있다.

## 사상의학

- 체질진단에 사용한 면담·체형·용모·성정·설문·전문가 합의 방법은 무엇인가?
- 진단자 수, 교육 수준, 불일치 처리와 진단 신뢰도를 보고했는가?
- 체질명뿐 아니라 소증, 현재 증상, 표리·순역과 병증 중증도를 기록했는가?
- 체질과 병증에 따른 처방 선택·가감·변경 기준이 명확한가?
- 치료 중 소증과 병증을 어떤 시점에 다시 평가했는가?

사상체질은 단일 검사값처럼 다루기보다 진단 과정 전체를 기술해야 한다. 특정 체질 하위군 결과는 표본수가 충분하고 사전에 계획됐는지 확인한 뒤 해석한다.

## 고전 처방과 연구 중재를 연결하는 법

| 층위 | 기록할 내용 |
|---|---|
| 전통 원전 | 출전, 원문 적응 맥락, 구성과 원래 제법 |
| 현대 제제 | 실제 원료, 제조·제형, 용량과 품질관리 |
| 임상 적용 | 대상 환자, 변증·체질, 가감과 병행치료 |
| 연구 결과 | 비교군, 결과지표, 시점, 효과 크기와 이상반응 |

이 층위를 분리해 기록하면 전통 지식을 현대 연구와 단절시키지 않으면서도, 어떤 제품과 어떤 환자에게 관찰된 결과인지 분명히 할 수 있다.

## 보고 완결성과 효과 판단은 구분한다

[CONSORT 2025](https://www.consort-spirit.org/)와 STRICTA 같은 보고지침은 독자가 중재와 결과를 평가하도록 돕는다. 체크리스트를 충실히 작성했다는 사실만으로 효과가 입증되거나 모든 편향이 제거되는 것은 아니다. 반대로 세부 보고가 부족하면 긍정적인 결과가 있어도 재현과 임상 적용 범위를 판단하기 어렵다.
