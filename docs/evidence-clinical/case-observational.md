# 증례·관찰연구 읽기
## 증례보고
새로운 임상현상·적용 가능성을 보여주지만 비교군이 없어 자연경과·동시치료·플라세보 효과를 분리하기 어렵습니다.

## 관찰연구
실제 진료현장의 사용패턴·예후·안전성을 볼 수 있지만 교란요인과 선택편향의 영향을 받을 수 있습니다.

## 해석
`증례에서 좋아졌다 → 모든 환자에게 효과 있다`로 확대하지 않습니다.

대신:
- 어떤 환자였는가?
- 어떤 병증이었는가?
- 다른 치료를 같이 했는가?
- 결과를 어떻게 측정했는가?
를 기록합니다.
