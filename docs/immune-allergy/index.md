# 면역·알레르기·만성염증·회복 지식망

면역·알레르기·회복은 현대의학적 개념이고, 한의학의 폐·비위·기혈·진액·위기 개념과 완전히 같은 것은 아니다. 다만 실제 임상에서는 **비염·피로·소화·통증·회복력 저하가 함께 나타나는 양상**을 종합적으로 살펴볼 수 있다.

면역은 단순히 높이고 낮추는 하나의 힘이 아닙니다. 선천면역·적응면역·면역조절·염증 해소가 서로 균형을 이루며 감염 방어와 조직 회복을 담당합니다. 이 균형이 오래 흔들리면 만성 저등급 염증이 혈관·대사·신경계와 연결될 수 있지만, CRP·ESR 한 번의 수치만으로 특정 질환을 진단하지는 않습니다.

```text
      ↓

      ↓

```
