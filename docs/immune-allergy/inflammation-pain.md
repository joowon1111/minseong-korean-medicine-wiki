# 염증·통증과 회복의 한의학적 지식망

통증은 조직 손상·기계적 부하·염증 반응·신경계 요인 등 여러 요소와 관련된다. 한의학에서는 통증의 위치·성질·급만성·허실을 살펴 **어혈·풍한습비·기혈허·허손** 등의 구조를 함께 본다.

```text
통증
├─ 어혈 → 활혈·통락
├─ 풍한습비 → 거풍습
└─ 오래된 허손 → 보간신·익기혈
```
