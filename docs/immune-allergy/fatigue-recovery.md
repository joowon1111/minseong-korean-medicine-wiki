# 피로·회복 저하의 한의학적 지식망

```text
피로·회복 저하
├─ 기허 → 인삼·황기
├─ 비위기허 → 사군자탕·육군자탕
├─ 기혈양허 → 십전대보탕
└─ 허손 → 녹용·공진단·경옥고
```
