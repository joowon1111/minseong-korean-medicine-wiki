# 피로·회복 저하의 한의학적 지식망

피로는 수면·소화·활동량·스트레스와 함께 변할 수 있다. 한의학에서는 **기허·비위기허·기혈양허·허손** 등의 구조를 살펴본다.

```text
피로·회복 저하
├─ 기허 → 인삼·황기
├─ 비위기허 → 사군자탕·육군자탕
├─ 기혈양허 → 십전대보탕
└─ 허손 → 녹용·공진단·경옥고
```
