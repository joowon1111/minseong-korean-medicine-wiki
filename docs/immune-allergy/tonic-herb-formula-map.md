# 보익 본초·방제 연결 지도

| 보익의 방향 | 핵심 본초 | 구성·감별을 볼 처방 |
|---|---|---|
| 보기·건비 | [인삼](../herbs/ginseng.md)·[백출](../herbs/atractylodes.md)·[복령](../herbs/poria.md) | [사군자탕](../formulas/sijunzi-tang.md) · [육군자탕](../formulas/liujunzi-tang.md) |
| 보기·고표 | [황기](../herbs/astragalus.md)·백출·[방풍](../herbs/saposhnikovia.md) | [옥병풍산](../formulas/yupingfeng-san.md) |
| 중기·회복 | 황기·인삼·[당귀](../herbs/angelica.md) 등 | [보중익기탕](../formulas/buzhong-yiqi-tang.md) |
| 기혈양허 | 보기약과 당귀·작약·숙지황 등의 양혈 배합 | [십전대보탕](../formulas/shi-quan-da-bu-tang.md) · [인삼양영탕](../formulas/renshen-yangrong-tang.md) |
| 기음·진액 | 인삼·[맥문동](../herbs/ophiopogon.md)·[오미자](../herbs/schisandra.md) | [생맥산](../formulas/shengmai-san.md) |
| 허손·회복의 개별화 | [녹용](../herbs/cervi-parvum-cornu.md)과 처방 전체의 배합 | [공진단](../formulas/gongjin-dan.md) · [맞춤 한약](../conditions/custom-herbal-medicine.md) |
| 진액·허약의 배합 | 인삼·생지황·복령·꿀 | [경옥고](../formulas/gyeongok-go.md) |

보익은 모든 사람의 면역을 같은 방향으로 높이는 치료가 아닙니다. 식사·수면·땀·건조·냉열과 회복 양상을 보고 필요한 방향을 정합니다.
