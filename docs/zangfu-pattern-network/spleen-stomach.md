# 비·위 병증

비·위 병증에서는 소화·흡수, 식욕, 복창, 대변, 담습, 기의 승강 등을 중심으로 살핀다.

대표적인 병증 예:
- 비기허
- 비양허
- 비불통혈
- 중기하함
- 한습곤비
- 습열온비
- 위음허
- 위열 등

```text
식욕·복창·대변·피로
        ↓
      비·위
        ↓
기허 / 양허 / 담습 / 습열 / 위열
        ↓
      치법·처방
```

→ [본초·방제](../portal/herbs-formulas.md)

## 주요 비·위 병증 비교

| 병증 | 핵심 증후 조합 | 설·맥에서 참고하는 방향 | 치법 방향 |
|---|---|---|---|
| 비기허 | 식욕저하·식후피로·복창·묽은 변·무력 | 설담, 태백, 맥허 | 건비익기 |
| 비양허 | 비기허 + 복부냉통·사지냉·부종 | 설담반, 맥침지 | 온양건비 |
| 중기하함 | 기허 + 처짐·탈항·장기 하수감·만성 설사 | 설담, 맥허약 | 보중익기·승양거함 |
| 비불통혈 | 비기허 + 멍·코피·월경과다 등 출혈 | 설담, 맥세약 | 익기섭혈 |
| 한습곤비 | 몸과 머리의 무거움·오심·복창·묽은 변 | 태백니, 맥유완 | 온화한습·건비 |
| 습열온비 | 몸 무거움·복창·구고·황색 분비·끈적한 변 | 태황니, 맥유삭 | 청열화습 |
| 위열 | 속쓰림·다식·구취·갈증·잇몸 불편 | 설홍, 태황, 맥삭 | 청위사화 |
| 위음허 | 공복 불편·구건·마른구역·변비 | 설홍소진, 맥세삭 | 양위생진 |
| 위기상역 | 구역·구토·트림·딸꾹질·역류 | 원인 병기에 따름 | 화위강역 |

## 감별의 핵심

- **비기허와 식적:** 평소 기능 저하가 중심인지, 과식 뒤 팽만·트림·후중이 중심인지 봅니다.
- **한습과 습열:** 냉감·묽고 맑은 분비물인지, 열감·구고·황니태가 뚜렷한지 비교합니다.
- **위열과 위음허:** 실열과 과도한 식욕이 중심인지, 건조·허열과 위의 윤택 부족이 중심인지 구분합니다.
- 체중 감소, 토혈·흑변, 연하곤란, 지속 구토, 심한 야간통은 우선 검사가 필요합니다.

## 장부 관계

- **간비불화·간위불화:** 긴장과 정서 변화가 소화·역류·복통을 악화
- **비폐기허:** 피로·식욕저하와 숨참·잦은 감기가 함께 나타남
- **비신양허:** 만성 설사·냉감·부종·요슬 무력이 함께 나타남
