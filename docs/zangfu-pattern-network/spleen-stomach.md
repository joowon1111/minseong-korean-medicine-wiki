# 비·위 병증

비·위 병증에서는 소화·흡수, 식욕, 복창, 대변, 담습, 기의 승강 등을 중심으로 살핀다.

대표적인 병증 예:
- 비기허
- 비양허
- 비불통혈
- 중기하함
- 한습곤비
- 습열온비
- 위음허
- 위열 등

```text
식욕·복창·대변·피로
        ↓
      비·위
        ↓
기허 / 양허 / 담습 / 습열 / 위열
        ↓
      치법·처방
```
