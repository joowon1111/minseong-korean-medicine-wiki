# 신·방광 병증

신·방광 병증에서는 생장·발육·생식, 수액대사, 요슬, 이명, 배뇨와 관련된 증후를 함께 살핀다.

대표적인 병증 예:
- 신양허
- 신음허
- 신정휴손
- 신기불고
- 신불납기
- 방광습열 등

```text
요슬산연·이명·배뇨·생식·호흡
             ↓
           신·방광
             ↓
양허 / 음허 / 정허 / 기불고 / 습열
             ↓
          치법·처방
```
