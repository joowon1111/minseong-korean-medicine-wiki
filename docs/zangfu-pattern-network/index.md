# 장부변증 핵심 지식망

장부변증은 환자의 증상과 소견을 **간·심·비·폐·신과 담·소장·위·대장·방광 등 장부 기능의 병리 변화**로 구조화하는 대표적인 한의학 변증 체계다.

```text
증상·맥·설·병력
        ↓
장부 기능의 변화
        ↓
간·심·비·폐·신 / 육부
        ↓
한열·허실·기혈진액
        ↓
치법·처방
```

## 증상군에서 장부로 찾기

| 주된 증상군 | 먼저 살필 장부 기능 | 함께 비교할 병증 |
|---|---|---|
| 옆구리 답답함·근긴장·월경 변화 | 간·담 | 간기울결, 간화, 간혈허, 담울 |
| 두근거림·불면·건망·흉민 | 심·소장 | 심기허, 심혈허, 심음허, 심화 |
| 식욕저하·복창·묽은 변·피로 | 비·위 | 비기허, 비양허, 담습, 위열·위음허 |
| 기침·숨참·코·피부·대변 변화 | 폐·대장 | 폐기허, 폐음허, 외감, 담조폐, 대장진휴 |
| 허리·무릎 약화·이명·배뇨 변화 | 신·방광 | 신양허, 신음허, 신정허, 신기불고, 방광습열 |

## 장부변증의 기본 원칙

1. 증상 하나를 장부 하나에 바로 연결하지 않습니다.
2. 현대의학적 장기 질환과 전통 장부병증을 동일시하지 않습니다.
3. 주증·동반증상·경과·설맥과 표리·한열·허실을 함께 봅니다.
4. 중심 장부와 영향을 주고받는 장부를 구분합니다.
5. 치료 뒤 주증뿐 아니라 식사·수면·대소변·활동의 변화를 재평가합니다.
