# 장부변증에서 치법으로

장부변증의 목적은 장부명을 붙이는 데서 끝나는 것이 아니라 **구체적인 치료 방향을 정하는 것**이다.

```text
장부
 ↓
허·실·한·열
 ↓
기·혈·음·양·담습·어혈 등
 ↓
치법
 ↓
방제·본초·침구
```

예:
- 비기허 → 건비익기의 방향
- 간기울결 → 소간이기의 방향
- 폐음허 → 자음윤폐의 방향
- 신양허 → 온보신양의 방향

## 장부별 대표 치법 지도

| 장부 | 병증 | 치법 | 치료에서 확인할 목표 |
|---|---|---|---|
| 간 | 간기울결 | 소간이기·해울 | 흉협창만, 근긴장, 소화·월경의 변동성 |
| 간 | 간혈허·간음허 | 보혈양간·자양간음 | 눈·근육·월경, 현훈·건조·허열 |
| 심 | 심기·심양허 | 익기양심·온보심양 | 두근거림, 흉민, 활동·냉감 |
| 심 | 심혈·심음허 | 보혈양심·자음안신 | 수면, 건망, 어지럼·도한 |
| 비 | 비기허·중기하함 | 건비익기·승양거함 | 식욕, 대변, 피로, 처짐 |
| 위 | 위열·위음허 | 청위·양위생진 | 속쓰림, 갈증, 공복 불편·건조 |
| 폐 | 폐기허·폐음허 | 익폐고표·자음윤폐 | 숨참, 기침, 땀, 인후 건조 |
| 신 | 신양허·신음허 | 온보신양·자음보신 | 요슬, 배뇨, 냉감 또는 허열 |
| 방광 | 방광습열 | 청열이습·통림 | 빈뇨·요급·배뇨통과 소변 양상 |

## 치법을 처방으로 바로 바꾸지 않는 이유

같은 건비익기라도 담습, 기체, 중기하함, 출혈이 함께 있는지에 따라 방제 구조가 달라집니다. 또한 체력·소화력·임신, 간·신장 기능, 복용약에 따라 본초의 용량과 제형을 조정해야 합니다.

```text
장부병증 → 치법 → 방제 구조 → 본초 배합 → 용량·제형 → 경과평가
```
