# 장부변증에서 치법으로

장부변증의 목적은 장부명을 붙이는 데서 끝나는 것이 아니라 **구체적인 치료 방향을 정하는 것**이다.

```text
장부
 ↓
허·실·한·열
 ↓
기·혈·음·양·담습·어혈 등
 ↓
치법
 ↓
방제·본초·침구
```

예:
- 비기허 → 건비익기의 방향
- 간기울결 → 소간이기의 방향
- 폐음허 → 자음윤폐의 방향
- 신양허 → 온보신양의 방향
