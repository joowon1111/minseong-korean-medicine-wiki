# 장부변증 통합 지도

```text
                 증상 정보
                    ↓
                 팔강변증
                    ↓
        ┌───────────┼───────────┐
      간·담        심·소장      비·위
        │             │           │
      폐·대장      신·방광     장부겸증
        └───────────┼───────────┘
                    ↓
          기혈·음양·담습·어혈
                    ↓
                   치법
                    ↓
             본초·방제·침구
```

장부변증은 팔강변증과 기혈진액변증을 이어 **증상에서 치료 방향으로 넘어가는 핵심 중간 지식망** 역할을 한다.
