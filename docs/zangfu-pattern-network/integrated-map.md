# 장부변증 통합 지도

```text
                 증상 정보
                    ↓
                 팔강변증
                    ↓
        ┌───────────┼───────────┐
      간·담        심·소장      비·위
        │             │           │
      폐·대장      신·방광     장부겸증
        └───────────┼───────────┘
                    ↓
          기혈·음양·담습·어혈
                    ↓
                   치법
                    ↓
             본초·방제·침구
```

장부변증은 팔강변증과 기혈진액변증을 이어 **증상에서 치료 방향으로 넘어가는 핵심 중간 지식망** 역할을 한다.

## 장부변증 통합 지도

장부변증은 장기의 해부학적 질환명과 동일한 개념이 아니라, **증상·기능·기혈진액·한열허실을 장부 기능체계로 해석하는 한의학적 틀**입니다.

비·위, 간·담, 심·소장, 폐·대장, 신·방광의 주요 병증을 서로 비교하고 치법·본초·방제로 연결합니다.
