# 요추 위치 확인·촉지 (SA2)

## 분류 {#_1}
**표면해부학적 위치 확인 자료** · 원본 자료 식별자 **SA2**

원본 CSV의 SA2 명칭은 공란입니다. **「요추 위치 확인·촉지」는 본문 내용을 요약한 편집 제목**이며 공식 경혈명이 아닙니다. SA2는 자료 식별자로 유지합니다.

## 해부학적 위치·구조 {#_2}

### 원본의 위치·구조 설명

1. 척추뼈 사이를 잡아야 할 때는 베개나 쿠션을 아랫배 밑으로 넣어주면 요추 사이가 벌어져서 촉지가 쉬워지고 환자도 편하게 된다.
2. 4번 요추 찾기: 위앞엉덩뼈가시(Anterior superior iliac spine, ASIS)에 각각 손을 얹고 엉덩뼈능선(iliac crest)의 가장 높은 부분을 따라 뒤정중선과 만나는 지점이 4번 요추가 되고 약간 아래에 4번 요추의 가시뼈돌기(spinous process of 4th lumbar vertebra)를 잡는다.
3. 이를 기준으로 가시뼈돌기(spinous process)를 촉지해 가면서 척추뼈를 세어 올라간다.
4. 5번 요추는 엉치뼈(sacrum)의 바닥(base)을 확인하고 4번 요추와 사이에서 잡는다.

## 자료의 범위 {#_3}

<span id="_4"></span>
<span id="_5"></span>

원본은 요추의 가시돌기와 엉치뼈를 촉지하는 순서를 담고 있습니다. 장골능의 높이를 이용한 설명은 요추 수준을 가늠하는 표면해부학적 참고이며, 특정 척추 수준이나 자침 위치를 확정하는 정보와 구별합니다. 원본에 적힌 ASIS와 장골능은 서로 다른 해부학적 구조이므로 구분하여 읽어야 합니다. 원본의 명칭 공란을 유지하고 이 설명용 제목은 별도 편집 데이터로 관리합니다.

사람의 내용 감수가 필요한 초안입니다. 분류·명칭·원본 대조와 자동 검증의 범위는 구별해 읽어 주세요.
