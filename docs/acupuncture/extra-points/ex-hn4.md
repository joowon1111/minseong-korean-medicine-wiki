# 어요 EX-HN4

## 분류
**경외기혈** · 코드 **EX-HN4**

## 위치
머리의 이마부위(frontal region), 동공(pupil) 바로 위의 눈썹 중앙 부위.

## 취혈
앞을 똑바로 바라보고, 동공(pupil) 바로 위의 눈썹 중앙 부위에서 취혈한다.

## 자침·주의
- 橫刺 0.3～0.5寸
