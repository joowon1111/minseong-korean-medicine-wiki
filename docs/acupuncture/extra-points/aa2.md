# 금연 목적의 이침 배혈 예시 (AA2)

## 분류 {#_1}
**이침 배혈 예시** · 원본 자료 식별자 **AA2**

원본에서 「금연침」으로 묶은 여러 이침점의 조합을 보존한 자료입니다. AA2는 이 배혈 예시의 식별자로, 단일 경혈의 표준 코드와 구분합니다.

## 배혈 구성 {#_2}

### 이침 배혈 구성

금연침: 이신문, 인후, 내비, 내분비, 폐1, 폐2

## 자료의 범위 {#_3}

<span id="_4"></span>
<span id="_5"></span>

이신문·인후·내비·내분비·폐1·폐2는 원본에 제시된 조합 구성입니다. 각 이침점의 위치와 사용 체계는 해당 원전·위치도에서 대조해야 합니다. 원본은 이 조합의 임상시험 결과나 효과 크기, 자극 방법·깊이·기간을 제시하지 않으므로 이 페이지에서는 배혈 구성의 범위로 설명합니다.

사람의 내용 감수가 필요한 초안입니다. 분류·명칭·원본 대조와 자동 검증의 범위는 구별해 읽어 주세요.
