# 주요 경혈

수백 개의 경혈 가운데 임상에서 특히 자주 활용되는 대표 경혈을 먼저 정리한다.

| 경혈 | 경맥 | 전통적 활용 방향 |
|---|---|---|
| 합곡(LI4) | 대장경 | 두면부·통증·표증 |
| 족삼리(ST36) | 위경 | 비위·기력·전신 조절 |
| 삼음교(SP6) | 비경 | 비·간·신 삼경의 교회 |
| 내관(PC6) | 심포경 | 흉민·심계·오심 |
| 태충(LR3) | 간경 | 소간·기체·두통 |
| 신문(HT7) | 심경 | 안신·심계·불면 |
| 관원(CV4) | 임맥 | 원기·하초·허손 |

## 지식망 연결
- 불면 → 신문·내관·삼음교
- 소화기 → 족삼리·내관
- 통증 → 합곡·태충
- 허손·회복 → 족삼리·관원

향후 각 경혈을 독립 문서로 확장해 위치·해부·고전·현대 연구를 연결한다.
