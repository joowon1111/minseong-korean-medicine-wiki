# 한의학 임상 비교 지식망

비교 문서는 어느 치료가 항상 더 좋다는 결론보다 **어떤 병증·구성·치료목표에서 갈라지는지**를 보여줍니다.

## 치료법 비교
[침 vs 전침](acupuncture-vs-electroacupuncture.md) · [침 vs 약침](acupuncture-vs-pharmacopuncture.md)

## 읽는 기준
**공통점 → 갈라지는 병기 → 구성 차이 → 환자 증상 → 치료목표 → 안전성·근거**

## 비교할 때 먼저 고를 기준

| 현재 상황 | 먼저 볼 비교 | 구분할 핵심 |
|---|---|---|
| 소화가 약하고 쉽게 지침 | [사군자탕·육군자탕](sijunzi-vs-liujunzi.md) | 비위기허에 담음·오심·팽만이 더해지는지 |
| 보익 처방을 구분하고 싶음 | [보중익기탕·십전대보탕](buzhong-vs-sipjeondaebo.md) | 보기승양과 기혈쌍보·온보의 차이 |
| 잠이 얕고 두근거림 | [귀비탕·온담탕](guibi-vs-wendan.md) | 기혈 부족과 담음·흉민의 비중 |
| 공진단·경옥고가 궁금함 | [공진단·경옥고](gongjin-vs-gyeongok.md) | 실제 구성·제형·복용 목적 |
| 치료 방식이 궁금함 | [침·전침](acupuncture-vs-electroacupuncture.md) · [침·약침](acupuncture-vs-pharmacopuncture.md) | 자극 방식·적합성·안전 확인 |

비교표의 증상은 처방을 고르는 확정 기준이 아닙니다. 표에서 차이를 이해한 뒤 각 처방의 구성·감별·임상근거로 이동하면 자료를 더 정확하게 읽을 수 있습니다.
