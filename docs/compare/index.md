# 처방·치료 비교 안내

비슷한 이름의 처방과 치료를 **구성·적용 맥락·목표·근거의 차이**로 비교하는 자료실입니다. 비교표에서 차이를 파악한 뒤 각 처방과 치료의 상세 문서로 이어갈 수 있습니다. 어떤 선택지가 항상 더 좋다는 순위를 정하는 곳은 아닙니다.

## 방제 비교

| 궁금한 질문 | 비교 문서 | 읽고 구분할 내용 |
|---|---|---|
| 공진단과 경옥고, 같은 기력회복용인가요? | [공진단·경옥고](gongjin-vs-gyeongok.md) | 실제 약재·제형·회복 목표, 제품과 연구의 차이 |
| 보중익기탕과 십전대보탕은 어떤 점이 다른가요? | [보중익기탕·십전대보탕](buzhong-vs-sipjeondaebo.md) | 보기승양과 기혈쌍보·온보, 소화·냉감·허약의 맥락 |
| 소화가 약할 때 사군자탕과 육군자탕은 어떻게 나누나요? | [사군자탕·육군자탕](sijunzi-vs-liujunzi.md) | 비위기허와 담음·오심·식후 팽만의 비중 |
| 잠이 얕고 두근거릴 때 귀비탕과 온담탕은 어떻게 다른가요? | [귀비탕·온담탕](guibi-vs-wendan.md) | 기혈 부족과 담음·흉민을 구분하는 질문 |
| 기허와 기혈양허라는 설명이 헷갈려요 | [기허·기혈양허](../questions/choice/qi-vs-qi-blood-deficiency.md) | 변증 개념과 빈혈 등 검사 진단의 차이 |

처방 이름을 알고 있다면 위 비교에서 시작하면 됩니다. 아직 처방보다 증상의 조합이 궁금하다면 [기운과 소화가 함께 약할 때](../questions/choice/fatigue-poor-digestion.md)처럼 실제 상황을 풀어 설명하는 문서가 먼저 도움이 됩니다.

## 치료법 비교

| 비교 문서 | 핵심 차이 | 함께 확인할 질문 |
|---|---|---|
| [침·전침](acupuncture-vs-electroacupuncture.md) | 수기·유침과 전기자극의 차이 | 자극 설정과 편안함, 통증·움직임의 변화는 어떻게 보는가? |
| [침·약침](acupuncture-vs-pharmacopuncture.md) | 침 자극과 제제·주입 자극의 차이 | 성분·부위·알레르기, 병행 목적과 근거는 무엇인가? |

치료를 병행하는 상황은 [오래된 허리통증에서 침과 한약](../questions/choice/chronic-back-pain-treatment.md)에서 자세히 봅니다. 치료 이름의 차이와 실제로 적용하는 부위·강도·횟수·제제의 차이를 함께 확인합니다.

## 읽는 기준

각 비교에서는 먼저 공통 목적을 확인하고, 갈라지는 병기와 구성, 환자 증상과 치료 목표를 차례로 읽습니다. 마지막으로 연구 대상과 안전성을 확인하면 전통적 설명과 실제 임상연구 결과를 혼동할 가능성이 줄어듭니다.

| 비교 단계 | 확인할 질문 |
|---|---|
| 구성 | 같은 이름이라도 원방·가감·제형·제조 방식이 같은가? |
| 대상 | 나이·진단·동반질환·증상 정도가 연구와 비슷한가? |
| 비교군 | 무치료·일반 진료·위약·다른 치료 중 무엇과 비교했는가? |
| 결과 | 증상점수·생활 기능·회복 기간 중 무엇을 측정했는가? |
| 한계 | 소규모·짧은 관찰·낮은 확실성 등 해석의 제한은 무엇인가? |

서로 다른 연구의 숫자를 나란히 놓는 것만으로 처방이나 치료의 우열을 판단하지 않습니다. [연구·근거 자료실](../portal/evidence.md)에서 이런 차이를 읽는 방법을 더 자세히 확인할 수 있습니다.

## 비교할 때 먼저 고를 기준

진료에서 해결하고 싶은 문제를 한 문장으로 정리해 보세요. “더 강한 보약”보다 “식사량이 줄고 오후 활동을 유지하기 어렵다”, “밤 통증 때문에 깨고 아침 움직임이 어렵다”처럼 쓰면 비교할 질문이 분명해집니다.

비교 문서에서 차이를 이해한 뒤에는 실제 구성·복용약·병력과 적합성을 진료에서 확인합니다. 경과는 [임상 평가·경과 자료실](../symptom-clinical/index.md)의 증상별 기능 지표로 이어집니다. 본초 자체의 감별은 [본초 비교](../herbal-integrated/herb-comparisons.md), 체질 처방의 구성 차이는 [사상 대표처방 비교](../sasang-formula-cards/comparison-map.md)에서 별도로 볼 수 있습니다.
