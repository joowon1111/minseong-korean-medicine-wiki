# 보중익기탕과 십전대보탕의 차이

두 처방 모두 허약 상태에서 활용되지만 초점이 다르다.

| 구분 | 보중익기탕 | 십전대보탕 |
|---|---|---|
| 중심 변증 | 비위기허·중기하함 | 기혈양허 |
| 치료 방향 | 보기 + 승양 | 보기 + 보혈 + 온보 |
| 대표 연결 | 황기·인삼·승마·시호 | 사군자탕 + 사물탕 계열 + 황기·육계 |
| 상세 | [보중익기탕](../formulas/buzhong-yiqi-tang.md) | [십전대보탕](../formulas/shi-quan-da-bu-tang.md) |

```text
기허 + 기함 → 보중익기탕
기허 + 혈허 → 기혈양허 → 십전대보탕
```
