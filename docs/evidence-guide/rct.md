# 임상시험과 RCT는 무엇인가?

RCT(Randomized Controlled Trial)는 대상자를 무작위로 여러 군에 배정해 치료 결과를 비교한다.

```text
대상자
 ↓ 무작위 배정
치료군 ↔ 비교군
 ↓
통증·기능·삶의 질 등
 ↓
결과 비교
```

## 한의학에서 볼 항목
- 대상자의 질환과 변증
- 침의 경혈·자극방법
- 한약의 구성·제형·용량
- 비교군
- 치료기간
- 추적기간
- 안전성
