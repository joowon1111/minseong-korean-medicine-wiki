# 한의학 근거 유형과 질문 지도

근거는 한 줄로 세운 서열표보다 **무슨 질문에 답하려는 연구인지** 먼저 확인할 때 정확하게 읽을 수 있다. 무작위 임상시험은 비교효과에 강하지만 희귀 이상반응이나 장기 사용 양상을 모두 보여주지는 못한다. 관찰연구와 전통 문헌도 각자의 질문에서 중요한 정보를 제공한다.

## 먼저 질문을 정한다

| 알고 싶은 것 | 우선 살펴볼 근거 | 함께 볼 자료 |
|---|---|---|
| 전통적으로 무엇을 어떻게 사용했는가 | 고전·의서·처방 원전 | 시대적 진단명, 제형·용량, 후대 주석 |
| 어떤 작용 가능성이 있는가 | 성분·세포·동물·기전 연구 | 실제 투여량, 제제 동일성, 사람 대상 연구 |
| 비교군보다 효과가 있는가 | 무작위 대조 임상시험(RCT) | 비뚤림 위험, 효과 크기, 신뢰구간, 이상반응 |
| 진료현장에서 어떻게 쓰이는가 | 코호트·등록자료·의무기록 연구 | 교란요인, 선택편향, 병용치료 |
| 드물거나 장기적인 위해가 있는가 | 대규모 관찰자료·약물감시·증례군 | 노출 기간, 분모, 인과성 평가 |
| 연구 전체의 방향은 어떠한가 | 체계적 문헌고찰 | 검색 범위, 포함 연구의 질, 이질성, 근거 확실성 |
| 여러 연구의 평균 효과는 얼마인가 | 적절한 메타분석 | 연구 간 차이, 예측구간, 출판편향 |

## ‘높은 단계’만으로 결론내리지 않는다

같은 연구 설계라도 수행과 보고의 질에 따라 신뢰도는 달라진다. 체계적 문헌고찰도 질이 낮은 소규모 연구만 포함하거나 서로 다른 처방·대상·평가 시점을 무리하게 합치면 결론이 불확실할 수 있다.

다음 세 축을 함께 본다.

1. **내적 타당도**: 무작위배정, 배정 은폐, 눈가림, 결측치 처리 등으로 편향을 얼마나 줄였는가?
2. **근거의 확실성**: 결과가 반복되고 정밀하며, 비뚤림·비일관성·간접성·출판편향 우려가 크지 않은가?
3. **적용 가능성**: 연구의 환자, 변증, 처방 구성, 시술 방식, 비교군과 추적기간이 내 질문과 맞는가?

## 한의학 근거는 이렇게 이어 읽는다

| 층위 | 읽을 때의 핵심 |
|---|---|
| 전통 문헌 | 원문에 기록된 적응 맥락과 후대의 임상적 확장을 구분한다. |
| 기전·전임상 | 임상효과의 증명이 아니라 가설과 생물학적 개연성을 본다. |
| 증례·관찰연구 | 실제 사용 양상과 안전성 신호를 보되 인과관계는 신중히 해석한다. |
| 임상시험·RCT | 치료군과 비교군의 차이, 효과의 크기와 불확실성을 읽는다. |
| 체계적 문헌고찰·지침 | 개별 연구를 종합한 결론과 권고의 조건을 확인한다. |

## 아카이브의 표현 원칙

현대 연구의 긍정적 결과는 그 의미를 충분히 설명하되 **연구 유형·대상·중재·비교군·기간·불확실성**을 함께 표시한다. 전통적 활용은 임상 맥락을 보여주는 자료로 존중하면서 현대 임상효과의 직접 증거와는 구분한다. 서로 다른 근거를 경쟁시키기보다 한 치료를 입체적으로 이해하는 자료로 연결한다.
