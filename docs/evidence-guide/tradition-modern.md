# 전통 문헌과 현대 연구는 어떻게 다른가?

**전통 문헌과 현대 연구는 서로 다른 질문에 답하는 근거**입니다. 고전의 오랜 사용 기록은 현대적 효과를 자동으로 증명하지 않고, 현대 임상시험의 평균 효과도 고전의 이론체계와 개별 운용 전체를 설명하지 않습니다. 두 층위를 섞지 않고 연결할 때 임상적으로 유용해집니다.

## 다섯 층위로 구분하기

| 근거 층위 | 답하는 질문 | 주의할 점 |
|---|---|---|
| 원전 기록 | 당시 무엇을 어떻게 설명했는가? | 판본·시대·문맥과 후대 해석을 구분 |
| 후대 주석·임상 전승 | 처방·혈위·변증이 어떻게 확장됐는가? | 반복 전승이 현대적 효과입증과 같지는 않음 |
| 약리·기전 연구 | 어떤 성분·경로·생물학적 반응이 관찰되는가? | 세포·동물 결과를 환자효과로 바로 확장하지 않음 |
| 임상 관찰·무작위시험 | 특정 환자군에서 어떤 결과와 위해가 나타나는가? | 중재 표준화, 비교군, 표본수와 추적기간 확인 |
| 체계적 문헌고찰·지침 | 전체 연구는 얼마나 일관되며 실제로 권고할 수 있는가? | 원 연구의 질과 적용대상, 권고 조건 확인 |

## 한 문장에 섞지 않는 표현법

| 피할 표현 | 권장 표현 |
|---|---|
| “고전에 기록되어 효과가 입증됐다.” | “고전에는 이러한 용법이 기록되어 있다. 현대 임상효과는 별도 연구에서 평가해야 한다.” |
| “동물실험에서 효과가 있었다.” | “전임상 연구에서 관련 기전 신호가 관찰됐으나 임상효과를 확정하지 않는다.” |
| “메타분석에서 유효하다.” | “해당 대상·비교군·결과에서 평균 차이가 보고됐으며, 이질성과 근거확실성은 다음과 같다.” |
| “지침이 권고한다.” | “어떤 환자에게 어느 강도와 확실성으로 권고하는지”를 함께 제시 |

## 예시 1: 반하사심탕

1. [상한론](../classics/shanghanlun.md)의 원문과 조문 맥락에서 처방의 역사적 위치를 확인합니다.
2. 후대 의서와 현대 임상에서 어떤 증상군·변증에 사용됐는지 구분합니다.
3. 현대 연구는 기능성 소화기 증상 등 구체적 대상, 정확한 제형·용량, 비교군과 결과지표로 읽습니다.
4. 고전의 병명이 현대 진단명과 같다고 전제하지 않으며, 현대 연구 결과도 모든 전통 적응을 대표하지 않습니다.

→ [반하사심탕](../formulas/banxia-xiexin-tang.md)

## 예시 2: 산조인

전통적으로 심신 불안과 수면 관련 맥락에서 사용된 기록, 산조인의 성분·기전 연구, 불면 환자를 대상으로 한 임상연구는 각각 다른 층위입니다. 원료 감별과 포제, 처방 속 배합, 단일 추출물 연구도 서로 같은 중재가 아닙니다.

→ [산조인 본초 카드](../authority/herbs/ziziphus-seed.md)

## 예시 3: 침구 고전과 현대 안전성

[침구갑을경](../classics/zhenjiu-jiayi-jing.md)과 [침구대성](../classics/zhenjiu-dacheng.md)은 혈위와 주치, 후대 침구학의 체계화를 이해하는 역사적 근거입니다. 현대 해부학·영상 연구는 혈위 주변 구조와 안전 깊이를 검토하고, 임상시험은 특정 질환에서의 효과와 위해를 평가합니다. 고전의 취혈 설명은 임상적 맥락을 주지만 현대 안전기준을 대체하지 않습니다.

## 문서를 작성할 때의 연결 순서

1. **원전**: 서명·편찬시기·판본·원문 위치를 밝힙니다.
2. **전통적 해석**: 후대 주석인지 현대적 요약인지 표시합니다.
3. **현대적 질문**: 대상, 중재, 비교, 결과(PICO)를 명확히 합니다.
4. **결과와 한계**: 효과크기뿐 아니라 편향위험·이질성·안전성을 씁니다.
5. **임상 적용**: 위험신호, 병용치료, 환자 선호와 불확실성을 포함합니다.
