# 전통 문헌과 현대 연구는 어떻게 다른가?

**전통 문헌과 현대 연구는 서로 다른 종류의 근거다.**

## 전통 문헌
고전은 당시의 임상경험과 의학이론이 어떻게 체계화되었는지를 보여준다.

예:
- [황제내경](../classics/huangdi-neijing.md)
- [상한론](../classics/shanghanlun.md)
- [동의보감](../classics/donguibogam.md)

## 현대 연구
현대 연구는 특정 중재를 정해진 연구설계와 결과지표로 평가한다.

```text
고전
→ 왜·어떻게 사용해왔는가?

현대 연구
→ 특정 대상에서 어떤 결과가 관찰되었는가?
```

따라서 고전의 기록을 현대 RCT와 동일한 근거로 표현하지 않고, 반대로 현대 연구만으로 한의학의 역사적 치료체계를 모두 설명하려 하지 않는다.
