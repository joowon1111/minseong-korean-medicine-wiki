# 체계적 문헌고찰·메타분석은 무엇인가?

Systematic review는 미리 정한 기준으로 관련 연구를 체계적으로 찾고 평가한다. Meta-analysis는 여러 연구의 수치 결과를 통계적으로 합친다.

## 장점
개별 연구보다 전체 연구 흐름을 보기 쉽다.

## 함께 확인할 것
- 포함된 연구 수와 대상자 수
- RCT의 질
- 치료법의 차이
- 비교군
- 이질성
- 출판편향

```text
여러 RCT
↓
Systematic review
↓
Meta-analysis
```

포함 연구의 대상·치료법·결과지표를 함께 보면 종합 결과의 임상적 의미를 더 구체적으로 파악할 수 있다.
