# PMID·DOI는 무엇인가?

## PMID
PMID는 PubMed에 등록된 논문에 부여되는 고유 번호다.

예:
```text
PMID: 39669697
```

같은 제목의 논문이 있더라도 PMID를 이용하면 정확한 연구를 찾기 쉽다.

## DOI
DOI는 학술 논문의 영구적인 디지털 식별자다.

예:
```text
DOI: 10.1016/j.imr.2024.101025
```
