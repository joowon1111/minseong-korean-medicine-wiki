# 사상체질 건강 → 악화 → 중증 → 회복

사상체질병증 진료지침은 건강상태의 최소 생리 조건인 **완실무병(完實無病)**을 체질별로 제시합니다.

| 체질 | 완실무병 조건 | 임상적으로 보는 핵심 |
|---|---|---|
| 태양인 | 소변왕다(小便旺多) | 소변 배출이 원활한가 |
| 소양인 | 대변선통(大便善通) | 대변 소통이 원활한가 |
| 태음인 | 한액통창(汗液通暢) | 땀이 자연스럽고 원활한가 |
| 소음인 | 음식선화(飮食善化) | 음식이 편안하게 소화되는가 |


```text
완실무병 → 소증 변화 → 초기 악화 → 표/리병 → 순/역증
→ 중증도 상승 → 치료 → 주증상 호전 → 소증·건강신호 회복
```

## 이 허브에서 보는 네 단계

### 1. 건강 기준선
완실무병은 자가 체질진단 체크리스트가 아니라 **평소 건강 상태를 비교하기 위한 기준선**입니다. 대변·소화·발한·배뇨를 한 번의 상태가 아니라 평소 패턴으로 기록합니다.

### 2. 초기 악화
주증상보다 먼저 수면·식욕·대소변·땀·한열·활동 회복이 미세하게 변할 수 있습니다. 체질별 병증은 이 변화가 어떤 방향으로 묶이는지를 봅니다.

### 3. 중증도 상승
섭취·배설·순환·호흡·보행 같은 기본 기능이 무너지거나 역증의 특징이 커지면 중증도를 높게 봅니다. 현대 의학적 위험신호가 있으면 체질 분류보다 필요한 검사가 우선입니다.

### 4. 회복
주증상 감소 → 소증 안정 → 기능 회복 → 완실무병 기준선 회복 순으로 추적합니다. 증상 하나만 좋아지고 소증·기능이 악화되면 병증을 다시 평가합니다.
