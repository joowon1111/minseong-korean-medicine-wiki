# 소음인 건강→악화→회복

## 건강
**음식선화** — 식사와 소화가 편안한 상태.

## 초기 변화
식욕저하·더부룩함·복부냉감·피로·무른변/설사·냉감 증가.

## 태음병 방향
`복만·복통·설사 + 갈증이 뚜렷하지 않음`을 중심으로 살피며 구토·심하비만·황달·부종·사지냉 등의 조합으로 더 세분합니다.

## 더 깊은 소음병 방향
설사·복통에 **갈증·심번·수족냉·신체통** 등이 더해지는 변화를 중요하게 봅니다.

## 회복
급한 위장 증상 감소 → 냉감 완화 → 식욕 회복 → 식후 불편 감소 → **음식선화 회복**.
