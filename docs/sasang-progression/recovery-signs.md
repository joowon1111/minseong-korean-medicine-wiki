# 사상체질 회복 신호 체크포인트

```text
급한 주증상 감소
 ↓
수면·식욕·대소변·발한 안정
 ↓
평소 소증 수준 회복
 ↓
체질별 완실무병 조건 안정
```

사상체질병증 진료지침은 건강상태의 최소 생리 조건인 **완실무병(完實無病)**을 체질별로 제시합니다.

| 체질 | 완실무병 조건 | 임상적으로 보는 핵심 |
|---|---|---|
| 태양인 | 소변왕다(小便旺多) | 소변 배출이 원활한가 |
| 소양인 | 대변선통(大便善通) | 대변 소통이 원활한가 |
| 태음인 | 한액통창(汗液通暢) | 땀이 자연스럽고 원활한가 |
| 소음인 | 음식선화(飮食善化) | 음식이 편안하게 소화되는가 |


국가 임상자료에서도 치료 후 관리와 재발 예방 과정에서 소증·병증 관련 지표를 지속적으로 평가하는 구조를 제시합니다.


## 회복은 세 층으로 봅니다

1. **주증:** 통증·열·설사·구토·기침 같은 급한 증상이 줄어드는가?
2. **소증:** 식욕·대변·소변·땀·수면·한열이 평소 방향으로 돌아오는가?
3. **기능:** 식사·보행·업무·운동·수면 뒤 회복이 실제로 좋아지는가?

## 체질별 회복 지표

| 체질 | 회복에서 특히 보는 것 |
|---|---|
| 소양인 | 편안한 배변, 갈증·상열 안정, 수면·배뇨·기력 회복 |
| 태음인 | 자연스러운 발한 뒤 개운함, 호흡·부종·대변·활동 회복 |
| 소음인 | 식욕·식후 편안함, 대변·냉감·기력, 발한 뒤 회복 |
| 태양인 | 보행·기립 또는 연하·섭취, 체중·수분과 배뇨 안정 |

## '증상만 좋아진 가짜 회복'을 피하기

설사는 줄었지만 소변이 감소하고 기력이 더 떨어지거나, 불면은 좋아졌지만 낮 졸림·호흡곤란이 심해지는 식의 변화는 전체 회복으로 보지 않습니다. 치료 전 기준선과 같은 항목을 반복 측정합니다.

## 재발 예방

회복기에는 수면·식사·활동을 갑자기 늘리지 않고, 병증에서 먼저 무너졌던 소증을 재발의 조기 신호로 사용합니다. 체질별 식사·운동·성정 관리는 현재 병증과 회복단계에 맞게 조정합니다.
