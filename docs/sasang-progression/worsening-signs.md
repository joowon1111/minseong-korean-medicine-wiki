# 사상체질 악화 신호 체크포인트

소증 기반 표리변증 연구에서는 **한열 민감도, 발한 정도, 음수량, 갈증, 안색, 신체통** 등을 세부 지표로 제시합니다.

| 항목 | 평소와 비교할 변화 |
|---|---|
| 소화 | 식욕·소화가 떨어졌나 |
| 대변 | 횟수·굳기·배변감이 달라졌나 |
| 소변 | 횟수·양·색이 달라졌나 |
| 땀 | 평소보다 안 나거나 과도해졌나 |
| 한열 | 추위·열감 반응이 달라졌나 |
| 갈증/음수 | 새로 생기거나 양상이 달라졌나 |
| 수면 | 입면·각성·수면 질이 달라졌나 |
| 통증 | 새로운 신체통이 생겼나 |
| 체력 | 활동 후 회복이 느려졌나 |

핵심은 **절대적인 수치보다 평소 소증에서 무엇이 변했는가**입니다.


## 체질별로 특히 민감하게 볼 변화

| 체질 | 초기 변화 | 더 깊어진 변화 |
|---|---|---|
| 소양인 | 대변·갈증·상열·수면 변화 | 설사·소모 또는 변폐·강한 리열, 하지무력 |
| 태음인 | 발한·무거움·호흡·식후 불편 | 폐조·조열·변폐 또는 심한 냉감·회복저하 |
| 소음인 | 식욕·식후 불편·묽은 변·냉감 | 망양의 탈진 또는 소음병의 수족냉·심한 설사 |
| 태양인 | 보행·섭취의 미세한 기능 저하 | 낙상·진행성 연하곤란·체중감소 |

## 악화는 '반대 방향 새 증상'도 중요합니다

치료 중 기존 증상은 줄지만 새로운 설사·변폐, 심한 갈증, 냉감, 불면, 부종이 생기면 단순 호전으로 보지 않습니다. 처방 강도·병증 위치·현대 질환의 진행을 다시 확인합니다.

## 공통 위험신호

의식 변화·실신, 흉통·호흡곤란, 지속 고열, 혈변·토혈·흑변, 반복 구토와 소변 감소, 급격한 체중감소, 진행성 연하곤란, 갑작스러운 신경학적 이상은 즉시 필요한 평가가 우선입니다.
