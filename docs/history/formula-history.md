# 처방의 역사적 흐름

처방은 각 시대의 **병리 이해와 임상적 문제의식이 약물 배합으로 구체화된 결과**로 볼 수 있다.

## 장중경 — 맥증과 고방
[상한론](../classics/shanghanlun.md)

`맥증·육경 → 치법 → 계지탕·마황탕·소청룡탕·소시호탕·오령산`

→ [장중경 계보](../network/zhang-zhongjing-lineage.md)

## 손사막 — 비증과 허손
[비급천금요방](../classics/beiji-qianjin-yaofang.md)

`풍한습비 + 간신·기혈허 → 독활기생탕`

→ [독활기생탕](../formulas/duhuo-jisheng-tang.md)

## 이동원 — 비위와 원기

→ [보중익기탕](../formulas/buzhong-yiqi-tang.md)
