한의학의 역사는 한 학설이 이전 학설을 모두 대체하는 직선적 발전사가 아닙니다. 기초이론, 맥증과 처방, 종합 임상서, 비위학설, 체질의학이 서로 다른 질문을 중심으로 축적된 흐름입니다. 시간 순서와 학파의 관점, 실제 처방의 계보를 함께 비교합니다.

## 한의학 역사 타임라인 {#timeline}

**1. 기초이론의 형성 — 황제내경**

[《황제내경》](../classics/huangdi-neijing.md)은 음양·오행, 장부, 기혈, 경락, 병인·병기와 침구 등 한의학의 기본 언어를 형성한 핵심 고전이다.

**2. 맥증과 고방 — 장중경**

[장중경](../physicians/zhang-zhongjing.md)의 [《상한론》](../classics/shanghanlun.md)과 [《금궤요략》](../classics/jinkui-yaolue.md)은 맥증과 병기를 실제 처방으로 연결하는 임상체계를 보여준다.

→ [장중경 계보](../physicians/zhang-zhongjing.md#formula-lineage)

**3. 종합 임상 — 손사막**

[손사막](../physicians/sun-simiao.md)의 [《비급천금요방》](../classics/beiji-qianjin-yaofang.md)은 내과·부인과·소아과·침구·식치·양생을 아우르는 종합 임상 의학의 흐름을 보여준다.

→ [손사막 계보](../physicians/sun-simiao.md#formula-lineage)

**4. 비위와 내상 — 이동원**

[이동원](../physicians/li-dongyuan.md)의 [《비위론》](../classics/piwei-lun.md)은 음식·노권, 비위손상과 원기부족을 강조하며 보기·승양 치료를 발전시켰다.

→ [이동원 계보](../physicians/li-dongyuan.md#formula-lineage)

**5. 조선 의학의 집대성 — 허준**

[허준](../physicians/heo-jun.md)의 [《동의보감》](../classics/donguibogam.md)은 내경·외형·잡병·탕액·침구의 구조로 방대한 의학지식을 재구성했다.

→ [허준 계보](../physicians/heo-jun.md#formula-lineage)

**6. 한국 체질의학 — 이제마**

[이제마](../physicians/lee-je-ma.md)의 [《동의수세보원》](../classics/donguisusebowon.md)은 태양인·태음인·소양인·소음인의 장부 구조와 병증·치료를 체계화했다.

→ [이제마 계보](../physicians/lee-je-ma.md#formula-lineage)

## 의학사상·학파 지도 {#schools-map}

| 흐름 | 핵심 관점 | 대표 연결 |
|---|---|---|
| 내경학 | 음양·장부·기혈·경락 | [황제내경](../classics/huangdi-neijing.md) |
| 상한·고방 | 맥증·육경·병기와 처방 | [상한론](../classics/shanghanlun.md) |
| 종합 임상 | 임상 각과·양생·식치 | [비급천금요방](../classics/beiji-qianjin-yaofang.md) |
| 비위학설 | 비위·원기·내상·승양 | [비위론](../classics/piwei-lun.md) |

| 사상의학 | 체질·장부 강약·표리병증 | [동의수세보원](../classics/donguisusebowon.md) |

**대표 처방으로 보기**

- 상한·고방 → [계지탕](../formulas/guizhi-tang.md)·[마황탕](../formulas/mahuang-tang.md)·[소시호탕](../formulas/xiaochaihu-tang.md)
- 비위학설 → [보중익기탕](../formulas/buzhong-yiqi-tang.md)
- 손사막 계통 → [독활기생탕](../formulas/duhuo-jisheng-tang.md)
- 동의보감 → [공진단](../formulas/gongjin-dan.md)·[경옥고](../formulas/gyeongok-go.md)
- 사상의학 → [사상의학 허브](../sasang/index.md)

**의미**

각 흐름은 서로 단절된 체계라기보다 이전 의학지식을 계승하면서 **특정 임상문제를 더 정교하게 설명하고 치료하는 방향으로 확장된 역사적 층위**로 이해할 수 있다.


## 처방의 역사적 흐름 {#formula-history}

처방은 각 시대의 **병리 이해와 임상적 문제의식이 약물 배합으로 구체화된 결과**로 볼 수 있다.

**장중경 — 맥증과 고방**

[상한론](../classics/shanghanlun.md)

`맥증·육경 → 치법 → 계지탕·마황탕·소청룡탕·소시호탕·오령산`

→ [장중경 계보](../physicians/zhang-zhongjing.md#formula-lineage)

**손사막 — 비증과 허손**

[비급천금요방](../classics/beiji-qianjin-yaofang.md)

`풍한습비 + 간신·기혈허 → 독활기생탕`

→ [독활기생탕](../formulas/duhuo-jisheng-tang.md)

**이동원 — 비위와 원기**

[비위론](../classics/piwei-lun.md)

`비위기허 + 중기하함 → 보기승양 → 보중익기탕`

→ [보중익기탕](../formulas/buzhong-yiqi-tang.md)

**허준·동의보감 — 허손과 양생**

[동의보감](../classics/donguibogam.md)

- [공진단](../formulas/gongjin-dan.md)
- [경옥고](../formulas/gyeongok-go.md)

아카이브에서는 이 처방들을 본초 구성뿐 아니라 현대 임상근거와도 연결한다.

**이제마 — 체질별 처방체계**

[동의수세보원](../classics/donguisusebowon.md)은 체질의 장부 구조와 현재의 병증을 함께 고려해 체질별 치료체계를 전개한다.

→ [사상의학](../sasang/index.md)
