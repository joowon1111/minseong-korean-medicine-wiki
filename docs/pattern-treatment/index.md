# 변증→치법 지식망

변증은 진단명 자체가 아니라 **어떤 치료 원칙을 세울 것인가를 결정하는 중간 단계**다.

```text
증상·사진
   ↓
변증
   ↓
치법
   ↓
본초·방제·경혈
   ↓
치료
```

## 병기와 치법을 연결하는 비교표

| 병기 | 함께 살피는 단서 | 치법의 방향 | 세부 자료 |
|---|---|---|---|
| 기허 | 활동 뒤 피로·무력·식욕 저하 | 보기·건비 | [기허→보기](qi-deficiency.md) |
| 혈허·기혈양허 | 창백·건조·어지럼과 기허의 동반 | 보혈·기혈쌍보 | [혈허→보혈](blood-deficiency.md) |
| 담음 | 오심·흉민·두중감과 비위 상태 | 화담·이기·건비 | [담음→치법](phlegm-fluid.md) |
| 어혈 | 고정통·외상 경과·혈행 정체의 증후 | 활혈·통락 | [어혈→치법](blood-stasis.md) |
| 심비양허 | 소화·피로와 수면·심계의 연결 | 보기양혈·안신 | [심비양허→치법](heart-spleen-deficiency.md) |
| 중기하함 | 비위기허에 승거 기능 저하가 더해짐 | 보기승양 | [중기하함→치법](sinking-middle-qi.md) |
| 풍한습비·허손 | 통증의 한열·무거움과 허약의 동반 | 거풍습과 보익의 비중 조절 | [비증·허손→치법](bi-deficiency.md) |

## 치법에서 실제 치료로 넘어갈 때

치법은 치료의 방향이며 처방명 하나와 고정 대응하지 않습니다. 같은 보기라도 담음이 겹치는지, 혈허나 냉감이 동반되는지에 따라 배합이 달라집니다. 본초·처방·침구는 각각의 상세 문서에서 구성과 적용 맥락을 확인합니다.

치료 뒤에는 처음 세운 목표에 맞춰 식사·배변·수면·활동·통증 등의 변화를 살피고 병기와 치료 계획을 다시 평가합니다. 전통 변증 용어는 현대 질환명이나 검사 결과와 별도로 기록합니다.
