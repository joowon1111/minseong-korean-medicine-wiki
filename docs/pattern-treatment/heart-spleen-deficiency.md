# 심비양허 → 보기양혈·안신

[심비양허](../concepts/heart-spleen-deficiency.md)는 비기허와 심혈 부족이 함께 나타나는 구조다.

```text
심비양허
 ↓
보기 + 양혈 + 안신
├─ 귀비탕
├─ 산조인
├─ 신문 HT7
└─ 내관 PC6
```

## 비슷한 수면 처방과의 차이

| 비교 방향 | 대표 문서 | 배합에서 읽는 핵심 |
|---|---|---|
| 기혈 부족 + 심비 양허 | [귀비탕](../formulas/guibi-tang.md) | 보기양혈·안신 |

## 적용과 경과 확인

같은 불면·두근거림이라도 소화·피로·건조·열감·흉민을 함께 봅니다. 심계의 빈도·유발 상황과 수면의 질을 기록하고 필요한 심장·내분비 평가와 연결합니다.

위 연결은 전통 치법과 배합의 비교입니다. 처방의 구체적 구성·감별·연구 출처는 각 대표 문서에서 확인합니다.
