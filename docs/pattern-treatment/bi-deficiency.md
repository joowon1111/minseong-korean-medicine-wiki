# 풍한습비·허손 → 거풍습·보간신·익기혈

오래된 통증에서는 사기의 제거뿐 아니라 허손을 함께 고려할 수 있다.

```text
풍한습비
  +
간신부족
  +
기혈부족
  ↓
거풍습 + 보간신 + 익기혈
  ↓
독활기생탕
```

## 적용과 경과 확인

오래 아프다는 이유만으로 한 처방을 고정하지 않습니다. 붓기·열감·외상·저림·근력 저하와 소화·회복 상태를 구분하고 통증·가동범위·걷기 등 기능을 함께 평가합니다.

위 연결은 전통 치법과 배합의 비교입니다. 처방의 구체적 구성·감별·연구 출처는 각 대표 문서에서 확인합니다.
