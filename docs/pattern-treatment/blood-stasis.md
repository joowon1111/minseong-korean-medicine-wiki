# 어혈 → 활혈·통락

[어혈](../diagnostics/blood-stasis.md)은 혈의 운행이 원활하지 않고 정체된 병리 상태다.

```text
어혈
 ↓
활혈·통락
├─ 통증 부위 평가
├─ 침
├─ 전침
└─ 부항
```

## 활혈 처방과 통증 치료의 연결

| 비교 방향 | 대표 문서 | 배합에서 읽는 핵심 |
|---|---|---|
| 외상 후 어혈 배합 | [당귀수산](../formulas/danggui-susan.md) | 활혈행기·지통의 구성 |
| 기체와 어혈 배합 | [혈부축어탕](../formulas/xuefu-zhuyu-tang.md) | 이기와 활혈의 결합 |
| 통증과 담습·한의 비교 | [통증 한약 처방](../herbal-integrated/formula-for-pain.md) | 어혈 외 병기까지 비교 |

## 적용과 경과 확인

어혈은 혈전과 같은 말이 아닙니다. 외상 부위·출혈·항응고제 복용·임신 여부를 함께 확인합니다. 침구와 한약은 기능 회복이라는 목표 아래 적합성을 각각 평가합니다.

위 연결은 전통 치법과 배합의 비교입니다. 처방의 구체적 구성·감별·연구 출처는 각 대표 문서에서 확인합니다.
