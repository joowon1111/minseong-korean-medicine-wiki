# 담음 → 화담·이기·건비

담음 치료는 **담을 정리하는 화담, 기의 소통을 돕는 이기, 담습이 반복되는 바탕을 살피는 건비**를 주증상과 허실·한열에 맞춰 조합합니다. 한증과 수음이 중심이면 온양화음의 방향도 구분합니다.

[담음 개념 안내](../diagnostics/phlegm-fluid.md) · [담음 변증 지도](../diagnostics/patterns/phlegm-fluid.md) · [담적과 만성 소화불편](../diagnostics/phlegm-accumulation.md)

## 담음에 무엇이 겹치는지 비교

| 치료 방향 | 주된 단서 | 대표 처방 |
|---|---|---|
| 조습화담·이기화중 | 담습·오심·흉완비민 | [이진탕](../formulas/erchen-tang.md) |
| 익기건비·화담 | 비위허약·식욕저하·피로·무른변 | [육군자탕](../formulas/liujunzi-tang.md) |
| 건비화담·행기 | 허약에 식후팽만·트림이 큼 | [향사육군자탕](../formulas/xiangsha-liujunzi-tang.md) |
| 행기산결·강역화담 | 목 이물감·흉민·긴장과의 연동 | [반하후박탕](../formulas/banxia-houpo-tang.md) |
| 이기화담·화위 | 오심·흉민에 심계·불면·번조 | [온담탕](../formulas/wendan-tang.md) |
| 건비화담·식풍 | 비허담습과 어지럼·두중 | [반하백출천마탕](../formulas/banxia-baizhu-tianma-tang.md) |
| 온양화음·건비이수 | 한증·중양부족과 수음·심계·현훈 | [영계출감탕](../formulas/linggui-zhugan-tang.md) |

열이 뚜렷하면 열을 조절하는 배합을 따로 살피고, 한약의 온열성을 일괄 적용하지 않습니다. ‘담적 치료’라는 이름을 들었더라도 과식 뒤 식적이면 [보화환](../formulas/baohe-wan.md), 심하비·한열착잡이면 [반하사심탕](../formulas/banxia-xiexin-tang.md)처럼 갈림점이 달라집니다. [담음 vs 식적](../diagnostics/differentials/phlegm-vs-food-stagnation.md)

## 본초와 침구의 역할 {#combined-care}

[반하](../herbs/pinellia.md)·[진피](../herbs/citrus-peel.md)·[복령](../herbs/poria.md)은 화담·강역·이기의 기본 구조, [인삼](../herbs/ginseng.md)·[백출](../herbs/atractylodes.md)은 건비, [목향](../herbs/aucklandia.md)·[사인](../herbs/amomum.md)은 행기화중의 배합과 연결됩니다. 각 본초를 단독 효능 목록으로 더하기보다 처방 안에서의 역할을 봅니다.

[침](../treatments/acupuncture.md)·[전침](../treatments/electroacupuncture.md)은 구체적인 증상과 진찰에 맞춰 선택합니다. 위장 불편에는 [중완 CV12](../acupuncture/points/cv12-zhongwan.md)·[족삼리 ST36](../acupuncture/points/st36-zusanli.md)·[내관 PC6](../acupuncture/points/pc6-neiguan.md), 담습의 전통적 맥락에는 [풍륭 ST40](../acupuncture/points/st40-fenglong.md)을 연결합니다. [뜸](../treatments/moxibustion.md)은 한증·허증과 피부 상태를 평가해 활용합니다.

## 적용과 경과 확인

| 중심 증상 | 치료 목표 | 다시 확인할 항목 |
|---|---|---|
| 소화불편·담적 관련 호소 | 식후불편·오심 감소, 식사량 회복 | 증상점수·트림 빈도·식사량·체중·배변 |
| 어지럼·두중 | 일상활동과 균형 회복 | 발생 횟수·지속시간·자세 연동·낙상 |
| 가래·기침 | 기침 부담·객담 불편 감소 | 양·색·혈담·발열·호흡곤란 |
| 목 이물감·흉민 | 삼킴 불편·긴장 연동 감소 | 실제 연하곤란·흉통·체중감소 |
| 불면·심계 | 잠과 낮 기능 회복 | 잠드는 시간·각성·심계 빈도·복용약 |

담음은 가래만을 뜻하지 않지만, 위 증상 모두의 원인을 담음으로 고정해서도 안 됩니다. 급성 어지럼과 신경학적 이상, 흉통·호흡곤란, 혈담, 진행하는 연하곤란 등은 별도 평가가 우선입니다.

한약은 포제·제형, 다른 약과의 병용, 임신 여부 등을 확인해 선택합니다. 감초가 여러 처방·제품에 중복되는지와 새로 생긴 부종·혈압 변화도 살핍니다. 치료 후 반응이 부족하면 화담약을 늘리기 전에 변증·원인 질환·생활요인을 다시 평가합니다.

## 생활 관리와 근거 확인 {#evidence-follow-up}

소화불편은 과식·야식·불규칙한 식사, 수면 부족, 개인별 유발 음식과의 관계를 기록해 조정합니다. 갈증·소변·기저질환을 무시한 과도한 수분 제한이나 무리한 발한으로 담음을 없애려 하지 않습니다.

기능성소화불량의 평가·한약·침구치료는 [한의표준임상진료지침](https://nikom.or.kr/nckm/module/practiceGuide/view.do?guide_idx=154&menu_idx=14)과 연결해 볼 수 있습니다. 구체적 처방의 연구 대상·제형·비교군은 각 처방 문서에서 확인합니다.
