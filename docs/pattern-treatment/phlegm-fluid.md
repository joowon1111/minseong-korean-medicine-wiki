# 담음 → 화담·이기·건비

[담음](../diagnostics/phlegm-fluid.md)은 진액대사의 병리적 정체를 설명한다.

```text
담음
 ↓
화담·이기·건비
├─ 반하
├─ 복령
├─ 육군자탕
└─ 온담탕
```

비위기허가 바탕이면 [육군자탕](../formulas/liujunzi-tang.md), 담위불화와 불면·흉민 등이 두드러지는 맥락에서는 [온담탕](../formulas/wendan-tang.md) 구조를 비교한다.

## 담음에 무엇이 겹치는지 비교

| 비교 방향 | 대표 문서 | 배합에서 읽는 핵심 |
|---|---|---|
| 비위기허가 바탕 | [육군자탕](../formulas/liujunzi-tang.md) | 보기건비와 화담 |
| 흉민·번조·오심의 배합 | [온담탕](../formulas/wendan-tang.md) | 이기화담과 담위의 조화 |
| 인후 이물감·기체 | [반하후박탕](../formulas/banxia-houpo-tang.md) | 행기산결과 강역 |

## 적용과 경과 확인

담음은 가래만을 뜻하지 않습니다. 소화·어지럼·흉부 증상을 함께 보되, 실제 부종·호흡곤란·급성 어지럼의 원인 감별은 별도로 합니다.

위 연결은 전통 치법과 배합의 비교입니다. 처방의 구체적 구성·감별·연구 출처는 각 대표 문서에서 확인합니다.
