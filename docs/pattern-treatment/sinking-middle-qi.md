# 중기하함 → 보기승양 {#_1}

[중기하함](../glossary/sinking-middle-qi.md)은 비위의 기가 허해 승거 기능이 약해진 상태를 설명한다.

보기승양은 비위의 기를 돕는 바탕에 승거 방향을 함께 두는 치법입니다. 황기·인삼·백출의 보기건비와 보중익기탕의 승마·시호 배합을 처방 전체 안에서 읽습니다.

## 보기승양과 다른 보익의 차이 {#_2}

| 비교 방향 | 대표 문서 | 배합에서 읽는 핵심 |
|---|---|---|
| 보기건비 기본 | [사군자탕](../formulas/sijunzi-tang.md) | 소화와 기허의 바탕 |
| 보기승양 | [보중익기탕](../formulas/buzhong-yiqi-tang.md) | 황기·인삼과 승마·시호의 배합 |
| 기혈쌍보 | [십전대보탕](../formulas/shi-quan-da-bu-tang.md) | 기와 혈의 부족을 함께 보함 |

## 적용과 경과 확인 {#_3}

중기하함은 단순한 피로나 저혈압의 동의어가 아닙니다. 처짐·장기하수·[탈항](../conditions/rectal-prolapse.md) 등의 실제 상태는 별도로 평가하며, 피로·배변·활동 후 변화와 함께 경과를 살핍니다.

[직장탈출의 구조·골반저 평가](../conditions/rectal-prolapse.md#assessment)에서는 돌출·누출·배출 기능을 나누어 봅니다. 변이 부드러워도 배출이 막히는 양상은 [골반저 배출장애](../conditions/constipation.md#incomplete-emptying)를 확인하고, 한약의 기력·식사·배변 목표를 실제 치료·재활과 맞춥니다.

위 연결은 전통 치법과 배합의 비교입니다. 처방의 구체적 구성·감별·연구 출처는 각 대표 문서에서 확인합니다.
