# 중기하함 → 보기승양

[중기하함](../glossary/sinking-middle-qi.md)은 비위의 기가 허해 승거 기능이 약해진 상태를 설명한다.

```text
비위기허
 ↓
중기하함
 ↓
보기승양
├─ 황기
├─ 인삼
└─ 보중익기탕
```

## 보기승양과 다른 보익의 차이

| 비교 방향 | 대표 문서 | 배합에서 읽는 핵심 |
|---|---|---|
| 보기건비 기본 | [사군자탕](../formulas/sijunzi-tang.md) | 소화와 기허의 바탕 |
| 보기승양 | [보중익기탕](../formulas/buzhong-yiqi-tang.md) | 황기·인삼과 승마·시호의 배합 |

## 적용과 경과 확인

중기하함은 단순한 피로나 저혈압의 동의어가 아닙니다. 처짐·장기하수·탈항 등의 실제 상태는 별도로 평가하며, 피로·배변·활동 후 변화와 함께 경과를 살핍니다.

위 연결은 전통 치법과 배합의 비교입니다. 처방의 구체적 구성·감별·연구 출처는 각 대표 문서에서 확인합니다.
