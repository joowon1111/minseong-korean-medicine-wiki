# 오래된 허리통증에서 침과 한약은 어떻게 같이 보나?

**오래된 허리통증에서는 통증 부위의 치료와 전신의 변증을 함께 고려할 수 있다.**

## 국소·기능적 치료
- [침](../../treatments/acupuncture.md)
- [약침](../../treatments/pharmacopuncture.md)
- [전침](../../treatments/electroacupuncture.md)
- [부항](../../treatments/cupping.md)

## 한약의 변증 축
```text
요통
├─ 어혈·기체
├─ 풍한습비
└─ 오래된 허손·간신·기혈허
             ↓
         독활기생탕 계열
```

→ [독활기생탕](../../formulas/duhuo-jisheng-tang.md)
→ [요통](../../conditions/low-back-pain.md)

치료 방법은 서로 경쟁하는 선택지라기보다 환자의 상태에 따라 **국소 치료와 전신 변증 치료를 조합하는 구조**로 이해할 수 있다.

→ [통증·근골격 허브](../../pillar/pain-musculoskeletal.md)
