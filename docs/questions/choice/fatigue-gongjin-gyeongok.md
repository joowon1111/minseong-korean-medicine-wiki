# 피로할 때 공진단과 경옥고는 어떻게 다른가?

**공진단과 경옥고는 모두 보익·회복의 맥락에서 활용되지만 처방 구성과 전통적인 치료 방향이 다르다.**

## 공진단을 이해하는 축
[공진단](../../formulas/gongjin-dan.md)은 녹용·당귀·산수유·사향 계열을 중심으로 **허손과 정혈의 보익**이라는 맥락에서 이해할 수 있다.

→ [녹용](../../herbs/cervi-parvum-cornu.md)
→ [공진단 임상근거](../../research/formulas/gongjin-dan.md)

[경옥고](../../formulas/gyeongok-go.md)는 인삼·생지황·복령·봉밀을 중심으로 **기와 진액, 양생과 회복**의 맥락에서 이해한다.
