# 자율조절과 내관·신문·족삼리

심계·오심·수면장애·피로처럼 자율신경 증상으로 표현되는 문제는 빈혈, 갑상샘질환, 부정맥, 약물, 수면장애와 정신건강 상태 등 여러 원인과 겹칠 수 있습니다. 아래 혈위는 진단명에 고정된 대응표가 아니라 **증후와 치료목표에 따라 배혈을 설계하는 비교 지도**입니다.

## 내관 PC6
```text
내관
├─ 심계·흉민
├─ 오심·소화
└─ 수면·정서
```
→ [내관 PC6](../acupuncture/points/pc6-neiguan.md)

## 신문 HT7
```text
신문
├─ 안신
├─ 심계
└─ 불면
```
→ [신문 HT7](../acupuncture/points/ht7-shenmen.md)

## 족삼리 ST36
```text
족삼리
├─ 비위·소화
├─ 기허
└─ 전신 회복
```
→ [족삼리 ST36](../acupuncture/points/st36-zusanli.md)

## 삼음교 SP6
```text
삼음교
├─ 비위·수습
├─ 월경·골반 증상
└─ 수면·회복
```
→ [삼음교 SP6](../acupuncture/points/sp6-sanyinjiao.md)

## 증상축별 비교

| 증상축 | 우선 비교할 혈위 | 함께 묻는 임상 질문 |
|---|---|---|
| 심계·흉민·불안정감 | 내관·신문 | 흉통, 실신, 운동 시 악화, 맥박 이상이 있는가? |
| 오심·상복부 불편 | 내관·족삼리 | 급성 복증, 탈수, 임신, 약물·감염 가능성이 있는가? |
| 잠들기 어려움·자주 깸 | 신문·내관·삼음교 | 수면무호흡, 하지불안, 우울·조증, 카페인·약물이 있는가? |
| 피로·소화저하 | 족삼리·삼음교 | 빈혈·갑상샘·감염·영양·수면 원인을 평가했는가? |

## 배혈을 읽는 순서

1. 위험신호와 원인 질환을 먼저 감별합니다.
2. 주증상과 동반증상, 시간대·유발요인을 정합니다.
3. 국소혈·원위혈, 표리경·교회혈 등 배혈 원리를 세웁니다.
4. 자침 깊이와 주변 신경·혈관 등 안전 해부를 확인합니다.
5. 증상 빈도, 수면·식사·활동 기능과 이상반응을 추적합니다.

이 혈위들은 하나의 증상에 고정된 혈이 아니며, “자율신경을 조절한다”는 포괄적 표현만으로 효과를 확정하지 않습니다. 질환별 임상연구에서는 대상, 비교군, 자침법과 평가한 자율신경 지표를 별도로 확인해야 합니다.
