# 심계·두근거림의 한의학적 지식망

심계는 스스로 심장 박동을 불편하게 느끼는 증상을 말한다. 증상의 발생 상황과 수면·피로·소화·정서적 긴장 등의 동반 양상을 함께 살핀다.

```text
심계
├─ 피로·건망·불면 → 심비양허
├─ 허약·기혈부족 → 기혈허
└─ 흉민·소화불편 → 담음 관련 구조
```
