# 손목터널증후군 — 정중신경 포착

엄지·검지·중지와 약지 요측의 저림·감각이상, 야간 증상, 손 사용 후 악화를 중심으로 봅니다.

`정중신경 → 손목터널 → 무지구 기능·손가락 감각 → 손저림·야간통`

경추 신경근병증, 원회내근증후군, 다발신경병증과 함께 감별합니다.

## 침 임상근거
2023 meta-analysis는 **16 RCT·1,025명**을 포함했습니다. 보조치료로 사용된 침에서 증상중증도·기능·통증·전기생리 지표의 긍정적인 결과가 보고되었습니다. PMID `36908786`.

2024 overview는 **9개 SR/MA**를 종합해 손목터널증후군 침 연구의 전체 근거지형을 평가했습니다. PMID `39640077`.
