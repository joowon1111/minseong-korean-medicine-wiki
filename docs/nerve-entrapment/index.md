# 신경포착증후군

신경포착증후군은 말초신경이 해부학적으로 좁거나 반복적인 압박·마찰을 받기 쉬운 부위에서 자극되어 **통증·저림·감각변화·근력저하**가 나타나는 임상군입니다.

## 환자 증상에서 찾기

| 주된 증상 | 먼저 살펴볼 신경·포착 |
|---|---|
| 엄지·검지·중지 저림 | 정중신경 · 손목터널 |
| 새끼손가락·약지 저림 | 척골신경 · 주관/팔꿈치 주변 |
| 손등·엄지 쪽 감각이상 | 요골신경 |
| 엉덩이에서 다리 뒤쪽으로 뻗는 통증 | 좌골신경 · 심부둔부 |
| 허벅지 바깥쪽 화끈거림·저림 | 외측대퇴피신경 |
| 종아리 바깥·발등 저림 | 총비골신경 |
| 발바닥 저림·화끈거림 | 경골신경 · 족근관 |

## 임상 탐색 순서

`저림·통증 위치 → 감각 분포 → 근력·반사 → 신경 주행 → 주요 포착부위 → 경추·요추 신경근 감별 → 관련 근육·근막 → 경혈·침구 → 현대 임상근거`

## 침구와 현대 임상근거

손목터널증후군은 침 연구가 비교적 많이 축적된 대표 신경포착질환입니다. 2023 systematic review/meta-analysis는 **16 RCT·1,025명**을 포함했고, 침을 보조치료로 사용한 연구에서 증상·기능·통증·전기생리 지표의 긍정적인 결과가 보고되었습니다. PMID `36908786`.

2024년에는 손목터널증후군 침 치료에 대한 **9개 systematic review/meta-analysis를 종합한 overview**가 발표되어 통증과 임상 outcome의 전체 근거지형을 평가했습니다. PMID `39640077`, DOI `10.1016/j.imr.2024.101088`.
