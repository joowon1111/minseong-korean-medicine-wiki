# 의가·인물 {#_1}

한의학은 여러 시대의 의가들이 고전과 임상 경험을 해석하고 발전시키며 형성된 의학 체계다.

| 의가 | 핵심 연결 |
|---|---|
| [장중경](zhang-zhongjing.md) | 상한론·금궤요략·고방 |
| [손사막](sun-simiao.md) | 비급천금요방·임상의학·의덕 |
| [이동원](li-dongyuan.md) | 비위론·비위기허·보중익기탕 |
| [허준](heo-jun.md) | 동의보감·조선 의학의 집대성 |
| [이제마](lee-je-ma.md) | 동의수세보원·사상의학 |

## 인물마다 어떤 질문이 다른가요? {#reading-questions}

장중경 계통에서는 맥증과 처방의 대응, 손사막에서는 여러 임상 분야와 식치·양생, 이동원에서는 비위·원기와 내상, 허준에서는 방대한 지식의 편집과 탐색, 이제마에서는 개인차와 체질병증을 중심으로 읽습니다. 서로 다른 학설을 한 줄의 발전 순서로 놓기보다 각 의가가 어떤 문제를 설명하려 했는지 비교하면 이해하기 쉽습니다.

한 처방이 여러 고전에 수록되었다면 최초 출전, 후대의 재수록, 가감·제형의 변화도 구분합니다. 책에 실려 있다는 이유만으로 그 책의 저자가 처음 만든 처방이라고 단정하지 않습니다. 상세 설명은 각 인물 문서에서 대표 저술과 처방으로 이어집니다.

## 근현대 한국 의학으로 이어 읽기 {#modern-korean}

[석곡 이규준](lee-gyujun.md)·[소문대요](../classics/somun-daeyo.md), [청강 김영훈](kim-young-hoon.md)·[청강의감](../classics/cheonggang-uigam.md)도 인물과 저술을 함께 읽는 경로입니다. 고전의 해석을 발전시키는 작업과 실제 진료 기록을 정리하는 작업은 자료의 성격이 다르므로 저술의 목적과 근거를 함께 확인합니다.
