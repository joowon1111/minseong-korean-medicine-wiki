# 태극침법의 역사와 형성

태극침법의 역사는 **사상의학에서 체질별 침치료를 모색한 배경 → 이병행의 선혈 체계 → 후대의 반응 관찰과 임상 연구**로 읽을 수 있습니다. [체질별 혈 구성](constitutions.md)을 옆에 놓고 보면 심경 오수혈과 원혈이 각각 어떤 역할로 도입되었는지 이해하기 쉽습니다.

## 이병행과 체질별 침치료 {#lee}

김재규의 2011년 논문은 《동의수세보원》의 소음인 합곡 활용과 체질에 맞는 침혈을 탐구하라는 취지를 태극침법의 배경으로 설명합니다. 이병행은 네 체질의 장부대소를 선혈에 적용하고, 심경 오수혈과 원혈의 보사로 구성한 침법을 제시했습니다. [김재규, 2011, 70쪽](https://koreascience.kr/article/JAKO201121554124305.page).

| 자료에서 확인하는 시점 | 내용과 확인 범위 |
|---|---|
| 1974년 발표에 관한 후대 기록 | 김재규(2011)는 《한방춘추》 발표를, 임교민·백진웅(2012)은 이병행의 《침도원류중마》를 중심으로 설명 |
| 《침도원류중마》 1974년판 | 임교민·백진웅은 행림서원판 342–353쪽의 체질·선혈·진단 설명을 인용·분석 |
| 1978년 이후 임상 계승 | 김재규는 경희의료원에서 박인상에게 태극침법과 심와부 압통 관찰을 배웠다고 기술 |
| 2011년 임상 기술 | 김재규의 임상 적응증 논문과 아건강 환자의 진료기록 보고로 활용·평가 방법이 구체화 |
| 2012–2014년 연구 | 오장원혈침법의 이론적 확장 제안, 체질별 HRV 연구와 만성 근골격계 통증의 후향적 연구 |
| 2022년 진료지침 | 사상체질병증의 침치료 개요와 소양인 불면 권고안 R20에 태극침법 수록 |

2019년 고찰의 참고문헌은 같은 책을 한방춘추사판 344–353쪽으로 표기합니다. 출판사·쪽수 표기의 차이는 각 논문에 귀속하며 하나의 확인된 판본으로 합치지 않습니다. [김재규, 2019 참고문헌](https://doi.org/10.13048/jkm.19019).

초기 문헌의 내용은 여기서 **원본 전체를 직접 대조한 전사본이 아니라, 출처를 명시한 후대 논문의 인용·분석을 통해 정리**했습니다. 1974년의 매체별 설명은 각각의 자료에 귀속하고 창안의 세부 연월이나 판본 계보를 덧붙이지 않습니다. [임교민·백진웅, 2012, 25–27쪽·참고문헌](https://koreascience.kr/article/JAKO201225150621736.page).

## 사상의학과 연결해 읽는 범위 {#sasang}

태양인·태음인·소양인·소음인이라는 이름과 장부대소의 틀은 사상의학과 연결됩니다. 태극침법의 실제 치료에는 여기에 **심경 오수혈의 배속과 경맥 원혈의 보사**라는 선혈 체계가 더해집니다. 따라서 사상체질침이라는 넓은 이름 아래 등장하는 모든 침법이 태극침법의 세 혈 구성을 사용하는 것은 아닙니다.

2012년의 문헌 분석은 사상의학과 태극침법에서 같은 장부 명칭이 쓰이더라도 개념의 범위와 선혈 논리가 다를 수 있음을 다룹니다. 이 지식망에서는 체질명은 원문대로 유지하고, **태극침법 안에서의 선택 원리**와 사상의학의 [소증·체질병증 진단](../sasang-guideline/index.md#ordinary-symptoms)을 구분해 연결합니다. [문헌 분석](https://koreascience.kr/article/JAKO201225150621736.page) · [사상체질침법 연구 경향, 2019](https://koreascience.kr/article/JAKO201928951543862.page).

## 임상적 계승과 반응 관찰 {#succession}

김재규(2011)는 박인상에게 배운 심와부 압통 관찰과 김정제에게 배운 타진 관찰을 함께 사용한 경위를 설명합니다. 자신의 임상 적용에서는 보사에 호흡을 함께 사용했다고 밝혔습니다. 이는 창안자의 설명과 후대 임상가의 조정이 만나는 지점입니다. [체질 판별과 반응 관찰](assessment.md)에서 **초기 심경혈 반응·후대 복부 관찰·연구의 설문 판정**을 나누어 봅니다.

## 오장원혈침법: 후대의 확장 제안 {#extensions}

임교민·백진웅(2012)은 《영추·구침십이원》의 원혈 논의를 바탕으로, 태극침법의 네 치료혈 조합을 **열 가지 조합의 ‘오장원혈침법’**으로 넓히는 이론적 모형을 제안했습니다. 장부 원혈을 함께 활용하는 추가 모형도 논의합니다.

이것은 이병행의 네 체질 기본 처방에 새 혈을 일괄 추가한 표준형이 아니라 **해당 연구자들의 확장안**입니다. 심경혈 선택과 체질 판단을 포함한 태극침법 본체와 구별하고, 이 확장 모형의 존재를 임상시험 결과처럼 서술하지 않습니다. 원혈 쌍의 변형은 [구성 차이를 읽는 표](constitutions.md#variants)에서 확인합니다. [2012년 원문, 32–37쪽](https://koreascience.kr/article/JAKO201225150621736.page).
