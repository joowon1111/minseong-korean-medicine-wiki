# 태극침법의 체질 판별과 반응 관찰

태극침법의 선혈은 **체질을 먼저 추정하고, 침 자극 전후의 반응을 관찰해 구성을 검토하는 과정**으로 설명됩니다. 초기 심경혈 반응법, 후대의 복부 지표 관찰법, 연구에서 사용한 설문 판정은 서로 다른 방법입니다. 다음은 문헌을 읽기 위한 임상 과정의 정리입니다.

## 문헌별로 무엇을 관찰했나? {#methods}

| 자료 | 체질 판단·관찰 방법 | 사용한 혈 구성 |
|---|---|---|
| 이병행의 방법을 정리한 2012년 문헌 분석 | 체형의 둘레를 비교하는 척도법과 심경혈 자극에 대한 반응을 소개 | 체질별 심경 오수혈의 선택 |
| 김재규(2011)의 임상 기술 | 심와부 압통 변화, 간탁음 관찰을 함께 사용 | 심경혈 1개·원혈 2개의 기본형 |
| 김재규(2019)의 서술적 고찰 | 외형·성격·소증으로 체질을 추정한 뒤 기본형의 반응을 비교하고 재진 반응을 확인 | 감별 때는 추가혈 없이 기본 세 혈 사용 |
| 소양인·소음인·태음인 HRV 연구(2012·2013) | QSCC II 설문으로 연구 대상의 체질을 정하고 침법별 HRV 반응 비교 | 논문이 정한 양측 세 혈 구성 |

출처: [2012년 문헌 분석](https://koreascience.kr/article/JAKO201225150621736.page), [2011년 임상 기술](https://koreascience.kr/article/JAKO201121554124305.page), [2019년 반응 지표 고찰](https://doi.org/10.13048/jkm.19019), [HRV 연구 목록](evidence.md#hrv).

## 심경혈 반응에서 기본형으로 {#heart-response}

| 문헌에서 비교하는 심경혈 | 연결하는 체질 | 이어지는 원혈 보사 |
|---|---|---|
| 소부 HT8 보 | 태양인 | [태충 보·태연 사](constitutions.md#taeyangin) |
| 영도 HT4 보 | 태음인 | [태연 보·태충 사](constitutions.md#taeeumin) |
| 소해 HT3 보 | 소양인 | [태계 보·태백 사](constitutions.md#soyangin) |
| 신문 HT7 보 | 소음인 | [태백 보·합곡 사](constitutions.md#soeumin) |

심경혈 한 자리의 반응을 보는 설명과, 기본 세 혈을 모두 사용한 후 반응을 보는 설명을 구별합니다. 김재규의 2019년 고찰은 심경의 인접혈만으로 판단하는 경우를 논의하고, **심와부 압통과 간탁음의 변화를 기본 세 혈의 반응과 함께 비교하는 방식**을 제시했습니다. [원문 90–91쪽](https://koreascience.kr/article/JAKO201924064455274.page).

## 복부 반응을 관찰하는 임상 흐름 {#workflow}

1. **소증·현재 증상과 체질 후보를 정리합니다.** 수면·소화·발한·대소변, 외형과 문진 정보를 확인합니다. 사상의학의 [소증과 병증 평가](../sasang-guideline/index.md#diagnostic-workflow)도 함께 읽습니다.
2. **시술 전 지표를 기록합니다.** 해당 문헌에서는 심와부의 압통과 양측 협륵부 타진에서 관찰한 ‘간탁음’을 사용합니다. 어떤 부위의 압통·소리를 어떤 기준으로 평가했는지 남깁니다.
3. **추정 체질의 기본 세 혈과 보사를 선택합니다.** 2019년 설명에서는 체질 감별 단계에 곡지·족삼리 등 추가혈을 섞지 않습니다.
4. **같은 조건에서 반응을 비교합니다.** 압통의 변화와 환자가 느끼는 차이를 기록하고, 판단이 불분명하면 체질 후보와 구성을 다시 검토합니다.
5. **다음 진료에서 증상·기능을 재확인합니다.** 즉각적인 복부 반응뿐 아니라 수면·통증·일상 기능과 치료 후 불편을 함께 평가합니다.

2011년 논문은 시술 1–2분 뒤의 압통 반응을, 2019년 논문은 비교 관찰 사이 30초–1분의 간격과 재진 확인을 기술합니다. 이 시간과 압통 감소 비율은 **저자가 제시한 관찰 방식**이며, 모든 진료에 적용되는 진단 정확도나 고정된 판정 기준으로 바꾸어 제시하지 않습니다.

‘간탁음’은 이 문헌들의 타진 지표 이름입니다. 이를 간비대·간질환의 확진 소견이나 혈액순환 검사 수치로 치환하지 않습니다. 2019년 자료는 임상 경험을 정리한 서술적 고찰이므로, 독립된 기준검사와 비교한 민감도·특이도를 산출한 진단시험과 구별해 읽습니다.

## 보사와 치료 경과 기록 {#record}

| 기록 항목 | 남길 내용 |
|---|---|
| 체질 판단 | 사용한 문진·소증·설문 또는 반응 관찰 방법 |
| 혈 구성 | 혈명·WHO 코드·좌우와 각 혈의 補·瀉 |
| 자극 조건 | 사용한 보사법·유침 조건·호흡 병행 여부 |
| 반응 지표 | 시술 전후 같은 부위의 압통, 타진 지표, 관찰 시점 |
| 임상 목표 | 통증·움직임, 잠드는 시간·야간 각성, 소화 불편 등 |
| 재평가 | 다음 진료의 지속 효과, 약물·병행 치료, 이상반응 |

2011·2019년 임상 기술의 호흡 병행과 2012·2013년 연구의 영수·염전·구륙보사 조건은 [연구 원문](evidence.md#hrv)에 귀속합니다. 같은 ‘보’와 ‘사’라는 이름만으로 자극량이 같다고 간주하지 않습니다. 실제 시술은 위치·해부학과 환자 상태를 확인하는 의료행위이며, [안전·위험신호](../acupuncture-integrated/safety.md)와 [치료 경과·재평가](../acupuncture-integrated/followup.md)를 함께 적용합니다.
