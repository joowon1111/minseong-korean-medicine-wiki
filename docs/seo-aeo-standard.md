# SEO·AEO·GEO 문서 표준

민성 한의학 아카이브는 한의학 정보를 **사람이 읽기 쉽고 문서의 주제와 관계가 명확하게 드러나는 형태**로 정리합니다.

## 문서의 주제

각 문서는 하나의 중심 주제를 명확하게 다룹니다.

- 증상·질환
- 본초
- 방제
- 환자가 자주 묻는 질문
- 고전과 한의학 이론
- 치료와 임상정보
- 연구·참고자료
- 주제별 허브와 지식망

## 제목과 설명

제목은 문서의 핵심 주제나 질문을 직접 표현하고, description은 문서에서 다루는 내용을 간결하게 설명합니다.

## 환자 검색형 콘텐츠

증상이나 질문을 다루는 문서는 가능한 한 다음과 같이 구성합니다.

**핵심 내용 → 증상의 특징과 패턴 → 감별과 위험신호 → 한의학적 해석 → 치료 접근 → 관련 자료 → 연결 문서**

전문용어와 일상적인 표현을 자연스럽게 연결합니다.

## 한의학 전문 콘텐츠

전문 문서는 **원전과 출전, 병증과 치법, 본초와 처방 구성, 임상적 활용, 관련 연구**를 서로 구분하면서 연결합니다.

## 연구·참고자료

연구를 소개할 때에는 문서의 주제와 직접 관련된 연구를 우선하며, 연구 대상과 방법, 주요 결과와 참고정보를 함께 살펴볼 수 있도록 구성합니다.

## 내부 지식망

아카이브의 문서는 다음과 같이 서로 연결됩니다.

**증상·질환 ↔ 한의학적 해석 ↔ 본초 ↔ 방제 ↔ 치료 ↔ 고전 ↔ 연구**

세부문서를 모두 메뉴에 나열하기보다 핵심색인과 주제 허브를 통해 관련 정보로 이동할 수 있도록 합니다.

## 질문형 콘텐츠

같은 증상이라도 시간대, 유발상황, 연령이나 동반 증상이 다르면 별도의 질문으로 다룰 수 있습니다. 각 문서는 해당 상황을 명확하게 설명하고 관련 질문과 연결합니다.

## 주요 보익 콘텐츠

녹용, 공진단, 경옥고 등 주요 보익 주제는 구성 본초, 관련 처방, 원전과 연구 자료를 함께 탐색할 수 있도록 연결합니다.
