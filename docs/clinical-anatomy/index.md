# 근육·말초신경 임상해부학 {#_1}

<span id="dermatomemyotome"></span>


이 섹션은 근육 이름을 암기하는 해부학이 아니라 **통증·저림·근력저하를 해부학적으로 추적하기 위한 임상 지식망**입니다.

감각이 이상한 위치, 약해진 동작, 신경근과 말초신경의 분포를 차례로 대조하는 자료입니다. 부위별 문서를 오가며 단편적인 신경 이름을 확인하는 대신, 아래에서 상지·하지·경부·둔부의 관계를 함께 비교할 수 있습니다.

[**MPS·근육·근막 아틀라스 →**](mps-atlas.md){ .md-button .md-button--primary }

주요 근육·근육군 20개를 8개 부위의 해부 도해로 살펴보고, 조직층·통증유발점·연관통 평가와 침치료 계획을 연결합니다.

## Dermatome·Myotome 임상지도 {#dermatome-myotome}

### 임상적 의미
- **Dermatome**: 하나의 spinal nerve root와 주로 연결되는 피부 감각영역
- **Myotome**: 특정 spinal segment와 주로 연결되는 근육·움직임

### 대표 분절

| 신경근 | 대표 감각영역 | 대표 움직임·근육 |
|---|---|---|
| C5 | 상완 외측 | 어깨 외전, 삼각근 |
| C6 | 전완 외측·엄지 | 팔꿈치 굴곡·손목 신전 |
| C7 | 중지 중심 | 팔꿈치 신전·손가락 신전 |
| C8 | 손 척측 | 손가락 굴곡 |
| T1 | 상지 내측 | 손가락 벌림·모음 |
| L2 | 대퇴 전면 | 고관절 굴곡 |
| L3 | 무릎 주변 | 무릎 신전 |
| L4 | 하퇴 내측 | 무릎 신전·발목 배굴 |
| L5 | 발등·엄지 | 엄지 신전·고관절 외전 |
| S1 | 발 외측 | 발목 저측굴곡 |

Dermatome 지도는 문헌과 개인에 따라 경계가 다를 수 있어 **증상분포 + 근력 + 반사 + 말초신경 분포**를 함께 봅니다.



## 상지 말초신경·근육 임상지도 {#upper-limb}

### 정중신경
원회내근·전완 굴곡근군·무지구 기능과 연결됩니다. 손목터널과 원회내근 주변이 대표적인 포착 감별부위입니다.

### 척골신경
전완 척측 굴곡근과 손의 여러 내재근에 관여합니다. 팔꿈치 주관과 Guyon canal을 구분합니다.

### 요골신경
상완삼두근과 손목·손가락 신전근군에 관여하며 상완, radial tunnel, posterior interosseous nerve 구간을 살펴봅니다.

### 액와신경
삼각근·소원근과 연결되며 어깨 외전 기능과 상완 외측 감각을 함께 봅니다.

### 견갑상신경
극상근·극하근과 연결되어 어깨 외전 시작과 외회전 기능을 살펴봅니다.

→ [신경포착증후군](../nerve-entrapment/index.md)


## 하지 말초신경·근육 임상지도 {#lower-limb}

### 좌골신경
둔부에서 대퇴후면으로 주행하며 경골신경과 총비골신경으로 나뉩니다.

### 총비골신경
비골두 주변이 대표적 포착부위입니다. 전경골근·장무지신근 등 배굴 기능과 발등 감각을 살펴봅니다.

### 경골신경
하퇴 후면 근육과 발바닥 감각·근육에 연결되며 족근관을 주요 포착부위로 봅니다.

### 대퇴신경
장요근 주변에서 대퇴 전면으로 이어지며 대퇴사두근의 무릎 신전과 연결됩니다.

### 외측대퇴피신경
운동기능보다 대퇴 외측 피부감각이 핵심입니다.

## 경부·견갑대 근육과 신경 {#neck-shoulder}

경부와 견갑대에서는 **신경근병증, 말초신경 포착, 근육성 통증**이 서로 비슷하게 느껴질 수 있어 함께 봅니다.

| 구조 | 주요 기능 | 신경 연결 |
|---|---|---|
| 삼각근 | 어깨 외전 | 액와신경 |
| 극상근 | 외전 시작 | 견갑상신경 |
| 극하근 | 외회전 | 견갑상신경 |
| 전거근 | 견갑골 전인·상방회전 | 장흉신경 |
| 승모근 | 견갑골 안정·회전 | 부신경 |
| 능형근 | 견갑골 내전 | 견갑배신경 |

## 둔부·고관절 근육과 신경 {#hip-gluteal}

### 이상근
고관절 외회전·안정과 관련되며 좌골신경과의 해부학적 관계 때문에 심부둔부 통증 평가에서 중요합니다.

### 중둔근
고관절 외전과 골반 안정에 관여하며 상둔신경의 지배를 받습니다.

### 대둔근
고관절 신전에 관여하며 하둔신경과 연결됩니다.

### 장요근
고관절 굴곡의 핵심 구조이며 요신경총과 해부학적으로 가까운 영역입니다.

`둔부통증 → 요추 신경근 → 좌골신경 → 심부둔부 근육 → 고관절 기능`

→ [심부둔부·좌골신경](../nerve-entrapment/deep-gluteal-sciatic.md)


## 말초신경 포착부위 지도 {#peripheral-nerve-map}

말초신경 포착은 신경이 **fibro-osseous tunnel, fibromuscular tunnel, 근육 관통부** 등을 지나는 특정 해부학적 위치에서 흔히 발생합니다.

### 상지
- 정중신경 → 원회내근 주변 · 손목터널
- 척골신경 → 주관 · Guyon canal
- 요골신경 → radial tunnel · 후골간신경
- 견갑상신경 → suprascapular notch · spinoglenoid notch

### 하지
- 좌골신경 → 심부둔부
- 총비골신경 → 비골두
- 경골신경 → 족근관
- 외측대퇴피신경 → 서혜인대 주변

임상적으로 병력과 신경학적 진찰이 기본이며 필요에 따라 전기진단, 초음파, MRI가 포착 위치와 원인 평가에 도움을 줄 수 있습니다.

→ [신경포착증후군](../nerve-entrapment/index.md)


## 침구와 해부학 {#_4}

361경혈의 해부·신경해부학적 특성을 정리한 연구에서는 각 경혈에 대해 층별 해부, 운동신경, 피부감각신경, dermatome 및 관련 근육·myotome을 연결하는 체계가 제안되었습니다. PMID `24139465`.

조직층의 자극이 구심성 감각 입력으로 전달되는 과정은 [말초신경과 침 자극](../acupuncture-science/peripheral-afferent.md), 척수분절과 원위부 자극의 관계는 [침과 통증조절](../acupuncture-science/pain-modulation.md)에서 이어집니다.
