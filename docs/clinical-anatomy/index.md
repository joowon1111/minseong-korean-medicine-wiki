# 근육·말초신경 임상해부학

이 섹션은 근육 이름을 암기하는 해부학이 아니라 **통증·저림·근력저하를 해부학적으로 추적하기 위한 임상 지식망**입니다.

## 핵심 구조

`증상 위치 → dermatome → myotome → spinal root → peripheral nerve → muscle → entrapment site → acupoint`

Dermatome은 한 신경근의 감각영역을 이해하는 기본 도구지만 개인차와 영역 중첩이 있으므로 절대적인 경계선으로 보지 않습니다. 근육 역시 하나의 신경근만으로 움직이는 경우보다 여러 분절이 함께 관여하는 경우가 많습니다.

## 침구와 해부학

361경혈의 해부·신경해부학적 특성을 정리한 연구에서는 각 경혈에 대해 층별 해부, 운동신경, 피부감각신경, dermatome 및 관련 근육·myotome을 연결하는 체계가 제안되었습니다. PMID `24139465`.
