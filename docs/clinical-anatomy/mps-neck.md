# 목·뒤통수 근육·MPS 아틀라스 {#overview}

목을 돌릴 때의 불편, 어깨를 으쓱하는 습관, 뒤통수 통증을 근육별 기능과 연결합니다. 승모근 아래에는 견갑거근과 더 깊은 후두하근군이 있어, 같은 피부 부위라도 평가할 조직층이 다릅니다.

## 상부 승모근 {#upper-trapezius}

**Upper trapezius**

| 해부 항목 | 요점 |
|---|---|
| 주요 부착 | 뒤통수·목덜미 인대 → 가쪽 빗장뼈·어깨뼈 부위 |
| 기능 | 견갑골 거상·상방회전에 참여 |
| 신경지배 | 부신경의 운동지배; C3–C4 감각성 기여 |

**평가:** 어깨를 올릴 때와 팔을 지지해 내렸을 때의 목·어깨 불편을 비교합니다. 촉진으로 나타난 통증이 평소 통증인지 묻습니다.

**함께 구분할 것:** 경추 신경근병증, 견갑대 기능 저하, 어깨 관절 통증을 함께 구분합니다.

[그림에서 보기](../assets/mps-atlas/neck.svg#upper-trapezius)

## 견갑거근 {#levator-scapulae}

**Levator scapulae**

| 해부 항목 | 요점 |
|---|---|
| 주요 부착 | C1–C4 가로돌기 → 견갑골 위각·안쪽 위모서리 |
| 기능 | 견갑골 거상 |
| 신경지배 | 견갑배신경 및 C3–C4 가지 |

**평가:** 고개 회전과 견갑골 위치를 바꿀 때 목 뒤가쪽·견갑골 위각 주변 증상이 어떻게 달라지는지 기록합니다.

**함께 구분할 것:** 견갑골 위각 압통만으로 원인을 확정하지 않고 목 관절과 신경 증상을 살핍니다.

[그림에서 보기](../assets/mps-atlas/neck.svg#levator-scapulae)

## 후두하근군 {#suboccipitals}

**Suboccipital muscles**

| 해부 항목 | 요점 |
|---|---|
| 주요 부착 | C1·C2와 뒤통수뼈 사이; 아래머리빗근은 C2–C1 연결 |
| 기능 | 머리 신전·회전의 세밀한 조절 |
| 신경지배 | 후두하신경(C1 뒤가지) |

**평가:** 큰·작은뒤머리곧은근과 위·아래머리빗근을 하나의 깊은 근육군으로 읽습니다. 상부 경추 움직임과 두통의 관계를 확인합니다.

**함께 구분할 것:** 전기가 오는 듯한 후두통, 감각 이상, 편두통 양상은 근육 압통과 구별합니다.

[그림에서 보기](../assets/mps-atlas/neck.svg#suboccipitals)

## 부위별 임상 연결 {#clinical}

목 회전 범위와 팔의 감각·근력을 함께 기록합니다. 목·견갑대 근육의 압통이 두통과 동반될 수 있으나, 갑작스러운 극심한 두통·새 신경학적 증상은 별도 평가가 우선입니다. 후두하부의 깊은 곳에는 척추동맥과 상부 경추 구조가 있어 피부 위치만으로 깊은 자극을 결정하지 않습니다.

[목 통증](../conditions/neck-pain.md) · [긴장형두통](../conditions/tension-headache.md) · [경부·견갑대 신경](index.md#neck-shoulder)

근육을 대상으로 침치료를 계획할 때는 [조직층·안전](mps-atlas.md#treatment)과 [치료 전후 재평가](../acupuncture-integrated/followup.md)를 함께 읽습니다.
