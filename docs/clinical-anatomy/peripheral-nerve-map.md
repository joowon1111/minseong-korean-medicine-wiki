# 말초신경 포착부위 지도

말초신경 포착은 신경이 **fibro-osseous tunnel, fibromuscular tunnel, 근육 관통부** 등을 지나는 특정 해부학적 위치에서 흔히 발생합니다.

## 상지
- 정중신경 → 원회내근 주변 · 손목터널
- 척골신경 → 주관 · Guyon canal
- 요골신경 → radial tunnel · 후골간신경
- 견갑상신경 → suprascapular notch · spinoglenoid notch

## 하지
- 좌골신경 → 심부둔부
- 총비골신경 → 비골두
- 경골신경 → 족근관
- 외측대퇴피신경 → 서혜인대 주변

임상적으로 병력과 신경학적 진찰이 기본이며 필요에 따라 전기진단, 초음파, MRI가 포착 위치와 원인 평가에 도움을 줄 수 있습니다.
