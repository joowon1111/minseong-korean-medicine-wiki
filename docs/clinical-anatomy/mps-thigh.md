# 허벅지·무릎 근육·MPS 아틀라스 {#overview}

앞쪽의 대퇴직근·내측광근, 뒤쪽의 햄스트링군, 안쪽의 장내전근을 비교합니다. 두 관절을 지나는 근육과 한 관절 중심의 근육을 나누면 계단·달리기·방향 전환에서 어느 동작이 증상을 만드는지 이해하기 쉽습니다.

## 대퇴직근 {#rectus-femoris}

**Rectus femoris**

| 해부 항목 | 요점 |
|---|---|
| 주요 부착 | 아래앞엉덩뼈가시·비구 위 → 슬개골·슬개인대를 거쳐 정강뼈 |
| 기능 | 고관절 굽힘·무릎 폄 |
| 신경지배 | 대퇴신경 |

**평가:** 넙다리곧은근이라고도 합니다. 고관절·무릎 각도를 바꿀 때 앞허벅지 불편과 무릎 폄 기능을 비교합니다.

**함께 구분할 것:** 근육 손상, 대퇴사두근·슬개 힘줄병, 고관절에서 전달되는 통증을 구분합니다.

[그림에서 보기](../assets/mps-atlas/thigh.svg#rectus-femoris)

## 내측광근 {#vastus-medialis}

**Vastus medialis**

| 해부 항목 | 요점 |
|---|---|
| 주요 부착 | 대퇴골 안쪽 뒤면 → 슬개골·안쪽 지지조직 |
| 기능 | 무릎 폄 |
| 신경지배 | 대퇴신경 |

**평가:** 안쪽넓은근이라고도 합니다. 무릎 폄 근력과 계단 동작을 보고, 무릎 위안쪽 압통이 평소 증상인지 확인합니다.

**함께 구분할 것:** 내측광근 한 부분의 약화만으로 모든 슬개대퇴 통증을 설명하지 않고 관절·다리 전체 부하를 봅니다.

[그림에서 보기](../assets/mps-atlas/thigh.svg#vastus-medialis)

## 햄스트링군 {#hamstrings}

**Hamstrings**

| 해부 항목 | 요점 |
|---|---|
| 주요 부착 | 주로 궁둥뼈결절 → 정강뼈·종아리뼈; 대퇴이두근 짧은갈래는 대퇴골 뒤쪽에서 시작 |
| 기능 | 무릎 굽힘·고관절 신전; 무릎 굽힌 상태의 안팎돌림 |
| 신경지배 | 주로 좌골신경의 경골부분; 대퇴이두근 짧은갈래는 총비골부분 |

**평가:** 엉덩관절을 굽힌 상태의 무릎 폄, 저항성 무릎 굽힘, 달리기에서 뒤허벅지 통증의 위치와 힘을 비교합니다. 허리에서 이어지는 당김과 국소 근육·힘줄 통증을 나누어 기록합니다.

**함께 구분할 것:** 급성 근육 손상, 궁둥뼈결절의 근위 햄스트링 힘줄병, 좌골신경·요추 신경근 증상을 구분합니다.

[그림에서 보기](../assets/mps-atlas/thigh.svg#hamstrings)

## 장내전근 {#adductor-longus}

**Adductor longus**

| 해부 항목 | 요점 |
|---|---|
| 주요 부착 | 두덩뼈 몸통 → 대퇴골 거친선 중간부 |
| 기능 | 고관절 모음; 굽힘을 보조 |
| 신경지배 | 폐쇄신경(L2–L4) |

**평가:** 다리를 모으는 저항과 방향 전환에서 사타구니·안쪽 허벅지 증상이 재현되는지 확인합니다. 고관절 가동범위와 보행·운동 부하를 함께 봅니다.

**함께 구분할 것:** 내전근 손상·힘줄병, 고관절 관절병, 서혜부 탈장과 치골 주변 통증을 구분합니다.

[그림에서 보기](../assets/mps-atlas/thigh.svg#adductor-longus)

## 부위별 임상 연결 {#clinical}

계단·앉았다 일어서기·걷기에서 증상을 기록하고 무릎 부종, 관절선 압통, 잠김 여부를 확인합니다. 근육의 압통과 관절 병변이 함께 있을 수 있어 치료 후에는 실제 동작의 변화를 비교합니다.

[무릎 통증](../conditions/knee-pain.md) · [고관절·엉덩관절 통증](../conditions/hip-pain.md) · [좌골신경통](../conditions/sciatica.md) · [근골격 기능 평가](../acupuncture-integrated/musculoskeletal.md)

근육을 대상으로 침치료를 계획할 때는 [조직층·안전](mps-atlas.md#treatment)과 [치료 전후 재평가](../acupuncture-integrated/followup.md)를 함께 읽습니다.
