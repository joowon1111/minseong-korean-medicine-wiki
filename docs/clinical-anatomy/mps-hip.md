# 엉덩이·고관절 근육·MPS 아틀라스 {#overview}

엉덩이 가쪽의 중둔근·소둔근은 보행 중 골반 조절에 중요하고, 이상근은 둔부 깊은 곳에 놓입니다. 표층과 심층을 분리해 고관절·좌골신경과의 관계를 읽습니다.

## 중둔근 {#gluteus-medius}

**Gluteus medius**

| 해부 항목 | 요점 |
|---|---|
| 주요 부착 | 장골 바깥면 → 대퇴골 큰돌기 |
| 기능 | 고관절 벌림·골반 조절 |
| 신경지배 | 상둔신경 |

**평가:** 중간볼기근이라고도 합니다. 한발 서기·보행에서 골반과 몸통의 보상 움직임, 가쪽 압통을 봅니다.

**함께 구분할 것:** 큰돌기 통증은 둔근 힘줄병·점액낭 주변 문제와 함께 평가합니다.

[그림에서 보기](../assets/mps-atlas/hip.svg#gluteus-medius)

## 소둔근 {#gluteus-minimus}

**Gluteus minimus**

| 해부 항목 | 요점 |
|---|---|
| 주요 부착 | 장골 바깥면의 깊은 부위 → 큰돌기 |
| 기능 | 고관절 벌림·안쪽돌림 |
| 신경지배 | 상둔신경 |

**평가:** 작은볼기근이라고도 합니다. 중둔근 아래의 깊은 층임을 먼저 이해하고 고관절 기능과 증상 분포를 대조합니다.

**함께 구분할 것:** 가쪽 다리 통증의 원인을 그림 한 장으로 결정하지 않고 요추·고관절·신경 소견을 확인합니다.

[그림에서 보기](../assets/mps-atlas/hip.svg#gluteus-minimus)

## 이상근 {#piriformis}

**Piriformis**

| 해부 항목 | 요점 |
|---|---|
| 주요 부착 | 천골 앞면 → 큰궁둥구멍을 지나 큰돌기 |
| 기능 | 고관절 바깥돌림; 굽힌 상태의 벌림 |
| 신경지배 | 이상근신경(S1–S2) |

**평가:** 궁둥구멍근이라고도 합니다. 앉기·고관절 회전에서 둔부 증상과 다리로 퍼지는 느낌을 따로 기록합니다.

**함께 구분할 것:** 이상근 압통과 좌골신경 포착은 같은 진단이 아닙니다. 좌골신경 주행 변이와 다른 심부둔부 원인을 고려합니다.

[그림에서 보기](../assets/mps-atlas/hip.svg#piriformis)

## 부위별 임상 연결 {#clinical}

한발 서기, 걷기, 고관절 움직임과 통증을 함께 기록합니다. 둔부에서 다리로 퍼지는 통증은 요추 신경근·고관절·힘줄·심부둔부 구조를 비교해야 합니다. 특히 저림·감각저하·근력저하가 있으면 신경 평가를 포함합니다.

[심부둔부·좌골신경](../nerve-entrapment/deep-gluteal-sciatic.md) · [좌골신경통 근거](../authority/conditions/sciatica.md) · [둔부 해부학](index.md#hip-gluteal)

근육을 대상으로 침치료를 계획할 때는 [조직층·안전](mps-atlas.md#treatment)과 [치료 전후 재평가](../acupuncture-integrated/followup.md)를 함께 읽습니다.
