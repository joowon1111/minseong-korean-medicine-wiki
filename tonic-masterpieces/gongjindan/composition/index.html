    공진단 구성·방의¶

    공진단은 녹용·당귀·산수유의 보익과 사향의 개규·활혈통락을 결합합니다. 처방 의미와 출전별 약량은 공진단 본초 해설에서 읽고, 이 문서에서는 실제 원료·가감·제형을 확인하는 항목을 정리합니다.

    원방과 가감방을 대조하는 순서¶

    확인 항목 조제·제조 자료에서 읽을 내용 방의와 연결하는 이유
    출전·구성 시재백일선방·동의보감 계열, 위씨가장방형, 후대 활투와 실제 가감방 사향·침향·포부자와 가미 약재의 배합 방향을 구체화
    녹용 기원종·산지·사용 부위·가공·배합량 보양·익정혈·강근골의 원료를 확인
    당귀 참당귀·일당귀·중국당귀의 학명, 부위·주세·주초 보혈·활혈 역할과 실제 사용 원료를 연결
    산수유 기원·성숙 과육·핵 제거·수치·배합량 보간신·수렴의 약용부위와 품질 확인
    사향 약용 규격·유통 이력·검사자료·환당 함량 소량 배합의 정체성과 혼합 균일성 확인
    침향·목향류 기원·약용부위·성분 규격과 추가·대체량 이기·온중 배합의 실제 내용을 확인
    인삼·숙지황 등 가미 약재별 수치·함량과 전체 원료량 보기와 보혈·자음의 비중을 구분
    환제·탕제·추출제 분말·농축비·결합재료·환 무게·보관·복용량 제형에 맞는 복용 계획과 연구 제제를 대조

    원전의 녹용·당귀·산수유 각 4량과 사향 반량은 전체 제조 배합의 기록입니다. 현재 조제품은 환당 총량과 약재별 실제 함량을 확인하며, 꿀·결합재료·금박 등도 조성 기록에 함께 표시합니다.

    주머니사향과 분말사향을 확인할 때¶

    보사향·주머니사향과 분말사향은 원료의 형태·가공과 검사자료를 구분해 살피는 항목입니다. 주머니를 포함한 총중량과 실제 배합하는 사향 내용물의 양을 나누어 기록하고, 분말은 기원·가공·규격검사와 보관 이력을 확인합니다. 무스콘 등 지표성분 자료는 원료 동일성·순도·전체 품질관리와 함께 읽습니다.

    원전의 사향 별연(別研)은 따로 곱게 가는 제조 과정입니다. 현대 조제에서는 정량·분쇄·혼합·환제화와 보관을 관리해 소량 성분이 고르게 배합되도록 합니다. 사향의 원료·규격

    가감방의 장점을 활용하는 기록¶

    사향공진단은 네 약의 보익·소통 배합을, 침향 가감방은 이기·강기·온중을, 인삼·숙지황 가미방은 보기·보혈·자음의 비중을 살펴 선택합니다. 목향을 쓰면 목향·토목향의 기원을 기록하고, 포부자를 쓰는 문헌형은 법제와 용량·전탕·병용약을 확인합니다. 출전별 가감 비교

    기록은 현재 허손·냉열·소화 → 선택한 구성과 제형 → 실제 복용량 → 피로·활동·수면·식사 변화로 이어갑니다. 사람 대상 연구는 사용한 제제·대상·결과지표를 기준으로 읽고, 실제 복용 후에도 같은 기능 항목을 추적합니다.
