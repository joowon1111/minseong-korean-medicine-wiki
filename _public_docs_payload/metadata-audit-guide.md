# 문서 메타데이터 가이드

문서의 메타데이터는 검색엔진과 AI가 페이지의 주제와 범위를 이해하고, 사용자가 원하는 정보를 쉽게 찾도록 돕습니다.

## 기본 항목

```yaml
---
title: 문서 제목
description: 문서의 핵심 내용을 설명하는 한 문장
tags: [핵심태그1, 핵심태그2, 핵심태그3]
---
```

## title

문서가 무엇에 관한 것인지 가장 직접적으로 표현합니다.

증상·질환은 일반적으로 사용하는 명칭을 우선하고, 자연어 질문 콘텐츠는 실제 질문 형태를 사용할 수 있습니다.

## description

문서의 핵심 범위를 간결하게 설명합니다.

- **증상·질환** — 증상, 감별, 한의학적 해석과 치료
- **방제** — 출전, 구성, 방의, 활용과 현대 연구
- **본초** — 기원, 성미·귀경, 효능, 처방에서의 역할과 연구
- **질문형 문서** — 질문에 대한 핵심 답변과 구분해야 할 상황

## tags

태그는 문서의 핵심 주제와 분류를 나타냅니다. 지나치게 많은 유사 태그를 나열하기보다 실제 탐색에 도움이 되는 핵심어를 사용합니다.

## 본문 제목

H1은 페이지의 중심 주제를 명확하게 나타내며 메타데이터의 `title`과 의미상 일치하도록 작성합니다.

## 핵심 답변

환자 질문이나 증상을 다루는 문서는 가능하면 문서 앞부분에서 핵심 내용을 바로 확인할 수 있도록 구성합니다.

이후 증상 패턴, 감별, 한의학적 해석, 치료와 관련 연구를 단계적으로 설명합니다.

## 내부링크

문서는 관련된 증상·본초·방제·치료·연구 문서로 자연스럽게 연결합니다.

세부문서는 다음과 같은 탐색 구조를 통해 찾을 수 있습니다.

**AI 핵심색인 → 주제 허브 → 세부문서**

## 연구 정보

현대 연구를 소개할 때에는 가능한 범위에서 연구 대상, 연구방법, 주요 결과와 참고문헌 정보를 함께 제공합니다.
