# 극혈(郄穴) 완전 정리

## 십이경맥 극혈

| 경맥 | 극혈 |
|---|---|
| 폐 LU | LU6 공최 |
| 대장 LI | LI7 온류 |
| 위 ST | ST34 양구 |
| 비 SP | SP8 지기 |
| 심 HT | HT6 음극 |
| 소장 SI | SI6 양로 |
| 방광 BL | BL63 금문 |
| 신 KI | KI5 수천 |
| 심포 PC | PC4 극문 |
| 삼초 TE | TE7 회종 |
| 담 GB | GB36 외구 |
| 간 LR | LR6 중도 |

## 기경의 극혈
- 음교맥: KI8 교신
- 양교맥: BL59 부양
- 음유맥: KI9 축빈
- 양유맥: GB35 양교

극혈은 전통적으로 급성·통증성·출혈성 증상과 연결해 활용해 왔으며, 실제 임상에서는 경맥 유주와 병증을 함께 봅니다.
