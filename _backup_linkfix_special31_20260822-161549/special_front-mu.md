# 모혈(募穴) 완전 정리

| 장부 | 모혈 |
|---|---|
| 폐 | LU1 중부 |
| 심포 | CV17 전중 |
| 심 | CV14 거궐 |
| 간 | LR14 기문 |
| 담 | GB24 일월 |
| 비 | LR13 장문 |
| 위 | CV12 중완 |
| 삼초 | CV5 석문 |
| 신 | GB25 경문 |
| 대장 | ST25 천추 |
| 소장 | CV4 관원 |
| 방광 | CV3 중극 |

모혈은 흉복부에서 해당 장부와 연결해 이해하는 특정혈입니다. 배수혈과 함께 보면 전면과 후면을 연결하는 배수모혈 구조가 됩니다.
