# 팔맥교회혈(八脈交會穴) 완전 정리

| 경혈 | 연결 기경 | 대표 짝 |
|---|---|---|
| SP4 공손 | 충맥 | PC6 내관 |
| PC6 내관 | 음유맥 | SP4 공손 |
| GB41 족임읍 | 대맥 | TE5 외관 |
| TE5 외관 | 양유맥 | GB41 족임읍 |
| SI3 후계 | 독맥 | BL62 신맥 |
| BL62 신맥 | 양교맥 | SI3 후계 |
| LU7 열결 | 임맥 | KI6 조해 |
| KI6 조해 | 음교맥 | LU7 열결 |

## 네 가지 대표 쌍

**공손 + 내관** → 충맥·음유맥  
**족임읍 + 외관** → 대맥·양유맥  
**후계 + 신맥** → 독맥·양교맥  
**열결 + 조해** → 임맥·음교맥
