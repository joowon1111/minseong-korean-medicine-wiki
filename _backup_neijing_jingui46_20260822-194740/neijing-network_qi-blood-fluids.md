# 기혈진액

기·혈·진액은 인체의 생명활동을 설명하는 핵심 개념이다.

```text
기
├─ 추동
├─ 온후
├─ 방어
└─ 고섭

혈
└─ 영양·윤택

진액
└─ 수분·윤택·대사
```

이 세 요소는 독립적으로 존재하기보다 장부와 경락의 기능 속에서 서로 영향을 주고받는다.
