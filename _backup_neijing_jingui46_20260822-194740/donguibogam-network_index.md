# 동의보감 임상 탐색 네트워크

《동의보감》은 인체와 질병, 본초·방제·침구를 한 체계 안에서 다루는 대표적인 한국 한의학 고전입니다. 이 네트워크는 원문을 반복 복제하기보다 **현재의 임상 지식망으로 들어가는 탐색층**으로 사용합니다.

## 여섯 임상 축
- [내경편](naegyeong.md) — 정·기·신·장부·기혈진액
- [외형편](oehyeong.md) — 두면·목·흉복·요배·사지 등 신체 부위
- [잡병편](japbyeong.md) — 내과·외감·허로·부인·소아 등 병증
- [탕액편](tangaek.md) — 본초·약성·배합·방제
- [침구편](chimgu.md) — 경락·경혈·자법·구법
- [양생·예방](yangsaeng-prevention.md) — 생활·계절·회복

## 현재 위키에서 읽는 순서
**환자 표현 → 위험신호·감별 → 동의보감의 병증·부문 → 한의 변증 → 본초·방제·경혈 → 현대 임상근거 → 재평가**
