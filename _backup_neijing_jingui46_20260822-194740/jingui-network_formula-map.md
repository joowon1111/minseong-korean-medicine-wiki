# 금궤요략 대표 처방 구조

금궤요략의 대표 처방은 병명보다 **병증 구조**와 함께 이해하는 것이 중요하다.

| 병증 축 | 대표 처방 예 |
|---|---|
| 담음·수기 | 영계출감탕·오령산·방기황기탕 |
| 흉비·심통 | 과루해백백주탕·과루해백반하탕·지실해백계지탕 |
| 허로 | 소건중탕·황기건중탕·서여환 |
| 부인병 | 당귀작약산·온경탕·계지복령환 |
| 복만·한산·숙식 | 병증 구조에 따른 온중·공하·소도 처방 |
