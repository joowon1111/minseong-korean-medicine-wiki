# 동의보감 공개 원문 자료의 출처와 가공

`source-manifest.json`과 `docs/assets/donguibogam/manifest.json`은 동일한 수록 범위를 기록합니다. 한의학고전DB 데이터는 사용하지 않았습니다. 브라우저의 일반 아카이브 검색은 원문 전사를 읽거나 다운로드하지 않습니다.

## 전사

- 허준 저, 한국어·중국어 위키문헌 사용자 전사·편집.
- 각 원본 문서의 수정판 ID, 고정 링크, 기여 이력, 원본 위키텍스트 SHA-256과 대응 영인 페이지를 manifest에 기록했습니다.
- 가져온 전사 및 전사에서 정리한 JSON 데이터는 **CC BY-SA 4.0**: https://creativecommons.org/licenses/by-sa/4.0/ 입니다. 고전 작품 자체의 권리와 현대 전사·편집의 이용조건을 구분합니다. 아카이브 자체의 독립 해설 전체에 이 이용조건을 확장하지 않습니다.
- 가공: 위키의 탐색·편집 UI를 제거하고 원문 본문을 평문으로 추출했습니다. 탕액편은 영인 페이지를 포함하는 `prp-pages-output`의 큰 글씨 항목명을 기준으로, 내경편은 확보된 문목의 제목을 기준으로 나누었습니다. 단락 간 공백을 정리하고 검색용 한글 표제와 존재하는 아카이브 문서의 연결을 추가했습니다. 한문 원문의 글자를 임의 교정하거나 새로운 번역을 생성하지 않았습니다.
- 탕액편의 세 권은 수록한 17개 부·서례 전사 전체를 담습니다. 각 페이지 전사는 교감 미완료(위키문헌 quality 1) 상태입니다. 내경편의 나머지와 외형·잡병·침구의 오자가 많은 대량 전사는 가져오지 않았습니다. 전권 텍스트화·정본·완역 완료를 주장하지 않습니다.
- 원본은 MediaWiki 공개 API에 서비스 식별 User-Agent를 명시하고 수정판 ID를 고정해 확인했습니다. 전사의 변경·재수록 시 원본의 기여 이력과 이용조건을 재확인하고 checksum·수록 범위를 갱신해야 합니다.

## 영인본

국립중앙도서관 디지털 자료 CNTS-00047980284, 목판본 23권 25책. Commons 파일의 `PD-scan / PD-South Korea`를 확인했습니다. 간행연도는 확인된 파일 서지에 없으므로 1613년 초간본으로 명명하지 않았습니다. 파일 순서를 원전의 편·권 순서로 임의 해석하지 않고 '영인본 제N책'으로 표시합니다.

전권 PDF 합계는 약 1.37 GB여서 기존 정적 사이트에 대용량 파일을 추가하지 않았습니다. 열람 화면은 선택한 한 페이지의 공개 이미지와 책 전체 PDF를 제공처에서 불러옵니다. 외부 이미지 연결에 의존하는 점과 자체에 수록된 전사의 범위를 화면에 명시합니다. 탕액편 전사에 대응하는 다른 영인 자료와 전권 열람용 목판본을 동일 판본으로 합치지 않습니다.

## 검색 격리

원문 데이터 네 파일은 전용 화면에서 검색할 때만 불러옵니다. 일반 한국어 색인과 Material 기본 검색에는 큰 원문 본문이 들어가지 않습니다. 전용 페이지 하나만 생성하고 메뉴에 개별 원문 항목·책을 추가하지 않았습니다. 기존 검색 결과 하단의 선택 링크는 검색어를 전용 화면으로 전달할 뿐, 일반 검색에서 전사 네 파일이나 영인본을 요청하지 않습니다.
