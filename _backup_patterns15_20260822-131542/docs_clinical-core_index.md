# 임상 핵심 본초·방제·경혈

이 페이지는 별도 체계를 만드는 것이 아니라 기존 **본초학·방제학·경혈·침구치료·증상 지식망**을 연결하는 임상 허브입니다.

## 핵심 본초
반하 · 진피 · 맥문동 · 오미자 · 백작약 · 시호 · 산조인 · 두충

→ [본초학 전체 보기](../herbs/index.md)

## 핵심 방제
평위산 · 이진탕 · 반하사심탕 · 향사육군자탕 · 산조인탕 · 천왕보심단 · 오적산 · 온경탕

→ [방제학 전체 보기](../formulas/index.md)

## 핵심 경혈
기존 족삼리·합곡·내관·신문·삼음교 등에 더해 곡지·외관·후계·양릉천·음릉천·태계·천추·풍륭·열결·공손을 확장합니다.
