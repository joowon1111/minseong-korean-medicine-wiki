    소음인 처방 배합망¶

    소음인 처방은 ‘몸이 차다’거나 ‘소화가 약하다’는 인상으로 한 묶음이 되지 않습니다. 신수열표열병의 울광·망양과 위수한리한병의 태음병·소음병을 먼저 가르고, 발한 뒤 기력, 음식선화, 복통·설사·구토, 사지냉과 전신 쇠약의 깊이에 따라 배합이 달라집니다.

    평소 음식선화·땀·대변 → 표병/리병 → 울광/망양 또는 태음병/소음병 → 승양·온중·온리·회양 → 처방 → 안전·경과 재평가

    울광·망양과 온위강음의 세부 분기에서 지침 처방과 후대 수록형의 차이를 함께 비교할 수 있습니다.

    병증 단계와 배합을 한눈에 보기¶

    병증축 처방 중심 배합 처방을 가르는 단서
    태양증·울광 초기 천궁계지탕 계지·백작약 + 천궁·진피·감초 오한·발열·두통·신체통과 발한 전후 기력
    표병·기체 향소산 향부자·소엽 + 진피·창출 표증과 흉복 답답함·식욕 변화
    표병·두통·기체 궁귀향소산 향소산축 + 천궁 두통·신체통과 기체·소화 변화의 결합
    망양중증·승양 승양익기탕 계지·백작약 + 인삼·황기 + 관계·당귀·백하수오 자한·신열, 불오한·단오열, 복만·대변비조·번조
    후대 태양양명 수록형 승양팔물탕 인삼·황기 + 관계·당귀·백작약·백출 갑오본 계통·후대 주치와 신축본 망양 처방을 구별
    망양·자한·사지구급 계지부자탕 계지·백작약·감초 + 포부자 지속 자한·냉감과 사지 구급·굴신 불편
    망양 심화 승양익기부자탕 승양익기탕 골격 + 포부자 지속 발한·냉감·쇠약과 활동 저하
    망양 심화·인삼계지축 인삼계지부자탕 인삼·계지·황기·백작약 + 포부자 발한 뒤 전신 쇠약·회복력 저하
    망양 심화·관계축 인삼관계부자탕 관계 고용량 + 황기·백작약·당귀·포부자 심한 냉감·탈진·섭취 감소와 전신상태
    태음병·한습 곽향정기산 곽향·소엽 + 건강·계피 + 반하·진피·청피·창출 오심·구토·설사·심하비만과 한습·담습
    태음병·자리증 백하오이중탕 백하수오·백출·백작약 + 계지·건강 복통·설사·식욕저하와 복부 냉감
    리한·기체·사려상비 향부자팔물탕 향부자·진피 + 당귀·백작약·천궁·백하수오 흉복 답답함·두통·구갈·긴장과 소화저하
    태음병·구토·정체 계지반하생강탕 생강·계지·반하 + 백작약·백출·진피 오심·구토·심하·흉부 답답함과 냉감
    태음병·급성 토사 궁귀총소이중탕 인삼 + 건강·관계·백출 + 포부자 급성 구토·설사·복통, 탈수·쇠약
    깊은 리한·허한 관계부자이중탕 인삼·건강·관계·백출 + 포부자 지속 설사·복통·사지궐냉·전신 쇠약
    소음병·장궐 오수유부자이중탕 건강·관계·오수유·부자 + 인삼·백출 구토·복통·설사와 깊은 사지냉·쇠약
    리한·흉복통·배뇨 관중탕 건강·양강·익지인·청피·오령지 흉복통·배뇨불리·사지권태와 냉감
    리한·복만·황색 변화 십이미관중탕 대복피·목향·지실·후박 + 건강·양강·하수오류 복만·황색 변화·부종과 간담도 감별

    네 개의 배합 중심축¶

    1. 계지·백작약의 표병·영위축¶

    천궁계지탕에서 시작한 계지·백작약축은 망양이 깊어지면서 보기·승양·온양 약물이 더해집니다.

    배합의 이동 대표 처방 병증 변화
    계지·백작약 + 천궁·진피 천궁계지탕 울광 초기의 오한·발열·두통·신체통
    계지·백작약 + 인삼·황기·관계·당귀 승양익기탕 지침의 망양중증: 복만·대변비조·번조와 불오한·단오열
    계지·백작약 + 부자 계지부자탕 자한·냉감·사지 구급
    인삼·계지·황기·백작약 + 부자 인삼계지부자탕 발한 뒤 쇠약과 양기 손상 심화

    2. 향부자·소엽·진피의 기체축¶

    향소산·궁귀향소산은 표병과 기체·소화 변화가 함께 있는지 봅니다. 향부자팔물탕도 향부자·진피를 공유하지만 급성 표병이 아니라 비위 허약과 기혈·사려상비가 겹친 맥락입니다.

    처방 더해지는 중심 갈림점
    향소산 소엽·창출·생강·총백 표증과 흉복 답답함·식욕 변화
    궁귀향소산 천궁 두통·신체통의 비중
    향부자팔물탕 당귀·백작약·천궁·백하수오·백출 만성 허약·기혈 회복과 긴장·수면

    3. 건강·관계·백출의 온중·리한축¶

    리병에서는 건강·관계·백출이 반복되지만 한습·담습, 단순 태음병 자리증, 깊은 허한·장궐을 구분합니다.

    분기 대표 처방 임상에서 더 보는 부분
    곽향·소엽·반하·청피·창출 곽향정기산 한습·담습, 오심·구토·심하비만
    백하수오·백작약·계지 백하오이중탕 복통·설사·식욕저하의 태음병 자리증
    인삼·관계·부자 관계부자이중탕 지속 설사·사지궐냉·전신 쇠약
    오수유·부자·소회향·보골지 오수유부자이중탕 구토·장궐·격양과 더 깊은 리한

    4. 부자 분기: 병증 깊이와 안전을 함께 읽기¶

    부자는 표병 망양과 리병의 깊은 허한 모두에 나타날 수 있으므로 부자가 있다는 사실만으로 병증 위치를 정할 수 없습니다.

    표병·망양 쪽 리병·소음병 쪽
    계지부자탕, 승양익기부자탕, 인삼계지부자탕, 인삼관계부자탕 궁귀총소이중탕, 관계부자이중탕, 오수유부자이중탕
    발한 뒤 탈진·냉감·자한과 활동 저하 복통·설사·구토·사지궐냉과 섭취·소변 저하

    부자 포함 처방은 기원·포제·실제량·전탕시간, 심혈관·간·신장 상태와 병용약을 기록합니다. 입술·혀·사지 저림, 오심·구토, 심계·부정맥, 어지럼은 즉시 복용을 중단하고 평가할 신호입니다.

    울광·망양과 온위강음의 세부 분기¶

    인삼·황기·백출이 겹친다는 사실보다 울광과 망양을 먼저 가릅니다. 땀이 새로 생겼다는 한 항목으로 병증을 변경하지 않고, 평소 소증과 발열·발한·대변·기력의 전체 경과를 봅니다.

    처방·병증 위치 구성에서 비교할 부분 가까운 처방과의 경계
    황기계지탕: 망양초증 후대 기록의 계지·황기·백작약·당귀·하수오·자감초와 생강·대조 천궁계지탕의 울광 초기와 발한 소증·현재 자한을 구분
    팔물군자탕: 울광중증 인삼·황기·당귀·백작약·백출·진피·자감초와 생강·대조의 공개기록 승양팔물탕의 갑오본 계통·후대 태양양명 주치와 구별
    독삼팔물군자탕: 울광말증·태양병궐음증 지침의 변방명·인삼 비중과 실제 원처방 조건 대조 팔물군자탕의 약미·량을 복사해 독삼 처방으로 표시하지 않음
    보중익기탕: 망양중증 인삼·황기·백출·당귀·진피·자감초·곽향·소엽의 소음인 수록형 일반 보중익기탕의 시호·승마와 다름. 승양익기탕과 구성·단계를 비교
    인삼오수유탕: 태양병궐음증 특정 후대 기록의 인삼·오수유·생강·당귀·백작약·제조 오수유부자이중탕과 오수유가 겹쳐도 표병과 리병의 문맥은 다름
    향사양위탕: 태음병 온위강음 인삼·백출·백작약·감초에 반하·진피·향부자·백두구·사인·건강·산사육 곽향정기산의 한습·구토, 백하오이중탕의 복통·설사와 비교
    강출관중탕: 태음병·황달 문맥 건강·백출·양강·익지인·진피·청피·향부자·적하수오·백하수오·대조 관중탕·십이미관중탕에서 약미를 가져와 빠진 용량을 보충하지 않음

    황기계지탕의 하수오 표기는 해당 후대 기록의 표기입니다. 신축본 원방의 약미로 일괄 치환하지 않습니다. 팔물군자탕 역시 이름의 ‘팔물’에 맞춰 공개기록에 없는 약재를 만들어 넣지 않습니다. 강출관중탕의 백하수오·적하수오는 서로 다른 원료이며, 향사양위탕과 강출관중탕의 누락 용량은 구성비 자료의 계산에 임의 편입하지 않습니다.

    병증 단계: 울광병 지침 · 망양병 지침 · 태음병 지침. 후대 구성은 각 처방 상세의 개별 공개기록을 따릅니다.

    가장 자주 헷갈리는 처방 쌍¶

└─ 땀 뒤 탈진·냉감 → 승양계·망양 처방군

├─ 한습·담습·심하비만 → 곽향정기산
├─ 복통·설사·식욕저하 → 백하오이중탕
├─ 구토·흉복 정체 → 계지반하생강탕
└─ 사지궐냉·전신 쇠약 → 부자이중계와 응급 원인 평가
