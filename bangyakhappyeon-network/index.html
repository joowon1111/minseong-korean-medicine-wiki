    방약합편 임상 지식망¶

    《방약합편》은 조선 후기 한의학의 방제와 본초 지식을 진료 현장에서 빠르게 찾고 활용할 수 있도록 압축·정리한 임상 처방서입니다.

    《황제내경》처럼 기초 이론의 출발점이거나 《상한론》처럼 특정 병증 체계를 세운 고전이라기보다, 앞선 의학 지식을 실제 처방 선택과 본초 배합으로 연결한 한국 한의학의 실용서라는 데 특징이 있습니다. 따라서 이 아카이브에서는 방약합편을 고대 핵심 고전과 나란히 두기보다 한국 한의학 임상서·처방서 영역에서 살펴봅니다.

    상통·중통·하통의 분류, 본초를 읽는 약성가, 칠방·십제의 치법을 연결해 처방서를 읽습니다. 처방명만 찾고 끝내기보다 수록본·구성·가감·제법이 같은지 확인하고, 현재 환자의 병증과 현대 임상근거는 별도로 평가합니다.

    방약합편이란¶

    《방약합편》은 조선 후기 황도연의 의학을 바탕으로 정리된 대표적 임상 의서로, 처방과 본초를 실제 활용하기 쉽게 압축한 성격이 강합니다.

    임상적 특징¶

    방대한 이론보다 처방을 찾고 약성을 확인하기 쉬운 실용성이 중요한 특징입니다.

    읽는 순서¶

    현재 증상·병기 → 상·중·하통 처방군 → 구성 본초 → 유사 처방 감별 → 용량·제형·안전성 → 현대 연구

    → 방제 구조 · 본초 배합

    방약합편 상통·중통·하통¶

    상통¶

    상대적으로 보하는 성격의 처방군을 탐색하는 축으로 봅니다.

    중통¶

    보사 어느 한쪽으로 치우치기보다 조화·중간적 치료 성격을 갖는 처방군을 탐색합니다.

    하통¶

    사법·공법 등 병사를 제거하는 방향이 상대적으로 뚜렷한 처방군을 탐색합니다.

    주의¶

    상·중·하통을 현대의 효과 강도나 약의 등급으로 오해하지 않습니다. 실제 처방은 원문 병증·구성·환자의 허실을 함께 확인합니다.

    → 칠방십제

    방약합편 본초·약성가¶

    약성가는 본초의 핵심 성질과 효능을 기억하기 쉽게 압축한 형식입니다.

    확장해서 읽기¶

    약성가 핵심어 → 기원·약용부위 → 성미·귀경 → 효능 → 주치 → 약대 → 대표 방제 → 현대 연구 → 안전성

    대표 탐색축¶

    인삼·황기 → 보기
    당귀·숙지황 → 보혈
    반하·진피 → 화담이기
    두충·우슬 → 근골·간신
    산조인·원지 → 안신

    → 본초학 · 본초 배합

    칠방십제(七方十劑)¶

    칠방¶

    대방·소방·완방·급방·기방·우방·복방 등 처방 규모, 작용의 완급, 구성 방식을 설명하는 틀입니다.

    십제¶

    선·통·보·설·경·중·삽·활·조·습 등 치료 작용의 방향을 분류하는 전통 개념입니다.

    임상적 의미¶

    왜 어떤 처방은 약미가 많고 어떤 처방은 간결한지, 보법·공법·조화법이 어떻게 구조화되는지를 이해하는 도구로 활용합니다.

    → 방제 구조 · 고전 처방 읽기

    방약합편 임상 탐색법¶

    환자 증상 → 위험신호 → 변증 → 치법 → 상·중·하통 처방군 → 구성 본초 → 유사 처방 감별 → 현대 임상 연결

    예시¶

    피로 → 기허/기혈양허/신허 → 보익 → 관련 처방군
    소화불량 → 비위기허/담음/식적/간울 → 건비·화담·이기
    통증 → 한습/어혈/허증 → 거풍습·활혈·보익

    → 질환→치료 지도

    방약합편과 동의보감 비교¶

    항목 방약합편 동의보감
    성격 처방·본초의 실용적 압축 인체·병증·탕액·침구의 종합 체계
    탐색 처방을 빠르게 찾기 유리 병증·부문별 맥락이 풍부
    본초 약성가 등 압축 정보 탕액편의 폭넓은 체계
    방제 상중하통 등 실용 분류 각 병문과 치료법 안에서 제시

    우열 비교가 아니라 동의보감은 종합 임상체계, 방약합편은 처방·본초 탐색의 실용성이라는 차이를 봅니다.

    → 동의보감

    방약합편 통합 지도¶

    방약합편 → 상·중·하통 → 처방 → 구성 본초 → 약성가 → 칠방십제/치법 → 현대 변증·질환 → 임상근거
