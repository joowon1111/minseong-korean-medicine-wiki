    고전 원문·해석¶

    읽고 싶은 책을 선택하세요. 원문을 바로 열거나, 아래 책별 안내에서 처음 읽을 대목과 해석을 고를 수 있습니다. 한문이 익숙하지 않다면 처음 읽기 안내부터 시작하세요.

    두 책의 전체 목차부터 보기¶

    개별 구절을 읽기 전에 책 전체에서 어느 자리에 놓인 내용인지 먼저 살펴보세요. 《동의보감》은 몸의 기능·부위·병증과 치료 수단으로, 《동의수세보원》은 사람을 이해하는 이론과 체질별 병론·처방으로 내려가는 구성이 핵심입니다.

    책 큰 목차의 흐름 목차와 편명 풀이
    동의보감 내경편 4권 → 외형편 4권 → 잡병편 11권 → 탕액편 3권 → 침구편 1권. 본문 23권에 목록 2권이 별도로 있습니다. 다섯 편의 뜻·본문 23권의 문목
    동의수세보원 권1의 이론 → 권2의 의원론·소음인 → 권3의 소양인 → 권4의 태음인·태양인·광제설·사상인변증론. 체질별 병론 사이에 선행방·신정방 수록부가 놓입니다. 4권의 목차·논설의 뜻·처방 수록부

    목차 해설에서 위치를 잡은 뒤 아래의 주제별 읽기 경로를 이용하면 전체 구성 → 해당 편·권 → 원문·풀이 → 병증·처방 순서로 이어 읽을 수 있습니다.

    상한론 — 조문 번호와 육경병으로 읽기¶

    수록: 통행 398조의 원문·독해와 서문·맥법·치법편. 조문은 원문과 한국어 독해를 함께 읽고, 관련 처방으로 이어갈 수 있습니다.

    • 처음 읽기: 태양병 1–3조부터. ‘제강’은 해당 병의 특징을 짧게 정리한 문장입니다.
    • 전체 목차: 1–398조와 판본 안내.
    • 육경병으로 바로 가기: 태양 상 · 태양 중 · 태양 하 · 양명 · 소양 · 태음 · 소음 · 궐음.
    • 책을 먼저 이해하기: 상한론 소개 · 처방 계열 비교.

    증후·배합·치료 순서로 읽는 다섯 경로¶

    조문 번호를 찾은 뒤에는 어떤 조건에서 처방이 등장하고, 앞뒤 문장과 무엇이 달라지는지 읽습니다. 아래 경로는 임상 처방을 고르는 자가진단표가 아니라 원문의 비교 대목을 찾는 안내입니다.

    읽을 주제 원문에서 출발 처방·현대 문서에서 이어 읽기
    계지탕의 증후와 복용 뒤 관찰 12조 계지탕: 구성과 원문에 붙은 조제·복용 조건
    치료 뒤 증상이 바뀌는 순서 29조 상한론 처방 계열: 같은 경과 안에서 처방을 나누는 이유
    소시호탕의 중심 증후와 겸증 96조 소시호탕: 원방과 조건부 가감의 구별
    결흉과 심하비의 갈림점 149조 반하사심탕류 비교 → 현대 소화불량의 처방 구성
    병이 풀린 뒤에도 남은 허약·구역과 조제 순서 397조 죽엽석고탕 죽엽석고탕: 본문의 증후와 배합 해설, 갱미 후입을 비교

    고전 심하비와 현대 기능성소화불량은 같은 진단명이 아닙니다. 원문은 증후와 배합을 이해하는 자료로, 질환 문서는 현재의 평가·치료·연구를 읽는 자료로 이어집니다. 각 조문에서 대조 원문과 판본 안내를 확인할 수 있습니다.

    금궤요략 — 편명과 관심 병증으로 읽기¶

    수록: 서문과 제1–22편 임상 원문, 398개 항목의 한국어 독해 요지. 이 항목 수는 해당 전사문의 구분이며 상한론의 398조와는 별개입니다. 독해 요지는 전 문장의 완역·교감본과 구분합니다.

    • 처음 읽기: 서문·판본 안내 → 제1편 장부경락선후병.
    • 전체 목차: 제1–22편 원문 목록.
    • 관심 주제로 바로 가기: 혈비·허로 · 기침·상기 · 흉비·심통 · 담음 · 부인 잡병.
    • 책을 먼저 이해하기: 금궤요략 소개.

    읽을 질문 원문과 비교 대목 다음 자료
    허로의 복부 불편과 보하는 배합은 어떻게 이어지나요? 제6편 소건중탕 → 황기건중탕 소건중탕 구성 · 황기건중탕 구성
    허번과 불면을 왜 함께 적었나요? 제6편 산조인탕 원방의 다섯 약과 선전 → 불면의 고전·임상 연결
    같은 길경탕은 두 책에서 어떤 문맥으로 나오나요? 상한론 311조의 인후통 → 금궤요략 7.12의 기침·배출물 같은 두 약과 서로 다른 병증 문맥을 비교
    같은 백호가인삼탕의 주치와 포제 표기는 어떻게 다른가요? 상한론 26조 → 금궤요략 2.26 → 13.12 같은 약량과 다른 주치·부기를 나누어 대조
    설사에 구토가 겹치면 처방과 기록은 어떻게 달라지나요? 상한론 172조 → 금궤요략 17.11 황금탕의 가감과 두 수록본의 생강량을 비교
    구토와 갈증은 어떤 순서로 살피나요? 구토편 17.2 → 담음편 12.28·12.30 증상의 선후와 소반하탕·소반하가복령탕의 구성을 비교
    담음에서는 증상의 위치와 경과를 어떻게 읽나요? 제12편 핵심 조문 연결 → 영계출감탕 영계출감탕: 배합·감별·연구 대상 확인

    각 처방을 약재 하나의 효능으로 요약하기보다 함께 쓰는 약재와 조제 순서를 읽습니다. 임상연구가 연결돼 있으면 연구에서 사용한 제제·대상·비교군을 해당 상세 문서에서 확인하세요.

    동의수세보원 — 개념·소증·병증을 함께 읽기¶

    수록: 1941년 석판본 이미지에서 직접 옮긴 권1 성명론·확충론·장부론 24대목을 포함한 총 64개 핵심 원문·자체 한국어 풀이와 기존 개념·소증·병증별 해석. 책 전체의 연속 원문이나 완역본은 아닙니다. ‘소증’은 평소의 소화·땀·대변·수면 등 상태를 가리키며, 현재 병증을 읽는 자료와 연결됩니다.

    • 전체 구성 먼저: 4권 목차·편명 풀이.
    • 원문을 바로 읽기: 아카이브 내부 원문·풀이. 소화, 땀, 明知其人 등으로 찾고 대조한 책 이미지도 열어 볼 수 있습니다.
    • 권1부터 읽기: 성명론의 성·명 → 확충론의 성정·관계 → 장부론의 수곡·진액 → 보명지주·체질별 병론.
    • 처음 읽기: 소음인의 음식 소화 → 핵심 원문·개념 해석.
    • 평소 증상에서 찾기: 소증별 원문 안내.
    • 병증에서 찾기: 병증별 원문·진료지침 연결표.
    • 체질·처방까지 이어 읽기: 동의수세보원 임상 지식망.
    • 책·판본 확인: 동의수세보원 소개. 이제마의 《동의수세보원》과 공정현의 《수세보원》은 서로 다른 책입니다.

    소증에서 병론으로 이어 읽는 여덟 경로¶

    한 문장을 읽은 뒤 평소 상태 → 병중 변화 → 감별·치료 판단으로 이어가면, 체질별 건강 기준과 실제 병론의 관계가 보입니다. 아래 순서는 학습 경로이며 독자가 자신의 체질이나 처방을 확정하는 절차는 아닙니다.

    읽을 주제 원문을 읽는 순서 비교할 핵심
    소음인의 소화와 반복 설사 음식선화 → 평소 설사·식사 중 땀 → 반복 복통 병례 건강 기준, 기존 소증, 이번 병의 경과를 나누기
    소음인 발한과 병세 망양의 정의 → 위가실·비약 땀의 유무만이 아니라 시작 시점·오한·배변 비교
    소양인의 발한과 반복 병세 손발바닥 발한 → 다시 앓는 경과 전신 발한과 병해, 일시 호전과 전체 경과 구별
    소양인의 두통·설사·변비 발열·두통에 설사 동반 → 신한복통과 배변 → 표병 두통·리병 변비 공통 증상과 갈리는 조건, 표한병 편의 열 증상
    태음인의 땀과 회복 한액통창 → 장감병 → 쾌한 → 병해 뒤 조리 땀의 양·모양·지속과 회복 단계
    태음인의 한열과 조열 한열에 따라 갈리는 표리 → 조열·소갈 감별 → 대변·소변·갈증 체온 하나와 병증 전체를 구별하고 체질 간 병론 비교
    태양인의 섭취·보행 기능 열격·반위 → 해역 → 두 증의 경중 증상의 시점·기능, 단독과 병존, 자료의 범위
    같은 체질에서도 달라지는 처방 곽향정기산의 수정 → 육미탕 병례의 재평가 → 기인·기증 선행 처방·저자 수정, 대표방·개별 병증·치료 반응

    동의보감 — 원문 검색·책 이미지·해석을 골라 읽기¶

    수록: 내경·외형·잡병·탕액·침구 다섯 편의 핵심 36대목 원문·자체 한국어 풀이와 기존 대표 처방 해설을 제공합니다. 전용 열람기로 검색 가능한 대량 전사는 탕액편 3권과 내경편 권1 신형·정의 확보된 부분입니다. 전권은 영인본(옛 책을 촬영한 이미지)으로 볼 수 있습니다. 전권의 모든 글자가 검색되거나 한국어로 번역되어 있는 것은 아닙니다.

    • 전체 구성 먼저: 다섯 편·본문 23권의 목차와 풀이.
    • 원문 검색: 원문 열람기에서 당귀, 當歸, 경옥고 같은 이름이나 한자 구절을 입력하세요. 검색어가 없으면 ‘권별 원문 목록’을 엽니다.
    • 책 이미지로 읽기: 전권 영인본 목차에서 편·권을 선택하세요.
    • 처음 읽기: 다섯 편 핵심 구문 지도 → 대표 처방의 긴 해설.
    • 주제별로 찾기: 내경·외형·잡병·탕액·침구 5편 색인 · 탕액편 본초 해설.

    증상과 치료 원칙으로 읽는 여덟 경로¶

    《동의보감》은 앞선 여러 의서의 말을 문목별로 모은 책입니다. 같은 증상을 다룬 구절도 누구의 설명인지, 어떤 조건을 붙였는지 확인하고 비교합니다.

    읽을 주제 원문을 읽는 순서 비교할 핵심
    자한과 도한 자한의 여러 병기 → 도한의 시간 구분 → 당귀육황탕 방해 증상의 정의·병기·처방 배합이라는 서로 다른 층위
    땀·배뇨와 진액 과도한 발한 뒤 변화 → 기행·수행 → 삼초·수도 증상의 선후, 수액의 흐름과 기능적 비유
    월경과 허실 월경 전 통증 → 비위허약·혈고와 혈폐 시점·증상·병기를 나누고 기본방과 가미 약미 읽기
    요통과 어혈·한·손상 요통 열 분류 → 좌섬 → 어혈 → 한요통 손상 계기·통증 성질·냉온 반응은 다른 관찰 축
    냉감·무거움과 보존된 기능 신착의 갈증·식사·배뇨 → 금궤요략 담음·수기·요통 연결 있는 증상뿐 아니라 없거나 유지된 소견도 읽기
    치료의 우선순위 선후로 읽는 표본 → 구토·섭취 곤란의 우선 처리 병이 생긴 순서와 당장 치료할 순서는 다를 수 있음
    본초의 배합·가공 백출·창출 → 작약의 배합 → 생강·건강 → 황련의 포제 같은 이름·같은 계통이라도 조건과 처방 속 역할 구별
    혈위와 반응 부위 표시한 자세 → 체격 차이 → 동신촌 → 아시혈 자세·비례·개인차·반응을 구별하며 취혈 원칙 읽기

    두 책에서 같은 말을 만났을 때¶

    공통 주제 동의보감에서 읽을 것 동의수세보원에서 읽을 것
    땀 진액문의 증상 정의와 여러 의가의 병기 설명 체질별 소증·병세·회복 기준의 차이
    소화·배변 비위·담습·진액 등의 문목과 처방 배합 평소 소증, 표리병의 경과와 체질별 처방 판단
    허약과 회복 허실·보사의 조건과 표본에 따른 치료 순서 완실무병의 기준, 병해 뒤 조리와 재평가
    같은 처방명 출전·약미·포제·가미의 조건 선행 처방의 인용과 이제마의 수정·논평

    예를 들어 《동의보감》의 자한·도한은 증상과 병기를 읽는 분류이고, 《동의수세보원》의 태음인 쾌한·소양인 손발바닥 발한은 각 체질 병론의 경과 판단입니다. 모두 땀에 관한 문장이어도 같은 진단표로 합치지 않습니다. 원문 옆의 문장 구조와 비교 해설에서 그 차이를 확인할 수 있습니다.

    처방 원문을 읽을 때 확인할 다섯 가지¶

    1. 어느 책·편·조문인가: 책 이름뿐 아니라 편명과 대조 판본을 확인합니다. 같은 이름의 책이나 후대 인용을 구분합니다.
    2. 어떤 조건에서 등장하는가: 증후의 나열, 앞선 치료, ‘만약’에 해당하는 분기와 치료 뒤 경과를 나누어 읽습니다.
    3. 무엇을 배합했는가: 기본 약미와 가감, 별도 전승의 부기를 구분합니다. 다른 출전의 약량으로 빈칸을 채우지 않습니다.
    4. 어떻게 가공·조제했는가: 법제, 먼저 달일 약재, 제형·복용 단위가 원문의 어느 부분에 적혔는지 확인합니다. 옛 단위를 숫자만 보고 현대 그램으로 바꾸지 않습니다.
    5. 어떤 현대 자료로 이어지는가: 처방 비교에서 배합 차이를, 질환별 안내에서 현재의 치료·임상연구를 확인합니다.

    예를 들어 《금궤요략》 산조인탕과 《동의보감》 몽문의 동명 처방은 구성부터 비교해야 합니다. 처방명이 같아도 출전과 실제 약미를 확인하는 습관이 원문 독해와 현대 연구 해석을 함께 돕습니다.

    원문을 찾은 다음에는¶

    원문 → 한국어 독해 → 관련 개념·처방 → 현대 연구 순서로 이어 읽을 수 있습니다. 원문의 한 문장, 이를 풀어 쓴 해석, 현대 연구 결과는 서로 다른 자료이므로 연결된 문서에서 출전과 연구 대상을 확인하세요. 원문의 옛 용량은 현재의 복용 지시가 아닙니다.

    다른 책을 찾는다면 한의학 고전 전체 안내, 책 사이의 차이가 궁금하다면 고전 비교를 이용하세요. 아카이브 검색창에서는 책 이름과 처방·주제를 함께 입력할 수 있습니다. 동의보감의 수록 한문 전사는 위의 전용 원문 검색에서 찾습니다.

    원문을 깊이 읽는 세 가지 관점¶

    고전의 한 조문을 해석할 때는 ① 원문에 실제로 적힌 말 ② 문맥과 판본 ③ 현대 임상에 연결하는 해설을 분리해 읽는 것이 좋습니다. 원문에 없는 병명이나 처방 효과를 번역문에 덧붙이지 않고, 후대 주석과 현대적 해석은 별도로 표시합니다. 처방의 약재 구성·용량이 다른 경우에는 먼저 해당 판본과 출전을 확인하세요.

    • 원문과 번역: 상한론 조문과 금궤요략에서 원문과 독해를 나란히 살펴봅니다.
    • 판본과 문맥: 동의보감 원문과 동의수세보원 원문의 편명·전후 문장을 함께 확인합니다.
    • 임상으로 연결: 본문에 등장하는 처방과 경혈은 각각의 상세 문서에서 구성·취혈·현대 연구를 이어 읽습니다.

    이는 별도의 문헌 탐정 페이지가 아니라 기존 고전 읽기의 공통 독해 원칙입니다.
