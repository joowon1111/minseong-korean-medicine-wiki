# 잠을 자도 개운하지 않고 자주 깨면 어떻게 보나요?

## 핵심 답변
수면시간만으로 수면상태를 판단하기는 어렵습니다. **잠드는 데 걸리는 시간, 자다가 깨는 횟수, 새벽각성, 다시 잠드는 데 걸리는 시간, 아침 회복감과 낮 기능**을 함께 봅니다. 두근거림·긴장·소화불편·상열감·피로가 동반되는지도 중요한 단서입니다.

## 시간패턴
- 잠들기 어려움: 취침 전 각성·긴장·생활리듬 확인
- 자주 깸: 각성 시각과 원인, 다시 잠드는 시간 확인
- 새벽에 깸: 반복되는 시각과 낮 피로 확인
- 충분히 자도 피곤함: 수면시간보다 회복감과 낮 기능 확인

## 한의학적 연결
불면은 심비양허·심혈허·음허·담열·간울 등 서로 다른 병증에서 나타날 수 있어 동반증상을 함께 봅니다. 귀비탕·온담탕·천왕보심단·산조인탕 등의 방제도 같은 불면이라는 이유만으로 동일하게 선택하지 않습니다.

## 먼저 평가할 신호
심한 코골이·무호흡 의심, 주간 졸림으로 안전에 문제가 생기는 경우, 새로 발생한 심한 두근거림·흉통·호흡곤란 등이 있으면 원인 평가가 우선합니다.
