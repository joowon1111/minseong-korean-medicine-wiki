# 질환→치료 통합 지도

## 불면
```text
불면
├─ 심비양허 → 귀비탕
├─ 담음·담위불화 → 온담탕
└─ 침구 → 신문·삼음교·내관·백회
```

→ [불면](../conditions/insomnia.md)

## 소화불량
```text
소화불량
├─ 비위기허 → 사군자탕·육군자탕
├─ 담음 → 온담탕
└─ 침구 → 족삼리·내관·중완
```

→ [소화불량](../conditions/dyspepsia.md)

## 요통
```text
요통
├─ 풍한습비·간신허 → 독활기생탕
├─ 침구 → 신수·위중
└─ 치료 → 침·약침·전침·부항
```

→ [요통](../conditions/low-back-pain.md)

## 비염
```text
비염
├─ 폐기허·위기불고 → 황기·인삼
└─ 침구 → 합곡·족삼리
```

→ [비염](../conditions/rhinitis.md)

## 피로·회복
```text
피로
├─ 기허 → 인삼·황기·보중익기탕
├─ 기혈양허 → 십전대보탕
├─ 허손·정혈 → 공진단
└─ 기음·양생 → 경옥고
```

→ [피로·회복 지식망](recovery-map.md)
