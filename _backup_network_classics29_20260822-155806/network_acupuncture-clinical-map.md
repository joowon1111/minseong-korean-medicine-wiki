# 침구 임상 지식망

침구치료는 **증상 → 경맥 → 특정혈 → 변증 → 국소·원위 배혈 → 자극방법**의 흐름으로 보면 기존의 단순 증상별 혈자리 목록보다 훨씬 입체적으로 이해할 수 있습니다.

## 증상별 임상 연결

### 불면·심계
심경·심포경·신경·독맥·교맥  
신문 HT7 · 내관 PC6 · 조해 KI6 · 백회 GV20 · 인당

### 소화불량
위경·비경·심포경·임맥  
족삼리 ST36 · 중완 CV12 · 내관 PC6 · 공손 SP4 · 풍륭 ST40

### 요통
방광경·신경·독맥  
신수 BL23 · 대장수 BL25 · 위중 BL40 · 곤륜 BL60 · 태계 KI3 · 명문 GV4

### 목·어깨
담경·방광경·소장경·대장경·삼초경  
풍지 GB20 · 천주 BL10 · 견정 GB21 · 천종 SI11 · 견우 LI15

### 무릎·하지
위경·비경·담경·방광경  
독비 ST35 · 족삼리 ST36 · 양릉천 GB34 · 음릉천 SP9 · 위중 BL40

### 비염·호흡기
폐경·대장경·임맥·방광경  
중부 LU1 · 척택 LU5 · 열결 LU7 · 영향 LI20 · 폐수 BL13

### 여성·하복부
비경·간경·신경·임맥·충맥  
삼음교 SP6 · 태충 LR3 · 관원 CV4 · 기해 CV6 · 혈해 SP10
