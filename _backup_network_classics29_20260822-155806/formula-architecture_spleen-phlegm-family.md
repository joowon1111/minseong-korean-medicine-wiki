# 비위·담음 처방 계열

핵심은 **반하·진피·복령을 중심으로 비위허, 기체, 담열, 한열착잡이 어떻게 결합하는가**입니다.

- 이진탕 — 담음의 기본 구조
- 육군자탕 — 비위기허 + 담음
- 향사육군자탕 — 비위기허 + 담음 + 기체
- 온담탕 — 담과 심계·불면·긴장
- 반하사심탕 — 심하비·위장관 한열착잡
- 평위산 — 습체·복만
