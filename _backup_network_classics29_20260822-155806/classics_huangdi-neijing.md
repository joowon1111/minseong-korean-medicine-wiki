# 황제내경(黃帝內經)

《황제내경》은 동아시아 전통의학의 **생리·병리·진단·양생·침구 이론의 기본 틀을 형성한 핵심 고전**이다. 오늘날에는 주로 《소문(素問)》과 《영추(靈樞)》 두 계통으로 전해진다.

## 소문(素問)
음양·오행, 장부, 병인·병기, 진단, 치료원칙과 양생 등 한의학의 이론적 토대를 폭넓게 다룬다.

## 영추(靈樞)
경락·경혈·침법과 인체의 기혈 운행을 중심으로 침구학의 고전적 기반을 보여준다.

## 핵심 지식망
```text
황제내경
├─ 음양·오행
├─ 기·혈·진액
├─ 장부
├─ 병인·병기
├─ 경락·경혈
└─ 침구
```

## 읽는 관점
《황제내경》의 장부·기혈·경락 개념은 현대 해부학 용어와 단순히 일대일 대응하기보다 **전통 의학의 기능적 관계망**으로 이해하는 것이 중요하다.
