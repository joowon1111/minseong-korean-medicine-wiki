# 팔강→치법 임상 지도

팔강은 처방명을 직접 결정하기보다 **치료 방향을 좁히는 역할**을 합니다.

| 판단 | 대표 치법 방향 |
|---|---|
| 표 | 해표 |
| 리 | 내부 병리에 따라 청·온·보·사 |
| 한 | 온리·산한 |
| 열 | 청열·양음 등 원인별 |
| 허 | 보기·보혈·자음·온양 |
| 실 | 이기·화담·활혈·소도·공하 등 |

## 복합병증
리허한 → 온중·보허  
리허열 → 자음·청허열  
비위기허+담음 → 보기건비+화담  
기혈허+어혈 → 보익+활혈을 병증에 맞게 조합

## 경혈과 연결
같은 치법도 경맥·특정혈·국소증상에 따라 배혈이 달라집니다.
