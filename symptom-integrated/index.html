    증상·질환 한눈에 보기¶

    환자는 의학용어보다 “허리가 아파요”, “자꾸 깨요”, “밥만 먹으면 더부룩해요”처럼 검색합니다.
    이 페이지는 그런 표현을 기존 증상·한약·방제·침구 자료로 바로 연결합니다.

    역방향 탐색도 가능¶

    • 본초에서 시작: 본초 찾기 → 실제 배합 처방
    • 방제에서 시작: 방제 찾기 → 병증·구성 본초
    • 침구에서 시작: 침구·치료 증상으로 찾기 → 한약·방제
    • 증상에서 시작: 이 페이지 → 병증 → 세 치료 지식망으로 분기

    이렇게 하면 위키의 본초·방제·침구·증상 자료가 각각 별도 사전처럼 존재하지 않고 하나의 임상 지식망으로 작동합니다.

    사상체질 자료와 함께 볼 때¶

    사상체질은 환자가 검색한 증상명만으로 결정하지 않습니다. 평소 소증과 병증의 변화를 함께 확인한 뒤 기존 일반방제·침구 자료와 별도의 진단축으로 교차해 봅니다.

    환자 증상군 사상의학에서 함께 볼 소증 사상자료 연결
    소화불량·식욕저하·설사 평소 소화력·대변·냉감·발한 소음인 · 태음인
    피로·회복저하 땀·식욕·수면·대변·한열 변화 체질별 병증 비교
    불면·열감·갈증 평소 수면·대변·갈증·한열 소양인
    냉증·설사·소화저하 냉감·발한·대변·섭취 소음인
    땀·호흡·체중·부종 발한·호흡·소화·한열 태음인
    배뇨·섭취·하지기능 변화 소변·섭취·하지기능 태양인

    같은 증상도 두 축으로 봅니다¶

    환자 증상
 ├─ 일반 한의학: 한열·허실·기혈·담습·어혈 → 일반방제
 └─ 사상의학: 체질 + 평소 소증 + 체질병증 변화 → 사상처방
