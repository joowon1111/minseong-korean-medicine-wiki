    수면·피로¶

    불면증·잠이 안 와요¶

    환자가 자주 묻는 것: “생각이 많아서 못 자요”, “한약 먹으면 잠이 깊어질까요?”

    패턴 처방
    심비양허·기혈허 귀비탕
    심신음혈부족 천왕보심단
    허번불면 산조인탕
    담울·심번·경계 가미온담탕

    본초: 산조인·원지·백자인·용안육 → 비교.
    침구: 긴장·두근거림·경항부·호흡·소화 상태를 함께 봄.
    회복: 입면시간↓ → 야간각성↓ → 재입면↑ → 아침 회복감↑ → 낮 기능↑.

    자꾸 깨요·얕은 잠¶

    총수면시간만 보지 않고 각성 횟수·재입면 시간·꿈·야간뇨·코골이·낮 졸림을 함께 확인합니다.

    만성피로·기운이 없어요¶

    패턴 처방
    비위기허·중기하함 보중익기탕
    노권·기혈구상 쌍화탕
    기혈양허·허손 십전대보탕
    기음양허 생맥산

    피로는 빈혈·갑상선·수면장애·감염 후 상태·약물 등 원인 평가가 필요할 수 있습니다.

    자고 나도 피곤해요¶

    수면시간보다 비회복성 수면 여부를 봅니다. 코골이·무호흡 가능성과 낮 졸림도 확인합니다.

    두근거림·가슴답답¶

    흉통·실신·호흡곤란은 먼저 평가. 심비양허·담울·기울에서는 귀비탕·가미온담탕·반하후박탕 계열을 비교합니다.

    긴장하면 몸이 굳어요¶

    간울·기체·담울 → 소요산 · 시호소간산 · 가미온담탕. 침구는 경항·흉곽·호흡패턴까지 연결합니다.

    기존 지식망으로 이동¶

    → 증상·치법으로 방제 찾기
    → 방제 찾기
    → 본초 찾기
    → 침구·치료 증상으로 찾기
    → 치료·경과·근거

    헷갈리기 쉬운 증상 연결¶

    현재 증상 함께 확인할 증상 갈림점
    불면 두근거림 · 어지럼 심비양허·담울·기혈허·간양 등
    만성피로 소화불량 · 비회복성 수면 비위기허인지 수면문제인지 구분
    두근거림 불면 · 가슴답답/울열 심비양허·담울·기울·심혈관 위험신호 구분
    긴장 목통증 · 스트레스성 소화불량 근긴장과 간울기체가 같이 나타나는지 확인

    빠른 탐색: 불면과 피로는 서로 원인과 결과가 될 수 있으므로 수면의 질 / 낮 기능 / 소화 / 심계 / 긴장을 한 묶음으로 봅니다.

    진료실 문진·변증 체크¶

    수면 문진¶

    • 잠드는 데 얼마나 걸리는가
    • 밤에 몇 번 깨는가
    • 깨면 다시 잠들기 쉬운가
    • 꿈이 많거나 심계·불안이 동반되는가
    • 아침에 개운한가
    • 낮 졸림·집중저하가 있는가

    피로 문진¶

    • 아침부터 피곤한가 / 오후에 심해지는가
    • 활동 후 회복시간
    • 식욕·소화·체중 변화
    • 추위를 많이 타는가 / 열감이 많은가
    • 땀·갈증·대변·소변 변화

    병증 갈림점¶

    패턴 병증축
    불면 + 심계 + 건망 + 식욕저하 심비양허
    허번·초조 + 음허 소견 음혈부족·허열
    불면 + 담·메스꺼움·흉민 담울
    피로 + 식욕저하 + 무력감 비기허
    피로 + 자한·구갈 기음양허

    재평가¶

    수면시간보다 입면·각성·아침 회복감·낮 기능을 같은 기준으로 추적합니다.

    생활관리·회복 체크¶

    불면¶

    • 기상시간을 가능한 일정하게 유지합니다.
    • 잠이 오지 않는 상태에서 침대에 오래 머무르는 습관을 줄입니다.
    • 늦은 시간 과도한 카페인·음주·강한 운동·밝은 화면 노출을 줄입니다.
    • 낮잠이 밤 수면을 방해한다면 시간과 길이를 조절합니다.

    피로¶

    • 하루 활동량을 한 번에 몰아 쓰지 않고 활동과 회복을 분배합니다.
    • 무리해서 활동한 다음 며칠간 크게 떨어지는 패턴이 있는지 기록합니다.
    • 식사량·수면·운동량을 함께 봅니다.

    회복지표¶

    증상 회복을 볼 때
    불면 입면시간, 야간각성, 재입면, 아침 회복감
    피로 활동 후 회복시간, 낮 기능, 식욕
    두근거림 발생빈도, 지속시간, 유발상황
    긴장 목·어깨 긴장, 호흡 깊이, 수면 영향

    심한 낮 졸림, 수면 중 무호흡 의심, 흉통·실신이 동반되는 두근거림은 별도 평가가 필요합니다.

    증상 지속기간에 따라 다시 보기¶

    단계 확인할 것 치료 방향
    최근 발생 스트레스·환경·카페인·약물·급성 질환 원인요인 교정 + 증상 안정
    수주 지속 수면패턴·심계·소화·긴장·낮 기능 병증 구체화 + 한약/침구 반응 확인
    만성화 비회복성 수면·기혈허·담울·생활패턴 수면·피로·소화·기능을 함께 재평가

    불면과 피로는 기간이 길어질수록 증상 자체보다 생활기능과 회복력을 더 중요하게 봅니다.
