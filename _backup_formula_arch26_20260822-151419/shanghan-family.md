# 상한 고방 계열

[상한론](../classics/shanghanlun.md)의 고방은 맥증과 병기의 차이에 따라 처방이 갈라진다.

```text
태양중풍 → 계지탕
태양상한·표실 → 마황탕
항배강 → 갈근탕
표증 + 수음 → 소청룡탕
소양병 → 소시호탕
수기불리 → 오령산
```
