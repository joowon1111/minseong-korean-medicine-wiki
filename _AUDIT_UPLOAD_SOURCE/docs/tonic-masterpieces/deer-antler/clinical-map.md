# 녹용 임상 활용 지도
`피로·허약·회복저하 → 기저질환 확인 → 한열·허실·기혈음양 → 보익 방향 판단 → 전체 처방에 배합 → 피로·식욕·수면·활동·소화 추적`

녹용은 '피곤하면 누구나 쓰는 약재'가 아니라 현재 병증과 처방 전체의 방향 안에서 이해합니다.
