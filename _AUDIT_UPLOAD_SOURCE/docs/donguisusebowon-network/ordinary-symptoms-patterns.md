# 소증과 체질병증

사상의학에서 **소증(素證)**은 평소 반복적으로 나타나는 생리적·증상적 특징을 뜻하며 체질병증 판단에 중요한 정보가 된다.

대표적으로 다음과 같은 항목을 함께 살핀다.

- 소화와 식욕
- 대변·소변
- 발한
- 수면
- 한열 반응
- 피로와 회복
- 정서와 생활 양상

```text
평소 소증
   +
현재 병증
   ↓
체질병증 판단
```

현재 증상만 보는 것이 아니라 평소의 상태와 비교한다는 점이 사상의학적 진단의 중요한 특징이다.
