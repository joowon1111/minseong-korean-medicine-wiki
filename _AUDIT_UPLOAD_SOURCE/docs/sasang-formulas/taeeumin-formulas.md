# 태음인 대표 처방 지식망

태음인에서도 현재 병증의 표리·한열 구조에 따라 처방이 구분된다. 임상 연구에서는 **태음조위탕·조위승청탕·청심연자탕·열다한소탕 계열**이 대표적으로 보고된다.

```text
태음인
  ↓
현재 병증
  ↓
├─ 표한병 맥락
│   ├─ 태음조위탕
│   └─ 조위승청탕
└─ 리열병 맥락
    ├─ 청심연자탕
    └─ 열다한소탕 계열
```

## 태음조위탕
태음인의 표한병과 소화·체중·전신 상태를 함께 살피는 임상 맥락에서 널리 알려진 대표 처방이다.

## 조위승청탕
태음인의 표병 구조와 연결해 탐색할 수 있는 사상체질 처방이다.

## 청심연자탕
태음인의 리열병 계열에서 자주 연구되고 활용되는 대표 처방이다.

## 열다한소탕
태음인 리열병의 열성 병증 구조에서 중요한 처방 계열로 다뤄진다.
