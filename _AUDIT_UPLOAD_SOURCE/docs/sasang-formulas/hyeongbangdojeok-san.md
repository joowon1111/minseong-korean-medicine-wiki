# 형방도적산

형방도적산은 사상의학에서 **소양인 병증의 맥락에서 이해되는 대표 처방 중 하나**다.

처방명만 독립적으로 외우기보다 《동의수세보원》의 체질·표리병증 체계 안에서 살펴보는 것이 중요하다.

```text
소양인
 ↓
현재 병증 평가
 ↓
표리·한열·증후 구분
 ↓
형방도적산 적용 맥락 탐색
```
