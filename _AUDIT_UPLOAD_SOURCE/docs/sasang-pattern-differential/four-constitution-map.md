# 네 체질 병증 감별 핵심표
| 체질 | 큰 감별축 | 악화 때 특히 보는 것 |
|---|---|---|
| 소음인 | 태음병 ↔ 소음병 / 망양병 | 설사·복통·갈증·수족냉·전신통·발한 |
| 소양인 | 망음 ↔ 흉격열 ↔ 음허오열 | 설사·열·갈증·대변·배뇨·진액소모 |
| 태음인 | 위완수한표한 ↔ 간수열리열 | 발한·오한·호흡 ↔ 열·구갈·조열 |
| 태양인 | 해역 ↔ 열격 | 하지·보행 ↔ 연하·섭취·구토 |

**체질명보다 병증 감별이 처방 선택에 더 직접적인 단계**입니다.
