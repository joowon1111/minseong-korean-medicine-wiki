# 소양인 건강→악화→회복

## 건강
**대변선통** — 배변이 편안하고 원활한 상태.

## 초기 변화
열감·갈증·배변 변화·복부불편·수면/번열·음수/소변 변화.

## 열이 성해지는 방향
`열감·구갈 + 대변 변화 + 흉격 번열` → 흉격열·리열 병증을 탐색합니다.

## 망음 방향
`복통·설사 + 냉감/오한 + 땀·진액 소모`의 조합을 살핍니다.

## 음허·오열이 깊어지는 방향
배뇨 변화·하지 위약·관절통·소화불량·복통·구토·전신 소모가 증가할 수 있습니다.

## 회복
열/갈증 또는 설사 감소 → 복통·구토·번열 안정 → 수면·피로 회복 → **대변선통 회복**.
