# 호흡·비염

## 비염·재채기·맑은 콧물
계절성/통년성·눈 가려움·코막힘·수면 영향을 함께 봅니다. 침구는 비강·두면부와 전신 상태를 연결합니다.

## 코막힘·축농증 느낌
- 비규폐색 → [창이자산](../formulas/cangerzi-san.md)
- 풍열·울열성 이비인후 → [형개연교탕](../formulas/jingjie-lianqiao-tang.md)
- 고열·심한 안면통·안와 증상은 우선 의학적 평가.

## 목이 자주 붓고 아파요
은교산 ↔ 형개연교탕 ↔ 연교패독산을 풍열표증 / 울열 / 열독·종통으로 구분합니다.

## 기침이 오래가요
| 병증 | 처방 |
|---|---|
| 풍열 + 기침 | [상국음](../formulas/sangju-yin.md) |
| 폐열·천해 | [마행감석탕](../formulas/maxing-ganshi-tang.md) |
| 담열옹폐 | [정천탕](../formulas/dingchuan-tang.md) |
| 폐기허 | [보폐탕](../formulas/bufei-tang.md) |
| 기음양허 | [생맥산](../formulas/shengmai-san.md) |

객혈·호흡곤란·고열·체중감소·흉통은 우선 평가합니다.

## 가래가 많아요
담습 → 이진탕·도담탕, 담열 → 정천탕. 반하·천패모·행인의 차이는 [본초 비교](../herbal-integrated/herb-comparisons.md)에서 확인합니다.

## 숨참·쌕쌕거림
급성 호흡곤란은 응급평가 우선. 폐열 마행감석탕 / 담열 정천탕 / 상실하허 소자강기탕으로 병증을 나눕니다.

| 기침 | [가래](#가래가-많아요) · [숨참](#숨참쌕쌕거림) | 풍열·폐열·담열·폐기허·기음허 |

**빠른 탐색:** 코·목·기침은 서로 이어지지만 `분비물 / 열 / 가래 / 천명 / 인후통 / 이물감`이 처방군을 나누는 핵심입니다.

## 진료실 문진·변증 체크

### 코·비염
- 맑은 콧물 / 누런 콧물
- 재채기·가려움·눈 증상
- 계절성 / 통년성
- 아침에 심한가
- 코막힘이 한쪽인지 양쪽인지
- 수면·후각에 영향을 주는가

### 기침·가래
- 마른기침 / 가래기침
- 가래 색·양·점도
- 밤 / 새벽 / 운동 / 찬공기와 연동
- 숨참·천명 동반
- 흉통·객혈·고열 여부

### 병증 갈림점
| 소견 | 병증축 |
|---|---|
| 풍열표증 + 인후통 | 풍열 |
| 맑은 콧물·재채기·한증 | 표허/풍한 계열 감별 |
| 누런 가래·열감 | 담열·폐열 |
| 오래된 기침 + 피로 | 폐기허 |
| 마른기침 + 구갈 | 음허·조열 |

### 침구에서 보기
비강·두면부만이 아니라 경항부·흉곽·호흡패턴을 함께 평가합니다.

## 생활관리·회복 체크

### 비염·코막힘
- 증상을 악화시키는 환경(먼지·찬공기·계절·수면환경)을 기록합니다.
- 실내가 지나치게 건조하거나 자극적인 환경인지 확인합니다.
- 코증상 때문에 수면이 깨는지도 함께 봅니다.

### 기침·가래
- 기침이 심한 시간대와 유발요인을 기록합니다.
- 찬공기·운동·식후·누웠을 때 악화되는지 확인합니다.
- 가래 색·양·점도 변화를 봅니다.

### 회복지표
| 증상 | 회복을 볼 때 |
|---|---|
| 비염 | 재채기, 콧물, 코막힘, 수면 |
| 코막힘 | 비강호흡, 야간 증상, 후각 |
| 기침 | 하루 횟수, 야간기침, 발작 여부 |
| 가래 | 양·점도·배출 편안함 |
| 숨참 | 활동 시 호흡, 야간 증상 |

> 숨이 차서 말을 하기 어렵거나 흉통·객혈·청색증 등이 있으면 즉시 평가가 우선입니다.

## 급성·반복성·만성 호흡증상 구분

| 단계 | 우선 확인 | 치료 방향 |
|---|---|---|
| 급성 | 감염·고열·호흡곤란·객혈 | 위험신호 우선 |
| 반복성 | 계절·알레르기·찬공기·환경 | 유발요인 + 표증/비규/담열 병증 |
| 만성 | 폐기허·기음허·담습·수면영향 | 전신 허실 + 호흡기능 + 재발요인 |

기침이 오래됐다고 같은 처방을 계속 쓰지 않고 **가래·열·진액·기허 여부가 어떻게 변했는지** 다시 봅니다.
