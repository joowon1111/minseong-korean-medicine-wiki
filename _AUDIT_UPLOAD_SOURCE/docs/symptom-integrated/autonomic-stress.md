# 자율신경·스트레스

## 어지럼증·머리가 띵해요
급성 신경학적 이상·실신·보행불가·갑작스러운 심한 두통은 우선 평가합니다.

- 비허담습·풍담 → [반하백출천마탕](../formulas/banxia-baizhu-tianma-tang.md)
- 간양상항·간풍 → [천마구등음](../formulas/tianma-gouteng-yin.md)
- 침구는 경항부·평형·자율신경 증상을 함께 평가.

## 스트레스 받으면 소화가 안 돼요
간울기체·칠정기울 → 소요산·시호소간산·분심기음. 소화 페이지의 비위 병증과 교차해서 봅니다.

## 목에 뭔가 걸린 느낌·매핵기
구조적 인후질환·연하곤란·체중감소를 먼저 확인. 담기울결 → [반하후박탕](../formulas/banxia-houpo-tang.md).

## 손발냉증·냉증
양허·한습·말초순환·기혈 상태를 구분. 양허수습은 진무탕, 충임허한·어혈은 온경탕과 연결합니다.

## 부종·몸이 잘 붓는다
| 병증 | 처방 |
|---|---|
| 수습·기화불리 | [오령산](../formulas/wuling-san.md) |
| 수열호결 | [저령탕](../formulas/zhuling-tang.md) |
| 양허수기 | [진무탕](../formulas/zhenwu-tang.md) |
| 비양허 수종 | [실비음](../formulas/shipi-yin.md) |

심장·신장·간질환 가능성이나 갑작스러운 부종은 우선 평가합니다.

## 화병처럼 답답하고 열이 올라요
간울화·울열·담울을 구분해 가미소요산·시호소간산·가미온담탕을 비교합니다. 흉통·호흡곤란은 별도 평가가 우선입니다.

## 진료실 문진·변증 체크

### 공통 문진
- 증상이 스트레스와 얼마나 연동되는가
- 두근거림·흉민·한숨·숨막힘
- 소화불량·복부팽만
- 불면·꿈·야간각성
- 열감·상열감·냉증
- 어지럼·두통·목긴장
- 땀·대변·소변 변화

### 병증 갈림점
| 소견 | 병증축 |
|---|---|
| 스트레스 + 흉협만·한숨 | 간울기체 |
| 목 이물감 + 흉민 + 담 | 담기울결 |
| 불면 + 심계 + 식욕저하 | 심비양허 |
| 상열감·초조·불면 | 울열·간화 |
| 어지럼 + 오심·담 | 비허담습 |
| 냉증 + 부종 | 양허·수습 |

### 재평가
증상 하나보다 **수면·소화·흉부불편·근긴장·활동기능**이 함께 변하는지 봅니다.

## 생활관리·회복 체크

### 스트레스성 증상
- 증상이 발생한 시간·상황·감정·수면·식사를 함께 기록합니다.
- 긴장할수록 호흡이 얕아지고 목·어깨·복부가 함께 굳는지 확인합니다.
- 과도한 카페인·수면부족·과로가 두근거림과 어지럼을 악화시키는지 봅니다.

### 냉증·부종
- 아침/저녁 중 언제 심한지 기록합니다.
- 한쪽만 붓는지, 양쪽이 비슷한지 확인합니다.
- 체중·배뇨·호흡곤란과 함께 변하는지 봅니다.

### 회복지표
| 증상 | 회복을 볼 때 |
|---|---|
| 어지럼 | 빈도, 지속시간, 보행·일상활동 |
| 스트레스성 소화불량 | 식후 불편 + 스트레스 연동 정도 |
| 매핵기 | 이물감 빈도, 연하 기능 |
| 냉증 | 냉감 지속시간, 일상 불편 |
| 부종 | 붓기 정도, 신발·양말 자국, 체중 |
| 울열·답답함 | 발생빈도, 수면·두근거림 동반 |

> 갑작스러운 편측 부종, 흉통·호흡곤란, 실신, 새 신경학적 증상은 자가관리보다 평가가 우선입니다.

## 증상의 단계와 패턴 변화

| 단계 | 특징 | 치료에서 볼 것 |
|---|---|---|
| 일시적 | 특정 스트레스와 짧게 연동 | 호흡·근긴장·수면·소화 변화 |
| 반복적 | 두근거림·소화불량·불면 등이 같이 반복 | 간울·담울·심비양허 등 병증 비교 |
| 만성화 | 피로·냉증·부종·수면저하가 누적 | 전신 허실·기혈·수습·기능 회복 |

초기의 간울·기체 중심 패턴이 장기화되면서 **담울·기혈허·양허·수습**이 더해질 수 있으므로 경과에 따라 병증을 다시 잡습니다.
