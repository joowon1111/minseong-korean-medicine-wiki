# 임상 핵심 변증 지도

한의학의 변증은 증상명을 하나의 처방에 바로 연결하는 과정이 아니라 **증상 조합과 시간패턴 → 한열·허실 → 기혈진액·장부 → 치법 → 본초·방제·경혈 → 치료반응 재평가**의 흐름으로 이해할 수 있습니다.

## 핵심 변증

| 변증 | 임상에서 먼저 보는 특징 | 바로가기 |
|---|---|---|
| **기허** | 쉽게 지침·회복저하·식욕저하 | [기허](qi-deficiency.md) |
| **혈허** | 창백·어지럼·건조·수면저하 | [혈허](blood-deficiency.md) |
| **기혈양허** | 피로와 혈허 증상이 함께 나타남 | [기혈양허](qi-blood-deficiency.md) |
| **담음** | 더부룩함·오심·가래·어지럼·무거움 | [담음](phlegm-fluid.md) |
| **어혈** | 고정통·자통·타박 후 통증·월경통 | [어혈](blood-stasis.md) |
| **한습** | 냉감·무거움·부종·날씨에 민감한 통증 | [한습](cold-damp.md) |
| **간울** | 스트레스와 소화·두통·수면·여성 증상의 연동 | [간울](liver-qi-stagnation.md) |
| **신허** | 요슬산연·야간뇨·중년 이후 회복저하 | [신허](kidney-deficiency.md) |

## 어떻게 사용하나요?

예를 들어 같은 피로라도 **기허인지, 기혈양허인지, 신허인지**에 따라 함께 나타나는 소화·수면·냉감·어지럼·배뇨 증상이 다를 수 있습니다.

같은 요통도 **한습·어혈·신허**의 비중이 다르면 본초·방제·경혈을 연결하는 방식이 달라집니다.
