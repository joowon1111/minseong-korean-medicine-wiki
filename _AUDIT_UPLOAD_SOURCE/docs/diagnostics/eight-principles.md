# 팔강변증

팔강변증(八綱辨證)은 복잡한 증후를 **표·리, 한·열, 허·실, 음·양**의 여덟 강령으로 정리하는 기본 변증 체계다.

## 표리(表裏)
병위의 깊이를 본다.

- **표:** 피부·근육·경락 등 비교적 외부
- **리:** 장부 등 비교적 내부

## 한열(寒熱)
병증의 성질을 구분한다.

- **한:** 냉감, 따뜻한 것을 선호하는 경향 등
- **열:** 열감, 갈증, 찬 것을 선호하는 경향 등

## 허실(虛實)
정기와 사기의 관계, 기능의 부족과 병리적 정체의 정도를 본다.

- **허:** 기·혈·음·양 등의 부족
- **실:** 사기·담음·어혈·식적 등 병리적 요인이 비교적 뚜렷한 상태

## 음양(陰陽)
앞의 여섯 강령을 포괄하는 총강이다. 일반적으로 리·한·허는 음적 성격, 표·열·실은 양적 성격과 연결해 이해할 수 있지만 실제 임상에서는 복합적인 형태가 흔하다.

## 복합 변증
```text
표 + 한 + 실 → 표한실증
리 + 열 + 실 → 이열실증
리 + 한 + 허 → 이한허증
```

실제 환자는 단일 강령보다 여러 요소가 동시에 나타날 수 있으므로 사진을 종합해 판단한다.
