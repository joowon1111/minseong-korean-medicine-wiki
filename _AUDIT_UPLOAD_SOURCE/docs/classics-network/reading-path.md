# 한의학 고전은 어떤 순서로 읽으면 좋은가?

처음부터 원문 전체를 순서대로 읽기보다 **기초이론 → 병증·처방 → 종합의학 → 체질의학**의 흐름으로 접근하면 이해가 쉽다.

```text
1. 황제내경
   ↓
2. 상한론
   ↓
3. 금궤요략
   ↓
4. 동의보감
   ↓
5. 동의수세보원
```

## 처음 읽는 경우
- 황제내경: 핵심 개념을 중심으로
- 상한론: 육경병증과 대표 처방 중심으로
- 금궤요략: 주요 잡병과 처방 연결 중심으로
- 동의보감: 분야별 구조를 중심으로
- 동의수세보원: 체질→병증→치료 구조를 중심으로

고전을 하나씩 분리해서 보기보다 **공통 개념과 서로 다른 임상 초점**을 비교하며 읽으면 지식망이 더 잘 연결된다.
