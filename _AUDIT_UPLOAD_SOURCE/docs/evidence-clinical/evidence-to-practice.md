# 근거 → 실제 임상 적용
좋은 연구라도 모든 환자에게 그대로 적용되는 것은 아닙니다.

```text
연구 결과
 +
환자 특성
 +
병증·중증도
 +
안전성
 +
환자 선호
 +
실현가능성
 ↓
임상 판단
```

## 적용 전에 묻는 것
- 연구대상과 현재 환자가 비슷한가?
- 효과크기가 의미 있는가?
- 위험·부작용은?
- 더 강한 표준치료가 있는가?
- 병용치료로 쓰는가 대체치료로 쓰는가?
- 추적 가능한 결과지표가 있는가?

이 과정을 통해 '근거가 있다'를 **실제 진료에서 사용할 수 있는 판단**으로 바꿉니다.
