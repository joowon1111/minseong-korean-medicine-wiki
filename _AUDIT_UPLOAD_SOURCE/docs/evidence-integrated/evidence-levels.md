# 근거 수준 읽기

연구는 종류마다 답할 수 있는 질문이 다릅니다.

| 연구 | 주로 알 수 있는 것 |
|---|---|
| 기초·전임상 | 성분·기전·생물학적 가능성 |
| 증례 | 실제 임상에서 관찰된 경과 |
| 관찰연구 | 환자군에서의 연관성과 경향 |
| RCT | 비교군 대비 치료효과 |
| 체계적 문헌고찰 | 여러 연구의 전체 흐름 |
| 메타분석 | 통합된 효과크기 |
| 진료지침 | 근거와 임상판단을 종합한 권고 |

## 중요한 원칙
**세포·동물실험의 긍정적 결과 = 사람에게 같은 임상효과**는 아닙니다. 반대로 전통적으로 오래 사용된 치료는 현대 연구가 아직 모든 임상 맥락을 포착하지 못할 수도 있으므로 연구 질문과 실제 사용 맥락을 함께 봅니다.
