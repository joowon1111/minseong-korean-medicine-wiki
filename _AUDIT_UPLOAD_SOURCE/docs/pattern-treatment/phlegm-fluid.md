# 담음 → 화담·이기·건비

[담음](../diagnostics/phlegm-fluid.md)은 진액대사의 병리적 정체를 설명한다.

```text
담음
 ↓
화담·이기·건비
├─ 반하
├─ 복령
├─ 육군자탕
└─ 온담탕
```

비위기허가 바탕이면 [육군자탕](../formulas/liujunzi-tang.md), 담위불화와 불면·흉민 등이 두드러지는 맥락에서는 [온담탕](../formulas/wendan-tang.md) 구조를 비교한다.
