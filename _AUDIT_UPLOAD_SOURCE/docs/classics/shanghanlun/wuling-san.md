# 오령산 조문

!!! info "조문 ID"
    **MS-SHL-TY-WLS-001** — 아카이브 내부 관리용 ID입니다.

## 원문
> 發汗已，脈浮數，煩渴者，五苓散主之。

## 번역
발한한 뒤에도 맥이 부삭하고 번갈이 있는 경우 오령산이 주치한다고 기술한다.

## 관련 원전 맥락
같은 계통의 문헌에는 상한 후 **한출이갈(汗出而渴)**인 경우 오령산을 사용하고, 갈증이 없으면 복령감초탕을 구분하는 조문도 이어진다.

## 해설
오령산을 단순한 '이뇨제'나 '부종 처방'으로만 이해하는 것은 상한론 조문의 맥락을 축소한다. 표리 상태, 갈증, 수액대사 관련 증후의 조합을 함께 본다.
