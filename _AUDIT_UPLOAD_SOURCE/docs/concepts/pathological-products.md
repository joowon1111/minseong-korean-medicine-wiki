# 어혈·담음·기체

## 어혈
[어혈](../diagnostics/blood-stasis.md)은 혈의 운행이 원활하지 않고 정체된 병리 상태를 설명한다. 통증이 오래되거나 고정된 양상 등과 연결해 살핀다.

## 담음
[담음](../diagnostics/phlegm-fluid.md)은 진액대사의 이상으로 생기는 병리적 산물을 설명한다.

대표 연결:
- [반하](../herbs/pinellia.md)
- [복령](../herbs/poria.md)
- [온담탕](../formulas/wendan-tang.md)
- [육군자탕](../formulas/liujunzi-tang.md)

## 기체
기체는 기의 운행이 막힌 상태를 뜻하며 창만·답답함이나 정서 변화에 따라 달라지는 증상과 연결해 이해한다.

```text
기체 → 기의 운행 정체
어혈 → 혈의 운행 정체
담음 → 진액대사의 병리적 정체
```

→ [기·혈·진액](../foundations/qi-blood-fluid.md)
