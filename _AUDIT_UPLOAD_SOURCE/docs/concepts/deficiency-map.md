# 기허·혈허·기혈양허

## 기허
[기허](../diagnostics/qi-deficiency.md)는 기의 추동·고섭·방어 등 기능적 작용이 부족한 상태를 설명한다.

대표 연결:
- [인삼](../herbs/ginseng.md)
- [황기](../herbs/astragalus.md)
- [사군자탕](../formulas/sijunzi-tang.md)
- [보중익기탕](../formulas/buzhong-yiqi-tang.md)

## 혈허
[혈허](../diagnostics/blood-deficiency.md)는 혈의 영양·자윤 기능이 부족한 상태다.

대표 연결:
- [당귀](../herbs/angelica.md)
- [숙지황](../herbs/prepared-rehmannia.md)
- [사물탕](../formulas/siwu-tang.md)
