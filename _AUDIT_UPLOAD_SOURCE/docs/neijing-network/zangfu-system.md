# 장부와 기능체계

황제내경의 장부론은 오장육부를 해부학적 기관만으로 보지 않고 생리적 기능과 상호관계의 체계로 설명한다.

```text
오장
├─ 간
├─ 심
├─ 비
├─ 폐
└─ 신

육부
├─ 담
├─ 소장
├─ 위
├─ 대장
├─ 방광
└─ 삼초
```

장부는 기혈진액, 정신활동, 소화·흡수, 호흡, 수분대사 등과 연결되어 이해된다.
