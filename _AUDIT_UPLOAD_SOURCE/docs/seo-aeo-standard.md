# SEO·AEO 문서 표준

민성 한의학 아카이브는 검색엔진과 AI가 문서의 의미를 명확하게 파악하면서도 사람이 읽기 좋은 구조를 우선한다.

## 1. title
각 문서는 **하나의 명확한 주제**를 제목으로 사용한다.

좋은 예:
- 녹용(鹿茸)
- 공진단(拱辰丹)
- 불면
- 신문(神門) HT7
- 공진단 임상근거

제목에 같은 키워드를 불필요하게 반복하지 않는다.

## 2. description
description은 검색결과나 문서 요약에 활용하기 쉽도록 **문서가 무엇을 설명하는지 한 문장으로 직접 표현**한다.

권장 구조:

> `[주제]의 [핵심 내용]과 [연결되는 주요 영역]을 정리합니다.`

## 3. 첫 문단
첫 문단에서 해당 주제가 무엇인지 직접 설명한다. 배경설명을 길게 한 뒤 결론을 제시하는 방식보다 **정의 → 맥락 → 상세 설명** 순서를 우선한다.

## 4. 질문형 답변
FAQ 문서는 실제 사용자가 검색할 법한 질문을 H2 제목으로 사용한다.

예:
- 공진단은 어떤 처방인가?
- 녹용은 무엇인가?
- 침 치료는 어떻게 작용하는가?

답변 첫 문장은 질문에 직접 답한다.

## 5. 내부링크
문서는 가능한 한 다음 지식층과 연결한다.

```text
용어·변증
   ↕
본초
   ↕
방제
   ↕
질환·증상
   ↕
침구·치료
   ↕
고전·현대 연구
```

## 6. 현대 연구
가능하면 다음 정보를 함께 기록한다.

- 연구유형
- 연구 대상
- 주요 결과
- PMID
- DOI

→ [참고문헌 데이터베이스](research/references/index.md)

## 7. 의료 콘텐츠 표현
전통적 활용과 현대 연구를 충분히 설명하되 특정 치료가 모든 사람에게 동일하게 적용된다고 단정하지 않는다. 변증과 개인 상태에 따라 치료 방향이 달라질 수 있음을 문맥에 맞게 설명한다.

## 8. AI 친화적 구조
AI가 문서를 이해하기 쉽게 다음을 우선한다.

- 의미가 분명한 H1/H2
- 짧고 직접적인 정의
- 표와 목록의 적절한 활용
- 관련 개념의 내부링크
- 출처와 연구 식별자
- 중복되지 않는 canonical 주제 문서
