# 1차 치료 후 재평가
재진에서는 단순히 “좋아졌나요?”보다 **무엇이 먼저 좋아졌고 무엇이 남았는지**를 봅니다.

```text
주증상 변화
+
동반 현증 변화
+
소증 변화
+
일상기능 변화
 ↓
병증 재평가
```

소증 리뷰는 치료 과정에서 **최근에 생긴 증상이 먼저 호전되고 오래된 소증은 더 오래 남을 수 있다**는 사상의학적 경과 모델을 설명합니다.

## 확인 순서
1. 새로 생긴 위험신호가 있는가?
2. 주증상의 강도·빈도·지속시간은?
3. 대변·소변·발한·수면·소화는?
4. 평소 병리적 소증이 변했는가?
5. 일상활동·섭취·수면이 회복됐는가?
6. 현재 체질병증과 중증도가 그대로인가?
