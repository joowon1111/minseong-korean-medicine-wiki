# 초진 기록
## 1. 체질
태양인 / 소양인 / 태음인 / 소음인과 체질 판단의 근거를 기록합니다.

## 2. 발병 전 소증
소화·식욕 / 대변 / 소변 / 땀 / 수면 / 한열 / 갈증·음수 / 피로·회복 / 성정·정서.

## 3. 현재 현증
- 주증상과 발병일
- 동반증상
- 일상기능 영향
- 섭취·배설·수면·활동 변화

## 4. 체질병증
`표/리 → 순/역 → 중증도 → 세부 병증`

## 5. 기준점
치료 후 비교할 수 있도록 가장 중요한 현증 2~3개와 병리적 소증 2~3개를 기준점으로 남깁니다.

소증은 발병 이전의 개인 고유 임상정보이며 체질진단·병증진단·치료전략·치료경과 평가에 모두 중요합니다.
