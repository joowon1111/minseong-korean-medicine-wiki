# 군신좌사와 처방 구조
전통 방제는 약재를 단순히 모아놓은 것이 아니라 **처방 안에서 역할을 나누는 구조**를 갖습니다.

| 역할 | 의미 |
|---|---|
| 군(君) | 핵심 병증을 직접 다룸 |
| 신(臣) | 군약을 보조하거나 주요 겸증을 다룸 |
| 좌(佐) | 부수 증상·독성·편성을 조절 |
| 사(使) | 약력을 조화하거나 특정 부위로 인도 |

```text
핵심 병증
 ↓
군약
 + 신약
 + 좌약
 + 사약
 ↓
처방 전체의 방향
```

실제 처방 해석에서는 각 약재를 고정된 역할로만 보지 않고 **배합 전체 속 기능**을 함께 봅니다.
