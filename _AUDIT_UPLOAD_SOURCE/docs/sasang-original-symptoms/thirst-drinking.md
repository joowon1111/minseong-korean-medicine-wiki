# 갈증·음수
2020년 표리병증 소증 진단지표에는 **음수량과 갈증**이 포함됐습니다.

**문진:** 평소 물 섭취량, 갈증 빈도, 찬물/따뜻한 물 선호, 한 번에 마시는 양, 설사·발한·열과의 관계.

소음인의 복통·설사에서 갈증 유무, 소양인의 열·진액손상에서 갈증 변화처럼 현재 병증의 깊이를 읽는 정보로 활용됩니다.
