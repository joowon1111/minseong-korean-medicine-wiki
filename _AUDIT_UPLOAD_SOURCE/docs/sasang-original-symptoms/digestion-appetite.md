# 소화·식욕
다기관 연구에서 식사량·속도·식욕 등은 체질별 차이가 보고됐고, 소화기 소증은 별도의 체계적 고찰과 평가도구 연구로 발전했습니다.

**문진:** 평소 식욕·식사량·속도, 식후 더부룩함·가스·복통, 음식 온도/종류에 따른 반응, 발병 후 변화.

- 소음인: **음식선화**가 핵심 건강신호.
- 소양인: 식욕을 열·갈증·대변과 함께 평가.
- 태음인: 소화·대변을 발한·체력과 함께 평가.
- 태양인: 섭취·연하·구토 변화가 열격병증에서 중요.
