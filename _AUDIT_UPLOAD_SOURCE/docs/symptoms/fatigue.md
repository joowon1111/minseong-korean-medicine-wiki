# 피로·기력저하

피로와 기력저하는 한의학에서 하나의 원인으로만 설명하지 않는다.

```text
피로·기력저하
├─ 기허 → 인삼·황기 → 보중익기탕
├─ 기혈양허 → 십전대보탕
├─ 비위기허 → 사군자탕·육군자탕
├─ 정혈·허손 → 녹용·공진단
└─ 기·진액·양생 → 경옥고
```
