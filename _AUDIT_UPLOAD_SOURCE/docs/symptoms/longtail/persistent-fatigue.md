# 자꾸 피곤하고 기운이 없을 때

피로가 반복될 때 한의학에서는 단순히 '기운이 없다'고만 보지 않고 **기허·비위기허·기혈양허·정혈부족·기음양허** 등의 차이를 살핀다.

```text
기허 → 인삼·황기 → 보중익기탕
기혈양허 → 십전대보탕
비위기허 → 사군자탕·육군자탕
정혈·허손 → 녹용·공진단
기·진액·양생 → 경옥고
```
