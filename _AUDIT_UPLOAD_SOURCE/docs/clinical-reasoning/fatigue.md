# 피로의 한의학적 임상 추론

## 1. 주증상
피로·기력저하가 언제 심해지는지, 수면·식욕·소화·활동량과 어떤 관계가 있는지 살핀다.

## 2. 변증의 갈림길
```text
피로
├─ 소화약화·식욕저하 → 비위기허
├─ 무력감 중심 → 기허
├─ 기허 + 혈허 양상 → 기혈양허
├─ 오래된 허손·정혈부족 → 허손
└─ 진액 소모·기허 → 기음양허
```
