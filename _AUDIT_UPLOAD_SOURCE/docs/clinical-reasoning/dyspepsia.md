# 소화불량의 한의학적 임상 추론

## 1. 증상
식후 더부룩함, 조기포만, 식욕저하, 오심, 트림 등 어떤 양상이 중심인지 살핀다.

## 2. 변증
```text
소화불량
├─ 피로·식욕저하 → 비위기허
├─ 담·오심·더부룩함 → 담음
├─ 과식 후 악화 → 식적
└─ 정서와 연동된 창만 → 기체
```
