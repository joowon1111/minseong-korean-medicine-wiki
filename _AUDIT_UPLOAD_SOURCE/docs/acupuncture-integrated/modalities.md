# 침·전침·뜸·부항

| 치료 | 핵심 | 주로 확인할 것 |
|---|---|---|
| 침 | 경혈·국소점 자극 | 통증·기능·병증 |
| 전침 | 침에 전기자극 | 강도·빈도·내약성 |
| 뜸 | 온열자극 | 한증·냉감·피부상태 |
| 부항 | 음압자극 | 근육긴장·국소 불편·피부 |
