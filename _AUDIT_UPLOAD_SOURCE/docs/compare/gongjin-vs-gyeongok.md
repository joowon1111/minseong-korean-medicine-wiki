# 공진단과 경옥고의 차이

공진단과 경옥고는 모두 보익·회복의 맥락에서 많이 알려져 있지만 **구성과 전통적 처방 방향이 다르다.**

| 구분 | 공진단 | 경옥고 |
|---|---|---|
| 대표 구성 | 녹용·당귀·산수유·사향 계열 | 인삼·생지황·복령·봉밀 |
| 중심 관점 | 정혈·허손·기혈의 회복 | 기와 진액·양생·보익 |
| 대표 본초 | 녹용 | 인삼·생지황 |
| 아카이브 | [공진단](../formulas/gongjin-dan.md) | [경옥고](../formulas/gyeongok-go.md) |
