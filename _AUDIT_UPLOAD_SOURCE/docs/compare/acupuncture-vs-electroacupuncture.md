# 침과 전침의 차이

전침은 자입한 침에 전기 자극을 연결한다는 점에서 일반 침과 차이가 있다.

| 구분 | 침 | 전침 |
|---|---|---|
| 자극 | 자입·수기 | 자입 + 전기 자극 |
| 조절 | 수기 방식·유침시간 | 주파수·강도·시간 등을 추가 조절 |
