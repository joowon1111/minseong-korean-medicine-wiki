# 한의학 근거 계층 지도

| 근거 유형 | 주로 답하는 질문 |
|---|---|
| 고전·전통 문헌 | 어떻게 이해하고 활용해왔는가? |
| 성분·기전 연구 | 어떤 성분·경로가 관련되는가? |
| 동물·전임상 연구 | 생체 모델에서 어떤 변화가 나타나는가? |
| 관찰연구 | 실제 임상에서 어떤 경향이 관찰되는가? |
| 임상시험 | 사람에게 어떤 변화가 나타나는가? |
| RCT | 비교군과 비교했을 때 효과 차이가 있는가? |
| Systematic review | 관련 연구 전체는 어떤 방향인가? |
| Meta-analysis | 여러 연구를 합친 효과 크기는 어떠한가? |

## 아카이브의 표현 원칙
현대 연구가 긍정적인 결과를 보인 경우 그 의미를 충분히 설명하면서도 **연구의 유형과 대상, 연구 규모를 함께 표시**한다.

이는 한의학을 부정적으로 서술하기 위한 것이 아니라, 전통적 지식과 현대 근거를 각각 가장 적절한 위치에서 보여주기 위한 구조다.
