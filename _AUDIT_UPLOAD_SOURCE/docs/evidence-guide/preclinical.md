# 전임상·기전 연구는 무엇을 알려주는가?

전임상 연구는 **어떤 생물학적 경로가 관련될 가능성이 있는가**를 탐색하는 데 유용하다.

## 대표 유형
- 성분 분석
- 세포 실험
- 동물모델
- 수용체·신호전달 연구
- 대사체·단백질체 연구

예를 들어 녹용·인삼·황기 등은 다양한 성분과 기전 연구가 축적되어 있다.

→ [녹용 근거 카드](../authority/herbs/velvet-antler.md)
→ [인삼 근거 카드](../authority/herbs/ginseng.md)
→ [황기 근거 카드](../authority/herbs/astragalus.md)

## 중요한 구분
```text
세포·기전 연구
→
사람 대상 임상연구로 확장
```

기전 연구는 본초와 침 치료의 작용 가능성을 설명하고, 사람 대상 임상연구와 함께 이해할 때 임상적 의미가 더욱 풍부해진다.
