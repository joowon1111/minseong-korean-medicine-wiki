# 인삼계지부자탕(人蔘桂枝附子湯)

## 체질·주치
**소음인 망양증**을 치료하는 처방으로 수록된다.

## 구성·용량
| 본초 | 용량 |
|---|---:|
| 인삼 | 15 g |
| 계지 | 11.25 g |
| 백작약 | 7.5 g |
| 황기 | 7.5 g |
| 당귀 | 3.75 g |
| 자감초 | 3.75 g |
| 대조 | 2매 |
| 생강 | 3조각 |

## 출전
『동의사상신편』(1929), 소음인. 한국전통지식포탈 **P0018129**.

## 조제
약재를 썰어 물에 달여 복용.
