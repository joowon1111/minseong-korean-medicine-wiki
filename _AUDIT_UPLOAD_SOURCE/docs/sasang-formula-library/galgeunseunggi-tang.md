# 갈근승기탕(葛根承氣湯)

## 체질·주치
**태음인**의 간열로 인한 온병과 대변불통을 치료하는 처방으로 수록된다.

## 구성·용량
| 본초 | 용량 |
|---|---:|
| 갈근 | 15 g |
| 대황 | 7.5 g |
| 황금 | 7.5 g |
| 길경 | 3.75 g |
| 백지 | 3.75 g |
| 승마 | 3.75 g |

**총량 41.25 g**

## 출전
『동의사상신편』(1929), 태음인. 한국전통지식포탈 **P0018574**.

## 조제
약재를 썰어 물에 달여 복용.
