# 궁귀향소산(當歸香蘇散)

## 체질·주치
**소음인** 처방으로 사시온역에 쓰는 것으로 수록된다.

## 구성·용량
| 본초 | 용량 |
|---|---:|
| 향부자 | 7.5 g |
| 자소엽 | 3.75 g |
| 진피 | 3.75 g |
| 창출 | 3.75 g |
| 천궁 | 3.75 g |
| 자감초 | 3.75 g |
| 대조 | 2매 |
| 생강 | 3조각 |
| 총백 | 5뿌리 |

## 출전
『동의사상신편』(1929), 소음인. 한국전통지식포탈 **P0018137**.

## 조제
약재를 가루내어 사용.
