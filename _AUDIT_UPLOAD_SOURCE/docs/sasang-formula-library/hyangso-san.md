# 향소산(香蘇散)W

## 체질·주치
**소음인** 처방으로 사시온역에 사용하는 것으로 수록된다.

## 구성·용량
| 본초 | 용량 |
|---|---:|
| 향부자 | 11.25 g |
| 소엽 | 9.375 g |
| 감초 | 3.75 g |
| 진피 | 3.75 g |
| 창출 | 3.75 g |
| 대조 | 2매 |
| 생강 | 3조각 |
| 총백 | 2뿌리 |

## 출전
『동의사상신편』(1929), 소음인. 한국전통지식포탈 **P0018182**.

## 조제
약재를 가루내어 사용.
