# 향부자팔물탕(香附子八物湯)

## 체질·주치
**소음인** 부인의 과도한 사려로 비가 상해 혀·목이 마르고 두통이 있는 병증에 쓰는 처방으로 수록된다.

## 구성·용량
| 본초 | 용량 |
|---|---:|
| 향부자 | 7.5 g |
| 당귀 | 7.5 g |
| 백작약 | 7.5 g |
| 백출 | 3.75 g |
| 자감초 | 3.75 g |
| 진피 | 3.75 g |
| 천궁 | 3.75 g |
| 백하수오 | 3.75 g |

**총량 41.25 g**

## 출전
『동의사상신편』(1929), 소음인. 한국전통지식포탈 **P0018144**.

## 조제
약재를 썰어 물에 달여 복용.
