# 화석지황탕(花惜地黃湯)

## 구성 본초·용량
| 본초 | 용량 |
|---|---:|
| 구기자 | 7.5 g |
| 목단피 | 5.625 g |
| 백복령 | 5.625 g |
| 산수유 | 7.5 g |
| 숙지황 | 15 g |
| 택사 | 5.625 g |

## 출전
소양인. 『동의사상신편』(1929). 한국전통지식포탈 P0018366.

## 조제·주치
탈음·허로에 쓰는 것으로 수록. 약재를 썰어 물에 달여 복용.

## 기록 원칙
한국전통지식포탈에 표시된 단위와 수치를 그대로 기록한다. 출전별 동명 처방의 구성이 다를 경우 별도 처방으로 구분하며, 표시되지 않은 용량은 임의로 보충하지 않는다.
