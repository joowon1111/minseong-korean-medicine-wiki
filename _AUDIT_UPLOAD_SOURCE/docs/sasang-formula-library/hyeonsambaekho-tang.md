# 현삼백호탕(玄蔘白虎湯)

## 구성 본초·용량
| 본초 | 용량 |
|---|---:|
| 나복자 | 5.625 g |
| 독활 | 5.625 g |
| 방풍 | 5.625 g |
| 산수유 | 5.625 g |
| 생지황 | 15 g |
| 석고 | 22.5 g 또는 37.5 g |
| 숙지황 | 37.5 g 또는 56.25 g |
| 시호 | 9.375 g |
| 지모 | 9.375 g |
| 현삼 | 15 g |

## 출전
소양인. 『동의사상신편』(1929). 한국전통지식포탈 P0018381.

## 조제·주치
망음증으로 섬어·변폐·동풍 등이 나타나는 병증에 쓰는 것으로 수록. 약재를 썰어 물에 달여 복용.

## 기록 원칙
한국전통지식포탈에 표시된 단위와 수치를 그대로 기록한다. 출전별 동명 처방의 구성이 다를 경우 별도 처방으로 구분하며, 표시되지 않은 용량은 임의로 보충하지 않는다.
