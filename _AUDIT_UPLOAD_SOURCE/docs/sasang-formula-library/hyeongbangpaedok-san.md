# 형방패독산(荊防敗毒散)G

| 본초 | 용량 |
|---|---:|
| 강활 | 3.75 g |
| 독활 | 3.75 g |
| 방풍 | 3.75 g |
| 생지황 | 3.75 g |
| 시호 | 3.75 g |
| 적복령 | 3.75 g |
| 전호 | 3.75 g |

## 출전
소양인. 『동의사상신편』(1929). 한국전통지식포탈 P0018325.

## 조제·주치
두통·한열왕래 등의 병증 정보가 연결되어 있으며 포탈 조제법은 약재를 가루내어 사용.

## 기록 원칙
한국전통지식포탈에 표시된 단위와 수치를 그대로 기록한다. 출전별 동명 처방의 구성이 다를 경우 별도 처방으로 구분하며, 표시되지 않은 용량은 임의로 보충하지 않는다.
