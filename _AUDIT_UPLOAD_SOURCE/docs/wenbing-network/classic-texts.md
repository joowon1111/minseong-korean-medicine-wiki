# 온열론과 온병조변

온병학의 발전에는 여러 고전이 중요한 역할을 했다. **엽천사의 온열론**은 위기영혈 변증의 전개에 큰 영향을 주었고, **오국통의 온병조변**은 삼초변증과 온병의 진단·치료 체계를 정리한 대표 저술로 알려져 있다.

```text
온열론
 ↓
위기영혈의 임상적 체계화

온병조변
 ↓
삼초변증·온병 처방 체계
```

이 두 흐름은 이후 온병학의 진단과 처방 구조를 이해하는 핵심 축이 되었다.
