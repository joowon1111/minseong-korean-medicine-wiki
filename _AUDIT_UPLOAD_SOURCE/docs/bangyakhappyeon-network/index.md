# 방약합편 핵심 지식망

《방약합편》은 조선 말기 임상에서 본초와 처방을 빠르게 찾아 활용할 수 있도록 구성된 대표적인 한의서다. 핵심은 **손익본초·약성가**와 **의방활투의 상통·중통·하통** 구조다.

```text
방약합편
├─ 손익본초
│   └─ 약성가
└─ 의방활투
    ├─ 상통: 보(補)
    ├─ 중통: 화(和)
    └─ 하통: 공(攻)
```
