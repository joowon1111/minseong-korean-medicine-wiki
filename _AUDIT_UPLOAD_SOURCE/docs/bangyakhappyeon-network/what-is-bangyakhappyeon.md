# 방약합편이란?

《방약합편》은 황도연의 의학 저술을 바탕으로 본초와 처방을 임상에서 찾기 쉽게 정리한 조선 말기의 대표적인 임상 편람서다.

```text
손익본초 → 약물의 성질·효능
의방활투 → 상통·중통·하통 → 처방 탐색
```

처방의 주치와 활용, 가감, 조제와 복용을 비교적 간결하게 찾아볼 수 있도록 구성된 점이 특징이다.
