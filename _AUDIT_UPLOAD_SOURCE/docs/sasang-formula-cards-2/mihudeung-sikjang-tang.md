# 미후등식장탕
**체질:** 태양인  
**큰 방향:** 열격증.

## 특히 보는 변화
연하·음식 섭취 곤란, 음식이 내려가지 않는 느낌, 구토·역류, 섭취량 감소와 체력·체중 변화를 봅니다.

`태양인 → 열격증 → 연하·섭취·구토 문제 → 미후등식장탕`

## 비교
- 오가피장척탕: 해역증의 요척·하지 기능 축.
- 미후등식장탕: 열격증의 섭취·연하 축.

## 회복
연하·섭취가 편해지고 구토·역류가 줄며 체력과 일상기능이 회복되는지 봅니다.
