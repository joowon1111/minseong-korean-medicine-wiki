# 천패모(川貝母)

## 핵심 정보
- **생약명:** Fritillariae Cirrhosae Bulbus
- **성미:** 고·감, 미한
- **귀경:** 폐·심
- **핵심 효능:** 청열윤폐, 화담지해, 산결소옹

## 임상에서 읽는 법
조담·열담·폐허구해의 전통 배합에서 중요하다.
