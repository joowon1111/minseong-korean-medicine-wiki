# 소풍산(消風散)

## 한눈에
- **치법:** 소풍양혈·청열제습
- **핵심 병증:** 풍습열이 피부에 울체된 소양·피부병증
- **주요 구성 골격:** 형개·방풍·우방자·선퇴·창출·고삼·목통·석고·지모·당귀·생지황·호마인·감초

## 처방 구조·감별
풍을 흩으면서 습열을 제거하고 혈분을 돌보는 구조다.

## 출전 읽기
『방약합편』은 담음에서 풍담에 도담탕, 한담에 오적산·이진탕 등을 구분해 연결하는 등 **병증별 처방군을 구조적으로 제시**한다. 개별 처방의 정확한 구성량은 해당 원전·수록본을 기준으로 기록하며 동명 처방은 섞지 않는다.

## 임상 탐색
`증상 → 위험신호 → 한열·허실 → 기혈진액·담습·어혈 → 치법 → 처방군 → 개별 처방`

→ [일반 방제 임상 지도](../herbal-integrated/general-formulary.md)

> 전통 병증과 현대 질환명을 1:1로 동일시하지 않으며, 실제 적용은 환자 상태와 안전성을 함께 평가한다.
