# 오약순기산(烏藥順氣散)

## 한눈에
**기체와 풍사를 함께 풀어 순기·소풍하는 대표 후세방**이다.

- **치법:** 순기소풍·산한
- **주치:** 풍질
- **출전:** 『태평혜민화제국방』, 『방약합편』(1884) 중통

## 『방약합편』 수록 구성·용량
| 본초 | 용량 |
|---|---:|
| 마황 | 5.625 g |
| 오약 | 5.625 g |
| 진피 | 5.625 g |
| 길경 | 3.75 g |
| 백강잠 | 3.75 g |
| 백지 | 3.75 g |
| 지각 | 3.75 g |
| 천궁 | 3.75 g |
| 건강 | 1.875 g |
| 감초 | 1.125 g |

**가미:** 생강 3편, 대조 2매.

## 방의
오약·진피·지각으로 기를 순행시키고, 마황·백지·강잠으로 풍사를 소산하며, 천궁으로 혈분과 두면·지체의 통증을 조절한다.

## 비교
- 분심기음: 칠정기울·흉복비체
- 오약순기산: 풍사 + 기체 + 지체통·마목의 방향
- 오적산: 한습·기혈담식이 더 복합적
