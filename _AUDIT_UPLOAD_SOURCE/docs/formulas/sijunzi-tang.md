# 사군자탕(四君子湯)

## 개요
사군자탕은 **인삼·백출·복령·감초** 네 약재로 구성되는 대표적인 보기(補氣) 처방이다. 비위의 기가 허한 상태를 기본으로 설명하며, 후대의 수많은 보기·기혈쌍보 처방이 이 구조를 바탕으로 확장되었다.

## 방제 구조
사군자탕은 한의학 방제학에서 **보기 처방의 기본 골격**으로 이해하기 좋다.

- 인삼: 원기와 비기를 보하는 중심
- 백출: 건비·조습
- 복령: 건비·삼습
- 감초: 보기·조화제약

네 약재가 함께 비위의 기를 보하고 소화·흡수 기능을 돕는 방향으로 작용한다고 설명한다.

## 처방의 확장
사군자탕의 구조는 후대 여러 처방으로 이어진다.

**사군자탕**
→ 진피·반하를 더하면 [육군자탕](liujunzi-tang.md) 계열  
→ 사물탕과 결합하면 [팔물탕](bazhen-tang.md)  
→ 다시 황기·육계가 더해지면 [십전대보탕](shi-quan-da-bu-tang.md)

이처럼 사군자탕은 보익 처방 네트워크의 출발점 가운데 하나이다.
