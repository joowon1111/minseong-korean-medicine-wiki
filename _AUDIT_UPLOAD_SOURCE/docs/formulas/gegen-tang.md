# 갈근탕(葛根湯)

## 출전
《상한론》 태양병 계통.

## 대표 조문
> 太陽病，項背強几几，無汗惡風，葛根湯主之。

→ [조문 해설](../classics/shanghanlun/gegen-tang.md)

## 전승 구성
《傷寒論注釋》 四庫全書本에는 갈근, 마황, 계, 작약, 감초, 생강, 대조의 일곱 약미가 기록되어 있다.

고대 도량형을 현대 g으로 단순 환산하지 않으며, 실제 임상 용량과 원전 용량은 별도로 구분한다.

## 방의
태양 표증에 항배강이 두드러지고 무한인 양상을 중심으로 설명한다. 또한 태양·양명 합병과 자하리 관련 조문에도 등장한다.

## 계지가갈근탕과 감별
- 계지가갈근탕 대표 조문: 항배강 + 한출 + 오풍
- 갈근탕 대표 조문: 항배강 + 무한 + 오풍
