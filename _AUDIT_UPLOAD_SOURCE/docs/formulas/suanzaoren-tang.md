# 산조인탕(酸棗仁湯)

## 핵심 카드
| 항목 | 내용 |
|---|---|
| 치법 | **양혈안신·청열제번** |
| 핵심 병증 | 허로·허번불면 |
| 주요 구성 골격 | 산조인·지모·복령·천궁·감초 |

증상명 하나와 처방을 바로 연결하지 않고 **한열·허실·기혈·담습·어혈·장부 병기**를 먼저 확인한 뒤 처방의 치법과 맞는지 봅니다.
