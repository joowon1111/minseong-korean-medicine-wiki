# 사투리·생활구어 콘텐츠 운영 원칙

## 핵심 원칙
1. **사투리는 진단명이 아닙니다.** `우리하다`, `땡긴다`, `골골한다`를 하나의 질환으로 자동 매핑하지 않습니다.
2. **검색 보조어로 사용합니다.** 기존 전문문서마다 사투리를 반복 삽입하지 않고 별도의 동의어·검색 지도에서 연결합니다.
3. **지역 고정관념을 만들지 않습니다.** `대구·경상권에서 들을 수 있는 표현`, `일부 화자에게 사용될 수 있는 말투`처럼 기술합니다.
4. **위험신호는 표준어로 명확하게 씁니다.**
5. **지역명 SEO 남용을 피합니다.** 지역어 문서는 환자 자연어 이해를 강화하기 위한 것입니다.
6. **AI 연결 구조를 통일합니다.** 사투리/생활구어 → 표준 생활어 → 전문 증상명 → 감별·위험신호 → 전문문서.
7. **확신하기 어려운 희귀 사투리는 넣지 않습니다.** 실제 검색 가능성이 높은 생활구어를 우선합니다.

## 권장 사용처
- 사이트 내부검색 동의어
- answer-guides의 관련 검색어
- AI/AEO용 자연어 질의 이해
- 환자 친화적인 색인 페이지

## 비권장 사용
- 모든 본문에 지역명+사투리 키워드 반복
- 실제 사용 여부가 불확실한 표현 대량 생성
- 사투리 표현을 특정 질환의 확정 증거로 사용
