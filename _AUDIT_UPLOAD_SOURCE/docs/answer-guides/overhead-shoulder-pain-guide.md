# 팔을 올릴 때 어깨가 아프면 무엇을 확인하나요?

## 핵심 답변
팔을 올릴 때 아픈 위치와 각도만큼 **스스로 올릴 때와 다른 사람이 움직여 줄 때의 차이, 근력저하, 야간통, 목을 움직일 때 통증이 변하는지**가 중요합니다.

## 생활동작으로 확인
머리 감기, 옷 입기, 뒤로 손 뻗기, 높은 선반 물건 꺼내기 중 어떤 동작이 가장 어려운지 기록하면 기능 변화를 보기 쉽습니다.

## 치료 후 평가
통증점수 외에 **통증 없이 팔이 올라가는 각도, 옷 입기·수면의 불편, 야간 각성, 힘을 쓸 수 있는 정도**를 비교합니다.

## 먼저 평가할 신호
외상 뒤 팔을 거의 들지 못하거나 뚜렷한 근력저하·변형·심한 부종이 있으면 구조적 손상을 먼저 확인해야 합니다.
