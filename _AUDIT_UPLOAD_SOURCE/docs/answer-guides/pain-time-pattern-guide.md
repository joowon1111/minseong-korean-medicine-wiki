# 통증이 아침·밤·움직일 때 다르면 무엇을 의미하나요?

## 핵심 답변
통증 시간과 상황은 원인을 단독 확정하지 않지만 **감별과 경과평가에 중요한 단서**입니다. 아침 첫 움직임, 오래 앉은 뒤, 걷기·계단, 밤에 누웠을 때처럼 재현 조건을 구체적으로 봅니다.

## 패턴별 확인
- 아침: 첫 움직임 후 변화와 뻣뻣함 지속시간
- 오래 앉기: 일어설 때 통증과 다리저림
- 걷기·서기: 쉬거나 앉았을 때 호전 여부
- 야간: 자세 변화와 관계, 휴식과 무관한 지속 여부
- 특정 동작: ROM·근력·근육·관절 부하와 관계

## 경중과 예후
통증점수 외에도 **통증 시작까지 걸리는 시간, 가능한 활동시간, 야간 각성 횟수, 아침 뻣뻣함 지속시간, 통증 후 회복시간**을 비교합니다.
