# 이상근증후군·엉치에서 다리저림

## 환자가 이렇게 검색할 수 있습니다

- 이상근증후군
- 엉치에서 다리로 저려요
- 오래 앉으면 엉치가 아파요
- 엉덩이에서 종아리까지 당겨요
- 이상근 약침

## 함께 구분할 상태

- 요추 신경근병증
- 둔부 MPS
- 천장관절 문제
- 좌골신경 포착
- 고관절 문제

## 먼저 확인해야 할 신호

- 진행하는 근력저하
- 대소변 이상
- 회음부 감각저하
- 양쪽 다리 증상의 급격한 악화

## 한의치료 연결

이상근 하나만 원인으로 단정하지 않고 요추와 둔부·고관절을 함께 봅니다. 약침은 좌골신경 해부와 주행을 고려해 안전하게 접근합니다.

## 치료를 한눈에 보기

**통증 위치·유발동작·ROM·근력·저림 → 위험신호 → 구조·기능·MPS → 한약·침·전침·약침 → 재평가** 순으로 봅니다.
