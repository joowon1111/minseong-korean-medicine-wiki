# 목·어깨·팔저림과 흉곽출구 증상

## 환자가 이렇게 검색할 수 있습니다

- 흉곽출구증후군
- 팔 들면 저려요
- 목 어깨 팔이 같이 저려요
- 손이 차고 팔이 저려요
- 쇄골 아래가 답답해요
- 팔저림 어깨통증

## 함께 구분할 상태

- 경추 신경근 문제
- 말초신경 포착
- 혈관성 문제
- 사각근·소흉근 MPS
- 자세·반복사용

## 먼저 확인해야 할 신호

- 팔의 갑작스러운 창백·청색증
- 심한 부종
- 맥박 변화와 심한 통증
- 진행하는 근력저하

## 한의치료 연결

신경성·혈관성 원인을 구분하고 자세·사각근·소흉근·견갑 기능을 함께 봅니다. 약침은 주요 혈관·신경 구조가 밀집된 부위이므로 해부학적 안전을 최우선합니다.
