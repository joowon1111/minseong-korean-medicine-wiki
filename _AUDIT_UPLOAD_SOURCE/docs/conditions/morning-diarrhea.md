# 아침설사·식후설사

## 환자가 이렇게 검색할 수 있습니다

- 아침마다 설사해요
- 아침에 화장실을 여러 번 가요
- 밥 먹으면 바로 설사해요
- 출근 전에 설사해요
- 긴장하면 아침설사
- 식후설사

## 함께 구분할 상태

- 과민성장증후군
- 위대장반사
- 식사·카페인
- 감염 후 장기능 변화
- 비허·간비불화·한습 등 병증

## 먼저 확인해야 할 신호

- 야간에 깨는 설사
- 혈변
- 발열
- 체중감소
- 탈수

## 한의치료 연결

시간패턴이 중요한 증상입니다. 아침·식후·긴장 상황과의 연동을 기록하고, IBS·설사·자율신경 자료와 연결해 병증을 구분합니다.

## 치료를 한눈에 보기

**식사와의 관계·배변·시간패턴·스트레스 → 위험신호 → 소화기 기능과 병증 → 한약·침·약침 → 재평가** 순으로 봅니다.
