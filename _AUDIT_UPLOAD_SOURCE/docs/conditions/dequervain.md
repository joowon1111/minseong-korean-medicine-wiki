# 드퀘르벵·엄지쪽 손목통증

## 환자가 이렇게 검색할 수 있습니다

- 드퀘르벵
- 엄지쪽 손목이 아파요
- 아기 안다가 손목이 아파요
- 엄지 움직이면 손목이 아파요
- 손목 건초염
- 산후 손목통증

## 함께 구분할 상태

- 드퀘르벵 건초염
- 손목 관절·인대 문제
- 손목터널증후군
- 전완부 근긴장

## 먼저 확인해야 할 신호

- 외상 후 심한 변형
- 심한 부종·발열
- 진행하는 감각저하·근력저하

## 한의치료 연결

엄지 움직임과 손목 부하를 확인하고 침·전침·약침은 장무지외전근·단무지신근 건초 주변을 해부학적으로 안전하게 평가해 연결합니다.
