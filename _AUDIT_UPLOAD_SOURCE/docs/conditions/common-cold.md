# 감기·급성 상기도감염

**검색어:** 감기 · 감모 · 몸살 · 감기몸살 · 급성 상기도감염 · 상기도감염 · 목감기 · 콧물감기 · 기침감기 · 인후통 · 감기 한약 · 감기 보험한약

감기는 기침·인후통·콧물·코막힘·재채기·발열·오한·몸살·두통·피로 등이 여러 조합으로 나타나는 흔한 급성 호흡기 증상군입니다. 한의학에서는 감모(感冒)의 범주에서 풍한·풍열·풍한습·수음·기허외감 등으로 세분해 봅니다.

## 먼저 감별

다음과 같은 경우에는 단순 감기 치료보다 필요한 평가가 우선합니다.

- 호흡곤란, 흉통, 객혈
- 지속되는 고열이나 의식 변화
- 심한 탈수
- 심한 연하곤란·인후부종
- 기침이 장기간 지속되거나 점점 악화되는 경우
- 폐렴·천식·독감·코로나19 등 다른 호흡기 질환이 의심되는 경우

## 한약치료

| 병증·주요 양상 | 대표적으로 비교할 처방 | 구별 포인트 |
|---|---|---|
| 풍한 + 항배강·몸살 | 갈근탕 | 뒷목·어깨 뻣뻣함, 오한, 근육통 |
| 풍한습 + 전신통 | 구미강활탕 | 몸살·관절통·습중 |
| 수음 + 맑은 콧물·기침 | 소청룡탕 | 맑은 비루·묽은 가래·기침 |
| 허약 + 외감·기침·담 | 삼소음 | 기허한 환자의 외감·담 |
| 기허 외감 | 인삼패독산 | 허약체질의 외감 |
| 풍열·인후통 | 은교산 | 인후통·열감 |
| 풍열·염증성 상기도 | 연교패독산 | 인후·열성 증상 |
| 이비인후 풍열 | 형개연교탕 | 코·인후·귀 주변 증상 |
| 소양병 양상 | 소시호탕 | 한열왕래·흉협 증상을 함께 확인 |
| 표리 복합 | 시호계지탕 | 계지탕증과 소시호탕증이 겹치는지 확인 |
| 기침 중심 풍열 | 상국음 | 풍열성 기침 |
| 폐열·천해 | 마행감석탕 | 열성 기침·천해 |
| 담습·가래 | 이진탕 | 가래·담습 |
| 기음허·회복저하 | 생맥산 | 피로·자한·구갈 등 병증 동반 |

처방명 하나를 감기 전체에 고정하지 않고 **오한/발열, 콧물 성상, 인후통, 갈증, 가래, 체력, 병기**를 함께 봅니다.

## 건강보험 한약제제

감기·기침은 건강보험 한약제제를 임상적으로 활용하기 좋은 외래 영역입니다.

대표적으로 비교할 수 있는 보험한약 처방군은 다음과 같습니다.

**갈근탕 · 구미강활탕 · 삼소음 · 인삼패독산 · 소청룡탕 · 소시호탕 · 시호계지탕 · 연교패독산 · 형개연교탕** 등

실제 처방·청구 시에는 최신 건강보험 급여목록에서 **현재 등재 제품·제형·코드**를 확인합니다.

→ [건강보험 한약제제](../herbal-integrated/insurance-herbal.md)

## 기침이 중심일 때

감기 이후 기침이 주증상으로 남는 경우에는 풍한·풍열뿐 아니라 담습·담열·폐열·폐기허·기음허 등을 다시 구분합니다.

→ [기침](cough.md)

## 비염·콧물이 중심일 때

맑은 콧물·재채기·코막힘이 지속되면 감기와 알레르기비염을 구분해서 봅니다.

→ [비염](rhinitis.md)

## 침·전침·약침과의 연결

감기에서는 한약치료가 중요한 축이며, 두통·경항통·인후·비부 불편·근육통 등 주증상에 따라 침구치료를 보조적으로 연결할 수 있습니다.
