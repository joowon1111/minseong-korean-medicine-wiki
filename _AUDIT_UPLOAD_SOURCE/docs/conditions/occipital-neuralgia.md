# 후두신경통·뒤통수 찌릿통증

- 후두신경통
- 뒤통수가 찌릿해요
- 머리 뒤가 전기 오듯 아파요
- 두피가 찌릿해요
- 목에서 뒤통수로 통증

## 함께 구분할 상태

- 경추성두통
- 긴장형두통

- 대·소후두신경 자극

## 먼저 확인해야 할 신호

- 새로운 마비·감각이상

- 대상포진성 수포
- 외상 후 악화
