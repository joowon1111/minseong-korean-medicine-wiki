# 음양(陰陽)

팔강에서 음양은 앞의 표리·한열·허실을 포괄해 병증의 전체 성격을 요약하는 상위 범주로 활용된다.

```text
양증의 큰 방향
→ 표 · 열 · 실

음증의 큰 방향
→ 리 · 한 · 허
```

이는 절대적인 등식이 아니라 병증의 전체적인 방향을 이해하기 위한 기본 구조다.
