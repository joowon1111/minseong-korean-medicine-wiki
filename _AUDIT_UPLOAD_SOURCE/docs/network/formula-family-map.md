## 6. 처방군 간 연결

```text
보기
사군자탕
├─ + 반하·진피 → 육군자탕
├─ + 사물탕 → 팔물탕 → 십전대보탕
├─ 변형 → 보중익기탕
└─ 보기+보혈+안신 → 귀비탕

화담
반하·진피·복령
├─ 온담탕
├─ 육군자탕
└─ 소청룡탕

상한론 태양병
계지탕 ↔ 마황탕
├─ 계지가갈근탕
├─ 갈근탕
├─ 대청룡탕
├─ 소청룡탕
└─ 마행감석탕
```
