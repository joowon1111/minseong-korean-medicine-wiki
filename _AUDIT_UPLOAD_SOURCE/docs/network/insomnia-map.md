# 불면 임상 지식망

불면은 한의학에서 하나의 동일한 병리로만 보지 않는다. **심비양허, 기혈부족, 담음·담열, 음혈부족 등 서로 다른 병리 구조**가 수면장애로 나타날 수 있다고 본다.

## 1. 심비양허·기혈부족
피로, 식욕저하, 심계, 건망, 안색저하 등과 불면이 함께 나타나는 구조.

연결:
- [기허](../diagnostics/qi-deficiency.md)
- [혈허](../diagnostics/blood-deficiency.md)
- [귀비탕](../formulas/guibi-tang.md)
- [인삼](../herbs/ginseng.md)
- [황기](../herbs/astragalus.md)
- [당귀](../herbs/angelica.md)
- [산조인](../herbs/ziziphus-seed.md)

## 2. 담음·담위불화
흉민, 오심, 어지럼, 심계, 불안정한 수면 등이 함께 나타나는 경우 담음 계열 변증과 연결해 볼 수 있다.

연결:
- [담음](../diagnostics/phlegm-fluid.md)
- [온담탕](../formulas/wendan-tang.md)
- [반하](../herbs/pinellia.md)
- [진피](../herbs/citrus-peel.md)
- [복령](../herbs/poria.md)

## 3. 안신 본초
[산조인](../herbs/ziziphus-seed.md)은 전통적으로 양심안신의 대표 본초이며, 현대에도 수면 관련 연구가 활발히 이어지고 있다.

## 지식망 요약
```text
불면
├─ 심비양허·기혈부족
│  ├─ 기허 / 혈허
│  ├─ 인삼·황기·당귀·산조인
│  └─ 귀비탕
└─ 담음·담위불화
   ├─ 담음
   ├─ 반하·진피·복령
   └─ 온담탕
```
