# 보기·기혈쌍보 처방 계보

한의학 방제는 처방 하나하나를 외우는 것보다 **기본방이 어떻게 확장되고 변형되는지** 이해하면 훨씬 체계적으로 볼 수 있다.

## 1. 보기의 기본축

**[사군자탕](../formulas/sijunzi-tang.md)**  
인삼 + 백출 + 복령 + 감초

비위기허를 보하는 대표적인 기본방이다.

### 사군자탕에서의 확장

사군자탕  
→ 반하 + 진피  
→ **[육군자탕](../formulas/liujunzi-tang.md)**

비위기허에 담습이 함께 있을 때의 구조로 발전한다.

---

## 2. 보혈의 기본축

**[사물탕](../formulas/siwu-tang.md)**  
숙지황 + 당귀 + 백작약 + 천궁

보혈과 활혈을 함께 고려하는 대표적인 기본방이다.

---

## 3. 기와 혈을 함께 보하는 구조

**사군자탕 + 사물탕**  
→ **[팔물탕](../formulas/bazhen-tang.md)**

즉,

인삼·백출·복령·감초  
+ 숙지황·당귀·백작약·천궁

의 8약 구조가 된다.

### 팔물탕에서 한 단계 더 확장

팔물탕  
+ 황기 + 육계  
→ **[십전대보탕](../formulas/shi-quan-da-bu-tang.md)**

십전대보탕은 기혈쌍보를 바탕으로 온보와 보익을 한층 강화한 대표 처방이다.

---

## 4. 사군자탕 계열의 또 다른 발전

사군자탕의 보기 구조를 바탕으로  
황기·당귀·진피·승마·시호 등이 결합하면

→ **[보중익기탕](../formulas/buzhong-yiqi-tang.md)**

비위기허와 중기하함을 함께 고려하는 처방으로 발전한다.

---

## 5. 보기 + 보혈 + 안신의 결합

인삼·황기·백출 등 보기약  
+ 당귀·용안육 등 보혈약  
+ 산조인·원지·복신 등 안신약

→ **[귀비탕](../formulas/guibi-tang.md)**

귀비탕은 기혈을 보하면서 심비양허와 안신 영역까지 확장되는 구조를 보여준다.

---

## 계보 한눈에 보기

```text
사군자탕
├─ + 반하·진피 → 육군자탕
├─ + 사물탕 → 팔물탕
│              └─ + 황기·육계 → 십전대보탕
├─ 변형·확장 → 보중익기탕
└─ 보기 + 보혈 + 안신 → 귀비탕

사물탕
└─ + 사군자탕 → 팔물탕
```
