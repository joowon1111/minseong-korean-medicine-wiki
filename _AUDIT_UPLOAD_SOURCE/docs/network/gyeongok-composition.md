# 경옥고 구성 본초

```text
경옥고
├─ 인삼 → 보기·원기
├─ 생지황 → 양음·생진
├─ 복령 → 건비·삼습
└─ 봉밀 → 보중·윤조·제형
```

## [인삼](../herbs/ginseng.md)
원기와 비·폐의 기를 돕는 보기의 중심축.

## [생지황](../herbs/fresh-rehmannia.md)
음혈과 진액을 돕는 자음·생진의 중심축.

## [복령](../herbs/poria.md)
비위를 돕고 습을 조절하여 보익약의 소화·흡수 기반을 보조한다.

## 봉밀
약성을 조화시키고 고(膏)의 제형을 형성하며 전통적으로 보중·윤조의 방향을 지닌다.

## 전체 구조
경옥고는 **보기 + 자음 + 건비 + 윤조**를 간결하게 결합한 양생 보익 처방이다.
