# 공진단 구성 본초

```text
공진단
├─ 녹용 → 보신양·익정혈·강근골
├─ 당귀 → 보혈·활혈
├─ 산수유 → 보간신·삽정고탈
└─ 사향 → 개규·행기·통락
```

## [녹용](../herbs/cervi-parvum-cornu.md)
공진단의 보익적 중심축. 정혈·신양·근골을 돕는다.

## [당귀](../herbs/angelica.md)
혈을 보하면서 혈행을 돕는 방향을 더한다.

## [산수유](../herbs/cornus-fruit.md)
간신을 보하고 정기의 지나친 소모를 수렴하는 방향을 더한다.

## [사향](../herbs/musk.md)
밀도 높은 보익 배합에 개규·행기·통락의 방향을 부여하는 특징적인 약재다.

## 전체 구조
공진단은 **보익 + 보혈 + 수렴 + 통달**이 결합된 처방으로 이해할 수 있다.

→ [공진단](../formulas/gongjin-dan.md)  
→ [공진단 지식망](gongjin-dan-map.md)
