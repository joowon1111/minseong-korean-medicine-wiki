# 요통 경혈 지식망

요통 침구치료에서는 **요부 국소혈 + 방광경 원위혈 + 변증 경혈**을 조합하는 방식이 널리 활용된다.

## 대표 경혈
- [신수 BL23](../acupuncture/points/bl23-shenshu.md) — 요부·신허 관련 대표 배수혈
- [위중 BL40](../acupuncture/points/bl40-weizhong.md) — 요배통의 대표 원위혈

2023년 저요통 RCT의 경혈 네트워크 분석에서는 BL23·GV3·BL20·BL40·BL25가 가장 자주 사용된 경혈군에 포함됐다. 같은 분석에서 침 치료군은 대조군보다 통증 감소에서 유리한 결과를 보였다.

2025년 미국의 대규모 Pragmatic RCT에서는 65세 이상 만성 요통 환자에서 침 치료를 기존 의료에 추가했을 때 6개월과 12개월의 요통 관련 기능장애가 더 크게 개선됐다.

```text
요통
├─ 요부 허약·신허 → 신수
├─ 태양경 요배통 → 위중
└─ 변증에 따라 두충·우슬·독활기생탕과 지식망 연결
```
