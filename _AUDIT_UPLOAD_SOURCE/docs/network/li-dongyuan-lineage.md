# 이동원 계보

[이동원](../physicians/li-dongyuan.md)의 의학은 **비위의 기능과 원기, 음식과 노권에 의한 내상**을 중시한다.

```text
음식부절·노권
      ↓
    비위 손상
      ↓
    원기 부족
      ↓
 비위기허·승청 저하
      ↓
    중기하함
      ↓
   보중익기탕
```

## 비위론
[《비위론》](../classics/piwei-lun.md)은 비위가 기혈 생성과 승강의 중심이라는 관점을 체계적으로 전개한다.

## 중기하함
비위의 기가 허해 승거 기능이 약해진 병리구조는 [중기하함](../glossary/sinking-middle-qi.md)으로 연결된다.
