# 처방 구성 네트워크

한의학 처방은 약재의 단순한 합이 아니라 **각 본초의 역할이 서로 보완되며 하나의 치료 방향을 만드는 배합 구조**다.

## 대표 처방

| 처방 | 핵심 구성 | 중심 방향 |
|---|---|---|
| [공진단](gongjin-composition.md) | 녹용·당귀·산수유·사향 | 정혈·보익·통락 |
| [경옥고](gyeongok-composition.md) | 인삼·생지황·복령·봉밀 | 보기·자음·건비·윤조 |
| [생맥산](shengmai-composition.md) | 인삼·맥문동·오미자 | 익기·양음·생진·수렴 |
| [오령산](wuling-composition.md) | 택사·저령·복령·백출·계지 | 이수·건비·기화 |
| [십전대보탕](shipjeondaebo-composition.md) | 팔물탕 + 황기·육계 | 기혈쌍보·온보 |

## 탐색 방법
처방에서 구성 본초로 이동한 뒤, 해당 본초가 들어가는 다른 처방을 다시 탐색할 수 있다. 이렇게 하면 `처방 → 본초 → 다른 처방`의 지식망이 형성된다.
