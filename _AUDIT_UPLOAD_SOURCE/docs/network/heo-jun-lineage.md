# 허준 계보

[허준](../physicians/heo-jun.md)의 [《동의보감》](../classics/donguibogam.md)은 방대한 동아시아 의학지식을 **내경·외형·잡병·탕액·침구**의 구조로 재편한 조선의 대표 의학서다.

```text
허준
 ↓
동의보감
├─ 내경 → 정·기·신·장부
├─ 외형 → 신체 부위별 증후
├─ 잡병 → 다양한 임상 병증
├─ 탕액 → 본초
└─ 침구 → 경락·경혈
```

## 공진단
[공진단](../formulas/gongjin-dan.md)은 허손·정기 소모와 연결되는 대표적인 보익 처방으로 아카이브에서는 녹용·당귀·산수유·사향과 현대 피로 연구까지 이어진다.

→ [공진단 임상근거](../research/formulas/gongjin-dan.md)

## 경옥고
[경옥고](../formulas/gyeongok-go.md)는 인삼·생지황·복령·봉밀을 중심으로 기와 진액, 양생과 회복을 함께 바라보는 대표 처방이다.

→ [경옥고 임상근거](../research/formulas/gyeongok-go.md)

## 탕액과 침구
동의보감 계보는 처방뿐 아니라 [본초학](../herbs/index.md)과 [침구학](../acupuncture/index.md)으로도 자연스럽게 확장된다.

→ [전체 의가·고전·처방 계보](physician-classic-formula-lineage.md)
