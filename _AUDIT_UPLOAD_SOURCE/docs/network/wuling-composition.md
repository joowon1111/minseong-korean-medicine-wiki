# 오령산 구성 본초

```text
오령산
├─ 택사 → 이수삼습
├─ 저령 → 이수삼습
├─ 복령 → 이수·건비
├─ 백출 → 건비·조습
└─ 계지 → 온양·기화
```

## [택사](../herbs/alisma.md)
이수의 중심적인 역할을 한다.

## [저령](../herbs/polyporus.md)
복령·택사와 함께 수습을 배출하는 방향을 강화한다.

## [복령](../herbs/poria.md)
이수하면서 비위를 돕는다.

## [백출](../herbs/atractylodes.md)
건비·조습을 통해 수액대사의 기반을 보조한다.

## 계지
온양과 기화의 방향을 더해 단순한 이뇨 약물의 조합을 넘어서는 처방 구조를 만든다.

## 전체 구조
오령산은 **이수 + 건비 + 기화**의 결합으로 이해하면 상한론의 수액대사 처방 구조를 파악하기 쉽다.
