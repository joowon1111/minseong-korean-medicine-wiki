# 한의치료 방법 지식망

```text
한의치료
├─ 침 → 경락·경혈·국소 자극
├─ 약침 → 경혈 + 약침액
├─ 전침 → 침 + 일정한 전기 자극
├─ 부항 → 음압·연부조직 자극
├─ 뜸 → 경혈 + 집중 온열
└─ 온열/TDP → 넓은 부위의 이완·온열 보조
```
