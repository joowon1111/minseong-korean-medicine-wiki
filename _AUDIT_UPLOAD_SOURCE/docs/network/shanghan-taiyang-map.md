# 상한론 태양병 지도

《상한론》의 태양병은 표에 병사가 머무는 초기 병태를 중심으로 하지만, **한출·무한, 번조, 수음, 항배강, 수기불리 등 증후의 조합에 따라 처방이 달라진다.**

```text
태양병
├─ 영위불화·한출 → 계지탕
├─ 표실·무한 → 마황탕
├─ 항배강 → 갈근탕 계열
├─ 표실 + 번조 → 대청룡탕
├─ 표증 + 수음 → 소청룡탕
└─ 수기불리 → 오령산
```

## 계지탕
영위불화와 자한을 중심으로 이해하는 태양중풍의 대표 처방이다.

→ [계지탕](../formulas/guizhi-tang.md)

## 마황탕
무한·신통 등 표실의 양상을 중심으로 하는 태양상한의 대표 처방이다.

→ [마황탕](../formulas/mahuang-tang.md)

## 갈근탕
태양병에서 항배강 등 경항부의 긴장이 두드러지는 맥락과 연결된다.

→ [갈근탕](../formulas/gegen-tang.md)

## 대청룡탕
강한 표실에 번조·내열의 양상이 함께 나타나는 구조를 이해하는 데 중요하다.

→ [대청룡탕](../formulas/daqinglong-tang.md)

## 소청룡탕
표증과 함께 담음·수음이 겹쳐 기침·천명·묽은 담 등의 양상이 나타나는 구조와 연결된다.

→ [소청룡탕](../formulas/xiaoqinglong-tang.md)

## 오령산
태양병 과정에서 수액대사의 불균형과 소변불리·구갈 등의 수기 문제를 다루는 대표 처방이다.

→ [오령산](../formulas/wuling-san.md)
