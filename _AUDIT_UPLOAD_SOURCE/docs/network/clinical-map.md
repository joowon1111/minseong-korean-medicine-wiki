# 증상별 임상 지도

한의학에서는 같은 증상이라도 **환자의 전체 상태와 변증에 따라 치료 방향이 달라질 수 있다.**  
이 페이지는 증상 하나를 특정 처방과 기계적으로 연결하는 대신, 현재 아카이브에 구축된 **증상 → 변증 → 본초 → 방제**의 흐름을 보여준다.

## 불면
[불면](../conditions/insomnia.md)

대표 연결:
- 심비양허·기혈부족 → [귀비탕](../formulas/guibi-tang.md)
- 담음·담위불화 → [온담탕](../formulas/wendan-tang.md)
- 안신 본초 → [산조인](../herbs/ziziphus-seed.md)

→ [불면 임상 지식망](insomnia-map.md)

## 만성피로
[만성피로](../conditions/chronic-fatigue.md)

대표 연결:
- 기허 → 인삼·황기
- 기혈허 → 팔물탕·십전대보탕
- 비위기허 → 보중익기탕
- 보익 본초 → 녹용

→ [만성피로 임상 지식망](fatigue-map.md)

## 소화불량
[소화불량](../conditions/dyspepsia.md)

대표 연결:
- 비위기허 → 사군자탕
- 비위기허 + 담습 → 육군자탕
- 담위불화 → 온담탕
- 주요 본초 → 백출·복령·반하·진피

→ [소화불량 임상 지식망](dyspepsia-map.md)

## 요통
[요통](../conditions/low-back-pain.md)

대표 연결:
- 풍한습비 + 간신부족 → 독활기생탕
- 근골 관련 본초 → 두충·우슬
- 혈허·어혈 동반 가능성 → 당귀·어혈 변증

→ [요통 임상 지식망](low-back-pain-map.md)

!!! note "임상적 이용"
    이 지도는 한의학 지식의 구조를 이해하기 위한 교육용 연결망이다. 실제 진료에서는 증상의 원인, 경고 신호, 환자의 전신상태와 변증을 함께 평가한다.
