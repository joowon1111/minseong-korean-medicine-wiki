# 신(腎)

## 핵심 기능
**장정(藏精), 주수(主水), 납기(納氣)**

## 개요
신은 정을 저장하고 성장·발육·생식, 수액대사, 호흡의 수납과 근골의 기반을 담당한다고 설명된다.

## 현대적 해석의 원칙
한의학의 신은 현대 해부학의 동일 이름 장기만을 뜻하지 않는다. 장기의 해부학적 기능에 더해 전신의 기혈진액·정신·체질적 기능을 포괄하는 전통적 기능체계로 이해한다.
