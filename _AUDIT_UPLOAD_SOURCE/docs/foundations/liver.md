# 간(肝)

## 핵심 기능
**소설(疏泄), 장혈(藏血)**

## 개요
간은 기의 원활한 소통과 혈의 저장을 주관하는 장부로 설명된다. 정서·근육·눈·월경 등과도 전통적으로 연결된다.

## 현대적 해석의 원칙
한의학의 간은 현대 해부학의 동일 이름 장기만을 뜻하지 않는다. 장기의 해부학적 기능에 더해 전신의 기혈진액·정신·체질적 기능을 포괄하는 전통적 기능체계로 이해한다.
