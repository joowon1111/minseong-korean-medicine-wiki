# 장부 개요

한의학의 장부 개념은 단순한 해부학적 장기보다 **생리기능·정신활동·기혈진액의 운행을 포함한 기능적 체계**다.

## 오장
- [간(肝)](liver.md) — 소설·장혈
- [심(心)](heart.md) — 주혈맥·장신
- [비(脾)](spleen.md) — 운화·통혈
- [폐(肺)](lung.md) — 주기·선발숙강
- [신(腎)](kidney.md) — 장정·주수·납기

## 상호 관계
오장은 각각 독립적이지만 기혈진액의 생성과 순환, 정·신·수액대사에서 서로 긴밀하게 연결된다.

예:
- 비 → 기혈 생성의 기반
- 심 → 혈맥을 주관
- 간 → 혈을 저장하고 기의 소통을 돕음
- 폐 → 기의 선발·숙강
- 신 → 정과 수액대사의 근본

## 사상의학과의 연결
사상의학에서는 이 장부 기능의 상대적 강약을 체질의 핵심 구조로 활용한다.
