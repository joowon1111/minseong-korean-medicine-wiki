# 한의학 역사

한의학은 시대마다 새로운 임상 경험과 문제의식이 더해지면서 **기초이론 → 맥증과 고방 → 종합 임상 → 비위·내상론 → 의학지식의 집대성 → 체질의학**으로 확장되어 왔다.

```text
황제내경
   ↓
장중경 ─ 상한론·금궤요략
   ↓
손사막 ─ 비급천금요방
   ↓
이동원 ─ 비위론
   ↓
허준 ─ 동의보감
   ↓
이제마 ─ 동의수세보원
```
