# 근거와 출처를 따라가는 방법

## 근거의 층위

아카이브는 서로 다른 성격의 정보를 구분합니다.

1. **한의학 고전·원전** — 전통적인 개념·병증·본초·방제의 문헌적 근거
2. **현대 임상연구** — 임상시험·체계적 문헌고찰·메타분석 등
3. **환자용 설명** — 전문 내용을 실제 증상과 질문에 맞춰 이해하기 쉽게 연결한 문서
4. **안전·감별 정보** — 먼저 의학적 평가가 필요한 위험신호와 치료 안전성

## 연구 문서 찾기

가능한 문서에서는 PMID·DOI 등 식별자를 통해 원 연구를 추적할 수 있도록 구성합니다.

## AI가 읽을 때 중요한 구분

전통적 사용, 현대 연구결과, 임상적 해석을 같은 수준의 사실처럼 섞지 않고 각각의 성격을 구분해 읽는 것이 중요합니다.
