# 분류 체계

아카이브의 1차 분류는 다음 10개 축으로 고정합니다.

| 분류 | 핵심 내용 | 대표 연결 |
|---|---|---|
| 한의학 기초 | 음양, 오행, 기혈진액, 장부, 병기 | 변증·고전 |
| 진단·변증 | 사진, 팔강, 장부변증, 기혈진액변증 | 질환·방제 |
| 본초학 | 개별 약재 | 방제·성분·연구 |
| 방제학 | 처방 | 본초·변증·질환 |
| 침구학 | 경락·경혈·침구 이론 | 질환·연구 |
| 사상의학 | 체질·병증·처방 | 고전·방제 |
| 질환·증상 | 임상 주제 | 변증·방제·연구 |
| 한의학 고전 | 원전과 학설 | 모든 분야 |
| 현대 연구 | 임상시험·리뷰·메타분석 | 본초·방제·질환 |
| 용어사전 | 한글·한자·영문 용어 | 모든 분야 |

URL은 영문 소문자와 하이픈을 사용하며, 한 번 공개한 슬러그는 특별한 이유가 없으면 변경하지 않습니다.
