# 장부변증이란?

장부변증은 증상을 해부학적 장기명에 단순 대응시키는 방식이 아니라, **한의학적 장부의 기능체계와 병리적 변화**를 종합해 병증을 구분하는 방법이다.

```text
주증상
+ 동반증상
+ 설·맥
+ 생활·경과
   ↓
장부 기능 분석
   ↓
허·실·한·열
   ↓
구체적 장부병증
```

팔강변증이 전체적인 방향을 잡는 기본 좌표라면, 장부변증은 **어느 기능체계가 중심인지**를 더 구체적으로 본다.
