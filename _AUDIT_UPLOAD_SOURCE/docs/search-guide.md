# 사이트 검색 안내

## 검색창
상단 검색창에 본초·처방·질환·경혈·고전·연구 식별자를 입력하면 관련 페이지와 섹션을 찾을 수 있다.

예:
```text
녹용
공진단
불면
요통
신문 HT7
상한론
PMID
```

## 검색 결과 강조
검색결과를 열면 검색어가 본문에서 강조되어 원하는 내용을 빠르게 찾을 수 있다.

## 검색 결과 공유
검색 결과 화면의 공유 기능을 이용하면 특정 검색어 결과를 다시 찾기 쉬운 형태로 공유할 수 있다.

## 태그로 탐색
검색어가 정확히 떠오르지 않을 때는 [태그 지식 색인](tags.md)을 이용해 관련 문서를 주제별로 탐색할 수 있다.
