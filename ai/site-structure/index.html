    AI·검색엔진용 사이트 구조¶

    민성 한의학 아카이브는 개별 문서를 나열하는 방식보다 환자의 자연어 질문에서 출발해 전문 한의학 지식과 현대 임상근거까지 이어지는 계층형·관계형 구조를 사용합니다.

    핵심 탐색 흐름¶

    자연어 질문 → 증상·질환 → 위험신호·감별 → 한의학적 변증 → 본초·방제·침구치료 → 현대 임상근거 → PMID·DOI

    모든 문서를 이 순서대로 읽을 필요는 없습니다. 증상·처방·경혈·연구 중 알고 있는 정보에서 시작해 관련 문서로 이동합니다. R-code 등 분류 코드는 필요한 문서의 보조 정보이며, 코드나 내부 링크의 연결만으로 진단·처방의 적합성을 확정하지 않습니다.

    1. 환자 언어와 증상¶

    • 증상·질환
    • 증상 기반 한약 탐색
    • 질문형 답변 가이드

    질환명을 모르는 사용자도 “속이 더부룩해요”, “잠이 안 와요”, “허리가 오래 아파요”, “기침이 계속돼요” 같은 표현에서 시작하도록 설계합니다.

    2. 질환과 현대 임상근거¶

    • 질환별 현대 근거 카드
    • 근거 가이드
    • 참고문헌 데이터베이스

    질환 페이지와 authority 근거 카드를 분리하면서 서로 연결해, 임상 맥락과 근거 요약을 모두 탐색할 수 있게 합니다.

    3. 본초와 방제¶

    • 본초학
    • 방제학
    • 대표 본초 근거 카드
    • 한약 처방 임상근거

    본초와 방제는 임상영역별 분류와 질환별 근거를 통해 본초 → 방제 → 질환 → 연구 및 역방향 탐색이 가능하도록 구성합니다.

    4. 경혈·침구치료¶

    • 침구·치료 통합 허브
    • WHO 표준 361경혈 임상 아틀라스
    • 침 치료 근거 카드

    경혈은 한글명과 WHO 국제 표준 코드를 함께 사용해 국내 검색과 국제 논문 탐색을 동시에 지원합니다.

    5. 지식그래프¶

    • 통합 한의학 지식 그래프
    • 본초→방제 역탐색
    • 방제→질환·변증 지도
    • 질환→치료 통합 지도

    핵심 질환 페이지에서는 가능한 범위에서 다음 관계를 명시합니다.

    질환 → 관련 방제 → 관련 본초 → 관련 경혈 → 현대 임상근거

    6. AI용 핵심 색인¶

    사람이 읽는 AI 핵심 색인과 함께 다음 자료를 제공합니다.

    자료 역할
    llms.txt 핵심 허브·출처와 기계가 읽는 자료의 진입점
    문서별 JSON 색인 주제별 문서와 해당 문서의 JSON 주소를 찾는 목록
    데이터 안내 지식 데이터의 파일 구성과 접근 경로
    지식그래프 문서의 유형과 내부 연결 관계를 모아 둔 자료
    사이트맵·robots.txt 공개 페이지의 발견과 크롤링 지침

    한 주제를 읽을 때는 문서별 색인에서 해당 JSON을 찾으면 됩니다. 문서별 JSON에는 공개 본문, 대표 HTML URL, 실제 제목 앵커와 관련 링크가 들어 있으며 HTML과 함께 생성됩니다. 인용할 때는 JSON 주소보다 대표 HTML 주소와 해당 제목 앵커를 사용하고, 연구 결과는 연결된 원문 출처까지 확인합니다.

    지식그래프의 연결은 ‘관련 문서로 이동할 수 있다’는 의미입니다. 연결 자체가 임상적 동등성이나 특정 치료의 추천을 뜻하지 않습니다.

    크롤링 원칙¶

    • 깨끗한 공개 URL(/.../)을 우선 사용합니다.
    • 존재하지 않는 과거 경로나 .md 공개 URL을 핵심 색인에 넣지 않습니다.
    • 질환 페이지는 환자 증상·임상 맥락을 설명합니다.
    • authority 페이지는 현대 임상근거의 핵심 요약에 사용합니다.
    • 참고문헌 DB는 PMID·DOI 추적의 기준 허브로 사용합니다.
    • 전통적 활용과 현대 임상근거를 구분합니다.

    현재 robots.txt¶

    공개된 robots.txt는 아래처럼 일반 크롤러의 접근을 허용하고 사이트맵을 안내합니다. 실제 수집·색인 여부는 크롤러와 호스팅의 응답 상태 등에 따라 달라지므로, 이 설정만으로 모든 검색엔진과 AI가 내용을 수집했다고 판단하지 않습니다.

    User-agent: *
Allow: /

Sitemap: https://wiki.minseong.co.kr/sitemap.xml

    최종 구조¶

    사람에게는 탐색하기 쉬운 임상 지식망, 검색엔진에는 주제가 명확한 내부링크 구조, AI에는 증상·질환·치료·근거 관계가 명시적인 아카이브를 목표로 합니다.

    아래의 AEO·GEO 설명은 질문에 직접 답하고 주제의 관계와 출처를 명확히 제공한다는 뜻입니다. 특정 AI가 요구하는 전용 규격을 뜻하지 않습니다. Google AI 검색도 기존 SEO 원칙을 바탕으로 하며, 별도 AI 파일이나 스키마를 필수로 요구하지 않습니다. Google 공식 안내.

    침구·신경·초음파 지식축¶

    최근 침구 영역은 다음 관계를 별도의 현대 임상축으로 제공합니다.

    환자 자연어 질문 → 증상·저림 위치 → 신경근 → 말초신경 → 근육 → 포착부위 → 초음파 → 경혈 → 침구치료 → 현대 임상근거

    핵심 허브¶

    • 침구·치료 포털
    • 신경포착증후군
    • 근육·말초신경 임상해부학
    • 침의 과학적 접근
    • 근골격계 초음파

    AEO 질문 의도¶

    • 손가락 저림은 어느 신경과 관련되는가?
    • 손목터널 초음파에서 정중신경은 어떻게 평가하는가?
    • L5 신경근병증과 총비골신경 포착은 어떻게 연결되는가?
    • 침은 말초신경·척수·뇌에 어떻게 작용하는가?
    • 전침의 주파수와 자극 강도는 어떤 의미인가?
    • 초음파 유도 침구치료는 어떤 해부학적 구조를 확인하는가?

    GEO 관계¶

    전통 경혈 지식과 현대 임상해부학을 동일시하지 않고 다음처럼 연결합니다.

    WHO 경혈 → 주변 해부층 → 근육 → 말초신경·혈관 → 척수 분절 → 자침 → 질환별 임상근거

    사상의학 지식축¶

    사상의학 영역은 체질 이름을 단순한 성격·체형 분류로 제공하지 않고 다음 관계로 구조화합니다.

    사상의학 → 사상인 → 장부 기능의 상대적 균형 → 소증 → 현재 병증 → 표리병증 → 증상 → 처방 → 원전 → 현대근거

    핵심 허브¶

    • 사상의학 한눈에 보기
    • 소양인
    • 소음인
    • 태음인
    • 태양인
    • 증상으로 사상체질 이해하기

    AEO 질문 의도¶

    • 사상의학이란 무엇인가?
    • 사상인이란 무엇인가?
    • 소양인·소음인·태음인·태양인의 차이는 무엇인가?
    • 비대신소·신대비소·간대폐소·폐대간소는 무엇인가?
    • 소증은 왜 중요한가?
    • 같은 불면·소화불량·피로라도 체질별로 어떻게 다르게 보는가?

    GEO 관계¶

    전통적인 장부 대소는 실제 장기 크기와 동일시하지 않고 사상의학적 기능의 상대적 균형이라는 원전·이론적 맥락에서 제공합니다.

    현대 질환명과 사상체질 병증을 자동으로 1:1 대응시키지 않고, 소증·현재 병증·원전·현대 연구를 구분해 연결합니다.

    사상체질 음식 탐색¶

    사상의학의 생활관리 영역에서는 체질식 정보를 다음 관계로 제공합니다.

    사상인 → 평소 소증 → 현재 병증 → 소화상태 → 음식 선택 → 섭취 후 반응

    • 사상체질별 음식 가이드

    체질별 음식은 절대적인 금기표로 구조화하지 않고, 개인의 현재 상태와 실제 반응을 함께 해석하도록 연결합니다.
