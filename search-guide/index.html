    사이트 검색 안내¶

    상단 검색창에서는 일상적인 증상 표현과 한의학 전문용어를 함께 검색할 수 있습니다. 정확한 병명이나 처방명을 몰라도 지금 불편한 증상을 그대로 입력해 보세요. 문서 전체를 찾을 때는 상단 검색창을, 특정 설명과 출처를 읽을 때는 아래 질문 검색을 이용합니다.

    질문으로 근거 자료 찾기¶

    처방명·본초명이나 짧은 질문으로 아카이브 본문 발췌와 해당 문서를 찾습니다. 전체 자료에서 검색하거나 고전, 처방, 본초, 임상·학습, 현대 연구로 범위를 좁힐 수 있습니다. 예를 들어 사군자탕과 육군자탕의 차이, 반하의 법제와 구성, 상한론 소양병 치법을 입력해 보세요.

    질문 검색을 준비하고 있습니다. 상단 검색창도 함께 이용할 수 있습니다.

    검색어를 입력하고 근거 자료 찾기를 누르면 관련 본문 발췌를 보여 줍니다. 결과의 문서 제목·소제목·발췌·본문과 출처 확인을 차례로 읽고 해당 문단으로 이동하세요. 고전의 원문과 해석, 처방의 출전·구성·용량, 본초의 성미·귀경·배합, 현대 연구의 대상·결과·한계를 문서 안에서 함께 읽어 보세요. 근거 자료 검색은 브라우저에서 처리하며 별도의 가입이나 유료 API 설정이 필요하지 않습니다.

    ChatGPT에서 자료를 함께 읽고 싶다면 질문·출처 복사를 눌러 발췌와 링크를 붙여 넣을 수 있습니다. 복사만으로 질문이 외부 AI에 자동 전송되지는 않습니다. 자동 복사가 제한되면 AI에 보낼 질문과 발췌 확인을 펼쳐 직접 복사할 수 있습니다. AI 답변에 제시된 출전·해석·구성·용량은 연결된 원문에서 확인하세요.

    화면에 출처 기반 AI 답변 생성 버튼이 표시되는 경우에는 버튼을 눌렀을 때 질문과 아카이브 발췌가 AI 서버와 OpenAI에 전송됩니다. 이 기능을 사용할 때는 이름·연락처·환자 개인정보를 입력하지 말고, 답변의 출처 링크와 실제 발췌를 함께 확인하세요. 버튼이 표시되지 않아도 본문 검색과 질문·출처 복사는 이용할 수 있습니다.

    한약 처방의 출전·원문·구성·용량 임상 핵심 처방 100선 처방을 선택해 비교

    검색창 이용하기¶

    검색창에 한 단어 또는 짧은 표현을 입력하면 문서 제목·주요 검색어·본문을 바탕으로 관련 문서를 우선 표시합니다.

    찾고 싶은 내용 검색어 예시
    증상을 일상 표현으로 찾기 잠이 안 와요, 허리가 아파요, 체했어요, 코가 막혀요
    증상·질환명으로 찾기 불면, 요통, 소화불량, 비염
    본초·방제 찾기 녹용, 인삼, 공진단, 보중익기탕
    경혈 찾기 신문, HT7, 신문 HT7
    고전·사상의학 찾기 상한론, 동의보감, 소음인, 소증
    민성의담 이야기 찾기 쌍화탕, 중종 삼소음, 허준 약값
    현대 연구 찾기 무작위 임상시험, 메타분석, PMID, DOI

    제목과 잘 맞는 문서를 우선 찾고, 관련 증상 표현·태그·본문도 함께 검색합니다. 검색 순서는 내용을 찾기 위한 안내이며, 치료의 효과나 개인에게 맞는 처방의 순위를 뜻하지 않습니다.

    검색 결과에서 문서 찾기¶

    검색 결과에는 관련성이 높은 문서가 우선 표시됩니다. 제목 아래의 요약을 함께 읽으면 원하는 증상·질환·치료 문서인지 빠르게 구분할 수 있습니다.

    결과가 너무 많을 때는 검색어를 조금 더 구체적으로 입력해 보세요.

    • 통증 → 발목통증, 손목통증, 턱관절통증
    • 잠 → 잠이 안 와요, 자주 깨요
    • 소화 → 식후 더부룩함, 명치가 답답해요
    • 저림 → 손이 저려요, 다리가 저려요

    질환의 설명과 연구를 함께 읽기¶

    최근 통합된 짧은 증상 안내·근거 카드의 주소는 기존 질환 본문이나 해당 연구 절로 이어집니다. 예전 카드 제목으로 검색해도 도착한 문서의 제목과 소제목을 확인하세요. 같은 질환의 평가·변증·치료·경과와 연구 조건을 한 문서에서 함께 읽을 수 있습니다.

    찾는 질문 바로 확인할 본문
    허리가 아플 때의 침·한약 등 치료 연구 요통 임상근거
    계단·쪼그림 등 동작에 따른 무릎통증 무릎통증 평가와 치료 · 연구 절
    잠들기 어렵고 자주 깨는 증상의 연구 불면 임상근거
    식후 불편감과 조기 포만감의 치료 연구 기능성소화불량 연구

    연구 결과는 실제 대상·치료·제제·비교군·기간을 함께 읽습니다. 여러 질환을 연결하는 근거 허브와 고유한 연구 자료는 연구·근거 통합 안내에서 찾을 수 있습니다.

    동의보감 원문 찾기¶

    일반 검색 결과 아래의 동의보감 원문에서 별도로 찾기를 누르면 같은 검색어로 원문 열람·검색을 엽니다. 기존 임상 문서 결과를 읽으면서 필요할 때 고전 원문을 추가로 확인할 수 있습니다.

    원문 화면에서는 당귀·當歸·경옥고 같은 한글·한자명이나 원문 구절을 입력합니다. 현재 검색 가능한 전사와 이미지로 열람하는 전권 영인본의 범위는 원문 화면에 표시합니다. 이미지에 있는 모든 글자가 검색되는 것은 아닙니다.

    비교·경혈·사상 탐색기로 좁혀 찾기¶

    일반 검색에서 대표 문서를 찾은 다음에는 각 분야의 탐색기로 자료를 나란히 살펴보세요.

    도구 이용 순서 본문에서 확인할 내용
    처방 구조·비교 이름·효능 검색 → 체계·체질·분류로 좁히기 → 2–4개 선택 또는 유사 처방 묶음 비교 출전·판본·구성·약량·가감과 유사 처방 감별
    본초 비교·감별 본초명·효능 검색 → 2–4개 선택 약용 부위·성미·귀경·효능과 처방 안의 역할
    경혈·침법 통합 탐색 경혈명·증상·근육·신경 검색 → 경락·부위·자료 범위 선택 표준경혈·사암침·동씨기혈의 위치 도해·주치 출처·해부학
    사상체질·병증 처방 탐색기 체질 → 병증 → 원문·감별 → 대표 처방 평소 소증과 현재 병증, 처방 배합·음식·양생·운동

    처방은 같은 이름이라도 출전·구성·용량이 다를 수 있으므로 수록본을 확인합니다. 경혈 검색은 관련 위치·주치 자료를 찾는 기능이고, 사상 탐색기는 체질·병증을 비교하는 학습 도구입니다. 검색 결과나 비교표만으로 개인의 진단·처방을 확정하지 않습니다.

    민성의담·하루 카드·24절기 찾기¶

    민성의담은 상단 독립 메뉴에서 엽니다. 일반 칼럼과 사상의학 이야기를 각각 최신순·회차순 목록에서 고르거나, 상단 검색창에 인물·본초·처방·사건을 입력하세요. 각 이야기에서 실제 기록의 날짜·원문 출전과 관련 임상 문서로 이어갈 수 있습니다.

    오늘의 한의학에서는 날짜 선택과 이전·다음 버튼으로 경혈·본초·상한론·사상의학 카드를 함께 이동합니다. 특정 주제를 찾으려면 페이지의 주제별 찾아보기를 사용하세요. 양생 문구 찾아보기는 240개 카드를 계절·생활 주제로 좁히거나 천금요방, 돌봄, 입추, 원문의 한자로 검색합니다.

    24절기 생활 일력에서는 절기 이름을 눌러 해당 카드를 바로 읽습니다. 한국 시간 기준 절기 당일 안내와 다른 날짜에 순환해서 만나는 절기 카드를 구분하며, 날짜별 카드와 개별 문구는 화면의 공유 기능으로 다시 열 수 있습니다.

    검색 결과 강조와 공유¶

    검색 결과에서 원하는 문서를 연 뒤 목차의 제목을 누르면 해당 부분으로 이동할 수 있습니다. 본문에서 단어를 바로 찾고 싶다면 컴퓨터의 Ctrl+F 또는 ⌘+F, 모바일 브라우저의 ‘페이지에서 찾기’를 이용하세요. 검색어 강조와 검색 결과 공유 기능의 표시 여부는 검색 화면에 따라 다를 수 있습니다.

    다른 사람에게 자료를 전달할 때는 문서를 연 뒤 주소창의 URL을 복사하면 됩니다. 특정 문단을 공유하려면 제목 옆 ¶ 링크의 주소를 복사하세요. 검색어를 다시 입력하지 않아도 같은 설명으로 바로 이동할 수 있습니다.

    다시 열고 싶은 화면 공유 방법
    질문 검색의 검색어·자료 범위 검색을 실행한 뒤 주소창 URL 복사
    찾은 설명과 원출처 본문과 출처 확인으로 연 문서의 ¶ 주소 복사
    선택한 본초·처방 비교 항목을 선택한 뒤 주소창 URL 복사
    선택한 경혈과 검색 조건 경혈 탐색기의 선택·검색 링크 복사 사용
    날짜별 하루 카드 날짜 링크 복사 사용
    특정 양생 문구 문구 링크 복사 또는 카드·출처 복사 사용

    문서가 통합되어 다른 주소로 이동한 경우에는 최종 도착한 대표 문서의 주소를 공유하세요.

    원하는 결과가 없을 때¶

    표현을 짧게 바꾸거나 비슷한 말로 다시 검색해 보세요. 질문 검색에서 범위를 좁혔다면 전체 자료로 바꿔 다시 시도하고, 처방·본초 비교에서는 체계·체질·분류 조건도 확인합니다. 자료를 불러오지 못했다는 안내가 나오면 다시 검색 또는 다시 불러오기를 누르거나 상단 검색창과 아래 허브를 이용하세요. 정확한 진단명을 모르는 경우에는 증상 중심 탐색이 더 편리합니다.

    • 증상으로 찾기
    • 질환별 보기
    • 태그 지식 색인
    • 전체 지식지도

    검색 결과만으로 증상의 원인이나 치료를 단정하지 말고, 각 문서의 위험신호·감별·치료 안내를 함께 확인하세요.
