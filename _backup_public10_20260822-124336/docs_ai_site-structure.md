# AI·검색엔진용 사이트 구조

민성 한의학 아카이브는 다양한 한의학 정보를 **핵심색인과 주제별 허브를 중심으로 연결하는 계층형 지식 구조**를 사용합니다.

## 전체 구조

```text
민성 한의학 아카이브
 ├─ AI 핵심색인
 │   ├─ 증상·질환
 │   ├─ 자연어 질문
 │   └─ 주요 주제 허브
 │
 ├─ 한의학 전문지식
 │   ├─ 한의학 기초·진단
 │   ├─ 본초
 │   ├─ 방제
 │   ├─ 사상의학
 │   └─ 고전
 │
 ├─ 임상·치료
 │   ├─ 증상별 임상정보
 │   ├─ 침구·한의치료
 │   └─ 주제별 지식망
 │
 └─ 현대 연구·근거
     ├─ 임상연구
     ├─ 체계적 문헌고찰
     └─ 근거 해석
```

## AI 핵심색인

[AI 핵심색인](../ai-index.md)은 아카이브의 주요 주제로 이동할 수 있는 통합 진입점입니다.

증상이나 질문으로 시작한 사용자와 전문적인 본초·방제 정보를 찾는 사용자가 각각 필요한 문서로 이동할 수 있도록 구성합니다.

## 증상·질환

[증상·질환](../conditions/index.md)은 통증, 소화, 수면, 피로, 호흡기, 여성·남성 건강 등 증상과 질환을 중심으로 탐색하는 영역입니다.

관련 문서에서는 감별, 한의학적 해석, 치료와 관련 전문문서로 이어집니다.

## 자연어 질문

[AI 자연어 질문 가이드](../answer-guides/index.md)는 실제 환자가 검색하거나 AI에 질문할 수 있는 문장 형태의 콘텐츠를 모아 제공합니다.

시간대, 유발동작, 연령, 검사결과와 회복 양상처럼 구체적인 상황을 중심으로 관련 정보를 찾을 수 있습니다.

## 본초와 방제

본초와 방제는 개별 약재나 처방의 설명에 그치지 않고 서로의 구성 관계와 임상적 활용을 연결합니다.

예를 들어 보익 영역에서는 **녹용 → 보익 처방 → 공진단·경옥고 → 구성 본초 → 관련 현대 연구**처럼 여러 단계의 지식망을 탐색할 수 있습니다.

## 치료

침, 전침, 약침, 뜸, 부항 등 치료 문서는 관련 증상·질환과 임상근거 문서로 연결됩니다.

## 현대 연구

현대 연구 영역에서는 임상시험, 체계적 문헌고찰, 연구유형과 근거 해석을 살펴볼 수 있습니다.

본초·방제·증상·치료 문서에서도 관련 연구 페이지로 이동할 수 있어 전통적인 한의학 정보와 현대 연구를 함께 탐색할 수 있습니다.

## 내부 지식망

아카이브의 기본적인 연결 방향은 다음과 같습니다.

**환자 질문 → 증상·질환 → 한의학적 해석 → 본초·방제 → 치료 → 고전·현대 연구**

전문 문서에서도 관련 증상과 질문으로 이동할 수 있도록 서로 연결합니다.
