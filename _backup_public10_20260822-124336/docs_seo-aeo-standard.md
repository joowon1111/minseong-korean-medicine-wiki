# SEO·AEO·GEO 문서 표준

민성 한의학 아카이브는 한의학 정보를 **사람이 읽기 쉽고, 검색엔진과 AI가 문서의 주제와 관계를 명확하게 이해할 수 있는 형태**로 정리합니다.

## 문서의 주제

각 문서는 하나의 중심 주제를 명확하게 다룹니다.

- **증상·질환** — 증상 특징, 감별, 한의학적 해석과 치료
- **본초** — 기원, 성미·귀경, 효능, 주요 처방과 연구
- **방제** — 출전, 구성, 방의, 전통적 활용과 현대 연구
- **자연어 질문** — 환자가 실제로 궁금해하는 상황에 대한 직접적인 답변
- **허브·지식망** — 관련 문서를 주제별로 연결하는 탐색 페이지

## 제목과 설명

`title`은 문서의 핵심 주제나 질문을 직접 표현합니다.

`description`은 검색 결과나 AI가 문서의 범위를 이해할 수 있도록 핵심 내용을 간결하게 설명합니다.

## 환자 검색형 콘텐츠

증상이나 질문을 다루는 문서는 가능한 한 다음 흐름을 따릅니다.

**핵심 답변 → 증상의 특징과 패턴 → 감별과 위험신호 → 한의학적 해석 → 한약·침구 등 치료 접근 → 관련 연구 → 연결 문서**

전문용어와 환자가 실제로 사용하는 표현을 자연스럽게 연결합니다.

## 한의학 전문 콘텐츠

한의학 전문 문서는 원전과 전통 이론을 바탕으로 다음 요소를 체계적으로 연결합니다.

**원전·출전 → 병증과 치법 → 본초와 처방 구성 → 임상적 활용 → 현대 연구**

고전적 개념과 현대 연구는 각각의 맥락을 구분하면서 함께 살펴볼 수 있도록 구성합니다.

## 현대 연구

현대 연구를 소개할 때에는 연구 대상, 방법, 주요 결과와 임상적 의미를 함께 설명합니다.

가능한 경우 다음 정보를 제공합니다.

- 연구 유형
- 대상과 치료방법
- 주요 평가변수와 결과
- PMID·DOI 등 참고정보

연구 결과는 해당 연구의 조건과 적용 범위를 고려하여 해석합니다.

## 내부링크

아카이브의 문서는 서로 독립된 정보가 아니라 지식망으로 연결됩니다.

**증상·질환 ↔ 변증 ↔ 본초 ↔ 방제 ↔ 치료 ↔ 고전 ↔ 현대 연구**

세부문서를 모두 메뉴에 나열하기보다 핵심색인과 주제 허브를 통해 관련 문서로 이동할 수 있도록 구성합니다.

## 자연어 질문과 검색의도

같은 증상이라도 시간대, 유발상황, 연령, 검사결과나 회복 단계가 다르면 질문의 의미가 달라질 수 있습니다.

각 자연어 질문 문서는 해당 상황의 핵심을 명확하게 설명하고, 관련 질문과 연결합니다.

## 보익·보약 콘텐츠

보익 처방과 본초는 약재 하나의 양이나 가격만으로 설명하지 않고 **원료, 약용부위, 처방 구성, 제형, 복용 맥락과 관련 연구**를 함께 살펴봅니다.

녹용·공진단·경옥고 등 주요 주제는 구성 본초와 관련 처방, 현대 연구로 이어지는 지식망으로 제공합니다.
