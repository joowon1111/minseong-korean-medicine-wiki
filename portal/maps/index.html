    전체 지식지도·안내

    환자의 생활 표현에서 전문 지식과 현대 임상근거까지, 지금 알고 있는 정보에 맞는 출발점을 선택합니다.

    🗣️ 증상으로 찾기아파요·저려요·부어요 같은 생활 표현 → 🩺 질환별 보기진단명·검사·감별·치료 → 🌿 본초·방제한약·보약·처방과 구성 약재 → 📍 침구·치료침·전침·약침·뜸·부항·경혈 → 🧭 사상의학체질·소증·병증·처방 → 🔬 연구·근거RCT·메타분석·PMID·DOI →

    어디서 시작하면 좋을까요?¶

    현재 알고 있는 정보 가장 빠른 시작점 다음 단계
    병명은 모르고 불편한 증상만 알아요 증상으로 찾기 위험신호 → 관련 질환 → 치료
    진단명이나 검사 결과를 알고 있어요 질환별 보기 감별 → 한의학적 해석 → 치료·근거
    한약·처방·약재가 궁금해요 본초·방제 통합 허브 본초 → 방제 → 증상·질환 → 연구
    침·약침·전침의 차이가 궁금해요 침구·치료 통합 허브 증상 → 경혈·해부학 → 치료법 → 재평가
    체질과 평소 소증이 궁금해요 사상의학 한눈에 보기 소증 → 현재 병증 → 처방·생활관리
    논문과 임상근거를 확인하고 싶어요 연구·근거 한눈에 보기 연구설계 → PMID·DOI → 임상 적용
    장부·기혈진액·병인·변증을 공부하고 싶어요 한의학 기초 통합 허브 개념 → 증상 해석 → 변증 → 치법
    고전 원문에서 출발하고 싶어요 고전 지식망 원문 → 병증·처방 → 현대 임상

    환자를 위한 두 개의 대표 입구¶

    증상으로 찾기¶

    병명을 모르더라도 환자가 실제로 표현하는 말에서 시작합니다.

    • 허리가 아파요
    • 손발이 저려요
    • 다리에 쥐가 나요
    • 몸이 붓고 무거워요
    • 입 벌릴 때 턱이 아파요
    • 밤에 다리가 불편해요
    • 잠이 안 오고 자주 깨요
    • 소화가 안 되고 더부룩해요

    → 생활 표현으로 증상 찾기

    질환별 보기¶

    진단명이나 의심 질환을 알고 있다면 질환 페이지에서 감별, 검사, 한의학적 해석, 한약·침구치료와 현대 근거를 함께 확인합니다.

    한의학 기초 지도¶

    개별 용어를 외우는 데 그치지 않고 증상을 해석하고 치료 방향을 정하는 구조로 연결합니다.

    본초와 방제를 약재명·처방명으로만 보지 않고 환자의 증상, 병증과 치료 목표로 연결합니다.

    검색으로 바로 찾기¶

    상단 검색창에는 다음처럼 입력할 수 있습니다.

    • 생활 표현: 입 벌릴 때 아파요, 밤에 다리가 불편해요
    • 증상: 저림, 부종, 불면, 더부룩함
    • 질환: 비염, 과민성장증후군, 손목터널증후군
    • 한약: 녹용, 귀비탕, 독활기생탕
    • 경혈·신경: 족삼리 ST36, 정중신경
    • 고전·연구: 동의수세보원, PMID, DOI

    사이트를 읽는 핵심 원칙¶

    1. 환자 표현과 전문 질환명을 연결합니다.
    2. 위험신호와 필요한 검사를 먼저 확인합니다.
    3. 한의학적 병증과 현대 질환명을 단순히 동일시하지 않습니다.
    4. 한약·침구·사상의학은 환자의 현재 상태에 맞춰 탐색합니다.
    5. 전통 출전과 현대 임상연구의 역할을 구분합니다.
    6. 치료효과는 증상뿐 아니라 기능·수면·소화·삶의 질로 재평가합니다.
