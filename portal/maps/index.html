    전체 둘러보기

    증상과 질환부터 고전 원문, 학습실, 비교 도구와 연구까지. 찾고 싶은 내용이나 읽고 싶은 방식으로 출발점을 선택하세요.

    목적별 시작점고전 원문·해석학습·비교 도구이야기·의학사연구·근거
    🗣️ 증상으로 찾기아파요·저려요·부어요 같은 생활 표현 → 🩺 질환별 보기진단명·검사·감별·치료 → 한의학 기초장부·기혈진액·진단·변증·임상 추론 → 고전 원문·해석상한론·금궤요략·동의수세보원·동의보감 → 🌿 본초·방제한약·보약·처방과 구성 약재 → 📍 침구·치료침·전침·약침·뜸·부항·경혈 → 🧭 사상의학체질·소증·병증·처방 → 🔬 연구·근거RCT·메타분석·PMID·DOI →

    어디서 시작하면 좋을까요?¶

    현재 알고 있는 정보 가장 빠른 시작점 다음 단계
    병명은 모르고 불편한 증상만 알아요 증상으로 찾기 위험신호 → 관련 질환 → 치료
    진단명이나 검사 결과를 알고 있어요 질환별 보기 감별 → 한의학적 해석 → 치료·근거
    한약·처방·약재가 궁금해요 본초·방제 통합 허브 본초 → 방제 → 증상·질환 → 연구
    침·약침·전침의 차이가 궁금해요 침구·치료 통합 허브 증상 → 경혈·해부학 → 치료법 → 재평가
    체질과 평소 소증이 궁금해요 사상의학 한눈에 보기 소증 → 현재 병증 → 처방·생활관리
    논문과 임상근거를 확인하고 싶어요 연구·근거 한눈에 보기 연구설계 → PMID·DOI → 임상 적용
    장부·기혈진액·병인·변증을 공부하고 싶어요 한의학 기초 통합 허브 개념 → 증상 해석 → 변증 → 치법
    고전 원문과 해석을 함께 읽고 싶어요 고전 원문·해석 책 선택 → 처음 읽기·목차 → 원문·독해
    문제를 풀고 기초 과목을 복습하고 싶어요 기초 한의학 퀴즈 & 학습실 과목 선택 → 카드·퀴즈 → 오답·원문 복습
    매일 짧게 한의학을 읽고 싶어요 오늘의 한의학 날짜별 카드 → 원문·풀이 → 관련 문서
    고전 속 사람과 처방 이야기가 궁금해요 민성의담 이야기 → 출전 → 원문·처방 해설

    환자를 위한 두 개의 대표 입구¶

    증상으로 찾기¶

    병명을 모르더라도 환자가 실제로 표현하는 말에서 시작합니다.

    • 허리가 아파요
    • 손발이 저려요
    • 다리에 쥐가 나요
    • 몸이 붓고 무거워요
    • 입 벌릴 때 턱이 아파요
    • 밤에 다리가 불편해요
    • 잠이 안 오고 자주 깨요
    • 소화가 안 되고 더부룩해요

    → 생활 표현으로 증상 찾기

    질환별 보기¶

    진단명이나 의심 질환을 알고 있다면 질환 페이지에서 감별, 검사, 한의학적 해석, 한약·침구치료와 현대 근거를 함께 확인합니다.

    → 질환별 보기
    → 질환별 현대 근거 카드

    증상에서 출발해 위험신호·감별 → 관련 질환·검사 → 변증·체질 → 치료·생활관리 → 연구 근거 → 경과와 재평가로 이어 읽습니다.

    고전 원문·해석과 현대 임상 연결¶

    네 책의 원문을 찾는 공통 입구는 고전 원문·해석입니다. 책별 시작 위치와 수록 범위를 먼저 확인하고, 관심 편·조문·병증으로 이동하세요.
