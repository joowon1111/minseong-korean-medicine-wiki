# 중·상 문항 편집 기준

## 정답을 아는 것과 오답을 구별하는 것을 함께 평가하기

보기를 같은 범주·같은 비교축으로 구성한다. 신경 문제라면 가까운 신경 또는 같은 신경의 손상 수준을, 위치 문제라면 같은 부위의 높이·뼈·힘줄 면을, 처방 문제라면 공통 골격을 가진 처방의 차이 약미·병기·출전을 비교한다. 정답과 무관한 장기·체질·치법을 오답으로 채워 난도를 낮추지 않는다.

‘하’는 단일 개념의 회상을 확인한다. 중은 둘 이상의 단서를 결합한다. 상은 세 축의 결합, 반례, 조건 변화, 판본·제형 또는 연구 비교 범위를 포함한다. 모호한 문장, 생소한 단어, 긴 보기 자체로 난도를 올리지 않는다. 난이도 표시는 출제 의도이며 실제 응답 자료 없이 정답률이나 검증된 난도를 주장하지 않는다.

## 문항별 검토

1. 문맥만으로 정답이 하나인지 확인한다. 조문 번호·수록본·비교 순서가 답에 영향을 주면 문제에 명시한다.
2. 적어도 두 오답은 정답의 일부 조건을 충족하게 한다. 핵심 조건 하나가 틀린 가까운 오답을 우선한다.
3. 네 보기의 문법·형식·비교축을 맞춘다. 정답만 길거나 자세하지 않은지, 오답만 절대적 표현을 쓰지 않는지 검토한다.
4. `nearestWrong`에는 가장 가까운 오답의 0부터 시작하는 번호를 기록한다. 정답과 달라야 한다. 해설은 이 보기가 충족한 조건과 틀린 조건을 각각 설명한다.
5. `discriminator`에는 최종 판단을 바꾸는 단서를 기록한다. 이 단서는 응답 후 해설에만 표시한다.
6. 모든 보기의 `detail`을 작성하고 `cardId`의 원문·근거와 대조한다. 임상 증례는 문헌 판독용 가정으로 쓰며 실제 환자의 확정 진단이나 처방으로 제시하지 않는다.
7. 고전 원문, 후대 처방 변형, 시험 제제와 현대 연구 결과의 층을 구분한다. 동일 약명·방명만으로 기원종·법제·제제·효과척도를 합치지 않는다.

`data/advanced_learning.json`의 `questionsPerLevel`로 과목별 균형을 유지한다. 기존 문항 ID는 학습 기록과 원문 링크를 위해 보존하고 새 문항은 다음 번호를 사용한다. 재생성 후 Python·JavaScript 검사, 정적 문항의 해설·앵커 및 사이트 빌드를 확인한다.

## 일반 퀴즈와 경혈 표시

경혈학·침구학에서는 혈명을 기본 표기로 쓴다. 국제 표준 코드는 원문 URL, 카드·문항 ID, 도해 대상, 검색 별칭에만 유지한다. 코드에서 혈명을 회상하는 문항은 혈명에서 위치·해부 표지를 감별하는 문항으로 교체한다. 같은 한글 혈명은 소속 경맥을 붙여 구분한다. 촌수는 표준 위치의 실제 구별 기준이므로 유지한다.

일반 문항의 오답은 원문에 있는 같은 항목에서 선택한다. 경혈은 같은 부위의 인접 혈, 해부학은 같은 구조 종류·부위, 본초는 같은 비교 묶음·효능군을 우선한다. 방제는 기존 처방 계열 비교표의 짝을 일반 처방집의 단원 경계보다 우선하여 사군자탕·육군자탕·향사육군자탕처럼 가까운 처방을 함께 비교한다. 같은 답의 표기 변형과 정답 혈명을 직접 알려주는 위치 주석을 보기에서 제외하고, 주석은 카드에 남긴다. 자동 선택은 난이도의 실측 검증이 아니므로 대표 보기를 읽어 문맥·단일 정답을 함께 검토한다.

## 실제 응답 자료에 따른 보정

실제 응답 자료를 사용할 수 있을 때 정답률, 상하위 집단 간 정답률 차이, 오답별 선택률을 검토한다. 거의 선택되지 않는 오답은 같은 범주의 더 가까운 대안으로 바꾸고, 상위 집단에서도 이견이 많은 문항은 문맥의 충분성과 근거부터 재검토한다.

출제 형식 참고: [NBME Item-Writing Guide](https://www.nbme.org/institutions/nbme-item-writing-guide/)의 단일 최선답·동질적인 보기 원칙. 한의학 내용의 근거는 각 문항에 연결된 아카이브 원문과 출전이다.

## 외부 문제 이용

상황·보기·해설은 독립적으로 작성한다. 외부 문항은 재사용 허가·범위가 확인된 경우에만 이용하며 출처와 조건을 기록한다. 기존 내부 난이도 키 basic/high/expert와 ID는 학습 기록 호환을 위해 유지하되 표시만 하/중/상으로 대응한다.

## 독립 증례·배혈·본초 추론 문항

`data/clinical_learning.json`은 일곱 과목의 5지선다 은행이다. `questionsPerLevel`은 과목별 중·상 문항 수의 기본값이며, 특정 과목을 집중 확장할 때 `questionsPerLevelBySubject`에 그 과목의 중·상 각각의 수를 명시한다. 등록되지 않은 과목명·양수가 아닌 수·정수 이외 값은 허용하지 않고, 각 과목의 실제 중·상 수가 지정값과 일치하는지 검증한다. 외부 예시는 유형만 참고하고 상황·수치·보기·해설을 독립적으로 작성한다. 배혈은 목적과 분류 체계를 명시하여 여러 가능한 임상 조합 사이의 모호함을 줄인다. 혈액검사 수치로 전통 변증이나 체질을 자동 확정하지 않는다. 검사표의 참고범위는 교육용 가정으로 표시하며, 초음파는 관찰·설정·구조 관계를 평가한다. 제외된 영상 방식은 문항에 넣지 않는다. 기존 ID와 기록을 보존하고 신규 문항은 다음 번호를 쓴다. 표는 `caption`, `headers`, `rows`로 기록해 모바일·보조기술과 정적 해설에서 같은 정보를 제공한다. 난이도는 출제 의도이며 실측 정답률이 아니다.

동일한 증후·약미를 보기 순서만 바꾸어 추가하지 않는다. 새 증례는 기능 보존·치료 전후·소증 기준선·병위·차이 약미 등 새로운 비교 조건을 갖도록 작성한다. 문항 제목·상황의 중복, 답 위치의 편중, 기원·부위·동명방과 원전·후대 수록본의 혼합을 확인한다. 문제 수 안내는 생성된 은행에서 갱신하고, 데이터 요청 버전·JavaScript 파일 버전·설정의 캐시 키를 함께 올려 기존 브라우저에서도 새 은행이 표시되게 한다.
