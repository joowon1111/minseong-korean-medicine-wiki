# 족삼리(足三里) ST36

족삼리는 족양명위경의 대표 경혈로 비위 기능과 전신의 기를 조절하는 임상 맥락에서 널리 활용된다.

## 주요 연결
```text
족삼리 ST36
├─ 비위·소화
├─ 기허·허약
├─ 전신 조절
└─ 비염 등 원위 배혈
```

→ [소화불량](../conditions/dyspepsia.md)
→ [소화·비위 허브](../pillar/digestion-spleen-stomach.md)
→ [비염](../conditions/rhinitis.md)

실제 배혈은 단독혈보다 중완·내관·삼음교 등 다른 경혈과 현재 변증을 함께 고려한다.
