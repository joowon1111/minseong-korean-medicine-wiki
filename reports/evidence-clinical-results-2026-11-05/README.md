# 질환별 대표 근거 보강·통합

기준 커밋: `dafe5a9efc8975784691c3a941453ac1a6a4a5e4`.

근거 포털에서 연결되는 기존 문서 8곳을 대상으로 임상적으로 중요한 결과와 적용 범위를 보완했다. 새 질환 카드를 만들지 않고 만성골반통 중복 카드는 기존 진료 안내로 통합한다. 전체 근거 문서의 전수평가나 독자적인 GRADE 등급 부여는 이번 범위가 아니다.

## 원자료와 출판 상태

아래 10개 PMID를 NCBI EFetch로 조회해 제목과 정정·철회·우려 연결을 확인했다. 조회된 레코드에는 `ErratumIn`, `RetractionIn`, `ExpressionOfConcernIn` 연결이 없었다. 이는 정식 편향 위험 평가나 연구의 무결성 보증을 뜻하지 않는다.

- CP/CPPS: `34399062`, `36506258`, `36960418`.
- 암 관련 피로: `23109700`, `23334562`, `23853057`, `32172198`, `38754041`.
- 암 관련 통증: `33734288`, `37962891`.

공식 AUA 2025 남성 만성골반통 지침의 권고문 28과 ASCO–SIO 2024 피로 지침을 확인했다. 홍삼 시험은 최종 논문을 기준으로 하며 학술대회 초록을 별도 성과로 합산하지 않았다. 서양삼의 주평가와 이후 시점, 홍삼의 전체·계획 준수 분석, 피로 침시험의 서로 다른 비교군을 함께 설명했다. 중복 카드에서 강조하던 네트워크 순위는 직접 비교·영역별 결과를 우선하는 방식으로 정리했다.

문서 빌드, 생성 HTML의 링크·앵커, 페이지 탐색·SEO 및 Git 인덱스 비밀정보 검사를 수행한다. 저장소의 `validate` 통과 후 병합하고 공개 페이지의 실제 반영을 확인한다.
