2,627개 파일(3,825,886바이트)을 삭제하고 이 보고서와 TSV 목록 2개를 추가했습니다. Git 이력을 다시 쓰거나 과거 커밋·브랜치·배포 이력을 제거하지 않았습니다. 저장소 전체 크기나 clone 전송량이 이 수치만큼 줄었다는 의미는 아닙니다.

삭제 근거는 [removed.tsv](removed.tsv)의 파일별 경로·기준 blob SHA·사유·보존본에 기록했습니다.

- **2,473개:** UTF-8 BOM 및 CRLF/LF 개행 차이만 정규화하면 현재 원본 또는 이번 정리에서 남긴 보존본과 바이트가 같은 복제본. 각 대응 파일이 실제로 남아 있고 정규화된 내용이 동일한지 삭제 전에 재검증했습니다. 본문을 요약하거나 유사도만으로 제거하지 않았습니다.
- **1개:** `_AUDIT_UPLOAD_SOURCE/docs/index.md`. 과거 사이트 탐색·홈 구성의 출력 스냅샷으로, 현재 원본은 `docs/index.md`입니다. 학술 원문이나 원본 데이터가 아닙니다.
- **153개:** 최상위의 과거 `APPLY_` 스크립트·상태 파일. 백업을 제외한 추적 텍스트 파일의 참조와 남기는 APPLY 항목의 전이적 호출 관계를 조사하여, 현재 도구·설치기·실행 안내에서 참조되지 않는 항목만 제거했습니다. 설치 스크립트를 실제로 실행하여 오래된 문서를 재적용하지는 않았습니다.

## 혼동 및 재유입 방지

- `README.md`와 `AGENTS.md`에 현재 편집·생성 경로와 과거 패키지의 역할을 명시했습니다.
- 저장소 전체에서 첫 검색 결과를 수정하던 `FIND_AND_FIX_POPULAR_TOPIC_DIGESTIVE.py`의 탐색 범위를 현재 `docs/`로 제한했습니다. 실제 내용을 바꾸는 해당 과거 스크립트는 실행하지 않았습니다.
- `.gitignore`에 로컬 백업·업로드 스냅샷·설정 백업·상태 파일 패턴을 추가했습니다. 이미 추적 중인 보존 자료를 숨기거나 제거하지 않으며, 현재 사용하는 payload를 포괄적으로 무시하지 않습니다.
- 이후 편집·자동화는 `docs/` 등 목적별 현재 경로를 명시해야 합니다. 남은 백업·payload는 현재 공개 문서 검색 대상으로 취급하지 않습니다. GitHub 검색 색인의 갱신 시점은 GitHub가 결정합니다.
