## 범위와 기준

기준 커밋 `cf82e91f35d4789ded9f48e60cd7d3d1169d9df2`의 소스를 빌드하고 사이트맵의 2,257개 URL을 검사했다. 이전 보고서의 약 155건을 현재 빈 태그 수로 재사용하지 않았다. HTML의 누락·공백, 사이트 공통 설명 재사용, 같은 설명의 중복, 적절한 고유 설명을 구분했다.

실제 빈 description은 0개였다. 개별 설명이 없는 문서가 MkDocs의 `site_description`을 상속하므로, 빈 태그만 검사하면 결손을 발견하지 못한다. 소스의 description 미지정 155개 중 5개는 사이트맵에서 제외된 작성 템플릿이다. 나머지 150개 문서와 홈페이지가 사이트 공통 설명을 출력했다. 홈페이지는 사이트 전체를 정확히 소개하므로 유지했다.

같은 설명을 공유한 페이지는 162개였다. 공통 설명을 쓰던 151개와 별도 중복 11개(상한론 2개, 복합증상 9개)다. 본문·출처를 확인하고 수정한 문서는 총 161개다. 본문이나 임상 주장 자체의 전수 재검증·개정은 이번 작업 범위가 아니다.
