# 동의보감 원문 열람·검색 검증

## 구현 범위

- 새 핵심 문서 1개: `/classics/donguibogam/original/`.
- 독립 검색용 전사 1,580항목: 탕액편 1,443항목, 내경편 권1 신형·정의 확보된 부분 137항목.
- 전권 영인본 25책 3,193이미지 페이지. 선택한 이미지와 PDF는 Wikimedia Commons에서 불러오며 저장소에 전권 PDF를 복제하지 않음.
- 전권의 검색 가능한 텍스트화·교감·번역 완료가 아님. 확보된 전사는 교감 미완료이며 영인본 대조가 필요함. 전사에 대응하는 판본과 전권 열람용 판본을 구분함.
- 기존 본초 문서 16개와 경옥고·동의보감 관련 허브를 실제 원문 항목에 연결함. 개별 원문 항목을 좌측 메뉴에 추가하지 않음.

## 출처 및 이용조건

한의학고전DB의 본문·번역·교감·데이터 구조를 수집하거나 재수록하지 않았음. 해당 DB는 이용조건을 안내하는 외부 참고 링크로만 유지함.

가져온 자료는 위키문헌 공개 전사(CC BY-SA 4.0)와 Commons 공개 영인본(PD-scan / PD-South Korea 표시)임. 저자·기여 이력·고정 수정판·가공 방식·이용조건·checksum을 별도 manifest와 화면에 기록함. 아카이브 자체 해설과 가져온 전사의 이용조건을 분리함.

## 검증 결과

- Python 전체 테스트 119개 통과.
- Node 테스트 파일 3개 통과: 기존 한국어 검색, 경혈 탐색, 새 원문 검색 및 일반 페이지에서의 비로딩.
- 기존 한국어 검색 색인 2,117문서 유지. 대표 검색어 30개의 상위 12개 결과 URL 및 순서가 변경 전과 동일함.
- Material 기본 검색 색인에 원문 열람 페이지가 포함되지 않음. 원문 전사는 전용 화면에서 검색·직접 항목 열람 시에만 로딩함.
- YAML 유효성 검사 통과. 원문 항목 ID·출처·체크섬·내부 연결 검사 통과.
- 전체 소스 문서 2,123개: 깨진 링크 0, HTML의 `.md` 링크 0, URL 충돌 0, 동일 내용 문서 0, 중복 제목 0.
- 완성된 사이트: 깨진 링크 0, 깨진 앵커 0.
- 페이지 발견 검사: 2,118문서, 제목 앵커 17,561개, 오류 0.
- MkDocs 빌드 성공, sitemap 2,118/2,118 URL의 Git 날짜 확인.
- Git index 보안 검사: 9,306파일, 발견 사항 0.

## 남은 범위

내경편 나머지와 외형·잡병·침구의 정확한 검색용 전사는 미수록. 전체 텍스트를 추가하려면 별도 재이용 가능한 출처를 확보하고 판본·오자·권리 상태를 확인해야 함. 영인 이미지의 제공처 장애 시에는 전사 검색은 유지되지만 이미지 열람은 제한될 수 있음.

이 보고서는 병합 전 로컬 검증을 기록함. 실제 배포 완료 여부는 GitHub Actions와 공개 사이트를 별도로 확인함.
