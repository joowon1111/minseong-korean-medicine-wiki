# 동의보감 원문 탐색·영인본 목차 보강

## 완료 범위

- 원문 검색명 117개를 편집 데이터로 추가하여 148항목의 한글 검색을 보강했다. 기존 원문 1,580항목의 ID·제목·본문·출처·대응 영인 페이지는 변경 전과 같음을 비교했다.
- 현대 본초 문서 연결 39개를 추가했다. 부위명만 있던 28항목은 동일 출처에서 앞에 놓인 본초 이름을 탐색 문맥으로 표시한다. 원문 문장을 교정하거나 현대 생약과 동일한 기원으로 판정하지 않는다.
- 수록 원문을 권별로 둘러보고 50항목씩 마지막 항목까지 넘길 수 있다. 목록 범위와 결과 페이지를 URL로 다시 열 수 있다.
- 공개 영인본의 권두제·신형 항목을 직접 대조해 내경 4권·외형 4권·잡병 11권·탕액 3권·침구 1권과 목록 2권을 구분했다. 제24책은 목록 권2, 제25책은 목록 권1이다.
- 영인본을 편·권 이름과 원전 편목으로 선택할 수 있다. 제1책의 내경 본문은 신형 항목이 보이는 이미지 29쪽으로, 나머지 책은 확인한 권두제 이미지 3쪽으로 이동한다. 확인한 이미지 URL은 manifest에 기록했다.
- 기존 침구편 임상 지도에서 해당 영인본으로 직접 이동한다. 일반 검색의 대표 질의 30개는 결과 URL과 순서를 유지한다.

## 검증

- Python 120개, Node 31개 테스트 통과.
- 원문 목록의 모든 1,580항목을 중복·누락 없이 페이지별로 확인했다. 마지막 페이지·범위별 목록·부위 문맥·한글명·영인본 탐색 시 전사 비로딩을 검사했다.
- MkDocs 빌드 성공. 전체 소스·생성 사이트 링크·앵커 오류 0건, 페이지 발견 검사 2,118문서·17,561제목 앵커 오류 0건.
- Git index의 비밀정보 검사를 거친 뒤 발행한다.

## 남은 범위

검색 가능한 전사의 범위는 탕액편 3권과 내경편 권1 일부로 유지된다. 내경편 나머지·외형편·잡병편·침구편의 오자·누락이 많은 공개 전사는 이번에 대량 수록하지 않았다. 정확한 전권 전사·교감·번역을 완료했다고 표시하지 않는다. 한의학고전DB 본문·번역·교감 자료는 사용하지 않았다.

이 보고서는 병합 전 검증 기록이며 실제 공개 반영 여부는 GitHub Actions와 운영 화면을 별도로 확인한다.
