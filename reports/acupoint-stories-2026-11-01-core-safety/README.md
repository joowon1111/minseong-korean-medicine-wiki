## 출전과 편집 범위

- 중의급성 공개 전사본 [『침구대성』](https://jicheng.tw/tcm/book/%E9%87%9D%E7%81%B8%E5%A4%A7%E6%88%90_1/index.html)의 수양명·족양명·족태양·족궐음 경혈 주치에서 여섯 항목을 직접 확인했다. 필요한 짧은 원문만 인용하고 한국어 풀이를 직접 작성했다. 확인된 별명·위치·주치와 글자 뜻을 구분하며 역사적 사건이나 효과를 창작하지 않았다.
- 인영·방광수·장문의 현재 위치는 KMCRIC 개별 표준경혈 자료와 대조했다. 나머지 위치는 기존 표준 위치 블록을 보존해 설명했다.
- 인영: [경동맥집 해부학](https://www.ncbi.nlm.nih.gov/books/NBK519577/) 및 [de Lange 외, Europace 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC11544318/)의 반사 반응·감시·사전 평가를 확인했다. 경동맥동 마사지의 결과나 발생률을 인영 자침에 전용하지 않았다. 기존 자침법 수치는 원자료 기재로 보존하고 보편적인 안전 깊이가 아니라는 점을 명시했다.
- 대장수: 말미의 중복 일반론 5개 절을 앞의 해당 절로 통합했다. 기존 링크 3개는 지식망 연결에 옮기고 `_8`~`_12` 앵커는 해당 절 앞의 호환 앵커로 보존했다. 나머지 기존 제목·앵커 및 임상 블록은 그대로 유지했다.
- 새 이야기에는 모두 `point-story` 고정 앵커를 부여했다. 아틀라스·3D 지도·경혈 데이터·메뉴·스크립트는 변경하지 않았다.

## 전수 집계

- 최신 기본 브랜치 기준 이야기 제목 있음 **166개**, 없음 **195개**.
- 이번 6개 추가 후 제목 있음 **172개 / 361개**, 없음 **189개**.
- `coverage.csv`는 361개 각 경로의 실제 본문에서 전후 제목 존재 여부를 다시 집계했다. 이전 face 보고서의 154개는 당시 결과이며 최신 집계로 덮어쓰지 않는다.
- 제목 유무 집계이지 기존 172개 이야기 전체의 품질 재검수나 361개 전수 보강 완료를 의미하지 않는다. 나머지 주요 후보는 팔료혈·고황·담수 등이며 다음 차수에서 원전과 기존 문서를 검토한다.
