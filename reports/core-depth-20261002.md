# 핵심 페이지 깊이 보강·중복 주제 통합

기준: `main` 커밋 `887c67abad57ea333093a9b48f851b93b5d4d38e`.
새 공개 문서를 추가하지 않고 기존 대표 페이지의 감별·병증·처방·치료·경과 설명과 탐색 경로를 보강했다. 이번 변경은 검토용 PR이며 기본 브랜치 병합·배포는 수행하지 않는다.

## 실제 보강

- 기능성소화불량: PDS·EPS 양상과 감별, 비위기허·습체·식적·기체·한열착잡의 처방 비교, 침·전침·약침 적용 맥락, 식사·생활·경과 평가를 기존 치료 절에 통합. 연구 목록을 본문 치료 순서로 옮기고 식물성 복합제와 동아시아 처방의 분류를 구분했다.
- 소아 잦은 감기·허약: 새 감염/지속 비염/감염 후 회복을 구분하고 노출·중증도·성장·식사·수면을 연결했다. 병증별 대표 처방 학습과 연령에 맞는 치료 구성, 발열일·결석일·회복시간·성장 흐름을 보강했다.
- 가슴답답함: 운동·식후·긴장·움직임·호흡기 양상의 감별표, 병증별 처방 비교, 침구 적용 맥락과 경과 지표를 보강했다.
- 불면·요통·족저근막염: 질환별 대표 근거 카드에 대상·중재·비교군·기간·결과·적용 범위를 통합했다. 침·전침·약침을 서로 다른 프로토콜로 읽으며 임상 결과를 구체적으로 설명했다.
- 소화·수면 허브: 목록형 변증 설명을 비교표로 바꾸고 뒤에 누적되던 반복 링크를 본문과 감별표로 통합했다. 명시적 기존 앵커는 유지했다.
- 비염 처방 찾기: 분비물·냉열·기력·담습의 조합별 대표 처방 비교와 질환·소아·근거 연결을 보강했다.
- 사상의학: 소화·수면·피로 안내와 통합 지도에서 소증→현증→병증 단계→처방→경과로 연결했다. 기존 체질별 심화 페이지를 중복 작성하지 않았다.
- 질문 안내 15개: 첫발 통증, 계단 무릎통증, 아침 요통, 야간 손저림, 팔 올릴 때 어깨통증, 보행 후 발목통증, 양반다리 고관절통, 독서두통, 냉감·저림, 소아 반복감기, 식욕·성장, 검사 후 흉민, 내시경 정상 소화불편, 스트레스 소화불편, 팽만·가스의 구분 질문과 직접 심화 경로를 개선했다.

## 통합한 기존 문서와 이동 경로

| 기존 문서 | 대표 목적지 |
|---|---|
| `authority/insomnia.md` | `authority/conditions/insomnia.md` |
| `authority/conditions/chronic-low-back-pain-update.md` | `authority/low-back-pain.md` |
| `authority/conditions/plantar-heel-pain-update.md` | `authority/conditions/plantar-fasciitis.md` |
| `conditions/stress-gut.md` | `autonomic/stress-digestion.md` |
| `conditions/heartburn.md` | `conditions/gastritis-symptoms.md`, 내부 본문 링크는 `#heartburn-route` |

5개 기존 경로는 `mkdocs.yml`에 리디렉션을 추가하고, 내부 링크는 대표 목적지로 직접 변경했다. 속쓰림 리디렉션은 기존 URL의 해시가 두 번 연결되지 않도록 페이지 단위로 두며, 내부 본문 링크는 구체적인 절로 연결한다. `symptom-care-routes`와 `modality-care-routes`의 기존 명시적 앵커도 유지했다.

## 질문 안내 전수 구조 점검

`question-route-inventory-20261002.json`에 비색인 질문 안내 111개의 핵심 답변과 직접 질환/자율신경 연결을 기록했다. 임상 질문 108개와 비임상 검색·편집 참고 3개를 구분한다. 이 분류는 구조 점검이며 모든 문서의 임상 적절성을 점수화하거나 111개를 모두 재작성했다는 뜻이 아니다.

## 원문 확인 중 바로잡은 분류

- [PMID 40626505](https://pubmed.ncbi.nlm.nih.gov/40626505/)는 2025 Cochrane **프로토콜**이다. 완료된 리뷰로 표현했던 불면 카드와 불면 본문의 참고문헌을 수정했다.
- [PMID 38981452](https://pubmed.ncbi.nlm.nih.gov/38981452/)는 *Bunium persicum*·*Coriandrum sativum* 복합 식물성 제제 시험이다. 이를 동아시아 한약 처방 시험으로 일괄 소개하던 문장을 수정했다.
- [PMID 40938602](https://pubmed.ncbi.nlm.nih.gov/40938602/)의 enhanced acupuncture는 유지치료를 더한 군이다. EA 약어를 전침과 혼동하지 않도록 설명했다.
- [PMID 23227789](https://pubmed.ncbi.nlm.nih.gov/23227789/)의 족저근막염 전침 시험은 30명·기본관리 병행·5주 10회·치료 후 6주 추적이다. 2025 사지 통증 종합 리뷰와 별개의 설계로 제시했다.

## 검증

- Python 기존 테스트 120개, Node 기존 테스트 42개 통과.
- MkDocs 빌드 및 검색·AI 지식 연결 인덱스 재생성.
- 소스와 생성 사이트의 내부 링크·앵커, URL 충돌·정확 중복 본문, 탐색 인덱스 검사.
- 새 문서 추가 대신 공개 Markdown 문서 수는 2,126개에서 2,121개로 감소했다.
- 화면 검증용 Chromium을 사용할 수 없어 모바일/데스크톱 브라우저에서의 육안 검증은 완료하지 않았다. 생성 HTML의 표 구조와 Material 테마의 표 스크롤 래퍼 생성 코드·CSS, 리디렉션 목적지·앵커를 정적 검사했다. 실제 뷰포트에서의 넘침·가독성은 미검증이다.
