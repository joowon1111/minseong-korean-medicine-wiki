## 확인 범위와 상태

아카이브는 공개 HTML과 저장소를 확인했다. 제목, 대표 URL, robots.txt, 사이트맵, WebSite·Organization·WebPage·BreadcrumbList와 공개 본문 JSON이 이미 있다. 기존 구조를 유지하고 빈 부분을 보완한다. 검색 순위·색인 증가·AI 인용 증가를 측정한 결과는 아니다.

한의원은 검색 도구에서 공개 본문을 읽을 수 있었으나, 이번 실행 환경의 직접 HTTP 요청에서는 홈페이지·중점진료·오시는 길·robots.txt가 503으로 응답했다. 관리자 화면은 연결 시간초과였고 한 차례 새로고침도 같았다. 모든 사용자·검색엔진에게 장애가 발생한다는 뜻으로 일반화할 수 없다. WordPress 설정이나 콘텐츠는 저장하지 못했다. 보안 설정을 낮추거나 임의 API를 사용하지 않았다.

## 이번 아카이브 변경

- 자동 생성 WebPage/MedicalWebPage를 기존 홈페이지의 발행 주체 식별자와 연결한다. 개인 저자나 검토자를 일괄 추정하지 않는다.
- 문서 언어에 맞는 Open Graph locale과 텍스트 공유 카드를 제공한다. 기존 메타 태그는 작은따옴표·큰따옴표 모두 인식해 중복 생성을 막는다. 공유 카드는 순위 보장 수단이 아니다.
- 사이트맵의 모든 HTML에서 단일 제목, 자기참조 canonical, Open Graph 대표 URL 일치, 공유 정보 중복, 우발적인 noindex를 검사하도록 CI를 추가한다.
- 설명의 공백·중복은 빌드 결과로 집계한다. 기존 160개 설명 누락 중 이번 범위 5개를 채우며, 나머지는 본문을 읽고 단계적으로 보완한다. 공통 문구를 개별 설명으로 오인하지 않는다.
