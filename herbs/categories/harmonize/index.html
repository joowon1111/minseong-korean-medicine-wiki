    화해·조화 본초 임상 지식망¶

    화해·조화 계열 본초는 한쪽을 강하게 보하거나 사하기보다 표리 사이·간비 불화·간울·소양병처럼 서로 다른 기능축의 조정을 이해할 때 중요합니다.

    화해는 단일 본초 분류라기보다 처방의 치법으로 쓰이는 경우가 많습니다. 시호·황금·반하처럼 서로 다른 효능군의 본초가 처방 안에서 맡는 역할을 효능·주치 표준과 함께 읽습니다.

    처방을 구성하는 대표 본초¶

    화해제는 하나의 효능군만 모은 처방이 아닙니다. 시호가 소양·간울의 막힌 기기를 여는 중심이라면, 황금은 울열·습열을 맑히고, 반하는 담과 위기의 상역을 내리며, 백작약은 혈을 기르고 긴장을 완화합니다. 생강·대조·감초는 중초와 전체 배합을 받치지만, 처방에 따라 역할과 비율이 달라집니다.

    병증·치법의 중심 대표 본초 조합 실제 처방에서 읽기
    소양 반표반리의 화해 시호 + 황금 + 반하 소시호탕
    소양에 양명리실이 겹침 시호 + 황금 + 지실 + 대황 + 백작약 대시호탕
    간울과 혈허·비허의 조정 시호 + 당귀 + 백작약 + 백출 + 복령 소요산·가미소요산
    간기울결과 흉협부 통증 시호 + 향부자 + 지각 + 천궁 + 백작약 시호소간산
    담화·번조와 중진안신 배합 시호 + 반하 + 용골 + 모려 시호가용골모려탕

    • 간비불화
    • 소양병의 왕래한열·흉협고만
    • 담음과 정서 증상의 결합

    같은 시호를 다르게 읽는 기준¶

    소시호탕 → 대시호탕 → 시호소간산 → 소요산 → 보중익기탕을 나란히 보면 시호가 화해퇴열 / 소간해울 / 승거양기 가운데 어느 역할을 맡는지 분명해집니다. 처방 이름에 시호가 들어간다는 이유만으로 같은 병증군으로 묶지 않습니다.

    • 왕래한열·흉협고만·구고·구역의 조합이면 소양 화해 구조를 먼저 봅니다.
    • 정서 변화와 흉협·소화·월경 증상이 함께 움직이면 간울과 혈허·비허의 비중을 나눕니다.
    • 처짐·오래된 설사 등 기허하함에서는 황기·인삼·백출이 중심이고 시호·승마는 승양을 돕는 배합입니다.

    임상 연결¶

    → 간울 vs 담음성 흉민

    현대 연구에서는 체온·염증 매개물질·신경행동·소화기 증상·삶의 질 등 서로 다른 지표가 사용됩니다. 이 지표를 화해·소간이라는 전통 개념 전체와 동일시하지 않고, 시호 단일 성분·시호 원약재·완성 처방의 근거를 나누어 읽습니다.
