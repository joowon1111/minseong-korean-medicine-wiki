    기초 한의학 퀴즈 & 학습실¶

    민성 한의학 아카이브는 한의학의 기초 개념을 체계적으로 익히고, 구조·위치·분류·효능·배합의 관계를 스스로 설명할 수 있도록 돕고자 이 학습실을 마련했습니다. 한의학을 처음 접하는 분부터 한의대 과목을 복습하는 학생까지, 문서와 도해에 연결된 학습카드 1,562개 · 해설형 문제 7,840개로 기초 다섯 과목과 상한론·사상의학을 함께 공부할 수 있습니다.

    이곳의 학습카드와 문항·해설은 한의학 교육과 학습을 위한 자료입니다. 개념을 이해하고 복습하는 교육·학습 목적으로만 활용해 주세요. 개인의 건강 문제에 대한 판단과 처방을 대신하는 자료가 아니며, 실제 진단과 한의학 치료는 한의원에서 한의사의 진료를 통해 받으시기 바랍니다.

    바로 복습하기¶

    과목과 단원을 고른 뒤 카드를 뒤집거나 퀴즈를 풀어 보세요. 틀린 문제는 오답 다시 풀기, 헷갈린 카드는 다시 볼 카드, 남겨 둘 자료는 북마크 카드에서 모아 볼 수 있습니다.

    하는 단일 개념 회상, 중은 유사 구조·병증 감별, 상은 예외·조건 변화·복수 단서의 판단입니다.

    퀴즈에서 문제 난이도 → 하 / 중 / 상을 고르면 고난도 통합·감별 문제를 풀 수 있습니다. 일곱 과목에 각각 중 17문제·상 17문제, 총 238문제가 있습니다. 보기는 같은 부위·분류·처방군 안에서 일부 조건을 공유하도록 구성했습니다. 답을 고른 뒤 결정적 감별 단서, 가장 가까운 오답, 보기별 해설과 연결 원문을 확인하고, 과목별 중·상 문제와 보기별 해설에서도 같은 문항을 읽을 수 있습니다. 등급은 출제 의도에 따른 구분이며 실제 정답률로 보정한 난이도는 아닙니다.

    증례·배혈·본초 추론 (5지선다)에서는 자체 작성한 444문제(중 222·상 222)를 별도로 풀 수 있습니다. 기초 해부학은 84문제입니다. 경혈학·침구학·본초학·방제학은 각각 36문제입니다. 상한론·사상의학은 각각 108문제입니다. 증례 → 변증·처방, 배혈 목적 → 혈 조합, 기원·약용 부위·효능 → 본초, 기능 보존 → 신경 분지, 초음파 관찰 → 구조·인공물 감별을 연결합니다. 혈액검사·경과 표는 교육용 가정이며, 답을 고른 뒤 다섯 보기의 해설과 결정적 감별 단서를 확인합니다.

    과목 중의 판단 상의 추가 판단
    해부학 작용·신경·관절·층의 연결 기능 보존·분지 위치·신경지배 예외
    경혈학 뼈·힘줄·면·기준점의 구별 개인별 골도분촌 계산·기준점 전환·복수 속성
    침구학 특정혈·배혈·비교군의 감별 분류축 교차·효과 크기·복합중재·안전성 분모
    본초학 유사 본초의 병위·부위·배합 역할 동명 기원·법제·누적 노출·시험물·처방 문맥
    방제학 공통 골격·차이 약재·병기의 감별 파생방의 실제 구성·한열착잡·동명방·제형
    상한론 조문 조건·치법·처방 감별 치료 뒤 변화·하법 제한·동명 현상·원문 명시 여부
    동의수세보원 같은 체질의 표리·순역·처방 분기 소증 변화·예외 증후·신축본·후대 배합·임상진료지침 구분

    학습 도구를 준비하고 있습니다. 실행되지 않으면 아래 과목별 학습 자료에서 전체 요약과 원문을 읽을 수 있습니다.

    어떻게 공부하면 좋을까요?¶

    1. 단원 하나를 선택: 처음부터 전체를 무작위로 풀기보다 경맥·특정혈·처방군처럼 범위를 좁힙니다.
    2. 카드 앞면에서 회상: 답을 보기 전에 말하거나 적어 봅니다. 모호했다면 ‘다시 볼게요’를 누릅니다.
    3. 10~20문제 확인: 정답 해설과 보기별 원문을 읽고, 왜 다른 보기는 다른 개념인지 구분합니다.
    4. 오답과 원문 복습: 맞힌 오답은 목록에서 빠집니다. 이해한 카드 수와 문제 정답 기록은 별도로 관리합니다.
    5. 다음날 다시 확인: ‘오늘의 10문제’는 같은 날짜·과목·선택 범위에서는 같은 문제를 제공합니다. 다른 범위로 좁혀 복습할 수도 있습니다.

    학교 강의계획서에 맞춰 순서를 조정하세요. 자료는 아카이브를 바탕으로 만든 자체 학습문제이며 특정 대학의 공식 교육과정이 아닙니다.

    해부학을 먼저 배우고 있다면 기초 해부학에서 부위별 근육 카드 → 설명으로 구조 식별 → 도해 식별 → 구조 이름 직접 입력 순서로 시작하세요.

    처음 시작하는 30일 학습 계획¶

    한 달 동안 일곱 과목을 한 번씩 연결하고, 어려운 단원을 다시 보는 계획입니다. 전체 문제은행을 30일 안에 소진하는 목표는 아닙니다. 하루 새 카드 5~10개·퀴즈 10~20문제·전날 오답 5개, 약 20~30분을 출발 기준으로 잡고 학업 일정에 맞춰 줄이거나 늘리세요. 이미 익숙한 단원은 새 카드 대신 중·상 감별 문제로 바꿉니다.

    새로 익힌 카드는 다음 날, 3일 뒤, 7일 뒤 다시 설명해 봅니다. 주간 복습일에는 새 카드를 늘리지 않고 오답과 북마크를 정리합니다. 아래 일정은 안내 표이며 자동 일정·알림 기능은 아닙니다.

    날 학습 범위 확인할 목표
    1일 해부학: 방향·면·조직층 앞뒤·안가쪽·장축/단축을 말하고 피부–근막–근육 층 연결
    2일 해부학: 어깨·팔꿈치 근육과 뼈 표지 회전근개와 이두근·상완근의 부착·작용 비교
    3일 해부학: 아래팔·손목 신경·혈관 정중·척골·요골 가지와 수근관 내용물 구분
    4일 해부학: 고관절·무릎·발목 구획·지배신경·정지 뼈를 함께 설명
    5일 초음파: 조직 식별·조작 힘줄·신경·혈관을 두 면과 입사각 변화로 구별
    6일 초음파: 부위 추적·도플러·측정 뼈 표지에서 구조 추적, 설정 차이와 구조 변화 구별
    7일 1주 복습: 해부학·초음파 오답 보기 없이 구조 이름과 가장 가까운 오답의 차이 설명
    8일 경혈학: 손목·아래팔 태연·신문·대릉·내관·외관의 힘줄·면·높이 구분
    9일 경혈학: 무릎·종아리·발목 음릉천·양릉천, 삼음교·현종, 태계·곤륜 비교
    10일 경혈학: 몸통·등·목 정중선·골도분촌·뼈 표지와 인접 혈 위치 설명
    11일 침구학: 오수혈·원낙극 혈명에서 분류 회상; 음경·양경의 수혈과 원혈 비교
    12일 침구학: 수모·팔회·하합혈 장부·소속 경맥·분류축을 구분해 연결
    13일 침구학: 배혈·팔맥·연구 읽기 조합 이유를 말하고 연구 비교군·결과·추적 구분
    14일 2주 복습 + 1주 오답 경혈·침구 가까운 보기 감별, 해부학 오답 재확인
    15일 본초학: 기원·부위·가공 약명과 실제 원료·법제 정보를 구별
    16일 본초학: 해표·청열·이기·화담 같은 효능군 안에서 병위·한열·배합 역할 비교
    17일 본초학: 보익·활혈·수삽 공통 효능과 각 본초의 추가 역할 설명
    18일 방제학: 보기·보혈·건중 공통 골격과 차이 약미를 연결

    고전 문제은행의 복습 순서¶

    상한론은 태양의 한출·무한 → 소양의 시호증 → 양명의 하법 조건 → 삼음의 한열·수기 순서로 좁혀 보세요. 사상의학·동의수세보원은 완실무병·장부대소 → 네 체질의 표리병론 → 체질 안의 처방 감별 순서가 좋습니다. 퀴즈에서 문제 유형을 선택하면 원문 풀이, 병증 해석, 치법·처방 연결과 새 증례·배합 판독을 따로 연습할 수 있습니다. 두 은행은 118개 카드·698문제를 제공합니다. 두 의서의 병증명은 각 체계의 문맥 안에서 읽습니다.
