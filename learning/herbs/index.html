    본초학 공부 — 이름에서 배합까지¶

    기초 한의학 학습실 / 본초학

    184개 카드 · 791문제. 개별 본초 120카드에 비교·감별 64카드를 더해 효능과 기원·부위, 처방 안의 역할을 묶었습니다. 문서에 확인된 항목을 카드에 표시하며 모든 본초에 성미·귀경·생약명 항목이 똑같이 채워진 것은 아닙니다.

    한 본초를 읽는 다섯 질문¶

    1. 무엇을 쓰는가: 식물·동물·광물의 기원과 실제 약용 부위를 확인합니다.
    2. 어떤 방향인가: 성미·귀경과 전통 효능을 설명합니다.
    3. 어떤 병기를 보는가: 효능에서 주치로 연결되는 한열·허실·기혈진액을 읽습니다.
    4. 처방에서 무엇을 맡는가: 같은 본초가 다른 배합에서 어떻게 역할이 달라지는지 봅니다.
    5. 무엇과 비교해야 하는가: 비슷한 본초의 공통점과 차이를 원문에서 확인합니다.

    퀴즈는 생약명·전통 효능뿐 아니라 원문에 확인된 약용 부위·성미·귀경과 비교군의 상대적 차이를 묻습니다. ‘이름 → 개념·특징’과 ‘설명 → 이름 찾기’를 번갈아 선택해 보세요. 효능은 현대의 특정 약리작용·질환명과 같은 뜻으로 외우지 않고 효능·주치 표준을 함께 읽습니다.

    카드와 효능 퀴즈¶

    아래 전체 학습 요약에서 본초별 효능과 원문을 읽을 수 있습니다.

    비교하며 외울 묶음¶

    묶음 비교할 질문 확인 자료
    인삼·황기·백출·산약 보기의 공통점 안에서 생진·고표·조습·고삽이 어떻게 다른가 보기·보익 본초 비교
    황련·황금·황백 청열조습·사화와 귀경·배합의 강조점은 무엇인가 청열약 5분류
    복령·택사·저령 이수삼습 외에 건비·안신·설열이 어떻게 연결되는가 택사의 비교표
    반하·죽여·천패모·길경 조습·청열·윤폐·선폐와 구역·가래의 방향을 구분하는가 천패모 비교
    생지황·숙지황 같은 지황 계열의 가공과 전통 효능이 어떻게 다른가 생지황 · 숙지황
    계지·육계 / 당귀의 기원종 이름이 비슷하거나 번역명이 같을 때 실제 원료를 확인하는가 본초 비교·감별

    학습 단원은 효능을 중심으로 묶은 복습용 분류입니다. 복합 효능을 가진 본초는 다른 단원과도 연결됩니다. 미후등·미후도처럼 문헌의 이름과 식물 기원을 구분해야 하는 항목은 그 불확실성을 카드에 보존했습니다.

    성미·귀경·효능을 병기와 연결하기¶

    한 본초를 ‘어떤 질환에 좋은가’로 시작하기보다 성질과 방향 → 병기 → 처방 속 역할의 순서로 읽습니다. 성미는 전통적으로 작용을 설명하는 언어이며 실제 맛이나 성분 하나로 효능을 결정하는 규칙이 아닙니다. 귀경은 작용을 설명하는 장부·경맥의 범주이고, 약물이 특정 장기에만 도달한다는 약동학 설명과 구분합니다.

    연결할 개념 구분 질문 본초·방제에서 확인
    청열조습 / 청열생진 습열·탁함을 말리는 방향인가, 열과 진액 손상을 함께 보는가? 황련·황금·황백의 고한 조습 / 석고·지모의 청열과 진액 고려
    조습화담 / 청열화담 / 윤폐 한습·오심인가, 담열인가, 건조·음손인가? 법제 반하 / 죽여·천패모 / 맥문동·백합을 비교
    건비익기 / 조습건비 허약한 운화를 받치는가, 습체를 조절하는 비중이 큰가? 백출의 사군자탕 / 창출의 평위산 역할
    이수삼습 / 수삽 머무는 수습을 배출하는가, 허약으로 새는 것을 거두는가? 복령·택사 / 오미자·산수유·연자육을 비교
    보혈 / 활혈 / 량혈 부족을 보하는가, 어혈을 푸는가, 혈분의 열을 식히는가? 숙지황·당귀 / 천궁·도인 / 생지황 등. 한 본초에 여러 방향이 겹칠 수 있음
    온리 / 보양 중초의 한과 구역·설사인가, 신양·정혈의 허약인가? 건강의 이중탕 역할 / 육계·녹용 등의 보양·익정 배합

    열감·냉감, 허약·창만, 건조·습체는 서로 함께 나타날 수 있습니다. 본초를 단일 증상에 대응시키기보다 효능·주치 표준과 본초 비교·감별을 함께 읽어 배합 이유를 설명합니다.

    약용 부위·가공이 바뀌면 무엇을 다시 확인하나요?¶

    기원식물의 학명과 약용 부위는 원료를 확인하는 출발점입니다. 기원이 비슷한 약재, 같은 식물의 다른 부위, 가공 전후 약재를 각각 구분하세요. 가공은 추출·성분·전통적 사용 방향에 영향을 줄 수 있으므로 이름만 같다고 같은 연구 시료로 합치지 않습니다.

    비교 확인할 원료·공정 전통적 학습의 초점
    계지 / 육계 가지 / 수피 해기·온경통맥과 보화조양·산한의 상대적 비중. 서로 바꾸어 기록하지 않음
    생강 / 건강 신선한 뿌리줄기 / 건조·가공 원료 해표·화위지구와 온중산한의 강조점. 건조했다고 모든 가공품이 같은 건강 규격은 아님
    생지황 / 숙지황 생지황 명칭 아래 실제 생품·건조품 구분 / 찌는 등 포제 공정 량혈·생진과 보혈·자음익정의 구분. 원료의 수분·가공 상태까지 확인
    감초 / 자감초 생품 / 보조재·가열법을 기록한 포제품 청열·윤폐·조화와 보기·완급의 비중을 처방 문맥에서 읽음
    백출 / 창출 각각 적용 공정서의 기원·뿌리줄기 규격 포제 전후 비교가 아니라 다른 약재의 비교. 건비익기와 조습건비의 비중 구분
    반하 / 법제 반하 원료 동정, 보조재·공정과 제품 규격 처방과 연구에 사용한 법제품을 정확히 밝힘. ‘법제했으니 모든 조건에서 안전’으로 해석하지 않음

    원료 동정·약용 부위·규격은 식품의약품안전평가원 생약종합정보에서 확인합니다. 출전의 포제 명칭, 조제기록, 연구 시험물을 나란히 적으면 같은 약재명 아래 섞인 차이를 발견할 수 있습니다.

    단미 효능에서 짝약·처방의 역할로¶

    두 본초가 함께 쓰인다는 사실만으로 현대 약리학의 상승효과가 입증되는 것은 아닙니다. 먼저 배합이 같은 치료축을 받치는지, 서로 다른 병기를 담당하는지, 한쪽의 방향을 조절하는지 설명하고, 현대 연구는 사용 시료·비교 설계에 맞춰 별도로 읽습니다.

    배합 예 두 역할을 연결하는 설명 처방에서 더 읽기
    인삼 + 백출 기를 보하는 축과 비위·습을 조절하는 축 사군자탕
    법제 반하 + 진피 조습화담·강역과 이기조습을 결합 이진탕 · 육군자탕
    계지 + 백작약 해기·온통과 영음 조절·완급을 함께 읽음 계지탕
    백작약 + 감초 유간·완급의 방향을 함께 읽음 작약감초탕
    황기 + 당귀 보기와 보혈을 기혈의 관계로 연결 당귀보혈탕; 원방 상대비를 실제 수록본에서 확인
    맥문동 + 오미자 음·진액을 기르는 방향과 수렴하여 지키는 방향 생맥산에서 인삼의 보기까지 연결
    황련·황금 + 건강 한열착잡에서 고한 청열과 신온 온중의 역할을 분담 반하사심탕; 한약을 ‘차다/덥다’ 하나로 평균내지 않음

    안전성도 배합 전체에서 봅니다. 감초는 여러 처방에 중복될 수 있으므로 총 노출과 기간, 혈압·부종·칼륨 관련 상태, 병용약을 함께 확인합니다. 관련 설명은 감초, NCCIH 감초 안전 정보, 본초·방제 안전성에 연결됩니다.

    본초 선택 이유 서술형 복습¶

    1. 백출과 창출은 같은 ‘출’이므로 서로 바꿔도 되나요?

    다른 본초로 기원과 규격을 각각 확인합니다. 백출은 건비익기와 조습을 함께, 창출은 조습건비·거풍산한의 비중을 읽습니다. 사군자탕과 평위산에서 각각 어떤 축을 맡는지 설명하면 차이가 더 분명합니다.

    2. 갈증이 있는 사례를 모두 청열조습약으로 연결하면 무엇이 빠지나요?

    갈증의 맥락이 실열·습열인지, 진액 손상·음허인지, 다른 원인인지 확인해야 합니다. 고한 조습과 청열생진·양음은 역할이 다르므로 열상·건조·습체·대변·전신 상태를 함께 봅니다. 갈증 한 증상이 본초를 결정하지 않습니다.

    3. 반하가 육군자탕과 반하사심탕에 모두 있어도 두 처방은 같은 방향인가요?

    육군자탕에서는 보기건비 바탕에 화담·강역을 더합니다. 반하사심탕에서는 한열착잡·심하비의 구조 안에서 화위·강역을 읽습니다. 반하 하나의 효능보다 함께 있는 인삼·백출, 황련·황금·건강 등의 배합축이 처방을 구분합니다.

    4. 생강과 건강의 차이를 수분량만으로 설명하면 충분한가요?

    신선한 원료인지 건조·가공 원료인지 확인한 뒤 전통적 작용의 비중, 공정·규격, 처방 문맥을 함께 봅니다. 생강의 화위지구·해표와 건강의 온중산한을 구분하고 실제 사용한 가공품을 기록합니다.

    5. 베르베린 세포실험을 황련탕약의 사람 치료효과로 읽어도 되나요?

    분리 성분과 원약재·탕약은 시험물이 다르고, 세포실험과 사람 임상시험은 연구 대상도 다릅니다. 성분·농도·투여경로·제형·비교군·결과를 구분한 뒤 관련성을 설명합니다. 연구 연결 표준을 다시 읽으세요.

    6. 감초가 조화제약이면 안전성 확인은 생략할 수 있나요?

    조화제약은 전통적 배합 역할입니다. 감초 노출량·기간과 다른 감초 함유 제품, 혈압·부종·칼륨 및 병용약은 별도 안전성 항목입니다. ‘조화’라는 효능 이름으로 모든 조건의 안전성을 대신하지 않습니다.

    현대 연구에서는 원약재·포제품·추출물·분리 성분과 복합처방을 구분합니다. 기원·규격은 식품의약품안전평가원 생약종합정보, 실제 적용과 연구 범위는 각 본초 원문의 참고문헌에서 확인하세요.
