# 경옥고 지식망

```text
경옥고
├─ 인삼 → 보기·원기
├─ 생지황 → 자음·생진
├─ 복령 → 건비·삼습
└─ 봉밀 → 보중·윤조·제형

        ↓

허손 · 양생 · 피로 · 회복

        ↓

현대 연구
├─ 피로·운동능력
├─ 삶의 질
├─ 면역·항산화
└─ 호흡기 연구
```
