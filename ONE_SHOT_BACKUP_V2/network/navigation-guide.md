# 아카이브 분류 안내

민성 한의학 아카이브는 문서를 찾기 쉽도록 본초와 방제를 **기능·치법 중심의 2단계 메뉴**로 정리합니다.

## 본초학
본초는 전통적인 주요 효능을 중심으로 다음과 같이 분류합니다.

- 보익약
- 안신·양심
- 화담·이기
- 이수삼습
- 양음·생진
- 활혈·보혈
- 온리·온보
- 개규
- 조화·기타

하나의 본초가 여러 기능을 가질 수 있으므로 **복령·오미자·우슬처럼 여러 분류에 중복 노출될 수 있습니다.** 이는 오류가 아니라 실제 본초의 다면적인 활용을 반영한 것입니다.

## 방제학
방제는 대표적인 치법과 처방군에 따라 다음과 같이 정리합니다.

- 보익제
- 해표·상한론 처방
- 화담·이기
- 이수제
- 거풍습·근골

하나의 처방이 여러 성격을 동시에 가질 수 있지만, 사용자가 찾기 쉽게 대표적인 성격을 중심으로 배치하고 필요한 경우 다른 분류에도 함께 노출합니다.

## 지식망
메뉴 분류와 별개로 **한의학 지식망**에서는 본초 → 방제, 방제 → 본초, 증상 → 변증 → 본초 → 방제의 방식으로 자유롭게 역탐색할 수 있습니다.
