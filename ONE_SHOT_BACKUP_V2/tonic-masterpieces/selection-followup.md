# 선택·경과관찰
## 선택 전
1. 피로·허약의 원인과 위험신호 확인
2. 기저질환·동시 복용약 확인
3. 한열·허실·기혈음양 평가
4. 소화·수면·대소변·활동상태 확인
5. 치료목표 설정

## 치료 후
피로 강도, 일상활동, 운동 후 회복, 식욕·소화, 수면, 통증·근골격 기능, 삶의 질과 이상반응을 추적합니다.

`좋아졌다/안 좋아졌다`만 보지 않고 **어떤 기능이 먼저 회복되고 무엇이 남는지** 기록합니다.
