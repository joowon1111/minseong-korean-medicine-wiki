# 황제내경

《황제내경》은 한의학의 기초 이론을 이해하는 데 핵심적인 고전이다. 음양·오행, 장부, 기혈진액, 경락, 진단과 치료 원칙 등 후대 한의학 이론의 큰 틀을 형성했다.

```text
황제내경
├─ 음양
├─ 장부
├─ 기혈진액
├─ 경락
├─ 병인·병기
└─ 진단·치료 원칙
```

현대 한의학 교육에서도 여러 기초과목이 이 고전의 개념과 연결된다.
