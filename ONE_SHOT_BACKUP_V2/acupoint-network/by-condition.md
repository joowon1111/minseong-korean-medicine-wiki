# 증상별 경혈 지도

```text
├─ 신문 HT7
├─ 삼음교 SP6
├─ 내관 PC6
└─ 백회 GV20
```

## 소화불량

```text
소화불량
├─ 족삼리 ST36
├─ 내관 PC6
└─ 중완 CV12
```

```text
요통
├─ 신수 BL23
├─ 위중 BL40
└─ 국소 아시혈
```

```text

├─ 합곡 LI4
```
