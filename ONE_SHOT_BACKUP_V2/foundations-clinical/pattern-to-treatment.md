# 변증 → 치법
변증은 치료의 끝이 아니라 **치법을 결정하기 위한 단계**입니다.

| 병증 예 | 치법 방향 예 |
|---|---|
| 기허 | 익기 |
| 혈허 | 보혈 |
| 양허 | 온양 |
| 음허 | 자음 |
| 기체 | 이기 |
| 어혈 | 활혈거어 |
| 담습 | 조습화담 |
| 풍한표증 | 해표산한 |
| 리열 | 청열 |

```text
증상
 ↓
병증
 ↓
치법
 ↓
본초·방제·침구
```

같은 병증에서도 환자의 겸증·중증도·경과에 따라 치료 구성이 달라질 수 있습니다.
