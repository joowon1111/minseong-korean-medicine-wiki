# 자음강화탕(滋陰降火湯)

## 한눈에
**음혈을 자양하면서 허화를 내리는 대표 자음강화방**이다.

- **치법:** 자음양혈·강허화
- **출전:** 『잡병원류서촉』 계통, 『방약합편』(1884) 중통

## 『방약합편』 수록 구성·용량
| 본초 | 용량 |
|---|---:|
| 백작약 | 4.875 g |
| 당귀 | 4.5 g |
| 맥문동 | 3.75 g |
| 백출 | 3.75 g |
| 숙지황 | 3.75 g |
| 생지황(주초) | 3 g |
| 진피 | 2.625 g |
| 감초(구) | 1.875 g |
| 지모(염초) | 1.875 g |
| 황백(염초) | 1.875 g |

**가미:** 생강 3편, 대조 2매

## 구조
숙지황·생지황·맥문동·작약·당귀로 음혈을 보하고, 지모·황백으로 허열을 내리며, 백출·진피·감초로 비위를 돌본다.
