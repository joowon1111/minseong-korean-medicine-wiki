# 경락과 경맥

황제내경은 경락을 인체 각 부위와 장부를 연결하는 기능적 네트워크로 설명한다.

```text
장부
 ↕
경맥
 ↕
경혈
 ↕
사지·체표
```

경락 이론은 침구학의 기초가 되며, 이후 경혈의 위치와 임상 활용 체계로 발전했다.
