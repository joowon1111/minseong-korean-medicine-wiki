# 근거의 층위
근거의 수준은 단순 서열이라기보다 **어떤 질문에 어떤 연구설계가 적합한가**를 보는 것이 중요합니다.

| 질문 | 주로 보는 연구 |
|---|---|
| 어떤 기전이 가능한가? | 세포·동물·기전 연구 |
| 실제 환자에서 어떤 현상이 나타나는가? | 증례·관찰연구 |
| 치료가 비교군보다 효과적인가? | RCT |
| 여러 연구 결과가 일관적인가? | 체계적 문헌고찰·메타분석 |
| 실제 진료에서 무엇을 권고할까? | 임상진료지침 |

한 단계 아래의 연구가 무가치한 것이 아니라 **답할 수 있는 질문의 범위가 다릅니다.**
