# 증상 → 침구 치료전략
같은 허리통증이라도 치료전략은 같지 않습니다.

## 먼저 구분
- 급성 / 만성
- 국소통 / 방사통
- 움직임에 따른 변화
- 근육·근막성 / 관절성 / 신경성 가능성
- 한의학적 한열·허실·경락 병증
- 위험신호 여부

```text
통증 위치
 + 유발·완화 동작
 + 신경학적 증상
 + 압통·가동범위
 + 전신상태
       ↓
치료 목표
       ↓
국소 치료 + 원위 경혈 + 운동·생활관리
```

침구치료는 하나의 고정 처방보다 **환자의 기능 문제와 치료목표에 맞춰 구성**하는 것이 중요합니다.
