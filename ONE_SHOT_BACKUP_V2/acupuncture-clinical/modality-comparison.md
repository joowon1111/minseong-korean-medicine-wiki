# 침 vs 전침 vs 뜸 vs 부항
| 치료 | 주요 특징 | 임상에서 보는 포인트 |
|---|---|---|
| 침 | 경혈·국소점 자극 | 통증·기능·병증 |
| 전침 | 침에 전기자극 추가 | 자극 강도·빈도·내약성 |
| 뜸 | 온열자극 | 한증·냉감·국소 순환·화상 주의 |
| 부항 | 음압 자극 | 근육 긴장·국소 불편·피부상태 |
| 운동·자가관리 | 기능 회복 | 장기적 활동·재발예방 |

침은 수기 또는 전기자극을 사용할 수 있으며, 현대 연구에서 통증과 일부 기능 결과에 대해 연구되어 왔습니다.

치료수단을 경쟁시키기보다 **현재 목표에 따라 단독 또는 복합적으로 구성**합니다.
