# 태음인 중증도·위험신호
태음인은 **위완수한표한병**과 **간수열리열병**이라는 큰 축에서 중증도가 진행합니다.

## 표한 악화
```text
발한 불리·오한·몸의 무거움
 ↓
호흡불편·사지냉
 ↓
폐조·전신쇠약 증가
```

## 리열 악화
```text
열·구갈·번조
 ↓
조열·건조
 ↓
진액·음혈 소모
 ↓
전신쇠약
```

## 위험신호
- 평소와 달리 발한이 크게 막히거나 비정상적
- 호흡불편의 증가
- 심한 냉감·사지냉 또는 지속되는 조열
- 진액소모·건조와 기력저하
- 태음인의 건강신호인 한액통창이 현저히 무너짐
