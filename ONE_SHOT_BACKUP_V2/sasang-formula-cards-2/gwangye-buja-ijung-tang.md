# 관계부자이중탕(官桂附子理中湯)

## 구성·용량·출전

| 본초 | 용량 |
|---|---:|
| 인삼 | 11.25 g |
| 건강(구움) | 7.5 g |
| 관계 | 7.5 g |
| 백출 | 7.5 g |
| 포부자 | 3.75–7.5 g |
| 백작약 | 3.75 g |
| 자감초 | 3.75 g |
| 진피 | 3.75 g |

한국전통지식포탈 항목에는 **곽향·당귀·사인·소엽·천궁·총백**도 구성약재로 수록되어 있으나 해당 화면에는 개별 g 용량이 표시되지 않는다. 따라서 임의의 용량을 채우지 않는다.

**출전:** 『동의사상신편』(1929), 소음인, P0018162. 약재를 썰어 물에 달여 복용.

**임상 위치:** 소음병 자리증 등 더 깊은 리한·허한 방향.

> 부자는 포제·용량·환자상태에 따른 안전성 판단이 특히 중요한 약재이므로 구성표를 자가복용 지침으로 사용하지 않는다.
