# 청폐사간탕(淸肺瀉肝湯)

## 구성·용량·출전

| 본초 | 용량 |
|---|---:|
| 갈근 | 15 g |
| 고본 | 7.5 g |
| 황금 | 7.5 g |
| 길경 | 3.75 g |
| 나복자 | 3.75 g |
| 대황 | 3.75 g |
| 백지 | 3.75 g |
| 승마 | 3.75 g |

**총량 48.75 g**

**출전:** 한국전통지식포탈 『동의사상신편』(1929), 태음인, **P0018569**.  
**조제:** 약재를 썰어 물에 달여 복용.  
**포탈 수록 증후:** 긴·현하고 유력한 맥, 성급·易怒, 두통, 변비, 황색/흑갈색 니태, 피부 발진·소양, 번갈 등.

열다한소탕과 비교하면 **대황이 추가되는 구성 차이**가 뚜렷하다. 태음인 간수열리열병·리열의 기존 임상 설명과 함께 본다.


## 위키 기록 원칙
동명 처방의 출전별 구성 차이가 있으면 혼합하지 않으며, 데이터베이스에서 확인되지 않은 용량은 임의로 보충하지 않는다.
