# 조리폐원탕(調理肺元湯)

## 구성 본초·용량
| 본초 | 용량 |
|---|---:|
| 길경 | 7.5 g |
| 나복자 | 3.75 g |
| 마황 | 3.75 g |
| 맥문동 | 7.5 g |
| 의이인 | 7.5 g |
| 황금 | 3.75 g |

## 출전
태음인. 『동의사상신편』(1929). 한국전통지식포탈 P0018577.

## 조제·주치
태음인 병에 응용 가능한 처방으로 수록되며 주치병증에 병후체허가 제시됨. 물에 달여 복용.

## 기록 원칙
한국전통지식포탈에 표시된 단위와 수치를 그대로 기록한다. 출전별 동명 처방의 구성이 다를 경우 별도 처방으로 구분하며, 표시되지 않은 용량은 임의로 보충하지 않는다.
