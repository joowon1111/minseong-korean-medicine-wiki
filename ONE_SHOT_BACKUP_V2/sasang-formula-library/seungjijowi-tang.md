# 승지조위탕(升芷調胃湯)

## 체질·주치
**태음인**의 무한과 산증에 사용하는 처방으로 수록된다.

## 구성·용량
| 본초 | 용량 |
|---|---:|
| 건율 | 11.25 g |
| 의이인 | 11.25 g |
| 나복자 | 7.5 g |
| 길경 | 3.75 g |
| 마황 | 3.75 g |
| 맥문동 | 3.75 g |
| 석창포 | 3.75 g |
| 오미자 | 3.75 g |
| 백지 | 원자료 개별 g 미표시 |
| 승마 | 원자료 개별 g 미표시 |

## 출전
『동의사상신편』(1929), 태음인. 한국전통지식포탈 **P0018555**.

## 조제
약재를 썰어 물에 달여 복용.

> 원자료에서 백지·승마의 개별 g가 표시되지 않아 임의 보충하지 않는다.
