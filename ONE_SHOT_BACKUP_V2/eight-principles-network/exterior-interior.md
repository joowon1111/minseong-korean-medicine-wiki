# 표리(表裏)

표리는 병변의 위치와 깊이를 살피는 기본 축이다.

```text
표
→ 체표·경락·외감 초기 등의 병위

리
→ 장부·내부의 병위
```

실제 임상에서는 표와 리가 명확히 분리되지 않고 **표리동병·반표반리 등 복합적인 양상**으로 나타날 수 있다.
