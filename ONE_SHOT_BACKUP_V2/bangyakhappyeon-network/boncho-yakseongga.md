# 손익본초와 약성가

손익본초와 약성가는 개별 본초의 성질과 효능을 압축적으로 파악하고 처방 구성의 의미를 이해하는 데 도움을 준다.

```text
본초
 ↓
성미·효능
 ↓
약성가
 ↓
처방 속 역할
```

본초와 방제를 따로 외우기보다 **약물의 성질 → 배합 → 처방의 치료 방향**으로 연결해 볼 수 있다.
