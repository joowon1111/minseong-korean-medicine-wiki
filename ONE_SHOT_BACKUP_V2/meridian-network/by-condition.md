# 경맥→증상 지도

## 불면
```text
심경 → 신문 HT7
심포경 → 내관 PC6
비경 → 삼음교 SP6
독맥 → 백회 GV20
```

## 소화불량
```text
위경 → 족삼리 ST36
심포경 → 내관 PC6
비경 → 삼음교 SP6
```

## 요통
```text
방광경 → 신수 BL23·위중 BL40
독맥 → 척주·두부 축
```

## 비염
```text
대장경 → 합곡 LI4
위경 → 족삼리 ST36
```

이 지도는 대표적인 임상 연결을 보여주며 실제 배혈은 병변 부위·경락·변증과 환자의 상태를 종합해 결정한다.
