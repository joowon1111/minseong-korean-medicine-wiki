# 본초 → 사상처방 역색인

사상처방을 구성하는 주요 본초에서 **어떤 처방으로 다시 연결되는지** 역방향으로 탐색하는 지식지도입니다.

```text
체질병증
 ↓
사상처방
 ↓
구성 본초
 ↓
본초 상세
 ↓
이 본초가 들어가는 다른 사상처방
```

## 사용하는 방법

예를 들어 **나복자**를 선택하면 나복자 자체의 본초학적 정보를 확인한 뒤, 다시 열다한소탕·태음조위탕·조위승청탕·나복자승기탕 등으로 이동하여 **같은 본초가 서로 다른 처방에서 어떤 배합과 용량으로 사용되는지** 비교할 수 있습니다.

이 페이지는 현재 위키에서 출전·구성·용량을 확인해 둔 사상처방을 중심으로 작성한 역색인입니다.
