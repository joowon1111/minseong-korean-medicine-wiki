# 대표 방제 비교
## 비슷한 증상, 다른 방제
| 주증 | 가능한 병증 예 | 방제 방향 예 |
|---|---|---|
| 피로 | 기허 / 혈허 / 양허 | 익기 / 보혈 / 온양 |
| 복통 | 한 / 열 / 기체 / 어혈 / 식적 | 온중 / 청열 / 이기 / 활혈 / 소도 |
| 불면 | 심혈허 / 심음허 / 담화 / 심비양허 | 보혈·양심 / 자음 / 청담화 / 보익심비 |
| 기침 | 풍한 / 풍열 / 담습 / 음허 | 산한 / 소풍청열 / 조습화담 / 자음윤폐 |

**같은 증상 = 같은 처방**이 아니라 `증상 → 병증 → 치법 → 방제`가 기본입니다.
