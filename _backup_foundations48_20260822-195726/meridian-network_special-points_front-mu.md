# 모혈(募穴) 임상 지식망

모혈은 장부의 기가 흉복부에 모이는 것으로 설명되는 특정혈입니다. 실제 임상에서는 **흉복부 압통·증상 부위·장부 변증·배수혈**을 함께 봅니다.

## 12장부의 모혈

| 장부 | 모혈 |
|---|---|
| 폐 | LU1 중부 |
| 심포 | CV17 전중 |
| 심 | CV14 거궐 |
| 간 | LR14 기문 |
| 담 | GB24 일월 |
| 비 | LR13 장문 |
| 위 | CV12 중완 |
| 삼초 | CV5 석문 |
| 신 | GB25 경문 |
| 대장 | ST25 천추 |
| 소장 | CV4 관원 |
| 방광 | CV3 중극 |

## 배수모혈로 보기

전면의 모혈과 등부의 배수혈을 함께 보면 장부를 전후에서 연결하는 구조가 됩니다.

- 폐: LU1 중부 ↔ BL13 폐수
- 간: LR14 기문 ↔ BL18 간수
- 비: LR13 장문 ↔ BL20 비수
- 위: CV12 중완 ↔ BL21 위수
- 신: GB25 경문 ↔ BL23 신수
- 대장: ST25 천추 ↔ BL25 대장수

## 임상 연결

소화·흉민·호흡·하복부·배뇨·여성 증상에서 모혈의 위치와 해당 장부 변증을 함께 봅니다.
