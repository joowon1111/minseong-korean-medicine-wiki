# 황제내경 진단과 임상 관찰

전통 진단은 환자의 **색·형·목소리·호흡·증상·생활·촉진·맥** 등 여러 정보를 종합하는 과정입니다.

## 현대 임상에서의 순서
1. 환자의 실제 주소
2. 위험신호와 일반의학적 감별
3. 망문문절의 전통적 정보
4. 팔강·장부·기혈진액 변증
5. 치료 후 재평가

## 중요한 점
설·맥 하나만으로 진단을 확정하지 않고 전체 증상과 경과를 함께 봅니다.
