# 사상의학 치료원칙

사상치료의 핵심은 **체질 → 처방명**의 단순 대응이 아닙니다.

## 치료 설계
1. 평소 소증 확인
2. 체질 후보와 현재 병증 확인
3. 표리·한열·순역·경중 판단
4. 치법과 체질처방 선택
5. 주증과 소증의 변화 재평가

## 처방
소양인의 형방도적산·형방사백산·양격산화탕처럼 같은 체질 안에서도 병증에 따라 처방이 달라집니다.
