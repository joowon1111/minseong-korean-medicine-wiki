# 하합혈(下合穴) 임상 지식망

하합혈은 육부의 기가 하지의 양경에서 합하는 것으로 설명되는 특정혈 체계입니다. 단순 암기보다 **어느 육부와 연결되는가 → 어떤 하지 경맥에 위치하는가 → 어떤 증상군에서 원위혈로 쓰이는가**를 함께 봅니다.

## 여섯 하합혈

| 육부 | 하합혈 | 소속 경맥 | 임상 연결 |
|---|---|---|---|
| 위 | ST36 족삼리 | 족양명위경 | 소화불량·식욕·회복·복부 기능 |
| 대장 | ST37 상거허 | 족양명위경 | 배변·복통·장 기능 |
| 소장 | ST39 하거허 | 족양명위경 | 하복부·장 기능 |
| 담 | GB34 양릉천 | 족소양담경 | 담경·근건·측면부 통증 |
| 방광 | BL40 위중 | 족태양방광경 | 요배부·하지·방광경 |
| 삼초 | BL39 위양 | 족태양방광경 | 삼초·수분대사·하지 |

## 임상에서 보는 법

하합혈은 육부 병증의 원위혈 선택 근거가 됩니다. 예를 들어 소화불량에서 족삼리를 단순히 “소화혈”로 보지 않고 **위경의 합혈 + 위의 하합혈**이라는 이중 성격으로 이해할 수 있습니다.

## 자주 연결하는 배혈

- 족삼리 ST36 + 중완 CV12 + 내관 PC6
- 상거허 ST37 + 천추 ST25
- 양릉천 GB34 + 족임읍 GB41
- 위중 BL40 + 대장수 BL25
