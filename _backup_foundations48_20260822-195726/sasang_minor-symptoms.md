# 사상의학 소증(素證) 임상 지도

사상의학에서 소증은 **병이 심하지 않을 때 평소 반복해서 나타나는 생리적·생활상의 특징**을 살펴보는 중요한 단서입니다. 체형이나 성격 한두 가지보다 소화·대소변·발한·수면·냉열·피로 같은 반복 패턴을 함께 봅니다.

## 소증에서 확인할 항목

| 영역 | 확인할 내용 |
|---|---|
| 소화 | 식욕·소화력·식후 불편감 |
| 대변 | 횟수·굳기·배변 후 편안함 |
| 소변 | 빈도·야간뇨·양상 |
| 땀 | 땀이 잘 나는지, 땀 후 편안한지 |
| 냉열 | 더위·추위 민감성, 손발냉감 |
| 수면 | 입면·각성·수면 후 회복 |
| 호흡·흉부 | 숨참·흉민·호흡의 편안함 |
| 피로 | 활동 후 회복속도 |

## 체질과 병증 사이에서

소증은 체질명을 바로 결정하는 체크리스트가 아닙니다.

**평소 소증 → 현재 증상의 변화 → 표리병증 → 순증·역증과 경중 → 처방 → 소증 회복 여부**

의 순서로 보는 것이 중요합니다.

## 경과평가

치료 후 주증 하나만 줄었는지보다 **평소 소화·대변·땀·수면·피로가 함께 안정되는지**를 봅니다.
