# 금궤요략 복만·한·식적 임상 지도

복만·복통·냉감·소화정체는 서로 비슷해 보여도 병기가 다릅니다.

## 감별축
- 한: 냉감·온열 선호
- 비위허: 식욕저하·묽은변·피로
- 담음: 오심·흉민·어지럼·가래
- 식적: 과식·특정 음식 후 복만·트림·대변 변화

## 임상 연결
중완 CV12 · 족삼리 ST36 · 내관 PC6 · 공손 SP4
