# 턱관절통증

**Temporomandibular Disorder**

## 환자가 이렇게 검색할 수 있습니다

- 턱관절
- 턱이 아파요
- 입 벌릴 때 턱이 아파요
- 턱에서 소리가 나요
- 입이 잘 안 벌어져요
- 아침에 턱이 뻐근해요

## 먼저 이해하기

턱관절통증은 개구범위·관절음·저작통·이갈이·두통·목통증을 함께 봅니다.

## 함께 구분할 상태

- 측두하악관절장애
- 저작근 MPS
- 이갈이·악물기
- 경항부 긴장과 연동
- 관절 내부 문제

## 먼저 확인해야 할 신호

- 외상 후 개구불가
- 턱이 빠져 닫히지 않음
- 심한 부종·발열
- 진행하는 감각·근력 이상

## 한의치료 연결

침·전침·약침은 교근·측두근·익돌근 관련 MPS와 ST6·ST7 등 국소 경혈을 해부학적으로 평가해 연결합니다.

치료는 증상명 하나만으로 정하지 않고 **발생 시점·유발상황·동반증상·기능저하·한의학적 병증**을 함께 평가합니다.
