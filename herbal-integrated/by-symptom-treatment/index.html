    방제 본초 임상탐색 처방감별 통합허브

    증상·치법으로 찾기¶

    증상에서 바로 처방으로 가지 않고 위험신호 → 병증 → 치법 → 후보 처방군 → 상세처방 순으로 좁혀갑니다.

    증상 → 병증축 → 치법 → 후보 2~4개 → 구성·용량·출전 확인

    피로·허약¶

    병증축 치법 대표 처방
    비위기허·중기하함 보기승양 보중익기탕
    심비양허·기혈부족 익기보혈·안신 귀비탕
    노권·기혈구상 조화기혈·보허 쌍화탕
    기혈양허·허손 온보기혈 십전대보탕
    기음양허·진액손상 익기생진 생맥산
    신음허 자보신음 육미지황환
    신양허 온보신양 팔미지황환

    빠른 감별: 보중익기탕 ↔ 귀비탕 ↔ 쌍화탕 ↔ 십전대보탕은 모두 피로에 쓰일 수 있지만 중기하함 / 심비양허 / 노권 / 기혈양허가 갈림점입니다.

    불면·심계·불안¶

    병증축 치법 대표 처방
    심비양허 익기보혈·양심 귀비탕
    심신음혈부족 자음양혈·안신 천왕보심단
    허번불면 양혈안신·청열제번 산조인탕
    담울·심번·경계 이기화담·안신 가미온담탕
    담기울결·매핵기 행기산결·화담 반하후박탕

    소화불량·복부팽만¶

    병증축 치법 대표 처방
    습체·창만 화습화위 평위산
    비기허 + 담습 + 기체 익기건비·화담이기 향사육군자탕
    비위허한 + 습체·기체 온중화습·이기 향사양위탕
    음식적체 소식화적 보화환
    한열착잡·심하비 한열평조 반하사심탕
    비위습체 + 수습·설사 화습이수 위령탕

    현훈·두통¶

    병증축 치법 대표 처방
    비허담습·풍담 건비화담·식풍 반하백출천마탕
    간양상항·간풍 평간식풍 천마구등음
    외풍 두통 소풍지통 천궁다조산
    풍한·풍열·습담·혈분 복합 소풍산한·청열지통 청상견통탕
    비연·비색 + 두통 소풍통규 창이자산

    기침·천식·호흡¶

    병증축 치법 대표 처방
    기허 + 외감풍한 + 담 익기해표·화담 삼소음
    풍열 + 기침 소풍청열·선폐 상국음
    폐열·천해 청열평천 마행감석탕
    담열옹폐 청열화담·평천 정천탕
    상실하허·기역·담연 강기평천·거담 소자강기탕
    량조·해수담희 양조윤폐·화담 행소산
    폐기허 보기보폐 보폐탕
    기음양허 익기생진 생맥산

    통증·비증¶

    병증축 치법 대표 처방
    한습 + 기혈담식 복합 산한조습·이기활혈 오적산
    만성 풍한습비 + 간신기혈허 거풍습·익간신·보기혈 독활기생탕
    흉중어혈 + 기체 활혈거어·행기지통 혈부축어탕
    기허혈어 + 통락장애 보기활혈·통락 보양환오탕
    하초축혈 + 열결 파혈하어·설열 도핵승기탕

    수습·부종·배뇨¶

    병증축 치법 대표 처방
    수습정체·기화불리 이수삼습·온양화기 오령산
    수열호결 + 음손 이수청열·양음 저령탕
    양허 + 수기내정 온양이수 진무탕
    중양부족 + 담음 온양화음 영계출감탕
    비양허 수종 온양건비·행기이수 실비음
    습열하주·열림 청열이수통림 팔정산

    열증·울열¶

    병증축 치법 대표 처방
    삼초 실열·화독 청열해독·사화 황련해독탕
    간담실화·간경습열 청간사화·청리습열 용담사간탕
    양명기분대열 청기분열·생진 백호탕
    열병 후 여열 + 기음손상 청열생진·익기 죽엽석고탕
    서열 + 기진양상 청서익기·양음생진 청서익기탕

    간울·기체¶

    병증축 치법 대표 처방
    간울 + 혈허·비허 소간해울·양혈건비 소요산
    간울혈허 + 울열 소간해울·청열 가미소요산
    간기울결 + 흉협통 소간이기·활혈 시호소간산
    칠정기울 + 흉복비체·수습 이기해울·통리 분심기음
    담기울결·매핵기 행기산결·화담 반하후박탕

    부인·조경¶

    병증축 치법 대표 처방
    충임허한 + 어혈 온경산한·양혈거어 온경탕
    혈허 + 기체·조경 양혈조경·이기 조경종옥탕
