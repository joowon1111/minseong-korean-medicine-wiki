# 머리의 표면해부학적 위치 확인 (SA1)

## 분류 {#_1}
**표면해부학적 위치 확인 자료** · 원본 자료 식별자 **SA1**

머리의 발제와 비례 거리를 이용해 표준경혈 위치를 확인하는 참고자료입니다. SA1은 이 자료의 식별자입니다.

## 해부학적 위치·구조 {#_2}

### 원본의 위치·구조 설명 {#source-record-description}

1. 전발제(前髮際) 중점-후발제(後髮際) 중점: 12촌
2. 백회(GV20) 잡는 법: 앞정중선 위, 전발제(前髮際)에서 위쪽으로 5촌에 위치하며 전발제(前髮際) 중점-후발제(後髮際) 중점을 12촌으로 잡고 그 중점에서 앞으로 1촌 내려온 지점.
3. 전발제(前髮際)가 분명하지 않은 경우 양 눈썹 사이 중점에서 후발제(後髮際)까지를 15촌으로 잡는다.
4. 후발제(後髮際)가 분명하지 않은 경우 대추(GV14)에서 후발제(後髮際) 중점까지를 3촌으로 하여 전발제(前髮際) 중점-대추(GV14)까지를 15촌으로 잡는다.
5. 전발제(前髮際) 중점-두유(ST8)까지 4.5촌으로 잡고 이를 기준으로 주변의 경혈들을 잡는다.

## 자료의 범위 {#_3}

<span id="_5"></span>

원본에 나오는 백회·대추·두유는 각각 별도의 표준경혈입니다. 이 페이지는 위치 확인의 기준을 설명하며, 각 혈의 취혈·자침은 해당 상세 문서에서 확인합니다.

사람의 내용 감수가 필요한 초안입니다. 분류·명칭·원본 대조와 자동 검증의 범위는 구별해 읽어 주세요.
