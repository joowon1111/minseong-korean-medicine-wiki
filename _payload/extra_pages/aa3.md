# 체중관리 목적의 이침 배혈 예시 (AA3)

## 분류
**이침 배혈 예시** · 원본 자료 식별자 **AA3**

원본에서 「비만침」으로 묶은 여러 이침점의 조합을 보존한 자료입니다. AA3는 이 배혈 예시의 식별자로, 단일 경혈의 표준 코드와 구분합니다.

## 위치

### 이침 배혈 구성

비만침: 위, 비, 기점, 내분비

## 자료의 범위

<span id="_4"></span>
<span id="_5"></span>

위·비·기점·내분비는 원본에 제시된 이침점 이름입니다. 이 목록의 「위」「비」는 이침 배혈 구성의 표기이며, 복부의 장기 위치나 정경혈 명칭과 구분합니다. 원본은 개별 점의 위치도, 자극 방법·깊이·기간이나 조합의 임상시험 결과를 제시하지 않으므로 배혈 구성의 범위로 설명합니다.

사람의 내용 감수가 필요한 초안입니다. 분류·명칭·원본 대조와 자동 검증의 범위는 구별해 읽어 주세요.
