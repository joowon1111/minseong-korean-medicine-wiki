# 귀의 해부학적 구조 (AA1)

## 분류 {#_1}
**귀 해부학 자료** · 원본 자료 식별자 **AA1**

이침 자료를 읽을 때 기준이 되는 귀의 해부학적 구조 목록입니다. AA1은 귀 전체의 구조 설명을 가리키는 자료 식별자입니다.

## 해부학적 위치·구조 {#_2}

### 원본의 위치·구조 설명

1. 이수(耳垂)
2. 이륜(耳輪)
3. 이륜결절(耳輪結節)
4. 이륜각(耳輪角)
5. 이주(耳珠), 이병(耳屛)
6. 주상절흔(珠上切痕), 병상절흔(屛上切痕)
7. 주하절흔(珠下切痕), 병하절흔(屛下切痕)
8. 대이병(對耳屛)
9. 병간절흔(屛間切痕)
10. 윤병절흔(輪屛切痕)
11. 대이륜(對耳輪)
12. 대이륜상각(對耳輪上脚)
13. 대이륜하각(對耳輪下脚)
14. 주상와(舟狀窩)
15. 삼각와(三角窩)
16. 이갑강(耳甲腔)
17. 이갑정(耳甲艇)
18. 이배(耳背)

## 자료의 범위 {#_3}

<span id="_4"></span>
<span id="_5"></span>

이수·이륜·이갑 등의 구조 이름과 개별 이침점은 구분합니다. 아래 목록은 18개의 해부학 용어이며, 18개 치료점이나 한 개의 경외기혈을 뜻하는 목록이 아닙니다. 원본에는 개별 이침점의 위치도·취혈·자침 정보가 없습니다.

사람의 내용 감수가 필요한 초안입니다. 분류·명칭·원본 대조와 자동 검증의 범위는 구별해 읽어 주세요.
