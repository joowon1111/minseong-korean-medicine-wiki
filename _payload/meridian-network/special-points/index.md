# 특정혈 임상 지식망

특정혈은 경혈을 단순히 위치와 주치로만 외우지 않고 **경맥 안에서 어떤 역할과 성격을 갖는지** 이해하게 해주는 핵심 체계입니다.

이 페이지는 특정혈을 별도 부록으로 분리하지 않고 **십이경맥 → 경맥별 전체 혈위 → 특정혈 → 배혈 → 증상·변증** 흐름 속에서 연결합니다.

## 특정혈을 실제로 읽는 순서

**증상·부위 → 관련 경맥 → 표리경 → 특정혈 성격 → 국소·원위혈 조합 → 변증 → 치료 반응 재평가**

예를 들어 소화불량에서 단순히 족삼리만 보는 것이 아니라, 족삼리 ST36이 **위경의 합혈이자 위의 하합혈**이라는 점과 중완 CV12·내관 PC6·공손 SP4 같은 다른 체계의 혈을 함께 보면 배혈 구조가 더 선명해집니다.
