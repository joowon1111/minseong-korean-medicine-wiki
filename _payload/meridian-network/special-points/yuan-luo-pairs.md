# 원락배혈(原絡配穴) 완전 정리

원락배혈은 한 경맥의 원혈과 표리경의 락혈을 함께 사용하는 배혈 원리입니다.

## 대표 조합

| 중심 경맥 | 원혈 | 표리경 락혈 |
|---|---|---|
| 폐 | LU9 태연 | LI6 편력 |
| 대장 | LI4 합곡 | LU7 열결 |
| 위 | ST42 충양 | SP4 공손 |
| 비 | SP3 태백 | ST40 풍륭 |
| 심 | HT7 신문 | SI7 지정 |
| 소장 | SI4 완골 | HT5 통리 |
| 방광 | BL64 경골 | KI4 대종 |
| 신 | KI3 태계 | BL58 비양 |
| 심포 | PC7 대릉 | TE5 외관 |
| 삼초 | TE4 양지 | PC6 내관 |
| 담 | GB40 구허 | LR5 여구 |
| 간 | LR3 태충 | GB37 광명 |

실제 임상에서는 원락배혈을 고정 공식처럼 적용하지 않고 주증, 경맥 유주, 허실, 국소 문제와 함께 판단합니다.
