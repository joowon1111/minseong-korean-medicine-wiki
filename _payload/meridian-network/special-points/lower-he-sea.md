# 하합혈(下合穴) 완전 정리

| 육부 | 하합혈 |
|---|---|
| 위 | ST36 족삼리 |
| 대장 | ST37 상거허 |
| 소장 | ST39 하거허 |
| 담 | GB34 양릉천 |
| 방광 | BL40 위중 |
| 삼초 | BL39 위양 |

하합혈은 육부의 병증을 하지의 양경 혈위와 연결하는 중요한 특정혈 체계입니다.

소화기·배변·비뇨·담부·삼초 기능을 볼 때 원위혈의 선택 근거를 이해하는 데 도움이 됩니다.
