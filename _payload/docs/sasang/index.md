# 사상의학 임상 지식망

사상의학은 단순한 체형·성격 분류가 아니라 **평소의 소증 → 현재 병증 → 표리·한열·순역·경중 → 치법 → 체질 처방 → 경과평가**를 함께 보는 의학 체계입니다.

## 체질을 판단할 때

특정 외형·성격 하나만으로 판단하지 않고 다음을 종합합니다.

- 평소 소화·식욕
- 땀과 체온·냉열
- 수면과 피로
- 대변·소변
- 호흡과 흉부 증상
- 병이 들었을 때 나타나는 반복 패턴

## 임상에서의 사용

체질은 현재 병증과 분리해서 사용하지 않습니다. 체질이 같아도 **표리병증, 한열, 대소변, 발한, 소화와 전신 상태**에 따라 처방 선택과 경과 판단이 달라집니다.
