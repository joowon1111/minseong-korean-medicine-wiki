# 전통지식·현대근거 통합 임상 지도

이 허브는 전통 한의학 지식과 현대 연구를 서로 대체시키지 않고 **임상에서 함께 읽는 구조**를 제공합니다.

## 전체 흐름
**환자 주소 → 위험신호 → 일반 감별 → 한의 변증 → 전통 치법 → 한약·침구 → 현대 근거 → 안전성 → 재평가**

## 전통지식
고전 원문·병증·성미귀경·방제구조·경맥·특정혈을 봅니다.

## 현대근거
사람 대상 임상연구를 중심으로 전임상·기전연구와 구분합니다.

## 임상적 통합
전통 병증명과 현대 질환명을 억지로 일대일 대응시키지 않고, 실제 연구 대상군과 임상증상을 연결합니다.

## 재평가
통증점수만이 아니라 기능·수면·소화·피로·활동능력·삶의 질·이상반응을 함께 봅니다.
