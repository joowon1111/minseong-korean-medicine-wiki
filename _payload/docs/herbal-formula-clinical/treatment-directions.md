# 치법→본초·방제 치료방향 지도

치법은 변증과 처방 사이를 연결하는 핵심 단계입니다.

| 치법 | 본초축 | 대표 처방군 |
|---|---|---|
| 보기·건비 | 인삼·황기·백출·복령 | 사군자탕·보중익기탕 |
| 보혈·양혈 | 당귀·숙지황·작약 | 사물탕·팔물탕 |
| 화담·이기 | 반하·진피·복령 | 이진탕·육군자탕·온담탕 |
| 활혈·거어 | 당귀·천궁·도인·홍화 | 당귀수산·계지복령환·소경활혈탕 |
| 거풍습·통락 | 독활·강활·우슬 | 독활기생탕 등 |
| 온리·산한 | 건강·육계 등 | 한증·한습 처방군 |
| 양심·안신 | 산조인·원지 등 | 귀비탕·산조인탕 계열 |

## 복합 치법
비위기허+담음 → 보기건비+화담  
기혈허+어혈 → 보익+활혈  
풍한습비+간신부족 → 거풍습+보간신
