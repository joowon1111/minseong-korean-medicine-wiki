# 본초·방제 임상 연결 지식망

본초와 방제를 따로 암기하기보다 **환자 증상 → 위험신호·감별 → 변증 → 치법 → 본초군 → 약대 → 방제 구조 → 현대근거 → 재평가**로 연결합니다.

## 기존 기준문서와의 관계
이 영역은 개별 본초·방제 내용을 다시 복제하지 않습니다. 실제 약재와 처방의 상세정보는 기존 [본초학](../herbs/index.md), [방제학](../formulas/index.md), [방제 구조](../formula-architecture/index.md)를 기준으로 하고, 여기서는 **임상적으로 서로 이동하는 길**을 제공합니다.
