# 본초→약대→방제 임상 지도

본초 하나의 효능을 외우는 것보다 **어떤 약과 만나 어떤 처방 구조를 만드는지**를 보는 것이 중요합니다.

| 본초축 | 대표 약대·조합 | 연결되는 처방 구조 |
|---|---|---|
| 인삼·황기·백출 | 보기·건비 | 사군자탕·보중익기탕·보익방 |
| 당귀·숙지황·작약·천궁 | 보혈·활혈 | 사물탕·팔물탕·십전대보탕 |
| 반하·진피·복령 | 화담·이기·건비 | 이진탕·육군자탕·온담탕 |
| 독활·두충·우슬 | 거풍습·근골·간신 | 독활기생탕 계열 |
| 산조인·원지 | 양심·안신 | 귀비탕·안신 처방군 |
| 녹용·숙지황·산수유 | 보익·정혈·간신 | 보익·신허 처방군 |
