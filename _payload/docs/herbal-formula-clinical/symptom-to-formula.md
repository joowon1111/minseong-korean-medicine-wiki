# 증상→변증→방제 임상 지도

증상명 하나에서 바로 처방으로 이동하지 않습니다.

## 피로
기허 / 기혈양허 / 신허 / 심비양허를 감별합니다.  
→ 사군자탕·보중익기탕 / 팔물탕·십전대보탕 / 신허 계열 / 귀비탕

## 소화불량
비위기허 / 담음 / 식적 / 간울을 구분합니다.  
→ 육군자탕·향사육군자탕 / 이진탕·온담탕 / 소도계 / 소간이기계

## 불면·심계
심비양허 / 담음·담열 / 혈·음 부족 / 간울·긴장  
→ 귀비탕 / 온담탕 / 산조인탕·천왕보심단 / 병증에 따른 시호계

## 근골격 통증
한습 / 어혈 / 풍한습비+허증 / 외상  
→ 오적산 / 소경활혈탕 / 독활기생탕 / 당귀수산

## 원칙
같은 증상에서도 위험신호와 현대 의학적 진단을 먼저 확인하고, 실제 변증과 환자 상태에 따라 처방을 선택합니다.
