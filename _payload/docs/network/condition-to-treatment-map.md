# 질환·증상→치료 임상 지도

`환자 증상 → 위험신호 → 일반의학적 감별 → 한의 변증 → 치법 → 본초·방제 / 경혈·침구 → 근거·안전성 → 재평가`

## 통증
요통·목·어깨·무릎·두통·저림 → 어혈·한습·신허·기혈허 → 독활기생탕·오적산·소경활혈탕 등 → 방광경·담경·독맥과 관련 특정혈

## 수면·자율신경
불면·심계·긴장 → 기혈양허·담음·간울·음혈부족 → 귀비탕·온담탕·천왕보심단 등 → 신문·내관·조해·백회

## 소화
소화불량·더부룩함·조기포만 → 비위기허·담음·식적·간울 → 육군자탕·향사육군자탕·반하사심탕 등 → 족삼리·중완·내관·공손

## 피로·회복
기력저하·병후 회복·냉감 → 기허·혈허·기혈양허·신허 → 인삼·황기·당귀·숙지황·녹용과 보익 처방 → 족삼리·기해·관원·태계
