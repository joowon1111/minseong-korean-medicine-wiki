# 임상근거 수준과 연구설계

근거수준은 단순히 위아래 서열만 의미하지 않습니다. 연구 질문에 따라 필요한 설계가 다릅니다.

| 연구 | 주로 알 수 있는 것 |
|---|---|
| 증례·증례군 | 새로운 임상 관찰과 가능성 |
| 관찰연구 | 실제 진료에서의 연관성과 경향 |
| 무작위 대조시험 | 특정 조건에서 중재의 비교효과 |
| 체계적 문헌고찰 | 여러 연구의 전체적인 방향 |
| 메타분석 | 비교 가능한 연구의 정량적 종합 |
| 전임상 연구 | 기전·생물학적 가능성 |

## 한의학 연구에서 추가 확인
변증 기준, 처방 가감, 한약 품질, 침구 프로토콜의 표준화 정도를 함께 봅니다.
