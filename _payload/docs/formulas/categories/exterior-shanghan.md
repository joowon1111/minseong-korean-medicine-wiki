# 해표·상한론 처방 임상 지식망

상한론 처방은 “감기약”이라는 현대 병명 분류보다 **조문의 맥증·한출/무한·오한·발열·번조·구갈·수기·흉협고만**의 조합으로 이해합니다.

## 태양병 대표 처방

- 계지탕 — 영위불화·자한의 구조
- 마황탕 — 표실·무한
- 계지가갈근탕 / 갈근탕 — 항배강수·표증
- 대청룡탕 — 표실과 번조·내열
- 소청룡탕 — 표한과 수음·기침
- 마행감석탕 — 폐열·천해 구조

## 소양·화해

- 소시호탕 — 왕래한열·흉협고만 등 소양병 구조

## 현대 임상에서의 읽기

고전의 조문과 현대 질환명을 일대일로 동일시하지 않고 **증상군·병기·치법**을 매개로 연결합니다.
