# 원혈(原穴) 임상 지식망

원혈은 각 경맥과 장부의 상태를 살펴보고 치료할 때 중요하게 다뤄지는 특정혈입니다.

## 12원혈
폐 LU9 태연 · 대장 LI4 합곡 · 위 ST42 충양 · 비 SP3 태백 · 심 HT7 신문 · 소장 SI4 완골 · 방광 BL64 경골 · 신 KI3 태계 · 심포 PC7 대릉 · 삼초 TE4 양지 · 담 GB40 구허 · 간 LR3 태충

음경의 원혈은 오수혈의 수혈과 일치하고, 양경에는 별도의 원혈이 있습니다.

## 임상 연결
원혈은 해당 경맥의 대표 원위혈 성격을 이해하는 데 도움이 되며, 표리경의 락혈과 함께 [원락배혈](yuan-luo-pairs.md)로 연결합니다.
