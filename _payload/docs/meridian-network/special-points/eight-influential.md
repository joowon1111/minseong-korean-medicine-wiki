# 팔회혈(八會穴) 임상 지식망

팔회혈은 장·부·기·혈·근·맥·골·수의 여덟 기능축을 대표하는 특정혈입니다.

## 팔회혈 전체

| 분류 | 회혈 | 연결 |
|---|---|---|
| 장회 | LR13 장문 | 오장·비위·복부 |
| 부회 | CV12 중완 | 육부·위장 |
| 기회 | CV17 전중 | 기·흉부·호흡·심계 |
| 혈회 | BL17 격수 | 혈·어혈·혈분 |
| 근회 | GB34 양릉천 | 근·건·관절 |
| 맥회 | LU9 태연 | 맥·폐경 |
| 골회 | BL11 대저 | 골·척추 |
| 수회 | GB39 현종 | 수·골수·근골 |

## 임상적으로 연결하기

팔회혈은 단독으로 쓰는 공식보다 **증상·변증·해당 경맥과 함께** 봅니다.

- 근골격: GB34 양릉천, BL11 대저, GB39 현종
- 혈·어혈: BL17 격수
- 소화·육부: CV12 중완
- 흉민·호흡·기: CV17 전중
- 맥·폐: LU9 태연
