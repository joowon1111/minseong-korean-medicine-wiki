# 팔맥교회혈(八脈交會穴) 임상 지식망

팔맥교회혈은 십이경맥의 혈이 기경팔맥과 연결되는 지점을 보여주는 중요한 배혈 체계입니다.

## 여덟 교회혈

| 경혈 | 연결 기경 | 대표 짝 |
|---|---|---|
| SP4 공손 | 충맥 | PC6 내관 |
| PC6 내관 | 음유맥 | SP4 공손 |
| GB41 족임읍 | 대맥 | TE5 외관 |
| TE5 외관 | 양유맥 | GB41 족임읍 |
| SI3 후계 | 독맥 | BL62 신맥 |
| BL62 신맥 | 양교맥 | SI3 후계 |
| LU7 열결 | 임맥 | KI6 조해 |
| KI6 조해 | 음교맥 | LU7 열결 |

## 네 가지 대표 조합

### 공손 + 내관
충맥·음유맥. 복부·흉부·소화·심계·여성 증상 연결에 자주 언급됩니다.

### 족임읍 + 외관
대맥·양유맥. 측면부·소양경·두면부·옆구리 영역과 연결해 봅니다.

### 후계 + 신맥
독맥·양교맥. 척주·경항·후두·수면/각성 축과 연결됩니다.

### 열결 + 조해
임맥·음교맥. 흉부·인후·호흡기·하복부와 음교맥의 수면 연결을 함께 봅니다.
