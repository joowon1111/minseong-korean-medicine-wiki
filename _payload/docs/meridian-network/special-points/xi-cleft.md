# 극혈(郄穴) 임상 지식망

극혈은 경맥의 기혈이 깊이 모이는 곳으로 설명됩니다. 전통적으로 **급성·통증성·출혈성 증상**과 연결해 활용해 왔습니다.

## 십이경맥 극혈

| 경맥 | 극혈 |
|---|---|
| 폐 | LU6 공최 |
| 대장 | LI7 온류 |
| 위 | ST34 양구 |
| 비 | SP8 지기 |
| 심 | HT6 음극 |
| 소장 | SI6 양로 |
| 방광 | BL63 금문 |
| 신 | KI5 수천 |
| 심포 | PC4 극문 |
| 삼초 | TE7 회종 |
| 담 | GB36 외구 |
| 간 | LR6 중도 |

## 기경 극혈
KI8 교신 — 음교맥  
BL59 부양 — 양교맥  
KI9 축빈 — 음유맥  
GB35 양교 — 양유맥

## 임상 연결
급성 통증·출혈 등 전통적 적응을 현대 임상에 그대로 대입하지 않고, 해당 경맥과 증상·안전성을 함께 봅니다.
