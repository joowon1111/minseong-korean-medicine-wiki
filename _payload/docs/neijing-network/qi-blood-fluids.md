# 황제내경 기·혈·진액

기·혈·진액은 서로 독립된 물질 목록이 아니라 **생성·운행·영양·윤택·회복을 설명하는 연결축**입니다.

## 기
기허·기체·기역·기함 등을 기능과 방향의 변화로 봅니다.

## 혈
혈허·어혈·출혈 등을 영양과 운행의 문제로 봅니다.

## 진액
담음·습·조燥·진액부족을 수분대사와 윤택의 문제로 봅니다.

## 복합병증
비위기허+담음 / 기혈허+어혈 / 음허+허열처럼 여러 병리가 함께 나타날 수 있습니다.
