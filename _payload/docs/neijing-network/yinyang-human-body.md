# 황제내경의 음양과 인체

음양은 신체 현상을 둘로 고정 분류하는 표가 아니라 **상대적이고 변화하는 관계를 읽는 기본 틀**입니다.

## 임상에서 보는 축
- 상·하
- 표·리
- 한·열
- 동·정
- 기능·물질
- 흥분·회복

## 팔강과 연결
팔강의 표리·한열·허실 판단을 음양의 큰 틀에서 종합할 수 있지만, 실제 환자에서는 여러 축이 동시에 나타납니다.

## 임상적 주의
현대의 자율신경·호르몬·면역기능과 음양을 그대로 동일시하지 않습니다. 전통적 설명 수준과 현대 생리학의 설명 수준을 구분합니다.
