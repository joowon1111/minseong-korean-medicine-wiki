# 사상 처방 임상 라이브러리

사상 처방은 **소양인이면 무조건 소양인 처방 하나**처럼 선택하지 않습니다.

`체질 → 평소 소증 → 현재 체질병증 → 표리·한열 → 순증/역증·경중 → 치법 → 처방 → 경과평가`

## 소양인 처방군

- 형방도적산
- 형방사백산
- 양격산화탕

세 처방은 모두 소양인 처방이라는 공통점이 있지만 **표리병증, 열의 위치와 정도, 대변·구갈·흉민 등 현재 증후**를 구분해 봅니다.

## 다른 체질 처방군

소음인·태음인·태양인 역시 체질명보다 각 체질의 병증 단계와 소증 변화를 우선합니다.

## 처방을 읽는 항목

- 출전과 원문 병증
- 구성 본초와 역할
- 원방의 용량·제형
- 적용되는 체질병증
- 비슷한 처방과 감별
- 복용 후 경과평가
- 현대 임상연구가 있다면 대상군·중재·결과지표
