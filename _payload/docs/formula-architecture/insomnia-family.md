# 안신·불면 처방 계열

| 처방 | 중심 구조 |
|---|---|
| 귀비탕 | 심비양허·기혈부족 |

| 천왕보심단 | 심신음혈부족·허열·심계 |
| 온담탕 | 담·심계·불면 |
