# 보익·회복 처방 계열

보익 처방은 **기허 → 혈허 → 기혈양허 → 신허·정혈부족** 가운데 어느 축이 중심인지에 따라 구조가 달라집니다.

- 사군자탕·보중익기탕 — 보기
- 사물탕 — 보혈
- 팔물탕·십전대보탕 — 기혈쌍보
- 귀비탕 — 심비·기혈
- 육미지황환·팔미지황환 — 신음·신양
- 공진단·경옥고 — 전통 보익 제형
