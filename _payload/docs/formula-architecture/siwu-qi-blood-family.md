# 사물탕·기혈쌍보 처방 계열

사물탕은 **숙지황·당귀·백작약·천궁**으로 보혈·양혈·행혈의 균형을 이루고, 사군자탕 계열과 결합하면서 기혈쌍보 구조로 확장됩니다.

| 처방 | 구조 |
|---|---|
| 사물탕 | 보혈 기본방 |
| 팔물탕 | 사군자탕 + 사물탕 |
| 십전대보탕 | 팔물탕 + 황기·육계 |
| 귀비탕 | 기혈보익 + 심비·안신 |

→ [혈허](../diagnostics/patterns/blood-deficiency.md) · [기혈양허](../diagnostics/patterns/qi-blood-deficiency.md)  
→ [기허·혈허·기혈양허 감별](../diagnostics/differentials/qi-vs-blood-vs-qi-blood.md)

## 임상 연결
어지럼·창백·수면저하·병후 회복·여성 생리 변화에서 혈허와 기허의 비중을 함께 봅니다.
