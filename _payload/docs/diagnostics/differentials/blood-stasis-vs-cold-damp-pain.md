# 어혈성 통증 vs 한습성 통증

| 항목 | 어혈 | 한습 |
|---|---|---|
| 통증 | 고정·찌름·압통 | 무겁고 뻣뻣함 |
| 계기 | 외상·수술·만성화 | 추위·습기·날씨 |
| 온열 반응 | 다양 | 따뜻하면 편한 경우가 많음 |
| 동반 | 혈색·월경 변화 | 냉감·부종·묽은변 |
| 본초축 | 당귀·천궁·단삼·도인 | 독활·강활·창출·의이인 |
| 처방축 | 당귀수산·소경활혈탕 | 오적산·독활기생탕 |

실제 환자에서는 어혈과 한습이 함께 나타날 수 있고 오래되면 기혈허·신허가 겹칠 수 있습니다.

## 경혈
어혈축: 격수 BL17 · 혈해 SP10 · 태충 LR3  
한습·비증축: 양릉천 GB34 · 위중 BL40 · 음릉천 SP9
