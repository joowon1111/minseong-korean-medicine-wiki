# 한의학 통합 임상추론

임상추론의 목적은 증상명 하나에서 처방이나 경혈로 바로 점프하지 않는 것입니다.

## 기본 흐름

**환자 주소 → 위험신호 → 일반의학적 감별 → 팔강 → 장부·기혈진액 변증 → 치법 → 한약·침구 → 근거·안전성 → 재평가**

## 1. 환자의 말에서 시작
'허리가 아파요', '잠이 안 와요', '소화가 안 돼요'처럼 실제 주소를 먼저 구조화합니다.

## 2. 위험신호
응급·중증 질환 가능성을 먼저 확인합니다.

## 3. 일반 감별
근골격·신경·심혈관·소화기·호흡기 등 현대 의학적 원인을 필요한 범위에서 감별합니다.

## 4. 한의학적 변증
팔강으로 큰 방향을 잡고 기허·혈허·담음·어혈·간울·신허 등으로 구체화합니다.

## 5. 치료 설계
치법을 정한 뒤 본초·방제와 경맥·경혈·치료수단을 연결합니다.

## 6. 근거와 안전성
전통적 사용, 임상연구, 안전성, 환자 선호와 현실적인 치료목표를 함께 봅니다.

## 7. 재평가
주증뿐 아니라 기능·수면·소화·피로·삶의 질과 이상반응을 함께 확인합니다.
