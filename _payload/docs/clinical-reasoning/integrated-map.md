# 통합 임상추론 지도

| 단계 | 핵심 질문 |
|---|---|
| 주소 | 환자가 실제로 가장 불편한 것은? |
| 위험신호 | 즉시 검사·의뢰가 필요한가? |
| 일반 감별 | 어떤 질환군을 우선 배제·확인할까? |
| 팔강 | 표리·한열·허실의 방향은? |
| 세부변증 | 기혈진액·장부·경락 중 무엇이 중심인가? |
| 치법 | 보·사·온·청·화담·활혈 등 방향은? |
| 치료 | 어떤 본초·방제·경혈·치료수단인가? |
| 근거 | 어떤 수준의 연구가 있는가? |
| 안전 | 금기·상호작용·해부학적 위험은? |
| 재평가 | 무엇이 얼마나 변했는가? |

## 임상에서 중요한 점
진단명과 한의 변증을 일대일로 대응시키지 않습니다. 같은 질환에서도 환자마다 변증과 치료목표가 달라질 수 있습니다.
