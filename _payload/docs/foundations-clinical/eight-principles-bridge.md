# 기초이론→팔강변증 연결

팔강은 복잡한 기초이론을 환자의 현재 병증에 적용할 때 큰 방향을 잡아줍니다.

**병위 → 표리**  
**성질 → 한열**  
**정기와 병리의 관계 → 허실**  
**전체 방향 → 음양**

팔강 판단 뒤에는 기허·혈허·담음·어혈·간울·신허 등 세부변증으로 내려갑니다.
