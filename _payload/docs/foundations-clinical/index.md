# 한의학 기초→임상 연결 지식망

기초이론은 정의를 암기하는 데서 끝나는 것이 아니라 **환자의 실제 증상을 구조화하는 언어**로 이어져야 합니다.

## 임상으로 내려가는 흐름
**음양·오행 → 장부 → 기혈진액 → 팔강 → 세부변증 → 치법 → 본초·방제·경혈 → 재평가**
