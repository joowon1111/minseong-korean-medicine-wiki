# 변증에서 치법·치료로

변증은 처방명을 맞히는 과정이 아니라 **치료 방향을 결정하는 과정**입니다.

| 변증 | 대표 치법 방향 |
|---|---|
| 기허 | 보기·건비 |
| 혈허 | 보혈·양혈 |
| 담음 | 화담·이기·건비 |
| 어혈 | 활혈·거어 |
| 한습 | 온리·산한·거습 |
| 간울 | 소간·이기 |
| 신허 | 자음·온양·익정 등 세분 |

## 치료수단
치법을 정한 뒤 본초·방제, 경맥·경혈, 침·전침·약침 등을 환자 상태에 맞게 선택합니다.
