# 황제내경

《황제내경》은 《소문》과 《영추》를 중심으로 **음양오행·장부·경락·병기·양생·침구**의 기본 틀을 보여주는 대표 고전입니다.

## 임상 핵심
음양·한열·허실 / 장부와 기혈진액 / 경락·경맥 / 병인·병기 / 계절·양생을 서로 연결해 읽습니다.

## 경락·침구
《영추》의 경맥·자법 논의는 현재 위키의 12경맥·임독맥·기경팔맥·특정혈 지식망을 이해하는 고전적 배경입니다.

→ [경락·경맥 임상 지식망](../meridian-network/index.md)
→ [특정혈](../meridian-network/special-points/index.md)

## 현대적으로 읽기
고전의 생리·병리 개념을 현대 해부학적 구조와 그대로 동일시하지 않고 전통적 임상추론 체계로 이해합니다.
