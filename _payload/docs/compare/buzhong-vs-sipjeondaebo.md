# 보중익기탕 vs 십전대보탕

| 항목 | 보중익기탕 | 십전대보탕 |
|---|---|---|
| 중심 | 기허·중기하함 | 기혈양허 + 온보 |
| 핵심 | 황기·인삼 + 승마·시호 | 팔물탕 + 황기·육계 |
| 단서 | 처짐·무력·활동 후 악화 | 피로·창백·냉감·회복저하 |
| 치료 | 보기승양 | 기혈쌍보·온보 |
