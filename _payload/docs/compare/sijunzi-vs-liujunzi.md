# 사군자탕 vs 육군자탕

| 항목 | 사군자탕 | 육군자탕 |
|---|---|---|
| 중심 | 비위기허 | 비위기허 + 담음 |
| 구조 | 인삼·백출·복령·감초 | 사군자탕 + 반하·진피 |
| 단서 | 피로·식욕저하·묽은변 | 기허 + 오심·더부룩함 |
| 치료축 | 보기건비 | 보기건비 + 화담이기 |

육군자탕은 보기건비 골격에 반하·진피가 더해진 구조로 이해합니다.
