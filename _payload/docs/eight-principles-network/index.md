# 팔강변증(八綱辨證) 임상 지식망

팔강은 **표·리, 한·열, 허·실, 음·양**의 네 쌍을 통해 복잡한 증후를 큰 방향에서 정리하는 기본 변증 틀입니다.

## 네 축
- [표 vs 리](exterior-interior.md) — 병위가 겉에 가까운지 안에 깊은지
- [한 vs 열](cold-heat.md) — 냉·열 양상의 방향
- [허 vs 실](deficiency-excess.md) — 정기의 부족과 사기의 성함
- [음 vs 양](yin-yang.md) — 앞의 여러 판단을 종합하는 상위 축

## 임상 순서
**환자 주소 → 위험신호 → 병위(표리) → 성질(한열) → 정사 관계(허실) → 음양 종합 → 장부·기혈진액 변증 → 치법 → 본초·방제·경혈**

팔강 하나만으로 처방을 결정하지 않고 장부변증·기혈진액·육경·사상체질 등 다른 체계와 함께 봅니다.
