# 태양인·소양인·태음인·소음인

사상체질은 체형·성격 한 가지로 결정하지 않습니다. 평소 소화·대소변·땀·수면·냉열·피로와 현재 병증을 함께 봅니다.

## 네 체질
### 태양인
고전적 상역·구토·하지 기능 등의 병증을 신중히 봅니다.

### 소양인
대변·구갈·열감·흉협·수면·소화의 패턴을 중요하게 봅니다.

### 태음인
발한·호흡·흉부·대변·피부·체액대사를 함께 봅니다.

### 소음인
소화력·복부 냉감·대변·발한·사지냉감·피로를 자세히 봅니다.
