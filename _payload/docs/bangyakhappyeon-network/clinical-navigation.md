# 방약합편 임상 탐색법

**환자 증상 → 위험신호 → 변증 → 치법 → 상·중·하통 처방군 → 구성 본초 → 유사 처방 감별 → 현대 임상 연결**

## 예시
피로 → 기허/기혈양허/신허 → 보익 → 관련 처방군  
소화불량 → 비위기허/담음/식적/간울 → 건비·화담·이기  
통증 → 한습/어혈/허증 → 거풍습·활혈·보익
