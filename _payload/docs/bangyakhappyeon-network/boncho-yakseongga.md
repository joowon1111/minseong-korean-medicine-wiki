# 방약합편 본초·약성가

약성가는 본초의 핵심 성질과 효능을 기억하기 쉽게 압축한 형식입니다.

## 확장해서 읽기
**약성가 핵심어 → 기원·약용부위 → 성미·귀경 → 효능 → 주치 → 약대 → 대표 방제 → 현대 연구 → 안전성**

## 대표 탐색축
인삼·황기 → 보기  
당귀·숙지황 → 보혈  
반하·진피 → 화담이기  
두충·우슬 → 근골·간신  
산조인·원지 → 안신
