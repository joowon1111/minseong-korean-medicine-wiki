# 경혈 임상 지식망

경혈은 하나의 증상에 하나의 혈을 대응시키기보다 **경맥·부위·변증·배혈 구조와 치료 목표** 속에서 이해하는 것이 중요합니다.

이 지식망에서는 개별 경혈에서 시작해 **증상 → 변증 → 배혈 → 침·전침 등 치료 → 관련 방제·본초 → 현대 임상근거**로 이어서 살펴볼 수 있습니다.

## 배혈 조합으로 보기

경혈은 단독혈보다 **치료 목표에 맞는 조합**으로 이해하면 임상적인 의미가 더 분명해집니다.

- **족삼리 + 중완 + 내관** → 비위·소화·오심·흉완부
- **신문 + 내관 + 인당** → 수면·심계·긴장
- **대장수 + 위중 + 곤륜** → 요부와 방광경 하지 연결
- **삼음교 + 관원 + 태충** → 여성·하복부·기혈
- **양릉천 + 족삼리 + 음릉천** → 무릎·근건·수습
- **열결 + 합곡 + 인당** → 호흡기·비부·두면부

## 방제·본초와 함께 보기

침구와 한약을 단순히 같은 효능으로 대응시키기보다 **공통되는 병증과 치법**을 중심으로 연결합니다.

- 비위허약: 육군자탕·향사육군자탕 ↔ 족삼리·중완·내관
- 수면·심계: 귀비탕·산조인탕 ↔ 신문·내관·인당
- 한습·어혈성 통증: 오적산·소경활혈탕 ↔ 대장수·위중·곤륜
- 여성 냉증·어혈: 온경탕·계지복령환 ↔ 삼음교·관원·태충
- 기허·회복저하: 보중익기탕·십전대보탕 ↔ 족삼리·기해·관원

침구 연구에서는 단일 경혈뿐 아니라 실제 임상과 유사한 **복합 배혈 프로토콜**이 폭넓게 사용됩니다. 연구를 살펴볼 때에는 대상 질환, 사용 경혈, 자침·전침 방법, 치료 횟수, 평가변수와 추적기간을 함께 확인합니다.
