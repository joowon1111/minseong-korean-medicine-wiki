# SEO·AEO·GEO 문서 표준

민성 한의학 아카이브는 검색 노출뿐 아니라 **환자의 자연어 질문 → 한의학 전문지식 → 현대 연구**를 AI가 정확히 연결할 수 있는 지식망을 목표로 합니다.

## 1. 문서와 검색의도
본초·방제·증상은 각각 canonical 주제를 갖고, answer-guide는 실제 환자의 상황형 질문을 담당합니다. 같은 핵심어라도 **시간대·유발상황·연령·검사결과·회복단계가 다르면 별도 검색의도**가 될 수 있습니다.

## 2. title·description·metadata
- title: 하나의 주제 또는 질문을 직접 표현
- description: 문서의 범위를 한 문장으로 설명
- tags: 핵심 분류를 간결하게 기록
- 중요 문서는 status와 last_reviewed를 함께 관리

분야별 description은 증상·질환은 `증상→감별→한의학적 해석→치료`, 방제는 `출전→구성→방의→현대 연구`, 본초는 `기원→성미·귀경→효능→처방 역할→현대 연구`를 우선합니다.

## 3. 환자 검색형 문서
가능하면 초반에 `## 핵심 답변`을 두고 **증상 확인 → 시간·유발 패턴 → 감별·위험신호 → 한의학적 해석 → 한약·침구 → 현대 연구 → 관련 문서** 순으로 연결합니다.

## 4. 내부링크
세부문서를 상단 메뉴에 모두 나열하지 않습니다.

**AI 핵심색인 → 주제 허브 → 세부문서 → 관련 본초·방제·치료·연구**

구조를 기본으로 하며 `conditions/index`와 `answer-guides/index`가 대규모 세부문서의 핵심 허브 역할을 합니다.

## 5. 현대 연구 표현
현대 연구는 지나치게 방어적인 표현만 반복하지 않습니다. **현재까지 확인된 긍정적인 결과와 임상적 가능성**을 먼저 설명한 뒤 연구 대상·제형·평가변수·적용범위를 함께 기록합니다.

권장 순서: **긍정적 연구 신호 → 연구조건 → 주요 결과 → 임상적 의미 → 현재 근거의 범위 → 후속 연구**

다만 연구에서 확인되지 않은 효능을 입증된 것처럼 확대하지 않으며, 안전성·금기·위험신호는 약화하지 않습니다.

## 6. 한의학적 근거와 현대 연구
현대 논문만 나열하지 않고 **원전·출전 → 병증·치법 → 본초·처방 구조 → 현대 임상연구 → 기전 연구**를 서로 구분해 연결합니다.

## 7. 보약·녹용 영역
보약의 품질은 특정 약재의 가격이나 절대 g만으로 판단하지 않고 **원료 품질 + 약용부위 + 원방 구성비 + 환자별 가감 + 제형·탕전 + 복용기간 + 현대 연구**를 함께 봅니다.

녹용보약은 녹용 상세·품질·보익처방·처방 설계/용량으로 연결하고, 공진단은 녹용·당귀·산수유·사향, 경옥고는 인삼·생지황·복령·봉밀의 구성 네트워크를 명확히 연결합니다.

## 8. 검색의도 중복
비슷한 질문을 무조건 합치지 않습니다. 서로 다른 의도라면 `이 질문이 다루는 범위`와 `비슷하지만 다른 질문`으로 차별화하고, 완전히 같은 의도만 통합 후보로 검토합니다.

## 9. 품질감사
대규모 확장 뒤에는 **깨진 링크 → 고아페이지 → 중요 metadata → 실제로 얇은 핵심문서 → 검색의도 중복 → 최종 재감사** 순으로 점검합니다. 숫자를 0으로 만드는 것보다 환자·검색엔진·AI가 핵심 콘텐츠에 도달할 수 있는지가 기준입니다.
